 ABSTRACT
 This report serves as an introduction, tutorial, and benchmark specification for out-of-pile
tests on metallic fuel. It introduces a new user to the EBR-II legacy fuel performance test
program and the fast reactor fuel performance databases built to preserve the records. It then
details the information stored in each database and how to find it. Benchmark specifications are
included for a small set of out-of-pile tests on U-10Zr fuel to function as a tutorial demonstrating
how the legacy fuel performance data sets stored in the FIPD and OPTD databases can be used
together to benchmark fuel performance models for steady-state and transient performance.

1 Introduction
 1.1 Overview
 The Metallic Fuels Irradiation Physics Database (FIPD) and the Out-of-Pile Transient
Database (OPTD) were created as part of an extensive effort to preserve valuable SFR fuels
knowledge collected during the Integral Fast Reactor (IFR) program [1, 2]. The IFR fuel testing
program included examination of Experimental Breeder Reactor-II (EBR-II)-irradiated fuel
pins after normal steady-state operation in the reactor as well as pins exposed to simulated
transient conditions such as loss-of-flow and loss-of-heat-sink. The most comprehensive set of
legacy data related to transient performance of metallic fuels was collected via out-of-pile
testing in furnaces at the Alpha-Gamma Hot Cell Facility (AGHCF) at Argonne National
Laboratory; the results demonstrate good metallic fuel survivability under design basis accident
conditions. The legacy data on metallic fuel performance in EBR-II and simulated transient
testing was made available to stakeholders via the FIPD and OPTD web-accessible databases
in [3] and [4], respectively, and efforts since have focused on supporting the increased
utilization of the databases for advanced nuclear fuels and materials research and development,
including to support the safety case for tested fuels and to develop and validate models used for
evaluation of fuel performance. This report is intended to serve as a user guide and tutorial for
utilizing FIPD and OPTD data to benchmark both steady-state and transient fuel performance
models. It presents an example benchmarking data set for U-10Zr fuel with HT9 cladding to
model fuel pins from their as-fabricated condition through steady-state irradiation in EBR-II
and then through overheating in transient-simulating furnaces at the AGHCF. Information is
provided to allow a model to be developed with 2 stages: stage one modeling the steady-state
irradiation and using post-irradiation examination data to check the result, and stage 2 beginning
from the as-irradiated state and modeling the out-of-pile transient test conditions, comparing
the result with post-test examination data.
 The report is structured as follows:
 Section 1 provides an overview of the databases.
 Section 2 describes the typical history and records of a fuel pin subjected to a steady state
irradiation in EBR-II and subsequent out-of-pile transient testing.
 Section 3 describes the EBR-II and out-of-pile furnace apparatus geometry and
instrumentation.
 Section 4 describes and provides benchmark data for overheating tests on EBR-II-irradiated
U-10Zr/HT9 fuel pin segments (FBTA tests), including where to find it in the databases.
 Section 5 describes and provides benchmark data for an overheating test conducted on an
intact, irradiated U-10Zr/HT9 EBR-II fuel pin (WPF test FM-1), including where to find it in
the databases.

 1.2 Metallic Fuels Irradiation and Physics Database (FIPD)
 The Metallic Fuels Irradiation and Physics Database (FIPD) is an organized collection of
EBR-II and Fast Flux Test Facility (FFTF) test pin data and documentation. The FIPD database
contains the information needed to model the steady-state irradiation of a fuel pin in EBR-II. It
includes pin operation conditions calculated using a collection of ANL analysis codes

 9

developed during the IFR program, including axial distributions for power, temperature,
fluence, burnup, and isotopic density. The database also contains measured pin data from
fabrication and post-irradiation examination (PIE), including pin fission gas release and gas
chemistry measurements, and axial distributions from profilometry, gamma scans, and neutron
radiography. There is also an extensive collection of documents associated with different pins
and experiments, including raw PIE data, design descriptions, safety analysis, and operational
reports. A detailed overview of FIPD content is in ref. [1] and the qualification process for
metallic fuel data in ref. [5].

 1.3 Out-of-Pile Transient Database (OPTD)
 The Out-of-Pile Transient Database (OPTD) is an organized, searchable archive of records
describing a series of out-of-pile furnace transient tests conducted on metallic fuel samples at
the AGHCF. The OPTD contains the information required to model the response of an
irradiated fuel pin to a simulated overheating transient. During the out-of-pile test program, fuel
pins (or pin segments) previously irradiated in EBR-II were placed into one of two furnace
apparatuses constructed in the AGHCF and overheated to examine the fuel-cladding
compatibility of each sample, margins to failure, and failure mechanisms. Records describing
the design, planning, and execution of the tests are included in the database as are test summary
reports, experimenter’s notes, and pre- and post-test examinations of the test samples. Key
experimental data for comparison with modeled results include measured cladding diameters
(for computing strain), metallography images (to identify fuel-cladding interaction thresholds
and depth of penetration into cladding), and failure time and location for whole-pin tests.
 A comprehensive test summary report is available on OSTI with at-a-glance summary
information for each of the out-of-pile furnace tests, including information about the tested fuel
samples, test conditions, purpose of the tests, and key results [2]. The structure and content of
OPTD has been detailed in prior reports [6, 7]. The pre- and post-test pin examination data
preserved in OPTD is included in the ongoing metallic fuels data qualification efforts described
ref. [5].

2 Life of a Tested EBR-II Metallic Fuel Pin
 This section describes the history of a fuel pin from fabrication through steady-state
irradiation and subsequent out-of-pile furnace transient testing. It also describes typical records
of the process and pin examinations and where to find those records in the databases.

 2.1 Pin Fabrication
 All IFR EBR-II fuel pins were fabricated at one of the related fuel fabrication facilities at
Argonne National Laboratory-West, at the EBR-II site [8]. U-Pu-Zr experimental pins were
fabricated at the Experimental Fuels Laboratory (EFL), which was established in April of 1984
after the positive acceptance of the IFR concept, while the U-Zr experimental pins were
fabricated at the Fuel Manufacturing Facility (FMF), along with the driver fuel pins. The
injection-casting fabrication process is described in detail in ref [8]. All the fuel pins that were
loaded into EBR-II were examined after fabrication to ensure that they met the design
dimensional requirements and tolerances prior to assembly.
 After fabrication, each pin was individually measured and as-fabricated data was recorded,
generally including fuel slug length, fuel slug mass, fuel slug diameter, fuel element (fuel pin)
mass, sodium bond mass, and xenon tag gas volume and tag ID.
 The fuel slug chemistry was also measured. Experimental slugs for each experiment were
fabricated in a series of casting batches. Separate casting batches were required for slugs of
different nominal compositions in the experiment (e.g., U-10Zr, U-8Pu-10Zr, U-19Pu-10Zr)
and in some cases these compositions were further split into multiple batches for practical
reasons. For each casting batch of experimental fuel slugs, at least one spare fuel slug was cast
specifically to be used for composition measurement. This sacrificial fuel pin underwent
chemical analysis and measured the weight fractions of uranium, plutonium and zirconium, as
well as the isotopic fractions of various uranium isotopes (U-234, U-235, U-236, U-238) and
plutonium isotopes (Pu-239, Pu-240, Pu-241, Pu-242). It is assumed that all the pins cast in the
same batch have the same chemical composition, so the weight fractions measured from the
sacrificial fuel slug can be multiplied out with the measured weight of each of the experimental
slugs to determine the weights of the various constituents in each slug.
 As these measurements were performed at the time of experiments during the IFR program,
records of these measurements are not always recoverable. The available data varies based on
which records remain for each experiment. All available data is stored in FIPD, with additional
data being added if and when it is discovered. In addition to measured fabricated data, nominal
design data is also available. There is generally enough design information available to
reproduce an experimental fuel pin, as shown in Figure 1.

 2.2 EBR-II Irradiation
 After fabrication, experimental test pins were wire-wrapped and loaded into hexagonal fuel
assemblies, shown schematically in Figure 2. Most experimental assemblies consisted of 61
pins, but several experiments studied larger diameter fuel slugs, which were loaded in 37 or 19
pin assemblies as required to fit in the assembly dimensions.

 Figure 2: Schematic representation of EBR-II wire-wrapped fuel pin and 37 pin fuel assembly.

 12

 Experimental assemblies were loaded into the EBR-II reactor core for a series of operational
periods, typically referred to as EBR-II runs. These runs were named sequentially from the start
of EBR-II operations (Run 1, August 1964) up to the when the reactor was shut down (Run
170B, September 1994). Starting with Run 26, related segments of a given operating period
started being labeled with letters, e.g., “Run 26” consisted of segments Run 26A, Run 26B, and
Run 26C.
 The IFR program started in 1993 with U-Pu-Zr metallic fuel testing starting in EBR-II in
Run 133A (February 1985) and continuing through the end of reactor operations with Run 170B
(September 1994). Experimental assemblies were loaded into the reactor for different runs
based on the desired experimental conditions. Experiments were also often removed from the
reactor, disassembled, and reconstituted before reinsertion into the reactor so that measurements
could be taken on the experimental pins at multiple times during the irradiation history. If the
pins underwent non-destructive examination, then they could be reloaded for additional
irradiation time if desired. If pins were selected for destructive examination, then they could
not be reloaded into the reactor and were instead replaced in the assembly with either fresh
experimental fuel pins from the experimental campaign or with standard driver fuel pins, often
referred to as “filler” pins, as they were typically only included to fill out the assembly and not
examined after irradiation. Like EBR-II runs, if experimental assemblies were reconstituted for
additional irradiation, the reconstitutions were labeled with sequential letters, e.g., experimental
assembly X425 consisted of subassemblies X425, X425A, X425B, X425C.
 Operating records for the EBR-II runs are also stored in FIPD. For many IFR EBR-II runs,
digital records include reactor power level and gas measurements of various krypton and xenon
isotopes. These digital data were originally recorded in the Germanium-Lithium Argon-
Scanning System (GLASS) measurement system [9, 10] in one-minute resolution. The EBR-II
power history in the GLASS dataset was adopted from the DAS (Digital data Acquisition
System) [10], which was recorded by an ion chamber [11]. A typical example of the power
ramp up history for a single day is shown in Figure 3.

 Figure 3: Example of digital EBR-II reactor power history for a single day.

produces the axial shape factors for linear power and flux, along with the time history of the
average power, fast flux, and coolant mass flux. Optionally, calculated time- and axially-

 2.3 Post Irradiation Examination
 After a period of irradiation, a variety of post irradiation examinations of the pins were
conducted, primarily at the Hot Fuel Examination Facility (HFEF). Non-destructive PIE was
conducted for some pins midway through their full irradiation in EBR-II (as mentioned
previously). Destructive PIE was done on pins at the end of their final irradiation run. PIE data
is available for a variety of pin-level measurements, including irradiated pin length and mass,
plenum gas measurements including volume, pressure, and temperature, and plenum gas
chemistry, which provides an isotopic breakdown of the plenum gas. Axial pin profiles are also
available for a variety of measurements, including contact and laser profilometry, neutron
radiography, and isotopic gamma scans for a variety of isotopes. The list of most relevant PIE
data is given in Table 1. These measurements are not available for every experimental pin, but
available PIE can be found in FIPD.

 Contact & Laser Profilometry cladding strain

 Neutron radiography fuel swelling or motion

 Weight data fuel pin weight
 Metallography data fuel, cladding, & interface characterization

 Profilometry measures the cladding outer diameter using either physical contact (contact
profilometry) or a laser (laser profilometry). Profilometry measurements are often compared
with the fresh fuel cladding diameter to measure cladding strain after irradiation. An example
of a contact profilometry measurement is given in Figure 7, and an example of laser
profilometry measurements are given in Figure 8. Detailed specifications for these
measurements are available in refs. [14, 15].

 2.4 Out-of-Pile Testing
 Some fuel pins irradiated in EBR-II were subsequently shipped from the HFEF to the
AGHCF for additional examination and out-of-pile testing in one of two furnace apparatuses.
The cladding wastage region resulting from the steady state irradiation has a lower melting
point and is therefore vulnerable to liquefaction at the high temperatures reached during
transient events. The out-of-pile tests evaluated transient performance of the test segments by
heating them to representative transient temperatures. This could result in additional
interdiffusion of cladding and fuel constituents. At sufficiently high temperature, a two-phase
solid/eutectic mixture formed in this reacted region and penetration of the liquid eutectic could
extend through the pre-existing solid-state interdiffusion band and deeper into previously
unaffected cladding.
 The Fuel Behavior Test Apparatus (FBTA) tests were conducted on more than 140 fuel pin
segments at 625°C – 850°C for durations of a few minutes up to 36 hours (most for 1 hour).
Tested pin segments were binary and ternary fuel pins (U-xPu-10Zr, x = 0 to 26) with HT9, D9,
or 316 stainless steel cladding and peak burnups from 2.3 to 17 at.%. A few tests were also
conducted on ternary fuels with varying Zr content. The results of the FBTA tests established
the time- and temperature-dependence of eutectic cladding penetration in the metallic fuel
samples as well as rough threshold temperatures for liquefaction. The Whole Pin Furnace
(WPF) tests were conducted on intact fuel pins from EBR-II, rather than segments, to study
synergistic effects of fission gas pressure loading and fuel-cladding interaction. Seven WPF
tests determined modes and mechanisms of pin failure, established safety margins and fuel
failure thresholds, and examined fuel motion within the pin.

 Furnace Transient Test
 To begin a furnace overheating transient test, a sample was installed in the furnace and
slowly ramped to a pre-test, priming temperature by the integrated computer control system.
The prescribed furnace transient routine then increased the temperature at a set ramp rate
selected to represent a rapid temperature rise to the target test temperature. The sample was held
at the target temperature for a prescribed duration or until pin failure was detected (for WPF
failure tests). The furnace was scrammed when the test end condition was met. The sample was

 21

allowed to cool naturally by convective heat loss. Each furnace apparatus included
instrumentation for live monitoring and measurement of the test environment during the test.
 The original digital files have not been recovered, but plots of the time-resolved instrument
measurements are available for many tests. Because the procedure and experimental setup for
the FBTA tests was standardized, it is reasonable to assume that tests conducted for the same
time and at the same temperature experienced roughly the same temporally resolved
temperature history. In other words, absent other information, we can assume the same
temperature ramp rate (generally 5-8°C/s), a relatively small and short-duration overshoot of
the target temperature (<10°C), and consistent temperature reading for the duration of the test
(+/- 2°C). An example temperature history for an FBTA test is shown in Figure 16.

3 Experiment Hardware and Instrumentation
 3.1 Experimental Breeder Reactor-II
 The EBR-II plant was designed and operated by Argonne National Laboratory for the U.S.
Department of Energy. Operation began in 1964 and continued until 1994. EBR-II is a
heterogeneous, sodium cooled fast breeder reactor designed to produce a thermal power of 62.5
MW with an electric output of approximately 20 MW.
 The EBR-II reactor vessel and its components are illustrated in Figure 20. The vessel grid-
plenum assembly accommodated 637 hexagonal subassemblies. The grid is divided into three
main regions: core, inner blanket (IB) and outer blanket (OB). Figure 21 illustrates the
subassembly arrangement of the reactor and the subassembly identification convention. Each
subassembly position was identified by a unique combination of three parameters: row, sector
and position within the sector. Subassembly row identification begins at Row 1 at the
subassembly in the core-center and moves outward to Row 16. Row 1 had one subassembly.
Row 2 had six subassemblies. From Row 2 outward to Row 14, each row had 6 more
subassemblies than the last.

 Figure 20: EBR-II Reactor Vessel and Neutron Shield Assembly. [21]

Each row was broken up into six sectors A through F. As each row approximated a hexagon,
each side of the row was assigned to one of the six sectors. The final parameter needed to
identify a subassembly position is the position within the sector. The line of subassemblies
dividing sectors A and F were defined as the subassemblies in position 1 of their respective

 25

rows within sector A. The line of subassemblies that divide sectors A and B are therefore
defined as the subassemblies in position 1 of their respective rows within sector B. This pattern
continues for the remaining four sides of the core layout. As an example, the subassembly
labeled as CR#10 in Figure 21 is positioned in subassembly location 5B3, where 5 is the row,
B is the sector and 3 is the position within the sector.

 Figure 21: EBR-II Core Layout. [21]

 The central core comprised the 61 subassemblies in the first five rows. An example core

 3.2 Fuel Behavior Test Apparatus
 The Fuel Behavior Test Apparatus (FBTA) allowed for isothermal heating of small test
specimens to investigate fuel/cladding interaction at elevated temperature conditions typically
found during a transient event [22]. It was comprised of an instrumented in-cell test rig
including the furnace and test chamber, a furnace control system, and fission gas detection and
collection systems [23]. The FBTA was instrumented with a thermocouple on the sample
holder, a linear-variable-displacement-transducer (LVDT), and a fission gas detector. The
experimental setup in the FBTA test chamber is shown in Figure 23.

 Figure 23: Experimental setup of the Fuel Behavior Test Apparatus (FBTA).

FBTA Furnace
 The FBTA utilized a 10” high quad-elliptical radiant heat furnace with four longitudinal
infrared filament bulbs allowing for rapid heating along the furnace centerline (up to 30°C/s in
small metallic IFR samples). The aluminum body of the furnace was cooled by recirculating
glycol coolant dissipating heat to an out-of-cell copper plate chiller.
FBTA Test Samples
 The FBTA only allowed for testing of short segments of fuel pins (< 10mm tall). The tested
samples were ~8mm tall sections cut from along the axial height of irradiated, clad fuel pins.
The ends of each sample were open and the cladding free of stress.
FBTA Test Chamber
 The FBTA test chamber contained a Tantalum cup sample holder (~10mm tall) that was set
atop a pedestal. This setup was enclosed by two concentric quartz tubes. A high-purity helium
flow through the inner tube provided an inert atmosphere for the test.

 27

Instrumentation
 A bare-wire Pt/Pt-Rh thermocouple was welded to the outside of the tantalum sample holder
to measure sample temperature, and a linear-variable-displacement-transducer (LVDT)
measured the vertical movement of a hold-down rod resting on the top surface of the test
specimen. The LVDT was affixed to the top of the hold-down rod and was intended to measure
fuel expansion or contraction during the test. The hold-down rod imparted a load of ~0.1MPa
to the sample.
Computer furnace control and data acquisition system
 Microcomputer control of the furnace power was based on feedback from the thermocouple
measuring the sample temperature. Instrumentation was integrated with a Data Acquisition
system (DAQ) which collected time-resolved measurements and saved them to digital data
files.
Fission gas detection and collection systems
 The helium flow through the inner quartz tube carried with it any fission gas released during
the test. An out-of-cell ionization chamber monitored the 85Kr activity over time. A gas
collection station was also available to collect the released Xe and Kr for later sampling and
analysis.

 3.3 Whole Pin Furnace
 The Whole Pin Furnace (WPF) was a taller radiant furnace with a more prototypical axial
temperature gradient designed to test intact fuel pin specimens within an evacuated and sealed
stainless-steel test section [24]. A fuel pin is a complex system that includes not only the fuel
and cladding, but also the filled sodium, filled gas, and any released fission gases in the plenum.
The WPF was established to examine the synergistic effects of fuel-cladding interactions like
those observed in the FBTA tests with other phenomena like fission gas pressure loading. The
WPF was comprised primarily of an in-cell furnace rig, a furnace control system, and a fission-
gas measurement system. A photograph of the WPF apparatus before installation in the hot cell
is in Figure 24.

 Figure 24: Whole Pin Furnace Apparatus.

 The WPF test section was instrumented with six thermocouples in the annulus along the
height of the fuel pin and two pressure transducers to detect pressure changes within the test
capsule. A schematic of the WPF test chamber including thermocouple elevations for test FM-
1 is shown in Figure 25. Note that the fuel, Na, and plenum relative locations are approximated
in the figure.

WPF Furnace
 The whole pin furnace was a radiant heating chamber with a 25” tall heating zone and
prototypical axial temperature gradient. It was powered by four longitudinal infrared-filament
lamps backed with elliptical reflective surfaces to focus the radiant energy at the furnace
centerline (with ~1” radial diameter), where the test pin would be placed. The relative height of
the test pin within the furnace could be adjusted to obtain the desired furnace temperature profile
in a particular region of the fuel pin. The furnace was capable of rapidly heating test pins at
rates up to 30°C/s. At steady state, the furnace had a large uniform temperature zone (~14” tall).
A representative steady-state axial temperature profile produced through the heating zone of
the WPF is shown in Figure 26, normalized to the temperature in the peak heating zone at the

Instrumentation

 Once-molten fuel debris was found adjacent to the failure site in the pin/containment tube
annulus, with fuel-cladding mixture on the inside and outside cladding diameter having thinned
the cladding from both directions. The post-test pin had radially non-uninform thinning of
cladding around the inside perimeter at the fuel-cladding interface due to metallurgical
interaction. Significant molten-phase cladding penetration extended to a maximum of 64% of
the cladding thickness at the failure location. Fission-gas pressure loading coupled with
cladding wall thinning resulted in the breach. When the cladding failed, the fission-gas pressure
forced bond sodium and molten fuel/cladding material through the breach and into the annulus.
Much of the bond sodium drained to the bottom of the test section, and the molten eutectic
continued to thin the cladding near the breach from the outside. Metallography revealed retained
fission gas bubbles coalesced in a narrow band of once-molten material surrounding the
unmelted fuel slug. The breach measured roughly 1500 µm long x 75 µm wide. Images of the
crack and termination point are in the Databook. Pretest predictions were that WPF pins would
fail at the fuel top, but the fuel/cladding gap was found to be open at the top of the FM-1 test
pin after steady-state irradiation in EBR-II, which prevented fuel-cladding interaction and
failure at that location.

6 Summary
 The FIPD and OPTD databases developed by the ART Fast Reactor Program are valuable
resources for understanding metallic fuel performance under ordinary operating and transient
conditions. Qualitative and quantitative fuel performance data are readily available to serve as
benchmarks for validation and verification of computational models. Data sourced from FIPD
and OPTD were used to generate benchmark specifications for 9 FBTA furnace tests on U-
10Zr/HT9 fuel pin segments and the WPF FM-1 test on a whole U-10Zr/HT9 pin. Isolation,
digitization, and qualification of the legacy data in both databases is part of an ongoing effort,
with many high-priority data sets already completed. More information about all the ART Fast
Reactor Databases is available at frdb.ne.anl.gov. Requests for access to the databases can be
made by contacting frp@anl.gov.

  APPENDIX A – EBR-II STEADY STATE CALCULATED OPERATING CONDITIONS
 The time-varying linear power, fast flux, and coolant mass flux are provided in FIPD in the
MOOSE/BISON PiecewiseLinear format [27], which provides the comma-separated time
values followed by the comma-separated measurement values. For example, average linear
power is provided as (t0,P0), (t1,P1), (t2,P2), etc.:
    t0,t1,t2,t3,t4,t5,t6,…
    P0,P1,P2,P3,P4,P5,P6,…

 The axial shape factors for linear power and fast flux are provided in FIPD in
MOOSE/BISON PiecewiseMultilinear format [28], which provides the shape factor as a
function of axial position and time (although the shape factors provided are assumed to be
constant over time). The first line provides the comma-separated axial locations. Each
subsequent line provides the time value for the line, followed by comma-separated
measurement values along the axial dimension for that time. For example, linear power is
provided as (t0,z0,P(t0,z0)), (t0,z1,P(t0,z1)), (t0,z2,P(t0,z2)), etc.:
    z0,z1,z2,z3,z4,z5,z6….
    t0,P(t0,z0),P(t0,z1),P(t0,z2),P(t0,z3),P(t0,z4),P(t0,z5),P(t0,z6),…
    t1,P(t1,z0),P(t1,z1),P(t1,z2),P(t1,z3),P(t1,z4),P(t1,z5),P(t1,z6),…
 …
 The time- and axially-varying linear power and flux histories can be generated by
multiplying out the axial profile with the average time history or each parameter.
 Since the original motivation for these generated functions was for use in BISON, the
generated values use SI units as expected by BISON. All times are provided in seconds, lengths
are provided in meters, linear power is provided in watts / meter, fast neutron flux is provided
in neutrons / square meter / second, coolant mass flux is provided in kilograms / square meter /
second, and the optional temperature boundary conditions are provided in degrees Celsius.
