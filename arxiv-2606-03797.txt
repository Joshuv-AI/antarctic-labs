Convergence of an algorithm for constructing Lyapunov functions for switched systems using meshfree collocation
Jay Ward ∗1 , Nicos Georgiou 1 and Peter Giesl 1

Abstract
. Switched systems are a class of dynamical systems where trajectories switch between different systems based on a switching rule. This rule can depend on time and/or the position of the trajectory in the state space. The existence of a Lyapunov function implies the existence of a uniformly asymptotically stable equilibrium point at the origin, which we prove in this paper. A method to construct Lyapunov functions for switched systems using meshfree collocation and quadratic programming was described in a related article. We prove that, under suitable assumptions, the algorithm described in this previous work converges as the fill distance between the collocation points tends to zero.

1.
Introduction

Lyapunov functions are a useful tool to show stability properties of a dynamical system and to determine the basin of attraction of equilibria. When a dynamical system is expressed as a system of differential equations, a (strict) Lyapunov function is a positive function that decreases along solutions of the system. For a smooth function this is equivalent to having a negative orbital derivative. The existence of a Lyapunov function implies that the system has an equilibrium point that is stable and attractive. The basin of attraction of the equilibrium point can be determined through sublevel sets of the Lyapunov function. For background, see
[
26
]
,
[
17
]
and
[
19
]
.

A construction method for Lyapunov functions for autonomous ODEs is developed in
[
13
]
. Meshfree collocation is used to find an approximation to the PDE
DV(\mathbf{x})=-\|\mathbf{x}\|^{2}
, where
D
represents the orbital derivative. To do this, finitely many collocation points are selected and the norm-minimal function such that the PDE is satisfied at these points is found. This method is extended in
[
9
]
where an approximate solution to a system of partial differential inequalities is found using quadratic programming. The approximate solution has been shown to converge to the solution of the system of partial differential inequalities as the fill distance decreases
[
10
]
.

It is useful to construct Lyapunov functions for a variety of dynamical systems, including switched systems. Switched systems are a family of dynamical systems where a switching rule determines which system is
“switched on”
. This switching rule can depend on time and/or position in the state space. Switched systems where time-dependent switching takes place are called arbitrary switched systems, and systems where state-dependent switching occurs are called variable structure systems. These systems have widespread applications in science, engineering and economics, e.g. water quality control, manufacturing systems, or aircraft control. An overview of switched systems can be found in
[
20
]
and a review of results related to the stability of such systems can be found in
[
7
]
.

Many methods have been developed to construct Lyapunov functions for switched systems. One such method is the algorithm developed in
[
14
]
to construct Continuous and Piecewise Affine (CPA) Lyapunov functions for arbitrary switched systems. This was then developed further to construct CPA Lyapunov functions for strongly asymptotically stable differential inclusions in
[
2
]
and
[
3
]
, and control CPA Lyapunov functions for weakly asymptotically stable differential inclusions in
[
4
]
. The algorithm was advanced in
[
15
]
and
[
16
]
and applied to variable structure examples. A different algorithm has been developed to construct Lyapunov functions for switched systems in
[
21
]
using meshfree collocation and quadratic programming.
A usual assumption in the literature is that the switched system follows one switching rule; however, the switched system defined in
[
21
]
allows switching based on time and/or position in the state space. To construct a Lyapunov function for this system, an approximate solution to a system of partial differential inequalities
D_{i}V(\mathbf{x})\leq{b_{i}(\mathbf{x})}
is found, where
i
indicates the system that is
“switched on”
,
D_{i}
is the orbital derivative with respect to
i
and
b_{i}
is a non-positive function which is zero at the equilibrium. In this paper, we show that under suitable assumptions the approximate solution converges to a solution
V
of the system of partial differential inequalities.

2.
Switched systems

In this paper, we consider switched systems that allow arbitrary switching, variable structure switching, or a combination of the two. We define a corresponding Lyapunov function and state the conditions needed for uniform asymptotic stability of the equilibrium point. The switched system we are considering is defined in (
2.1
) in the same way as in
[
21
]
. Systems are defined on subsets of the state space, with the union of these subsets making up the whole state space. The subsets may overlap; wherever this occurs, the system may switch arbitrarily to a different trajectory. This set-up was discussed in
[
20
]
, and it was stated that this switched system will have an asymptotically stable equilibrium point if there exists a Lyapunov function for each system in the region where it is defined. This allows multiple Lyapunov functions to be considered, as done in
[
5
]
and
[
18
]
. On the other hand,
[
21
]
states a theorem that the existence of a single Lyapunov function for a switched system implies that it has an asymptotically stable equilibrium point. We prove a stronger statement within this section: the existence of a Lyapunov function implies uniform asymptotic stability of the equilibrium point.

In Section
2.1
we define a switched system and a Lyapunov function for the system. We also list the assumptions we have on this system in Assumptions
2.2
. In the following Section
2.2
, we define what is means for this switched system to have a uniformly asymptotically stable equilibrium point, and show that a sufficient condition for uniform asymptotic stability is the existence of a Lyapunov function. This result is given in Theorem
2.7
.

3.1.
Reproducing kernel Hilbert spaces

The solution
v
to the minimisation problem (
3.10
), see Section
3.2
, belongs to a reproducing kernel Hilbert space
H
. We recall various properties of these spaces within this section, as well as specifying the reproducing kernel
\Phi:{\mathbb{R}}^{d}\times{\mathbb{R}}^{d}\rightarrow{\mathbb{R}}
we will be using in the construction of the function
v
in Section
4.4
. For more information on reproducing kernel Hilbert spaces, see
[
24
]
.

Definition 3.1
.

(Reproducing Kernel Hilbert Space (RKHS))

Let
\varnothing\neq\Omega\subseteq{\mathbb{R}}^{d}
. A Hilbert space
H=H(\Omega)
of continuous functions
f:\Omega\rightarrow{\mathbb{R}}
with inner product
\langle\cdot,\cdot\rangle_{H}
is called a reproducing kernel Hilbert space, abbreviated RKHS, if there is a function
\Phi:\Omega\times\Omega\rightarrow{\mathbb{R}}
with

(1)

\Phi(\cdot,\mathbf{x})\in{H}
for all
{\mathbf{x}\in\Omega}

(2)

g(\mathbf{x})=\langle{g(\cdot),\Phi(\cdot,\mathbf{x})}\rangle_{H}
for all
g\in{H}
and all
\mathbf{x}\in\Omega
.

The function
\Phi
is called the reproducing kernel of
H
. The reproducing kernel is called positive definite if for any pair of pairwise distinct points
\{x_{1},...,x_{N}\}\subseteq\Omega
the matrix
(\Phi(x_{i},x_{j}))_{i,j=1,...,N}
is positive definite.

As in
[
10
]
, the reproducing kernel Hilbert spaces that we consider are Sobolev spaces
H=H^{\alpha}(\Omega)
. We use the definition of the Sobolev space
W^{k,p}(\Omega)
found in
[
25
]
and set
H^{\alpha}(\Omega)=W^{\alpha,2}(\Omega)
so that for
\alpha\in{\mathbb{N}}_{0}

(3.3)

H^{\alpha}(\Omega):=\{u\in{L_{2}}(\Omega):|\beta|\leq\alpha,D^{\beta}u\in{L_{2}}(\Omega)\}

with scalar product
\displaystyle\langle{u,v}\rangle=\sum_{|\beta|\leq\alpha}\int_{\Omega}D^{\beta}u(\mathbf{x})D^{\beta}v(\mathbf{x})d\mathbf{x}
. If
\alpha
is not an integer, then we use operator interpolation theory to define the space and norm, for more details see
[
1
]
and
[
6
]
.

The following two lemmas will be used multiple times in Section
3.3
, in the proof of both Theorem
3.5
and Lemma
3.6
.

Lemma 3.2
.

If
\Omega\subseteq{\mathbb{R}}^{d}
is a bounded domain with Lipschitz boundary, then the space
H^{\alpha}(\Omega)
for
\alpha>d/2
is a RKHS.

Proof.

If
\Omega\subseteq{\mathbb{R}}^{d}
is a bounded domain with Lipschitz boundary, then there exists a continuous linear extension operator
[
24
]

E:H^{\alpha}(\Omega)\rightarrow{H^{\alpha}({\mathbb{R}}^{d})}
. This has the properties
Eu\big|_{\Omega}=u
and
\|Eu\|_{H^{\alpha}({\mathbb{R}}^{d})}\leq{C\|u\|_{H^{\alpha}(\Omega)}}
for all
u\in{H^{\alpha}(\Omega)}
with a fixed constant
C>0
. As stated in
[
10
]
, a consequence of the existence of the extension operator is the Sobolev embedding theorem for
H^{\alpha}(\Omega)
, which tells us that
H^{\alpha}(\Omega)\subseteq{C(\Omega)\cap{L_{\infty}(\Omega)}}
if
\alpha>d/2
. As this is a continuous embedding, we have that
\|f\|_{C(\Omega)\cap{L_{\infty}(\Omega)}}\leq{C\|f\|_{H^{\alpha}(\Omega)}}
for some
f\in{H^{\alpha}(\Omega)}
. The first norm can be rewritten as follows
\|f\|_{C(\Omega)\cap{L_{\infty}(\Omega)}}=\max_{x\in\Omega}|f(x)|
, which tells us that

|f(x)|\leq\max_{x\in\Omega}|f(x)|\leq{C\|f\|_{H^{\alpha}(\Omega)}}\Rightarrow|\delta_{x}(f)|\leq\max_{x\in\Omega}|\delta_{x}(f)|\leq{C\|f\|_{H^{\alpha}(\Omega)}}.

This shows continuity of the point evaluations
\delta_{x}:H^{\alpha}(\Omega)\rightarrow{\mathbb{R}}
, so our space
H^{\alpha}(\Omega)
is a RKHS
[
24
]
.
∎

The explicit form of the reproducing kernel of
H^{\alpha}(\Omega)
is usually unknown. To find a suitable substitute we use the following Lemma
3.3
which can be found in
[
10
]
and was developed with results from
[
24
]
.
The method of finding a suitable reproducing kernel for
H^{\alpha}(\Omega)
can be summarised as follows: choose a reproducing kernel
K_{\alpha}(\mathbf{x},\mathbf{y})
that delivers an equivalent norm to the standard norm on
H^{\alpha}({\mathbb{R}}^{d})
, and restrict it to find a reproducing kernel
k_{\alpha}(\mathbf{x},\mathbf{y})
for
H^{\alpha}(\Omega)
. A reproducing kernel
K_{\alpha}
that delivers this equivalent norm can be chosen to be a translation-invariant function
\Phi_{\alpha}(\mathbf{x}-\mathbf{y})
with certain properties on its Fourier transform.
\Phi_{\alpha}
can be chosen to be radial and, in particular, a Wendland function (see
[
10
]
), which we discuss further in (
3.4
).

Lemma 3.3
.

Assume
\Phi_{\alpha}\in{L_{1}({\mathbb{R}}^{d})}\cap{C({\mathbb{R}}^{d})}
has a Fourier transform
\hat{\Phi}_{\alpha}
satisfying

c_{1}(1+\|w\|_{2}^{2})^{-\alpha}\leq{\hat{\Phi}_{\alpha}(w)}\leq{c_{2}(1+\|w\|_{2}^{2})^{-\alpha}}

where
c_{1},c_{2}>0
are constants,
w\in{\mathbb{R}}^{d}
and
\alpha>d/2
. Let
\Omega\subseteq{\mathbb{R}}^{d}
be a bounded domain with a Lipschitz boundary. Let
k_{\alpha}:\Omega\times\Omega\rightarrow{\mathbb{R}}
be defined by
k_{\alpha}(\mathbf{x},\mathbf{y})=\Phi_{\alpha}(\mathbf{x}-\mathbf{y})
,
\mathbf{x},\mathbf{y}\in\Omega
. Then there exists an inner product
\langle\cdot,\cdot\rangle_{k_{\alpha}}:H^{\alpha}(\Omega)\times{H^{\alpha}(\Omega)}\rightarrow{\mathbb{R}}
on
H^{\alpha}(\Omega)
such that
k_{\alpha}
is the reproducing kernel of
H^{\alpha}(\Omega)
with respect to this inner product. The norm
\|\cdot\|_{k_{\alpha}}
induced by this inner product is equivalent to the standard norm on
H^{\alpha}(\Omega)
, i.e. there are constants
C_{1},C_{2}>0
such that

C_{1}\|u\|_{k_{\alpha}}\leq\|u\|_{H^{\alpha}(\Omega)}\leq{C_{2}\|u\|_{k_{\alpha}}}

Proof.

For
\alpha\in{\mathbb{N}}
, this is Corollary 10.48 from
[
24
]
. For real
\alpha>d/2
this then follows by interpolation theory
[
10
]
.
∎

In the construction of the function
v\in{H}
we are using meshfree collocation. This method has been applied to the construction of Lyapunov functions for autonomous ODEs in
[
13
]
and
[
9
]
. Following the methods explained here we assume that the reproducing kernel
\Phi
of the Hilbert space
H
is given by a radial basis function
\Psi_{0}
through
\Phi(\mathbf{x},\mathbf{y})=\Psi_{0}(\|\mathbf{x}-\mathbf{y}\|_{2})
.

For this radial basis function we use Wendland functions, which are a family of functions introduced in
[
22
]
and
[
23
]
. Wendland functions are positive definite with compact support, and are polynomials on their support. We define
\Psi_{0}(r):=\phi_{\ell,k}(cr)
, where
\phi_{\ell,k}(cr)
is a Wendland function with
c>0
,
k\in{\mathbb{N}}
a smoothness parameter and
\ell=\lfloor\frac{d}{2}\rfloor+k+1
. The reproducing kernel Hilbert space that corresponds to this Wendland function is norm-equivalent to the Sobolev space
H^{k+(d+1)/2}({\mathbb{R}}^{d})
. Wendland functions are defined by recursion: for
\ell\in{\mathbb{N}}
,
k\in{\mathbb{N}}_{0}

(3.4)

\begin{split}\phi_{\ell,0}(r)&=(1-r)_{+}^{\ell}\\
\phi_{\ell,k+1}(r)&=\int_{r}^{1}t\phi_{\ell,k}(t)dt\end{split}

for
r\in{\mathbb{R}}_{0}^{+}
, where
y_{+}=y
if
y\geq{0}
and
y_{+}=0
otherwise.

Using recursion, define
\Psi_{j}(r)=\displaystyle\frac{1}{r}\frac{d\Psi_{j-1}}{dr}(r)
for
j=1,2
and
r>0
. Note that
\lim_{r\rightarrow{0}}\Psi_{j}(r)
exists if the smoothness parameter

of the Wendland functions is sufficiently large.

3.2.
Discretised problem

We now discretise our problem. Fix collocation points

(3.5)

\mathbf{z}^{1},\dots,\mathbf{z}^{N}\in\Omega\text{ where }Z:=\{\mathbf{z}^{1},\dots,\mathbf{z}^{N}\}

where
N
is the total number of collocation points, and take subsets of these points

(3.6)

X_{i}:=Z\cap{C_{i}}=\{\mathbf{x}_{i}^{1},\dots,\mathbf{x}_{i}^{L_{i}}\}

for
i=1,\dots,k
, where
0\leq L_{i}\leq{N}
is the number of collocation points in the subset
C_{i}
. We have that
X_{i}\subseteq{Z}
for all
i\in{I}
, and

Z=\bigcup_{i\in{I}}X_{i}.

The sets
X_{i}
are not necessarily distinct as the sets
C_{i}
can overlap.

We can now define

(3.7)

b_{i}^{1}=b_{i}(\mathbf{x}_{i}^{1}),\dots,b_{i}^{L_{i}}=b_{i}(\mathbf{x}_{i}^{L_{i}})\in{\mathbb{R}},

and seek to find a function
v\in{H}
that satisfies

(3.8)

D_{i}v(\mathbf{x}_{i}^{\ell})\leq b_{i}^{\ell}\text{ for all }\ell=1,\dots,L_{i}

for
i=1,\dots,k
.

Another way to express (
3.8
) would be to find a function
v\in{H}
using the information
b_{i}^{\ell}\in{\mathbb{R}}
generated by the functionals
\lambda_{i}^{\ell}\in{H}^{*}
, i.e.
\lambda_{i}^{\ell}(v)\leq b_{i}^{\ell}
for all
i=1,\dots,k
and
\ell=1,\dots,L_{i}
. We define these functionals as the orbital derivative with respect to
\mathbf{f}_{i}
(
3.1
) applied at a particular collocation point
\mathbf{x}_{i}^{\ell}
, i.e.

(3.9)

(\lambda_{i}^{\ell})v(\cdot):=(\delta_{\mathbf{x}_{i}^{\ell}}\circ{D_{i}})v(\cdot)=\nabla{v}(\mathbf{x}_{i}^{\ell})\cdot\mathbf{f}_{i}(\mathbf{x}_{i}^{\ell})

for all
i=1,\dots,k
and
\ell=1,\dots,L_{i}
, with
\delta
being Dirac’s delta distribution.

The optimal reconstruction of
v
is then given by the solution of the problem

(3.10)

\min\{\|v\|_{H}:v\in{H}\text{, }\lambda_{i}^{\ell}(v)\leq b_{i}^{\ell}\text{, for all }i=1,\dots,k\text{ and }\ell=1,\dots,L_{i}\}.

We now state the following lemma which is similar to one in
[
9
]
, which shows that this minimisation problem has at most one solution.

Lemma 3.4
.

The problem (
3.10
) has at most one solution.

Proof.

Assume
s\in{H}
is a minimiser and
v\in{H}
is a solution of

(3.11)

\lambda_{i}^{\ell}(v)\leq b_{i}^{\ell}\text{, for all }i=1,\dots,k\text{ and }\ell=1,\dots,L_{i}.

Then
\langle{s,v-s}\rangle_{H}\geq{0}
. We assume in contradiction to this that
\langle{s,v-s}\rangle_{H}<{0}
. For
\alpha\in[0,1]
,
t=\alpha{v}+(1-\alpha)s
satisfies (
3.11
) and

\|t\|_{H}^{2}=\|s+\alpha(v-s)\|^{2}_{H}=\|s\|_{H}^{2}+2\alpha\langle{s,v-s}\rangle_{H}+\alpha^{2}\|v-s\|_{H}^{2}<\|s\|_{H}^{2}

for a suitable choice of
\alpha
. This is a contradiction to
s
being a minimiser.

Now let
s_{1},s_{2}\in{H}
be minimisers. This implies that both
\langle{s_{1},s_{2}-s_{1}}\rangle_{H}
and
\langle{s_{2},s_{1}-s_{2}}\rangle_{H}
are greater than or equal to zero, giving

0\leq\|s_{1}-s_{2}\|_{H}^{2}=\langle{s_{1},s_{1}-s_{2}}\rangle_{H}-\langle{s_{2},s_{1}-s_{2}}\rangle_{H}\leq{0}

which shows
s_{1}=s_{2}.

∎

.

Let

Let

be continuous functions and let

(

(3.12)

\begin{cases}\text{\rm{minimise }}\|v\|_{H}\\
\text{\rm{subject to }}D_{i}v(\mathbf{x}_{i})\leq{b_{i}}(\mathbf{x}_{i})\text{, }\forall{i=1,\dots,k}\text{\rm{ and }}\mathbf{x}_{i}\in{C_{i}}\end{cases}

and the sequence of optimisation problems:

For

we choose points

for

\theta=1,\dots,\Theta
and
m=1,\dots,M^{\theta}
.

From this point onward when we refer to the functionals
\lambda_{j}^{m,\theta}
we mean the definition (
4.11
) but replacing
p_{j}^{\theta}
with the components
p_{j}^{m,\theta}
from the vector
P^{m,\theta}
(
4.16
).

For notational convenience we now define

(4.17)

\rho^{\theta}:=\sum_{m=1}^{M^{\theta}}\rho^{m,\theta},\phantom{x}\rho:=\sum_{\theta=1}^{\Theta}\sum_{m=1}^{M^{\theta}}\rho^{m,\theta}\text{ and }{\mathcal{P}}:=\sum_{\theta=1}^{\Theta}\sum_{m=1}^{M^{\theta}}{\mathcal{P}}^{\theta}.

From (
4.16
) we have that the functionals
\lambda_{j}^{m,\theta}
for
j=1,\dots,\rho^{m,\theta}
are a basis for the whole set of functionals with
j=1,\dots,{\mathcal{P}}^{\theta}
. Therefore, the functionals at the point
\mathbf{y}^{m,\theta}
are expressed as a linear combination of this basis and we write this as

(4.18)

\lambda_{\sigma}^{m,\theta}=\sum_{j=1}^{\rho^{m,\theta}}\alpha_{\sigma,j}^{m,\theta}\lambda_{j}^{m,\theta}

for all
\sigma=1,\dots,{\mathcal{P}}^{\theta}
, for some appropriate
\alpha_{\sigma,j}^{m,\theta}\in{\mathbb{R}}
. We assemble the coefficients
\alpha_{\sigma,j}^{m,\theta}
for all of the collocation points
\mathbf{y}^{m,\theta}
as elements of a matrix
Q\in{\mathbb{R}}^{{\mathcal{P}}\times\rho}
such that

(4.19)

Q:=\left(\begin{array}[]{c}I\\
\tilde{Q}\end{array}\right)

where
I
is the
\rho\times\rho
identity matrix accounting for the coefficients
\alpha_{s,j}^{m,\theta}
for
\theta=1,\dots,\Theta
,
m=1,\dots,M^{\theta}
,
s,j=1,\dots,\rho^{m,\theta}
and
\tilde{Q}
is a block diagonal matrix that contains the remaining coefficients. The structure of this matrix is described in
[
21
]
.

4.4.
Quadratic programming problem

We now wish to show that the solution of (
4.12
) with the functionals
\lambda_{j}^{m,\theta}
defined above is of the form

(4.20)

v(\mathbf{x})=\sum_{\theta=1}^{\Theta}\sum_{m=1}^{M^{\theta}}\sum_{j=1}^{\rho^{m,\theta}}\beta_{j}^{m,\theta}(\lambda_{j}^{m,\theta})^{\mathbf{y}}\Phi(\mathbf{x},\mathbf{y})

where the coefficients
\beta_{j}^{m,\theta}
are elements of the vector
\boldsymbol{\beta}\in{\mathbb{R}}^{\rho}
which satisfies

(4.21)

\begin{cases}\text{\rm{minimise }}\boldsymbol{\beta}^{T}A\boldsymbol{\beta}\\
\text{\rm{subject to }}QA\boldsymbol{\beta}\leq\mathbf{b}\end{cases}

To find the matrices
Q
and
A
we applied our functionals to our proposed solution (
4.20
) and used the inequalities in (
4.12
).

The elements of
A\in{\mathbb{R}}^{\rho\times\rho}
are

(4.22)

a_{i,j}^{\eta,\theta;\ell,m}:=(\delta_{\mathbf{y}^{m,\theta}}\circ{D_{p_{j}^{m,\theta}}})^{\mathbf{x}}(\delta_{\mathbf{y}^{\ell,\eta}}\circ{D_{p_{i}^{\ell,\eta}}})^{\mathbf{y}}\Phi(\mathbf{x},\mathbf{y})=\langle(\lambda_{j}^{m,\theta})^{\mathbf{x}}\Phi(\cdot,\mathbf{x}),(\lambda_{i}^{\ell,\eta})^{\mathbf{y}}\Phi(\cdot,\mathbf{y})\rangle_{H}

for
\eta,\theta=1,\dots,\Theta
,
\ell=1,\dots,M^{\eta}
,
m=1,\dots,M^{\theta}
,
i=1,\dots,\rho^{\ell,\eta}
and
j=1,\dots,\rho^{m,\theta}
. This matrix is symmetric and accounts for the linearly independent functionals. Applying the matrix
Q
(
4.19
) accounts for the linearly dependent functionals as a linear combination of the independent ones (
4.18
). The values of the vector
\mathbf{b}\in{\mathbb{R}}^{{\mathcal{P}}}
are the elements
b_{j}^{m,\theta}
from the minimisation problem (
4.12
) for all
\theta=1,\dots,\Theta
,
m=1,\dots,M^{\theta}
and
j=1,\dots,{\mathcal{P}}^{\theta}
.

We can also see that minimising
\boldsymbol{\beta}^{T}A\boldsymbol{\beta}
as in (
4.21
) is the same as minimising
\|v\|_{H}
in the following way

\displaystyle\|v\|^{2}_{H}

\displaystyle=

\displaystyle\left\langle\sum_{\eta=1}^{\Theta}\sum_{\ell=1}^{M^{\eta}}\sum_{i=1}^{\rho^{\ell,\eta}}\beta_{i}^{\ell,\eta}(\lambda_{i}^{\ell,\eta})^{\mathbf{y}}\Phi(\cdot,\mathbf{y}),\sum_{\theta=1}^{\Theta}\sum_{m=1}^{M^{\theta}}\sum_{j=1}^{\rho^{m,\theta}}\beta_{j}^{m,\theta}(\lambda_{j}^{m,\theta})^{\mathbf{z}}\Phi(\cdot,\mathbf{z})\right\rangle_{H}

\displaystyle=

\displaystyle\sum_{\eta=1}^{\Theta}\sum_{\ell=1}^{M^{\eta}}\sum_{i=1}^{\rho^{\ell,\eta}}\sum_{\theta=1}^{\Theta}\sum_{m=1}^{M^{\theta}}\sum_{j=1}^{\rho^{m,\theta}}\beta_{i}^{\ell,\eta}\beta_{j}^{m,\theta}\langle(\lambda_{i}^{\ell,\eta})^{\mathbf{y}}\Phi(\cdot,\mathbf{y}),(\lambda_{j}^{m,\theta})^{\mathbf{z}}\Phi(\cdot,\mathbf{z})\rangle_{H}

\displaystyle=

\displaystyle\sum_{\eta=1}^{\Theta}\sum_{\ell=1}^{M^{\eta}}\sum_{i=1}^{\rho^{\ell,\eta}}\sum_{\theta=1}^{\Theta}\sum_{m=1}^{M^{\theta}}\sum_{j=1}^{\rho^{m,\theta}}\beta_{i}^{\ell,\eta}\beta_{j}^{m,\theta}a_{i,j}^{\eta,\theta;\ell,m}

\displaystyle=

\displaystyle\boldsymbol{\beta}^{T}A\boldsymbol{\beta}.

Now we are able to show that if there is a feasible solution to (
4.21
), the solution of (
4.12
) is of the form (
4.20
). We do this with the following lemma and theorem, the proofs of which are found in
[
21
]
.

Lemma 4.3
.

If there is a feasible solution (i.e. a
\boldsymbol{\beta}
that satisfies the constraints) of the problem (
4.21
), then the solution of the minimising problem (
4.21
) is unique.

Theorem 4.4
.

If there is a feasible solution to the problem (
4.21
), the minimiser of the problem (
4.12
) is of the form (
4.20
) where the coefficients
\beta_{j}^{m,\theta}
are determined by the solution of the problem (
4.21
).

Remark 4.5
.

We can check if there is a feasible solution to (
4.21
) computationally; then there exists a unique minimiser to each discretised problem (
3.14
). This is due to Theorem
4.4
as we know that there will exist a Lyapunov function for the system of the form (
4.20
). We choose these functions as our sequence
v_{n}^{\varepsilon}
in Theorem
3.5
with
\varepsilon=0
.

6.
Conclusion

In this paper, we have shown in Theorem
3.5
that the algorithm to construct a Lyapunov function for the switched system (
2.1
) originally presented in
[
21
]
converges under some specific assumptions. One such assumption is that the fill distance (
3.13
) decreases as the number of collocation points increases. In Section
3.4
we gave a way to choose collocation points so that the assumption on the fill distance is met. The construction method from
[
21
]
applies to both arbitrary switched and variable structure systems, as well as systems that have a combination of time- and state-dependent switching. We have provided further details on this method and given two new examples. Another main result is that the existence of a Lyapunov function for a switched system implies that the origin is a uniformly asymptotically stable equilibrium point of the system.

In Theorem
3.5
we also assumed the existence of a function
V_{0}
. In future work, we will provide sufficient conditions for the existence of such a function.
