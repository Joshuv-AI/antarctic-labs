ABSTRACT
This report documents the AMMT program’s development and submission of a draft ASME Code
Case to qualify Laser Powder Bed Fusion (L-PBF) Type 316H stainless steel for Section III, Di-
vision 5 Class A and SM high-temperature nuclear applications. It summarizes the technical basis,
the comprehensive high-temperature mechanical test database assembled between 2023–2026, and
the proposed code language and qualification framework submitted to ASME. The work was co-
ordinated across multiple national laboratories and leverages prior ASME efforts to integrate ad-
ditive manufacturing into the Boiler & Pressure Vessel Code.
The body of the report describes the experimental database and analysis supporting the Code Case:
tensile, creep, fatigue, creep-fatigue, and thermal-aging tests collected from multiple additive man-
ufacturing sites, machine types, and powder lots, with material processed by a solution-anneal heat
treatment. The dataset — including both full-size and subsized specimens and tests oriented par-
allel and perpendicular to build direction — shows limited tensile anisotropy, tensile properties
comparable to wrought 316H, creep strength within the scatter of wrought material, but markedly
reduced creep ductility above about 650 °C associated with rapid σ-phase formation in L-PBF
microstructures.
The draft Code Case itself prescribes a staged qualification model (manufacturing process quali-
fication, component qualification, and per-build witness testing), treats L-PBF components as
equivalent to Type 316 weld metal for design and inspection, and requires mechanical, chemical,
and metallographic controls tied to ASTM/ISO 52946. Key acceptance criteria include tensile tests
within a 90% prediction interval of the AMMT dataset, a creep-fatigue screening test adapted from
ASME Section III, Division 5, Subsection HB, HBB-2800 but with the cycle acceptance reduced
to 100 for L-PBF material, and double volumetric inspection of production components.
The report concludes that the present data support treating L-PBF 316H as analogous to conven-
tional fusion weld metal for Division 5 design and inspection, while highlighting important cave-
ats: the σ-phase-driven loss of creep ductility above ~650 °C, preliminary indications of enhanced
creep-fatigue sensitivity in some lots, and remaining gaps in long-term aging and additional cyclic
testing. Recommended next actions include completing outstanding cyclic and long-duration
creep/aging tests on the solution-annealed condition, supporting inclusion of the 316H chemistry
and heat treatment in ASTM/ISO 52946, and continuing engagement with ASME and NRC during
balloting and review to enable industry adoption.

1 Introduction
This report summarizes work by the Advanced Materials and Manufacturing Technologies
(AMMT) program to develop an ASME Nuclear Code Case to allow the use of the Laser Powder
Bed Fusion (L-PBF) manufacturing process to produce components for high temperature nuclear
service. The Code Case would specifically allow the use of L-PBF 316H stainless steel compo-
nents for Class A and Class SM construction under the rules of Section III, Division 5 of the ASME
Boiler & Pressure Vessel Code. This report describes the technical basis for the Code Case and
documents the draft Code Case submitted to the cognizant ASME Boiler & Pressure Vessel Code
Committees.
If accepted by ASME, the Code Case would be the first set of rules allowing use of additively
manufactured components in high temperature reactor applications. This would be a key achieve-
ment by itself, in addition to the program’s goal of using this Code Case as a testbed to explore
accelerated qualification approaches to address the industry need for a wider palette of qualified
high temperature materials and manufacturing techniques.
The draft Code Case is a key result stemming from many years of work both in the AMMT pro-
gram and at ASME. Specifically, the Code Case combines knowledge and insight from three
streams of technical work:
 1. Work at ASME by the Board on Pressure Technology Codes and Standards Special Com-
 mittee on use of Additive Manufacturing for Pressure Retaining Equipment and other
 ASME Code Committees to develop a basis for how the Boiler Code will handle additively
 manufactured materials. These efforts resulted in approved nuclear Code Cases for low
 temperature Wire Arc Additive Manufacturing (WAAM) components (N-955) and
 draft/in-progress Code Cases for low temperature applications of L-PBF. These efforts
 provide a framework for how ASME expects additively manufactured components to be
 procured and documented and how quality control and assurance will work in the context
 of the Boiler Code.
 2. Work by the AMMT program on process qualification approaches. One key focus of
 AMMT research is on developing improved process qualification techniques, with a par-
 ticular focus on accelerating the qualification of new materials and advanced manufactur-
 ing processes. This work feeds into the approaches used in the draft Code Case to ensure
 process repeatability and material quality/performance.
 3. The high temperature test campaign on L-PBF 316H materials carried out by the AMMT
 program over the past three years. This test program has assembled the most comprehen-
 sive database on the high temperature performance of L-PBF stainless steels to date, in-
 cluding over 120 tension tests, 90 creep tests, and 70 cyclic tests. This test data, along with
 the corresponding material characterization campaign, informed the Code Case approach
 to setting design material data for L-PBF components.
The key features of the draft Code Case are:
 1. Adopting, as much as possible, the precedent developed by earlier ASME low temperature
 and non-nuclear approaches to integrating advanced manufacturing into the Boiler & Pres-
 sure Vessel Code. This includes adopting a common framework for material certification,

 1

 quality, and procurement and a similar, though somewhat modified, approach to process
 qualification and witness test requirements.
 2. A staged approach to qualification where a material supplier would need to demonstrate
 process control, component performance, and continued quality in production builds via a
 combination of mechanical property testing and material characterization. The Code Case
 also allows for more innovative approaches to process qualification provided these alter-
 native methods produce comparable material quality and performance and with agreement
 between the material supplier and the purchaser.
 3. A component design approach that treats the entire L-PBF component as if it was manu-
 factured from a 316H weldment. This approach, supported by the mechanical property
 testing collected by the AMMT program, reuses the robust Section III, Division 5 design
 methods and data for weldments and accelerates the material qualification process by re-
 ducing the testing burden, relative to treating L-PBF 316H as an entirely new material.
 4. An approach to production component inspection and NDE likewise comparable to how
 Section III, Division 5 treats critical (Category A) welded joints. This represents a burden-
 some, though certainly conservative, starting point. ASME may choose to reduce post-
 production inspection requirements as the community accumulates experience with L-PBF
 and other additively manufactured parts in high temperature nuclear service.
A few prior decisions on L-PBF qualification are not discussed in detail in this report but are
prerequisites for understanding the Code Case and the general qualification approach. These in-
clude the selection of 316H as the targeted material chemistry, discussed in [1] and the choice of
the solution annealing heat treatment, documented in [2].
This report first describes the entirety of the mechanical property test database in Chapter 2 and
how that test data supports the Code Case’s approach of treating L-PBF 316H components like
welds in the context of the ASME design rules. Chapter 3 then documents the approach the Code
Case takes to process qualification and component inspection in general terms.
Chapter 4 is a copy of the draft Code Case submitted to ASME for review. Chapter 5 is a com-
mentary on the Code Case, likewise, submitted to ASME. The commentary provides more detailed
technical justification on specific choices made in the Code Case proper (e.g. specific numbers of
tests required, quality control and procurement language, etc.).
Finally, Chapter 6 summarizes the qualification effort and describes next steps. The work is near-
ing completion with the submission of the Code Case to ASME, however some remaining tests
need to be wrapped up in FY27 to provide a complete dataset to underly the choices made in the
Code Case. This chapter also briefly discusses some lessons learned from this initial ASME qual-
ification effort by the AMMT program.

2 The properties of 316H stainless steel manufactured with the L-PBF process
2.1 Summary of key high temperature mechanical properties
This chapter summarizes the mechanical test data on L-PBF 316H generated by the AMMT pro-
gram test activities over three years (2023-2026). The focus of this chapter is on analyzing how
the mechanical properties of the L-PBF material compare to wrought material to support the ap-
proach adopted for the Code qualification: that L-PBF 316H behaves similarly to a conventional
fusion weld made to join wrought 316H. If this hypothesis is true, it greatly accelerates the qual-
ification process as the Code already has an extensive set of design rules and an approach to design
material data for fusion welds.
To this end, this chapter focuses mostly on the test data and average material properties and less
on microstructural interpretation, i.e. why the material has the measured properties. Parallel work
in the AMMT program is addressing microstructural characterization and material optimization.
However, this report does briefly summarize key microstructural connections where relevant for
Code qualification (mostly by reference to other published reports).
To capture variability in the mechanical properties of L-PBF materials manufactured at different
sites, with different machines (and machine manufacturer), and with different lots of 316H powder
this test campaign included samples prepared at three manufacturing sites:
 1. Argonne National Laboratory (ANL)
 2. Oak Ridge National Laboratory (ORNL)
 3. Los Alamos National Laboratory (LANL)
on three different types of fabrication equipment:
 1. Renishaw AM 400 (both ANL and ORNL)
 2. GE Concept Laser M2 (ORNL)
    3. EOS M290 (LANL)
and using five lots of powder with different chemical compositions (see Table 2.1). The objective
of this strategy was to try to capture the variability in actual production. For wrought materials to
meet this objective ASME requires test data from three full-scale commercial heats. ASME cur-
rently does not have a corresponding requirement for L-PBF or other additive manufacturing pro-
cesses, but the distribution of specimens across machine types, manufacturing sites, and powder
lots aims to accomplish a similar objective.

Additionally, test samples were machined and printed so that the direction of load aligned with the
build direction (i.e. vertical samples) and perpendicular to the build direction (i.e. horizontal sam-
ples). By printing and testing both types of samples, this test program ensured that the bound-
ing/worst-case specimen properties would be captured in the test data.
Testing was conducted at ANL, ORNL, and Idaho National Laboratory (INL). Material was typ-
ically printed in large blocks and then specimens machined to the final geometry.
The material tested in the qualification study presented here was all solution annealed for 1 hour
at 1100 °C followed by a water quench. This heat treatment was established first based on a
preliminary set of tests comparing the performance of material with no heat treatment, a stress
relief heat treatment at 650 °C for 24 hours, various solution annealing heat treatments, and hot
isostatic pressing (HIP) [1]. The conclusions of this initial study were that the as-built and stress-
relieved materials had inadequate ductility while the HIP heat treatment did not significantly im-
prove the cyclic properties. This left a solution annealing heat treatment, which produced adequate
ductility without requiring the extra expense of HIP. A follow up study looked at different specific
annealing conditions, concluding that the 1 hour/1100 °C condition provided the best homogeni-
zation/annealing without causing partial recrystallization [2].

The color of the data point indicates the machine used to fabricate the L-PBF materials (or wrought
material in black). The symbol indicates the specimen orientation (for L-PBF) or distinguishes
wrought (circles) from fusion welds (crosses) for the few plots where conventional weldment data
is available. A solid line provides design material data from ASME, typically for 316H weldments.

Figure 2.1 compared the tensile properties of L-PBF 316H to the properties of wrought material.

2.1.2 Creep properties
The ASME Code is primarily concerned with the creep rupture strength of materials, as a factor in
setting allowable stresses and in creep-fatigue design analysis, and the creep deformation rate,
used in the design limits on strain accumulation and to calculate stress relaxation for thermal
stresses. While the Code does not use creep ductility data directly, there is also a general expec-
tation that materials used for Code construction should generally be ductile to allow for strain
redistribution in service, to allow for a leak before break design philosophy, and to dissipated
energy in the event of the failure of a pressurized component. Both the second and third criteria
are less applicable to most high temperature reactors, which will operate at low pressure, but nev-
ertheless the currently qualified Section III, Division 5, Class A and SM high temperature metallic
materials are generally quite ductile in creep.

 Figure 2.5. Creep strength of L-PBF material relative to wrought, summarized on a Larson-Miller diagram.

Figure 2.5 compares the creep strength of wrought material to that of the L-PBF on a Larson-
Miller diagram. The value of 𝐶 for calculating the Larson-Miller parameter, 𝐿𝑀𝑃 = 𝑇(𝐶 + log 𝑡# )
with 𝑇 absolute temperature and 𝑡# the rupture time, for all points on the plot is the same at 𝐶 =
16.54. This value was determined through a lot centered fit to the wrought material data [4].
Because the Larson-Miller 𝐶 is consistent across all the data, this plot fairly compares the strength
of wrought versus L-PBF material. The line is the average Larson-Miller polynomial correlation
to the wrought data, indicating the average strength of wrought material.
This data shows that L-PBF has nearly the same strength as wrought material across a wide range
of creep conditions. The L-PBF material generally splits the average wrought strength (i.e. about
half the samples weaker than wrought and half stronger).
The vertical direction samples tend to be stronger than the horizontal samples, particularly as the
test temperature increases. For matched pairs (i.e. same powder, manufacturer, and test condi-
tions) the vertical strength is greater than the horizontal strength in 50% of samples at 600 °C, 80%
of samples at 725 °C, and 100% of samples at 800 °C. This is consistent with the creep rate, as
discussed below.

Finally, Figure 2.8 compares the creep ductility of the L-PBF material to wrought material. These
plots show the creep ductility as a function of stress at three discrete temperatures. At 600 °C the
L-PBF material ductility is on the low end of the scatter in the wrought ductility. However, at 725
°C and 800 °C the L-PBF creep ductility is exceptionally low – much lower than wrought material.
Parallel work in the AMMT program identified the rapid formation of the intermetallic σ phase as
the culprit behind the reduced creep ductility at the higher temperatures. σ phase embrittlement is
a known issue for 316H, typically in the heat affected zone near welds. AMMT work has demon-
strated that σ formation occurs much more quickly in L-PBF material compared to wrought [5],
though the mechanism explaining the difference is currently unclear.
This rapid fall off in creep ductility sets the temperature limit for the application of L-PBF com-
ponents for Class A construction in the draft Code Case. Chapter 3 discusses the specific rational
behind the actual value of temperature selected for the limit (650 °C), but the intent is to ensure
that any component put into actual service has adequate creep ductility.
The trend in anisotropy in creep ductility is stark: for matched samples the vertical orientation has
a higher ductility than the horizontal ductility in every test.
The trends in anisotropy observed in this data are explained by physics-based modeling and sim-
ulation work carried out by the AMMT program [6] [7]. Recall that for rupture strength the two
orientations are comparable at 600 °C, but the horizontal orientation is weaker at higher tempera-
tures. The trend in creep deformation is similar: the samples creep faster in the vertical direction
at 600 °C but creep faster in the horizontal direction at 800 °C. The horizontal orientation has
lower ductility at all temperatures.
The modeling work demonstrates these trends are caused by the elongated grain structure of L-
PBF material, with the grains elongated parallel to the build direction. This means that vertical
orientation samples have far fewer grain boundaries aligned with the loading direction compared
to horizontal samples. If the grain boundaries are stronger than the grain bulk, the modeling work

 9

suggests the material should creep faster in the vertical direction because the fewer grain bounda-
ries and larger “effective grain size” means samples loaded in this direction have fewer obstacles
to dislocation motion. However, if grain boundaries are weak to the point where creep cavitation
controls the material deformation behavior then the horizontal direction will creep faster, as there
are more boundaries per unit length in that direction.
Based on the test data, we except that the σ phase is causing grain boundary embrittlement, leading
to the grain boundaries weakening relative to the grain bulk at higher temperatures. This, com-
bined with the modeling results, would explain the anisotropy in the creep deformation rate and
the creep ductility.

2.1.3 Thermal aging
A previous Argonne National Laboratory technical report [2] and an associated publication [5]
describe the thermal aging data collected on L-PBF 316H. Briefly summarizing: L-PBF does
undergo thermal aging when started from the as-built, un-heat-treated condition. The yield
strength significantly decreases from the initial strength, especially at high temperatures. Changes
in the tensile strength also occur, but are more moderate compared to the yield strength.
However, as demonstrated in [1] because of the way the Section III, Division 5 thermal aging
factors are calculated, this reduction in the yield and tensile strengths does not translate to signifi-
cant thermal aging factors. The Code aging factors are calculated as the ratio of the average aged
strength of the material divided by the design material strength (𝑆! for yield strength, 𝑆" for tensile
strength). Because the design values of 𝑆! in particular significantly lower bound the average
strength of the unaged material and because the L-PBF material starts out at a higher yield strength
compared to wrought material, aging over 100,000 hours is not expected to reduce the yield or
tensile strength of the material below design strength (seeFigure 2.9). Therefore, the aging behav-
ior is bounded by the existing thermal aging factors for 316 steel provided in the Code.

There are two caveats to this conclusion. The first is that the aging studies were conducted on as-

2.1.5 Creep-fatigue

temperature without a hold.

2.2 Correlations: chemistry, equipment, and low/high temperature properties
The high temperature dataset collected by the AMMT program on L-PBF 316H material is now
large enough to study whether the performance of the material is correlated to composition, man-
ufacturing, or other mechanical properties. Specifically, we are interested in:
 1. If the long-term creep and creep-fatigue performance of the material is correlated to tensile
 properties. This would support the case for using high temperature tensile tests to qualify
 the material and provide witness data on production components and potentially lessen the
 need to do qualification and witness creep-fatigue test.

 3. If the mechanical properties are correlated to the build site, with the goal of understanding

2.3 Summary of the mechanical test results
The key results of the mechanical test campaign to date are:
 1. The material has tensile properties comparable to wrought 316H and limited tensile anisot-
 ropy.
 2. The material does undergo thermal aging, but not to the extent that would require reduced
 thermal aging factors, compared to wrought material, for Section III, Division 5 applica-
 tions.
 3. L-PBF material has the same creep strength as wrought 316H
 4. However, it has significantly lower creep ductility at temperatures above 650 °C caused by
 the rapid formation of the σ phase.
 5. There is a clear, explainable trend in creep anisotropy. However, the anisotropy is rela-
 tively mild.
 6. L-PBF material behaves quite similarly to conventional fusion welds under pure fatigue
 conditions, both at room temperature and elevated temperature.
 7. Preliminary data suggests L-PBF material may have reduced creep-fatigue performance
 compared to wrought, but more testing is required to make a final determination.
Overall, the test data to date supports the approach adopted by the Code Case: for design treat a
Class A or Class SM L-PBF component as if it was entirely manufactured from weld. The Code
design rules and design data, with the possible exception of the creep-fatigue interaction diagram,
would produce a safe design with adequate conservatism.
Mechanical testing should continue to wrap up the remaining tests required to fully establish this
approach for ASME qualification:
 1. Additional cyclic testing is needed, both pure fatigue at room temperature and one temper-
 ature above 650 °C as well as additional creep-fatigue testing on non-EOS material.
 2. The thermal aging study should be repeated with solution annealed material.

 17

 3. ASME typically requires 20,000 hour creep testing to justify a 100,000 hour design life.
 These tests should continue, though it is unlikely they will change the conclusions of this
 study.
Long term creep and aging testing should continue to support extending the maximum allowable
service life of L-PBF components beyond 100,000 hours in the future.
The most interesting correlation is between the tensile properties of the L-PBF and its creep per-
formance – there is a strong negative correlation between tensile properties (yield strength, tensile
strength, and ductility) and creep strength. While the physical cause of this correlation is unknown,
it is some indication that high temperature tensile testing can help ensure future batches of material
have similar creep properties to the current dataset.

3 Approaches to process qualification
3.1 The need for process qualification
Material qualification in the context of high temperature reactor design has two main objectives:
 1. Provide design material properties that reactor designers can use to model the behavior of
 the material during the design process. Engineering conservatism dictates that these prop-
 erties often are lower bounds on the true material behavior to account for variation induced
 by fabrication and to provide adequate margin against other uncertainty.
 2. Ensure that the manufacturing process is repeatable. The reactor vendor should have as-
 surance that if they produce their component with a qualified manufacturing process, that
 final component will have material properties at least as good as the design properties.
Put together, these two factors can be summarized to view material qualification as a contract with
designers: a qualified material, manufactured through a qualified process, will have material prop-
erties at least as good as the design properties.
The previous chapter discussed the mechanical properties of L-PBF 316H, making the case that
the existing design material data for conventional fusion-welded 316H in Section III, Division 5
can provide the first requirement in this list. This chapter then focuses on the second requirement:
process qualification to ensure that components will have reliable, repeatable material properties.
Specifically, the goal is to ensure that any printed component will have key mechanical properties
sufficiently similar to the test data collected by the AMMT program, ensuring the design data we
selected remains applicable.

3.2 Options considered

One challenge with L-PBF and other additive manufacturing processes is unlike conventional
forgings or castings, there is no “stock” target material to characterize prior to part fabrication, so
quality and repeatability must be engineered into every stage of the workflow [8]. The following
subsections describe techniques that can be combined to ensure material reproducibility and
demonstration process qualification. The final L-PBF Code Case selected techniques from this list
primarily based on how easy they are to implement in the current Code material qualification
framework. Future work could expand the library of available techniques with the goal of reducing
the amount of testing and characterization required to qualify components in the future.

3.2.1 Feedstock (Powder/Wire) Control
Because AM builds the material at the same time as the part, powder characteristics directly drive
both defect populations and final chemistry, and controlling the feedstock is the first line of defense
against build-to-build variability. Draft qualification plans call for a powder specification covering
chemistry, particle size distribution, morphology, flowability, apparent density, and stor-
age/transport conditions, generally following ISO/ASTM 52907 [9]. Chemistry limits and inter-
stitial monitoring — particularly oxygen — are especially important, because moisture uptake and
oxygen ingress during recycling can coarsen oxide inclusions and measurably reduce hardness and
consistency, motivating enforceable oxygen thresholds on both feedstock and as-built material for
every build cycle [9]. Producers also need documented recycling and refresh procedures — with

 19

batch tracking, blending records, and before/after chemical analyses — to control compositional
and morphological drift over successive builds [10] [11]. Selection of the atomization route (gas,
plasma, or plasma rotating electrode process) is a related consideration, with cost trading against
powder-induced porosity from entrapped gas [11].

3.2.2 Process Parameter Optimization ("Process Window")
For a given machine and feedstock, systematic design-of-experiments studies are used to map laser
power, scan speed, hatch spacing, layer thickness, and scan rotation to porosity and microstructure,
identifying a "sweet spot" processing window that avoids lack-of-fusion at low energy density and
keyholing at high energy density. Multi-institutional AMMT work on 316H at ORNL, ANL,
LANL, and PNNL has shown that even when powders all fall within the same ASTM A240 chem-
istry, the optimal window must be re-derived for each machine-and-powder combination rather
than transferred wholesale [12] [13]. The target condition is stable convection-mode melt-pool
operation, verified by polished cross-section metallography, which yields near-full density and
uniformly consolidated material suitable as a baseline for downstream qualification.

3.2.3 Process Control and Machine Qualification
Once an acceptable process window has been identified, it must be locked in and continually ver-
ified. This is typically accomplished through a formal manufacturing plan that documents all con-
figurable machine parameters and their allowable ranges [9]. At a higher level, an Installation /
Operational / Performance Qualification framework, adapted from other regulated industries, pro-
vides structured evidence that the machine, the procedure, and the resulting parts each meet re-
quirements [8]. Underlying all of this, a preventive machine maintenance plan covering optics,
gas flow, sensor calibration, and consumable replacement is essential, because drift in any of these
subsystems will move the effective process point out of the qualified window and directly degrade
build-to-build repeatability [10].

3.2.4 In-Situ Process Monitoring
In-situ sensing provides spatially resolved evidence of the process state during the build itself. The
most mature approach uses layer-wise visible and near-infrared imaging analyzed with deep-learn-
ing classifiers — for example, ORNL's Peregrine platform with the Dynamic Multilabel Segmen-
tation Convolutional Neural Network — to detect and localize spatter, edge swelling, recoater
streaking, and porosity precursors [14]. Complementary melt-pool diagnostics using photodiodes,
high-speed CCD cameras, pyrometers, fiber-integrated two-color pyrometry, and embedded fiber-
optic thermometry are being developed to capture the thermal history of the material and distin-
guish conduction-mode from keyhole-mode melting, providing ground-truth data on the local pro-
cess physics [15]. Using this data as a per-part quality-assurance tool is a potential route to ensuring
process qualification, although Code acceptance of in-situ signatures is still evolving and will re-
quire software quality assurance, standardized algorithms, and physics-informed models before
high-confidence part acceptance decisions can be made purely on in-situ evidence [16].

 20

3.2.5 Post-Build Non-Destructive Evaluation (NDE)
Post-build NDE provides independent evidence that a specific part meets its geometric and mate-
rial requirements. For small-to-moderately sized AM parts, X-ray and neutron computed tomog-
raphy (XCT and nCT) remain the "gold standard," resolving porosity, lack-of-fusion defects, and
geometric conformity in three dimensions [17]. Because CT methods are limited by component
size, thickness, and portability, they are increasingly complemented by ultrasonic testing (UT) and
resonance ultrasound spectroscopy (RUS), which scale to larger components and additionally pro-
vide information on elastic moduli and microstructure, along with surface and near-surface meth-
ods such as dye penetrant and eddy-current testing [17]. Building on this toolset, the AMMT
program is developing a witness-coupon plus validated-NDE paradigm in which coupons built
alongside the component are destructively characterized to anchor the material state, while the
component itself is confirmed with fast, inexpensive volumetric NDE at risk-informed locations
identified through probabilistic assessment [17]. Broader state-of-the-art surveys of NDE for AM
include Waller et al. [18].

3.2.6 Witness Specimens and Statistical Qualification

Witness specimens — coupons built with each production run — are a practical bridge between
per-build acceptance and the underlying qualification database. Witness testing is well-suited to
time-independent properties such as yield strength and ultimate tensile strength and existing
ASME approaches to additive manufacturing use witness testing to directly ensure the material
tensile (and, if required, fatigue and toughness) properties meet or exceed the design values.
However, witness testing itself is not sufficient for time-dependent behavior such as creep, creep-
fatigue, and thermal aging, where full witness coverage would require impractically long and
expensive test matrices.

3.2.7 Modeling, Digital Twins, and Machine Learning

Physics-based and data-driven models are increasingly used to reduce the amount of testing
required and to extend qualified windows to new geometries and conditions. Melt-pool and part-
scale thermal simulations predict solidification structure, thermal history, and residual stress, and
are being used both to guide parameter selection and to quantify build-to-build variability [19].
Multiscale, machine-learning-accelerated process–structure–property–performance (PSPP)
frameworks — for example, INL's MALAMUTE-based work — aim to link melt-pool physics
through microstructure to component performance in a way that supports more cost-effective
qualification [20], and chemistry-aware machine-learning defect predictors coupled to CFD melt-
pool simulations (e.g., using Flow-3D) are being used to identify robust parameter and
composition sets that minimize defect formation [21]. These modeling capabilities are increasingly
integrated into digital-factory and digital-twin infrastructure that stores in-situ, ex-situ, and model
data on a per-component basis, enabling both rigorous model validation and traceable per-part
records for qualification [19].

3.2.8 Putting It Together
No single control ensures repeatable AM material. The Code Case adopts a combination of these
approaches to ensure material reliability.

3.3 The process qualification model implemented in the Code Case
The process qualification approach adopted for the draft Code Case was set through a combination
of AMMT program work on accelerated qualification approaches and past ASME experience qual-
ifying additively manufactured materials. This section summarizes the approach, which is then
documented in detail in the next two chapters.

3.3.1 Three qualification stages
The draft Code Case requires validating and documenting process qualification in three stages:
 1. Manufacturing process qualification
 2. Component qualification
 3. Witness testing with production components
Each step addresses a different need and requires a different amount and type of testing and char-
acterization. The process qualification step ensures that the manufacturer has a good set of process
parameters and adequate process to control to produce material consistent with the test data used
to set the design allowables in the Code Case. These prints can be bulk blocks of material or near
net shape test samples.
Component qualification ensures that the actual microstructure produced in a build of the compo-
nent itself will retain adequate properties. The main concern here is that the local cooling rate will
vary, both spatially across the component and from the cooling rate during printing the process
qualification blocks or samples. This will affect the microstructure of the component and may
produce material properties which deviate from the process qualification builds (and from the de-
sign data in the Code Case). This print can either be a sacrificial copy of the final component from
which mechanical test samples can be cut from or a build with representative thicknesses, and
hence cooling rates, to the final component.
The last stage of qualification is witness testing. This requires the material supplier print test
samples along with each production build of the component itself. The test data from these witness
samples ensures that the actual, final components maintain adequate performance, again relative
to the design data.
This approach is generally “graded” – more testing is required in the process qualification stage
than in the component and witness testing. Each step need not be repeated so long as the material
supplier maintains the same process control. So, for example, if the component qualification tests
pass the criteria and the witness tests continue to have acceptable properties the vendor never needs
to repeat the initial process qualification.
The general types of testing required during this staged qualification process are described below.
Specific test requirements are given in the Code Case itself in the next chapter.
The Code Case allows alternative approach to component qualification (e.g. in situ monitoring) if
the manufacturer can demonstrate they can maintain the required material properties and the pur-
chaser agrees with their approach.

 22

3.3.2 Mechanical witness testing
Direct mechanical testing is the main type of characterization required for all three stages of the
qualification process. The goal is to ensure the material meets or exceeds the design properties
used in the Code Case (essentially, equivalence to conventional 316 fusion weld properties given
in the Code). However, as noted above, we cannot require direct testing of the most relevant
material properties for Section III, Division 5 design – long-term creep and creep-fatigue tests –
and so the direct testing is instead limited to short-term screening tests and tensile testing to ensure
that the material being produced falls into the distribution of test data collected by the AMMT
program for L-PBF 316H. The idea is that if the short-term test data falls inside the distribution
established by the DOE testing then the long-term properties of that material should also match
the long-term DOE tests.

3.3.2.1 Tensile testing
The tensile testing approach is largely guided by the current ASME approach to qualifying additive
manufacturing for low temperature applications. The goal is to demonstrate that the tensile prop-
erties of the printed material fall within an acceptable range, given by the ASME design data.
ASME has adopted a formal criterion that “99% of the material falls within the confidence bound
establishing the design data.” However, current ASME practice is to allow the producer to forgo
a statistical analysis if 15 test results all fall within the acceptable range. We adopted this approach
for process qualification.
However, this Code Case did have to reconsider what the acceptable range of properties should be
for high temperature applications. The minimum property for the current ASME low temperature
rules is set equal to the design strength -- 𝑆! for yield strength and 𝑆" /1.1 for tensile strength.
These bounds are appropriate at room temperature because they are minimum bounds, specifically
equal to the minimum specified property from the material specification at room temperature.
However, because of how ASME calculates these properties as a function of temperature the de-
sign values become much closer to an average or nominal property at high temperatures. Figure
3.1 illustrates this trend using test data and draft values of 𝑆! and 𝑆" for Alloy 709 [22]. About a

measurements of the uniform elongation. We elected not to impose an upper limit on tensile duc-
tility, as there seems to be no detrimental effects of a material with higher ductility than the AMMT
test data.
In addition to the prediction bound, we imposed additional lower bounds on the yield strength (the
design values of 𝑆! ) and the uniform elongation (set to 15% as an absolute minimum on tensile
ductility, determined by committee judgement). We tabulate the resulting allowable property
bounds in Appendix A of the draft Code Case. The values of 𝑆! end up not controlling the yield
stress limits at any temperature and the 15% ductility floor only affects a very narrow temperature
range.

3.3.2.2 Creep-fatigue testing
The correlation analysis in Chapter 2 suggests there is a connection between elevated temperature
tensile properties and creep performance. However, the tensile properties are still not directly
measuring a property relevant to high temperature design.
Section III, Division 5 already contains an acceptance test for the creep-fatigue properties of 316H
(wrought) steel. This test is defined in HBB-2800. The test is at 1,100 °C at a 1% fully reversed
strain range with a 1 hour tensile hold. The material must survive 200 cycles without failure or a
20% load drop. This test is relatively short term, as it can be terminated after around 200 hours if
the material has not failed.

 24

While this test directly measures the creep-fatigue performance of the material, the history behind
the test indicates it is really used as a screening test for creep ductility. Past work demonstrated
that creep-fatigue strength correlates to creep ductility and that this acceptance test would screen
out heats of wrought 316H with unacceptably low ductility.
The draft Code Case proposes to adopt the same model for L-PBF material: adopted the creep-
fatigue test to screen against low creep ductility and low creep-fatigue strength parts. However,
we do not expect L-PBF to be able to survive 200 cycles. The available data shows that conven-
tionally welded 316 samples have significantly lower ductility compared to wrought – roughly
one-third the creep ductility at the test condition. As such we expect welded material to only meet
one-half to one-third of the cycles required for base metal. The Code Case therefore sets the ac-
ceptance requirement for L-PBF material to 100 cycles.

3.3.3 Additional testing
In addition to mechanical property testing the Code Case requires chemical composition testing
and metallographic examination. The purpose of the chemical composition testing is to ensure
that the as-built, printed material remains within the chemistry requirements for 316H. The pur-
pose of the metallographic examination is to ensure the material is free from lack of fusion or
crack-like defects.

3.4 Post-manufacturing inspection requirements
Post-manufacturing inspection is a separate requirement from process qualification. It provides
final assurance that the actual component going into service is free of any critical defects.
Critical (Category A) welds for Section III, Division 5, Class A and SM components require a full
double volumetric inspection prior to service. This can be radiography (RT) from two angles or a
combination of radiography and ultrasonic (UT) inspection. This requirement is often considered
burdensome but reflects the known vulnerability of weld and heat affected zone material to creep
damage.
Inspection requires defining a critical defect. This should reflect the type or types of defects that
cause the component to be unfit for service and must also be detectable through the selected form
of Nondestructive Evaluation (NDE). For the moment the Code Case puts the burden of defining
this critical defect on the purchaser, as they are the only one who can adequately evaluate the
service requirements of the component. At present there is no evidence that manufacturing the
part through L-PBF will affect the types and sizes of critical defects for high temperature reactor
components and so the purchaser should be able to determine the size and types of defects from
experience with conventionally manufactured components.
The Code Case explicitly allows the use of X-ray Compute Tomography (CT) as an inspection
technique. It allows a single CT scan of a component to satisfy the double volumetric inspection
requirement set by Section III, Division 5. This makes sense, as CT is essentially an infinite angle
radiography study. Of course not all components could undergo CT, as the component size and
wall thickness may limit the applicability of the technique.

 5. Joining by welding is not allowed. Unlike low temperature applications,

 (a) The maximum service temperature limits L-PBF 316 to the temperature range

 corresponding creep embrittlement [5]. Figure 5.1 shows a TTT diagram for 316H

 diminishing to zero by 600 °C. The 650 °C limit is therefore based on a combina-
 tion of these precipitation studies and the direct creep ductility test data. This
 work on L-PBF material is in line with the general understanding of sigma phase
 stability in wrought 316 and similar stainless steels [12]. Work is underway to
 mitigate this embrittlement through chemistry, manufacturing, or other changes to
 the process. In the future that work should allow us to relax this temperature limit.

Acceptance criteria

The low temperature rules (R24-182 and N-955) both require that the test results from
the mechanical property testing must demonstrate with 95% confidence that 99% of the
fabricated material samples meet the specified minimum tensile properties. The mini-
mum requirements are given by the design values of 𝑆! and 𝑆" (which match the mini-
mum specified properties at room temperature) and the minimum specified tensile elon-
gation, all from the corresponding ASME wrought material specification. Both sets of
reference rules do not require a statistical analysis if 15 or more samples are tested.

This approach does not work at high temperatures, as:
 1. The design values of 𝑆" are not the lower bounds at elevated temperatures.
 Roughly half of wrought material will have tensile strengths less than 𝑆" at higher
 temperatures. Even the values of 𝑆" divided by 1.1 do not lower-bound the ten-
 sile strength of a significant fraction of wrought materials.
 2. There is no minimum required tensile ductility values for elevated temperatures in
 Section II, Part D (or elsewhere in the ASME Boiler and Pressure Vessel Code).

To work around these issues, this Code Case reformulates the required tensile proper-
ties to require the L-PBF material to have properties in agreement with the elevated
temperature mechanical property data collected by the DOE test program to support the
qualification of L-PBF 316 for Section III, Division 5 service. The concept is to demon-
strate that the future, qualified material has similar tensile properties to the DOE mate-
rial and therefore will have similar long-term, high temperature properties critical for high
temperature design. This assumption is further backstopped by the creep-fatigue test-
ing.

Except for ductility, we elected to enforce both lower and upper bounds on the tensile
properties. Again, the idea is that the material should be similar in all respects to the
DOE data, not just meeting some specified minimum values. As a hypothetical exam-
ple, very strong (in the sense of tension tests) cold worked wrought 316 has lower creep
ductility and strength compared to annealed material. An upper bound on yield and ten-
sile strength would help to screen out this material, ensuring it matches the long-term
creep data collected through the DOE test campaign.

Specifically, then, a 90% prediction interval on the DOE tensile test data was used to
establish the upper and lower bound tensile properties. The design values of 𝑆! (and
hence the minimum specified room temperature yield strength) were further imposed as
lower bound cutoffs, along with a minimum tensile ductility of 15% as an absolute lower
bound on adequate ductility for any high temperature material, established through the
judgement of the committee. The Code Case does not impose an upper bound on the
tensile ductility, as there are not any negative consequences to material with better duc-
tility but the same strength as the DOE data. Figure 5.4 plots the resulting property val-

7.1.2 Creep-fatigue testing

Acceptance criteria

HBB-2800 requires a creep-fatigue acceptance test on 304 and 316 base material. The
test is at 1,100 °C at a 1% fully reversed strain range with a 1 hour tensile hold. The
material must survive 200 cycles without failure or a 20% load drop.

This test was implemented to screen out material with low creep ductility. The creep-
fatigue test is a quicker way to identify heats with low ductility, compared to direct creep
testing.

Test data on L-PBF material indicates it does not have the ductility to survive 200 cy-
cles. However, it’s likely that a weld or cross-weld sample of conventionally fusion
welded 316 would also not meet the screening criteria. The goal of this Code Case is to
draw an analogy between L-PBF 316 and 316 welds, so a more reasonable screening
criteria would reflect the creep ductility of a cross-weld sample.

Figure 5.5 plots creep ductility from base metal and weld samples. The figure indicates
that conventionally welded 316 samples have roughly 1/3rd the creep ductility as a base
metal sample at the acceptance test conditions. A similar calculation using “nominal”
Code properties for 316 base metal and a welded sample with 16-8-2 filler suggestions
that the welded sample would have roughly half the creep-fatigue life.

6 What’s next?
6.1 Code qualification of L-PBF 316
With the development and submission of the Code Case to ASME, the work on the Code qualifi-
cation of L-PBF 316H can begin wrapping up. This report did however highlight a few activities
that must be continued to promote the eventually acceptance of the draft rules by ASME:
 1. The remaining cyclic and creep testing needs to be concluded in FY27 to provide a firm technical
 basis for the 100,000 Code Case.

 2. Program support will be needed to support the Code Case during the balloting process. At a mini-
 mum this includes lab staff time to attend ASME meetings and provide detailed replies to technical
 questions. Likely it will also include additional testing and characterization to provide new data to
 respond to inquiries from ASME members.
 3. The draft Code Case assumes that 316H chemistry and the solution anneal heat treatment recom-
 mended by the program will be incorporated into the ASTM/ISO Specification 52946. Balloting
 on this task is in progress, but the program should provide any support needed to resolve objections
 and include the high carbon chemistry into the standard.
Longer term the program should continue to support industry adoption of the L-PBF manufactur-
ing process using the Code Case as a framework. This could include:
 1. Recommending manufacturing, chemistry, and/or heat treatment options to mitigate σ phase em-
 brittlement at high temperatures, to provide an option for L-PBF 316H components operating above
 650 °C.

 2. Radiation and environmental testing of L-PBF 316H stainless steel to provide data to industry.
 These tests are already underway and should continue. While this data is not required for an ASME
 Code Case, it is needed for actual industry application of the technology.
 3. Testing to support joining L-PBF components to other 316H parts, either conventionally manufac-
 tured or additively manufactured, with conventional fusion weld processes.
 4. Long-term testing to provide data to support extending the maximum design life of L-PBF compo-
 nents from 100,000 to 500,000 hours, to support industry-requested 60 year design lives.
 5. Engagement with the NRC, after ASME approval of the initial Code Case. NRC endorsement will
 be required prior to reactor vendors being allowed to use L-PBF components in US commercial
 reactors.
Beyond these immediate tasks related to L-PBF 316H qualification, the program should continue
to look at ways to continue to accelerate the qualification of new material and manufacturing tech-
niques and gain industry, ASME, and NRC acceptance of these approaches. The Code Case dis-
cussed in this report is a first step in this direction, but the program should continue to engage to
develop a technical basis for the acceptance of new approaches, including in situ monitoring, dig-
ital twin/component modeling, and data and AI based techniques.

 54

6.2 What have we learned?
This point, near the end of the development of the initial AMMT-sponsored ASME Code Case,
would be a good time to reflect on the material qualification process developed by the program.
On one hand, three years between the decision to qualify L-PBF 316H and having a complete draft
Code Case is a significant improvement over past material qualification efforts. On the other hand,
the process could be further accelerated and optimized to start to make available a wider array of
advanced manufacturing processes and materials to US reactor developers.
A full analysis of the qualification campaign would require additional effort and likely could fill
an entire report by itself, but a brief reflection on the 316H effort yields a few initial issues to
consider in a longer analysis:
 1. The selection of the high carbon 316H material was made early in the program, but recent EPRI
 sponsored work suggests that the more available (and more widely studied) low carbon 316L com-
 position has comparable creep performance [24]. While there was essentially no data on L-PBF
 316H available at the start of the project to make an informed decision, future work might explore
 automated or AI driven screening methods to select materials for qualification.
 2. A substantial portion of the first year’s effort was devoted to selecting process parameters and a
 heat treatment for future material builds. The AMMT program has already sponsored methods for
 automating and accelerating the selection of process parameters which could be applied to speed
 up this part of the qualification process in the future. Similar methods could be developed for heat
 treatment selection.
 3. Disseminating material test data across the multiple institutions participating in the AMMT pro-
 gram in a common, machine-readable format was an initial bottleneck. While this was eventually
 overcome, standardized FAIR data formats for the testing and characterization experiments com-
 monly used for high temperature qualification would remove this bottleneck in future qualification
 efforts.

 4. While this initial Code Case benefits from AMMT work on accelerated qualification approaches,
 for example by drawing the analogy between L-PBF 316H and the performance of fusion welds,
 more advanced techniques were not included in the initial set of rules. This includes approaches
 based on physics-based models, machine learning, and AI. Additional work is required to gain
 industry and ASME acceptance of these approaches, which could potentially revolutionize the pro-
 cess of qualifying components for high temperature nuclear service.
