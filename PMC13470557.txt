Tissue-specific lead (Pb) partitioning dataset for sweetpotato cultivars ‘Bayou Belle’ and ‘Beauregard’ under controlled greenhouse Pb exposure
Authors: Arthur Q. Villordon, Mae Ann Bravo, Marissa Barbosa, Don LaBonte, Lorin Harvey
Published: 2026

ABSTRACT
This data article describes a greenhouse-derived dataset of lead (Pb) concentrations in four tissue types from two orange-fleshed sweetpotato cultivars, ‘Bayou Belle’ and ‘Beauregard’, that were exposed to controlled Pb treatments. Plants were grown from May 7 to June 28, 2026, and assigned to three treatment levels: untreated control, 10 mg L⁻¹ Pb, and 20 mg L⁻¹ Pb. Pooled tissue samples were collected from storage root, lateral and non-swollen root tissue, stem, and leaf, with three biological replicates per cultivar × treatment × tissue combination; each biological replicate consisted of tissue pooled from three subsamples to meet the minimum sample-weight requirement for elemental analysis. The dataset contains 72 observations with variables for cultivar, Pb treatment, tissue source, Pb concentration, and sample weight. Lead concentrations are reported in μg kg⁻¹ and were measured in digested plant tissue using inductively coupled plasma mass spectrometry. The repository includes the analysis-ready CSV file, two R scripts for weighted least squares and unweighted sensitivity workflows, and README documentation. These data can support tissue-level Pb partitioning research, cultivar comparisons, food safety assessment, statistical workflow testing, and sweetpotato sampling protocol development.

Background

Sweetpotato is a root crop for which Pb concentration data are commonly reported for edible storage root or flesh tissue. Bravo et al. generated root system architecture and storage root Pb data for sweetpotato cultivars ‘Bayou Belle’ and ‘Beauregard’ under controlled greenhouse Pb exposure using sand substrate and Hoagland nutrient solution with 0, 10, 20, and 30 mg L⁻¹ Pb [1]. A separate Data in Brief article by Bowers et al. provided sweetpotato flesh Pb concentration data for ten United States accessions exposed to 10 mg L⁻¹ Pb and analyzed by ICP-MS [2]. The present dataset provides Pb concentration measurements for pooled storage root, lateral and non-swollen root, stem, and leaf samples from ‘Bayou Belle’ and ‘Beauregard’ under controlled greenhouse Pb exposure. The repository also includes an analysis-ready data file, two R scripts, and a README for reuse in tissue-category sampling, cultivar comparison, and statistical workflow applications.

Data Description

The primary data file is data.csv. It contains 72 observations representing two cultivars, ‘Bayou Belle’ (BB) and ‘Beauregard’ (BX); three Pb treatments, untreated control, 10 mg L⁻¹ Pb, and 20 mg L⁻¹ Pb; four tissue categories, storage root (SR), lateral and non-swollen root tissue (LR), stem (ST), and leaf (LV); and three biological replicates per cultivar × treatment × tissue combination. Each biological replicate is represented by a pooled tissue sample prepared from three subsamples of the same cultivar, treatment, and tissue category to meet the minimum sample weight requirement for elemental analysis. Variables include Variety, Treatment, Tissue, Lead, and Weight. The Lead variable is reported in micrograms per kilogram (μg kg⁻¹), which is equivalent to ppb for the tissue analytical result. The Weight variable records the submitted pooled sample weight used for weighted least squares analysis. The repository contains four files: data.csv, analyze_pb_wls_basic.R, analyze_pb_unweighted_sensitivity.R, and README.txt [3]. The file data.csv is the analysis-ready dataset. The file analyze_pb_wls_basic.R contains the primary weighted least squares workflow using Weight as the weighting variable. When run, this script creates a local output folder containing the cleaned analysis dataset, the Type III ANOVA table, the model coefficient table, the text output, and the R session information. The file analyze_pb_unweighted_sensitivity.R contains the unweighted sensitivity workflow that uses the same model formula, excluding the weighting variable. When run, this script creates a local output folder containing the corresponding cleaned dataset, Type III ANOVA table, model coefficient table, text output, and R session information. The README.txt file defines variable names, tissue and treatment codes, model formulas, and instructions for running the scripts.

Experimental Design, Materials and Methods

Plant material and greenhouse conditions

The dataset was acquired from a greenhouse trial conducted from May 7 to June 28, 2026 at the LSU AgCenter Sweet Potato Research Station, Chase, Louisiana, USA (32°6′N, 91° 42′W). Two orange-fleshed sweetpotato cultivars were used: ‘Bayou Belle’ (BB) and ‘Beauregard’ (BX). These cultivars were selected because they were included in prior greenhouse Pb work on root system architecture and storage root Pb accumulation [1].

Virus-tested vegetative terminal cuttings were used as planting material. The greenhouse protocol followed the controlled substrate-and-nutrient-solution approach used in prior sweetpotato Pb work [1]. In that protocol, cuttings were planted in 10-cm-diameter, 30-cm-tall PVC pots with detachable bottoms and drainage holes, and washed river sand was used as the substrate. The cuttings were 25 to 30 cm long, had five to six fully opened leaves, had an approximately 5-mm basal diameter, and were planted to a uniform depth of 6 cm.

Plants were supplied with Hoagland nutrient solution [4] and assigned to three Pb treatment levels: CK, no added Pb; 10 mg L⁻¹ Pb; and 20 mg L⁻¹ Pb. Lead was supplied as lead(II) acetate trihydrate, Pb(CH₃COO)₂·3H₂O, consistent with the Pb source used in the prior greenhouse protocol [1]. Treatments were arranged as cultivar × Pb treatment combinations, with three biological replicates per cultivar × treatment × tissue category in the archived dataset.

Tissue collection

Four tissue categories were collected from each cultivar × Pb treatment combination: storage root (SR), lateral and non-swollen root tissue (LR), stem (ST), and leaf (LV). The LR category included lateral roots and other non-swollen root tissue, distinct from storage roots. Each cultivar × treatment × tissue category included three biological replicates.

Each biological replicate consisted of one pooled tissue sample prepared from three subsamples collected from the same cultivar, Pb treatment, and tissue category. Pooling was used to meet the minimum sample-weight requirement for elemental analysis. The analysis-ready dataset therefore contains one row per pooled tissue sample, rather than one row per individual subsample. Root tissue samples were briefly soaked in 100 μM CaCl₂ to displace loosely bound Pb ions, then thoroughly washed with distilled water, following the root-rinsing approach described by Bowers et al. [2].

Elemental analysis

Pooled plant tissue samples were submitted to Brooks Applied Labs, Seattle, Washington, USA, for toxic element analysis. Samples were homogenized and digested using a modified version of the AOAC 2015.01 method for Heavy Metals in Food [5]. Digestates were analyzed for total Pb by inductively coupled plasma mass spectrometry (ICP-MS). Lead concentrations in the archived dataset are reported as µg kg⁻¹, equivalent to ppb for the tissue analytical value. The Brooks Applied Labs certificate of analysis provided sample-specific method detection limits (MDL) and limits of quantitation (LOQ) for Pb; Pb MDLs ranged from 0.29 to 6.29 µg kg⁻¹, Pb LOQs ranged from 0.86 to 18.9 µg kg⁻¹, and all reported Pb concentrations exceeded the corresponding sample-specific LOQ.

Data organization

The analysis-ready file data.csv was organized with one row per pooled tissue sample. The file contains 72 observations: two cultivars × three Pb treatments × four tissue categories × three biological replicates. Categorical variables were coded as Variety, Treatment, and Tissue. Numeric variables were coded as Lead and Weight.

The Variety variable contains two levels: BB for ‘Bayou Belle’ and BX for ‘Beauregard.’ The Treatment variable contains three levels: CK, 10, and 20, corresponding to no added Pb, 10 mg L⁻¹ Pb, and 20 mg L⁻¹ Pb, respectively. The Tissue variable contains four levels: SR, LR, ST, and LV, corresponding to storage root, lateral and non-swollen root tissue, stem, and leaf. The Lead variable contains Pb concentration in µg kg⁻¹. The Weight variable records the submitted pooled sample weight used as the weighting variable in the weighted least squares workflow.

Statistical workflow and deposited R scripts

Weighted least squares analysis was conducted in R using Weight as the weighting variable. The primary fixed-effect model was:Lead∼tissue×variety×treatment

Type III ANOVA tables were generated using sum-to-zero contrasts and the R package car. The repository includes the script analyze_pb_wls_basic.R, which reads data.csv, sets the factor order for Variety, Treatment, and Tissue, fits the weighted model, and writes locally generated output files that include the cleaned dataset used for analysis, Type III ANOVA table, model coefficient table, model summary, and R session information.

An unweighted sensitivity workflow was included in the script analyze_pb_unweighted_sensitivity.R. This script uses the same fixed-effect model but omits Weight as a weighting variable. When run, it writes locally generated output files that include the cleaned dataset used for the unweighted analysis, the Type III ANOVA table, the model coefficient table, the model summary, and the R session information.

The README.txt file provides instructions for running the two scripts in R/RStudio or on the command line and defines the required columns in data.csv.

Limitations

The dataset was generated under controlled greenhouse conditions and includes two cultivars, three Pb treatments, four tissue categories, and three biological replicates per cultivar × treatment × tissue combination. Each biological replicate represents one pooled tissue sample prepared from three subsamples; therefore, Pb concentration values are not available for individual subsamples. The dataset is specific to the growth conditions, substrate, Pb treatment method, sampling date, tissue categories, sample preparation procedure, and analytical protocol used. The data report total Pb concentration in bulk tissue samples and do not include Pb speciation, subcellular localization, spatial distribution within tissues, or field-based validation. The dataset is also limited to culivars ‘Bayou Belle’ and ‘Beauregard’ and does not represent broader sweetpotato germplasm diversity.
