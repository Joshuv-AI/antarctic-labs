HAARES: Half-Split Residual Basis Routing for Deep Transformers
Kehan Wang

Abstract
Block-level residual routing makes learned residual aggregation practical by routing over block summaries, but each summary compresses an ordered sequence of attention and MLP updates into one cumulative vector. We propose HAARES, a lightweight residual basis router that keeps the cumulative block source and adds one half-split detail basis, computed as the difference between first-half and second-half residual updates. The detail basis is RMS-matched and updated online, exposing coarse intra-block trajectory information without dense sublayer-level routing. Across OpenWebText, cross-domain character-level benchmarks, and BPE-tokenized OpenWebText, the empirical pattern is depth-dependent: gains are small or mixed at shallow depth and most reliable in 48-layer models. In the 201M 48-layer setting, HAARES improves over Block AttnRes across all three seeds, while a 453M two-seed probe shows the same direction. Ablations rule out source duplication, random signed details, fixed detail-source biases, or block-count changes alone. Cost analysis shows that the method is FLOP-light but not wall-clock-free: it adds memory and routing overhead, yet its relative arithmetic cost is amortized as width grows and earlier convergence can reduce time-to-target.



Introduction

Residual connections define the depth-wise interface of Transformer language models: in PreNorm architectures, attention and MLP sublayers update a stream that stabilizes optimization and carries information across depth
[
2
,
5
,
7
]
. Standard accumulation gives later layers only one running state. Depth-wise residual routing relaxes this interface, and Block Attention Residuals make it scalable by routing over block summaries instead of all layer-level states
[
3
]
.

The block-level interface introduces a bottleneck: a block contains ordered attention and MLP updates, but cumulative-only routing represents it by one net displacement. Blocks with similar totals can hide different internal trajectories, especially in deep models where each source compresses many residual events and late sublayers may reinforce, correct, or cancel earlier movements.

We propose HAARES, a half-split residual basis router. It keeps the cumulative basis used by Block Attention Residuals and adds one detail basis formed by subtracting second-half residual updates from first-half updates. This signed source is a low-cost, Haar-like sketch of early-to-late drift rather than a reconstruction of all sublayers. It is RMS-matched and updated online, so sublayers can route over completed block bases and the current partial block basis.

Our claim is conditional: the detail source is most useful when cumulative summaries become lossy, not as a universal residual replacement. Experiments support this depth-dependent view. On OpenWebText with
d=512
, HAARES is slightly better than Block AttnRes at 12 layers, tied at 24 layers, and clearly better at 48 layers; the 201M three-seed result, a 453M two-seed probe, BPE-tokenized OpenWebText, and cross-domain benchmarks show the same direction. Ablations test block granularity, source duplication, random signed details, RMS matching, detail-source bias, and cost.

Our contributions are: (i) identifying intra-block trajectory compression as a limitation of cumulative-only block residual routing; (ii) introducing a minimal two-basis block representation that augments cumulative displacement with one half-split detail source; and (iii) providing controlled experiments and cost analysis showing when this structured detail helps and when it does not.

Related Work

Residual Scaling and Stable Deep Transformers.

Residual learning preserves identity paths across depth
[
2
]
, while normalization placement and residual scaling affect Transformer trainability
[
7
]
. ReZero, LayerScale, and DeepNorm improve stability through residual initialization or scaling
[
1
,
4
,
6
]
. HAARES instead asks what information remains when several residual updates are compressed into one block-level source.

Depth-Wise Residual Routing.

Cross-layer access methods let later layers use earlier representations more directly. Attention Residuals formulate residual accumulation as depth-wise softmax routing, while Block Attention Residuals reduce cost by routing over block summaries
[
3
]
. HAARES keeps the same block-level routing principle but changes each source representation from a cumulative basis to a cumulative-plus-half-split basis.

Compressed Trajectory Representations.

A block summary trades information for efficiency. Dense sublayer-level routing preserves temporal detail but scales poorly, while cumulative block routing discards residual order. HAARES keeps block-level complexity and adds one signed early-to-late contrast, so the ablations separate structured detail from simply adding sources or changing block count.

Preliminaries

Consider a decoder-only Transformer with hidden dimension
d
and
L
layers, each containing attention and MLP residual sublayers. We partition the
2L
residual sublayers into
N
contiguous blocks; assume block
B_{n}
contains
m
sublayers. Since routing mixes multiple residual sources rather than using only the previous hidden state, we denote the output of the
r
-th residual sublayer in block
B_{n}
as

u_{n,r}=f_{n,r}(\operatorname{Norm}(\tilde{h}_{n,r})),

(1)

where
f_{n,r}
is either an attention module or an MLP module, and
\tilde{h}_{n,r}
is the routed input to this sublayer.

Block Attention Residuals represent block
B_{n}
by the cumulative basis

C_{n}=\sum_{r=1}^{m}u_{n,r}.

(2)

This source captures the net residual output of the block, but it discards the order in which the sublayer outputs are produced.

Method

Figure
1
gives an overview of HAARES. The key difference from Block Attention Residuals is that each block source is expanded from a single cumulative basis
C
into a two-basis representation
(C,\widehat{D})
, where
\widehat{D}
is the RMS-matched half-split detail basis.

Figure 1:
Architecture of HAARES. Ordered sublayer outputs form a cumulative basis
C
and half-split detail basis
D
. The RMS-matched detail
\widehat{D}
is routed with token, completed-block, and current partial sources; partial bases are updated online, while final readout uses cumulative sources only.

Half-Split Residual Bases

HAARES extends the block representation used in Block Attention Residuals from one cumulative basis into two residual bases. The cumulative basis
C_{n}
is defined in Eq.
2
. To encode a coarse intra-block trajectory detail, we define

D_{n}=\sum_{r=1}^{\lceil m/2\rceil}u_{n,r}-\sum_{r=\lceil m/2\rceil+1}^{m}u_{n,r}.

(3)

Equivalently,
D_{n}
applies the signed pattern
[+1,\ldots,+1,-1,\ldots,-1]
along the ordered sublayers of a block. This basis compares early-stage and late-stage residual movements. The pair
(C_{n},D_{n})
therefore represents both where the block moves the representation overall and how the first half differs from the second half.

Online Basis Construction

The basis construction is maintained online. Before the
r
-th sublayer of block
B_{n}
, the available partial cumulative basis and partial detail basis are

C_{n}^{(r-1)}=\sum_{t=1}^{r-1}u_{n,t},

(4)

D_{n}^{(r-1)}=\sum_{t=1}^{r-1}s_{t}u_{n,t},\quad s_{t}=\begin{cases}+1,&t\leq\lceil m/2\rceil,\\
-1,&t>\lceil m/2\rceil.\end{cases}

(5)

After the sublayer output
u_{n,r}
is computed, the partial bases are updated as

C_{n}^{(r)}=C_{n}^{(r-1)}+u_{n,r},\quad D_{n}^{(r)}=D_{n}^{(r-1)}+s_{r}u_{n,r}.

(6)

Thus, the current block does not need to finish before its trajectory information becomes available. After an attention sublayer produces an output, the partial basis is immediately updated, and the following MLP sublayer can route over the updated partial source.

RMS-Matched Detail Sources

Because
D
is a signed difference, its scale may differ from that of
C
. We therefore match the RMS magnitude of the detail basis to the corresponding cumulative basis:

\widehat{D}=D\cdot\operatorname{sg}\left[\operatorname{clip}\left(\frac{\operatorname{RMS}(C)}{\operatorname{RMS}(D)+\epsilon},\frac{1}{\gamma},\gamma\right)\right],

(7)

where
\epsilon=10^{-6}
and
\gamma
bounds the rescaling factor. We use
\gamma=4
in all experiments. The stop-gradient operator
\operatorname{sg}[\cdot]
prevents gradients from passing through the scale factor, so the router can use the direction of the detail basis without being dominated by unstable scale adaptation.

Depth-Wise Source Routing

Before the
r
-th sublayer in block
B_{n}
, HAARES constructs the source set

\displaystyle\mathcal{S}_{n,r}={}

\displaystyle\{e\}\cup\{C_{i},\widehat{D}_{i}\}_{i<n}\cup\mathcal{P}_{n,r},

(8)

\displaystyle\mathcal{P}_{n,r}={}

\displaystyle\begin{cases}\varnothing,&r=1,\\
\{C_{n}^{(r-1)},\widehat{D}_{n}^{(r-1)}\},&r>1.\end{cases}

where
e
is the token embedding,
\{C_{i},\widehat{D}_{i}\}_{i<n}
are completed block sources, and
\mathcal{P}_{n,r}
is the current partial source after at least one sublayer in the current block has been evaluated. For the Block Attention Residuals baseline, all
\widehat{D}
sources are removed, leaving only cumulative block sources.

For each source
s\in\mathcal{S}_{n,r}
, the routing logit is

z_{s}=q^{\top}\operatorname{RMSNorm}(s)+b_{s},

(9)

where
q\in\mathbb{R}^{d}
is a learned query vector and
b_{s}
is a source bias. The routing weight and routed input are

\alpha_{s}=\frac{\exp(z_{s})}{\sum_{s^{\prime}\in\mathcal{S}_{n,r}}\exp(z_{s^{\prime}})},\quad\tilde{h}_{n,r}=\sum_{s\in\mathcal{S}_{n,r}}\alpha_{s}s.

(10)

Attention and MLP sublayers use separate routers and separate query vectors. The embedding and cumulative sources use zero bias, while the half-split detail source uses a per-block learnable scalar bias initialized to
-2.0
. The fixed-bias variants in Table
8
replace these learned detail-source biases with constants while keeping the same half-split basis.

Final Readout

The final language-model readout uses only cumulative sources:

\mathcal{S}_{\mathrm{final}}=\{e\}\cup\{C_{i}\}_{i=1}^{N}.

(11)

Thus, the detail basis affects intermediate routing, while output logits use only the embedding and cumulative summaries.

Experiments

Experimental Setup

Datasets and Tokenizers.

We evaluate on OpenWebText, WikiText-103, TinyStories, Yelp Review Full, and CodeSearchNet-Python. OpenWebText is the main benchmark; the others test transfer across encyclopedia text, stories, reviews, and code. For OpenWebText, we use HuggingFace
openwebtext
, 30/80 parquet shards, with
\mathrm{row\_index}\bmod 10=0
as validation. The character pipeline uses a 256-entry
SimpleTokenizer
with four special tokens and the 252 most frequent Unicode characters. The BPE robustness check uses a 4096-token Byte-Level BPE tokenizer trained on the first 100M raw OpenWebText bytes, with a 95/5 train/validation split. Raw text is preserved, chunked to context length 512, and no extra EOS is inserted between lines.

Training and Evaluation Protocol.

Paired methods use the same split, tokenizer, batch construction, optimizer, initialization, data order, budget, and evaluation schedule. We train with AdamW using
\beta=(0.9,0.95)
, default
\epsilon_{\mathrm{Adam}}=10^{-8}
, learning rate
3\times 10^{-4}
, weight decay 0.01 excluding bias/norm/gate/query and other less-than-two-dimensional parameters, and global gradient clipping at 1.0. We use constant learning rate, fp32, no warmup/decay, no dropout, no gradient accumulation, no activation checkpointing, no early stopping, and no
torch.compile
. Seed-averaged results use model seeds
\{42,123,2026\}
unless stated; the dataloader seed is fixed at 42. We evaluate every 2K steps on the full validation set, report best validation loss, compute PPL as
\exp(\mathrm{loss})
, and do not select by test performance.

Block Configuration and Baselines.

Block-level methods use
N=4
by default; for 48-layer models each block contains 12 layers, or 24 residual sublayers. Ablations use
N\in\{4,6,8\}
. Block AttnRes shares the backbone and router but removes all
D
-type sources. HAARES uses
\widehat{D}
, RMS matching with
\epsilon=10^{-6}
and
\gamma=4
, zero-initialized router queries, and a per-block detail-source bias initialized to
-2.0
. Standard Residual uses ordinary PreNorm addition; ReZero uses per-sublayer scalar
\alpha=0
; LayerScale uses per-channel
\gamma
initialized to 0.1/
10^{-5}
/
10^{-6}
for 12L/24L/48L.

Hardware and Software.

Small runs use NVIDIA GeForce RTX 4090 GPUs; medium/large OpenWebText runs use NVIDIA RTX PRO 6000 GPUs. The environment is PyTorch 2.8.0, Python 3.12, CUDA 12.8, cuDNN 9.x, and Ubuntu 22.04. Cost measurements use a single RTX PRO 6000 at fp32 with batch size 16 and sequence length 512; throughput is measured over 2000-step windows and peak memory with
torch.cuda.max_memory_allocated()

Cost-Performance Analysis

HAARES adds one detail basis for each cumulative block basis, so its routing cost depends on source count rather than directly on layer count. For a model with
L
layers and
N
blocks, each block has
m=2L/N
residual sublayers. At sublayer
(n,r)
, the source counts are

S_{\mathrm{Block}}(n,r)=n+\mathbf{1}_{r>1},\quad S_{HAARES}(n,r)=2n-1+2\mathbf{1}_{r>1}.

(12)

Averaging over all blocks and residual sublayers gives

\overline{S}_{\mathrm{Block}}=\frac{N+3}{2}-\frac{1}{m},\quad\overline{S}_{HAARES}=N+2-\frac{2}{m}.

(13)

The router computes normalized source keys, a softmax, and a weighted sum, with arithmetic
O(SBTd)
. Extra arithmetic over Block AttnRes is therefore linear in
(\overline{S}_{HAARES}-\overline{S}_{\mathrm{Block}})BTd
, plus element-wise construction and RMS matching of
D
; attention and MLP projections scale quadratically with width.

Conclusion

We introduced HAARES, a residual basis router that augments cumulative block summaries with one RMS-matched half-split detail basis. The method preserves block-level routing while exposing coarse early-to-late trajectory information. The evidence is conditional but consistent: gains are small or mixed at shallow and intermediate depth, and are most reliable in deep block-routed models, including 48-layer OpenWebText, the 453M two-seed probe, BPE-tokenized runs, and cross-domain benchmarks. Ablations rule out simpler explanations based only on more sources, random signed details, finer block partitions, or fixed detail-source biases. HAARES adds memory and per-step overhead, but its added arithmetic is small and faster convergence can offset the cost in the 201M time-to-target analysis. Overall, half-split residual basis routing is a targeted mechanism for making cumulative block summaries more expressive in sufficiently deep Transformers.
