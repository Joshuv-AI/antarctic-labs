Kaczmarz Linear Attention
Jiaxuan Zou, Ruifeng Ren, Yong Liu

Abstract
Long-context language modeling remains central to modern sequence modeling, but the quadratic cost of Transformer attention makes scaling computationally prohibitive. Linear recurrent models address this bottleneck by compressing the context into a fixed-size state, making the rule that forgets, writes, and edits information a central design problem. To address state maintenance, Gated DeltaNet (GDN) combines gated state decay with delta-rule residual writes, using a learnable coefficient to balance forgetting and update magnitude. However, this coefficient is learned empirically rather than derived from the underlying objective, which can lead to suboptimal update magnitudes. We revisit the online-regression objective underlying GDN and, inspired by the Kaczmarz projection method, derive the key-norm-normalized dynamic step size β t = η t / ( ∥ k t ∥ 2 2 + ε ) \beta_{t}={\color[rgb]{0,0,1}\eta_{t}/(\lVert k_{t}\rVert_{2}^{2}+\varepsilon)} for residual updates. We propose Kaczmarz Linear Attention (KLA), a one-scalar modification of GDN that preserves the state shape, gates, linear recurrence, and chunkwise parallel algorithm. At the 0.4B scale with a 1B-token budget, KLA achieves the lowest validation perplexity among evaluated linear-time baselines (8.09 vs. 8.50 for GDN) and remains stable up to 65K tokens. On controlled tasks, KLA reaches 100% on single-needle-in-a-haystack (S-NIAH) retrieval, improves 8 × 8\times multi-query associative recall (MQAR) by 7.03 points over GDN, and delivers 2.1 × 2.1\times higher decode throughput at 32K context. These results suggest that the key-norm-normalized Kaczmarz coefficient is a first-order design axis for delta-rule sequence models: it improves accuracy, extrapolation, and decoding efficiency without changing the recurrent state or hardware kernel. An anonymized implementation is included in the supplementary material and available at https://github.com/anonymous-kla-review/kla-anonymous .

Linear-time sequence models seek to alleviate this bottleneck by replacing token-token attention with a fixed-size recurrent state.
As all past-token information is compressed into bounded memory, the state-update rule—which determines what the model writes, overwrites, preserves, and later retrieves—becomes the central design choice.
Different lines of work propose different update rules based on distinct design insights.

Although these models reduce quadratic attention to linear-time recurrence, their writes do not explicitly account for the key-value associations already stored in the state.
When similar keys recur, repeated writes can redundantly accumulate related information instead of editing the existing association.

Delta-rule models address this redundancy by writing the residual between the target value and the value predicted by the current state.
DeltaNet therefore overwrites a specific key direction instead of only adding or decaying information
[
44
]
.
To control the residual-write magnitude more finely, Gated DeltaNet (GDN) introduces a learned scalar that balances forgetting and updating and improves long-context retrieval
[
42
]
.
However, this scalar is primarily an empirical design choice rather than a theoretically specified step size.
An inappropriate coefficient can over-correct large-norm keys, under-correct small-norm keys, and leave the write scale mismatched to the current key.
Because the GDN update admits an online-regression view, the coefficient can instead be derived from the per-token optimization problem.

KLA resolves this coefficient problem by treating each delta-rule write as a Kaczmarz projection.
The key insight is simple: a key-value write imposes one linear constraint,
S_{t}^{\mathsf{T}}k_{t}=v_{t}
, and the closest state satisfying that constraint is reached with the Kaczmarz step size
\beta_{t}={\color[rgb]{0,0,1}\eta_{t}/(\lVert k_{t}\rVert_{2}^{2}+\varepsilon)}

[
15
]
.
This self-normalized projection turns the gated delta rule into an exact per-token update in the unrelaxed case while preserving the GDN state shape, gates, linear recurrence, and chunkwise parallel kernel.
Thus KLA changes the coefficient, not the architecture.

Empirical gains.

Background and Problem Analysis

Linear-time sequence models replace the token-token attention matrix with a recurrent state
S_{t}\in\mathbb{R}^{d_{k}\times d_{v}}
, so the main design choice is the write rule applied to this state. Linear attention writes each key-value pair additively,
S_{t}=S_{t-1}+k_{t}v_{t}^{\mathsf{T}}
, and a query reads
o_{t}=S_{t}^{\mathsf{T}}q_{t}

[
16
]
. Gated Linear Attention (GLA) adds data-dependent forgetting,
S_{t}=\operatorname{Diag}(\alpha_{t})S_{t-1}+k_{t}v_{t}^{\mathsf{T}}
, so earlier content can decay before the next write
[
43
]
. In the scalar-gated notation used below, this forget-then-write pattern is

\widetilde{S}_{t-1}=\alpha_{t}S_{t-1},\qquad S_{t}=\widetilde{S}_{t-1}+k_{t}v_{t}^{\mathsf{T}}.

These recurrent forms are efficient; the delta-rule family changes the write itself.

Delta-rule models make the state content-editable by writing the residual between the target value and the current state prediction. In the scalar-gated GDN template
[
42
]
, the residual is measured and written back along the current key direction:

S_{t}=\widetilde{S}_{t-1}+\beta_{t}k_{t}e_{t}^{\mathsf{T}}=(I-\beta_{t}k_{t}k_{t}^{\mathsf{T}})\widetilde{S}_{t-1}+\beta_{t}k_{t}v_{t}^{\mathsf{T}},\qquad e_{t}=v_{t}-\widetilde{S}_{t-1}^{\mathsf{T}}k_{t}.

The rank-one correction edits the state in the active key direction, and
\beta_{t}
determines the step length of this edit. After decay, token
t
can be viewed through a data-fit loss and its regularized online-regression form:

\mathcal{L}_{t}(S)=\frac{1}{2}\|S^{\mathsf{T}}k_{t}-v_{t}\|_{2}^{2},\qquad\mathcal{J}_{t}(S;\lambda_{t})=\mathcal{L}_{t}(S)+\frac{\lambda_{t}}{2}\|S-\widetilde{S}_{t-1}\|_{F}^{2}.

Here
\mathcal{L}_{t}
fits the current key-value association, while the regularization term keeps the new state close to the decayed memory. The residual direction
k_{t}e_{t}^{\mathsf{T}}
is the negative gradient direction of
\mathcal{L}_{t}
at
\widetilde{S}_{t-1}
, and the scalar coefficient controls how strongly this residual is written. In the GDN template, this coefficient is supplied by a learned gate,
\beta_{t}=\eta_{t}
; equivalently, the update magnitude is learned empirically rather than derived from the regularized objective. The next section derives this coefficient from the per-token optimization problem itself.

3
Kaczmarz Linear Attention

3.1
Kaczmarz coefficient from constrained optimization

The regularized view above isolates the residual direction from the scalar that controls its magnitude. We now derive the scalar by treating a key-value write as a single linear constraint on the recurrent state. The Kaczmarz method is a classical row-action method for solving linear systems by repeatedly projecting the current iterate onto one constraint hyperplane at a time
[
15
]
. For token
t
, we choose the state closest to the decayed state
\widetilde{S}_{t-1}
that satisfies the current key-value constraint:

\minimize_{S\in\mathbb{R}^{d_{k}\times d_{v}}}\;\tfrac{1}{2}\lVert S-\widetilde{S}_{t-1}\rVert_{F}^{2}\quad\text{subject to}\quad S^{\mathsf{T}}k_{t}=v_{t}.

(1)

This problem asks for the minimum-norm state change that makes key
k_{t}
read out value
v_{t}
. The constraint set
\mathcal{A}_{t}=\{S:S^{\mathsf{T}}k_{t}=v_{t}\}
is an affine subspace with normal direction
k_{t}
, so the optimal correction has the form
S_{t}=\widetilde{S}_{t-1}+k_{t}c^{\mathsf{T}}
for some
c\in\mathbb{R}^{d_{v}}
. Substituting this form into the constraint gives
\widetilde{S}_{t-1}^{\mathsf{T}}k_{t}+c\lVert k_{t}\rVert_{2}^{2}=v_{t}
, hence
c=e_{t}/\lVert k_{t}\rVert_{2}^{2}
, and the exact projection is

S_{t}=\widetilde{S}_{t-1}+\frac{1}{\lVert k_{t}\rVert_{2}^{2}}\,k_{t}\,e_{t}^{\mathsf{T}}.

(2)

Thus Kaczmarz writes the residual
e_{t}
with a step length normalized by the key energy. The practical KLA update adds a learned relaxation gate and a numerical stabilizer,

S_{t}=\widetilde{S}_{t-1}+\beta_{t}\,k_{t}e_{t}^{\mathsf{T}},\qquad\beta_{t}=\frac{{\color[rgb]{0,0,1}\eta_{t}}}{{\color[rgb]{0,0,1}\lVert k_{t}\rVert_{2}^{2}+\varepsilon}}.

(3)

When
\eta_{t}=1
and
\varepsilon=0
, (
3
) reduces to the exact Kaczmarz projection in (
2
). The relaxed update also has an online-regression interpretation:

Proposition 1

(Exact proximal form)
.

For any
\eta_{t}\in(0,1]
and
\varepsilon\geq 0
, define
\mu_{t}=\eta_{t}/((1-\eta_{t})\lVert k_{t}\rVert_{2}^{2}+\varepsilon)
. The relaxed update in (
3
) is the exact minimizer of

\min_{S}\;\frac{1}{2}\lVert S-\widetilde{S}_{t-1}\rVert_{F}^{2}+\frac{\mu_{t}}{2}\|S^{\mathsf{T}}k_{t}-v_{t}\|_{2}^{2}.

Thus, the practical coefficient can be read either as a relaxed Kaczmarz step or as the closed-form solution of a proximal local regression problem.

Connection to GDN.

To make the coefficient-level comparison explicit, return to the data-fit loss
\mathcal{L}_{t}
defined in
section

2
. GDN and KLA use the same decayed state
\widetilde{S}_{t-1}
, residual
e_{t}
, and rank-one write direction
k_{t}e_{t}^{\mathsf{T}}
; they differ only in the scalar multiplying that write. Along the one-parameter path
S(\tau)=\widetilde{S}_{t-1}+\tau k_{t}e_{t}^{\mathsf{T}}
, substituting into
\mathcal{L}_{t}
gives

\mathcal{L}_{t}(S(\tau))=\frac{1}{2}\bigl(1-\tau\lVert k_{t}\rVert_{2}^{2}\bigr)^{2}\lVert e_{t}\rVert_{2}^{2}.

(4)

The exact line-search coefficient is therefore
\tau^{*}=1/\lVert k_{t}\rVert_{2}^{2}
. GDN uses
\beta_{t}=\eta_{t}
, so it matches this step only when the learned scalar happens to equal
1/\lVert k_{t}\rVert_{2}^{2}
for the current token. In contrast, KLA uses
\beta_{t}=\eta_{t}/(\lVert k_{t}\rVert_{2}^{2}+\varepsilon)
and recovers the exact minimizer when
\eta_{t}=1
and
\varepsilon=0
. The improvement is not a new write direction; it is a key-energy correction to the GDN step length.

3.2
Why the Kaczmarz coefficient is natural

The constrained optimization view gives a candidate coefficient, and the following result explains why this coefficient is natural. The same scalar simultaneously satisfies three desiderata that are usually treated separately in online learning: it is an orthogonal projection, an exact line-search minimizer, and a normalized gradient step. This unified characterization justifies why the key-norm term should appear in the delta-rule coefficient rather than in an auxiliary heuristic.

Theorem 1

(Projection, line search, and normalized SGD)
.

Assume
\eta_{t}=1
and
\varepsilon=0
. Let
\widetilde{S}_{t-1}=\alpha_{t}S_{t-1}
,
e_{t}=v_{t}-\widetilde{S}_{t-1}^{\mathsf{T}}k_{t}
, and
\mathcal{A}_{t}=\{S:S^{\mathsf{T}}k_{t}=v_{t}\}
. The update

S_{t}=\widetilde{S}_{t-1}+\frac{1}{\lVert k_{t}\rVert_{2}^{2}}\,k_{t}\,e_{t}^{\mathsf{T}}

satisfies
S_{t}^{\mathsf{T}}k_{t}=v_{t}
. Moreover, the same update is simultaneously:

(i)

the orthogonal projection of
\widetilde{S}_{t-1}
onto
\mathcal{A}_{t}
in Frobenius norm;

(ii)

the exact minimizer of
\mathcal{L}_{t}(S)
along the direction
\widetilde{S}_{t-1}+\tau k_{t}e_{t}^{\mathsf{T}}
; and

(iii)

a normalized SGD update on
\mathcal{L}_{t}
with coefficient
1/\lVert k_{t}\rVert_{2}^{2}
.

Remark 1
.

By the projection theorem for Hilbert spaces,
S_{t}
is the unique element of
\mathcal{A}_{t}
closest to
\widetilde{S}_{t-1}
. The Kaczmarz update makes the minimum-norm change to the state while exactly satisfying the constraint.

Proposition 2

(Residual contraction)
.

Let
e_{t}=v_{t}-\widetilde{S}_{t-1}^{\mathsf{T}}k_{t}
and
e_{t}^{+}=v_{t}-S_{t}^{\mathsf{T}}k_{t}
. Then

e_{t}^{+}=\Bigl(1-\eta_{t}\frac{\lVert k_{t}\rVert_{2}^{2}}{\lVert k_{t}\rVert_{2}^{2}+\varepsilon}\Bigr)\,e_{t}.

(5)

For
0<\eta_{t}\leq 1
, the residual contracts and the per-token loss decreases monotonically:
\mathcal{L}_{t}(S_{t})\leq\mathcal{L}_{t}(\widetilde{S}_{t-1})
.

Equation

5
gives the stability condition for the relaxed update. The contraction factor is bounded by the gate
\eta_{t}
and regularized by
\varepsilon
, so the update cannot amplify the current residual. The Kaczmarz coefficient depends on
\widetilde{S}_{t-1}
and
k_{t}
, not on the form of the decay operator; therefore KLA and KDA
[
36
]
are orthogonal improvements. Proofs are in
appendix

A
.

Palindrome.

Palindrome requires the model to reproduce a random token sequence in reverse order, testing ordered sequence storage rather than key-value association:

\begin{array}[]{rccccccccc}\textbf{Input}&O&G&R&S&U&N&E&\langle\mathrm{sep}\rangle&E\;N\;U\;S\;R\;G\;O\\
\textbf{Output}&\phi&\phi&\phi&\phi&\phi&\phi&\phi&\phi&N\;U\;S\;R\;G\;O\;\phi\end{array}

Multi-Query Associative Recall (MQAR).

MQAR tests whether a model can retrieve values associated with multiple query keys appearing at different positions in the context. For example, after observing pairs such as
B\mapsto 0
and
G\mapsto 5
, the model must output the corresponding values when queried:

\begin{array}[]{rccccccccccccccc}\textbf{Input}&A&1&C&3&B&0&M&8&G&5&E&4&\langle\mathrm{sep}\rangle&B&G\\
\textbf{Output}&\phi&\phi&\phi&\phi&\phi&\phi&\phi&\phi&\phi&\phi&\phi&\phi&\phi&0&5\end{array}

S-NIAH.

Single-needle-in-a-haystack evaluates whether the model can write and retrieve one salient key-value association among long distractor contexts.

Stack.

Stack simulates LIFO push-pop state tracking. The input contains push operations that insert elements into one of several stacks and pop operations that require the model to output the most recently pushed element for the queried stack. The task stresses repeated local state edits rather than a single retrieval.

6
Limitations

KLA improves the local write coefficient but retains the capacity limits of a fixed-size recurrent state.
The exact projection result in
theorem

1
holds only when
\eta_{t}=1
and
\varepsilon=0
; the practical model trades exactness for numerical stability and adaptive write strength.
In low-precision arithmetic, very small key norms make the choice of
\varepsilon
important.
The longest Palindrome setting also shows a case where GDN slightly outperforms KLA, suggesting that structured reversal may need mechanisms beyond key-norm-normalized residual writes.

7
Conclusion

KLA shows that the delta-rule coefficient determines whether a recurrent write solves its local regression problem. Viewing the write as a constrained projection yields the Kaczmarz coefficient, a self-normalized replacement for GDN’s learned scalar that becomes an orthogonal projection, exact line-search minimizer, and normalized gradient step in the unrelaxed setting.

Empirically, this coefficient improves 0.4B pretraining PPL by 0.41 over GDN, lowers long-context PPL by 3.7–4.1 across tested lengths, improves MQAR
8\times
extrapolation by 7.03 points, reaches 100% on S-NIAH, and preserves GDN-like prefill while improving 32K decode throughput by
2.1\times
. The ablations identify key-norm normalization as necessary for stable pretraining, while Palindrome remains a boundary case for normalized residual writes. Future work should test larger state layouts, diagonal or expanded gating, and larger-scale pretraining regimes.

Appendix A
Proofs for the Tokenwise Theory

A.1
Proof of
Theorem

1

Let
\widetilde{S}=\widetilde{S}_{t-1}
,
e=e_{t}
, and
k=k_{t}
.

Part (ii): exact line search.

Consider the one-parameter family
S(\tau)=\widetilde{S}+\tau ke^{\mathsf{T}}
. Substituting into the per-token loss:

\displaystyle\mathcal{L}_{t}(S(\tau))

\displaystyle=\frac{1}{2}\|S(\tau)^{\mathsf{T}}k-v_{t}\|_{2}^{2}=\frac{1}{2}\bigl\|\widetilde{S}^{\mathsf{T}}k+\tau e\lVert k\rVert_{2}^{2}-v_{t}\bigr\|_{2}^{2}

\displaystyle=\frac{1}{2}\bigl(-e+\tau\lVert k\rVert_{2}^{2}e\bigr)^{2}=\frac{1}{2}\bigl(1-\tau\lVert k\rVert_{2}^{2}\bigr)^{2}\lVert e\rVert_{2}^{2}.

(10)

Setting the derivative to zero:
\tau^{*}=1/\lVert k\rVert_{2}^{2}
.

Constraint satisfaction.

Substituting
\tau^{*}
:

\displaystyle S_{t}^{\mathsf{T}}k=\widetilde{S}^{\mathsf{T}}k+e\frac{k^{\mathsf{T}}k}{\lVert k\rVert_{2}^{2}}=\widetilde{S}^{\mathsf{T}}k+e=v_{t}.

(11)

Hence
S_{t}\in\mathcal{A}_{t}
.

Part (i): orthogonal projection.

The tangent space of
\mathcal{A}_{t}
is
T_{\mathcal{A}_{t}}=\{H\in\mathbb{R}^{d_{k}\times d_{v}}:H^{\mathsf{T}}k=0\}
. The correction
\Delta=S_{t}-\widetilde{S}=ke^{\mathsf{T}}/\lVert k\rVert_{2}^{2}
. For any
H\in T_{\mathcal{A}_{t}}
:

\displaystyle\langle\Delta,H\rangle_{F}=\operatorname{tr}\Bigl(\frac{1}{\lVert k\rVert_{2}^{2}}ke^{\mathsf{T}}H^{\mathsf{T}}\Bigr)=\frac{1}{\lVert k\rVert_{2}^{2}}e^{\mathsf{T}}(H^{\mathsf{T}}k)=0,

(12)

since
H^{\mathsf{T}}k=0
. Therefore
\Delta\perp T_{\mathcal{A}_{t}}
, confirming that
S_{t}
is the orthogonal projection of
\widetilde{S}
onto
\mathcal{A}_{t}
.

Part (iii): normalized SGD.

The gradient of
\mathcal{L}_{t}
at
\widetilde{S}
is
\nabla_{S}\mathcal{L}_{t}\big|_{S=\widetilde{S}}=k(\widetilde{S}^{\mathsf{T}}k-v_{t})^{\mathsf{T}}=-ke^{\mathsf{T}}
. Therefore:

S_{t}=\widetilde{S}-\frac{1}{\lVert k\rVert_{2}^{2}}\nabla_{S}\mathcal{L}_{t}\big|_{S=\widetilde{S}},

which is normalized gradient descent with coefficient
1/\lVert k\rVert_{2}^{2}
.

Remark 2
.

By the projection theorem for Hilbert spaces,
S_{t}
is the unique element of
\mathcal{A}_{t}
satisfying
\lVert S_{t}-\widetilde{S}\rVert_{F}\leq\lVert S-\widetilde{S}\rVert_{F}
for all
S\in\mathcal{A}_{t}
, with equality only when
S=S_{t}
. The Kaczmarz update makes the minimum Frobenius-norm change to the state.

A.2
Alternative derivation via Lagrange multipliers

The Lagrangian of (
1
) is
\mathcal{J}(S,\lambda)=\frac{1}{2}\lVert S-\widetilde{S}\rVert_{F}^{2}+\lambda^{\mathsf{T}}(S^{\mathsf{T}}k-v_{t})
with
\lambda\in\mathbb{R}^{d_{v}}
. Setting
\partial\mathcal{J}/\partial S=0
:

S-\widetilde{S}+k\lambda^{\mathsf{T}}=0\implies S=\widetilde{S}-k\lambda^{\mathsf{T}}.

Substituting into
S^{\mathsf{T}}k=v_{t}
:

\displaystyle(\widetilde{S}-k\lambda^{\mathsf{T}})^{\mathsf{T}}k=v_{t}\implies\lambda=\frac{\widetilde{S}^{\mathsf{T}}k-v_{t}}{\lVert k\rVert_{2}^{2}}=-\frac{e}{\lVert k\rVert_{2}^{2}}.

(13)

Therefore
S_{t}=\widetilde{S}+ke^{\mathsf{T}}/\lVert k\rVert_{2}^{2}
, recovering the Kaczmarz update. ∎

A.3
Proof of
Proposition

1

The proximal problem is:

\minimize_{S}\;\frac{1}{2}\lVert S-\widetilde{S}\rVert_{F}^{2}+\frac{\mu_{t}}{2}\|S^{\mathsf{T}}k-v_{t}\|_{2}^{2}.

Setting the gradient to zero:
S-\widetilde{S}+\mu_{t}k(S^{\mathsf{T}}k-v_{t})^{\mathsf{T}}=0
.
Substituting
S=\widetilde{S}+\tau ke^{\mathsf{T}}
:

\displaystyle\tau ke^{\mathsf{T}}+\mu_{t}k\bigl(\tau\lVert k\rVert_{2}^{2}e-e\bigr)^{\mathsf{T}}

\displaystyle=0

\displaystyle k\,e^{\mathsf{T}}\bigl(\tau+\mu_{t}\tau\lVert k\rVert_{2}^{2}-\mu_{t}\bigr)

\displaystyle=0.

(14)

Solving:
\tau=\mu_{t}/(1+\mu_{t}\lVert k\rVert_{2}^{2})
. Substituting
\mu_{t}=\eta_{t}/((1-\eta_{t})\lVert k\rVert_{2}^{2}+\varepsilon)
:

\displaystyle\tau=\frac{\eta_{t}}{(1-\eta_{t})\lVert k\rVert_{2}^{2}+\varepsilon+\eta_{t}\lVert k\rVert_{2}^{2}}=\frac{\eta_{t}}{\lVert k\rVert_{2}^{2}+\varepsilon},

(15)

which is exactly the KLA coefficient. ∎

A.4
Proof of
Proposition

2

Starting from (
3
):

\displaystyle S_{t}^{\mathsf{T}}k

\displaystyle=\widetilde{S}^{\mathsf{T}}k+\frac{\eta_{t}}{\lVert k\rVert_{2}^{2}+\varepsilon}e\,(k^{\mathsf{T}}k)=\widetilde{S}^{\mathsf{T}}k+\eta_{t}\frac{\lVert k\rVert_{2}^{2}}{\lVert k\rVert_{2}^{2}+\varepsilon}e.

(16)

Therefore:

\displaystyle e_{t}^{+}=v_{t}-S_{t}^{\mathsf{T}}k=e-\eta_{t}\frac{\lVert k\rVert_{2}^{2}}{\lVert k\rVert_{2}^{2}+\varepsilon}e=\Bigl(1-\eta_{t}\frac{\lVert k\rVert_{2}^{2}}{\lVert k\rVert_{2}^{2}+\varepsilon}\Bigr)e.

(17)

For
\eta_{t}\in(0,1]
and
\varepsilon\geq 0
, the factor lies in
[0,1)
, so
\|e_{t}^{+}\|_{2}<\|e_{t}\|_{2}
. Squaring both sides gives
\mathcal{L}_{t}(S_{t})\leq\mathcal{L}_{t}(\widetilde{S}_{t-1})
. ∎

A.5
Decay-agnostic remark

Let
D_{t}
be any linear operator and
\widetilde{S}=D_{t}S_{t-1}
. The projection problem
\min_{S\in\mathcal{A}_{t}}\lVert S-\widetilde{S}\rVert_{F}
depends only on the base point
\widetilde{S}
and the constraint
\mathcal{A}_{t}
. The derivation of
theorem

1
uses only
e=v_{t}-\widetilde{S}^{\mathsf{T}}k
and
\lVert k\rVert_{2}^{2}
, making no assumption about how
\widetilde{S}
was produced from
S_{t-1}
. The Kaczmarz coefficient applies regardless of whether
D_{t}=\alpha_{t}I
,
D_{t}=\operatorname{Diag}(\alpha_{t})
, or any other linear decay.

(\gamma_{i}R_{0}k_{i})^{\mathsf{T}}=(D_{\gamma}KR_{0}^{\mathsf{T}})_{i}

.

Define the strict lower-triangular matrix:

L_{ij}=\begin{cases}\beta_{i}\,\dfrac{\gamma_{i}}{\gamma_{j}}\,G_{ij},&j<i,\\
0,&j\geq i.\end{cases}

Using the causal decay matrix

for

The

The output at position

is

\displaystyle o_{i}

\displaystyle=\gamma_{i}R_{0}q_{i}+\sum_{j=1}^{i}\frac{\gamma_{i}}{\gamma_{j}}\,u_{j}\,(k_{j}^{\mathsf{T}}q_{i}).

Stacking all

O=D_{\gamma}QS_{0}+(A\odot QK^{\mathsf{T}})\,U,

where

\displaystyle S_{\mathrm{out}}=R_{C}^{\mathsf{T}}

\displaystyle=\Bigl(\gamma_{C}R_{0}+\sum_{j=1}^{C}\frac{\gamma_{C}}{\gamma_{j}}\,u_{j}\,k_{j}^{\mathsf{T}}\Bigr)^{\mathsf{T}}

B.4
Why coefficient substitution suffices

The entire derivation uses
\beta_{i}
only through the diagonal matrix
B=\operatorname{Diag}(\beta_{1},\ldots,\beta_{C})
and the recurrences (
19
)–(
21
). No structural property of the GDN coefficient—such as the absence of
\lVert k_{i}\rVert_{2}
in the denominator—is invoked at any step. Replacing
\beta_{i}=\eta_{i}
with
\beta_{i}=\eta_{i}/(\lVert k_{i}\rVert_{2}^{2}+\varepsilon)
therefore produces the complete KLA chunkwise algorithm by substituting a different diagonal matrix
B
into the same GDN kernel. No new CUDA kernel or parallel reduction is required.

B.5
Extension to diagonal gating

When the decay operator is diagonal,
D_{t}=\operatorname{Diag}(\alpha_{t})
(as in GLA and KDA
[
36
]
), the scalar
\gamma_{i}
becomes a vector
\bm{\gamma}_{i}
and all decay products become elementwise. The WY propositions generalize by replacing
\gamma_{r\to i}
with
\operatorname{Diag}(\bm{\gamma}_{r\to i})
wherever it appears. The local Kaczmarz coefficient still applies unchanged; only the transition algebra inside the chunk changes. The chunkwise derivation for diagonal-gated KLA follows the KDA template with
B
substituted accordingly.
