1. What are the major goals of the project?
The objective of RAPIDS2 SciDAC Institute for Computer Science and Data is to assist Office of
Science (SC) application teams in overcoming computer science and data challenges in the use of
DOE supercomputing resources to achieve science breakthroughs. To accomplish this objective,
the Institute solved computer science and data technical challenges for SciDAC and SC science
teams, worked directly with SC scientists and DOE facilities to adopt and support our technologies,
and coordinated with other SciDAC Institute activities to maximize impact on SC science.
This report presents the activities and outcomes of the Northwestern University team as a member
of the RAPIDS2 Institute. Our goals include the followings.
 1. Maintain the software sustainability of Parallel NetCDF (PnetCDF), a production parallel
 I/O library, deployed on all DOE parallel computers and commonly used in scientific
 research communities, which provides a full set of I/O functions to enable users to create
 self-describing files.
 2. Development of Python package of PnetCDF.
 3. Development of an I/O module for Darshan to capture the I/O activities of PnetCDF.
 Darshan is an I/O characterization tool developed at ANL that transparently captures I/O
 access pattern information from HPC applications.
 4. Working with the high-energy physics research group at the Fermi National Laboratory to
 develop parallel I/O modules and data management utility software to support various post
 neutrino simulation data analysis workload, in specific particle track graph data generation
 and neural network model training.
 5. Collaborating with the computational science researchers in the Lawrence Berkeley
 National Laboratory on developing parallel algorithms for shortening the run time of neural
 network model training of Cosmoflow and DeepCAM applications on the DOE
 supercomputers.
 6. Ensuring the performance scalability on the DOE leadership parallel computers for the
 software developed under this project.
2. What was accomplished under these goals?

PnetCDF — Two versions of the software, 1.14.0 and 1.14.1 were released on November 11, 2024
and July 31, 2025, respectively. They include new features, such as the intra-node data aggregation,
for performance enhancement and supports for using MPI large-count feature defined in MPI
standard 4.0.
PnetCDF Python — The first Python package (version 1.0.0) for PnetCDF was released on
November 12, 2024. The package also contains many example python programs, including
MNIST, a machine learning application using CNN whose I/O module is modified to make use
PnetCDF.
Support Scalable Data Management for Data Analysis Workload in Neutrino Particle
Collision Research – Neutrino particle simulations in High Energy Physics (HEP) generate large
volumes of data that, when analyzed, can be used to help better understand the fundamental
particles and their interactions. Reconstructing low-level particle tracks in neutrino physics can
address some of the most fundamental questions about the universe. In the Exa.TrkX Project, an
illustrative HEP application, preprocessed simulation data is fed into a state-of-art Graph Neural
Network (GNN) model, accelerated by GPUs. Collaborating with Giuseppe Cerati at FNAL and V
Hewes and Adam Aurisano at University of Cincinnati, we so-authored a technical paper published
in the Physical Review D. in August 2024.
Accelerating the Computation of Convolutional Neural Network Training — Neural networks
are rapidly gaining popularity in scientific research, but training the models is often very time-
consuming. Particularly when the training data samples are large high-dimensional arrays, efficient
training methodologies that can reduce the computational costs are crucial. To reduce the training
cost, we have developed a Multi-Resolution Model Fusion (MRMF) method that combines models
trained on reduced-resolution data and then refined with data in the original resolution. This work
is established upon a collaboration with John Wu, Jan Balewski, Alex Sim, and Peter Nugent at
LBNL. A technical paper was published in arXiv in October 2025.
Performance Study of Modern Parallel I/O Techniques — High-level I/O libraries, such as
PnetCDF and HDF5, are commonly used by large-scale scientific applications to perform I/O tasks
in parallel. These I/O libraries store the metadata of data objects in files along with their raw data.
To ensure metadata consistency during parallel data object creation, they require applications to
call the metadata APIs collectively using consistent metadata. Such a requirement can result in an
expensive consistency check, as its cost increases with the metadata volume and the number of
processes. To address this limitation, we developed a new file header format which enables
independent data object creation and can reduce the objects required for consistency check. This
work is published in the PDSW workshop in November 2025.

5. What do you plan to do during the next reporting period to accomplish the goals?
This is the final report.

We will continue working on the proposed tasks, including development of scalable algorithms,
for parallel data management and machine learning algorithms, and their applications in scientific
applications supported by DOE.

Data Movement in Storage Hierarchy on HPC Machines – In collaborating with researchers at
LBNL, John Wu and his team, we are developing a data caching layer that uses a background thread
to move data stored in a storage hierarchy consisting of file system, NVRAM, and RAM. The
targeted applications are ML applications exhibiting an I/O pattern of reading data repeatedly and
randomly shuffled. Caching soon-to-be-accessed data in a nearby storage device can significantly
reduce the I/O costs.

that can satisfy many synergistic performance requirements for large-scale data analysis
