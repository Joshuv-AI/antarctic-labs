Abstract
. Recently, Generative Recommenders (GRs) have emerged as a transformative recommendation paradigm by replacing traditional item IDs with semantic indices (SIDs). Owing to the exceptional generative capabilities of diffusion models, a few pioneering works explore developing GRs with diffusion architectures as the backbone. However, a fatal limitation of existing diffusion-based GRs is that the diffusion process applies uniformly to all items within the historical interactions. In contrast, the user preference is shaped by multifaceted time-evolving factors and thus exhibits a non-stationary distribution in the temporal aspect. To bridge this gap, this study proposes a novel GR framework, named TDPM, by designing the time-aware diffusion on SID tokens. Specifically, TDPM explicitly integrates the impact of time-evolving user preferences into the diffusion process. In detail, the user preference is disentangled into (i) the period preference , which remains consistent over a long time-span, and (ii) the point preference , which is triggered by recent focal events. Extensive experiments on three public real-world datasets demonstrate the significant superiority of TDPM over the state-of-the-art baselines. TDPM achieves average improvements of up to 29.21% and 25.45% in terms of HR@20 and NDCG@20, respectively. The ablation study further underscores the necessity of time-aware token diffusion in diffusion-based GRs. Our code and datasets are available at https://github.com/Sylphy666/TDPM.

Preliminary

2.1.
Generative Recommendation

Let
U
denote the set of all users and
I
denote the set of all items. For a given user
u\in U
, let
H_{u}
denote
u
’s interaction history of length
n
, represented as
H_{u}=(i_{1},i_{2},\dots,i_{n})\in I
in chronological order. Unlike traditional discriminative recommendation methods
(
13
;
28
)
that mostly retrieve recommendation results based on
Maximum Inner Product Search
, GR models can directly generate the next item that the user is most likely to interact with, conditioned on the interaction history
(
5
)
. GR models address this problem by modeling the conditional probability distribution over the user interaction history, specifically by outputting the most probable next-item prediction according to
p(i_{n+1}\mid(i_{1},i_{2},\dots,i_{n}))
.

2.2.
SID-based Generative Recommender

The GR paradigm based on semantic indices (SID), leverages item semantic representations to construct discrete and structured SID for each item. And GR subsequently models the probability distribution over the user interaction history in SID space, rather than directly in the raw ID space
(
35
;
36
)
. By compressing high-dimensional semantic features into compact discrete SID, SID-based approaches substantially mitigate the scalability challenges inherent in conventional GRs while preserving semantic proximity among items. Concretely, this paradigm comprises two principle modules,
SID Generation
and
Recommendation-oriented Finetuning

(
35
;
22
)
.

2.2.1.
SID Generation

The objective of this module is to produce discrete tokens as SID for each item, grounded in its rich semantic features (e.g., textual descriptions and visual attributes). The generation process typically unfolds in two stages. First, for an arbitrary item
i_{j}
, an off-the-shelf pretrained embedding model (e.g., LLMs or multi-modal LLMs) is employed to extract a dense semantic embedding vector
e_{j}\in\mathbb{R}^{d}
. Second, to compress the continuous embedding into discrete SID, a vector quantization algorithm, such as Residual Quantized VAE (RQ-VAE)
(
38
;
35
)
or Residual Quantization K-Means (RQ-KMeans)
(
36
)
is employed over the entire set of item embedding vectors
\{e_{j}\mid j=1,\dots,\mid I\mid\}
. This procedure yields a multi-level, coarse-to-fine discrete SID for each item. The resulting SID is denoted as a token sequence
(s^{(1)},\dots,s^{(m)})
with
m
denoting the length of SID and each
s^{(k)},k=1,\dots,m
belonging to a finite vocabulary determined by the corresponding quantization layer
(
22
;
35
)
. Notably, this hierarchical structure endows the SID space with a semantic tree topology, where items sharing common prefixes exhibit stronger semantic similarity.

2.2.2.
Recommendation-oriented Finetuning

The GR paradigm aims to model the probability distribution of each user’s interaction history within the derived SID space
(
35
)
. Specifically, for a given user
u
with an interaction history of length
n
, denoted as
H_{u}=(i_{1},i_{2},\dots,i_{n})
, the corresponding SID sequence
S_{u}
is constructed by concatenating the SID of the interacted items:

(1)

S_{u}=\bigl((s_{1}^{(1)},\dots,s_{1}^{(m)}),\dots,(s_{n}^{(1)},\dots,s_{n}^{(m)})\bigr).

SID-based GR predominantly adopts autoregressive modeling paradigm
(
22
;
38
;
35
;
36
)
, wherein the conditional probability of the next item’s SID is factorized token by token:

(2)

p\bigl(s_{n+1}^{(1:m)}\mid S_{u}\bigr)=\prod_{k=1}^{m}p\bigl(s_{n+1}^{(k)}\mid s_{n+1}^{<k},S_{u}\bigr),

where
s_{n+1}^{(1:m)}
is the SID of next item the user will interact with and
s_{n+1}^{<k}
denotes the tokens that the model has predicted.

Existing implementations generally achieve this autoregressive generation using large language model (LLM)
(
22
;
38
;
35
)
, which iteratively predict each token of the target SID. By modeling in the compact and discrete SID space, these models avoid scoring every raw item individually, thereby enabling efficient and scalable next-item prediction, meanwhile still benefiting from the rich semantic structure encoded in the discrete representations.

2.3.
Diffusion Model

Diffusion model is a class of deep generative models grounded in non-equilibrium thermodynamics
(
26
;
10
;
27
)
, which has achieved remarkable success across various generation tasks
(
23
;
9
;
2
;
33
)
. The framework comprises two complementary processes: a forward diffusion process that gradually perturbs data by adding noise into pure noise, and a reverse process that reconstructs data by iteratively removing the added noise
(
10
)
.

Formally, the clean data sample
x_{0}
is sampled from the target data distribution
q(x_{0})
and the denoising diffusion model aims to approximate the real data distribution by
q_{\theta}(x_{0})

(
10
;
27
)
. In the forward diffusion process,
q(x_{0})
is diffused into a pure Gaussian noise distribution using a fixed Markov chain,

(3)

q(x_{t}\mid x_{t-1})=\mathcal{N}\left(x_{t};\sqrt{\alpha_{t}}x_{t-1},\sqrt{1-\alpha_{t}}\mathbf{I}\right),

where
\alpha_{t}\in(0,1]
controls the diffusion scale at time step
t\in[1,T]
and
T
is the total number of diffusion time steps. For end-to-end optimization, the perturbed sample
x_{t}
at time step
t
, can be sampled directly from
x_{0}
by reparameterization,

(4)

x_{t}=\sqrt{\bar{\alpha}_{t}}x_{0}+\sqrt{1-\bar{\alpha}_{t}}\epsilon,\quad\epsilon\sim\mathcal{N}(0,\mathbf{I}),

where
\bar{\alpha}_{t}=\prod_{i=1}^{t}\alpha_{i}
.

The reverse reconstruction process is also a Markov chain starting at
p_{\theta}\sim(x_{T};0,\mathbf{I})
and learns to invert this diffusion process through parameterized denoising transitions:

(5)

p_{\theta}(x_{t-1}\mid x_{t})=\mathcal{N}\bigl(x_{t-1};\mu_{\theta}(x_{t},t),\Sigma_{t}(x_{t},t)\bigr),

where
p_{\theta}(x_{t-1}\mid x_{t})
is a learnable transfer probability (the variance schedule
\Sigma_{t}
is fixed). A simplified loss function is derived from the maximum likelihood of
p_{\theta}(x_{0})

(
16
)
, i.e.,

(6)

L(\theta)=\mathbb{E}_{x_{0}\sim q(x_{0}),\epsilon\sim N(0,\textbf{I})}\bigl[\lVert\epsilon-\epsilon_{\theta}(x_{t},t)\rVert^{2}\bigr].

The estimated noise
\epsilon_{\theta}
can be used to represent
\mu_{\theta}
in
p_{\theta}(x_{t-1}\mid x_{t})
and thus
x_{t-1}
could be sampled from
p_{\theta}(x_{t-1}\mid x_{t})
. Through iterative denoising from Gaussian noise, diffusion model is capable of generating high-quality data samples step by step.

3.
Methodology

In this section, we elaborate the proposed GR framework
TDPM
. As illustrated in Figure
2
, TDPM first disentangles user preference into the period preference and the point preference. Afterwards, the period and point preferences are synergized to adapt the standard diffusion process for SID-based generative recommendation.

3.1.
Semantic ID Generation

Similar to existing GR approaches that utilize SID paradigm
(
22
;
38
;
35
)
, we first generate an SID consisting of
m
tokens for each item in the item set
I
, which encodes rich semantic information grounded in textual descriptions of each item.

3.1.1.
Semantic Embedding Extraction

For each item
i_{j}\in I
, we leverage a large language model (LLM) pretrained for embedding generation to encode the corresponding textual metadata (e.g., title, description, category and brand) into a dense semantic embedding vector
\mathbf{e}_{j}\in\mathbb{R}^{d}
. The resulting SID encodes the rich semantic information of the item in a continuous vector space.

3.1.2.
Residual Quantization

To convert a continuous embedding vector into discrete tokens, we apply RQ-KMeans algorithm
(
36
)
over the entire set of item embedding vectors
\{e_{j}\mid j=1,\dots,\mid I\mid\}
,

(7)

\begin{gathered}s_{j}^{(k)}=\text{argmin}_{c\in\mathcal{C}^{(k)}}\bigl\lVert\mathbf{r}^{(k)}-\mathbf{c}\bigr\rVert_{2}^{2},\\
\mathbf{r}^{(k+1)}=\mathbf{r}^{(k)}-\mathbf{c}_{s_{j}^{(k)}},\quad k=1,\dots,m,\end{gathered}

where
s_{j}^{(k)}
is the
k
-th token assigned to item
i_{j}
,
\mathbf{r}^{(k)}
denotes the residual vector at the
k
-th quantization layer where specifically
\mathbf{r}^{(1)}=\mathbf{e}_{j}
,
\mathcal{C}^{(k)}
denotes the set of clustering centroids at the
k
-th quantization layer and
\mathbf{c}_{s_{j}^{(k)}}
is the corresponding embedding vector of the clustering centroid that token
s_{j}^{(k)}
belongs to. This residual quantization process is repeated for
m
iterations, yielding an
m
-token SID
S_{j}=(s_{j}^{(1)},\dots,s_{j}^{(m)})
for each item.

The hierarchical structure of the residual quantization algorithm endows the resulting SID space with a coarse-to-fine semantic structure. And hence items sharing common prefixes tend to be semantically similar, while subsequent layers progressively refine more fine-grained distinctions. This property is particularly beneficial for generative recommendation as it introduces a meaningful inductive bias over the discrete token space.

3.2.
Time-Aware Token Diffusion based on Preference Disentanglement

For a user
u
with interaction history of length
n
, the original item ID sequence
H_{u}=(i_{1},i_{2},\dots,i_{n})
is converted into the corresponding SID sequence
S_{u}
to represent the user’s interaction history, defined as
S_{u}=\bigl((s_{1}^{(1)},\dots,s_{1}^{(m)}),\dots,(s_{n}^{(1)},\dots,s_{n}^{(m)})\bigr)
.

Since SID-based diffusion model replaces the conventional noise-adding in the forward diffusion process with token-masking, our proposed time-aware token diffusion is therefore realized as
time-aware token masking
. In the forward process, each interacted item is assigned with a masking probability
p_{j},j=1,\dots,n
. Based on the masking probability
p_{j}
, each token of each item’s SID is independently masked, indicating that the probability that all
m
tokens of an item are simultaneously masked is thus
{p_{j}}^{m}
. Additionally let
[M]
denote the special mask token and
\tilde{S_{u}}
denote the masked SID sequence. In fact, a higher masking probability represents a higher attention to this item. Through such masking mechanism, the model can better learn the SID co-occurrence patterns and concentrate more intently on the time-evolving user preference.

Different from standard diffusion process, we develop the time-aware token masking strategy in the training phase, which imposes time-aware and non-uniform degrees of perturbation on each item in the interaction history. Specifically, within the time-aware token masking strategy, the masking probability
p_{j}
for the
j
-th item in the interaction history is determined by user preference. To effectively capture the preference signals inherent in user behaviors, we disentangle the user preference into
period preference

p_{period}
and
point preference

p_{point}
. These disentangled preferences respectively capture the stable long-term preference accumulated over time and the transient short-term preference triggered by recent focal events. Therefore, the final masking probability
p_{j}
for item
i_{j}
is comprehensively determined by the period preference and the point preference via an adaptive weighting mechanism to dynamically balance their respective magnitude.

As illustrated in Figure
2
, TPDM simultaneously incorporates the period preference and the point preference, and dynamically regulates their respective contributions to the final masking probability
p_{j}
through the adaptive weight
\lambda
. Then the SIDs of items in the interaction history are masked based on their masking probabilities. And to align with the inference task, the SID of the target item is enforced to be fully masked. Eventually, the masked SID sequence
\tilde{S_{u}}
is fed into the model for reverse token prediction.

3.2.1.
Period preference

To explicitly model the enduring interest consistency that characterizes the user’s long-term preference, we introduce
period preference
. Specifically, the period preference captures stable behavioral patterns that persist over an extended time period. The primary role of period preference is to regulate the masking probability in a temporally adaptive manner, thereby guiding the model to prioritize the reconstruction of recent items while maintaining the awareness of earlier items.

Concretely, we first assign a temporal index
t_{j}=t(j)
to each item in the user’s interaction history in chronological order, where
t(\cdot)
is a non-decreasing function of position
j
(e.g.
t(j)=j^{k},k\geqslant 0
). The temporal index is then converted into a continuous masking probability that sensitively reflects the temporal order. Concretely we apply a normalization function
\mathrm{Norm}(\cdot)
that centers and scales the temporal indices, followed by a squashing function
\phi_{t}:\mathbb{R}\to(0,1)
that restricts the output to the unit interval. Formally,

(8)

p_{period}=\phi_{t}\bigl(\mathrm{Norm}(t_{j})\bigr),

where
\phi_{t}
is chosen to be monotonically increasing, (e.g., Sigmoid function), ensuring that larger temporal indices are assigned with larger values of
p_{period}
. This formulation reflects the relative positions of all interacted items in chronological order.

The increasing profile of
\phi_{t}
is motivated by the intuition that a user’s current interest is typically better reflected by items interacted in the near past
(
31
;
20
)
. Accordingly, by inflating the value of
p_{period}
for later position, we deliberately increase the amount of perturbation to those items during the forward diffusion process. In essence, the period preference serves as a
temporally progressive regularization
that biases diffusion model toward faithfully reconstructing the most predictive parts of the SID sequence, while simultaneously encoding the consistency of user preferences.

Figure
3
indicates that the period preference increases monotonically with the progression of interaction time. This design represents the intuition that more recent interactions carry greater predictive weights for next-item recommendation
(
19
)
, as they better capture the user’s current interest state. Accordingly, later items in the interaction history are assigned with larger period preference values, enabling the model to prioritize temporally proximate signals when modeling long-term preference consistency.

3.2.2.
Point Preference

To complement the period preference capturing enduring preference consistency, we introduce
point preference
to model the abrupt and point-specific interest deviations in interaction history. Unlike the stable and slowly-evolving nature of period preference, point preference is inherently transient and irregular, representing the user’s sensitivity to immediate stimuli.

Formally, for the
j
-th item
i_{j}
in the interaction history, point preference quantifies the interest deviation between adjacent interacted items. We compute each item’s semantic deviation with the preceding item
i_{j-1}
based on their embedding vectors and define the interest deviation
d_{j}
and point preference
p_{point}
as

(9)

\begin{gathered}d_{j}=1-\text{sim}(e_{j-1},e_{j}),\\
p_{point}=\phi_{d}(d_{j}),\end{gathered}

where
\text{sim}(\cdot,\cdot)
is a similarity function (e.g., cosine similarity function) and to guarantee a consistent numerical range across different samples,
\phi_{d}
, a scaling function, is further employed to normalize
d_{j}
to [0, 1]. Specifically, as for the first item whose preceding item doesn’t exist, the interest deviation of the first item,
d_{1}
, is set to 0, leading
p_{point}=0
. Due to the absence of preceding interacted item, there exists no measurable interest deviation at the starting point. And the first item simply serves as the initial anchor from which the subsequent interest deviations can be computed.

Point preference plays a critical role, distinct from that of the period preference. A large
p_{point}
value indicates a substantial interest deviation from the previous interacted items. By incorporating
p_{point}
into the masking probability
p_{j}
, we deliberately increase the perturbation level on items representing significant interest deviations. During the forward diffusion process, such items are more heavily masked, forcing the model to learn the interest deviations. This mechanism serves two purposes. First, it compels the model to learn how to recover interest deviations from sparse and noisy signals, thereby sharpening its sensitivity to behavioral changes. Second, by amplifying the reconstruction difficulty at the deviation points, the model is encouraged to build a more robust internal representation of user preference dynamics. In essence, point preference acts as an
interest-deviation amplifier
, ensuring that pivotal points of preference changes receive heightened attention.

indicates that the point preference
p_{point}
follows no fixed schedule. The resulting values exhibit an irregular pattern driven by the user interest deviations between adjacent items, with a notably low value assigned to the first interacted item.

3.2.3.
Weighed Fusion of Period Preference and Point Preference.

To simultaneously capture the disentangled preferences from the interaction history, the period preference and the point preference are fused via an adaptive weighting mechanism, defined as

(10)

p_{j}=\alpha+\beta\cdot\bigl[\lambda p_{period}+(1-\lambda)p_{point}\bigr],

where the hyperparameters are defined as follows:

•

\alpha
: a base masking probability that prevents the masking probability
p_{j}
from vanishing in extreme cases (e.g., when both
p_{period}
and
p_{point}
approach zero);

•

\beta
: a scaling factor that controls the overall contribution of the fused preference of
p_{period}
and
p_{point}
;

•

\lambda
: an adaptive weight that dynamically balances the contributions of period preference and point preference. More importantly,
\lambda
is not fixed but gradually increases as the training progresses, reflecting the growing significance of the period preference in later epochs. Concretely, we adopt a power-law growth schedule:

(11)

\lambda=\lambda_{start}+\biggl(\frac{E_{curr}-E_{warm}}{E_{total}-E_{warm}}\biggr)^{k},

where
\lambda_{start}
is the initial value of
\lambda
at the beginning of the time-aware token masking stage,
E_{curr}
denotes the current epoch,
E_{\text{warm}}
is the epoch at which the preceding warm-up stage ends (detailed in Section
3.3
),
E_{total}
denotes the total number of training epochs, and
k
controls the curvature of growth schedule of the adaptive weight
\lambda
.

The fused result serves as the masking probability
p_{j}
for each item, which determines the degree of token masking.

Each token in the SID of a given item
i_{j}
is independently masked based on the masking probability
p_{j}
. To align with the inference task, we explicitly enforce full masking of all
m
tokens belonging to the target item in the interaction history.

The training objective of the time-aware token masking stage is to maximize the likelihood of predicting the correct tokens, employing the following loss function with the model parameter
\theta
,

(12)

\mathcal{L}_{T}=-\Sigma_{k=1}^{mn}\mathbb{I}[\tilde{S_{u}}(k)=\texttt{[M]}]\cdot p_{j}\cdot logp_{\theta}(S_{u}(k)\mid\tilde{S_{u}}),

where
S_{u}(k)
represents the ground-truth token at
k
-th position,
\tilde{S_{u}}(k)
is the token at the
k
-th position in the masked SID sequence
\tilde{S_{u}}
, the indicator function
\mathbb{I}[\cdot]
ensures that the loss is computed exclusively over the masked positions and
p_{j}
is the masking probability of
j
-th item in the interaction history which the
k
-th token
S_{u}(k)
belongs to (
j=\left\lfloor\frac{k-1}{m}\right\rfloor+1
). The weighting mechanism amplifies the training signal for tokens belonging to items with higher masking probabilities, thereby encouraging the model to concentrate more on recovering the masked tokens at positions that are considered more informative. 3.3.
Optimization

In practical implementation, we usually utilize a warm-up stage before the time-aware token masking stage, which draws inspiration from the pretrain-finetune paradigm of large language model training

)
. The warm-up stage functions as a pretraining phase, allowing the model to develop a general understanding of the SID vocabulary and its co-occurrence patterns through stochastic masked token reconstruction. Building upon this, the time-aware token masking stage serves as a task-specific finetuning phase, where the model learns to perform next-item recommendation, precisely the objective of the inference phase.

At the warm-up stage of training, we employ a uniform token masking strategy, wherein all the items in the interaction history share an identical masking probability
p
,

(13)

p_{1}=p_{2}=\cdots=p_{n}=p.

To improve the training stability, the identical masking probability
p
is not fixed but sampled from a bounded uniform distribution,

(14)

p\sim\mathcal{U}(p_{\min},p_{\max}),

where
\mathcal{U}
denotes the uniform distribution,
p_{\min}
and
p_{\max}
denote the lower and upper bound of the uniform distribution respectively. This stochastic sampling of
p
exposes the model to varying degrees of data perturbation, enabling stability and robustness across different masking ratios and building a solid foundation for the subsequent time-aware token masking stage.

Once the masking probability
p
is determined, each token in the SID sequence is independently masked according to
p
, and the resulting masked sequence is then fed into the diffusion model for the reverse prediction. The training objective of the warm-up stage is almost the same as the time-aware token masking stage, adopting similar loss function but without the weighting mechanism,

(15)

\mathcal{L}_{W}=-\Sigma_{j=1}^{mn}\mathbb{I}[\tilde{S_{u}}(j)=\texttt{[M]}]\cdot logp_{\theta}(S_{u}(j)\mid\tilde{S_{u}}),

where all terms retain the same meanings as in Equation
12
.

Serving as a pretraining phase, the warm-up stage is essentially designed to establish a foundational understanding of the SID space before the more intricate task-specific time-aware token masking stage. Specifically, it equips the model with the basic capability of recovering masked tokens based on the partially observed SID sequence, analogous to the masked aotoencoding paradigm
(
28
)
. By exposing the model to a simple and uniform masking schedule, the warm-up stage guides the model parameters toward a well-conditioned initialization, in order to prevent the following time-aware token masking stage from collapse. In essence, the warm-up stage provides a stable pretrained model for the downstream finetuning phase with the task of next-item recommendation.

Once the warm-up stage establishes a stable initialization, the training advances to the time-aware token masking stage, where the uniform token masking strategy is replaced by the proposed time-aware token masking strategy. In the time-aware token masking stage, the perturbation undergoes a sharp escalation in difficulty. Specifically, the masking probability shifts from being sampled from a simple bounded uniform distribution to being dynamically determined by the fused preference of period preference and point preference. And SID of the target item is forcibly fully masked (the last
m
tokens are replaced with
[M]
), ensuring the alignment with the inference task. Additionally, in the time-aware token masking stage, a normalized temporal embedding is further incorporated into the model’s input, providing explicit temporal information and strengthening the model’s sensitivity to interaction order.

3.4.
Inference

In the inference phase, given a user
u\in U
with interaction history
H_{u}=(i_{1},\dots,i_{n})
and the corresponding SID sequence
S_{u}=\bigl((s_{1}^{(1)},\dots,i_{1}^{(m)}),\dots,(s_{n}^{(1)},\dots,s_{n}^{(m)})\bigr)
, the objective is to generate SID of the next item
i_{n+1}
that the user will interact with.

First, we append
m
special mask tokens
[M]
to the end of the SID sequence
S_{u}
, forming the masked input sequence as

(16)

\tilde{S_{u}}=\bigl((s_{1}^{(1)},\dots,s_{1}^{(m)}),\dots,(s_{n}^{(1)},\dots,s_{n}^{(m)}),(\texttt{[M]},\dots,\texttt{[M]})\bigr).

Notably, only the last
m
tokens are masked, with the other observed tokens serving as the prior conditions. The normalized temporal embedding is injected into the model’s input as it is fed into the well-trained model, the same as the time-aware token masking stage of training. The model then begins the autoregressive prediction of the masked tokens, using a constrained beam search.

Crucially, during the prediction process, we adopt a constrained decoding strategy based on a pre-constructed prefix tree (Trie) rather than an unconstrained beam search. At each prediction step
k\in(1,\dots,m)
, the model computes a conditional distribution over all possible tokens for the current position. However, the search is only allowed to follow the branches that constitute valid prefixes of the existing SIDs in the catalog. This ensures that the generated SID always corresponds to a genuine item. Finally, the complete SID with highest probability is selected, and the corresponding item is output as the predicted next item
i_{n+1}
.

4.2.
Overall Performance

The overall recommendation performance of the proposed TDPM and the baseline methods on three public real-world datasets are represented in Table
2
. Hence the following three conclusions can be derived from the performance comparison.

First, integrating SID and diffusion model is necessary and promising to unleash the potential of diffusion model for improving sequential recommendation performance.
As for the baseline methods, the generative recommenders based on SID (
i.e.,
TIGER and LC-Rec) perform better than raw ID-based methods (
i.e.,
GRU4Rec, Caser, SASRec, BERT4Rec and FMLP-Rec) on several datasets, demonstrating the effectiveness of SID for sequential recommendation. In addition, non-SID diffusion-based recommenders (
i.e.,
PreferDiff, DDSR and PreferGrow) outperform conventional methods (
i.e.,
GRU4Rec and Caser), which demonstrates the competitiveness and immense potential of diffusion model for sequential recommendation. This demonstrates that it’s necessary and promising to integrate SID and diffusion model to unleash the great potential of diffusion model for sequential recommendation.

Second, disentangling user preference into period preference and point preference enables a more fine-grained and behaviorally grounded modeling of user preference.
Prior SID-based diffusion models typically treat all interacted items with a uniform diffusion mechanism, which overlooks the co-existence phenomenon of preference consistency and interest deviations inherent in the user interaction history. By explicitly disentangling the user preference into period preference and point preference, our TDPM fundamentally addresses this limitation. The period preference encapsulates the stable user profile accumulated over time. The point preference, in contrast, sensitively captures the user transient short-term interests.
Third, the time-aware token diffusion based on preference disentanglement bridges the gap between standard diffusion and sequential recommendation.
Unlike prior diffusion-based recommenders that adopt the forward diffusion process of standard diffusion model, TDPM dynamically modulates the masking probability of each interacted item according to the weighted fusion of the period preference and the point preference. This design fundamentally reconciles the uniform forward diffusion process of standard diffusion model with the inherently non-uniform preference distribution in the user interaction history. The consistent superiority of our proposed TDPM on all three datasets underscores the effectiveness of the time-aware token diffusion based on preference disentanglement.

4.4.
Hyperparameter Sensitivity Analysis

To investigate the sensitivity of TDPM to key hyperparameters and provide practical guidance for the model tuning, we conduct systematic hyperparameter analysis on Beauty dataset. Specifically, we examine the impact of the following hyperparameters: the base masking probability
\alpha
preventing the masking probability
p_{j}
from vanishing, the scaling factor
\beta
controlling the overall contribution of the fused user preference, the initial value
\lambda_{start}
of the adaptive weight
\lambda
balancing the relative contributions of the period preference and the point preference, and the growth curvature
k
governing how
\lambda
evolves with the progression of training.

4.4.1.
Masking Probability

The masking probability
p_{j}
in the time-aware token masking stage is jointly governed by two hyperparameters: the base masking probability
\alpha
and the scaling factor
\beta
, as defined in Equation
10
. Specifically,
\alpha
provides the lower bound that prevents
p_{j}
from degenerating to zero in extreme cases, thereby ensuring a minimum level of perturbation across all interacted items. In contrast,
\beta
controls the overall contribution of period preference and point preference, effectively determining the dynamic range over which
p_{j}
can vary in response to the preference signals. To better comprehend how these two hyperparameters jointly shape the masking probability and consequently the recommendation preference, we conduct a grid search over
\alpha
and
\beta
on Beauty dataset, reporting the recommendation performance of each configuration.

As shown in Figure
6
, with both
\alpha
and
\beta
set as {0.1, 0.3, 0.5}, we notice that the best performance tends to be achieved when
\beta
is larger than
\alpha
(i.e., the lower triangle of the heatmap). This phenomenon implies that the fused preference modeling should be given a relatively higher weight and if
\beta
is much less than
\alpha
(e.g.,
\alpha=0.5
&
\beta=0.1
), the model can hardly capture the user preference. Notably, when both
\alpha
and
\beta
set to large values (e.g.,
\alpha=0.5
&
\beta=0.5
), the final masking probability
p_{j}
becomes excessively high, leading to a significant performance degradation. This decline can be attributed to the severe perturbation of historical interaction information: with too few visible tokens remaining in the masked SID sequence, the model receives extremely insufficient historical context to accurately capture the underlying user preferences.

4.4.2.
Weighted Preference Fusion

The fusion of period preference and point preference at the time-aware token masking stage is controlled by two critical hyperparameters: the initial value
\lambda_{start}
of the adaptive weight
\lambda
and the growth curvature
k
, as specified in Equation
11
. Concretely,
\lambda_{start}
determines the starting contribution ratio of period preference
p_{period}
relative to the point preference
p_{point}
at the beginning of the time-aware token masking stage, while
k
governs how rapidly this ratio evolves with the progression of training. To comprehend the sensitivity of TDPM to these two hyperparameters and identify the optimal fusion schedule, we vary
\lambda_{start}
and
k
individually on Beauty dataset, reporting the recommendation performance of each configuration.

As shown in Figure
7
, with
\lambda_{start}
and
k
set as {0.3, 0.5, 0.8} and {0.5, 1.0, 2.0} respectively, we notice that the best performance tends to be achieved when
\lambda_{start}
is set as a medium value and
k
is set as a large value (e.g.,
\lambda_{start}=0.5
&
k=2.0
). The results reveal two crucial insights. First, a moderately balanced initialization of
\lambda
(e.g.,
\lambda_{start}\approx 0.5
) allows the model to effectively learn both period preference and point preference, but this benefit materializes only when paired with a large
k
. When
k
is set to a small value (e.g.,
k=0.5
), the fusion weight shifts too rapidly at the early stage, causing that
\lambda_{start}=0.5
cannot balance the relative contributions of period preference and point preference sufficiently, leading to inferior performance. Second, a large
k
(e.g.,
k=2.0
) yields consistently superior results by maintaining the balanced fusion throughout most of the training epochs and concentrating on the transition toward period preference in the final epochs. The optimal configuration is therefore
\lambda_{start}=0.5
combined with
k=2.0
, which achieves the best overall performance on Beauty dataset.

5.
Conclusion

In this paper, we bridge the gap between the uniform forward diffusion process of standard diffusion model and the non-uniform user preference distribution in sequential recommendation by
Preference Disentanglement
and
Time-Aware Diffusion
. Specifically, we first disentangle user preference from a temporal perspective into period preference and point preference, explicitly modeling both enduring preference consistency and abrupt interest deviations. Building upon this disentangled preference modeling, we propose the time-aware token diffusion, realized as time-aware token masking that dynamically modulates the masking probability of each interacted item according to the disentangled period preference and point preference, fundamentally departing from the indiscriminate uniform diffusion adopted by prior SID-based diffusion models. Extensive experiments on three public real-world datasets demonstrate the necessity and superiority of the proposed time-aware token diffusion for SID-based diffusion models.

Appendix A
Implementation Detail

SID Generation.

This study employs the open source large language model
Qwen3-Embedding-8B

(
37
)
pretrained for embedding generation and developed by Alibaba to encode each item’s textural metadata into 4096-dimensional embedding vector, which is kept frozen in subsequent clustering. We then apply Residual Quantization K-Means algorithm over the entire set of the embedding vectors with
m=4
quantization layers, each containing
\mid\mathcal{C}^{(k)}\mid=256
clustering centroids for
k=1,\dots,m
, resulting a 4-token SID for each item. All SIDs are collected into the vocabulary and a prefix tree (Trie) is constructed to enable the constrained beam search.

Model Architecture.

Following
(
24
)
, we employ an 8-layer encoder-only transformer model with a hidden dimension of 128, rotary position embedding (RoPE) and 8 attention heads. A multi-layer perceptron with a hidden size of 3072 is used. The total number of trainable parameters is approximately
7M
.

Training Configuration.

We train our TDPM using the AdamW optimizer
(
18
)
with a learning rate of
3\times 10^{-3}
, weight decay of
1\times 10^{-3}
and a batch size of 128. Usually, the warm-up stage lasts for 30-60 epochs, during which masking probability
p
is sampled from the bounded uniform distribution
\mathcal{U}(0.0,0.5)
. For period preference modeling, we employ a simple temporal index distribution function
t(j)=j
, adopt
z-score normalization function
as
\text{Norm}(\cdot)
to center and scale the temporal indices, and
standard Sigmoid function

\sigma=\frac{1}{1+e^{-x}}
as the squashing function
\phi_{t}
. And for period preference modeling, we employ cosine similarity as
sim(\cdot,\cdot)
to measure the semantic proximity between adjacent items followed by a
Max-Min normalization function
to scale the output into [0, 1] as
\phi_{d}
. The time-aware token masking stage runs for an additional 60-90 epochs with
\alpha=0.1
,
\beta=0.3
,
\lambda_{start}=0.5
and
k=2.0
.
