1 The Model
The model is similar to the Binary Fission Model (BFM) in chapter three of the Stochastic Neutronics
Primer Volume I [1], however, we add photons as a product of induced fission events (IFEs). We will find
that tracking the population of an additional particle adds an additional layer of complexity because we are
now looking for a joint probability distribution. The model is as follows:

 • instantly after an IFE, two neutrons (no ) and two photons (γ) emerge, known as the Binary Fission
 Model,
 • neutrons emitted following an IFE travel at speed v, and naturally photons travel at speed the speed
 of light, c,
 • we ignore neutron capture, but account for photon capture,

 • the system has a source of strength S, which emits one neutron per source event (SE), traveling at
 speed v.

2 Forward Master Equation Formulation
2.1 Probability Balance and Master Equation
We are looking for the joint probability distribution:

 Pn,m (t) = the probability of there being n neutrons and m photons within the system at time t, (1)

where there are two possible initial conditions that could cause the system to have n neutrons at time t,
but there is only one initial condition that could cause there to be m photons at time t. We state that
photons can only be created by an IFE, therefore their population always starts at zero. Neutrons, on the
other hand, can be created by a source event or IFE. Thus, the system can begin with an initial number
of neutrons, i, that undergo fission to produce n neutrons and m photons. Alternatively, there could be a
neutron-producing source, in which case there are no initial neutrons.
 We find Pn,m (t) using knowledge of the possible mutually exclusive events the system could experience
over a short interval, ∆t, before some final time t. We assume ∆t is sufficiently small, such that only one
event could possibly occur in the interval. We define this interval:

                                               If = [t − ∆t, t],                                          (2)
where the subscript f indicates that this is the forward collision interval. The possible events over the
collision interval for our model are:

 • A neutron collides with the medium and is absorbed, causing an IFE, producing two neutrons and two
 photons.
 • A photon collides with the medium and is captured.
 • A source event (SE) occurs, producing one neutron.
 • No event occurs.

However, these events alone do not complete the picture. For each event we must specify that the system
previously occupied a state that will cause the event to bring the system to the interrogated state (n,m).
We use the probability of the event occurring multiplied by the probability of the system taking on the
dependent probabilistic to define the probability that the system takes one possible path. All possible paths
for our model are shown in the event tree in Figure 1. We add the probabilities of all event paths to find
the total probability of reaching the desired state (n,m). This summation is referred to as the probability
balance.

rates. Reaction rates are defined as the probability per particle per unit energy per unit time that some
event, x, will occur. The reaction rate for some event is calculated using the macroscopic cross section, Σx ,
and particle speed, v, with the following equation:

                                                       λx = v(E)Σx (E, t).                                                    (4)

4.2 Future Work
There is still much to do. We will look for a way to invert Eq. 35 to hopefully find an analytic solution to
the probability balance PDE. If that is proven to be impossible, we can utilize numerical techniques to gain
insight from our work. We will also look to derive moments of Eq. 35 to find average neutron and photon
populations. Finally, we would like to find an analytic solution for the case in which the source term, S, is
nonzero.
