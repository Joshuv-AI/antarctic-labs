Breaking chains with trees: Deep learning with 𝒪 ⁡ ( log ⁡ N ) \mathcal{O}(\log N) parallel time complexity
Neeraj Mohan Sushma, Aditya Nagarsekar, Cabrel Teguemne Fokam, Robin Schiewer, Amit Kumar Pal, Anand Subramoney, David Kappel, [3ex] Center for Cognitive Interaction Technology, Bielefeld University, Germany {neeraj.sushma, robin.schiewer, amit.pal, david.kappel}@uni-bielefeld.de, [1ex] Ruhr Universität Bochum, Germany, [1ex] Birla Institute of Technology, Science, Pilani, Goa Campus, [1ex] Royal Holloway, University of London, UK anand.subramoney@rhul.ac.uk

Abstract
Modern deep neural network architectures are trained via backpropagation, which requires errors to be sequentially propagated through all layers before parameters can be updated. This introduces two limitations: locking, where layer-wise updates are strictly interdependent and cannot proceed in parallel, and the weight transport problem, which requires symmetric forward and backward pathways for exact gradient computation. These constraints restrict parallelism, increase memory and communication overhead, and pose challenges for scalable learning. In this work, we propose Hierarchical Block-Local Learning (HBLL), a framework that decomposes deep neural networks into hierarchically linked blocks trained using local learning objectives derived from variational principles, eliminating the need for full end-to-end backpropagation while maintaining effective information propagation across the network. HBLL is the first algorithm that is able to train deep neural networks in 𝒪 ⁡ ( log ⁡ N ) \mathcal{O}(\log N) parallel time complexity, where N N is the number of network layers. We show that HBLL implicitly defines a family of subnetworks corresponding to different hierarchical paths, enabling flexible inference with different effective numbers of layers. We evaluate HBLL on a set of challenging vision and language modeling tasks, achieving competitive performance. We also extend HBLL to recurrent sequence architectures, applying to settings that otherwise rely on backpropagation through time.

Introduction

Error Backpropagation
(
Rumelhart et al. 1986
)
, has emerged as the de facto standard method for training deep neural networks. This method computes gradients by propagating activations sequentially through all layers of a deep neural network, computing the loss at the output and propagating the gradients sequentially backward through the network. Backpropagation has demonstrated unprecedented scaling properties enabling deep neural networks with trillions of parameters and close to human-level performance on complex tasks including natural language modeling. However, these gains come at increasing computational and energy costs, driven not just by the model size but also by the training paradigm itself.

One major disadvantage of Backpropagation stems from the sequential error propagation scheme. Updates are locked until a full forward-backward pass across all layers of the network was performed. This locking problem limits the parallelization properties in learning and leads to reduced hardware utilization
(
Jaderberg et al. 2017
)
.
The limitations of backpropagation have motivated the search for alternative learning methods that relax or remove the need for global error propagation. In particular, local learning approaches aim to train different parts of networks using locally defined rules, reducing inter-layer dependencies and improving scalability. However, while such approaches have shown promise in vision and smaller-scale settings, their ability to scale to large network sizes remains limited.

In this work, we propose Hierarchical Block-local learning (HBLL), a framework that enables scalable gradient estimation in deep neural networks without full end-to-end backpropagation.
HBLL decomposes networks into hierarchically organized blocks trained using local objectives derived from a variational formulation, providing a general and theoretically grounded framework for local learning.
By enabling communication between levels of the hierarchy through invertible transformations, HBLL allows information to propagate across the network while avoiding global gradient dependencies.
We provide a principled probabilistic interpretation of learning without global backpropagation, that enables distributed training.
Our results demonstrate that HBLL scales to vision classification and autoregressive language modeling, achieving competitive performance on CIFAR-10, CIFAR-100
(
Krizhevsky 2009
)
and WikiText-103
(
Merity et al. 2017
)
.
We also apply HBLL to recurrent neural networks (RNNs), formulating a hierarchical local-learning approach for training sequential models.

The main advantage of our hierarchical network learning approach is that it can be efficiently parallelized. The parallel compute complexity allows us to reason about the compute efficiency of algorithms that run on multiple parallel resources. The parallel compute complexity
T_{\infty}
denotes the optimal level of parallelization an algorithm can achieve on an optimal number of parallel compute nodes (c.f.
Cormen et al. 2022
, p.779f). The compute complexity of conventional error backpropagation is
\mathcal{O}(N)
, since it propagates information forward and backward through the network. We present here the first
T_{\infty}=\mathcal{O}(\log N)
parallel algorithm.

The contributions of this paper are summarized as follows:

•

We propose a Hierarchical Block-Local Learning (HBLL), a framework for training deep neural networks without full end-to-end backpropagation by decomposing the network into hierarchically organized blocks optimized using local objectives.

•

We introduce a probabilistic learning framework, derived from a variational formulation, that enables learning without global gradient propagation while supporting distributed and parallel training with
\mathcal{O}(\log N)
parallel compute complexity.

•

We demonstrate that HBLL achieves competitive performance on tasks including vision classification and autoregressive language modeling, on benchmarks such as CIFAR-10, CIFAR-100 and WikiText-103.

•

We show that HBLL implicitly defines a family of subnetworks corresponding to different hierarchical paths, enabling flexible inference under varying computational constraints.

•

We formulate HBLL-RNN, a recurrent variant of HBLL that trains a
sequential model using hierarchical local learning.

2
Related Work

A large number of training algorithms based on local learning in deep neural networks (DNNs) have been proposed in the literature.
Early approaches relied on fixed random feedback weights
(
Lillicrap et al. 2014
;
Nøkland 2016
)
to propagate the model error to individual layers. Subsequent work introduced learnable feedback weights
(
Kolen and Pollack 1994
;
Akrout et al. 2019
)
, which improved performance over fixed random projections. Another line of research, known as target propagation
(
Lee et al. 2015
;
Meulemans et al. 2020
)
, replaces error signals with targets propagated through the network
(
Frenkel et al. 2021
;
Ernoult et al. 2022
;
Shibuya et al. 2023
)
.
While our method also employs learnable feedback weights, it differs in that it derives a principled hierarchical feedback structure to update weights and scales naturally to language modeling.

Another family of methods adopts contrastive learning objectives
(
Chen et al. 2020
;
Oord et al. 2019
)
, where models are trained using positive and negative examples, from which local learning rules at the layer or block level can be derived
(
Xiong et al. 2020
;
Illing et al. 2021
)
. The forward-forward algorithm
(
Hinton 2022
;
Zhao et al. 2023
)
is a prominent example, in which inputs paired with correct or incorrect labels are propagated through the network. Extensions include adding a prediction head at the output layer and using inter-class samples as alternatives
(
Aghagolzadeh and Ezoji 2025
)
, show that Forward-Forward-style training can be scaled successfully to Vision Transformers
(
Dosovitskiy et al. 2021
)
. Forward-pass-only methods such as layer-wise zero-order gradient approximations estimate parameter updates through parameter perturbations
(
Malladi et al. 2023
)
rather than backpropagated gradients.
In contrast, our work does not rely on contrastive objectives or zeroth-order gradient estimates but instead focuses on probabilistic block-wise local learning.

A number of approaches target block-wise or layer-wise optimization directly
(
Ye et al. 2026
)
. Decoupled neural interfaces
(
Jaderberg et al. 2017
)
use auxiliary “utility networks” to approximate backward gradients, thereby decoupling layer training. More recently,
Ma et al. 2024
propose using parts of subsequent layers as auxiliary networks, introducing complex dependencies across blocks during backpropagation. In our case, auxiliary networks are independent, except for a shared prediction head across blocks.

Kappel et al. 2023
derive local losses from a probabilistic interpretation of DNN training, but do not scale to ImageNet. We also adopt a probabilistic formulation for local losses
(
Salvatori et al. 2025
)
; however, our learning is hierarchical, and auxiliary networks are not all directly connected to the output layer. Finally,
Nøkland and Eidnes 2019
combine a matching loss with a local cross-entropy loss but do not scale to ResNet architectures.
To the best of our knowledge, these approaches have not been evaluated across both attention-based vision architectures, such as Vision Transformers, and natural language processing tasks.

3
Hierarchical Block-Local Learning

3.1
Neural nets, chains and trees

Deep neural networks (DNNs) are universal function approximators that map an input
\mathbf{x}
to an output
\mathbf{y}=f(\mathbf{x})
, via a transfer function
f:\mathbf{x}\rightarrow\mathbf{y}
,
(\mathbf{x},\mathbf{y})\in\mathcal{D}_{\mathbf{x}}\times\mathcal{D}_{\mathbf{y}}
, where
\mathcal{D}_{\mathbf{x}}
,
\mathcal{D}_{\mathbf{y}}
are some (possibly high-dimensional) domains. Typically
f
is constructed by chaining together a sequence of
N
nested operations,
(f_{1}\circ f_{2}\circ\dots\circ f_{N})(\mathbf{x})=f(\mathbf{x})=\mathbf{y}
, where
\mathbf{a}_{n}=f_{n}(\mathbf{a}_{n-1})
are the transfer functions with activations
\mathbf{a}_{n}
.
N
can denote the number of layers in the network. However, in many modern neural network architectures it is natural to think of this chain of operations in terms of more complex functional blocks, such as transformer blocks that consist themselves of multiple layers, and the theoretical framework we present here is agnostic to the level of granularity that is chosen.

It can be insightful to adopt a probabilistic interpretation of the chain of operations performed by a DNN. To make this explicit we use the reparameterization trick
(
Kingma and Welling 2013
)
to introduce latent variables
\mathbf{z}_{n}=\mathbf{a}_{n}+\boldsymbol{\varepsilon}_{n}
, where
\boldsymbol{\varepsilon}_{n}
is block-wise independent noise with small amplitude. Using this, we can interpret the sequence of transformations to define a Markov chain over latent representations.
Let
\{\mathbf{z}_{1},\dots,\mathbf{z}_{N-1}\}
be the latent representations across the blocks, then the DNN can be defined as a directed graphical model of the form (see Fig.
1
A for an illustration):

\mathbf{x}\rightarrow\mathbf{z}_{1}\rightarrow\mathbf{z}_{2}\rightarrow\cdots\rightarrow\mathbf{z}_{N-1}\rightarrow\mathbf{y}.

(1)

Thus, we model the network as an inhomogeneous first-order Markov chain:

p(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N-1},\mathbf{z}_{N}\mid\mathbf{x})=\prod_{n=1}^{N}p(\mathbf{z}_{n}\mid\mathbf{z}_{n-1}),\quad\text{with }\mathbf{z}_{0}=\mathbf{x},\mathbf{z}_{N}=\mathbf{y}.

(2)

This induces the joint distribution:

p(\mathbf{x},\mathbf{z}_{1},\dots,\mathbf{z}_{N-1},\mathbf{y})=p(\mathbf{x})\,p(\mathbf{y}\mid\mathbf{z}_{N-1})\prod_{n=1}^{N-1}p(\mathbf{z}_{n}\mid\mathbf{z}_{n-1})\;.

(3)

A single pass through the network corresponds to inference along this joint distribution, which can be computed by traversing the chain once, resulting in
\mathcal{O}(N)
time complexity. Due to the sequential nature, this computation cannot be parallelized, i.e. the longest (and only) computational path traverses the entire chain.

However, we show here that shortcuts can be included in this probabilistic model to speed-up its evaluation. The training objective to maximize the fit of this probabilistic model with respect to the transfer functions
f_{n}
(or their respective set of parameters) entails evaluating the posterior distribution

p(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N-1}\mid\mathbf{x},\mathbf{y})=\frac{p(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N-1},\mathbf{y}\mid\mathbf{x})}{p(\mathbf{y}\mid\mathbf{x})}.

(4)

To overcome the limitation to
\mathcal{O}(N)
time complexity, we construct an alternate model
q
that allows us to efficiently evaluate this posterior.
We construct this factorization in a divide-and-conquer manner by introducing intermediate variables at multiple levels of hierarchies.
At the first levely, introducing
\mathbf{z}_{N/2}
decomposes the chain into segments
(\mathbf{x}\rightarrow\mathbf{z}_{N/2})
and
(\mathbf{z}_{N/2}\rightarrow\mathbf{y})
, and applying the same construction to each segment (e.g., introducing
\mathbf{z}_{N/4}
and
\mathbf{z}_{3N/4}
) progressively breaks the chain into smaller subproblems, yielding a hierarchical tree-structured decomposition of the true posterior.

\displaystyle q(\mathbf{z}_{1},\dots,\mathbf{z}_{N-1}\mid\mathbf{x},\mathbf{y})

\displaystyle=q(\mathbf{z}_{N/2}\mid\mathbf{x},\mathbf{y})\,

(5)

\displaystyle\times q(\mathbf{z}_{N/4}\mid\mathbf{x},\mathbf{z}_{N/2})\,q(\mathbf{z}_{3N/4}\mid\mathbf{z}_{N/2},\mathbf{y})\,

\displaystyle\cdots

\displaystyle\times q(\mathbf{z}_{1}\mid\mathbf{x},\mathbf{z}_{2})\,q(\mathbf{z}_{3}\mid\mathbf{z}_{2},\mathbf{z}_{4})\,\cdots\,q(\mathbf{z}_{N-1}\mid\mathbf{z}_{N-2},\mathbf{y})

\displaystyle=\prod_{n=1}^{N-1}q(\mathbf{z}_{n}\mid pa(n))\;,

where
pa(n)
denotes the parent blocks of
\mathbf{z}_{n}
in the induced hierarchical structure shown in Fig.
1
.

The hierarchical factorization in Eq. (
5
) can be formalized as the following theorem:

Theorem 1
.

Let
\mathbf{x},\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N-1},\mathbf{y}
be random variables whose joint distribution factorizes as a first-order Markov chain:

p(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N-1},\mathbf{y}\mid\mathbf{x})=\prod_{n=1}^{N-1}p(\mathbf{z}_{n}\mid\mathbf{z}_{n-1})\,p(y\mid\mathbf{z}_{N-1}),\quad\text{with }\mathbf{z}_{0}=\mathbf{x}.

(6)

Then there exists a mapping
d:\{1,\dots,N-1\}\to\mathbb{N}_{0}
such that the posterior distribution over intermediate representations admits the factorization

p(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N-1}\mid\mathbf{x},\mathbf{y})=\prod_{n=1}^{N-1}p\!\left(\mathbf{z}_{n}\mid\mathbf{z}_{n-2^{d(n)}},\,\mathbf{z}_{n+2^{d(n)}}\right),

(7)

where the boundary variables are identified with
\mathbf{z}_{0}=\mathbf{x}
and
\mathbf{z}_{N}=\mathbf{y}
, and each conditional is defined with respect to the corresponding valid parent variables in the induced hierarchical structure.

This result shows that the posterior over intermediate representations admits an equivalent tree-structured decomposition, which reduces the computational path through the network from
\mathcal{O}(N)
to
\mathcal{O}(\log N)
.

Variational local learning framework using tree-structured factorization

We now derive the local learning objective induced by the variational distribution
q
defined in Eq. (
5
).
Training a deep neural network can be interpreted as maximizing the likelihood of observed data
(\mathbf{x},\mathbf{y})
.
For example, minimizing the cross-entropy loss corresponds to the negative log-likelihood of a categorical distribution parameterized by a softmax, while the mean squared error corresponds to the log-likelihood of a Gaussian with fixed variance.

To incorporate intermediate block-local representations
\mathbf{z}_{n}
, we adopt a variational formulation.
In particular, we consider the log-likelihood loss:

\mathcal{L}=-\log p(\mathbf{y}\mid\mathbf{x}).

(8)

Introducing a variational distribution
q(\mathbf{z}_{1},\dots,\mathbf{z}_{N-1}\mid\mathbf{x},\mathbf{y})
, we define the auxiliary loss:

\displaystyle\mathcal{F}

\displaystyle=-\log p(\mathbf{y}\mid\mathbf{x})+\mathrm{KL}\big(q(\mathbf{z}_{1:N-1}\mid\mathbf{x},\mathbf{y})\,\|\,p(\mathbf{z}_{1:N-1}\mid\mathbf{x},\mathbf{y})\big)

(9)

\displaystyle=\mathbb{E}_{q}\left[\log\frac{q(\mathbf{z}_{1},\dots,\mathbf{z}_{N-1}\mid\mathbf{x},\mathbf{y})}{p(\mathbf{z}_{1},\dots,\mathbf{z}_{N-1},\mathbf{y}\mid\mathbf{x})}\right],

where the expectation is taken with respect to the variational posterior in Eq. (
5
).

Substituting the Markov factorization (Eq. (
2
)) and the hierarchical factorization of
q
, we obtain:

\displaystyle\mathcal{F}

\displaystyle=\mathbb{E}_{q}\left[\sum_{n=1}^{N-1}\log\frac{q(\mathbf{z}_{n}\mid pa(n))}{p(\mathbf{z}_{n}\mid\mathbf{z}_{n-1})}\;-\;\log p(\mathbf{y}\mid\mathbf{z}_{N})\right].

(10)

This formulation replaces global backpropagation with a collection of local objectives defined over the hierarchical structure. Since the expectation is taken with respect to
q
can be evaluated in
\mathcal{O}(\log N)
parallel steps.

This objective decomposes into local terms associated with each block, where each block learns to align its variational conditional distribution
q(\mathbf{z}_{n}\mid pa(n))
with the corresponding forward model
p(\mathbf{z}_{n}\mid\mathbf{z}_{n-1})
.
In practice, the expectation in Eq. (
10
) is approximated using Monte Carlo sampling. Specifically, we draw
M
(throughout all experiments we used
M=1
though) samples
\mathbf{z}^{(m)}\sim q(\mathbf{z}\mid\mathbf{x},\mathbf{y})
and approximate:

\mathcal{F}\approx\frac{1}{M}\sum_{m=1}^{M}\left[\sum_{n=1}^{N-1}\log\frac{q(\mathbf{z}_{n}^{(m)}\mid pa(n))}{p(\mathbf{z}_{n}^{(m)}\mid\mathbf{z}_{n-1}^{(m)})}-\log p(\mathbf{y}\mid\mathbf{z}_{N}^{(m)})\right].

(11)

To obtain tractable learning rules, we assume that the conditional distributions
p(\mathbf{z}_{n}\mid\mathbf{z}_{n-1})
and
q(\mathbf{z}_{n}\mid pa(n))
belong to the exponential family.
Under this assumption, the KL divergence between the forward and variational distributions can be expressed in terms of their moments, enabling efficient computation of local learning signals.
In particular, each block parameterizes the natural parameters of the corresponding exponential family distribution, allowing gradients to be computed using local statistics such as means and variances.
A detailed derivation of the sampling approximation and the resulting learning rules is provided in the Appendix.

Experiments

We evaluate HBLL across supervised classification, autoregressive language
modeling, and recurrent sequence modeling tasks.
We first study MNIST
(
Lecun et al. 1998
)
using multilayer perceptrons to test whether HBLL can train deeper feedforward networks with local objectives.
We then evaluate Vision Transformer-style architectures
(
Dosovitskiy et al. 2021
)
on CIFAR-10 and CIFAR-100
(
Krizhevsky 2009
)
to assess whether HBLL remains effective on attention-based vision models under increasing task complexity.
Next, we evaluate HBLL on WikiText-103
(
Merity et al. 2017
)
to study its applicability to autoregressive language modeling.
Finally, we extend HBLL to recurrent neural networks(RNNs) and evaluate the resulting HBLL-RNN models on sequential MNIST and permuted-sequential MNIST.
Across these experiments, we compare HBLL primarily against standard
end-to-end backpropagation (BP) using matched architectures and training
settings. Where applicable, we also report contrastive Forward-Forward
local-learning results from prior work as an additional reference point

(
Aghagolzadeh and Ezoji 2025
)
.

4.1
MNIST Classification

4.1.1
Experimental Setup

We first evaluate HBLL on MNIST
(
Lecun et al. 1998
)
, a standard handwritten digit classification benchmark consisting of grayscale images from 10 classes.
We use this standard dataset to compare HBLL with standard end-to-end backpropagation (BP) and Contrastive Forward-Forward
(
Aghagolzadeh and Ezoji 2025
)
(CFF+M) across increasing model depths.

We use a simple multilayer perceptron (MLP) with sigmoid activations and no
residual connections or normalization layers. For HBLL, the model depth
determines the hierarchy used for local learning, while the corresponding BP and CFF+M baselines are chosen to have an equivalent number of layers. We evaluate hierarchy depths 2, 3, and 4, corresponding to models with 4, 8, and 16 layers, respectively. We additionally vary the hidden dimensionality across 50, 100, and 500 hidden units. Training details, including learning rates, batch sizes, and optimization settings, are provided in Appendix
6.5.1
.

4.5
Recurrent Sequence Modeling

Although the main experiments in this work focus on feedforward and Transformer-style architectures, the HBLL formulation can also be adapted to recurrent sequence modeling.
This is natural because recurrent architectures define Markovian transitions over hidden states, which align with the conditional factorization in Theorem
1
.
In this setting, the hierarchy is interpreted over time indices, and each node summarizes a block of past inputs.
However, the recurrent cell deployed at inference must be causal: the lowest-depth cell consumes only the previous hidden state and the current input, yielding a standard autoregressive recurrence. To ensure this, we obtain a causal variant through a single change to how the inter-node message is formed. A node at depth
d(n)
folds its left input block, the
2^{d(n)}
symbols
\mathbf{x}_{n-2^{d(n)}},\dots,\mathbf{x}_{n-1}
, a span that doubles with depth, into a state passed to its children,

\mathbf{h}_{n}=f_{d(n)}\big(\mathbf{h}_{n-2^{d(n)}},\mathbf{x}_{n-2^{d(n)}:n-1}\big)

(12)

propagated from the left parent only. The future (right) parent enters solely as a training target for local learning. Each depth
d
therefore has its own cell
f_{d}
sharing a single hidden width
H
, and cells higher in the tree have larger input sizes in proportion to the longer input spans (
2^{d}
symbols) they summarise. This construction is causal with full coverage: every node’s receptive field is exactly the prefix
\mathbf{x}_{0},\dots,\mathbf{x}_{n}
, it depends on all past inputs and no future ones, and every depth sees the full input, which is necessary for the per depth RNNs to train.
Thus, the tree provides a parallel training structure, while inference follows the usual causal recurrent rollout of the single shared depth-0 cell
f_{0}
.

Inside the tree the finest chain is teacher-forced (each node reads the clean predecessor from its left parent), but at inference the cell consumes its own output,
\mathbf{h}_{t}=f_{0}(\mathbf{h}_{t-1},\mathbf{x}_{t})
, so errors compound over the
N
steps. The deployed states are then drawn from a self-generated distribution unlike the clean training one, an exposure-bias mismatch that leaves the tree readouts accurate while the rolled chain degrades with length, collapsing at the largest depths.
To address the mismatch between tree-based training and autoregressive rollout at inference, we experimented with a parallel consistency stage that exposes the recurrent cell to self-generated predecessor states without requiring a full sequential rollout.
The tree pass first produces a clean target state
\bar{\mathbf{h}}_{t}
for each position
t
, which is detached from the computational graph. We initialize the consistency states using these tree-generated targets:

\displaystyle\tilde{\mathbf{h}}^{(0)}_{t}

\displaystyle=\bar{\mathbf{h}}_{t}.

(13)

For each consistency sweep
i=1,\ldots,K
, every position is recomputed using the previous position’s state from the preceding sweep:

\displaystyle\tilde{\mathbf{h}}^{(i)}_{t}

\displaystyle=f_{0}\!\left(\tilde{\mathbf{h}}^{(i-1)}_{t-1},\mathbf{x}_{t}\right),\qquad i=1,\ldots,K.

(14)

Equivalently, this corresponds to applying the deployed recurrent transition

p_{\theta}(\mathbf{h}_{t}\mid\mathbf{h}_{t-1},\mathbf{x}_{t})

using predecessor states generated by the model itself in the previous sweep.
Importantly, within a fixed sweep
i
, all states
\tilde{\mathbf{h}}^{(i-1)}_{t-1}
are treated as fixed values from the previous sweep. Therefore, the updates over all positions
t
are conditionally independent and can be computed in parallel.
After
K
sweeps, we match the corrected states to the clean tree targets using the consistency objective

\displaystyle\mathcal{L}_{\mathrm{cons}}

\displaystyle=\sum_{t}\left\|\tilde{\mathbf{h}}^{(K)}_{t}-\bar{\mathbf{h}}_{t}\right\|_{2}^{2}.

(15)

This trains the deployed recurrent cell
f_{0}
on states closer to the
self-generated distribution encountered during autoregressive inference, while avoiding a full sequential rollout during training.
As a result, the recurrent cell is encouraged to remain stable under the state distribution encountered during deployment. The
logN
span is preserved for
K\leq logN
, which is true in practice as
N
grows.

4.5.1
Experimental Setup

We evaluate the recurrent variant on sequential MNIST and permuted-sequential MNIST. In both, each image is flattened to its 784 pixels; permuted-sequential MNIST additionally reorders those 784 pixels by a single fixed random permutation (the same permutation for every image, shared across train and test). This destroys spatial locality, so the model can no longer rely on neighbouring-pixel structure and must integrate information across the whole sequence. At tree depth
D
the input is split into
N=2^{D}
steps, each consuming
\lceil 784/2^{D}\rceil
consecutive (permuted) pixels; the pixels are start-padded with leading zeros to
N\lceil 784/2^{D}\rceil
so the split is even and the deployed chain ends on real pixels. In every case the deployed model is the single depth-0 base cell unrolled over this full sequence, which we compare against a backpropagation-through-time (BPTT) recurrent baseline of identical cell type, hidden width, and parameter count. We test two cells, a GRU
(
Cho et al. 2014

and a gateless Elman-style RNN cell (a single linear layer with sigmoid activation)
(
Elman 1990

5
Discussion

Our results demonstrate that hierarchical block-local learning can scale to vision classification tasks and autoregressive language modeling.
We first show that HBLL remains effective on MNIST classification with simple feedforward MLPs across increasing depths.
On CIFAR-10, HBLL achieves competitive accuracy with Vision Transformer-style architectures and produces useful shorter hierarchical paths.
On CIFAR-100, HBLL further remains competitive under a larger label space, matching or slightly improving over the corresponding backpropagation baseline in top-5 accuracy.
In addition, the CIFAR-10 corruption experiments show that HBLL improves robustness under missing-data and label-noise settings, suggesting that the hierarchical block-local objective can provide useful regularization when inputs or supervision are degraded.
On WikiText-103, while there is a slight performance gap compared to end-to-end backpropagation, HBLL provides a viable approach to language modeling without relying on full end-to-end backpropagation.
We further show that the same hierarchical local-learning principle can be
extended to recurrent neural networks, where HBLL-RNN remains competitive with BPTT on sequential and permuted-sequential MNIST while using a causal recurrent cell at inference.
By removing the requirement for full backpropagation across the entire network, HBLL addresses the locking problem and reduces inter-layer dependencies during training.
This enables parallel and distributed training across blocks.
The local learning objectives in HBLL are derived from a variational formulation, providing a principled probabilistic foundation for training without global backpropagation.
HBLL also implicitly defines a family of subnetworks corresponding to different hierarchical paths, enabling flexible inference with varying computational budgets.
Another interesting direction is to investigate whether the subnetworks induced by different hierarchical paths can support efficient inference schemes such as speculative decoding, where shallower paths could serve as draft models and deeper paths as verification models.
Despite the promising results, a gap remains between HBLL and fully backpropagated models, particularly at larger depths.
Future work includes improving the efficiency of local objectives, exploring richer invertible transformations (e.g., flow-based couplings) etc.

\mathbf{z}_{n}

\mathbf{z}_{0}=\mathbf{x}

{p}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{0}\right)\;=\;\prod_{n=1}^{N}{p}\left(\mathbf{z}_{n}\,\middle|\,\mathbf{z}_{n-1}\right)\;.

(16)

\mathcal{N}_{1}:\quad{q_{1}}\left(\mathbf{z}_{1}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{2}\right)\;=\;\frac{{p}\left(\mathbf{z}_{1}\,\middle|\,\mathbf{z}_{0}\right){p}\left(\mathbf{z}_{2}\,\middle|\,\mathbf{z}_{1}\right)}{{p}\left(\mathbf{z}_{2}\,\middle|\,\mathbf{z}_{0}\right)}\;.

(19)

Clearly here, the chain and tree factorization coincide.
The next larger model
\mathcal{N}_{2}
, with 5 nodes can be constructed recursively

\mathcal{N}_{2}:\quad{q_{2}}\left(\mathbf{z}_{1},\mathbf{z}_{2},\mathbf{z}_{3}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{4}\right)\;=\;{q_{1}}\left(\mathbf{z}_{2}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{4}\right){q_{1}}\left(\mathbf{z}_{1}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{2}\right){q_{1}}\left(\mathbf{z}_{3}\,\middle|\,\mathbf{z}_{2},\mathbf{z}_{4}\right)\;,

(20)

and
\mathcal{N}_{3}
, with 9 nodes

\displaystyle\mathcal{N}_{3}:\quad{q_{2}}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{7}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{8}\right)\;=

\displaystyle{\displaystyle q_{1}}\left(\mathbf{z}_{4}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{8}\right)\times

(21)

\displaystyle{\displaystyle q_{2}}\left(\mathbf{z}_{1},\mathbf{z}_{2},\mathbf{z}_{3}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{4}\right){q_{2}}\left(\mathbf{z}_{5},\mathbf{z}_{6},\mathbf{z}_{7}\,\middle|\,\mathbf{z}_{4},\mathbf{z}_{8}\right)\;,

and in general
\mathcal{N}_{d}
,
d>3
, with
N=2^{d}+1
nodes, the inductive step
d-1\rightarrow d
gives

\displaystyle\mathcal{N}_{d}:\quad{q_{d}}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N-1}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{N}\right)\;=

\displaystyle{\displaystyle q_{1}}\left(\mathbf{z}_{\lfloor N/2\rfloor}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{N}\right)\times

(22)

\displaystyle{\displaystyle q_{d-1}}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{\lfloor N/2\rfloor-1}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{\lfloor N/2\rfloor}\right)\times

\displaystyle{\displaystyle q_{d-1}}\left(\mathbf{z}_{\lfloor N/2\rfloor+1},\dots,\mathbf{z}_{N-1}\,\middle|\,\mathbf{z}_{\lfloor N/2\rfloor},\mathbf{z}_{N}\right)\;.

Using this result, it is straightforward to prove the identity (
5
).

\displaystyle\quad{q_{d}}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N-1}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{N}\right)\;=

\displaystyle\frac{{p}\left(\mathbf{z}_{\lfloor N/2\rfloor}\,\middle|\,\mathbf{z}_{0}\right){p}\left(\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{\lfloor N/2\rfloor}\right)}{{p}\left(\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{0}\right)}\times

\displaystyle\frac{{p}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{\lfloor N/2\rfloor}\,\middle|\,\mathbf{z}_{0}\right)}{{p}\left(\mathbf{z}_{\lfloor N/2\rfloor}\,\middle|\,\mathbf{z}_{0}\right)}\times

\displaystyle\frac{{p}\left(\mathbf{z}_{\lfloor N/2\rfloor+1},\dots,\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{\lfloor N/2\rfloor}\right)}{{p}\left(\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{\lfloor N/2\rfloor}\right)}\;=\;

\displaystyle\frac{{p}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{\lfloor N/2\rfloor}\,\middle|\,\mathbf{z}_{0}\right)\,{p}\left(\mathbf{z}_{\lfloor N/2\rfloor+1},\dots,\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{\lfloor N/2\rfloor}\right)}{{p}\left(\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{0}\right)}\;=\;

\displaystyle\frac{{p}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{0}\right)}{{p}\left(\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{0}\right)}\;=\;{p}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N-1}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{N}\right)\;.

6.2
Variational learning framework

Many commonly used loss functions in deep learning have a probabilistic interpretation, e.g., the cross entropy loss of a binary classifier is identical to the Bernoulli log-likelihood, and the mean squared error corresponds to the log-likelihood of a Gaussian with constant variance. In this formulation, the outputs of the DNN are interpreted as the statistical parameters to a conditional probability distribution (e.g., the mean of a Gaussian) and the loss function measures the support of observed data samples
\mathbf{x}
and
\mathbf{y}
.

To introduce intermediate block-local representations
\mathbf{z}_{n}
in the network, we consider the ELBO loss
\mathcal{F}
, i.e. a variational upper bound to the log-likelihood loss
\mathcal{L}=-\log{p}\left(\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{0}\right)

\displaystyle\mathcal{F}

\displaystyle=\;-\log{p}\left(\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{0}\right)+{\mathcal{D}_{KL}}\left(q\,\middle|\,p\right)

(23)

\displaystyle=\;\mathbb{E}_{q}\left[\log\frac{{q}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N-1}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{N}\right)}{{p}\left(\mathbf{z}_{1},\mathbf{z}_{2},\dots,\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{0}\right)}\right]\quad\geq\;\mathcal{L}\;,

where the expectation is with respect to the variational posterior (
5
). By inserting Eqns. (
4
) and (
5
) we get

\displaystyle\mathcal{F}

\displaystyle=\;\mathbb{E}_{q}\left[\sum_{n=1}^{N-1}\log\frac{{q}\left(\mathbf{z}_{n}\,\middle|\,pa(n)\right)}{{p}\left(\mathbf{z}_{n}\,\middle|\,\mathbf{z}_{n-1}\right)}-\log{p}\left(\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{N-1}\right)\right].

(24)

6.3
Exponential family distributions

To derive concrete losses and update rules for HBLL, we consider the exponential family (EF) of probability distributions, given by

\displaystyle{\alpha_{n}}\left(\mathbf{z}_{n}\right)

\displaystyle\;=\;\prod_{i}{\alpha_{ni}}\left(z_{ni}\right)\;=\;\prod_{i}h(z_{ni})\,{\exp}\left({T}\left(h_{ni}\right)\phi_{ni}-{A}\left(\phi_{ni}\right)\right)\;,

(25)

with base measure
h
, sufficient statistics
T
, log-partition function
A
, and natural parameters
{\phi_{kj}}
.
This rich class contains the most common distributions, such as Gaussian, Poisson or Binomial, as special cases.
One interesting property of the EF is that the Kullback-Leibler (KL-) divergence, to measure the distance between two distributions
\rho_{k}
and
\alpha_{k}
, with parameters
\boldsymbol{\gamma}_{k}
and
\boldsymbol{\phi}_{k}
, can be expressed using only the means
\mu
and variances
\sigma^{2}
of the distributions, i.e.

\displaystyle-\nabla{\mathcal{D}_{KL}}\left(\rho_{n}\,\middle|\,\alpha_{n}\right)\;=\;\sum_{i}

\displaystyle\left({\mu}\left(\rho_{ni}\right)-{\mu}\left(\alpha_{ni}\right)\right)\nabla\phi_{ni}\;+\;{\sigma^{2}}\left(\rho_{ni}\right)\left(\phi_{ni}-\gamma_{ni}\right)\nabla\gamma_{ni}\;.

(26)

Furthermore, if we consider two EF distributions with natural parameters
\boldsymbol{\phi}_{1}
and
\boldsymbol{\phi}_{2}
, the posterior distribution will also be an EF distribution with natural parameters
\boldsymbol{\phi}_{3}=\boldsymbol{\phi}_{1}+\boldsymbol{\phi}_{2}
.

We will exploit these property to construct local learning rules that can be computed efficiently.
A network directly implements an EF distribution if the activations
a_{ni}
at block
n
encode the natural parameters,
a_{ni}=\phi_{ni}
.

We approximate the expecation in Eq.
10
by a finite set of
M
samples
S=\{\mathbf{x}^{(m)}\}
,
\mathbf{x}^{(m)}\sim{q}\left(\mathbf{x}^{(m)}\,\middle|\,\mathbf{z}_{0},\mathbf{z}_{N}\right)
,
1\leq m\leq M
.

\displaystyle\mathcal{F}

\displaystyle\approx\;\sum_{m=1}^{M}\sum_{n=1}^{N-1}{\mathcal{D}_{KL}}\left(\rho_{n}^{(m)}\,\middle|\,\alpha_{n}^{(m)}\right)-\mathbb{E}_{q_{N}}\left[\log{p}\left(\mathbf{z}_{N}\,\middle|\,\mathbf{z}_{N-1}^{(m)}\right)\right]\;.

(27)

For the example of a Binomial random variable we have
x_{ni}\in\{0,1,\dots c\}
,
h(x)=\binom{c}{x}
,
{T}\left(x\right)=x
and
{A}\left(\phi\right)=c\,\log\left(1+e^{\phi}\right)

[
Koller and Friedman 2009
]
.

For the Binomial distribution we have
{\mu}\left(\rho\right)=c\,\rho
and
{\sigma^{2}}\left(\rho\right)=c\,\rho\,\left(1-\rho\right)
.

Bernoulli KL loss

\displaystyle{\mathcal{D}_{KL}}\left(\rho_{n}\,\middle|\,\alpha_{n}\right)\;=\;\sum_{i}\ln\frac{1-\rho_{ni}}{1-\alpha_{ni}}\;+\;\rho_{ni}\cdot\ln\frac{\rho_{ni}\,(1-\alpha_{ni})}{\alpha_{ni}\,(1-\rho_{ni})}\;.

(28)

6.4
Linear Gaussians with known variance

In the vision and language modeling experiments we consider case of the linear Guassian random varialbes with known scalar variance
\sigma^{2}
. Thus, in our HBLL framework, the latent random variables are distributed according to a Normal distribution
\mathbf{z}_{n}\sim{p}\left(\mathbf{z}_{n}\,\middle|\,\mathbf{z}_{n-1}\right)=\mathcal{N}(\mathbf{z}_{n}\mid\boldsymbol{\mu}_{\mathbf{z}_{n}\mid\mathbf{z}_{n-1}},\sigma^{2}\mathbf{I})
, where
\boldsymbol{\mu}_{n}=\mathbf{a}_{n}
is the mean directly governed by the block activations. For this convenient choice we can compute the posterior distribution
{p}\left(\mathbf{z}_{n}\,\middle|\,\mathbf{z}_{n-1},\mathbf{z}_{n+1}\right)
, as

\displaystyle\mathbf{z}_{n}\sim{p}\left(\mathbf{z}_{n}\,\middle|\,\mathbf{z}_{n-1},\mathbf{z}_{n+1}\right)\;=\;\mathcal{N}(\mathbf{z}_{n}\mid\frac{1}{2}\boldsymbol{\mu}_{\mathbf{z}_{n}\mid\mathbf{z}_{n-1}}+\frac{1}{2}\boldsymbol{\mu}_{\mathbf{z}_{n}\mid\mathbf{z}_{n+1}},\frac{1}{2}\sigma^{2}\mathbf{I})\;.

(29)

To perform the Bayesian inversion
\boldsymbol{\mu}_{\mathbf{z}_{n}\mid\mathbf{z}_{n+1}}
with an arbitrary neural network block, we used the first order Taylor series approximation

\displaystyle\boldsymbol{\mu}_{\mathbf{z}_{n}\mid\mathbf{z}_{n+1}}\approx\mathbf{a}_{n}+\frac{1}{2}\nabla\lVert\mathbf{a}_{n+1}-\mathbf{z}_{n+1}\rVert_{2}\;,

(30)

where
\lVert\cdot\rVert_{2}
denotes the Euclidean norm, and
\mathbf{z}_{n+1}
is here the sampled latent variable from the next level in the hierarchy. Thus, variational posterior samples were generated according to

\displaystyle\mathbf{z}_{n}=\mathbf{a}_{n}+\frac{1}{4}\nabla\lVert\mathbf{a}_{n+1}-\mathbf{z}_{n+1}\rVert_{2}+\boldsymbol{\varepsilon}\;,\quad\text{with}\quad\boldsymbol{\varepsilon}\sim\mathcal{N}(\boldsymbol{\varepsilon}\mid\boldsymbol{0},\frac{1}{2}\sigma^{2}\mathbf{I})\;.

(31)

For MNIST, we use a simple multilayer perceptron with sigmoid activations and no residual connections or normalization layers.
We evaluate hierarchy depths
D\in\{2,3,4\}
, corresponding to networks with
4
,
8
, and
16

For each depth, we vary the hidden dimensionality over

\{50,100,500\}
.
The same architecture depth and hidden dimensionality are

The exact hyperparameters for the MNIST classification are as follows: we use a batch size of 64, the AdamW optimizer
[

]

For the HBLL model , the latent posterior variance is fixed to one and activations are treated deterministically without adding any noise.

The HBLL model uses a depth-
3
hierarchy.
The full path contains seven Transformer blocks, while the short path contains three Transformer blocks.
We compare against end-to-end backpropagation with corresponding effective depths.
We report CFF+M baselines from the prior work

For all CIFAR-10 experiments, we use the same data augmentation pipeline across HBLL and BP consisting of random cropping, horizontal flipping, and RandAugment

For missing-data and label-noise experiments,

The exact hyperparameters for the CIFAR-10 classification are as follows: we use a batch size of 256, the AdamW optimizer
[
Loshchilov and Hutter 2019
]
, a learning rate of 0.0005, and train for 500 epochs.
For the HBLL model, posteriors are sampled using the
reparameterization trick with a constant noise scale of
0.005
.

(Permuted-)Sequential MNIST Classification (HBLL-RNN)

For sequential and permuted-sequential MNIST we use the recurrent variant of HBLL (HBLL-RNN),

D

shared across train and test. The same cell type, hidden width, and parameter count are used for the

The exact hyperparameters for the (permuted-)sequential MNIST experiments are as follows: we use a
batch size of
128
, the AdamW optimizer
[
Loshchilov and Hutter 2019
]
, a learning rate of
0.001
,
weight decay of
10^{-4}
, gradient-norm clipping at
5.0
, and train for
200
epochs. We use
mixed-precision training with bfloat16. HBLL-RNN is trained block-locally at
\mathcal{O}(\log N)

span, with all nodes at a given depth evaluated in one batched call and inter-node states detached.
The deployed chain is additionally trained with the parallel fixed-point (consistency) correction at
consistency weight
1.0
, differentiating only through the final sweep; we select the number of
iterations
K
per depth (the best
K
reported in each table, with
K{=}0
denoting tree-only, no
correction, which is used throughout for the gateless Elman cell). Activations are treated
deterministically without added noise, and a single recurrent cell is shared across the tree so that
the deployed depth-
0
chain is one cell rolled. For the timing comparisons we implement the GRU cell explicitly, as plain matrix multiplications, for both HBLL and the BPTT baseline, rather than using PyTorch’s
nn.GRU
. The latter dispatches to a fused cuDNN kernel, which would give the baseline a kernel-level speed advantage unrelated to the training algorithm; since HBLL does not yet have an equivalent fused CUDA kernel, using the unfused cell for both sides isolates the algorithmic (training-span) speedup and keeps the comparison fair.
