1.0 Summary
 The purpose of this data services request was to demonstrate integration of the U.S. Department of
 Energy (DOE) Atmospheric Radiation Measurement (ARM) User Facility “met” datastreams with time
 series data from other earth science data sources using the Broker for Assimilation, Synthesis and
 Integration of eNvironmental Diverse, Distributed Datasets (BASIN-3D) data synthesis software tool.
 BASIN-3D is an open-source Python library that enables researchers to integrate data across configured
 public and private data sources. It provides a common query language for researchers to request
 measurement locations and time series data based on specified locations, variables, time period, statistics,
 aggregation, and data quality. BASIN-3D acquires the data that match the query from each configured
 data source and translates the results into the harmonized vocabularies, thus reducing researchers'
 data-wrangling effort. In addition, because the queries are executed on demand, researchers can easily
 regenerate their synthesized data sets as new data and/or data updates become available, eliminating
 one-off data products. BASIN-3D can output data using a variety of different data structures for end-user
 applications including Python pandas DataFrames and hdf5 output formats.

 This work was part of an effort to augment BASIN-3D to enable integration across high-priority, publicly
 available earth science data sources, especially those in DOE's Biological and Environmental Research
 (BER) programs. Currently BASIN-3D (version 1.1.1, https://github.com/BASIN-3D/basin3d) provides
 off-the-shelf support to integrate time series data across the U.S. Geological Survey (USGS) National
 Water Information System (NWIS) Daily and Instantaneous Values water data, U.S. Environmental
 Protection Agency (EPA) Water Quality eXchange data, and Environmental System Science Data
 Infrastructure for a Virtual Ecosystem (ESS-DIVE) data using its Hydrologic Monitoring Reporting
 Format. DOE’s Watershed Function Science Focus Area also uses a customized BASIN-3D deployment
 to provide synthesized data to its researchers. Other currently funded efforts are building connections to
 AmeriFlux FLUXNET carbon, water, and energy flux and meteorological time series data, and DayMet
 interpolated historical climate spatiotemporal data. We are targeting the ARM “met” datastreams to
 augment existing BASIN-3D connections to other climate and environmental data sources. The “met”
 datastreams provide high temporal resolution, and their highly calibrated temperature, wind speed, wind
 direction, surface pressure, humidity, and precipitation are consistent across ARM observatories and
 mobile facility deployments. This suite of data sources will enable researchers to build synthesis data sets
 (e.g., meteorological forcing or benchmarking data sets) for scientific analysis and modeling.
 Programmatically synthesized data sets from diverse data sources will also support a variety of machine
 learning (ML) applications.

 The data service request was completed between February and September 2025. ARM’s application
 programming interface (API) services were updated to meet the metadata and data needs for BASIN-3D
 integration, due for completion September 2026.

2.0 Results
 Several improvements to the ARM API metadata and on-demand data services were implemented to meet
 the requirements for BASIN-3D integration.

 The metadata updates to the metadata API service allows search of ARM holdings for a particular data
 product (https://metadata-api.svcs.arm.gov/metadata/data_product). In our case, these improvements
 allowed for on-demand listing of all “met” data products available from ARM with the necessary
 metadata (location, variables, time periods) to provide integration with other publicly available time series
 data. Key improvements to this service include:
  • Search filters for bounding box coordinates
  • Addition of a data_level parameter to more explicitly specify a data product
  • Listing of all unique datastreams for the data_product specified
  • Explicit listing of the Site Name and Grand Unified Configuration (GUC) information in the metadata
 response
  • List of variables available in each datastream.

 A new metadata service (https://metadata-api.svcs.arm.gov/variables) was built to list all variables across
 all met datastreams (i.e., at all locations where the met b1 product is available). This endpoint is critical to
 create a vocabulary mapping that is used by BASIN-3D to translate between ARM met vocabulary and
 BASIN-3D vocabulary.

 Finally, the ARMLive on-demand subsetting and combiner data service
 (https://adc.arm.gov/armlive/mod) was updated to enable units to be added to a Comma-Separated Values
 (CSV)-formatted file download. We also identified issues with the subsetting datastreams by variables.

 These changes enable us to build a BASIN-3D connection to ARM met datastreams, enabling BASIN-3D
 users to acquire ARM met time series data in the same format and vocabularies with USGS NWIS Daily
 and Instantaneous Values water data, EPA Water Quality eXchange data, and ESS-DIVE data using its
 Hydrologic Monitoring Reporting Format. This connection is scheduled to be completed by September
 2026.
