ABSTRACT
Test systems must be capable of classifying measured data as expected or anomalous in real time.
Anomalous results may portend system failure, and, if undetected, may result in damage to the unit,
test equipment, or potential harm to personnel. This report investigates the use of Gaussian Mixture
Models (GMMs) as a clustering tool in classifying time-series data. To address shape variation across
time-series waveforms (including pulses, ramps, and steady-state regions, etc.), the data are clustered
into two-dimensional Gaussian distributions that are then used for classification. Classification is
performed using two approaches. In the first, data are considered valid if they fall within a window
defined relative to the principal component axes of the assigned Gaussian region. In the second,
data are classified based on metrics derived from fourth-order cumulants. In this latter approach,
anomalies are classified by (1) an angular metric that considers how the measured datapoint affects
the principal direction of kurtosis and (2) a magnitude metric that quantifies the change
in kurtosis along the principal direction. Results on representative pulsed-waveform data with
injected anomalies show that the two kurtosis metrics are complementary—some anomalies
primarily rotate the principal direction while others predominantly increase kurtosis magnitude—
combining them improves detection across transition and steady-state regions.
Both the windowed approach and the kurtosis method successfully labeled all data in the exemplar
dataset. Further work is needed to determine when real-world scenarios are best served by
characterizing anomalies via acceptance windows versus when they are more effectively detected
through changes in kurtosis.

1. INTRODUCTION
Providing test equipment with the capability of recognizing, in real-time, when problems arise is often
the last line of defense in keeping the proverbial magic smoke inside a prototype unit. Certain scenarios
are straightforward: a current limiter trips, an over-voltage alarm goes off, etc. But there are other
scenarios where the measured data might indicate a problem is developing and the test system must
decide whether a measured data point indicates the unit might fail in the future: the current begins to
drift upward; voltage droops; a capacitor’s loss increases. To determine, for each measurement,
whether the result is anomalous, test systems must define the expected signal level and the range of
acceptable variation.
Figure 1 shows an example of noisy, but valid, data for a hypothetical square-wave pulse. This data
can be broken into four distinct regions: the on- and off-states and the transitions regions (settling
and turn-off). Anything falling outside of the noise band for this curve is considered anomalous.
Previous efforts to classify the data in real time focused on predicting the next data point using a
Long-Short Term Memory (LSTM) model (trained using either sets of historical results or simulated
data). The data were then classified as anomalous if the difference between the measured and predicted
value resulted in a z-score above a certain level:

This z-score approach proved effective when the unit was in a steady state condition but was unable
to handle regions immediately following on-to-off or off-to-on transitions. While LSTMs can handle
time dependencies, the LSTM model requires a fixed number of data points to begin predicting the
next value. Consequently, they cannot readily predict values precisely at, or immediately following, a
transition. One could, given enough training data and a large enough network, train the LSTM to
predict the transitions. This was not done as the goal was to keep the models simple and enable
rapid classification for real-time measurements. To avoid misclassifying data at the transitions, the
cited manuscript simply labeled all points with the settling and turn-off regions as “Warning”,
leaving it as an exercise for the reader to decide whether to heed said warnings.
Realistically, the most likely time for a failure is during a transition, when the in-rush currents might
exceed a critical value and damage the circuitry. It is therefore desirable to accurately classify all data
in and around the time a unit turns on or off. The simplest, though least accurate approach, is to
draw a box around the transition region and require the measured values (be they current or voltage)
to fall within this region (e.g. if one measures the current, then defining the settling region as
occurring between 𝑡0 and 𝑡1 leads to a requirement of the type: 𝐼𝑚𝑖𝑛 < 𝐼 < 𝐼𝑚𝑎𝑥 for 𝑡0 < 𝑡 < 𝑡1.)
Given that the signal should decay, anomalous behavior within the “settling region” might include
constant or increasing values. The use of simple upper and lower limits fails to recognize these
scenarios as the unit approaches the end of the settling region (Figure 2).

It would be more accurate to fit the decay to some function and assign a z-score to the measured
values deviation from the empirical fit. As noted previously [1], variability in the nature of the

settling behavior introduces a potentially large number of fitting parameters that complicate this
approach.
Rather than predict a specific value for the next data point, this report uses a Gaussian Mixture
Model (GMM) with two-dimensional Gaussian distributions to cluster a set of valid training data. It
aims to classify measured values in terms of the value’s relationship to these clusters. At first glance,
Gaussian distributions don’t appear to be an obvious choice for clustering waveform data—the
pulse in Figure 1 can be broken up into regions that are approximately constant, linear, or
exponential—and Gaussian distributions only appear as one-dimensional descriptions of the noise
on top of those dependencies. However, the inherent flexibility in defining the shape of a multi-
dimensional Gaussian enables the GMM to act as a general-purpose clustering tool that can easily
distinguish between the various regions in the pulse. This report demonstrates the potential of
GMMs to cluster data and then uses two different approaches to determine whether data should be
considered anomalous. The first approach uses the variances of those clusters to define a “valid”
region. The second considers the applicability of defining anomalies based on kurtosis—a metric
well suited for anomaly detection due to its sensitivity to outliers [2]. To classify data using kurtosis,
this report considers changes to both the magnitude and direction of principal kurtosis vector [3].
All classification attempts in this report utilize the data plotted in Figure 3, which adds four different
exemplar anomalies to Figure 1. These anomalies occur at the off-to-on transition (excess in-rush
current), within the steady-state region for the on-state (signal droop and a signal spike), and at the
on-to-off transition (negative bounce during turn off). The goal is to correctly identify the set of
anomaly points within Figure 3, without mistakenly mis-labeling any of the valid, noisy data as
anomalous.

2. GMM REVIEW
For data of the type depicted in Figure 1, the test system must synchronize the on/off transitions
across all runs so that any given region occurs at approximately the same time in each dataset. How
the test system achieves this synchronization, whether through software or hardware triggers in the
test sequences or some type of post-processing of the data, is left as an exercise to the reader.
Assuming the data are aligned in time, then the use of the Gaussian distributions will automatically
account for any subtle variations that may occur between tests: these could be timing jitter in the
actual transitions; variations in the magnitude or decay rate of signals; measurement noise, etc.

then assigned to the distribution corresponding to the one with the highest conditional probability.

2.2. Defining Valid Windows
Anomalies can be defined by whether a measured data point has a low probability of belonging to
any of the Gaussian distributions. The report begins by specifying that the data must fall within an
ellipse defined by setting the semi-major and semi-minor axes equal to three standard deviations
from the mean along the principal axes of the distributions (Figure 4). Inspection of Figure 4 shows
that the anisotropic nature of the distributions can potentially lead to significant classification errors.
Consider the initial off state (Gaussian #1) and the subsequent on state (Gaussian #3). The
distributions have maximum variance along the time axis and, using a 99.5% probability limit, these
distributions have significant overlap in time, though not in value. As a result, a measurement of
𝐼 = 10 at 𝑡 = 1 𝑠 would be classified as valid data belonging to Gaussian #3. Similarly, measuring a
value of 𝐼 = 0 at 𝑡 = 2.5 𝑠 would erroneously be categorized as valid data within Gaussian #1. Both
of these datapoints should be classified as anomalies.

 Figure 4. Areas containing 99.5% probability for each of the Gaussian distributions based on the
 initial GMM fit.
To resolve these types of overlap issues, the valid window must be compressed along the axis of
maximum variance. For Gaussians #1 and #3, this corresponds to a stricter criterion in time than in
value. Note that the use of time and value axes works for only distributions with no-covariance,
which is approximately true for Gaussians #1, #3, #4, and #5; but doesn’t hold for Gaussian #2
(see Table 1). Therefore, the appropriate axes of comparison are not those of time and measured
value, but the axis of maximum variation and its orthogonal counterpart. These correspond to the
principal axes determined by principal component analysis.

By reducing the valid-data criteria along the first principal component axis, the semi-major axis of
the ellipse defining the valid-data window has shrunk considerably. The corresponding increase in
the z threshold along the semi-minor axis (from 3 to 4) increases the width of the window along

distributions. This will enable the routine to handle some degree of potential timing jitter. But by
limiting the extent of the overlap, the anisotropic z-score limits prevent glaring classification errors
such as the two possible cases mentioned above.
Figure 5 demonstrates that GMM can readily cluster the pulsed waveform training data and define
regions that constitute expected behavior. Before testing the approach with anomalous data, it is
worth noting that GMMs outperformed attempts to group these data using k-means clustering. This

potential off-nominal conditions and prevent damage to the UUT, the tester, or system operators.

Smart systems need to be capable of updating their underlying models as more data becomes
available. In this example, each valid measurement represents additional data that can be used to
fine-tune the GMM parameters. Running the full GMM fitting routine when new data is acquired
would significantly slow the classification algorithm, as it would recomputes the means and standard
deviations from the full training dataset—including the additional point. As the dataset becomes
larger and larger, this approach becomes infeasible. However, the means and variances can all be

the current values of the mean and variances, the number of data points used to compute these
current values, and the new data point; it does not use the complete history of the data that
generated the current mean and variances.

3.2. Integrating Kurtosis Analysis with Real-Time Data Acquisition
To implement kurtosis-based anomaly classification in real-time, one must first decide to what
region an incoming measurement belongs. Then, the anomaly metrics can be computed and the data
labeled accordingly. Leveraging section 2, the measured data are assigned to regions using a GMM
[6]. Unlike section 2, the Gaussian parameters that define a region are not used to determine
whether a point is anomalous. Rather, the GMM is used only as a clustering tool, identifying which
subset of training data the measured value most likely belongs. Then, given a subset of the training
data, the analysis can proceed along the lines of section 3.1. That is, a new data point replaces a
point from the requisite training data cluster and the changes to kurtosis for that cluster are
calculated. This process assumes that the algorithm begins with a pre-trained GMM model,
computed directions of maximum kurtosis for training data for each Gaussian cluster, the
corresponding calculated magnitude of kurtosis along that direction, and a dataset containing
projections of all members of that cluster onto its primary kurtosis direction. The steps are as
follows (steps highlighted in red correspond to those necessary to calculate 𝑀2, while those in blue
determine ∆𝑘):
 1. Use the GMM to determine to which region a measurement most likely belongs. (What
 follows utilizes only the training data for this region.)

 27

 2.  Remove a data point with the same time stamp from the training data.
 3.  Insert the measured data point and compute the fourth order cumulant tensor (equation 1).
 4.  Transform the tensor into a 2 × 8 matrix (equation 3.2).
 5.  Perform SVD on the resultant matrix.
 6.  Compute the fractional contributions of each feature (equation 3.3) and corresponding
 anomaly metric, 𝑀2 (equation 3.4).
 7. Remove a point from the projection of the training data onto its principal axis
 (corresponding to the same timestamp as the measured data) and update the kurtosis
 resulting from the removal of the aforementioned point.
 8. Project the measured data point onto the principal direction (of the original training data);
 insert the projection into the projected training data set; and update the kurtosis.
 9. Compute the change in kurtosis, ∆𝑘, along this principal direction resulting from replacing
 the training data point with this measured point.
 10. Classify data as anomalous if either 𝑀2 or ∆𝑘 are above some predefined threshold.
To test the methodology, a set of noisy data (similar to that shown in Figure 3, but with different
randomly generated noise) was processed using the above ten step procedure. Finding the elements
of the cumulant tensor and determining the magnitude of kurtosis are both computationally
expensive procedures. To reduce the classification time, both 𝐶𝑖𝑗𝑘𝑙 and 𝑘 were calculated using on-
line update formulas (see, e.g., [7] and [8], and the Appendix section). Based on the results shown in
Figure 9, the threshold for defining an anomaly with 𝑀2 was set to 𝑀2 > 0.01. Through trial and
error, the threshold for ∆𝑘 was set to ∆𝑘 > 0.1.

This simple example shows that kurtosis has considerable potential for classifying time-series data;
but several challenges remain for applying the technique more broadly. While the definition of an
anomaly appears to depend on only two threshold values (𝑀2 and ∆𝑘) the number of
hyperparameters is actually considerably larger. To calculate the changes in kurtosis, the training data
was divided into non-overlapping regions defined by the GMM. Thus, for 𝑁 Gaussians, defining the
known data regions contributes 2𝑁 hyperparameters for the means in 𝑡 and 𝑣; and 4𝑁
hyperparameters for the covariance matrix. In addition to the region definitions, depending upon
the shape of the data within a region, single threshold values for 𝑀2 and ∆𝑘 may be less effective
than assigning individual cut-off values for each region. Thus, the total number of potential
hyperparameters to optimize may be as high as ~8𝑁. Manually tuning these when faced with more
complex datasets with numerous regions becomes intractable; to operate robustly across different
waveforms, an automated routine must be developed that optimizes all of these parameters
programmatically. This is left as future work.

4. CONCLUSIONS
Time series data can be readily classified as valid or anomalous with the aid of Gaussian Mixture
Models. The data are treated as a collection of two-dimensional clusters, with time and measurement
value serving as the correlated variables. The GMM is trained on a set of valid data, dividing the raw
data up into a set of well-defined regions. During a test, this GMM assigns incoming data points to
the region it most likely belongs. Then classification can proceed in one of two ways. In the first
case, a “valid data” window is defined relative to the principal axes of the Gaussian distributions.
The windows are rectangular boxes within the PC1/PC2 coordinate system, with dimensions that
are tunable hyperparameters to be optimized based on the training data’s shape. Using single-shot
update formulas on classified data allows the routine to continuously incorporate additional
“training data” and improve the accuracy of the predictions, without deleteriously affecting the
algorithm’s run time. In the second classification approach, the measured data point’s effect on the
magnitude and direction of the principal kurtosis vector is calculated. Utilizing online update
formulas, the fourth order tensor approach can be made to run nearly as fast as classification based
on the second order variance calculations. Further work is required to determine which scenarios are
better suited for the two routines, and to develop automated routines to select the hyperparameters
that define anomalies within a given region.

second and fourth centered moments can be calculated from
