Techniques for integration within Bezier domains and approximation of circular arcs
Authors: Logah Perumal
Published: 2026

ABSTRACT
This work presents techniques to perform integration of arbitrary functions within Bezier domains in two dimensions. Techniques that are considered for general nth order Bezier domains are the use of Green’s theorem and method of integration over parametrized surface. Derivation and steps to implement Green’s theorem for the integrations are provided. New expressions for calculation of integration of functions within quadratic and cubic Bezier domains are then derived based on the concept of bijective mapping, with following advantages:•Comparison with alternate method (integration over parametrized surface) for integration within a quadratic Bezier domain shows that the proposed formula is simpler and easier to use.•Method proposed for the cubic Bezier domains can be used to approximate arbitrary circular arcs and subsequently perform integration of functions within the circular arc domains.The new methods are then implemented within the context of Extended Finite Element Method (X-FEM) and Strain-based Finite Element Method (SB-FEM) to solve problems with circular arc boundaries.•Simulation results show improvement in the solution accuracy.

Introduction

Integration of functions within a domain is particularly of interest within the context of Finite Element Analysis (FEA). FEA discretizes the problem domain by using finite number of elements and integration of functions within the individual elements is performed to obtain the element matrices, which are later merged to form global matrices for the entire domain. Among the factors that affect accuracy of the solution are the accuracy of the domain’s geometry representation (through discretization) and the technique used for the integration within the individual elements. Various discretization methods can be seen within different types of FEA. Each discretization method is facilitated with a suitable integration technique, which can be interchangeably used or merged with other techniques. Three most common discretization methods are the area discretization (used in Finite Element Method (FEM) and Strain-based FEM), boundary discretization (used in Boundary Element Method (BEM)) and uniform background mesh (used in Extended FEM (XFEM), Immersed Boundary Method (or CutFEM), and Finite Cell Method).

In case of area discretization, the entire active area of the domain is discretized by using finite number of elements that conform to the shape of the domain. Discretization of the inner area of the domain can be performed easily by using conventional linear finite elements (such as triangular or quadrilateral elements), but care must be taken when regions near the curved boundaries of the domain are to be discretised. Curvatures of the domain’s boundaries need to be represented correctly for better solution accuracy. Several techniques are available to approximate curvatures of the boundaries. Those are the use of adaptive mesh [1], isoparametric elements [2], higher order elements (HO) [[3], [4], [5]], isogeometric analysis [6], use of curved elements [7,8] and etc. Frequently, integration within the elements in FEM are carried out by first transforming the curved elements in actual problem domain (physical space) to a reference domain (parent space) by using suitable coordinate transformation (Jacobian transformation) followed by use of standard numerical integration schemes onto the reference domain (that involve integration points and weights), such as Newton-Cotes integration, Gauss-Legendre integration, classical Gaussian Quadrature, Generalized Gaussian Quadrature [9], trapezoidal quadrature [10], Double Exponential (DE) formula [11], etc. Use of adaptive integration techniques for arbitrary domains and to reduce computational time can be seen in [12].

Boundary discretization such as in BEM involves division of boundary of the problem domain into several sub elements for analysis, instead of partitioning entire area of the problem domain. Integration of functions is then carried out along the discretised boundaries. BEM produces integral equations that need to be treated for singularity. Analytical and numerical regularizations can be used to treat the singularity, which include analytical line integral, coordinate transformations followed by the use of Gaussian Quadrature, use of Taylor series expansion or power series expansion, radial integration method, semi-analytical approaches, integration by parts, hybrid approach and etc [13].

In case of uniform background mesh, the problem domain lies within the regular and structured grids that do not conform to the actual shape of the problem domain. The grids are categorised into three; grids that are cut/intersected by the domain’s boundaries, grids that are outside the problem domain and grids that represent voids within the problem domain. Integration within the first category requires special techniques to capture the curvature of the problem domain. Various techniques can be implemented, such as subdivision of the grid (that is intersected by the domain’s boundary) by using high number of linear elements, quadtree/octree meshes or by using polygonal elements followed by integration in parent space through mapping [14], use of equivalent functions [14], use of moment–fitting, local quasi-parametrization and Monte-Carlo techniques [15]. Fubini’s theorem can be used to perform the integration when equations of the boundary curves are known [16]. Another method employs homogeneous numerical integration scheme to convert area integration to boundary integration (dimension reduction) along the parametric curves (domain’s boundary) that cut the grids [17]. Use of Stokes or divergence theorem and Green’s formula for the dimension reduction can also be seen in the literature [12].

Some of the limitations found in the existing techniques are:1.Some of the existing techniques rely on Jacobian transformation (to perform integration) which could lead to matrix singularities for high element distortions.2.Uniform background meshing techniques involve high number of elements to approximate the irregular boundaries and use of computationally complex methods such as Monte Carlo.3.Fubini’s theorem can be used to avoid the above-mentioned drawbacks. However, this method requires explicit equations of the boundary curves, which might not be available especially when the boundaries are represented by parametric curves.4.Dimension reduction by using Stokes or divergence theorem and Green’s formula requires the integrals to be in a specific vector form, or in the form of Mdx+Ndy.

In this work, integration of arbitrary functions, f (x, y) within Bezier domains is studied and implemented in Finite Element Analysis (FEA). Three methods are considered. Those are the use of Green’s theorem, method of integration over parametrized surface and bijective mapping. The second method (method of integration over parametrized surface) is a standard existing method classified as Method 2 and described in the section: Method 2: Integration over parametrized surface. New approaches are then introduced in the implementation of these methods, which address limitations of the existing techniques. The modifications/new approaches are described below:1.Green’s theorem is often used to calculate area of a domain and to solve line integrals that are in vector form, or in the form of Mdx+Ndy. However, implementation of Green’s theorem for integration of arbitrary functions f (x, y) within a Bezier domain is not readily available. In this work, function M is taken as zero and the Green’s theorem is implemented in the order dxdy to perform integration of arbitrary functions within a Bezier domain. Steps for the implementation of the technique are provided. Limitations of this method due to selection of M = 0 are described and alternate approach to overcome these limitations (by letting N = 0) are provided in the section: Limitations.2.Bijective mapping is used to form new integration formulas for quadratic Bezier domains that are simpler and easier to compute. Method 3: Bijective mapping

Formula for integration of functions within a Bezier domain can be derived by using proposition below:Let Pi be the Bezier control points in the physical coordinate system corresponding to predetermined pi in reference coordinate system. Then, bijective mapping of Pi to pi will generate unique curve and plane in the reference coordinate system.Integrations and other operations can then be performed onto the unique curve and plane in the reference coordinate system, hence simplifies the calculation.

Let Pi be the Bezier control points in the physical coordinate system corresponding to predetermined pi in reference coordinate system. Then, bijective mapping of Pi to pi will generate unique curve and plane in the reference coordinate system.

Location of V for the arc in physical coordinate system is then determined by substituting location of the arc’s midpoint in reference coordinate system (obtain r and s coordinates for the arc’s midpoint from Eq. (28) by substituting x and y values with coordinates of M given in Eq. (27)) and in physical coordinate system (P) into Eq. (29) and solving for V. P2 and P3 can then be determined by substituting the V and corresponding r and s values (for P2 and P3, respectively) into Eq. (29). r and s values for P2 and P3 can be respectively obtained by substituting x and y values with coordinates of P2 and P3 given in Eq. (27). The general equation for approximation of arbitrary circular arc by using cubic Bezier curve through mapping as described in this work is given as:P1=ArcstartpointP2=(1.3330826×ArcMidpoint)+(0.0560985P1)−(0.3891810P4)(30)P3=(1.3330826×ArcMidpoint)−(0.3891810P1)+(0.0560985P4)P4=Arcendpoint

This technique can be used with general nth order Bezier, Non-Uniform Rational B-Splines (NURBS) or any other established Bezier curves for the approximation of the circular arc by simply extending two edges of the two non-parallel sides of the convex hull. However, complexity of the integrand will differ, according to the type of approximation used. In case of approximation by using NURBS, the integrand will consist of rational functions which require special or more complex integration techniques. Accuracy of approximation of the circular arc might be higher when NURBS is used, but the integration of rational functions within the domain needs to be handled with care. Furthermore, the final simulation results for some cases might not show significant improvement when NURBS is used, since the current technique has shown very good results (for instance, smallest error of 0.05% for example 2 in the section: Example 2: analysis of thick curved beam).

Approximation of circular arcs

Problems from XFEM and SB-FEM are used as examples to validate the new methods. Example 1 is based on XFEM, which is analysis of a plate with circular hole. Examples 2 and 3 are based on SB-FEM, which are analysis of thick circular beam and thick-walled cylinder, respectively. Bezier control points for the circular arcs in all the examples are obtained by using Eq. (30). Midpoint of a curve is found based on the start and end points of the curve as well as the radius.

Limitations

Limitation of the method 1 and alternate approach (letting N = 0)

The Method 1 in the section: Method 1: Green's theorem is described for the case where M is set to be zero. This causes the integration to be performed with respect to x as shown by Eq. (5) and imposes restriction that, the function f(x,y) should have closed-form antiderivatives with respect to x (an inherent dependence on x-integration). This limitation can be overcome by letting N = 0 to allow integration to be performed with respect to y instead. Hence, selection of M or N to be zero can be made based on the availability of closed-form antiderivatives of the function f(x,y). Limitations and mitigations of method 3 for cubic Bezier domains

The method described in the section: Cubic Bezier domain (under Method 3: Bijective mapping) (for cubic Bezier domains) is limited to convex hulls with non-parallel sides that can be extended to form a virtual vertex V. However, convex hull of the control points that are in the form of parallelogram, square and other shapes with parallel sides can still be solved by using the method presented in this work but requires splitting of the original Bezier curve into two or more smaller segments. An example is shown in Fig. 17 for a convex hull of control points in the form of a parallelogram. The original curve is split into two segments (Fig. 17(b)). Convex hulls of control points of these two segments have non-parallel sides which satisfy the requirement of the method. Integration can then be carried out within three subdomains labelled as R1 to R3 as shown in the Fig. 17(c).Fig. 17Integration within a cubic Bezier domain with convex hull of control points in the form of a parallelogram (a) original convex hull with parallel sides (b) splitting of the curve into two segments (c) formation of virtual vertex V and subdomains R1 to R3.
