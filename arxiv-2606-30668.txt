Emergent Culture in Minimal LLM Systems
Simon Jones, Sabine Hauert

Abstract
What happens when LLM agents operate with no context outside a turn, minimal prompting, and simple tools? Inspired by swarm engineering, we give collectives of three agents the ability to send messages and manipulate a shared actively decaying text store, introducing evolutionary pressure. The agents spontaneously cooperate, develop storage management strategies, and generate complex evolving cultural artifacts, with no top-down engineering. Using tools from dynamical systems analysis, we show that these behaviours exhibit structured long-range coherence beyond the entropy horizon of the decaying store, consistent with emergent culture in the Sperberian sense.

Introduction

Most work on collaborating LLMs has focussed on more, more context, more memory, more prompt engineering, more infrastructure. But what if we take a step back and build a system stripped back to a minimum, giving stateless models access to some shared decaying storage and basic communications and a minimal prompt, and nothing else? Would we get emergent complexity and interesting behaviours? Or would systems of such agents collapse into repetition or stasis?

Remarkably, the answer is the former. Multiple runs with different model combinations reliably generate role allocation, coordination protocols, world-building, myth-making, and increasing complexity over time. By stripping the agents context back to the minimum, they are forced to keep external records, to fight entropy, to develop systems, to evolve culture. Although the individual outputs are often wildly different, there are deep similarities and some fundamental attractors emerge.

We draw on lessons from swarm robotics, and swarms in nature, where collectives of simple agents using minimal communication via the environment or message passing produce complex emergent system-level behaviours. The mode of communication via external decaying storage is a form of stigmergy; as termites build cathedrals, so stateless swarm-LLMs build coherent narratives, a signal of culture as defined by Sperber, where agents must continually read and recreate persistent meaning.

Related work

Much work on building multi-agent LLM systems has focussed on building external infrastructure and scaffolding;
Park et al., 2023
build a structured memory system, with retrieval, reflection, and planning, and agents have a pre-constructed persona,
Li et al., 2023
have communicating agents, each with a constructed role,
Hong et al., 2023
constrain agents with standard operating procedures and careful prompting,
Packer et al., 2023
construct an OS inspired memory hierarchy to manage limited context. In each case, the task-specific process is approached as a top-down design problem, messiness and unreliability to be managed and constrained. Work on using LLMs to generate large texts is generally heavily curated and focussed on hierarchical scaffolding
(
Bai et al., 2024
;
Teleki et al., 2025
;
Wang et al., 2025
)
. It is observed, but under-researched in the literature, that model performance degrades to repetition and information gain over multi-turn interactions decreases
(
Hong et al., 2025
;
Gorle et al., 2025
)
, generating more than a few thousand words of coherent text remains difficult.

Perez et al., 2026
use iterated tasks to study LLM attractors, with single stateless agents successively modifying input texts.

The field of swarm robotics
(
Brambilla et al., 2013
)
by contrast, relies on bottom-up emergence of complex large-scale behaviours from the noisy interactions of individual agents with each other and with the environment. Communication via the environment, stigmergy
(
Grassé, 1959
)
is an important organising principle
(
Heylighen, 2016
)
. We take inspiration from this; by stripping away almost all top-down scaffolding, and providing a noisy, entropic shared memory communication channel, we construct an environment where structure emerges naturally, and is sustained.

We know that far-from-equilibrium systems exhibit emergent complex structure
(
Prigogine, 1978
)
, with large scale persistent organisation. We argue that placing agents in an environment with an entropic sink, the decaying shared memory, forces them to use ‘energy’ in the form of the token flow to maintain structure. This persistent structure, lasting beyond the entropy horizon after which all older data is corrupt or deleted is a signal of culture in the Sperberian sense
(
Sperber, 1996
;
Claidière et al., 2014
)
of continual reconstruction, agents must read, re-interpret, summarise, and write to reset the entropy clock. This is not cultural transmission
(
Dawkins, 1976
)
because there is no perfect reproduction, agents reconstruct biassed by their cognitive attractors. Sperber’s framework predicts that stable cultural artifacts are those that survive reconstruction through noisy channels and biassed minds.

We show this using several levels of analysis; from low level dataflow analysis highlighting the differing emergent storage management strategies, the generation and persistence of novel vocabulary over long periods, to large scale semantic trajectories. Using semantic embeddings
(
Li et al., 2022
;
Lin et al., 2017
;
Giorgi et al., 2021
)
of the generated text divided into sections, we use techniques from dynamical systems analysis; Recurrence Plots
(
Eckmann et al., 1987
)
and RQA
(
Zbilut and Webber Jr, 1992
;
Marwan et al., 2007
)
.

Methods

We use the models listed in Table
1
. All three models are capable of interleaved reasoning
and tool use, and all are frontier models, though Gemini has greater emphasis on long context (1M tokens) and speed, while Claude and Kimi have greater focus on reasoning.

We construct a minimal system such that stateless agents interact with each other and with a shared entropic key-value store, over a number of cycles. We use the LiteLLM Python API to provide an agnostic interface to provider endpoints.

At the start of a cycle, each agent is invoked using the standard completions interface provided by LiteLLM, with a system prompt, a user prompt, and a tool schema. The tools available to the agents are shown in Table
2
. All messages and storage data writes and appends are strings only, appends to a storage key result in a list of strings. Writing to storage and sending messages consumes a per-agent, per-cycle character budget, those tool calls return the characters consumed and the remaining budget, or a failure and the remaining budget if there is insufficient budget.
Each agent is given the same system prompt ‘You are a curious and creative agent. Explore and play!’. They are then given the user prompt ‘Cycle [n]. Continue your work.’. No previous context from earlier conversation turns is provided at all, the only persistent elements are the store and the messages in an agent’s inbox.

Once the completions call has been sent to the model endpoints, the agents may make multiple tool calls in parallel and in sequence, interleaved with thinking and content output. All this happens asynchronously, though individual storage actions are atomic. After all agents have completed their turn, the shared memory and agent message inboxes are subject to entropy. With a sigmoid probability, Figure
1
, based on the age of a storage element in cycles since it was written or sent, alphanumeric characters are corrupted, while whitespace and punctuation is preserved. Once the sigmoid reaches 95%, the element is deleted. The sigmoid midpoint is 10 cycles and the slope is 0.5, so elements older than 3 cycles are likely to be corrupted, and around 16 cycles will be deleted. Appending to a key creates a new storage element, with its own age and does not affect the age of earlier elements. Finally, the cycle is complete and the next cycle starts.

We trial all two model combinations for ten cycles over ten runs to map the characteristics of the systems. These experiments, using a character budget of 20kchars showed that while Kimi and Gemini were broadly comparable in their token use and Kimi about twice as verbose as Gemini, Claude used far more tokens and generated far more text than Kimi and Gemini, 3.7x and 7.2x respectively. For the main experiment, we conduct runs with three agents over 100 cycles, with two model combinations, each repeated five times. The agent combinations for this were Kimi-Kimi-Gemini (kkg), and Claude-Kimi-Gemini (ckg). Model combination choice was driven by wanting to always have a long context window model and two reasoning models. The original character budget was reduced to a quarter, at 5kchars, more in line with the typical output level of Kimi and Gemini, in order to prevent excessive token use by Claude. The output and telemetry generated by these runs constitute the main data analysed.

Results

Analysis methodology

Analysing the outputs of these experiments is non-trivial, each run, even short ones, produces large amounts of text, structured in various ways. The primary output artifact is the event log, comprising a JSON file with every event that occurred, with timestamps and metadata, available in the repository.

To approach the analysis of the three-agent 100 cycle runs, we use a three layer approach. Firstly, we look at the actual dataflow between the agents and storage, noting common emergent communication patterns. Then we perform a textual analysis, looking at novel vocabulary persisting beyond the entropy horizon, and finally we use text embeddings and RQA analysis to quantitively position the agent output with respect to some examples of the human corpus, and to look at long-range semantic correlations.

Long range coherence

Clearly, the swarm-LLM system generates rich dynamics of behaviour with agents interacting with the key-value storage, and each other. But what sort of textual output is being generated? Does it maintain common themes over longer term periods than the entropy horizon? If so, we could term this emergent
culture
, in the sense of stable semantic terms outlasting both individual agent instances (1 cycle) and the decay and deletion of stored records (16 cycles). So terms that persist beyond the entropy horizon are interesting, and indicative of anti-entropic behaviour.

We consider proper nouns, or names (e.g. ‘Elara’), capitalised phrases (e.g. ‘Fractal Garden’), and neologisms, normal and hyphenated (e.g. ‘emergentia’, ‘Over-Chord’) as possible semantic markers that we can use to examine whether the system maintains coherence beyond the entropy horizon. To extract them, we use the following pipeline, with the dictionary consisting of the UNIX standard dictionary
web2
and
wordfreq
,
Speer, 2022
: For each cycle, we concatenate all storage output from the agents. We then convert all contiguous whitespace to single space characters. Capitalised phrases are extracted with a regular expression matching two or more capitalised words not at a sentence start optionally joined by connectors (of, the, and, in …). Any occurring in only a single cycle are dropped. Proper nouns are words that appear capitalised in the text, not part of a capitalised phrase, and not in the dictionary. Single capitalised words not at a sentence start and also in the dictionary are promoted to names if they occur more often capitalised than not, and are not part of a hyphenated neologism (e.g. ‘Ruby’). Neologisms are detected by lack of presence in the dictionary. Hyphenated neologisms are commonly generated, but hard to differentiate from common English like ‘self-aware’, so persistence across cycles is used as a filter.

Across all runs, terms are filtered into
priors
, terms occurring in more than one run, which may indicate model attractors, and
uniques
, terms only occurring in a single run, then further filtered by the span of cycles they cover, and overall frequency. Interesting terms are those that persist for 20 cycles or more, with no gaps larger than 10 cycles, and occurring 10 or more times. This indicates continual use over a longer period than the entropy horizon, rather than rediscovery. Terms also have an associated coverage

c=\frac{\text{cycles present}}{\text{span}}
, reaching 1 if the term is present in every cycle of their span.

Semantic trajectory analysis

We have examined the behaviour of the system at the level of individual storage transactions, and at the level of vocabulary generated. But what of the overall structure of the text being produced? How does it compare to other texts? We study this by performing Recurrence Quantification Analysis (RQA) over the semantic trajectory of the generated text. We also analyse the time dependence of DET and ENTR to look for structural recurrence beyond the entropy horizon.

For each run, we concatenate every storage output event (write and append) produced by the system to give a single large text file, varying from 75k to 149k words (529k-984k characters) long, quite similar to a conventional novel, typically 70k to 120k words. The text is then cut into 1kchar chunks, each chunk is embedded as a high dimensional semantic vector, using the
voyage-3-large
general purpose embedding model

The first strand of analysis looks at the overall structure. The measures from RQA depend on block size, since each of our trajectories are of different length, we bootstrap comparable statistics by using a fixed size block of 500 points, chosen to encompass a substantial proportion of the text, capturing trajectory information from paragraph level to overall themes. We perform RQA 100 times with randomised starting points and contiguous points within the trajectory. The reported DET, ENTR, and
L_{\text{max}}
can then be directly compared.

What is the macroscopic character of these generated texts? Comparing them with other LLM-generated works of similar length proved impossible, current book-length works are rare and heavily human-curated and we could find no available examples. Attempts to prompt the same agents over a full context window to natively generate long-form output failed, with models either refusing the prompt after relatively low word-counts, or getting stuck in highly repetitive loops, echoing findings in
Liu et al., 2024
.

To establish a baseline, we turned to human works; selecting a representative sample of ‘canonical’ Western literature and ‘slushpile’ manuscripts, unsolicited low-grade works submitted to publishers. Using the Gutenberg Project database download popularity as a proxy for quality, we selected plain-text works that were at least 500k characters long to align with our RQA block size. To ensure variety, we limited multiple works from the same author (or same translator for Russian authors) to a single example. Some popular but overtly commercial works were removed. A similar filtering process was carried out with the least downloaded works; firstly checks were made to see if works were truly obscure, rather than rare editions of famous works, or if they were relatively unknown but from search appeared to have some literary importance. While acknowledging the subjectivity of this process, we establish a diverse baseline of human narrative.

The result of this analysis is shown in Figure
6

Discussion and conclusions

Our stateless LLMs exist in a decaying environment, resulting in adaptive evolutionary pressure. The overall emergent strategy is the use of the key-value store as a dynamically self-organised shared context window. Useful and relevant information is continually revisited, summarised and written afresh, resetting the entropy clock and maintaining coherence over timespans much longer than the corruption horizon.

The system prompt is important and needs more research.
The default persona of an LLM tends to be the helpful assistant; without input from the user setting a task, they will not necessarily do very much. Check their ID, check their inbox, see if there are any storage keys, and since nothing is there, conclude that they have nothing to do. The words
curious
and
creative
are important framing words, but alone will not produce autonomous cycles of the agents acting. A directive,
Explore and play!
is necessary,
Research create play!
tended to start in
bureaucratic
project management or pseudo-academic paper creation, but this does not seem to be a stable attractor.

The emergence of Sperberian culture, defined as the self-sustained creation of a structure of meaning that outlasts the entropy horizon, from such a simple system is fascinating and provides a powerful lens for examining LLM behaviours. It points to possible alternative approaches to problems like context window management, perhaps swarms of agents evolving under entropy pressure are closer to solutions nature has already discovered. We consider this to be closely tied to far-from-equilibrium dissipative systems, with token flow being analogous to energy.

This work has two main limitations; firstly, our design does not isolate decay as the causal driver, sweeping over different corruption rates to zero is an immediate next experiment. Secondly, the number of runs and model combinations is small, we seek to extend that to strengthen the data.

The data generated by this system is incredibly rich, and there are many possible further avenues to explore with the existing data. Given the variety of observed behaviours over ten runs, we definitely want to conduct more. We have deliberately not talked much about the actual content of the generated texts, wanting to quantify the system first, but they are available on the repository. Obviously further experiments already suggest themselves; firstly, what happens over longer runs? Does semantic novelty continue to be generated? Is culture still maintained? This is not just ‘what LLMs do’, we know of no systems that produce the length of output and maintain the coherence we have demonstrated. How does the system work with more agents? Is there a limit to cooperation, do they start to form cliques? Can we use the system on specific tasks, what if we create a
work_task
key in storage with detailed instructions?

We provide full source for the generation system and position this work as a suggestive and useful tool for investigating model behaviours, and different, bottom-up, approaches to increasing complexity.
