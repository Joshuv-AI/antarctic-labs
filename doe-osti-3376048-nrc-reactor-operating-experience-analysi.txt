component performance studies, loss-of-offsite power analysis, initiating events
analysis, and system studies provided on the NRC Reactor Operating Experience
Results and Databases website (https://nrcoe.inl.gov/).

 NRC Reactor Operating Experience Analysis and
 Trend Summary: 2024 Update
 1. INTRODUCTION
 This report presents a summary of the Nuclear Regulatory Commission’s (NRC’s) reactor operating
experience (OpE) analyses with data through 2024 as well as the reliability and frequency trends
identified in the 2024 update reports provided on the NRC Reactor Operating Experience Results and
Databases website (https://nrcoe.inl.gov/). The 2024 update included the following OpE analyses and
reports:
• Loss-of-offsite power (LOOP) analysis, which has been updated every other year starting with the
 2023 update. As such, no 2024 update is available; instead, the 2023 update is presented in this
 summary:
 - Analysis of Loss-of-Offsite-Power Events 2023 Update [1].
• Initiating event (IE) analysis, which has been updated every other year starting with the 2023 update.
 As such, no 2024 update is available; instead, the 2023 update is presented in this summary:
 -  Initiating Event Rates at U.S. Nuclear Power Plants, 2023 Update [2].
• Component performance studies, which have been updated every other year starting with the 2016
 update:
 - Enhanced Component Performance Study: Air-Operated Valves 1998–2024 [3]
 - Enhanced Component Performance Study: Emergency Diesel Generators 1998–2024 [4]
 - Enhanced Component Performance Study: Motor-Driven Pumps 1998–2024 [5]
 - Enhanced Component Performance Study: Motor-Operated Valves 1998–2024 [6]
 - Enhanced Component Performance Study: Turbine-Driven Pumps 1998–2024 [7].
• System reliability studies, which have been updated every other year starting with the 2016 update:
 -  System Study: Auxiliary Feedwater 1998–2024 [8]
 - System Study: Emergency Power System 1998–2024 [9]
 - System Study: High-Pressure Coolant Injection 1998–2024 [10]
 - System Study: High-Pressure Core Spray 1998–2024 [11]
 - System Study: High-Pressure Safety Injection 1998–2024 [12]
 - System Study: Isolation Condenser 1998–2024 [13]
 - System Study: Reactor Core Isolation Cooling 1998–2024 [14]
 - System Study: Residual Heat Removal 1998–2024 [15].
 There were no updates for the industry-average parameter estimates, common-cause failure (CCF)
parameter estimates, or causal CCF parameter estimates with data through 2024, as these studies are
updated approximately every 5 years. The latest associated reports used data through 2020:
• Industry-Average Performance for Components and Initiating Events at U.S. Commercial Nuclear
 Power Plants: 2020 Update [16]
• CCF Parameter Estimations, 2020 Update, Revision 1 [17]
• Causal CCF Parameter Estimations 2020 [18].
 Note that the above analyses may include multiple specific studies:

 1

• The LOOP analysis includes the LOOP IE frequency analysis, LOOP frequency trending analysis,
 and LOOP duration analysis.
• The IE analysis includes the IE baseline analysis and IE frequency trending analysis.
• The industry-average parameter estimates include component unreliability and IE frequency
 estimates.
• The CCF parameter estimates include estimations of CCF alpha factors, causal alpha factors, and
 CCF prior distributions.
Different periods of data were used in specific studies for a variety of reasons. For example:
• The most recent 15-year period was generally used in industry-average parameter estimates as well as
 in the CCF parameter estimates (previously, 1997 or 1998 was mostly used as the starting year for the
 data period in various analyses including for the LOOP and parameter estimates).
• The most recent 10-year period was usually used in a trending analysis.
 Table 1 provides a list of data periods used in the latest NRC OpE analysis updates.
 In the remaining sections, the important statistically significanta trends (on reliability and
unavailability), either increasing or decreasing, as identified in the 2024 update, are presented.

a “Statistically significant” is defined in terms of the “p-value.” A p-value is a probability that indicates whether the null
 hypothesis that there is no trend in the data should be accepted or rejected. P-values less than or equal to 0.05 indicate that
 we are 95% confident that there is a trend in the data (reject the null hypothesis of no trend). By convention, we use the
 “Michelin Guide” scale: p-value <0.05 (statistically significant), p-value <0.01 (highly statistically significant), p-value
 <0.001 (extremely statistically significant).

 2. LOSS-OF-OFFSITE POWER EVENTS
 The following trends were identified in critical operation LOOP frequencies in the most recent 10-
year period from 2014 to 2023 [1]:
• Decreasing trend in critical operation all-categories (grid-related, plant-centered, switchyard-centered,
 and weather-related) LOOP frequencies
• Decreasing trend in critical operation grid-related LOOP frequencies.
 The following trends were identified for LOOP durations over the 1997–2023 post-deregulation
period:
• Increasing trend in all-operations (critical and shutdown) all-categories LOOP durations
• Increasing trend in all-operations switchyard-centered LOOP durations
• Increasing trend in shutdown operation all-categories LOOP durations.

 3. RATES OF INITIATING EVENTS
 The occurrence rates trends for IEs are summarized in this section. Sixteen IE categories were trended
and displayed in Ref. [2]. Note that the LOOP IEs analyzed in that IE analysis [2] were also analyzed in
the LOOP analysis [1] as the critical operation all-categories LOOPs (the LOOP analysis also analyzed
shutdown operation and individual-category LOOPs). The decreasing LOOP trend identified in the 2023
IE update [2] and presented below is the same trend identified in the 2023 LOOP update [1] and presented
in the previous section for critical operation all-categories LOOP frequencies.
 The following trends were identified for IE frequencies in the most recent 10-year period from 2014
to 2023:
• Decreasing trend in LOOP (critical operation all-categories) occurrence rates
• Decreasing trend in the pressurized water reactor transient occurrence rates.

 4. COMPONENT PERFORMANCE STUDIES
 The component performance studies were last updated using data through 2024. The summary
provided in this section is therefore the latest available information until the next update, which is
scheduled for completion when the 2026 data are available.
 The trending analysis in the study used data over the last 10 years, from 2015 to 2024. Important
trends (on unreliability and unavailability) and observations from the analysis are presented below.
 Component Trends Consistent with the 2022 Updates:
 Air-Operated Valves (AOVs)
• The failure probability estimate trend for low-demand AOVs (those with less than or equal to 20
 demands per reactor year) failing to open or close is highly statistically significant and decreasing.
 The same trend was observed in the 2022 AOV update [19].
• The failure rate estimate trend for low-demand AOVs failing to operate or control is statistically
 significant and decreasing. The same trend was observed in the 2022 AOV update.
 Emergency Diesel Generators (EDGs)
• The failure rate estimate trend for emergency power system (EPS) EDGs failing to run is statistically
 significant and decreasing. The same trend was observed in the 2022 EDG update [20].
• The unreliability (24-hour mission) trend for EPS EDGs is statistically significant and decreasing.
 The same trend was observed in the 2022 EDG update.
 Motor-Driven Pumps (MDPs)
• The unavailability trend for standby MDPs is highly statistically significant and decreasing. The same
 trend was observed in the 2022 MDP update [21].
• The unreliability (24-hour mission) trend for standby MDPs is extremely statistically significant and
 decreasing. The same trend was observed in the 2022 MDP update.
 Motor-Operated Valves (MOVs)
• The failure probability estimate trend for low-demand MOVs failing to open or close is highly
 statistically significant and decreasing. The same trend was observed in the 2022 MOV update [22].
 Turbine-Driven Pumps (TDPs)
• The failure rate estimate trend for standby turbine-driven pumps (TDPs) failing to run after the first
 hour is extremely statistically significant and decreasing. The same trend was observed in the 2022
 TDP update [23].
• The failure rate estimate trend for normally running TDPs failing to run is extremely statistically
 significant and decreasing. The same trend was observed in the 2022 TDP update.
• The unreliability (24-hour mission) trend for standby TDPs is extremely statistically significant and
 decreasing. The same trend was observed in the 2022 TDP update.
 New Component Trends Not Identified in the 2022 Updates:
 MOVs
• The failure rate estimate trend for high-demand MOVs (those with greater than 20 demands per
 reactor year) to operate spuriously is statistically significant and decreasing. This is a new trend that
 was not observed in the 2022 MOV update.

 7

 4.1. Air-Operated Valves
4.1.1. Increasing Trends

4.1.1.1. Extremely Statistically Significant
• The frequency of demands per reactor year for low-demand AOVs to open or close was found to be
 increasing.
• The frequency of demands per reactor year for AOVs to open or close for high-demand valves was
 found to be increasing.

4.1.2. Decreasing Trends

4.1.2.1. Highly Statistically Significant
• The failure probability for low-demand AOVs failing to open or close was found to be decreasing.
• The frequency of fail to open or close events (events per reactor year) for low-demand AOVs was
 found to be decreasing.

4.1.2.2. Statistically Significant
• The failure rate for low-demand AOVs failing to operate or control was found to be decreasing.
• The frequency of fail to operate or control events (events per reactor year) for low-demand AOVs
 was found to be decreasing.

 4.2. Emergency Diesel Generators
4.2.1. Increasing Trends

4.2.1.1. Extremely Statistically Significant
• The frequency of demands per reactor year for EPS and high-pressure core spray (HPCS) EDGs to
 start was found to be increasing.
• The frequency of fail to load/run demands per reactor year for EPS and HPCS EDGs to load and run
 was found to be increasing.

4.2.1.2. Statistically Significant
• The frequency of fail to run hours per reactor year for EPS and HPCS EDGs was found to be
 increasing.

4.2.2. Decreasing Trends

4.2.2.1. Statistically Significant
• The failure rate for EPS EDGs failing to run was found to be decreasing.
• The unreliability (24-hour mission) of EPS EDGs was found to be decreasing.
• The frequency of fail to run events for EPS and HPCS EDGs was found to be decreasing.

 8

 4.3. Motor-Driven Pumps
4.3.1. Increasing Trends

4.3.1.1. Extremely Statistically Significant
• The standby MDP run > 1H hours per reactor year were found to be increasing.
• The normally running MDP run hours per reactor year were found to be increasing.

4.3.1.2. Statistically Significant
• The frequency of demands per reactor year for standby MDPs to start was found to be increasing.
• The standby MDP run < 1H hours per reactor year were found to be increasing.

4.3.2. Decreasing Trends

4.3.2.1. Extremely Statistically Significant
• The unreliability (24-hour mission) of standby MDPs was found to be decreasing.

4.3.2.2. Highly Statistically Significant
• The standby MDP unavailability was found to be decreasing.

 4.4. Motor-Operated Valves
4.4.1. Increasing Trends

4.4.1.1. Extremely Statistically Significant
• The frequency of demands per reactor year for low-demand MOVs to open or close was found to be
 increasing.

4.4.2. Decreasing Trends

4.4.2.1. Highly Statistically Significant
• The failure probability for low-demand MOVs failing to open or close was found to be decreasing.
• The frequency of failure to open or close events (events per reactor year) for low-demand MOVs was
 found to be decreasing.

4.4.2.2. Statistically Significant
• The failure rate for high-demand MOVs operating spuriously was found to be decreasing.
• The frequency of spurious operation events (events per reactor year) for high-demand MOVs was
 found to be decreasing.

 4.5. Turbine-Driven Pumps
4.5.1. Increasing Trends
• None.

 9

4.5.2. Decreasing Trends

4.5.2.1. Extremely Statistically Significant
• The failure rate for standby TDPs to run after the first hour was found to be decreasing.
• The failure rate for normally running TDPs to run was found to be decreasing.
• The standby TDP unreliability (24-hour mission) was found to be decreasing.
• The frequency of fail to run after the first hour events (events per reactor year) for standby TDPs was
 found to be decreasing.
• The frequency of fail to run events (events per reactor year) for normally running TDPs was found to
 be decreasing.

4.5.2.2. Statistically Significant
• The frequency of demands per reactor year for normally running TDPs to start was found to be
 decreasing.
• The normally running TDP run hours per reactor year were found to be decreasing.

 5. SYSTEM PERFORMANCE STUDIES
 The system performance studies were last updated using data through 2024. The summary provided
in this section is therefore the latest available information until the next update, which is scheduled for
completion when the 2026 data are available.
 The trending analysis in the study used data over the most recent 10 years, from 2015 to 2024, and
identified the following trends:
• Decreasing trend in the industry-wide estimates of auxiliary feedwater (AFW) system 24-hour
 mission unreliability
• Decreasing trend in the industry-wide estimates of EPS system 24-hour mission unreliability
• Decreasing trend in the industry-wide estimates of high-pressure safety injection (HPSI) system start-
 only unreliability
• Decreasing trend in the industry-wide estimates of HPSI system 24-hour mission unreliability
• Decreasing trend in the industry-wide estimates of residual heat removal (RHR) system low-pressure
 injection (LPI) start-only unreliability
• Decreasing trend in the industry-wide estimates of RHR system LPI 24-hour mission unreliability.

 5.1. Auxiliary Feedwater System
 A statistically significant decreasing trend was identified in the industry-wide estimates of the AFW
system 24-hour mission unreliability for the most recent 10-year period. The same trend was observed in
the 2022 AFW update [24].

 5.2. Emergency Power System
 A statistically significant decreasing trend was identified in the industry-wide estimates of the EPS
system 24-hour mission unreliability for the most recent 10-year period. The same trend was observed in
the 2022 EPS update [25].

 5.3. High-Pressure Coolant Injection System
 No statistically significant trends were identified in the high-pressure coolant injection (HPCI) system
unreliability trend results for the most recent 10-year period.

 5.4. High-Pressure Core Spray System
 No statistically significant trends were identified in the HPCS system unreliability trend results for
the most recent 10-year period.

 5.5. High-Pressure Safety Injection System
 Statistically significant decreasing trends were identified in both the HPSI system start-only
unreliability and 24-hour mission unreliability for the most recent 10-year period. The same trends were
observed in the 2022 HPSI update [26].

 5.6. Isolation Condenser System
 No statistically significant trends were identified in the isolation condenser (ISO) system unreliability
trend results for the most recent 10-year period.

 11

 5.7. Reactor Core Isolation Cooling System
 No statistically significant trends were identified in the reactor core isolation cooling (RCIC) system
unreliability trend results for the most recent 10-year period.

 5.8. Residual Heat Removal System
 A statistically significant decreasing trend was identified in the RHR system LPI start-only
unreliability. A highly statistically significant decreasing trend was identified in the industry-wide
estimate of RHR LPI 24-hour mission unreliability. The same trends were observed in the 2022 RHR
update [27].
