 1 Introduction
 The J2 plasticity model is a generic implementation of a von Mises yield surface and offers
 flexibility in isotropic hardening description and dependence on strain rate and temperature.
 Implementation of the constitutive equations utilize an elastic-predictor, inelastic-corrector,
 where each loading step is initially assumed to be fully elastic. The elastic assumption is
 evaluated for yielding, if no yielding occurs, the stress update is complete, and the next step
 can proceed. If the stress evaluated in the elastic state exceeds the yield stress, an iterative
 plastic correction is utilized to map the stress-strain state back to yield surface [1].

 In some circumstances, an increase in computational time when using the rate-dependent
 J2 plasticity model has been observed, discussed in Section 2. To better understand and
 address the observed slowdown, the plasticity model is simplified to 1D (Section 3) and
 implemented in MATLAB for rapid testing of modifications to the inelastic-correction. From
 the 1D results, a new initialization method for the correction algorithm is applied within the
 Library of Advanced Materials for Engineering (LAMÉ), Section 4, for use in finite element
 code Sierra. The new initialization is then compared to the traditional method (Section 5)
 to determine if the computational slowdown is improved.

6 Conclusion and Future Work
The initialization of the inelastic correction is traditionally zero, in this work it is proposed
to initialize to the total strain taken in the step to address a computational slowdown that
has been observed in the rate dependent J2 model. Implementing the new initialization
method in LAMÉ led to a reduction in the average iterations per inelastic correction, with
the largest reductions seen as the number of prescribed steps increase. Further more, the
iterations of the new initialization performed the same across strain rates, not exhibiting the
rate dependence of the traditional iteration that adds to computational expenses. Relating
the reduction of iterations to a CPU time savings resulted in a large uncertainty due to short
computing time of the single element simulations and the complexities of remote computing.
Some simulations resulted in longer computing time then the traditional method despite
the decrease in iterations, it is unknown if this increase is due to numerical model or other
computing task and extraneous factors. Further multi-element simulations with various
input should be conducted to obtain better CPU metrics.
It is expected that there will be some circumstances, that may lead to additional expenses,
it would be desirable to have a criterion to determine when the traditional initialization

should be used instead of the new initialization. One possible metric, the normalization
of the Johnson-Cook rate term by the number of simulated steps, was studied and showed
a weak correlation in time savings as the ratio decreased. Further comparisons of various
simulation input and material parameters are needed to determine a viable metric.
