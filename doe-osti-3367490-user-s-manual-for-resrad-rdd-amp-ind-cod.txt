 1 INTRODUCTION

 Version 2.0 of the RESRAD-RDD&IND computer code is designed to support the
implementation of protective action guides (PAGs) after a nuclear emergency incident including
a radiological dispersal device (RDD) and/or an improvised nuclear device (IND) incident (EPA
2017). Eight different group types, addressing various decisions, are available for selection. The
RESRAD-RDD&IND code calculates radiological doses, stay times, etc., for the selected group
that the user wishes to focus on. (That is, the results for all the groups are not calculated
simultaneously, and the input for those other groups do not matter, although some parameter
values are shared between groups.)

 Version 2.0 has a user-friendly interface so that the RESRAD-RDD&IND code can be
used with minimal training. For example, the user can select the major characteristics of the
problem-event type, source term, and decision type from the left side of the interface and then
calculate the results with the default assumptions for the exposure scenarios. More in-depth
analysis would include specifying site-specific exposure scenario characteristics in the right side
of the interface. The procedures for data entry and results viewing are self-explanatory. This is
because common window maneuvering features and text instructions were incorporated in the
interface design. General and context-specific help are available to aid users entering parameter
values, as well.

 The RESRAD-RDD&IND computer code gives the user the option to select either an
RDD or IND incident for analysis. For an RDD event analysis, 11 radionuclides (Am-241,
Cf-252, Cm-244, Co-60, Cs-137, Ir-192, Po-210, Pu-238, Pu-239, Ra-226, and Sr-90) are
included. These 11 radionuclides are the radionuclides most likely used for an RDD. More than
90 radionuclides can be selected for an IND event analysis. Initial default concentrations are
provided for 44 radionuclides for a uranium-fueled IND event. These 44 radionuclides are those
that would contribute significantly to the radiation dose associated with a uranium-fueled bomb
detonation. The radionuclides generated from ingrowth of these 44 initial radionuclides are also
automatically included in the analysis. Pu-239, Cs-134m, Ru-105, and Rb-89 and their progeny
can be selected for analysis if they are detected and their concentrations are determined.

 This user’s guide, which is Volume 2 of the User’s Manual for RESRAD-RDD&IND
Code Version 2, provides instructions to users on how to install the RESRAD-RDD&IND code,
navigate the interface, and use the various features, including those discussed above, to set up an
analysis and view/print the results in text outputs. Volume 1 of the User’s Manual for RESRAD-
RDD&IND Code Version 2 (Yu et al. 2026), which contains descriptions of the methodology
and theoretical basis for dose modeling and the mathematical equations implemented in the code,
can be accessed and viewed through the Help menu in the code or can be downloaded from the
RESRAD website (https://resrad.evs.anl.gov).

 This user’s guide contains seven chapters that discuss the following topics:

 1. Introduction: This chapter.

 2. Installation: Discusses system requirements and the installation and uninstallation
 procedures.

 2 INSTALLATION

 The RESRAD family of codes, including RESRAD-RDD&IND Version 2.0, is
distributed through the RESRAD website (https://resrad.evs.anl.gov). The code requires a
Microsoft Windows 10 or later operating system. A printer driver must be installed, but an
actual printer does not need to be attached. The code has been tested and is fully compatible
with the Windows 10 and 11 operating systems. The following sections describe the procedures
for downloading and installing the code (Section 2.1), checking the installation (Section 2.2), and
uninstalling the code (Section 2.3).

2.1 INSTALLING FROM THE RESRAD WEBSITE

 Procedures for downloading and installing RESRAD-RDD&IND code are described as
follows. (Note that administrative rights are required for installation of the RESRAD-RDD&IND
code.)

 • Connect to the RESRAD website at https://resrad.evs.anl.gov/.

 • Click on the Download option.

 • Fill in the requested information and submit. An email with the download link will be
 sent to the supplied email address. Click on the link to download the installation
 program.

 • When the installation program launches, follow the instructions for entering the
 requested information. (Note: First-time users are advised to accept the default
 selections.) The code should not be installed in the program files directory, as it needs
 to write temporary files to the installation directory and modify the data files there
 every time it is executed.

 • If the default installation selections are used, the files needed to execute RESRAD-
 RDD&IND Version 2.0 will be installed at C:\RESRAD_Family\RDD_IND\2.0\. The
 installation would also create the following subdirectories:

 o C:\RESRAD_Family\RDD_IND\2.0\QA_files\: Quality assurance (QA) files are
 saved under this subdirectory.

 o C:\RESRAD_Family\RDD_IND\2.0\Reports\: PDF files of the reports generated
 after running calculations are saved under this subdirectory by default.

 o C:\RESRAD_Family\RDD_IND\2.0\Resources\: The radionuclides database used
 is saved under this subdirectory.

 o C:\RESRAD_Family\RDD_IND\2.0\UserFiles\: The user files are saved under
 this subdirectory. The folder will be created when the user saves the first input
 file.

 3

 • After installation, the program will be placed under the RESRAD Family group in the
 Start menu and a new RESRAD-RDD&IND 2.0 icon will appear on the computer’s
 desktop.

 • Double-click the RESRAD-RDD&IND 2.0 icon to start RESRAD-RDD&IND. (Note: if
 “Launch RESRAD-RDD&IND” is selected before finishing the installation, the program
 will start automatically after the installation is completed.)

2.2 CHECKING THE INSTALLATION

 Two quality assurance input files are placed in the QA_files subdirectory (to the directory
where the code was installed) (for the sake of brevity, this folder is referred as “...\QA_files\”
herein) during the installation of the code. Each of them checks the installation of the code for
conducting analyses for different groups (B and C) in the code. These files can be run on
RESRAD-RDD&IND to obtain output files for comparison with those generated by the code
developers to verify a successful installation. The latter are placed in the
...\QA_files\QAoutputforComparison\ subdirectory during installation. (For the sake of brevity,
this folder is referred as “…\QAoutputforComparison\” herein.) The files in
…\QAoutputforComparison\ are read-only to prevent accidental modifications, and read-only
duplicate copies of the QA input files are also included in this subdirectory because the input
files in …\QA_files\ are not read-only to allow them to be processed by the code.

 • Double-click the RESRAD-RDD&IND 2.0 icon on the computer desktop to start
 RESRAD-RDD&IND.

 • Click File in the Menu Bar on top of the interface, click Open, then select and open
 the “QA_IND_Group_C.rdd” input file in the …\QA_files\ subdirectory.

 • Press Calculate button, then press Yes on the Save Before Calculate prompt to start
 the calculations.

 • When the calculations are completed, an output file in PDF format will be written to
 …\QA_files\ and will open in the default PDF viewer.

 • One of the following approaches may be used to compare the file saved in the
 ...\QA_files\ subdirectory to the corresponding output file,
 “QA_IND_Group_C_expected.pdf,” in the …\QAoutputforComparison\ subdirectory
 that was generated by the code developers:

 o Open the PDF file in the …\QAoutputforComparison\ subdirectory in a separate
 window and visually compare the two files.

 o Alternatively, a computer program with a file comparison function may be able to
 automate the comparison (e.g., the Compare Files function in Adobe Acrobat
 Pro).

 4

 The input information and dose results listed in the two output files are expected to be the
same, although the time and date listed in the upper-left corner of the first page will be different.

 The RESRAD-RDD&IND code has many subgroups and generates numerous output
files. An additional QA file is included in the distribution package and is installed in the
...\QA_files\ and …\QAoutputforComparison\ subdirectories. Run RESRAD-RDD&IND with
other QA input files as described above for QA_IND_Group_C.rdd and compare the results.
(Note: More QA files may be available at the User Center on the RESRAD website.)

2.3 UNINSTALLATION

 Use Uninstall, a program utility in the Windows Control Panel (accessible by searching
for “control panel” in the Start menu), to uninstall RESRAD-RDD&IND Version 2.0.

 3 STARTING RESRAD-RDD&IND

 After installation, RESRAD-RDD&IND Version 2.0 can be started by one of the
following three methods: (1) double-click the RESRAD-RDD&IND shortcut icon on the
desktop, (2) choose RESRAD-RDD&IND from the RESRAD Family in the list of all programs
accessible by clicking the Start icon on the taskbar of the main screen, or (3) go to the directory
where RESRAD-RDD&IND is installed and double-click the RESRAD-RDD&IND application
program.

 4 INPUT FORMS

 Upon starting the code, a RESRAD-RDD&IND pre-setup form (screen) is displayed
(Figure 1). The left side of the pre-setup screen provides background and contact information for
the code. The right side of the screen contains Event Selection checkboxes (RDD or IND) and
the Preference Settings command button. The checkboxes allow the user to select the RDD or
IND component of the code for conducting dose analyses. For analyzing an RDD event, select
the RDD checkbox. Clicking on the Preference Settings button takes the user to the form that
allows setting the preferences for the run (Figure 2), and clicking on the OK button takes the user
to the main interface screen of the RESRAD-RDD&IND code for analyzing an RDD or IND
event.

 Figure 1. Pre-setup Form of the RESRAD-RDD&IND Code

 Figure 2 shows the Preference Settings form in the RESRAD-RDD&IND code. This
form allows setting the user’s preferences. The user has an option to show or hide Tooltips (On
or Off radio buttons for Tooltips); select traditional or SI units for radionuclide concentration and
dose; select a jpeg, jpg, png, or gif file that can be used as the cover page for the report; select the
ICRP-107 (ICRP 2008) or ICRP-38 (ICRP 1983) radionuclide database; and select the internal
dose coefficient available for the selected radionuclides database. The external dose coefficient
selected based on the selected internal dose coefficients is shown.

 9

 Figure 2. Preference Settings Screen in the RESRAD-RDD&IND Code

 In the RESRAD-RDD&IND code, clicking in the input box provides Tooltips for the
input parameter. The Tooltips are input hints providing the minimum, default, and maximum
values allowed for the parameter.
 Checking the “Include a report cover page” checkbox includes a cover page in the report.
The screenshot below shows the default cover page. The date displayed on the cover page
reflects the date the report was generated.

 10

 Clicking on the Change command button opens the dialog box for selecting the image file
for the cover page. The contents of the selected image file will be the cover page of the report.
The default cover page can be restored by clicking the Change command button and then
clicking Cancel in the file dialog box.

 If the “Show 0 for values less than 1E-38” checkbox is checked, the reports will show 0
for values less than 1E-38 regardless of the units selected.

 The View button allows viewing the dose coefficients. For an RDD or IND event
analysis, the user can choose the ICRP-107 or ICRP-38 radionuclide database. For the ICRP-107
radionuclide database, the user can choose internal dose coefficients from either DOE-STD-
1196-2022 (DOE 2022) or DCFPAK302. When DOE-STD-1196-2022 internal dose coefficients
are selected, the code uses FGR 15 (EPA 2025) external dose coefficients, and when
DCFPAK302 internal dose coefficients are selected, the code uses DCFPAK302 external dose
coefficients. For the ICRP-38 radionuclide database, the code uses internal dose coefficients
from ICRP-72 (ICRP 1996) and external dose coefficients from FGR 12 (Eckerman et al. 1993).
The ICRP-72 database library dose conversion factors (DCFs) were developed based on the
ICRP-38 radionuclide database, while the FGR 15 and DCFPAK3.02 database library DCFs
were developed based on the ICRP-107 radionuclide database.

 By default, the radionuclides database library selection is set to ICRP-107 and the
internal dose coefficient library is set to DOE-STD-1196-2022 for the RDD or IND event
analyses. Changes made in the Preference Settings form are saved when the code is exited, and

calculating a weathering correction factor include Mobile Fraction, Shorter Half-Life, and

Initial Source Partioning Factors (Ratio to Outdoor Ground Deposition): The partitioning
factor is the concentration ratio between a given surface and soil/street. The RESRAD-
RDD&IND code considers concentration ratios (partitioning factors) between other
contaminated surfaces and streets/soils with default partitioning factors such as 1 for street/soil
and roof, 0.5 for exterior walls, 0.1 for interior floor, and 0.05 for interior walls.

Weathering Correction Factors: For each contaminated surface, the weathering correction
factor is defined as the ratio of the radionuclide concentration at time t to the deposited
radionuclide concentration at time 0 after accounting for radiological decay and ingrowth over
time t. Andersson et al. (2003) proposed that the weathering process and the effect of migration
generally follow a two-class exponential behavior with time, as represented by the following
equation:

                                       w(t) = ae-(bt)+(1-a)e-(ct)                                  (1)

where w(t) is the radioactivity fraction retained after weathering at time t and a, b, and c are
parameters for each surface. In this equation, there is a mobile fraction a with a shorter half-life b
due to loose binding to the surface or due to the higher migration rate in the case of permeable
surfaces. There is also a less mobile fraction (1-a) with a longer half-life c due to strong binding
to the surface or a lower migration rate. The default values are based on the collected data for
Cs-137. The user may input radionuclide-specific values, if data are available. It is expected that
the longer half-life fraction c is more likely to be radionuclide-dependent.

4.4.3 General Features of Parameters and Input Tabs

 The values of input parameters that are enabled can be modified. Fixed values are
displayed for information in disabled input boxes. The data field is highlighted in yellow if a
parameter has the default value. No highlight indicates deviation from the default.

 The different exposure scenarios considered for a group for dose calculations after an
RDD or IND event are listed in the Exposure Parameters tab. These exposure scenarios are
grouped under different subgroups according to the characteristics of receptors, contamination
locations, or modeling methods. Doses are calculated for each scenario in every subgroup. Input
parameters for all scenarios in the group are displayed in the same tab for Groups B and D. They
are displayed in different tabs for each subgroup in Groups C and E. To modify the exposure
parameters for scenarios in a different subgroup, the subgroup number tab (located in the 2nd
horizontal bar at the top of the input screen) has to be selected first. Upon the selection of the
subgroup number, the exposure scenarios grouped under that subgroup will be displayed and the
exposure parameters used by each scenario of that subgroup can be modified. Figure 55 shows
the Exposure Parameters input screen for Subgroup C5.

 To reset to the default value for a specific parameter after its value was changed, move
the cursor to the input field of that parameter, then press F6 on the keyboard. To reset to the
default values for all parameters, go to the Menu Bar located on top of the Global Settings panel
(the left panel), select File and choose New from the dropdown list. The New option will close
the current input file and start a new file with all parameters set at default values.

 Another feature for the parameters in an input screen associated with the exposure
parameter tabs is that internal bounds were set for the value of each parameter. If the value
entered is outside the range set for the parameter, a red warning sign will appear next to the input
value upon exiting that input box (Figure 61). No other operation can be performed until the
error is rectified. The internal bounds were selected to prevent mathematical overflow or
underflow problems and physically impossible situations (e.g., spending 25 hours per day
outdoors). They do not correspond to the range of the parameter under normal conditions.

 6 VERIFICATION AND QUALITY CONTROL OF RESRAD-RDD&IND

 The RESRAD-RDD&IND software was developed following the RESRAD Program
Quality Assurance and Quality Control procedures. The calculations performed by the software
were verified by hand calculations and/or other separately developed spreadsheets implementing
the equations used in the software. Many parameter values used in the RESRAD-RDD&IND
software were taken from the RESRAD database. These include soil-to-plant transfer factors,
meat and milk transfer factors, dose conversion factors, decay half-lives, and scenario-specific
occupancy factors. The RESRAD database is well documented and verified (Yu et al. 2000,
2001, 2022).
