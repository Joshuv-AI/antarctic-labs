ABSTRACT
OcuPHLUX is a graphical software tool that processes digital images of a bright glint/glare
source and produces, for each image color channel, an estimate of reflected irradiance at the
camera and a corresponding ocular hazard assessment. The tool is intended to enable rapid
glint/glare characterization using a digital camera rather than specalized instrumentation. A core
element of the workflow is a calibration reference image of the Sun. It is important to note that
capturing an image of the Sun or an intense glint/glare source with a digital camera may produce
some hazards. It is important to never view an intense light source, like the Sun, with an optical
viewfinder on a digital camera, even with filters on the lens.
OcuPHLUX supports common image formats (e.g., JPG, PNG, TIFF) and can process RAW
camera imagery through integration with an external RAW conversion utility (dcraw). For best
accuracy and repeatability, the RAW processing workflow described in this manual is
recommended.

1. GRAPHICAL USER INTERFACE (GUI) AND USER INPUTS

1.1. Tool Overview (Functional Blocks)

The tool includes the following primary capabilities:

 • Image processing and irradiance mapping: Conversion of pixel intensity to irradiance
 maps W m−2 of the glint/glare or otherwise illuminated source on a per-image-channel
 basis, including optional cropping and interactive interrogation via transect plots.

 • Uncertainty analysis: An analytically derived uncertainty quantification allows for user
 specification of input uncertainties by assigning the standard deviation on the nominal input.
 These uncertainties are propagated through the pixel-to-irradiance conversion model to
 produce nominal results and uncertainty bounds for irradiance estimation and ocular hazard
 estimation.

 • Ocular hazard assessment: Pixel-by-pixel hazard classification based on estimated retinal
 exposure, using a length reference in the subject image to infer an angular source size
 (subtended angle).

 • Analytical reference scenarios: Independent analytical calculations for representative
 diffuse, point-focus specular, and line-focus specular reflectors. These serve as a sanity
 check and for interpretive context.

 • Data export and reproducibility: Export of processed outputs and import/export of
 text-based session files to reproduce settings and results.

 • Diagnostics: A GUI text stream plus run-time logs saved in the working directory to
 support debugging and troubleshooting.

In addition, the OcuPHLUX application currently makes use of two external tools to extract
metadata from image and convert RAW images to a suitable format. These tools are ExifTool by
Phil Harvey and can be located at https://exiftool.org/ and dcraw which Windows
compatable executables can be located at https://github.com/ncruces/dcraw/releases.
During development it was noted that the dcraw application is no longer supported, but was still
selected to minimize initial deviation from the original software. Future development will source
replacements for integration into the application.

 13

1.2. Recommended Hardware for Data Collection

The following hardware is recommended for acquiring images used in OcuPHLUX:

 • A digital camera capable of saving RAW images.

 • Neutral density (ND) filters to prevent sensor saturation and reduce risk of sensor damage
 when imaging bright sources. An example included in Section 4.3 may serve as a point of
 reference for filter selection.

 • A tripod (recommended) to improve repeatability and reduce motion blur.

 • A rangefinder (recommended) to measure the camera-to-subject distance.

1.3. GUI Layout

1.3.1. Sidebar Controls

The sidebar contains the primary execution and plotting controls. Typical controls include:

 • Tab Navigation Alternate way of navigating the tab system and reading current tab with a
 dropdown menu.

 • Session management: Quick import/export buttons for text-based session files.

 • Processing toggles: Boolean options to include/exclude major analysis blocks and UI
 elements.

 • Run and save actions: Buttons to run the tool with current settings and to export results
 shown on the active tab. Export of results is only avaliable when primary calculations have
 been run. The Save All Data button can be used after the primary analysis is run to quickly
 generate all output for current settings.

 • Plot controls: Buttons to generate plots and to redraw plots when the application window
 size changes.

 • Context-specific plot selection: A dropdown menu box whose options depend on the
 active tab (e.g., nominal vs. uncertainty bounds).

 • Transect controls: Persistent row/column inputs and a dedicated update button for the Flux
 Maps and Transects tab.

 • Reset and exit: Reset returns inputs to defaults and clears plots; exit closes the application.

If primary image processing is enabled and a user has not selected the Sun and subject images, the
tool prompts the user to select them during execution.

 14

1.3.2. Tabs (High-Level Description)

The GUI organizes inputs and outputs into the following tabs:
User Input Primary inputs for image processing (Sun/subject imagery, filters, geometry,
 reflectivity, and options).
Analytical Input Inputs for analytical reference scenarios and plots.

Uncertainty Settings Input uncertainty definitions used to generate uncertainty bounds for
 primary results.
Analytical Plots Analytical irradiance and hazard plots for diffuse, point-focus, and line-focus
 cases.
Sun and Subject Images Preview of the selected (and possibly cropped) Sun and subject images.

Image Scale Preview of the length-scale annotation drawn on the subject image for hazard
 analysis.
Flux Maps and Transects Primary computed irradiance maps (per channel) and interactive
 transect plots.
Ocular Hazard Per-channel irradiance maps and pixel-level ocular hazard outputs.

Warnings and Output Messages Consolidated warnings, errors, and informational messages
 produced during execution.

The User Input tab contains the primary settings for image processing. It also includes buttons

1.4.3. Uncertainty Settings Tab

The Uncertainty Settings tab defines the input uncertainties used in the primary analysis
uncertainty propagation. Each field is specified as the standard deviation of a Gaussian
distribution. The uncertainty model is based on analytical sensitivity of the pixel-to-irradiance
conversion equation (see Chapter 2).

 Figure 1-3. Example of the uncertainty settings input tab and arguments.

 standoff distance from the reflector.
 • Hazard-coded corneal irradiance vs. distance: The same irradiance values, color-coded
 by hazard classification derived from estimated retinal exposure.

1.5. Hazard Classification Legend (Used Throughout the GUI)

In plots that include hazard classification, markers are used to indicate severity based on the tool’s
hazard model and a nominal exposure duration of 0.15 s (a representative blink response time):
Green Low potential for an afterimage at 0.15 s exposure.

Yellow Potential for an afterimage lasting at least 1 s at 0.15 s exposure.

Red Potential for permanent eye damage (retinal burn) at 0.15 s exposure.

These hazard levels are applied consistently in the Analytical Plots and Ocular Hazard tabs.

2. THEORY AND MODELS

2.1. Overview of the Processing Approach

OcuPHLUX converts image pixel intensities into irradiance estimates by using a Sun image as a
calibration reference and applying camera metadata (e.g., exposure time, f-number, ISO),
user-provided attenuation factors, and other details about the scene. The subject image is
processed using the same camera response assumptions, then scaled using reflectivity and
geometry to estimate reflected irradiance. Finally, ocular hazard metrics are computed from the
irradiance maps using an eye model and an estimated angular source size. The underlying theory
and mathematical models can be found in [1, 2, 3] with examples of use cases and prior use of this
method in the following [4, 5, 6]. If a user would like to reference diagrams for the default
analytical settings, they can be found in [3]. Further ocular hazard adjustments due to photopic
sensitivity are applied to the calculated irradiance maps based on the human eye wavelength
sensitivity from [7]. This scaling factor will always be less than or equal to the primary
calculation data for the Red, Green, and Blue wavelength bands specified if the requested color
model is supported either by the data collection camera or conversion code.
Important: The tool assumes camera response behavior consistent with the selected workflow
(RAW recommended). When non-RAW formats are used, in-camera processing (tone curves,
compression, white balance, channel scaling, etc...) can violate the linearity assumptions used in
the primary conversion from pixel intensity to irradiance.

GG01-2500 Flux Gauge from Huxeflux USA at fluxes from 50 to 300 W cm−2 at the National

blue channels on raw images, respectively. The RSME error in the same evaluation is 9.50, 7.96,

green and blue channels is 7.77, 6.40, and 6.17 W cm−2 , respectively. As shown in Figure 3-1, it is
clear that bias is introduced in image conversion algorithms for the JPG format that significantly
biases the OcuPHLUX estimation upward. These photos were captured with the same Nikon

4. STEP-BY-STEP GUIDES AND INCLUDED EXAMPLES

4.1. Before You Begin (Data and Safety)

 1. Never look through a digital camera viewfinder when imaging the sun or intense glint/glare
 sources to prevent damage to a user’s eye. A connected digital display with "live view"
 preview is recommended for safety.
 2. Use appropriate neutral density (ND) filters when imaging the Sun or intense glint/glare
 sources to avoid sensor saturation and reduce risk of sensor damage.
 3. Prefer RAW image capture, but if possible capture both standard image format and RAW.
 4. Record (or retain in metadata) camera settings: ISO, f-number, and shutter speed for both
 Sun and subject images. If digital camera does not automatically retain these values in the
 image metadata, they may have to be embedded into the image prior to processing.
 5. Measure the camera-to-subject distance and record a physical reference length visible in the
 subject image. These values are only needed during processing for ocular hazard
 assessment, but are required for accurate estimates.

4.2. Collecting Data with a Digital Camera: Stationary Glint/Glare Source

 1. Prepare camera tripod and rangefinder if avaliable. Check camera clock and set to match
 known source if needed. This is important if image time stamps need to be compared to
 measured data like DNI, or simple matching of timestamps with notes.
 2. Set camera to manual focus if possible. Autofocus adds additional time to image capture
 and may hinder data collection if glint/glare source is only present for a short time.
 3. Mount camera with zoom lens and ND filters. Example data presented used a single NiSi
 ND 5.0 Solar Filter. If avaliable, a single high optical density is recommended over a
 stack-up of multiple low optical density filters. For reference, during example collection,
 unsaturated direct images of the sun were collected with a single ND 4.0 reflective and a
 single ND 5.0 absorptive filter with different lenses and camera settings to maintain a sharp
 focused image.
 4. Focus on glint/glare source and note zoom lens focal length setting. If possible lock focal
 length in place during data acquitision.
 5. Capture image(s) of glint/glare subject.

 35

 6. With the exact same focal length setting, prepare to image the Sun directly making
 adjustments with the focal ring to maintain a sharp image.

 7. Capture image(s) of the Sun.

 8. Record notes of time and image numbers, and if avalible safely record distance from camera
 to glint/glare source.

 9. If possible, either take a measurement or a best approximation of a feature in the subject
 image. Note the orientation of this measurment as it will need to be drawn on the subject
 image during processing to produce an ocular hazard estimate.

4.3. Example Workflow: Process Collected Data

This example describes the standard processing workflow: select images, provide user inputs, run
irradiance conversion, review maps/transects, compute ocular hazard, export data. It is
recommended to read through these instructions once in their entirety first for a user who is new to
this tool and workflow.

4.3.1. Step 1: Start a New Session

 1. Launch OcuPHLUX.

 2. (Optional) Use the sidebar Reset control to clear prior settings.

 3. In the User Input tab set the Output Data Directory with the provided button.

 4. (Optional) Use the sidebar Import Session File button to load a previous session’s inputs.

 5. Use the sidebar Processing Options to select which steps of the computation to complete:

 • Primary image processing

 • Ocular hazard estimate

 • Analytical scenarios

 • Output summary information

 • Display instructions during execution

 36

4.3.2. Step 2: Select the Calibration and Subject Images

 1. In the User Input tab, using the Select Sun and Subject Images button select the Sun
 image then Subject image following file prompt titles. If a RAW type image is selected, the
 path displayed will resemble the path to a TIFF style image automatically converted using a
 set formula and the dcraw application. If the ExifTool or dcraw utilities is not on the user’s
 PATH or in the working directory for the OcuPHLUX application, they will be prompted to
 provide a path to the utilities for each image.
 • (Optional) a user may forgo selection of Sun and subject images, and will be prompted
 for their selection when the Run Current Selections button is selected.
 2. If the tool prompts for image selection during execution, follow the dialog to choose the files.

4.3.3. Step 3: Enter Acquisition and Scene Parameters

In the User Input tab:
 1. Enter the Sun filter factor and Subject filter factor.
 2. Enter the Subject reflectivity
 3. Enter the Direct normal irradiance (DNI) (or accept the default if appropriate).
 4. Enter the Subject distance from camera.
 5. Enter the Subject Reference Length for Drawing Step
 6. Choose a Pixel threshold value to exclude background pixels from calculation (optional
 but recommended).
 7. Choose Summary Table Blocks if generating summary information.
 8. Enter parameters for an observer’s eye. Defaults are recommended for these options.
 9. Open the Uncertainty Settings tab and enter standard deviation values for parameters if
 known.

4.3.4. Step 4: (Optional) Enable Photopic Weighting

In the User Input tab:
 1. Select the Color space (RGB or BGR).
 2. Set Apply Photopic Sensitivity Adjustment... to True only if your workflow requires
 photopic-adjusted hazard outputs.
 3. Enter Photopic wavelength boundaries in nm as two increasing values.

 37

4.3.5. Step 5: Run the Primary Processing

 1. Use the sidebar Run Current Selections control to execute the analysis.

 2. If the images are larger than the current display resolution, a series of pop-up windows will
 show image previews so a user can select crop regions for input images.

 3. If executing ocular hazard estimation, an additional pop-up will appear prompting for a user
 to draw either a line or circle on the subject image. The length, or diameter, must represent
 the Subject Reference Length for Drawing Step input.

 a) Draw the reference annotation: Press either "L" for line or "C" for circle on your
 keyboard to switch between drawing modes. To draw, click and hold the left mouse
 button and drag the cursor. For a line, the initial click sets the starting point and the
 release sets the end point. For a circle, the initial click sets the center and the release
 sets the radius.

 • a line for a known length, or

 • a circle for a known diameter,

 b) Press the spacebar, enter, escape, or "Q" key to exit this prompt after drawing.

 4. Review the Warnings and Output Messages tab for:

 • saturated pixel warnings,

 • missing/invalid field formatting,

 • and any other generated notes for the user.

4.3.6. Step 6: Review Irradiance Maps and Transects

 1. Open the Flux Maps and Transects tab.

 2. Use the plot selection control to switch between between nominal and uncertainty bounds.

 3. Use the Generate Plots button to generate the current selection’s plot. A selection of 18
 plots may be retained for rapid tab or dropdown menu selection switching for comparison.

 4. Use the sidebar transect row/column inputs and the Update Transect Data button to
 inspect specific rows/columns through the computed maps.

 38

4.3.7. Step 7: Review Ocular Hazard Outputs

 1. Open the Ocular Hazard tab.
 2. Use the Generate Plots button to generate the current selection’s plot. A selection of 18
 plots may be retained for rapid tab or dropdown menu selection switching for comparison.
 3. Review per-channel hazard results and compare to the hazard legend in Section 1.5.
 4. If results appear inconsistent with expectations, review input selections but in particular:
 • correct filter factors,
 • subject reflectivity estimate,
 • correct camera-to-subject distance,
 • correct reference length and annotation,
 • observer eye parameters,
 • and absence of significant saturation in the Sun image.

4.3.8. Step 8: Export Results and Save the Session

 1. While viewing a set of generated plots, use the sidebar Save Displayed Data button to
 export plots/data in view for the current tab.
 2. Check the Output Data Directory for populated results.
 3. Use the Export Session File button to save a json file with all settings required to reproduce
 the current analysis.

4.4. Example Workflow: Run an Analytical Reference Scenario

Note that the analytical scenarios are independent of other settings and can be run independently
if only the sidebar checkbox Analytical Estimates is checked.
 1. Open the Analytical Input tab.
 2. Enter Analytical Settings: General (Observer Horizontal Distance from Source, DNI, etc...).
 3. Populate scenario inputs:
 • Diffuse: height, reflectivity list, power/area terms, visible area.
 • Point focus: specular reflectivity list, Sun size, divergence pad, mirror geometry, focal
 length list.
 • Line focus: specular reflectivity list, Sun size, divergence pad, aperture, focal length
 list.

4. Open the Analytical Plots tab and use the Generate Plots button to generate the current
 plotting dropdown menu selection plots. Toggle the dropdown menu between the Cornea
 Irradiance and Ocular Hazard selections for different views of the calculated data.
5. Interpret hazard-coded results using Section 1.5.
