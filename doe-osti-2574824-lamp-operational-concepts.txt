Executive Summary
This brief report describes the major operational changes resulting from accelerator design and
implementation of the LAMP scope. Improvements in operational performance are discussed, along with
implications for integration with the existing LANSCE accelerator complex. Potential impacts to the
present LANSCE operational modes and integration with the existing personnel and machine protection
systems are also discussed.

1 Introduction
The LAMP scope of work introduces several major changes in accelerator technology to the front end of
the LANSCE accelerator, replacing the ageing Cockcroft-Walton (CW) injectors and associated beam
transport sections with new ion sources and low-energy beam transports, a Radio Frequency Quadrupole
(RFQ) accelerator and medium-energy transport line, and a new modern state-of-the-art drift-tube linac
(DTL).
As a result of these upgrades, there are several potentially required changes to the operations of the
LANSCE accelerator which may include modifications to the present accelerator operational modes.
Additionally, these new systems require integration with the existing LANSCE machine and personnel
protection systems, including the Personnel Protection System, the Run Permit System and the Fast Protect
System. In most cases this integration will require both software and controls modifications, and hardware
modifications of detector and monitoring hardware, as well as potentially safety-rated equipment such as
safety-rated beam plugs.
This report briefly summarizes an initial look at potential operational changes due to the present LAMP
preconceptual project scope. The content of this report may be useful in highlighting any additional project
scope needed to ensure successful implementation and integration of the project scope with the LANSCE
accelerator complex.

2 LAMP Scope and Impact
In addition to improving operational reliability, LAMP modernization of the front-end accelerator
technology should improve operations:
 • SNS-type H- ion source – increases H- beam current; extends source lifetime to 4 Months (99.9%
 availability); reduces Cesium handling requirements, results in significantly reducing source
 recycle and recovery tuning times, higher reliability, and higher availability.
 • RFQ accelerator replaces Cockcroft-Waltons – eliminates obsolete systems and hard-to-find
 components; RF system vs HV electrostatic eliminates susceptibility to weather/humidity changes
 and arc downs; eliminates SF6 use; expect shorter conditioning at start-up.
 • New 6-tank DTL replaces electromagnetic quadrupoles with permanent magnet quadrupoles –
 eliminates 12 magnet power supplies (90 shunts); eliminates need to set DTL magnet gradients
 during start-up. However, there are still matching quadrupoles between DTL tanks.
The greatest potential positive impact on beam availability to the average LANSCE run cycle is the
implementation of a new H- ion source:
 • At present there are an average of 9 H- ion source recycles per run cycle. With the new type of ion
 source, this is reduced to ~2 source recycles per run cycle.
 − Each source recycle = 72 hrs + 40 hrs tune recovery = 112 hrs total
 − 7 recycles x 112 hrs / recycle = 784 hrs!
 − Potential increase in total beam hours per run cycle: 3700 hrs + 784 hrs = 4284 hrs
 − The H+ ion source is highly reliable and has a very long lifetime (> 6 months); the H - ion
 source is currently the operational bottleneck.

It should be noted that any additional unaccounted reduction in source recycle and tune recovery times,
front-end conditioning, or improvements in system reliability potentially further increases additional beam
time to users. RFQ Test Stand operations during the project technology maturation should inform front-end
conditioning and improve start-up. Additionally, maintenance of other systems that may impact these
potential gains in beam delivery should be evaluated.

reliable and more capable like-for-like functional replacement for the first 100 MeV of the LANSCE
accelerator.

3 LANSCE Operating Modes
Implementation of the LAMP scope requires preserving the present LANSCE operating modes. These
operating modes are described below:

 • 01BL MODE – allows use of the entire low-energy beam transport, using either H+ or H−.

 • 211 MEV MODE and IPBL MODE – used for tuning either H+ or H− through the drift-tube
 LINAC, the transition region, and into the upstream end of the side-coupled LINAC.

 • IPF Target MODE (either for tuning or production) – is the mode in which H+ beam is delivered
 to the IPF target station.

 • 800 MeV MODE – allows delivery of H+ or H− beams through the side-coupled LINAC into the
 switchyard, where the particle beam impacts a stationary beam stop.

 • Line X/B-C MODE – Line X/B-C Mode allows delivery of H− beam down Line X to either the
 2X beam stop or into either Line B to the ultracold neutron (UCN) target or Line C through the
 proton radiography experimental area into the Line C beam stop.

 • Line D and PSR Beam Delivery MODE – allows delivery of tuning level H− beam to the PSR.
 Beam impacts either the ring injection beam stop or the tune-up beam stop.

 • Line D or PSR to WNR MODE – allows delivery of tuning or production level beam to the WNR
 facility, either to Target 2 or Target 4.

 • Line D or PSR to 1L Target MODE – allows delivery of tuning or production level beam to the
 1L Target for the Lujan Center.

Figure 2 shows a flow chart of the LANSCE beam delivery modes for both H+ and H- beam delivery. It
should be noted that at present, the 01BL Mode is common to both H+/H-, the 211-MeV Mode is also
common to H+/H- but only required for H- now since no H+ beam is accelerated beyond the Isotope
Production Facility (IPF) at 100 MeV, and only the H- beam can be directed to SY Direct mode (800
MeV). Currently the Accelerator Operations Manual (AOM) and associated operations checklists only
include H- to 800 MeV. These will need to be updated and reauthorized in the future for 800 MeV H+
beam delivery to Area A (Line A) or Line C/Proton Radiography. There are currently also some special
modes like 40 MeV mode that will change due to new DTL tank energy breakpoints resulting from the
LAMP DTL replacement.

Since there will be changes in the injector and beamline topology due to LAMP, some changes in
operating modes will be required. However, these changes should be very modest and occur only before
beam injection at 3 MeV into the new DTL. Table 1 summarizes the present operational modes and
highlights the modest changes required. Figure 3 indicates the two proposed new operational modes. The
new Injector/LEBT mode allows 100-keV beam delivery to a Faraday cup or beam stop at low duty factor
for tuning. This mode will also be used to characterize and tune either the H+ or H- ion sources and
transport lines – this mode includes intermediate beam stops and diagnostics for each injector. It also
allows for characterization and enables beam matching into the RFQ of either a single beam or both
beams simultaneously. This mode will require Faraday cups, emittance scanners and other diagnostics
capability in the transport lines.

The MEBT/01BL mode allows 3-MeV beam delivery to a beam stop in the MEBT at low duty factor for
tuning. This mode will be used to characterize and tune either the H+ or H- beam from the RFQ using the
MEBT magnets, chopper, and bunchers for beam matching into the DTL of either a single beam or both
beams simultaneously. This mode will require a beam stop, emittance scanners and other diagnostics
capability. An alternative to be considered would be to drift the beam through the first DTL tank to an
inter-tank beam stop. Diagnostics placement and tuning should be modeled for both new modes.

4 Personnel Safety System and Machine Protection
The new LAMP front-end configuration may require a new Radiation Safety System (RSS)-rated beam
plug to maintain the current level of personnel safety for entry into the accelerator tunnel during various
beam operations. These beam plugs are used to protect personnel working downstream during tuning
operations and during corrective maintenance. Figure 4 shows the beam plug configurations required for
entry into exclusion areas. Also highlighted in the figure are the beam plugs potentially impacted by the
LAMP project scope. Figure 4 is taken from the Standard and Report for Primary Beam Plugs Used in
RSS, January 9, 2004. This document defines the standards and requirements for this critical personnel
safety system. Figure 5 shows all the RSS-rated beam plugs at LANSCE and their locations.

The 01BL02 and 03 beam plugs are part of the system ready to interrupt beam upstream of the linac if the
RSS indicates a fault condition anywhere downstream. These plugs are specially designed for rapid
insertion and are regularly tested. The interrupt feature could alternatively be provided by switching off
the last Transport D (TD) bending magnet (for the new LAMP configuration this could be implemented
by using the LEBT bending magnet which combines the two beam species; a potential operations issue
might be reproducibility due to magnet hysteresis). Fusible beam plugs are used as a last resort to prevent
a potentially lethal radiation dose to workers in the event of a beam on event with workers in the tunnel.
Besides insertion into the beam line by the operators to set up a particular operational configuration as
shown in Fig. 4; the fusible beam plugs are also activated by the SCRAM buttons located in the tunnel.

New or modified RSS-rated beam plugs will be required either in the 2-beam section of the LEBT or in
the MEBT before, the DTL. The project should include the design and integration of this required safety
system at either 100 keV or 3 MeV. Integration with the 100-MeV beam plugs will also be required.

The new LAMP Front End will also need to be integrated into the Active Controls Interlock Systems at
LANSCE. These systems are machine protection systems used to prevent machine damage from errant
beam spill and to limit activation for hands-on maintenance. The Active Controls Interlock Systems
include the Run Permit (RP) System and the Fast Protect (FP) System. Figure 6 shows the hierarchy and
response times for the PSS, RP and FP systems.

Figure 6 Personnel and Machine Protection systems hierarchy at LANSCE.

 The RP system is used to establish and monitor specific equipment configurations for accelerator
 operations. The status of the equipment configuration is monitored in real time by checking the state
 of each system in the configuration (on/off, parameter setpoints and ranges). A specific operational
 configuration is established (RP ready) prior to operations with beam.

 The FP system mitigates beam-induced damage and activation from excessive beam spill. Losses are
 limited to <1 nA/m. A system fault interrupts the beam gate to the injector on a pulse-by-pulse basis
 to limit the output beam current. Automatic resumption of beam delivery occurs after the fault
 condition is cleared. The FP system monitors: Injector high-voltages and currents, beam deflectors,
 servo-lock on RF systems (trip levels at ± 1° phase, ± 1% amplitude), guard rings, activation
 protection (scintillating detectors, ion chambers, etc.), beam permit states, radiation monitoring &
 protection system states, magnet current set-points, and integrated beam transmission losses (~100
 nA).

 Implementation and integration of machine protection needs to be part of the LAMP scope. This
 includes developing/specify machine protection hardware implementation for the two new injectors.
 Most likely the existing hardware will need to be modified or replaced (100 keV vs 750 keV).
 Implementation may not be identical to the current implementation but must meet similar response
 time and timing requirements. Also, controls interfacing and integration requirements with the
 existing Fast Protect and Run Permit systems will need to be defined in coordination with specifying
 a complete set of instrumentation and diagnostics for the new front end.

5 Other Related Operational Issues to Consider
 • Maintenance of other systems will need to be re-evaluated to take advantage of the higher
 reliability/availability of the new front end.

 • Integration of the new front end with the 100-MeV Transition Region (TR) and Isotope
 Production Facility (IPF) will be critical for the operational success of LAMP.

 • Start-up parameters will need to be determined for the new front end – pulse length, repetition
 rate, etc. (150 µs @ 4 Hz, is typical for diagnostics during turn on). These should become part of
 the project commissioning and transition to operations plans.

 • Progressive start-up for both beams may need to be optimized – for example, starting up with one
 beam vs the other may prove to be more effective. This will need to be understood during
 integrated testing and commissioning.

6 Conclusions
This brief report describes the major operational changes resulting from accelerator design and
implementation of the LAMP scope. Improvements in operational performance resulting primarily from
implementation of an SNS-like H- ions source and injector system were discussed. Successful
implementation of this LAMP scope could significantly increase beam time to the users by many hundreds
of hours. However, the main purpose of this report was to create awareness within LAMP of potential
operational issues that may increase the project scope, and are necessary for project success, but that may
not have been previously considered in the very early stages of the project. Operational issues that were
found to potentially impact on the project include the LANSCE operational modes where modest changes
are required, and integration with the existing personnel and machine protection systems which may require
some beam plug and/or controls modifications. Some details of the expected changes required have been
outlined and may be used as a starting point for more detailed scope development. Finally, this report is
most likely not complete. Therefore, it is recommended that further consideration of operational impacts
continue throughout the design and planning phases of the project.
