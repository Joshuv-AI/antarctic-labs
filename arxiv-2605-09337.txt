Adversary-Robust Learning from Fully Asynchronous Directional Derivative Estimates
Anik Kumar Paul, Nibedita Roy, Nagesh Talagani, Swetha Ganesh, Gugan Thoppe, Alexandre Reiffers-Masson

Abstract
We propose FAR-SIGN (Fully Asynchronous Robust optimization via SIGNed directional projections) for adversary-resilient learning in parameter-server–worker systems. FAR-SIGN achieves robustness through sign-based updates along carefully designed directions and mitigates the resulting bias via a two-timescale mechanism. It admits both first-order and zeroth-order implementations and enables fully asynchronous execution without requiring a private reference dataset at the server. We establish almost-sure convergence of FAR-SIGN to the set of stationary points for smooth, nonconvex objectives. Moreover, we prove the near-optimal rate of O ( n − 1 / 4 + ϵ ) O(n^{-1/4+\epsilon}) in the first-order setting and the standard O ( n − 1 / 6 + ϵ ) O(n^{-1/6+\epsilon}) in the zeroth-order setting, where n n is the iteration count and ϵ > 0 \epsilon>0 can be chosen arbitrarily small. Experiments on MNIST show that FAR-SIGN outperforms robust aggregation-based methods in both accuracy and wall-clock time.

Problem Setup, Proposed R-SIGN Algorithm, and Main Results

We now introduce our distributed-feedback setting and FAR-SIGN, our fully
asynchronous algorithm for adversary-resilient learning in this setting. Using two-timescale averaging and a directional robustness condition, we prove almost-sure
convergence and nonasymptotic rates that closely match the standard first- and
zeroth-order benchmarks.

2.1
Problem Setup

We aim to minimize a smooth, possibly nonconvex objective

f:\mathbb{R}^{d}\to\mathbb{R}
in a parameter-server architecture with
N

workers. The server does not observe gradients or function values directly;
instead, it obtains directional feedback from workers, where a fixed but
unknown subset
\mathcal{A}\subseteq[N]
may be adversarial. Specifically, at each interaction, the server sends a point
x\in\mathbb{R}^{d}
and a
direction
a
to a worker. Honest workers return directional derivative
information, while adversarial workers may return arbitrary values. We study
two honest-worker feedback models. In the
first-order
setting, an honest
worker returns
a^{\top}\widetilde{\nabla}f(x)
, where

\widetilde{\nabla}f(x)
is a stochastic gradient sample. In the

zeroth-order
setting, an honest worker does not access gradients and
instead returns the two-point finite-difference estimate
[\hat{f}(x+\lambda a)-\hat{f}(x-\lambda a)]/(2\lambda),
where
\lambda>0
is the perturbation radius and
\widehat{f}(\cdot)
denotes a
noisy function evaluation. Since
workers may respond at different times, feedback can arrive asynchronously and
may be computed at stale iterates.

This setup is motivated by large-scale learning systems, including
federated and parameter-server deployments, where worker-side feedback may be
delayed and be adversarially corrupted.

2.2
Proposed FAR-SIGN Algorithm

FAR-SIGN’s pseudocode for minimizing a function
f
is presented in Algorithm
1
. Each worker
l
is
assigned a fixed dictionary of directions

A^{(l)}=[a_{1}^{(l)}\;\cdots\;a_{m}^{(l)}]\in\mathbb{R}^{d\times m}
, known to the server. The server maintains an auxiliary variable
y_{n}^{(l)}(i)
for each worker-direction pair
(l,i)
, which tracks a moving average of past directional derivative estimates along
a_{i}^{(l)}
.

FAR-SIGN is event-driven and asynchronous: at the
n
-th update time, the server uses only the estimates currently available from the worker-direction pairs
(l,i)
with
l\in\mathcal{W}_{n}
and
i\in\mathcal{I}_{n}^{(l)}
. These estimates may have
been computed at stale iterates
x_{n-\tau_{n}^{(l)}}
, since the server iterate can change while a worker is computing. Honest workers return either first-order directional derivative estimates or zeroth-order finite-difference estimates, whereas adversarial workers may return arbitrary values. Upon receiving these estimates, the server updates
x_{n}
along the
directions
a_{i}^{(l)}
using
\sign(-y_{n}^{(l)}(i))
, updates the corresponding averages
y_{n}^{(l)}(i)
using
Y_{i}^{(l)}
, and leaves all other auxiliary variables unchanged.

For simplicity, Algorithm
1
is written for the uniform-arrival setting, where every worker-direction pair
(l,i)\in[N]\times[m]
is equally likely to produce the next available estimate. Nonuniform arrivals can be handled via inverse-probability weighting in the
x
-update.

Key features.

FAR-SIGN combines event-driven asynchronous updates, signed directional descent, and two-timescale averaging. Event-driven updates allow the server to use the
worker-direction estimates available at the current update time, without waiting for a prescribed round, batch, or quorum, enabling full asynchrony. Signed
directional updates replace robust aggregation and therefore require neither a robust aggregation rule nor a trusted server-side reference dataset; they also
support both first-order directional derivatives and zeroth-order finite-difference estimates. Finally, applying the sign to the moving average
y_{n}^{(l)}(i)
, rather than the raw estimate
Y_{i}^{(l)}
, mitigates sign bias, since generally
\mathbb{E}[\sign(G)]\neq\sign(\mathbb{E}[G])
. Together with the
directional robustness condition below, these ingredients ensure that honest directional information dominates adversarial feedback.

2.3
Main Results: Asymptotic Convergence, and Convergence Rates

We impose the following assumptions throughout.

To obtain explicit constants, we assume that
|\mathcal{W}_{n}|=|\mathcal{I}_{n}^{(l)}|=1
. That is, at each update
n\geq 0
, the estimate of a single randomly chosen worker along a single randomly selected direction
a_{i}^{(l)}
is available. The results extend to other update patterns with suitable modifications of the constants.

Assumption 1

(
Objective function
)
.

The function
f:\mathbb{R}^{d}\to\mathbb{R}
is twice continuously differentiable, coercive, and
L
-smooth, i.e.,
\exists L>0
such that
\left\lVert\nabla f(x)-\nabla f(y)\right\rVert\leq L\left\lVert x-y\right\rVert\quad\forall x,y\in\mathbb{R}^{d}.

We next specify the stochastic model for stale feedback. At each update time

n
, every worker
w\in[N]
has a potential staleness value
\tau_{n}^{(w)}
.
If worker
w
contributes feedback at time
n
, then this feedback is computed
at the stale iterate
x_{n-\tau_{n}^{(w)}}
. Let
\mathcal{F}_{n}
denote the history before
the current responding worker-direction pairs are revealed:

\mathcal{F}_{n}:=\sigma\!\left(\{x_{k},y_{k}^{(w)},\tau_{k}^{(w)}:0\leq k\leq n,\ w\in[N]\}\right).

(1)

Conditional on
\mathcal{F}_{n}
, the responding worker-direction pairs at time
n
are
independent of the fresh oracle noise.

Assumption 2

(
First-order feedback noise
)
.

For every honest worker
w\in[N]
and
n\geq 0
, its noisy gradient estimate at
x_{n-\tau_{n}^{(w)}}
satisfies

\mathbb{E}\!\left[\widetilde{\nabla}f(x_{n-\tau_{n}^{(w)}})\mid\mathcal{F}_{n}\right]\overset{\textnormal{a.s.}}{=}\nabla f(x_{n-\tau_{n}^{(w)}}),\qquad\mathbb{E}\!\left[\left\|\widetilde{\nabla}f(x_{n-\tau_{n}^{(w)}})-\nabla f(x_{n-\tau_{n}^{(w)}})\right\|^{2}\mid\mathcal{F}_{n}\right]\leq\sigma^{2},

for some
\sigma^{2}>0
. The dependence of

\widetilde{\nabla}f(\cdot)
on worker
w
is suppressed for notational
convenience.

Assumption 3

(
Zeroth-order feedback noise
)
.

For every honest worker
w\in[N]
, dictionary direction
a_{i}^{(w)}
with
i\in[m]
, and
n\geq 0
, the noisy function evaluations at
x_{n-\tau_{n}^{(w)}}
satisfy

\displaystyle\widehat{f}(x_{n-\tau_{n}^{(w)}}+\lambda_{n}a_{i}^{(w)})

\displaystyle=f(x_{n-\tau_{n}^{(w)}}+\lambda_{n}a_{i}^{(w)})+\zeta_{n+1}^{(1)},

\displaystyle\widehat{f}(x_{n-\tau_{n}^{(w)}}-\lambda_{n}a_{i}^{(w)})

\displaystyle=f(x_{n-\tau_{n}^{(w)}}-\lambda_{n}a_{i}^{(w)})+\zeta_{n+1}^{(2)}.

Moreover, for
r\in\{1,2\}
, we have
\mathbb{E}\!\left[\zeta_{n+1}^{(r)}\mid\mathcal{F}_{n}\right]\overset{\textnormal{a.s.}}{=}0,
and
\mathbb{E}\!\left[|\zeta_{n+1}^{(r)}|^{2}\mid\mathcal{F}_{n}\right]\leq K

for some
K>0
. The dependence of
\widehat{f}(\cdot)
and the noise variables
on worker
w
is suppressed for notational convenience.

Assumption 4

(
Stepsizes
)
.

The stepsizes
(\alpha_{n})
and
(\beta_{n})
satisfy

\sum_{n}\alpha_{n}=\sum_{n}\beta_{n}=\infty,\qquad\sum_{n}(\alpha_{n}^{2}+\beta_{n}^{2})<\infty,\qquad\frac{\alpha_{n}}{\beta_{n}}\to 0,\qquad\sum_{n}\frac{\alpha_{n}^{2}}{\beta_{n}}<\infty.

For the zeroth-order case, the perturbation lengths
(\lambda_{n})
also
satisfy
\sum\limits_{n}\dfrac{\beta_{n}^{2}}{\lambda_{n}^{2}}<\infty,
and
\sum\limits_{n}\beta_{n}\lambda_{n}<\infty.

Remark 2.1
.

An example of stepsize and perturbation sequences satisfying the above condition is

\alpha_{n}=\frac{1}{(n+1)^{a}},\quad\beta_{n}=\frac{1}{(n+1)^{b}},\quad\text{ and }\lambda_{n}=\frac{1}{(n+1)^{p}},

where
\frac{1}{2}<b<a\leq 1,

b+p>1,

b-p>\frac{1}{2},
and
2a-b>1,
e.g.,
a=0.91,b=0.8,p=0.25.

Assumption 5

(
L^{2}
-dominated staleness
)
.

For each worker
w\in[N]
, the staleness sequence
(\tau_{n}^{(w)})
is
nonnegative and integer-valued. Moreover, there exists a nonnegative random
variable
\tau
with
\mathbb{E}[\tau^{2}]<\infty
such that
\tau_{n}^{(w)}\leq\tau\text{ a.s. for all }n\geq 1,\;w\in[N].

Assumption 6
.

The matrix
A
has full column rank. Moreover, for any subset
S
satisfying
|S|\leq|\mathcal{A}|
,

\sum\limits_{w\in S^{c}}\left\lVert({A^{(w)}})^{\top}x\right\rVert_{1}>\sum\limits_{w\in S}\left\lVert(A^{(w)})^{\top}x\right\rVert_{1}\quad\forall\;x\in\mathbb{R}^{d}\setminus\{0\},

where
S^{c}
denotes the complement of
S
. This condition is agnostic to the objective function
f.

Remark 2.2
.

Assumption
6
holds for several simple and practically relevant observation designs,. Two representative cases are as follows.

1.

Full-coordinate observations.

If
A^{(w)}=\mathbb{I}_{d},
the
d

, then Assumption

holds whenever
|\mathcal{A}|/N<1/2
. This choice reduces FAR-SIGN to a two-timescale variant of stochastic sign-SGD, at an
O(Nd)

2.

Scalar (single-direction) observations.

When each worker uses a single probing direction (
m=1
), Assumption
6
reduces to the robustness condition in
(
18

19
)
. In this case, each
y_{n}^{(w)}
is scalar, yielding an

memory footprint. For example, in the setting with four-workers and one adversarial settworker, the following set of direction matrices from

(Almost-sure convergence)
.

Let

.

Theorem

gives the standard stationarity guarantee
for smooth nonconvex objectives in a setting that combines adversarial workers,

(First-order rate)
.

,

,

, and

\frac{\sum_{k=1}^{n}\alpha_{k}\,\mathbb{E}\|\nabla f(x_{k})\|_{1}}{\sum_{k=1}^{n}\alpha_{k}}\leq Cm^{3/2}N(n+1)^{-1/4+\epsilon}.

Remark 2.6
.

With first-order feedback, FAR-SIGN achieves a near-optimal nonconvex stochastic rate, despite adversarial workers and asynchronous stale feedback.

(Zeroth-order rates)
.

,

,

,

. Then, for some constant

.

FAR-SIGN attains the standard zeroth-order nonconvex rate under independent evaluation noise and recovers the faster rate when the two function evaluations share the same noise.

3
Outline of Proofs of Main Results

We now outline the proofs of our main results, emphasizing the technical ideas
behind FAR-SIGN and how they enable full asynchrony and adversary resilience.
At a high level, the analysis combines two-timescale tracking of stale
directional feedback with a directional robustness condition that guarantees
descent despite adversarial workers. Full details are deferred to the appendix.

3.1
Proof of Theorem
2.3

The proof proceeds in four steps.

Step 1 (Fast-timescale tracking).

The condition
\alpha_{n}/\beta_{n}\to 0
makes
x_{n}
quasi-static from the
perspective of the faster
y
-recursion. Thus, for each honest worker

w\in\mathcal{A}^{c}
,
y_{n}^{(w)}
tracks the moving equilibrium

{A^{(w)}}^{\top}\nabla f(x_{n})
. With

e_{n}^{(w)}:=y_{n}^{(w)}-{A^{(w)}}^{\top}\nabla f(x_{n})
, we prove

\|e_{n}^{(w)}\|\to 0
and

\sum_{n}\alpha_{n}\|e_{n}^{(w)}\|<\infty
a.s. This controls sign bias and provides
the summable error term needed below.

Step 2 (Robust descent).

Conditioning on the current state, the mean slow drift is

\bar{g}_{n}=\sum_{w\in\mathcal{A}}A^{(w)}\xi_{n}^{(w)}+\sum_{w\in\mathcal{A}^{c}}A^{(w)}\sign(-y_{n}^{(w)}),\qquad\xi_{n}^{(w)}\in[-1,1]^{m}.

Write
\bar{g}_{n}=g_{\rm id}(x_{n})+r_{n}
, where
g_{\rm id}(x_{n})
is obtained by
replacing
y_{n}^{(w)}
with
{A^{(w)}}^{\top}\nabla f(x_{n})
for honest workers,
and
r_{n}
is the corresponding tracking-error residual. Assumption
6
,
following the robustness idea from
(
19
)
, gives

\nabla f(x_{n})^{\top}g_{\rm id}(x_{n})\leq-\eta\|\nabla f(x_{n})\|_{1}
for
\eta>0
.
Since
a(\sign(-b)-\sign(-a))\leq 2|a-b|
for
a,b\in\mathbb{R},
we get

\nabla f(x_{n})^{\top}r_{n}\leq 2\sum_{w\in\mathcal{A}^{c}}\|e_{n}^{(w)}\|_{1}
.
Thus, adversaries are controlled by directional robustness, while the residual
is summable by Step 1.

Step 3 (Stability).

Combining the above drift bound with
L
-smoothness yields an
almost-supermartingale inequality for
f(x_{n})
. Since the positive error terms
are summable by Step 1 and Assumption
4
, the
Robbins–Siegmund theorem
(
33
)
implies that

f(x_{n})
converges a.s. Coercivity of
f
then gives almost-sure boundedness of

(x_{n})
.

Step 4 (Limiting stochastic recursive inclusion).

The slow recursion is naturally set-valued because the sign map is
discontinuous at zero and adversaries may choose arbitrary signed directions.
Using boundedness and Step 1, the two-timescale stochastic recursive inclusion
framework of
35
shows that
x_{n}
tracks

\dot{x}(t)\in H(x(t))
, where

H(x)=\left\{\sum_{w\in\mathcal{A}}A^{(w)}\xi^{(w)}+\sum_{w\in\mathcal{A}^{c}}A^{(w)}\lambda^{(w)}:\xi^{(w)}\in[-1,1]^{m},\ \lambda_{j}^{(w)}\in\rm Sign\!\left(-{a_{j}^{(w)}}^{\top}\nabla f(x)\right)\right\},

with
\rm Sign(z)=\{\sign(z)\}
for
z\neq 0
and
\rm Sign(0)=[-1,1]
. We show that

H
is Marchaud and that
f
is a Lyapunov function: Assumption
6

implies
\nabla f(x)^{\top}v\leq-\eta\|\nabla f(x)\|_{1}
for every
v\in H(x)
.
Hence the largest invariant set is contained in

\mathcal{X}^{\star}=\{x:\nabla f(x)=0\}
. The convergence theorem of

35
yields
x_{n}\to\mathcal{X}^{\star}
a.s.

3.2
Outline of Proof of Theorem 2.7

The proof establishes explicit non-asymptotic convergence rates for the zeroth-order setting and proceeds in four steps.

Step 1 (Finite-horizon tracking error)
. We first establish a conditional mean-square bound for the fast-timescale tracking error
e_{n}^{(w)}:=y_{n}^{(w)}-{A^{(w)}}^{\top}\nabla f(x_{n})
. We observe that
\{e_{n}^{(w)}\}
satisfies a linear stochastic approximation recursion, perturbed by a delay element and a bias term of
\mathcal{O}(\alpha_{n})
arising from the time-varying nature of
x_{n}
. Adapting standard stochastic approximation techniques and incorporating the above non-trivialities, we derive the conditional bound
\mathbb{E}[\|e_{n+1}^{(w)}\|^{2}\mid\mathcal{F}_{n}]\leq(1-\beta_{n})\mathbb{E}[\|e_{n}^{(w)}\|^{2}]+R_{n}+\mathbb{E}[D_{n}]
, where
R_{n}=\mathcal{O}\big(\frac{\beta_{n}^{2}}{\lambda_{n}^{2}}+\beta_{n}\lambda_{n}^{2}+\alpha_{n}^{2}+\beta_{n}^{2}+\frac{\alpha_{n}^{2}}{\beta_{n}}\big)
, and the delay component is
D_{n}=\mathcal{O}\big(\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}\big)
(see Proposition
C.1
for the detailed derivation). Using Fubini’s Theorem in Lemma
B.8
, we establish that:
\mathbb{E}[\sum_{k=1}^{n}D_{k}]=\mathcal{O}\big(\mathbb{E}[\tau^{2}]\sum_{k=1}^{n}\alpha_{k}^{2}\big)
.

Step 2 (Tracking Rate)
. Next, by iteratively expanding the above recursion and applying the discrete finite-horizon estimate from Proposition
2
, we obtain in Corollary
C.3
:
\mathbb{E}\big[\|e_{n+1}^{(w)}\|^{2}\big]\leq\widetilde{C}_{1}\,(1+n)^{-\gamma}
, where
\widetilde{C}_{1}>0
is a constant and
\gamma=\min\{b-2p,\,2p,\,2a-b,\,2a-2b\}
.

Step 3 (Ergodic gradient bound)
. We then leverage the standard
L
-smoothness descent lemma. By incorporating the properties of the signed update — following the same approach detailed in Step 2 of Theorem
2.3
— we obtain the inequality:

\displaystyle\mathbb{E}[f(x_{n+1})\mid\mathcal{F}_{n}]\leq{}

\displaystyle f(x_{n})-\alpha_{n}\eta\|\nabla f(x_{n})\|_{1}+2\alpha_{n}|\mathcal{A}^{c}|\|e_{n}^{(w)}\|_{1}+\frac{L}{2}\alpha_{n}^{2}K_{5}^{2}.

A key non-triviality in evaluating this descent is the presence of the two-timescale tracking error term
2\alpha_{n}|\mathcal{A}^{c}|\|e_{n}^{(w)}\|_{1}
. We control this term by transitioning from the
L_{2}
norm bounds established in Step 2 to the expected
L_{1}
norm using Jensen’s inequality (
\mathbb{E}\|e_{k}^{(w)}\|\leq\sqrt{\mathbb{E}\|e_{k}^{(w)}\|^{2}}
) and the norm equivalence (
\|v\|_{1}\leq\sqrt{m}\|v\|_{2}
).

Step 4 (Final Convergence Rate)
. Finally, by taking the total expectation, telescoping the descent inequality over
n
iterations, and dividing by
S_{n}:=\sum_{k=1}^{n}\alpha_{k}
, we obtain the ergodic gradient bound (Corollary
C.6
). Substituting the step-size given in Theorem
2.7
we obtain the desired result.

Numerical Simulation

We empirically evaluate whether FAR-SIGN’s non-buffered signed-directional updates translate into wall-clock gains in adversarial neural-network training.
Our focus is not to benchmark large-scale image classification, but to provide a controlled comparison against Byzantine-resilient zeroth-order robust-aggregation baselines under the same query budget.

(

The data is split randomly across workers.

We evaluate FAR-SIGN against CYBER-0
(

We combine CYBER-0 with buffered execution
(

Each method is run for

For the zeroth-order implementation of FAR-SIGN, we use identity observation matrices,

The worker samples

For each perturbation

Conclusion and Future Work

We proposed FAR-SIGN, a signed directional projection framework for adversary-resilient optimization with both first- and zeroth-order feedback.
FAR-SIGN updates upon individual worker estimate arrivals, requiring neither server-side reference data nor buffering.
Using a two-timescale stochastic recursive inclusion framework, we proved boundedness and almost-sure convergence to stationary points for smooth, potentially nonconvex objectives, and established rates of
O(n^{-1/4+\epsilon})
and
O(n^{-1/6+\epsilon})
in the first- and zeroth-order regimes, respectively.
Our MNIST experiments with
24\%
Byzantine workers show that this non-buffered structure yields
6.2
–
35.2\times
wall-clock speedups over CYBER-0 robust-aggregation baselines while maintaining comparable or better accuracy.

The current work assumes homogeneous worker objectives, with all workers evaluating gradients of the same function
f
. Extending the theory to heterogeneous objectives and evaluating FAR-SIGN on larger architectures and federated benchmarks are important directions for future work.

Proposition A.2
.

Let
\beta_{n}=C_{b}(n+1)^{-b}
with
b\in(0,1)
and let

P_{n}=C_{p}(1+n)^{-p}
for some constants
C>0
and
p>0
. Define

S_{n}:=\sum_{i=0}^{n}\Bigg(\prod_{k=i+1}^{n}(1-\beta_{k})\Bigg)P_{i}.

Then

S_{n}\leq\frac{3C_{p}\,2^{p}(n+1)^{b}}{C_{b}(n+2)^{p}}+o\!\left(\frac{1}{(n+1)^{r}}\right),\qquad\text{for every }r>0.

(2)

Remark A.3
.

The bound in Proposition
A.2
admits the following interpretation.
The leading term is of order

\mathcal{O}\!\left((n+1)^{-(p-b)}\right),

while the remainder term is super-polynomially small, i.e., it decays faster
than any inverse polynomial. Consequently, the estimate separates the dominant
polynomial decay from an exponentially small tail.

Proof.

We start by noting that

\displaystyle\sum_{i=0}^{n}\Bigg(\prod_{k=i+1}^{n}(1-\beta_{k})\Bigg)P_{i}\leq\sum_{i=0}^{n}\exp\!\left(-\sum_{k=i+1}^{n}\beta_{k}\right)\frac{C}{(1+i)^{p}}.

With
\beta_{k}=C_{b}(k+1)^{-b}
and
0<b<1
,

\sum_{k=i+1}^{n}\beta_{k}=C_{b}\sum_{k=i+1}^{n}(k+1)^{-b}\geq C_{b}\frac{n-i}{(n+1)^{b}}.

Hence

\exp\!\Big(-\sum_{k=i+1}^{n}\beta_{k}\Big)\leq\exp\!\Big(-C_{b}\frac{n-i}{(n+1)^{b}}\Big),

and, with the change of variable
m=n-i
,

\displaystyle S_{n}

\displaystyle\leq\sum_{m=0}^{n}\exp\!\Big(-C_{b}\frac{m}{(n+1)^{b}}\Big)\frac{C}{(n-m+1)^{p}}

\displaystyle=\sum_{m=0}^{\lfloor n/2\rfloor}\exp\!\Big(-C_{b}\frac{m}{(n+1)^{b}}\Big)\frac{C}{(n-m+1)^{p}}

\displaystyle+\sum_{m=\lfloor n/2\rfloor+1}^{n}\exp\!\Big(-C_{b}\frac{m}{(n+1)^{b}}\Big)\frac{C}{(n-m+1)^{p}}

\displaystyle=:\mathbf{T}_{1}+\mathbf{T}_{2}.

For
\mathbf{T}_{1}
we have
n-m+1\geq(n+2)/2
, so

\displaystyle\mathbf{T}_{1}

\displaystyle\leq\frac{C\,2^{p}}{(n+2)^{p}}\sum_{m=0}^{\lfloor n/2\rfloor}\exp\!\Big(-C_{b}\frac{m}{(n+1)^{b}}\Big)

\displaystyle\leq\frac{C\,2^{p}}{(n+2)^{p}}\frac{1}{1-\exp\!\big(-C_{b}/(n+1)^{b}\big)}.

Using
1-e^{-x}\geq x/3
for
0<x<1
with
x=C_{b}/(n+1)^{b}
(valid for large
n
), we get

\mathbf{T}_{1}\leq\frac{C\,2^{p}}{(n+2)^{p}}\cdot\frac{3(n+1)^{b}}{C_{b}}\leq\frac{3\cdot 2^{p}}{C_{b}}\,C\,(n+1)^{b-p}.

For
\mathbf{T}_{2}
we have

\displaystyle\sum_{m=\lfloor n/2\rfloor+1}^{n}\exp\!\Big(-C_{b}\frac{m}{(n+1)^{b}}\Big)\frac{C}{(n-m+1)^{p}}

\displaystyle\leq{}

\displaystyle C\sum_{m=\lfloor n/2\rfloor+1}^{n}\exp\!\Big(-C_{b}\frac{m}{(n+1)^{b}}\Big)

\displaystyle={}

\displaystyle C\,\frac{\exp\!\Big(-C_{b}\frac{\lfloor n/2\rfloor+1}{(n+1)^{b}}\Big)\Big(1-\exp\!\big(-C_{b}\frac{n-\lfloor n/2\rfloor}{(n+1)^{b}}\big)\Big)}{1-\exp\!\big(-C_{b}/(n+1)^{b}\big)}

\displaystyle\leq{}

\displaystyle\frac{C\,\exp\!\big(-C_{b}\frac{\tfrac{n}{2}+1}{(n+1)^{b}}\big)}{1-\exp\!\big(-C_{b}/(n+1)^{b}\big)}

\displaystyle\leq{}

\displaystyle\frac{3C\,(n+1)^{b}}{C_{b}}\,\exp\!\Big(-C_{b}\frac{\tfrac{n}{2}+1}{(n+1)^{b}}\Big),

where the last inequality uses
1-e^{-x}\geq x/3
applied with

x=C_{b}/(n+1)^{b}
(valid for large
n
).

Define

A_{n}:=(n+1)^{b}\exp\!\Big(-C_{b}\frac{\tfrac{n}{2}+1}{(n+1)^{b}}\Big).

To show
\mathbf{T}_{2}=o((n+1)^{-r})
for any
r>0
, consider

\ln\!\big((n+1)^{r}A_{n}\big)=(r+b)\ln(n+1)-C_{b}\frac{\tfrac{n}{2}+1}{(n+1)^{b}}.

Since

Appendix B
Proof of Almost Sure Convergence (Theorem
2.3
)

Before proceeding with the proof of Theorem
2.3
, it is convenient to rewrite the algorithmic updates in the framework of a two–time–scale stochastic approximation scheme. This representation will allow us to clearly separate the dynamics of the local variables from that of the global iterate.

In particular, the local variable corresponding to each worker
w
evolves on the slower time scale. Its update can be written as

y_{n+1}^{(w)}=y_{n}^{(w)}+\beta_{n}\,\widetilde{h}^{(w)}(n),

(3)

where
\{\beta_{n}\}
denotes the associated step–size sequence.

On the other hand, the global iterate
x_{n}
evolves on the faster time scale and is updated according to

x_{n+1}=x_{n}+\alpha_{n}\,\widetilde{g}(n),

(4)

where
\{\alpha_{n}\}
is the corresponding step–size sequence.

The quantities
\widetilde{h}^{(w)}(n)
and
\widetilde{g}(n)
capture the effective increments in the slow and fast time scales, respectively. Using Algorithm
1
, we now make these expressions explicit under the different settings considered in this work.

Asynchronous setting.

In the asynchronous regime, at each iteration only one worker
l\in[N]
and one coordinate
i\in[m]
are selected. Consequently, the update affects only a single component of a single worker. This leads to

\widetilde{h}^{(w)}(n)(j)=mN\bigl[\,Y_{n+1}^{(w)}(j)-y_{n}^{(w)}(j)\,\bigr]\mathbf{1}_{\{j=i\}}\mathbf{1}_{\{w=l\}},

(5)

where the indicator functions ensure that only the selected coordinate and worker are updated.

The corresponding fast time scale update is given by

\widetilde{g}(n)=Nm\,a_{i}^{(l)}\,\mathrm{sign}\!\bigl(-y_{n}^{(l)}(i)\bigr),

(6)

where
l
and
i
denote the randomly selected worker and coordinate, respectively.

Oracle models.

We now specify how the quantities
Y_{n+1}^{(w)}(j)
are obtained under different oracle models.

First–order case.

In the first–order setting, the oracle provides (possibly noisy) gradient information, and we have

Y_{n+1}^{(w)}(j)={a_{j}^{(w)}}^{\top}\widetilde{\nabla}f(x_{n-\tau_{n}^{(w)}}).

(7)

Note that the delayed gradient satisfies Assumption
2
.

Zeroth–order case.

In the zeroth–order setting, gradient information is approximated using finite differences. Specifically,

Y_{n+1}^{(w)}(j)=\frac{\widehat{f}(x_{n-\tau_{n}^{(w)}}+\lambda_{n}a_{j}^{(w)})-\widehat{f}(x_{n-\tau_{n}^{(w)}}-\lambda_{n}a_{j}^{(w)})}{2\lambda_{n}}.

(8)

The oracle evaluations are corrupted by additive noise. In particular,

\widehat{f}(x_{n-\tau_{n}^{(w)}}+\lambda_{n}a_{i}^{(w)})=f(x_{n-\tau_{n}^{(w)}}+\lambda_{n}a_{i}^{(w)})+\zeta_{n+1}^{(1)},

\widehat{f}(x_{n-\tau_{n}^{(w)}}-\lambda_{n}a_{i}^{(w)})=f(x_{n-\tau_{n}^{(w)}}-\lambda_{n}a_{i}^{(w)})+\zeta_{n+1}^{(2)}.

Here,
\{\zeta_{n}^{(1)}\}
and
\{\zeta_{n}^{(2)}\}
are martingale difference sequences with respect to the filtration

\mathcal{F}_{n}:=\sigma\!\bigl(x_{k},y_{k}^{(l)},\zeta_{k}^{(1)},\zeta_{k}^{(2)},\tau_{k}^{(l)}\,:\,k\leq n,\,l\in[N]\bigr).

Moreover, there exists a constant
\mathrm{K}>0
such that

\mathbb{E}\!\left[\|\zeta_{n+1}^{(i)}\|^{2}\mid\mathcal{F}_{n}\right]\leq\mathrm{K},\qquad i\in\{1,2\},\;n\geq 0.

Properties of Drift Term for First-Order Setting

Lemma B.1
.

For any honest worker
w\in[N]
, the following statements hold.

(a)

The conditional expectation of
\widetilde{h}^{(w)}(n)
satisfies

\mathbb{E}\!\left[\widetilde{h}^{(w)}(n)\,\big|\,\mathcal{F}_{n}\right]={A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}^{(w)}.

(b)

The second moment admits the bound

\mathbb{E}\!\left[\left\lVert\widetilde{h}^{(w)}(n)\right\rVert^{2}\,\big|\,\mathcal{F}_{n}\right]\;\leq\;2mN\,\left\lVert{A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}^{(w)}\right\rVert^{2}+2mN\bar{A}^{2}\sigma^{2}.

Proof.

The proof of (a) is straightforward under the assumption
2
.

proof of (b)

\displaystyle\mathbb{E}\!\left[\big\|\widetilde{h}^{(w)}(n)\big\|^{2}\,\big|\,\mathcal{F}_{n}\right]

\displaystyle=mN\,\mathbb{E}\!\left[\big\|Y_{n+1}^{(w)}-y_{n}^{(w)}\big\|^{2}\,\big|\,\mathcal{F}_{n}\right].

(9)

Next, we add and subtract
{A^{(w)}}^{\top}\nabla f(x_{n})
inside the
norm and apply the inequality
\|u+v\|^{2}\leq 2\|u\|^{2}+2\|v\|^{2}
, which

\displaystyle\mathbb{E}\!\left[\big\|Y_{n+1}^{(w)}-y_{n}^{(w)}\big\|^{2}\,\big|\,\mathcal{F}_{n}\right]

\displaystyle\leq 2\big\|{A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}^{(w)}\big\|^{2}

(10)

\displaystyle+2\,\mathbb{E}\!\left[\big\|{A^{(w)}}^{\top}\widetilde{\nabla}f(x_{n-\tau_{n}^{(w)}})-{A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})\big\|^{2}\,\big|\,\mathcal{F}_{n}\right].

In view of Assumption

we obtain

\mathbb{E}\!\left[\big\|\widetilde{h}^{(w)}(n)\big\|^{2}\,\big|\,\mathcal{F}_{n}\right]\leq 2mN\big\|{A^{(w)}}^{\top}\nabla f(x_{n})-y_{n}^{(w)}\big\|^{2}+2mN\bar{A}^{2}\sigma^{2},

.

\widetilde{h}^{(w)}(n)
satisfies

\mathbb{E}\!\left[\widetilde{h}^{(w)}(n)\,\big|\,\mathcal{F}_{n}\right]={A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}^{(w)}+\mathrm{B}(n),

where the bias term
\mathrm{B}(n)
obeys the bound

\left\lVert\mathrm{B}(n)\right\rVert_{\infty}\leq L\lambda_{n}\bar{A}^{2}.

(b)

The second moment admits the bound

\mathbb{E}\!\left[\left\lVert\widetilde{h}^{(w)}(n)\right\rVert^{2}\,\big|\,\mathcal{F}_{n}\right]\;\leq\;2mN\,\left\lVert{A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}^{(w)}\right\rVert^{2}+\frac{Km}{\lambda_{n}^{2}}.

Proof.

Proof of (a)

We begin by introducing the filtration
\mathcal{G}_{n}
, defined as

\mathcal{G}_{n}=\sigma\Big(\{x_{k}\},\{y_{k}\},\{\zeta_{k+1}^{(1)}\},\{\zeta_{k+1}^{(2)}\},\{\tau_{k}^{(w)}\}\;\;\big|\;\;0\leq k\leq n,\;w\in[N]\Big).

This filtration captures the entire history of the iterates, delays, and noise realizations up to time
n
.

For any honest worker
w
and any coordinate
j\in[d]
, we now evaluate the conditional expectation of
\widetilde{h}^{(w)}(n)(j)
. We write

\begin{split}\mathbb{E}\!\left[\widetilde{h}^{(w)}(n)(j)\,\big|\,\mathcal{F}_{n}\right]&\overset{(a)}{=}\mathbb{E}\!\left[\mathbb{E}\!\left[\widetilde{h}^{(w)}(n)(j)\,\big|\,\mathcal{G}_{n}\right]\,\big|\,\mathcal{F}_{n}\right]\\
&\overset{(b)}{=}\mathbb{E}\!\left[Y_{n+1}^{(w)}(j)-y_{n}^{(w)}(j)\,\big|\,\mathcal{F}_{n}\right]\\
&\overset{(c)}{=}\frac{f\!\left(x_{n-\tau_{n}^{(w)}}+\lambda_{n}a_{j}^{(w)}\right)-f\!\left(x_{n-\tau_{n}^{(w)}}-\lambda_{n}a_{j}^{(w)}\right)}{2\lambda_{n}}-y_{n}^{(w)}(j),\end{split}

(11)

Step (a) follows directly from the tower property of conditional expectation.

To establish step (b), we compute the inner conditional expectation explicitly:

\begin{split}\mathbb{E}\!\left[\widetilde{h}^{(w)}(n)(j)\,\big|\,\mathcal{G}_{n}\right]&=\mathbb{E}\!\left[mN\big(Y_{n+1}^{(w)}(j)-y_{n}^{(w)}(j)\big)\mathbf{1}_{\{j=i\}}\mathbf{1}_{\{w=l\}}\,\big|\,\mathcal{G}_{n}\right]\\
&\overset{(1)}{=}mN\big(Y_{n+1}^{(w)}(j)-y_{n}^{(w)}(j)\big)\mathbb{E}\!\left[\mathbf{1}_{\{j=i\}}\mathbf{1}_{\{w=l\}}\,\big|\,\mathcal{G}_{n}\right]\\
&\overset{(2)}{=}mN\big(Y_{n+1}^{(w)}(j)-y_{n}^{(w)}(j)\big)\mathbb{E}\!\left[\mathbf{1}_{\{j=i\}}\mathbf{1}_{\{w=l\}}\right]\\
&\overset{(3)}{=}Y_{n+1}^{(w)}(j)-y_{n}^{(w)}(j).\end{split}

Here, step (1) uses the fact that
Y_{n+1}^{(w)}(j)-y_{n}^{(w)}(j)
is
\mathcal{G}_{n}
–measurable.
Step (2) follows from the independence of the random selections
i
and
l
from
\mathcal{G}_{n}
.
Step (3) uses the identity

\mathbb{E}\!\left[\mathbf{1}_{\{j=i\}}\mathbf{1}_{\{w=l\}}\right]=\frac{1}{mN}.

Finally, step (c) is obtained by substituting the definition of
Y_{n+1}^{(w)}(j)
in the zeroth–order oracle model, together with the martingale difference property of the noise.

Next, we analyze the expression in (
11
) by applying a second–order expansion of the function
f
along the direction
a_{j}^{(w)}
around the delayed iterate
x_{n-\tau_{n}^{(w)}}
. By the second–order mean value theorem, there exist
\theta_{1},\theta_{2}\in(0,1)
such that

\begin{split}&\frac{f\!\left(x_{n-\tau_{n}^{(w)}}+\lambda_{n}a_{j}^{(w)}\right)-f\!\left(x_{n-\tau_{n}^{(w)}}-\lambda_{n}a_{j}^{(w)}\right)}{2\lambda_{n}}-y_{n}(j)\\
&=\frac{1}{2\lambda_{n}}\Big[\big(f(x_{n-\tau_{n}^{(w)}})+\lambda_{n}\langle\nabla f(x_{n-\tau_{n}^{(w)}}),a_{j}^{(w)}\rangle+\lambda_{n}^{2}\langle a_{j}^{(w)},\nabla^{2}f(x_{n-\tau_{n}^{(w)}}+\theta_{1}\lambda_{n}a_{j}^{(w)})a_{j}^{(w)}\rangle\big)\\
&\qquad\qquad-\big(f(x_{n-\tau_{n}^{(w)}})-\lambda_{n}\langle\nabla f(x_{n-\tau_{n}^{(w)}}),a_{j}^{(w)}\rangle+\lambda_{n}^{2}\langle a_{j}^{(w)},\nabla^{2}f(x_{n-\tau_{n}^{(w)}}-\theta_{2}\lambda_{n}a_{j}^{(w)})a_{j}^{(w)}\rangle\big)\Big]\\
&\qquad-y_{n}(j).\end{split}

(12)

We now simplify the expression. The zeroth–order terms cancel, and the first–order terms combine as

\frac{1}{2\lambda_{n}}\cdot 2\lambda_{n}\langle\nabla f(x_{n-\tau_{n}^{(w)}}),a_{j}^{(w)}\rangle={a_{j}^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}}).

The remaining second–order terms give rise to a bias term. Therefore,

\frac{f\!\left(x_{n-\tau_{n}^{(w)}}+\lambda_{n}a_{j}^{(w)}\right)-f\!\left(x_{n-\tau_{n}^{(w)}}-\lambda_{n}a_{j}^{(w)}\right)}{2\lambda_{n}}-y_{n}(j)={a_{j}^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}(j)+B(n),

where the bias term
B(n)
is defined as

\begin{split}B(n)=\frac{\lambda_{n}}{2}\Big(\langle a_{j}^{(w)},\nabla^{2}f(x_{n-\tau_{n}^{(w)}}+\theta_{1}\lambda_{n}a_{j}^{(w)})a_{j}^{(w)}\rangle+\langle a_{j}^{(w)},\nabla^{2}f(x_{n-\tau_{n}^{(w)}}-\theta_{2}\lambda_{n}a_{j}^{(w)})a_{j}^{(w)}\rangle\Big).\end{split}

Finally, under the assumption that
\nabla f
is Lipschitz continuous with constant
L
, the Hessian is bounded in operator norm by
L
. Hence, we obtain

|B(n)|\;\leq\;L\lambda_{n}\bar{A}^{2},

where
\bar{A}
is an upper bound on
\|a_{j}^{(w)}\|
.

Proof of (b)

We begin by expanding the squared norm coordinate-wise:

\mathbb{E}\!\left[\left\lVert\widetilde{h}^{(w)}(n)\right\rVert^{2}\,\big|\,\mathcal{F}_{n}\right]=\sum_{j=1}^{m}\mathbb{E}\!\left[\big(\widetilde{h}^{(w)}(n)(j)\big)^{2}\,\big|\,\mathcal{F}_{n}\right].

Thus, it suffices to obtain an upper bound on each coordinate term

\mathbb{E}\!\left[\big(\widetilde{h}^{(w)}(n)(j)\big)^{2}\,\big|\,\mathcal{F}_{n}\right]
.

Using the tower property of conditional expectation, we write

\begin{split}&\mathbb{E}\!\left[\big(\widetilde{h}^{(w)}(n)(j)\big)^{2}\,\big|\,\mathcal{F}_{n}\right]\\
&=\mathbb{E}\!\left[\mathbb{E}\!\left[\big(\widetilde{h}^{(w)}(n)(j)\big)^{2}\,\big|\,\mathcal{G}_{n}\right]\,\Big|\,\mathcal{F}_{n}\right]\\
&\overset{(a)}{=}mN\,\mathbb{E}\!\left[\big(Y_{n+1}^{(w)}(j)-y_{n}^{(w)}(j)\big)^{2}\,\big|\,\mathcal{F}_{n}\right],\end{split}

(13)

where step (a) follows from the definition of
\widetilde{h}^{(w)}(n)
together with the independence of the random coordinate
i\sim U([m])
and the worker index
l\sim U([N])
from
\mathcal{G}_{n}
.

We now bound the squared term. Using the inequality
(a+b)^{2}\leq 2(a^{2}+b^{2})
, we obtain

\begin{split}&\big(Y_{n+1}^{(w)}(j)-y_{n}^{(w)}(j)\big)^{2}\\
&\leq 2\Bigg(\frac{f\!\left(x_{n-\tau_{n}^{(w)}}+\lambda_{n}a_{j}^{(w)}\right)-f\!\left(x_{n-\tau_{n}^{(w)}}-\lambda_{n}a_{j}^{(w)}\right)}{2\lambda_{n}}-y_{n}^{(w)}(j)\Bigg)^{2}\\
&\quad+\frac{\big(\zeta_{n+1}^{(1)}-\zeta_{n+1}^{(2)}\big)^{2}}{2\lambda_{n}^{2}}.\end{split}

We next bound the expectation of each term separately.

For the first term, using the second–order expansion established in (
12
), we obtain

\begin{split}&\mathbb{E}\!\left[\left(\frac{f\!\left(x_{n-\tau_{n}^{(w)}}+\lambda_{n}a_{j}^{(w)}\right)-f\!\left(x_{n-\tau_{n}^{(w)}}-\lambda_{n}a_{j}^{(w)}\right)}{2\lambda_{n}}-y_{n}^{(w)}(j)\right)^{2}\,\Big|\,\mathcal{F}_{n}\right]\\
&\leq\big({a_{j}^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}^{(w)}(j)\big)^{2}+\mathcal{O}(\lambda_{n}^{2}).\end{split}

(14)

For the second term, under Assumption
3
, we have

\mathbb{E}\!\left[\frac{\left\lVert\zeta_{n+1}^{(1)}-\zeta_{n+1}^{(2)}\right\rVert^{2}}{2\lambda_{n}^{2}}\,\Big|\,\mathcal{F}_{n}\right]\leq\frac{K}{\lambda_{n}^{2}}.

(15)

Substituting the bounds from (
14
) and (
15
) into (
13
), and summing over all coordinates, completes the proof.
∎

Remark B.3
.

Note that when the function evaluation noises are same it can be verified from the Lemma
B.2
that
K=0
.

B.2
Properties of Drift Term for Global Iterates

Lemma B.4
.

The stochastic drift
\widetilde{g}(n)
admits the decomposition

\mathbb{E}\big[\widetilde{g}(n)\mid\mathcal{F}_{n}\big]=g(x_{n},y_{n})+b(x_{n},y_{n}),

where

\displaystyle g(x_{n},y_{n})

\displaystyle=\sum_{w\in\mathcal{A}}A^{(w)}\,\sign\!\big(-y_{n}^{(w)}\big)+\sum_{w\in\mathcal{A}^{c}}A^{(w)}\,\sign\!\big(-{A^{(w)}}^{\top}\nabla f(x_{n})\big),

\displaystyle b(x_{n},y_{n})

\displaystyle=\sum_{w\in\mathcal{A}^{c}}A^{(w)}\,\sign\!\big(-y_{n}^{(w)}\big)-\sum_{w\in\mathcal{A}^{c}}A^{(w)}\,\sign\!\big(-{A^{(w)}}^{\top}\nabla f(x_{n})\big).

Moreover, the iterates satisfy the uniform almost–sure bound

\|\widetilde{g}(n)\|\leq mN\,\bar{A}.

Proof.

At iteration
n
, a worker–coordinate pair
(l,i)
is sampled uniformly from

[N]\times[m]
. By construction, the update takes the form

\widetilde{g}(n)=mN\,a_{i}^{(l)}\,\mathrm{sign}\!\bigl(-y_{n}^{(l)}(i)\bigr).

Taking conditional expectation with respect to
\mathcal{F}_{n}
, and using the independence of
(l,i)
from
\mathcal{F}_{n}
, we obtain

\displaystyle\mathbb{E}\big[\widetilde{g}(n)\mid\mathcal{F}_{n}\big]

\displaystyle=\sum_{w=1}^{N}\sum_{j=1}^{m}a_{j}^{(w)}\,\mathrm{sign}\!\bigl(-y_{n}^{(w)}(j)\bigr).

We now separate the contribution of honest and adversarial workers. Adding and subtracting the term

\sum_{w\in\mathcal{A}^{c}}\sum_{j=1}^{m}a_{j}^{(w)}\,\mathrm{sign}\!\big(-{a_{j}^{(w)}}^{\top}\nabla f(x_{n})\big),

we obtain

\mathbb{E}\big[\widetilde{g}(n)\mid\mathcal{F}_{n}\big]=g(x_{n},y_{n})+b(x_{n},y_{n}),

where
g(x_{n},y_{n})
and
b(x_{n},y_{n})
are defined as above.

Finally, since
\|a_{j}^{(w)}\|\leq\bar{A}
for all
j
and
w
, we have the pointwise bound

\|\widetilde{g}(n)\|=mN\,\|a_{i}^{(l)}\|\leq mN\bar{A},

which completes the proof.
∎

B.3
A Two Time Scale Stochastic Approximation Scheme

We first record several useful properties of the stochastic drift terms

\widetilde{h}^{(w)}(n)
and
\widetilde{g}(n)
that will be used repeatedly in the subsequent analysis.

The conditional expectation of
\widetilde{h}^{(w)}(n)
satisfies

\mathbb{E}\!\left[\widetilde{h}^{(w)}(n)\mid\mathcal{F}_{n}\right]={A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}^{(w)}+B_{n},\qquad\|B_{n}\|_{\ast}\leq K_{1}\lambda_{n},

(16)

where the term
B_{n}
represents the bias introduced by the gradient approximation.

Further, the conditional second moment of

\widetilde{h}^{(w)}(n)
admits the bound

\mathbb{E}\!\left[\|\widetilde{h}^{(w)}(n)\|^{2}\mid\mathcal{F}_{n}\right]\leq K_{2}\left\|{A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}^{(w)}\right\|^{2}+\frac{K_{3}}{\lambda_{n}^{2}}+K_{4}.

(17)

Similarly, the stochastic drift term
\widetilde{g}(n)
satisfies

\mathbb{E}\!\left[\widetilde{g}(n)\mid\mathcal{F}_{n}\right]=g(x_{n},y_{n})+b(x_{n},y_{n}),

(18)

where
b(x_{n},y_{n})
denotes the corresponding bias term. In addition, we have the uniform bound

\|\widetilde{g}(n)\|\leq K_{5}.

(19)

The constants
K_{1},K_{2},K_{3},K_{4},
and
K_{5}
are given in Lemma
B.1
,
Lemma
B.2
and
Lemma
B.4
.

B.4
Proof of Almost Sure Boundedness

In this subsection, we prove the following Theorem.

Theorem B.5

(Boundedness of the Iterate)
.

Suppose that Assumptions
1
,
3
,
4
, hold. Assume further that the stochastic drift terms
satisfy conditions (
16
), (
17
), (
18
), and
(
19
).
Then the following hold:

1.

The iterate sequence
\{x_{n}\}
is almost surely bounded:

\mathbb{P}(\sup\limits_{n\geq 1}\left\lVert x_{n}\right\rVert<\infty)=1.

2.

The iterate sequence
\{y_{n}^{(w)}\}
for each honest worker is also almost surely bounded:

\mathbb{P}(\sup\limits_{n\geq 1}\left\lVert y_{n}^{(w)}\right\rVert<\infty)=1.

The proof strategy for Theorem
B.5
proceeds in two steps.

Proof Strategy

1.

Step 1 (Fast-timescale tracking):
We show that the fast iterate
y_{n}^{(w)}
tracks the directional gradient
{A^{(w)}}^{\top}\nabla f(x_{n})
almost surely. This is achieved by establishing that the squared tracking error
\left\lVert e_{n}^{(w)}\right\rVert^{2}
satisfies an almost supermartingale recursion (Theorem
A.1
), as detailed in Theorem
B.7
. The main non-triviality lies in controlling the bias introduced by the time-varying parameter
x_{n}
and the asynchronous delays. We bound the iterate movement via
\left\lVert x_{n+1}-x_{n}\right\rVert\leq\mathcal{O}(\alpha_{n})
, and handle the delay-induced error using Cauchy-Schwarz:

\left\lVert x_{n-\tau_{n}^{(w)}}-x_{n}\right\rVert^{2}\leq K_{5}^{2}\,\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}.

Lemma
B.8
then ensures this delay perturbation is summable by proving
\sum_{n\geq 1}\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}<\infty
a.s.

2.

Step 2 : Stability of
\mathbf{x_{n}}
We show that the objective suboptimality
f(x_{n})-\inf f(x)
also satisfies an almost supermartingale recursion (Lemma
B.9
). To successfully apply Theorem
A.1
to the objective sequence, we must guarantee that
\sum_{n\geq 1}\alpha_{n}\left\lVert e_{n}^{(w)}\right\rVert_{1}<\infty
almost surely, a crucial summability condition formally proven in Theorem
B.7
. Consequently, we see that
f(x_{n})

converges almost surely.
Finally, since the objective function
f
is coercive, the almost sure convergence of
f(x_{n})
implies that the sequence
\{x_{n}\}
remains almost surely bounded.

Before proceeding we need the following Proposition.

Proposition B.6
.

Fix a worker
w\in\mathcal{A}^{c}
and define

e_{n}^{(w)}:=y_{n}^{(w)}-{A^{(w)}}^{\top}\nabla f(x_{n}).

Then

\begin{split}\mathbb{E}\!\left[\|e_{n+1}^{(w)}\|^{2}\mid\mathcal{F}_{n}\right]\leq\big(1-A_{n}\big)\|e_{n}^{(w)}\|^{2}+B_{n}\|e_{n}^{(w)}\|+C_{n}+D_{n},\end{split}

(20)

where

A_{n}:=2\beta_{n}-c_{2}\beta_{n}-4K_{2}\beta_{n}^{2}-\beta_{n}^{2},\qquad c_{2}>0,

B_{n}:=2\bar{A}LK_{5}\alpha_{n},

C_{n}:=\frac{2K_{3}\beta_{n}^{2}}{\lambda_{n}^{2}}+\frac{\beta_{n}}{c_{2}}K_{1}^{2}\lambda_{n}^{2}+2\alpha_{n}^{2}L^{2}\bar{A}^{2}K_{5}^{2}+2K_{4}\beta_{n}^{2},

and

D_{n}:=4K_{2}L^{2}\bar{A}^{2}K_{5}^{2}\beta_{n}^{2}\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}+L^{2}\bar{A}^{2}K_{5}^{2}\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}.

Proof.

From (
3
), the iterate update for each honest worker
w
is

y_{n+1}^{(w)}=y_{n}^{(w)}+\beta_{n}\tilde{h}^{(w)}(n).

Define the error vector for each worker
w
as

e_{n+1}^{(w)}=y_{n+1}^{(w)}-{A^{(w)}}^{\top}\nabla f(x_{n+1}).

Then we have

\begin{split}\|e_{n+1}^{(w)}\|^{2}&=\Big\|y_{n}^{(w)}+\beta_{n}\widetilde{h}^{(w)}(n)-{A^{(w)}}^{\top}\nabla f(x_{n+1})\Big\|^{2}\\
&=\Big\|y_{n}^{(w)}+\beta_{n}\widetilde{h}^{(w)}(n)-{A^{(w)}}^{\top}\nabla f(x_{n})+{A^{(w)}}^{\top}\nabla f(x_{n})-{A^{(w)}}^{\top}\nabla f(x_{n+1})\Big\|^{2}\\
&=\underbrace{\big\|y_{n}^{(w)}+\beta_{n}\widetilde{h}^{(w)}(n)-{A^{(w)}}^{\top}\nabla f(x_{n})\big\|^{2}}_{(a)}\\
&\quad+\underbrace{\big\|{A^{(w)}}^{\top}\nabla f(x_{n})-{A^{(w)}}^{\top}\nabla f(x_{n+1})\big\|^{2}}_{(b)}\\
&\quad+\underbrace{2\Big(y_{n}^{(w)}+\beta_{n}\widetilde{h}^{(w)}(n)-{A^{(w)}}^{\top}\nabla f(x_{n})\Big)^{\top}{A^{(w)}}^{\top}\big(\nabla f(x_{n})-\nabla f(x_{n+1})\big)}_{(c)}.\end{split}

(21)

Taking conditional expectation with respect to
\mathcal{F}_{n}
on both sides of (
21
), we bound
(a)
,
(b)
, and
(c)
separately.

Bound on the term (a)

Consider term (a). Taking conditional expectation with respect to

\mathcal{F}_{n}
yields

\begin{split}&\mathbb{E}\!\left[\big\|y_{n}^{(w)}+\beta_{n}\widetilde{h}^{(w)}(n)-{A^{(w)}}^{\top}\nabla f(x_{n})\big\|^{2}\,\middle|\,\mathcal{F}_{n}\right]\\[3.00003pt]
\leq{}&\|e_{n}^{(w)}\|^{2}+\underbrace{\beta_{n}^{2}\mathbb{E}\!\left[\|\widetilde{h}^{(w)}(n)\|^{2}\mid\mathcal{F}_{n}\right]}_{(d)}+\underbrace{2\beta_{n}(e_{n}^{(w)})^{\top}\mathbb{E}\!\left[\widetilde{h}^{(w)}(n)\mid\mathcal{F}_{n}\right]}_{(e)}.\end{split}

Bound on the term (e)

\begin{split}&2\beta_{n}(e_{n}^{(w)})^{\top}\mathbb{E}\!\left[\widetilde{h}^{(w)}(n)\mid\mathcal{F}_{n}\right]\\
&=2\beta_{n}(e_{n}^{(w)})^{\top}\big({A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}^{(w)}+B_{n}\big)\\
&\overset{(a)}{=}2\beta_{n}(e_{n}^{(w)})^{\top}\big(-e_{n}^{(w)}+{A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-{A^{(w)}}^{\top}\nabla f(x_{n})+B_{n}\big)\\
&\overset{(b)}{\leq}-2\beta_{n}\left\lVert e_{n}^{(w)}\right\rVert^{2}+\underbrace{2\beta_{n}(e_{n}^{(w)})^{\top}\big({A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-{A^{(w)}}^{\top}\nabla f(x_{n})\big)}_{(f)}\\
&\quad+c_{2}\beta_{n}\left\lVert e_{n}^{(w)}\right\rVert^{2}+\frac{\beta_{n}}{c_{2}}K_{1}^{2}\lambda_{n}^{2}.\end{split}

Step (a) uses

e_{n}^{(w)}=y_{n}^{(w)}-{A^{(w)}}^{\top}\nabla f(x_{n}).

Step (b) follows from

\langle a,b\rangle\leq\frac{c}{2}\|a\|^{2}+\frac{1}{2c}\|b\|^{2},\qquad c>0,

applied to
(e_{n}^{(w)})^{\top}B_{n}
with
c=c_{2}
and
\|B_{n}\|\leq K_{1}\lambda_{n}
.

Bound on the term (f)

Note that

\begin{split}&2\beta_{n}(e_{n}^{(w)})^{\top}\big({A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-{A^{(w)}}^{\top}\nabla f(x_{n})\big)\\
&\leq\beta_{n}^{2}\left\lVert e_{n}^{(w)}\right\rVert^{2}+\left\lVert{A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-{A^{(w)}}^{\top}\nabla f(x_{n})\right\rVert^{2}\\
&\leq\beta_{n}^{2}\left\lVert e_{n}^{(w)}\right\rVert^{2}+L^{2}\bar{A}^{2}\left\lVert x_{n-\tau_{n}^{(w)}}-x_{n}\right\rVert^{2}.\end{split}

(22)

Further, in view of (
4
) we obtain

\begin{split}\left\lVert x_{n-\tau_{n}^{(w)}}-x_{n}\right\rVert&\leq\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}\left\lVert\widetilde{g}(k)\right\rVert\leq K_{5}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}.\end{split}

Using Cauchy–Schwarz
(\sum\limits_{k\geq 1}u_{k}v_{k})^{2}\leq\sum\limits_{k\geq}u_{k}^{2}\sum\limits_{k\geq}u_{k}^{2}
, we obtain

\begin{split}\left\lVert x_{n-\tau_{n}^{(w)}}-x_{n}\right\rVert^{2}&\leq K_{5}^{2}\left(\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}\right)^{2}\leq K_{5}^{2}\,\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}.\end{split}

Bound on the term (d)

\begin{split}&\beta_{n}^{2}\mathbb{E}\!\left[\|\widetilde{h}^{(w)}(n)\|^{2}\mid\mathcal{F}_{n}\right]\\
&\leq\beta_{n}^{2}\Big(K_{2}\left\lVert{A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-y_{n}^{(w)}\right\rVert^{2}+\frac{K_{3}}{\lambda_{n}^{2}}+K_{4}\Big)\\
&\leq\beta_{n}^{2}\Big(2K_{2}\left\lVert{A^{(w)}}^{\top}\nabla f(x_{n-\tau_{n}^{(w)}})-{A^{(w)}}^{\top}\nabla f(x_{n})\right\rVert^{2}+2K_{2}\left\lVert{A^{(w)}}^{\top}\nabla f(x_{n})-y_{n}^{(w)}\right\rVert^{2}\\
&\qquad\qquad+\frac{K_{3}}{\lambda_{n}^{2}}+K_{4}\Big)\\
&\leq\beta_{n}^{2}\Big(2K_{2}L^{2}\bar{A}^{2}\left\lVert x_{n-\tau_{n}^{(w)}}-x_{n}\right\rVert^{2}+2K_{2}\left\lVert e_{n}^{(w)}\right\rVert^{2}+\frac{K_{3}}{\lambda_{n}^{2}}+K_{4}\Big)\\
&\leq\beta_{n}^{2}\Big(2K_{2}L^{2}\bar{A}^{2}K_{5}^{2}\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}+2K_{2}\left\lVert e_{n}^{(w)}\right\rVert^{2}+\frac{K_{3}}{\lambda_{n}^{2}}+K_{4}\Big).\end{split}

Bound on the term (b)

\begin{split}&\|{A^{(w)}}^{\top}\nabla f(x_{n})-{A^{(w)}}^{\top}\nabla f(x_{n+1})\|^{2}\\
&\overset{(a)}{\leq}\left\lVert A^{(w)}\right\rVert^{2}\,\left\lVert\nabla f(x_{n})-\nabla f(x_{n+1})\right\rVert^{2}\\
&\overset{(b)}{\leq}\bar{A}^{2}L^{2}\,\left\lVert x_{n+1}-x_{n}\right\rVert^{2}\\
&\overset{(c)}{\leq}\bar{A}^{2}L^{2}\,\alpha_{n}^{2}K_{5}^{2}.\end{split}

(23)

(a) uses
\|A^{\top}v\|\leq\|A\|\|v\|
.
(b) uses
L
-smoothness.
(c) follows from the explicit form (
4
).

Bound on the term (c)

\begin{split}&2\big(y_{n}^{(w)}+\beta_{n}\widetilde{h}^{(w)}(n)-{A^{(w)}}^{\top}\nabla f(x_{n})\big)^{\top}{A^{(w)}}^{\top}\big(\nabla f(x_{n})-\nabla f(x_{n+1})\big)\\
&=2\big(e_{n}^{(w)}+\beta_{n}\widetilde{h}^{(w)}(n)\big)^{\top}{A^{(w)}}^{\top}\big(\nabla f(x_{n})-\nabla f(x_{n+1})\big)\\
&\leq 2\left\lVert e_{n}^{(w)}\right\rVert\,\left\lVert{A^{(w)}}^{\top}(\nabla f(x_{n})-\nabla f(x_{n+1}))\right\rVert\\
&\quad+\beta_{n}^{2}\left\lVert\widetilde{h}^{(w)}(n)\right\rVert^{2}+\left\lVert{A^{(w)}}^{\top}(\nabla f(x_{n})-\nabla f(x_{n+1}))\right\rVert^{2}\\
&\leq 2\bar{A}L\left\lVert e_{n}^{(w)}\right\rVert\left\lVert x_{n+1}-x_{n}\right\rVert+\beta_{n}^{2}\left\lVert\widetilde{h}^{(w)}(n)\right\rVert^{2}+\bar{A}^{2}L^{2}\left\lVert x_{n+1}-x_{n}\right\rVert^{2}\\
&\leq 2\bar{A}LK_{5}\alpha_{n}\left\lVert e_{n}^{(w)}\right\rVert+\beta_{n}^{2}\left\lVert\widetilde{h}^{(w)}(n)\right\rVert^{2}+\bar{A}^{2}L^{2}K_{5}^{2}\alpha_{n}^{2}.\end{split}

The first inequality is in view of

2ab\leq a^{2}+b^{2},

and the Cauchy-Schwarz
\left\langle a,b\right\rangle\leq\left\lVert a\right\rVert\left\lVert b\right\rVert
. The last inequality follows from (
23
). Combining the bounds for terms (a), (b), and (c) in (
21
) we obtain the result.
∎

In the next theorem, we show that the stochastic error sequence

\{\|e_{n}^{(w)}\|^{2}\}

satisfies an almost supermartingale recursion in the sense of the Robbins–Siegmund theorem. This property allows us to apply the Robbins–Siegmund theorem directly and conclude that

e_{n}^{(w)}\to 0\qquad\text{a.s.}

Theorem B.7
.

1.

For each honest worker
w
, the sequence
\{y_{n}^{(w)}\}
almost surely tracks the true gradient in the sense that

\lim_{n\to\infty}\|y_{n}^{(w)}-{A^{(w)}}^{\top}\nabla f(x_{n})\|=0\qquad\text{a.s.}

2.

For each honest worker
w
, the sequence
\{\alpha_{n}\|e_{n}^{(w)}\|\}
is summable almost surely:

\sum_{n\geq 1}\alpha_{n}\|e_{n}^{(w)}\|<\infty\qquad\text{a.s.}

Proof.

To prove the theorem, we set
c_{2}=1
and rewrite
Proposition
B.6
in the form

\begin{split}\mathbb{E}\!\left[\|e_{n+1}^{(w)}\|^{2}\mid\mathcal{F}_{n}\right]\leq{}&\big(1+K_{2}\beta_{n}^{2}\big)\|e_{n}^{(w)}\|^{2}\\
&\quad+\underbrace{\Big(-\beta_{n}\|e_{n}^{(w)}\|^{2}+2\bar{A}LK_{5}\alpha_{n}\|e_{n}^{(w)}\|\Big)}_{\mathbf{T}_{4}}+C_{n}+D_{n}.\end{split}

(24)

We now analyze the term
\mathbf{T}_{4}
. The first term is negative and provides a stabilizing effect, whereas the second term acts as a perturbation. To make this structure explicit, we complete the square:

\begin{split}&-\beta_{n}\|e_{n}^{(w)}\|^{2}+2\bar{A}LK_{5}\alpha_{n}\|e_{n}^{(w)}|\\[1.99997pt]
={}&-\beta_{n}\Bigg(\|e_{n}^{(w)}\|^{2}-\frac{2\bar{A}LK_{5}\alpha_{n}}{\beta_{n}}\|e_{n}^{(w)}\|+\frac{\bar{A}^{2}L^{2}K_{5}^{2}\alpha_{n}^{2}}{\beta_{n}^{2}}\Bigg)+\frac{\bar{A}^{2}L^{2}K_{5}^{2}\alpha_{n}^{2}}{\beta_{n}}\\[1.99997pt]
={}&-\beta_{n}\Bigg(\|e_{n}^{(w)}\|-\frac{\bar{A}LK_{5}\alpha_{n}}{\beta_{n}}\Bigg)^{2}+\frac{\bar{A}^{2}L^{2}K_{5}^{2}\alpha_{n}^{2}}{\beta_{n}}.\end{split}

(25)

Substituting the above expression into (
24
), we obtain

\begin{split}\mathbb{E}\!\left[\|e_{n+1}^{(w)}\|^{2}\mid\mathcal{F}_{n}\right]\leq{}&\big(1+K_{2}\beta_{n}^{2}\big)\|e_{n}^{(w)}\|^{2}-\beta_{n}\Bigg(\|e_{n}^{(w)}\|-\frac{\bar{A}LK_{5}\alpha_{n}}{\beta_{n}}\Bigg)^{2}\\
&\quad+C_{n}+\frac{\bar{A}^{2}L^{2}K_{5}^{2}\alpha_{n}^{2}}{\beta_{n}}+D_{n}.\end{split}

(26)

Next, observe that Assumption
4
implies

\sum_{n\geq 1}\beta_{n}^{2}<\infty,

and

\sum_{n\geq 1}\left(C_{n}+\frac{\bar{A}^{2}L^{2}K_{5}^{2}\alpha_{n}^{2}}{\beta_{n}}\right)<\infty.

Therefore, in order to verify the hypotheses of
Theorem
A.1
, it remains to establish that

\sum_{n\geq 1}D_{n}<\infty\qquad\text{a.s.}

By the definition of
D_{n}
, this reduces to proving that

\sum\limits_{n\geq 1}\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}<\infty\quad\text{a.s.}.

(27)

However, (
27
) holds in view of Lemma
B.8
.

Therefore, by applying Theorem
A.1
, we obtain:

•

The sequence
\{\|e_{n}^{(w)}\|^{2}\}
converges almost surely to a finite
random variable.

•

Moreover,

\sum_{n\geq 1}\beta_{n}\left(\|e_{n}^{(w)}\|-\frac{L\alpha_{n}K_{5}\bar{A}}{\beta_{n}}\right)^{2}<\infty\qquad\text{a.s.}

(28)

Proof of Statement 1.

Since
\sum_{n\geq 1}\beta_{n}=\infty
, the summability condition in (
28
)
implies that

\liminf_{n\to\infty}\left(\|e_{n}^{(w)}\|-\frac{L\alpha_{n}K_{5}\bar{A}}{\beta_{n}}\right)^{2}=0,

or equivalently,

\liminf_{n\to\infty}\|e_{n}^{(w)}\|=0.

Together with the almost sure convergence of
\|e_{n}^{(w)}\|
to a finite random
variable, this yields

\lim_{n\to\infty}\|e_{n}^{(w)}\|=0\qquad\text{almost surely}.

Proof of Statement -2.

Observe that

0\leq\beta_{n}\Big(\|e_{n}^{(w)}\|-\tfrac{L\alpha_{n}K_{5}\bar{A}}{\beta_{n}}\Big)^{2}.

By the Young–Fenchel inequality,

\alpha_{n}\|e_{n}^{(w)}\|\leq\frac{1}{2}\beta_{n}\|e_{n}^{(w)}\|^{2}+\frac{\alpha_{n}^{2}}{2\beta_{n}}.

Moreover, using the inequality
(a+b)^{2}\leq 2(a^{2}+b^{2})
, we obtain

\begin{split}\beta_{n}\|e_{n}^{(w)}\|^{2}\leq{}&2\beta_{n}\Bigg[\Big(\|e_{n}^{(w)}\|-\frac{L\alpha_{n}K_{5}\bar{A}}{\beta_{n}}\Big)^{2}+\frac{L^{2}K_{5}^{2}\bar{A}^{2}\alpha_{n}^{2}}{\beta_{n}^{2}}\Bigg].\end{split}

Consequently,

\displaystyle\sum_{n\geq 1}\alpha_{n}\|e_{n}^{(w)}\|\leq{}

\displaystyle\sum_{n\geq 1}\frac{1}{2}\beta_{n}\|e_{n}^{(w)}\|^{2}+\frac{\alpha_{n}^{2}}{2\beta_{n}}

\displaystyle\leq{}

\displaystyle\sum_{n\geq 1}\beta_{n}\Big(\|e_{n}^{(w)}\|-\tfrac{L\alpha_{n}K_{5}\bar{A}}{\beta_{n}}\Big)^{2}+\sum_{n\geq 1}\frac{\alpha_{n}^{2}}{2\beta_{n}}\big(1+2L^{2}K_{5}^{2}\bar{A}^{2}\big).

By Assumption
4
, the right-hand side is finite almost surely, which
establishes the claim.
∎

Lemma B.8
.

\mathbb{E}[\sum_{n\geq 1}\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}]\leq\mathbb{E}[\tau^{2}]\sum_{k\geq 1}\alpha_{k}^{2}

Proof.

Consider the nonnegative random series

\sum_{n\geq 1}\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}.

Since all terms are nonnegative, Tonelli’s theorem allows us to interchange the order of expectation and summation. Hence,

\begin{split}&\mathbb{E}\!\left[\sum_{n\geq 1}\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}\right]\\
={}&\mathbb{E}\!\left[\sum_{n\geq 1}\tau_{n}^{(w)}\sum_{k=1}^{\infty}\alpha_{k}^{2}\mathbf{1}_{\{n-\tau_{n}^{(w)}\leq k\leq n-1\}}\right]\\
={}&\sum_{k\geq 1}\alpha_{k}^{2}\sum_{n=k+1}^{\infty}\mathbb{E}\!\left[\tau_{n}^{(w)}\mathbf{1}_{\{\tau_{n}^{(w)}\geq n-k\}}\right].\end{split}

Now introduce the change of variables

m=n-k.

Then

\begin{split}&\sum_{k\geq 1}\alpha_{k}^{2}\sum_{n=k+1}^{\infty}\mathbb{E}\!\left[\tau_{n}^{(w)}\mathbf{1}_{\{\tau_{n}^{(w)}\geq n-k\}}\right]\\
={}&\sum_{k\geq 1}\alpha_{k}^{2}\sum_{m=1}^{\infty}\mathbb{E}\!\left[\tau_{k+m}^{(w)}\mathbf{1}_{\{\tau_{k+m}^{(w)}\geq m\}}\right].\end{split}

By Assumption
5
,

\tau_{n}^{(w)}\leq\tau\qquad\text{a.s.}

for all
n
, where
\tau
is an integer-valued random variable satisfying

\mathbb{E}[\tau^{2}]<\infty.

Therefore,

\begin{split}&\sum_{k\geq 1}\alpha_{k}^{2}\sum_{m=1}^{\infty}\mathbb{E}\!\left[\tau_{k+m}^{(w)}\mathbf{1}_{\{\tau_{k+m}^{(w)}\geq m\}}\right]\\
\leq{}&\sum_{k\geq 1}\alpha_{k}^{2}\,\mathbb{E}\!\left[\tau\sum_{m=1}^{\infty}\mathbf{1}_{\{\tau\geq m\}}\right].\end{split}

Since
\tau
is integer-valued, we have

\sum_{m=1}^{\infty}\mathbf{1}_{\{\tau\geq m\}}=\tau.

Consequently,

\mathbb{E}\!\left[\sum_{n\geq 1}\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}\right]\leq\mathbb{E}[\tau^{2}]\sum_{k\geq 1}\alpha_{k}^{2}<\infty.

Since the random variable

\sum_{n\geq 1}\tau_{n}^{(w)}\sum_{k=n-\tau_{n}^{(w)}}^{n-1}\alpha_{k}^{2}

is nonnegative and has finite expectation, it follows that it is finite almost surely. This completes the proof.
∎

To complete the proof of almost sure boundedness of the iterates
\{x_{n}\}
, it remains to analyze the behavior of the objective sequence
\{f(x_{n})\}
. The next lemma shows that
\{f(x_{n})\}
satisfies an almost supermartingale-type recursion.

Lemma B.9
.

Under Assumptions
1
,
3
, and
6
, the following descent inequality holds:

\displaystyle\mathbb{E}[f(x_{n+1})\mid\mathcal{F}_{n}]\leq f(x_{n})

\displaystyle-\alpha_{n}\eta\|\nabla f(x_{n})\|_{1}+2\alpha_{n}|\mathcal{A}^{c}|\|e_{n}^{(w)}\|_{1}+\frac{L}{2}\alpha_{n}^{2}K_{5}^{2},

where
\eta>0
is a constant.

Proof.

Since
f
is
L
–smooth by Assumption
1
, we have the standard descent inequality

f(x_{n+1})\leq f(x_{n})+\nabla f(x_{n})^{\top}(x_{n+1}-x_{n})+\frac{L}{2}\|x_{n+1}-x_{n}\|^{2}.

(29)

Recall that the global iterate evolves according to

x_{n+1}=x_{n}+\alpha_{n}\widetilde{g}(n).

Substituting this update into (
29
) gives

\begin{split}f(x_{n+1})\leq{}&f(x_{n})+\alpha_{n}\nabla f(x_{n})^{\top}\widetilde{g}(n)+\frac{L}{2}\alpha_{n}^{2}\|\widetilde{g}(n)\|^{2}.\end{split}

Taking conditional expectation with respect to
\mathcal{F}_{n}
, we obtain

\begin{split}\mathbb{E}[f(x_{n+1})\mid\mathcal{F}_{n}]\leq{}&f(x_{n})+\alpha_{n}\nabla f(x_{n})^{\top}\mathbb{E}[\widetilde{g}(n)\mid\mathcal{F}_{n}]\\
&\quad+\frac{L}{2}\alpha_{n}^{2}\mathbb{E}[\|\widetilde{g}(n)\|^{2}\mid\mathcal{F}_{n}].\end{split}

(30)

Next, recall that from Lemma
B.4

\mathbb{E}[\widetilde{g}(n)\mid\mathcal{F}_{n}]=g(x_{n},y_{n})+b(x_{n},y_{n}).

(31)

Substituting (
31
) into (
30
), we obtain

\begin{split}\mathbb{E}[f(x_{n+1})\mid\mathcal{F}_{n}]\leq{}&f(x_{n})+\alpha_{n}\nabla f(x_{n})^{\top}g(x_{n},y_{n})\\
&\quad+\alpha_{n}\nabla f(x_{n})^{\top}b(x_{n},y_{n})+\frac{L}{2}\alpha_{n}^{2}K_{5}^{2}.\end{split}

We now estimate the two drift terms separately.

Step 1: Bound on
\nabla f(x_{n})^{\top}g(x_{n},y_{n})
.

Recall from Lemma
B.4
that

g(x_{n},y_{n})=\sum_{w\in\mathcal{A}}A^{(w)}\sign(-y_{n}^{(w)})+\sum_{w\in\mathcal{A}^{c}}A^{(w)}\sign\!\big(-{A^{(w)}}^{\top}\nabla f(x_{n})\big).

Taking inner product with
\nabla f(x_{n})
gives

\begin{split}\nabla f(x_{n})^{\top}g(x_{n},y_{n})={}&\sum_{w\in\mathcal{A}}\nabla f(x_{n})^{\top}A^{(w)}\sign(-y_{n}^{(w)})\\
&\quad+\sum_{w\in\mathcal{A}^{c}}\nabla f(x_{n})^{\top}A^{(w)}\sign\!\big(-{A^{(w)}}^{\top}\nabla f(x_{n})\big).\end{split}

Using the identity

a^{\top}\sign(-a)=-\|a\|_{1},

we obtain

\displaystyle\nabla f(x_{n})^{\top}g(x_{n},y_{n})\leq{}

\displaystyle\sum_{w\in\mathcal{A}}\|{A^{(w)}}^{\top}\nabla f(x_{n})\|_{1}-\sum_{w\in\mathcal{A}^{c}}\|{A^{(w)}}^{\top}\nabla f(x_{n})\|_{1}.

Finally, Assumption
6
implies

\nabla f(x_{n})^{\top}g(x_{n},y_{n})\leq-\eta\|\nabla f(x_{n})\|_{1}\quad\eta>0\quad\text{(see Lemma 2; \cite[cite]{\@@bibref{Authors Phrase1YearPhrase2}{ganesh2023online}{\@@citephrase{[}}{\@@citephrase{]}}} for the detailed proof)}.

Step 2: Bound on
\nabla f(x_{n})^{\top}b(x_{n},y_{n})
.

From Lemma
B.4
, the bias term satisfies

b(x_{n},y_{n})=\sum_{w\in\mathcal{A}^{c}}A^{(w)}\sign(-y_{n}^{(w)})-\sum_{w\in\mathcal{A}^{c}}A^{(w)}\sign\!\big(-{A^{(w)}}^{\top}\nabla f(x_{n})\big).

Therefore,

\begin{split}\nabla f(x_{n})^{\top}b(x_{n},y_{n})={}&\sum_{w\in\mathcal{A}^{c}}({A^{(w)}}^{\top}\nabla f(x_{n}))^{\top}\\
&\quad\times\Big(\sign(-y_{n}^{(w)})-\sign(-{A^{(w)}}^{\top}\nabla f(x_{n}))\Big).\end{split}

Using the elementary inequality

a\big(\sign(-b)-\sign(-a)\big)\leq 2|b-a|,\qquad\forall\,a,b\in\mathbb{R},

coordinatewise, we obtain

\displaystyle\nabla f(x_{n})^{\top}b(x_{n},y_{n})\leq{}

\displaystyle 2\sum_{w\in\mathcal{A}^{c}}\|{A^{(w)}}^{\top}\nabla f(x_{n})-y_{n}^{(w)}\|_{1}=\left\lVert e_{n}^{(w)}\right\rVert_{1}.

Combining the bounds obtained in Steps 1 and 2, we arrive at

\displaystyle\mathbb{E}[f(x_{n+1})\mid\mathcal{F}_{n}]\leq{}

\displaystyle f(x_{n})-\alpha_{n}\eta\|\nabla f(x_{n})\|_{1}

\displaystyle+2\alpha_{n}\sum_{w\in\mathcal{A}^{c}}\|e_{n}^{(w)}\|_{1}+\frac{L}{2}\alpha_{n}^{2}K_{5}^{2},

which proves the claim.
∎

Remark B.10
.

Lemma
B.9
shows that the objective sequence
\{f(x_{n})\}
satisfies an almost supermartingale-type recursion. Indeed, by Corollary
B.7
,

\sum_{n\geq 1}\alpha_{n}\|e_{n}^{(w)}\|_{1}<\infty\qquad\text{a.s.}

for every honest worker
w\in\mathcal{A}^{c}
. Together with the condition

\sum_{n\geq 1}\alpha_{n}^{2}<\infty,

the additional error terms are summable almost surely. Hence, the Robbins–Siegmund theorem applies to the sequence
\{f(x_{n})\}
.

We are now in a position to establish the almost sure boundedness of the global iterates.

Proof.

From Lemma
B.9
, we have

\displaystyle\mathbb{E}[f(x_{n+1})\mid\mathcal{F}_{n}]\leq{}

\displaystyle f(x_{n})-\alpha_{n}\eta\|\nabla f(x_{n})\|_{1}

\displaystyle+2\alpha_{n}|\mathcal{A}^{c}|\|e_{n}^{(w)}\|_{1}+\frac{L}{2}\alpha_{n}^{2}K_{5}^{2}.

By Assumption
4
,

\sum_{n\geq 1}\alpha_{n}^{2}<\infty.

Moreover, Corollary
B.7
implies that, for each honest worker
w\in\mathcal{A}^{c}
,

\sum_{n\geq 1}\alpha_{n}\|e_{n}^{(w)}\|_{1}<\infty\qquad\text{a.s.}

Therefore, all positive error terms in the above recursion are almost surely summable. Applying the Robbins–Siegmund theorem (Theorem
A.1
), we conclude that the sequence
\{f(x_{n})\}
converges almost surely to a finite random variable.

Finally, since
f
is coercive, every sublevel set of
f
is bounded. Because the sequence
\{f(x_{n})\}
converges almost surely, it remains almost surely bounded, and consequently the iterates
\{x_{n}\}
remain in a bounded sublevel set of
f
. Hence,
\{x_{n}\}

is almost surely bounded.

The almost sure boundedness of
\{y_{n}^{(w)}\}
now follows directly from Corollary
B.7
.
∎

Lemma B.11
.

For any
T>0
,

\lim_{n\to\infty}\sup_{\,n\leq k\leq\tau^{1}(n,T)}\left\|\sum_{m=n}^{k}\beta_{m}M_{m+1}^{(1)}\right\|=0\quad\text{a.s.},

where

\tau^{1}(n,T):=\min\left\{m\geq n\;\middle|\;\sum_{k=n}^{m+1}\beta_{k}\geq T\right\}.

Proof.

Define

S_{n}:=\sum_{k=1}^{n}\beta_{k}M_{k+1}^{(1)},\qquad n\geq 1.

Then
\{S_{n}\}
is a square-integrable martingale with respect to

\{\mathcal{F}_{n}\}
.

Since
S_{n+1}-S_{n}=\beta_{n}M_{n+1}^{(1)}
, we have

\displaystyle\sum_{n\geq 1}\mathbb{E}\!\left[\|S_{n+1}-S_{n}\|^{2}\mid\mathcal{F}_{n}\right]

Lemma B.14
.

The set-valued map
H:\mathbb{R}^{d}\rightrightarrows\mathbb{R}^{d}
is a Marchaud map.

Proof.

We prove the three required properties of
H
.

Step 1: Convexity and compactness.

For fixed
x
, each coordinate set defining
H(x)
is convex and compact (either a singleton
\{\pm 1\}
or the interval
[-1,1]
). Hence
H(x)
is a finite Minkowski sum of convex compact sets, and is therefore convex and compact.

Step 2: Boundedness.

Every coordinate of any
h\in H(x)
lies in
[-N,N]
; thus
\|h\|_{\infty}\leq N
, and in particular
\|h\|
is uniformly bounded.

Step 3: Closedness of the graph (upper semicontinuity).

Let
x_{n}\to x
and
h_{n}\in H(x_{n})
with
h_{n}\to h
. By construction there exist vectors
\lambda_{w,n}\in[-1,1]^{m}
such that

h_{n}=\sum_{w=1}^{N}A^{(w)}\lambda_{w,n},\qquad n\geq 0.

By compactness of
[-1,1]^{m}
we may (passing to a subsequence if necessary) assume
\lambda_{w,n}\to\xi_{w}\in[-1,1]^{m}
for each
w
. We claim that the limit
\xi_{w}
satisfies the coordinate–wise rules defining
H(x)
, namely

\xi_{w}(j)\in\begin{cases}\operatorname{sign}\!\big(-{a_{j}^{(w)}}^{\top}\nabla f(x)\big),&w\in\mathcal{A}^{c},\ {a_{j}^{(w)}}^{\top}\nabla f(x)\neq 0,\\[4.0pt]
[-1,1],&\text{otherwise}.\end{cases}

Indeed, if
w\in\mathcal{A}^{c}
and
{a_{j}^{(w)}}^{\top}\nabla f(x)\neq 0
, then by continuity of
\nabla f
there exists
N_{0}
such that for all
n\geq N_{0}
the sign
\operatorname{sign}(-{a_{j}^{(w)}}^{\top}\nabla f(x_{n}))
equals
\operatorname{sign}(-{a_{j}^{(w)}}^{\top}\nabla f(x))
; hence
\lambda_{w,n}(j)
is eventually constant and the limit
\xi_{w}(j)
equals that sign. If
{a_{j}^{(w)}}^{\top}\nabla f(x)=0
(or
w\in\mathcal{A}
), then each
\lambda_{w,n}(j)\in[-1,1]
and therefore
\xi_{w}(j)\in[-1,1]
.

Thus
\xi_{w}
satisfies the defining coordinate conditions at
x
, and

h=\lim_{n\to\infty}h_{n}=\sum_{w=1}^{N}A^{(w)}\xi_{w}\in H(x).

Therefore the graph of
H
is closed, i.e.
H
is upper semicontinuous. This completes the proof.
∎

Remark B.15
.

Lemma
B.14
is crucial for establishing the asymptotic convergence of

\{x_{n}\}
via (
42
), as it guarantees well–posedness of the limiting
differential inclusion. In particular, for any initial condition

x_{0}\in\mathbb{R}^{d}
, there exists a Carathéodory solution
x(\cdot)
that is
absolutely continuous and satisfies
\dot{x}(t)\in H(x(t))
almost everywhere.
This existence result enables the asymptotic stability analysis in
Lemma

, which ultimately yields convergence
x_{n}
to the set of stationary points.

Lemma B.16
.

Consider the differential inclusion

\dot{x}(t)\in H(x(t)),

where
H
is the set-valued map defined in (
42
). Then every
Carathéodory solution
x(t)
of this differential inclusion converges
asymptotically to the set of stationary points

\mathcal{X}^{\ast}:=\{x\in\mathbb{R}^{d}\mid\nabla f(x)=0\}.

Proof.

We analyze the asymptotic behavior of the differential inclusion using a
Lyapunov argument. Define

V(x):=f(x)-f^{\ast}.

The set-valued Lie derivative of
V
with respect to the inclusion

\dot{x}\in H(x)
is

\widetilde{\mathcal{L}}V(x):=\big\{a\in\mathbb{R}\;\big|\;\exists\,v\in H(x)\text{ such that }a=\nabla V(x)^{\top}v\big\}.

Fix any
a\in\widetilde{\mathcal{L}}V(x)
. Then there exists
v\in H(x)
such
that

a=\nabla f(x)^{\top}v.

By definition of
H
, the vector
v
admits the representation

v=\sum_{w=1}^{N}\sum_{j=1}^{m}a_{j}^{(w)}\lambda_{w}(j),

which yields

\displaystyle a

\displaystyle=\sum_{w\in\mathcal{A}^{c}}\sum_{j=1}^{m}\nabla f(x)^{\top}a_{j}^{(w)}\lambda_{w}(j)+\sum_{w\in\mathcal{A}}\sum_{j=1}^{m}\nabla f(x)^{\top}a_{j}^{(w)}\lambda_{w}(j).

For honest workers
w\in\mathcal{A}^{c}
, we have

\lambda_{w}(j)=\operatorname{sign}\!\big(-{a_{j}^{(w)}}^{\top}\nabla f(x)\big),

while for adversarial workers
w\in\mathcal{A}
,
\lambda_{w}(j)\in[-1,1]
. It
therefore follows that

\begin{split}a&\leq-\sum_{w\in\mathcal{A}^{c}}\|{A^{(w)}}^{\top}\nabla f(x)\|_{1}+\sum_{w\in\mathcal{A}}\|{A^{(w)}}^{\top}\nabla f(x)\|_{1}\\
&\leq-\eta\|\nabla f(x)\|_{1}\leq 0,\end{split}

(44)

where
\eta>0
is the constant defined earlier. Consequently,

\sup_{a\in\widetilde{\mathcal{L}}V(x)}a\leq 0.

By Proposition 10 of
10
, this implies that

\frac{d}{dt}f(x(t))\leq 0\quad\text{for almost all }t\geq 0,

(45)

that is, the function
f(x(t))
is non-increasing along any Carathéodory
solution.

Let
f(x(0))=c
and define the sublevel set

S:=\{x\in\mathbb{R}^{d}\mid f(x)\leq c\}.

By (
45
), the set
S
is positively invariant. Moreover,
S
is
compact by Assumption
1
. We may therefore invoke the invariance
principle for differential inclusions (Theorem 4 of
10
)
to conclude that every Carathéodory solution converges asymptotically to the
largest invariant set contained in

S\cap\overline{\{x\in\mathbb{R}^{d}\mid 0\in\widetilde{\mathcal{L}}V(x)\}}.

Finally, from (
44
) we see that

0\in\widetilde{\mathcal{L}}V(x)
if and only if
\nabla f(x)=0
, which implies

x\in\mathcal{X}^{\ast}
. This completes the proof.
∎

Remark B.17
.

Combining Proposition
B.6
and Corollary
B.7
with the Robbins–Siegmund argument, we have shown that the iterates are almost surely bounded and that the fast variables
y_{n}^{(w)}
track the moving equilibria
{A^{(w)}}^{\top}\nabla f(x_{n})
. Using this tracking together with Lemmas
B.14
and
B.16
(ODE/ODI stability) we concluded in Theorem

The two key mechanisms behind this result are (i) time–scale separation, which allows the fast dynamics to equilibrate around the directional gradients, and (ii) the ODI formulation, which handles non-smooth and adversarial contributions via a Marchaud map and an invariance principle.

In the next section we quantify these statements: we derive explicit convergence rates that depend explicitly on the step-size schedules and problem parameters.

Proposition C.1

Suppose Assumptions

Proof.

From Proposition

Consequently,

Finally, observing that

\frac{B_{n}^{2}}{4c_{2}\beta_{n}}=\frac{B_{n}^{2}}{\beta_{n}},

where

This completes the proof.

completes the proof.

The next Corollary is now immediate.

Corollary C.6

(Explicit constants in the ergodic gradient bound)
.

Suppose the assumptions of Theorem
2.7
hold. Then,

\frac{1}{S_{n}}\sum_{k=1}^{n}\alpha_{k}\,\mathbb{E}\bigl\|\nabla f(x_{k})\bigr\|_{1}\leq\frac{\mathrm{I}_{1}}{\eta S_{n}}+D_{1}\,m^{1/2}\,(1+n)^{-s_{1}}+D_{2}\,(1+n)^{-s_{2}},

where

\mathrm{I}_{1}:=\mathbb{E}[f(x_{1})]-\inf f,

and

s_{1}:=\min\!\Bigl\{\frac{\gamma}{2},\,1-a\Bigr\},\qquad s_{2}:=\min\{a,\,1-a\}.

The constants
D_{1}
and
D_{2}
are given by

D_{1}=\frac{2|\mathcal{A}^{c}|}{\eta}\sqrt{\widetilde{C}_{1}},\qquad D_{2}=\frac{LK_{5}^{2}\alpha}{2\eta}.

Proof.

Starting from the estimate obtained in
Proposition
C.5
, we have

\displaystyle\frac{1}{S_{n}}\sum_{k=1}^{n}\alpha_{k}\,\mathbb{E}\|\nabla f(x_{k})\|_{1}\leq{}

\displaystyle\frac{\mathbb{E}[f(x_{1})]-\inf f}{\eta S_{n}}+\underbrace{\frac{2|\mathcal{A}^{c}|}{\eta}\,\frac{\sqrt{\widetilde{C}_{1}}\,m^{1/2}\,\sum_{k=1}^{n}\alpha_{k}(1+k)^{-\gamma/2}}{S_{n}}}_{\mathbf{M}_{1}}

(55)

\displaystyle+\underbrace{\frac{LK_{5}^{2}}{2\eta}\,\frac{\sum_{k=1}^{n}\alpha_{k}^{2}}{S_{n}}}_{\mathbf{M}_{2}}.

We treat the three terms on the right-hand side separately.

(i) The initial term.

The first term is simply

\frac{\mathbb{E}[f(x_{1})]-\inf f}{\eta S_{n}}=\frac{\mathrm{I}_{1}}{\eta S_{n}}.

Its behaviour is determined by the growth of
S_{n}=\sum_{k=1}^{n}\alpha_{k}
.
For the standard polynomial stepsize
\alpha_{k}\asymp c_{\alpha}k^{-a}

(with
a\neq 1
), we have
S_{n}\asymp c_{\alpha}\,n^{1-a}
, so the first
term is
O(n^{a-1})
.

(ii) The
\mathbf{M}_{1}
term.

Consider the numerator

\sum_{k=1}^{n}\alpha_{k}(1+k)^{-\gamma/2}\asymp\sum_{k=1}^{n}k^{-a-\gamma/2}.

Set
p:=a+\gamma/2
. By the integral test, or equivalently by standard

p
-series asymptotics, we have

\sum_{k=1}^{n}k^{-p}=\begin{cases}\mathcal{O}\!\left(n^{1-p}\right),&p<1,\\[4.0pt]
\mathcal{O}(1),&p>1.\end{cases}

Since
S_{n}\asymp n^{1-a}
, it follows that

\frac{\sum_{k=1}^{n}\alpha_{k}(1+k)^{-\gamma/2}}{S_{n}}=\mathcal{O}\bigl((1+n)^{-s_{1}}\bigr),\qquad s_{1}:=\min\!\Bigl\{\frac{\gamma}{2},\,1-a\Bigr\}.

Therefore,

\frac{2|\mathcal{A}^{c}|}{\eta}\,\frac{\sqrt{\widetilde{C}_{1}}\,m^{1/2}\,\sum_{k=1}^{n}\alpha_{k}(1+k)^{-\gamma/2}}{S_{n}}=D_{1}\,m^{1/2}(1+n)^{-s_{1}},

where

D_{1}=\frac{2|\mathcal{A}^{c}|}{\eta}\sqrt{\widetilde{C}_{1}},

up to the harmless multiplicative constants coming from the standard
summation estimate.

(iii) The
\mathbf{M}_{2}
term.

For the third term, we examine

\sum_{k=1}^{n}\alpha_{k}^{2}\asymp\sum_{k=1}^{n}k^{-2a}.

Applying the same
p
-series argument with
q:=2a
, we obtain

\sum_{k=1}^{n}k^{-2a}=\begin{cases}\mathcal{O}\!\left(n^{1-2a}\right),&2a<1,\\[4.0pt]
\mathcal{O}(1),&2a>1.\end{cases}

Dividing by
S_{n}\asymp n^{1-a}
gives

\frac{\sum_{k=1}^{n}\alpha_{k}^{2}}{S_{n}}=\mathcal{O}\bigl((1+n)^{-s_{2}}\bigr),\qquad s_{2}:=\min\{a,\,1-a\}.

Thus,

\frac{LK_{5}^{2}}{2\eta}\,\frac{\sum_{k=1}^{n}\alpha_{k}^{2}}{S_{n}}=D_{2}\,(1+n)^{-s_{2}},

where

D_{2}=\frac{LK_{5}^{2}\alpha}{2\eta},

again up to the harmless multiplicative constants coming from the exact
stepsize prefactor.

Conclusion.

Combining the three estimates above and substituting them into
(
55
), we obtain

\frac{1}{S_{n}}\sum_{k=1}^{n}\alpha_{k}\,\mathbb{E}\|\nabla f(x_{k})\|_{1}\leq\frac{\mathrm{I}_{1}}{\eta S_{n}}+D_{1}\,m^{1/2}\,(1+n)^{-s_{1}}+D_{2}\,(1+n)^{-s_{2}},

where
s_{1}
and
s_{2}
are as defined above and

D_{1}=\frac{2|\mathcal{A}^{c}|}{\eta}\sqrt{\widetilde{C}_{1}},\qquad D_{2}=\frac{LK_{5}^{2}\alpha}{2\eta}.

This completes the proof.
∎
