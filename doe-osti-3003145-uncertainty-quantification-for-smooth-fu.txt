Introduction
This document outlines a method for processing functional output (i.e., curves) for the
ultimate purpose of sampling curves under specified input conditions for use in modeling
and simulation uncertainty quantification (UQ) studies. A set of benchmark curves
sufficiently representative of the relevant scenario(s) being simulated are provided to the
process and formatted as described in Section 1. Principal Component Analysis (PCA) is
utilized to discover the components of uncertainty in the benchmark curves and is outlined
in Section 2. Section 3 describes the application of uncertainty quantification to the PCA
results for the purpose of sampling curves to be used in UQ analysis. Section 4 applies
these techniques to an example benchmark dataset. Concluding remarks are provided in
the final section.

1. Formatting of Benchmark Curves
At a minimum, each benchmark curve is supplied with an index variable and an output of
interest measuring observed responses corresponding to the index values. If the index
variable is categorical, it should have common levels across all benchmark curves. If the
index variable is quantitative, it must be ordered monotonically for each curve or sorted to
satisfy this requirement, so that a technique such as linear interpolation can be applied to
register the curves as described in the next paragraph. In the example of Section 4,
increasing levels of pressure were applied to a foam core punch and the resulting values of
stress and strain were measured. The output of interest is strain, and the index variable is
stress, which in this example is quantitative.

Often, a quantitative index variable is not supplied on a common set of values across all
benchmark curves. Before PCA can be applied, this variable must be registered to a
common set of values, so that a mean curve can be computed and used to create
centered curves for application of PCA as described in Section 2. It is good practice to
select a common set of values having similar size (subsequently denoted N) as the sets of
values provided with the original curves. As an illustration, suppose the quantitative index
variable t satisfies 𝑡!"# ≤ 𝑡 ≤ 𝑡!$% for each benchmark curve. Then it is possible to
establish a common set of N values of t on the interval [𝑡!"# , 𝑡!$% ]. Once the common set
of index values is determined, an interpolation method is utilized to map the output values
to this set for each benchmark curve. In practice, the index grids utilized in functional data

 1

analysis are often sufficiently refined that linear interpolation is adequate, as in the
subsequent example. However, this must be verified at least informally, and in some cases
more advanced interpolation methods (e.g., polynomial, spline) may be necessary.

In some applications, the index variable may not be solely increasing or decreasing but
rather follow a pattern analogous to that observed with hysteresis curves. Such settings
are processed by splitting the index variable into segments containing uniquely increasing
or decreasing values. Each segment is then registered to a common set of index values
having similar size as the corresponding segment in the original data to facilitate the
fidelity of the interpolation method used to approximate the segments of the observed
curve, following by the mapping of output values in each segment to its corresponding
common index set for each benchmark curve. Registered curves corresponding to each
segment are then concatenated in the proper order for subsequent application of PCA.

2. Principal Component Analysis
Each benchmark curve (experimental run) is associated with a set of covariates which
describe the controlled and environmental conditions under which its output was
measured and are recorded to study their potential influence on output variation.
Controlled inputs are varied according to an experimental design consisting of n runs,
while environmental inputs are recorded for use in statistical analysis but cannot be
“dialed in” for each experimental run. These covariates are referred to collectively as x in
the following discussion. In the stress-strain example of Section 4, x consists of four
elements: Part, Angle, Azimuth, and Density, recorded for each foam punch taken. Part is
a categorical controlled input designating the part tested for each experiment. Angle and
Azimuth are also controlled inputs specifying the central position of the foam punch on the
Part. Density of the foam material is the single environmental covariate, measured after
each foam punch is collected. The goal of the next two sections is to describe
methodology for generating a sample of curves corresponding to user-specified settings
for the covariates x. It is assumed that quantitative values of x specified for curve sampling
are contained within the convex hull1 of quantitative values associated with the supplied
benchmark curves (mitigating issues associated with extrapolating empirical statistical
models).

Due to the functional nature of the benchmark curves, principal component (PC)
regression is utilized to identify trends in the supplied covariates. A principal component
analysis (PCA) is conducted on the registered curves (see Section 1), producing (1)
principal components (eigenvectors) representing the main modes of variation in the
curves and (2) scalar scores representing the coordinate values of each curve with respect
to each principal component. The amount of total variation in the curves explained by each
principal component is computed, and the smallest subset of components (in order of

Principal component regression (PCR) involves selecting separate regression models for
each of the p scores 𝑠" (∙) using the observed scores (leading columns of the matrix S
above) obtained from PCA on the experimentally generated (or simulated) curves. This
approach allows predictions of centered curves for arbitrary covariates x to be made using
Equation (1) as described in Section 3. Model selection is accomplished via the stepAIC
function of the MASS package for the R software. This algorithm optimizes the Akaike
Information Criterion2 (AIC) or the Bayesian Information Criterion3 (BIC) in a stepwise
selection algorithm to choose the best regression model out of a class of possibilities
bounded by the constant model (minimal) and a user-specified full model (maximal). The
AIC or BIC criterion is also used more generally to consider models of potential interest
that exist outside of such specified model classes. These criteria are defined as follows,

 AIC = -2*logLik + 2*df
 BIC = -2*logLik + df*log(n),

for logLik the value of the log-likelihood function at its global maximum, df the number of
free model parameters, and n the number of observations used in model fitting. Larger
values of logLik in the first term of either criterion indicate better goodness of fit, while the
second term penalizes for model complexity (number of free parameters). Therefore,
models associated with smaller values of these criteria are preferred. Additional details
regarding the derivation and interpretation of these criteria are given in the references
provided.

a statistical population. In the above discussion, this pertains to the Part covariate. Two
regression modeling approaches to treatment of the Part covariate are possible. The first
incorporates Part in the candidate models as a fixed effect, as is done with the other
covariates. The second treats Part as a random effect. The purpose of this latter
approach is to allow model predictions for parts not included in the experimental design,
assuming it is reasonable to treat a part as being drawn randomly from a population of

4. Example: Stress-Strain Curves
This example of the methodology introduced in the previous sections is taken from an
experiment on 20mm foam punches collected from four semi-spherical foam parts to
understand the impact of part, location and material density on the attributes of the foam.
To demonstrate the PCA method, only the tests of mechanical compression (MTS) are
considered, and so stress versus strain curves are the raw data used in this analysis. The
Part being tested, the Angle from the perpendicular where the punch is placed, and the
Azimuth of the punch are controlled covariates through specification in a designed
experiment. The Density of the foam material is the single environmental covariate,

 6

measured after each foam punch is collected. A primary goal of the data analysis is to
produce a statistical regression model that is designed to predict stress-strain curves with
quantification of uncertainties including variability across parts for arbitrary fixed covariate
values.

4.1 Principal Component Analysis

For the purposes of this example, PCA is performed on stress versus strain curves
measured from n = 160 punches. Stress is designated as the index variable, with strain the
output variable. Strain values from each curve were registered to a common index set of N
= 420 stress values using linear interpolation. A single principal component (p = 1) was
retained, itself explaining 99.8% of total variation in the available set of curves (exceeding
the informal threshold of 99%). The scores corresponding to this retained component were
computed via Equation (2). Figure 1 plots all 160 stress-strain curves in gray. The colored
curves represent the quintiles of these scores substituted in for s1(x) in Equation (1) and
added to the mean stress-strain curve yM plotted in black. In other words, the colored
curves demonstrate that essentially all the variability in the measured curves is
represented effectively by scaling the dominant principal component and applying the
resulting deviation to the mean curve.

4.2 Principal Component Regression

As described in Section 2, covariates in a regression model describing the behavior of the
scores for each retained principal component can be treated as either fixed or random
effects. The Part covariate was treated as a random effect so that the regression model

 7

would possess the capability to make predictions for parts not included within the
experimental design as a function of the fixed covariates, with part-to-part variability and
aleatory uncertainty accounted for in the prediction standard errors. The other three
covariates Angle, Azimuth, and Density were all taken to be fixed effects. Initially, three
models for the Part random effect were considered:

 1. No Part random effect
 2. Random intercept by Part
 3. Random intercept and random slope in Angle by Part

Each model assumed a full quadratic regression in the fixed effects. Table 1 presents the
analysis of variance table showing that the third model outperforms the other two in terms
of AIC, BIC, and the likelihood ratio tests. As stated previously, models associated with
smaller values of AIC and BIC are preferred. For either criterion, the model estimated as
the “best” has the smallest criterion value in the model class under consideration. Table 2
provides intuition regarding the level of empirical support for model i as the actual best
model in the class based on its AIC or BIC difference Di from the estimated best model4.
Likelihood ratio tests (LRTs) compare the differences in maximum log-likelihood (logLik)
between two nested models to determine if a subset of parameters may be eliminated. A
small p-value (5% threshold typically assumed) associated with an LRT indicates that
statistically significant evidence exists to retain the parameter(s) proposed for elimination.

Conclusions
This document provides a roadmap for processing functional data observed from physical
or simulation experiments using principal component analysis for application to
uncertainty quantification studies. The steps are as follows:

 1. A set of curves are generated with respect to an index variable. If distinct curves are
 observed at different values of the index variable, each curve must be registered to
 a common set of values chosen for the index variable by the user.
 2. Conduct PCA on the entire set of registered curves. Select the smallest number of
 modes which collectively explain a level of total variance in the set of curves
 exceeding a user-specified threshold (typically, 99%).
 3. Conduct PCR independently on each retained score in terms of the specified
 covariate values for each experiment.
 4. For each specified covariate setting at which predictions are desired, sample a
 user-specified number of curves and if desired, mean and bounding curves.
 5. Utilize the results as appropriate in uncertainty quantification studies.
