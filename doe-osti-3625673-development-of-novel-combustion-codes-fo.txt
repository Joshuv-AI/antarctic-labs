 Executive Summary of CRADA Work:

 The Allam-Fetvedt Cycle, a novel supercritical CO₂ (sCO₂) power cycle developed by 8 Rivers
 Capital, LLC, generates low-cost power from fossil fuels while capturing combustion-CO₂. This
 cycle employs high-temperature oxy-combustion using sCO₂ as the working fluid, leading to a
 challenging environment for materials. The most critical component for reliable deployment of
 this technology is the combustor-turbine interface. In the proposed partnership between NLR and
 8 Rivers, we will develop a simulation-based tool to provide key design inputs for defining the
 materials and geometries required in this critical area.

 CRADA benefit to DOE, Participant, and US Taxpayer:

 • Enhances the laboratory’s core competencies

 Summary of Research Results:

 Predicting the temperatures reached in the combustion process is critical to materials selection.
 This project used PeleC, a reacting-flow code developed as part of the Office of Science’s
 Exascale Computing Project. This reacting flow code was used to perform high-fidelity
 simulations of the combustor environment. Results allow the creation of models that can be
 integrated into simulation tools used by 8 Rivers to accelerate the design process. The results
 of this project show that real gas effects will impact the design of combustors, a critical part of
 this technology. The project also identified an approach to including these effects in
 commercial codes in a computationally efficient manner. This is expected to de-risk this
 technology and accelerate its adoption.

 The PeleC combustion code developed at NLR will be used to perform high-fidelity simulations
 of the combustor environment, the results of which will be used to generate a machine learning-
 based surrogate model for high-throughput design iteration. This model will allow rapid
 determination of combustor and turbine materials selection parameters, hastening the
 deployment of the overall technology.

 Task 1: Validation of non-ideal reacting flow modules in PeleC

 Deliverable: Conference publication highlighting the comparison between simulation results and
 experiments. Codes and input files made open source through GitHub repository.

 The Allam-Fetvedt Cycle, as shown in figure 1, is a novel power cycle developed by 8 Rivers
 Capital, LLC. By using oxy-combustion in a closed-loop cycle using supercritical-CO2 (sCO2) as
 a working fluid, this cycle enables low-cost power generation from fossil fuels while allowing
 relatively simple capture of CO2 generated in the combustion process.

 Figure 1: Allam-Fetvedt Cycle
 The combustor design is critical to the deployment of this cycle. Oxy combustion in supercritical
 carbon dioxide has been likened by 8 Rivers to “lighting a match in a fire extinguisher.”
 Simulation of the combustor in this configuration is computationally challenging, as it requires
 simulating chemical reactions in a real-gas environment in a complex geometry. In addition to
 modeling system performance, predictions of temperature, gas composition, and flow
 configuration at the exit of the combustor impact design choices. As an example, predicting
 these parameters impacts materials selection for the turbine stage.
 This project used NLR’s PeleC exascale combustion code to perform high-fidelity simulations
 of the combustor environment. The goal of this project was to use these simulations to build a
 fundamental understanding of real-gas effects in these systems and to allow the creation of
 models that can be integrated into simulation tools used by 8 Rivers to accelerate the design
 process.

 3

 Results

 NLR performed a series of 1D flame calculations using the Cantera open-source Python library,
 with appropriate modifications for the real gas equation of state needed to capture the behavior
 of sCO2. This approach allowed rapid examination of hundreds of operating conditions,
 covering a range of temperatures, pressures, and mixture compositions. Representative results,
 showing how dilution of CH4 with sCO2 impacts flame behavior, is shown as figure 2. The 1-
 D flame here features CH4 with varying sCO2 dilution reacting with an oxygen/sCO2 mixture.

 Higher dilution amounts reduce the flame temperature, making flame extinction more
 likely. The flame structure also changes. Addition cases (shown as figure 3) demonstrate
 that as the pressure increases, the flame reactions strengthen, leading to a thinner reaction
 zone that can function at higher strain rates.

 Figure 3. Impact of pressure on flame structure

 Finally, using the same tools to examine premixed flames showed that the flame thickness
 decreased with pressure. The results also showed that flame speed varied with pressure and,
 most importantly, was sensitive to the gas model used for sCO2. This shows that using equations
 that incorporate real gas is vital for the simulation of these systems, greatly increasing the
 expense of simulations.

 NLR is in the process of using simulations in PeleC to capture these effects as part of the
 Exascale Computing Project. This information will be incorporated into software that will be
 delivered to 8 Rivers to accelerate their simulations in commercial computational fluid dynamic
 (CFD) software.

 NLR also created simulations of a representative combustor geometry to evaluate the impact of
 real gas effects. These simulations used the Soave-Redlick-Kwong (SRK) model to find the
 density and specific heat of sCO2. Initial work showed that while using the SRK model near the
 critical point may lead to inaccurate predictions of flow structure and heat transfer, these issues
 are not a concern at the pressures and temperatures encountered in 8 River’s systems. These
 simulations were performed using PeleC and computational resources at NLR and ORNL. The
 combustor is shown in figure 4 below:

 Two sets of runs were performed for these operating conditions: one using an ideal gas model
 and the other using the Soave-Redlich-Kwong, or SRK, model. The temperature profiles for the
 centerline of the turbine for the system operating with fuel jets of 100% CH4 for both gas models
 are shown as figure 5, while the temperature profiles for the system operating with fuel jets of
 40% CH4 for both gas models are shown as figure 6. These results are very computationally
 intensive, requiring extended runs on Summit to achieve convergence. As of this writing, the
 extended cases are still being run to achieve results needed for journal-quality publication as part
 of the Exascale Computing project.

 Qualitatively, the impact of varying gas models and flow conditions is difficult to see in
 temperature fields. The key to understanding the potential impacts is by looking at temperatures
 and gas concentrations along the centerline of the combustor, as shown in figures 7 (a) through
 (d). These results show that the combustion processes are impacted both by flow conditions and
 by the equation of state used. The equation of state has an impact on the system that is
 comparable to changes in flow conditions. This indicates that using the computationally
 expensive SRK equation is necessary to achieve results with engineering accuracy.

 NLR’s results show that real gas effects impact system performance for oxycombustion in
 supercritical carbon dioxide. This, in turn, means that they must be included in simulations for
 engineering design. In large-scale simulations, this requires using equations of state such as the
 SRK equation. In practice, these increased the computational time needed for simulations by a
 factor of 3. This reflects not only the increased computational time needed to use the equation of
 state but also the need to use more conservative solution parameters due to stability concerns.

 This impacts the ability of engineers attempting to use smaller-scale simulations to evaluate
 engineering designs. The reduced-order models that NLR will develop as part of the exascale
 computing project in continuation of this project will accelerate system design.

 Implementation

 The project was implemented using the PeleC code, developed as part of the Office of Science’s
 Exascale Computing Project (ECP). PeleC is designed specifically to take advantage of exascale
 computing architectures, such as ORNL’s Summit machine.

 Issues or Challenges

 Because this project began in 2020, it experienced major disruptions from COVID. The project
 was also built around using PeleC, whose development was also heavily impacted by COVID.
 The project scope changed in response to these challenges. The project also stretched over
 multiple fiscal years as a result.

 Task 4: Build a surrogate model of the combustor using machine learning (ML) techniques

 Deliverables: ML based model with codes to generate the same. Codes shared openly through
 the GitHub repository. Publication highlighting the methodologies and analysis of results.

 The Task 4 deliverables included an ML-based model with codes to generate the same. The
 relevant codes were shared as open source in a GitHub repository. In addition, NLR was
 responsible for a publication highlighting the methodologies and analysis of results.

 Task 5: Demonstration of ML-based model to design and material selection of combustor
 liner and nozzle-turbine assembly

 Deliverables: Design workflow in terms of scripts and codes to use accurate and light weight
 MLbased surrogate model into existing design and material selection practice using commercial
 codes.

 The Task 5 deliverables included a design workflow in terms of scripts and codes to use an
 accurate and lightweight ML-based surrogate model into existing design and material selection
 practice using commercial codes.

 Because of the importance of sCO2 in industrial decarbonization, NLR will prioritize
 development of reacting flow sCO2 capabilities in the PeleC code through remaining exascale
 funding. NLR and 8 Rivers have had preliminary discussions about a phase 2 project. Finally,
 NLR will present at least two conference papers based on this work, with the goal of turning both
 conference papers into archival journal papers. By identifying the impact of real gas effects on
 combustor design and creating an approach for incorporating these effects into future combustor
 design, this work is expected to accelerate adoption of 8 River’s Allam-Fetdvedt cycle, and its
 use in decarbonization. As of this writing, the first demonstration-scale deployment of this
 technology has already been connected to the ERCOT grid. Several other commercial-scale
 deployments have been announced. These simulations allow these technologies to be de-risked
 using computational resources.
