Canonical reconstruction and forcing absoluteness of standard structures Thanks: IM CAS (RVO 67985840).
Tomasz Kania

Abstract
. We isolate a simple preservation principle governing when it is absolute, between transitive models of set theory, that a given algebraic or topological-algebraic structure has a standard form F ⁡ ( X ) F(X) indexed by a set X X . The principle is: if the index X X (or a proxy for it) can be recovered from F ⁡ ( X ) F(X) by a uniform definable construction, then the class of structures isomorphic to some F ⁡ ( X ) F(X) is downward absolute from forcing extensions. Answering a question raised by Noah Schweber, we deduce in particular that no group that fails to be a full symmetric group in the ground model can become one after forcing; the result holds already in 𝖹𝖥 \mathsf{ZF} . The same mechanism applies to full transformation monoids, powerset Boolean algebras, full relation algebras, full clones, full partition lattices, products R X R^{X} of finitely generated centrally indecomposable rings, the commutative C ∗ C^{*} -algebras ℓ ∞ ​ ( X ) \ell_{\infty}(X) and c 0 ​ ( X ) c_{0}(X) , full endomorphism rings, the operator algebras ℬ ⁡ ( H ) \mathcal{B}(H) and 𝒦 ⁡ ( H ) \mathcal{K}(H) , and ℓ 1 ​ ( X ) \ell_{1}(X) as a real Banach lattice. In the motivating symmetric-group case, the same reconstruction gives more than descent: it yields a uniform Π 1 1 \Pi^{1}_{1} definition of fullness over transitive 𝖹𝖥 \mathsf{ZF} -models. We then exhibit clean torsor obstructions, in the standard symmetric-model situation: finite covers Y × n Y\times n already separate 𝖹𝖥 \mathsf{ZF} -failure from 𝖹𝖥𝖢 \mathsf{ZFC} -descent without any completeness caveat, and the finite-support normed space c 00 ​ ( I ) c_{00}(I) provides the analogous Banach example. Bare-Banach-space isomorphism with ℓ 1 ​ ( Γ ) \ell_{1}(\Gamma) exhibits a genuine 𝖹𝖥𝖢 \mathsf{ZFC} -descent. We conclude with the corresponding, relative, obstructions to Π 1 1 \Pi^{1}_{1} -definability of standardness over transitive 𝖹𝖥 \mathsf{ZF} -models.

1.
Introduction

A recurring question, which surfaces in many guises across algebra and
analysis, is whether being a “standard” object of a given type is
itself a definable property of the abstract structure. One instance was
raised by Noah Schweber: if a group
G
fails to be isomorphic to any
full symmetric group
\operatorname{Sym}(X)
, can forcing make it one? More generally,
for a class
\mathcal{C}=\{F(X):X\text{ a set}\}
of
standard
forms
of some structure type, is membership in
\mathcal{C}
preserved as we
move between transitive models of
\mathsf{ZF}
or
\mathsf{ZFC}
?

On its face the predicate “
A\cong F(X)
for some
X
” is

\Sigma^{1}_{2}
: it asserts the existence of an index
X
and of an
isomorphism
A\to F(X)
. The familiar “potential counterexample”
heuristic for ruling out a
\Pi^{1}_{1}
definition of such a class is to
find
A
outside
\mathcal{C}
in a ground model and inside
\mathcal{C}
in a forcing
extension. The goal of this note is to record a uniform obstruction to
this heuristic in many natural cases, and to delineate the cases where
the heuristic really does succeed.

For full symmetric groups the situation is stronger still. The
canonical reconstruction of the point set from the abstract group
yields a direct
\Pi^{1}_{1}
definition of fullness. Thus, in the
motivating example, the forcing strategy cannot work not merely because
fullness is downward absolute, but because fullness is already

\Pi^{1}_{1}
over transitive
\mathsf{ZF}
-models.

The key observation is elementary but unifying. Call a standard form

F(X)

canonically reconstructible
if the index set
X
can be
recovered, up to a definable bijection, from the abstract structure of

F(X)
by a formula of the appropriate signature. Whenever this holds,
isomorphism with some
F(X)
is downward absolute between any two
transitive models of
\mathsf{ZF}
, one of which contains the other:

If the index of a standard structure
F(X)
can be reconstructed
canonically from its abstract structure, then the predicate
“
A\cong F(X)
for some
X
” is downward absolute from forcing
extensions, and indeed from any outer transitive
\mathsf{ZF}
-model.

The first main result illustrates the programme.

Theorem 1.1

(Full symmetric groups;
\mathsf{ZF}
)
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
and let
G\in M
be
a group. If
N\models
“
G\cong\operatorname{Sym}(X)
for some set
X
”, then

M\models
“
G\cong\operatorname{Sym}(Y)
for some set
Y
”.

In particular, no forcing extension of any
\mathsf{ZFC}
model can turn a
non-full group into a full symmetric group. The same scheme of
reconstruction applies to a variety of structures. We shall prove
unconditional
\mathsf{ZF}
-descent for:

\bullet

full symmetric groups and full transformation monoids;

\bullet

powerset Boolean algebras and Boolean rings of all subsets;

\bullet

full relation algebras
\operatorname{Rel}(X)=\mathcal{P}(X\times X)
;

\bullet

full clones
\mathscr{O}_{X}
of all finitary operations on
X
;

\bullet

full partition lattices
\Pi(X)
;

\bullet

products
R^{X}
where
R
is finitely generated as a unital ring
and has no central idempotents other than
0
and
1
— covering

\mathbb{Z}
, all
\mathbb{Z}/p^{m}\mathbb{Z}
, all finite fields
\mathbb{F}_{p^{n}}
, all
matrix rings
M_{k}(\mathbb{F}_{q})
, and all polynomial rings

\mathbb{Z}[t_{1},\ldots,t_{n}]
;

\bullet

the commutative
C^{*}
-algebras
\ell_{\infty}(X)
and
c_{0}(X)
;

\bullet

full endomorphism rings
\operatorname{End}_{D}(V)
of non-zero vector spaces
possessing a rank-one complemented line;

\bullet

the operator algebras
\mathcal{B}(H)
and
\mathcal{K}(H)
on a non-zero Hilbert
space;

\bullet

\ell_{1}(X)
as a real Banach lattice.

For each of the above, the index can be reconstructed canonically by an
absolute formula. We shall also prove
\mathsf{ZFC}
-descent for several
choice-dependent examples. For finite covers and
c_{00}(\Gamma)
we
give explicit
\mathsf{ZF}
-obstructions; for Hilbert spaces the obstruction is
the familiar basis-existence issue:

\bullet

finite covers — the class of equivalence relations isomorphic
to
Y\times n
for some set
Y
and a fixed integer
n\geqslant 2
;

\bullet

bare normed-space isomorphism with
c_{00}(\Gamma)
;

\bullet

bare Banach-space isomorphism with
\ell_{1}(\Gamma)
;

\bullet

Hilbert-space isomorphism with
\ell_{2}(\Gamma)
— a
basis-existence issue.

The
\mathsf{ZF}
-obstructions are always of the same form: a bundle of locally
isomorphic factors without a global trivialisation. Forcing, through
the generic production of a section, can turn the bundle into a trivial
standard object.

2.
Framework: the descent lemma

We work throughout with transitive models of set theory. The generic
situation, unless stated otherwise, is a pair
M\subseteq N
of
transitive models of
\mathsf{ZF}
; the main case of interest is that of a
forcing extension
N=M[G]
, but no special property of forcing is used
beyond transitivity and agreement of the membership relation. The
framework accommodates
\mathsf{ZF}
ground models, symmetric submodels, inner
models and outer forcing extensions uniformly.

Given a set
Y\in M
, we write
F^{M}(Y)
and
F^{N}(Y)
for the standard
structure built from
Y
as computed in
M
and in
N
respectively. In
general one only has
F^{M}(Y)\subseteq F^{N}(Y)
, because
N
may contain
new subsets, sequences, or operators over the old set
Y
.

Convention 2.1

(Scalars)
.

For statements involving Banach spaces,
C^{*}
-algebras, and other
structures whose definition makes reference to a scalar field, the
scalar field is regarded as a fixed named sort. Equivalently, we
restrict to pairs
M\subseteq N
in which the real (and, if applicable,
complex) fields of
M
and
N
coincide. This rules out only the
orthogonal phenomenon that a ground-model real Banach space is not
automatically a vector space over the reals of a forcing extension. All
constructions below respect this convention.

Convention 2.2

(The zero
C^{*}
-algebra)
.

We allow the zero
C^{*}
-algebra as a unital
C^{*}
-algebra, with
0=1
,
when this avoids irrelevant empty-space exceptions.

The elementary observation on which everything rests is the following.

Lemma 2.3

(Descent lemma)
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
, and let

A,Y,\theta\in M
. Suppose that the standard construction
F
is
absolute on old elements, in the sense that

F^{M}(Y)=F^{N}(Y)\cap M.

If

N\models\text{``$\theta:A\to F^{N}(Y)$ is an isomorphism''},

then

M\models\text{``$\theta:A\to F^{M}(Y)$ is an isomorphism''}.

Proof.

Since
\theta,A\in M
and
M
is transitive, every value of
\theta

is an element of
M
. Thus, if
N
sees that
\theta(a)\in F^{N}(Y)
,
then

\theta(a)\in F^{N}(Y)\cap M=F^{M}(Y).

So
M
sees that
\theta
maps
A
into
F^{M}(Y)
.

The algebraic or metric-algebraic identities asserting that
\theta

preserves the named operations are absolute once all objects involved
belong to
M
. Injectivity is also absolute, since it is a bounded
statement about the ground-model set
A
.

It remains only to check surjectivity onto the old target. Let

z\in F^{M}(Y)
. Then
z\in F^{N}(Y)
, so in
N
there is some
a\in A

with
\theta(a)=z
. Since
A\in M
and
M
is transitive, this same

a
belongs to
M
. Hence
M
sees that
z
lies in the range
of
\theta
.
∎

Remark 2.4

(Old-part absoluteness)
.

In all applications below, the equality
F^{M}(Y)=F^{N}(Y)\cap M
is
straightforward. For example:

•

\operatorname{Sym}^{M}(Y)=\operatorname{Sym}^{N}(Y)\cap M
;

•

(Y^{Y})^{M}=(Y^{Y})^{N}\cap M
;

•

\mathcal{P}^{M}(Y)=\mathcal{P}^{N}(Y)\cap M
;

•

\operatorname{Rel}^{M}(Y)=\operatorname{Rel}^{N}(Y)\cap M
;

•

for a fixed ground-model ring
R
,

(R^{Y})^{M}=(R^{Y})^{N}\cap M
;

•

if
E,U\in M
, then

\operatorname{End}_{E}^{M}(U)=\operatorname{End}_{E}^{N}(U)\cap M
;

•

\mathscr{O}_{Y}^{M}=\mathscr{O}_{Y}^{N}\cap M
for the many-sorted
full clone on
Y
;

•

\Pi^{M}(Y)=\Pi^{N}(Y)\cap M
for the full partition lattice
on
Y
;

•

under the scalar convention, old bounded, finite-support,

c_{0}
-, or
\ell_{1}
-families are recognised correctly in
M
and
N
.

For
\mathcal{B}(K)
and
\mathcal{K}(K)
, an old function
T:K\to K
which
N
sees
as linear and bounded is already seen as linear and bounded in
M
. For

\mathcal{K}(K)
on a Hilbert space, we use the characterisation

\mathcal{K}(K)=\overline{\mathcal{F}(K)}^{\|\cdot\|},

where
\mathcal{F}(K)
denotes the finite-rank operators. If an old
operator
T:K\to K
belongs to
\mathcal{K}^{N}(K)
, then for every rational

\varepsilon>0
the model
N
contains a finite-rank operator
S

with

\|T-S\|<\varepsilon.

By finite-dimensionality and the Riesz representation theorem, such
an
S
can be written as a finite sum of rank-one operators

x\longmapsto\langle x,u_{j}\rangle v_{j}

with
u_{j},v_{j}\in K
and old scalars; hence
S
is coded by finite
ground-model data and belongs to
M
. Therefore
M
also sees
T
as a
norm-limit of finite-rank operators, and

\mathcal{K}^{M}(K)=\mathcal{K}^{N}(K)\cap M.

Translating to first-order-style definability, we recall that a property

\forall Z\,\varphi(Z,A)
with
\varphi
absolute is downward absolute
from outer transitive models.

Lemma 2.5

(
\Pi^{1}_{1}
-test)
.

Let
\mathcal{C}
be a class of structures definable, uniformly over transitive
models of
\mathsf{ZF}
, by a
\Pi^{1}_{1}
formula of the form

\forall Z\,\varphi(Z,A)
whose matrix
\varphi
is absolute for
transitive submodels. Then
\mathcal{C}
is downward absolute: if

M\subseteq N
are transitive models,
A\in M
, and
N\models A\in\mathcal{C}
, then
M\models A\in\mathcal{C}
.

Proof.

Standard, see
e.g.

[
7
,
10
]
. If
N\models\forall Z\,\varphi(Z,A)
, then in particular
\varphi(Z,A)
holds in
N
for
every
Z\in M
. By absoluteness of the matrix,
M\models\varphi(Z,A)
for every such
Z
, so
M\models\forall Z\,\varphi(Z,A)
.
∎

Consequently, if one can exhibit
M\subseteq M[G]
and
A\in M
with

A\notin\mathcal{C}^{M}
but
A\in\mathcal{C}^{M[G]}
, then
\mathcal{C}
does not admit a

\Pi^{1}_{1}
definition uniform over transitive
\mathsf{ZFC}
-models. The
theorems of Sections
3
and
4
show that this
strategy fails for a large collection of standardness classes, and
exhibit several natural cases where it succeeds.

3.
Unconditional
\mathsf{ZF}
-descent

We gather here the standardness classes that admit canonical
reconstruction already in
\mathsf{ZF}
, and hence are downward absolute under
any outer transitive-model extension.

3.1.
Full symmetric groups

In all that follows,
\operatorname{Sym}(X)
denotes the group of all bijections

X\to X
.

Lemma 3.1

(Definability of transpositions)
.

There is a first-order group formula
\tau(x)
such that, for every
infinite set
X
, the set of elements of
\operatorname{Sym}(X)
satisfying
\tau
is
exactly the set of transpositions.

Proof.

Let

\tau(x):=x\neq 1\ \wedge\ x^{2}=1\ \wedge\ \forall y\,\bigl(x\cdot(yxy^{-1})\bigr)^{6}=1.

We show that, in
\operatorname{Sym}(X)
with
X
infinite,
\tau
defines the
transpositions. Note that
yxy^{-1}
ranges over the full conjugacy
class of
x
as
y
ranges over
\operatorname{Sym}(X)
, so the clause says that
x

multiplied by any of its conjugates has order dividing
6
.

If
x
is a transposition
, then every conjugate
z=yxy^{-1}

is also a transposition, and the product of two transpositions has
order
1
(when they are equal),
2
(when they are disjoint), or
3

(when they share a point). Hence
(xz)^{6}=1
.

Conversely
, suppose
x\in\operatorname{Sym}(X)
is an involution moving at
least four points and not a transposition. We shall produce a conjugate

z=yxy^{-1}
with
(xz)^{6}\neq 1
.

Write
x=\prod_{i\in I}(a_{i}\,b_{i})
as a product of disjoint

2
-cycles, with
|I|\geqslant 2
, the
a_{i},b_{i}\in X
pairwise
distinct across
i
.

Case A.

x
has a fixed point
e\in X
. Since
|I|\geqslant 2
,
pick indices
1,2\in I
, and consider the
5
distinct points
a_{1},b_{1},a_{2},b_{2},e
. Define
\sigma\in\operatorname{Sym}(X)
to act on these five
points as the
5
-cycle
(a_{1}\,b_{1}\,a_{2}\,b_{2}\,e)
and as the identity
on every
2
-cycle
\{a_{i},b_{i}\}
of
x
with
i\geqslant 3
and
everywhere else. Set
z=\sigma x\sigma^{-1}
. A direct computation
shows that
z
acts on
\{a_{1},b_{1},a_{2},b_{2},e\}
as

(b_{1}\,a_{2})(b_{2}\,e)
and agrees with
x
elsewhere. Composing,

xz\text{ acts on }\{a_{1},b_{1},a_{2},b_{2},e\}\text{ as }(a_{1}\,b_{1}\,b_{2}\,e\,a_{2}),

a
5
-cycle, and as the identity off this set. Hence
xz
has order
5

and
(xz)^{6}=xz\neq 1
.

Case B.

x
has no fixed points. Since
X
is infinite and
x

has no fixed point,
x
has infinitely many
2
-cycles; in particular,
it has at least four of them. Pick indices
1,2,3,4\in I
and
consider the
8
distinct points
a_{1},b_{1},\ldots,a_{4},b_{4}
. Define

\sigma\in\operatorname{Sym}(X)
to act on these eight points as the
8
-cycle

(a_{1}\,b_{1}\,a_{2}\,b_{2}\,a_{3}\,b_{3}\,a_{4}\,b_{4})
, and as the identity
on every other
2
-cycle of
x
. Set
z=\sigma x\sigma^{-1}
. Then

z
restricted to
\{a_{1},b_{1},\ldots,a_{4},b_{4}\}
is the involution

(b_{1}\,a_{2})(b_{2}\,a_{3})(b_{3}\,a_{4})(b_{4}\,a_{1})
, and agrees with
x

elsewhere. A direct computation shows

xz\text{ acts on }\{a_{1},b_{1},\ldots,a_{4},b_{4}\}\text{ as }(a_{1}\,a_{4}\,a_{3}\,a_{2})(b_{1}\,b_{2}\,b_{3}\,b_{4}),

i.e.
as a product of two disjoint
4
-cycles, and as the identity
elsewhere. Hence
xz
has order
4
, and
(xz)^{6}=(xz)^{2}=(a_{1}\,a_{3})(a_{2}\,a_{4})(b_{1}\,b_{3})(b_{2}\,b_{4})\neq 1
.

In both cases
\tau(x)
fails, completing the proof.
∎

Remark 3.2
.

For finite
X
, the same formula need not isolate the transpositions:
in
S_{4}
it also detects double transpositions, and in

, since the finite case is handled

the formula does isolate the

\operatorname{Sym}(X)
on an infinite

first-order equivalent to its standard form goes back, in various

]
and

]
; see also
[

,

]
and the

Theorem 3.3

(Canonical reconstruction for
\operatorname{Sym}(X)
)
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
and let
G\in M
be
a group. If

N\models\text{``$G\cong\operatorname{Sym}(X)$ for some set $X$''},

then

M\models\text{``$G\cong\operatorname{Sym}(Y)$ for some set $Y$''}.

Proof.

If
N
sees
G\cong\operatorname{Sym}(X)
with
X
finite, then
G
is finite and
the finite isomorphism is already an element of
M
, which therefore
witnesses the conclusion. We henceforth assume
X
infinite in
N
.

Reconstruction of transpositions.

By Lemma
3.1
there is a formula
\tau(x)

defining transpositions in
\operatorname{Sym}(X)
. In
M
, let

T=\{g\in G:G\models\tau(g)\}.

Since the definition of
T
is a first-order property of
G
, the set

T
is an element of
M
. In
N
, under any isomorphism
G\cong\operatorname{Sym}(X)
,
T
is identified with the full set of transpositions of
X
.

Reconstruction of the underlying set.

For non-commuting
s,t\in T
, define

P(s,t)=\{s,t\}\cup\bigl\{r\in T:rs\neq sr,\ rt\neq tr,\ r\neq sts\bigr\}.

If, in
\operatorname{Sym}(X)
,
s=(a\,b)
and
t=(a\,c)
with
a,b,c

pairwise distinct, then
sts=(b\,c)
, and a transposition
r
fails
to commute with both
s
and
t
precisely when
r=(a\,d)
for some

d\in X\setminus\{a\}
, or
r=(b\,c)
. Thus

P(s,t)=\bigl\{(a\,d):d\in X,\ d\neq a\bigr\}=:E_{a},

the
star of
a
.

Let

Y=\bigl\{P(s,t):s,t\in T,\ st\neq ts\bigr\}\in M.

Two stars
E_{a}
and
E_{a^{\prime}}
with
a\neq a^{\prime}
are distinct, and the map

a\mapsto E_{a}
is a bijection
X\to Y
in
N
. Thus
Y
is a canonical
avatar of the original set
X
, reconstructed from
G
alone.

Reconstruction of the action.

Define, in
M
,

\theta:G\to\operatorname{Sym}^{M}(Y),\qquad\theta(g)(E)=\{grg^{-1}:r\in E\}\quad(E\in Y).

Conjugation by
g
preserves transpositions and non-commutation, and
hence permutes the stars. For each
g\in G
,
\theta(g)
is thus a
permutation of
Y
belonging to
M
. In
N
, after identification with

\operatorname{Sym}(X)
, the map
\theta
is the natural action of
\operatorname{Sym}(X)
on its
set of stars, which is isomorphic to the tautological action on
X
;
in particular,
\theta
is a group isomorphism
G\to\operatorname{Sym}^{N}(Y)
.

By Lemma
2.3
applied to
A=G
, using
\operatorname{Sym}^{M}(Y)=\operatorname{Sym}^{N}(Y)\cap M
, the same
\theta
is an isomorphism
G\to\operatorname{Sym}^{M}(Y)
in
M
. Hence
M
sees
G\cong\operatorname{Sym}(Y)
.
∎

Corollary 3.4

(A uniform
\Pi^{1}_{1}
definition of fullness)
.

The class of groups isomorphic to
\operatorname{Sym}(X)
for some set
X
admits a
uniform
\Pi^{1}_{1}
definition over transitive models of
\mathsf{ZF}
.

Proof.

For each
n<8
, the assertion
G\cong S_{n}
is first-order, since it
is the assertion that
G
is a finite group with a specified
multiplication table. It remains to describe a single
\Pi^{1}_{1}

condition capturing the cases
|X|\geqslant 8
and the infinite cases.

Let
\tau(x)
be the group formula from
Lemma
3.1
. The same proof shows that
\tau

defines the transpositions in
\operatorname{Sym}(X)
whenever
|X|\geqslant 8
, as
well as when
X
is infinite. For
s,t\in G
, write
D(s,t)
for the
first-order condition

\tau(s)\wedge\tau(t)\wedge st\neq ts.

For pairs
(s,t)
satisfying
D
, define the first-order relation

\rho(r;s,t)
by

\rho(r;s,t)\Longleftrightarrow\tau(r)\wedge\bigl(r=s\vee r=t\vee(rs\neq sr\wedge rt\neq tr\wedge r\neq sts)\bigr).

Thus, in an actual symmetric group,
\rho(r;s,t)
says that the
transposition
r
belongs to the star
P(s,t)
.

Define an equivalence relation on pairs satisfying
D
by

(s,t)\equiv(u,v)\Longleftrightarrow D(s,t)\wedge D(u,v)\wedge\forall r\,\bigl(\rho(r;s,t)\leftrightarrow\rho(r;u,v)\bigr).

Let
Y
be the quotient of the definable class of
D
-pairs by this
equivalence relation. This is not introduced as a new parameter in the
formula; it is only a convenient abbreviation for the definable
quotient.

Conjugation gives a definable action on the quotient via

g\cdot(s,t)=(gsg^{-1},gtg^{-1}).

Now let
R
be a second-order variable coding a binary relation on the
set of
D
-pairs. There is a first-order condition, with parameter
R
,
saying that
R
codes a permutation of the quotient
Y=D/{\equiv}
:
namely,
R
is
\equiv
-saturated, total and single-valued
on
\equiv
-classes, and likewise for the inverse relation. Denote this
first-order condition by
\operatorname{Perm}(R)
. Likewise, for

g\in G
, there is a first-order condition
\operatorname{Ind}(g,R)

saying that
R
is the permutation induced by
g
:

\forall(s,t)\,\forall(u,v)\,\Bigl(R\bigl((s,t),(u,v)\bigr)\leftrightarrow(u,v)\equiv(gsg^{-1},gtg^{-1})\Bigr),

with the quantifiers restricted to
D
-pairs.

Consider the sentence
\Phi_{\infty}(G)
asserting

\forall g\,\Bigl[\bigl(\forall(s,t)\,\bigl(D(s,t)\Rightarrow(gsg^{-1},gtg^{-1})\equiv(s,t)\bigr)\bigr)\Rightarrow g=1\Bigr]

and

\forall R\,\bigl(\operatorname{Perm}(R)\Rightarrow\exists g\in G\ \operatorname{Ind}(g,R)\bigr).

The first displayed part says that the conjugation action on the
reconstructed quotient
Y
is faithful; the second says that every
permutation of
Y
is induced by an element of
G
. This is a

\Pi^{1}_{1}
condition: the only second-order quantifier is the universal
quantifier over
R
; all remaining quantifiers are first-order
quantifiers over elements of
G
.

Now suppose
G\models\Phi_{\infty}
. In the ambient transitive model,
form the actual quotient set
Y=D/{\equiv}
. The conjugation action
gives a homomorphism
\theta:G\to\operatorname{Sym}(Y)
; the first part of

\Phi_{\infty}
says that
\theta
is injective, and the second part says
that
\theta
is surjective. Hence
G\cong\operatorname{Sym}(Y)
.

Conversely, if
G\cong\operatorname{Sym}(X)
with
|X|\geqslant 8
or with
X

infinite, then
\tau
defines precisely the transpositions, the
quotient
D/{\equiv}
is exactly the set of point-stars, and the
conjugation action is the natural full action of
\operatorname{Sym}(X)
on
X
.
Thus
G\models\Phi_{\infty}
.

Therefore fullness is defined by the single formula

\Bigl(\bigvee_{n<8}G\cong S_{n}\Bigr)\vee\Phi_{\infty}(G).

Since a finite first-order disjunction with a
\Pi^{1}_{1}
formula is
again equivalent to a
\Pi^{1}_{1}
formula, this gives the desired uniform

\Pi^{1}_{1}
definition.
∎

Remark 3.5

(Atomic permutation groups)
.

The preceding proof separates the first-order and genuinely
second-order parts of fullness. The first-order part reconstructs a
definable quotient
Y
and says that
G
acts faithfully on
Y
by
conjugation. If one adds the first-order clauses saying that the

\tau
-elements act as transpositions on
Y
and that every pair of
distinct points of
Y
is swapped by some
\tau
-element, one obtains
the usual “atomic permutation group” situation:
G
is identified
with a subgroup of
\operatorname{Sym}(Y)
containing all transpositions. Fullness is
then exactly the additional
\Pi^{1}_{1}
assertion that every permutation
of
Y
is induced by an element of
G
.

3.2.
Full transformation monoids

Let
X^{X}
denote the full transformation monoid under composition.

Theorem 3.6
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
and let
S\in M
be
a monoid. If
N\models
“
S\cong X^{X}
for some set

”, then

“
S\cong Y^{Y}

”.

Proof.

Assume

(the empty case is trivial). In

, an

is a constant function if and only if

for
every

: necessity is immediate; sufficiency follows by

itself constant. Hence the set

corresponds in

to the set of constants in

, which is a copy
of

.

Define, in

,

\theta:S\to C^{C},\qquad\theta(s)(c)=sc\quad(c\in C).

Since constants are closed under left multiplication by any element,

\theta
is well-defined, and in
N
it coincides with the standard
identification of
X^{X}
with the full transformation monoid on its set
of constants. By Lemma
2.3
,
\theta
is an isomorphism

in

.
∎

Powerset Boolean algebras

Theorem 3.7
.

Let

be transitive models of
\mathsf{ZF}
and let

”, then

”.

Let

be the set of atoms of

or

,

.
∎

Corollary 3.8
.

The property “

.

In

, every complete atomic Boolean algebra is canonically

,

∎

3.4.
Full relation algebras

Let
\operatorname{Rel}(X)=\mathcal{P}(X\times X)
be the full relation algebra on
X
,
with Boolean operations, relational composition

(R;S)=\{(x,z):\exists y\,(x,y)\in R\wedge(y,z)\in S\}
,
converse
R^{\smile}=\{(y,x):(x,y)\in R\}
, and identity relation

1^{\prime}=\{(x,x):x\in X\}
.

Theorem 3.9
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
, and let
A\in M
be
a relation algebra. If

N\models\text{``$A\cong\operatorname{Rel}(X)$ for some set $X$''},

then

M\models\text{``$A\cong\operatorname{Rel}(Y)$ for some set $Y$''}.

Proof.

In
\operatorname{Rel}(X)
, the atoms of the underlying Boolean algebra are the
singletons
\{(x,y)\}
. Among them, the atoms below the identity
relation
1^{\prime}
are precisely the diagonal atoms
\{(x,x)\}
. Thus the
set

Y=\{a\in A:a\text{ is a Boolean atom and }a\leqslant 1^{\prime}\}

is definable in the relation-algebra structure and is a canonical copy
of
X
.

For
r\in A
, define

\theta(r)=\{(p,q)\in Y\times Y:p;r;q\neq 0\}.

In
N
, after identifying
A\cong\operatorname{Rel}(X)
and
Y
with
X
, this is
exactly the usual identification of a relation with the set of pairs of
points it relates. Hence
N
sees

\theta:A\to\operatorname{Rel}^{N}(Y)

as an isomorphism. Since
\operatorname{Rel}^{M}(Y)=\operatorname{Rel}^{N}(Y)\cap M
, the descent
lemma gives the result in
M
.
∎

3.5.
Full clones

Let
\mathscr{O}_{X}
denote the many-sorted clone of all finitary
operations on a set
X
, with sorts
X^{X^{n}}
for
n<\omega
,
composition, and projections; cf.
[
17
]
. For
X=\emptyset

we use the usual convention: the nullary sort is empty, and every
positive-arity sort is a singleton.

Theorem 3.10
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
, and let
C\in M
be
a many-sorted clone. If

N\models\text{``$C\cong\mathscr{O}_{X}$ for some set $X$''},

then

M\models\text{``$C\cong\mathscr{O}_{Y}$ for some set $Y$''}.

Proof.

If
N
sees
X=\emptyset
, then
C
is the degenerate many-sorted
clone with empty nullary sort and exactly one operation in each
positive arity. This is absolute sort by sort: each sort is either
empty or a singleton, and the unique sort-preserving isomorphism
belongs to
M
. Thus
M
already sees
C\cong\mathscr{O}_{\emptyset}
.
Assume henceforth that
X\neq\emptyset
.

The constant unary operations form a definable copy of the underlying
set: in
\mathscr{O}_{X}
, a unary operation
c
is constant iff
c

equals the composition
c\circ f
for every unary operation
f
. Let

Y
be this set. Every
n
-ary operation acts on
Y^{n}
by substitution
into constants. This gives, in
M
, a clone homomorphism

\theta:C\to\mathscr{O}_{Y}.

In
N
, this is the standard representation of the full clone on its
set of constants, hence an isomorphism onto
\mathscr{O}_{Y}^{N}
. Since
old finitary operations on
Y
are exactly the old elements of

\mathscr{O}_{Y}^{N}
, Lemma
2.3
applies.
∎

3.6.
Full partition lattices

Let
\Pi(X)
denote the lattice of all equivalence relations on
X
,
ordered by refinement, with join equal to the equivalence hull of the
union.

Theorem 3.11
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
, and let
L\in M
be
a lattice. If

N\models\text{``$L\cong\Pi(X)$ for some set $X$''},

then

M\models\text{``$L\cong\Pi(Y)$ for some set $Y$''}.

Proof.

The cases
|X|\leqslant 2
are finite and hence absolute. Assume

|X|\geqslant 3
. In
\Pi(X)
, the atoms are precisely the partitions
obtained from the discrete partition by identifying a single unordered
pair
\{a,b\}
. Thus the atom set of
L
is, in
N
, canonically
identified with the edge set of the complete graph on
X
. Throughout
the proof we write
\{a,b\}
for the atom whose non-trivial block is

\{a,b\}
.

Say that two atoms
s,t
are
triangular
if
s\neq t
and their
join
s\vee t
dominates exactly three atoms. In
\Pi(X)
, this is
equivalent to
s
and
t
sharing a point: if
s=\{a,b\}
and
t=\{a,c\}
, then
s\vee t
is the partition whose non-trivial block is

\{a,b,c\}
and the three atoms below
s\vee t
are
\{a,b\}
,

\{a,c\}
,
\{b,c\}
; while if
s=\{a,b\}
and
t=\{c,d\}
with

\{a,b\}\cap\{c,d\}=\emptyset
, then the atoms below
s\vee t

are only
s
and
t
.

For two triangular atoms
s,t
, let
w(s,t)
denote the unique atom
below
s\vee t
different from both
s
and
t
(in the example above,

w(s,t)=\{b,c\}
). Define, in complete analogy with the
symmetric-group construction,

P(s,t)=\{s,t\}\cup\bigl\{r:r\text{ triangular with both }s\text{ and }t,\ r\neq w(s,t)\bigr\}.

If
s=\{a,b\}
and
t=\{a,c\}
, then an atom
r
is triangular
with both
s
and
t
iff
r
shares a point with each,
i.e.

r\in\{\{a,x\}:x\neq a\}\cup\{\{b,c\}\}
. Excluding
w(s,t)=\{b,c\}
, we obtain the star

P(s,t)=\bigl\{\{a,x\}:x\neq a\bigr\}=:E_{a}.

Set

Y=\bigl\{P(s,t):s,t\text{ triangular atoms of }L\bigr\}\in M.

In
N
,
Y
is canonically bijective with
X
via
a\mapsto E_{a}
.

Finally, recover the lattice structure. If
E,E^{\prime}\in Y
are distinct
stars, then
E\cap E^{\prime}
consists of a unique atom; in
N
, if
E=E_{a}

and
E^{\prime}=E_{b}
, this atom is
\{a,b\}
.

For
\ell\in L
, define a binary relation
R_{\ell}
on
Y
by

E\,R_{\ell}\,E^{\prime}

iff either
E=E^{\prime}
, or
E\neq E^{\prime}
and the unique atom in
E\cap E^{\prime}

lies below
\ell
. Let
\theta(\ell)
be the transitive closure
of
R_{\ell}
. Since
R_{\ell}
is symmetric and reflexive by construction,
its transitive closure is an equivalence relation on
Y
.

In
N
, this is exactly the usual description of a partition by the
graph whose edges are the pairs contained in a common block. Hence
N

sees

\theta:L\to\Pi^{N}(Y)

as an isomorphism. Since
\Pi^{M}(Y)=\Pi^{N}(Y)\cap M
,
Lemma
2.3
yields the conclusion in
M
.
∎

3.7.
Products of finitely generated centrally indecomposable rings

The following
\mathsf{ZF}
-theorem covers many natural finitely generated
ring factors, including finite factors with non-trivial automorphisms.

Theorem 3.12
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
. Let
R\in M
be a
non-zero unital ring with no central idempotents other than
0
and
1
.
Assume that
R
is generated as a unital ring by a finite tuple

\bar{r}=(r_{1},\ldots,r_{m}).

Let
A\in M
be a unital ring. If

N\models\text{``$A\cong R^{X}$ for some set $X$''},

then

M\models\text{``$A\cong R^{Y}$ for some set $Y$''}.

Proof.

The case
X=\emptyset
is trivial, so assume
X\neq\emptyset

in
N
. Let
E
be the Boolean algebra of central idempotents of
A
,
and let

Y=\operatorname{At}(E)\in M.

Since
R
has no non-trivial central idempotents,
N
identifies
Y

with the set of coordinate idempotents of
R^{X}
.

Choose, in
N
, an isomorphism
j:A\to R^{X}
. For each generator

r_{i}
, let
a_{i}\in A
be the unique element such that
j(a_{i})
is the
constant function on
X
with value
r_{i}
. Since
A\in M
, each
a_{i}

belongs to
M
.

For every
e\in Y
we now define a homomorphism

\phi_{e}:R\longrightarrow Ae.

Let
\mathcal{T}_{m}
be the set of ring terms in
m
variables and integer
coefficients, coded by natural numbers in the usual way. Since
\bar{r}

generates
R
as a unital ring, for every
r\in R
there is a term

t\in\mathcal{T}_{m}
such that

r=t^{R}(\bar{r}).

Choose the least such term in the fixed coding, and define

\phi_{e}(r)=t^{A}(\bar{a})\,e,

where
\bar{a}=(a_{1},\ldots,a_{m})
.

This is independent of the choice of representative term. Indeed, if

t^{R}(\bar{r})=u^{R}(\bar{r}),

then, in
N
, after applying the isomorphism
j:A\to R^{X}
, the
elements
t^{A}(\bar{a})\,e
and
u^{A}(\bar{a})\,e
have the same value in
the coordinate corresponding to
e
. Hence they are equal in
Ae
.
Since all objects involved lie in
M
, this equality is absolute.
Therefore
\phi_{e}
is a well-defined unital ring homomorphism in
M
.

In
N
, the map
\phi_{e}
is precisely the coordinate identification
of
R
with the corner
Ae
, and therefore is an isomorphism. Since

R,A,e
and the finite tuple
\bar{a}
all belong to
M
, the
assertion that
\phi_{e}
is a ring isomorphism is absolute; thus
M

also sees that every
\phi_{e}
is an isomorphism.

Define, in
M
,

\theta:A\longrightarrow R^{Y},\qquad\theta(a)(e)=\phi_{e}^{-1}(ae)\qquad(a\in A,\ e\in Y).

In
N
, this is the usual coordinate map
A\cong R^{Y}
. Hence
N
sees

\theta
as an isomorphism
A\to(R^{Y})^{N}
. By
Lemma
2.3
, using
(R^{Y})^{M}=(R^{Y})^{N}\cap M
, the same map
is an isomorphism
A\to(R^{Y})^{M}
in
M
.
∎

Corollary 3.13
.

In
\mathsf{ZF}
, the property “
A\cong R^{X}
for some set
X
” is downward
absolute for each of the following fixed rings
R
:

\mathbb{Z},\qquad\mathbb{Z}/p^{m}\mathbb{Z},\qquad\mathbb{F}_{p^{n}},\qquad M_{k}(\mathbb{F}_{q}),\qquad\mathbb{Z}[t_{1},\ldots,t_{n}].

More generally, the same holds for every finitely generated unital ring
with no non-trivial central idempotents.

Remark 3.14
.

Products
R^{X}
with

a finite non-rigid factor — a finite field

with

, or a matrix ring

— are

-descent examples: they descend already in

.

Thus the usual automorphism-torsor obstruction does not apply to full

of finitely generated factors. (The torsor phenomenon

.)

3.9.
Endomorphism rings

We now pass to reconstructions where the recovered object is not a set

\mathsf{ZF}

,

.

. In

in

. In

.

,

, and in
particular for finite fields. It is also automatic for the prime
field
\mathbb{Q}
, where the isomorphism is the canonical map

q\mapsto q\cdot 1_{E}
.

Corollary 3.19
.

In
\mathsf{ZF}
, the following are downward absolute:

(i)

isomorphism with some full matrix ring
M_{n}(D)
, where

n\geqslant 1
and the division ring
D
are allowed to vary;

(ii)

isomorphism with some
\operatorname{End}_{D}(V)
with
V
admitting a
complemented line.

Proof.

Part (ii) is Theorem
3.17
.

For (i), suppose that
N
sees
A\cong M_{n}(D)
for some

n\geqslant 1
and some division ring
D
. Applying
Theorem
3.17
,
M
obtains a division ring

E=pAp
and a right
E
-module
U=Ap
such that

A\cong\operatorname{End}_{E}(U).

In
N
, the module
U
has an
E
-basis of size
n
. Choose such a
finite basis in
N
. Its elements belong to the ground-model set
U
,
so the finite tuple itself belongs to
M
, and the assertion that it is
an
E
-basis is absolute. Hence
M
sees
U\cong E^{n}
, and therefore

A\cong\operatorname{End}_{E}(E^{n})\cong M_{n}(E).\qed

3.10.
The operator algebras
\mathcal{B}(H)
and
\mathcal{K}(H)

Theorem 3.20
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
, and let
A\in M
be
a unital complex
C^{*}
-algebra. If
N\models
“
A\cong\mathcal{B}(H)
for
some Hilbert space
H
”, then
M\models
“
A\cong\mathcal{B}(K)
for some
Hilbert space
K
”.

Proof.

If
N
sees
H=0
, then
A
is the zero
C^{*}
-algebra, and the
conclusion is immediate. Assume henceforth that
H\neq 0
. In
N
,

A\cong\mathcal{B}(H)
contains a rank-one (
i.e.
minimal) projection
p
,
which lies already in
M
.

Set
K=Ap
in
M
. For
x,y\in K
we have
x^{*}y\in pAp
.
Minimality of
p
yields
pAp=\mathbb{C}p
(this is absolute once
p
is
minimal). Hence there is a unique scalar
\langle x,y\rangle
with

x^{*}y=\langle x,y\rangle p.

The formula above defines an inner product on
K=Ap
in
M
. In
N
,
after identifying
A
with
\mathcal{B}(H)
and
p
with a rank-one projection,
the Hilbert space
K=Ap
is naturally isometric to
H
. Thus
N
sees

K
as complete. Completeness descends to
M
, since every Cauchy
sequence belonging to
M
is also a Cauchy sequence in
N
and has the
same limit in the ground-model set
K
.

Finally, left multiplication

\theta:A\to\mathcal{B}^{M}(K),\qquad\theta(a)(x)=ax

is a
*
-homomorphism in
M
. In
N
,
\theta
is the canonical
faithful representation of
\mathcal{B}(H)
on
H\cong Ap
, which is an
isomorphism onto
\mathcal{B}(K)
. Apply Lemma
2.3
.
∎

Theorem 3.21
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
, and let
A\in M
be
a complex
C^{*}
-algebra. If
N\models
“
A\cong\mathcal{K}(H)
for some
Hilbert space
H
”, then
M\models
“
A\cong\mathcal{K}(K)
for some
Hilbert space
K
”.

Proof.

Assume
H\neq 0
; the zero case is trivial. In
N
, choose a minimal
projection
p\in A
. Since
A\in M
, this projection belongs to
M
.
As in the proof of Theorem
3.20
, define
K=Ap
and give it
the inner product determined by

x^{*}y=\langle x,y\rangle p.

Then
N
identifies
K
with
H
.

Left multiplication defines

\theta:A\longrightarrow\mathcal{B}(K),\qquad\theta(a)(x)=ax.

In
N
, under the identifications

and

, the

is exactly
\mathcal{K}(K)^{N}
. Therefore

sees

\theta:A\to\mathcal{K}(K)^{N}

as a

-isomorphism.

By the old-part absoluteness for

explained in

3.11.
\ell_{1}
as a Banach lattice

Recall that a Banach lattice
\ell_{1}(\Gamma)
with its coordinatewise
order has a distinguished set of
positive normalised atoms
:
unit vectors
u\geqslant 0
with
\|u\|=1
such that
0\leqslant v\leqslant u
implies
v=\alpha u
for some
0\leqslant\alpha\leqslant 1
. These are precisely the standard basis vectors
e_{\gamma}
.

Theorem 3.22
.

Let
M\subseteq N
be transitive models of
\mathsf{ZF}
and let
E\in M
be
a real Banach lattice. If
N\models
“
E\cong\ell_{1}(\Gamma)
isometrically as Banach lattices”, then the same
holds in
M
for some
\Gamma\in M
.

Proof.

Let
Y
be the set of positive normalised atoms of
E
:

y\in Y

iff
y\geqslant 0
,
\|y\|=1
, and whenever
0\leqslant z\leqslant y
there is a scalar
0\leqslant\alpha\leqslant 1
such that

z=\alpha y
. This definition is made in the language of Banach
lattices and hence gives
Y\in M
.

In
N
, under an isometric lattice isomorphism
E\cong\ell_{1}(\Gamma)
,
the set
Y
is exactly the set of standard unit vectors.

For
x\in E_{+}
and
y\in Y
, define

\alpha_{y}(x)=\sup\bigl\{\alpha\in\mathbb{R}_{+}:\alpha y\leqslant x\bigr\}.

In
\ell_{1}(\Gamma)
this is precisely the
y
-coordinate of
x
. For
general
x\in E
, put

\alpha_{y}(x)=\alpha_{y}(x^{+})-\alpha_{y}(x^{-}).

Now define

\theta:E\longrightarrow\ell_{1}(Y),\qquad\theta(x)(y)=\alpha_{y}(x).

In
N
, the map
\theta
is the usual coordinate map from

\ell_{1}(\Gamma)
to
\ell_{1}(Y)
, and is therefore an isometric lattice
isomorphism onto
\ell_{1}^{N}(Y)
. By Lemma
2.3
, and by
old-part absoluteness for
\ell_{1}(Y)
under the scalar convention,

\theta
is an isometric lattice isomorphism
E\cong\ell_{1}^{M}(Y)

in
M
.
∎

4.
\mathsf{ZFC}
-descent and
\mathsf{ZF}
-obstructions

We now turn to standardness properties that are downward absolute in

\mathsf{ZFC}
, but not in
\mathsf{ZF}
. The typical situation is that canonical
reconstruction produces a bundle of locally standard pieces — fibres,
signs, phases, automorphism torsors — which
\mathsf{ZFC}
permits to
trivialise. We begin with the cleanest example, where there are no
completeness or new-sequences caveats.

4.1.
Finite covers: the basic
\mathsf{ZFC}
-only example

Fix an integer
n\geqslant 2
. Let
\mathcal{C}_{n}
be the class of equivalence
relations isomorphic to the standard equivalence relation on

Y\times n
, where

(y,k)\sim(y^{\prime},k^{\prime})\quad\Longleftrightarrow\quad y=y^{\prime}.

Proposition 4.1
.

The class
\mathcal{C}_{n}
is downward absolute between transitive models of

\mathsf{ZFC}
.

Proof.

Let
M\subseteq N
be transitive models of
\mathsf{ZFC}
, and let
(E,\sim)\in M
. If
N
sees
(E,\sim)\cong Y\times n
, then every

\sim
-class has exactly
n
elements. This is absolute to
M
. Let

Q=E/{\sim}
, which belongs to
M
. Since
M\models\mathsf{ZFC}
, choose
in
M
a bijection from each equivalence class onto
\{0,\ldots,n-1\}
.
These choices assemble to an isomorphism

(E,\sim)\cong Q\times n

inside
M
.
∎

Proposition 4.2
.

Let
M\models\mathsf{ZF}
be transitive and suppose that
M
contains a
family
(P_{i})_{i\in I}
of two-element sets with no choice function.
If
N\supseteq M
is an outer transitive model containing a choice
function for this family, then for every fixed
n\geqslant 2
there is
an equivalence relation
(E,\sim)\in M
such that

M\models(E,\sim)\not\cong Y\times n\text{ for every }Y,

but

N\models(E,\sim)\cong I\times n.

Consequently, relative to the existence of such transitive models, the
class
\mathcal{C}_{n}
is not downward absolute in
\mathsf{ZF}
.

Proof.

For each
i\in I
, form an
n
-element set

Q_{i}=P_{i}\times\{0\}\ \cup\ \{(i,k):2\leqslant k<n\}.

The elements
(i,k)
for
2\leqslant k<n
are distinguished
fillers, while the two elements of
P_{i}\times\{0\}
remain unordered.

Let

E=\{(i,q):i\in I,\ q\in Q_{i}\},

and put

(i,q)\sim(j,r)\quad\Longleftrightarrow\quad i=j.

Each equivalence class has exactly
n
elements.

If
M
saw
(E,\sim)\cong Y\times n
, then each class would be
labelled by
\{0,\ldots,n-1\}
. In the class over
i
, look at the
two elements coming from
P_{i}\times\{0\}
and choose the one whose
label is smaller. This gives a choice function for
(P_{i})_{i\in I}
,
contradiction.

On the other hand, any outer transitive model containing a choice
function for
(P_{i})_{i\in I}
can first choose one element from
each
P_{i}
and then label each
Q_{i}
by
\{0,\ldots,n-1\}
. Hence
such an outer model sees

(E,\sim)\cong I\times n.\qed

4.2.
Bare
\ell_{1}(\Gamma)
as a Banach space

Theorem 4.3
.

Let
M\subseteq N
be transitive models of
\mathsf{ZFC}
and let
E\in M
be
a Banach space over the named scalar field
\mathbb{K}
. If
N\models

“
E\cong\ell_{1}(\Gamma)
linearly isometrically”, then the same
holds in
M
for some
\Gamma\in M
.

Proof.

If
E=\{0\}
, then
M
already sees
E\cong\ell_{1}(\emptyset)
, so
there is nothing to prove. Assume henceforth that
E\neq 0
.

The set
D=\operatorname{Ext}(\operatorname{Ball}(E))
of extreme points of the closed unit ball
is definable from the norm. In
\ell_{1}(\Gamma)
, the extreme points
are exactly
\{\lambda e_{\gamma}:\gamma\in\Gamma,\ |\lambda|=1\}
;
cf.
[
11
, Vol. II]
. Let
\mathbb{T}=\{\lambda\in\mathbb{K}:|\lambda|=1\}
act on
D
by scalar multiplication; the
quotient
Y=D/\mathbb{T}
is, in
N
, in bijection with
\Gamma
. Both
D

and
Y
belong to
M
.

Using
\mathsf{ZFC}
in
M
, choose a section
s:Y\to D
. For
x\in E
and

y\in Y
, let
\theta(x)(y)
be the unique scalar
\alpha
minimising

\beta\longmapsto\|x-\beta s(y)\|.

Equivalently,

\|x-\alpha s(y)\|\leqslant\|x-\beta s(y)\|\qquad(\beta\in\mathbb{K}).

In
N
, after identifying
E
with
\ell_{1}(\Gamma)
and
s(y)
with a
chosen unit vector on the corresponding coordinate line, this unique
minimiser is exactly the corresponding coordinate of
x
. Hence
N
sees

\theta
as the usual coordinate map

E\longrightarrow\ell_{1}^{N}(Y).

In particular,
N
sees
\theta
as linear, isometric and onto. By
Lemma
2.3
, using old-part absoluteness for
\ell_{1}(Y)
,
the same map is an isometric linear isomorphism

E\cong\ell_{1}^{M}(Y)

in
M
.
∎

Remark 4.4

(Other
\ell_{p}
spaces)
.

For
1<p<\infty
,
p\neq 2
, analogous
\mathsf{ZFC}
-descent statements
should follow from the Banach–Lamperti description of the surjective
linear isometries of
\ell_{p}(\Gamma)

[
3
]
, after one first
gives an intrinsic definition of the coordinate one-dimensional bands.
We do not need this extension in the present note. The case
p=2
is
basis-dependent and is better treated separately as a Hilbert-space
basis question; see Subsection
4.5
.

4.3.
Bare
c_{00}(\Gamma)
as a normed space

Let
c_{00}(\Gamma)
denote the real or complex vector space of
finitely supported scalar functions on
\Gamma
, equipped with its

\ell_{1}
norm. In Theorem
4.5
the scalar field is the
named field
\mathbb{K}
from Convention
2.1
; in
Proposition
4.7
we specialise to the real case.

Theorem 4.5
.

Let
M\subseteq N
be transitive models of
\mathsf{ZFC}
, and let
E\in M

be a normed space over the named scalar field
\mathbb{K}
. If

N\models\text{``$E\cong c_{00}(\Gamma)$ linearly isometrically
for some set $\Gamma$''},

then

M\models\text{``$E\cong c_{00}(Y)$ linearly isometrically for some
set $Y$''}.

Proof.

The zero space is trivial, so assume
E\neq 0
. Let

D=\operatorname{Ext}(\operatorname{Ball}(E)).

In
c_{00}(\Gamma)
with the
\ell_{1}
norm, the extreme points of the
closed unit ball are exactly

\{\lambda e_{\gamma}:\gamma\in\Gamma,\ |\lambda|=1\}.

Let
\mathbb{T}=\{\lambda\in\mathbb{K}:|\lambda|=1\}
and put

Y=D/\mathbb{T}
. Using
\mathsf{ZFC}
in
M
, choose a section
s:Y\to D
.

For
x\in E
and
y\in Y
, let
\theta(x)(y)
be the unique
scalar
\alpha
minimising

\beta\longmapsto\|x-\beta s(y)\|.

In
N
, this is exactly the
y
-coordinate of
x
. Hence
N
sees

\theta:E\to c_{00}^{N}(Y)

as the standard coordinate isometry. Since old finitely supported
families on
Y
are exactly the old elements of
c_{00}^{N}(Y)
, the
descent lemma yields

M\models E\cong c_{00}^{M}(Y).\qed

4.4.
\mathsf{ZF}
-obstruction: a sign torsor

The use of
\mathsf{ZFC}
in Theorems
4.3
and
4.5
is
essential. The cleanest unconditional torsor obstruction is given by
the finite-support analogue
c_{00}(I)
, which has no completeness or
new-sequence caveat. We treat both forms.

The following obstruction is stated for real normed spaces. A complex
analogue can be formulated using circle torsors, but the real
two-point version is the cleanest and is sufficient for the

\mathsf{ZF}
-failure phenomenon.

Proposition 4.6

(Sign torsors for
\ell_{1}
)
.

Let
M\models\mathsf{ZF}
be transitive, and suppose that
M
contains a
family
(P_{i})_{i\in I}
of two-element sets with no choice function.
For each
i
, let

L_{i}=\Bigl\{f:P_{i}\to\mathbb{R}:\sum_{p\in P_{i}}f(p)=0\Bigr\},

and equip
L_{i}
with the norm

\|f\|=\frac{1}{2}\sum_{p\in P_{i}}|f(p)|.

Thus
L_{i}
is a one-dimensional real normed space, and its unit sphere
is canonically identified with
P_{i}
: the point
p\in P_{i}

corresponds to the function
u_{p}
satisfying

u_{p}(p)=1,\qquad u_{p}(q)=-1

for the other element
q\in P_{i}
.

Form

E=\bigoplus_{i\in I}^{\ell_{1}}L_{i}.

Then
M
does not contain a linear isometry

E\cong\ell_{1}(J)

for any set
J
.

If
N\supseteq M
is an outer transitive model with the same scalar
field, containing a choice function for
(P_{i})_{i\in I}
, and
satisfying the no-new-
\ell_{1}
-vectors conditions

\ell_{1}^{N}(I)=\ell_{1}^{M}(I)

and

\left(\bigoplus_{i\in I}^{\ell_{1}}L_{i}\right)^{N}=\left(\bigoplus_{i\in I}^{\ell_{1}}L_{i}\right)^{M},

then

N\models\text{``$E\cong\ell_{1}(I)$ linearly isometrically''}.

Proof.

The extreme points of the closed unit ball of
E
are exactly the unit
vectors in the summands
L_{i}
. Hence an isometry
E\cong\ell_{1}(J)

would send these extreme points onto
\{\pm e_{j}:j\in J\}
and would
choose, for each
i
, the unique unit vector in
L_{i}
mapped to a
positive basis vector. Since the unit sphere of
L_{i}
is canonically

P_{i}
, this gives a choice function for
(P_{i})_{i\in I}
,
contradiction.

Conversely, a choice function for
(P_{i})
chooses a unit vector

u_{i}\in L_{i}
for every
i
. The map

\sum_{i}\alpha_{i}u_{i}\longmapsto(\alpha_{i})_{i\in I}

is then the desired isometry, because the no-new-vectors hypotheses
ensure that the domain and target computed in
N
are exactly the old
ones.
∎

Proposition 4.7

(Finite-support version)
.

With
(P_{i})
and
L_{i}
as above, put

E_{00}=\bigoplus_{i\in I}^{00}L_{i},

the algebraic finite-support direct sum with its
\ell_{1}
norm. Then

M
does not see
E_{00}
as linearly isometric to
c_{00}(J)
for any
set
J
, but every outer transitive model with the same scalar field
and containing a choice function for
(P_{i})
sees

E_{00}\cong c_{00}(I).

Proof.

The obstruction in
M
is the same as in
Proposition
4.6
: an isometry with
c_{00}(J)

would choose a positive unit vector in each summand
L_{i}
, hence a
choice function for
(P_{i})
.

Conversely, a choice function for
(P_{i})
chooses unit vectors

u_{i}\in L_{i}
, and the finite-support map

\sum_{i\in F}\alpha_{i}u_{i}\longmapsto\sum_{i\in F}\alpha_{i}e_{i}

is a linear isometry
E_{00}\cong c_{00}(I)
. There is no issue about
new supports: finite subsets of ground-model sets are already
ground-model sets. Under the scalar convention, there are no new scalar
coefficients either.
∎

4.5.
Hilbert spaces as
\ell_{2}(\Gamma)

The operator-algebra statement
A\cong\mathcal{B}(H)
is basis-free, but the
standard presentation
H\cong\ell_{2}(\Gamma)
is not.

Proposition 4.8
.

Between transitive models of
\mathsf{ZFC}
, the property

H\cong\ell_{2}(\Gamma)\text{ for some set }\Gamma

is downward absolute for Hilbert spaces
H
over the named scalar field.

Proof.

If
M\models\mathsf{ZFC}
and
H\in M
is a Hilbert space, then
M
contains
an orthonormal basis of
H
by the usual Zorn-lemma argument. Hence

M
already sees
H\cong\ell_{2}(\Gamma)
for some
\Gamma
.
∎

Remark 4.9
.

In
\mathsf{ZF}
, the assertion that every Hilbert space has an orthonormal
basis is a genuine choice principle. Thus a Hilbert space without an
orthonormal basis in a ground model may become isomorphic to

\ell_{2}(\Gamma)
in an outer model which adds such a basis and does not
create additional square-summable coordinate families. This is the
Hilbert-space analogue of the
\ell_{1}
sign-torsor caveat.

5.
Consequences for
\Pi^{1}_{1}
-definability

The preceding results have two different kinds of consequences. For
the canonically reconstructible classes, they show that the usual
forcing strategy for disproving
\Pi^{1}_{1}
-definability cannot work. In
the motivating case of full symmetric groups,
Corollary
3.4
gives the stronger positive conclusion
that fullness itself has a uniform
\Pi^{1}_{1}
definition over transitive

\mathsf{ZF}
-models. For the torsor examples, by contrast, one obtains actual
failures of
\Pi^{1}_{1}
-definability over
\mathsf{ZF}
.

Corollary 5.1
.

Let
\mathcal{C}
be any of the
\mathsf{ZF}
-descent classes proved above; for example

\operatorname{Sym}(X),\quad X^{X},\quad\mathcal{P}(X),\quad\operatorname{Rel}(X),\quad\mathscr{O}_{X},\quad\Pi(X),\quad R^{X}

with
R
finitely generated and centrally indecomposable,

\ell_{\infty}(X),\quad c_{0}(X),\quad\mathcal{B}(H),\quad\mathcal{K}(H),

or
\ell_{1}(X)
as a real Banach lattice. Then there are no transitive models

M\subseteq N
of
\mathsf{ZF}
and no
A\in M
such that

M\models A\notin\mathcal{C}\qquad\text{but}\qquad N\models A\in\mathcal{C}.

In particular, no forcing extension of a
\mathsf{ZFC}
ground model can turn a
non-standard object of one of these kinds into a standard one.

Corollary 5.2
.

For the
\mathsf{ZFC}
-descent classes — bare Banach-space isometry with some

\ell_{1}(\Gamma)
, finite covers
Y\times n
, normed-space isometry
with some
c_{00}(\Gamma)
, and Hilbert-space isomorphism with

\ell_{2}(\Gamma)
— there are no transitive models
M\subseteq N

of
\mathsf{ZFC}
and no
A\in M
such that

M\models A\notin\mathcal{C}\quad\text{but}\quad N\models A\in\mathcal{C}.

Thus the original forcing strategy cannot refute a putative

\Pi^{1}_{1}
definition over transitive
\mathsf{ZFC}
-models.

The next two corollaries are to be read relative to the standard
existence, obtained for example by symmetric-model methods, of
transitive
\mathsf{ZF}
-models containing a family of pairs with no choice
function and an outer transitive model adding such a choice function
and, for the normed-space statement, preserving the named scalar field;
cf.
[
8
,
6
]
.

Corollary 5.3
.

Assume that there are transitive models
M\subseteq N
of
\mathsf{ZF}
such
that
M
contains a family of two-element sets with no choice function
and
N
contains a choice function for that family. Then, for each

n\geqslant 2
, the class of equivalence relations isomorphic to

Y\times n
has no
\Pi^{1}_{1}
definition uniform over transitive

\mathsf{ZF}
-models with absolute matrix.

Proof.

By Proposition
4.2
, this class is not
downward absolute between such transitive
\mathsf{ZF}
-models. But any uniform

\Pi^{1}_{1}
definition with absolute matrix would be downward absolute by
Lemma
2.5
.
∎

Corollary 5.4
.

Under the same transitive-model hypothesis, the property, for real
normed spaces, “is linearly isometric to
c_{00}(J)
for some set

J
” has no
\Pi^{1}_{1}
definition uniform over transitive
\mathsf{ZF}
-models
with absolute matrix.

Proof.

Use Proposition
4.7
and
Lemma
2.5
.
∎

Remark 5.5
.

For the Banach-space property “is linearly isometric to some

\ell_{1}(\Gamma)
”, the same
\mathsf{ZF}
-level non-definability conclusion is
available whenever the sign-torsor construction is carried out inside
outer models preserving the relevant
\ell_{1}
-summable families.
Without that preservation hypothesis, the finite-cover and
finite-support versions are the clean unconditional examples.

6.
Concluding remarks and questions

The examples collected above suggest a general pattern and several
natural open problems.

Question 6.1
.

Is there a syntactic criterion on a functor
F:\mathbf{Set}\to\mathbf{Struct}
equivalent to downward absoluteness, in
\mathsf{ZF}
, of the
class of structures of the form
F(X)
? A candidate condition is that
the isomorphism class of
F(X)
has a
single-sorted definable
skeleton
(in the sense of Rubin
[
14
]
) reconstructing
X
.

Question 6.2
.

Which classes of Banach algebras satisfy
\mathsf{ZFC}
-downward absoluteness
of standardness? For instance, is the property “is isometrically
isomorphic to the group algebra
L^{1}(G)
for some locally compact
abelian group
G
