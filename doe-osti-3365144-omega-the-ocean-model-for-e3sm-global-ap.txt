The Impact
This work enables more detailed and faster simulations of the global ocean, which are essential for improving E3SM and
addressing DOE mission needs. By making ocean models efficient on emerging exascale computers, it opens the door to
higher-resolution Earth system simulations that were previously impractical.

Summary
This study introduces Omega Version 0, the first step toward a new ocean model designed for modern heterogeneous
high-performance computing architectures. Unlike legacy ocean models, Omega is written in C++ using the Kokkos
library to ensure performance portability across CPUs and GPUs. The model solves the shallow water equations with
passive tracers as the first critical step toward a full exascale ready ocean circulation model. Verification tests
demonstrate that Omega produces accurate results consistent with theory and with MPAS-Ocean. Performance
benchmarks show substantial gains: Omega runs about 1.4× faster than MPAS-Ocean on CPUs and 47× on GPUs. Omega
achieves a dramatic improvement in energy efficiency on GPU nodes compared to CPU nodes on exascale systems like
Frontier and Aurora (5.3× per watt on Frontier). These results demonstrate that a ground-up redesign of ocean modeling
software can successfully leverage modern computing architectures, positioning Omega as a next-generation
component of the DOE’s E3SM earth system model for version four.
