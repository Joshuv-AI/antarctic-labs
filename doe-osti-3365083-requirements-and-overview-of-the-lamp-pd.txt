1 Introduction
1.1 LAMP Project Background

 o The Los Alamos Neutron Science Center (LANSCE) is located at Technical Area 53 (TA-53) at
 Los Alamos National Laboratory in Los Alamos, New Mexico. LANSCE is driven by an 800 mega
 electron volt (MeV) proton accelerator that delivered first beam in 1972. The LANSCE
 accelerator is unique in that it accelerates both H- (to full energy of 800 MeV) and H+ ions (up to
 100 MeV currently but has accelerated high-power H+ beam to 800 MeV in the past) and supports
 five separate experimental areas that operate simultaneously with each having different timing and
 beam current requirements. Many of the LANSCE accelerator front end components date back to
 its original commissioning in 1972, including the ion sources, Cockcroft-Walton (CW) generators,
 and the Drift Tube LINAC (DTL) which accelerates the beam up to 100 MeV.
 o The purpose of the LANSCE Accelerator Modernization Project (LAMP) is to replace and
 modernize multiple accelerator systems and components to improve beam delivery, reliability and
 availability. LAMP modernization will improve system maintainability and prepare the facility for
 operation through 2050. The scope of modernization currently includes the LANSCE front end (up
 to 100 MeV). This scope includes modernizing the two ion sources, replacing the two CW
 generators with a modern Radio Frequency Quadrupole (RFQ), and replacing the DTL which
 is exhibiting severe degradation and has significantly exceeded its expected lifespan.
 Modernization of accelerator systems beyond the 100 MeV beam energy are not within the
 currently approved scope of LAMP, however, end-to-end modeling through the entire accelerator
 including the Proton Storage Ring (PSR) will need to be performed to verify the project’s
 performance requirements for all five experimental areas.
 o LAMP will be executed as a congressional line-item project under DOE Order 413.3b for the
 National Nuclear Security Agency (NNSA). The design will follow the Program Requirements
 Document (PRD) for LAMP and other requirements that flow down from the PRD.

2 General System Requirements
2.1 Vault overview and general requirements.

 - To facilitate the control of CAD models and drawings LAMP plans to use a PDM style Vault. To
 this end the project has chosen to use SolidWorks PDM and will model many of the structures of
 the Vault off the existing AOT-MDE Mesa Vault. These structures include file formats, data cards,
 workflows, variables within the workflows, approval structures, hardware libraries, and release
 formats.

 - The three primary requirements for the PDM are:

 1. Serve as a version control repository for all CAD data to ensure a single version of the
 design truth.

 3. Facilitate a controlled review of each component to ensure safe, reliable components that

 we will use a graded approach to ensure that each product, component, and document receives the

2.2.3 Product Grade & Watermarks

 o Due to the nature of the LAMP scope, we will use a graded approach to products. This graded
 approach is like the ML level used by LANL, but the grade level determination will consider
 impact, safety, cost, and use case with the context of LAMP and LANSCE.

 o The purpose of the graded approach is to ensure the proper amount of review and verification
 without bogging down components in the approval and review system.

 o There are four grade levels for use within LAMP. The grade definition as well as the grade
 determination criteria are defined within the LAMP Design Standards.

 o Grade level determines workflow routing and approvals required.

 o Note: On drawing title blocks, grade level will be called out automatically. In addition,
 in any approval field not required by the grade we want to have an N/A assigned.
 (Typically, at release).

 o Grade level will determine final water mark on parts. Watermarks need to be non-editable and
 locked to the drawing.

 o The default watermark on all drawings upon creation of a drawing through approvals is:

 o Preliminary. Not for Fabrication.

2.3 Workflows and Access Control

2.3.1 General Access Control

 o PDM Vault should limit read access to only those within one of the user groups defined within
 the PDM system.

 o PDM Vault should limit write access to only those given permission at the current step.
 Typically, this will only be write access at Under Editing or Revision Under Editing.

 o PDM Vault should limit elevation/promotion to only those in a designated user group given
 promotion or release authority as designated within the Configuration Management Plan,
 LAMP-SE-PLAN-002

2.3.2 User Groups

 o User groups are defined to control access to files and automate assignment in workflows.

 o Individuals will need to be able to be assigned to multiple user groups.

 o Typical PDM User groups are:

 o General Users

  Read access to all files within Vault.

  No write access to CAD files (Parts, Assemblies, Drawings).

  Ability to write imported files.

 o CAD Users

  Editing access to all files within the Under Editing state.

  Ability to elevate files to the Under Checking state.

  Ability to return a file to Under Editing from any state. This change should
 require a comment added to the file that is saved.

  Ability to move a file from Released to Revision Under Editing. This change
 should require a comment and the creation of an electronic ECN.

 o Design Reviewer Group:

  Ability to return files to Under Editing and attached annotated PDF to file.

  Ability to elevate files to Engineering Review.

 o Engineering Review Group:

  Ability to elevate files to Mechanical Review (Grade 1, 2, 3 workflow).

  Ability to release files to R&D Released State (Grade 4 workflow).

  Ability to attach Engineering Analysis DACs to file structure within PDM.

 o Mechanical Review (Final Reviewer in Grade 3 workflow).

  Ability to elevate files to Final Release (Grade 3 workflow).

  Ability to elevate files to SMER (Subject Matter Expert Review) and select

 o Subject Matter Expert Review (Necessary in Grade 1 or Grade 2 Components).

  Ability to attached Committee Review findings and decision document.

 o Project Review (Grade 1 or 2 components).

  Ability to elevate file to Final Release.

  Ability to attach engineering documents to file.
