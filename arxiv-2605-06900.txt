Accelerated Relax-and-Round for Concave Coverage Problems
Matthew Fahrbach, Mehraneh Liaee, Morteza Zadimoghaddam

Abstract
We present an accelerated relax-and-round algorithm for concave coverage problems, which generalize the classic maximum coverage problem. Building on the relax-and-round framework of Barman et al. [ STACS 2021 ], we propose two significant improvements. First, we replace the linear programming (LP) relaxation step with a projected accelerated gradient method applied to a smooth surrogate objective to achieve a O ~ ​ ( m ​ n ​ ε − 1 ) \tilde{O}(mn\varepsilon^{-1}) running time. Second, we use a specialized rounding scheme for the hypersimplex that combines the Carathéodory decomposition algorithm in Karalias et al. [ NeurIPS 2025 ] with randomized swap rounding of Chekuri et al. [ FOCS 2010 ]. We prove tight approximation ratios for new reward functions, including a 0.827 0.827 -approximation for the logarithmic reward φ ⁡ ( x ) = log ⁡ ( 1 + x ) \varphi(x)=\log(1+x) . Finally, we conduct maximum multi-coverage experiments on synthetic and real-world graphs, demonstrating that our algorithm outperforms approaches that use state-of-the-art LP solvers.

Definition 1.1

We start by reviewing the relax-and-round framework in

LP relaxation.

First, extend the reward function
\varphi
to be piecewise linear on the domain
\mathbb{R}_{\geq 0}
:

\varphi(x):=\lambda\varphi(\lfloor x\rfloor)+(1-\lambda)\varphi(\lfloor x\rfloor+1),

where
\lambda=1-(x-\lfloor x\rfloor)\in[0,1]
.
This piecewise linear extension is also concave and nondecreasing.
Now consider the natural linear programming (LP) relaxation:

Concave coverage LP relaxation.

maximize

\displaystyle\sum_{j\in R}w_{j}c_{j}

subject to

\displaystyle y_{j}=\sum_{i\in N(j)}x_{i},~~\forall j\in R

\displaystyle c_{j}\leq\varphi(y_{j}),~~\forall j\in R

\displaystyle\sum_{i=1}^{n}x_{i}=k

\displaystyle 0\leq x_{i}\leq 1,~~\forall i\in L

Each piecewise linear constraint
c_{j}\leq\varphi(y_{j})
can be represented using at most
\deg(j)
linear constraints since

\varphi(x)
is a concave hull and the maximum value of
y_{j}
is
\deg(j)
.
For example, if
\deg(j)=n
, then
c_{j}\leq\varphi(y_{j})
is equivalent to

\displaystyle c_{j}

\displaystyle\leq\varphi(0)+(\varphi(1)-\varphi(0))\cdot(y_{j}-0),

\displaystyle c_{j}

\displaystyle\leq\varphi(1)+(\varphi(2)-\varphi(1))\cdot(y_{j}-1),

\displaystyle~~~~~~~~~~~~~~~~~~~~~~~~~\vdots

\displaystyle c_{j}

\displaystyle\leq\varphi(n-1)+(\varphi(n)-\varphi(n-1))\cdot(y_{j}-(n-1)).\vskip-5.69046pt

Let
\mathbf{x}^{*}\in[0,1]^{n}
be an optimal solution to the LP relaxation.
By extending
C
to the domain
[0,1]^{n}
as in the LP relaxation,
the two functions agree on integral points, i.e.,
C(\mathbf{1}_{S})=C(S)
,
and we have the upper bound

C(\mathbf{x}^{*})\geq C(\mathbf{1}_{S^{*}})=\textnormal{OPT},

(3)

where
S^{*}
is an optimal solution to the discrete problem.

Multilinear extension.

For any set function

f:2^{[n]}\rightarrow\mathbb{R}_{\geq 0}
,
its
multilinear extension

F:[0,1]^{n}\rightarrow\mathbb{R}_{\geq 0}
is defined as

F(\mathbf{x}):=\sum_{S\subseteq[n]}f(S)\prod_{i\in S}x_{i}\prod_{i\not\in S}(1-x_{i}).\vskip-2.84544pt

There is a probabilistic interpretation of the multilinear extension.
For any
\mathbf{x}\in[0,1]^{n}
,
let
S_{\mathbf{x}}
be a random subset where each
i\in[n]

is included independently with probability
x_{i}
, and not included with probability
1-x_{i}
.
Then, the multilinear extension of

is simply
F(\mathbf{x})=\mathbb{E}[f(S_{\mathbf{x}})]

After computing the LP solution
\mathbf{x}^{*}

Pipage rounding can be applied here because

1.

C(S)
is submodular

Smooth approximate coverage function

Building on
7
’s approach,
we present our accelerated relax-and-round algorithm for concave coverage problems.
Our first step is to construct a smooth approximation for
C(\mathbf{x})
.
This allows us to use accelerated projected gradient methods to design a fast approximate LP solver.

Nesterov smoothing for piecewise linear functions.

Let
f:\mathbb{R}^{n}\rightarrow\mathbb{R}
be the piecewise linear concave function

f(\mathbf{x})=\min_{i\in[d]}\left(\mathbf{a}_{i}^{\intercal}\mathbf{x}+b_{i}\right).

Since
f(\mathbf{x})
is not continuously differentiable, we use Nesterov smoothing with an entropy regularizer.

Definition 3.1
.

For any
\mu>0
, the
log-sum-exp (LSE) smoothing
of
f(\mathbf{x})
is

f_{\mu}(\mathbf{x}):=-\mu\log\left(\sum_{i=1}^{d}\exp\left(-\frac{\mathbf{a}_{i}^{\intercal}\mathbf{x}+b_{i}}{\mu}\right)\right).

As
\mu\rightarrow 0
,
f_{\mu}(\mathbf{x})
converges uniformly from below to
f(\mathbf{x})
.
We give the gradient, smoothness, and approximation guarantees of
f_{\mu}(\mathbf{x})

in
Section

B.1
.

Figure 1
:
Examples of LSE smoothing.

Smoothing the coverage function
C(\mathbf{x})
.

We apply LSE smoothing to each
j\in R
.
Start by writing

\varphi_{j}(\mathbf{x}):=\min_{i=1}^{\deg(j)}\left(\mathbf{a}_{j,i}^{\intercal}\mathbf{x}+b_{i}\right),

where

\displaystyle\mathbf{a}_{j,i}

\displaystyle=(\varphi(i)-\varphi(i-1))\mathbf{1}_{N(j)}

\displaystyle b_{i}

\displaystyle=\varphi(i-1)-(\varphi(i)-\varphi(i-1))(i-1).

Definition 3.2
.

For any
\mu>0
, define the
smooth coverage function
as

\widetilde{C}_{\mu}(\mathbf{x}):=\sum_{j\in R}w_{j}\varphi_{j,\mu}(\mathbf{x}).

Note that
\widetilde{C}_{\mu}(\mathbf{x})
is not the same as applying LSE smoothing to
C(\mathbf{x})
, hence the tilde notation.

LSE smoothing is a temperature-controlled softmin, so define the probabilities

\displaystyle p_{j,i}(\mathbf{x})

\displaystyle:=\frac{\exp\left(-(\mathbf{a}_{j,i}^{\intercal}\mathbf{x}+b_{i})/\mu\right)}{\sum_{k=1}^{\deg(j)}\exp(-(\mathbf{a}_{j,k}^{\intercal}\mathbf{x}+b_{k})/\mu)}.

(6)

Lemma 3.3
.

The smooth coverage function
\widetilde{C}_{\mu}(\mathbf{x})
has the following properties:

•

Gradient.

\nabla\widetilde{C}_{\mu}(\mathbf{x})=\sum_{j\in R}w_{j}\mathbf{1}_{N(j)}\sum_{i=1}^{\deg(j)}p_{j,i}(\mathbf{x})\cdot(\varphi(i)-\varphi(i-1)).

•

Smoothness.

Let
d_{R}:=\sum_{j\in R}w_{j}\deg(j)
be the effective degree in
R
. Then,

\lVert\nabla^{2}\widetilde{C}_{\mu}(\mathbf{x})\rVert_{2}\leq\frac{d_{R}}{4\mu}.

•

Approximation.

Let
\mathbf{x}^{*}
be a maximizer of
C(\mathbf{x})
and
\widetilde{\mathbf{x}}_{\mu}^{*}
be a maximizer of
\widetilde{C}_{\mu}(\mathbf{x})
. Then,

C(\mathbf{x}^{*})-\mu\log d_{R}\leq\widetilde{C}_{\mu}(\widetilde{\mathbf{x}}^{*}_{\mu})\leq C(\mathbf{x}^{*}).

Proof sketch.

We give the full proof in
Section

B.2
.
The gradient
\nabla\widetilde{C}_{\mu}(\mathbf{x})
and the approximation guarantees follow from linearity and LSE smoothing properties.
To bound the smoothness, we relate the Hessian
\nabla^{2}\widetilde{C}_{\mu}(\mathbf{x})

to the covariance matrix of the random vector
Y_{j}(\mathbf{x})\mathbf{1}_{N(j)}
, where
Y_{j}(\mathbf{x})
is a discrete random variable over the slopes
\varphi(i)-\varphi(i-1)
with probability mass function
p_{j}(\mathbf{x})
.
The result follows from applying Popoviciu’s inequality.

]

A.1
Poisson concavity ratio lower bound

Lemma A.1
.

For any concave nondecreasing function
\varphi:\mathbb{Z}_{\geq 0}\rightarrow\mathbb{R}
such that
\varphi(0)=0
,

\alpha_{\varphi}\geq 1-\frac{1}{e}.

Proof.

By
7
,
it suffices to show that
\alpha_{\varphi}(k)\geq 1-\nicefrac{{1}}{{e}}
for all positive integers
k
.
We construct a lower bound
f_{k}
for
\varphi
that holds for any choice of
k
.
For
x\leq k
, by the definition of concavity,

\varphi(x)\geq\varphi(k)\frac{x}{k}.

For
x\geq k
, since
\varphi
is nondecreasing,

\varphi(x)\geq\varphi(k).

Combining these two piecewise bounds into a single inequality for
x\geq 0
, let

f_{k}(x):=\frac{\varphi(k)}{k}\min\left(x,k\right).

Now that we have a lower bound for
\varphi
that is purely a multiple of
\min(x,k)
,
fix the value of
k\geq 1
and let
X\sim\textnormal{Pois}(k)
.
It follows that

\displaystyle\alpha_{\varphi}(k)

\displaystyle=\frac{\mathbb{E}[\varphi(X)]}{\varphi(k)}\geq\frac{\mathbb{E}\left[\min\left(X,k\right)\right]}{k}.

Applying
Lemma

D.1
,

\displaystyle\mathbb{E}\left[\min\left(X,k\right)\right]

\displaystyle=k\Pr(X\leq k-2)+k\Pr(X\geq k)

\displaystyle=k\left(1-\Pr\left(X=k-1\right)\right).

Substituting this into our inequality,

\alpha_{\varphi}(k)\geq\frac{k\left(1-\Pr(X=k-1)\right)}{k}=1-\frac{k^{k-1}e^{-k}}{(k-1)!}=1-\frac{k^{k}e^{-k}}{k!}=1-\Pr(X=k).

This value is minimized at
k=1
, which proves the claim.
∎

B.1
Properties of log-sum-exp smoothing

Recall that

\displaystyle f(\mathbf{x})

\displaystyle=\min_{i\in[d]}\left(\mathbf{a}_{i}^{\intercal}\mathbf{x}+b_{i}\right)

\displaystyle f_{\mu}(\mathbf{x})

\displaystyle=-\mu\log\left(\sum_{i=1}^{d}\exp\left(-\frac{\mathbf{a}_{i}^{\intercal}\mathbf{x}+b_{i}}{\mu}\right)\right).

Gradient.

Following
12
,

\nabla f_{\mu}(\mathbf{x})=\sum_{i=1}^{d}p_{i}(\mathbf{x})\mathbf{a}_{i},

(8)

where
p_{i}(\mathbf{x})
is the softmin probability distribution over the pieces:

p_{i}(\mathbf{x})=\frac{\exp\left(-(\mathbf{a}_{i}^{\intercal}\mathbf{x}+b_{i})/\mu\right)}{\sum_{j=1}^{d}\exp\left(-(\mathbf{a}_{j}^{\intercal}\mathbf{x}+b_{j})/\mu\right)}.

Therefore, the gradient
\nabla f_{\mu}(\mathbf{x})
is a convex combination of the
\mathbf{a}_{i}
vectors.

Hessian.

Similarly, following
12
,

\displaystyle\nabla^{2}f_{\mu}(\mathbf{x})=-\frac{1}{\mu}\left[\sum_{i=1}^{d}p_{i}(\mathbf{x})\mathbf{a}_{i}\mathbf{a}_{i}^{\intercal}-\left(\sum_{i=1}^{d}p_{i}(\mathbf{x})\mathbf{a}_{i}\right)\left(\sum_{i=1}^{d}p_{i}(\mathbf{x})\mathbf{a}_{i}\right)^{\intercal}\right].

(9)

Smoothness.

We bound the smoothness constant of
f_{\mu}
by bounding the spectral norm of its Hessian

[
36
, Lemma 1.2.2]
:

\left\lVert\nabla^{2}f_{\mu}(\mathbf{x})\right\rVert_{2}\leq L.

Since
f_{\mu}(\mathbf{x})
is concave,

\nabla^{2}f_{\mu}(\mathbf{x})
is negative semi-definite
and the spectral norm equals the absolute value of the smallest eigenvalue.
By the Courant–Fisher theorem,

\displaystyle\left\lVert\nabla^{2}f_{\mu}(\mathbf{x})\right\rVert_{2}=\left\lvert\lambda_{\min}(\nabla^{2}f_{\mu}(\mathbf{x}))\right\rvert=\max_{\lVert\mathbf{v}\rVert_{2}=1}\left\lvert\mathbf{v}^{\intercal}\nabla^{2}f_{\mu}(\mathbf{x})\mathbf{v}\right\rvert.

For any
\mathbf{v}\in\mathbb{R}^{n}
, the quadratic form is proportional to the negative variance of the discrete
random variable
Z
that takes the value
\mathbf{v}^{\intercal}\mathbf{a}_{i}
with probability
p_{i}(\mathbf{x})
:

-\mathbf{v}^{\intercal}\nabla^{2}f_{\mu}(\mathbf{x})\mathbf{v}=\frac{1}{\mu}\mathrm{Var}_{p(\mathbf{x})}(\mathbf{v}^{\intercal}\mathbf{a}_{i}).

To find the maximum possible variance, we use Popoviciu’s inequality,
which states that the variance of any bounded random variable
Z\in[m,M]
is bounded by
(M-m)^{2}/4
.

For a unit vector
\mathbf{v}
, the maximum difference between any two values of the random variable

Lemma C.2

C.5
Rounding in the hypersimplex

C.5.1
Carathéodory decomposition

A key insight for our rounding strategy is Carathéodory’s theorem, which states that any point
\mathbf{x}
in an
n
-dimensional convex hull
\textnormal{Conv}(P)\subseteq\mathbb{R}^{n}
can be written as a convex combination of at most
n+1
vertices of
P
.
In our case, we want to decompose a fractional solution
\mathbf{x}^{(T)}\in\Delta_{n,k}
,
where
\Delta_{n,k}
is the hypersimplex (the convex hull of all binary vectors in
\{0,1\}^{n}
with exactly
k
ones).
Even though the hypersimplex lives in
\mathbb{R}^{n}
, the constraint
\sum_{i=1}^{n}x_{i}=k

restricts it to an
(n-1)
-dimensional affine subspace.
Thus, the effective dimension is
n-1
and Carathéodory’s theorem
guarantees that any point
\mathbf{x}\in\Delta_{n,k}
can be written as a convex combination of at most
n
vertices.

Computing a Carathéodory decomposition can be expensive, often requiring linear programming,
which is often too slow for large-scale coverage problems.
To solve this, we use the recent combinatorial breakthrough in

as it is a highly efficient way to decompose
\mathbf{x}\in\Delta_{n,k}
into at most
n
vertices.

D.1
Properties of Poisson random variables

Lemma D.1
.

If
X\sim\textnormal{Pois}(x)
and
c\in\mathbb{Z}_{\geq 0}
, then

\mathbb{E}[\min(X,c)]=x\Pr(X\leq c-2)+c\Pr(X\geq c).

Proof.

Observe that

\displaystyle\mathbb{E}[\min(X,c)]

\displaystyle=\sum_{k=0}^{\infty}\min(k,c)\frac{x^{k}e^{-x}}{k!}

\displaystyle=\sum_{k=1}^{c-1}k\frac{x^{k}e^{-x}}{k!}+\sum_{k=c}^{\infty}c\frac{x^{k}e^{-x}}{k!}

\displaystyle=x\sum_{k=1}^{c-1}\frac{x^{k-1}e^{-x}}{(k-1)!}+c\Pr(X\geq c)

\displaystyle=x\sum_{k=0}^{c-2}\frac{x^{k}e^{-x}}{k!}+c\Pr(X\geq c)

\displaystyle=x\Pr(X\leq c-2)+c\Pr(X\geq c).\qed

Lemma D.2
.

Let
X\sim\textnormal{Pois}(x)
.
For any nonnegative concave function
\varphi:\mathbb{Z}_{\geq 0}\rightarrow\mathbb{R}
,

\frac{d}{dx}\mathbb{E}[\varphi(X)]=\mathbb{E}[\varphi(X+1)-\varphi(X)].

Proof.

Observe that

\displaystyle\frac{d}{dx}\mathbb{E}[\varphi(X)]

\displaystyle=\frac{d}{dx}\sum_{k=0}^{\infty}\varphi(k)\Pr(X=k)

\displaystyle=\sum_{k=0}^{\infty}\varphi(k)\frac{d}{dx}\left(\frac{e^{-x}x^{k}}{k!}\right)

\displaystyle=\sum_{k=0}^{\infty}\varphi(k)\left(\frac{ke^{-x}x^{k-1}}{k!}-\frac{e^{-x}x^{k}}{k!}\right)

\displaystyle=\sum_{k=0}^{\infty}\varphi(k)\frac{e^{-x}x^{k-1}}{(k-1)!}-\sum_{k=0}^{\infty}\varphi(k)\frac{e^{-x}x^{k}}{k!}

\displaystyle=\sum_{k=0}^{\infty}\varphi(k+1)\frac{e^{-x}x^{k}}{k!}-\sum_{k=0}^{\infty}\varphi(k)\frac{e^{-x}x^{k}}{k!}

\displaystyle=\mathbb{E}[\varphi(X+1)]-\mathbb{E}[\varphi(X)],

which completes the proof.
∎

Corollary D.3
.

If
X\sim\textnormal{Pois}(x)
, then

\frac{d}{dx}\mathbb{E}[\min(X,c)]=\Pr(X\leq c-1).

Proof.

Applying
Lemma

D.2
,

\displaystyle\frac{d}{dx}\mathbb{E}[\min(X,c)]

\displaystyle=\mathbb{E}[\min(X+1,c)-\min(X,c)]

\displaystyle=\mathbb{E}[\mathbf{1}_{X\leq c-1}]

\displaystyle=\Pr(X\leq c-1),

as desired.
∎

\displaystyle=(1-\beta)\cdot\left[\beta c+\Pr(X\leq c-1)(\beta x+(1-\beta)c)-\beta\mathbb{E}[\min(X,c)]\right]

\displaystyle=(1-\beta)\cdot\left[\beta c+\Pr(X\leq c-1)(\beta x+(1-\beta)c)-\beta(x\Pr(X\leq c-2)+c\Pr(X\geq c))\right]

\displaystyle=(1-\beta)\cdot\left[\beta c+\Pr(X\leq c-1)(\beta x+(1-\beta)c)-\beta(x\Pr(X\leq c-2)+c(1-\Pr(X\leq c-1)))\right]

\displaystyle=(1-\beta)\cdot\left[\Pr(X\leq c-1)(\beta x+(1-\beta)c)-\beta(x\Pr(X\leq c-2)-c\Pr(X\leq c-1))\right]

\displaystyle=(1-\beta)\cdot\left[\Pr(X\leq c-1)(\beta x+(1-\beta)c)-\beta(x\Pr(X\leq c-1)-x\Pr(X=c-1)-c\Pr(X\leq c-1))\right]

\displaystyle=(1-\beta)\cdot\left[\Pr(X\leq c-1)(\beta x+(1-\beta)c-\beta x+\beta c)+\beta x\Pr(X=c-1)\right]

\displaystyle=(1-\beta)\cdot\left[\Pr(X\leq c-1)c+\beta x\Pr(X=c-1)\right]

\displaystyle=(1-\beta)\cdot c\cdot\left[\Pr(X\leq c-1)+\beta\Pr(X=c)\right].

Therefore,

h^{\prime}(x)=\frac{(1-\beta)c\left[\Pr(X\leq c-1)+\beta\Pr(X=c)\right]}{(\beta x+(1-\beta)c)^{2}}\geq 0,

which implies that
\alpha_{\varphi}(x;c,\beta)
is increasing for
x\geq c
.
This finishes the case analysis and completes the proof.
∎
