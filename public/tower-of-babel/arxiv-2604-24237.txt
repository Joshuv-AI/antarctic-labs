Computational Complexity of the Interval Ordering Problem
Simeon Pawlowski, Vincent Froese

Abstract
We study an interval ordering problem introduced by Dürr et al. [Discrete Appl. Math. 2012] which is motivated by applications in bioinformatics. The task is to order a given set of n n intervals with the goal of minimizing a certain objective which is defined via a given cost function f f which assigns a cost to the exposed part of each interval (that is, the pieces not covered by previous intervals). We develop a dynamic programming approach which solves the problem with 𝒪 ⁡ ( 2 n ​ poly ​ ( n ) ) \mathcal{O}\mathopen{}\left(2^{n}\text{poly}(n)\right)\mathclose{} oracle calls to f f and arithmetic operations. Moreover, our approach yields polynomial-time algorithms for all cost functions f f such that f − f ⁡ ( 0 ) f-f(0) is subadditive or superadditive. This answers an open question for the function f ⁡ ( x ) = 2 x f(x)=2^{x} . We contrast these results by proving a running time lower bound of 2 n − 1 2^{n-1} for any algorithm that solves the problem for every function f f (with oracle access only) and further proving NP-hardness for very restricted classes of functions. Thus, we significantly narrow the gap regarding the computational complexity of the problem.

Introduction

We study the
f
-
Interval Ordering
problem introduced by Dürr et al.
[
4
]
where we are given a set
\mathcal{I}
of
n
intervals
I_{j}=[a_{j},b_{j})\subset\real
with
a_{j}<b_{j}
for
j=1,\ldots,n

and the task is to find a total ordering of the intervals that minimizes the overall costs depending on the “exposed parts” of the intervals.
For an ordering
\sigma=(\sigma\mathopen{}\left(1\right)\mathclose{},\ldots,\sigma\mathopen{}\left(n\right)\mathclose{})\in S_{n}
(where
S_{n}
denotes the set of permutations of

I_{j}
is

I_{j}
which is not “covered” by intervals coming before
I_{j}
in

(see
\cref

Note that
E_{\sigma,j}
is a union of disjoint intervals.
Its

is defined as the total sum of the lengths of its individual intervals (an interval
[a,b)
has length

).
Now, a given cost function

assigns a cost to each interval depending on the length of its exposed part.

The
f
-
Interval Ordering
problem is motivated by a problem in biochemistry called protein folding, that is, computing the spatial structure of a protein
(a large molecule consisting of many different atoms linked together).
A simplified version of the problem is to reconstruct the protein backbone, that is, to determine the position of the main string of atoms (a special case of the well-studied distance geometry problem
[
1
,
3
,
6
,
7
,
8
]
).
This problem can be simplified to a certain bitstring reconstruction problem where the goal is to find a binary string such that for given index intervals, the corresponding substring equals an unknown string.
Equality can only be tested via an oracle, which means that one has to try all possible substrings in the worst case.
In short,
f
-
Interval Ordering
with integral intervals and
f(x)=2^{x}
corresponds to finding a process order of the intervals which minimizes the overall number of oracle tests (see Dürr et al.
[
4
, Section 2]
for a detailed exposition and further literature references).
Besides this direct application,
f
-
Interval Ordering
is a natural interval scheduling problem which might find further applications and which we believe to be of independent interest on its own.

Dürr et al.
[
4
]
showed that
f
-
Interval Ordering
is NP-hard for a rather artificial (discontinuous non-monotonic) cost function
f
, but solvable in polynomial time if the input intervals are
agreeable
, that is, there is an ordering induced by the left interval end points which is the same as an ordering induced by the right end points.
They also prove polynomial-time solvability for
laminar
intervals (that is, for every two intervals
I_{i},I_{j}
, either
I_{i}\cap I_{j}=\emptyset
or one is contained in the other) if the function
f-f(0)
is superadditive (note that their NP-hardness result holds for laminar intervals).
Most importantly, they posed the open question whether the problem is polynomial-time solvable for the cost function
f(x)=2^{x}
, which constitutes the motivating use-case in biochemistry.

Our Results.

In this work, we answer this question positively showing that
f
-
Interval Ordering
can be solved in polynomial time for all functions
f
for which
f-f(0)
is superadditive.
Our main contribution is a dynamic programming algorithm described in
\cref
sec:arbitrary-cost that solves
f
-
Interval Ordering
for arbitrary cost functions in
\mathcal{O}\mathopen{}\left(n^{3}\cdot 2^{n}\right)\mathclose{}
time (assuming
f
can be computed in constant time).
The algorithm is based on the key idea to consider all possible exposed (and covered) parts instead of the intervals themselves.
This view allows us to do a refined analysis of the structure of exposed parts in
\cref
sec:polynomial to obtain polynomial-time algorithms for all cost functions
f
where
f-f(0)
is subadditive or superadditive.
We also show that the case of pairwise intersecting intervals can be solved in
\mathcal{O}\mathopen{}\left(n^{5}\right)\mathclose{}
time for arbitrary cost functions.

We complement our algorithmic results in
\cref
sec:hardness by showing a worst-case running time lower bound of
2^{n-1}
for every algorithm solving
f
-
Interval Ordering
for arbitrary
f
with only oracle access to
f
. Notably, this result is also based on considering exposed parts. Hence, our results reveal that the exposed parts are essential for understanding the complexity of the problem.
Moreover, we prove NP-hardness for strictly increasing continuous piecewise linear functions.
Thus, we draw a more precise picture of the complexity landscape for
f
-
Interval Ordering
(see
\cref
tab:results for an overview).
Finally, in
\cref
sec:parameter, we discuss some parameterized complexity results.

Preliminaries

For
n\in\mathbb{N}
, we define
[n]\coloneqq\{1,\ldots,n\}
.
A function
f\colon\left[0,\infty\right)\to\real
is
superadditive
(
subadditive
) if
f\mathopen{}\left(x+y\right)\mathclose{}\geq f\mathopen{}\left(x\right)\mathclose{}+f\mathopen{}\left(y\right)\mathclose{}
(
f\mathopen{}\left(x+y\right)\mathclose{}\leq f\mathopen{}\left(x\right)\mathclose{}+f\mathopen{}\left(y\right)\mathclose{}
) for all
x,y\in\left[0,\infty\right)
.

We consider intervals of the form
I=\left[a,b\right)\subset\real
with
a<b\in\real
.
We call
a
the
start point
and
b
the
end point
of
I
.
The
length

\mathopen{}\left|I\right|\mathclose{}
of
I
is defined as
b-a
.
We say that two intervals
I_{i}
and
I_{j}

touch
each other if they are disjoint and their union is an interval.
For a set
\mathcal{I}=\mathopen{}\left\{I_{1},\ldots,I_{n}\right\}\mathclose{}
of intervals and a permutation
\sigma\in S_{n}
, we call the tuple
\mathopen{}\left(I_{\sigma\mathopen{}\left(1\right)\mathclose{}},\ldots,I_{\sigma\mathopen{}\left(n\right)\mathclose{}}\right)\mathclose{}
a
sequence
of
\mathcal{I}
.
We say that
I_{i}

comes before

I_{j}
if
\sigma^{-1}\mathopen{}\left(i\right)\mathclose{}<\sigma^{-1}\mathopen{}\left(j\right)\mathclose{}
.
For a subset
\mathcal{I}^{\prime}\subseteq\mathcal{I}
, we call
C(\mathcal{I}^{\prime})\coloneqq\bigcup_{I\in\mathcal{I}^{\prime}}{I}
the
covered area
of
\mathcal{I}^{\prime}
.
Note that
C(\mathcal{I}^{\prime})
is a union of some pairwise disjoint intervals.
We call the intervals in the smallest set of intervals whose union equals
C(\mathcal{I}^{\prime})
the
interval components
of
C(\mathcal{I}^{\prime})
(an empty covered area has no interval components).
If
C(\mathcal{I}^{\prime})
is an interval, then we call it a
covered interval
.
We define
\mathcal{C}_{\mathcal{I}}\coloneqq\{C(\mathcal{I}^{\prime})\mid\mathcal{I}^{\prime}\subseteq\mathcal{I}\}
.
Note that the exposed part
E_{\sigma,j}
of
I_{j}
is exactly
I_{j}\setminus C(\mathcal{I}^{\prime})
, where
\mathcal{I}^{\prime}=\{I_{i}\mid\sigma^{-1}\mathopen{}\left(i\right)\mathclose{}<\sigma^{-1}\mathopen{}\left(j\right)\mathclose{}\}
.
Again, we call the intervals of the smallest set of intervals whose union is
E_{\sigma,j}
, the
interval components
of
E_{\sigma,j}
.
We define
\mathcal{E}_{\mathcal{I}}\coloneqq\{E_{\sigma,j}\mid I_{j}\in\mathcal{I},\sigma\in S_{n}\}\setminus\{\emptyset\}
.

Throughout this work, we assume that the cost function
f\colon\left[0,\infty\right)\to\real
is computable and we neglect the time required to compute it and also the running times for arithmetic operations.

3
Arbitrary Cost Functions

In this section, we develop an exponential-time algorithm computing the optimal cost for arbitrary cost functions
f
.
To start with, note that there is a simple standard dynamic programming approach to solve the problem in
\mathcal{O}\mathopen{}\left(2^{n}\cdot\text{poly}(n)\right)\mathclose{}
time:
Use a table to store optimal costs for each subset
\mathcal{I}^{\prime}\subseteq\mathcal{I}
of input intervals. Clearly, each entry can be computed via

\opt(\mathcal{I}^{\prime})=\min_{I_{j}\in\mathcal{I}^{\prime}}(\opt(\mathcal{I}^{\prime}\setminus\{I_{j}\})+f(|I_{j}\setminus\bigcup_{I_{i}\in\mathcal{I}^{\prime}\setminus\{I_{j}\}}I_{i}|)).

However, it is not clear how to adapt this approach to obtain polynomial time for special cost functions (since the table has exponential size).
Therefore, we develop a different approach based on analyzing the structure of optimal solutions in terms of exposed and covered parts.
This leads to a dynamic program with a polynomial-size table which allows us to derive polynomial-time algorithms for special cases in
\Cref
sec:polynomial.

First, note that if
C(\mathcal{I})
has multiple interval components, then we can clearly solve the corresponding subinstances independently and sum up their optimal costs.
Hence, we assume that
C(\mathcal{I})
is an interval.
For
X\subseteq\real
, let
\mathcal{I}_{X}\coloneqq\mathopen{}\left\{I\in\mathcal{I}\mid I\subseteq X\right\}\mathclose{}
be the subset of
\mathcal{I}
induced by
X
and let
\opt(\mathcal{I}^{\prime})
denote the optimal cost of
\mathcal{I}^{\prime}\subseteq\mathcal{I}
(where
\opt(\emptyset)\coloneqq 0
).
The following lemma describes how an optimal solution can be recursively computed based on the possible exposed parts
\mathcal{E}_{\mathcal{I}}
.

\opt(\mathcal{I})=\min\mathopen{}\left\{f\mathopen{}\left(\mathopen{}\left|E\right|\mathclose{}\right)\mathclose{}+\mathopen{}\left(\mathopen{}\left|\mathcal{I}\right|\mathclose{}-\mathopen{}\left|\mathcal{I}_{C\setminus E}\right|\mathclose{}-1\right)\mathclose{}\cdot f\mathopen{}\left(0\right)\mathclose{}+\opt(\mathcal{I}_{C\setminus E})\mid E\in\mathcal{E}_{\mathcal{I}},C\setminus E\in\mathcal{C}_{\mathcal{I}}\right\}\mathclose{}.

Proof 3.3
.

Consider an optimal ordering
\sigma
and let the corresponding sequence be
\mathopen{}\left(I_{1},\ldots,I_{n}\right)\mathclose{}
without loss of generality.
Let
I_{k}
be the last interval that is not completely covered, that is,
E_{\sigma,k}\neq\emptyset
(see
\Cref

Further, let
\mathcal{I}^{\prime}\coloneqq\{I_{1},\ldots,I_{k-1}\}
and
C^{\prime}\coloneqq C(\mathcal{I}^{\prime})=C\setminus E_{\sigma,k}
.
Note that we can assume that no interval from
I_{k+1},\ldots,I_{n}
is completely covered by
C^{\prime}
(that is,
\mathcal{I}^{\prime}=\mathcal{I}_{C^{\prime}}
) since otherwise we could move it directly before
I_{k}
in
\sigma
without changing the cost (since the cost is
f(0)
in both cases).

Hence, we can decompose
\opt(\mathcal{I})
as follows:
First, we have the cost of the intervals
I_{k+1},\ldots,I_{n}
, which are all completely covered. Hence, their cost is
\mathopen{}\left(n-k\right)\mathclose{}\cdot f\mathopen{}\left(0\right)\mathclose{}=(|\mathcal{I}|-|\mathcal{I}_{C^{\prime}}|-1)f\mathopen{}\left(0\right)\mathclose{}
.
Second, we have the cost of
I_{k}
, which is
f\mathopen{}\left(\mathopen{}\left|E_{\sigma,k}\right|\mathclose{}\right)\mathclose{}
.
Finally, we have the cost of the subsequence
\mathopen{}\left(I_{1},\ldots,I_{k-1}\right)\mathclose{}
.
Together, this yields

\opt(\mathcal{I})=f\mathopen{}\left(\mathopen{}\left|E_{\sigma,k}\right|\mathclose{}\right)\mathclose{}+(|\mathcal{I}|-|\mathcal{I}_{C^{\prime}}|-1)\cdot f\mathopen{}\left(0\right)\mathclose{}+\opt(\mathcal{I}_{C^{\prime}}),

which implies

\opt(\mathcal{I})\geq\min\mathopen{}\left\{f\mathopen{}\left(\mathopen{}\left|E\right|\mathclose{}\right)\mathclose{}+\mathopen{}\left(\mathopen{}\left|\mathcal{I}\right|\mathclose{}-\mathopen{}\left|\mathcal{I}_{C\setminus E}\right|\mathclose{}-1\right)\mathclose{}\cdot f\mathopen{}\left(0\right)\mathclose{}+\opt(\mathcal{I}_{C\setminus E})\mid E\in\mathcal{E}_{\mathcal{I}},C\setminus E\in\mathcal{C}_{\mathcal{I}}\right\}\mathclose{}.

The reverse inequality “
\leq
” easily holds since for every
E\in\mathcal{E}_{\mathcal{I}}
with
C\setminus E\in C_{\mathcal{I}}
there exists a sequence
\sigma
which achieves the cost

f\mathopen{}\left(\mathopen{}\left|E\right|\mathclose{}\right)\mathclose{}+\mathopen{}\left(\mathopen{}\left|\mathcal{I}\right|\mathclose{}-\mathopen{}\left|\mathcal{I}_{C\setminus E}\right|\mathclose{}-1\right)\mathclose{}\cdot f\mathopen{}\left(0\right)\mathclose{}+\opt(\mathcal{I}_{C\setminus E}).

First, order all intervals in
\mathcal{I}_{C\setminus E}
optimally. Then, take an interval which has the exposed part
E
, followed by all remaining intervals.

Note that
\opt(\mathcal{I}_{C\setminus E})
can again be computed as the sum of optimal costs of the individual interval components of

.
That is, to compute

.
This leads to a dynamic program which computes optimal costs for all covered intervals in a topological order with respect to the proper subset relation.

.

Proof 3.9
.

Assume that
\mathcal{I}=\mathopen{}\left\{I_{1},\ldots,I_{n}\right\}\mathclose{}
are in descending order of their lengths.
We build the set
\mathcal{E}_{\mathcal{I}}
iteratively.
Let
\mathcal{I}_{k}\coloneqq\mathopen{}\left\{I_{1},\ldots,I_{k}\right\}\mathclose{}
for all
k\in[n]

and consider the set
\mathcal{E}_{\mathcal{I}_{k}}
.
Since
\mathopen{}\left|I_{i}\right|\mathclose{}\geq\mathopen{}\left|I_{k+1}\right|\mathclose{}
for all

, there are no proper subintervals of
I_{k+1}
in
\mathcal{I}_{k}
.
Therefore, the exposed part of
I_{k+1}
in any sequence of
\mathcal{I}_{k+1}
is either empty or an interval

•

whose start point is either the start point of
I_{k+1}
or an end point of some interval in
\mathcal{I}_{k}

•

and whose end point is either the endpoint of
I_{k+1}
or a start point of an interval in
\mathcal{I}_{k}
.

Thus, there are at most
\mathopen{}\left(k+1\right)\mathclose{}^{2}

I_{k+1}
in
\mathcal{E}_{\mathcal{I}_{k+1}}
.
Moreover, for every

, there are the two (possibly identical or empty) exposed parts
E
and

.
That is, we obtain the recursive relation
\mathopen{}\left|\mathcal{E}_{\mathcal{I}_{k+1}}\right|\mathclose{}\leq 2\cdot\mathopen{}\left|\mathcal{E}_{\mathcal{I}_{k}}\right|\mathclose{}+\mathopen{}\left(k+1\right)\mathclose{}^{2}

, where
\mathopen{}\left|\mathcal{E}_{\mathcal{I}_{1}}\right|\mathclose{}=1
.

We now show inductively that
\mathopen{}\left|\mathcal{E}_{\mathcal{I}_{k}}\right|\mathclose{}\leq 6\cdot 2^{k}-k^{2}-4k-6
for all
k\in\mathopen{}\left\{1,\ldots,n\right\}\mathclose{}
.
For

, this is clear.
For

, we have:

\displaystyle\mathopen{}\left|\mathcal{E}_{\mathcal{I}_{k}}\right|\mathclose{}

\displaystyle\leq 2\cdot\mathopen{}\left|\mathcal{E}_{\mathcal{I}_{k-1}}\right|\mathclose{}+k^{2}

\displaystyle\leq 2\cdot\mathopen{}\left(6\cdot 2^{k-1}-(k-1)^{2}-4(k-1)-6\right)\mathclose{}+k^{2}

\displaystyle=6\cdot 2^{k}-2k^{2}+4k-2-8k+8-12+k^{2}

\displaystyle=6\cdot 2^{k}-k^{2}-4k-6

Hence,
\mathopen{}\left|\mathcal{E}_{\mathcal{I}}\right|\mathclose{}\in\mathcal{O}\mathopen{}\left(2^{n}\right)\mathclose{}
.

We compute the set
\mathcal{E}_{\mathcal{I}}
in
n

5
Hardness Results

In this section, we complement our algorithmic results from the previous sections with running time lower bounds and NP-hardness.

5.1
Exponential Running Time Lower Bound

We show that the exponential part of
\mathcal{O}\mathopen{}\left(2^{n}\right)\mathclose{}
in the running time of
\cref
alg:compute-opt from
\cref
sec:arbitrary-cost is basically optimal.
More precisely, we prove that every deterministic algorithm that computes an optimal interval ordering for every
f
without knowledge about
f
(that is, it is only provided an
oracle
for
f
which outputs
f(x)
in constant time) takes at least
2^{n-1}
time (in the worst case).
To prove this lower bound, we show that
f
must be evaluated at all distinct lengths of exposed parts, of which there can be exponentially many.

Lemma 5.27
.

For all
n\geq 2
, there exists a set
\mathcal{I}
of
n
intervals with
|\{|E|\mid E\in\mathcal{E}_{\mathcal{I}}\}|\geq 2^{n-1}
such that, for each
E\in\mathcal{E}_{\mathcal{I}}
, there
is an ordering of
\mathcal{I}
where no interval has an exposed part of length
|E|
.

Proof 5.28
.

Let
\mathcal{I}=\mathopen{}\left\{I_{1},\ldots,I_{n}\right\}\mathclose{}
with
I_{i}\coloneqq\left[2^{i},2^{i+1}\right)
for all
i\in[n-1]
and
I_{n}=\left[0,2^{n}\right)
.
Since
I_{1},\ldots,I_{n-1}
are pairwise disjoint subintervals of
I_{n}
, each
I_{i}
with
i\in[n-1]
has exposed parts of length
2^{i}
and
0
.
Moreover,
I_{n}
has exposed parts of length
2^{n}-\sum_{i\in X}2^{i}
, where
X\subseteq\mathopen{}\left\{1,\ldots,n-1\right\}\mathclose{}
.
Clearly, there are
2^{n-1}
possible sets
X
and each
\sum_{i\in X}2^{i}
is unique (an even number between 0 and
2^{n}-2
).
Hence, the possible lengths of exposed parts are all even numbers between 0 and
2^{n}
.

For each of these lengths, there is an interval ordering where no exposed part has this length.
To see this, note that the sequence
(I_{1},\ldots,I_{n})
has only exposed parts of length
2^{i}
for
i\in[n-1]
.
And for each
i\in[n-1]
, the sequence
(I_{1},\ldots,I_{i-1},I_{i+1},\ldots,I_{n},I_{i})
has no exposed part of length
2^{i}
.

We now show that an algorithm with only oracle access to
f
has to evaluate
f
at all distinct lengths of exposed parts.

Theorem 5.29
.

Let
A
be a deterministic algorithm computing an optimal interval ordering for arbitrary
f
with oracle access to
f
only.
Then, the worst-case running time of
A
is at least
2^{n-1}
.

Proof 5.30
.

Consider the interval set
\mathcal{I}
from
\cref
lem:lower-bound for
n\geq 2
and assume towards a contradiction that
A
outputs an optimal sequence
\sigma
in less than
2^{n-1}
time, that is, without evaluating
f
for all distinct lengths of exposed parts.
Let
L
be the length of an exposed part for which
f(L)
is never queried by
A
.
We define a new cost function
f^{*}
which only differs from
f
at the value
L
such that
\sigma
is suboptimal for
f^{*}
on
\mathcal{I}
.
Note that
A
, however, will still output
\sigma
on
\mathcal{I}
for
f^{*}
since it is deterministic and never queries the value
f^{*}\mathopen{}\left(L\right)\mathclose{}
and
f^{*}
equals
f
on all other values (hence, we obtain a contradiction).

If an exposed part of an interval for
\sigma
has length
L
, then we set
f^{*}\mathopen{}\left(L\right)\mathclose{}\coloneqq M>0
.
Clearly, for large enough
M
, every sequence involving the exposed part length
L
is not optimal for
f^{*}

since there also exists a sequence avoiding all exposed parts of lengths
L
(by construction of
\mathcal{I}
).

Otherwise, if no exposed part appearing in
\sigma
has length
L
, then we set
f^{*}\mathopen{}\left(L\right)\mathclose{}\coloneqq M<0
small enough.
Clearly, now every sequence not involving an exposed part of length
L
is suboptimal for
f^{*}
(by analogous arguments as above).

Note that the above argument relies on choosing an appropriate function
f^{*}
which must have specific values at only finitely many points.
Hence, the lower bound also holds for algorithms that solve
f
-
Interval Ordering
(with oracle access) only for a certain class of functions such as piecewise constant or polynomials.

5.2
NP-Hardness

Dürr et al.
[
4
]
showed NP-hardness for the cost function
f
where

if

is a power of two and
f\mathopen{}\left(x\right)\mathclose{}=x
otherwise.
This function is rather artificial not being superadditive or monotone or continuous (however, it works for integral intervals).
They reduced from the well-known NP-hard
Problem 5.31

(Partition)
.
problem
[
5
]
.

Problem 5.31

(Partition)
.

\blacktriangleright

Input:
A multiset
X=\mathopen{}\left\{x_{1},\ldots,x_{n}\right\}\mathclose{}
of positive integers.

\blacktriangleright

Question:
Is there a subset
X^{\prime}\subseteq X
such that
\sum_{x\in X^{\prime}}{x}=\nicefrac{{1}}{{2}}\cdot\sum_{i=1}^{n}{x_{i}}
?

We strengthen the NP-hardness of
Problem 1.1

(
f
-Interval Ordering)
.

including continuous piecewise linear cost functions.

Theorem 5.32
.

f
-
Interval Ordering
is
NP-hard
if there exist
\varepsilon>0
,
x_{0}>2\varepsilon
, and
c_{1}<c_{2}<c_{3}
(and
h
,
h^{\prime}
) such that

•

f(x)=c_{2}\cdot x
for
x\in\mathopen{}\left[0,2\varepsilon\right]\mathclose{}
,

•

f(x)=c_{1}\cdot x+h
for
x\in\mathopen{}\left[x_{0}-\varepsilon,x_{0}\right]\mathclose{}
, and

•

f(x)=c_{3}\cdot x+h^{\prime}
for
x\in\mathopen{}\left[x_{0},x_{0}+\varepsilon\right]\mathclose{}.

Proof 5.33
.

Consider an instance
X=\mathopen{}\left\{x_{1},\ldots,x_{n}\right\}\mathclose{}
of
Problem 5.31

(Partition)
.
.
We build an instance for
Problem 1.1

(
f
-Interval Ordering)
.
.
Let
S_{k}\coloneqq\sum_{i=1}^{k}{x_{i}}
for all
k\in\mathopen{}\left\{1,\ldots,n\right\}\mathclose{}
and
S_{0}\coloneqq 0
.
We add the intervals
I_{k}\coloneqq\left[\nicefrac{{2\varepsilon S_{k-1}}}{{S_{n}}},\nicefrac{{2\varepsilon S_{k}}}{{S_{n}}}\right)
for all
k\in\mathopen{}\left\{1,\ldots,n\right\}\mathclose{}
to our instance.
These intervals are pairwise disjoint and cover the interval
\left[0,2\varepsilon\right)
.
They represent the integers from
X
, as
\mathopen{}\left|I_{k}\right|\mathclose{}=\nicefrac{{2\varepsilon x_{k}}}{{S_{n}}}
holds for all
k\in\mathopen{}\left\{1,\ldots,n\right\}\mathclose{}
.
We further add the interval
I_{0}\coloneqq[0,x_{0}+\varepsilon)
and set
W\coloneqq f(\varepsilon)+f(x_{0})
.
Note that
I_{0}
contains all other intervals.
So, the exposed length of
I_{0}
will be
\mathopen{}\left|I_{0}\right|\mathclose{}-\sum_{I\in\mathcal{I}^{\prime}}{\mathopen{}\left|I\right|\mathclose{}}\in[x_{0}-\varepsilon,x_{0}+\varepsilon]
, where
\mathcal{I}^{\prime}
is the set of intervals that come before
I_{0}
.

If
X
has a solution
X^{\prime}\subseteq X
,
then we order the intervals such that all intervals
I_{j}
with
x_{j}\in X^{\prime}
come before
I_{0}
and the remaining intervals come after
I_{0}
.
Then, the exposed part of
I_{0}
has length

x_{0}+\varepsilon-\sum_{x_{j}\in X^{\prime}}|I_{j}|=x_{0}+\varepsilon-\sum_{x_{j}\in X^{\prime}}\frac{2\varepsilon x_{j}}{S_{n}}=x_{0}+\varepsilon-\frac{2\varepsilon}{S_{n}}\frac{S_{n}}{2}=x_{0}.

Hence, the overall cost is

\sum_{x_{j}\in X^{\prime}}f(|I_{j}|)+f(x_{0})=c_{2}\sum_{x_{j}\in X^{\prime}}|I_{j}|+f(x_{0})=c_{2}\varepsilon+f(x_{0})=f(\varepsilon)+f(x_{0})=W.

Conversely, assume that there is an interval sequence
\sigma
which has cost at most
W
. Then, let
I^{\prime}
be the subset of intervals coming before
I_{0}
in
\sigma
and let
l_{0}
be the length of the exposed part of
I_{0}
. If
l_{0}=x_{0}+t
for some
t\in(0,\varepsilon]
, then the cost for
I_{0}
is
f(x_{0}+t)=f(x_{0})+c_{3}\cdot t
. Moreover, the intervals in
I^{\prime}
have total length
\varepsilon-t
and their cost is
f(\varepsilon-t)=c_{2}\cdot(\varepsilon-t)
.
Thus, the overall cost is
f(x_{0})+c_{2}\varepsilon+t(c_{3}-c_{2})=W+t(c_{3}-c_{2})>W
since
c_{3}>c_{2}
. Hence, this is not possible.
Analogously, if
l_{0}=x_{0}-t
for
t\in(0,\varepsilon]
, then the overall cost would be

f(x_{0})-c_{1}\cdot t+c_{2}\cdot(\varepsilon+t)=f(x_{0})+c_{2}\varepsilon+t(c_{2}-c_{1})=W+t(c_{2}-c_{1})>W
(as
c_{2}>c_{1}
), which is again a contradiction.
Hence, it follows that
l_{0}=x_{0}
which implies that the intervals in
I^{\prime}
have total length
\varepsilon
. Hence, they correspond to a solution for
X
.

Note that in
\Cref
thm:general-reduction we only fixed the order of the slopes
c_{1}
,
c_{2}
, and
c_{3}
, but not their actual values.
As all these values may be positive (or negative) we obtain the following.

Corollary 5.34
.

f
-
Interval Ordering
is
NP
-hard for continuous strictly increasing (decreasing) piecewise linear cost functions
f
(with only three pieces).

We remark that our reductions do not work for integral input intervals (unlike the reduction by Dürr et al.
[
4
]
).
But we believe that our approach could be adapted to yield NP-hardness for continuous monotonic piecewise linear functions and integral intervals.
The cost function would need multiple nonlinear “kinks” at increasingly large scales.

6
Parameterized Complexity

In this section, we introduce a more fine-grained analysis of the computational complexity of
f
-
Interval Ordering
.
To this end, we identify certain parameters which render the problem tractable when their values are small (constants).
As the exponential part of the running time of our general algorithm depends on the number
\mathopen{}\left|\mathcal{E}_{\mathcal{I}}\right|\mathclose{}
of possible exposed parts,
we aim for parameters which bound this number.

Our first parameter is the maximum number of interval components of any exposed part in
\mathcal{E}_{\mathcal{I}}
, which we call
\alpha_{\mathcal{I}}
.
Note that we have already seen a polynomial-time algorithm for the case that
\alpha_{\mathcal{I}}=1
in
\cref
thm:interval-exposed.
We generalize this result to any constant value of
\alpha_{\mathcal{I}}
(in terms of parameterized complexity, the problem is in XP for parameter
\alpha_{I}
).

Theorem 6.35
.

The size of
\mathcal{E}_{\mathcal{I}}
is bounded in
\mathcal{O}\mathopen{}\left(n^{2\alpha_{\mathcal{I}}}\right)\mathclose{}
. Thus,
f
-
Interval Ordering
is polynomial-time solvable whenever
\alpha_{\mathcal{I}}
is constant.

Proof 6.36
.

Each interval component of an exposed part has at most
n
possible start and end points.
Thus, each exposed part has at most
n^{2}
possible interval components.
So, for each non-empty exposed part, we have at most
\alpha_{\mathcal{I}}
choices, each being one of the at most
n^{2}
interval components.
This yields
\mathcal{O}\mathopen{}\left(n^{2\alpha_{\mathcal{I}}}\right)\mathclose{}
different exposed parts.

To compute
\mathcal{E}_{\mathcal{I}}
, we iterate over all intervals
I
in
\mathcal{I}
and compute all covered intervals that are contained in
I
.
As any exposed part has at most
\alpha_{\mathcal{I}}
interval components, we can partition the covered intervals into at most
\alpha_{\mathcal{I}}-1
sets of pairwise intersecting or touching covered intervals.
Then we just iterate over all combinations of covered intervals to find all exposed parts.
To prevent duplicates, we keep the exposed parts in a balanced search tree.
Thus, we can compute the set
\mathcal{E}_{\mathcal{I}}
in
\mathcal{O}\mathopen{}\left(n^{2\alpha_{\mathcal{I}}+c}\right)\mathclose{}
time for some constant
c
.

It is unclear whether the exponential part of the running time can be solely confined to
\alpha_{\mathcal{I}}
, that is, whether a running time of
g(\alpha_{\mathcal{I}})\cdot n^{\mathcal{O}\mathopen{}\left(1\right)\mathclose{}}
is possible (this is called
fixed-parameter tractability
in parameterized complexity
[
2
]
).
However, for the parameter
s_{\mathcal{I}}
defined as the maximum number of proper subintervals any interval
I\in\mathcal{I}
has in
\mathcal{I}
, fixed-parameter tractability can be shown (note that agreeable intervals have
s_{\mathcal{I}}=0
).

Theorem 6.37
.

The size of
\mathcal{E}_{\mathcal{I}}
is bounded in
\mathcal{O}\mathopen{}\left(n^{2}\cdot 2^{s_{\mathcal{I}}}\right)\mathclose{}
. Thus,
f
-
Interval Ordering
is fixed-parameter tractable with respect to
s_{\mathcal{I}}
.

Proof 6.38
.

Clearly, there are
\mathcal{O}\mathopen{}\left(n^{2}\right)\mathclose{}
possible pairs of first start and last end points of the interval components of any exposed part.
The interval spanned by the first start and last end point of any exposed part has at most
s_{\mathcal{I}}
subintervals in
\mathcal{I}
.
Hence, there are at most
2^{s_{\mathcal{I}}}
different exposed parts for each combination of first start and last end point.
So, overall there are
\mathcal{O}\mathopen{}\left(n^{2}\cdot 2^{s_{\mathcal{I}}}\right)\mathclose{}
possible exposed parts.
It is easy to see that we can compute the set
\mathcal{E}_{\mathcal{I}}
in
\mathcal{O}\mathopen{}\left(n^{c}\cdot 2^{s_{\mathcal{I}}}\right)\mathclose{}

c

7
Conclusion

We took a large step towards settling the computational complexity of the interval ordering problem.
As regards the cost function, we showed broad families of functions to be polynomial-time solvable while we showed NP-hardness already for some very restricted functions.
It might be interesting to further close the gap between the tractable and intractable cases by identifying the specific properties that render a function tractable.
For example, the complexity for subadditive and superadditive functions is open.

Regarding running times, on one side, there is clearly the challenge to improve the polynomial running times.
This may allow experiments on real-world datasets in order to evaluate whether integrating an
f
-
Interval Ordering
solver into actual protein backbone reconstruction algorithms is worth the computation overhead.
On the other side, proving conditional running time lower bounds for the polynomial-time solvable cases would also be interesting.
Moreover, we initiated the study of the parameterized complexity of the problem. It could be fruitful to identify parameters which render instances tractable in practice.
For example, it is open whether the problem is fixed-parameter tractable for the maximum number
\alpha_{\mathcal{I}}
of interval components of any exposed part.
