 If the link latency is controlled to keep a constant phase
 at the receiver, the round-trip link latency will remain con-
 stant, but the one-way link latency will still fluctuate. To
 keep a constant one-way link latency the latency must be
 adjusted symmetrically on both the upstream and down-
 stream links. This could be achieved by adjusting both up-
 stream and downstream TXPIs to the same value. Instead,
 to avoid having to adjust the TXPI on the downstream sys-
 tem, the RXPI on the upstream system can be allowed to
 deviate from zero to compensate by the same amount. The
 upstream TXPI value will be controlled to be equal and op-
 posite to the RXPI value, in other words, they will sum to
 zero. This changes the latency control loop error term and
 results in PISO Parallel Clock and RXRECCLKOUT that
 are offset from MGTREFCLK by the same magnitude but
 in different directions. This allows the latency control loop
