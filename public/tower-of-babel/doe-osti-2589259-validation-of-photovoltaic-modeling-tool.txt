1 Introduction
Solargraf® is a cloud-based 3D design tool that allows users to design solar and storage systems
with elements such as roof pitch, azimuth, height, walls, obstructions, trees, and more. Through a
Cooperative Research and Development Agreement (CRADA), Enphase Energy collaborated
with the U.S. Department of Energy’s National Renewable Energy Laboratory (NREL) to
validate Solargraf’s 3D design simulation against measured PV system performance.

This study followed the same methodology that NREL has used for the verification of other PV
modeling tools (Janine Freeman, 2013; Darice Guittet, 2018). Solargraf designs were set up for
three fixed-tilt systems for which NREL has detailed system specifications, meteorological data,
and measured system performance as described in Table 2 in the methodology section of this
report. The predicted performance results from Solargraf simulations were compared to
measured data to determine tool performance as well as results from SAM to determine
performance in relation to other PV modeling tools.

2 About the Tools
NREL experts validated Solargraf® by comparing results to measured data. In addition,
researchers compared Solargraf results to results of the System Advisor Model (SAM)
2024.12.12 to benchmark Solargraf’s error margins against other photovoltaic modeling
software. Simulation results for Solargraf were calculated using the web-based tool in January
2025.

Solargraf uses SAM’s software development kit (SDK) to do the irradiance computation from
weather file by running the SAM Simulation Core (SSC) software library. This allows Enphase
to integrate SAM’s C++ models directly into Solargraf for irradiance modelling. Solargraf has
their own in-house engine for DC and AC computation using IV curves generated at per module
or submodule level. The loss assumptions for both models differ slightly and are shown in Table
1 below. These default assumptions were used for all three systems that were modeled in this
paper to best represent the case where a model user does not have sufficient information to
update these assumptions.

3 Methodology
Three PV systems from NREL’s South Table Mountain campus were modeled by NREL and
Enphase in both Solargraf® and SAM. Table 2 highlights the important features of the modeled
systems; full system descriptions are available in Freeman 2013, Freeman 2014. Concurrent
meteorological weather and performance data from 2011 and 2012 (depending on the system as
shown below) were selected to model each system. For the purposes of this analysis, hours with
snow or other types of system outages were excluded from the comparison for all systems
modeled in both tools.

Solargraf models shading losses by using simulations of the sun’s path throughout the day and
weather data to calculate irradiance and Solar Access Values (SAVs). Solargraf also considers
shading from roof facets through the Solargraf Shading Engine feature. These shading features
available in Solargraf were used in that tool’s analysis for each of these three systems, whereas
no such shading losses were input into the SAM models for the same systems. The shading from
these features calculated by Solargraf was less than a 3% loss annually for each system, as the
buildings in this analysis represent largely unshaded commercial-scale PV systems.

Solargraf’s annual error of prediction falls between -3.9% and -1.3% which is within the range of
tools examined in previous studies. It is likely that Solargraf’s tendency to predict annual energy
lower than SAM is due to the shading calculations that the tool applies, given that the total losses
applied for each of the two tools, although categorized differently, are quite similar.

It should be noted that any software tool can “predict” exactly the correct annual energy if the
losses are set accordingly, and that one of the more difficult aspects of PV modeling, after
correcting for weather data uncertainty, is setting some of these loss values appropriately
(especially soiling). As mentioned in the Methodology section, we chose to use default loss

5 Conclusion and Discussion
To validate Solargraf®’s system performance, researchers modeled three fixed-tilt systems in
both Solargraf and SAM. Results were compared against measured data to determine accuracy.
Consistent with previous studies, hours including snow or system outages were excluded from
the comparison. Solargraf’s results were comparable with SAM with an annual error of
prediction range between -3.9% and -1.3% and an hourly normalized RMSE range between 2.9%
and 4.7% . Monthly normalized production shows that Solargraf has a seasonal monthly
variation error which is consistent with SAM and other modeling tools. Ultimately, this
validation shows that Solargraf’s predictions are comparable with SAM. Further validation with
other PV system types and locations would provide further information about the accuracy of
Solargraf. This study does not comment on the usability of Solargraf.
