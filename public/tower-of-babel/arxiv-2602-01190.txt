Translating measurable sets
M. Laczkovich

Abstract
We prove that if A , B A,B are compact subsets of ℝ {\mathbb{R}} such that the upper density of B B is positive at every point of B B , then there is a closed null set N ⊂ A N\subset A such that N + B = A + B N+B=A+B . As a corollary we find that if A , B ⊂ ℝ A,B\subset{\mathbb{R}} are measurable, and every null subset N N of A A can be translated into B B (that is, if B B contains a suitable translate of N N ), then there is a null set N 0 N_{0} such that A ∖ N 0 A\setminus N_{0} can be translated into B B . The topic is related to some consistency results of the theory of additive properties of the reals.

Introduction and main results

We say that the set
A\subset{\mathbb{R}}
can be translated into the set
B
if
there exists a real number
x
such that
A+x=\{a+x\colon a\in A\}\subset B
.
The Lebesgue measure of the set
A\subset{\mathbb{R}}
is denoted by
|A|
. A set

N\subset{\mathbb{R}}
is
null
, if
|N|=0
.

We start with the following question. Suppose
A
and
B
are measurable subsets
of
{\mathbb{R}}
such that every null subset of
A
can be translated into
B
.
Does this condition imply that
A
can be translated into
B
? The answer is
negative: if
N
is a singleton (or more generally a nonempty and countable set)
and
B={\mathbb{R}}\setminus N
, then every null set can be translated into
B
, but
{\mathbb{R}}

cannot be translated into
B
. We prove, however, the following.

Theorem 1.1
.

If
A,B\subset{\mathbb{R}}
are measurable, and every null subset of
A
can be translated
into
B
, then there is a null set
N\subset A
such that
A\setminus N
can be translated
into
B
.

If
B
is closed, then the statement of Theorem
1.1
is obvious; moreover,
we can conclude that
A
can be translated into
B
. Indeed, let
C
be a
countable subset of
A
such that the closure of
C
equals
A
. Clearly, if

C
can be translated into
B
and
C+x\subset B
, then
A+x\subset B
. We show that
the same conclusion holds if
B
is a
G_{\delta}
set which is closed in the density
topology.

We denote by
d(A,x)
and by
\overline{d}(A,x)
the density and the upper density
of the set
A\subset{\mathbb{R}}
at the point
x
. A set
G\subset{\mathbb{R}}
is said to be
d
-open
if
G
is Lebesgue measurable and
d(A,x)=1
for every
x\in A
.
The
density topology
is defined as the collection of all
d
-open sets.
It is well known that the density topology is a completely regular Hausdorff
topology on
{\mathbb{R}}
(see
[
6
, pp. 148-152]
). A set
B\subset{\mathbb{R}}
is
d
-closed
if
{\mathbb{R}}\setminus B
is
d
-open; that is, if
B
contains every
point
x
such that
\overline{d}(B,x)>0
.

Theorem 1.2
.

Let
A\subset{\mathbb{R}}
be Lebesgue measurable, and suppose that
B\subset{\mathbb{R}}
is
d
-closed
and is
G_{\delta}
in the Euclidean topology. If every null subset of
A
can be
translated into
B
, then
A
can be translated into
B
.

Theorem
1.2
implies Theorem
1.1
. Indeed, suppose
A,B
are measurable,
and every null subset of
A
can be translated into
B
. Let
B_{1}=B\cup\{x\in{\mathbb{R}}\colon\overline{d}(B,x)>0\}
. Then
B_{1}
is
d
-closed, and
B_{1}\setminus B

is null by the Lebesgue density theorem. Let
B_{2}
be a
G_{\delta}
set such that

B_{1}\subset B_{2}
and
B_{2}\setminus B_{1}
is null. Then
B_{2}
is also
d
-closed, and

B_{2}\setminus B
is a null set. Since every null subset of
A
can be translated
into
B_{2}
,
A
can be translated into
B_{2}
by Theorem
1.2
. If
A+x\subset B_{2}
, then
(A\setminus N)+x\subset B
, where
N=(B_{2}\setminus B)-x
is a null set,
proving Theorem
1.1
.

The condition that
A
can be translated into
B
can be formulated in terms
of sums of sets as follows. If
B\subset{\mathbb{R}}
, then we denote
-B=\{-x\colon x\in B\}
and
B^{c}={\mathbb{R}}\setminus B
. The set
\{a+b\colon a\in A,\ b\in B\}
is
denoted by
A+B
.

Lemma 1.3
.

For every
A,B\subset{\mathbb{R}}
, the following are equivalent.

(i)

A
cannot be translated into
B
.

(ii)

A+(-B^{c})={\mathbb{R}}
.

Proof.
The set
A
cannot be translated into
B
if and only if for every
x\in{\mathbb{R}}

there is an
a\in A
such that
x+a\notin B
; that is,
x+a\in B^{c}
. Thus
(i)
\iff x\in(-A)+B^{c}
for every
x\in{\mathbb{R}}\iff(-A)+B^{c}={\mathbb{R}}\iff A+(-B^{c})={\mathbb{R}}
.
\square

According to the lemma above, the statement of Theorem
1.2
is equivalent
to the following.
Suppose that
A
is measurable, and
B
is
d
-open and

F_{\sigma}
. If
A+B={\mathbb{R}}
, then there is a null set
N\subset A
such that
N+B={\mathbb{R}}
.

We will prove somewhat more.

Theorem 1.4
.

Suppose that
A
is measurable,
B
is
F_{\sigma}
, and
\overline{d}(B,x)>0
for every

x\in B
. Then there is a null set
N\subset A
such that
N+B=A+B
.

We can say more if
A
and
B
are compact.

Theorem 1.5
.

Let
A,B
be compact subsets of
{\mathbb{R}}
such that
\overline{d}(B,x)>0
for every

x\in B
. Then there is a closed null set
N\subset A
such that
N+B=A+B
.

Theorems
1.4
and
1.5
will be proved in the next section.

We conclude with some remarks and problems.

Remarks on Theorem
1.1
.
We may ask if the following, stronger
statement is true.

(T):
If
A,B\subset{\mathbb{R}}
are measurable, and every null subset of
A

can be translated into
B
, then there is a countable set
C\subset A
such that

A\setminus C
can be translated into
B
.

The answer is negative, at least consistently. A set
N
is called
strongly
meager
if every null set can be translated away from
N
. Therefore, if
N
is
an uncountable strongly meager set, then every null set can be translated into

{\mathbb{R}}\setminus N
, but
{\mathbb{R}}\setminus C
cannot be translated into
{\mathbb{R}}\setminus N
for any
countable set
C
. It is consistent with ZFC that there are strongly
meager sets of cardinality continuum (see
[
2
, Corollary 8.20, p. 304]
),
and thus (T) is consistently false.

On the other hand, it is also consistent with ZFC that every strongly
meager set is countable (see
[
2
, Metatheorem 9.2, p. 385]
). Thus (T)
is consistently true in the case
A={\mathbb{R}}
. This motivates the following
questions.

Problem 1.6
.

Is
(T)
consistent with
ZFC
?

Problem 1.7
.

Suppose that
A,B\subset{\mathbb{R}}
are Borel. Is it true that if every null subset
of
A
can be translated into
B
, then there is a countable set
C\subset A

such that
A\setminus C
can be translated into
B
?

Remarks on Theorem
1.4
.
It is clear that some condition on
B
is
necessary: if
|A|>0
and
B
is countably infinite, then the conclusion of
the theorem is false. More generally, suppose that
B
is nonempty and has the
property that
N+B
is null for every null set
N
. It is obvious that if

|A|>0
, then
N+B\neq A+B
for every null set
N\subset A
. It
is known that under Martin’s axiom there is such a set
B
of cardinality
continuum
[
5
]
. See also
[
4
, Theorem 12]
, where such a set is
constructed under (CH). By
[
4
, Theorem 13]
, it is also consistent
with ZFC that there is a coanalytic set
B
with the properties above.

Problem 1.8
.

Let
(S)
denote the following statement: if
A,B\subset{\mathbb{R}}
are measurable
and
B
is uncountable, then there is a null set
N\subset A
such that

N+B=A+B
. Is
(S)
consistent with
ZFC
?

Note that (S) implies (T). Indeed, suppose that
A,B
are measurable, and
every null subset of
A
can be translated into
B
. If
B^{c}
is countable,
then
A\setminus B^{c}
can be translated into
B
; in fact,
A\setminus B^{c}\subset B
. Suppose
that
B^{c}
is uncountable. If
N
can be translated into
B
, then

N+(-B^{c})\neq{\mathbb{R}}
by Lemma
1.3
. If this is true for every null set

N\subset A
, then
A+(-B^{c})\neq{\mathbb{R}}
by (S), and thus
A
can be translated into

B
. Therefore, if (S) is consistent with ZFC then so is (T).

Remarks on Theorem
1.5
.

The Erdős-Kunen-Mauldin theorem states that
if
B\subset{\mathbb{R}}
is a nonempty
perfect set, then there is a perfect null set
N\subset{\mathbb{R}}
such that
N+B={\mathbb{R}}
.
(See
[
4
, Theorem 1]
and also
[
3
]
, where a stronger statement is
proved.) A common generalization of the Erdős-Kunen-Mauldin theorem and
Theorem
1.5
would be the following: if
A,B
are nonempty perfect sets,
then there is a
closed
null set
N\subset A
such that
N+B=A+B
.
Unfortunately, this is false, as we show in Section 3.

Problem 1.9
.

Suppose that
A,B\subset{\mathbb{R}}
are perfect. Is it true that
N+B=A+B
for
a suitable (not necessarily closed) null set
N\subset A
?

Proof of Theorems
1.4
and
1.5

Lemma 2.1
.

If
A
is measurable and
0<|A|<\infty
, then for every
\varepsilon>0
there
is a compact set
P\subset A
such that
|A\setminus P|<\varepsilon
and
\overline{d}(P,x)\geq 1/2
for
every
x\in P
.

Proof.
Let
\varepsilon>0
be given, and let
\varepsilon_{0},\varepsilon_{1},\ldots
be positive numbers
such that
\sum_{k=0}^{\infty}\varepsilon_{k}<\varepsilon
. Let
K
be a compact subset of
A

such that
|A\setminus K|<\varepsilon_{0}
.

Let
{\cal I}
denote the set of closed intervals
I
such that
|I|<1
and

|I\cap K|>|I|/2
. Then
{\cal I}
is a Vitali cover of the set of density
points of
K
. By the Vitali covering theorem, there is a sequence

I_{1}^{1},I_{2}^{1},\ldots
of pairwise disjoint elements of
{\cal I}
such that they
cover a.e. density point of
K
, hence a.e. point of
K
. Then there
is an integer
N_{1}
such that
|K\setminus P_{1}|<\varepsilon_{1}
, where
P_{1}=\bigcup_{n=1}^{N_{1}}I_{n}^{1}
.

Repeating the argument above in each of the intervals
I_{n}^{1}
we obtain the
pairwise disjoint closed intervals
I_{1}^{2},\ldots,I_{N_{2}}^{2}
and the set

P_{2}=\bigcup_{n=1}^{N_{2}}I_{n}^{2}
with the following properties:

\bullet

For every
1\leq n\leq N_{2}
there is an
m
such that
I_{n}^{2}\subset I_{m}^{1}
;

\bullet

|I_{n}^{1}\cap P_{2}\cap K|>|I_{n}^{1}|/2
for every
n=1,\ldots,N_{1}
;

\bullet

|I_{n}^{2}|<1/2
and
|I_{n}^{2}\cap K|>\tfrac{2}{3}\cdot|I_{n}^{2}|
for every

1\leq n\leq N_{2}
;

\bullet

|K\setminus P_{2}|<\varepsilon_{2}
.

Repeating this construction we obtain, for every
k\geq 2
, the
pairwise disjoint closed intervals
I_{1}^{k},\ldots,I_{N_{k}}^{k}
and the set

P_{k}=\bigcup_{n=1}^{N_{k}}I_{n}^{k}
with the following properties:

\bullet

For every
1\leq n\leq N_{k}
there is an
m
such that
I_{n}^{k}\subset I_{m}^{k-1}
;

\bullet

|I_{n}^{j}\cap P_{k}\cap K|>\tfrac{j}{j+1}\cdot|I_{n}^{j}|
for every

j=1,\ldots,k-1

and
n=1,\ldots,N_{j}
;

\bullet

|I_{n}^{k}|<1/k
and
|I_{n}^{k}\cap K|>\tfrac{k}{k+1}\cdot|I_{n}^{k}|
for every

1\leq n\leq N_{k}
;

\bullet

|K\setminus P_{k}|<\varepsilon_{k}
.

Let
P=\bigcap_{k=1}^{\infty}P_{k}
. Then
P
is closed,
P\subset K\subset A
,
|A\setminus P|<\varepsilon
, and
\overline{d}(P,x)\geq 1/2
for every
x\in P
. Indeed, if
x\in P
, then
there are integers
n_{k}
such that
x\in I_{n_{k}}^{k}

(k=1,2,\ldots)
. For every

k
we have

|I_{n_{k}}^{k}\cap P|=\lim_{m\to\infty}\left|I_{n_{k}}^{k}\cap P_{m}\right|\geq\tfrac{k}{k+1}\cdot|I_{n_{k}}^{k}|.

Putting
J_{k}=[x-h_{k},x+h_{k}]
, where
h_{k}=\min\{h\geq 0\colon I_{n_{k}}^{k}\subset[x-h,x+h]\}
, we obtain
|J_{k}|\leq 2|I_{n_{k}}^{k}|
and
\liminf_{k\to\infty}|J_{k}\cap P|/|J_{k}|\geq 1/2
, proving
\overline{d}(P,x)\geq 1/2
.
\square

The following lemma is a variant of the Luzin-Menchoff theorem

[
1
, Theorem 6.4, p. 20]
).

Lemma 2.2
.

Suppose that
A
is measurable,
F\subset A
is compact, and
\overline{d}(A,x)>0
for
every
x\in F
. Then there is a compact set
P
such that
F\subset P\subset A
and

\overline{d}(P,x)>0
for every
x\in P
.

Proof.
Let
a=\min F
and
b=\max F
. We may assume that the right upper
density of
A
at the point
a
is positive. Indeed, otherwise the left upper
density of
A
at
a
must be positive, and then
|A\cap(-\infty,a)|>0
.
In this case there is a density point
a_{1}
of
A
such that
a_{1}<a
, and
then we can replace
F
by
F\cup\{a_{1}\}
. Similarly, we may assume that
the left upper density of
A
at the point
b
is positive.

Let
(a_{n},b_{n})

(n=1,2,\ldots)
be the components of
[a,b]\setminus F
. For
every
n
, let
(x_{k}^{n})_{k=-\infty}^{\infty}
be a sequence such that
a_{n}<x_{k}^{n}<x_{k+1}^{n}<b_{n}
for every integer
k
,
\lim_{k\to-\infty}x_{k}^{n}=a_{n}
and

\lim_{k\to\infty}x_{k}^{n}=b_{n}
and

\lim_{k\to-\infty}(x^{n}_{k+1}-x^{n}_{k})/(x_{k}^{n}-a_{n})=\lim_{k\to\infty}(x^{n}_{k+1}-x^{n}_{k})/(b_{n}-x_{k+1}^{n})=0.

By Lemma
2.1
, for every
n
and
k
there is a compact set

P_{k}^{n}\subset[x_{k}^{n},x_{k+1}^{n}]\cap A
such that
|P_{k}^{n}|\geq|[x_{k}^{n},x_{k+1}^{n}]\cap A|/2
, and
\overline{d}(P_{k}^{n},x)\geq 1/2
for every
x\in P_{k}^{n}
. (If

[x_{k}^{n},x_{k+1}^{n}]\cap A
is null, then we choose
P_{k}^{n}=\emptyset
.)

We put
P=F\cup\bigcup_{n=1}^{\infty}\bigcup_{k=-\infty}^{\infty}P_{k}^{n}
.
Then
P
is compact,
F\subset P\subset A
, and it is easy to check that

\overline{d}(P,x)>0
for every
x\in P
.
\square

Proof of Theorem
1.5

Let
A,B\subset{\mathbb{R}}
be compact, and suppose that the upper density of
B
is
positive at every point of
B
.

Let
{\cal N}
denote the family of those closed subsets of
A
for which

N+B=A+B
. Then
{\cal N}
is nonempty, as
A\in{\cal N}
. If
N_{1}\supset N_{2}\supset\ldots
is a nested sequence of elements of
{\cal N}
and
N=\bigcap_{i=1}^{\infty}N_{i}
, then
N\in{\cal N}
. Indeed, let
x\in A+B
be arbitrary. For every
i

we have
N_{i}\in{\cal N}
, and thus
x=y_{i}+z_{i}
, where
y_{i}\in N_{i}
and

z_{i}\in B
. There is a sequence of indices
i_{k}
such that the subsequences

y_{i_{k}}
and
z_{i_{k}}
are convergent. If
y_{i_{k}}\to y
and
z_{i_{k}}\to z
, then

y\in N
,
z\in B
and
y+z=x
, proving
x\in N+B
. Since this is true for every

x\in A+B
, we have
N+B\supset A+B
and
N\in{\cal N}
.

It is well known that every transfinite and strictly decreasing sequence of
closed subsets of
{\mathbb{R}}
is countable. (See
[
7
, Theorem 51, p. 66]
.)
Therefore, the intersection of every transfinite and strictly decreasing
sequence of the elements of
{\cal N}
belongs to
{\cal N}
. This implies that
{\cal N}

contains a minimal element (with respect to inclusion). Let
N\in{\cal N}
be
a minimal element of
{\cal N}
; we prove that
N
is null.

Suppose
|N|>0
, and let
a\in N
be a density point of
N
. Since
N

is minimal,
N_{n}=N\setminus(a-1/n,a+1/n)\notin{\cal N}
for every
n=1,2,\ldots
.
Thus
N_{n}+B\neq A+B=N+B
, and we can choose an element
c_{n}\in(N+B)\setminus(N_{n}+B)
. Then
c_{n}=a_{n}+b_{n}
for suitable
a_{n}\in N
and
b_{n}\in B
,
and whenever
c_{n}=x+y
with
x\in N
and
y\in B
, then
x\in(a-1/n,a+1/n)
.
In particular, we have
a_{n}\in(a-1/n,a+1/n)
.

Turning to a suitable subsequence, we may assume that the sequence
b_{n}

is convergent. Suppose
b_{n}\to b
, then
b\in B
. We have
\overline{d}(B,b)>0
by
assumption, and thus the set
b-B
has positive upper density at the origin.
Since the origin is a density point of
N-a
, it follows that

(N-a)\cap(b-B)
is of positive measure. Let
|(N-a)\cap(b-B)|=m
.

It is well known, and is easy to prove, that if
E,F\subset{\mathbb{R}}
are measurable,
then the function
h\mapsto|E\cap(F+h)|
is continuous. Thus the function

h\mapsto m(h)=|(N-a)\cap(b+h-B)|
is continuous. Since
m(0)=m>0
,
there is a
\delta>0
such that
|(N-a)\cap(b+h-B)|>m/2
for every
|h|<\delta
.

Put
Q_{h}=(N-a)\cap(b+h-B)
. If
u\in Q_{h}
, then
u+a\in N
,
b+h-u\in B
,
and
a+b+h=(u+a)+(b+h-u)
. If
|h|<\delta
, then it follows from

|Q_{h}|>m/2
that there are elements
u_{1},u_{2}\in Q_{h}
such that

|u_{1}-u_{2}|>m/4
, since otherwise
Q_{h}
could be covered by a segment of
length
m/4
, which is impossible.

Since
c_{n}\to a+b
, there is an
n
such that
|c_{n}-a-b|<\delta
and
n>8/m
.
Fix such an index
n
, and put
h=c_{n}-a-b
. Then there are elements

u_{1},u_{2}\in Q_{h}
such that
|u_{1}-u_{2}|>m/4
, and

c_{n}=a+b+h=(u_{1}+a)+(b+h-u_{1})=(u_{2}+a)+(b+h-u_{2}).

Here
u_{i}+a\in N
and
b+h-u_{i}\in B

(i=1,2)
, and thus
u_{1}+a,u_{2}+a\in(a-1/n,a+1/n)
. This, however, contradicts
2/n<m/4
. This contradiction
proves that
|N|=0
.
\square

Proof of Theorem
1.4

Suppose that
A
is measurable,
B
is
F_{\sigma}
, and the upper density of
B

is positive at every point of
B
.

We have
A=N_{0}\cup A^{\prime}
, where
N_{0}
is null and
A^{\prime}
is
F_{\sigma}
. Let

A^{\prime}=\bigcup_{k=1}^{\infty}F_{k}
and
B=\bigcup_{k=1}^{\infty}P_{k}
, where
F_{k}
and

P_{k}
are compact. We may assume that
F_{1}\subset F_{2}\subset\ldots
and

P_{1}\subset P_{2}\subset\ldots
. It is enough to prove that for every
k=1,2,\ldots

there is a null set
N_{k}\subset A
such that
N_{k}+B\supset F_{k}+P_{k}
. Indeed, if
this is true, then
N=\bigcup_{k=0}^{\infty}N_{k}
is null, and

\displaystyle N+B=

\displaystyle(N_{0}+B)\cup\bigcup_{k=0}^{\infty}(N_{k}+B)\supset(N_{0}+B)\cup\bigcup_{k=0}^{\infty}(F_{k}+P_{k})=

\displaystyle(N_{0}+B)\cup(A^{\prime}+B)=A+B.

Fix
k
. We have
\overline{d}(B,x)>0
for every
x\in P_{k}
. By Lemma

2.2
, there is a compact set
Q_{k}
such that
P_{k}\subset Q_{k}\subset B
and

\overline{d}(Q_{k},x)>0
for every
x\in Q_{k}
. By Theorem
1.5
, there is a closed
null set
N_{k}\subset F_{k}
such that
N_{k}+Q_{k}=F_{k}+Q_{k}
. Then
N_{k}+B\supset N_{k}+Q_{k}=F_{k}+Q_{k}\supset F_{k}+P_{k}
.
\square

An example

Theorem 3.1
.

Let
A
be a nowhere dense compact perfect set of positive measure. Then there
exists a compact perfect set
B
such that
N+B\neq A+B
for every closed null
subset
N
of
A
.

Proof.
We denote by
{\rm cl}\,E
and
{\rm int}\,E
the closure and the interior of the set

E
. For every positive integer
k
let
i_{k}
denote the largest integer
i

such that
2^{i}\mid k
. Then
i_{k}<k
for every
k
, and for every nonnegative
integer
m
there are infinitely many
k
with
i_{k}=m
.

Let
X
be a countable dense subset of
A
, and let
x_{0},x_{1},\ldots
be an
enumeration of
X
. We construct a sequence
(y_{k})
such that
B={\rm cl}\,(\{y_{k}\})
is perfect and compact, and whenever
x_{k}+y_{k}=x+y
, where
x\in A
and
y\in B
, then
x=x_{k}
and
y=y_{k}
. It will follow that if
N\subset A
and

N+B=A+B
, then
x_{k}\in N
for every
k
; that is,
X\subset N
. Thus
N
must
be dense in
A
and, consequently, if
N
is closed that it must be equal to

A
, and cannot be a null set.

We turn to the construction of the numbers
y_{k}
.
Put
y_{0}=0
. Since
(x_{0}+y_{0}-A)^{c}
is an everywhere dense
open set, we can choose pairwise disjoint closed intervals
I_{n}^{0}\subset(x_{0}+y_{0}-A)^{c}
such that

{\rm cl}\,\left(\bigcup_{n=1}^{\infty}I_{n}^{0}\right)=\{y_{0}\}\cup\bigcup_{n=1}^{\infty}I_{n}^{0}.

Suppose that
k>0
, and we have defined the points
y_{0},\ldots,y_{k-1}
and the
closed intervals
I_{1}^{k-1},I_{2}^{k-1},\ldots
such that

{\rm cl}\,\left(\bigcup_{n=1}^{\infty}I_{n}^{k-1}\right)=\{y_{0},\ldots,y_{k-1}\}\cup\bigcup_{n=1}^{\infty}I_{n}^{k-1}.

The set
G_{k}=\bigcap_{i=0}^{k-1}(y_{i}-x_{k}+A)^{c}
is everywhere dense and open.
Thus we can choose a point
y_{k}\in G_{k}\cap\bigcup_{n=1}^{\infty}{\rm int}\,I_{n}^{k-1}

such that
0<|y_{k}-y_{i_{k}}|<1/2^{k}
.

Since
(x_{k}+y_{k}-A)^{c}
is an everywhere dense open set, we can choose pairwise
disjoint closed intervals

I_{n}^{k}\subset(x_{k}+y_{k}-A)^{c}\cap\bigcup_{n=1}^{\infty}{\rm int}\,I_{n}^{k-1}

such that

{\rm cl}\,\left(\bigcup_{n=1}^{\infty}I_{n}^{k}\right)=\left(\bigcup_{n=1}^{\infty}I_{n}^{k}\right)\cup\{y_{0},\ldots,y_{k}\}\subset(x_{k}+y_{k}-A)^{c}\cup\{y_{0},\ldots,y_{k}\}.

(1)

In this way we defined the points
y_{k}
and the intervals
I_{n}^{k}
for every

k\geq 0
and
n\geq 1
. Put
Y=\{y_{0},y_{1},\ldots\}
and
B={\rm cl}\,(Y)
. Then

B
is a compact set, as
Y
is bounded. We show that
B
is perfect. Indeed,
if
y\in B\setminus Y
, then
y
is not an isolated point of
B
, since
y
is the
limit of a subsequence of
(y_{k})
. On the other hand, if
y=y_{m}
, then

i_{k}=m
for infinitely many
k
. Thus
0<|y_{k}-y_{m}|<1/2^{k}
for infinitely
many
k
proving that
y_{m}
is not an isolated point of
B
either.

It follows from the construction that
B\subset{\rm cl}\,(\bigcup_{n=1}^{\infty}I_{n}^{k})

for every
k
. Therefore, by (
1
) we obtain

B\subset(x_{k}+y_{k}-A)^{c}\cup\{y_{0},\ldots,y_{k}\}\qquad(k=0,1,\ldots).

(2)

Suppose that
x_{k}+y_{k}=x+y
, where
x\in A
and
y\in B
. Then
y=x_{k}+y_{k}-x\in x_{k}+y_{k}-A
, and thus (
2
) gives
y\in\{y_{0},\ldots,y_{k}\}
. If
y\neq y_{k}
, then
y_{k}=x+y-x_{k}\in\bigcup_{i=0}^{k-1}(y_{i}-x_{k}+A)=(G_{k})^{c}
, which contradicts
y_{k}\in G_{k}
.
Thus
y=y_{k}
and, consequently,
x=x_{k}
. As we saw above, this implies
that whenever
N+B=A+B
, where
N\subset A
, then
N
must be dense in
A
, and
thus it cannot be a closed null subset of
A
.
\square
