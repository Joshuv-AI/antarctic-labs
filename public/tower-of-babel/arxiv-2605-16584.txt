Provably Efficient Sensor Allocation for Unknown High-dimensional Systems with Limited Sensing
Yuyang Zhang, Derya Cansever, Na Li

Abstract
This paper focuses on learning efficient sensor allocations that ensure observability of unknown high-dimensional linear systems using only a small number of sensors. Existing methods either require an impractically large number of sensors or assume access to an observable allocation in advance. We propose a two-stage framework that overcomes these limitations: first, a novel system identification algorithm integrates information from multiple trajectories, each observing different subsets of state coordinates; then, a classic sensor allocation method is adapted to operate on the learned system parameters. Our non-asymptotic guarantees show that the proposed approach learns a sensor allocation with a near-optimal number of sensors when sensors can be allocated on any state coordinate. We further extend the results to settings with inaccessible state coordinates that are unavailable for sensor allocation.

High-dimensional dynamical systems are ubiquitous in real-world applications, such as power grids

In high-dimensional linear systems, classic sensor allocation methods typically assume access to an exact dynamical model

in order to compute efficient allocations. However, constructing accurate models from first principles is infeasible in such settings, making it necessary to estimate the model from data. This raises two major challenges. First, it is unclear whether the performance guarantees of the existing sensor allocation methods remain valid when applied to approximate models. Second, even estimating an approximate model is itself nontrivial. Standard least-squares methods require access to full state trajectories, which demand prohibitively extensive sensing

,

,

. Alternatively, Ho-Kalman-type algorithms can operate on partially observed trajectories

To address the aforementioned difficulties, we propose a two-stage framework for learning efficient sensor allocations that guarantee observability with only a small number of sensors.
In stage one
, we develop a system identification (SYSID) algorithm that estimates the system dynamics without requiring observability and with an arbitrary number of sensors. Specifically, consider the following
r
-dimensional linear dynamical system
x_{t+1}=Ax_{t}+Bu_{t}+w_{t}
with state
x_{t}\in\mathbb{R}^{r}
, input
u_{t}\in\mathbb{R}^{m}
, and noise
w_{t}\in\mathbb{R}^{r}

We prove that the estimation error is bounded by

\tilde{\mathcal{O}}(\cdot)
hides constants and logarithmic factors,
T
is the trajectory length, and
s_{\min}
is the least number of trajectories used to measure a state coordinate.
Intuitively, as long as every state coordinate is observed in at least one trajectory, i.e.

We highlight that this condition requires no prior structural knowledge and is easily satisfied—for instance, even with only one sensor, the system can be learned by collecting
r
data trajectories, each measuring a different state coordinate.

In stage two
, we adapt a greedy sensor allocation algorithm to operate on the estimated system parameters from stage one. A carefully designed rank estimation subroutine mitigates the influence of estimation noise, and the resulting algorithm is guaranteed to produce a sensor allocation ensuring observability with at most
\left(1+\log(r)\right)n^{*}

is the minimum number needed.
Unlike prior work
[

,
3

23

that requires exact system dynamics, our algorithm operates directly on models learned from data.

Finally, we extend the proposed algorithms to systems with inaccessible state coordinates, where sensors can not be allocated.
We show that the above algorithms, with minor modifications, can still learn efficient sensor allocations in this scenario, provided that the accessible state coordinates are sufficient to ensure observability of the system.

II-B

The Sensor Allocation Problem

As discussed in Section
I
, this paper focuses on unknown high-dimensional systems with a large state dimension
r
. The goal is to learn a sensor allocation that ensures observability with a small number of sensors.
Since the system is unknown, a natural approach is to first identify the system from data and design the sensor allocation based on the estimated model. However, standard identification methods either require a massive number of sensors to cover all state coordinates or a sensor allocation that renders the system observable, both of which are impractical in practice.

To overcome this challenge, we propose the following problem setting where
K
data trajectories are collected, each measuring a possibly different set of state coordinates. Specifically, let
\bar{n}
denote the number of available sensors during data collection. For each trajectory
k\in[K]
, we choose a measurement matrix
C_{k}\in\mathbb{R}^{\bar{n}\times r}
with
\bar{n}
sensors, inject inputs
\mathcal{U}_{k}=\{u_{k,t}\}_{t\in[0,T]}
, and observe
\mathcal{Y}_{k}=\{y_{k,t}\}_{t\in[0,T+1]}
as specified by
Equation

2
.

Our goal is to choose measurement matrices
\{C_{k}\}_{k\in[K]}
, collect the datasets
\bigcup_{k\in[K]}\left(\mathcal{Y}_{k}\cup\mathcal{U}_{k}\right)
, and learn a single measurement matrix
\widehat{C}

such that
(A,\widehat{C})
is observable, or equivalently, the observability matrix
O(\widehat{C})
is full-column-rank. To avoid confusion, we will refer to the final output
\widehat{C}
as the
sensor allocation
to differentiate it from the
measurement matrices

\{C_{k}\}_{k\in[K]}
used only during data collection.

Overview of Our Solution

In the following sections, we propose a two-stage framework to solve the problem.
In stage one (

III-A

Rationale of the algorithm design

We first state our principle to choose the measurement matrices
\{C_{k}\}_{k\in[K]}
:
measure every state coordinate in at least one trajectory
.
As we will show later in

III-C

and
B

One can easily follow this principle for any given number of sensors
\bar{n}
with measurement matrices

\begin{split}C_{k}={}&\begin{bmatrix}e_{(k-1)\bar{n}+1}^{\intercal}&e_{(k-1)\bar{n}+2}^{\intercal}&\cdots&e_{k\bar{n}}^{\intercal}\end{bmatrix}^{\intercal},~\forall k\in[K],\end{split}

where

With the chosen measurement matrices and the corresponding dataset

, we aim to learn the system matrices

. To motivate the learning algorithm, we consider the simple example where

To learn the system matrices, one naive approach is to perform least-squares on pairs
({\left[x_{k,t+1}+\eta_{k,t+1}\right]_{k},\left[x_{k,t}+\eta_{k,t}\right]_{k},u_{k,t}})

Our algorithm follows a different approach. By a recursive expansion of the state dynamics (

\displaystyle x_{k,t+1}=\sum_{\tau=0}^{d}A^{\tau}Bu_{k,t-\tau}

\displaystyle+{}

\displaystyle\underbrace{\sum_{\tau=d+1}^{t}A^{\tau}Bu_{k,t-\tau}+\sum_{\tau=0}^{t}A^{\tau}w_{k,t-\tau}}_{\mathcal{Z}_{k,t}}.

\vdots\\
u_{k,t-d}\\
\end{bmatrix}}_{U_{k,t}(d)}+\mathcal{Z}_{k,t},\end{split}

(3)

Since the input

IV
Stage Two: Data-Driven Sensor Allocation

With the approximated system matrix
\widehat{A}
from Stage One, we now learn an efficient sensor allocation to make the system observable with a small number of sensors.

We present a greedy algorithm (
Algorithm

2

At each iteration, the algorithm first estimates the observability matrix rank under the current sensor allocation
\widehat{C}
using a rank estimation subroutine
\mathcal{E}

If
\widehat{C}
does not make the system observable, adding a sensor on a new state coordinate (or equivalently, adding a new row to
\widehat{C}
) may increase the observability matrix rank.
The algorithm estimates rank increase
h_{i}
for every state coordinate
i
not measured by the current
\widehat{C}
(line 3-4) using the rank-estimation subroutine
\mathcal{E}
, which estimates the observability matrix rank for any given measurement matrix
\widehat{C}
. It subsequently adds a sensor on the coordinate with the largest rank increase (line 5). The iteration ends when observability matrix rank reaches
r
.

Algorithm 2

Sensor Allocation

1:

Init:
coordinate set
\mathcal{I}=[r]
, initial allocation
\widehat{C}\in\mathbb{R}^{0\times r}
, rank estimation subroutine
\mathcal{E}
;

2:

while

\mathcal{E}(\widehat{C})<r

do

3:

Estimate rank increase of observability matrix:

4:

for
any state coordinate
i\in\mathcal{I}
that is not currently measured

do

\begin{split}h_{i}\leftarrow\mathcal{E}\left(\begin{bmatrix}\widehat{C}\\
e_{i}^{\intercal}\end{bmatrix}\right)-\mathcal{E}\left(\widehat{C}\right);\end{split}

5:

Select state coordinate with the largest rank increase:

\begin{split}i^{*}\leftarrow{}&\arg\max_{i}h_{i},\quad\widehat{C}\leftarrow\begin{bmatrix}\widehat{C}\\
e_{i^{*}}^{\intercal}\end{bmatrix}.\end{split}

6:

Output:

\widehat{C}\in\mathbb{R}^{\widehat{n}\times r}
.

In
Algorithm

2
, the key component is the rank estimation subroutine
\mathcal{E}
. Unlike existing literature that either assumes this rank information as prior knowledge or requires the exact system matrix
A

[
34
,
3
,
23
]
, we design a subroutine
\mathcal{E}
(
Algorithm

3
) to estimate the rank from
\widehat{A}
, the data-driven estimate of
A
from
Algorithm

1
.

Algorithm 3

Rank Estimation Subroutine
\mathcal{E}

1:

Initialization:
receive
1/(s_{\min}T)
and
\widehat{A}
.

2:

Input:
measurement matrix
C
;

3:

Form observability matrix:

\begin{split}\widehat{O}(C)\leftarrow\begin{bmatrix}C^{\intercal}&(C\widehat{A})^{\intercal}&\cdots&(C\widehat{A}^{r-1})^{\intercal}\end{bmatrix}^{\intercal};\end{split}

4:

Rank estimation:

\begin{split}\widehat{r}\left(C\right)\leftarrow\max\left\{i:\sigma_{i}\left(\widehat{O}(C)\right)>\sqrt[4]{\frac{1}{s_{\min}T}}\right\};\end{split}

5:

Output:

\widehat{r}\left(C\right)
.

Specifically, given
\widehat{A}
, the subroutine first forms an approximation of the true observability matrix
O(C)=\begin{bmatrix}C^{\intercal}&(CA)^{\intercal}&\cdots&(CA^{r-1})^{\intercal}\end{bmatrix}^{\intercal}
for the query matrix
C
, denoted by
\widehat{O}(C)
(line 3). When
\widehat{A}
is sufficiently accurate, the singular values of
\widehat{O}(C)
naturally split into two groups:
\text{rank}(O(C))
large singular values corresponding to the non-zero singular values of
O(C)
, and
r-\text{rank}(O(C))
small singular values corresponding to the zero singular values of
O(C)
. The threshold
\sqrt[4]{1/(s_{\min}T)}
is carefully chosen to separate the two groups of singular values. Here the constants
s_{\min},T
are defined in
Theorem

1
.

Now we state the performance guarantee for
Algorithm

2
.

Theorem 2
.

Consider system
(A,B,\sigma_{u}^{2},\sigma_{w}^{2})
satisfying Assumption
1
with
\psi_{A},\rho_{A}
and Assumption
2
. Consider
\widehat{A}
satisfying

\left\|\widehat{A}-A\right\|\leq\kappa_{2}\sqrt{s_{\max}md/s_{\min}^{2}T}

for some constant
\kappa_{2}\geq 1
. Let
\sigma_{O}\coloneqq\min_{C\in\mathcal{C}}\sigma_{\min}(O(C))
, where
\mathcal{C}
denotes the set of all non-zero measurement matrices.
If

\begin{split}{}&T>\max\left\{\frac{16}{s_{\min}\sigma_{O}^{4}},\frac{10\psi_{A}^{8}\kappa_{2}^{4}}{\rho_{A}^{8}(1-\rho_{A})^{8}}\cdot\frac{s_{\max}^{2}}{s_{\min}^{2}}\frac{m^{2}d^{2}}{s_{\min}}\right\},\end{split}

(7)

then the output
\widehat{r}(C)
of Algorithm
3
is accurate for any measurement matrix
C
. Namely,

\begin{split}\widehat{r}(C)={}&\text{rank}\left(O(C)\right)=\text{rank}(\begin{bmatrix}C^{\intercal}&\cdots&(CA^{r-1})^{\intercal}\end{bmatrix}^{\intercal}).\end{split}

(8)

Furthermore, with
Algorithm

3
as the rank estimation subroutine, the output
\widehat{C}\in\mathbb{R}^{\widehat{n}\times r}
of
Algorithm

2
satisfies

\begin{split}(A,\widehat{C})\text{ is observable},\quad\widehat{n}\leq\left(1+\log(r)\right)\cdot n^{*}.\end{split}

(9)

Here
n^{*}
is the least number of sensors needed to make the system observable. ∎

Combining this result with
Theorem

1
,
Algorithm

2
is guaranteed to learn an efficient sensor allocation that is optimal up to constant
1+\log(r)
.
We remark that the constants in (
7
) reflect worst-case analysis. Our numerical experiments in
Section

VII
confirm that the algorithm succeeds with a moderate trajectory length in practice.

V-A

Proof of
Theorem

1

Proof.
We begin by analyzing the least-squares problem (line 6 of
Algorithm

1
) and deriving the optimality condition for its solution
\widehat{G}
. For each row of
\widehat{G}
, we express its error as the combination of a noise term and an estimated signal covariance term (
Step 1
). We then derive an upper bound for the noise term and the error of the estimated signal covariance inverse term (
Step 2
). Finally, we concatenate the rows of
\widehat{G}
and upper bound the error concatenation (
Step 3
).

Step 1.
Consider the least-squares objective in line 6 of
Algorithm

1
. By taking the gradient with respect to
\widehat{G}
and setting it to zero, we get the optimality condition on
\widehat{G}
:

\begin{split}{}&\sum_{k\in[K],t\in[d,T]}C_{k}^{\intercal}\left(C_{k}\widehat{G}U_{k,t}(d)-y_{k,t+1}\right)U_{k,t}(d)^{\intercal}=0.\end{split}

(10)

Here
U_{k,t}(d)=\begin{bmatrix}u_{k,t}^{\intercal}&\cdots&u_{k,t-d}^{\intercal}\end{bmatrix}^{\intercal}
.

Recall
y_{k,t+1}=C_{k}\left(x_{k,t+1}+\eta_{k,t+1}\right)
.
We expand
x_{k,t+1}
as
x_{k,t+1}=\sum_{\tau=0}^{t}A^{\tau}\left(Bu_{k,t-\tau}+w_{k,t-\tau}\right)
by state dynamics
Equation

1
and obtain the following expansion for
y_{k,t+1}

\begin{split}y_{k,t+1}={}&C_{k}\left(\sum_{\tau=0}^{t}A^{\tau}\left(Bu_{k,t-\tau}+w_{k,t-\tau}\right)+\eta_{k,t+1}\right)\\
={}&C_{k}GU_{k,t}(d)+C_{k}\underbrace{\left(\eta_{k,t+1}+\sum_{\tau=0}^{d}A^{\tau}w_{k,t-\tau}\right)}_{\Delta_{k,t+1}^{2}}\\
{}&+C_{k}\underbrace{\sum_{\tau=d+1}^{t}A^{\tau}\left(Bu_{k,t-\tau}+w_{k,t-\tau}\right)}_{\Delta_{k,t+1}^{1}}.\end{split}

(11)

Here recall that
G=\begin{bmatrix}B&\cdots&A^{d}B\end{bmatrix}
is the true Markov parameters.
Substituting into the optimality condition of
\widehat{G}
(
Equation

10
) and rearranging the terms give

\begin{split}{}&\sum_{k\in[K],t\in[d,T]}C_{k}^{\intercal}C_{k}\left(\widehat{G}-G\right)U_{k,t}(d)U_{k,t}(d)^{\intercal}\\
={}&\underbrace{\sum_{k\in[K],t\in[d,T]}C_{k}^{\intercal}C_{k}\left(\Delta_{k,t+1}^{1}+\Delta_{k,t+1}^{2}\right)U_{k,t}(d)^{\intercal}}_{\Delta}.\end{split}

(12)

Consider any coordinate
i\in\mathcal{I}=\big\{i:[\sum_{k\in[K]}C_{k}^{\intercal}C_{k}]_{i}^{i}\neq 0\big\}
that is measured in at least one trajectory. To bound the error of
[\widehat{G}]_{i}
, we take the
i
-th row of
Equation

12
on both sides and get

\begin{split}\sum_{k\in[K],t\in[d,T]}\left[C_{k}^{\intercal}C_{k}\right]_{i}\left(\widehat{G}-G\right)U_{k,t}(d)U_{k,t}(d)^{\intercal}=[\Delta]_{i}\\
\end{split}

(13)

Since
C_{k}
is the measurement matrix for trajectory
k
, we know

\begin{split}[C_{k}^{\intercal}C_{k}]_{i}=\left\{\begin{array}[]{ll}e_{i}^{\intercal},&\text{state coordinate }i\text{ is observed}\\
&\text{in trajectory }k,\\
0,&\text{otherwise}.\end{array}\right.\end{split}

Therefore,
[C_{k}^{\intercal}C_{k}]_{i}(\widehat{G}-G)
equals
[\widehat{G}-G]_{i}
if state coordinate
i
is measured in trajectory
k
, and equals
0
otherwise. It then follows by
Equation

13
that

\begin{split}{}&\left[\widehat{G}-G\right]_{i}\underbrace{\sum_{k\in\mathcal{K}_{i},t\in[d,T]}U_{k,t}(d)U_{k,t}(d)^{\intercal}}_{\widehat{\Sigma}_{i}}=[\Delta]_{i}.\end{split}

(14)

Here we use
\mathcal{K}_{i}\coloneqq\{k:[C_{k}^{\intercal}C_{k}]_{i}^{i}\neq 0\}
to denote the trajectories where the
i
-th state coordinate is measured, and use

\widehat{\Sigma}_{i}
to denote the estimated signal covariance.

Step 2.
To bound the error
\left[\widehat{G}-G\right]_{i}
, we first upper bound norm of the noise term
\Delta
defined in
Equation

12
. This is challenging because
\Delta_{k,t}^{1}
,
\Delta_{k,t}^{2}
and
U_{k,t}(d)
are dependent across time steps
t
.
To tackle this issue, we carefully manipulate the martingale formed by the terms and utilize the self-normalizing martingale analysis from previous work
[
1
,
27
]
, yielding the following lemma:

Lemma 2
.

Consider the setting of
Theorem

1
. With probability at least
1-\delta/2
,

\begin{split}\left\|\Delta\right\|\leq\kappa_{4}\cdot\sqrt{mds_{\max}(T-d+1)},\end{split}

where
\kappa_{4}=\kappa_{1}\cdot\sigma_{u}^{2}/4
.∎

Importantly,
\left\|\Delta\right\|
scales sublinearly with
{s_{\max}(T-d+1)}
, where
s_{\max}=\max_{i}|\mathcal{K}_{i}|
is the maximum diagonal element of
\sum_{k\in[K]}C_{k}^{\intercal}C_{k}
.

We then show that the estimated signal covariance
\widehat{\Sigma}_{i}
is invertible and upper bound the deviation of its inverse
\widehat{\Sigma}_{i}^{-1}
from the true covariance inverse
\Sigma_{i}^{-1}\coloneqq 1/\left(|\mathcal{K}_{i}|(T-d+1)\sigma_{u}^{2}\right)I
.

By a covariance concentration bound (
Lemma

4
in Appendix
A
), we know that for
T
satisfying
Equation

5
, with probability at least
1-\delta/(2K)
, the following concentration holds for any trajectory
k\in[K]
,

\begin{split}{}&\frac{1}{T-d+1}\sum_{t=d}^{T}U_{k,t}(d)U_{k,t}(d)^{\intercal}\succeq\frac{\sigma_{u}^{2}}{2}I,\\
{}&\left\|\frac{1}{T-d+1}\sum_{t=d}^{T}U_{k,t}(d)U_{k,t}(d)^{\intercal}-\sigma_{u}^{2}I\right\|\leq\kappa_{5}\sqrt{\frac{md}{T}},\end{split}

where
\kappa_{5}=2\sigma_{u}^{2}\sqrt{c\left(\log^{4}(2mdT)+\log\left(2K/\delta\right)\right)}
and
c
is an absolute constant from previous work
[
20
, Theorem 4.1 with
L=1
]
.
Thus, with a union bound, the above holds for all trajectories
k\in[K]
with probability at least
1-\delta/2
.
When the above events hold, it naturally follows by the definition of
\widehat{\Sigma}_{i}
that for all
i\in[r]
,

\begin{split}{}&\widehat{\Sigma}_{i}=\sum_{k\in\mathcal{K}_{i},t\in[d,T]}U_{k,t}(d)U_{k,t}(d)^{\intercal}\succeq\frac{\sigma_{u}^{2}}{2}|\mathcal{K}_{i}|(T-d+1)I,\\
\end{split}

This confirms the invertibility of
\widehat{\Sigma}_{i}
. Moreover,

\begin{split}{}&\left\|\widehat{\Sigma}_{i}-\Sigma_{i}\right\|\leq\sum_{k\in\mathcal{K}_{i}}\left\|\sum_{t=d}^{T}U_{k,t}(d)U_{k,t}(d)^{\intercal}-\sigma_{u}^{2}(T-d+1)I\right\|\\
{}&\hskip 45.00006pt\leq|\mathcal{K}_{i}|T\cdot\kappa_{5}\sqrt{\frac{md}{T}}.\end{split}

Thus, with probability at least
1-\delta/2
, the following holds for all
i\in[r]

\begin{split}{}&\left\|\widehat{\Sigma}_{i}^{-1}-\Sigma_{i}^{-1}\right\|\leq\left\|\widehat{\Sigma}_{i}^{-1}\right\|\left\|\Sigma_{i}-\widehat{\Sigma}_{i}\right\|\left\|\Sigma_{i}^{-1}\right\|\\
\leq{}&\left(\frac{2}{\sigma_{u}^{2}|\mathcal{K}_{i}|(T-d+1)}\right)\cdot\left(|\mathcal{K}_{i}|T\kappa_{5}\sqrt{\frac{md}{T}}\right)\\
{}&\hskip 20.00003pt\cdot\left(\frac{1}{\sigma_{u}^{2}|\mathcal{K}_{i}|(T-d+1)}\right)\\
\leq{}&\frac{2\kappa_{5}}{\sigma_{u}^{4}(T-d+1)^{2}}\sqrt{\frac{mdT}{s_{\min}^{2}}}\\
\end{split}

(15)

Here in the last inequality, we have used
s_{\min}=\min_{i\in\mathcal{I}}|\mathcal{K}_{i}|
, which is the minimum nonzero diagonal element of
\sum_{k\in[K]}C_{k}^{\intercal}C_{k}
.
This inequality shows that the distance between
\widehat{\Sigma}_{i}^{-1}
and
\Sigma_{i}^{-1}
decays superlinearly with
T
.

Step 3.

Finally, we concatenate
[\widehat{G}-G]_{i}
for all
i\in\mathcal{I}\coloneqq\{i_{1},\cdots,i_{|\mathcal{I}|}\}
and upper bound the norm of the concatenation.

\begin{split}{}&\left\|\left[\widehat{G}-G\right]_{\mathcal{I}}\right\|=\left\|\begin{bmatrix}[\Delta]_{i_{1}}\widehat{\Sigma}_{i_{1}}^{-1}\\
\vdots\\
[\Delta]_{i_{|\mathcal{I}|}}\widehat{\Sigma}_{i_{|\mathcal{I}|}}^{-1}\\
\end{bmatrix}\right\|\\
\leq{}&\left\|\begin{bmatrix}[\Delta]_{i_{1}}\Sigma_{i_{1}}^{-1}\\
\vdots\\
[\Delta]_{i_{|\mathcal{I}|}}\Sigma_{i_{|\mathcal{I}|}}^{-1}\\
\end{bmatrix}\right\|+\left\|\begin{bmatrix}[\Delta]_{i_{1}}\left(\widehat{\Sigma}_{i_{1}}^{-1}-\Sigma_{i_{1}}^{-1}\right)\\
\vdots\\
[\Delta]_{i_{|\mathcal{I}|}}\left(\widehat{\Sigma}_{i_{|\mathcal{I}|}}^{-1}-\Sigma_{i_{|\mathcal{I}|}}^{-1}\right)\\
\end{bmatrix}\right\|.\end{split}

(16)

In the last line of
Equation

16
, the first term equals the following matrix by the definition
\Sigma_{i}^{-1}=1/\left(|\mathcal{K}_{i}|(T-d+1)\sigma_{u}^{2}\right)I
:

\begin{split}\left\|\begin{bmatrix}\dfrac{1}{|\mathcal{K}_{i_{1}}|(T-d+1)\sigma_{u}^{2}}[\Delta]_{i_{1}}\\
\vdots\\
\dfrac{1}{|\mathcal{K}_{i_{|\mathcal{I}|}}|(T-d+1)\sigma_{u}^{2}}[\Delta]_{i_{|\mathcal{I}|}}\\
\end{bmatrix}\right\|\leq\dfrac{1}{s_{\min}(T-d+1)\sigma_{u}^{2}}\left\|\Delta\right\|.\end{split}

The upper bound holds because
s_{\min}=\min_{i\in\mathcal{I}}|\mathcal{K}_{i}|
.

In the last line of
Equation

16
, the second term is upper bounded by

\begin{split}{}&\sqrt{|\mathcal{I}|}\cdot\max_{i\in\mathcal{I}}\left\|[\Delta]_{i}\left(\widehat{\Sigma}_{i}^{-1}-\Sigma_{i}^{-1}\right)\right\|\\
\leq{}&\sqrt{r}\left\|\Delta\right\|\max_{i\in\mathcal{I}}\left\|\widehat{\Sigma}_{i}^{-1}-\Sigma_{i}^{-1}\right\|\leq\frac{2\kappa_{5}}{\sigma_{u}^{4}}\sqrt{\dfrac{rmdT}{s_{\min}^{2}(T-d+1)^{4}}}\left\|\Delta\right\|.\end{split}

Here the last inequality is by
Equation

15
.

Substitute the two bounds into
Equation

16
and we get

\begin{split}{}&\left\|\left[\widehat{G}-G\right]_{\mathcal{I}}\right\|\\
\leq{}&\dfrac{1}{s_{\min}(T-d+1)\sigma_{u}^{2}}\left\|\Delta\right\|+\frac{2\kappa_{5}}{\sigma_{u}^{4}}\sqrt{\dfrac{rmdT}{s_{\min}^{2}(T-d+1)^{4}}}\left\|\Delta\right\|.\end{split}

When
Equation

5
holds, the second term is smaller than the first term. Therefore, we conclude that

\begin{split}\left\|\left[\widehat{G}-G\right]_{\mathcal{I}}\right\|\leq{}&\dfrac{2}{s_{\min}(T-d+1)\sigma_{u}^{2}}\kappa_{4}\sqrt{mds_{\max}T}\\
\leq{}&\kappa_{1}\sqrt{\frac{s_{\max}}{s_{\min}}\frac{md}{s_{\min}T}}.\end{split}

In the last line we have used
T-d+1\geq T/2
.∎

Proof of
Lemma

1

Proof.

For notational simplicity, we first define

\begin{split}G\coloneqq{}&\begin{bmatrix}B&\cdots&A^{d}B\end{bmatrix},G^{-}\coloneqq\begin{bmatrix}B&\cdots&A^{d-1}B\end{bmatrix},\\
G^{+}\coloneqq{}&\begin{bmatrix}AB&\cdots&A^{d}B\end{bmatrix}=AG^{-}.\\
\end{split}

Because the system is controllable and
d\geq r
,
G^{-}
is full-row-rank and has right pseudo-inverse, denoted as
(G^{-})^{\dagger}
.

We will also use the following notations where
\widehat{G}
is the output of
Algorithm

1
:

\begin{split}\widehat{G}\coloneqq{}&\begin{bmatrix}\widehat{B}&\cdots&\widehat{A^{d}B}\end{bmatrix},\widehat{G}^{-}\coloneqq\begin{bmatrix}\widehat{B}&\cdots&\widehat{A^{d-1}B}\end{bmatrix},\\
\widehat{G}^{+}\coloneqq{}&\begin{bmatrix}\widehat{AB}&\cdots&\widehat{A^{d}B}\end{bmatrix}.\end{split}

Since
\widehat{G}^{-}-G^{-}
is a submatrix of
\widehat{G}-G
, we know that

\begin{split}\left\|\widehat{G}^{-}-G^{-}\right\|\leq\left\|\widehat{G}-G\right\|\leq\frac{\sigma_{\min}(G^{-})}{2},\end{split}

where the last inequality holds by
Equation

6
.
Therefore,
\sigma_{r}(\widehat{G}^{-})
is lower bounded as follows

\begin{split}{}&\sigma_{r}\left(\widehat{G}^{-}\right)\geq\sigma_{r}\left(G^{-}\right)-\left\|\widehat{G}^{-}-G^{-}\right\|\\
={}&\sigma_{\min}\left(G^{-}\right)-\left\|\widehat{G}^{-}-G^{-}\right\|\geq\frac{\sigma_{\min}\left(G^{-}\right)}{2}.\end{split}

(17)

We then conclude that
\widehat{G}^{-}
is full-row-rank and has right pseudo-inverse, denoted by
(\widehat{G}^{-})^{\dagger}
.

We now upper bound
\|\widehat{A}-A\|
.
Since
\widehat{A}=\widehat{G}^{+}(\widehat{G}^{-})^{\dagger}

and
A=G^{+}(G^{-})^{\dagger}
, we know that

\begin{split}{}&\left\|\widehat{A}-A\right\|=\left\|\widehat{G}^{+}\big(\widehat{G}^{-})^{\dagger}-G^{+}\left(G^{-}\right)^{\dagger}\right\|\\
\leq{}&\left\|\big(\widehat{G}^{+}-G^{+})\big(\widehat{G}^{-}\big)^{\dagger}\right\|+\left\|G^{+}\left(\big(\widehat{G}^{-}\big)^{\dagger}-\left(G^{-}\right)^{\dagger}\right)\right\|\\
\leq{}&\left\|\widehat{G}^{+}-G^{+}\right\|\left\|\big(\widehat{G}^{-}\big)^{\dagger}\right\|+\left\|G^{+}\right\|\left\|\big(\widehat{G}^{-}\big)^{\dagger}-\left(G^{-}\right)^{\dagger}\right\|\\
\end{split}

(18)

For the first term, we have

\begin{split}{}&\left\|\widehat{G}^{+}-G^{+}\right\|\leq\left\|\widehat{G}-G\right\|,\\
{}&\left\|\big(\widehat{G}^{-}\big)^{\dagger}\right\|=\frac{1}{\sigma_{r}(\widehat{G}^{-})}\leq\frac{2}{\sigma_{\min}\left(G^{-}\right)}.\end{split}

Here the first inequality is because
\widehat{G}^{+}-G^{+}
is a submatrix of
\widehat{G}-G
, and the second inequality is by
Equation

17
.
For the second term, we have

\begin{split}\left\|\big(\widehat{G}^{-}\big)^{\dagger}-\big(G^{-}\big)^{\dagger}\right\|\overset{(i)}{\leq}{}&2\left\|\big(\widehat{G}^{-}\big)^{\dagger}\right\|\left\|\big(G^{-}\big)^{\dagger}\right\|\left\|\widehat{G}^{-}-G^{-}\right\|\\
\leq{}&2\frac{2}{\sigma_{\min}(G^{-})}\frac{1}{\sigma_{\min}(G^{-})}\left\|\widehat{G}^{-}-G^{-}\right\|\\
\leq{}&\frac{4}{\sigma_{\min}^{2}\left(G^{-}\right)}\left\|\widehat{G}-G\right\|.\end{split}

Here
(i)
is by
[
37
, Theorem 4.1]
.
Substituting upper bounds of the two terms back into
Equation

18
gives

\begin{split}\left\|\widehat{A}-A\right\|\leq{}&\left(\frac{2}{\sigma_{\min}\big(G^{-}\big)}+\frac{4\left\|G\right\|}{\sigma_{\min}^{2}\left(G^{-}\right)}\right)\left\|\widehat{G}-G\right\|\\
\leq{}&\frac{6\left\|G\right\|}{\sigma_{\min}^{2}\big(G^{-}\big)}\left\|\widehat{G}-G\right\|.\end{split}

In the last line, we have used
\sigma_{\min}\left(G^{-}\right)\leq\left\|G^{-}\right\|\leq\left\|G\right\|
.

For
\widehat{B}
, we note that
\widehat{B}-B=[\widehat{G}]^{1:m}-[G]^{1:m}=[\widehat{G}-G]^{1:m}
is a submatrix of
\widehat{G}-G
. Therefore
\|\widehat{B}-B\|\leq\|\widehat{G}-G\|
.
∎

V-C

Proof of
Theorem

2

Proof.

For simplicity, we let
c_{1}=s_{\max}md/s_{\min}
and
\rho_{\Delta}\coloneqq\left\|\widehat{A}-A\right\|\leq\kappa_{2}\sqrt{c_{1}/(s_{\min}T)}
.

Step 1: We first prove
Equation

8
.
To do this, we first upper bound error of the estimated observability matrix
\widehat{O}(C)
for any non-zero measurement matrix
C
.

\begin{split}\left\|\widehat{O}(C)-O(C)\right\|\leq\sum_{i=1}^{r-1}\left\|C(A^{i}-\widehat{A}^{i})\right\|\leq\sum_{i=1}^{r-1}\left\|A^{i}-\widehat{A}^{i}\right\|.\end{split}

We relate error in
\widehat{A}^{i}
to error in
\widehat{A}
with the following lemma:

Lemma 3
.

Consider any matrix
A
satisfying Assumption
1
with constants
\psi_{A},\rho_{A}
. Consider any perturbation
\Delta
satisfying
\left\|\Delta\right\|\leq\rho_{\Delta}
. The following holds for any positive integer
n
:

\begin{split}\left\|(A+\Delta)^{n}-A^{n}\right\|\leq n\left(\frac{\psi_{A}}{\rho_{A}}\right)^{2}\left(\rho_{A}+\frac{\psi_{A}}{\rho_{A}}\rho_{\Delta}\right)^{n-1}\rho_{\Delta}.\qed\end{split}

(19)

We apply the above lemma and get

\begin{split}{}&\left\|\widehat{O}(C)-O(C)\right\|\leq\sum_{i=1}^{r-1}i\left(\frac{\psi_{A}}{\rho_{A}}\right)^{2}\left(\rho_{A}+\frac{\psi_{A}}{\rho_{A}}\rho_{\Delta}\right)^{i-1}\rho_{\Delta}\\
={}&\frac{\psi_{A}^{2}}{\rho_{A}^{2}}\rho_{\Delta}\frac{1-r(\rho_{A}+\psi_{A}\rho_{\Delta}/\rho_{A})^{r-1}+(r-1)(\rho_{A}+\psi_{A}\rho_{\Delta}/\rho_{A})^{r}}{(1-(\rho_{A}+\psi_{A}\rho_{\Delta}/\rho_{A}))^{2}}\\
\leq{}&\frac{\psi_{A}^{2}}{\rho_{A}^{2}}\rho_{\Delta}\frac{1-(r-1)(\rho_{A}+\psi_{A}\rho_{\Delta}/\rho_{A})^{r-1}\left(1-\rho_{A}-\psi_{A}\rho_{\Delta}/\rho_{A}\right)}{(1-(\rho_{A}+\psi_{A}\rho_{\Delta}/\rho_{A}))^{2}}.\end{split}

By
Equation

7
,
T>16\psi_{A}^{2}\kappa_{2}^{2}c_{1}/(\rho_{A}(1-\rho_{A}))^{2}
and therefore
\rho_{A}+\psi_{A}\rho_{\Delta}/\rho_{A}<(3\rho_{A}+1)/4<1
. It then follows that,

\begin{split}{}&\left\|\widehat{O}(C)-O(C)\right\|\leq\frac{(4/3)^{2}\psi_{A}^{2}}{\rho_{A}^{2}(1-\rho_{A})^{2}}\rho_{\Delta}\\
\leq{}&\frac{(4/3)^{2}\psi_{A}^{2}}{\rho_{A}^{2}(1-\rho_{A})^{2}}\sqrt{\frac{\kappa_{2}^{2}c_{1}}{s_{\min}T}}<\sqrt[4]{\frac{1}{s_{\min}T}}.\end{split}

Here the last inequality is also by
Equation

7
.

Now we define
r_{c}\coloneqq\text{rank}\left(O(C)\right)
and get

\begin{split}\sigma_{r_{c}}\left(\widehat{O}(C)\right)\geq{}&\sigma_{r_{c}}\left(O(C)\right)-\left\|\widehat{O}(C)-O(C)\right\|\\
\geq{}&\sigma_{O}-\sqrt[4]{\frac{1}{s_{\min}T}}>\sqrt[4]{\frac{1}{s_{\min}T}}.\end{split}

The last inequality is by
Equation

7
. On the other hand, for positive integer

VIII
Conclusions

In this paper, we address the problem of learning efficient sensor allocations that guarantee observability with a small number of sensors for unknown high-dimensional linear systems.
Our two-stage solution consists of a novel SYSID algorithm that integrates information from multiple data trajectories, each potentially observing a different subset of the state coordinates, and a sensor allocation algorithm that operates on approximated system parameters. When sensors can be allocated on any state coordinate, the SYSID algorithm is guaranteed to learn the system parameters up to an error of
\tilde{\mathcal{O}}(\sqrt{md/(s_{\min}T)})
, where
m
is the input dimension,
d\geq r
is a hyperparameter with
r
being the state dimension,
s_{\min}
is the least number of trajectories used to measure one state coordinate, and
T
is the trajectory length. Furthermore, the sensor allocation algorithm is guaranteed to output an allocation with at most
(1+\log(r))n^{*}
sensors, where
n^{*}
is the minimum number of sensors required to ensure observability. We also extend our algorithms to scenarios where certain state coordinates are inaccessible. The efficiency of our algorithms is validated through numerical experiments.

Lemma 5

General Lemmas

Lemma 7
.

For any random matrix
M\in\mathbb{R}^{a\times b}
, there exists a unit vector
x\in\mathbb{S}^{b-1}
such that for all
\epsilon<1

\begin{split}\mathbb{P}(\left\|M\right\|>z)\leq\left(1+\frac{2}{\epsilon}\right)^{b}\mathbb{P}\left(\left\|Mx\right\|>(1-\epsilon)z\right).\end{split}

(50)

Here
\mathbb{S}^{b-1}
denotes the unit sphere in
\mathbb{R}^{b}
.

Proof.

From Lemma 5.3 of
[
35
]
, we know that

\begin{split}\mathbb{P}\left(\left\|M\right\|>z\right)\leq\mathbb{P}\left(\max_{x\in\mathcal{N}_{\epsilon}}\left\|Mx\right\|>(1-\epsilon)z\right),\end{split}

(51)

where
\mathcal{N}_{\epsilon}
is any
\epsilon
-net of
\mathbb{S}^{b-1}
with
|\mathcal{N}_{\epsilon}|\leq\left(1+2/\epsilon\right)^{b}
.
On the other hand,

\begin{split}{}&\mathbb{P}\left(\max_{x\in\mathcal{N}_{\epsilon}}\left\|Mx\right\|>(1-\epsilon)z\right)\leq\sum_{x\in\mathcal{N}_{\epsilon}}\mathbb{P}\left(\left\|Mx\right\|>(1-\epsilon)z\right).\end{split}

Combining the above inequalities gives

\begin{split}\mathbb{P}\left(\left\|M\right\|>z\right)\leq\sum_{x\in\mathcal{N}_{\epsilon}}\mathbb{P}\left(\left\|Mx\right\|>(1-\epsilon)z\right).\end{split}

(52)

Thus, by the pigeonhole principle, there exists
x\in\mathcal{N}_{\epsilon}
s.t.

\begin{split}\mathbb{P}\left(\left\|M\right\|>z\right)\leq{}&|\mathcal{N}_{\epsilon}|\cdot\mathbb{P}\left(\left\|Mx\right\|>(1-\epsilon)z\right)\\
\leq{}&\left(1+\frac{2}{\epsilon}\right)^{b}\mathbb{P}\left(\left\|Mx\right\|>(1-\epsilon)z\right).\end{split}

(53)

∎

Lemma 8

(Adapted from Theorem 4.1 of
[
20
]
)
.

Consider any
\delta\in(0,1)
. Let
C\in\mathbb{R}^{L\times L}
be a circulant matrix where the first row has distribution
\mathcal{N}(0,I)
. For any
L_{r}\times L_{c}
submatrix
\Phi_{L_{r}L_{c}}
of
C

\begin{split}L_{r}>cL_{c}\max\left\{\log^{2}(L_{c})\log^{2}(L),\log(1/\delta)\right\},\end{split}

\begin{split}{}&\left\|\frac{1}{L_{r}}\Phi_{L_{r}L_{c}}^{\intercal}\Phi_{L_{r}L_{c}}-I\right\|\\
\leq{}&\sqrt{c\frac{L_{c}}{L_{r}}\max\left\{\log^{2}(L_{c})\log^{2}(L),\log(1/\delta)\right\}}.\end{split}

(55)

Here

[

, consider any of its

, denoted by RIC, is defined as in

\begin{split}\text{RIC}\coloneqq{}&\max_{x\in\mathbb{R}^{L}:\left\|x\right\|=1\text{ and }\left\|x\right\|_{0}\leq L_{c}}\left|\frac{1}{L_{r}}\left\|\Phi_{L_{r}}x\right\|^{2}-\left\|x\right\|^{2}\right|\\
={}&\max_{x\in\mathbb{R}^{L}:\left\|x\right\|=1\text{ and }\left\|x\right\|_{0}\leq L_{c}}\left|x^{\intercal}\left(\frac{1}{L_{r}}\Phi_{L_{r}}^{\intercal}\Phi_{L_{r}}-I\right)x\right|.\end{split}
