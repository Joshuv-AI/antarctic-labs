avbirt: A Python Package for Flexible Item Factor Analysis with Adversarial Variational Bayes
Authors: Nanyu Luo, Feng Ji
Published: 2026

Description

The open-source Python package avbirt (Adversarial Variational Bayes for Item Response Theory) implements Importance-Weighted Adversarial Variational Bayes (IWAVB), a deep adversarial learning algorithm for high-dimensional item factor analysis (IFA) of ordinal item response data (Luo & Ji, 2025). From a single estimator class, it fits confirmatory and exploratory IFA models under the graded response model (Samejima, 1969), returning item discriminations, category intercepts, factor scores, the inter-factor correlation matrix, and an approximate marginal log-likelihood. IWAVB bridges variational autoencoders (VAEs; Kingma & Welling, 2014) and generative adversarial networks (GANs; Goodfellow et al., 2014): whereas VAE-based estimators such as the importance-weighted autoencoder (IWAE) for IFA (Urban & Bauer, 2021) restrict the inference model to a standard normal family, Adversarial Variational Bayes (Mescheder et al., 2017) replaces the closed-form Kullback–Leibler term with an auxiliary discriminator network, yielding a flexible, implicitly defined posterior that better fits non-normal latent distributions.

Three further techniques make IWAVB practical at scale: an importance-weighted ELBO that tightens the bound toward marginal maximum likelihood (Burda et al., 2016), adaptive contrast that keeps the adversarial task tractable in high dimensions, and doubly reparameterized gradients that reduce encoder-gradient variance (Tucker et al., 2019). IWAVB matches the state-of-the-art IWAE on parameter recovery while consistently attaining higher likelihoods, and outperforms it when the latent variables are multimodal (Luo & Ji, 2025). Built on PyTorch (Paszke et al., 2019) and Pyro (Bingham et al., 2019), the package offers a scikit-learn-style API (fit, predict, log-likelihood, and parameter accessors), verified configuration presets, and an automatic hyperparameter tuner; full methodology and evaluations appear in Luo and Ji (2025).

Availability

avbirt is a free, open-source program for Adversarial Variational Bayes estimation of confirmatory and exploratory item factor analysis under the graded response model, released under the MIT license and under continued development. Written in Python (3.9+) on PyTorch (Paszke et al., 2019) and Pyro (Bingham et al., 2019), it is platform-independent (Linux, macOS, and Windows), runs on a standard CPU with no unusual memory or disk requirements, and uses a CUDA-capable GPU for high-dimensional models (GPU memory being the only resource that scales with model size). Documentation includes an installation and usage guide, an application programming interface (API) reference, a changelog, and executable example notebooks reproducing the published studies. The program is distributed free over the internet: install from the Python Package Index with pip install avbirt, with source code, documentation, and issue tracker at https://github.com/Feng-Ji-Lab/AVBIRT.
