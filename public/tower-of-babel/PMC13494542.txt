Systematic benchmarking of CUT&Tag improves the reliability and reproducibility of chromatin analysis
Authors: Josiah D. Murray, Atrayee Ray, Khanmi Kasomva, Erica Steen, Cary Stelloh, Kirthi Pulakanti, Phillip A. Doerfler, Navonil De Sarkar, Qiongzi Qiu, Yong Liu, Aron M. Geurts, Allen W. Cowley, Alison E. Meyer, Mingyu Liang, Sridhar Rao
Published: 2026

ABSTRACT
SummaryCleavage under target and tagmentation (CUT&Tag) is a widely used method for profiling chromatin occupancy; however, its reproducibility is impacted by a lack of standardization in experimental and analytical procedures. This study identifies four key parameters critical for optimizing CUT&Tag performance. First, optimal cell number requirements are target and species specific: H3K27me3 detection requires ≥10K cells in both mouse and rat cells, whereas CTCF mapping needs 50K cells in mouse embryonic stem cells and 100K in rat C6 cells, reflecting potential differences in protein abundance and antibody affinity. Second, the peak-calling methodology is crucial; default model-based analysis of chromatin immunoprecipitation followed by sequencing (MACS2) scaling causes a paradoxical decrease in peak numbers with decreasing IgG control size, a limitation resolved by the “scale-to-large” option. Third, duplicate removal strategies differentially affect peak callers, with MACS2 performing best using biological reads and sparse enrichment analysis for CUT&RUN (SEACR) relying on technical duplicates for accurate calling. Finally, mild crosslinking with 0.2 mM ethylene glycol bis (succinimidyl succinate) (EGS) for 5 min enhances CTCF detection and reduces variability. Together, these optimizations establish practical guidelines for reliable CUT&Tag experimental design and analysis.

Introduction

Cleavage under target and tagmentation (CUT&Tag) is an epigenomic assay used to profile the genomic occupancy of proteins.1 Since the method was originally described in 2019,2 CUT&Tag has gained widespread usage with hundreds of peer-reviewed publications. Compared with chromatin immunoprecipitation followed by sequencing (ChIP-seq), CUT&Tag requires fewer cells, lower sequencing depth, and can be automated to increase throughput.3 These advantages have led to the rapid uptake of CUT&Tag by the scientific community. However, several aspects of the CUT&Tag protocol vary across publications, indicating a need for further standardization. Key optimization opportunities include cell numbers, crosslinking conditions, duplicate read handling, and peak-calling program selection and parameters. These choices can have significant impacts on data quality and the reliability of biological inferences. Given the popularity of CUT&Tag, it is important to provide the research community with more information about these choices and their impact on results.

Cell numbers for CUT&Tag range from 500,000 to single-cell applications. Despite improvements in the resolution of single-cell CUT&Tag (scCUT&Tag), it is currently not possible to capture a factor’s complete genome-wide binding in a single cell. Therefore, peak calling for scCUT&Tag is performed on pseudo-bulk samples created by combining data from thousands of single cells. Researchers would benefit from knowing how many cells are sufficient to saturate peak calling for both histone and non-histone targets. Another common practice is gentle crosslinking with 0.1% formaldehyde (CH2O) to stabilize protein-DNA interactions and to preserve cells prior to freezing. The benefits of this strategy are unproven outside the context of freezing samples for storage and represent an opportunity to help researchers optimize their crosslinking approach.

For computational analysis of CUT&Tag data, one key choice facing researchers is which program to use for peak calling. Many papers use model-based analysis of ChIP-seq (MACS)4 for peak calling, but the sparse enrichment analysis for CUT&RUN (SEACR) algorithm5 was written specifically for CUT&RUN/CUT&Tag data and may be better suited. Despite this, most papers continue to use MACS2, and several other peak-calling programs have also been published.6 Additionally, although the original CUT&Tag publication used ∼2–3 million (M) reads, deeper sequencing is not uncommon for CUT&Tag libraries, which increases the percentage of duplicate sequences. Researchers must decide how to handle these duplicate reads. This decision is complicated because duplicates can arise from PCR amplification, as an optical sequencing artifact, or due to true biological duplicates from separate cells. It would be helpful to know how common biological duplicates are, where they typically occur, whether their prevalence varies by CUT&Tag target, and how their retention or removal impacts peak calling.

To address these issues, we systematically standardized cell input numbers across mouse and rat samples using representative cell lines under defined crosslinking conditions with multiple biological replicates and performed peak calling with MACS2 and SEACR. We also performed scCUT&Tag to determine biological duplication rates across different chromatin targets. Our findings demonstrate that histone marks require fewer cells than sequence-specific DNA-binding proteins like CTCF. Peak-calling optimization shows that MACS2 should be run using the “scale-to-large” setting to enable peak detection with the low-background IgG-control files that are typical of CUT&Tag. We also find that MACS2 and SEACR have opposite patterns in response to duplicates. MACS2 calls more peaks when technical duplicates are present, and SEACR calls more peaks when technical duplicates are removed. Finally, we show that CUT&Tag for CTCF can be significantly improved using light crosslinking with 0.2 mM ethylene glycol bis (succinimidyl succinate) (EGS). These findings can aid in the design and analysis of CUT&Tag experiments, thereby allowing for more reliable chromatin analyses.

Results

Cell number optimization for CUT&Tag

To achieve high-quality genome-wide CUT&Tag profiles, optimization of the input cell number is crucial and depends on the target protein’s abundance and genomic distribution. We investigated cell number requirements for two targets: H3K27me3, a highly abundant repressive histone mark, and CTCF, a CCCTC-motif binding transcription factor. We hypothesized that optimal cell numbers would differ between these targets and potentially across species due to differences in protein distribution and antibody affinity.

To test this hypothesis, CUT&Tag experiments were performed in mouse embryonic stem cells (mESCs) and rat C6 glial cells and compared with published human erythroleukemia cell line (K562) data. Standardization using these rodent cell lines enabled the assessment of cross-species reproducibility of H3K27me3 and CTCF binding, serving as a benchmark for comparison with published human data.1 Four different cell numbers (1K, 10K, 50K, and 100K cells) were tested per target and cell type. Most libraries achieved a high sequencing depth (∼10M to 48M reads), comparable to or exceeding published H3K27me3 CUT&Tag datasets in K5621 (compare Figure S1A and S1C with S1B). CTCF libraries exhibited higher duplication rates (45%–84%; Figure S1C, green bar), resulting in 2M–9M unique fragments, sufficient for downstream analysis, whereas H3K27me3 libraries displayed low duplication (∼2%–13%) (Figure S1A, green bar). This suggests that library complexity is driven primarily by the genomic-binding characteristics of the target mark, rather than sequencing depth alone. Two low-quality H3K27me3 samples (<0.2M mapped reads; one from mESC 1K cells [replicate 3], and another from rat C6 1K cells [replicate 2], Table S1) were excluded. Merged replicate signal profiles revealed distinct cell number dependencies. H3K27me3 signal intensity scaled proportionally with cell number in both cell types, with a pronounced drop from 10K to 1K (Figure 1A), particularly in rat C6 cells. These findings indicate that a minimum of 10K cells is sufficient for reliable genome-wide H3K27me3 profiling by CUT&Tag across species. CTCF exhibited more stringent cell number requirements and cell-type-specific dependencies (Figure 1A). To validate signal intensity and cell-number-dependent effects, we examined representative H3K27me3 and CTCF loci in mESCs and rat C6 cells.

Alignments from three biological replicates per condition were merged to generate signal tracks and MACS2 peaks (by using scale-to-large). At the Hoxb locus, a known H3K27me3-enriched region in embryonic stem cells (ESCs),7,8 signal intensity markedly decreased from 10K to 1K cells (Figure 1B, top and bottom). Interestingly, at 1K cells, although the overall H3K27me3 signal decreased, peak numbers increased relative to higher inputs. This reflects signal fragmentation: a strong signal at higher cell numbers produces fewer, broad peaks spanning polycomb repressive domains, whereas a weakened signal at 1K cells becomes fragmented into many small, isolated peaks with reduced biological relevance. These observations confirm that ≥10K cells are required for reliable H3K27me3 detection in both species. In contrast, at the Cebpb locus, previously reported to contain CTCF-binding sites within its regulatory region,9 both signal and peak numbers dropped sharply from 50K to 10K cells in both species (Figure 1C), confirming higher input requirements for CTCF.

Beyond cell number optimization, we assessed whether sequencing depth affects peak detection. We performed saturation analysis by randomly downsampling CTCF (5M to 10K) and H3K27me3 (15M to 10K) data from mESCs (100K cell input) and calling peaks with MACS2 default settings (Figure S1D). Both marks showed decreasing peak counts with reduced read depth. H3K27me3 peak counts saturated at ∼10M reads (Figure S1D, light blue), whereas CTCF peak counts did not reach saturation even at the original depth (∼9M) (Figure S1D, deep blue). At comparable read depths (e.g., 5M to 10K), both marks showed similar declining trends, indicating that sequencing depth is a critical parameter for peak detection in CUT&Tag.

Finally, we performed an irreproducible discovery rate (IDR) analysis on H3K27me3 and CTCF peaks (detected by MACS2 scale-to-large) across input levels to assess peak reproducibility. Peak concordance increased with higher input in both mESCs and rat C6 cells (Figure S2). H3K27me3 showed reproducible peaks at ≥10K input cells (Figures S2A and S2C), whereas CTCF achieved the highest reproducibility at 50K–100K cells in both cell types (Figures S2B and S2D). Overall, ∼10K cells are sufficient for genome-wide H3K27me3 profiling, while CTCF requires higher, cell-type-dependent inputs, and adequate sequencing depth is necessary for accurate peak detection across targets and species.

Optimization of peak callers across cell numbers and targets

We initially used MACS2 for our peak-calling analyses but acknowledge that alternative algorithms can influence CUT&Tag data interpretation. To determine commonly used peak-calling software, we reviewed 250 articles published between 2020 and 2025 that explicitly reported their peak caller (Figure 2A; Table S2). Based on this, we compared MACS2 and SEACR using our datasets to identify the optimal peak-calling strategy. For MACS2, we tested two scaling modes: default scaling, which downsamples the larger dataset to match the smaller one, and scale-to-large, which scales the smaller dataset up to the larger read depth.4 Because scale-to-large may inflate low-count regions and introduce false positives, we applied a stringent q value (or broad cutoff) of 1e−5 versus 0.01 for default scaling. All MACS2 analyses were performed with “--nolambda” and “--nomodel” to improve CUT&Tag performance.5,12 SEACR uses a distinct strategy, segments the genome-wide signal into continuous regions, and assigns scores based on fragment counts.5 It then determines a cutoff that maximizes the ratio of target regions to total regions above threshold, using a default “stringent” mode, with an optional more permissive “relaxed” mode (see Meers et al.5 for details). We excluded outlier replicates identified by Grubbs’ test (Table S1, outliers marked by ∗). We used two IgG normalization strategies: (1) merged IgG, in which replicate-level IgG reads were pooled to generate a merged control file for all replicates at each condition (Figures 2B and 2C; Figures S3A and S3B, left); and (2) corresponding IgG, in which replicate-matched IgG controls were used (Figures 2B and 2C; Figures S3A and S3B, right).

In mESCs, MACS2 (both modes) consistently outperformed SEACR for H3K27me3 and CTCF across most input cell numbers, yielding higher peak counts, tighter replicate clustering, and saturation consistent with signal intensity results (Figures 2B and 2C). However, under the corresponding IgG at lower cell input (1K), SEACR identified more H3K27me3 peaks than MACS2 but with high replicate variability and no consistent increase across inputs (Figure 2B, compare left vs. right). For H3K27me3, MACS2 detected ∼2–7 × 103 peaks at 1K cells and increased to ∼4–9 × 104 peaks at 100K, whereas SEACR (stringent and relaxed) remained <∼104 peaks with greater variability (Figure 2B; Table S1). For CTCF, MACS2 robustly detected ∼3–60 × 103 peaks across inputs, while SEACR remained sparse and inconsistent (Figure 2C; Table S1). MACS2-detected peaks saturated at 10K for H3K27me3 and at 50K for CTCF, consistent with our signal intensity analysis. Notably, under merged IgG, MACS2 default mode detected more H3K27me3 peaks, while scale-to-large improved CTCF detection. Consensus peak analysis across three replicates for each cell input condition showed that MACS2 (in both modes) results were similar between the merged and the corresponding IgG conditions for both marks (Figures 2D and 2E, blue and yellow shapes). In contrast, SEACR varied substantially between control strategies, particularly for CTCF, along with increased variability across replicates (Figure 2E, green and red shapes). Overall, MACS2 provides more consistent and reproducible peak detection across both IgG control strategies, whereas SEACR, despite detecting more peaks under the corresponding IgG, exhibits high replicate variability and no consistent increase with cell input.

In rat C6 cells, SEACR again produced higher H3K27me3 peak counts at low input but with strong replicate variability, whereas MACS2 scale-to-large showed a steady, reproducible increase in peak numbers with cell number and outperformed default scaling under both IgG normalization strategies (Figure S3A). For CTCF, MACS2 scale-to-large remained most stable, while SEACR showed extreme variability and frequent peak loss at low inputs (Figure S3B). We did not observe substantial differences in peak numbers between the two IgG control strategies across most peak callers, except with MACS2 default (Figure S3C). In contrast, CTCF peak detection by SEACR differed markedly between the two IgG control strategies (Figure S3D). Thus, despite occasional high peak counts, SEACR’s replicate-level instability limits its reliability.

Analysis of published H3K27me3 CUT&Tag data from K562 cells (H3K27me3, GEO: GSE158327 [“lab samples”]; IgG, GEO: GSM3680227)1 showed that MACS2 default was inconsistent, whereas MACS2 scale-to-large and SEACR performed more comparably (Figure S3E). Although the behavior of peak calling differs somewhat from our study, several technical factors may explain these discrepancies, likely due to the use of a single IgG control (derived from 100K cells) and lower sequencing depth (Table S1). Overall, across our datasets and external validation, MACS2 with scale-to-large provided the most robust and consistent peak detection.

To assess peak reproducibility across cell inputs, we calculated pairwise overlap percentages of high-confidence H3K27me3 peaks (present in two of three replicates) using MACS2 (scale-to-large) and SEACR (stringent) (Figure S4). Because SEACR failed to detect CTCF peaks at higher inputs (100K and 50K), analysis was restricted to H3K27me3. In mESCs, MACS2 (scale-to-large) showed high reproducibility, with strong overlaps between 100K and lower inputs (50K and 10K) (Figure S4A, left heatmap). In contrast, SEACR detected fewer peaks and showed much lower overlap between the 100K and 50K conditions (Figure S4B, left heatmap). In rat C6 cells, SEACR exhibited relatively higher overlap than MACS2 (compare Figure S4A with S4B, right heatmaps), likely due to fewer peaks detected at the 100K condition compared to the lower inputs (Figure S4B, Venn diagram). Overall, MACS2 scale-to-large achieves more consistent and robust peak identification across inputs in mESCs, whereas SEACR is more variable and context dependent.

To determine whether cell input requirements and the peak-calling behavior extend to other histone modifications, we analyzed four additional histone marks in mESCs: H3K27ac (active enhancer and promoter), H3K4me3 (active promoter), H3K36me3 (active gene bodies), and H3K9me3 (repressive chromatin) (Figures S4C–S4E). CUT&Tag profiles from 10K to 100K cells were highly comparable, indicating that ∼10K cells are also sufficient to reliably detect these histone marks (Figure S4C). Consistent with earlier observations, MACS2 detected more peaks compared to SEACR, whereas SEACR exhibited higher replicate-level variability across all marks for both input conditions (Figure S4D). Representative loci illustrated consistent enrichment patterns across input levels, including active marks (H3K27ac, H3K4me3, and H3K36me3) at the Sox2 locus (Figure S4E).

SEACR (both modes) detected few CTCF peaks at high IgG reads (10M–2.5M) but showed a sharp increase as IgG read decreased, indicating optimization for low-background conditions but excessive stringency at higher IgG reads (Figure 3A, red and green lines). MACS2 default detected peaks above 2.5M IgG but failed at 0.01M, suggesting insufficient statistical power for peak detection with sparse controls (Figure 3A, blue line). In contrast, MACS2 scale-to-large maintained consistent peak detection across all IgG depths (Figure 3A, orange line). This indicates that scale-to-large reliably scales the control to treatment depth, ensuring consistent peak detection across varying IgG read levels.

To validate peak quality across these conditions, we calculated the fraction of reads in peaks (FRiP) scores for each downsampled IgG condition (Figure 3B). FRiP analysis supported these trends: MACS2 scale-to-large maintained a consistent FRiP score (∼0.13) across all IgG levels, whereas MACS2 default declined sharply at low IgG levels (<0.02 below 0.05M IgG reads), and SEACR showed an increase in FRiP score with decreasing IgG depth (Figure 3B). We further addressed peak-calling consistency by calculating overlap percentages between peaks called with the full combined IgG reads and those called with downsampled IgG controls using MACS2 scale-to-large and SEACR stringent (Figure 3C). Peak overlap analysis further demonstrated that MACS2 scale-to-large maintained high concordance across IgG depths (Figure 3C, top, red correlation), indicating the method’s reliability and credibility for peak detection across a wide spectrum of background signal availability, while SEACR showed low concordance (Figure 3C, bottom, blue coloration), highlighting the method’s sensitivity to background signal abundance.

Genome browser visualization of representative CTCF loci in mESCs and rat C6 cells validated these findings (Figures 3D and 3E). For this analysis, we merged all three 100K mESC CTCF replicates and performed peak calling with the described methods using combined IgG controls. Known mm10 CTCF cis-regulatory elements (CREs) from the SCREEN database13 were included as positive controls to validate true binding sites.

Peaks identified by all callers (black arrows) represent high-confidence CTCF-binding sites, aligning with known CREs and validating biological relevance (Figures 3D and 3E). Peaks called by only MACS2 (brown arrow) indicated its higher sensitivity in identifying certain binding events not captured by SEACR, reflecting differences in the statistical framework and thresholding. Peaks detected by all methods except SEACR stringent (blue arrows) highlight the conservative nature of SEACR. Peaks called only by SEACR relaxed (red arrows) often show minimal CTCF signal over IgG controls, suggesting potential false positives (Figures 3D and 3E). These observations were consistent in rat C6 cells (Figure 3E), further emphasizing the differential sensitivity and specificity among the peak callers.

Collectively, IgG read depth critically affects peak calling. MACS2 scale-to-large provides robust, consistent detection with stable FRiP across variable background, whereas SEACR performs reliably only under low-background conditions. Additionally, technical duplicates may further impact peak calling by inflating read counts and potentially leading to spurious peak calls. This is examined in the next section.

The presence of biological duplicates in CUT&Tag data is target and cell number dependent

All CUT&Tag libraries contain fragments with identical sequences (duplicates) arising from technical sources (PCR amplification and sequencing artifacts) or from two independent cells undergoing tagmentation at the same genomic loci (biological duplicates). Some analytical pipelines remove duplicate fragments to minimize technical noise, whereas others retain them to preserve biological signal. scCUT&Tag enables the identification of biological duplicates by tracing identical fragments originating from different cells (Figure 4A). We hypothesized that biological duplicates would be more prevalent for proteins with specific genomic localizations and less common for histone marks like H3K27me3. To test this, we performed scCUT&Tag for the cohesin subunit RAD21 in human OCI-AML3 cells and re-analyzed published H3K27me3 scCUT&Tag data from K562 cells.2 A suitable CTCF antibody for scCUT&Tag could not be identified (data not shown). Both samples were sequenced deeply (55 × 103 reads per cell for H3K27me3 and 83 × 103 for RAD21) and showed comparable data quality based on unique fragments per cell (Figures 4B and 4C). Duplicates within the same cell were considered technical and removed. This approach identified biological duplicates in both samples but revealed striking differences in frequency. They were extremely rare in H3K27me3 libraries (<0.2% of all biological fragments in 900 cells) but more common for RAD21 (∼4% in 1,400 cells). Biological duplicates increased with cell input (Figure 4D) and rose faster than technical duplicates, increasing their overall contribution (Figures 4E and 4F), indicating a meaningful signal at higher cell numbers. A previous assay for transposase-accessible chromatin using sequencing (ATAC-seq) study incorporating unique molecular identifiers (UMIs) found that for 100K cells, ∼6% of mapped reads were biological duplicates, with 80% of these originating from the top 2% of the most accessible loci.14 We identified a similar bias in scCUT&Tag for H3K27me3, with biological duplicates enriched in high-signal genomic bins (Figure 4G, left). Compared to H3K27me3, RAD21 showed a stronger bias, with ∼75% of biological duplicates occurring within genomic bins corresponding to the top 2% of signal (Figure 4G, right). A similar but weaker trend was observed for all duplicates (biological + technical), implying that retained duplicates can enhance signal at high-occupancy sites. The optimal number of duplicates to retain depends on both chromatin target and cell number. MACS2 models biological duplicates using a binomial framework, identifying suitable thresholds in our scCUT&Tag data: one duplicate allowed for H3K27me3 and up to two for RAD21, consistent with histograms for biological duplicates in H3K27me3 and RAD21 (Figure 4H). SEACR does not provide statistical modeling for duplicate removal.

To assess the impact of duplicate handling on peak calling, we compared three strategies: “all” (retain all reads including duplicates), “unique fragments” (remove all duplicates), and “biological” (retain unique fragments and biological duplicates). As biological duplicates occur at high-signal regions, and Integrative Genomics Viewer (IGV) tracks appeared nearly identical across strategies (aside from the y axis; Figures 5A and 5B), we hypothesized that duplicate removal would have minimal impact on peak discovery. Peak calling was performed using MACS2 scale-to-large, SEACR stringent, and SEACR relaxed. H3K27me3 peaks were compared with ENCODE ChIP-seq peaks, and only three conditions had >75% agreement with ENCODE: MACS2 for “biological fragments”, MACS2 for unique fragments, and SEACR stringent for “all fragments” (Figure 5C). Technical duplicates led to false positives in MACS2 (relative to ENCODE), whereas SEACR called fewer peaks for all fragments. Peak calling for RAD21 showed similar but more pronounced patterns (Figure 5D). SEACR was particularly unstable, and despite only a 4% difference in input reads (5.01M vs. 4.8M), biological fragments yielded ∼300K RAD21 peaks, while unique fragments yielded <10K peaks. MACS2 was consistent across these two conditions, generating expected peak numbers (30K–60K, consistent with prior studies15,16), but overcalled peaks when technical duplicates were present (∼650K peaks for all fragments). Although the all fragments dataset was ∼95% duplicates, SEACR performed best under this condition. SEACR overcalled peaks for biological fragments, as very few of the ∼300K peaks (<5%) overlapped with peaks detected using unique fragments and all fragments, resulting in few consensus SEACR peaks for RAD21 (<12K, see brown bar in Figure 5D). SEACR biological fragments peaks also often missed clear RAD21-binding sites detected by other SEACR methods and MACS2 (see arrows for representative loci in Figures S6A and S6B). Overall, biological duplicate removal had minimal impact on MACS2 peak numbers but strongly affected SEACR. This suggests that MACS2 is more reproducible when duplicates are removed, whereas SEACR may benefit from higher duplication levels.

Although scCUT&Tag can distinguish biological duplicates, its sparse signal (only 1K–10K unique fragments per cell, even for abundant targets) limits interpretability, as the absence of signal does not imply the absence of binding. While signal sparsity, a well-documented issue for single-cell ATAC-seq (scATAC-seq), can be partially overcome using matrix imputation,17 most CUT&Tag experiments in the literature are performed in bulk. To assess whether these trends extend to bulk data, we performed bulk CUT&Tag for RAD21 in OCI-AML3 cells and removed duplicates using either Picard or MACS2 binomial duplicate removal modeling. The same general pattern was observed: MACS2 called more peaks with duplicates present, whereas SEACR called more peaks when duplicates were removed (Figure 5E), though the effects were less pronounced due to lower duplication (∼20%). Consensus peak overlaps (≥50% replicates) are shown in Figure 5F. Together with our scCUT&Tag results, these findings demonstrate that duplicate reads impact peak calling and should be carefully considered. Overall, we find the statistical modeling and adjustable q value of MACS2 to be useful for calling peaks with more or less stringency based on the experimental purpose.

EGS crosslinking improves CUT&Tag discovery of CTCF-binding sites

The hyperactive pA-Tn5 transposase used for CUT&Tag exhibits non-specific DNA binding, leading to high background signal at open chromatin regions if low-salt buffers are used during tagmentation.18 This can be minimized using supra-physiological NaCl concentrations (∼300 nM), which allow salt ions to compete with pA-Tn5-DNA interactions but may also strip transcription factors from chromatin.19 Light crosslinking with 0.1% formaldehyde (CH2O) is commonly used to prevent this but has not been shown to improve results and can reduce library yields at higher CH2O concentrations. EGS, a protein-protein crosslinker with a longer spacer (∼16 Å), has been used in ChIP-seq.20,21 We reasoned that EGS could stabilize protein-chromatin interactions without limiting pA-Tn5 access due to the flexibility of its extended spacer and reduced propensity for crosslinking DNA. To optimize EGS crosslinking conditions, OCI-AML3 cells were crosslinked for 5 min with varying EGS concentrations and subjected to CTCF CUT&Tag. Capillary electrophoresis revealed that higher EGS concentrations reduced library yield, but 0.2 mM EGS produced yields comparable to native (uncrosslinked) CUT&Tag (Figure S7A). Based on this finding, we tested CUT&Tag for CTCF under five crosslinking conditions: 0.2 mM EGS, 0.1% CH2O, dual crosslinking (either 0.2 mM EGS + 0.1% CH2O or 0.5 mM EGS + 0.1% CH2O), and native (uncrosslinked) cells.

Capillary electrophoresis showed that EGS crosslinking shifted fragment sizes toward mononucleosomes, though this was not reflected in sequenced reads (Figures S7A and S7B), likely because Illumina platforms preferentially cluster smaller fragments. Pairwise correlation analysis using 500 bp genomic bins revealed that dual-crosslinking samples grouped together, as did 0.2 mM EGS samples. Uncrosslinked samples (0 mM EGS) showed the most replicate-to-replicate variability, indicating that crosslinking can increase the reproducibility of CUT&Tag for CTCF (Figure 6A). We next examined how crosslinking impacts library diversity. This demonstrated a dose-dependent reduction in library diversity with stronger crosslinking, but 0.2 mM EGS preserved diversity and improved consistency among replicates compared to uncrosslinked cells (Figure 6B, top). Elbow plots for MACS2 peaks revealed that, despite lower CTCF library diversity in dual-crosslinked samples, peak numbers remained similar to uncrosslinked samples (Figure 6C). Notably, 0.2 mM EGS crosslinking consistently produced higher peaks across q value thresholds and significantly increased peak counts at q = 1e−5 compared to uncrosslinked samples, with mean peak totals of 44.9K and 31.4K, respectively (p = 0.028, Figure 6D). These peaks were highly reproducible, yielding 41.7K consensus CTCF peaks (defined as peaks identified in two of four replicates) versus only 31K for uncrosslinked samples (Figure 6E). Peak overlaps for all replicates are shown in Figure S7C.

Each crosslinking condition identified unique consensus peaks (608 for uncrosslinked, 1,519 for 0.1% CH2O, and 8,182 for 0.2 mM EGS) (Figure 6E). To test the validity of these condition-specific peaks, we performed motif enrichment analysis using HOMER and compared the results to the 28,475 consensus peaks shared across all crosslinking conditions (Figure 6F). Motif analysis showed strong CTCF enrichment across all sets. The highest log2 enrichment was in 0.1% CH2O-specific peaks (4.2), followed by shared consensus peaks (4.1), 0.2 mM EGS (3.6), and uncrosslinked samples (3.5). Comparison with published CTCF ChIP-seq data demonstrated that 0.2 mM EGS crosslinking improved detection at genomic loci with clear ChIP-seq signal, whereas uncrosslinked and 0.1% CH2O conditions had weaker signal at these sites (example shown in Figure S7D). Overall, while all conditions captured unique CTCF-binding sites, 0.2 mM EGS crosslinking identified substantially more high-confidence peaks and improved CUT&Tag performance, suggesting that a 5-min 0.2 mM EGS crosslinking step may be helpful for CUT&Tag profiling of sequence-specific DNA-binding proteins.

Discussion

This study identifies several fundamental optimization parameters that are essential for successful CUT&Tag experimental design. Our findings reveal that careful consideration of these technical factors can significantly impact data quality and experimental reproducibility.

Input cell number represents a critical parameter that varies substantially based on target protein characteristics and the experimental system. Our analysis demonstrates that optimal cell number depends on the genome-wide binding abundance of the target protein(s). For the highly abundant histone mark H3K27me3, a minimum of 10K cells provides sufficient signal for reliable genome-wide occupancy profiling, reflecting its broad genomic distribution and high cellular abundance (Figure 1). Extending our analysis to additional histone marks, including H3K27ac, H3K4me3, H3K36me3, and H3K9me3, further supports the conclusion that ∼10K input cells are generally sufficient to capture genome-wide enrichment patterns for five distinct histone marks, which frequently do not overlap in the genome (Figures S4C–S4E). By contrast, the transcription factor CTCF requires substantially higher cell numbers due to its more restricted genomic distribution and lower abundance. Also, our findings reveal species-specific differences in optimal cell numbers: while 50K cells represent the minimum threshold for CTCF detection in mESCs, rat C6 cells require 100K cells for equivalent signal quality (Figure 1A, right). This species-specific variation likely reflects reduced antibody affinity when using antibodies raised against mouse epitopes in rat cells, highlighting the importance of empirical optimization for each experimental system. Nevertheless, our data suggest that 50K–100K cells represent a logical starting point for DNA-binding proteins, as MACS2 scale-to-large detected a consistent number of peaks across these cell numbers (Figures 2B and 2C; Figures S3A and S3B).

The choice of peak-calling algorithm represents another critical decision that significantly impacts downstream analysis quality. Our comprehensive comparison of SEACR and MACS2 reveals distinct performance characteristics that inform method selection. MACS2 using the scale-to-large parameter demonstrates greater robustness across varying experimental conditions, maintaining consistent peak detection across a wide range of IgG control read depths and cell input numbers (Figures 2B–2D and 3A–3C). This robustness stems from its ability to appropriately scale treatment signals to match low-background control depths, preserving signal-to-noise ratios regardless of background abundance. By contrast, MACS2 default scaling fails when IgG control reads become sparse, while SEACR exhibits an inverse performance pattern, struggling with high IgG read depths but improving under low-background conditions (Figure 3A). Based on our findings, we recommend that researchers carefully consider IgG control read depth when selecting peak-calling methods. For studies with variable IgG control read depths across conditions, MACS2 scale-to-large provides the most robust and consistent performance.

Our scCUT&Tag analysis reveals that biological duplicates represent a significant source of signal in CUT&Tag experiments, particularly for transcription factors with specific genomic localizations. The finding that biological duplicates increase with cell number and occur preferentially at high-signal regions aligns with previous observations in ATAC-seq studies.14 This suggests that some duplicate retention may be beneficial for peak detection, particularly at highly occupied sites. The differential sensitivity of MACS2 and SEACR to duplication levels provides important guidance for duplicate handling strategies. MACS2’s statistical approach for duplicate removal makes it a more robust choice for most users; however, both peak-calling approaches are affected by duplication levels, indicating that duplicate processing is a crucial aspect of CUT&Tag analysis.

Our investigation of EGS crosslinking reveals a promising approach for improving CUT&Tag performance for transcription factors. The finding that 0.2 mM EGS crosslinking increases CTCF peak detection by ∼43% while maintaining library quality represents a significant technical advancement. The improved reproducibility and enhanced detection of consensus peaks suggest that EGS crosslinking stabilizes protein-chromatin interactions without compromising pA-Tn5 accessibility. The observation that EGS crosslinking increases peak numbers without reducing library diversity indicates that the improvement reflects enhanced signal detection rather than reduced background. This is particularly important for transcription factors, where signal-to-noise ratios can be challenging. The recommendation to consider 0.2 mM EGS crosslinking for sequence-specific DNA-binding proteins provides a simple solution for improving CUT&Tag performance in this important class of targets. In the future, exploring the use of EGS in scCUT&Tag may expand the feasibility of studying transcription factors.

This comprehensive analysis of CUT&Tag optimization parameters provides essential guidance for researchers implementing this powerful technique. A CUT&Tag workflow summarizing our findings is shown in Figure 7. Our findings demonstrate that successful CUT&Tag experiments require careful consideration of multiple technical factors, including cell number, peak-calling method selection, IgG control library size, duplicate handling, and crosslinking conditions. Limitations of the study

Several limitations remain within our study. The MACS2 scale-to-large option assumes that IgG background libraries are similar to or smaller than the target libraries, so caution is required when IgG libraries are substantially larger. Peak-calling parameters (broad vs. narrow) were assigned based on ENCODE guidelines rather than optimized for our specific conditions. This study focused on analytical optimization and did not evaluate spike-in normalization, which may be important when global chromatin changes are expected. Optimization of pA-Tn5 concentrations for individual antibodies was beyond the scope of this study, and the manufacturer’s recommended dilution (1:20) was used. Although 0.2 mM EGS crosslinking improved CTCF detection, its applicability to other chromatin targets remains unclear. Finally, potential antibody lot-to-lot variation was not evaluated, though validated CUT&Tag antibodies were used to minimize variability.

Experimental model and study participant details

Cell culture

The mESC cells is a male, in-house generated, ICM-derived 129SVJ-derived mouse cell line23 that were cultured in mouse ES cell media: 80% DMEM (Corning, 10-017-CV), 15% HI FBS (Gemini, Benchmark, 100–106), 2% Penicillin-Streptomycin (Corning, 30-002-CI), 1% Nucleoside Mix, (EMD Millipore, ES-008-D), 1% L-Glutamine, (Gibco, 25030081), 1% MEM Non-Essential Amino Acids (Gibco, 11-140-050), 10−4 M 2-Mercaptoethanol (Sigma, M-6250). Rat C6 glial cells were cultured in 85% DMEM, 10% HI FBS (Gemini, Foundation, 900-108), 1% Penicillin-Streptomycin. OCI-AML3 cells were cultured in 80% MEM Alpha (Corning, 10-022-CV), 20% FBS (Gemini, Foundation, 900-108), 1% Penicillin-Streptomycin. All cells were maintained at 37°C and 5% CO2.

Method details

CUT&Tag library preparation

CUT&Tag was performed in a direct-to-PCR manner.1 Briefly, cells were washed 1x in 1mL of PBS and then resuspended in 100 μL of triton-wash-150 buffer (150mM NaCl, 20mM HEPES, 0.5mM Spermidine, 0.05% Triton X-100, & 1x Protease Inhibitor Cocktail, can be stored at 4°C for a week) per reaction. For cell number optimization experiments, 1K, 10K, 50K, or 100K mESC and rat C6 cells were used. 4 μL per reaction of Concanavalin A beads (Bangs BP531) were activated in bulk by washing 2x in cold Con-A activation buffer (20mM HEPES, 10mM KCl, 1mM CaCl2 & 1mM MnCl2, can be stored up to 6 months). For each wash, beads were gently resuspended by pipetting and placed on a magnet to aspirate clear buffer. After aspirating the second wash, beads were removed from the magnet and resuspended in 4 μL per reaction of cold Con-A activation buffer, keeping the beads on ice and never allowing them to dry. Cells in Triton-wash-150 were bound to 4 μL of beads per reaction by incubating on a rotator at room temperature for 10 min. Bead-bound cells were transferred to low-bind PCR tubes (100 μL having 10 -100K cells per reaction) and placed on a cold magnet to remove supernatant, and then 50μL of primary antibody was immediately added (1:50 dilution in 0.1% BSA + Triton-wash-150 buffer). Tubes were gently flicked to resuspend. The following primary antibodies were used: RAD21 (Genetex gtx106012), CTCF (Millipore 07729), H3K27ac (Millipore mabe647), H3K27me3 (Cell Signaling 9733), and IgG-Control (Cell Signaling 2729). Primary antibody incubation was performed overnight on a rotator at 4°C. The following day, cells were washed once on a cold magnet using Triton-wash-150, and then 50 μL of secondary antibody anti-rabbit (Antibodies Online abin101961) was added (1:100 dilution in Triton-wash-150 buffer). Tubes were removed from the magnet and gently flicked to resuspend. Samples were incubated with secondary antibody on a rotator at 4°C for one hour, after which they were washed twice in 200 μL of triton-wash-300 buffer (triton-wash-150 supplemented with NaCl to reach 300 mM), inverting tubes to resuspend with each wash. Cells were then resuspended in 25 μL pAG-Tn5 from Epicypher (151117 - 1:20 dilution in Triton-wash-300 buffer) and incubated for one hour at 4°C. After incubation, unbound pAG-Tn5 was removed, and the cells were washed three times with Wash-300 buffer. Tagmentation was initiated by resuspending cells in 50 μL cold tagmentation buffer (wash-300 supplemented with 10 mM MgCl2) and incubating at 37°C for one hour. To stop tagmentation, samples were placed on a magnet, the tagmentation buffer was removed, and the cells were washed in 100μL of room temperature 10 mM TAPS +0.2 mM EDTA. After the wash was aspirated, tagmented chromatin was then released using 5μL of 10mM TAPS +1% SDS +11 units/mL thermolabile proteinase K (NEB P8111S). The release mixture was incubated for one hour at 37°C followed by an additional hour at 55°C to inactivate the proteinase K. Following tagmented fragment release, SDS was quenched using 15 μL of 6% Triton X-100. The 20 μL of quenched sample was placed on ice, and then 25 μL of NEB Q5 High-Fidelity 2X Master Mix (NEB M0492L) and 2 μL each of 10 μM i5 and i7 primers were added. Primers were ordered from Invitrogen using sequences from Buenrostro et al.34 Library amplification was performed using the following thermocycler conditions with a heated lid: 1 cycle at 58°C for 5 min, 1 cycle at 72°C for 5 min, 1 cycle at 98°C for 5 min, 14 cycles of 98°C for 10 s and 60°C for 10 s, 1 cycle of 72°C for 1 min, hold at 8°C. Amplified libraries were purified by adding 65 μL (1.3x) of AmpureXP beads, and incubating at room temperature for 10 min, followed by two washes in 80% ethanol and elution in 25 μL of 10 mM Tris-HCl (pH 8.0). Library concentrations were determined using high-sensitivity ds1000 TapeStations on an Agilent 4150. Based on these concentrations, libraries were pooled together, and 150bp paired-end sequencing was performed on a Novaseq X to obtain ∼15 × 106 paired-end reads per sample.

Crosslinking optimization

100K OCI-AML3 cells were resuspended in 1mL of PBS, and then crosslinking was performed by adding the appropriate quantity of either 75 mM EGS in DMSO or 16% methanol-free CH2O. Crosslinking with EGS was always performed for 5 min, whereas CH2O crosslinking was only performed for two minutes (CH2O crosslinking timed to match prior CUT&Tag publications).1 All crosslinking reactions were quenched using glycine (2X the molar concentration of EGS or formaldehyde). For dual crosslinking samples, EGS was added first, and then CH2O was added after three minutes, so that glycine quenching could be performed simultaneously for both CH2O and EGS. After crosslinking, samples were split in half so that 50K cells were used for CTCF and 50K cells were used for IgG control.

scCUT&Tag library preparation

Single-cell CUT&Tag (scCUT&Tag) was performed as described by Jannsens et al., 2021.3 Briefly, 50K cells were lightly crosslinked for 3 min using 0.1% CH2O and then resuspended in triton-wash-150 buffer. Wheat germ agglutinin (WGA) beads were prepared by adding 10 μg (2 μL) of WGA (Vector Labs B-1025-5) to 5 μL of biotinylated Dynabeads (Invitrogen 11205D) and incubating at room temperature for 30 min with occasional mixing. See Fujiwara et al., 2023 for additional information about CUT&Tag bead choice.35 WGA beads were activated using 2X washes in Con-A activation buffer, after which cells were bound to 5 μL of beads. Cells were incubated with a 1:20 dilution of anti-RAD21 (Genetex gtx106012) overnight at 4°C on a rotator. The following day cells were washed 2x in triton-wash-150 and then incubated in a 1:50 dilution of secondary antibody (Antibodies Online abin101961) for one hour, again at 4°C. Following secondary incubation cells were washed twice in 200 μL of triton-wash-300 buffer and then incubated with 25 μL pAG-Tn5 from Epicypher (151117 - 1:15 dilution in triton-wash-300) for one hour at 4°C. Following three additional washes, cells were resuspended in 50 μL tagmentation buffer (wash-300 supplemented with 10 mM MgCl2) and incubated at 37°C for one hour. Following tagmentation, cells were washed 1x in triton-wash-150 supplemented with 2 mM EDTA to remove any remaining Mg2+. Tagmented cells were then resuspend in triton-wash-150 and passed through a 20 μm filter (Pluriselect NC1444161) to remove clumps. Cells were then counted 2x using a DAPI filter on a Countess 3, after which cells were placed on a magnet and resuspended in TAPS buffer (10 mM TAPS, 0.05% Triton X-100, 10 mM KCl, 1x DAPI, and 5% glycerol) at a concentration of 50 cells/μL. Cells were then dispensed onto a 350v chip using Takara’s ICELL8cx instrument. The chip was blotted, sealed with RC film, and centrifuged at 1,200g for 3 min after which nanowells were imaged to identify candidate wells with a single cell. During processing of the chip images, an unfiltered dispense of 35 nL (0.8% SDS +7.5U/mL Thermolabile Proteinase K in H2O) was performed. The chip was blotted, sealed with freezing film, and centrifuged at 2,250g for 3 min. Next, the ICELL8 chip was incubated on a thermocycler at 37°C for one hour followed by 58°C for another hour. The chip was then kept at 4°C overnight. The next morning, the chip was centrifuged at 2,250g and then a 35nL filtered dispense of 14% Triton X-100 (in H2O) was performed. The chip was again blotted and a filtered dispense for 35 nL of i5 primer was performed. This process was repeated with 35 nL of i7 primer. After this dispense, the chip was blotted, sealed with RC film and centrifuged at 2,250g for 3 min. Next, a filtered dispense for 100nL of KAPA PCR mix (2.775x High-fidelity Buffer, 0.85mM dNTPs, 0.05 U/μL KAPA polymerase) (Roche 07958838001) was performed. The chip was blotted, sealed with RC film and centrifuged at 2,250g for 3 min. PCR amplification was then performed using the following conditions: 5 min at 58°C, 10 min at 72°C, 30 s at 98°C, followed by 15 cycles of 15 s at 98°C, 10 s at 60°C, 5 s at 72°C, followed by a final extension for 1 min at 72°C after which an infinite hold was set for 8°C. The library was then collected via a Takara collection kit using centrifugation at 2,250g for 10 min. The final library was purified by two rounds of AmpureXP purification using a 1:1.3 sample-to-bead ratio. During each AmpureXP purification step, beads were washed 2x with 80% ethanol. The final library was eluted in 25μL of 10mM Tris-HCl and then quantified using TapeStation. 150bp paired-end sequencing was then performed on a Novaseq X.

Quantification and statistical analysis

Quantification and statistical analyses were performed primarily in R (4.3.1) using ggplot2 (3.5.2) and GenomicRanges (1.52.1), with read processing and peak analyses performed using Cutadapt (4.0), Bowtie2 (2.5.0), Picard (2.25.0), Samtools (1.22.1), Bedtools (2.30.0), deepTools (3.5.6), MACS2 (2.2.9.1), SEACR (1.3), and IDR (2.0.2). Results were summarized across biological replicates as mean ± standard deviation unless otherwise indicated. Grubbs’ test was used to identify outlier peak counts (p < 0.05), IDR <0.05 was used to define reproducible peaks, and linear regression was used for single-cell duplicate analyses. Detailed analysis steps are described below.

CUT&Tag data analysis for cell number optimization by different peak callers

Raw sequencing reads (FASTQ files) were trimmed using Cutadapt24 with the parameters -j 5 -m 20 -a CTGTCTCTTATACACATCT -A CTGTCTCTTATACACATCT to remove adapter sequences and short reads. For cell number optimization experiments, species-specific reference genomes were used for alignment. Specifically, mouse embryonic stem cell (mESC) CUT&Tag data were aligned to the mouse reference genome (mm10), rat C6 cell data were aligned to the rat reference genome (rn6), and OCI-AML3 cell data were aligned to the human reference genome (ENSEMBL GRCh38, release 111). Alignments were performed using Bowtie225 with the parameters --local --very-sensitive --no-mixed --no-discordant --phred33 -I 10 -X 700. Duplicate reads were removed from the resulting BAM files using Picard (java -jar $PICARD MarkDuplicates I = sample.sorted.bam O = sample.dedup.bam M = sample.dedup.metrics.txt REMOVE_DUPLICATES = true). The deduplicated BAM files were converted to CPM (counts per million)-normalized bigWig tracks using deepTools bamCoverage.28 These bigWig tracks were visualized in Integrative Genomics Viewer (IGV) and further analyzed to generate heatmaps and average profile plots using deepTools computeMatrix and plotProfile,28 respectively.

For bulk datasets, samples with fewer than 0.2 million mapped reads were excluded from downstream peak analyses to ensure data quality. Specifically, the 1K mESC H3K27me3 replicate 3, and 1K rat C6 H3K27me3 replicate 2 were removed. Peak calling was performed using four different methods: (i) MACS2 (2.2.9.1)4 (default scaling; q-value/broad cutoff 0.01), (ii) MACS2 (“scale-to-large” scaling; q-value/broad cutoff 0.00001), (iii) SEACR5 (stringent mode), and (iv) SEACR (relaxed mode). For cell number analyses, each replicate was used as the treatment sample (H3K27me3 and CTCF), while the combined IgG BAM files were generated by merging three replicates using $PICARD MergeSamFiles, were used as the control. For MACS2, the following parameters were used: --keep-dup all --nomodel --extsize 200 --shift 0 --nolambda. Based on the ENCODE guidelines, narrow peaks were called for CTCF, H3K4me3, and H3K27ac, whereas broad peaks were called for H3K27me3, H3K36me3, and H3K9me3. The effective genome size was set to ‘mm’ for the mouse and 2.6e9 for the rat. For SEACR, BAM files were first converted to reads-per-million normalized BedGraph files using bedtools genomecov.27 These BedGraph files were then used for peak calling in both stringent and relaxed modes.

To compare the number of H3K27me3, H3K27ac, H3K4me3, H3K36me3, H3K9me3, and CTCF peaks identified by MACS2 and SEACR, the number of detected peaks (Y axis, log scale) was plotted against cell input numbers (X axis) for each of the four peak-calling methods using ggplot2.32 Grubbs’ test (p < 0.05) was applied to identify replicates with significantly deviating peak counts, which were excluded from the final line plots (S1, marked with ∗).

For saturation analysis, we downsampled the three replicates of CTCF (or H3K27me3) derived from the 100K cell input of mESC, which was systematically downsampled to a series of target read counts (5,000,000–10,000) using Samtools, while the IgG BAM file (merged from three replicates) was retained at full depth. Peaks were called using MACS2 with both default (qValue 0.01) and scale-to-large normalization (qValue 0.0001), and SEACR was applied under stringent and relaxed settings. R was used for downstream analyses and data summarization.

For peak overlap analysis, peak files were imported as GRanges objects, and overlaps were calculated using GenomicRangesintersect (1.52.1) with default settings (minOverlap = 1bp).31 For each comparison, the percentage of overlapping peaks was computed. Overlap matrices were generated separately for each replicate (R1–R3) across cell numbers (100K, 50K, 10K, and 1K). Mean overlap percentages and standard deviations (mean ± SD) were calculated across replicates for each pairwise comparison. We performed the same overlap analysis across cell numbers using consensus peaks that are present in 2 out of 3 replicates of each cell number condition. Heatmaps were visualized using ggplot2, with the overlap percentage represented as a color gradient. The ggVenn package was used to make Venn diagrams showing the unique and overlapping peaks between two cell inputs.

IDR analysis

Peak reproducibility was assessed using IDR (Irreproducible Discovery Rate) analysis on H3K27me3 and CTCF peaks generated from three replicates. As we had more than two replicates, we used the individual merged BAM files for H3K27me3 and CTCF generated from three replicates of each cell number using mESC and Rat C6 cells, and randomly split them into two pseudoreplicates. Peaks were called independently using MACS2 (“scale-to-large”) and SEACR (stringent) using these two pseudoreplicate files. IDR v2.0.2 (https://github.com/nboley/idr) was applied with an IDR threshold of 0.05, ranking MACS2 peaks by pvalue and SEACR peaks by signal value. SEACR BED files were converted to narrowPeak format for IDR analysis. Reproducible peaks (black dots in the scatterplot, IDR <0.05) and not reproducible peaks (red dots in the scatterplot) were visualized in scatterplots comparing log10 peak scores between pseudoreplicates.

Data analysis for downsampling of IgG reads

To evaluate the effect of control library depth on CTCF peak detection by different peak calling methods, three biological replicates of CTCF (derived from 100K cell input) CUT&Tag (M100K_CTCF_R1–R3) were analyzed against a combined IgG control from three biological replicates (M100K_IgG) for mESC. The IgG BAM file was systematically downsampled to a series of target read counts (5,000,000–10,000) using Samtools, while the CTCF BAM files were retained at full depth. Peaks were called using MACS2 with both default (qValue 0.01) and scale-to-large (qValue 0.00001) normalization, and SEACR was applied under stringent and relaxed settings. R was used for downstream analyses and data summarization.

To quantify the Fraction of Reads in Peaks (FRiP) score at each replicate and downsampling level, the total number of mapped reads was determined using Samtools.26 Reads overlapping MACS2 (or SEACR) peaks were quantified using Bedtools intersect.27 FRiP scores were calculated as the ratio of reads in peaks to total reads. Summary statistics, including mean and standard deviation of FRiP scores across replicates, were generated in R.29

Data analysis for biological duplication and EGS crosslinking

For biological duplication analyses and EGS crosslinking, peak calling was performed using individual treatment samples and individual IgG files from the same replicate. MACS2 narrowPeak calling was applied for CTCF analysis, while broadPeak calling was used for H3K27me3. For MACS2 “scale-to-large” a stringent q-value cutoff of 1e−5, was used. Peak counts were calculated for each condition and consensus peaks (for bulk RAD21 and CTCF) were defined as those identified in 2/4 replicates. For comprehensive visualization, alignment files from all replicates were merged. EGS files were normalized by CPM to generate representative bigWig files. In the case of biological duplicates, read counts were not normalized in order to preserve y axis scaling. IGV tracks were generated using these combined bigWig files. All scripts used for analysis are available on GitHub (see code availability section).

Literature review of CUT&Tag peak calling

Publications using CUT&Tag were identified on 10/30/2025 using Python and PubMed’s API tool. Because many papers use both CUT&Tag and ChIP-seq, data retrieved from PubMed and analyzed by Python was manually verified to ensure that the peak caller identified was used for CUT&Tag as opposed to ChIP-seq. The script used to perform the PubMed API search is available here: https://github.com/josiahmurra/pubmed_cuttag_scraper.

CUT&Tag analysis for external dataset

H3K27me3 CUT&Tag datasets from the K562 cell line were downloaded from GEO accession GSE158327 (“lab samples”), with the corresponding IgG control from GSM3680227. Reads were aligned to the human reference genome (ENSEMBL GRCh38, release 111) using the Bowtie2 parameters described above. We applied the same preprocessing pipeline used in our study, including duplicate removal, and used the resulting deduplicated BAM files for peak calling with four different algorithms. For MACS2 (default and “scale-to-large” modes), peaks were called using a broad cutoff of 0.01.
