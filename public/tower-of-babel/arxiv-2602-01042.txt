Abstract
Given an n n -bit Boolean function with a complexity measure (such as block sensitivity, query complexity, etc.) M ⁡ ( f ) = k M(f)=k , the hardness condensation question asks whether f f can be restricted to O ⁡ ( k ) O(k) variables such that the complexity measure is Ω ⁡ ( k ) \Omega(k) ? In this work, we study the condensability of block sensitivity, certificate complexity, AND (and OR) query complexity and Fourier sparsity. We show that block sensitivity does not condense under restrictions, unlike sensitivity: there exists a Boolean function f f with query complexity k k such that any restriction of f f to O ⁡ ( k ) O(k) variables has block sensitivity O ⁡ ( k 2 3 ) O(k^{\frac{2}{3}}) . This answers an open question in [ 3 ] in the negative. The same function yields an analogous incondensable result for certificate complexity. We further show that 𝖠𝖭𝖣 \mathsf{AND} (and 𝖮𝖱 \mathsf{OR} ) decision trees are also incondensable. In contrast, we prove that Fourier sparsity admits a weak form of condensation.

Introduction

Hardness condensation is a powerful lower-bound technique in Boolean function complexity theory that allows us to reduce the size of a problem while preserving its essential complexity characteristics. In the context of Boolean functions, hardness condensation refers to the process of identifying smaller subfunctions that retain the complexity properties of the original function. Conceptually, it seeks to determine whether the computational hardness is “concentrated” in specific parts of the input domain.

In this section, we will define various complexity measures of Boolean functions that we will be working with. Along with the definitions, we will also discuss some basic properties and known results about these measures that will be useful in the later sections.

Any Boolean function

Discussion and Conclusion

In this work, we have explored the condensability and incondensability properties of several Boolean function complexity measures. We establish the incondensability of the block sensitivity (and certificate complexity), thus resolving an open question posed in

The connections between condensability and the separations between various Boolean function complexity measures is worth noting.
