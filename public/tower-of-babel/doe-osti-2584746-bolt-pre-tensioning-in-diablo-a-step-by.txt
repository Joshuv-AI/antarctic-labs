General solver methodology
 Element set with two bolts

 1. Apply pre-strain in an element set [or all/various element sets]
 2. Determine single way to measure the load/stress in one element set
 • If more than one bolt in element set, use one bolt or average of all
 3. Solve for an approximate initial state (bolt interaction) - Two options:
 1) Bisection (simplest, probably fastest)
 a) Solution for first element set (e.g. four system iterations)
 b) …
 c) Solution for last element set
 2) Or solve/tighten all element sets at once (Nonlinear Optimization)
 4. Continue to a second step after bolt pre-tensioning stage

 9

Apply strain: Other input parameters to element sets

1. #pre_stress_max_optimization_iterations (10) is the maximum number of iterations per element set (i.e.
 step solutions)
2. #pre_stress_max_abs_prestress_error (1.0D0) absolute error tolerance in the pre-stress
3. #pre_stress_min_prestrain_multiplier (1.0D-7) Minimum multiplier on #pre_strain_scalar for the solution
4. #pre_stress_max_prestrain_multiplier (1.0D0) Maximum multiplier on #pre_strain_scalar for the solution
5. #pre_strain_scalar (0.0D0) Reference, initial applied pre-strain

Recommendations
 • The default for total number of iterations per element set is 10; typically, 4-5 iterations may suffice
 • The default absolute tolerance in the pre-stress is 1.0D0 (user should overwrite)
 • Make this tolerance looser than those of your system solves
 • #pre_stress_min_prestrain_multiplier and #pre_stress_max_prestrain_multiplier can be overwritten; do not
 use a large #pre_strain_scalar (>40%)
 • Lower bound for pre-strain: #pre_strain_scalar * #pre_stress_min_prestrain_multiplier
 • Upper bound for pre-strain: #pre_strain_scalar * #pre_stress_max_prestrain_multiplier

 1. One element set for all shanks within each port**
 2. We’ll be targeting average target pre-stress
 3. Three element print blocks (cutting plane)
 1. Location, direction, and radius for each element
 print block computed manually
 4. Sequential bisection and global optimization are used

 ** In this case, bolt heads are included in pre-strain element set (maybe not recommended in general)

 20

Summary
• Various ways to define target metric in the bolt
• Pre-stress happens in the first time step:
 • If the step is cut, targe value is scaled and an intermediate pre-stress root finding
 process takes place
 • Only the pre-stress state at the end of the first time step is carried over to the next
 time step (i.e. it’s the one that matters)
• Use stresslink to reduce nonlinearities while bolt tightening (Or use final pre-strain)
• The iteration process (per element set)
 • If we know roughly the same pre-strain will apply to a set of bolts, use one element set
 • Each element set must have the same direction
 • If multiple bolts, target in one bolt only or average of all (sideset-driven)
• When sequential tightening may significantly affect other bolt states, use #global_prestress
 • Global (or all-at-once) process may take more iterations comparatively
