 Executive Summary of CRADA Work:

 Through the ARIES platform, this proposed project aims to bridge a gap and utilize the power
 hardware-in-the-loop (PHIL) and controller hardware-in-the-loop (CHIL) experiments and create
 open-source interconnection and interoperability information that can aid in faster and cheaper
 installation and operation of grid forming fuel cell inverters.

 CRADA benefit to DOE, Participant, and US Taxpayer:

 • Assists laboratory in achieving programmatic scope
 • Uses the laboratory’s core competencies

 Task 2: Digital real-time simulation modeling of microgrid system with distributed assets
 for Fuel cell inverter experiments.

 In this task, NLR will take the necessary steps to create a stable digital real-time simulation
 model in Electromagnetic transient domain. The model will be built using ARIES platform’s
 Novacor asset. The microgrid model will contain distributed assets like capacitor banks, load
 tap-changer, voltage regulators, PV, and BESS which can impact the modes of operation of fuel
 cell inverters during transitions. An existing dynamic model for a fuel cell system will be
 adapted to evaluate the ability to provide power to a grid-forming inverter while maintaining
 high performance (efficiency), managing flow and thermal dynamics, and maintaining safe
 operating conditions.

 Task 2 Results:

 A stable, digital real-time simulation model was successfully developed in the electromagnetic
 transient domain (EMT) using the Novacor asset. The comprehensive microgrid model
 incorporated key distributed assets. The primary outcome is a high-fidelity simulation platform
 capable of analyzing the complex interactions within the microgrid. This model enables detailed
 evaluation of the grid-forming fuel cell inverters’ ability to interact with various power system
 assets.

 Task 3: Power hardware-in-the-loop setup development.

 In this task NLR will identify the necessary power hardware equipment, reserve the power
 devices, and integrate the devices with the DRTS model built under task 1. In addition, NLR will
 develop the necessary PHIL interface for the fuel cell inverter to be interfaced with the DRTS
 model.

 Task 3 Results:

 The necessary power hardware equipment was identified, reserved, and successfully integrated
 with the digital real-time simulation (DRTS) model developed in Task 1. A custom power-
 hardware-in-the-loop (PHIL) interface was developed for the fuel cell inverter. This interface
 was used to successfully connect the physical fuel cell inverter with the DRTS model,
 establishing a complete and functional hardware-in-the-loop (HIL) simulation environment.

 The preliminary work performed under this task was published in the following presentation:
 https://www.nlr.gov/docs/fy24osti/89141.pdf

 Task 4: Controller hardware-in-the-loop and algorithm development.

 In this task NLR will identify the necessary controller equipment, reserve the controller devices,
 and integrate the devices with the DRTS model built under Task 1. Formal optimization
 techniques will be used to dynamically dispatch controllable resources to develop control and
 dispatch algorithms for complementary use of hydrogen fuel cell grid-forming inverters in a
 100% renewable microgrid.

 Task 4 Results:

 The necessary controller equipment was identified, reserved, and successfully integrated with the
 DRTS model developed under Task 1, creating a full controller-hardware-in-the-loop (CHIL)
 system. This task produced a control board with advanced exchange capabilities, enabling and
 validating hierarchical control through simple and inexpensive boards. The system is now
 capable of being reproduced continuously in a highly realistic virtual environment. Figure 4
 shows the target interoperability approaches used in this work.

 Figure 4. Different interoperability approaches considered for the board development

 Task 5: Interconnection and interoperability requirements advancements.

 In this task NLR will focus on the improvements to DER interconnection and interoperability
 requirements for fuel cell inverter integration into the grid with grid following and grid forming
 modes of operation.

 Task 5 Results:

 A comprehensive review and analysis of existing distributed energy resource (DER)
 interconnection and interoperability standards was completed. This analysis specifically focused
 on identifying gaps and areas for improvement related to the integration of fuel cell inverters.

 The preliminary work was presented in the following poster:
 https://www.nlr.gov/docs/fy23osti/85146.pdf

 Task 6: Complete a report documenting scenarios:

 NLR should complete the detailed documentation of the HIL setup, interface development,
 interconnection, and interoperability requirements. NLR should present the outcome to at least
 one interconnection standard meeting, and one interoperability standards meeting. NLR should
 complete all the necessary NLR internal reviews to make the documentation public through
 OSTI.gov.

 Task 6 Results:

 A comprehensive set of documentation was authored and finalized, detailing the project's HIL
 setup, the developed interfaces, and the proposed interconnection and interoperability
 requirements.

 The key findings and recommendations from this work were presented to stakeholders at
 standards meetings. Following these dissemination activities, the documentation successfully
 passed all internal reviews and was submitted for public release. This task transitioned the
 project's technical learnings into accessible and impactful resources for the broader energy
 community, ensuring the knowledge generated is shared widely.

 The results of Task 6 are available in the following report: https://dx.doi.org/10.17023/6vq1-bf15
