Enforcing Mixed State-Input Constraints with Multiple Backup Control Barrier Functions: A Projection-based Approach
Laszlo Gacsi, Adam K. Kiss, Ersin Daş, Tamas G. Molnar

Abstract
Ensuring the safety of control systems often requires the satisfaction of constraints on states (such as position or velocity), control inputs (such as force), and a mixture of states and inputs (such as power that depends on both velocity and force). This paper presents a safety-critical control framework for enforcing mixed state-input constraints through a generalization of backup control barrier functions (backup CBFs). First, we extend the backup CBF approach to maintain multiple decoupled state and input constraints using a single backup set–backup controller pair. Second, we address mixed state-input constraints by converting them into state constraints using a projection from the state-input space to the state space along the backup controller. In the special case of decoupled state and input constraints, the proposed method simplifies the synthesis of backup CBFs by eliminating the need for saturating backup control laws. Finally, we demonstrate the efficacy of the proposed method on an inverted pendulum example, where constraints on the angle (state), torque (input), and power (mixture of state and input) are satisfied simultaneously.



I
Introduction

Safe behavior is an essential requirement for controlling modern autonomous systems.
Formally, safety is often defined as a state constraint–keeping the system’s state within a safe set in the state space–which can be enforced, for example, using
control barrier functions
(CBFs)
[
2
]
.
Yet, this formulation often does not take into account the
limitations of control inputs explicitly.
Synthesizing safe controllers for dynamical systems subject to both state and input constraints is a common challenge in real-world control problems.

In many applications, such as robotic systems and vehicles, state and input constraints are coupled.
For example, acceleration-based safety constraints for rigid-body robotic systems are both state and input-dependent
[
5
]
.
For autonomous ground vehicles, the admissible stability region can vary with steering angle and braking force, making the corresponding safety constraint depend on both state and input
[
10
]
. Similarly, tipover avoidance constraints for legged and wheeled robots explicitly depend not only on states but also on inputs
[
5
,
16
]
. Input-dependent constraints also arise in passivity-based teleoperation of multi-robot systems
[
14
]
, and the trajectory space forward invariance problem
[
17
]
.

To address
decoupled
state and input limits within the CBF framework, integral CBF methods
[
1
,
4
]
augment the system dynamics by treating the inputs as new states.
Recently, in
[
16
]
, the notion of zero-order CBFs was introduced to enforce input-dependent safety via a one-step sampled-data condition; however, the resulting constraint is generally nonconvex.
An alternative approach is the

backup CBF method

[
8
,
3
]
which offers both formal safety guarantees and feasibility under input constraints.
Backup CBFs have been applied to mobile robots
[
11
]
, spacecraft
[
18
]
,
manipulators
[
12
]
, with other works exploring
non-smooth constraints
[
9
]
, timed reach-avoid specifications
[
20
]
, and dynamic safety margin
[
6
]
.
Yet, backup CBFs have not been established for
mixed
(coupled) state-input constraints.

Fig. 1:
Overview of the proposed projection-based backup CBF approach.

In this paper, we develop a safe control approach to enforce mixed state-input constraints using backup CBFs.
First, we extend the backup CBF method to handle
multiple decoupled
state and input constraints using a single backup set–backup controller pair.
Then, we address
mixed
constraints.
The key idea of our approach, shown in Fig.
1
, is a projection
from the state-input space to the state space, to transform mixed constraints into pure state constraints.
If the mixed constraints are affine in the input, the proposed backup CBF-based controller synthesis problem becomes an easy-to-solve quadratic program.
Moreover, for decoupled state and input constraints, our approach also helps to simplify the design of backup controllers and the calculation of backup CBFs by obviating the need for saturating backup controllers.
We showcase our approach on an inverted pendulum subject to angle (state), torque (input), and power (mixed) constraints.

II-B

Backup Control Barrier Functions

The foundation of the backup CBF method

3
]

The backup set is a subset of the constraint set, defined as:

\mathcal{S}_{\mathrm{b}}=\{\mathbf{x}\in\mathbb{R}^{n}:h_{\mathrm{b}}(\mathbf{x})\geq 0\}\,,

(7)

{\mathcal{S}_{\mathrm{b}}\subseteq\mathcal{C}}

The backup controller is a smooth controller
{\mathbf{k}_{\mathrm{b}}:\mathbb{R}^{n}\to\mathcal{U}}

A procedure for constructing backup set–backup controller pairs is elaborated on in
[
7
]

Typically, the backup set is a small subset of the constraint set, representing safe but (very) conservative behavior.
Therefore, the backup controller

\mathcal{S}_{\mathrm{b}}

Multiple Backup CBFs

IV
Mixed State-Input Constraints

In this section, we establish our main result: a projection-based framework to handle mixed state-input constraints. We first introduce this concept for a single constraint and then extend it to the multi-constraint case.

IV-A

Projection with Single Constraint

We define the mixed state-input constraint set
\mathcal{D}
via the smooth function
H:\mathbb{R}^{n}\times\mathbb{R}^{m}\to\mathbb{R}
:

\mathcal{D}=\big\{(\mathbf{x},\mathbf{u})\in\mathbb{R}^{n}\times\mathbb{R}^{m}:H(\mathbf{x},\mathbf{u})\geq 0\big\}.

(16)

Our objective is to find a locally Lipschitz controller
\mathbf{k}
such that the closed-loop system (
2
) satisfies

{\big(\mathbf{x}(t),\mathbf{k}(\mathbf{x}(t))\big)\in\mathcal{D}}
,
or equivalently

{H\big(\mathbf{x}(t),\mathbf{k}(\mathbf{x}(t))\big)\geq 0}
,
for all
{t\geq 0}

(at least for a certain set of initial conditions to be discussed later).
For now, we focus on a single mixed constraint and omit other state, input, or mixed constraints—these will be addressed in the next subsection.
Unlike pure state constraints,
H(\mathbf{x},\mathbf{u})
has
relative degree zero
because the input
\mathbf{u}
appears explicitly. While one could be tempted to directly enforce the constraint
{H(\mathbf{x},\mathbf{u})\geq 0}
in the optimization, this may not be recursively feasible. To ensure recursive feasibility for mixed state-input constraints, we extend the backup CBF method.

Our key idea is to project the constraint from the state-input space
{\mathbb{R}^{n}\times\mathbb{R}^{m}}
to the state space
\mathbb{R}^{n}
along the backup controller
{\mathbf{u}=\mathbf{k}_{\mathrm{b}}(\mathbf{x})}
.
We define the
projected constraint set
:

\mathcal{C}_{\mathrm{p}}=\big\{\mathbf{x}\in\mathbb{R}^{n}:(\mathbf{x},\mathbf{k}_{\mathrm{b}}(\mathbf{x}))\in\mathcal{D}\big\}=\{\mathbf{x}\in\mathbb{R}^{n}:h(\mathbf{x})\geq 0\},

(17)

with the
projected constraint function

{h:\mathbb{R}^{n}\to\mathbb{R}}
:

h(\mathbf{x})\triangleq H\big(\mathbf{x},\mathbf{k}_{\mathrm{b}}(\mathbf{x})\big)\,,

(18)

which is smooth because both
H
and
\mathbf{k}_{\mathrm{b}}
are smooth.

We require the following properties for the backup set–backup controller pair.

Assumption 1
.

The backup set satisfies
{\mathcal{S}_{\mathrm{b}}\subseteq\mathcal{C}_{\mathrm{p}}}
, while the backup controller
{\mathbf{k}_{\mathrm{b}}:\mathbb{R}^{n}\to\mathbb{R}^{m}}
renders the backup set
\mathcal{S}_{\mathrm{b}}
forward invariant along (
8
).

Then, using the backup flow
\boldsymbol{\varphi}_{\mathrm{b}}
corresponding to (
8
), we define the invariant set:

\mathcal{S}_{\mathrm{I}}^{\mathrm{p}}=\left\{\mathbf{x}\in\mathbb{R}^{n}:\begin{array}[]{l}h\big(\boldsymbol{\varphi}_{\mathrm{b}}(\theta,\mathbf{x})\big)\geq 0,\ \forall\theta\in[0,T],\\
h_{\rm b}\big(\boldsymbol{\varphi}_{\mathrm{b}}(T,\mathbf{x})\big)\geq 0\end{array}\right\}.

(19)

We establish that the mixed state-input constraint is satisfied when using the backup controller inside this set.

Lemma 1
.

If
\mathbf{x}\in\mathcal{S}_{\mathrm{I}}^{\rm p}
, then
\big(\mathbf{x},\mathbf{k}_{\mathrm{b}}(\mathbf{x})\big)\in\mathcal{D}

Proof.

By the definition of

in (

implies
{h\big(\boldsymbol{\varphi}_{\mathrm{b}}(0,\mathbf{x})\big)\geq 0}

{\boldsymbol{\varphi}_{\mathrm{b}}(0,\mathbf{x})=\mathbf{x}}

Projection with Multiple Constraints

By combining the ideas from Section
III
and Section
IV-A
, we extend the projection method to multiple constraints:

\mathcal{D}=\big\{(\mathbf{x},\mathbf{u})\in\mathbb{R}^{n}\times\mathbb{R}^{m}:H_{j}(\mathbf{x},\mathbf{u})\geq 0,\ \forall j\in\mathcal{J}\big\}\,,

(22)

with smooth constraint functions
{H_{j}:\mathbb{R}^{n}\times\mathbb{R}^{m}\to\mathbb{R}}
.
Note that this involves state constraint (
{\mathcal{D}=\mathcal{C}\times\mathbb{R}^{m}}
), input constraint (
{\mathcal{D}=\mathbb{R}^{n}\times\mathcal{U}}
), and the combination of decoupled state and input constraints (
{\mathcal{D}=\mathcal{C}\times\mathcal{U}}
) as special cases, while also capturing general mixed constraints in the state-input space.

We propose to use the projected constraint set:

\displaystyle\mathcal{C}_{\mathrm{p}}

\displaystyle=\big\{\mathbf{x}\in\mathbb{R}^{n}:\big(\mathbf{x},\mathbf{k}_{\mathrm{b}}(\mathbf{x})\big)\in\mathcal{D}\big\}

(23)

\displaystyle=\{\mathbf{x}\in\mathbb{R}^{n}:h_{j}(\mathbf{x})\geq 0,\ \forall j\in\mathcal{J}\},

with the projected constraint functions
{h_{j}:\mathbb{R}^{n}\to\mathbb{R}}
:

h_{j}(\mathbf{x})\triangleq H_{j}\big(\mathbf{x},\mathbf{k}_{\mathrm{b}}(\mathbf{x})\big).

(24)

Then, with a backup set
\mathcal{S}_{\mathrm{b}}
and a backup controller
\mathbf{k}_{\mathrm{b}}
satisfying Assumption
1
, we construct the invariant set:

\mathcal{S}_{\mathrm{I}}^{\mathrm{p}}=\left\{\mathbf{x}\in\mathbb{R}^{n}:\begin{array}[]{l}h_{j}\big(\boldsymbol{\varphi}_{\mathrm{b}}(\theta,\mathbf{x})\big)\geq 0,\forall\theta\!\in\![0,T],\!\forall j\!\in\!\mathcal{J},\\
h_{\rm b}\big(\boldsymbol{\varphi}_{\mathrm{b}}(T,\mathbf{x})\big)\geq 0\end{array}\!\!\right\}\!,

(25)

see Fig.
1
(where
{h_{j}\big(\boldsymbol{\varphi}_{\mathrm{b}}(\theta,\mathbf{x})\big)\!=\!0}
is plotted for various
\theta
).

Based on the results of the previous sections, we enforce the invariance of this set and the satisfaction of the mixed constraints using (
21a
) for each
h_{j}
, (
21b
), and (
21c
) for each
H_{j}
.
Thus, we propose the optimization problem (OP):

\displaystyle\mathbf{k}(\mathbf{x})=\underset{\mathbf{u}\in\mathbb{R}^{m}}{\operatorname{argmin}}\quad\|\mathbf{u}-\mathbf{k}_{\mathrm{d}}

\displaystyle(\mathbf{x})\|^{2}

(26)

\displaystyle\textrm{s.t.}\quad\dot{h}_{j}\big(\boldsymbol{\varphi}_{\mathrm{b}}(\theta,\mathbf{x}),\mathbf{u}\big)

\displaystyle\geq-\alpha_{j}\big(h_{j}(\boldsymbol{\varphi}_{\mathrm{b}}(\theta,\mathbf{x}))\big),

\displaystyle\forall\theta\!\in\![0,T]\,,\forall j\in\mathcal{J}\,,

\displaystyle\dot{h}_{\mathrm{b}}\big(\boldsymbol{\varphi}_{\mathrm{b}}(T,\mathbf{x}),\mathbf{u}\big)

\displaystyle\geq-\alpha_{\mathrm{b}}\big(h_{\mathrm{b}}(\boldsymbol{\varphi}_{\mathrm{b}}(T,\mathbf{x}))\big)\,,

\displaystyle H_{j}(\mathbf{x},\mathbf{u})

\displaystyle\geq 0\,,\quad\forall j\in\mathcal{J}\,.

By construction, this OP is recursively feasible because
{\mathbf{k}(\mathbf{x})=\mathbf{k}_{\mathrm{b}}(\mathbf{x})}
is a feasible solution.

Corollary 2
.

There exist
{\alpha_{j},\alpha_{\rm b}\in\mathcal{K}^{\rm e}}
such that the backup CBF-OP (

) is feasible for all
{\mathbf{x}\in\mathcal{S}_{\mathrm{I}}^{\mathrm{p}}}
.
Furthermore, the controller (

) ensures for all
{\mathbf{x}_{0}\in\mathcal{S}_{\mathrm{I}}^{\mathrm{p}}}
that
{\mathbf{x}(t)\in\mathcal{S}_{\mathrm{I}}^{\mathrm{p}}}

Remark 3
.

The backup CBF-OP (
26
) is a quadratic program if and only if

are affine in
\mathbf{u}
:

H_{j}(\mathbf{x},\mathbf{u})=b_{j}(\mathbf{x})-\mathbf{a}_{j}(\mathbf{x})\mathbf{u}\,,\quad\forall j\in\mathcal{J}\,,

(27)

where
{\mathbf{a}_{j}:\mathbb{R}^{n}\to\mathbb{R}^{1\times m}}
,
{b_{j}:\mathbb{R}^{n}\to\mathbb{R}}
are smooth functions.

Remark 4
.

For state constraints (
{\mathbf{a}_{j}(\mathbf{x})=\mathbf{0}}
), the last constraint with
H_{j}
in (
26
) is inactive and can be omitted.
For input constraints (
\mathbf{a}_{j}
and
b_{j}
are constants),

encodes the input constraint and the optimization is done over
{\mathbf{u}\in\mathbb{R}^{m}}
, rather than
{\mathbf{u}\in\mathcal{U}}
as in (

is also added.
Hence, for the special case of decoupled state and input constraints (discussed in Section

\displaystyle\mathbf{k}(\mathbf{x})=\underset{\mathbf{u}\in\mathbb{R}^{m}}{\operatorname{argmin}}

\displaystyle\|\mathbf{u}-\mathbf{k}_{\mathrm{d}}(\mathbf{x})\|^{2}

(28)

\displaystyle\textrm{s.t.}\quad\dot{\psi}\big(\boldsymbol{\varphi}_{\mathrm{b}}(\theta,\mathbf{x}),\mathbf{u}\big)

\displaystyle\geq-\alpha\big(\psi(\boldsymbol{\varphi}_{\mathrm{b}}(\theta,\mathbf{x}))\big)\,,\ \forall\theta\in[0,T]\,,

\displaystyle-\mathbf{a}_{j}\dot{\mathbf{k}}_{\rm b}(\mathbf{x},\mathbf{u})

\displaystyle\geq-\alpha_{j}\big(b_{j}-\mathbf{a}_{j}\mathbf{k}_{\mathrm{b}}(\mathbf{x})\big)\,,\ \forall j\in\mathcal{J}\,,

\displaystyle\dot{h}_{\mathrm{b}}\big(\boldsymbol{\varphi}_{\mathrm{b}}(T,\mathbf{x}),\mathbf{u}\big)

\displaystyle\geq 0\,,\quad\forall j\in\mathcal{J}\,.

Compared to the standard backup CBF-QP (
11
), this includes the additional second constraint with the derivative of
\mathbf{k}_{\mathrm{b}}
.

Remark 5
.

The projection may help to simplify the backup controller design.
For decoupled state and input constraints (
{\mathcal{D}=\mathcal{C}\times\mathcal{U}}
), the standard backup CBF method requires

{\mathcal{S}_{\mathrm{b}}\subseteq\mathcal{C}}
and
{\mathbf{k}_{\mathrm{b}}(\mathbf{x})\in\mathcal{U}}
for all
{\mathbf{x}\in\mathbb{R}^{n}}
.
This often means that the backup controller needs to be saturated to enforce input constraints over the entire state space.
As opposed, the projection-based method requires
{\mathcal{S}_{\mathrm{b}}\subseteq\mathcal{C}_{\mathrm{p}}}
, meaning
{\mathcal{S}_{\mathrm{b}}\subseteq\mathcal{C}}
and
{\mathbf{k}_{\mathrm{b}}(\mathbf{x})\in\mathcal{U}}
for all
{\mathbf{x}\in\mathcal{S}_{\mathrm{b}}}
.
So input constraints only need to hold inside the (small) backup set
\mathcal{S}_{\mathrm{b}}
, eliminating the need for saturation.
This can also simplify the computation of the backup flow.
For example, if (
1
) is feedback linearizable, the backup controller can be constructed so that the backup system (
8
) is linear,
{\dot{\mathbf{x}}=\mathbf{A}\mathbf{x}}
.
Then, the backup flow:

\boldsymbol{\varphi}_{\mathrm{b}}(\theta,\mathbf{x})=e^{\mathbf{A}\theta}\mathbf{x}

(29)

can be calculated analytically.
This eliminates the need for forward integration at each time step, significantly reducing the computational cost of the backup CBF method.
The price of these benefits is that the projection reduces the size of the set where the system operates (i.e.,
{\mathcal{C}_{\mathrm{p}}\subseteq\mathcal{C}}
).

VI
Conclusion

In this paper, we proposed a systematic control approach to enforcing mixed state-input constraints.
We introduced a projection to convert input constraints and more complex, mixed (e.g., power) constraints to state constraints, and enforce them using backup CBFs in a recursively feasible manner.
Our approach also enhances the classical backup CBF framework by eliminating the need for saturated backup controllers and potentially enabling analytical backup flow calculation.
We demonstrated our theoretical results on an inverted pendulum with state, input, and power constraints.
