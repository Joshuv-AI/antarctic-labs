 Abstract
 High-fidelity hydrodynamic simulations require conformal quadrilateral-mesh refinement
 to maintain numerical stability and accuracy. However, the existing refinement algorithm in
 LANL Meshing Code is constrained by an equality requirement on two opposite sides, which
 restricts its utility for complex geometries. This work presents two generalized refinement
 algorithms that extend the input space by removing this constraint. Comparative analysis
 against established literature demonstrates that our approaches improve overall element quality.
 These generalizations enhance the flexibility of Crosslink, enabling more robust and versatile
 hydrodynamic simulations.

 A mesh approximates geometry with a collection of simpler shapes (triangles, quadrilaterals,
etc.). Meshes are typically used for computer graphics and numerical methods. We are interested
in quadrilateral mesh refinement algorithms that are useful for hydrodynamics simulations.

1 Introduction
A mesh is a combination of topological information (connectivity) and geometric information. In
general, a mesh is a collection of points in Rn along with edges, unordered pairs of said points.
For a quadrilateral mesh in R2 , typically edge information is not stored explicitly unless needed.
Instead, connectivity is stored by making 4-tuples of points that represent a quad. In particular, a
quad is represented by a counter-clockwise listing of its nodes.
 LANL meshing tools use a block topology by which a geometry is broken up into patches (blocks),
each patch is then individually meshed using quads and stitched together. Block structured meshing
is useful for numerical methods as it allows for the generation of quads of arbitrary size. Making
the size of the quads smaller typically improves the accuracy of the numerical method for the given
simulation. Meshing a single block using only quadrilaterals is called quadrangulation. To refine a
given block, we need to know how many subdivisions along each edge. In Figure 2, the input to
the refinement algorithm would be (4, 4, 4, 4) [order: bottom, right, top, left] as we desire a refined
quad that has 4 nodes on each side. When each side has an equal number of refinement nodes the
problem of refining the quad is simple and we take a 4x4 grid in the unit square (called uv-space)
and map that to the arbitrary quad in xy-space. The requirement of having all refinement nodes

 Before continuing to generalize the input space of the side dimensions for a quadrangulation
algorithm, we should investigate when a quadrangulation exists in the first place. To this end
notice that every quad in a quad mesh has 4 sides. An edge is either on the interior or boundary
of the mesh. If the edge is on the boundary of a mesh, it is only associated with 1 quad. Whereas
if the edge is on the interior of a mesh, it is associated with 2 quads. This yields the following

                                           4F = Eb + 2Ei                                           (1)

where F is the number of quads in the mesh, Eb is the number of boundary edges, and Ei is the
number of interior edges. Notice that

                                          Eb = 2(2F − Ei ).

Thus, Eb must be even. This puts a constraint on the possible inputs for dimensions. Since we have
taken the input dimensions (d0 , d1 , d2 , d3 ) to be the number of nodes on each boundary, the number
of edges on each boundary is (d0 − 1, d1 − 1, d2 − 1, d3 − 1). Then, the total number of boundary
edges is Eb = d0 + d1 + d2 + d3 − 4. The requirement is that Eb be even. So, d0 + d1 + d2 + d3
must be even. Another way to view this criterion is that the number of odd input dimensions must
be even. A rigourous proof of Equation 1 can be done by induction on the number of quads in
the mesh as shown in [2]. With this fundamental restriction in mind, we introduce the algorithms
compared in this study.

2 Single Directional Refinement with Diamonds
The first generalized refinement algorithm presented here generalizes the input space to allow only
two opposite sides to be differ by an even number (e.g. (3, 5, 3, 9) or (4, 6, 10, 6)). The idea of the
procedure is to start with the larger of the differing refinement nodes and insert diamonds. As
pictured in Figure 4, each diamond has 3 incoming nodes that connect to 3 of the larger of the
differing refinement nodes and 1 outgoing node that connects to 1 of the smaller of the differing
refinement nodes. So each diamond removes 2 refinement nodes (hence the requirement of differing
by an even number). But, the diamond requires two nodes of support from the equal sides. To
allow for refinement inputs with larger difference in differing refinement nodes with less nodes on
the equal sides we can add multiple diamonds per row. An example of 2 diamonds in one row is
shown in Figure 5.
 Figures 4 and 5 demonstrate the general principle of adding diamonds to start at the larger edge
and add diamonds to reduce to the smaller edge. In practice, we have multiple patterns that can
be inserted depending on the number of edges left to reduce to the smaller edge. Many patterns
can be made that vary the number of diamonds and the location of diamonds inserted. Table 1
contains the 4 patterns used in the example program. Notice there are two different two diamond
patterns. These are alternated in the code if pattern 2A was just inserted and enough space is left
for two diamonds, then pattern 2B is inserted.
 We have described a method for quadrangulating a quad that loosens the requirement on edge
lengths to two opposite sides must be the same and the non-equal sides differ by even numbers.
As seen near the end of the description of the method, many different variations of this general

3 Pattern Based Refinement
Takayama et. al [3] presents an algorithm for quadrangulation of any input dimensions that meet
the base requirements for existence of a quadrangulation. The algorithm attempts to minimize the
number of singularities. Informally, a singularity is a vertex that would not occur in a regular grid
in terms of the number of incoming edges to that vertex (degree of the vertex).

 Vertex Type Typical Degree
 Interior 4
 Boundary 3
 Corner 2

 To the end of minimizing singularities in the algorithm Takayama et. al uses a Trimming →
Pattern → Padding structure. The Trimming procedure first ”maximally reduces input.” The
idea is that if regular grids can be stitched together, then the singularities can only occur in the
subproblem. After no more regular grids can be stitched, a topology with a minimum number of
singularities is selected based on the form of the reduced subproblem.

4 Alternating Diamond Refinement
The original single directional refinement with diamonds makes the assumption that two opposite
dims are equal. But, we desire an algorithm that can be used for a wider class of inputs. To this
end, the alternating diamond refinement algorithm uses the same principle as the single directional
refinement with diamonds, but the direction of refinement can alternate during the placement of
diamonds. To illustrate how the alternating direction works, see Figure 10.
 Additionally, the alternating diamond refinement doesn’t have a set of diamond templates as in
the original unidirectional algorithm. Instead the alternating diamond refinement will try to pack

 8

the diamonds as much as possible up to a maximum number of diamonds per refinement step (a
tunable parameter). Also, the diamonds are spread out as evenly as possible along the current
refinement step.
 Although, alternating refinement direction does remove the restriction that two opposite dims
are equal, the algorithm does not support the entire input space of possible quadrangulation. A
list of necessary, but possibly not sufficient criteria are as follows

 • All dimensions must be ≥ 3
 • Opposite difference must be even (This is fixable with a check and L-pattern placement at
 start.)
 • Enough support dims for the diamonds placed (Exact Formula WIP)

5 CORL
Another proposal to tackle the bidirectional refinement problem is the CORL algorithm, which
accomplishes refinement by strategically deciding which of the two O-pattern should encase a smaller
mesh in order to spread out singularities and balance regular grids with refinement patterns. The
function is recursive in nature and reduces the refinement in the directions in which the refinement
level is most dramatic at each layer.
 By inserting ”C” patterns, we decrease the side with the largest number of subdivisions by 2. By
inserting ”L” patters, we decrease the two largest sides by 1 each. The algorithms then prioritizes
the sides with the largest number of subdivisions to decrease, so at each iterative step we have small
differences in subdivisions between opposite sides of the mesh. Through experimentation we have
also developed a method of adding full square pads around the perimeter to improve the isotropy
by having fewer singularities in the corner, by having regular grid cells around to accommodate the
irregular cells from the patterns. This step showed a significant improvement in isotropy, and so
we have elected to leave it in the algorithm implementation, although it is ignored in the theory of
the algorithm for clarity.

7 Mesh Quality Metrics
To Assess whether a mesh is ”good” we must define one or more metrics to measure quality. Our
main focus for this project is isotropy, or closeness to the unit square the mesh was made from. To
quantify this we can assess the stretching affect that the transformation between the unit square
the quad element has on each element in the mesh. Based on the analysis done in [1], we explored
many options for ways to quantify mesh quality, and while we tested several, we landed on using
the condition number of the Jacobian matrix evaluated at 9 points of the reference object, the unit
square. We define
 σ1
                                     µ(T ) = κ(J(T )) − 1 =     −1                               (3)
 σ2
This metric is a measure of the difference in scaling rates in opposing directions, so the larger the
value, the more skewed away from a perfect square the element is. This metric is invariant to
size scaling, only considering shape deformity, which is our priority in applications. Poorly condi-
tioned (extremely skewed) elements in a mesh are worse for hydrodynamic Lagrangian simulations,
increasing the risk of convexity and error in simulation. We care about the conditioning of the
mapping for the gradient of the finite element shape function, since it will measure closeness to
folding that would result in concavity of the mesh during hydrodynamic Lagrangian simulations.

9 Future Work
While we finished the goals outlined in the project, we have a vision for further work to make the
tools we made more robust and usable. The ultimate goal for this is for the code to be implemented
in Crosslink so it can expand the input space as intended. Similarly, in order for this code base to
be useful in a larger group of simulations, we would want to expand one or both of our algorithms
to 3-D.
