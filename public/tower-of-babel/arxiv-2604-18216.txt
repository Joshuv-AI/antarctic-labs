A Counterexample to EFX n ≥ 3 n\geq 3 Agents, m ≥ n + 5 m\geq n+5 Items, Monotone Valuations via SAT-Solving
Hannaneh Akrami, Alexander Mayorov, Kurt Mehlhorn, Shreyas Srinivas, Christoph Weidenbach

Abstract
SAT solving has recently been proven effective in tackling open combinatorial problems. We contribute two additional results in the context of fair distribution of indivisible goods. Specifically, we demonstrate that EFX (envy-freeness up to any good) allocations always exist for three agents and seven goods, while we provide a counterexample for the case of n ≥ 3 n\geq 3 agents and m ≥ n + 5 m\geq n+5 goods. An allocation is EFX if no agent would envy the allocation of any other agent if any single item were to be removed from the other agent’s bundle of goods. Each agent’s preferences are modeled by a monotone valuation function on all potential bundles. After analyzing theoretical aspects of the problem, we encode the negation of the EFX instances into SAT. Satisfiability of the respective SAT formula constitute a counter-example to EFX, unsatisfiability of the respective SAT formula implies that EFX holds. The theoretical foundations of the encoding are proven correct in LEAN. For the three agents and seven goods case, we obtained a proof of unsatisfiability using SPASS-SAT of size about 30 GB in about 30 hours. It was shown to be correct by DRAT-trim. In the case of three agents and eight goods, SPASS-SAT computed satisfiability indicating a counterexample in the form of three specific agent valuations in about 20 hours. It was verified by probing all possible bundle assignments; the verification takes seconds. The extension of the counterexample to n ≥ 4 n\geq 4 agents and m ≥ n + 5 m\geq n+5 goods does not involve SAT-solving. This counterexample resolves, in the negative, one of the central questions in the theory of discrete fair division.

Our Results:

The smallest case that is open for unrestricted monotone valuations is three agents and seven goods. We show that an EFX-allocation always exists in this situation. We also show that this is no longer true for eight goods by exhibiting three valuations

Theoretical Foundations of the EFX Encoding

In this section we provide some theoretical foundations of EFX that will eventually improve the encoding of EFX in SAT, i.e., the size of the CNF and the runtime of an afterward applied SAT-solver.

In general,
m
items can be allotted to
n
agents in
n^{m}
ways. For
n=3
and
m=7
we have
3^{7}=2187
distinct allocations, a manageable number.
Actually, the number is less since all bundles must be non-empty in an EFX-allocation, see Section
3.5
. However, the number of valuations is enormous.
Note that a set of size seven has
\binom{7}{3}=35
subsets of three elements and that the values of these subsets may have any order. So the number of valuations is at least
35!\approx(35/e)^{35}\geq 10^{35}
.

We use two techniques for restricting the search space; see Sections
2.1
and
2.2
. These techniques are essential for solvability; see Section
5
. The following facts are useful.

Fact 1
(
[
8
]
)

If there is a counterexample to EFX, then there is a counterexample in which the valuations are non-degenerate, i.e.,
v_{i}(A)\not=v_{i}(B)
for any
i
and distinct sets
A
and
B
.

Proof:
[Sketch]
We sketch the proof that is presented fully in the Lean code accompanying this paper. Let the goods be
g_{0}
to
g_{m-1}
. Given a degenerate counterexample, we can obtain a non-degenerate version by perturbing the valuation functions as follows. We construct a new valuation function that first multiplies all valuations by a large multiplicative factor, so that any two distinct values are at least
2^{m}
apart, and then increases the value of a set

by
\sum_{g_{i}\in S}2^{i}
.

Non-degeneracy implies that non-empty sets have strictly positive value.

Fact 2

If
m\geq n
, all agents receive non-empty bundles in an EFX-allocation for a non-degenerate instance.

Proof:
Assume that there is an agent that receives an empty bundle. Let
v
be its valuation. Then there is another agent that receives a bundle

containing at least two items. Then for any

, we have
v(B\setminus g)>0=v(\emptyset)
.

From now on, we assume that our instance is non-degenerate. Then in an EFX-allocation, all agents receive a non-empty bundle, and, hence, any agent receives at most four items for
m=6
, five items for
m=7
,
and six items for

.

2.1
Fixing an Item Order for Agent Zero

Obviously, EFX is symmetric in agents and items. We must not fix an overall valuation for any agent. But we can fix the valuation of agent zero on bundles of size one.
We postulate that
v_{0}(0)<v_{0}(1)<\ldots<v_{0}(m-1)
, where we identify the singleton set with its content.

Lemma 1

If there is a counter-example to EFX then there is a counter-example in which
v_{0}
obeys the item order above.

Proof:
Simply rename the goods. More presisely, assume the goods are
h_{0}
,
h_{1}
, …, and
v_{0}(h_{i_{0}})<v_{0}(h_{i_{1}})<\ldots
. Replace

by

in all sets and redefine the valuations accordingly. A formal development can be found in the LEAN companion material.

2.2
Leveled Valuations

Recall that in a non-degenerate instance with seven items, no EFX allocation allocates more than five items to any agent.
Therefore, the EFX-conditions never involve sets of size six or seven. It therefore seems plausible that the valuations of the sets of size six and seven are irrelevant.

3
Encoding EFX into SAT

EFX is complicated because it involves a quantifier alternation.

\forall\,\text{valuations}\,v\ \exists\,\text{allocation}\,X\ \forall\,\text{agents}\,i,j\ \forall\,\text{goods}\,g\in X_{j}\;:\;v_{i}(X_{j}\setminus g)<v_{i}(X_{i}).

If the number
m
of goods as well as the number
n
of agents is fixed, the above formula can actually be turned into a finite Boolean combination. We will encode its negation

\exists\,\text{valuation}\,v\ \forall\,\text{allocations}\,X\ \exists\,\text{agents}\,i,j\ \exists\,\text{good}\,g\in X_{j}\;:\;\neg(v_{i}(X_{j}\setminus g)<v_{i}(X_{i})).

into SAT and check for satisfiability. The number of potential allocations is rather small compared to the number of potential valuations; see Section
2
. So we decided on a SAT-formulation where valuations correspond to assignments to propositional variables, and the remaining part of the formula is expressed by Boolean constraints over these variables.

4.1
The Theory of EFX Allocations

We set up the theory of discrete allocations of goods for general Lean types

We first define a structure of valuation functions that encodes both a valuation function and basic properties of this function. We also define an allocation structure

To allow wider use of this formalization, we allow partial allocations. Completeness is stated as an additional property that can be included as an assumption in the relevant theorems.

\mathit{val}(i,A)
is the value of the set
A
for agent
i
. We then check monotonicity and the EFX-property. For monotonicity, we run for all
i\in\{0,1,2\}
over all pairs
A
,
B
with
0\leq A,B<256
. If

, we check that

. For the EFX-property with run over all triples
A
,
B
,
C
with
0\leq A,B,C<256
. If the triple does not correspond to a partition, we discard it. Otherwise, we check the EFX-condition with
0

A
,
1
owning set
B

C
owning set

. For example, we must have
v_{0}(B\setminus g)<v_{0}(A)
for all

for all

More Agents and Goods

We extend the counterexample to more than three agents, more precisely, we first extend it to
n\geq 4
agents and
m=n+5
goods and then to
m\geq n+5
goods.

We have
n\geq 4
agents
0
to
n-1
and
m=n+5
goods. The goods are the goods
G=\{\hskip 0.50003ptg_{0},\ldots,g_{7}\hskip 0.50003pt\}
from our counterexample for
3
agents and
n+5-8=n-3
new goods
H=\{\hskip 0.50003pth_{0},\ldots,h_{n-4}\hskip 0.50003pt\}
. The valuations are as follows. We use
v_{i}
,
i\in\{\hskip 0.50003pt0,1,2\hskip 0.50003pt\}
, for the valuations of our basic counterexample and
\bar{v}_{i}
,
0\leq i\leq n-1
, for the valuations of the extended counterexample. Let
M=v_{2}(G)+1
. Then,

\displaystyle\bar{v}_{i}(S)

\displaystyle=v_{i}(S\cap G)

for
i=0,1
and any
S\subseteq[m]

\displaystyle\bar{v}_{i}(S)

\displaystyle=v_{2}(S)

for
i\geq 2
and
S\subseteq G

\displaystyle\bar{v}_{i}(S)

\displaystyle=M

for
i\geq 2
and

Note that the goods in
H
have no value to the agents
0
and
1
and that agents
2
to
n-1
have identical valuations. Also subsets of
G
have the same value as in basic counterexample, and, for any agent
i\geq 2
, any subset containing an element in
H
has value larger than any subset of
G
.

Assume that an EFX-allocation
(X_{0},\ldots,X_{n-1})
exists. Since
H
consists of exactly
n-3
goods, there must be an agent
i^{*}\in\{\hskip 0.50003pt2,\ldots,n-1\hskip 0.50003pt\}
that owns no good in
H
, say
i^{*}=2
. So
X_{i^{*}}\subseteq G
and hence
\bar{v}_{i^{*}}(X_{i^{*}})\leq\bar{v}_{i^{*}}(G)<M
. Consider now any
X_{j}
with
X_{j}\cap H\not=\emptyset
. If
X_{j}
has cardinality two or more, there is a proper subset of
X_{j}
that has value
M+1
for
i^{*}
, and the allocation is not EFX. Thus, there are
n-3
agents each owning one of the items in
H
and nothing else. The remaining three agents own the items in
G
and one of them owns at least two items in
G
. Suppose now that there is an agent
i\in\{\hskip 0.50003pt0,1\hskip 0.50003pt\}
that owns one of the items in
H
and nothing else. Then
X_{i}
has value zero for
i
and hence

strongly envies the agent owning two or more items in
G
. We conclude that the agents
0
,
1
and
i^{*}
share the goods in
G
between them. Thus, their bundles would form an EFX-allocation for the basic counterexample.

The example readily extends to more goods by adding dummy items of value zero. Indeed, let
I_{0}=G\cup H
be the set
n+5

\bar{v}_{0}
to
\bar{v}_{n-1}
be the valuations. Let

be any superset of

and extend any valuation to

by defining

for any subset

. Then there is no EFX-allocation of

as it would induce an EFX-allocation of

.

An SMT Encoding

The approach presented in Section
3
translates the problem into a Boolean satisfiability (SAT) question. Encoding EFX involves representing valuations and their comparison succinctly. This suggests an encoding as a Satisfiability
Modulo Theory (SMT) problem over a theory that supports numbers and ordering natively. We use quantifier-free Linear Real Arithmetic (LRA)
[
12
,
6
,
11
]
as the theory.
Our formulation in LRA works as follows. For each agent
i
and set
A
, we introduce a (real-valued) variable
v^{i}_{A}
. The value of
v^{i}_{A}
is the valuation of the set
A
for the agent
i
. We have the following constraints:

•

Positivity:

v^{i}_{A}\geq 0
for all
i
and
A\subseteq[m]

•

Monotonicity:
For all bundles of goods
A,B\subseteq[m]
such that
A\subset B
,
v^{i}_{A}<v^{i}_{B}
for every agent
i

•

Item Order:
For agent zero
v^{0}_{\{\hskip 0.50003ptj\hskip 0.50003pt\}}<v^{0}_{\{\hskip 0.50003ptk\hskip 0.50003pt\}}
for
0\leq j<k\leq m

•

EFX:
There exists an allocation
(A_{0},A_{1},A_{2})
such that for all pairs of agents
i
,
j
and
g\in A_{j}
we have
v^{i}_{A_{j}\setminus g}<v^{i}_{A_{i}}
. More precisely, we express this as

\mathit{EFX}:=\bigvee_{(A_{0},A_{1},A_{2})}\bigwedge_{\begin{subarray}{c}i,j\\
i\neq j\end{subarray}}\bigwedge_{g\in A_{j}}v^{i}_{A_{j}\setminus g}<v^{i}_{A_{i}}

where the disjunction ranges over all possible ordered partitions of
[m]
into 3 subsets.

The existence of an EFX-allocation is equivalent to the unsatisfiability of
\text{Positivity}\wedge\text{Monotonicity}\wedge\text{Item Order}\wedge\neg\mathit{EFX}
.
The formulation in LRA is much more compact than the formulation as in SAT. For
m=7
, the EFX constraint consists of 1806 disjuncts, each consisting of 14 conjunctions of inequalities, summing up to 25284 inequalities.
Represented efficiently as a Boolean circuit, we get an overall size of under 15000 nodes.

Conclusions and Open Problems

We have shown that EFX exists for three agents and seven goods but does not always exist for three agents and eight or more goods.
We close with some open problems and suggestions for further work.

•

For three agents and sufficiently many goods, EFX exists for two monotone and one MMS valuation and does not exist for three monotone valuations. Can one replace MMS by a more general notion and still have existence?

•

When do EFX-allocations exist for four or more agents? Do they exist for additive valuations? Do they exist for
m=n+4
goods and monotone valuations? Note that they exist for
m=n+3
goods
[
13
]
and do not exist for
m=n+5
goods (this paper).

•

For additive valuations and any number of agents, an allocation that is simultaneously
8
8

8

An allocation
(X_{1},\ldots,X_{n})
is EEFX if for every
i
, there is a partition of
\cup_{j\not=i}X_{j}
into
n-1
bundles
Y_{1}
to
Y_{n-1}
such that
i
with
X_{i}
does not strongly envy any of them. An allocation is EF1 if for every
i
and
j
there is a
g\in X_{j}
such that
v_{i}(X_{j}\setminus g)\leq v_{i}(X_{i})
.
EEFX (epistemic EFX) and EF1 (envy-free up to some item) always exists
[
3
]
. Is there a counterexample for general valuations? Our counterexample to EFX is not a counterexample to EEFX + EF1.

•

We found our counterexample for eight items with the help of a SAT-solver and 20 hours of compute time.
Verification of the counterexample takes only a few seconds. Is there an alternative way, clever guessing maybe, for finding a counterexample. We suspect that a counterexample to EEFX + EF1, if it exists, will have many more items, and so an alternative way of identifying difficult instances would be useful.

Appendix B
Further Theoretical Aspects of EFX

We briefly discuss ideas that did not eventually make it into the final CNF encoding, but
might be valuable for different instances of EFX, e.g., considering the case of four agents.

Singletons:

Many allocations, in which agent 0 is assigned a singleton, are guaranteed not to be EFX. Assume agent 0 is allocated a singleton. If this item is
m-3
or less, the allocation is not EFX. If the item is
m-2
and
m-1
is not in a singleton, the allocation is not EFX. For seven goods, this reasoning excludes 380 out of the 1806 allocations.

Breaking it into Pieces:

The driving quantifier for the eventual size of the formula is the allocation quantifier. It can be broken into
pieces. If
X_{0}
,
X_{1}
,
X_{2}
is an allocation, then there are six possible orderings of their cardinalities that could be considered separately. This could be further refined by considering all possible combinations of cardinalities, e.g., for
m=7
:

(5,1,1),(4,2,1),(4,1,2),(3,2,2),

(3,3,1),(3,1,3),(2,1,4)
,
(2,4,1)
,
(2,2,3)(2,3,2),(1,1,5),(1,5,1),(1,3,3),(1,4,2),(1,2,4)
.

Breaking Symmetry Further by Restricting Valuations:

We have restricted the valuation of agent zero by ordering the items. We can still interchange the valuations of agents one and two if we also interchange the bundles assigned to them. Alternatively, we could define an order on evaluations and postulate that the valuation of agent one precedes or is equal to the valuation of agent two. In this way, we could halve the search space at the expense of an increased complexity of the formula. We have not explored this possibility further.

No Envy-Cycles:

Consider the following directed
envy-graph
, whose vertices are the agents. We have an edge from agent
i
to agent
j
if
i
prefers the bundle assigned to
j
over the bundle assigned to them. The edges of the graph are called
envy
edges. It is easy to see that if there is an EFX-allocation, then there is an EFX-allocation without an envy-cycle. One simply reassigns the bundles along any envy-cycle.

Appendix C
The Program Checking the Counterexample

The following program checks the counterexample.

#include <cassert>

#include <math.h>

#include <iostream>

#include <fstream>

int m = 8;

int P = 256;

int k = m - 2;

int val[3][256];

int pow(int i)

{ assert (0 <= i && i < 8);

if (i == 0) return 1;

if (i == 1) return 2;

if (i == 2) return 4;

if (i == 3) return 8;

if (i == 4) return 16;

if (i == 5) return 32;

if (i == 6) return 64;

if (i == 7) return 128;

return 256;

}

bool is_in(int i, int A) // returns true if i is a member of A

{ assert (0 <= i && i < m && 0 <= A && A < P);

return ((A / pow(i)) % 2);

}

int card(int A)

{ assert (0 <= A && A < P);

int c = 0;

for (int i = 0; i < m; i++)

if (is_in(i,A)) c++;

return c;

}

bool subset(int A, int B)

{ assert (0 <= A && A < P && 0 <= B && B < P);

for (int i = 0; i < m; i++)

if ( is_in(i,A) && ! is_in(i,B) ) return false;

return true;

}

bool is_monotone(int i)

{ assert (0 <= i && i <= 2);

for (int A = 0; A < P; A++)

for (int B = 0; B < P; B++)

{ if (A == B) continue;

if ( !subset(A,B) || val[i][A] < val[i][B] ) continue;

return false;

}

return true;

}

bool is_EFX(int v, int A, int B, int C)

// checks whether agent v with set A strongly envies B or C

{ assert(0 <= v && v <= 2 && 0 <= A && A < 256 && 0 <= B && B < 256

&& 0 <= C && C < 256);

for (int g = 0; g < m; g++){

if (is_in(g,B) && val[v][B-pow(g)] > val[v][A]){

return false;

}

if (is_in(g,C) && val[v][C - pow(g)] > val[v][A]){

return false;

}

}

return true;

}

bool is_EFX(int A, int B, int C)

// checks whether (A,B,C) is EFX: O owns A, 1 owns B, 2 owns C

{ assert(0 <= A && A < P && 0 <= B && B < P && 0 <= C && C < P);

if (!is_EFX(0,A,B,C) || !is_EFX(1,B,A,C) || !is_EFX(2,C,A,B)) return false;

return true;

}

bool is_EFX()

/* checks whether there is an EFX-allocation by running over all

triples A, B, C with 0 <= A,B,C < 256. First checks that the three sets

form a partition and then checks EFX */

{ for (int A = 0; A < P; A++)

for (int B = 0; B < P; B++)

for (int C = 0; C < P; C++)

{ bool good_values = (card(A) > 0) && (card(B) > 0) && (card(C) > 0);

if (! good_values ) continue;

for (int i = 0; i < m; i++)

{ int c = is_in(i,A) + is_in(i,B) + is_in(i,C);

if ( c == 0 || c >= 2) good_values = false;

}

if (good_values && is_EFX(A,B,C))

return true;

}

return false;

}

int main(){

std::ifstream myinput("ThreeVals.txt");

// each line has the form: set as a number, set as a bitstring, rank;

// the ranks are increasing

for (int i = 0; i < 3; i++){

for (int r = 0; r < 256; r++){

int s; int k; int w;

myinput >> s; myinput >> k; myinput >> w;

assert (w == r);

val[i][s] = r;

}

std::cout << "\nval " << i << (is_monotone(i)? " is monotone" : " is not monotone");

// check monotonicity of val(i,*)

}

myinput.close();

std::cout << (is_EFX()? "\nfound an EFX allocation\n" : "\nno EFX allocation\n");

// check all possible allocations for EFX-property

return 0;

}
