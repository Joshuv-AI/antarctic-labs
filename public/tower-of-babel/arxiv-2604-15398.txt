Python library supporting Discrete Variational Formulations and training solutions with Collocation-based Robust Variational Physics Informed Neural Networks (DVF-CRVPINN)
Tomasz Służalec, Marcin Łoś, Askold Vilkha, Maciej Paszyński

Abstract
We explore the possibility of solving Partial Differential Equations (PDEs) using discrete weak formulations. We propose a programming environment for defining a discrete computational domain, introducing discrete functions defined over a set of points, constructing discrete inner products, and introducing discrete weak formulations employing Kronecker delta test functions. Building on this setup, we propose a discrete neural network representation, training the solution function defined over a discrete set of points and employing discrete finite difference derivatives in the automatic differentiation procedures. As a challenging computational model example, we focus on Stokes equations in two-dimensions, defined over a discrete set of points. We train the solution using the discrete weak residual and the Adamax algorithm with discrete automatic differentiation of the discrete gradients. Despite introducing the python environment, we also provide a rigorous mathematical formulation based on discrete weak formulations, proving the well-posedness and robustness of the loss function. The solution of the discrete weak formulations is based on neural network training employing a robust loss function that is related to the true error. In this way, we have a robust control of the numerical error during the training of the neural networks. Besides the Stokes formulation, we also explain the functionality of the proposed library using the Laplace problem formulation.

Variational Physics-Informed Neural Networks (VPINNs)

To address this issue, Robust VPINNs (RVPINNs) were proposed in

Despite their theoretical appeal, existing RVPINN implementations rely on numerical integration and dense linear algebra, leading to prohibitive computational costs and memory requirements.

The robust loss is defined as a Riesz representative of the residual, which practical implementation involves the inverse of the Gram matrix, namely,

\displaystyle\mathcal{L}(\theta)=\left\|{Au_{\theta}-f}\right\|_{V^{\prime}}^{2}=R_{\theta}^{T}GR_{\theta}=\text{RES}\,(\theta)^{T}G^{-1}\,\text{RES}(\theta)

(1)

where

R_{\theta}=G^{-1}\,\text{RES}(\theta)
is a vector
representing
v\mapsto\left({Au-f},{v}\right)_{h}
,
\text{RES}(\theta)_{i}=\left({Au-f},{v_{i}}\right)_{h}
is the weak residual vector,
where
v_{i}
is the
i
-th basis function of
V
, following the VPINN formulation.
This loss is robust, which means that the true error (the difference between the neural network solution and the exact solution) is bounded by the square root of the robust loss, up to the continuity and coercivity constants

\frac{1}{\mu}\sqrt{\mathcal{L}(\theta)}\leq\left\|{u_{\theta}-u_{\text{exact}}}\right\|_{h}\leq\frac{1}{\alpha}\sqrt{\mathcal{L}(\theta)}.

(2)

As a precursor to the present study, the collocation-based robust variational framework was introduced and validated in two spatial dimensions in
[
33
]
. In that work, the CRVPINN methodology combined point-collocation with a Gram-matrix-weighted loss function and an LU-based solver strategy, leading to a substantial reduction in computational cost compared to classical RVPINNs while preserving robustness. The approach was successfully demonstrated on a range of two-dimensional problems, including Laplace, advection–diffusion, Stokes, stationary Navier–Stokes, and linear elasticity equations, showing that the collocation-based formulation provides an efficient and stable alternative to integration-based variational PINNs.

In this paper, we introduce a programming framework for defining a discrete computational domain, incorporating discrete functions over a set of points, constructing discrete inner products, and formulating discrete weak problems using Kronecker delta test functions.
Building on this foundation, we develop a discrete neural network representation in which the solution function is defined over discrete points and trained using finite-difference-based derivatives within automatic differentiation.

As a challenging test case, we consider the two-dimensional Stokes equations on a discrete point set. The solution is obtained by minimizing a discrete weak residual using the Adam optimization algorithm, with gradients computed through discrete automatic differentiation.

In addition to the Python implementation, we provide a rigorous mathematical framework based on discrete weak formulations, establishing the well-posedness and robustness of the loss function. The neural network is trained using a loss function closely related to the true error, ensuring reliable control of numerical accuracy throughout training.

Mathematical framework

Following
[
33
]
,
we consider the 2D unit square
\Omega=(0,1)^{2}

and a set of uniformly distributed collocation points

\Omega_{h}\coloneq\{(ih,jh):0\leq i,j\leq N\},

(3)

where
h=1/N
is the point spacing for some fixed grid size
N
.
Our discrete formulations will be built using subspaces of the space
of real functions on
\Omega_{h}
:

D_{h}\coloneq\{u\colon\Omega_{h}\to\mathbb{R}\}\cong\mathbb{R}^{(N+1)^{2}}

(4)

which we endow with a scalar product and the induced norm:

\left({u},{v}\right)_{h}\coloneq h^{2}\sum_{p\in\Omega_{h}}u(p)v(p),\qquad\left\|{u}\right\|_{h}^{2}\coloneq\left({u},{u}\right)_{h}.

(5)

Continuous derivatives will be approximated using finite difference operators
given by

\displaystyle\nabla_{+}u_{i,j}\coloneq

\displaystyle\left(\nabla_{x+}u_{i,j},\nabla_{y+}u_{i,j}\right)\coloneq\left(\frac{u_{i+1,j}-u_{i,j}}{h},\frac{u_{i,j+1}-u_{i,j}}{h}\right)

(6)

\displaystyle\nabla_{-}u_{i,j}\coloneq

\displaystyle\left(\nabla_{x-}u_{i,j},\nabla_{y-}u_{i,j}\right)\coloneq\left(\frac{u_{i,j}-u_{i-1,j}}{h},\frac{u_{i,j}-u_{i,j-1}}{h}\right)

for these indices
(i,j)
where the right-hand side is defined,
and zero otherwise.
Here,
u_{i,j}
is a shorthand for
u(ih,jh)
.
Using these, we can define a degenerate scalar product and a corresponding seminorm:

\left({u},{v}\right)_{\nabla,h}\coloneq\left({\nabla_{x+}u},{\nabla_{x+}v}\right)_{h}+\left({\nabla_{y+}u},{\nabla_{y+}v}\right)_{h},\qquad\left\|{u}\right\|_{\nabla,h}^{2}\coloneq\left({u},{u}\right)_{\nabla,h}.

(7)

When restricted to the subspace

D_{0,h}\coloneq\left\{u\in D_{h}:\left.u\right|_{\partial\Omega_{h}}=0\right\},\quad\partial\Omega_{h}\coloneq\partial\Omega\cap\Omega_{h}

(8)

of functions that vanish on the discrete boundary points,
these two become a scalar product and a norm, respectively.
The standard discrete Laplace operator

\Delta u_{i,j}\approx\frac{1}{h^{2}}\left(u_{i,j+1}+u_{i,j-1}+u_{i+1,j}+u_{i-1,j}-4u_{i,j}\right)

(9)

corresponds to
\Delta_{h}u=\nabla_{+}\cdot(\nabla_{-}u)=\nabla_{-}\cdot(\nabla_{+}u)
.

Let
\tau_{\alpha}^{\pm}
denote the shift operator in direction
\alpha
,
that is

\left(\tau_{x}^{+}u\right)_{ij}=\begin{cases}u_{i+1,j}&\text{for }i<N\\
0&\text{for }i=N\end{cases}\quad\left(\tau_{x}^{-}u\right)_{ij}=\begin{cases}u_{i-1,j}&\text{for }i>0\\
0&\text{for }i=0\end{cases},

(10)

and similarly for
\tau_{y}^{\pm}
and
\tau_{z}^{\pm}
.

Lemma 1

Shift operators
\tau_{\alpha}^{+}
and
\tau_{\alpha}^{-}
are adjoint,
that is
\left({\tau_{\alpha}^{+}u},{v}\right)_{h}=\left({u},{\tau_{\alpha}^{-}v}\right)_{h}

for all
u,v\in D_{h}
.

Proof

We will prove it for
\alpha=x
; for other directions, the proof is the same.
Since the scalar product is bilinear, it is enough to consider the case
when
u
is a basis function,
that is,
u=\delta^{ij}
for some
0\leq i,j\leq N
.
If
i=0
, then
\tau_{x}^{+}\delta^{ij}\equiv 0
, so
\left({\tau_{x}^{+}\delta^{ij}},{v}\right)_{h}=0
.
On the other hand,
\left(\tau_{x}^{-}v\right)_{ij}=0
,
and consequently
\left({\delta^{ij}},{\tau_{x}^{+}v}\right)_{h}=0
as well.
For
i\neq 0
, function
\tau_{x}^{+}\delta^{ij}
is nonzero only at the point
corresponding to
(i-1,j)
,
so

\left({\tau_{x}^{+}\delta^{ij}},{v}\right)_{h}=h^{3}\,v_{i-1,j}=h^{3}\,\left(\tau_{x}^{-}v\right)_{ij}=\left({\delta^{ij}},{\tau_{x}^{-}v}\right)_{h}

(11)

which completes the proof.
∎

Lemma 2

\tau_{\alpha}^{-}\circ\nabla_{+}[\alpha]=\nabla_{-}[\alpha]
.

Proof

Let
u\in D_{h}
, then for
i>0
we have

\left(\tau_{x}^{-}\nabla_{x+}u\right)_{ij}=\left(\nabla_{x+}u\right)_{i-1,j}=h^{-1}(u_{ij}-u_{i-1,j})=\left(\nabla_{x-}u\right)_{ij}.

(12)

For
i=0
, both sides are zero.
Proof for other directions is the same.
∎

Lemma 3
(Discrete product rule)

Any pair
u,v\in D_{h}
satisfies

\displaystyle\nabla_{+}[\alpha](uv)

\displaystyle=\left(\nabla_{+}[\alpha]u\right)\,v+\tau_{\alpha}^{+}u\left(\nabla_{+}[\alpha]v\right)

(13)

\displaystyle\nabla_{-}[\alpha](uv)

\displaystyle=\left(\nabla_{-}[\alpha]u\right)\,v+\tau_{\alpha}^{-}u\left(\nabla_{-}[\alpha]v\right).

Proof

For
i<N
we have

\displaystyle\nabla_{x+}(uv)_{ij}

\displaystyle=u_{i+1,j}v_{i+1,j}-u_{ij}v_{ij}

(14)

\displaystyle=u_{i+1,j}v_{i+1,j}-u_{i+1,j}v_{ij}+u_{i+1,j}v_{ij}-u_{ij}v_{ij}

\displaystyle=u_{i+1,j}(\nabla_{x+}v)_{ij}+(\nabla_{x+}u)_{ij}v_{ij}

\displaystyle=\left(\tau_{x}^{+}u\right)_{ij}(\nabla_{x+}v)_{ij}+(\nabla_{x+}u)_{ij}v_{ij}.

For
i=N
, both sides are zero.
Proofs for other directions and for
\nabla_{-}[\alpha]
are the same.
∎

Lemma 4

Any
u\in D_{0,h}
satisfies
\left({\nabla_{+}[\alpha]u},{1}\right)_{h}=0
.

Proof

\displaystyle\left({\nabla_{x+}u},{1}\right)_{h}

\displaystyle=h^{3}\sum_{\bm{x}\in\Omega_{h}}(\nabla_{x+}u)(\bm{x})

(15)

\displaystyle=h^{2}\sum_{j,k=0}^{N}\left\{\sum_{i=0}^{N}\left[u_{i+1,j,k}-u_{ijk}\right]\right\}

\displaystyle=h^{2}\sum_{j,k=0}^{N}\left[u_{Njk}-u_{0jk}\right]=0,

since
\left.u\right|_{\partial\Omega_{h}}=0
.
∎

Lemma 5
(Discrete integration by parts)

Any pair
u,v\in D_{h}
such that
uv\in D_{0,h}
satisfies

\left({\nabla_{+}[\alpha]u},{v}\right)_{h}=-\left({u},{\nabla_{-}[\alpha]v}\right)_{h}

(16)

Proof

By
lemma

4
,
\left({\nabla_{+}[\alpha](uv)},{1}\right)_{h}=0
.
Combining it with
lemma

3
we obtain

\left({\nabla_{+}[\alpha]u},{v}\right)_{h}+\left({\tau_{\alpha}^{+}u},{\nabla_{+}[\alpha]v}\right)_{h}=\left({\nabla_{+}[\alpha](uv)},{1}\right)_{h}=0

(17)

so
\left({\nabla_{+}[\alpha]u},{v}\right)_{h}=-\left({\tau_{\alpha}^{+}u},{\nabla_{+}[\alpha]v}\right)_{h}
.
By
lemma

1
we get

\left({\tau_{\alpha}^{+}u},{\nabla_{+}[\alpha]v}\right)_{h}=\left({u},{\tau_{\alpha}^{-}\nabla_{+}[\alpha]v}\right)_{h}
,
and finally
lemma

2

gives us
\left({u},{\tau_{\alpha}^{-}\nabla_{+}[\alpha]v}\right)_{h}=\left({u},{\nabla_{-}[\alpha]v}\right)_{h}
,
which proves the desired equality.
∎

Theorem 2.1
(Discrete Poincaré inequality)

There exists a constant
K>0
,
independent of
N
,
such that

\left\|{\bm{u}_{h}}\right\|_{h}\leq K\left\|{\bm{u}_{h}}\right\|_{\nabla,h}

(18)

for all
\bm{u}_{h}\in D_{0,h}
.

Proof

Let
g\in D_{h}
be given by
g_{ij}=ih
.
Then
\left(\nabla_{x-}g\right)_{ij}=1
unless
i=N
.
Therefore, by
lemma

5

\left\|{u}\right\|_{h}^{2}=\left({\nabla_{x-}g},{u^{2}}\right)_{h}=\left({g},{\nabla_{x+}(u^{2})}\right)_{h}.

(19)

Using
lemma

3
we get

\nabla_{x+}u^{2}=(u+\tau_{x}^{+}u)\nabla_{x+}u.

(20)

Since
\left\|{\tau_{x}^{+}u}\right\|_{h}=\left\|{u}\right\|_{h}
,
using Cauchy-Schwarz inequality we obtain

\left\|{u}\right\|_{h}^{2}=\left({g},{(u+\tau_{x}^{+}u)\nabla_{x+}u}\right)_{h}\leq 2\left\|{g}\right\|_{h}\left\|{u}\right\|_{h}\left\|{\nabla_{x+}u}\right\|_{h}

(21)

and thus
\left\|{u}\right\|_{h}\leq 2\left\|{g}\right\|_{h}\left\|{\nabla_{x+}}\right\|_{h}\leq 2\left\|{u}\right\|_{\nabla,h}
,
since
\left\|{g}\right\|_{h}\leq\left\|{1}\right\|_{h}=1
.
∎

3
Theoretical foundations of the discrete weak formulation of the Stokes equations

We start by recalling the strong formulation of the Stokes equations:
find velocity
\bm{u}\coloneq(u_{x},u_{y})
and pressure
p
such that

\left\{\begin{aligned} -\Delta\bm{u}+\nabla p&=\bm{f}\text{ in }\Omega\\
\nabla\cdot\bm{u}&=0\text{ in }\Omega\\
\bm{u}&=\bm{g}\text{ on }\partial\Omega\end{aligned}\right.

(22)

By introducing stress
\bm{\sigma}
we can reformulate it as a first-order system:

\left\{\begin{aligned} -\nabla\cdot\bm{\sigma}+\nabla p&=\bm{f}\text{ in }\Omega\\
\nabla\cdot\bm{u}&=0\text{ in }\Omega\\
\bm{\sigma}-\nabla\bm{u}&=0\text{ in }\Omega\\
\bm{u}&=\bm{g}\text{ on }\partial\Omega\end{aligned}\right.

(23)

As demonstrated in
[
27
]
,
if we define
A\colon H_{A}\to\bm{L}^{2}(\Omega)
by

A(\bm{u},\bm{\sigma},p)\coloneq\left(-\nabla\cdot\bm{\sigma}+\nabla p,\nabla\cdot\bm{u},\bm{\sigma}-\nabla\bm{u}\right)

(24)

where
H_{A}\subset\bm{L}^{2}(\Omega)\times\bm{L}^{2}(\Omega)\times L^{2}(\Omega)

is an appropriate Sobolev-type space,
the variational formulation
\left({Au},{v}\right)=\left({f},{v}\right)

is well-posed with
L^{2}
norm on the test space
and the graph norm
\left\|{u}\right\|_{H_{A}}^{2}\coloneq\left\|{u}\right\|_{L^{2}}^{2}+\left\|{Au}\right\|_{L^{2}}^{2}

on the trial space.
Furthermore, to obtain stability in the
L^{2}
norm on the trial space,
it may be possible to use the

graph adjoint norm

\left\|{v}\right\|_{H_{A^{*}}}^{2}\coloneq\left\|{v}\right\|_{L^{2}}^{2}+\left\|{A^{*}v}\right\|_{L^{2}}^{2}

on the test space, where
A^{*}
is the formal adjoint of
A
.
We apply these ideas to derive a stable discrete formulation
of the Stokes equations in the CRVPINN framework.

To ensure our discrete formulation is well-defined,
we must take care to properly choose the discrete space
where
u_{h}=(\bm{u}_{h},\bm{\sigma}_{h},p_{h})
lives.
Let us denote it by
\mathcal{U}_{h}=V_{h}\times S_{h}\times P_{h}

and endow it with the
D_{h}
scalar product, that is,
for
u_{h}=(\bm{u}_{h},\bm{\sigma}_{h},p_{h})

and
v_{h}=(\bm{v}_{h},\bm{\tau}_{h},q_{h})
we let

\left({u},{v}\right)_{\mathcal{U}_{h}}=\left({\bm{u}_{h}},{\bm{v}_{h}}\right)_{h}+\left({\bm{\sigma}_{h}},{\bm{\tau}_{h}}\right)_{h}+\left({p_{h}},{q_{h}}\right)_{h}

(25)

For the velocity space
V_{h}
, the natural choice is
D_{0,h}^{2}
,
since it incorporates the Dirichlet boundary conditions.
In a few places we will use a projection operator
\pi_{0}\colon D_{h}^{2}\to D_{0,h}

that sets the boundary values of a vector field to zero.
We can replace the Laplacian with its discrete version
\Delta_{h}
.
For the first order formulation, we can write it as
either
\Delta_{h}\bm{u}_{h}=\nabla_{+}\cdot\bm{\sigma}_{h}
,
with
\bm{\sigma}_{h}=\nabla_{-}\bm{u}_{h}
,
or
\Delta_{h}\bm{u}_{h}=\nabla_{-}\cdot\bm{\sigma}_{h}
,
with
\bm{\sigma}_{h}=\nabla_{+}\bm{u}_{h}
.
This choice is arbitrary, but it will influence the choice of other
discrete derivative signs.
We will assume the choice of the first option:
\bm{\sigma}_{h}=\nabla_{-}\bm{u}_{h}
.
Similarly, the direction of the pressure gradient is arbitrary, and we will choose
\nabla_{+}p_{h}
.
The momentum equation thus reads

-\nabla_{+}\cdot\bm{\sigma}_{h}+\nabla_{+}p_{h}=\bm{f}.

(26)

We will write the zero divergence condition
in a way that ensures
\left({\nabla_{+}p_{h}},{\bm{u}_{h}}\right)_{h}=-\left({p_{h}},{\nabla_{-}\cdot\bm{u}_{h}}\right)_{h}

is zero:

\nabla_{-}\cdot\bm{u}_{h}=0.

(27)

Lemma 6

Image of the map
\operatorname{div}_{h}\colon D_{0,h}^{2}\to D_{h}

given by
\operatorname{div}_{h}\bm{u}_{h}=\nabla_{-}\cdot\bm{u}_{h}

is the space
D^{p}_{h}
defined as

D^{p}_{h}=\left\{f\in D_{h}:f|_{\Gamma_{p}}=0,\left({f},{1}\right)_{h}=0\right\}

(28)

where

\Gamma_{p}=\left(\{0\}\times[0,1]\cup[0,1]\times\{0\}\right)\cap\partial\Omega_{h}\cup\{(1,1)\}.

(29)

Proof

Since
\left({\nabla_{-}\cdot\bm{u}_{h}},{p_{h}}\right)_{h}=-\left({\bm{u}_{h}},{\nabla_{+}p_{h}}\right)_{h}
,
operator
\operatorname{grad}_{h}\colon D_{h}\to D_{0,h}^{2}

given by
\operatorname{grad}_{0,h}p_{h}=\pi_{0}(\nabla_{+}p_{h})

is the adjoint of
\operatorname{div}_{h}
(up to the sign).
Therefore,
\operatorname{im}\operatorname{div}_{h}=\left(\ker\operatorname{grad}_{0,h}\right)^{\perp}
.
Suppose
\operatorname{grad}_{0,h}p=0
.
Let
a=p_{11}
.
We have
(\nabla_{+}p)_{ij}=0
for all
0<i,j<N
,
so
p_{i+1,j}=p_{ij}
,

p_{i,j+1}=p_{ij}
.
This allows us to conclude that
p_{ij}=a
for all the points
except the corner
p_{NN}
and edges
p_{0j}
,
p_{i0}
.
In other words,
\operatorname{grad}_{0,h}p=0
implies
p
is constant
on
\Omega_{h}\setminus\Gamma_{p}
.
Conversely, all such functions have zero
\operatorname{grad}_{h}
.
Therefore, the kernel of
\operatorname{grad}_{h}
consists of
all functions that are constant on
\Omega_{h}\setminus\Gamma_{p}
.
Its orthogonal complement is comprised of functions that vanish on
\Gamma_{p}
,
and have zero mean over
\Omega_{h}\setminus\Gamma_{p}
,
which is exactly
D^{p}_{h}
.
∎

This lemma suggest the appropriate space for the pressure is
P_{h}=D^{p}_{h}
.
Finally, no additional conditions are needed for
\bm{\sigma}_{h}
,
so we can take
S_{h}=D_{h}^{4}
.
The full system has the form

\left\{\begin{aligned} -\nabla_{+}\cdot\bm{\sigma}_{h}+\nabla_{+}p_{h}&=\bm{f}\\
\nabla_{-}\cdot\bm{u}_{h}&=0\\
\bm{\sigma}_{h}-\nabla_{-}\bm{u}_{h}&=0\\
\end{aligned}\right.

(30)

Let
a\colon\mathcal{U}_{h}\times\mathcal{U}_{h}\to\mathbb{R}
be the bilinear form given by

\displaystyle a(u_{h},v_{h})

\displaystyle=\left({-\nabla_{+}\cdot\bm{\sigma}_{h}+\nabla_{+}p_{h}},{\bm{v}_{h}}\right)_{h}

(31)

\displaystyle+\left({\nabla_{-}\cdot\bm{u}_{h}},{q_{h}}\right)_{h}

\displaystyle+\left({\bm{\sigma}_{h}-\nabla_{-}\bm{u}_{h}},{\bm{\tau}_{h}}\right)_{h}

This form naturally defines
A\colon\mathcal{U}_{h}\to\mathcal{U}_{h}^{\prime}

by
\langle Au_{h},v_{h}\rangle=a(u_{h},v_{h})
.
Using formulas for discrete integration by parts,
we can compute its adjoint
A^{\prime}
:

\displaystyle\langle A^{\prime}v_{h},u_{h}\rangle

\displaystyle=\left({\nabla_{+}\cdot\bm{\tau}_{h}-\nabla_{+}q_{h}},{\bm{u}_{h}}\right)_{h}

(32)

\displaystyle+\left({-\nabla_{-}\cdot\bm{v}_{h}},{p_{h}}\right)_{h}

\displaystyle+\left({\bm{\tau}_{h}+\nabla_{-}\bm{v}_{h}},{\bm{\sigma}_{h}}\right)_{h}

Let
\mathcal{V}_{h}=\mathcal{U}_{h}
with a different norm:
\left\|{v_{h}}\right\|_{\mathcal{V}_{h}}^{2}=\left\|{v_{h}}\right\|_{h}^{2}+\left\|{A^{\prime}v_{h}}\right\|_{\mathcal{U}_{h}^{\prime}}^{2}
,
where
\left\|{A^{\prime}v_{h}}\right\|_{\mathcal{U}_{h}^{\prime}}=\sup_{u_{h}\in\mathcal{U}_{h},\left\|{u_{h}}\right\|_{h}=1}\left|\langle A^{\prime}v_{h},u_{h}\rangle\right|

is the dual norm.
We will henceforth understand
A
and
A^{\prime}
as
mappings
A\colon\mathcal{U}_{h}\to\mathcal{V}_{h}^{\prime}
and
A^{\prime}\colon\mathcal{V}_{h}\to\mathcal{U}_{h}^{\prime}
, respectively.

Theorem 3.1

There exists a constant
\gamma>0
,
independent of
N
,
such that

\sup_{\begin{subarray}{c}v_{h}\in\mathcal{V}_{h}\\
v_{h}\neq 0\end{subarray}}\frac{a(u_{h},v_{h})}{\ \ \ \left\|{v_{h}}\right\|_{\mathcal{V}_{h}}}=\gamma\left\|{u_{h}}\right\|_{\mathcal{U}_{h}}\quad\forall u_{h}\in\mathcal{U}_{h}

(33)

To prove this theorem, we need some auxiliary results.

Lemma 7

Operator
A^{\prime}
is an isomorphism.

Proof

Since we are dealing with finite-dimensional spaces,
it is enough to show injectivity.
Suppose
A^{\prime}v_{h}=0
for some
v_{h}=(\bm{v}_{h},\bm{\tau}_{h},q_{h})
.
Then
\bm{\tau}_{h}=-\nabla_{-}\bm{v}_{h}
,
and applying
A^{\prime}v_{h}
to
(\bm{v}_{h},\bm{0},0)
we obtain

\displaystyle 0

\displaystyle=\left({-\nabla_{+}\cdot\bm{\tau}_{h}},{\bm{v}_{h}}\right)_{h}-\left({\nabla_{+}q_{h}},{\bm{v}_{h}}\right)_{h}

(34)

\displaystyle=\left({\bm{\tau}_{h}},{\nabla_{-}\bm{v}_{h}}\right)_{h}+\left({q_{h}},{\nabla_{-}\cdot\bm{v}_{h}}\right)_{h}

\displaystyle=\left({-\nabla_{-}\bm{v}_{h}},{\nabla_{-}\bm{v}_{h}}\right)_{h}+0

\displaystyle=-\left\|{\bm{v}_{h}}\right\|_{\nabla,h}^{2}

so
\bm{v}_{h}=0
and
\bm{\tau}_{h}=-\nabla_{-}\bm{v}_{h}=0
.
Finally, by
lemma

6
, there exists
\bm{u}_{h}\in D_{0,h}^{2}

such that
\nabla_{-}\cdot\bm{u}_{h}=q_{h}
,
so
\left\|{q_{h}}\right\|_{h}^{2}=\left({q_{h}},{q_{h}}\right)_{h}=\left({q_{h}},{\nabla_{-}\cdot\bm{u}_{h}}\right)_{h}=-\left({\nabla_{+}q_{h}},{\bm{u}_{h}}\right)_{h}
.
But since
\bm{\tau}_{h}=0
, we have
-\left({\nabla_{+}q_{h}},{\bm{u}_{h}}\right)_{h}=\left({-\nabla_{+}\cdot\bm{\tau}_{h}-\nabla_{+}q_{h}},{\bm{u}_{h}}\right)_{h}=0

and so
q_{h}=0
.
∎

Lemma 8
(Discrete Babuška-Aziz inequality)

There exists a constant
\beta>0
,
independent of
N
,
such that

\sup_{\begin{subarray}{c}\bm{u}_{h}\in V_{h}\\
\bm{u}_{h}\neq 0\end{subarray}}\frac{\left({\nabla_{-}\cdot\bm{u}_{h}},{p_{h}}\right)_{h}}{\left\|{\bm{u}_{h}}\right\|_{\nabla,h}}\geq\beta\left\|{p_{h}}\right\|_{h}

(35)

for every
p_{h}\in P_{h}
.

Lemma 9

Let
q_{h}\in P_{h}
.
There exists
\bm{v}_{h}\in V_{h}

such that

\nabla_{-}\cdot\bm{v}_{h}=q_{h}

(36)

and
\left\|{\bm{v}_{h}}\right\|_{\nabla,h}\leq\beta^{-1}\left\|{q_{h}}\right\|_{h}

Proof

Let
\widehat{V_{h}}
denote the subspace of these
\bm{u}_{h}\in V_{h}

that satisfy
\nabla_{-}\cdot\bm{u}_{h}=0
.
We can decompose
V_{h}
as
V_{h}=\widehat{V_{h}}\oplus\widehat{V_{h}}^{\perp}
,
where
⟂
denotes orthogonal complement with respect to
\left({\cdot},{\cdot}\right)_{\nabla,h}
.
Given
\bm{u}_{h}=\widehat{\bm{u}_{h}}+\bm{w}_{h}
,
\widehat{\bm{u}_{h}}\in\widehat{V_{h}}
,

\bm{w}_{h}\in\widehat{V_{h}}^{\perp}
we have for every
p_{h}\in P_{h}

\frac{\left|\left({\nabla_{-}\cdot\bm{u}_{h}},{p_{h}}\right)_{h}\right|}{\left\|{\bm{u}_{h}}\right\|_{\nabla,h}}=\frac{\left|\left({\nabla_{-}\cdot\bm{w}_{h}},{p_{h}}\right)_{h}\right|}{\sqrt{\left\|{\widehat{\bm{u}_{h}}}\right\|_{\nabla,h}^{2}+\left\|{\bm{w}_{h}}\right\|_{\nabla,h}^{2}}}\leq\frac{\left|\left({\nabla_{-}\cdot\bm{w}_{h}},{p_{h}}\right)_{h}\right|}{\left\|{\bm{w}_{h}}\right\|_{\nabla,h}^{2}}

(37)

so the supremum of the above expression over all
\bm{w}_{h}\in\widehat{V_{h}}^{\perp}

is the same as over all
\bm{v}_{h}\in V_{h}
.
Therefore, by the Babuška-Aziz inequality (
lemma

8
),

\sup_{\begin{subarray}{c}\bm{u}_{h}\in\widehat{V_{h}}^{\perp}\\
\bm{u}_{h}\neq 0\end{subarray}}\frac{\left({\nabla_{-}\cdot\bm{u}_{h}},{p_{h}}\right)_{h}}{\left\|{\bm{u}_{h}}\right\|_{\nabla,h}}\geq\left\|{p_{h}}\right\|_{h}

(38)

Let
b\colon\widehat{V_{h}}^{\perp}\times P_{h}\to\mathbb{R}
be a bilinear form
given by
b(\bm{u}_{h},p_{h})=\left({\nabla_{-}\cdot\bm{u}_{h}},{p_{h}}\right)_{h}
.
We have a pair of adjoint operators:

\displaystyle B

\displaystyle\colon\widehat{V_{h}}^{\perp}\to P_{h}^{\prime},

\displaystyle\langle B\bm{v}_{h},p_{h}\rangle

\displaystyle=\left({\nabla_{-}\cdot\bm{u}_{h}},{p_{h}}\right)_{h}

(39)

\displaystyle B^{\prime}

\displaystyle\colon P_{h}\to(\widehat{V_{h}}^{\perp})^{\prime},

\displaystyle\langle B^{\prime}p_{h},\bm{v}_{h}\rangle

\displaystyle=-\left({\bm{u}_{h}},{\nabla_{+}p_{h}}\right)_{h}

Equation

38
is equivalent to the statement
that
B^{\prime}
satisfies the inf-sup condition
with constant
\beta
,
that is
\left\|{B^{\prime}p_{h}}\right\|_{V_{h}^{\prime}}\geq\beta\left\|{p_{h}}\right\|_{h}
.
Since
B
is injective and
B^{\prime}
is bounded below,
by Theorem 1 of
[
5
]
,

B
is bounded below with the same constant,
and by the Babuška Theorem,
problem
B\bm{v}_{h}=q_{h}
has a unique solution satisfying
\left\|{\bm{v}_{h}}\right\|_{\nabla,h}\leq\beta^{-1}\left\|{q_{h}}\right\|_{h}
.
∎

Lemma 10

There exists
\alpha>0
,
independent of
N
,
such that
\left\|{A^{\prime}v_{h}}\right\|_{\mathcal{U}_{h}^{\prime}}\geq\alpha\left\|{v_{h}}\right\|_{h}

for all
v_{h}\in\mathcal{V}_{h}
.

Proof

Let
\mathcal{V}_{h}\ni v_{h}=(\bm{v}_{h},\bm{\tau}_{h},q_{h})

and
A^{\prime}v_{h}=f
.
We can decompose
f\in\mathcal{U}_{h}^{\prime}

as
\langle f,u_{h}\rangle=\left({\bm{f}},{\bm{u}_{h}}\right)_{h}+\left({\bm{h}},{\bm{\sigma}_{h}}\right)_{h}+\left({g},{p_{h}}\right)_{h}

for
\bm{f}\in V_{h}
,
\bm{h}\in S_{h}
and
g\in P_{h}
.
Since
A^{\prime}
is an isomorphism by
lemma

7
,
there exist
v_{h}^{\bm{f}},v_{h}^{\bm{h}},v_{h}^{g}\in\mathcal{V}_{h}

such that
\langle Av_{h}^{\bm{f}},u_{h}\rangle=\left({\bm{f}},{\bm{u}_{h}}\right)_{h}
,

\langle Av_{h}^{\bm{h}},u_{h}\rangle=\left({\bm{h}},{\bm{\sigma}_{h}}\right)_{h}
,
and
\langle Av_{h}^{g},u_{h}\rangle=\left({g},{p_{h}}\right)_{h}
.

Claim

\left\|{v_{h}^{\bm{f}}}\right\|_{h}\leq C_{1}\left\|{\bm{f}}\right\|_{h}

for some constant
C_{1}>0
,
independent of
N
.

Let
v_{h}^{\bm{f}}=\left(\bm{v}_{h}^{\bm{f}},\bm{\tau}_{h}^{\bm{f}},q_{h}^{\bm{f}}\right)
.
We have
\bm{\tau}_{h}^{\bm{f}}+\nabla_{-}\cdot\bm{v}_{h}^{\bm{f}}=0
,
so
\nabla_{+}\cdot\bm{\tau}_{h}^{\bm{f}}=-\Delta_{h}\bm{v}_{h}^{\bm{f}}

and thus

\left({-\Delta_{h}\bm{v}_{h}^{\bm{f}}-\nabla_{+}q_{h}^{\bm{f}}},{\bm{u}_{h}}\right)_{h}=\left({\bm{f}},{\bm{u}_{h}}\right)_{h}

(40)

for all
\bm{u}_{h}\in V_{h}
.
Putting
\bm{u}_{h}=\bm{v}_{h}^{\bm{f}}
in the above equation we get

\left({-\Delta_{h}\bm{v}_{h}^{\bm{f}}},{\bm{v}_{h}^{\bm{f}}}\right)_{h}-\left({\nabla_{+}q_{h}^{\bm{f}}},{\bm{v}_{h}^{\bm{f}}}\right)_{h}=\left({\bm{f}},{\bm{v}_{h}^{\bm{f}}}\right)_{h}.

(41)

Integrating the first term by parts
and noting that

-\left({\nabla_{+}q_{h}^{\bm{f}}},{\bm{v}_{h}^{\bm{f}}}\right)_{h}=\left({q_{h}^{\bm{f}}},{\nabla_{-}\cdot\bm{v}_{h}^{\bm{f}}}\right)_{h}=0

(42)

we get

\left\|{\bm{v}_{h}^{\bm{f}}}\right\|_{\nabla,h}^{2}=\left\|{\nabla_{+}\bm{v}_{h}^{\bm{f}}}\right\|_{h}^{2}=\left({\bm{f}},{\bm{v}_{h}^{\bm{f}}}\right)_{h}\leq\left\|{\bm{f}}\right\|_{h}\left\|{\bm{v}_{h}^{\bm{f}}}\right\|_{h}.

(43)

Let
K
be the discrete Poincaré constant from Lemma
2.1
.
Then

\left\|{\bm{v}_{h}^{\bm{f}}}\right\|_{\nabla,h}^{2}\leq\left\|{\bm{f}}\right\|_{h}\left\|{\bm{v}_{h}^{\bm{f}}}\right\|_{h}\leq K\left\|{\bm{f}}\right\|_{h}\left\|{\bm{v}_{h}^{\bm{f}}}\right\|_{\nabla,h}

(44)

so
\left\|{\bm{v}_{h}^{\bm{f}}}\right\|_{\nabla,h}\leq K\left\|{\bm{f}}\right\|_{V_{h}^{\prime}}
.
Since
\bm{\tau}_{h}^{\bm{f}}=-\nabla_{-}\cdot\bm{v}_{h}^{\bm{f}}
,
we have
\left\|{\bm{\tau}_{h}^{\bm{f}}}\right\|_{h}=\left\|{\bm{v}_{h}^{\bm{f}}}\right\|_{\nabla,h}\leq K\left\|{\bm{f}}\right\|_{h}
.
Furthermore,
\left\|{\bm{v}_{h}^{\bm{f}}}\right\|_{h}\leq K\left\|{\bm{v}_{h}^{\bm{f}}}\right\|_{\nabla,h}\leq K^{2}\left\|{\bm{f}}\right\|_{h}
.
As for
q_{h}^{\bm{f}}
, from
eq.

40
for every
\bm{u}_{h}\in V_{h}
we have

-\left({\nabla_{+}q_{h}^{\bm{f}}},{\bm{u}_{h}}\right)_{h}=\left({\Delta_{h}\bm{v}_{h}^{\bm{f}}},{\bm{u}_{h}}\right)_{h}+\left({\bm{f}},{\bm{u}_{h}}\right)_{h}.

(45)

Integrating by parts we get

\displaystyle\left({q_{h}^{\bm{f}}},{\nabla_{-}\cdot\bm{u}_{h}}\right)_{h}

\displaystyle=-\left({\nabla_{+}\bm{v}_{h}^{\bm{f}}},{\nabla_{+}\bm{u}_{h}}\right)_{h}+\left({\bm{f}},{\bm{u}_{h}}\right)_{h}

(46)

\displaystyle\leq\left\|{\bm{v}_{h}^{\bm{f}}}\right\|_{\nabla,h}\left\|{\bm{u}_{h}}\right\|_{\nabla,h}+\left\|{\bm{f}}\right\|_{h}\left\|{\bm{u}_{h}}\right\|_{h}

\displaystyle\leq 2K\left\|{\bm{f}}\right\|_{h}\left\|{\bm{u}_{h}}\right\|_{\nabla,h}.

Using the discrete Babuška-Aziz inequality (
lemma

8
)
we get

\left\|{q_{h}^{\bm{f}}}\right\|_{h}\leq\beta^{-1}\sup_{\begin{subarray}{c}\bm{u}_{h}\in V_{h}\\
\bm{u}_{h}\neq 0\end{subarray}}\frac{\left({q_{h}^{\bm{f}}},{\nabla_{-}\cdot\bm{u}_{h}}\right)_{h}}{\left\|{\bm{u}_{h}}\right\|_{\nabla,h}}\leq 2K\beta^{-1}\left\|{\bm{f}}\right\|_{h}.

(47)

Putting together upper bounds of
\bm{v}_{h}^{\bm{f}}
,
\bm{\tau}_{h}^{\bm{f}}
and
q_{h}^{\bm{f}}

provides a bound of
v_{h}^{f}
and proves the claim.
∎

Claim

\left\|{v_{h}^{\bm{h}}}\right\|_{h}\leq C_{2}\left\|{\bm{h}}\right\|_{s_{h}^{\prime}}

for some constant
C_{2}>0
,
independent of
N
.

We have
\bm{\tau}_{h}^{\bm{h}}=-\nabla_{-}\bm{v}_{h}^{\bm{h}}+\bm{h}
, so

\left({-\Delta_{h}\bm{v}_{h}^{\bm{h}}},{\bm{u}_{h}}\right)_{h}-\left({\nabla_{+}q_{h}^{\bm{h}}},{\bm{u}_{h}}\right)_{h}=\left({\nabla_{+}\cdot\bm{h}},{\bm{u}_{h}}\right)_{h}.

(48)

Letting
\bm{u}_{h}=\bm{v}_{h}^{\bm{h}}
and integrating by parts, we obtain

\left({\nabla_{+}\bm{v}_{h}^{\bm{h}}},{\nabla_{+}\bm{v}_{h}^{\bm{h}}}\right)_{h}+\left({q_{h}^{\bm{h}}},{\nabla_{-}\cdot\bm{v}_{h}^{\bm{h}}}\right)_{h}=-\left({\bm{h}},{\nabla_{-}\bm{v}_{h}^{\bm{h}}}\right)_{h}.

(49)

Since
\left({q_{h}^{\bm{h}}},{\nabla_{-}\cdot\bm{v}_{h}^{\bm{h}}}\right)_{h}=0
, we are left with

\left\|{\bm{v}_{h}^{\bm{h}}}\right\|_{\nabla,h}^{2}=-\left({\bm{h}},{\nabla_{-}\bm{v}_{h}^{\bm{h}}}\right)_{h}\leq\left\|{\bm{h}}\right\|_{h}\left\|{\bm{v}_{h}^{\bm{h}}}\right\|_{\nabla,h},

so
\left\|{\bm{v}_{h}^{\bm{h}}}\right\|_{\nabla,h}\leq\left\|{\bm{h}}\right\|_{h}

This implies
\left\|{\bm{v}_{h}^{\bm{h}}}\right\|_{h}\leq K\left\|{\bm{h}}\right\|_{h}

\left\|{\bm{\tau}_{h}^{\bm{h}}}\right\|_{h}=\left\|{\nabla_{-}\bm{v}_{h}^{\bm{h}}+\bm{h}}\right\|_{h}\leq\left\|{\nabla_{-}\bm{v}_{h}^{\bm{h}}}\right\|_{h}+\left\|{\bm{h}}\right\|_{h}\leq(1+K)\left\|{\bm{h}}\right\|_{h}.

(51)

Bound for

can be establish in the same way as the one for

.
For every

\displaystyle\left({q_{h}^{\bm{h}}},{\nabla_{-}\cdot\bm{u}_{h}}\right)_{h}

\displaystyle=-\left({\nabla_{+}\bm{v}_{h}^{\bm{h}}},{\nabla_{+}\bm{u}_{h}}\right)_{h}-\left({\bm{h}},{\nabla_{-}\bm{u}_{h}}\right)_{h}

\displaystyle\leq\left\|{\bm{v}_{h}^{\bm{h}}}\right\|_{\nabla,h}\left\|{\bm{u}_{h}}\right\|_{\nabla,h}+\left\|{\bm{h}}\right\|_{h}\left\|{\bm{u}_{h}}\right\|_{\nabla,h}

and thus by

\left\|{q_{h}^{\bm{h}}}\right\|_{h}\leq\beta^{-1}\sup_{\begin{subarray}{c}\bm{u}_{h}\in V_{h}\\

Claim

\left\|{v_{h}^{g}}\right\|_{h}\leq C_{3}\left\|{g}\right\|_{h}

, there exists

Let
\bm{w}_{h}=\bm{v}_{h}^{g}-\bm{v}_{h}^{0}
,

\nabla_{-}\cdot\bm{w}_{h}=0

\bm{\tau}_{h}^{g}+\nabla_{-}\bm{w}_{h}=-\nabla_{-}\bm{v}_{h}^{0}

\displaystyle\left\|{v_{h}^{g}}\right\|_{h}

\displaystyle=\left\|{\widetilde{w}_{h}+(\bm{v}_{h}^{0},\bm{0},0)}\right\|_{h}

\displaystyle\leq\underbrace{3\max\{C_{1},C_{2},C_{3}\}^{2}}_{\alpha^{-2}}\left(\left\|{\bm{f}}\right\|_{h}^{2}+\left\|{\bm{h}}\right\|_{h}^{2}+\left\|{g}\right\|_{h}^{2}\right)

\displaystyle=\alpha^{-2}\left\|{f}\right\|_{\mathcal{U}_{h}^{\prime}}^{2}

\displaystyle=\alpha^{-2}\left\|{A^{\prime}v_{h}}\right\|_{\mathcal{U}_{h}}^{2}

,
\bm{g}
,

(of

6
Conclusions

We propose a Python framework for solving PDEs
using discrete variational formulations based on the CRVPINN method. The CRVPINN method employs robust discrete loss function that is related with the true error.
Its goal is to facilitate building the matrices and right-hand side vectors
of such formulations by providing an intuitive, clean, concise, and convenient syntax
for defining weak variational forms,
inspired by FEniCS and the Unified Form Language.
It allows rapid prototyping of new formulations,
and integrates easily into a larger scientific computation ecosystem.
Its use alongside the PyTorch framework is illustrated on two PDEs –
a simple Laplace problem with uniform Dirichlet conditions,
and a more complex Stokes formulation,
showcasing tensor and composite function spaces.
In both cases, the mathematical formulation can be naturally translated
into code, even for relatively complex forms,
such as the ones encountered in the Stokes problem.
The numerical results demonstrate that the method
is capable of delivering accurate results
in a reasonable number of training epochs,
while providing a reliable and efficient error estimate in the form of its loss function.
