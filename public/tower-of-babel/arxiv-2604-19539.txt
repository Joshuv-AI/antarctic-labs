An effective window framework for closed-Loop regional SAR reconnaissance with hybrid direct-relay downlink scheduling
Linhong Li, Qi Feng, Kebo Li, Yangang Liang

Abstract
Regional synthetic aperture radar (SAR) reconnaissance depends on more than geometric visibility alone. An executable observation must simultaneously satisfy geometric feasibility, image quality constraints, and timely data delivery within the mission horizon. This paper develops an effective window framework for regional SAR window generation, per window signal level quality screening, and hybrid direct-relay closed loop scheduling. Through coarse angular bandpass screening, a planar characteristic curve containment test, and one dimensional boundary bisection, the framework forms geometry feasible candidate observation windows with millisecond-level accuracy for their entry and exit times. Each candidate window is then assessed in stripmap mode with a companion point target under a unified echo generation and Back Projection (BP) imaging workflow; only windows whose range and azimuth impulse response width (IRW), peak sidelobe ratio (PSLR), and integrated sidelobe ratio (ISLR) all satisfy the preset thresholds are retained. The retained observation, relay, and downlink windows feed a quality constrained hybrid direct-relay closed-loop mixed-integer linear programming (MILP) formulation for joint scheduling of observation and ground return. Numerical experiments demonstrate that the proposed framework unifies STK consistent millisecond level window accuracy and explicit per window quality constraints within one hybrid closed loop scheduling model, and that this model improves closure performance and ground returned data volume relative to a relay only baseline.

Introduction

Time critical reconnaissance, disaster response, maritime surveillance, and persistent monitoring
continue to increase the demands placed on synthetic aperture radar (SAR) acquisition and data return.
As mission assessment shifts from the simple question of whether a target is visible to the broader
question of whether useful information can be formed and delivered in time, the value of an imaging
activity increasingly depends on target illuminability, focused image quality, and ground delivery
within the admissible mission horizon. From this perspective, a geometrically visible interval is
only a potential opportunity rather than an executable observation window. For side looking SAR,
incidence, squint, and dwell constraints further compress the geometrically visible arcs, and
geometric accessibility alone does not guarantee interpretable imagery. At the same time, the
mission is not complete until the acquired data reach a ground station through either a direct
path or a relay assisted path. Regional SAR scheduling is therefore governed jointly by visibility,
image quality, and data return. These coupled requirements call for a unified framework that can
both generate candidate SAR observation windows efficiently and coordinate observation, relay, and
downlink decisions within one closed-loop model. Guided by this viewpoint, the literature reviewed
below is organized along three related axes: satellite observation and downlink scheduling, rapid view field and window generation, and per window signal level quality evaluation.

Per window image quality evaluation has received far less attention in the scheduling literature. Standard signal processing references establish impulse response width (IRW), peak sidelobe ratio (PSLR), and integrated sidelobe ratio (ISLR) as canonical point target figures of merit for spaceborne SAR

Most scheduling models treat all geometry feasible windows as interchangeable tasks with a single profit coefficient, and they do not test whether the focused image meets a prescribed quality standard. A per window quality screening layer anchored in IRW, PSLR, and ISLR is still missing from the closed-loop scheduling pipeline.

To address these gaps, this paper develops an effective window framework for regional SAR scheduling. The framework couples a hybrid direct-relay closed-loop optimization model with a three stage window construction chain and per window signal level quality screening. Window generation follows angular bandpass screening, a planar characteristic curve containment test, and one dimensional boundary bisection. Side looking SAR admissibility is enforced throughout the preprocessing chain. Each geometry feasible window is then evaluated by a companion point target stripmap simulation under a unified echo generation and Back Projection (BP) workflow, and only windows satisfying the prescribed range and azimuth IRW, PSLR, and ISLR criteria are retained for optimization.

The main contributions of this paper are as follows:

1.

A hybrid direct-relay closed-loop MILP model for regional SAR reconnaissance. Direct downlink and relay assisted downlink are optimized jointly under shared observation, communication, and latency constraints, and mission value is attached to completed request closure.

2.

A three stage fast effective window construction procedure for regional targets under side looking SAR admissibility. The procedure combines angular bandpass screening, a planar characteristic curve containment test, and one dimensional boundary bisection.

3.

A per window signal level quality screening procedure. A companion point target is generated and evaluated under a unified echo generation model and Back Projection (BP) imaging workflow; range and azimuth IRW, PSLR, and ISLR are then used to retain only windows with acceptable focusing quality before scheduling.

2
Hybrid Direct and Relay Satellite Downlink Model

This section formulates the exact scheduling model for the reconnaissance mission. The implementation pipeline runs from available window generation to per window signal level quality evaluation and then to exact scheduling, but the hybrid closed-loop MILP is presented first because it defines the closure relations that the preprocessing pipeline must satisfy. Its inputs are four families of candidate windows, and its outputs are the exact start times and execution durations of the selected windows. Window generation and imaging quality assessment are introduced in Section
3
.

2.1
Mission and Task Description

The mission considered in this paper is not adequately described as a simple collection of visible imaging opportunities. As illustrated in Fig.
1
, mission completion depends on three tightly coupled components: a target set defining the observation demand, an observation resource layer determining effective observability under SAR imaging constraints, and a communication resource layer determining whether the acquired data reach the ground within the admissible latency. Accordingly, this paper is limited to regional SAR imaging of stationary targets under hybrid ground return and does not address the additional dynamics and coupling relations introduced by mission mixes involving movers or heterogeneous payloads.

2.1.1
Observation and Communication Resources

The observation resource layer is the set
S

A geometrically visible interval does not directly imply an observation opportunity usable for the mission, and SAR specific physical admissibility conditions must be evaluated for each candidate window. The communication resource layer comprises the set
R

G

[0,H]

j\in J

\mathcal{G}_{j}
for each regional area of interest (AOI) on the Earth reference surface; Section
3
specifies how these boundaries enter window generation. Three task types jointly form the closure loop:

1.

Observation task
: an observation satellite
s\in S
images target
j\in J
in an effective observation window.

2.

Relay task
: an observation satellite
s\in S
transfers acquired data to a relay satellite
r\in R
.

3.

Downlink task
: a ground return is performed either by an observation satellite
s\in S
through direct downlink or by a relay satellite
r\in R
through relay downlink to a ground station
g\in G
.

The scheduler determines which targets are closed, which effective observation opportunities are selected, and how the resulting data are routed to the ground. This task decomposition induces four window families in the MILP: observation windows
K^{O}_{s,j}
, relay uplink windows
K^{R}_{s,r}
, relay downlink windows
K^{D}_{r,g}
, and direct downlink windows
K^{DG}_{s,g}
. Observation, relay, and downlink tasks all run without preemption within their assigned windows, and they are coupled through timing, storage, communication visibility, and platform conflicts.

2.1.2
Regional Targets and Mission Value

Each
j\in J
denotes one regional area of interest (AOI); the construction of effective observation windows from
\mathcal{G}_{j}
is detailed in Section
3
. A task is regarded as closed only when the acquired data are delivered to a ground station within
[0,H]
through a relay assisted chain or a direct downlink. When several AOIs compete for the same satellites or ground assets, relative priorities may be encoded by profit weights on targets.

2.3
Extended Hybrid Closed Loop Model

The mixed constellation reconnaissance problem admits two closed-loop return modes: direct downlink from the observation satellite to a ground station, or relay assisted downlink through an intermediate relay satellite. The closure model is extended to a hybrid direct-relay setting. A fourth family of candidate windows is introduced for direct downlink:

2.3.1
Modified Objective Function

In the hybrid model, relay hops are treated as intermediate transport rather than mission completion events. Accordingly, the objective
Z_{\mathrm{hybrid}}
is composed of observation reward, ground delivered data reward, complete offload reward on each observation satellite, and a weak preference for earlier ground delivery:

\begin{gathered}Z_{\mathrm{hybrid}}=\max[\alpha\sum_{s\in S}\sum_{j\in J}\sum_{k\in K^{O}_{s,j}}t^{\mathrm{Img}}\cdot x^{O}_{s,j,k}+\beta\sum_{s\in S}\sum_{g\in G}\sum_{k\in K^{DG}_{s,g}}p^{DG}_{s,g,k}+\beta\sum_{r\in R}\sum_{g\in G}\sum_{k\in K^{D}_{r,g}}p^{D}_{r,g,k}+\\
\gamma\sum_{s\in S}c_{s}-\delta\sum_{s\in S}\sum_{g\in G}\sum_{k\in K^{DG}_{s,g}}\frac{i^{DG}_{s,g,k}}{T_{\max}}\,p^{DG}_{s,g,k}-\delta\sum_{r\in R}\sum_{g\in G}\sum_{k\in K^{D}_{r,g}}\frac{i^{D}_{r,g,k}}{T_{\max}}\,p^{D}_{r,g,k}],\end{gathered}

(26)

where the first term rewards completed observations, the second and third terms reward data delivered to ground stations by direct and relay downlink, the fourth term rewards full inventory closure on each observation satellite, and the final two terms assign a weak preference to earlier downlink opportunities;

,

,
\gamma
, and

3
Effective Window Closed-Loop Scheduling for Regional SAR Reconnaissance

This section presents the effective window construction method for regional SAR tasks. The procedure consists of two stages: rapid discretization of continuous time visibility into candidate observation windows, and geometry dependent quality evaluation together with threshold based filtering for effective window formation.

3.1
Rapid discretization of continuous time visibility into candidate windows

Under a SAR field of view description aligned with the Systems Tool Kit (STK) side looking payload model, continuous time regional visibility is sampled and screened into a sparse set of candidate observation windows. The procedure combines a coarse geometric filter that retains orbit arcs with potential target intersection and a projection plane refinement that determines the entry and exit times of each candidate window.

3.2
Geometry Dependent Imaging Quality Evaluation and Window Filtering

The coarse-to-fine geometric screening in the preceding subsection yields
geometry-feasible candidate windows. In regional stripmap imaging, however,
viewing geometry, and therefore focusing quality and achievable resolution,
varies from window to window, so these opportunities are not equivalent scheduling
tasks and should not be treated as interchangeable. Signal-level SAR simulation
quantifies performance on each candidate window and yields physically grounded
scheduling constraints.

3.2.1
Key geometric parameters governing imaging quality

A side looking stripmap acquisition mode is assumed throughout this work. The antenna boresight is fixed relative to the platform and the ground swath is illuminated continuously as the satellite advances along its orbit. Under this configuration, the imaging performance of each candidate window is primarily governed by four geometric parameters. Since these quantities have already been defined in Section
3.1.1
, only their quality implications are summarized here.

The incidence angle
\theta_{\mathrm{inc}}
, related to the ground point elevation angle by Eq. (
53
), controls the projection from slant range to ground range resolution:

\delta_{r}=\frac{c}{2B},\qquad\delta_{g}=\frac{\delta_{r}}{\sin\theta_{\mathrm{inc}}},

(73)

where
c
is the speed of light in vacuum,
B
is the transmitted chirp bandwidth,
\delta_{r}
is the slant range resolution,
\delta_{g}
is the ground range resolution, and
\theta_{\mathrm{inc}}
is the incidence angle. Larger incidence angles lead to coarser ground range resolution for the same radar hardware. The squint angle
\theta_{\mathrm{sq}}
, related to the Doppler cone angle
\theta_{\mathrm{DC}}
in Eq. (
59
), governs Doppler centroid behavior and range azimuth coupling in stripmap imaging. Larger squint magnitudes imply less favorable focusing conditions. The slant range
R
, defined as the Euclidean distance from the satellite position to the target ECEF position at the window midpoint, affects both propagation loss and apparent target angular motion. For a fixed platform speed, a larger slant range yields a narrower Doppler bandwidth and therefore a broader azimuth mainlobe. Finally, the dwell time, defined as the duration over which the target remains within the azimuth beam footprint, bounds the theoretical azimuth resolution through

\delta_{a}=\frac{L_{a}}{2},

(74)

where
L_{a}
is the physical antenna length, and approaching this bound requires a coherent integration time at least as long as the prescribed minimum dwell. These geometric interpretations follow standard SAR imaging principles
[
44
,
45
]
.

The geometric quantities above are evaluated at the temporal midpoint of each candidate window using the same SGP4 orbit propagator and ECEF coordinate transformations introduced in Section
3.1.1
. The echo generation, focusing algorithm, and point target analysis procedures follow established SAR signal processing methodology. The frequency domain echo model and BP focusing approach are described in detail in
[
46
,
47
]
.

3.2.2
Quality evaluation indicators and effective imaging time

Each candidate window is assigned a companion point target for imaging quality evaluation. A unit reflectivity scatterer is placed at the geodetic center of the target region, mapped to ECEF coordinates, and evaluated with the same orbit parameters, observation geometry, echo generation model, and BP imaging process as the area scene. The azimuth pulse count
N_{a}
is the ceiling of the product of the pulse repetition frequency and the candidate window duration, clipped between preset minimum and maximum pulse counts to keep the simulation tractable while the coherent aperture remains substantially longer than the minimum dwell required for coarse screening. The range sample count
N_{r}
uses the same fast-time record length for echo synthesis of the companion point and of the regional area patch. Let
h
denote the focused impulse response in either the range or the azimuth direction through the peak, normalized to unit peak amplitude. The mainlobe is the central portion bounded by the first nulls, and the sidelobe region comprises the remainder of the profile. Three indicators are defined as follows.

1.

The impulse response width
W_{\mathrm{IRW}}

-3

Formally,

W_{\mathrm{IRW}}=\Delta x_{-3\,\mathrm{dB}}.

(75)

2.

The peak sidelobe ratio
W_{\mathrm{PSLR}}

Formally,

W_{\mathrm{PSLR}}=\frac{\max_{\text{sidelobe}}|h|^{2}}{\max_{\text{mainlobe}}|h|^{2}}.

(76)

The integrated sidelobe ratio

Formally,

(77)

\delta_{g}
and

are used here as interpretable geometric descriptors, whereas IRW, PSLR, and ISLR serve as the final quality indicators at the signal level.

3.3
From effective windows to MILP candidate sets

The preceding two subsections cover the observation leg of the preprocessing chain:
Section 3.1 discretizes continuous-time regional visibility into geometry-feasible
candidate observation windows, and Section 3.2 evaluates imaging quality
and applies threshold-based filtering to build the effective observation
window set. This subsection turns to the communication leg: it generates
the communication windows from communication visibility, assembles them
with the effective observation windows into the four candidate window families
required by the hybrid MILP in Section
2
, and thereby closes
the main preprocessing chain. Finally, supplementary preprocessing is applied to
the assembled families before they are passed to the solver.

3.3.2
Post Generation Window Processing

Before the four candidate window classes enter the hybrid MILP solver, two complementary screening stages are applied. The first is a duration screening on observation windows. The second is a reachability screening on communication windows. The duration screening removes observation windows that are too short to support one complete SAR acquisition. The reachability screening removes relay uplink, relay downlink, and direct downlink windows that cannot participate in any feasible closure path. The resulting inputs remain consistent with both physical visibility and mission requirements. The duration criterion is applied independently to each observation window and retains it only when its effective duration is no less than the minimum SAR acquisition time:

d^{O}_{s,j,k}-i^{O}_{s,j,k}\;\geq\;t^{\mathrm{Img}},

(84)

where
i^{O}_{s,j,k}
and
d^{O}_{s,j,k}
are the opening and closing epochs of observation window
k\in K^{O}_{s,j}
produced by Algorithm
3.1.3
, and
t^{\mathrm{Img}}
is the minimum imaging time required for one complete acquisition. Any window violating this inequality is removed before optimization, since selecting it would necessarily render the schedule infeasible.

The reachability criterion enforces causal order along the relay assisted path from observation to relay uplink and then to relay downlink. A relay uplink window
k_{2}\in K^{R}_{s,r}
is retained only when it admits at least one preceding observation and at least one downstream relay downlink to a ground station:

\exists\;k_{1}\in K^{O}_{s,j},\;\;j\in J,\quad k_{3}\in K^{D}_{r,g},\;\;g\in G,\quad\text{s.t.}\quad d^{O}_{s,j,k_{1}}\;\leq\;i^{R}_{s,r,k_{2}}\;\text{ and }\;d^{R}_{s,r,k_{2}}\;\leq\;i^{D}_{r,g,k_{3}},

(85)

where
d^{O}_{s,j,k_{1}}
is the closing epoch of a preceding observation window,
i^{R}_{s,r,k_{2}}
and
d^{R}_{s,r,k_{2}}
are the opening and closing epochs of the relay uplink window under consideration, and
i^{D}_{r,g,k_{3}}
is the opening epoch of a subsequent relay downlink window. A direct downlink window
k_{2}\in K^{DG}_{s,g}
is retained under the analogous requirement that at least one preceding observation window exists on the same satellite:

\exists\;k_{1}\in K^{O}_{s,j},\;\;j\in J,\quad\text{s.t.}\quad d^{O}_{s,j,k_{1}}\;\leq\;i^{DG}_{s,g,k_{2}}.

(86)

where
i^{DG}_{s,g,k_{2}}
is the opening epoch of the direct downlink window under consideration. Any communication window violating Eq. (
85
) or Eq. (
86
) is removed before optimization, because it cannot contribute to a feasible data return path in the hybrid MILP.

4
Experiments

This section presents experimental validation of the proposed framework. The experiments followed the method chain of the framework.
Experiment I
validated the hybrid mixed integer formulation on a controlled benchmark with prescribed feasible windows and focused on closed-loop scheduling performance under relay and direct downlink competition.
Experiment II
evaluated the first preprocessing stage by comparing the candidate window discretization procedure with an independent reference in terms of geometry feasible candidate window generation.
Experiment III
evaluated the second preprocessing stage by examining geometry dependent imaging quality assessment and the resulting effective window screening behavior.
Experiment IV
integrated the full pipeline, from effective window construction to hybrid MILP scheduling, in an operationally realistic scenario. All experiments were executed on a 64 bit Windows laptop with an Intel 12th Gen Core i9-12900H CPU (base frequency 2.5 GHz, 14 physical cores, 20 logical processors). The mixed integer linear programming layer of the scheduling formulation was implemented in C++ using Microsoft Visual Studio 2022, and the induced programs were solved with Gurobi 12.0. Satellite state propagation employed the SGP4 model. Rapid candidate window generation and geometry dependent per window quality analysis were implemented in Python 3.11.

5
Conclusion

This paper presents a unified effective window framework for regional SAR scheduling. The framework couples access analysis, image quality evaluation, and mission closure optimization in one pipeline. The method combines a hybrid direct-relay closed-loop MILP with regional window generation based on coarse angular screening, a planar characteristic curve containment test, and boundary bisection, together with per window signal level quality evaluation using a companion point target and six IRW, PSLR, and ISLR indicators. The experiments showed accurate recovery of reference windows, rejection of geometrically feasible but imaging inferior opportunities, and closed-loop scheduling at constellation scale under practical computational budgets. Regional SAR scheduling requires joint treatment of visibility, image quality, and data return.

Future work will extend the present SAR framework to more general heterogeneous observation scenarios. One direction is a unified effective window model for multiple payload types, especially optical sensors and radar sensors. The extension will need to incorporate illumination conditions, cloud sensitivity, viewing geometry, spatial resolution, and radar imaging modes. Another direction is dynamic target tracking. That problem requires joint treatment of target motion, state uncertainty, revisit demand, closed-loop replanning, payload assignment, and relay or downlink resource allocation.
