Byzantine Consensus in Directed Graphs with Message Authentication
Nitin H. Vaidya, Lewis Tseng

Abstract
. ABSTRACT: 1 1 1 Revised May 2026. This is a revised version of a manuscript prepared in February 2026. In particular, Lemma 5.7 and Table 2 are added, the Related Work section is revised, and some other minor edits have been made. We consider the problem of reaching consensus in communication networks that are modeled by directed graphs. We assume the existence of a message authentication mechanism (such as digital signatures) to verify the integrity of messages. We identify the necessary and sufficient conditions on the directed communication graph for the following problems to be solvable: (i) exact consensus in synchronous systems; and (ii) approximate consensus in asynchronous systems.

Introduction

Byzantine consensus is an important distributed primitive, and over forty years of research has been conducted on this problem
(
lamport_agreement
;
lamport_agreement2
;
dolev_82_BG
)
. In recent years, there has been work on Byzantine consensus in systems where the underlying network is modeled by a directed graph (e.g.,
(

(
Tseng_podc2015
;
Tseng_PODC20
)
, the necessary and sufficient conditions under message authentication were not previously established for directed graphs. This paper addresses this gap. We consider a distributed system under the following assumptions:

•

The communication network is modeled by a directed graph
G(V,E)
where each vertex in

represents a node in the distributed system, and each directed edge in

•

•

Up to

•

Each node

has a binary input (i.e., 0 or 1) denoted as

.

•

Each node
u\in V

.

•

A message authentication mechanism is available – in particular, we assume the availability of digital signatures using public-key cryptography
(

)
. With message authentication, a faulty node cannot tamper a message from a non-faulty node without the tampering being detectable.

In a synchronous system, a Byzantine consensus algorithm
(
lamport_agreement
;
lamport_agreement2
)
should satisfy the requirements below.

•

Termination
: each non-faulty node eventually outputs a value.

•

Validity
: the output at each non-faulty node must equal the input of some non-faulty node.

•

Agreement
: the outputs of the non-faulty nodes must be identical.

In an asynchronous system,
due to the FLP impossibility
(
FLP_one_crash
)

\epsilon

(

)
, with
\epsilon>0

•

Termination
: each non-faulty node eventually outputs a value.

•

Validity
: the output at each non-faulty node must be in the convex hull (or the range) of the inputs of the non-faulty nodes.

•

\epsilon
-agreement
: the outputs of the non-faulty nodes must be within
\epsilon
of each other.

(w,s)\in Y_{v}
at the end of step 2(i) in the deciding iteration.

•

Finally, observe that

can only contain values for the nodes in

The above three observations prove that

This proves the correctness of Algorithm

Sufficient Condition for Asynchronous Consensus

The goal in this section is to prove the sufficiency of the conditions for asynchronous consensus stated in Theorem

To prove the sufficiency of Condition A, let us assume that graph

Although in Section

The algorithm proceeds in asynchronous rounds, with rounds numbered 1, 2, 3, etc. Each node

The algorithm description below refers to three procedures: (a) Correctness check for a message, (b) Completeness check for set

The algorithm proceeds in asynchronous rounds.

Correctness of the Asynchronous Consensus Algorithm

Assume that graph
G(V,E)
satisfies Condition A described in Definition
B.1

Let

denote the actual set of faulty nodes in a given execution of the asynchronous algorithm. We will show that the asynchronous algorithm satisfies the termination, validity and
\epsilon
-agreement properties described in Section
1
for asynchronous algorithms.

Proof of the Termination Property:
We first show that the progress of a non-faulty node through each asynchronous round cannot be impeded by the faulty nodes. In particular, we show that, for each non-faulty node
v
, the completeness check in each round will be satisfied eventually.

•

Note that
S_{F^{*}}
contains only non-faulty nodes, since
S_{F^{*}}\subseteq V-F^{*}
by definition.

•

Now observe that Condition A is stronger than Condition S, and therefore, Lemma
5.4
holds under Condition A too. Lemma
5.4
implies that, each node in
S_{F^{*}}
has a path to every non-faulty node (including
the nodes in
S_{F^{*}}
), such that these paths do not include any faulty nodes as internal nodes.

•

The above property ensures that the completeness check can eventually pass at any non-faulty node
v
for
F_{v}=F^{*}
. In general, the completeness check may be satisfied sooner for some
F_{v}
different from
F^{*}
. Therefore, each non-faulty node will eventually complete any given asynchronous round. Thus, it will eventually complete
R_{max}
rounds, and select an output.

Proof of the Validity Property:
Consider any given round, and consider the update procedure used by a non-faulty node
v
for updating its state variable
s_{v}
in that round. Observe that the
\phi
nodes whose values are dropped in step I of the update procedure are necessarily faulty (because a non-faulty node sends only one state variable value in each round, and a faulty node cannot tamper messages signed by a non-faulty node).

After the completion of step I of the update procedure, each remaining value in
X_{v,v}
comes from a distinct node. If the
f-\phi
smallest values that are dropped from
X_{v,v}
in step II all come from faulty nodes, then the remaining values in
X_{v,v}
must all come from non-faulty nodes. Similar argument holds if the largest
f-\phi
values dropped in step II all come from faulty nodes.

On the other hand, in step II, if at least one of the smallest
f-\phi
values dropped comes from some non-faulty node, and at least one of the largest
f-\phi
values dropped comes from some non-faulty node, then every value remaining in
X_{v,v}
is within the range of these two values from non-faulty nodes.

In each case, the values used in computing new
s_{v}
in step III are within the range of the values received from non-faulty nodes in that round. Therefore, the new value of
s_{v}
is also within the range of the values received from non-faulty nodes in that round.

Now recall that the nodes send their current state variable values at the start of each given round. Also, at the start of round 1, the state variable value at each node is equal to the node’s input. Then applying the above argument inductively, we conclude that the validity property is satisfied by the outputs of the non-faulty nodes.

[m_{v},M_{v}]\subseteq[s_{min}(r),s_{max}(r)]
.

(6)

\displaystyle s_{u}(r+1)=\frac{M_{u}+m_{u}}{2}

(7)

\displaystyle s_{v}(r+1)=\frac{M_{v}+m_{v}}{2}

As shown earlier,
[m_{u},M_{u}]\cap[m_{v},M_{v}]\neq\emptyset
. This implies that

and

\displaystyle|s_{u}(r+1)-s_{v}(r+1)|

\displaystyle=

\displaystyle s_{u}(r+1)-s_{v}(r+1)\mbox{~~because $s_{v}(r+1)\leq s_{u}(r+1)$}

\displaystyle=

\displaystyle\frac{M_{u}+m_{u}}{2}-\frac{M_{v}+m_{v}}{2}

\displaystyle=

\displaystyle\frac{M_{u}-m_{v}}{2}-\frac{M_{v}-m_{u}}{2}

\displaystyle\leq

\displaystyle\frac{M_{u}-m_{v}}{2}\mbox{\hskip 7.22743ptbecause $M_{v}\geq m_{u}$, as noted above}

\displaystyle\leq

\displaystyle\frac{s_{max}(r)-s_{min}(r)}{2}

Thus, the range of the state variable values of the non-faulty nodes shrinks at least in half after each asynchronous round. Thus, after a sufficiently large number of rounds (which we call

Recall that we assume
f>0
. Now, for some set
F
and nodes
u,v
, if
|reach_{u}(F)\cap reach_{v}(F)|\geq f+1
, then

|reach_{u}(F)\cap reach_{v}(F)|\geq 1
.
Therefore, the definition of the 1-reach condition trivially implies the following order:

1-reach with
\rho=1

\Leftarrow
1-reach with
\rho=f+1

L.2.
Proof of “1-reach with
\rho=f+1

\Leftarrow
2-reach with
\rho=1
”

We will prove the contrapositive. Suppose that the graph
G(V,E)
does not satisfy 1-reach with
\rho=f+1
. Then there exists
F\subset V
,
|F|\leq f
and nodes
u,v\in V-F
such that
|reach_{u}(F)\cap reach_{v}(F)|\leq f
. We consider two cases:

•

(Case 1)
|reach_{u}(F)\cap reach_{v}(F)|=0
: Let us choose
F_{1}=F_{2}=F
. Then
u\in V-F_{1}
,
v\in V-F_{2}
, and
|reach_{u}(F_{1})\cap reach_{v}(F_{1})|=0
.
This violates the 2-reach condition with
\rho=1
.

•

(Case 2)
1\leq|reach_{u}(F)\cap reach_{v}(F)|\leq f
:
Let
X=reach_{u}(F)\cap reach_{v}(F)
. Then
X
is non-empty. Also, by the definition of the reach sets
X\subseteq V-F
.

Let us consider some node
w\in X
. If there is some node
z\in V-F-X
in
reach_{w}(F)
, then
z
has a path to
w
in
G_{F}
. This, in conjunction with the fact that
w\in X
, implies that
z
also has paths
u
and
v
both in
G_{F}
. Therefore,
z
must be in
reach_{u}(F)
and
reach_{v}(F)
both. Hence
z\in X
, which is a contradiction with
z\in V-F-X
. Thus, we can infer that
reach_{w}(F)\subseteq X
for
w\in X
, and
|reach_{w}(F)|\leq|X|\leq f
.

Let us define
F_{1}=F
and
F_{2}=reach_{w}(F)
. We can choose
F_{2}=reach_{w}(F)
because
|reach_{w}(F)|\leq f
. Observe that
w\in X\subseteq V-F=V-F_{1}
. Consider any node
y\in V-F_{2}
. Then
reach_{y}(F_{2})\subseteq V-F_{2}
, by the definition of a reach set. Since
F_{2}=reach_{w}(F)=reach_{w}(F_{1})
, we get
reach_{w}(F_{1})\cap reach_{y}(F_{2})\subseteq F_{2}\cap(V-F_{2})=\emptyset
. This violates the 2-reach condition with
\rho=1
.

In both cases above, the 2-reach condition with
\rho=1
is violated, proving the contrapositive.

L.3.
Proof of “2-reach with
\rho=1

\Leftarrow
2-reach with
\rho=f+1
”

Recall that we assume
f>0
. Now, for some sets
F_{1}
and
F_{2}
, and nodes
u,v
, if
|reach_{u}(F_{1})\cap reach_{v}(F_{2})|\geq f+1
, then

|reach_{u}(F_{1})\cap reach_{v}(F_{2})|\geq 1
.
Therefore, the definition of the 2-reach condition trivially implies the following order:

2-reach with
\rho=1

\Leftarrow
2-reach with
\rho=f+1

L.4.
Proof of “2-reach with
\rho=f+1

\Leftarrow
3-reach with
\rho=1
”

We will prove the contrapositive.
To prove this let us assume that the given graph violates the 2-reach condition with
\rho=f+1
. Therefore, there exist sets
F_{1},F_{2}\subseteq V
,
|F_{1}|,|F_{2}|\leq f
, and
u\in V-F_{1}
,
v\in V-F_{2}
such that
|reach_{u}(F_{1})\cap reach_{v}(F_{2})|\leq f
. For brevity, let us define
X=reach_{u}(F_{1})\cap reach_{v}(F_{2})
. Thus,
|X|\leq f
.

To simplify the presentation here, when a set contains a single element (e.g., set
\{u\}
), we will not write the curly brackets. For example,
X-\{u\}-\{v\}
will be written as
X-u-v
in the simplified notation, and
X\cup\{w\}
will be written as
X\cup w
.
In other words, when using the simplified notation,
X-u=\{x~|~x\in X\mbox{~and~}x\neq u\}
.

Recall that we assume
f>0
. We will consider four cases below, and in each case, define new sets
\mathbb{F}
,
\mathbb{F}_{1}
and
\mathbb{F}_{2}
, such that the newly defined sets will satisfy the following properties:

•

(Property 1)
|\mathbb{F}|,|\mathbb{F}_{1}|,|\mathbb{F}_{2}|\leq f

•

(Property 2)
u\in V-\mathbb{F}-\mathbb{F}_{1}
and
v\in V-\mathbb{F}-\mathbb{F}_{2}

•

(Property 3)
F_{1}\subseteq\mathbb{F}\cup\mathbb{F}_{1}
and
F_{2}\subseteq\mathbb{F}\cup\mathbb{F}_{2}

•

(Property 4)
\mathbb{F}\cup\mathbb{F}_{1}\cup\mathbb{F}_{2}=X\cup F_{1}\cup F_{2}

•

(Property 5)
reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})\cap reach_{v}(\mathbb{F}\cup\mathbb{F}_{2})=\emptyset

Now we enumerate the four cases (and sub-cases, when needed) and define the new sets. Note that, by definition,
u\in reach_{u}(F_{1})
and
v\in reach_{v}(F_{2})
. In each case, it is easy to see that the new sets satisfy properties 1 through 4 above. Later we will show that they satisfy property 5 as well. Recall that we assume
f>0
.

•

(Case 1)
u,v\not\in X
: Define
\mathbb{F}=X
,
\mathbb{F}_{1}=F_{1}
,
\mathbb{F}_{2}=F_{2}
.

•

(Case 2)
u\in X
and
v\not\in X
: Thus,
u\neq v
. There are two possibilities in this case.

(i)

F_{2}=\emptyset
: Define
\mathbb{F}=X-u
,
\mathbb{F}_{1}=F_{1}
, and
\mathbb{F}_{2}=\{u\}
.

(ii)

F_{2}\neq\emptyset
: Since
u\in X
and
X=reach_{u}(F_{1})\cap reach_{v}(F_{2})
,
u\in reach_{v}(F_{2})
. Recall that
v\in V-F_{2}
. Also, since
u\in reach_{v}(F_{2})
,
u\in V-F_{2}
. So
u,v\not\in F_{2}
, and since
F_{2}\neq\emptyset
, there must be some other node
w\in F_{2}
. Define
\mathbb{F}=(X-u)\cup w
,
\mathbb{F}_{1}=F_{1}
,
\mathbb{F}_{2}=(F_{2}-w)\cup u
.

•

(Case 3)
u\not\in X
and
v\in X
: This case is handled analogous to Case 2.

•

(Case 4)
u\in X
and
v\in X
: Here, similar to Case 2 above, we need to consider several possibilities.

(i)

F_{1}=F_{2}=\emptyset
: Define
\mathbb{F}=X-u-v
,
\mathbb{F}_{1}=\{v\}
, and
\mathbb{F}_{2}=\{u\}
.

(ii)

F_{1}=\emptyset
and
F_{2}\neq\emptyset
: Following an argument similar to that in Case 2(ii), there must be some node
w\in F_{2}
that is distinct from
u
and
v
. Define
\mathbb{F}=(X-u-v)\cup w
,
\mathbb{F}_{1}=\{v\}
, and
\mathbb{F}_{2}=(F_{2}-w)\cup u
.

(iii)

F_{1}\neq\emptyset
and
F_{2}=\emptyset
: This is handled analogous to case (ii) above.

(iv)

F_{1}\neq\emptyset
and
F_{2}\neq\emptyset
: Then, similar to case (ii), there must be nodes
w_{1}\in F_{1}
and
w_{2}\in F_{2}
such thar
w_{1}
and
w_{2}
are both distinct from
u
and
v
(however, it is possible that
w_{1}=w_{2}
). Define
\mathbb{F}=(X-u-v)\cup w_{1}\cup w_{2}
,
\mathbb{F}_{1}=(F_{1}-w_{1})\cup v
and
\mathbb{F}_{2}=(F_{2}-w_{2})\cup u
.

It is straightforward to verify that the sets
\mathbb{F},\mathbb{F}_{1},\mathbb{F}_{2}
defined in each case satisfy properties 1, 2, 3 and 4 listed above. Using properties 1 through 4, we now show that these sets satisfy property 5 as well.

•

Properties 1 and 2 allow us to define
reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})
and
reach_{v}(\mathbb{F}\cup\mathbb{F}_{2})
. By Property 3,
F_{1}\subseteq\mathbb{F}\cup\mathbb{F}_{1}
, therefore,
reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})\subseteq reach_{u}(F_{1})
. Similarly,
reach_{v}(\mathbb{F}\cup\mathbb{F}_{2})\subseteq reach_{u}(F_{2})
. Therefore,

(8)

\displaystyle reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})\cap reach_{v}(\mathbb{F}\cup\mathbb{F}_{2})

\displaystyle\subseteq

\displaystyle reach_{u}(F_{1})\cap reach_{v}(F_{2})

(9)

\displaystyle\Rightarrow reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})\cap reach_{v}(\mathbb{F}\cup\mathbb{F}_{2})

\displaystyle\subseteq

\displaystyle X

•

Now, by the definition of the reach sets,
reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})
is disjoint with
\mathbb{F}\cup\mathbb{F}_{1}
. Similarly,
reach_{v}(\mathbb{F}\cup\mathbb{F}_{2})
is disjoint with
\mathbb{F}\cup\mathbb{F}_{2}
. This implies that
reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})\cap reach_{v}(\mathbb{F}\cup\mathbb{F}_{2})
is disjoint with
\mathbb{F}\cup\mathbb{F}_{1}\cup\mathbb{F}_{2}
. Thus, by property 4,
reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})\cap reach_{v}(\mathbb{F}\cup\mathbb{F}_{2})
does not contain any nodes in
X\cup F_{1}\cup F_{2}
. Therefore,

(10)

\displaystyle(reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})\cap reach_{v}(\mathbb{F}\cup\mathbb{F}_{2}))\cap X

\displaystyle=

\displaystyle\emptyset

Equations
9
and
10
together imply that

reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})\cap reach_{v}(\mathbb{F}\cup\mathbb{F}_{2})=\emptyset
, proving Property 5. Since properties 1 through 4 hold in all the four cases enumerated earlier, Property 5 is also proved in all the cases. Property 5 implies that

|reach_{u}(\mathbb{F}\cup\mathbb{F}_{1})\cap reach_{v}(\mathbb{F}\cup\mathbb{F}_{2})|=0

Therefore, the 3-reach condition with
\rho=1
is violated, proving the contrapositive.
