A Parameterized Algorithm for Testing whether the Limit of a Diagram is Empty Thanks: CUNY CityTech Thanks: NIST
Ernst Althaus, Benjamin Merlin Bumpus, James Fairbanks

Abstract
A limit of a (small) diagram d : 𝒥 → ℰ d:\mathscr{J}\to\mathscr{E} in a complete category ℰ \mathscr{E} can be thought of as specifying a set of equations involving the objects of ℰ \mathscr{E} . To motivate this intuitively, one can think of each object d ⁡ ( j ) d(j) as a “variable” and each morphism in 𝒥 \mathscr{J} as a “constraint” connecting these variables. If ℰ \mathscr{E} has an initial object, a natural question arises: does our set of equations have any solution at all? Equivalently, we can ask: is the limit of d d initial? In this paper we consider the computational problem that, given finite diagram d d in a finitely complete category ℰ \mathscr{E} , asks whether its limit is empty. We construct a fast algorithm (in the sense of parameterized complexity theory) that solves this problem when ℰ \mathscr{E} is of the form 𝐅𝐢𝐧𝐒𝐞𝐭 𝒞 \mathbf{FinSet}^{\mathscr{C}} for a finite category 𝒞 \mathscr{C} and d d is a structured co-decomposition, i.e. a diagram arising from the opposite of the Grothendieck construction of a simple graph.

Many computational problems can be formulated as functors

Prior work

Hence the pipeline for computational problems we have in mind is as follows: Given some discrete structure

\mathscr{E}
, such as a graph or database, along with a computational problem

is equivalent to checking if
\lim(P\circ d)\cong\varnothing

By reformulating computational problems in this way, we can use the method of “divide and conquer” by checking if
(P\circ d)(x)\cong\varnothing
for each vertex

, and then combining the results. This results in a significantly faster algorithm than would usually be obtainable. Furthermore, this is an extremely general construction. For example, it applies to any computational problem

More formally, here we will understand a “fast algorithm” to mean

Theorem
4.9
.

Given a structured co-decomposition

and let

To appreciate our main result, consider first how one might naïvely solve

Finally, the proof of Theorem

First let us note that

if and only if

Given a structured co-decomposition

\textsc{InLim}(\mathop{\raisebox{0.86108pt}{$\smallint\!\!$}}G^{\text{op}},\mathbf{FinSet})
in time

Proof.

Let us present the algorithm as follows. First compute the section test diagrams
(\tau_{\sigma})_{\sigma\in\prodop\displaylimits_{s\in S}d(s)}
. Computing each
\tau_{\sigma}
takes
\mathcal{O}(w^{2}\cdot|V(G)|)

\text{deg}(s)

\mathcal{O}(w^{k}\cdot w^{2}\cdot|V(G)|)

The running time follows since the algorithm of Corollary

times.

Qed.

Let

5

Discussion

In this paper, we have shown that categorical problems about the initiality of limits can be approached using ideas from parameterized complexity. For tree-shaped diagrams, recursive computation via pullbacks allows one to decide initiality efficiently, with running time linear in the number of objects. For diagrams of arbitrary shape, we reduce the problem to a family of tree-structured diagrams using feedback vertex sets, yielding a fixed-parameter tractable algorithm whose complexity depends on the size of the feedback vertex set rather than the full diagram.

In subsequent papers, we will apply these results to develop fast dynamic programming algorithms for generalized CSPs (constraint satisfaction problems) and their categorical duals, co-CSPs. To hint at how this is done, consider the concrete case in which we are given a graph
X
and a structured decomposition
[
4
]

d:\mathop{\raisebox{0.86108pt}{$\smallint\!\!$}}G\to\mathbf{Gr}
with colimit
X
. The
3
-coloring problem can be encoded as a presheaf
\mathbf{Gr}(-,K_{3})
where
K_{3}
is the irreflexive complete graph on three vertices. The composite diagram

\mathop{\raisebox{0.86108pt}{$\smallint\!\!$}}G^{\text{op}}\xrightarrow{d}\mathbf{Gr}^{\text{op}}\xrightarrow{\mathbf{Gr}(-,K_{3})}\mathbf{Set}

determines a structured co-decomposition whose bags have size at most
\alpha=3^{\max_{x\in G}|d(x)|}
. This is a structured co-decomposition of the solution space of the three coloring problem on
X
. Since representables turn colimits into limits

\lim(\mathbf{Gr}(-,K_{3})\circ d)\cong\varnothing\;\;\text{if and only if $X$ is $3$-colorable.}

Thus, applying our main result, we obtain a generalization of the classical FPT-time dynamic programming algorithm for
3
-
Coloring
parameterized by
\max_{x\in G}|d(x)|
and the feedback vertex number
k
of the auxiliary graph
G
. In practical terms, this yields an algorithm running in time

\mathscr{O}(\alpha^{k}\cdot\alpha^{2}\cdot|V(G)|).

Classically, algorithmicists think of dynamic programming as computing over (tree) decompositions; however, our results make clear that the relevant data structure is the co-decomposition of the solution space. This suggests that these techniques were never really about graphs in the first place. Indeed our main theorem and the discussion above is object agnostic. These results and their applications show that, although categorical algorithmics is a severely understudied area of research, simple constructions can already bear fruitful results and thus deserve further investigation.
