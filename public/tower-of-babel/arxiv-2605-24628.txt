Memory Uncertainty Relation and Harmonic Memory in Random Recurrent Networks
Taichi Haruna, Kohei Nakajima

Abstract
We present an inequality that bounds the short-term memory capability of dynamical systems from below. It can be interpreted as an uncertainty relation between a measure of short-term memory and that of the size of state fluctuations induced by input signals. The lower bound can be achieved by a readout weight and thus represents a suboptimal memory called harmonic memory. We examine analytically and numerically the inequality in a number of reservoir systems subject to input noise. We illustrate cases in which equality is achieved exactly, equality holds asymptotically, and the inequality is strict. We also study the effect of a state-space regularization to elucidate the inequality in terms of the fluctuation structure of the state-space. We find that a certain strength of input noise induces extra memory under the regularization, and we refer to this phenomenon as noise-induced memory. We observe that the memory uncertainty relation does not hold in general for the regularized memory and harmonic memory. This fact is explained in terms of the mechanism of noise-induced memory.



I
Introduction

A prerequisite for a dynamical system to perform temporal information processing is that it has short-term memory capability. Namely, to emit a desired output signal depending on a recent sequence of temporarily varying input signals, the system must somehow store the input signals within its state and be able to reconstruct them. Studies of reservoir computing have shown that random recurrent neural networks and even physical systems can achieve this characteristic by utilizing their transient dynamics induced by input signals
Maass et al. 2002
;
Jaeger and Haas 2004
;
Lukoševičius and Jaeger 2009
;
Tanaka et al. 2019
;
Nakajima 2020
;
Nakajima and Fischer 2021
.

The short-term memory capability of a dynamical system can be quantified by measuring how the current state of the system is correlated with or dependent on past input signals. Building on this idea, several measures of short-term memory have been proposed such as memory capacity
Jaeger 2002
, information processing capacity
Dambre et al. 2012
, and Fisher memory
Ganguli et al. 2008
. These measures have been extensively studied from different perspectives: analytic expressions of memory capacity
White et al. 2004
;
Hermans and Schrauwen 2010
and Fisher memory
Tiňo 2018
in linear random recurrent neural networks, mean-field calculations in nonlinear cases
Toyoizumi and Abbott 2011
;
Schuecker et al. 2018
;
Haruna and Nakajima 2019
, optimality in relation to the edge of chaos
Bertschinger and Natschläger 2004
;
Boedecker et al. 2012
;
Farkaš et al. 2016
, effects of correlations
Marzen 2017
;
Gonon et al. 2020
or noise
Guan et al. 2025
in input signals, and memory-nonlinearity trade-off relations
Dambre et al. 2012
;
Inubushi and Yoshimura 2017
;
Kubota et al. 2021
;
Schulte to Brinke et al. 2023
. For linear random recurrent neural networks, the structure of the state-space related to short-term memory has also been studied in terms of feature space representations of input signals using temporal kernels
Tino 2020
and encoding of input signals by controllability matrices
Verzelli et al. 2021
.

Here, we investigate the relation between the statistical structure of the state-space and the memory function that yields the memory capacity when summed over its argument
k
representing the time delay of the input signals. In particular, we give a simple inequality that bounds the memory function from below and thus can be regarded as an uncertainty relation. The lower bound is the reciprocal of the relative size of state fluctuations in the average direction where the past input signal entered in the system
k
steps before is stored. We show that the lower bound can be achieved by a specific readout weight vector, namely, it represents a suboptimal memory. We call it
harmonic memory
. In the following, we restrict our focus on a class of random recurrent networks subject to input noise to obtain analytical results, although the inequality holds for broader class of dynamical systems. We also examine the relation between the memory and harmonic memory capacities under a state-space regularization called
principal component regularization (PCR)
to shed light on the role of the direction in the state-space on which the harmonic memory is realized in relation to the principal component structure of the state fluctuations. We find that PCR gives rise to
noise-induced memory (NIM)
in which a certain level of noise in input signals enhances the short-term memory capability. We show that the degree of the enhancement can be different between the regularized memory and harmonic memory capacities, and even the latter can become larger than the former for a certain reservoir network architecture.

This paper is organized as follows. In Sec.
II
, we introduce the recurrent neural network model that we use in this paper and review the memory function associated with it. In Sec.
III
, first we derive the lower bound of the memory function and show that it represents a suboptimal memory. The inequality is studied through examples with different reservoir network architectures. Second, we introduce PCR and explain the mechanism of NIM and its effect on the relation between the regularized memory and harmonic memory function as described above. Finally, in Sec.
IV
, we give several remarks on connections between our results and the existing literature.

II
Model

Specifically, we consider the following discrete-time recurrent neural network model called an echo-state network (ESN) with
N
neurons
Jaeger 2001
;
White et al. 2004
;
Massar and Massar 2013
. Let
x_{n}(t)\in\mathbb{R}
be the state of neuron
n
(
1\leq n\leq N
) in the reservoir layer at time step
t
. We write
\bm{x}(t)=(x_{1}(t),x_{2}(t),\dots,x_{N}(t))^{\mathrm{T}}
, where
\mathrm{T}
represents the transpose of a vector or a matrix. The time evolution of
\bm{x}(t)
obeys the following equation:

\bm{x}(t+1)=\bm{f}\left(W\bm{x}(t)+s(t+1)\bm{v}+\bm{z}(t)\right),

(1)

where
s(t+1)
is an input signal given at time step
t+1
,
\bm{v}=(v_{1},v_{2},\dots,v_{N})^{\mathrm{T}}\in\mathbb{R}^{N}
is a weight vector between the input and the reservoir neurons,
W=\left(w_{mn}\right)_{1\leq m,n\leq N}
is a connection matrix of the reservoir layer with
w_{mn}\in\mathbb{R}
a weight from neuron
n
to neuron
m
,
\bm{z}(t)=(z_{1}(t),z_{2}(t),\dots,z_{N}(t))^{\mathrm{T}}\in\mathbb{R}^{N}
is a noise vector, and
\bm{f}=(f_{1},f_{2},\dots,f_{N})
with
f_{n}
an activation function of neuron
n
. The output signal
y(t)
is the state of the readout neuron at time step
t
that is given by

y(t)=\sum_{i=1}^{L}u_{i}x_{i}(t),

(2)

where we assume that the indices of the reservoir neurons connected to the readout neuron are
i=1,2,\dots,L
(
L\leq N
) without loss of generality. We write
\bm{u}=(u_{1},u_{2},\dots,u_{L})\in\mathbb{R}^{L}
. By abuse of notation, we write
\bm{x}(t)=(x_{1}(t),x_{2}(t),\dots,x_{L}(t))^{\mathrm{T}}\in\mathbb{R}^{L}
. Thus,
y(t)=\bm{u}^{\mathrm{T}}\bm{x}(t)
. Given a target output signal
d(t)
, the readout weight vector
\bm{u}
is optimized under the condition that the mean squared error
\langle\left|y(t)-d(t)\right|^{2}\rangle_{t}
is minimized, where
\langle\dots\rangle_{t}
is the time average.

Let
s(t)
be a stationary input signal with mean
0
and variance
1
. For each
k=0,1,2,\dots
, we consider
d(t)=s(t-k)
as the target signal. The readout weight vector
\bm{u}
that minimizes
\langle\left|y(t)-s(t-k)\right|^{2}\rangle_{t}
is given by
\bm{u}=\bm{u}_{k}=C^{-1}\bm{p}_{k}
, where

C=\langle\bm{x}(t)\bm{x}(t)^{\mathrm{T}}\rangle_{t}

(3)

is an
L\times L
symmetric matrix and
\bm{p}_{k}\in\mathbb{R}^{L}
is defined by

\bm{p}_{k}=\langle s(t-k)\bm{x}(t)\rangle_{t}.

(4)

We assume that the time averages defining
C
and
\bm{p}_{k}
exist, and that
C
is positive definite so that
C^{-1}
exists. We put

\hat{y}_{k}(t)=\bm{u}_{k}^{\mathrm{T}}\bm{x}(t)=\bm{p}_{k}^{\mathrm{T}}C^{-1}\bm{x}(t).

(5)

The coefficient of determination defined as

\displaystyle m(k)

\displaystyle=1-\langle\left|\hat{y}_{k}(t)-s(t-k)\right|^{2}\rangle_{t}

\displaystyle=1-\langle\hat{y}_{k}(t)^{2}\rangle_{t}+2\langle\hat{y}_{k}(t)s(t-k)\rangle_{t}-\langle s(t-k)^{2}\rangle_{t}

\displaystyle=-\bm{p}_{k}^{\mathrm{T}}C^{-1}\bm{p}_{k}+2\bm{p}_{k}^{\mathrm{T}}C^{-1}\bm{p}_{k}

\displaystyle=\bm{p}_{k}^{\mathrm{T}}C^{-1}\bm{p}_{k}

(6)

is a measure of the degree of reconstruction of
s(t-k)
from
\hat{y}_{k}(t)
for each
k=0,1,2,\dots
, where we have used
\langle s(t-k)^{2}\rangle_{t}=1
and
\langle\hat{y}_{k}(t)^{2}\rangle_{t}=\bm{p}_{k}^{\mathrm{T}}C^{-1}\bm{p}_{k}
to obtain the third line. The latter holds since
\langle\hat{y}_{k}(t)^{2}\rangle_{t}=\bm{p}_{k}^{\mathrm{T}}C^{-1}\langle\bm{x}(t)\bm{x}(t)^{\mathrm{T}}\rangle_{t}C^{-1}\bm{p}_{k}=\bm{p}_{k}^{\mathrm{T}}C^{-1}CC^{-1}\bm{p}_{k}=\bm{p}_{k}^{\mathrm{T}}C^{-1}\bm{p}_{k}
. We note that this gives an alternative expression of
m(k)
, namely,
m(k)=\langle\hat{y}_{k}(t)^{2}\rangle_{t}
.
m(k)
is called the memory function and satisfies
0\leq m(k)\leq 1

Jaeger 2002
.

III
Results

III.1
Memory Uncertainty Relation and Harmonic Memory

We introduce a quantity

h(k)=\frac{\|\bm{p}_{k}\|^{2}}{\overline{\bm{p}}_{k}^{\mathrm{T}}C\overline{\bm{p}}_{k}}

(7)

when
\|\bm{p}_{k}\|>0
and otherwise
h(k)=0
for each
k=0,1,2,\dots
, where
\overline{\bm{p}}_{k}=\frac{\bm{p}_{k}}{\|\bm{p}_{k}\|}
and
\|\bm{p}_{k}\|=\sqrt{\bm{p}_{k}^{\mathrm{T}}\bm{p}_{k}}
. We show that
h(k)
is a lower bound of
m(k)
, namely, the following inequality holds:

m(k)\geq h(k).

(8)

The condition of equality is described later.

To see that Eq. (
8
) holds, let
\mu_{1}\geq\mu_{2}\geq\dots\geq\mu_{L}>0
be the eigenvalues of the positive definite matrix
C
, with
\bm{q}_{i}
the eigenvector corresponding to
\mu_{i}
(
i=1,2,\dots,L
). We can take the eigenvectors
\bm{q}_{1},\bm{q}_{2},\dots,\bm{q}_{L}
so that they form an orthonormal basis of
\mathbb{R}^{L}
. Thus,

C=\sum_{i=1}^{L}\mu_{i}\bm{q}_{i}\bm{q}_{i}^{\mathrm{T}}.

(9)

It is enough to consider the case
\|\bm{p}_{k}\|>0
. Substituting

C^{-1}=\sum_{i=1}^{L}\mu_{i}^{-1}\bm{q}_{i}\bm{q}_{i}^{\mathrm{T}}

(10)

into Eq. (
6
) and using Jensen’s inequality, we have

m(k)=\|\bm{p}_{k}\|^{2}\sum_{i=1}^{L}\mu_{i}^{-1}\pi_{k,i}\geq\frac{\|\bm{p}_{k}\|^{2}}{\sum_{i=1}^{L}\mu_{i}\pi_{k,i}}=h(k),

(11)

where we have used the fact that the nonnegative quantities

\pi_{k,i}=\left(\overline{\bm{p}}_{k}^{\mathrm{T}}\bm{q}_{i}\right)^{2}=\frac{\left(\bm{p}_{k}^{\mathrm{T}}\bm{q}_{i}\right)^{2}}{\|\bm{p}_{k}\|^{2}}

(12)

(
i=1,2,\dots,L
) form a probability distribution
\bm{\pi}_{k}=(\pi_{k,1},\pi_{k,2},\dots,\pi_{k,L})
on the set
\{1,2,\dots,L\}
. The equality in Eq. (
8
) holds if and only if
\mu_{i}
is constant on the support of
\bm{\pi}_{k}
.

Equation (
8
) can be interpreted as an uncertainty relation analogous to the thermodynamic uncertainty relation that gives a trade-off relation between the entropy production rate and the relative size of fluctuations of the probability currents in a wide range of nonequilibrium thermodynamic systems
Barato and Seifert 2015
;
Gingrich et al. 2016
, although the derivation of Eq. (
8
) is much simpler. For each
k=0,1,2,\dots
,
f(k)=h(k)^{-1}
is the relative size of the second moment of
\bm{x}(t)\in\mathbb{R}^{L}
in the direction of
\bm{p}_{k}
. In particular, if
\langle\bm{x}(t)\rangle_{t}=\bm{0}
, then
f(k)
is regarded as the relative size of the variance of
\bm{x}(t)
in the direction of
\bm{p}_{k}
. If we write Eq. (
8
) as
m(k)f(k)\geq 1
, then this represents a trade-off relation between
m(k)
and
f(k)
: One cannot make both quantities small simultaneously. We also note that it is an instance of the Cramér–Rao inequality
Cover and Thomas 2006
:
f(k)\geq m(k)^{-1}
. Indeed, if we consider the Gaussian probability density function
p(\bm{x};\theta)\propto\exp\left(-\frac{1}{2}(\bm{x}-\theta\bm{p}_{k})^{\mathrm{T}}C^{-1}(\bm{x}-\theta\bm{p}_{k})\right)
on
\mathbb{R}^{L}
with the parameter
\theta\in\mathbb{R}
, then
\hat{\theta}(\bm{x})=\frac{\bm{p}_{k}^{\mathrm{T}}\bm{x}}{\|\bm{p}_{k}\|^{2}}
is an unbiased estimator of
\theta
. It is straightforward to see that
f(k)
is the variance of
\hat{\theta}
and
m(k)
the Fisher information for
p(\bm{x};\theta)
.

Alternatively, Eq. (
8
) can be seen as an instance of the AM-HM inequality
Hardy et al. 1988
, namely, the arithmetic mean of given positive real numbers is greater than or equal to their harmonic mean. Indeed,
m(k)=\sum_{i=1}^{L}m_{i}(k)\pi_{k,i}
is the arithmetic mean of

m_{i}(k)=\frac{\|\bm{p}_{k}\|^{2}}{\mu_{i}}.

(13)

However,
h(k)
is the harmonic mean of
m_{i}(k)
. Hence, Eq. (
8
) follows.

Next, we show that
h(k)
is not only a lower bound of
m(k)
, but also represents a memory. Namely, it is a coefficient of determination corresponding to a certain readout weight
\bm{u}
. Indeed, for an arbitrary readout weight
\bm{u}\in\mathbb{R}^{L}
, the coefficient of determination is given by

\displaystyle 1-\langle\left|y(t)-s(t-k)\right|^{2}\rangle_{t}

\displaystyle=2\langle s(t-k)y(t)\rangle_{t}-\langle y(t)^{2}\rangle_{t}

\displaystyle=2\bm{u}^{\mathrm{T}}\bm{p}_{k}-\bm{u}^{\mathrm{T}}C\bm{u}.

(14)

Let us restrict
\bm{u}
in the direction of
\bm{p}_{k}
and write
\bm{u}=\sigma\bm{p}_{k}
(
\sigma\in\mathbb{R}
). It is straightforward to show that Eq. (
14
) is maximized when
\sigma=\sigma_{k}
and the corresponding maximum value is
h(k)
, where

\sigma_{k}=\frac{1}{\overline{\bm{p}}_{k}^{\mathrm{T}}C\overline{\bm{p}}_{k}}.

(15)

Thus,
h(k)
is a suboptimal memory realized using a specific readout weight, and we call it the
harmonic memory function
. We write

\hat{y^{\prime}}_{k}(t)=\sigma_{k}\bm{p}_{k}^{\mathrm{T}}\bm{x}(t),

(16)

and we have
h(k)=\langle\hat{y^{\prime}}_{k}(t)^{2}\rangle_{t}
. Indeed,
\langle\hat{y^{\prime}}_{k}(t)^{2}\rangle_{t}=\sigma_{k}^{2}\bm{p}_{k}^{\mathrm{T}}\langle\bm{x}(t)\bm{x}(t)^{\mathrm{T}}\rangle_{t}\bm{p}_{k}=\sigma_{k}^{2}\bm{p}_{k}^{\mathrm{T}}C\bm{p}_{k}=\sigma_{k}\|\bm{p}_{k}\|^{2}=h(k)
.

14
).

We also note that the difference between
m(k)
and
h(k)
denoted by
\Delta(k)=m(k)-h(k)\geq 0
can be expressed as

\Delta(k)=\frac{1}{h(k)}\sum_{i=1}^{L}\left(m_{i}(k)-h(k)\right)^{2}\rho_{k,i},

(17)

where

\rho_{k,i}=\frac{\pi_{k,i}}{m_{i}(k)}h(k)

(18)

(
i=1,2,\dots,L
) form a probability distribution on the set
\{1,2,\dots,L\}
(Appendix

). Thus,
\Delta(k)
is the relative variance of
m_{i}(k)
(
i=1,2,\dots,L
) with respect to their harmonic mean such that the individual deviations are weighted by the corresponding contributing factors
\frac{\pi_{k,i}}{m_{i}(k)}
to
h(k)
.

Next, we investigate the behavior of
h(k)
and its relation to
m(k)
through examples. In the following examples, we assume that the input signal
s(t)
satisfies
\langle s(t)\rangle_{t}=0
and
\langle s(t)s(t+k)\rangle_{t}=\iota\delta_{k,0}
(
k=0,1,2,\dots
), the input weight vector
\bm{v}
is sampled from the uniform distribution on the unit sphere in
\mathbb{R}^{N}
, and the noise vector
\bm{z}(t)
satisfies
\langle\bm{z}(t)\rangle_{t}=\bm{0}
and
\langle z_{m}(t)z_{n}(t+k)\rangle_{t}=\beta\delta_{k,0}\delta_{m,n}
(
1\leq m\neq n\leq N
,
k=0,1,2,\dots
), where
\delta_{i,j}
is the Kronecker delta,
\iota>0
is the strength of the input signal, and
\beta\geq 0
is the strength of the noise. The next three examples are linear (
\bm{f}=\mathrm{id}_{\mathbb{R}^{N}}
) and all the reservoir neurons are connected to the readout (
L=N
). In these cases, we can assume that
\iota=1
without loss of generality and we have

\bm{p}_{k}=W^{k}\bm{v}

(19)

and

C=C_{0}+\beta C_{n},

(20)

where
C_{0}=\sum_{k=0}^{\infty}\bm{p}_{k}\bm{p}_{k}^{\mathrm{T}}
and
C_{n}=\sum_{k=0}^{\infty}W^{k}W^{k\mathrm{T}}

White et al. 2004
. As the fourth example, we consider briefly a nonlinear case with
L=\mathcal{O}(1)
.

The first example involves distributed shift register networks (DSRNs)
White et al. 2004
. For a DSRN, its connection matrix
W
is given as follows. Putting
\bm{v}_{1}=\bm{v}
, we take
\bm{v}_{2},\bm{v}_{3},\dots,\bm{v}_{N}\in\mathbb{R}^{N}
so that
\bm{v}_{1},\bm{v}_{2},\dots,\bm{v}_{N}
form an orthonormal basis of
\mathbb{R}^{N}
, and we define
W=\sqrt{\alpha}\sum_{n=1}^{N-1}\bm{v}_{n+1}\bm{v}_{n}^{\mathrm{T}}
, where
0<\alpha<1
. Since
W\bm{v}_{n}=\sqrt{\alpha}\bm{v}_{n+1}
for
1\leq n\leq N-1
and
W\bm{v}_{N}=\bm{0}
, we have
\bm{p}_{k}=\alpha^{\frac{k}{2}}\bm{v}_{k+1}
for
k=0,1,\dots,N-1
and
\bm{p}_{k}=\bm{0}
for
k\geq N
. We also have
C=\sum_{n=1}^{N}\mu_{n}\bm{q}_{n}\bm{q}_{n}^{\mathrm{T}}
, with
\mu_{n}=\alpha^{n-1}+\tilde{\beta}(1-\alpha^{n})
and
\bm{q}_{n}=\bm{v}_{n}
for
n=1,2,\dots,N
, where
\tilde{\beta}=\beta/(1-\alpha)
. Thus,

m(k)=\frac{\alpha^{k}}{\alpha^{k}+\tilde{\beta}(1-\alpha^{k+1})}=h(k)

(21)

for
k=0,1,\dots,N-1
and
m(k)=h(k)=0
for
k\geq N
. Indeed, for each
k=0,1,\dots,N-1
, the condition of equality for Eq. (
8
) holds, since
\pi_{k,n}=\left(\overline{\bm{p}}_{k}^{\mathrm{T}}\bm{q}_{n}\right)^{2}=\left(\bm{v}_{k+1}^{\mathrm{T}}\bm{v}_{n}\right)^{2}=\delta_{k+1,n}
.

The second example involves random orthogonal networks (RONs)
White et al. 2004
with
W=\sqrt{\alpha}Q
, where
0<\alpha<1
and
Q
is an
N\times N
orthogonal matrix sampled uniformly at random from the set of all
N\times N
orthogonal matrices. We have

\bm{p}_{k}=\alpha^{\frac{k}{2}}\tilde{\bm{v}}_{k}

(22)

and

C=\sum_{k=0}^{\infty}\alpha^{k}\tilde{\bm{v}}_{k}\tilde{\bm{v}}_{k}^{\mathrm{T}}+\tilde{\beta}I,

(23)

where

\tilde{\bm{v}}_{k}=Q^{k}\bm{v}

(24)

and
I
is the identity matrix. For finite
N
, the equality in Eq. (
8
) does not hold in general, but we find

m(k)=\frac{\alpha^{k}}{\alpha^{k}+\tilde{\beta}}=h(k)

(25)

for
k=0,1,2,\dots
as
N\to\infty
under the annealed approximation such that
Q
and
\bm{v}
are resampled at each time step. Since the left-hand equality is shown in
White et al. 2004
, here we derive only the right-hand equality (Appendix
B
).

The third example involves random Gaussian networks (RGNs). Let
R=(r_{mn})_{1\leq m,n\leq N}

Principal Component Regularization of the Reservoir State-Space and Noise-Induced Memory

Next, we investigate the behaviors of

IV
Concluding Remarks

The mechanism of NIM is reminiscent of recurrence resonance
Krauss et al. 2019
;
Metzner et al. 2024
, in which the mutual information between the current state of the system and that of the next time step is maximized at a certain strength of noise. The noise degrades temporal correlation in the state of the system on one hand, and it enlarges and uniformizes the region of the state-space visited by the system on the other hand. The balance between these two competing effects leads to a peak of the mutual information as the noise strength is varied. Similarly, two competing effects are involved in NIM as explained in the previous section: the noise added to the input signals blurs the memory of them in the current state on one hand, and the number of available directions in the state-space to store the input signals increases on the other hand.

The memory functions
m(k)
for linear ESNs with
L=N
are known to be monotonically decreasing functions of
k

Jaeger 2002
. Namely,
m(k)\geq m(k+1)
holds for
k=0,1,2,\dots
for a single realization of such ESN. However,

does not necessarily decrease monotonically. Indeed, we have

h(k)-h(k+1)\geq\Delta(k+1)-\Delta(k).

(34)

If

, then the inverted inequality
h(k)<h(k+1)
is allowed (Fig.
9
). We note that if
h(k)<h(k+1)
holds, then we have the strict inequality
m(k)>h(k)
. This argument is formally similar to the justification of consistency between the second law of thermodynamics and Maxwell’s demon in general information exchange processes
Sagawa and Ueda 2012
;
Sagawa and Ueda 2013
, in that the inequality that holds in the whole system does not necessarily restrict to subsystems. This could indicate a common mathematical framework subsuming both of them, which is not pursued further here.

Recently, the usefulness of the memory capacity as a measure of inherent information processing capability of reservoir network architectures has been questioned since it achieves its maximum value for generic reservoir networks in linear ESNs without input noise, and it can vary depending on the scale of input signals in nonlinear ESNs
Ballarin et al. 2026
. Here, we give a few comments on this criticism. First, our approach in this paper focuses on the performance of ESNs relative to a specific task, namely, the short-term memory capability. Second, we have studied the short-term memory capability of ESNs in terms of the fluctuation structure of their state-space and how input noise modifies it. Ballarin et al.
Ballarin et al. 2026
lacks this viewpoint. Third, our interest is not only on the memory capacity itself (called the total memory capacity in Ballarin et al.
Ballarin et al. 2026
), but also on the memory functions (called the
\tau
-lag memory capacity in Ballarin et al.
Ballarin et al. 2026
) which have richer information on the relation between the short-term memory capability and the fluctuation structure of the state-space. For example, we have explained the reason why the inequality

holds for sufficiently small noise strength
\beta
in RGNs by examining the difference between
m_{\epsilon}(k)
and
h_{\epsilon}(k)
in how they utilize the state-space to store the input signals. Fourth and finally, we note that if we regard the scale of the input signals as a control parameter, the fact that the memory capacity can reflect it in nonlinear systems can be an advantage for exploring an effective way to use nonautonomous dynamical systems as reservoirs in the context of physical reservior computing where the architecture of reservoirs themselves could be difficult to adjust, as we discussed in our previous work
Haruna and Nakajima 2019
.

In conclusion, we have presented an inequality representing an uncertainty relation associated with the short-term memory capability of ESNs. It gives a lower bound for the memory function. The lower bound itself can be regarded as a suboptimal memory and is called the harmonic memory function. We found that the uncertainty relation does not necessarily hold for the regularized memory and harmonic memory functions under the state-space regularization called PCR and this fact is related to NIM induced by PCR. The inequality holds as long as both sides of Eq. (
8
) can be defined, and thus has broad applicability in a wide range of dynamical systems.

\displaystyle\operatorname{tr}C_{0}

\displaystyle=\operatorname{tr}\left(C-\alpha^{k}Q^{k}\bm{v}\bm{v}^{\mathrm{T}}Q^{-k}\right)

\displaystyle=\operatorname{tr}C-\alpha^{k}\operatorname{tr}\left(Q^{k}\bm{v}\bm{v}^{\mathrm{T}}Q^{-k}\right)

\displaystyle=\operatorname{tr}\left(\sum_{l=0}^{\infty}\alpha^{l}\tilde{\bm{v}}_{l}\tilde{\bm{v}}_{l}^{\mathrm{T}}+\tilde{\beta}I\right)-\alpha^{k}\operatorname{tr}\left(\tilde{\bm{v}}_{k}\tilde{\bm{v}}_{k}^{\mathrm{T}}\right)

\displaystyle=\sum_{l=0}^{\infty}\alpha^{l}\operatorname{tr}\left(\tilde{\bm{v}}_{l}\tilde{\bm{v}}_{l}^{\mathrm{T}}\right)+\tilde{\beta}\operatorname{tr}I-\alpha^{k}\operatorname{tr}\left(\tilde{\bm{v}}_{k}\tilde{\bm{v}}_{k}^{\mathrm{T}}\right)

\displaystyle=\sum_{k=0}^{\infty}\alpha^{k}+\tilde{\beta}N-\alpha^{k}

\displaystyle=\frac{1}{1-\alpha}+\tilde{\beta}N-\alpha^{k},

(45)

where we used Eq. (
40
) in the first equality, Eqs. (
23
) and (
24
) in the third equality, and the fifth equality holds since
\operatorname{tr}\left(\tilde{\bm{v}}_{k}\tilde{\bm{v}}_{k}^{\mathrm{T}}\right)=\operatorname{tr}\left(\tilde{\bm{v}}_{k}^{\mathrm{T}}\tilde{\bm{v}}_{k}\right)=\operatorname{tr}1=1
and
\operatorname{tr}I=N
. From Eqs. (
44
) and (
45
), we find

\mathrm{E}\left[r\right]=\tilde{\beta}+\mathcal{O}\left(\frac{1}{N}\right).

(46)

Finally, we find

\displaystyle\mathrm{E}\left[h(k)\right]

\displaystyle=\mathrm{E}\left[\frac{\|\bm{p}_{k}\|^{2}}{\overline{\bm{p}}_{k}^{\mathrm{T}}C\overline{\bm{p}}_{k}}\right]

\displaystyle=\mathrm{E}\left[\frac{\alpha^{k}}{\alpha^{k}+r}\right]

\displaystyle\geq\frac{\alpha^{k}}{\alpha^{k}+\mathrm{E}\left[r\right]}\to\frac{\alpha^{k}}{\alpha^{k}+\tilde{\beta}}=m(k),

(47)

as
N\to\infty
, where we used Eqs. (
22
) and (
41
) in the second equality, and Jensen’s inequality and Eq. (
46
) in the third line.

Appendix C
Eigenvalues and eigenvectors of
C
for RONs in the context of NIM

Let
K^{\prime}_{\epsilon}
be the largest
k
such that
\alpha^{k}+\tilde{\beta}>\epsilon
as in the main text. We assume that
K^{\prime}_{\epsilon}
is a constant independent of
N
. We put
\nu_{kl}=\tilde{\bm{v}}_{k}^{\mathrm{T}}\tilde{\bm{v}}_{l}
. We assume that
\nu_{kl}=\mathcal{O}(\frac{1}{\sqrt{N}})
for
0\leq k\neq l\leq K^{\prime}_{\epsilon}
.

Let

\bm{d}_{k}=C\tilde{\bm{v}}_{k}-\left(\alpha^{k}+\tilde{\beta}\right)\tilde{\bm{v}}_{k}.

(48)

Since
C
is given by Eq. (
23
) for RONs, we have

\bm{d}_{k}=\sum_{l\neq k}\alpha^{l}\nu_{kl}\tilde{\bm{v}}_{l}.

(49)

For
k\leq K^{\prime}_{\epsilon}
, we evaluate

\displaystyle\left\|\bm{d}_{k}\right\|^{2}

\displaystyle=\sum_{l,l^{\prime}\neq k}\alpha^{l+l^{\prime}}\nu_{kl}\nu_{kl^{\prime}}\nu_{ll^{\prime}}

\displaystyle=\sum_{k\neq l,l^{\prime}\leq K^{\prime}_{\epsilon}}\alpha^{l+l^{\prime}}\nu_{kl}\nu_{kl^{\prime}}\nu_{ll^{\prime}}

\displaystyle\qquad+\sum_{l,l^{\prime}>K^{\prime}_{\epsilon}}\alpha^{l+l^{\prime}}\nu_{kl}\nu_{kl^{\prime}}\nu_{ll^{\prime}}.

(50)

The first sum in Eq. (
50
) is
\mathcal{O}(\frac{1}{N})
since
\nu_{kl}\nu_{kl^{\prime}}=\mathcal{O}(\frac{1}{N})
and the sum has a finite number of terms independent of
N
. For the second sum in Eq. (
50
), we have

\left\|\sum_{l,l^{\prime}>K^{\prime}_{\epsilon}}\alpha^{l+l^{\prime}}\nu_{kl}\nu_{kl^{\prime}}\nu_{ll^{\prime}}\right\|\leq\alpha^{2K^{\prime}_{\epsilon}+2}\sum_{l,l^{\prime}\geq 0}\alpha^{l}\alpha^{l^{\prime}}=\left(\frac{\alpha^{K^{\prime}_{\epsilon}+1}}{1-\alpha}\right)^{2}.

(51)

Thus, Eq. (
50
) can be arbitrarily small as
N\to\infty
and
K^{\prime}_{\epsilon}
is sufficiently large. In particular, there exists
g_{N,K^{\prime}_{\epsilon}}>0
such that

\left\|\bm{d}_{k}\right\|<g_{N,K^{\prime}_{\epsilon}}

(52)

for all
0\leq k\leq K^{\prime}_{\epsilon}
and
\lim_{K^{\prime}_{\epsilon}\to\infty}\lim_{N\to\infty}g_{N,K^{\prime}_{\epsilon}}=0
.

Next, we show that there is no eigenvalue
\mu_{n}
of
C
that cannot be approximated by the form
\alpha^{k}+\tilde{\beta}
for
1\leq n\leq K_{\epsilon}
. To show this claim, we appeal to a proof by contradiction. Let
\mu
be an eigenvalue of
C
such that
\mu>\epsilon
, namely,
\mu=\mu_{n}
for some
1\leq n\leq K_{\epsilon}
, and assume that
\mu
cannot be approximated by any of
\alpha^{k}+\tilde{\beta}
with
0\leq k\leq K^{\prime}_{\epsilon}
. Let
\tilde{\bm{v}}
be a normalized eigenvector corresponding to
\mu
. Since
\mu
is different from
\alpha^{k}+\tilde{\beta}
for all
0\leq k\leq K^{\prime}_{\epsilon}
, there exists
\xi>0
such that

\min_{0\leq k\leq K^{\prime}_{\epsilon}}\left\{\left|\alpha^{k}+\tilde{\beta}-\mu\right|\right\}>\xi.

(53)

Note that
\xi
does not depend on
K^{\prime}_{\epsilon}
if
K^{\prime}_{\epsilon}
is sufficiently large.

We have

\displaystyle\mu

\displaystyle=\tilde{\bm{v}}^{\mathrm{T}}C\tilde{\bm{v}}

\displaystyle=\sum_{k=0}^{\infty}\alpha^{k}\left(\tilde{\bm{v}}^{\mathrm{T}}\tilde{\bm{v}}_{k}\right)^{2}+\tilde{\beta}=S_{1}+S_{2}+\tilde{\beta},

(54)

where

S_{1}=\sum_{k=0}^{K^{\prime}_{\epsilon}}\alpha^{k}\left(\tilde{\bm{v}}^{\mathrm{T}}\tilde{\bm{v}}_{k}\right)^{2}

(55)

and

S_{2}=\sum_{k=K^{\prime}_{\epsilon}+1}^{\infty}\alpha^{k}\left(\tilde{\bm{v}}^{\mathrm{T}}\tilde{\bm{v}}_{k}\right)^{2}\leq\sum_{k=K^{\prime}_{\epsilon}+1}^{\infty}\alpha^{k}=\frac{\alpha^{K^{\prime}_{\epsilon}+1}}{1-\alpha}.

(56)

S_{2}
can be arbitrarily small if
K^{\prime}_{\epsilon}
is sufficiently large. For
S_{1}
, since
C
is symmetric, we have

\displaystyle\mu\tilde{\bm{v}_{k}}^{T}\tilde{\bm{v}}

\displaystyle=\tilde{\bm{v}_{k}}^{T}C\tilde{\bm{v}}

\displaystyle=\left(C\tilde{\bm{v}_{k}}\right)^{T}\tilde{\bm{v}}

\displaystyle=\left(\alpha^{k}+\tilde{\beta}\right)\tilde{\bm{v}_{k}}^{T}\tilde{\bm{v}}+\bm{d}_{k}^{T}\tilde{\bm{v}}.

(57)

From Eqs. (
57
), (
52
) and (
53
),

\displaystyle\left|\tilde{\bm{v}_{k}}^{T}\tilde{\bm{v}}\right|

\displaystyle=\frac{\left|\bm{d}_{k}^{T}\tilde{\bm{v}}\right|}{\left|\alpha^{k}+\tilde{\beta}-\mu\right|}

\displaystyle<\frac{g_{N,K^{\prime}_{\epsilon}}}{\xi}

(58)

for all
0\leq k\leq K^{\prime}_{\epsilon}
. Thus, we obtain

S_{1}=\sum_{k=0}^{K^{\prime}_{\epsilon}}\alpha^{k}\left(\tilde{\bm{v}}^{\mathrm{T}}\tilde{\bm{v}}_{k}\right)^{2}<\frac{g_{N,K^{\prime}_{\epsilon}}^{2}}{(1-\alpha)\xi^{2}}

(59)

by Eqs. (
55
) and (
58
). It follows that
S_{1}\to 0
as
N\to\infty
and
K^{\prime}_{\epsilon}\to\infty
. From Eqs. (
54
), (
56
) and (
59
),

\mu\to\tilde{\beta}\leq\epsilon-\alpha^{K^{\prime}_{\epsilon}+1}<\epsilon

(60)

as
N\to\infty
and
K^{\prime}_{\epsilon}\to\infty
, where the first inequality holds since
\alpha^{K^{\prime}_{\epsilon}+1}+\tilde{\beta}\leq\epsilon
by the definition of
K^{\prime}_{\epsilon}
. However, Eq. (
60
) contradicts the assumption
\mu>\epsilon
.

In summary, up to the approximation error,
\mu_{n}=\alpha^{n-1}+\tilde{\beta}
and
\tilde{\bm{v}}_{n-1}
satisfies the condition to be an eigenvector of
C
corresponding to
\mu_{n}
for
n=1,2,\dots,K_{\epsilon}
.

Appendix D
m(k)
and
h(k)
under finite time average

In this appendix, we study the overestimates of
m(k)
and
h(k)
when they are close to zero if the infinite time average
\langle\cdot\rangle_{t}
is replaced by a finite time average
\langle\cdot\rangle_{t,T}=\frac{1}{T}\sum_{t=0}^{T-1}(\cdot)
. We model the situation
m(k)=h(k)=0
as follows. Let
\nu>\mu_{1}\geq\mu_{2}\geq\dots\geq\mu_{L}>\lambda>0
with
\nu,\lambda
constants independent of
L
, and
\bm{q}_{1},\bm{q}_{2},\dots,\bm{q}_{L}
unit vectors in
\mathbb{R}^{L}
that form an orthonormal basis of it. We assume that
\bm{x}(t)=\sum_{i=1}^{L}a_{i}(t)\bm{q}_{i}
where
a_{i}(t)
are mutually independent stochastic variables with mean
0
and variance
\mu_{i}
for
i=1,2,\dots,L
and
t=0,1,2,\dots
. We also assume that each
a_{i}(t)
is independent of input signals
s(t^{\prime})
for
t^{\prime}=0,1,2,\dots
and all the moments of
a_{i}(t)
and
s(t)
are finite. In this appendix,
\mathrm{E}\left[\cdot\right]
denote the average over
a_{i}(t)
and
s(t)
.

Let
C_{T}=\langle\bm{x}(t)\bm{x}(t)^{\mathrm{T}}\rangle_{t,T}
and
\bm{p}_{k,T}=\langle s(t-k)\bm{x}(t)\rangle_{t,T}
. It is straightforward to see that

\mathrm{E}\left[C_{T}\right]=\sum_{i=1}^{L}\mu_{i}\bm{q}_{i}\bm{q}_{i}^{\mathrm{T}}.

(61)

Thus,
\mu_{1},\mu_{2},\dots,\mu_{L}
are the eigenvalues of
\mathrm{E}\left[C_{T}\right]
and
\bm{q}_{1},\bm{q}_{2},\dots,\bm{q}_{L}
are corresponding eigenvectors.
\lambda,\nu
are lower and upper bounds of the eigenvalues that are not dependent on
L
, respectively. These exist for the three linear models in the main text with positive noise strength
\beta>0
. In the following, we find that
\mathrm{E}\left[m(k)\right]=\frac{L}{T}
and
\mathrm{E}\left[h(k)\right]=\mathcal{O}\left(\frac{L}{T}\right)
. Since one can show that the deviations of
C_{T}
from
\mathrm{E}\left[C_{T}\right]
add higher order terms of
\frac{L}{T}
to
\mathrm{E}\left[m(k)\right]
and
\mathrm{E}\left[h(k)\right]
after some algebra, we ignore them in the following calculations by assuming
L\ll T
, and write
C
for
\mathrm{E}\left[C_{T}\right]
.

We put
A_{i}=\langle s(t-k)a_{i}(t)\rangle_{t,T}
for
i=1,2,\dots,L
. Since
\bm{p}_{k,T}=\sum_{i=1}^{L}A_{i}\bm{q}_{i}
, we have

m(k)=\bm{p}_{k,T}^{\mathrm{T}}C^{-1}\bm{p}_{k,T}=\sum_{i=1}^{L}\mu_{i}^{-1}A_{i}^{2},

(62)

\|\bm{p}_{k,T}\|^{2}=\sum_{i=1}^{L}A_{i}^{2},

(63)

and

\bm{p}_{k,T}^{\mathrm{T}}C\bm{p}_{k,T}=\sum_{i=1}^{L}\mu_{i}A_{i}^{2}.

(64)

Using
\mathrm{E}\left[A_{i}\right]=0
and
\mathrm{E}\left[A_{i}^{2}\right]=\frac{\mu_{i}}{T}
, we obtain

\mathrm{E}\left[m(k)\right]=\frac{1}{T}\sum_{i=1}^{L}\mu_{i}^{-1}\mu_{i}=\frac{L}{T},

(65)

e_{1}=\mathrm{E}\left[\|\bm{p}_{k,T}\|^{2}\right]=\frac{1}{T}\sum_{i=1}^{L}\mu_{i}=\frac{\operatorname{tr}C}{T},

(66)

and

e_{2}=\mathrm{E}\left[\bm{p}_{k,T}^{\mathrm{T}}C\bm{p}_{k,T}\right]=\frac{1}{T}\sum_{i=1}^{L}\mu_{i}^{2}=\frac{\operatorname{tr}\left(C^{2}\right)}{T}.

(67)

For
\mathrm{E}\left[h(k)\right]
, the following inequality holds.

\mathrm{E}\left[h(k)\right]\geq\frac{e_{1}^{2}}{e_{2}}=c\frac{L}{T},

(68)

where we used the Cauchy-Schwarz inequality for
\sqrt{\bm{p}_{k,T}^{\mathrm{T}}C\bm{p}_{k,T}}
and
\frac{\|\bm{p}_{k,T}\|^{2}}{\sqrt{\bm{p}_{k,T}^{\mathrm{T}}C\bm{p}_{k,T}}}
, and put

c=\frac{\left(\operatorname{tr}C\right)^{2}}{L\operatorname{tr}\left(C^{2}\right)}.

(69)

We note that
c\leq 1
, which also follows from the Cauchy-Schwarz inequality.

Next, we quantitatively evaluate the gap between both sides of Eq. (
68
) for large
L
and
T
with
L\ll T
. We put

\gamma_{1}=\frac{\|\bm{p}_{k,T}\|^{2}-e_{1}}{e_{1}}

(70)

and

\gamma_{2}=\frac{\bm{p}_{k,T}^{\mathrm{T}}C\bm{p}_{k,T}-e_{2}}{e_{2}}.

(71)

We have

\displaystyle h(k)

\displaystyle=\frac{\left(e_{1}+\left(\|\bm{p}_{k,T}\|^{2}-e_{1}\right)\right)^{2}}{e_{2}+\left(\bm{p}_{k,T}^{\mathrm{T}}C\bm{p}_{k,T}-e_{2}\right)}

\displaystyle=\frac{e_{1}^{2}}{e_{2}}\frac{(1+\gamma_{1})^{2}}{1+\gamma_{2}}

\displaystyle=\frac{e_{1}^{2}}{e_{2}}(1+\gamma_{1})^{2}(1-\gamma_{2}+\gamma_{2}^{2}-\dots)

\displaystyle=\frac{e_{1}^{2}}{e_{2}}(1+2\gamma_{1}-\gamma_{2}+\gamma_{1}^{2}-2\gamma_{1}\gamma_{2}+\gamma_{2}^{2}-\dots)

\displaystyle=\frac{e_{1}^{2}}{e_{2}}\left(1+2\gamma_{1}-\gamma_{2}+(\gamma_{1}-\gamma_{2})^{2}-\dots\right).

(72)

The third line in Eq. (
72
) can be justified by
\mathrm{E}\left[\gamma_{2}\right]=0
and
\mathrm{Var}\left(\gamma_{2}\right)=\mathrm{E}\left[\gamma_{2}^{2}\right]=\mathcal{O}\left(\frac{1}{L}\right)
, where
\mathrm{Var}\left(X\right)
is the variance of a given stochastic variable
X
. It also holds that
\mathrm{E}\left[\gamma_{1}\right]=0
and
\mathrm{Var}\left(\gamma_{1}\right)=\mathrm{E}\left[\gamma_{1}^{2}\right]=\mathcal{O}\left(\frac{1}{L}\right)
. To obtain these order estimates of
\mathrm{E}\left[\gamma_{1}^{2}\right]
and
\mathrm{E}\left[\gamma_{2}^{2}\right]
, we need
\mathrm{Var}\left(A_{i}^{2}\right)
. Since
\mathrm{E}\left[A_{i}^{4}\right]=\frac{3\mu_{i}^{2}}{T^{2}}+\mathcal{O}\left(\frac{1}{T^{3}}\right)
after some algebra, we have

\mathrm{Var}\left(A_{i}^{2}\right)=\mathrm{E}\left[\left(A_{i}^{2}\right)^{2}\right]-\mathrm{E}\left[A_{i}^{2}\right]^{2}=\frac{2\mu_{i}^{2}}{T^{2}}+\mathcal{O}\left(\frac{1}{T^{3}}\right).

(73)

Thus,

\displaystyle\mathrm{E}\left[\gamma_{1}^{2}\right]

\displaystyle=\frac{\sum_{i=1}^{L}\mathrm{Var}\left(A_{i}^{2}\right)}{e_{1}^{2}}

\displaystyle=\frac{2\operatorname{tr}\left(C^{2}\right)+\mathcal{O}\left(\frac{L}{T}\right)}{\left(\operatorname{tr}C\right)^{2}}=\mathcal{O}\left(\frac{1}{L}\right)

(74)

and similarly

\mathrm{E}\left[\gamma_{2}^{2}\right]=\frac{2\operatorname{tr}\left(C^{4}\right)+\mathcal{O}\left(\frac{L}{T}\right)}{\left(\operatorname{tr}\left(C^{2}\right)\right)^{2}}=\mathcal{O}\left(\frac{1}{L}\right),

(75)

where we used
0<\lambda\leq\mu_{i}<\nu
for
i=1,2,\dots,L
in the last equalities in Eqs. (
74
) and (
75
).

Now, we take the average of the right-hand side of Eq. (
72
) as follows.

\displaystyle\mathrm{E}\left[h(k)\right]

\displaystyle=\frac{e_{1}^{2}}{e_{2}}\left(1+2\mathrm{E}\left[\gamma_{1}\right]-\mathrm{E}\left[\gamma_{2}\right]+\mathrm{E}\left[(\gamma_{1}-\gamma_{2})^{2}\right]-\dots\right)

\displaystyle=c\frac{L}{T}\left(1+\mathrm{E}\left[(\gamma_{1}-\gamma_{2})^{2}\right]-\dots\right).

(76)

To calculate
\mathrm{E}\left[(\gamma_{1}-\gamma_{2})^{2}\right]
, we need

\displaystyle\mathrm{E}\left[\gamma_{1}\gamma_{2}\right]=\frac{1}{e_{1}e_{2}}\left(\sum_{i,j=1}^{L}\mu_{i}\mathrm{E}\left[A_{i}^{2}A_{j}^{2}\right]-e_{1}e_{2}\right).

(77)

Since

\mathrm{E}\left[A_{i}^{2}A_{j}^{2}\right]=\frac{\mu_{i}\mu_{j}}{T^{2}}+\mathcal{O}\left(\frac{1}{T^{3}}\right)

(78)

for
i\neq j
, we have

\displaystyle\sum_{i,j=1}^{L}\mu_{i}\mathrm{E}\left[A_{i}^{2}A_{j}^{2}\right]

\displaystyle=\sum_{i=1}^{L}\mathrm{E}\left[A_{i}^{4}\right]+\sum_{i\neq j}\mu_{i}\mathrm{E}\left[A_{i}^{2}A_{j}^{2}\right]

\displaystyle=\frac{3\sum_{i=1}^{L}\mu_{i}^{3}}{T^{2}}+\frac{\sum_{i\neq j}\mu_{i}^{2}\mu_{j}}{T^{2}}+\mathcal{O}\left(\frac{L^{2}}{T^{3}}\right)

\displaystyle=\frac{2\sum_{i=1}^{L}\mu_{i}^{3}}{T^{2}}+\frac{\sum_{i,j=1}^{L}\mu_{i}^{2}\mu_{j}}{T^{2}}+\mathcal{O}\left(\frac{L^{2}}{T^{3}}\right)

\displaystyle=\frac{2\operatorname{tr}\left(C^{3}\right)}{T^{2}}+e_{1}e_{2}+\mathcal{O}\left(\frac{L^{2}}{T^{3}}\right).

(79)

Substituting Eq. (
79
) into Eq. (
77
),

\displaystyle\mathrm{E}\left[\gamma_{1}\gamma_{2}\right]

\displaystyle=\frac{1}{e_{1}e_{2}}\left(\frac{2\operatorname{tr}\left(C^{3}\right)}{T^{2}}+\mathcal{O}\left(\frac{L^{2}}{T^{3}}\right)\right)

\displaystyle=\frac{2\operatorname{tr}\left(C^{3}\right)}{\operatorname{tr}C\operatorname{tr}\left(C^{2}\right)}+\mathcal{O}\left(\frac{1}{T}\right).

(80)

Combining Eqs. (
74
), (
75
) and (
80
), we obtain

\mathrm{E}\left[(\gamma_{1}-\gamma_{2})^{2}\right]=\eta+\mathcal{O}\left(\frac{1}{T}\right),

(81)

where

\eta=2\left(\frac{\operatorname{tr}\left(C^{2}\right)}{\left(\operatorname{tr}C\right)^{2}}+\frac{\operatorname{tr}\left(C^{4}\right)}{\left(\operatorname{tr}\left(C^{2}\right)\right)^{2}}-2\frac{\operatorname{tr}\left(C^{3}\right)}{\operatorname{tr}C\operatorname{tr}\left(C^{2}\right)}\right).

(82)

Note that
\eta\geq 0
by the Cauchy-Schwarz inequality.

In summary, the ratio of
\mathrm{E}\left[h(k)\right]
to its lower bound in Eq. (
68
) is

\frac{\mathrm{E}\left[h(k)\right]}{c\frac{L}{T}}=1+\eta,

(83)

if we ignore the
\mathcal{O}\left(\frac{1}{T}\right)
term in Eq. (
81
). Since
\eta=\mathcal{O}\left(\frac{1}{L}\right)
, we expect that the equality in Eq. (
68
) approximately holds for large
T
and
L
with
L\ll T
. For example, in Figs.
10
(a) and
10
(b),
\eta\approx 0.0283
and
\eta\approx 0.0205
, respectively.

Finally, we note that if
\eta=0
and
T\to\infty
then
\mathrm{E}\left[(\gamma_{1}-\gamma_{2})^{2}\right]=0
by Eq. (
81
). This in turn implies that
\gamma_{1}=\gamma_{2}
almost everywhere, which is the equality condition of Eq. (
68
).
