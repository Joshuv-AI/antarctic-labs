Zoe Paraskevopoulou, Anja Petković Komel, Sophie Rain, Lefteris Lazaropoulos, Alexis Terry

Abstract




Scope.
This technical report contains the formal definitions
and metatheory for the
act
specification and verification language. It documents
the syntax, the operational pointer semantics, the type system
and the main metatheoretic results (type-safety).
The mechanised proofs are available in the
act
repository

Notes:

•

The non-terminals
\mathit{id},x,y
denote identifiers that start
with lowercase letter, and non-terminal
\mathit{Id},A
denote identifiers
that start with capital letters, i.e. contracts. The terminal
i
denotes a numeric literal.

•

We denote repetition with
{\color[rgb]{0,1,1}\overline{\color[rgb]{0,0,0}\text{overbar}}}
. For example,

{\color[rgb]{0,1,1}\overline{\color[rgb]{0,0,0}e}}
denotes an ordered collection of expressions. When we want to be
able explicitly refer to an item in a collection we index over a countable
set, for example
\{e_{i}\}_{i\in[1,N]}
is a collection of
N

expressions and
e_{i}
is the
i
-th expression.

•

References in expressions and assignments have a type annotation.
This is the type of the reference and it is filled during type checking.
It is used in the bounds elaboration phase.

The state maps each location

to a pair of a contract type and a mapping
from storage variables to values.
For readability, we write

to denote the contract

\ell

(i.e.,

). We write

to denote the value of storage variable

at location
\ell
in
state
s
(i.e.,

Semantics of Variable References

s^{t};\rho;\mathit{ref}\Downarrow_{\ell}(\mathit{v},t_{p})

The state in the pointer semantics of variable references is annotated with a tag
t
that takes values from the
set
\{\bm{\mathtt{{U}}},\bm{\mathtt{{T}}}\}
, denoting whether the reference appears in an untimed or timed judgement.
An untimed state is a single state
s^{\bm{\mathtt{{U}}}}=s
and a timed state is a pair of pre- and post-states
s^{\bm{\mathtt{{T}}}}=(s_{\bm{\mathtt{{pre}}}},s_{\bm{\mathtt{{post}}}})
.
We will omit the tag
t
from the rest of the judgements, assuming they just propagate the same tag on the states, as given.
The tag
t_{p}\in\{\bm{\mathtt{{U}}},\bm{\mathtt{{pre}}},\bm{\mathtt{{post}}}\}
denotes the timing of the evaluated reference.

Reference Judgment

The reference judgement is annotated with a tag

set
\{\bm{\mathtt{{S}}},\bm{\mathtt{{N}}}\}
.
\bm{\mathtt{{S}}}
denotes a storage reference that is
reachable from the current contract’s storage, without any coercion. References
tagged with
\bm{\mathtt{{N}}}

that involve coercions or environment variables.

Only references tagged with
\bm{\mathtt{{S}}}
can be updated.
