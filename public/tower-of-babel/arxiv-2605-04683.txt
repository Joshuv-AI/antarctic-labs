Average Attention Transformers and Arithmetic Circuits
Lena Ehrmuth, Laura Strieker

Abstract
We analyse the computational power of transformer encoders as sequence-to-sequence functions on vectors. We show that average hard attention can be used to simulate arithmetic circuits if they are given as an input to an encoder. The circuit families that can be simulated this way have constant depth while using unbounded addition, binary multiplication and sign \sign gates. The transformers we use have arithmetic circuits instead of feed-forward networks. With typical average attention the functions they compute are also computed by the same class of circuit families. Our results hold for transformers over the reals, rationals and any ring in between the two.

Introduction

Transformers
(
9
)
have recently gained popularity in machine learning applications as well as theoretical research.
The analysis of their expressivity has mostly been focused on what decision problems can be solved by transformers.
In that regard, Boolean circuits have been a promising model for comparison.
For example,

5
)
showed that leftmost hard attention transformers over
\mathbb{Q}

can only recognize languages in
\textbf{AC}^{0}

the class of functions computed by Boolean circuit families of constant depth and polynomial size with unbounded fan-in.

8

8
)
showed that average hard attention transformers using floats
can only recognize languages in logspace-uniform
\textbf{TC}^{0}
and

6

(
6
)
showed the same result for soft attention transformers with logarithmic precision.
There are also a number of descriptive characterizations comparing transformers to logics.

3

(
3

defined an extension of first-order logic
with modular predicates on positions and counting quantifiers and
showed that its definable languages are between the languages recognized by
soft attention transformers with fixed and unlimited precision.

1

1
)
showed that all languages definable in
first-order logic with arbitrary unary predicates can be recognized by
leftmost hard attention transformers and
even when extending this logic with counting terms,
the definable languages are recognized by average hard attention transformers.
Whereas
11

(
11
)
showed that transformers
using left- and rightmost
attention with strict masking and no positional embedding
recognize exactly the languages definable in linear temporal logic.

All of those results are limited to decision problems over finite alphabets.
We want to analyse the expressivity of transformers as functions
from vector sequences to vector sequences and compare them to arithmetic circuits.
These circuits take numbers as inputs and their gates compute functions like addition, multiplication
and the
\sign

This allows us to reason precisely about the theoretical transformer model, which uses real numbers and
also about practical implementations using rational numbers for approximation.
We adapt a model of generalized transformers by
5

(
5
)
and
use it to define a class of average dot-product attention transformers
which use arithmetic circuits instead of feed-forward networks.

Main Results

The main contribution of this paper is a correspondence between average attention circuit transformers and the function class
\textbf{FSAC}^{0}_{R}[\sign]
.
All functions computed by the transformers are in
\textbf{FSAC}^{0}_{R}[\sign]
and
all circuits from an
\textbf{FSAC}^{0}_{R}[\sign]
family can be simulated by a single such transformer.

Our results give a new perspective on the expressivity of transformers and
we think that the field of machine learning would benefit from advances in the theory of algebraic computation and vice versa.
We would also like to emphasize that theoretical results have the potential to inspire practical development.

2.1
Algebra

We will discuss arithmetic circuits and transformers using values from arbitrary semirings.

Definition 2.1
.

A
semiring
is a set
R
equipped with binary functions
+
and
\times
such that

•

(R,+)
is a commutative monoid with identity
0
,

•

(R,\times)
is a monoid with identity
1
,

•

0
is absorbing with respect to
\times
and

•

\times
distributes over
+
.

A semiring is called
commutative
if
(R,\times)
is a commutative monoid.
A
ring
is a semiring such that
(R,+)
is an abelian group.
A
field
is a ring such that
(R,\times)
is an abelian group.

We can perform addition and multiplication over any semiring.
A ring also allows subtraction and over a field we can additionally use division.
For example,

\mathbb{N}
is a semiring but not a ring,

\mathbb{Z}
is a ring but not a field and

\mathbb{Q},\mathbb{R}
are fields.

If we want to simulate the computation of one semiring within another,
we need what we call an extension.

Definition 2.2
.

Let
R
and
T
be semirings with functions
+_{R},\times_{R}
and
+_{T},\times_{T}

having identities
0_{R},1_{R}
and
0_{T},1_{T}
.
Then a function
f\colon R\to T
is a
homomorphism
if we get

\displaystyle f(x+_{R}y)

\displaystyle=f(x)+_{T}f(y),

\displaystyle f(x\times_{R}y)

\displaystyle=f(x)\times_{T}f(y),

\displaystyle\text{and }f(1_{R})

\displaystyle=1_{T}

for all
x,y\in R
.
We call
T
a
semiring extension
of
R
if there is an injective homomorphism from
R
to
T
.
If
T
is also a ring/field, we call
T
a
ring/field extension
of
R
.

For example,

\mathbb{N}
is a semiring extension of
\mathbb{N}
,

\mathbb{Z}
is a ring extension of
\mathbb{N}
and

\mathbb{Q}
is a field extension of
\mathbb{Z}
.

Definition 2.3
.

An ordered semiring is a semiring
R
with a partial order
\mathord{\leq}\subseteq R^{2}

such that for all
x,y,z\in R
we get

\displaystyle x\leq y\>

\displaystyle\Rightarrow\>x+z\leq y+z\quad\text{and}

\displaystyle x\leq y\text{ and }0\leq z\>

\displaystyle\Rightarrow\>x\times z\leq y\times z\text{ and }z\times x\leq z\times y.

We call a ring extension of
\mathbb{Z}

\mathbb{Z}
-ordered,
if it preserves the usual order of
\mathbb{Z}
, which means that for all
x,y\in\mathbb{Z}

f(x)\leq f(y)\quad\Leftrightarrow\quad x\leq y.

We will need an order on our values to define hard attention.

2.2
Arithmetic Circuits

We compare transformers to the well established theoretical model of circuits.
For a more thorough introduction to this topic, see
7

(
7
)
or
10

(
10
)
.
A circuit is defined by an acyclic graph labeled with functions over some set.
In this paper, this will be a semiring with its operations
+
and
\times
.

Definition 2.4
.

A
circuit basis
is a pair
(S,B)
where
S
is a set or domain and
B
is a set of
functions
f\colon S^{k}\to S
with
k\in\mathbb{N}
and
functions on sequences
f\colon S^{*}\to S
.

Definition 2.5
.

A
circuit

C
over a basis
(S,B)
with
m
inputs and
n
outputs
is a tuple
C=(V,E,\alpha,\beta)
where

•

(V,E)
is a finite directed acyclic graph,
the nodes of which are called the gates of
C
,

•

\beta\colon V\to S\cup B\cup\{x_{1},\dots,x_{m},y_{1},\dots,y_{n}\}

is a labeling function that assigns each element of
\{x_{1},\dots,x_{m},y_{1},\dots,y_{n}\}
exactly once and

•

\alpha\colon E\to\mathbb{N}
is a function such that for each node
v\in V
,

\alpha(N_{\text{in}}(v))=\{1,\dots,|N_{\text{in}}(v)|\}
where

N_{\text{in}}(v)=\{u\mid(u,v)\in E\}
is the in-neighbourhood of
v
.

We call the in- and out-degree of gates their fan-in and fan-out.
The function
\beta
determines the type of each gate
and thereby imposes some conditions on the graph:

•

A gate
v
with
\beta(v)\in S
is called a constant gate and has fan-in
0
.

•

A gate
v
with
\beta(v)\in\{x_{1},\dots,x_{m}\}
is called an input gate and has fan-in
0
.

•

A gate
v
with
\beta(v)\in\{y_{1},\dots,y_{n}\}
is called an output gate,
has fan-in
1
and fan-out
0
.

•

A gate
v
with
\beta(v)\in B
is called a function gate and has no restrictions.

The
size
of a circuit is the number of gates it has and
the
depth
of a circuit is the length of the longest path from an input to an output gate.

Definition 2.6
.

A circuit
C=(V,E,\alpha,\beta)
over
(S,B)
with
m
inputs and
n
outputs
computes a function
f_{C}\colon S^{m}\to S^{n}
defined as follows.
Each gate
v\in V
computes a function
f_{C,v}\colon S^{m}\to S
inductively defined as

\overline{x}\mapsto\begin{cases}c&\text{if }\beta(v)=c\in S\\
x_{i}&\text{if }\beta(v)=x_{i}\\
f_{C,u}(\overline{x})&\begin{multlined}\text{if }\beta(v)\in\{y_{1},\dots,y_{n}\}\\[-11.0pt]
\text{ and }N_{\text{in}}(v)=\{u\}\end{multlined}\\[2.0pt]
\begin{multlined}b(f_{C,u_{1}}(\overline{x}),\dots{\\[-11.0pt]
}\dots,f_{C,u_{k}}(\overline{x}))\\
\end{multlined}&\begin{multlined}\text{if }\beta(v)=b\in B\text{ and}\\[-11.0pt]
\hskip 1.0ptN_{\text{in}}(v)=\{u_{1},\dots,u_{k}\}\\
\text{ s.t. }\alpha(u_{1})<\dots<\alpha(u_{k})\end{multlined}\end{cases}

and
f_{C}(\overline{x})=(f_{C,\beta^{-1}(y_{1})},\dots,f_{C,\beta^{-1}(y_{n})})
.

A single circuit takes an input vector whose dimension is equal to the number of input gates.
To handle inputs sequences of any length, we need a family of circuits.

Definition 2.7
.

A
circuit family

C=({C}_{n})_{n\in\mathbb{N}}
over
(S,B)
is a sequence of circuits over
(S,B)

such that each circuit
C_{n}
has exactly
n
inputs.
It computes a function

f_{C}\colon S^{*}\to S^{*},\overline{x}\mapsto f_{C_{|\overline{x}|}}(\overline{x}).

We define
\textbf{FSizeDepth}_{(S,B)}(f_{s},f_{d})
as the set of functions computed by circuit families over
(S,B)

that have
\size(C_{n})\in\mathcal{O}(f_{s}(n))
and
\depth(C_{n})\in\mathcal{O}(f_{d}(n))
.

If the basis is a semiring with addition and multiplication functions,
the corresponding circuits are called arithmetic.
We define three different complexity classes based on the fan-in of addition and multiplication gates.

Definition 2.8
.

Let
R
be any semiring with operations
+
and
\times
.
We define
+_{*}\colon R^{*}\to R,\overline{x}\mapsto\sum_{i=1}^{|\overline{x}|}x_{i}
and

\times_{*}\colon R^{*}\to R,\overline{x}\mapsto\prod_{i=1}^{|\overline{x}|}x_{i}
.
Then a bounded fan-in (arithmetic) circuit over
R
is a circuit over the basis
(R,\{+,\times\})
,
a semi-unbounded fan-in circuit over
R
uses the basis
(R,\{+_{*},\times\})
and
an unbounded fan-in circuit over
R
uses the basis
(R,\{+_{*},\times_{*}\})
.
We use
\textbf{FCirc}_{R}
for functions computed by an unbounded fan-in circuit over
R
.
These always have fixed size input and output vectors.
To analyse functions of sequences, we define complexity classes for the three kinds of circuit families.

\displaystyle\textbf{FNC}^{0}_{R}

\displaystyle=\textbf{FSizeDepth}_{(R,\{+,\times\})}(n^{\mathcal{O}(1)},1)

\displaystyle\textbf{FSAC}^{0}_{R}

\displaystyle=\textbf{FSizeDepth}_{(R,\{+_{*},\times\})}(n^{\mathcal{O}(1)},1)

\displaystyle\textbf{FAC}^{0}_{R}

\displaystyle=\textbf{FSizeDepth}_{(R,\{+_{*},\times_{*}\})}(n^{\mathcal{O}(1)},1)

All three classes restrict circuit families to polynomial size and constant depth,
but we get
\textbf{FNC}^{0}_{R}\subsetneq\textbf{FSAC}^{0}_{R}\subsetneq\textbf{FAC}^{0}_{R}
.
For example,
(\sum_{i=1}^{n}x_{i})_{n\in\mathbb{N}}\in\textbf{FSAC}^{0}_{R}\setminus\textbf{FNC}^{0}_{R}
and

(\prod_{i=1}^{n}x_{i})_{n\in\mathbb{N}}\in\textbf{FAC}^{0}_{R}\setminus\textbf{FSAC}^{0}_{R}
,
because using only binary gates they require circuit families of logarithmic depth.

Because these circuits can only compute functions where each component is defined by a polynomial,
which are continuous, while transformers can compute uncontinuous functions,
we need to extend the circuit bases with other functions.
For this purpose we use the following notation.

Definition 2.9
.

Let
(S,B)
and
(S,A)
be circuit bases.
Then
\textbf{FSizeDepth}_{(S,B)\!}(f_{s},\!f_{d})[A]=\textbf{FSizeDepth}_{(S,A\cup B)\!}(f_{s},\!f_{d})
.
For a semiring
R
, we use
\textbf{FCirc}_{R}[A]
for functions computed by circuits over

(R,\{+_{*},\times_{*}\}\cup A)
.

When explicitly listing the contents of the set
A
, the braces will be omitted,
e.g.
\textbf{FNC}^{0}_{R}[f,g]
instead of
\textbf{FNC}^{0}_{R}[\{f,g\}]
.

2.3
Characteristic Functions

It will later be useful to distinguish elements of a fixed finite set.
This requires the following kind of function.

Definition 2.10
.

Let
A
be a set and
a\in A
.
Then the function
\chi^{A}_{a}\colon A\to\{0,1\}
is defined as

\chi^{A}_{a}(x)=\begin{cases}1&\text{if }x=a\text{ and}\\
0&\text{otherwise}\end{cases}.

Such a function is not generally computable by an arithmetic circuit unless
A=\{0,1\}
.
One way to mitigate this fact is adding the
\zero
function to a ring.
It is defined as

\zero(x)=\begin{cases}1&\text{if }x=0\\
0&\text{otherwise}\end{cases}.

Lemma 2.11
.

Let
R
be a ring and
r\in R
.
Then
\chi^{R}_{r}\in\textbf{FCirc}_{R}[\zero]
.

Proof.

The following formula
describes such a circuit:

\chi^{R}_{r}(x)=\zero(x-r)=\zero(x+(-1)\times r)\qed

If
R
is a field, we can instead use Lagrange polynomials to interpolate any finite set of values.

Lemma 2.12
.

Let
R
be a field,
A\subseteq R
be finite and
a\in A
.
Then there is a polynomial
p^{A}_{a}\colon R\to R
in
\textbf{FCirc}_{R}

such that
p^{A}_{a}(x)=\chi^{A}_{a}(x)
for all
x\in A
.

The proof can be found in the
Appendix
.

2.4
Generalized Transformers

We adapt a definition by
5

(
5
)

to describe transformer encoders using values from arbitrary semirings.
Also, instead of using them for decision problems,
we look at the functions computed by encoders with no output layer.
This allows us to directly output real values and compare them to the values computed by circuit families.

A transformer can have multiple layers with multiple attention heads.
Each head uses an attention function to compute attention scores between pairs of vectors and
a pooling function to combine all vectors based on those.
The activation function of a layer takes in the results of its attention heads.
Usually, the activation functions are computed by feedforward networks,
the attention functions are dot-products and
the pooling functions apply softmax to the attention scores and compute a weighted sum of all vectors.

Definition 2.13
.

A
generalized transformer
with
K
layers and
H
attention heads is a tuple

(R,\allowbreak d,\allowbreak\Sigma,\allowbreak f^{\text{in}},\allowbreak f^{\text{pos}},\allowbreak f^{\text{att}}_{1,1},\allowbreak f^{\text{att}}_{1,2},\dots,f^{\text{att}}_{K,H},\allowbreak f^{\text{pool}}_{1,1},\dots,f^{\text{pool}}_{K,H},\allowbreak f^{\text{act}}_{1},\dots,f^{\text{act}}_{K})
where

•

R
is the underlying semiring,

•

d\in\mathbb{N}
is the dimension,

•

\Sigma
is the (possibly infinite) input alphabet,

•

f^{\text{in}}\colon\Sigma\to R^{d}
is the input embedding,

•

f^{\text{pos}}\colon\mathbb{N}\times\mathbb{N}\to R^{d}
is the positional embedding,

•

f^{\text{att}}_{k,h}\colon R^{d}\times R^{d}\to R
is the attention function for attention head
h
in layer
k
,

•

f^{\text{pool}}_{k,h}\colon(R^{d})^{*}\times R^{*}\to R^{d}
is the pooling function for attention head
h
in layer
k
and

•

f^{\text{act}}_{k}\colon(R^{d})^{H+1}\to R^{d}
is the activation function for layer
k
.

Such a transformer computes a function
T\colon\Sigma^{*}\to(R^{d})^{*}
defined by induction over
k
.
First, the input sequence
X=(x_{1},\dots,x_{n})\in\Sigma^{*}
is turned into
a sequence of
R^{d}
-vectors using input and positional embedding:

Y^{0}=\big(f^{\text{in}}(x_{1})+f^{\text{pos}}(1,n),\dots,f^{\text{in}}(x_{n})+f^{\text{pos}}(n,n)\big)

Then each layer
k
transforms the previous sequence
Y^{k-1}
into a sequence
Y^{k}
of the same length in the following way.
The attention function of each attention head
h
produces an
n\times n
matrix of attention values:

a^{k,h}_{i,j}=f^{\text{att}}_{k,h}(Y^{k-1}_{i},Y^{k-1}_{j})\quad\text{for }1\leq i,j\leq n

The pooling function of each attention head
h
turnes it back into a vector sequence:

Z^{k,h}_{i}=f^{\text{pool}}_{k,h}\big(Y^{k-1},(a^{k,h}_{i,1},\dots,a^{k,h}_{i,n})\big)\quad\text{for }1\leq i\leq n

Finally, the activation function of the layer is applied to each vector in those sequences:

Y^{k}_{i}=f^{\text{act}}_{k}\big(Y^{k-1}_{i},Z^{k,1}_{i},\dots,Z^{k,H}_{i}\big)\quad\text{for }1\leq i\leq n

The output of the transformer is just the output of the last layer:
T(X)=Y^{K}
.

2.5
Restricted Transformers

We can define classes of transformers by restricting the choices for the functions they use.

Definition 2.14
.

Let
R
be a semiring and
A,B,C,D,E
be sets of functions.
Then
\textbf{GT}_{R}\big(A,\allowbreak B,\allowbreak C,\allowbreak D,\allowbreak E\big)
is the set of transformers using

R
as the underlying semiring, input embeddings from
A
,
positional embeddings from
B
, activation functions from
C
,
attention functions from
D
and pooling functions from
E
and

\textbf{FT}_{R}\big(A,\allowbreak B,\allowbreak C,\allowbreak D,\allowbreak E\big)
is the set of functions computed by them.

To describe the original transformer model by
9

(
9
)
,
we define three sets of functions.

\textbf{DPA}_{R}
is the set of attention functions computable via dot-products.

\textbf{WS}_{R}(f)
describes a weighted sum using the resulting values of a function
f
on the attention scores.
And
\textbf{WP}_{R}(f)
is a variation of
\textbf{WS}_{R}(f)
that uses multiplication instead of addition
while also excluding zero values and will be used later.

Definition 2.15
.

Let
R
be a semiring and
f\colon R^{*}\to R^{*}
.

\displaystyle\textbf{DPA}_{R}

\displaystyle=\left\{\begin{gathered}g\colon R^{d}\times R^{d}\to R,\\
(\overline{x},\overline{y})\mapsto A\overline{x}\cdot B\overline{y}\end{gathered}\,\middle|\,\begin{gathered}d\in\mathbb{N}\text{ and}\\
A,B\in R^{d\times d}\end{gathered}\right\}

\displaystyle\textbf{WS}_{R}(f)

\displaystyle=\left\{\begin{gathered}g\colon(R^{d})^{*}\times R^{*}\to R^{d},\\
(X,\overline{a})\mapsto\sum_{i=1}^{|X|}f(\overline{a})_{i}\times X_{i}\end{gathered}\,\middle|\,d\in\mathbb{N}\right\}

\displaystyle\textbf{WP}_{R}(f)

\displaystyle=\left\{\begin{gathered}g\colon(R^{d})^{*}\times R^{*}\to R^{d},\\
(X,\overline{a})\mapsto\bigodot_{\begin{subarray}{c}i=1\\
\hskip-32.7779ptf(\overline{a})_{i}\neq 0\hskip-32.7779pt\end{subarray}}^{|X|}f(\overline{a})_{i}\times X_{i}\end{gathered}\,\middle|\,d\in\mathbb{N}\right\}

Here
\odot
is used for element-wise multiplication of vectors.

The original model uses
R=\mathbb{R}

and pooling functions from
\textbf{WS}_{R}(\softmax)
where

\softmax(\overline{a})_{i}=\frac{e^{a_{i}}}{\sum_{j=1}^{|\overline{a}|}e^{a_{j}}}.

This scheme is called soft attention.
In this paper, we are only concerned with hard attention,
because it makes it possible to attend only to specific vectors.
There are three variants of hard attention.
Leftmost (or unique) and rightmost attention are defined by the functions

\displaystyle\hardleft(\overline{a})

\displaystyle=\begin{cases}1&\text{if }i=\min M\\
0&\text{otherwise}\end{cases}

\displaystyle\text{ and }\hardright(\overline{a})

\displaystyle=\begin{cases}1&\text{if }i=\max M\\
0&\text{otherwise}\end{cases}

\displaystyle\text{ with }M

\displaystyle=\{i\mid a_{i}\text{ is maximal in }\{a_{1},\dots,a_{|\overline{a}|}\}\}.

Here we say that each vector attends to only one vector.
Average attention is defined by the function

\avg(\overline{a})_{i}=\begin{cases}\frac{1}{|M|}&\text{if }i\in M\\
0&\text{otherwise}\end{cases}.

Here each vector attends to
|M|
vectors.

These attention schemes correspond to pooling functions from

\textbf{WS}_{R}(\hardleft),\textbf{WS}_{R}(\hardright)
and
\textbf{WS}_{R}(\avg)
respectively.
They require a (partial) order on
R
to define maximal elements while

\avg
also relies on the existence of multiplicative inverses of
\mathbb{N}\setminus\{0\}
.

3
Simulating Transformers with Circuits

The equations describing the computation of a transformer can be seen as a description of a circuit family.
Their length is only dependent on the length
n
of the input sequence.
If all functions used by a generalized transformer
T
are computable by circuits and we fix
n
,
we can connect those together to construct a circuit for
T
.
The circuits for all
n
form a circuit family.
This requires the input alphabet
\Sigma
to be a subset of
R^{k}
for some
k
,
but if it is finite, the complexity of a mapping
f\colon\Sigma\to R^{k}
is essentially trivial.

Because transformers have a fixed number of layers,
the depth of the resulting circuits grows linearly with the depth of the circuits for the functions they use. The pooling functions are the only ones that require a circuit family,
as all others are defined on fixed-size vectors.
Therefore, if those families have constant depth, so will the family for the transformer.
The size also grows linearly with the size of the pooling function circuits,
but it is at least quadratic in
n
, because of the
n\times n
matrix of attention values.
For a detailed explanation of this construction, see
4

(
4
)
.

Theorem 3.1
.

Let
R
be any semiring,
(R,B)
a circuit basis and
P\subseteq\{f\colon\mathbb{N}^{2}\to R\}
. Then

\textbf{FT}_{R}\big(\textbf{FCirc}_{R}[B],\allowbreak P,\allowbreak\textbf{FCirc}_{R}[B],\allowbreak\textbf{FCirc}_{R}[B],\allowbreak\textbf{FNC}^{0}_{R}[B]\big)\allowbreak\subseteq\textbf{FNC}^{0}_{R}[B]
.
This also holds if we replace
FNC
with
FSAC
or
FAC
.

There is no restriction on the positional embedding,
because it does not actually need to be computed by the circuit family.
Since it is only dependent on the number of inputs,
its values can be stored in constant gates.

3.1
Simulating Restricted Transformers

Dot-products over any semiring
R
can be computed by arithmetic circuits, so
\textbf{DPA}_{R}\subseteq\textbf{FCirc}_{R}
.
For the hard attention functions, we get
\hardleft,\hardright,\avg\in\textbf{FSAC}^{0}_{R}[\sign]

where

\sign(x)=\begin{cases}1&\text{if }x>0\\
0&\text{if }x=0\\
-1&\text{if }x<0\end{cases}.

So
\textbf{WS}_{R}(\hardleft),\textbf{WS}_{R}(\hardright),\textbf{WS}_{R}(\avg)\subseteq\textbf{FSAC}^{0}_{R}[\sign]
.
The most common type of activation function is a feed-forward network using the
rectified linear unit function which are also part of
\textbf{FCirc}_{R}[\sign]
.
All together, these restricted transformers compute functions in
\textbf{FSAC}^{0}_{R}[\sign]
.

4
Simulating Circuits with Transformers

Because transformers are length-preserving,
they cannot directly compute functions that are not.
To work around this difference,
the input to the transformer must be long enough to fit the output of the function.
We choose a similar approach to
2

(
2
)
.
They used graph neural networks on graphs of circuits to compute their output values.
Since transformers only work on vectors of numbers, we need some way to encode the circuits as such.

We use one vector for each edge in the circuit, so the length of the encoding is quadratic with respect to the size of the circuit.
We assume that the gates are numbered with indices from
\mathbb{N}
.
The types of the gates will be encoded with their incoming edges.
Since the input and constant gates do not have any, we also add one vector for each of those.

Definition 4.1
.

Let
R
be a semiring extension of
\mathbb{N}
,
C=(V,E,\alpha,\beta)
an
R
-circuit with
n
inputs
and
\overline{u}\in R^{n}
.
We fix a set
T=\{{t}_{\textit{c}},{t}_{\textit{in}},{t}_{\textit{out}},{t}_{+},{t}_{\times}\}\subseteq R

of different constants for the gate types.
For
V=\{v_{1},\dots,v_{|V|}\}
we define the
encoding

E_{C}(C,\overline{u})\in(R^{5})^{*}
as follows:

•

For each constant gate
v_{i}\in\{v\mid v\in V,\beta(v)\in R\}

we add the vector
(i,0,0,{t}_{\textit{c}},\beta(v_{i}))
.

•

For each input gate
v_{i}\in\{v\mid\beta(v)\in\{x_{1},\dots,x_{n}\}\}

we add the vector
(i,0,0,{t}_{\textit{in}},u_{k})
where
\beta(v_{i})=x_{k}
.

•

For each edge
(v_{i},v_{j})\in E
we add the vector
(j,i,\alpha((v_{i},v_{j})),t,0)

where
t
is either
{t}_{+},{t}_{\times}
or
{t}_{\textit{out}}

depending on whether
v_{j}
is a
+,\times
or output gate.

To improve the readability,
we denote the components
(x_{1},x_{2},x_{3},x_{4},x_{5})
of these vectors by
(x_{s},x_{p},x_{i},x_{t},x_{v})
,
so the vector
\overline{x}

the index of the predecessor

\alpha((u,v))

,
the type of

in

and
the value assigned to

Definition 4.3
.

We say that a transformer
T

simulates
a circuit
C
with
n
inputs encoded with
E_{C}
,
if for all
\overline{x}\in R^{n}
,
the values assigned to the incoming edges of output gates in
T(E_{C}(C,\overline{x}))
are exactly
f_{C}(\overline{x})
.

We can use attention heads to fetch the values of the predecessors of each gate
and propagate them along the edges.
This is a relatively simple construction if we leave some freedom for the attention and pooling functions,
but it is still possible with a restriction to hard dot-product attention.
The proofs for all statements in this section have been deferred to the appendix.

4.1
Using Generalized Attention

For the input embedding we use the identity function
\id
,
so the transformer uses the same dimension as the encoding.
We define two attention functions
f^{\text{att}}_{E},f^{\text{att}}_{V}\colon R^{5}\times R^{5}\to R
.
The first one,

f^{\text{att}}_{E}(\overline{x},\overline{y})=\begin{cases}1&\text{if }x_{p}=y_{s}\\
0&\text{otherwise}\end{cases},

lets
\overline{x}
attend only to those vectors describing incoming edges of the
x_{p}
-th gate.
It will be used to transfer the values from the incoming to the outgoing edges of each node.
The second attention function,

f^{\text{att}}_{V}(\overline{x},\overline{y})=\begin{cases}1&\text{if }x_{s}=y_{s}\\
0&\text{otherwise}\end{cases},

lets the vectors of all incoming edges of the same gate attend only to each other.
It will be used to compute the values of the gates from the values of its predecessors.
If
R
is a ring, both functions are computed by an
R
-circuit using the
\zero
function,
since
f^{\text{att}}_{E}(\overline{x},\overline{y})=\zero(x_{p}-y_{s})
and
f^{\text{att}}_{V}(\overline{x},\overline{y})=\zero(x_{s}-y_{s})
.

Now we can define one pooling function for addition and one for multiplication to simulate the arithmetic gates.
They will be used by different attention heads in the same layer
and the activation function will choose which one to use based on the gate type.
One possible choice for pooling functions is

f^{\text{pool}}_{+}(X,\overline{a})=\sum_{i=1}^{|X|}a_{i}\times X_{i}\text{ and }f^{\text{pool}}_{\times}(X,\overline{a})=\bigodot_{\begin{subarray}{c}i=1\\
a_{i}\neq 0\end{subarray}}^{|X|}a_{i}\times X_{i}.

Note that
f^{\text{pool}}_{+}\in\textbf{WS}_{R}(\id)
and
f^{\text{pool}}_{\times}\in\textbf{WP}_{R}(\id)
where
\id\colon R^{*}\to R^{*}
is the identity on sequences.
To choose the right value based on the gate type, we need the functions

\chi^{T}_{t}\colon T\to\{0,1\}
for
t\in T=\{{t}_{\textit{c}},{t}_{\textit{in}},{t}_{\textit{out}},{t}_{+},{t}_{\times}\}
.
We define an activation function
f^{\text{act}}_{V}\colon(R^{5})^{3}\to R^{5}
as

\displaystyle f^{\text{act}}_{V}(\overline{x}^{in},\overline{x}^{+},\overline{x}^{\times})_{v}=\big(\chi^{T}_{{t}_{\textit{in}}}(\overline{x}^{in}_{t})+\chi^{T}_{{t}_{\textit{c}}}(\overline{x}^{in}_{t})\big)

\displaystyle\times\overline{x}^{in}_{v}+

\displaystyle\big(\chi^{T}_{{t}_{\textit{out}}}(\overline{x}^{in}_{t})+\chi^{T}_{{t}_{+}}(\overline{x}^{in}_{t})\big)

\displaystyle\times\overline{x}^{+}_{v}+

\displaystyle\chi^{T}_{{t}_{\times}}(\overline{x}^{in}_{t})

\displaystyle\times\overline{x}^{\times}_{v}

and
f^{\text{act}}_{V}(\overline{x}^{in},\overline{x}^{+},\overline{x}^{\times})_{j}=\overline{x}^{in}_{j}
for
j\in\{s,p,i,t\}
.
This function retains the values for input and constant gates as well as all information about the circuit.
Due to
Lemma

2.11
, we get
f^{\text{act}}_{V}\in\textbf{FCirc}_{R}[\zero]
for any ring
R
,
but if
R
is a field, we can use polynomials from
Lemma

2.12
instead.

Because the attention function
f^{\text{att}}_{E}
must be used before this to move the predecessor values into
x_{v}
,
we add a second transformer layer.
The activation function
f^{\text{act}}_{E}\colon(R^{5})^{3}\to R^{5}
for this layer is defined as

f^{\text{act}}_{E}(\overline{x},\overline{y},\overline{z})_{v}=\big(\chi^{T}_{{t}_{\textit{in}}}(x_{t})+\chi^{T}_{{t}_{\textit{c}}}(x_{t})\big)\times x_{v}+\\
\big(\chi^{T}_{{t}_{\textit{out}}}(x_{t})+\chi^{T}_{{t}_{+}}(x_{t})+\chi^{T}_{{t}_{\times}}(x_{t})\big)\times y_{v}

and also retains the other values.
For the pooling function we can use
f^{\text{pool}}_{+}
or
f^{\text{pool}}_{\times}
,
because each vector of a correct encoding attends to at most one vector.

When we use all these functions to define a transformer

\Big(R,5,R^{5},\id,0,f^{\text{att}}_{E},0,f^{\text{att}}_{V},f^{\text{att}}_{V},\\
f^{\text{pool}}_{+},0,f^{\text{pool}}_{+},f^{\text{pool}}_{\times},f^{\text{act}}_{E},f^{\text{act}}_{V}\Big)

with two layers, it is able to simulate circuits of depth
1
and
by stacking more copies of these two layers, we can simulate circuits of higher depth.
We write
0
for functions of unused attention heads,
but
f^{\text{att}}_{E}
and
f^{\text{pool}}_{+}
could be used instead,
because their values are ignored by
f^{\text{act}}_{E}
.

Theorem 4.4
.

Let
R
be a commutative ring extension of
\mathbb{Z}
.
Then for each
K\in\mathbb{N}
there is a transformer
in
\textbf{GT}_{R}\big(\{\id\},\allowbreak\{0\},\allowbreak\textbf{FCirc}_{R}[\zero],\allowbreak\textbf{FCirc}_{R}[\zero],\allowbreak\textbf{WS}_{R}(\id)\cup\textbf{WP}_{R}(\id)\big)

of dimension
5
with
2K
layers
that simulates any unbounded fan-in
R
-circuit of depth
\leq K
encoded with
E_{C}
.

This also implies that, for each
\textbf{FAC}^{0}_{R}
-circuit family,
there is a transformer that can simulate all of its circuits.

4.2
Using Hard Attention

A similar construction can be done using average dot-product attention, but there are two key differences.
Firstly it attends only to the maximal attention values.
Therefore we need two dot-products
f^{\text{att}}_{E},f^{\text{att}}_{V}
such that
for a fixed
\overline{x}
the values
f^{\text{att}}_{E}(\overline{x},\overline{y})
and
f^{\text{att}}_{V}(\overline{x},\overline{y})
reach their maximum
among all vectors
\overline{y}
when
x_{p}=y_{s}
and
x_{s}=y_{s}
respectively.
Secondly average attention scales the result by a factor of
\frac{1}{k}
where
k
is the number of such values.
This can be counteracted by computing how many vectors were attended to and multiplying the result by that number.
We will use the pooling functions

\displaystyle f^{\text{pool}}_{+}(X,\overline{a})

\displaystyle=\sum_{i=1}^{|X|}\avg(\overline{a})_{i}\times X_{i}\in\textbf{WS}_{R}(\avg)\text{ and}

\displaystyle f^{\text{pool}}_{\times}(X,\overline{a})

\displaystyle=\bigodot_{\begin{subarray}{c}i=1\\
\hskip-32.7779pt\avg(\overline{a})_{i}\neq 0\hskip-32.7779pt\end{subarray}}^{|X|}\avg(\overline{a})_{i}\times X_{i}\in\textbf{WP}_{R}(\avg).

They require the underlying semiring to have a (partial) order and
we assume it is compatible with the usual order of the integers.
Then we can define

\displaystyle f^{\text{att}}_{E}(\overline{x},\overline{y})

\displaystyle=x_{p}^{2}-(y_{s}-x_{p})^{2}

\displaystyle=2x_{p}y_{s}-y_{s}^{2}=2y_{s}\times x_{p}-x_{one}\times y_{ssq}\text{ and}

\displaystyle f^{\text{att}}_{V}(\overline{x},\overline{y})

\displaystyle=x_{s}^{2}-(y_{s}-x_{s})^{2}

\displaystyle=2x_{s}y_{s}-y_{s}^{2}=2x_{s}\times y_{s}-x_{one}\times y_{ssq}.

This is implemented by adding two more dimensions to each vector and
setting them to
x_{one}=1
and
x_{ssq}=x_{s}^{2}
.
These values can be set either by the input embedding or by the activation function of an additional transformer layer.

To count the predecessors of each gate, we can use the numbering of the edges.
When using average attention on a vector with predecessors
\overline{x}^{1},\dots,\overline{x}^{k}

having values
\{1,\dots,k\}
in
x_{i}
,
the result
\overline{y}
of the pooling function
f^{\text{pool}}_{+}
has

y_{i}=\sum_{j=1}^{k}\frac{j}{k}=\frac{k(k+1)}{2k}=\frac{k+1}{2}.

Therefore we can compute the number of predecessors as
k=2\times y_{i}-1
.
If this computation is also done in the first layer,
we can multiply the intermediate values by
k
to correct for the scaling of average attention.

Because the definition of average attention requires multiplicative inverses of
\mathbb{N}\setminus\{0\}
,
the following theorems only hold, when
R
is an extension of
\mathbb{Q}
.
This also allows for using polynomials from
Lemma

2.12
for the
\chi^{T}_{t}
functions.

The modified version of
f^{\text{act}}_{E}
is defined as

f^{\text{act}}_{E}(\overline{x},\overline{y},\overline{z})_{v}=\big(\chi^{T}_{{t}_{\textit{in}}}(x_{t})+\chi^{T}_{{t}_{\textit{c}}}(x_{t})\big)\times x_{v}+\\
\big(\chi^{T}_{{t}_{\textit{out}}}(x_{t})+\chi^{T}_{{t}_{+}}(x_{t})+\chi^{T}_{{t}_{\times}}(x_{t})\big)\times(2\times z_{i}-1)\times y_{v}

and
f^{\text{act}}_{E}(\overline{x},\overline{y},\overline{z})_{j}=\overline{x}_{j}
for
j\in\{s,p,i,t,n,one,ssq\}
.
For
f^{\text{act}}_{V}
, we use the previous definition while also retaining the new components.
Finally, we define the input embedding
f^{\text{in}}\colon R^{5}\to R^{7}
as

f^{\text{in}}(\overline{x})=\big(x_{s},\dots,x_{v},1,x_{s}^{2}\big)
.
The new two layer transformer is now

\Big(R,7,R^{5},f^{\text{in}},0,f^{\text{att}}_{E},f^{\text{att}}_{V},f^{\text{att}}_{V},f^{\text{att}}_{V},\\
f^{\text{pool}}_{+},f^{\text{pool}}_{+},f^{\text{pool}}_{+},f^{\text{pool}}_{\times},f^{\text{act}}_{E},f^{\text{act}}_{V}\Big).

4.3
Simulating Bounded Fan-in

If we only look at semi-unbounded fan-in circuits,
the second pooling function can be eliminated from the transformer.
To compute the values of binary multiplication gates,
we have one attention head attend to the first edge of each gate and one to the second.
The two values are then multiplied by the activation function.
We define the attention function
f^{\text{att}}_{B(n)}\colon R^{8}\times R^{8}\to R
as

f^{\text{att}}_{B(n)}(\overline{x},\overline{y})=x_{s}^{2}-(y_{s}-x_{s})^{2}+n^{2}-(y_{i}-n)^{2}\\
=2x_{s}\times y_{s}-x_{one}\times y_{ssq}+2nx_{one}\times y_{i}-x_{one}\times y_{isq}.

This requires another dimension with
x_{isq}=x_{i}^{2}
.
When
\overline{x}
has an
n
-th predecessor,
the function reaches its maximum value only when
y_{s}=x_{s}
and
y_{i}=n
.
We can now replace the attention head using
f^{\text{pool}}_{\times}

with two attention heads using
f^{\text{att}}_{B(1)}
and
f^{\text{att}}_{B(2)}

and redefine the second activation function

\displaystyle f^{\text{act}}_{V}(\overline{x}^{in},\overline{x}^{+},\overline{x}^{1},\overline{x}^{2})_{v}=\quad

\displaystyle\big(\chi^{T}_{{t}_{\textit{in}}}(\overline{x}^{in}_{t})+\chi^{T}_{{t}_{\textit{c}}}(\overline{x}^{in}_{t})\big)

\displaystyle\times\overline{x}^{in}_{v}+

\displaystyle\big(\chi^{T}_{{t}_{\textit{out}}}(\overline{x}^{in}_{t})+\chi^{T}_{{t}_{+}}(\overline{x}^{in}_{t})\big)

\displaystyle\times\overline{x}^{+}_{v}+

\displaystyle\chi^{T}_{{t}_{\times}}(\overline{x}^{in}_{t})

\displaystyle\times(x^{1}_{v}\times x^{2}_{v}).

Because the two attention heads attend only to one value,
we need to exclude multiplication gates from the correction factor we previously applied in
f^{\text{act}}_{E}
.
Therefore

\displaystyle f^{\text{act}}_{E}(\overline{x},\overline{y},\overline{z},\overline{w})_{v}=\big(\chi^{T}_{{t}_{\textit{in}}}(x_{t})+\chi^{T}_{{t}_{\textit{c}}}(x_{t})\big)

\displaystyle\times x_{v}+

\displaystyle\big(\chi^{T}_{{t}_{\textit{out}}}(x_{t})+\chi^{T}_{{t}_{+}}(x_{t})\big)

\displaystyle\times(2z_{i}-1)\times y_{v}

\displaystyle+\;\chi^{T}_{{t}_{\times}}(x_{t})

\displaystyle\times y_{v}.

We also add the new dimension to the activation functions and the input embedding

f^{\text{in}}(\overline{x})=\big(x_{s},\dots,x_{v},1,x_{s}^{2},x_{i}^{2}\big)
.
The new two layer transformer is now

\Big(R,8,R^{5},f^{\text{in}},0,f^{\text{att}}_{E},f^{\text{att}}_{V},0,f^{\text{att}}_{V},f^{\text{att}}_{B(1)},f^{\text{att}}_{B(2)},\\
f^{\text{pool}}_{+},f^{\text{pool}}_{+},0,f^{\text{pool}}_{+},f^{\text{pool}}_{+},f^{\text{pool}}_{+},f^{\text{act}}_{E},f^{\text{act}}_{V}\Big).

4.4
Simulating Circuit Extensions

Using the attention functions
f^{\text{att}}_{B(3)},f^{\text{att}}_{B(4)},\dots

we can fetch the values from an arbitrary number of predecessors.
This works as long as the fan-in of the gates is bounded by the number of attention heads.
So for any set
B
of functions
f\colon R^{k}\to R
,
we can simulate circuits over the basis
(R,B)

if we allow activation functions from
\textbf{FCirc}_{R}[B]
.
This requires an expansion of the encoding
E_{C}
to include the gate types for
B
.

Theorem 4.10
.

Let
R
be a
\mathbb{Z}
-ordered ring extension of
\mathbb{Q}
,
and
B
a finite set of functions
f\colon R^{k}\to R
.
Then for each
K\in\mathbb{N}
there is a transformer

5
Conclusion

In this paper, we established a correspondence between
generalized average attention transformers using circuits as activation functions and
the arithmetic circuit class
\textbf{FSAC}^{0}_{R}[\sign]
.
Over any semiring
R
, these transformers only compute functions in
\textbf{FSAC}^{0}_{R}[\sign]
and
if
R
is a
\mathbb{Z}
-ordered ring extension of
\mathbb{Q}
,
there is a transformer for each
\textbf{FSAC}^{0}_{R}[\sign]
-family that can simulate all of its circuits encoded with
E_{C}
.
Unfortunately, this is not possible while only allowing feed-forward networks as activation functions,
because those cannot perform multiplication of two inputs.

This does not imply that any
\textbf{FSAC}^{0}_{R}[\sign]
-function is also computed by a transformer.
In fact, this would be impossible, as circuit families are a non-uniform model of computation.
If we used transformers to generate longer sequences of vectors, similar to how they are used in natural language processing,
we could also compute the encoding of a circuit from just the input vector.
Our result would then lead to an equivalence between circuit families that are uniformly described by a transformer and
the functions computed by such transformers.

Impact Statement

This paper presents work whose goal is to advance the field of machine learning theory.
There are many potential societal consequences of our work,
none of which we feel must be specifically highlighted here.

\displaystyle f^{\text{att}}_{z\pm}(\overline{x},\overline{y})

\displaystyle=\pm x_{v}\times y_{s}

\displaystyle+\frac{9}{4}-(y_{s}-\frac{3}{2})^{2}+\frac{1}{4}-(y_{i}-\frac{1}{2})^{2}

\displaystyle=\pm x_{v}\times y_{s}

\displaystyle+\frac{3}{2}x_{one}\times y_{s}-x_{one}\times y_{ssq}

\displaystyle+\frac{1}{2}x_{one}\times y_{i}-x_{one}\times y_{isq}.

Because every non-empty circuit has at least two nodes and
every valid encoding of a circuit has only integer values in
x_{s}
and
x_{i}
,
the term
-(y_{s}-\frac{3}{2})^{2}
reaches its maximum only when
y_{s}=1
or
y_{s}=2
and
the term
-(y_{i}-\frac{1}{2})^{2}
reaches its maximum only when
y_{i}=0
or
y_{i}=1
.
There are two cases for each of the two gates with indices
1
and
2
:

•

If the gate is an input or constant gate,
it has only one corresponding vector
\overline{y}
with
y_{i}=0
.

•

Otherwise, the gate may have multiple corresponding vectors,
but it has exactly one with
y_{i}=1
.

In both cases, there are exactly two vectors for which the term

-(y_{s}-\frac{3}{2})^{2}-(y_{i}-\frac{1}{2})^{2}
is maximal.
Let those be
\overline{y}
and
\overline{z}
such that
y_{s}=1
and
z_{s}=2
.
Then for any vector
\overline{x}
, we get

f^{\text{att}}_{z+}(\overline{x},\overline{z})-f^{\text{att}}_{z+}(\overline{x},\overline{y})=(z_{s}-y_{s})\times x_{v}=x_{v}

and
f^{\text{att}}_{z-}(\overline{x},\overline{z})-f^{\text{att}}_{z-}(\overline{x},\overline{y})=-x_{v}
.
When these attention functions are used in an attention head with
f^{\text{pool}}_{+}

resulting in vectors
\overline{u}^{+}
and
\overline{u}^{-}
, there are three cases for
u^{+}_{s}
and
u^{-}_{s}

•

If
x_{v}=0
,
\overline{x}
attends only to
\overline{y}
and
\overline{z}
.
Therefore,
u^{+}_{s}=u^{-}_{s}=\frac{1+2}{2}=\frac{3}{2}
.

•

If
x_{v}<0
,
f^{\text{att}}_{z+}
makes
\overline{x}
attend only to
\overline{y}
,
because
f^{\text{att}}_{z+}(\overline{x},\overline{y})>f^{\text{att}}_{z+}(\overline{x},\overline{z})
.
Therefore,
u^{+}_{s}=1
.

•

If
x_{v}>0
,
f^{\text{att}}_{z-}
makes
\overline{x}
attend only to
\overline{y}
,
because
f^{\text{att}}_{z-}(\overline{x},\overline{y})>f^{\text{att}}_{z-}(\overline{x},\overline{z})
.

u^{-}_{s}=1
.

Any other vector
\overline{w}
cannot have an effect here,

-x_{v}\times w_{s}\leq-x_{v}\times y_{s}

x_{v}\times w_{s}\leq x_{v}\times y_{s}

\zero(x_{v})=4\times(u^{+}_{s}-1)\times(u^{-}_{s}-1)

Because the transformer does not need to compute anything if there are no output gates and

If
