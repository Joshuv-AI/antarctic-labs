The search for exotic knot traces
Marc Kegel, Jonathan Spreer

Abstract
. Two distinct knots are said to be friends if their complements, filled along the 0 0 -slope, produce diffeomorphic 3 3 -manifolds. In this article, we develop a practical algorithm, implemented using SnapPy and Regina , to search for a friend of a given knot. As an application, we construct a census of simple knots that admit friends and use these data to formulate conjectures about knot friends.

We say that two knots in the

Question 1.1

Given a knot

Question 1.2

Is there an algorithm that, given a knot

1.1.
Algorithmic search for friends

The main contribution of this article is code and the results of running this code. Namely, we have the following result.

Algorithm
1

(Friend search)

There exists a practical and implemented algorithm that takes as input a diagram of a knot
K
, or a triangulation of the exterior of
K
, and outputs a (possibly empty) list of friends of
K
.

Note that the solution of the homeomorphism problem for closed
3

3

[

[
26

implies the existence of an algorithm that takes as input a knot

and outputs in finite time any given friend of
K
– if it exists: Enumerate all knots

by increasing crossing number, create their
0

, and check if

and
K^{\prime}(0)
are diffeomorphic. This approach was taken in
[
1
]
for knots of low complexity. However, since the enumeration of knots has super-exponential running time in the crossing number, this is impractical in general. Nonetheless, on a theoretical level,
1.2
reduces to certifying that a given knot has no friend.

Algorithm

1

K
and first constructs a
1
-vertex triangulation of its
0
-surgery.
It then removes an embedded closed curve
c
from
K(0)
, and checks if
K(0)\setminus c
is the complement of a knot in
S^{3}
using the
6
-theorem
[
2
,
36
]
. This procedure is then iterated over all curves
c
in
K(0)
up to ambient isotopy (i.e. over all knots in
K(0)
) using a sensibly chosen order.

For producing a
1
-vertex triangulation of
K(0)
from the input diagram, we use readily available functionality of
SnapPy

[
15
]
. For enumerating a list of curves

to remove from

we use the fact that every edge in a
1
-vertex triangulation describes an embedded closed curve in the underlying manifold: We first produce a list of
1
-vertex triangulations of
K(0)
by exhaustively modifying the initial triangulation using local moves (e.g. bi-stellar flips
[
45
,
50
]

[

Section

2

By standard arguments (carried out rigorously in a more specialised setting in

), we can expect every ambient isotopy class of a closed curve in

to be realised as an edge in some triangulation of

of

is observed by an edge in a triangulation of

3

A similar algorithm for hyperbolic
0

[
19

and further extended and used in
[
18

1

1.3.
Piccirillo friends

Let

As the notation suggest the Piccirillo friend construction is independent of the diagram

unknotting arc

x

Piccirillo friends of twisted Whitehead doubles are isotopic to the original knot; see for example

below. Regarding the converse, we verify that for all but the

is not isotopic to

Conjecture
5.5

The Piccirillo friend

of a knot

1.4.
Concordance friends

In the last part of the article, we present another (so far unsuccessful) method to search for friends with different sliceness status. We say that two knots
K
and
K^{\prime}
are
concordance friends
if there exists a sequence of knots

K=K_{1},K_{2},K_{3},\ldots,K_{n-1},K_{n}=K^{\prime}

such that for every
i
, the knots
K_{i}
and
K_{i+1}
are either concordant or friends. Since concordant knots have the same smooth
4
-genus and thus the same sliceness status, we immediately obtain the following.

Corollary 1.5

If there exist concordance friends with different sliceness statuses, then there exists a smooth
4
-manifold that is homotopy equivalent to
S^{4}
but not diffeomorphic to
S^{4}
.∎

To search for concordance friends, we attach ribbon bands (see
6.1
) to a given knot
K
to create knots that are concordant to
K
.

Algorithm
3

(Concordance search)

There exists a practical and implemented algorithm that takes as input a knot diagram of a knot
K
and outputs arbitrarily many knots
K^{\prime}

(
presented as diagrams
)
that are concordant to
K
.

In Section
6
, we explain
Algorithm

3
in more detail and combine it with
Algorithm

1
to obtain an algorithm that searches for concordance friends of an input knot, see
Algorithm

4
. As an application, we explain a new strategy to search for concordance friends with different sliceness status, see
Algorithm

6
. We also apply our code to find concordance friends of many torus knots, cables, and Whitehead doubles. Note that it follows from
[

that any knot has a concordance friend (that is not obviously concordant to

2.
The friend search

In this section, we present
Algorithm

1
to search for a friend of a given knot
K
.

Algorithm 1

Algorithm to search for friends of a given knot
K
.

Input:

A knot diagram
D
representing the knot
K
.

Output:

A (possibly empty) list of knot diagrams representing friends of
K
.

(1)

In
SnapPy
, construct an ideal triangulation of the knot complement of
K
.

(2)

Create the
0
-surgery
K(0)
on this ideal triangulation.

(3)

Send
K(0)
to
Regina
to obtain a
1
-vertex triangulation
T
of
K(0)
.

(4)

For each edge
e
in
T
:

(a)

Drill out
e
to obtain an ideal triangulation of
E=K(0)\setminus e
.

(b)

Check if
E
is diffeomorphic to the complement of a knot
K^{\prime}
in
S^{3}
:

(i)

Check if
H_{1}(E)
is isomorphic to
\mathbb{Z}
. If it is not,
E
is not a knot complement, skip to the next edge
e
.

(ii)

If
H_{1}(E)
is isomorphic to
\mathbb{Z}
, look up
E
as a triangulation of a known knot complement. If it is, add
E
to a list of potential friends, and skip to the next edge.

(iii)

If not, send
E
to
SnapPy
and search for a hyperbolic structure.

(iv)

If
SnapPy
finds a hyperbolic structure, compute all slopes of length less than
6
.

(v)

For each such slope
s
:

(A)

Create the filled manifold
E(s)
.

(B)

Check if
E(s)
is diffeomorphic to
S^{3}
(by either simplifying its fundamental group, or running
3
-sphere recognition in
Regina
).

(C)

If it is, add
E
to the list of potential friends, skip to next edge
e
.

(5)

Using a mix of knot invariants and comparisons, sort out duplicates in the list of potential friends to obtain a list of knot exteriors representing certifiably distinct knots different to
K
.

(6)

If the list of friends is empty (and some upper bound on running time is not met), apply Pachner moves to
T
, and go back to (4).

(7)

If friends have been found (represented by ideal triangulations), create their diagrams using the method described in
[
19
]
.

2.1.
Correctness and caveats of
Algorithm

1

In this section, we discuss why
Algorithm

1
, modulo some caveats and adjustments, will find any given friend
K^{\prime}
of the input knot
K
in finite time.

For Steps (1)-(3), note that
SnapPy
uses an algorithm originally due to Weeks
[
55
]
to construct an ideal triangulation of the knot complement of
K
from a diagram of
K
. The algorithm is efficient and guaranteed to return an ideal triangulation with number of tetrahedra at most four times the number of crossings of the input diagram, plus a small additive constant. Permanently filling the torus cup of the resulting ideal triangulation and sending it to Regina to obtain a
1
-vertex triangulation
T
of the closed
3
-manifold
K(0)
is again deterministic and efficient.

For Step (4), note that in a
1
-vertex triangulation of a closed
3
-manifold, every edge is a loop edge, and hence an embedding of the circle into that manifold. In particular, every edge
e
of
T
represents a knot in
K(0)
. Moreover, every (PL) embedding of a circle into a closed
3
-manifold can be triangulated with the circle being represented as a sequence of edges. Using standard moves and simplification procedures, this circle can always be transformed into a loop, and the surrounding triangulated
3
-manifold can always be turned into a
1
-vertex triangulation. The latter statement technically has a very weak and detectable caveat that does not play a role in our situation, see
[
12
]
for details. It follows that, if
K
has a friend
K^{\prime}
, then there exists a triangulation
T^{\prime}
of
K(0)
with an edge representing
K^{\prime}
. Moreover, as constructions from
[
31
,
28
]
show, such a triangulation need not necessarily be excessively large. Hence, we can hope for
K^{\prime}
to be represented by an edge in a triangulation
T^{\prime}
, where
T^{\prime}
is either
T
itself or a slight modification thereof. In fact, this hope is confirmed by the results of our experiments as presented in
Table

4
.

Step (4)(b) is implemented as a heuristic. Computing the homology of a manifold is a straightforward, polynomial time procedure. Looking up
E
in a list of known knot complements is as well. This can fail, however, if
E
does not simplify to a knot complement triangulation in the database. In rare instances, we may even miss a case where
E
is the complement of input knot
K
. However, theoretically this can be avoided since the homeomorphism problem for
3
-manifolds is solved
[
35
]
, and practically, this can be avoided by computing enough knot invariants – revealing that this problem almost never appears. Similarly,
SnapPy
may not find a hyperbolic structure on
E
, despite
E
being hyperbolic. Experiments with Dunfield’s
Regina
recognition code
[
20
]
, cf.
[
24
]
, show that this almost never happens. Theoretically, it is decidable if a manifold is hyperbolic
[
39
]
, and thus the algorithm can be made rigorous here as well. Moreover, if
SnapPy
does not find a hyperbolic structure on
E
, we can also use Dunfield’s
Regina
recognition code to check if
E
is the complement of a non-hyperbolic knot in
S^{3}
.

For Step (4)(b)(iv), it follows from the 6-theorem
[
2
,
36
]
that, if
E
is a knot complement, then there exists a filling along a slope of length less than
6
yielding
S^{3}
. Moreover, since
3
-sphere recognition is solved and implemented in
Regina
, if a filling yields
S^{3}
, we are guaranteed to find it (although, in practice, we do not run
Regina
’s
3
-sphere recognition routine, but a heuristic to simplify the fundamental group of the filled manifold, using the resolution of the Poincaré conjecture
[
46
,
47
]
).

Finally, for every triangulation of a knot complement
E
in
S^{3}
found by our algorithm, by construction, the corresponding knot
K^{\prime}
admits a Dehn filling to
K(0)
. Since a
p/q
-surgery on a knot
K
has first homology isomorphic to
\mathbb{Z}_{p}
, it follows that the
0
-surgery of
K^{\prime}
is diffeomorphic to
K(0)
and thus
K
and
K^{\prime}
are friends.

In Step (6), since any two
1
-vertex triangulations of the same closed 3-manifold are connected by a finite sequence of Pachner moves
[
41
,
45
]
, and assuming that we never miss identifying a knot complement in
S^{3}
, any exhaustive breadth first search through the Pachner graph will find every friend of
K
in finite time. In practice, the
Regina
function
retriangulate
performs exactly that up to a specified depth, and we use this function for our friend search. However, this explores many very similar triangulations with edges representing very similar curves. To counterbalance this, we also run a variant where the next triangulation is determined by the Markov chain style random walk from
[
3
]
. In both methods, we keep a list of triangulations of
K(0)
, and candidate knot complements
E
to avoid testing the same triangulations and curves multiple times.

For Step (7), given a triangulation of the complement
E
of a friend
K^{\prime}
, we use the method from
[
19
]
to turn
E
into a diagram of
K^{\prime}
. For this, we save the
S^{3}
-filling of
E
, change the basis on the cusp of
E
such that
1/0
corresponds to the meridian, and then run the method to create a diagram of
K^{\prime}
. In a second step, we use
SnapPy
to simplify the initial diagram and finally record its PD code. Note that this method is a heuristic and is not always guaranteed to work. But again theoretically there is an algorithm creating a knot diagram as a corollary of the resolution of the homeomorphism problem for
3
-manifolds with toroidal boundary.

2.2.
Other methods to find friends

If the
0
-surgery
K(0)
of
K
is hyperbolic, there are two other options to drill curves from
K(0)
as done in
[
19
]
and
[
18
]
. There, curves
c
are enumerated by considering paths in the
1
-skeleton of a dual cell-decomposition, or by drilling out short geodesics. Both options work in
SnapPy
without the use of
Regina
.

(1)

For the first option we take the triangulation
T
of
K(0)
and create closed loops
c
in the
1
-skeleton of the dual cell-decomposition of
T
. Using
SnapPy
, we drill out these curves
c
and proceed as in the above algorithm. By modifying
T
, we obtain different dual curves. However, since the way
T
is modified – as implemented in
SnapPy
– is not exhaustive, this search sometimes fails to find existing friends.

(2)

For the second option, we compute the length spectrum of
K(0)
up to a certain bound of the length. Then we drill out the geodesics in the length spectrum and proceed as above. Note that this algorithm is at the moment not guaranteed to find any given friend, since it is not known if the dual curve of a friend
K^{\prime}
is always a geodesic. For further discussion, we refer to
[
18
]
.

We implemented the above two methods. They find all low-complexity friends that were found by
Algorithm

1
. However, there are significant differences in running times. In some examples,
Algorithm

1
is much quicker to find friends, while in other examples, the methods presented here are quicker. Thus, in practice, running all three methods in parallel may be optimal. We refer to
Section

4
for further comparison of the runtimes of the different methods.

6.3.
Search for friends with different sliceness statuses

By combining the friend search (
Algorithm

1
) and the concordance search (
Algorithm

3
), we have a potential way to search for concordance friends with different sliceness statuses.

For that, we start with a finite set
F_{1}
of slice knots and use
Algorithm

3
to create a new set
F_{2}
of knots concordant to a knot in
F_{1}
. (By construction, the knots in
F_{2}
are all slice.) Then we use
Algorithm

1
to create a set
F_{3}
of knots that are friends with a knot in
F_{2}
. Then we iterate this process to create an arbitrarily long chain of knots that are concordance friends with a slice knot. If any computable slice obstruction for a knot in this chain is non-vanishing, then there exists a pair of concordance friends with different sliceness status. Since the topological Poincaré conjecture in dimension
4
is true
[
23
]
, two concordance friends have necessarily the same topological sliceness status. Thus, the above sliceness obstructions need to be smooth obstructions. Example candidates for such smooth sliceness obstructions are the s-invariant and its generalizations, or potentially also the sliceness obstructions coming from knot Floer homology. In principle, these obstructions are computable, but quickly become infeasible with increasing crossing number. Since the knots created with
Algorithm

1
and
3
usually have a high crossing number, this approach is not very likely to terminate.

On the other hand, it is possible to find a ribbon certificate even for knots of large crossing number. In
[
27
]
, modern machine learning methods are used for detecting a certificate for a knot bounding a ribbon disk. While no decidable algorithm for ribbonness is known, the machine learning approach produces a
verifiable certificate
for ribbonness if successful, and the authors demonstrate that their programs can reliably detect ribbon certificates even for knots of high crossing number. A different algorithm is described in
[
18
]
.
