Unified Pix Token And Word Token Generative Language Model
Haun Leung ZiNan Wang

Abstract
Since the emergence of Vision Transformer (ViT), it has been widely used in generative language model and generative visual model. Especially in the current state-of-art open source multimodal models, ViT obtained by CLIP or SigLIP method serves as the vision encoder backbone to help them acquire visual understanding capabilities. But this method leads to limitations in visual understanding for details, such as difficulty in recognizing small text or numbers in images. To address these issues, we propose a new model to unify pix token and word token into the generative language model. The new model also features with each pix of image having its own token embedding, color folding, global conditional attention approximation and image unsupervised pretraining. We conducted image unsupervised pretraining experiments using our new model to explore its potential. The experimental results show that it has good performance even in small model and with limited training data. We believe our model also conforms to the scaling law, as long as model parameters and training data increased, its performance will continue to improve.

Introduction

Since the emergence of Vision Transformer (ViT), it has been widely used in generative language model and generative visual model. Especially in the current state-of-art open source multimodal models, just like Llava, ViT obtained by CLIP or SigLIP method serves as the vision encoder backbone to help them acquire visual understanding capabilities. But this method leads to some issues. Either there are limitations in visual understanding for details, such as difficulty in recognizing small text or numbers in image. Either there are visual understanding drifts in multi-turns of conversations, the first turn of conversation is correct, but errors are prone to occur later on. Although these limitations can be alleviated by adding more training data related to the issues or optimization CLIP method, there will still be other challenges in the future.

We believe that these limitations are likely due to the CLIP method, including the following reasons.

1) The encoded features cannot represent all the details of the image

ViT encodes images into a small features that is similar to a text features. But what if this text does not fully describe other small details of the image? Or can the text describe all the details of the image? In this case, the encoded features of the image cannot represent all the details of the image.

2) The slightest nudge causes the widest chain reaction

If a small change is made for the image, for example the license plate number of car in the image changes from 1 to 6, the all floating-point numbers in the encoded features will change. The slightest nudge causes the widest chain reaction, which is not good.

3) ViT use a fake token embedding

ViT forms a fake token embedding by patching the pixels in the image. But this fake token embedding does not have truly adjustable parameters. So the expressive ability of ViT is questionable. We may need to propose a new architecture to address its shortcomings.

4) Limitations of supervised training

CLIP uses supervised training, but the supervised training data is always limited. It is easy to cause deficiencies outside of distribution.

We creatively proposed a new architecture to unify pix token and word token into the generative language model, no longer relying on ViT encoder. We believe that each pix of image should have its own unique token and true token embedding that we call Pix Token Embedding. We also proposed the concept of Color Folding, which reduces the huge amount of computation and makes Pix Token Embedding feasible. Furthermore, we have proposed Global Conditional Attention Approximation that enables the entire lengthy Pix Token Embedding sequence of image to participate in self-attention operations effectively and feasibly. Now the new architecture make generative language model can predict pix token like predicting word token. We also proposed image unsupervised pretraining, which enable model to learn the patterns of the pixes from huge image datas. And our method is lossless in image data preprocessing, but models like ViT suffer losses in image data preprocessing.

We conducted experiments on image unsupervised pretraining, using our unified pix Token and word token model. We found that it has the potential to learn the patterns of the pixes. The experimental results show that it has good performance even in small model and with limited training data. We believe our architecture also conforms to the scaling law, as long as model parameters and training data increased, its performance will continue to improve.

However, due to our limited computing resources, we are unable to conduct experiments with large-scale model and data. We cannot predict the upper limit of its potential.

ViT (Vision Transformer) and application

ViT (Vision Transformer) and application

(
6

is a computer vision model based on Transformer architecture
(
15
)
. It transforms image processing tasks into sequence processing problems, making breakthrough progress in multiple visual tasks. The core idea of ViT is to view an image as a sequence of image patchs. Specifically, it devides the input image into fixed sized non overlapping small patchs, and then linearly projects each small patch into a token embedding. These token embedding sequences, along with an additional learnable classification token embedding, form the input of the Transformer encoder.

CLIP (Contrastive Language-Image Pre-training)

(
11

CLIP and SigLIP are multimodal contrastive learning models based on the Vision Transformer (ViT) architecture, aimed at mapping images and text to the same semantic space for cross modal understanding.

In LLM, ViT obtained through CLIP or SigLIP methods is used as the vision encoder backbone to assist large language models in acquiring visual understanding capabilities. For example, LLAVA

2.4
Global attention with Transformer

The Transformer architecture employing full attention mechanisms on full-sized images requires substantial computational resources, which exceed current capabilities and are thus unfeasible. Current research efforts are exploring ways to reduce computational load or avoid direct full-attention mechanisms. Research work in this area includes Swin Transformer
(
8
)
, QWen-2.5-VL
(
1
)
and so on.

Swin Transformer
uses shifted window based self-Attention to avoid full attention Swin Transformer, like ViT, divides images into token embeddings based on patches. Then use multi head self-attention based on shifted window to these token embeddings. Shifted windows include W-MSA and SW-MSA. W-MSA is a regular window, while SW-MSA is an irregular window. Swin Transformer will also merge token embeddings layer by layer.

Qwen2.5-VL
employs a redesigned Vision Transformer (ViT) architecture as vision encoder to enhance performance and efficiency. Structurally, they incorporate 2D-RoPE and window-based attention mechanisms to support native input resolutions while accelerating the computation of the entire visual encoder. During both training and inference, the height and width of the input images are resized to multiples of 28 before being fed into the ViT. In their architecture, only four layers employ full self-attention, while the remaining layers utilize windowed attention with a maximum window size of 112112 (corresponding to 88 patches). Regions smaller than 112x112 are processed without padding, preserving their original resolution. This design allows the model to operate natively at the input resolution, avoiding unnecessary scaling or distortion. But in the Qwen2.5-VL paper, the architecture figure show that they use M window-based attention blocks in front and the only last block using full attention.

Some differences:

Swin Transformer first uses regular window attention, and then uses inregular window attention. QWen-2.5-VL first used regular window attention, and finally used global attention. QWen-2.5-VL and Swin Transformer both use token embedding merging. Our proposed method is different from Swin Transformer and QWen-2.5-VL in that it does not require complex inregular window attention, full attention, or token embedding merging. It only requires simple local window mask multi-head self-attention operation.

Swin Transformer and QWen-2.5-VL, like ViT, divide images into token embeddings based on patches, which is a type of fake token embeddings without adjustable parameters during training. But we are a true per pix token embedding.

3.1
Pix Token Embedding

In the current popular LLMs, if we ignore the fancy tokenizing method of the tokenizer, we can approximately assume that each word token has its own independent token embedding. It is this method that gives each word token sufficient expressive power, and after training with massive text data, its parameters can be adjusted to appropriate positions, thereby improving the ability of LLMs.

ViT divides the pixels in the image into patches, and then forms a token embedding by channel for each pixel in each patch. We believe that this approach at least has two drawbacks:

* First it does not have adjustable parameters, it is a fake token embedding.

* Second not every pix has its own independent token embedding.

Before proposing our method, we make the following assumptions: The shape of image with 3 color channels (RGB channels) is (3, H, W), where 3 is the number of channels, H is the image height, and W is the image width. And the length of the color channel is L which defaults to 256.

We believe that every pix should also have its own true token embedding. To achieve this goal, our design is as follows: Each pix of image corresponds to a unique one token which has one’s own token embedding. As shown in Figure
1
.

The value of pix token is related to the color value of the pix. The formula for calculating the value of token is:

Token_{value}=r+g*L+b*L*L

L is the length of the color channel. r is R channel value and g is the G channel value and b is the B channel value.

If L is
256
, the token value range is
[0,256*256*256]
. So the total number of tokens dictionary is
256*256*256
.

Because every token have it’s own token embedding, so the total number of token embeddings is
256*256*256
. The dimension of token embedding is set according to the actual situation, and we define it as d. In space, these token embeddings are continuous and the tensor shape is (
256*256*256
, d).

Attention: Actually also there is an additional pad token for pix due to differences in height and width of image.

Pix Token Embeddings Sequence

Next, we will investigate how to obtain a token embeddings sequence from all the pixels in the image. Our combination method is sequential: In order from left to right, and then from top to bottom, extract a pix token from the image and find its corresponding pix token embedding. Then combine these pix token embeddings in chronological order to form a token embeddings sequence.

3.1.2
Lossless of Data Preprocessing

As is well known, image data needs to be preprocessed before model training. The traditional method is to map RGB color values from
[0-255]
to
[0-1.0]
, for example
1/255=0.00392156862745098

Due to the limited number of floating-point digits in tensors, it is necessary to perform bit truncation on color values, which can result in losses. Although we think the loss value is relatively small, considering the lower learning rate and different optimizer methods and considering training with 16 bits or lower, there are imperfections.

The Pix Token Embedding method we propose will not have this problem, it is lossless data preprocessing.

3.2.1
Folding Factor

We propose the concept of Color Folding, and its idea is as follows: We propose a Folding Factor whose range of values is
[1,2,4,8,16,32,64,128,256]
. Assuming the length of each color channel L is 256, the folded color length is equal to
(256/foldingfactor)
. Folding factor reduces the length of color channel, which is equivalent to fewer color species, which can reduce unnecessary computation.

For example, before folding, each pix has
256*256*256=16777216
colors. If folding factor is 8, then each pix has
32*32*32=32768
colors. The reduction of colors is enormous!

Due to the consistency between the total number of pix tokens and the total number of colors, the reduction in computational complexity is also significant.

Color Value after Color Folding:

Assuming that the color of a pix is
(R,G,B)
and folding factor is f. After color folding the color of the pix is
(R//f,G//f,B//f)
. It means the new color value of another color space.

3.3
Unified Pix Token And Word Token Model

We propose unified pix token and word token generative language model: It unifys the pix token into the generative language model where only word token is used. The core idea of our model are: one is unified pix token and word token, and the other is using local conditional self-attention to approximate global conditional self-attention.
It overcomes the drawbacks of large computational complexity and slow speed while approaching the performance of global conditional self-attention. An overview of our model is depicted in Figure
4
.

The model process is as follows:

1) Get Word Token Embedding

For the input model text sequence, we obtain word token embedding sequence based on word token.

2) Get Pix Token Embedding

For the input image (3, H, W), we first obtain a pix token embedding sequence from the token embedding dictionary using the method described in section 3.1.1.

3) Global To Local Window

Convert the global pix token embedding sequence into local window pix token embedding sequence.

4) Local Window Mask Multi-head Self-Attention

Then send the local window pix token embedding sequence to the L transformer decoders. First add position embedding for the whole sequence with a rotary embedding way in every decoder. Then perform mask multi-head self-attention for every local window sequence.

5) Get Last Token Embedding

Get the last pix token embedding from every local window pix token embedding sequence.

6) Unified Pix Token And Word Token Mask Multi-head Self-Attention

We integrate word token embedding sequence and pix token embedding sequence into one sequence, and then send to the I transformer decoders to perform mask multi-head self-attention.

7) MLP Head

The final output goes through a MLP head and we get the predict token.

A simple example of the above process is shown in the Figure
5
. We will explain in detail the key steps of the above process.

3.3.1
Global to Local Window

Assuming that the shape of pix token embedding sequence obtained from image (3, H, W) according to the method in section 3.1.1 is (N,d), N=H*W is the sum of all pixels in the image. We divide the image into (N/K)**2 windows in order from left to right and top to bottom and each window the height and width are both K. The pix token embedding of pixels in each window forms a pix token embeddings sequence. The pix token embedding sequence of all window forms a batch. So the pix token embedding sequence dimension changes from (N, d) to (N/K**2, K**2, d).

In this way, The global pix token embedding sequence becoming a batch local window pix token embedding sequence.

Taking Figure
5
as an example to illustrate: The global pix token embedding sequence changes from (16, d) to (4, 4, d). Both H and W are 4, N is 16 and K is 2.

Note: W must can be divided by the K. If the H cannot be divided by the K, it needs to be filled with pix pad token (section 3.5.1) to the same long as W.

(N/K**2,K**2,d)

Local Window Conditional Attention:

Perform mask multi-head self-attention operation on K**2 pix token embeddings according to N/K**2 batches.

3.3.4
Unified Pix Token and Word Token Conditional Attention And Token Predict

Unified Pix Token and Word Token Mask Multi-head Self-Attention:

We integrate word token embedding sequence and pix token embedding sequence into one sequence, and then send to the I transformer decoders to perform mask multi-head self-attention.

Token Predict:

To predict word token the same as the current method that is next word token. To predict pix token, the model predict the first pix token of the next local window.

Global Conditional Attention Approximation:

Observing the entire process, we use a clever method to approximate global conditional attention. The reasons are as follows, refer to Figure
4
:

Assuming the input text word token is
X
, the input image pix tokens is
(p1,p2,...,pN)
, and the output response of model is
Y
. The probability of
Y
is
P(Y|X,p_{1},p_{2},...,p_{N})
. But due to the length of pix tokens being too long, for example the length of pix tokens of image with a height and width of 256 is 65556, It’s not feasible to do self-attention operation. Our method can avoid this problem, and approximate the goal. We know
(E_{k},E_{2k},...,E_{N})
are the token embedding after local window conditional attention. The probability of
E_{k}
is
P(E_{k}|p_{1},p_{2},...,p_{K})
. The probability of
E_{2k}
is
P(E_{2k}|p_{K+1},p_{K+2},...,p_{2K})
. The probability of
E_{N}
is
P(E_{N}|p_{N-K+1},p_{N-K+2},...,p_{N})
. The probability of
Y
is
P(Y|X,E_{k},E_{2k},...,E_{N})
. we obtain the equation:

P(Y|X,E_{k},E_{2k},...,E_{N})\approx P(Y|X,p_{1},p_{2},...,p_{K},p_{K+1},p_{K+2},...,p_{2K},...,p_{N-K+1},p_{N-K+2},...,p_{N})=P(Y|X,p_{1},p_{2},...,p_{N})
. So our method can approximate the global conditional attention.

3.4
The advantages of unified token model

3.4.1
Every pix has its true token embedding

ViT forms a fake token embedding by patching the pixels in the image. But this fake token embedding does not have truly adjustable parameters. Pixes do not have their own independence token embedding.

Our model every pix has its own independence token embedding. These pix token embedding has adjustable parameters just like word token embedding. So there is a stronger expressive ability.

3.4.2
The unity of pix token and word token

Our model finally unifies pix token and word token. The number of word Tokens in the current popular generative language model is approximately tens of thousands. There are also tens of thousands of pix tokens in our model, according to different fold factor. We can feel the beauty of this symmetry.

In the unified token space, we can do self-attention operation and token predict for both pix token and word token. But in Llava, we cannot do pix token predict. This is not perfect.

3.4.3
Say bye bye to "the slightest nudge causes the widest chain reaction"

We know that image is encoded as features by ViT in CLIP method. But if a small change is made for the image, for example the license plate number of car in the image changes from 1 to 6, the all floating-point numbers in the encoded features will change. The slightest nudge causes the widest chain reaction, which is not good.

Our model can avoid such problems. Only one or a few token embedding have undergone changes, but most of the others will not change. This makes it easier for model to capture small changes.

3.4.4
Image unsupervised pretraining

GPT-3 tells us that extensive word token unsupervised pretraining is the cornerstone for LLMs to achieve success. But CLIP method is using image supervised training. This is clearly the reason for the missing distribution.

Our model finally makes image unsupervised pretraining possible. Our model can undergo the following pretraining:

1) Only word token pretraining

This is the same as the currently popular method. We won’t go into detail anymore.

3) Mixed word token and pix token pretraining

There are massive mixed samples of text and image in reality world, for example, image news on the Internet. We can now use these mixed sample for pretraining. This is something that previous methods like Llava were unable to achieve!

But how to deal with batch datas in pretraining?
Our model encapsulate the operations (steps 2, 3, 4, and 5 in section 3.3) on image into a module called ImageBlock. It accepts input from batch images and its output is batch pix token embedding sequence.

Taking 3 samples as an example:

sample S1 is only text: (T). sample S2 is text and image mixture: (I, T). sample S3 is text and image mixture: (T1, I, T2). T is a text sequence, I is a shape of (3,H,W) image.

Brief pretraining process:

1) First obtain T of all samples and get word token embedding sequence and label tokens.

2) Second obtain I of all samples and its label tokens, then send it to the ImageBlock to obtain pix token embedding sequence.

3) Connect word token embedding sequence and pix token embedding sequence into a sequence. Connect label tokens of T and I into a sequence.

4) Perform unified conditional attention operation on the connected token embedding sequence and final output predict tokens.

5) Finally, the obtained predict tokens and label tokens will undergo Cross-Entropy Loss‌ operation.

The mixed samples format supported by our model see Appendix
A
. Users should convert their mixed image and text data into this format.

3.5
Implement Supplementation

These are some supplements to the implementation of model details.

3.5.1
Pad Pix Token

During pretraining, batch processing of images is required. Our model supports images of any ratio. To achieve this goal, We set the length and width of the target image both to image size L. we scale the length or width of the source images to L, and add a pad pix token to the remaining shortfall. This pad pix token will not participate in conditional self-attention operations in local window, which is achieved through mask.

As shown in Figure
6
. Assuming image size L is 6, local window size is 3. For image (3x6x5), due to insufficient width and the addition of pax pix token, it turns into image (3x6x6). For image (3x5x6), due to insufficient height and the addition of pax pix token, it turns into image (3x6x6).

Figure 6:
Add Pad Pix Token To Source Image.

3.5.2
Sub Local Window

When our model supports large image size L, if local window size is too small, the resulting pix token embedding sequence will be too long. And if local window size is too large, the conditional self-attention operation in local window will take too long time. So we use sub local window attention to solve this problem.

Specific method:

Stage one is to use a suitable local window size to divide the global pix token embedding sequence of the source image. After getting the last token embedding, we obtained a pix token embedding sequence.

Stage two continue to perform a smaller local window size on the pix token embedding sequence and carry out conditional self-attention operations in local window.

The subsequent steps are the same as before.

As shown in Figure
7
. Assuming image size L is 8, local window size is 2. After stage one local window attention, we got a pix token embedding sequence with a length of 16. And then continue to perform a smaller local window size of 2 on it and got 4 local window pix token embedding sequence. Subsequent local window attention can be carried out on these local sequence and finally obtaining a ix token embedding sequence with a length of 4.

Sub Local Window Attention.

4
Experiments

We conducted a only image unsupervised pretraining experiments using our unified pix token and word token model. The purpose of the experiment is to demonstrate the feasibility of our model, and we expect its results to be similar to those of only text unsupervised pretraining like GPT-3.

Due to our lack of computing resources, we are unable to conduct other experiments, such as mixed text and image unsupervised pretraining. We hope everyone can understand. So we conducted the experiment that best demonstrated the potential of our model, that is only image unsupervised pretraining.

4.1
Settings

1) Dataset

Training dataset:
Due to our lack of computing resources, we used a dataset with a small quantity and low resolution. We used 120000 image samples from the llava-cc3m-pretrain-595k dataset, about 6 billion pix tokens.

Validate dataset:
We used one thousand samples from the llava-cc3m-pretrain-595k dataset.

2) Model

Due to our lack of computing resources, we used a model with 120 millions parameters. It is structurally simple and does not contain the current complex features such as MoE, model parallelism and tensor parallelism and so on. The configuration information of the model is as Table
1
.

3) Training

We trained our model, using learning rate 0.0006, cosine learning rate scheduler, AdamW with
\beta 1
= 0.9,
\beta 2
= 0.999, dropout of 0.1, weight decay of 0.01, gradient clipping at global norm 1, batch size 2.
Image related parameters: image size is 224, color fold factor is 16, and local window size is 16.

Experimental Results

5
Conclusion

We first analyzed the limitations of current state-of-art open source generative language models in visual understanding. Then we propose a new model to solve this issues: Unified pix token and word token generative language model. Our model have many advantages, including the ability to undergo image unsupervised pretraining.

We conducted only image unsupervised pretraining experiments using our model. The experimental results have proven that after a certain amount of data pretraining, our model can learn the patterns of the pix token sequence.
We believe that when we increase the number of parameters and datas, our model also conforms to the scaling law of generative language model.

The new model we proposed is a perfect way to unify pix token and word token together into generative language model. We believe it can replace the CLIP method currently used in production.
