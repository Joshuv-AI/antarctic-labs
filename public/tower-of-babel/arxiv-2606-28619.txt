DERIVATIVE OF THE JACOBI POLYNOMIALS WITH RESPECT TO THEIR ORDER AND APPLICATIONS TO INDEFINITE INTEGRATION


Abstract
We calculate the first derivative of the Jacobi polynomials with respect to their order in explicit form. This derivative is not an elementary function, but contains elementary special cases. As an application, we use our result with a recently devised method for resolving a new class of indefinite integrals containing Jacobi polynomials.

2
Calculation of the derivative with respect to the order

We will now compute the first derivative of the Jacobi polynomials with respect to their order. To this end, we first first extend the domain of the order
to the positive real axis by expressing the Jacobi polynomials through the hypergeometric function. In the next step we calculate the derivative
of the resulting expression, and evaluate it at nonnegative integer values of the order. It should be stressed that the process of differentiating the
hypergeometric function is not new in general
[
11
]
, but in the present case yields a closed-form result. Let
n
be a nonnegative integer, and assume that
a
,
b
are real-valued numbers. We define the Jacobi polynomial of order
n
with parameters

a
and
b
as

\displaystyle P_{n}^{(a,b)}(x)

\displaystyle=

\displaystyle\frac{1}{n!}\sum\limits_{k=0}^{n}\frac{(-n)_{k}~(a+b+n+1)_{k}~(a+k+1)_{n-k}}{k!}\left(\frac{1-x}{2}\right)^{k}.

While here
n
is a discrete variable, we can extend the definition of the Jacobi polynomials, such that the order is defined on the positive half-axis.
To this end, we use the following known relation to the hypergeometric function for a positive real number
\mu
:

\displaystyle P_{\mu}^{(a,b)}(x)

\displaystyle=

\displaystyle\frac{\Gamma(a+\mu+1)}{\Gamma(\mu+1)~\Gamma(a+1)}~{}_{2}F_{1}\left(-\mu,a+b+\mu+1,a+1,\frac{1-x}{2}\right),

(1)

where
\Gamma
and
{}_{2}F_{1}
denote the Gamma and hypergeometric functions, respectively. Note that the definition (
1
) is valid as long as the parameter
a
does not take negative integer values.
We will comment further on this restriction below. Next, we observe that the function
\mu\mapsto P_{\mu}^{(a,b)}(x)
is
continuously differentiable on the positive half-axis, since both the Gamma function and the hypergeometric function are. This statement includes the special case

\mu=0
in the sense of a limit. We can now compute the derivative
of (
1
) with respect to
\mu
at nonnegative integer values
n
. We find in a first step

\displaystyle\left[\frac{\partial}{\partial\mu}~P_{\mu}^{(a,b)}(x)\right]_{\mid\mu=n}

\displaystyle=

\displaystyle\Bigg\{\left[\frac{\partial}{\partial\mu}~\frac{\Gamma(a+\mu+1)}{\Gamma(\mu+1)~\Gamma(a+1)}\right]{}_{2}F_{1}\left(-\mu,a+b+\mu+1,a+1,\frac{1-x}{2}\right)+

(2)

\displaystyle\hskip-56.9055pt+~\frac{\Gamma(a+\mu+1)}{\Gamma(\mu+1)~\Gamma(a+1)}~\left[\frac{\partial}{\partial\mu}~{}_{2}F_{1}\left(-\mu,a+b+\mu+1,a+1,\frac{1-x}{2}\right)\right]\Bigg\}_{\mid\mu=n}.

The derivative in the first line can be found in a straightforward manner. We have

\displaystyle\left[\frac{\partial}{\partial\mu}~\frac{\Gamma(a+\mu+1)}{\Gamma(\mu+1)~\Gamma(a+1)}\right]_{\mu=n}

\displaystyle=

\displaystyle\frac{\Gamma(1+a+n)~[\psi(1+a+n)-\psi(1+n)]}{\Gamma(1+a)~\Gamma(1+n)},

where
\psi
denotes the digamma function. It remains to determine the derivative of the hypergeometric function in (
2
), which can be done by
employing its series representation. We obtain

\displaystyle\left[\frac{\partial}{\partial\mu}~{}_{2}F_{1}\left(-\mu,a+b+\mu+1,a+1,\frac{1-x}{2}\right)\right]_{\mid\mu=n}

\displaystyle=

(3)

\displaystyle\hskip-256.0748pt=~\left[\frac{\partial}{\partial\mu}~\sum\limits_{k=0}^{\infty}\frac{(-\mu)_{k}~(a+b+\mu+1)_{k}}{k!~(a+1)_{k}}\left(\frac{1-x}{2}\right)^{k}\right]_{\mu=n}

\displaystyle\hskip-256.0748pt=~-\left\{\sum\limits_{k=0}^{\infty}\frac{(-\mu)_{k}~(a+b+\mu+1)_{k}}{k!~(a+1)_{k}}~\big[\psi(k-\mu)-\psi(-\mu)\big]\left(\frac{1-x}{2}\right)^{k}\right\}_{\mu=n}+

\displaystyle\hskip-256.0748pt+~\left\{\sum\limits_{k=0}^{\infty}\frac{(-\mu)_{k}~(a+b+\mu+1)_{k}}{k!~(a+1)_{k}}~\big[\psi(a+b+\mu+1+k)-\psi(a+b+\mu+1)\big]\left(\frac{1-x}{2}\right)^{k}\right\}_{\mid\mu=n}.

We will now express these series in closed form by using the fact that

is taken at a nonnegative integer value

contribute. This is so because for

the difference of the digamma functions

the term

equals zero, once we insert

. The reason for splitting this series is
that the difference of the digamma functions must be handled differently for the two cases. In addition, we will apply the following relationship for
the Pochhammer symbol:

\displaystyle(-\mu)_{k}

\displaystyle=

\displaystyle(-\mu)_{n}~(-\mu+n+1)_{k-n-1}~(-\mu+n).

Upon implementing the above in (

\displaystyle\hskip-256.0748pt=~-\left\{\sum\limits_{k=0}^{n}\frac{(-\mu)_{k}~(a+b+\mu+1)_{k}}{k!~(a+1)_{k}}~\big[\psi(k-\mu)-\psi(-\mu)\big]\left(\frac{1-x}{2}\right)^{k}\right\}_{\mu=n}+

\displaystyle\hskip-256.0748pt~\times\left(\frac{1-x}{2}\right)^{k}\Bigg\}_{\mid\mu=n}.

We proceed by inserting the value

(5)

\displaystyle\hskip-256.0748pt=~-\sum\limits_{k=0}^{n}\frac{(-n)_{k}~(a+b+n+1)_{k}}{k!~(a+1)_{k}}~\lim\limits_{\mu\rightarrow n}\big[\psi(k-\mu)-\psi(-\mu)\big]\left(\frac{1-x}{2}\right)^{k}+

\displaystyle\lim\limits_{\mu\rightarrow n}(-\mu+n)~\big[\psi(k-\mu)-\psi(-\mu)\big]

\displaystyle=

This limit will be used for the sum in line (

\displaystyle\left[\frac{\partial}{\partial\mu}~{}_{2}F_{1}\left(-\mu,a+b+\mu+1,a+1,\frac{1-x}{2}\right)\right]_{\mid\mu=n}

\displaystyle=

(10)

\displaystyle\hskip-142.26378pt=~-\sum\limits_{k=1}^{n}\sum\limits_{j=0}^{k-1}\frac{(-n)_{k}~(a+b+n+1)_{k}}{(j-n)~k!~(a+1)_{k}}\left(\frac{1-x}{2}\right)^{k}+

In order to find a closed-form representation for the series in the last line, we identify it with a hypergeometric function. After factoring out terms,

\displaystyle\left[\frac{\partial}{\partial\mu}~{}_{2}F_{1}\left(-\mu,a+b+\mu+1,a+1,\frac{1-x}{2}\right)\right]_{\mid\mu=n}

\displaystyle\left[\frac{\partial}{\partial\mu}~P_{\mu}^{(a,b)}(x)\right]_{\mid\mu=n}

\displaystyle=

\displaystyle\hskip-113.81102pt=~\frac{\Gamma(1+a+n)~[\psi(1+a+n)-\psi(1+n)]}{\Gamma(1+a)~\Gamma(1+n)}~{}_{2}F_{1}\left(-n,a+b+n+1,a+1,\frac{1-x}{2}\right)+

\displaystyle\hskip-113.81102pt+~\frac{\Gamma(a+n+1)}{\Gamma(n+1)~\Gamma(a+1)}\times

3
Application: Wronskian integral formula

As mentioned in the introduction, recently a method was devised for generating indefinite integrals through parameter derivatives
[
7
]
. For the
sake of completeness, we will now summarize the main result from the latter reference: suppose that
u
and
V
are smooth functions, defined on an open subset of
\mathbb{R}^{2}
, such that the equation

\displaystyle\frac{\partial^{2}u(x,\mu)}{\partial x^{2}}+V(x,\mu)~u(x,\mu)

\displaystyle=

\displaystyle 0,

(14)

is satisfied. Then the following formula for indefinite integration holds:

\displaystyle\int\limits^{x}\frac{\partial V(t,\mu)}{\partial\mu}~u(t,\mu)^{2}~dt

\displaystyle=

\displaystyle W_{\frac{\partial u}{\partial\mu},u}(x,\mu),

(15)

where
W
denotes the Wronskian of the functions in its index. We observe that (
15
) allows for resolving the indefinite integral on the left side
by evaluation of the Wronskian on the right side, which merely involves differentiation. Our goal in this application is to match the general form of equation (
14
) with
a particular case solved by Jacobi polynomials, where the parameter
\mu
is given by their order. As a consequence, the Wronskian on the right side
of (
15
) contains the derivative of the Jacobi polynomials with respect to the order
\mu
, which is precisely our result (
). Let us now start out by
stating the equation solved by Jacobi polynomials. We recall that it can be written in the form

\displaystyle(1-x^{2})~\frac{d^{2}}{dx^{2}}~P_{n}^{(a,b)}(x)+[b-a-(a+b+2)~x]~\frac{d}{dx}~P_{n}^{(a,b)}(x)+n~(n+a+b+1)~P_{n}^{(a,b)}(x)=0.

This equation does not have the form (
14
), since it contains a first-order derivative term. Therefore, in the next step we will gauge away that term, and we will
generalize the order
n
of the Jacobi polynomials to the real variable
\mu
. We define

\displaystyle u(x,\mu)

\displaystyle=

\displaystyle(1-x)^{\frac{a+1}{2}}(1+x)^{\frac{b+1}{2}}~P_{\mu}^{(a,b)}(x),

(16)

recall that for non-integer values of
\mu
the definition (
1
) applies. Substitution shows that (
16
) is a solution to

\displaystyle\frac{\partial^{2}u(x,\mu)}{\partial x^{2}}+\Bigg[\frac{1-a^{2}}{4~(x-1)^{2}}+\frac{1-b^{2}}{4~(1+x)^{2}}-\frac{(1+a)~(1+b)-2~\mu~(1+a+b)-2~\mu^{2}}{4~(x-1)}+

\displaystyle\hskip 142.26378pt+~\frac{(a+1)~(b+1)+2~\mu~(1+a+b)+2~\mu^{2}}{4~(x+1)}\Bigg]~u(x,\mu)~=~0,

which matches the general form (
14
), provided we define the function
V
as

\displaystyle V(x,\mu)

\displaystyle=

\displaystyle\frac{1-a^{2}}{4~(x-1)^{2}}+\frac{1-b^{2}}{4~(1+x)^{2}}-\frac{(1+a)~(1+b)-2~\mu~(1+a+b)-2~\mu^{2}}{4~(x-1)}+

\displaystyle+

\displaystyle\frac{(a+1)~(b+1)+2~\mu~(1+a+b)+2~\mu^{2}}{4~(x+1)}.

We are now ready to evaluate the left side of the integral formula (
15
). To this end, we need the derivative of
V
with respect to
\mu
, which
can be readily computed as

\displaystyle\frac{\partial V(x,\mu)}{\partial\mu}

\displaystyle=

\displaystyle\frac{1+a+b+2~\mu}{1-x^{2}}.

Substitution of this derivative, along with (
16

\displaystyle\int\limits^{x}\frac{\partial V(t,\mu)}{\partial\mu}_{\mid\mu=n}~u(t,n)^{2}~dt=(1+a+b+2~n)\int\limits^{x}(1-t)^{a}~(1+t)^{b}~P_{n}^{(a,b)}(t)^{2}~dt.

(17)

Observe that we are taking the integrand at a nonnegative integer value

of
\mu

a closed form of the integral (
17
) has not been reported in the literature so far. Now that we completed
evaluating the left side of (

\displaystyle W_{\frac{\partial u}{\partial\mu},u}(x,n)

\displaystyle=

\displaystyle\left[\frac{\partial u(x,\mu)}{\partial\mu}\right]_{\mid\mu=n}\frac{\partial u(x,n)}{\partial x}-u(x,n)\left[\frac{\partial^{2}u(x,\mu)}{\partial x~\partial\mu}\right]_{\mu=n}.

(18)

Let us consider each of the four terms on the right side separately. According to (

\displaystyle\left[\frac{\partial u(x,\mu)}{\partial\mu}\right]_{\mu=n}

\displaystyle=

\displaystyle(1-x)^{\frac{a+1}{2}}(1+x)^{\frac{b+1}{2}}\left[\frac{\partial}{\partial\mu}~P_{\mu}^{(a,b)}(x)\right]_{\mu=n}.

(19)

Note that the derivative on the right side is precisely our result (

\displaystyle\left(\frac{\partial}{\partial\mu}~P_{\mu}^{(2,2)}(x)\right)_{\mid\mu=1}

\displaystyle=

\displaystyle\frac{-32+x+134~x^{2}+97~x^{3}}{20~(1+x)^{2}}+3~x~\log\left(\frac{1+x}{2}\right)

\displaystyle\left(\frac{\partial}{\partial\mu}~P_{\mu}^{(1,1)}(x)\right)_{\mid\mu=2}

\displaystyle=

\displaystyle\frac{-7-59~x+19~x^{2}+79~x^{3}}{16~(1+x)}+\frac{3}{4}~(5~x^{2}-1)~\log\left(\frac{1+x}{2}\right).

We now insert these derivatives into the Wronskian (
21
). After collecting terms, we arrive at the final form

\displaystyle W_{\frac{\partial u}{\partial\mu},u}(x,2)

\displaystyle=

\displaystyle-\frac{3}{16}~\left(16-21~x+77~x^{3}-147~x^{5}+75~x^{7}\right).

(22)

Up to an additive constant, this is the indefinite integral in (
17
). We can verify directly by either integrating the latter, or by taking the derivative
of (
22
).

4
Discussion and concluding remarks

Let us now conclude this work with a few comments on the relation (
1
), and on the extension of our main result (
) to polynomials other
than the Jacobian case. First, we recall that the identity (
1
) between the Jacobi polynomials and the hypergeometric function is undefined for
negative integer values of the parameter
a
. This issue can be addressed by employing an alternative representation to (
1
), given by

\displaystyle P_{\mu}^{(a,b)}(x)

\displaystyle=

\displaystyle\frac{\Gamma(-b)}{\Gamma(\mu+1)~\Gamma(-\mu-b)}~{}_{2}F_{1}\left(-\mu,a+b+\mu+1,b+1,\frac{1+x}{2}\right),

(23)

which is valid as long as the parameter
b
does not take integer values. Besides (
1
) and (
23
), there are further representations
of the Jacobi polynomials, each of which involve different constraints on the parameters. Next, let us point out that for suitable parameter settings,
the Jacobi polynomials reduce to a variety of special cases, representing other polynomial systems. As a consequence, our result on the derivative
(
) can be used for the latter special cases. For example, we recall the following definition of the Gegenbauer polynomials

\displaystyle C_{n}^{a}(x)

\displaystyle=

\displaystyle\frac{(2~a)_{n}}{\left(a+\frac{1}{2}\right)_{n}}~P_{n}^{\left(a-\frac{1}{2},a-\frac{1}{2}\right)}(x).

We can calculate the derivative of these polynomials with respect to their order
n
. This gives

\displaystyle\left[\frac{\partial}{\partial\mu}~C_{\mu}^{a}(x)\right]_{\mid\mu=n}

\displaystyle=

\displaystyle\frac{(2~a)_{n}~\left[\psi(2~a+n)-\psi\left(a+n+\frac{1}{2}\right)\right]}{\left(a+\frac{1}{2}\right)_{n}}~P_{n}^{\left(a-\frac{1}{2},a-\frac{1}{2}\right)}(x)+

(24)

\displaystyle+

\displaystyle\frac{(2~a)_{n}}{\left(a+\frac{1}{2}\right)_{n}}~\left[\frac{\partial}{\partial\mu}~P_{\mu}^{\left(a-\frac{1}{2},a-\frac{1}{2}\right)}(x)\right]_{\mid\mu=n},

where the derivative of the Jacobi polynomials can be found in (
). We omit to insert the latter result, as (
24
) would become
excessively long. Next, we will compute the derivative of the Legendre polynomials with respect to their order. To this end, we use the following
relation between them and the Jacobi polynomials:

\displaystyle P_{n}(x)

\displaystyle=

\displaystyle P_{n}^{(0,0)}(x).

The sought derivative is given by

\displaystyle\left[\frac{\partial}{\partial\mu}~P_{\mu}(x)\right]_{\mid\mu=n}

\displaystyle=

\displaystyle\left[\frac{\partial}{\partial\mu}~P_{\mu}^{(0,0)}(x)\right]_{\mid\mu=n},

which can be evaluated directly from (
). As a further example, we will now consider the Chebyshev polynomials of the first kind. These can be
written in the form

\displaystyle T_{n}(x)

\displaystyle=

\displaystyle\frac{P_{n}^{\left(-\frac{1}{2},-\frac{1}{2}\right)}(x)}{P_{n}^{\left(-\frac{1}{2},-\frac{1}{2}\right)}(1)}.

We calculate the derivative of these polynomials with respect to their order as follows:

\displaystyle\left[\frac{\partial}{\partial\mu}~T_{\mu}(x)\right]_{\mid\mu=n}

\displaystyle=

\displaystyle\frac{1}{P_{n}^{\left(-\frac{1}{2},-\frac{1}{2}\right)}(x)}\left[\frac{\partial}{\partial\mu}~P_{\mu}^{\left(-\frac{1}{2},-\frac{1}{2}\right)}(x)\right]_{\mid\mu=n}-

\displaystyle-

\displaystyle\frac{P_{n}^{\left(-\frac{1}{2},-\frac{1}{2}\right)}(x)}{P_{n}^{\left(-\frac{1}{2},-\frac{1}{2}\right)}(1)^{2}}\left[\frac{\partial}{\partial\mu}~P_{\mu}^{\left(-\frac{1}{2},-\frac{1}{2}\right)}(1)\right]_{\mid\mu=n}.

Again, we observe that the remaining derivatives can be found from our result (
).
As a last example, we consider the Chebyshev polynomials of the second kind, given by the definition

\displaystyle U_{n}(x)

\displaystyle=

\displaystyle(n+1)~\frac{P_{n}^{\left(\frac{1}{2},\frac{1}{2}\right)}(x)}{P_{n}^{\left(\frac{1}{2},\frac{1}{2}\right)}(1)}.

The derivative of these polynomials with respect to their order is found in a similar way as for their counterparts above. We compute

\displaystyle\left[\frac{\partial}{\partial\mu}~U_{\mu}(x)\right]_{\mid\mu=n}

\displaystyle=

\displaystyle\frac{P_{n}^{\left(\frac{1}{2},\frac{1}{2}\right)}(x)}{P_{n}^{\left(\frac{1}{2},\frac{1}{2}\right)}(1)}+\frac{n+1}{P_{n}^{\left(\frac{1}{2},\frac{1}{2}\right)}(x)}\left[\frac{\partial}{\partial\mu}~P_{\mu}^{\left(\frac{1}{2},\frac{1}{2}\right)}(x)\right]_{\mid\mu=n}-

\displaystyle-

\displaystyle\frac{(n+1)~P_{n}^{\left(\frac{1}{2},\frac{1}{2}\right)}(x)}{P_{n}^{\left(\frac{1}{2},\frac{1}{2}\right)}(1)^{2}}\left[\frac{\partial}{\partial\mu}~P_{\mu}^{\left(\frac{1}{2},\frac{1}{2}\right)}(1)\right]_{\mid\mu=n}.

As a final comment, we mention that our integral formula (
15
) is applicable to the special cases of the Jacobi polynomials mentioned in this section.
Consequently, the formula can be used to set up and resolve indefinite integrals involving those polynomials.
