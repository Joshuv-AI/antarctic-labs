Dual-Solver: A Generalized ODE Solver for Diffusion Models with Dual Prediction
Soochul Park, Yeon Ju Lee

Abstract
Diffusion models achieve state-of-the-art image quality. However, sampling is costly at inference time because it requires a large number of function evaluations (NFEs). To reduce NFEs, classical ODE numerical methods have been adopted. Yet, the choice of prediction type and integration domain leads to different sampling behaviors. To address these issues, we introduce Dual-Solver, which generalizes multistep samplers through learnable parameters that continuously (i) interpolate among prediction types, (ii) select the integration domain, and (iii) adjust the residual terms. It retains the standard predictor-corrector structure while preserving second-order local accuracy. These parameters are learned via a classification-based objective using a frozen pretrained classifier (e.g., MobileNet or CLIP). For ImageNet class-conditional generation (DiT, GM-DiT) and text-to-image generation (SANA, PixArt- α \alpha ), Dual-Solver improves FID and CLIP scores in the low-NFE regime ( 3 ≤ 3\leq NFE ≤ 9 \leq 9 ) across backbones.

Introduction

Generative modeling aims to learn a data distribution and generate new samples that resemble real data.
Classic approaches include autoregressive models that factorize likelihoods over pixels or tokens
(
55
;
44
)
, variational auto-encoders that optimize an evidence lower bound
(
23
;
54
)
, flow-based models that construct exact, invertible density maps
(
8
;
24
)
, and generative adversarial networks that learn via adversarial training between a generator and a discriminator
(
11
;
1
)
.
Diffusion models have emerged as a powerful class of generative models.
In seminal work,
48
introduced diffusion probabilistic modeling with a forward noising process and a learned reverse process trained by minimizing a KL-divergence objective.
Subsequent reformulations
(
14
)
have streamlined training and inference with simple denoising objectives (e.g., noise or data prediction), leading to state-of-the-art fidelity and robust scaling.
Today, diffusion models drive progress across multiple modalities, including images
(
7
;
42
)
, audio
(
26
;
32
)
, and video
(
15
;
25
)
.

Diffusion models generate samples through iterative denoising steps, making the inference cost scale with the number of function evaluations (NFEs).
Leveraging the probability–flow formulation, which casts sampling as an ordinary differential equation
(
52
)
, a number of recent works have proposed ODE-based acceleration methods.
Along one axis, classical ODE methods—singlestep Runge–Kutta
(
43
)
and multistep Adams–Bashforth
(
2
)
—provide off-the-shelf accuracy–NFE trade-offs for a given evaluation budget
(
3
)
.
Along a second axis, diffusion-dedicated solvers exploit the structure of the denoising dynamics: they approximate noise or data predictions with low-order Taylor expansions or Lagrange interpolation and derive closed-form updates
(
37
;
36
;
40
;
61
;
59
)
.
Lastly, learned solvers optimize the timestep schedule and other sampling-related parameters
(
62
;
45
;
46
;
57
)
.
Because these parameters depend on the backbone and dataset, such solvers are typically tailored to specific backbones and settings (e.g., a chosen NFE and guidance scale).
Training also incurs substantial preparation overhead, as it requires many teacher trajectories or final samples generated using high-NFE sampling.
However, compared to the classical methods and dedicated solvers discussed above, learned solvers deliver substantially better sample quality and remain an active area of research.

We introduce Dual-Solver, a learned solver for diffusion models with three types of learnable parameters:

•

a prediction parameter
\gamma
that interpolates among noise, velocity, and data predictions (Sec.
3.1
);

•

a domain change parameter
\tau
that interpolates between logarithmic and linear domains (Sec.
3.2
);

•

a residual parameter
\kappa
that adjusts the residual term while preserving second-order accuracy (Sec.
3.3
).

We further propose a classification-based learning strategy that yields high-fidelity images even in the low-NFE regime (Sec.
5.2
).
Unlike regression-based learning, which typically requires many target samples generated at high NFEs, our approach requires no target samples.
Solver parameters are learned using either pretrained image classifiers
(
12
;
10
;
18
)
or a zero-shot classifier
(
41
)
.
For
3\leq
NFE
\leq 9

6

2
Preliminaries

2.1
Diffusion Models

Training process.

Diffusion models
(
14
;
52
)
are trained as follows.
A clean sample
{\bm{x}}_{0}
is drawn from the data distribution, and noise is drawn independently from the standard Gaussian distribution. They are then linearly combined
with signal rate
\alpha_{t}
and noise rate
\sigma_{t}
:

{\bm{x}}_{t}\;=\;\alpha_{t}\,{\bm{x}}_{0}\;+\;\sigma_{t}\,\bm{\epsilon},\qquad\text{where }\,{\bm{x}}_{0}\sim p_{\text{data}},\,\bm{\epsilon}\sim\mathcal{N}(\mathbf{0},{\bm{I}}),\,0\leq t\leq T.

(1)

Here,
\alpha_{t}
and
\sigma_{t}
are set by a predefined schedule. Common choices include
variance-preserving (VP), with
\alpha_{t}^{2}+\sigma_{t}^{2}=1

(
48
;
14
)
;
variance-exploding (VE), with
\alpha_{t}=1,\ \sigma_{t}\geq 0

(
50
;
51
)
;
and optimal transport (OT), with
\alpha_{t}=1-t,\ \sigma_{t}=t,\ T=1

(
31
)
.
The backbone is trained to take a noisy sample
{\bm{x}}_{t}
and the time
t
as input and to predict one of the following: the noise
\bm{\epsilon}
, the clean sample
{\bm{x}}_{0}

(
14
)
, or the velocity
{\bm{v}}_{t}=\frac{d\alpha_{t}}{dt}{\bm{x}}_{0}+\frac{d\sigma_{t}}{dt}\bm{\epsilon}

(
31
)
.
By convention, the backbone parameters are denoted
\theta
, and the predictions are written as
\bm{\epsilon}_{\theta}
(noise),
{\bm{x}}_{\theta}
(data), and
{\bm{v}}_{\theta}
(velocity).

Sampling process.

The dynamics corresponding to Eq.
1
can be expressed as the following stochastic differential equation (SDE)
(
52
)
:

d{\bm{x}}_{t}\;=\;f_{t}\,{\bm{x}}_{t}\,dt\;+\;g_{t}\,d{\bm{w}}_{t},\qquad f_{t}\;=\;\frac{d\log\alpha_{t}}{dt},\quad g_{t}^{\,2}\;=\;\frac{d\sigma_{t}^{2}}{dt}\;-\;2\,\frac{d\log\alpha_{t}}{dt}\,\sigma_{t}^{2},

(2)

where
{\bm{w}}_{t}
is a standard Wiener process.
A probability-flow ODE that shares the same marginal distributions as the SDE at every time
t
has been proposed
(
52
)
:

\frac{d{\bm{x}}_{t}}{dt}\;=\;f_{t}\,{\bm{x}}_{t}\;-\;\frac{1}{2}\,g_{t}^{\,2}\,\nabla_{{\bm{x}}}\log q_{t}({\bm{x}}_{t}),\quad\text{where }\;\nabla_{{\bm{x}}}\log q_{t}({\bm{x}}_{t})\;=\;-\frac{\mathbb{E}[\bm{\epsilon}\mid{\bm{x}}_{t}]}{\sigma_{t}}\;\approx\;-\frac{\bm{\epsilon}_{\theta}({\bm{x}}_{t},t)}{\sigma_{t}}.

(3)

Given this ODE, one can perform sampling using classical numerical methods beyond Euler, such as singlestep Runge–Kutta
(
43
)
and multistep Adams–Bashforth schemes
(
2
)
.
Moreover, several works split the right-hand side into linear and nonlinear parts, and evaluate the nonlinear term using finite-difference approximations
(
37
;
36
;
61
)
or via Lagrange interpolation
(
40
;
59
)
.

2.2
Prediction Types

Diffusion backbones are typically trained with noise prediction
(
14
;
22
;
39
)
, whereas flow-matching backbones are trained with velocity prediction
(
31
;
4

58

.
However, noise, velocity, and data predictions can be converted into one another as follows.

{\bm{x}}_{\theta}({\bm{x}}_{t},t)\;=\;\frac{{\bm{x}}_{t}-\sigma_{t}\,\bm{\epsilon}_{\theta}({\bm{x}}_{t},t)}{\alpha_{t}},\quad{\bm{v}}_{\theta}({\bm{x}}_{t},t)\;=\;\frac{d\alpha_{t}}{dt}\,{\bm{x}}_{\theta}({\bm{x}}_{t},t)\;+\;\frac{d\sigma_{t}}{dt}\,\bm{\epsilon}_{\theta}({\bm{x}}_{t},t).

(4)

Using these relationships, a different prediction type can be used at sampling time from that used during training.
For diffusion models, many early samplers use noise prediction
(
14
;
49
;
33
;
40
;
37
)
.
More recently, data prediction has also been widely adopted to improve sample quality
(
36
;
58
;
57
)
.
In contrast, flow-matching backbones typically use velocity prediction at sampling time, as in training
(
31
;
4
;
58
;
46
)
.

Discretization discrepancy.

We ask a simple question: do the prediction types yield the same update?
In continuous time, yes; in discrete time, no.
Fig.
2
illustrates this discrepancy in two dimensions.
For example, applying the Euler method in the
\lambda
-domain (half log-SNR) to noise prediction yields
{\bm{x}}_{t_{i+1}}^{\text{noise}}=\tfrac{\alpha_{t_{i+1}}}{\alpha_{t_{i}}}\big[{\bm{x}}_{t_{i}}-\sigma_{t_{i}}\,\Delta\lambda_{t_{i}}\,\bm{\epsilon}_{\theta}({\bm{x}}_{t_{i}},t_{i})\big],

where
\Delta\lambda_{t_{i}}:=\lambda_{t_{i+1}}-\lambda_{t_{i}}
.
Applying the same method to data prediction and rewriting the result using Eq.
4
gives
{\bm{x}}_{t_{i+1}}^{\text{data}}=\tfrac{\alpha_{t_{i+1}}}{\alpha_{t_{i}}}\big[(1+\Delta\lambda_{t_{i}})e^{-\Delta\lambda_{t_{i}}}\,{\bm{x}}_{t_{i}}-e^{-\Delta\lambda_{t_{i}}}\sigma_{t_{i}}\,\Delta\lambda_{t_{i}}\,\bm{\epsilon}_{\theta}({\bm{x}}_{t_{i}},t_{i})\big].

Since
e^{-\Delta\lambda_{t_{i}}}=1-\Delta\lambda_{t_{i}}+\tfrac{1}{2}\Delta\lambda_{t_{i}}^{2}+\cdots
, they differ at order
O((\Delta\lambda_{t_{i}})^{2})
.
This naturally raises the question of which update is preferable in practice.

3
Dual-Solver

3.1
Dual Prediction with Parameter
\gamma

We propose a
dual prediction
scheme that uses both
{\bm{x}}_{\theta}
and
\bm{\epsilon}_{\theta}
together.
We call it
dual
because it treats
{\bm{x}}_{\theta}
and
\bm{\epsilon}_{\theta}
separately, unlike velocity prediction, which bundles them into
{\bm{v}}_{\theta}
.
Moreover, we introduce the following integral formulation parameterized by
\gamma
, which interpolates between the integral forms of noise, velocity, and data prediction.

Integral form of dual prediction.

\displaystyle{\displaystyle\bm{x}}_{t_{i+1}}=A\,{\bm{x}}_{t_{i}}+B\!\left[\int_{t_{i}}^{t_{i+1}}C\,{\bm{x}}_{\theta}({\bm{x}}_{t},t)\,dt+\int_{t_{i}}^{t_{i+1}}D\,\bm{\epsilon}_{\theta}({\bm{x}}_{t},t)\,dt\right],

(5)

\displaystyle\text{where }\;\begin{cases}A=\left({\sigma_{t_{i+1}}}/{\sigma_{t_{i}}}\right)^{\gamma},\,B=\sigma_{t_{i+1}}^{\gamma},\,C=\dfrac{d}{dt}\!\big(\alpha_{t}\,\sigma_{t}^{-\gamma}\big),\,D=\dfrac{d}{dt}\!\big(\sigma_{t}^{\,1-\gamma}\big)\text{ for }\gamma\geq 0,\\[10.0pt]
A=\left({\alpha_{t_{i+1}}}/{\alpha_{t_{i}}}\right)^{-\gamma},\,B=\alpha_{t_{i+1}}^{-\gamma},\,C=\dfrac{d}{dt}\!\big(\alpha_{t}^{\,1+\gamma}\big),\,D=\dfrac{d}{dt}\!\big(\sigma_{t}\,\alpha_{t}^{\,\gamma}\big)\text{ for }\gamma<0.\end{cases}

It has the following properties:

•

When
\gamma=-1
, the integral reduces to the noise-prediction form (Table
1
).

•

When
\gamma=0
, the integral reduces to the velocity-prediction form (Table
1
).

•

When
\gamma=1
, the integral reduces to the data-prediction form (Table
1
).

From Eq.
3
, we derive the differential form of dual prediction and, by integrating, obtain the integral form given above; the full derivation is provided in Appendix
B.1
. Another role of
\gamma
is to control how much
{\bm{x}}_{t_{i}}
contributes to
{\bm{x}}_{t_{i+1}}
: increasing
\gamma
decreases the coefficient
A
multiplying
{\bm{x}}_{t_{i}}
, whereas decreasing
\gamma
increases
A
.

3.2
Log-Linear Domain Change with Parameter
\tau

Domain change.

Let
L:(0,\infty)\to\mathcal{I}
be a
C^{1}
diffeomorphism onto an interval
\mathcal{I}\subseteq\mathbb{R}
.
To apply a change of variables to the integrals in Eq.
5
, we define the following:

\begin{cases}u(t)=L\big(\alpha_{t}\,\sigma_{t}^{-\gamma}\big),\,v(t)=L\big(\sigma_{t}^{\,1-\gamma}\big)\text{ for }\gamma\geq 0,\\[6.0pt]
u(t)=L\big(\alpha_{t}^{\,1+\gamma}\big),\,v(t)=L\big(\sigma_{t}\,\alpha_{t}^{\,\gamma}\big)\text{ for }\gamma<0.\end{cases}

(6)

By the chain rule,
\tfrac{d}{dt}L^{-1}(u)=\tfrac{dL^{-1}(u)}{du}\,\tfrac{du}{dt}
and similarly for
v
.
Thus, we obtain

{\bm{x}}_{t_{i+1}}=A{\bm{x}}_{t_{i}}\;+\;B\left[\int_{u_{i}}^{u_{i+1}}\frac{dL^{-1}(u)}{du}\,{\bm{x}}_{\theta}(u)\,du+\int_{v_{i}}^{v_{i+1}}\frac{dL^{-1}(v)}{dv}\,\bm{\epsilon}_{\theta}(v)\,dv\right].

(7)

Here,
u_{i}=u(t_{i}),\ u_{i+1}=u(t_{i+1})
and
v_{i}=v(t_{i}),\ v_{i+1}=v(t_{i+1})
.
A
and
B
are as defined in Eq.
5
, and

{\bm{x}}_{\theta}(u)\coloneqq{\bm{x}}_{\theta}({\bm{x}}_{u^{-1}(u)},\,u^{-1}(u))

and

\bm{\epsilon}_{\theta}(v)\coloneqq\bm{\epsilon}_{\theta}({\bm{x}}_{v^{-1}(v)},\,v^{-1}(v))
.

Log-linear transform.

Previous works
(
9
;
40
;
62
)
use the linear transform
L(y)=y
with noise prediction.
Because
\tfrac{d}{du}L^{-1}(u)=1
, the integrand carries no weighting factor, making it straightforward to develop approximations such as Taylor expansions and Lagrange interpolation.
By contrast, other works
(
37
;
36
;
61
;
59
)
use a logarithmic transform
L(y)=\log y
.
Because
\tfrac{d}{du}L^{-1}(u)=e^{u}
, the integrand carries an exponential weight. A closed-form approximation can be obtained via an exponential integrator
(
17
)
or by using Lagrange interpolation.
Motivated by these works, we propose a
log-linear
transform parameterized by a scalar
\tau
.

L(y;\tau)\;=\;\frac{\log\!\left(1+\tau y\right)}{\tau},\quad\tau>0.

(8)

This transform is invertible, with inverse
L^{-1}(u;\tau)=\bigl(e^{\tau u}-1\bigr)/\tau
; its weighting factor is
\tfrac{\mathrm{d}}{\mathrm{d}u}L^{-1}(u;\tau)=e^{\tau u}
. Consequently, it has the following properties:

•

As
\tau\to 0^{+}:\,

L(y;\tau)\to y,\,

\;\tfrac{\mathrm{d}}{\mathrm{d}u}L^{-1}(u;\tau)\to 1
.

•

When
\tau=1:\,

L(y;\tau)=\log(1+y),\,

\;\tfrac{\mathrm{d}}{\mathrm{d}u}L^{-1}(u;\tau)=e^{u}
.

We apply the log–linear transform to Eq.
7
, allowing separate parameters
\tau_{u}
and
\tau_{v}
for the
u
- and
v
-integrals, respectively.
A comparison of domain-change functions is presented in Sec.
6.2.3
.

3.3
Approximation with Parameter
\kappa

On the interval
[u_{i},u_{i+1}]
, we approximate
{\bm{x}}_{\theta}
in two ways: (i) the first-order approximation
{\bm{x}}_{\theta}(u)={\bm{x}}_{\theta}(u_{i})
; and (ii) the second-order forward-difference approximation
{\bm{x}}_{\theta}(u)={\bm{x}}_{\theta}(u_{i})+\tfrac{\Delta{\bm{x}}_{\theta}(u_{i})}{\Delta u_{i}}(u-u_{i})
. Here,
{\bm{x}}_{\theta}(u_{i})\coloneqq{\bm{x}}_{\theta}({\bm{x}}_{u^{-1}(u_{i})},u^{-1}(u_{i}))
,
\Delta{\bm{x}}_{\theta}(u_{i})\coloneqq{\bm{x}}_{\theta}(u_{i+1})-{\bm{x}}_{\theta}(u_{i})
, and
\Delta u_{i}\coloneqq u_{i+1}-u_{i}
. We also introduce
K(\Delta u_{i};\kappa_{u})=\kappa_{u}(\Delta u_{i})^{2}
, an
\mathcal{O}((\Delta u_{i})^{2})
term, to allow additional flexibility in the residual term while preserving local accuracy.

\kappa_{u}
is a real scalar parameter that controls the magnitude of the residual term.
Applying the same approximations to
\bm{\epsilon}_{\theta}
yields the following first-order predictor
{\bm{x}}_{t_{i+1}}^{\text{1st-pred.}}
and second-order corrector
{\bm{x}}_{t_{i+1}}^{\text{2nd-corr.}}
:

\displaystyle{\bm{x}}_{t_{i+1}}^{\text{1st-pred.}}=A{\bm{x}}_{t_{i}}+B\Big[{\bm{x}}_{\theta}(u_{i})\!\big(\Delta L^{-1}(u_{i})+K(\Delta u_{i};\kappa_{u})\big)+\bm{\epsilon}_{\theta}(v_{i})\!\big(\Delta L^{-1}(v_{i})+K(\Delta v_{i};\kappa_{v})\big)\Big].

(9)

\displaystyle{\bm{x}}_{t_{i+1}}^{\text{2nd-corr.}}=\;A{\bm{x}}_{t_{i}}+B\Big[

\displaystyle{\displaystyle\bm{x}}_{\theta}(u_{i})\,\Delta L^{-1}(u_{i})+\frac{\Delta{\bm{x}}_{\theta}(u_{i})}{2}\,\big(\Delta L^{-1}(u_{i})+K(\Delta u_{i};\kappa_{u})\big)+

(10)

\displaystyle\bm{\epsilon}_{\theta}(v_{i})\,\Delta L^{-1}(v_{i})+\frac{\Delta\bm{\epsilon}_{\theta}(v_{i})}{2}\,\big(\Delta L^{-1}(v_{i})+K(\Delta v_{i};\kappa_{v})\big)\Big].

Here,
\Delta L^{-1}(u_{i})\coloneqq L^{-1}(u_{i+1})-L^{-1}(u_{i})
and
A
and
B
are as defined in Eq.
5
.
When evaluating
L^{-1}(u_{i})
, with
\alpha_{t_{i}}
,
\sigma_{t_{i}}
, and
\gamma
already known, it can be obtained without writing
L^{-1}
explicitly.
For example, for
\gamma\geq 0
, we have
L^{-1}(u_{i})=\alpha_{t_{i}}\sigma_{t_{i}}^{-\gamma}
(see Eq.
6
).

Detailed derivations of the predictor and corrector are provided in Appendix
B.2
, and the corresponding local-accuracy theorem and its proof are given in Appendix
C
.

4
Implementation Details

Dual-Solver performs sampling using a predictor–corrector scheme
(
3
)
based on the equations developed in the previous section.
We detail the sampling scheme in Sec.
4.1
and then present all learnable parameters in Sec.
4.2
.

4.1
Sampling Scheme

Alg.
1
describes the sampling procedure of Dual-Solver.
Sampling requires a backbone that provides both
{\bm{x}}_{\theta}
and
\bm{\epsilon}_{\theta}
; when only one prediction is available, the other can be obtained via Eq.
4
.
Given
M
steps, we use timesteps
\{t_{i}\}_{i=0}^{M}
with
t_{0}=T
and draw the initial noise
{\bm{x}}_{t_{0}}\sim\mathcal{N}(0,I)
.
We also use a list
\ell
to store previous evaluations.
Empirically, a first-order predictor with a second-order corrector performs best, as shown in Sec.
6.2
.
At step
i
, the first-order predictor takes the current state
{\bm{x}}_{t_{i}}
and the model evaluations
\{{\bm{x}}_{\theta}({\bm{x}}_{t_{i}},t_{i}),\,\bm{\epsilon}_{\theta}({\bm{x}}_{t_{i}},t_{i})\}
to produce a provisional sample
{\bm{x}}_{t_{i+1}}^{\prime}
.
The second-order corrector then combines the evaluations at
t_{i}
with fresh evaluations at
t_{i+1}
, i.e.,
\{{\bm{x}}_{\theta}({\bm{x}}_{t_{i+1}}^{\prime},t_{i+1}),\,\bm{\epsilon}_{\theta}({\bm{x}}_{t_{i+1}}^{\prime},t_{i+1})\}
, to yield the corrected sample
{\bm{x}}_{t_{i+1}}
.
At the final step
i=M-1
, the corrector is not applied.

4.2
Learnable Parameters

For each
i
-th step, the parameter sets are

\phi_{i}^{\mathrm{pred}}=\{\gamma_{i}^{\mathrm{pred}},\tau_{u,i}^{\mathrm{pred}},\tau_{v,i}^{\mathrm{pred}},\kappa_{u,i}^{\mathrm{pred}},\kappa_{v,i}^{\mathrm{pred}}\}

and

\phi_{i}^{\mathrm{corr}}=\{\gamma_{i}^{\mathrm{corr}},\tau_{u,i}^{\mathrm{corr}},\tau_{v,i}^{\mathrm{corr}},\kappa_{u,i}^{\mathrm{corr}},\kappa_{v,i}^{\mathrm{corr}}\}
.
Thus, each step uses
2\times 5=10
parameters, except for the last step (
i=M-1
), which does not use the corrector and therefore has only 5 parameters.
Fig.
3
shows the learned parameters for the NFE=5 setting using a DiT
(
39
)
backbone.
Assuming a noise-prediction backbone (the same reasoning applies to data- and velocity-prediction backbones) and a first-order predictor with a second-order corrector (Sec.
4.1
),

\phi_{i}^{\mathrm{pred}}
and
\phi_{i}^{\mathrm{corr}}
determine the coefficients for an update that combines the current state
{\bm{x}}_{t_{i}}
and two model evaluations,

\bm{\epsilon}_{\theta}({\bm{x}}^{\prime}_{t_{i}},t_{i})
and
\bm{\epsilon}_{\theta}({\bm{x}}^{\prime}_{t_{i+1}},t_{i+1})
,
to produce
{\bm{x}}_{t_{i+1}}
.
This may seem heavy, but Sec.
6.2.2
shows it is necessary.

In addition to these parameters, we also learn the evaluation times
\{t_{i}\}_{i=1}^{M-1}
(with
t_{0}
and
t_{M}
fixed), where
M
denotes the number of steps.
Following prior work
(
53
;
57
)
,
we employ unnormalized step variables
\{\Delta t^{\prime}_{i}\}_{i=0}^{M-1}
and apply a softmax over
i=0,\dots,M-1
to obtain normalized step sizes
\{\Delta t_{i}\}_{i=0}^{M-1}
(nonnegative and summing to one).
The timesteps are obtained via a cumulative sum:
t_{i}=t_{0}+(t_{M}-t_{0})\sum_{k=0}^{i-1}\Delta t_{k},\,i=1,\dots,M-1.

5.1
Regression-based Parameter Learning

In regression-based learning, a solver with trainable parameters is referred to as a student solver, while an existing fixed solver is referred to as a teacher solver.
The student is then trained to imitate the behavior of the teacher running at a high NFE.
Most prior works adopt
trajectory regression

(
45
;
62
;
57
)
, which compares the trajectories generated by the teacher and the student, or
sample regression

(
46
)
, which compares only the final samples.
Since comparisons in the trajectory or sample space often show a mismatch with visual perceptual quality,
feature regression
has been proposed
(
53
)
, in which the discrepancy is measured in a feature space using metrics such as LPIPS
(
60
)
.
However, all of these methods require a teacher solver and incur substantial overhead in preparing supervision targets, and they tend to perform poorly in the very low NFE regime (e.g., NFE
\leq 5
; see Table

5.2
Classification-based Parameter Learning

Beyond feature regression, we consider
soft-label classification
, where we apply a cross-entropy loss between the classifier outputs (probabilities) of the student and the teacher.
This approach yields improved results in the low-NFE regime (Table
5
), but it still requires a teacher solver to generate the target probabilities.

To remove this dependency, we further propose
hard-label classification
, which compares the student’s classifier outputs (probabilities) against the input class label using a cross-entropy loss, without any teacher solver.
The overall training procedure is described in Alg.
2
.
The sample
{\bm{x}}_{0}
generated by the solver
\mathcal{S}
is passed through the decoder
\mathcal{D}
and the classifier
\mathcal{C}
to obtain class probabilities
p
. We then compute a cross-entropy loss between
p
and the class label
y\sim\mathcal{Y}
, and update the solver parameters
\phi
for all time steps via backpropagation.
For text-to-image tasks, the class labels are replaced with text prompts, which can be obtained from datasets such as MSCOCO 2014
(
30
)
or MJHQ-30K
(
29
)
, and the cross-entropy loss is replaced with CLIP loss
(
41
)
.

Unlike regression to teacher targets, this method focuses on whether the generated samples lie on the correct side of the classifier’s decision boundary, enabling less restrictive training.
A potential issue is a mismatch between the distribution learned by the classifier and the ground-truth data distribution, but this can be mitigated by selecting an appropriate classifier.
In Sec.
6.2.4
, we examine the relationship between the classifier’s accuracy and the resulting FID scores.

7
Conclusions and Limitations

This paper introduces Dual-Solver, a predictor–corrector sampler that achieves second-order numerical accuracy.
It features per-step learnable parameters
(\gamma,\tau,\kappa)
that govern the prediction types, the integration domain, and the second-order residual adjustment.
All solver parameters are optimized end-to-end with a classification-based objective using a pretrained image classifier.
Across diverse diffusion and flow matching backbones, experiments show substantial improvements over competing solvers in the low-NFE regime (
3\leq
NFE
\leq 9
), as measured by FID and CLIP score.
Limitations include the absence of unconditional backbones and a lack of analysis beyond second-order accuracy; both are left for future work.

Appendix B
Derivations

B.1
Derivation of Dual Prediction

Differential Form of Dual Prediction.

The differential form corresponding to the integral form in Eq.
5
is given by

\frac{d{\bm{x}}_{t}}{dt}=\beta{\bm{x}}_{t}+\alpha_{t}\!\Big(\frac{d\log\alpha_{t}}{dt}-\beta\Big){\bm{x}}_{\theta}({\bm{x}}_{t},t)+\sigma_{t}\!\Big(\frac{d\log\sigma_{t}}{dt}-\beta\Big)\bm{\epsilon}_{\theta}({\bm{x}}_{t},t).

(11)

To derive this form, we start from the probability-flow ODE in Eq.
3
:

\displaystyle\frac{d{\bm{x}}_{t}}{dt}=f_{t}\,{\bm{x}}_{t}-\frac{1}{2}\,g_{t}^{2}\,\nabla_{\bm{x}}\log q({\bm{x}}_{t}),\,

\displaystyle\text{ where }f_{t}=\frac{d\log\alpha_{t}}{dt},\,g_{t}^{2}=\frac{d}{dt}\sigma_{t}^{2}-2\,f_{t}\,\sigma_{t}^{2},\,\nabla_{\bm{x}}\log q({\bm{x}}_{t})=-\,\frac{\bm{\epsilon}_{\theta}({\bm{x}}_{t},t)}{\sigma_{t}}.

Substituting
f_{t}
,
g_{t}^{2}
, and
\nabla_{\bm{x}}\log q({\bm{x}}_{t})
yields:

\displaystyle\frac{d{\bm{x}}_{t}}{dt}

\displaystyle=\frac{d\log\alpha_{t}}{dt}\,{\bm{x}}_{t}+\frac{1}{2\sigma_{t}}\!\left(\frac{d}{dt}\sigma_{t}^{2}-2\frac{d\log\alpha_{t}}{dt}\,\sigma_{t}^{2}\right)\bm{\epsilon}_{\theta}({\bm{x}}_{t},t)

\displaystyle=\frac{d\log\alpha_{t}}{dt}\,{\bm{x}}_{t}+\sigma_{t}\!\left(\frac{d\log\sigma_{t}}{dt}-\frac{d\log\alpha_{t}}{dt}\right)\bm{\epsilon}_{\theta}({\bm{x}}_{t},t).

Introducing an arbitrary
\beta\in\mathbb{R}
, we can rewrite:

\displaystyle\frac{d{\bm{x}}_{t}}{dt}

\displaystyle=\beta{\bm{x}}_{t}+\Big(\frac{d\log\alpha_{t}}{dt}-\beta\Big){\bm{x}}_{t}+\sigma_{t}\!\left(\frac{d\log\sigma_{t}}{dt}-\frac{d\log\alpha_{t}}{dt}\right)\bm{\epsilon}_{\theta}({\bm{x}}_{t},t)

\displaystyle=\beta{\bm{x}}_{t}+\Big(\frac{d\log\alpha_{t}}{dt}-\beta\Big)\big(\alpha_{t}{\bm{x}}_{\theta}({\bm{x}}_{t},t)+\sigma_{t}\bm{\epsilon}_{\theta}({\bm{x}}_{t},t)\big)+\sigma_{t}\!\left(\frac{d\log\sigma_{t}}{dt}-\frac{d\log\alpha_{t}}{dt}\right)\bm{\epsilon}_{\theta}({\bm{x}}_{t},t)

\displaystyle=\beta{\bm{x}}_{t}+\alpha_{t}\!\Big(\frac{d\log\alpha_{t}}{dt}-\beta\Big){\bm{x}}_{\theta}({\bm{x}}_{t},t)+\sigma_{t}\!\Big(\frac{d\log\sigma_{t}}{dt}-\beta\Big)\bm{\epsilon}_{\theta}({\bm{x}}_{t},t).

Thus, we obtain the differential form of
dual prediction
. It is straightforward to verify that choosing
\beta=\tfrac{d}{dt}\log\alpha_{t}
recovers the noise-prediction form,
\beta=\tfrac{d}{dt}\log\sigma_{t}
recovers the data-prediction form, and
\beta=0
recovers the velocity-prediction form in Table
1
.

Integral Form of Dual Prediction.

We next apply the variation-of-constants method to Eq.
11
to obtain the following integral representation:

\displaystyle{\bm{x}}_{t_{i+1}}=

\displaystyle\exp\!\Bigl(\int_{t_{i}}^{t_{i+1}}\beta_{u}\,du\Bigr)\,{\bm{x}}_{t_{i}}\;+\;

\displaystyle\int_{t_{i}}^{t_{i+1}}\exp\!\Bigl(\int_{s}^{t_{i+1}}\beta_{u}\,du\Bigr)\Bigl[\alpha_{s}\Bigl(\frac{d\log\alpha_{s}}{ds}-\beta_{s}\Bigr)\,{\bm{x}}_{\theta}\;+\;\sigma_{s}\Bigl(\frac{d\log\sigma_{s}}{ds}-\beta_{s}\Bigr)\,\bm{\epsilon}_{\theta}\Bigr]\,ds.

We reparameterize
\beta
in terms of a new variable
\gamma\in\mathbb{R}
as follows:

\beta(\gamma)=\begin{cases}\displaystyle\gamma\,\frac{d\log\sigma_{t}}{dt}\;=\;\gamma\,\frac{\dot{\sigma}_{t}}{\sigma_{t}},&\gamma\geq 0,\\
\displaystyle-\gamma\,\frac{d\log\alpha_{t}}{dt}\;=\;-\gamma\,\frac{\dot{\alpha}_{t}}{\alpha_{t}},&\gamma<0.\end{cases}

Then we obtain the
\gamma
-interpolated integral form of dual prediction (Eq.
5
).

Derivation of Second-Order Corrector

First, we approximate
{\bm{x}}_{\theta}(u)
and
\bm{\epsilon}_{\theta}(v)
at
u_{i}
and
v_{i}
by a second-order forward-difference expansion.

\displaystyle{\bm{x}}_{t_{i+1}}\approx A{\bm{x}}_{t_{i}}\;+\;B\bigg[

\displaystyle{\displaystyle\bm{x}}_{\theta}(u_{i})\Delta L^{-1}(u_{i})\;+\;\frac{\Delta{\bm{x}}_{\theta}(u_{i})}{\Delta u_{i}}\int_{u_{i}}^{u_{i+1}}(u-u_{i})\frac{dL^{-1}(u)}{du}du\;+\;

\displaystyle\bm{\epsilon}_{\theta}(v_{i})\Delta L^{-1}(v_{i})\;+\;\frac{\Delta\bm{\epsilon}_{\theta}(v_{i})}{\Delta v_{i}}\int_{v_{i}}^{v_{i+1}}(v-v_{i})\frac{dL^{-1}(v)}{dv}dv\bigg].

Using

\displaystyle\frac{1}{\Delta u_{i}}

\displaystyle\int_{u_{i}}^{u_{i+1}}(u-u_{i})\frac{dL^{-1}(u)}{du}\,du

\displaystyle=\frac{1}{2}\left(\left.\frac{dL^{-1}(u)}{du}\right|_{u_{i}}\Delta u_{i}+O((\Delta u_{i})^{2})\right)

\displaystyle=\frac{1}{2}\left(\Delta L^{-1}(u_{i})+\mathcal{O}((\Delta u_{i})^{2})\right)

we obtain

\displaystyle{\bm{x}}_{t_{i+1}}=A{\bm{x}}_{t_{i}}\;+\;B\bigg[

\displaystyle{\displaystyle\bm{x}}_{\theta}(u_{i})\Delta L^{-1}(u_{i})+\frac{\Delta{\bm{x}}_{\theta}(u_{i})}{2}\left(\Delta L^{-1}(u_{i})+\mathcal{O}((\Delta u_{i})^{2})\right)

\displaystyle+\bm{\epsilon}_{\theta}(v_{i})\Delta L^{-1}(v_{i})+\frac{\Delta\bm{\epsilon}_{\theta}(v_{i})}{2}\left(\Delta L^{-1}(v_{i})+\mathcal{O}((\Delta v_{i})^{2})\right)\bigg].

Next, while preserving second-order accuracy, we incorporate the
K(\Delta u_{i};\kappa_{u})=\mathcal{O}((\Delta u_{i})^{2})
and
K(\Delta v_{i};\kappa_{v})=\mathcal{O}((\Delta v_{i})^{2})
residual terms, which yields the second-order corrector of Dual-Solver (Eq.
10
).

Appendix C
Local Truncation Error

C.1
Local Truncation Error of First-Order Predictor

Theorem C.1
.

Assume that
{\bm{x}}_{\theta}(u)
and
\bm{\epsilon}_{\theta}(v)
are
C^{1}
on
[u_{i},u_{i+1}]
and
[v_{i},v_{i+1}]
, respectively. Let
{\bm{x}}^{\text{exact}}_{t_{i+1}}
denote the exact update in equation
7
, and let
{\bm{x}}^{\text{1st-pred.}}_{t_{i+1}}
denote the first–order predictor defined in equation
9
. Then we have

\big\|{\bm{x}}_{t_{i+1}}^{\text{exact}}-{\bm{x}}_{t_{i+1}}^{\text{1st-pred.}}\big\|\;=\;\mathcal{O}\!\big((\Delta u_{i})^{2}+(\Delta v_{i})^{2}\big).

Proof.

From Eq.
7
,
the exact update can be written as

{\bm{x}}_{t_{i+1}}^{\text{exact}}=A{\bm{x}}_{t_{i}}\;+\;B\left[I_{u}\;+\;I_{v}\right],

where
I_{u}=\int_{u_{i}}^{u_{i+1}}\frac{dL^{-1}(u)}{du}\,{\bm{x}}_{\theta}(u)\,du
and
I_{v}=\int_{v_{i}}^{v_{i+1}}\frac{dL^{-1}(v)}{dv}\,\bm{\epsilon}_{\theta}(v)\,dv
.

Eq.
9
defines the first-order predictor

{\bm{x}}_{t_{i+1}}^{\text{1st-pred.}}=A{\bm{x}}_{t_{i}}\;+\;B\Big[I^{\prime}_{u}\;+\;I^{\prime}_{v}\Big],

with
I^{\prime}_{u}={\bm{x}}_{\theta}(u_{i})\,\big(\Delta L^{-1}(u_{i})+K(\Delta u_{i};\kappa_{u})\big)
and
I^{\prime}_{v}=\bm{\epsilon}_{\theta}(v_{i})\,\big(\Delta L^{-1}(v_{i})+K(\Delta v_{i};\kappa_{v})\big)
.

The accuracy can be obtained by taking a Taylor expansion of
I_{u}
and estimating the order of
I_{u}-I^{\prime}_{u}
.

Expansion of
I_{u}

\displaystyle I_{u}

\displaystyle=\int_{u_{i}}^{u_{i+1}}\frac{dL^{-1}(u)}{du}{\bm{x}}_{\theta}(u)du

\displaystyle={\bm{x}}_{\theta}(u_{i})\Delta L^{-1}(u_{i})\;+\;\mathcal{O}\big((\Delta u_{i})^{2}\big).

Order estimate of
I_{u}-I^{\prime}_{u}

I_{u}-I^{\prime}_{u}=\mathcal{O}\!\big((\Delta u_{i})^{2}\big)\;-\;{\bm{x}}_{\theta}(u_{i})\,K(\Delta u_{i};\kappa_{u}).

Since
{\bm{x}}_{\theta}(u_{i})=\mathcal{O}(1)
and
K(\Delta u_{i};\kappa_{u})=\mathcal{O}((\Delta u_{i})^{2})
, it follows that

{\bm{x}}_{\theta}(u_{i})\,K(\Delta u_{i};\kappa_{u})=\mathcal{O}\big((\Delta u_{i})^{2}\big).

Therefore,

I_{u}-I^{\prime}_{u}=\mathcal{O}\!\big((\Delta u_{i})^{2}\big).

The bound
I_{v}-I^{\prime}_{v}=\mathcal{O}\big((\Delta v_{i})^{2}\big)
can be derived in the same way.

Conclusion

\displaystyle{\bm{x}}_{t_{i+1}}^{\text{exact}}-{\bm{x}}_{t_{i+1}}^{\text{1st-pred.}}

\displaystyle=B\big[(I_{u}-I^{\prime}_{u})+(I_{v}-I^{\prime}_{v})\big]

\displaystyle=B\Big[\mathcal{O}((\Delta u_{i})^{2})+\mathcal{O}((\Delta v_{i})^{2})\Big]

\displaystyle=\mathcal{O}\big((\Delta u_{i})^{2}+(\Delta v_{i})^{2}\big).

∎

C.2
Local Truncation Error of Second-Order Predictor

Theorem C.2
.

Assume that
{\bm{x}}_{\theta}(u)
and
\bm{\epsilon}_{\theta}(v)
are
C^{2}
on
[u_{i-1},u_{i+1}]
and
[v_{i-1},v_{i+1}]
, respectively. Let
{\bm{x}}^{\text{exact}}_{t_{i+1}}
denote the exact update in equation
7
, and let
{\bm{x}}^{\text{2nd-pred.}}_{t_{i+1}}
denote the second–order predictor defined in equation
12
. Then we have

\big\|{\bm{x}}_{t_{i+1}}^{\text{exact}}-{\bm{x}}_{t_{i+1}}^{\text{2nd-pred.}}\big\|\;=\;\mathcal{O}\!\big((\Delta u_{i})^{3}+(\Delta v_{i})^{3}\big).

Proof.

From Eq.
7
,
the exact update is given by

{\bm{x}}_{t_{i+1}}^{\text{exact}}=A{\bm{x}}_{t_{i}}\;+\;B\left[I_{u}\;+\;I_{v}\right],

where
I_{u}=\int_{u_{i}}^{u_{i+1}}\frac{dL^{-1}(u)}{du}\,{\bm{x}}_{\theta}(u)\,du
and
I_{v}=\int_{v_{i}}^{v_{i+1}}\frac{dL^{-1}(v)}{dv}\,\bm{\epsilon}_{\theta}(v)\,dv
.

Eq.
12
defines the second-order predictor

{\bm{x}}_{t_{i+1}}^{\text{2nd-pred.}}=A{\bm{x}}_{t_{i}}\;+\;B\Big[I^{\prime}_{u}\;+\;I^{\prime}_{v}\Big],

with
I^{\prime}_{u}={\bm{x}}_{\theta}(u_{i})\,\Delta L^{-1}(u_{i})+\frac{\Delta{\bm{x}}_{\theta}(u_{i-1})}{2r_{i}^{(u)}}\,\big(\Delta L^{-1}(u_{i})+K(\Delta u_{i};\kappa_{u})\big)
and
I^{\prime}_{v}=\bm{\epsilon}_{\theta}(v_{i})\,\Delta L^{-1}(v_{i})+\frac{\Delta\bm{\epsilon}_{\theta}(v_{i-1})}{2r_{i}^{(v)}}\,\big(\Delta L^{-1}(v_{i})+K(\Delta v_{i};\kappa_{v})\big)
.

The accuracy can be obtained by taking a Taylor expansion of
I_{u}
and estimating the order of
I_{u}-I^{\prime}_{u}
.

Expansion of
I_{u}

\displaystyle I_{u}=\int_{u_{i}}^{u_{i+1}}\frac{dL^{-1}(u)}{du}\,{\bm{x}}_{\theta}(u)\,du

\displaystyle={\bm{x}}_{\theta}(u_{i})\,\Delta L^{-1}(u_{i})+\int_{u_{i}}^{u_{i+1}}\frac{dL^{-1}(u)}{du}\big({\bm{x}}_{\theta}(u)-{\bm{x}}_{\theta}(u_{i})\big)\,du

\displaystyle={\bm{x}}_{\theta}(u_{i})\,\Delta L^{-1}(u_{i})+{\bm{x}}^{\prime}_{\theta}(u_{i})\int_{u_{i}}^{u_{i+1}}(u-u_{i})\frac{dL^{-1}(u)}{du}\,du\;+\;\mathcal{O}\!\big((\Delta u_{i})^{3}\big)

\displaystyle={\bm{x}}_{\theta}(u_{i})\,\Delta L^{-1}(u_{i})+\frac{1}{2}\,{\bm{x}}^{\prime}_{\theta}(u_{i})\,\Delta u_{i}\,\Delta L^{-1}(u_{i})\;+\;\mathcal{O}\!\big((\Delta u_{i})^{3}\big)

\displaystyle={\bm{x}}_{\theta}(u_{i})\,\Delta L^{-1}(u_{i})+\frac{1}{2r_{i}^{(u)}}\,\Delta{\bm{x}}_{\theta}(u_{i-1})\,\Delta L^{-1}(u_{i})\;+\;\mathcal{O}\!\big((\Delta u_{i})^{3}\big).

Order estimate of
I_{u}-I^{\prime}_{u}

I_{u}-I^{\prime}_{u}=\mathcal{O}\!\big((\Delta u_{i})^{3}\big)\;-\;\frac{1}{2r_{i}^{(u)}}\,\Delta{\bm{x}}_{\theta}(u_{i-1})\,K(\Delta u_{i};\kappa_{u}).

Since
\Delta{\bm{x}}_{\theta}(u_{i-1})=\mathcal{O}(\Delta u_{i})
and
K(\Delta u_{i};\kappa_{u})=\mathcal{O}((\Delta u_{i})^{2})
, it follows that

\Delta{\bm{x}}_{\theta}(u_{i-1})\,K(\Delta u_{i};\kappa_{u})=\mathcal{O}\big((\Delta u_{i})^{3}\big).

Therefore,

I_{u}-I^{\prime}_{u}=\mathcal{O}\!\big((\Delta u_{i})^{3}\big).

The bound
I_{v}-I^{\prime}_{v}=\mathcal{O}\big((\Delta v_{i})^{3}\big)
can be derived in the same way.

Conclusion

\displaystyle{\bm{x}}_{t_{i+1}}^{\text{exact}}-{\bm{x}}_{t_{i+1}}^{\text{2nd-pred.}}

\displaystyle=B\big[(I_{u}-I^{\prime}_{u})+(I_{v}-I^{\prime}_{v})\big]

\displaystyle=B\Big[\mathcal{O}((\Delta u_{i})^{3})+\mathcal{O}((\Delta v_{i})^{3})\Big]

\displaystyle=\mathcal{O}\big((\Delta u_{i})^{3}+(\Delta v_{i})^{3}\big).

∎

Appendix G
Details of parameter interpolation across NFEs

In this section, we describe how to interpolate the parameters discussed in Sec.
6.3
so that they can be used at other NFEs.
The parameters of Dual-Solver,

\phi=\{\gamma^{\mathrm{pred}},\tau_{u}^{\mathrm{pred}},\tau_{v}^{\mathrm{pred}},\kappa_{u}^{\mathrm{pred}},\kappa_{v}^{\mathrm{pred}},\gamma^{\mathrm{corr}},\tau_{u}^{\mathrm{corr}},\tau_{v}^{\mathrm{corr}},\kappa_{u}^{\mathrm{corr}},\kappa_{v}^{\mathrm{corr}}\},

are given as arrays whose length equals the NFE.
(The corrector parameters have length NFE
-1
, and we match the length to NFE by repeating the last element.)
For example,
\gamma^{\mathrm{pred}}=(\gamma^{\mathrm{pred}}_{0},\dots,\gamma^{\mathrm{pred}}_{NFE-1})
.
To interpolate these parameters, we consider the following linear interpolation scheme for a generic array.

Definition G.1

(Linear interpolation)
.

Let
f^{(M)}=(f^{(M)}_{0},\dots,f^{(M)}_{M-1})
be an array of length
M
.
The linearly interpolated array
\mathrm{Interp}(f^{(M)};N)
of length
N
is defined as follows.
First, set

t_{i}=\frac{i}{N-1}\,(M-1),\qquad j_{i}=\big\lfloor t_{i}\big\rfloor,\qquad\alpha_{i}=t_{i}-j_{i},

and for each
i=0,\dots,N-1
define

\mathrm{Interp}(f^{(M)};N)[i]=(1-\alpha_{i})\,f^{(M)}_{j_{i}}+\alpha_{i}\,f^{(M)}_{j_{i}+1}.

Definition G.2

(Averaged linear interpolation)
.

Let
M<N<L
be three NFEs, and let

f^{(M)}\in\mathbb{R}^{M}
and
f^{(L)}\in\mathbb{R}^{L}
be the corresponding arrays.
We first obtain their linearly interpolated versions of length
N
,

\tilde{f}^{(M)}=\mathrm{Interp}(f^{(M)};N),\qquad\tilde{f}^{(L)}=\mathrm{Interp}(f^{(L)};N).

We then use the relative position of
N
between
M
and
L
as weights and define

w_{M}=\frac{L-N}{L-M},\qquad w_{L}=\frac{N-M}{L-M},

and, for each
i=0,\dots,N-1
,

\mathrm{Interp}(f^{(M)},f^{(L)};N)[i]=w_{M}\,\tilde{f}^{(M)}[i]+w_{L}\,\tilde{f}^{(L)}[i].

Using this procedure, we obtain the array for an intermediate NFE from the two arrays at neighboring NFEs, and apply the same construction to every parameter in
\phi
.
Examples of interpolated parameters are shown in Fig.
15
.
Specifically, we obtain the parameters for NFE = 4, 6, and 8 by interpolating those learned at NFE = (3, 5), (5, 7), and (7, 9), respectively.
