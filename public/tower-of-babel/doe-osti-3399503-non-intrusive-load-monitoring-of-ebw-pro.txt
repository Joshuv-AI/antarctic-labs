 24 of 31

●
 arc out events are manifested directly in beam voltage and current
●
 “hard” arc out events can be detected in input and output power
 – “soft” arc out events detected in output power but not detected input
 power
 ●
 to be detected in input power, arc out event must be greater than some
 amplitude/duration/energy threshold
 ●
 recommend study to determine arc out event threshold causing deleterious
 influence on weld quality
●
 disturbances that show change in beam current also show in
 beam bias voltage signal

 25 of 31

●
 pulsing beam voltage did not yield expected results
 – pulsing pattern did not appear regularly in beam voltage signal
 – programmed Beam voltage values were not achieved
 – programmed Beam current value not achieved

●
 pulsing beam voltage produces corresponding changes in beam current and beam bias signals
●
 potential causes of unexpected results
 – machine program operated differently than anticipated
 – machine not designed/capable of changing beam voltage at a rapid rate
 – machine is designed to maintain constant beam voltage and pulsing beam voltage causes machine control
 system to oscillate
 – recommend deeper understanding of machine programming and repeat beam voltage pulsing experiments

●
 influence of beam voltage pulsing detected in beam output power signal but not detected in input
 power signal

 26 of 31

●
 pulsing beam current produces changes between
 commanded values as expected
 – since beam bias voltage controls beam current, pulsing beam
 current produces corresponding changes in beam bias voltage
●
 pulsing beam current produces changes in input and output
 power signals
 – as beam current pulsing frequency increases, a frequency limit will
 be reached where beam current pulsing frequency and amplitude
 will not be detectable in input power due to 60Hz input power
 frequency
 – recommend study to determine limits of detecting beam pulsing in
 input beam power
 27 of 31

●
  pulsing beam focus current under the conditions tested
  here produced no readily detectable changes in the
  beam focus current, input power nor output power
  signals
●
 disturbances that influence beam current, voltage and
 therefore beam power can be detected in input and
 output power
 – there is a limit to disturbance frequency, period, amplitude
 and energy below which a disturbance can not be detected
 in input power
 28 of 31

●
 the following process output signals:
 ●
 Stigmator X,Y
 ●
 Deflection X,Y
 ●
 Alignment X,Y
 – were found to be constant during a weld and show no
 changes due to changes in beam current, voltage bias
●
 in addition to process input power, process output
 signals (see Slide 4) are useful to monitor for
 ensuring repeatability of process operation

 Future Work

  determine amplitude/duration/energy of beam arc outs
  necessary to influence weld quality

  determine limit of detection for small amplitude, short duration
  disturbances in input power and process output signals

  Consider dropping beam deflection signals from list of
  monitored process outputs
 –
 in many applications deflection signal frequency will be
 greater than that resolvable by data acquisition system

  add chamber vacuum level to list of monitored process outputs
