 1. ATR LOOP ACTIVITY REPORT
This report contains the gamma-ray emitting radionuclides concentration and decontamination factor
results from gamma-ray spectrometry measurements of ATR loop liquid samples by the Radiation
Measurements Laboratory (RML) for ATR Cycle:

                                          175C Nov. 05, 2025, to Jan. 23, 2026

 This report consists of five subsections, one for each loop that is sampleda. The subsections contain
the results for each sampling of the loop along with the date and time of sampling, isotope identification,
sample type, and reactor power (MW) at the time of sampling. The results are reported in units of
microcurie per milliliter of sample. The results are obtained utilizing HPGe detectors and industry
standard measurement methods [1]. The numerical output of this report is generated by the Historical
Analytical Laboratory Observations (HALO) system. All radionuclide concentrations have been decay-
corrected to the time of sampling.
 2. DECONTAMINATION FACTOR CALCULATIONS
The nomenclature of the samples is indicated below:

 Table 1: Nomenclature utilized in ATR Loop Reports

 Nomenclature Explanation
 BIX Water sample Before Ion Exchange
 BIX-7 Recount of BIX after allowing 7 days for decay
 AIX Water sample After Ion Exchange
 PIX Pressurized water sample
 DFX Decontamination Factor for water samples

The Decontamination factor (DFX) calculation consists of the following logic:

a At this time, the 2A loop is not being sampled and measured as a function of this report.

 Table 2:DFX Logic

 Condition Resulting DFX
 If BIX > 0 and AIX < 0 DFX = BIX/AIX
 If BIX > 0 and AIX = 0 No DFX is reported
 If BIX > 0 and AIX is a limit valueb DFX ≥ BIX/AIX
 If BIX is a limit valueb No DFX is reported
 If BIX = 0 No DFX is reported

 2.1. Measurement Results
The results of this report have been obtained by use of routinely updated RML procedures for ATR loop
radionuclide analysis. All measurement results have been reviewed and checked for correctness by RML
personnel. The uncertainties reported in these results are a total calculated uncertainty. Details will be
provided by RML personnel as requested.

There is only one PIX sample per cycle for each measured loop. Therefore, PIX results will only be found
for one sampling of each loop.

 3. REFERENCES

b In these results, a limit value is designated by the < symbol and is indicative of a radionuclide activity being below the

 Minimum Detectable Activity (MDA). MDA varies based on the radionuclide, counting time, activity in the sample,
 counting geometry and other factors.
