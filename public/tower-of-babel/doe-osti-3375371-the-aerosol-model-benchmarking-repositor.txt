 Abstract
 The Aerosol Model Benchmarking Repository and Standards (AMBRS) project was initiated to
 provide tools and to establish community standards for benchmarking aerosol models. This
 report describes a set of open-source tools for building, running, and analyzing aerosol box
 model simulations in a standardized framework. The framework consists of three core
 components: AMBuilder, a CMake-based build system that compiles supported models
 consistently; AMBRS, a Python module that defines unified numerical experiments and
 executes them with aligned inputs; and part2pop, an aerosol analysis package that
 standardizes output, computes diagnostics, and visualizes simulation results. Together, these
 tools enable reproducible intercomparison of aerosol schemes and support process-level
 evaluation of how model simplifications affect predictions of size distributions, cloud
 condensation nuclei activity, and other relevant properties relevant for the Earth-Energy
 system. Beyond its role in benchmarking, AMBRS provides a platform for studying aerosol
 processes across scales and can be used to generate training data for AI/ML applications in
 support of a broader hierarchical aerosol modeling strategy.

Abstract ii

 Summary
 The AMBRS framework lowers the barrier for systematic evaluation of aerosol models by
 providing an integrated workflow:

 • Build: AMBuilder compiles aerosol box models with consistent options and layout,
 ensuring reproducibility.

 • Run: AMBRS executes unified ensembles of scenarios across models, harmonizing
 inputs and outputs.

 • Analyze: part2pop interprets results, producing diagnostics and figures that allow direct
 comparison.

 The tools are modular, extensible, and designed for community use. While AMBuilder and
 AMBRS were developed under this project, part2pop was originally created under other DOE-
 supported efforts and is broadly applicable beyond benchmarking. Together, these
 components provide a foundation for quantifying structural uncertainty, informing the
 development of next-generation aerosol models, and producing standardized datasets suitable
 for AI/ML model training.

 1.0 Introduction
 Large-scale aerosol effects depend on particle-level characteristics, such as size, shape, and
 chemical composition, and there are a wide variety of approaches for representing aerosol in
 models (e.g., Stier et al. 2005; Liu et al. 2012; Pierce and Adams 2009; Bauer et al. 2008; Mann
 et al. 2014; Matsui et al. 2018; Tegen et al. 2019). In atmospheric sciences, global
 intercomparisons, such as AeroCom phase II, reveal a broad spread in aerosol burden and
 microphysics even under harmonized inputs (Mann et al. 2014; Tegen et al. 2019). However,
 these top-down intercomparison experiments cannot easily disentangle structural deficiencies in
 the aerosol representation from other uncertainties, such as meteorology and emissions. The
 few studies that have quantified structural uncertainty in aerosol representations have shown
 that differences in model assumptions about particle size-distributions can strongly affect
 aerosol radiative properties and cloud condensation nuclei activity (e.g., Ching et al. 2012;
 Fierce et al. 2016; Fierce et al. 2020; Matsui et al. 2018; Zheng et al. 2021), but studies have
 been isolated to idealized comparisons between a small number of model approximations. As a
 path forward, we introduce a toolkit to facilitate aerosol model benchmarking, intercomparison,
 and development.

 The Aerosol Model Benchmarking Repository and Standards (AMBRS) project provides an
 integrated set of tools for building aerosol box models, running unified numerical experiments,
 and analyzing model output in a standardized framework. The goal is to make it straightforward
 to intercompare parameterizations across models and quantify structural uncertainty in reduced
 aerosol models.

 This report documents the current state of the AMBRS tools, focusing on three main
 components:
 1. AMBuilder — build system for consistent model compilation.
 2. AMBRS — driver for running experiments and managing ensembles.
 3. part2pop — analysis package for harmonized diagnostics and visualization.

 Each component can be used on its own, but they are designed to interoperate so that models
 are built consistently, simulations are defined and executed comparably, and outputs feed a
 common analysis workflow. An overview of the AMBRS components is provided in Table 1;
 individual components and example use cases are provided in the remainder of this report.

 2.0 AMBuilder (Build)
 AMBuilder is a CMake-based build system developed to provide a consistent and automated
 way to configure and compile aerosol box models. It manages compiler settings, dependencies,
 and chemistry options, ensuring that models are built with the same layout and can be executed
 in a standardized environment. This eliminates the ad hoc and error-prone process of manually
 compiling models, allowing researchers to focus on scientific experiments rather than build
 logistics. It also maximizes model compatibility with each scenario available in AMBRS. By
 design, AMBuilder enforces a directory layout and versioned installation scheme, making it
 easier to track which executables were used in benchmarking studies.

 Although AMBuilder is currently configured to support CARMA, MAM4, and PartMC, its modular
 structure makes it straightforward to add new models or extend options, for example by
 enabling CAMP chemistry or including MOSAIC. The system is designed for long-term
 extensibility and reproducibility, providing a foundation for all simulations carried out with
 AMBRS.

 Typical usage:
 cmake -S . -B build -DCMAKE_INSTALL_PREFIX=<prefix> [options]
 cd build
 make install

 Install Python dependencies for AMBRS:
 pip install -r requirements.txt

 3.0 AMBRS (Run)
 The AMBRS Python module provides the layer for defining and executing numerical
 experiments in a consistent way across different aerosol box models. It is the central driver of
 the benchmarking framework, translating shared experiment definitions into model-specific
 inputs and collecting outputs in a unified format. Experiments are defined in terms of species,
 processes, size distributions, and environmental conditions, which are then sampled to create
 perturbed parameter ensembles or single-scenario test cases. Once an ensemble is defined,
 AMBRS manages directories, input files, and parallel execution of each model. Outputs are
 collected into standardized files with aligned variables, units, and metadata, ensuring direct
 comparability across models. Currently, AMBRS supports single-box model experiments with
 PartMC and MAM4, but its structure is designed to be extensible: new models can be added
 through input/output adapters, and new experiment templates can be introduced as the scope of
 benchmarking grows. This component ensures that benchmarking is not only reproducible but
 also scalable to a larger library of models and scenarios.

 4.0 part2pop (Analyze)
 part2pop is a Python analysis package that provides standardized diagnostics and visualization
 of aerosol populations. It was originally developed as a general-purpose tool under other
 project funding to support a wide range of aerosol science applications, including optics, cloud
 condensation nuclei (CCN), and freezing diagnostics. Under the AMBRS project, part2pop has
 been linked as the analysis layer for benchmarking experiments, but its scope extends well
 beyond this application. Within AMBRS, part2pop provides a consistent way to build particle
 populations from model outputs, compute derived quantities, and generate figures for direct
 comparisons. For example, the part2pop package provides size distributions, CCN activity, or
 mixing state indices across models and visualizes the results. Because it was designed for
 flexibility and extensibility, new diagnostics and visualization modules can be added without
 disrupting existing workflows, making it well-suited to support both AMBRS and other aerosol
 modeling efforts.

 Example: plot dN/dlnD (Fig. 1) and CCN activation fraction (Fig. 2) from AMBRS outputs.

 5.0 Next steps
 The AMBRS workflow will continue to evolve as a resource for the Department of Energy’s
 broader mission in Energy-Earth System Modeling. AMBRS provides a hierarchical modeling
 framework that links high-fidelity particle-resolved simulations with the simplified aerosol
 models, enabling systematic evaluation of how model approximations impact model predictions
 of aerosol properties relevant to the Energy-Earth system.

 Future work will extend AMBRS in several directions. Through engagement with the aerosol
 community, we will expand the library of supported models, test cases, and simulated
 processes. By connecting outputs to observational datasets, AMBRS can also help bridge
 verification and validation layers in DOE’s hierarchical modeling strategy.

 Another key opportunity is the use of AMBRS to generate standardized datasets for artificial
 intelligence and machine learning (AI/ML). Ensembles of simulations spanning wide parameter
 ranges can be used to train surrogate models and emulators, accelerating model development
 and enabling reduced-cost exploration of aerosol–climate interactions. This capability will
 support DOE’s long-term vision for integrating AI/ML with high-performance computing to
 advance predictive Earth system science.

 Taken together, these next steps position AMBRS as more than a benchmarking platform: it is a
 tool for accelerating development of the next generation of aerosol models, strengthening
 DOE’s Energy–Earth System Modeling portfolio, and enabling new science at the interface of
 multiscale modeling, high-fidelity simulations, and AI/ML.
