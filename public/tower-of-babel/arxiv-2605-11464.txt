Abstract
We present the first amplitude analysis and branching fraction measurement of D + → K S 0 ​ K L 0 ​ π + D^{+}\rightarrow K_{S}^{0}K_{L}^{0}\pi^{+} decay. The analysis uses a dataset corresponding to an integrated luminosity of 20.3 fb − 1 \rm fb^{-1} , which was recorded at a center-of-mass energy 3.773 GeV by the BESIII detector. The measured branching fraction is ℬ ⁡ ( D + → K S 0 ​ K L 0 ​ π + ) = ( 5.780 ± 0.085 ± 0.052 ) × 10 − 3 \mathcal{B}(D^{+}\rightarrow K_{S}^{0}K_{L}^{0}\pi^{+})=(5.780\pm 0.085\pm 0.052)\times 10^{-3} , where the first uncertainty is statistical and the second is systematic. Using the known value of ℬ ( D + → ϕ π + , ϕ → K + K − ) {\cal B}(D^{+}\to\phi\pi^{+},\,\phi\to K^{+}K^{-}) , we determine the relative branching fraction between ϕ → K S 0 ​ K L 0 \phi\to K_{S}^{0}K_{L}^{0} and ϕ → K + ​ K − \phi\to K^{+}K^{-} to be ℬ ( D + → ϕ π + , ϕ → K S 0 K L 0 ) / ℬ ( D + → ϕ π + , ϕ → K + K − ) = 0.628 ± 0.022 ± 0.015 ± 0.017 \mathcal{B}(D^{+}\to\phi\pi^{+},\phi\to K_{S}^{0}K_{L}^{0})/\mathcal{B}(D^{+}\to\phi\pi^{+},\phi\to K^{+}K^{-})=0.628\pm 0.022\pm 0.015\pm 0.017 , where the third uncertainty is related to ℬ ( D + → ϕ π + , ϕ → K + K − ) \mathcal{B}(D^{+}\to\phi\pi^{+},\phi\to K^{+}K^{-}) . This result is significantly lower than the previous world average and is consistent with the isospin expectation for the ϕ \phi meson’s coupling to charged and neutral kaon pairs.
