 ABSTRACT

The primary objective of the technical collaboration is to validate and implement adaptive feed rate control,
tool wear monitoring, and anomaly detection for the finish machining of additive components. Most
additively manufactured components need finish machining to achieve surface finish and tolerance
requirements. Distortions and surface roughness of additively manufactured components can result in high
forces and tool breakage or excessive tool wear during post-additive finish machining, which can result in
rework or part scrap. In this collaboration, methods, and models for feed rate control, tool wear monitoring,
and anomaly detection via a digital twin will be evaluated and validated.

 1. SUMMARY

The following tasks were completed during the technical collaboration with CARON Engineering.
 1. The CARON Engineering Tool Monitoring and Adaptive Control (TMAC) system was installed
 on the Makino a51nx and the DMG eVo 60 ultrasonic machine at the Manufacturing Demonstration
 Facility. The TMAC installation was part of the cost shared by CARON Engineering. To facilitate
 the adaptive control portion, the adaptive control interface was also installed on the Makino a51 nx
 machine.
 2. CARON Engineering developed a .csv converter tool. This enables converting the raw data stored
 inside TMAC in the .tmd format to .csv format. The data in .csv format can be easily analyzed
 using standard computer languages such as Python.
 3. Cutting tests were completed at different axial and radial depths of cut to determine the sensitivity
 of the TMAC power transducer. Results show that the power transducer could detect cuts greater
        than 0.015 kW (0.2 HP).
 4. An analytical model to predict cutting power was validated using test cuts.
 5. TMAC power transducer data was collected for an industrial representative tool path on Titanium
 6Al4V. Results showed an increase in cutting power with tool wear.
 6. The adaptive control feature was tested using a worn tool. The ideal cutting power was selected
 based on the analytical model prediction. Results showed that TMAC was successfully able to
 adaptively change the feed rate to maintain constant cutting power.
 7. The TMAC system was used for distortion and porosity monitoring in additively manufactured
 components.

 2. INTRODUCTION

Caron Engineering’s tool monitoring and adaptive control system, TMAC, is a real-time tool wear and
breakage detection and adaptive feed-rate control system for machining. TMAC measures tool wear and
detects breakage in real time by monitoring true spindle motor power. TMAC learns the optimum power
for each tool and cutting section and compares it to the user-defined limits to calculate wear as the tool is
cutting. It operates on the principle that the power required to cut a part increases as the tool wear increases.
TMAC adaptive control module learns the optimum power for each tool and continuously maintains a
constant tool load by automatically adjusting the feed rate in real time. This results in decreased cycle time,
longer tool life, and more machine uptime, especially with difficult-to-machine materials. The browser-
based HMI allows users to access TMAC anytime, anywhere, and from any network-connected device
(including smartphones). Figure 1 shows the TMAC dashboard showing the measured cutting power in
machining.

 5

Figure 1. TMAC dashboard showing cutting power as a function of time.

Hybrid manufacturing (additive and subtractive) enables the manufacturing of complex geometries with
desirable tolerances and surface finish. Hybrid manufacturing can be completed in a single setup on the
same machine, or two setups on two different machines. Additive manufacturing (AM) generates high
residual stresses due to the thermal history generated by the process, which can result in significant part
distortion as well as defects such as cracking or part separation from the build plate. Additive components
also have a relatively high surface roughness as compared to rough machining. This presents a challenge in
the finish machining of additively manufactured components. The part distortion and roughness result in
varying and unknown tool engagements. This can lead to high cutting forces which can cause tool breakage
or excessive tool wear. Furthermore, during the AM process, each processing parameter combination results
in a complex multiphase and multiscale interaction, which can result in local defects and site-specific
microstructure. Finish machining of AM components with defects can result in reduced productivity, higher
machining costs, and reduced efficiency. Therefore, there is a need for online monitoring of AM
components that can detect defects and account for and compensate for the distortions caused by the
additive process.
The objective of this technical collaboration is to validate and implement real-time adaptive feed rate
control and tool wear monitoring for post-additive machining of components using the Caron TMAC
system using a process digital twin. There are two primary research tasks. First, the adaptive feed-rate
control will be evaluated using machining. The true cutting power during machining will be measured using
a high-speed, multi-range power transducer. Physics-based machining simulation models will be used to
predict the cutting power in machining using the nominal part geometry. The predicted cutting power will
be used to set the threshold for the adaptive control system. Second, methods for monitoring part distortion
and defect in AM components will be developed and validated. This will result in a robust hybrid
manufacturing process, resulting in improved productivity, reduced downtime and scrap, and improved tool
life.

3.1 TMAC system settings

The TMAC system operates on a power threshold for tool wear monitoring and adaptive control, since
cutting power increases as tool wear increases. This is shown in Figure 3. In Fig. 3, the green dotted line
shows the learned cutting power. The learned cutting power is the expected cutting power with a new tool.
The white dotted line denotes the idle spindle power. The yellow and red dotted lines define the warning
and extreme power limit, respectively. When the cutting power exceeds the threshold defined by the
warning limit (yellow dotted line), the system gives a warning but continues operation. When the power
exceeds the threshold defined by the extreme limit (red dotted line), the system alarms out and stops the
cutting operation. To avoid false positives, a threshold time in seconds can be defined. The system provides
a warning or extreme alarm when the cutting power exceeds the learned power continuously for the
threshold time. The blue dotted line denotes an undercut limit. If the tool engagement on the workpieces is
smaller or in case of tool breakage, the measured cutting power will be less than the learned value. In this
case, the TMAC system can provide an undercut alarm. The different power thresholds for warning,
extreme, undercut, and learned value are provided by the user for different tools in a part program. The
TMAC system can be automatically turned on using G-code commands inserted in the part program. For
the Makino machine, the G-code command is: G65 P9118 J29. In the command, J29 refers to the job
number in the TMAC system. Each job consists of sections for different tools with the associated threshold
power values. The desired section for a tool can be called with the following command on the Makino
machine: G65 P9118 M1 T20 S1 I9117. The best practice is to initiate the TMAC system after the tool is

rotating, but not cutting. This enables the TMAC system to calibrate the idle spindle power and compensate
for it in the real-time dashboard.

 4. POWER TRANSDUCER SENSITIVITY

To test the sensitivity of the power transducer, cutting tests were completed at different axial and radial
depths of cut using a four flute, 12.7 mm diameter end mill, on Titanium 6Al4V. The spindle speed was
4010 rpm and the feed per tooth was 0.05 mm/tooth (802 mm/min linear feed rate). A test program was
created with six different radial depths of cut – {1.5, 1, 0.5, 0.25, 0.125, and 0.0625} mm and three different
axial depths of cut - {2, 1, and 0.1} mm. Figure 4 shows the results from the power transducer for axial
depth of cut equal to 2 mm (a), 1 mm (b), and 0.1 mm (c). Three repeats were completed at each axial depth
of cut. Note that the raw data was converted to .csv format using the CSV converter tool developed by
CARON for this collaboration and plotted using Python. In Fig. 4, each increase in cutting power
corresponds to a test cut at a different radial depth of cut. Note that the idle power at 4010 rpm was in the
0.46 kW – 0.48 kW range. As seen in Figure 4(a), the power transducer can detect cuts greater than 0.015
kW; this corresponds to a radial depth of cut of 0.25 mm and 2 mm axial depth of cut. This result indicates
that the power transducer can detect geometric deviations in the workpiece greater than 0.25 mm at a radial
depth of cut of 2 mm at 4010 rpm and 0.05 mm/tooth.

 6. TOOL WEAR MONITORING AND ADAPTIVE CONTROL

To test the influence of tool wear on cutting power, tool wear tests were completed on Titanium 6Al4V
with an industrially representative tool path. Figure 6 shows the part geometry and tool path for the open
pocket. The part was programmed in MasterCAM. The spindle speed was 3500 rpm feed per tooth was
0.04 mm/tooth, radial depth was 3.81 m (30% radial immersion), and axial depth of cut was 1 mm. The
power was continuously monitored during the operation using the TMAC system. After each pocket, the
tool wear was measured using a microscope. Figure 7 shows the increase in flank wear as a function of
machining time. As seen in Fig. 7, the average flank wear on the tool increases with machining time.

 10

Figure 6. (a) Part geometry and (b) tool path for the open pocket.

Figure 7. Increase in average flank wear as a function of cut time.

The power signal was measured using the power transducer in the TMAC system. Using Eq. 3, the cutting
power for programmed machining parameters was calculated as 0.078 kW. The measured power was 0.076
kW. Figure 8 shows the power signal for the last layer for pockets 1, 3, 5, and 6. As seen in Fig. 8, the
cutting power increases with machining time as tool wear increases. Figure 9 shows the relationship
between cutting power with average flank wear. As seen in Fig. 9, the average cutting power increases from
0.076 kW to 0.135 kW (80% increase) as the average flank wear increases to 0.24 mm.

Additional tool wear tests were completed on Titanium 6Al4V and Stainless Steel 304 at 50000 rpm, 1 mm
axial depth, 12.7 mm radial depth (100% radial immersion), and 0.04 feed per tooth. For Titanium 6Al4V,
the cut power increased from 0.33 kW to 0.55 kW (63% increase) at average flank wear equal to 0.21 mm.
For SS304, the cut power increased from 0.33 kW to 0.56 kW (66% increase) as the average flank wear
increased to 0.28 mm. These results could be used to automatically set power for a selected average flank
wear value.

The adaptive control feature of TMAC was evaluated next. The adaptive control adjusts the feed rate of the
tool in real time to maintain a set threshold cutting power value. The adaptive control feature was evaluated
with a new and worn tool. Figure 10 shows the results for a new tool (a) and a worn tool (b). The cutting
power threshold was set as 0.46 kW (denoted as a gray line). Note that the threshold power includes the
idle power value since the system the TMAC system is activated before the spindle starts rotating. If the
TMAC system is activated after the spindle is rotating, the system corrects for idle power and the threshold
can be set using the analytical power model shown in Eq. 3. The green line denotes the measured power,
and the red line shows the feed rate. For a new tool, the adaptive control feature increases the feed rate to
120% when the tool is not in the cut (120% was set as the maximum limit in this operation). This enables
a reduction in total cycle time. When the tool is in-cut, the feed rate is adjusted to maintain cutting power
equal to 0.46 kW. The adaptive control feature resulted in a 13% reduction in total cycle time by reducing
the air cut part of the program. As seen in Fig. 8, tool wear causes an increase in cutting power. In this case,
the adaptive control feature reduces the feed rate. This is shown in Fig. 10 (b). The reduction in feed rate
compensates for the increase in tool wear; this increases tool life and prevents catastrophic breakage.

 7. DISTORTION MONITORING IN AM USING TMAC

As noted, large distortions due to buildup of residual stresses is a challenge in AM. The TMAC system was
used to monitor the distortions in AM. Three 50.8 mm Aluminum 6061-T6 square blocks were machined
on a 101.6 mm square base to represent different cases for geometric deviation due to distortion in additive
manufacturing; the three blocks are shown in Figure 11. The first block is centered on the base; this
represents the baseline case with no geometric deviation (Fig. 11(a)). The second block is translated from
the center of the base by 6.6 mm in X and 12.6 mm in Y (Fig. 11(b)) and the third block is rotated 25 degrees
clockwise (Fig. 11(c)); both cases represent the severe geometric distortion in large-scale additive
manufacturing. The outer square measuring 101.6 mm serves as a bounding envelope, while the inner
square represents the additive build geometry that can lie anywhere within the bounding envelope due to
distortion.

The blocks were machined on a Makino a51nx machine using straight line tool paths at 8000 rpm, 1.5 mm
axial depth, 25% radial immersion (3.175 mm), and 0.1 mm/tooth feed rate with a four-flute 12.7 mm
diameter end-mill. The facing operation resulted in 32 total passes over the bounding envelope. In addition
to power monitoring, TMAC also enables synchronized sampling of tool position through the machine
controller. For the Makino a51nx machine, the tool position was monitored through the Fanuc FOCAS
communication protocol. The TMAC system connection to the CNC network enabled data acquisition from
the power sensor and the servo drive network simultaneously by triggering them through machine
commands in the G-code. This synchronization was achieved by modifying a macro-variable (0 or 1)
through a G-code command and triggering data acquisition based on its value. The TMAC sampling rates
for the power sensor and servo network were 1185 Hz and 200 Hz, respectively. However, the Fanuc servo
network is not designed for high-speed controller data collection. As a result, duplicate values of the most
recent update are published by the TMAC system until updated values are supplied by the servo network.
To synchronize the measured cutting power and tool position values, the duplicate tool position values were
replaced with linear interpolation between successive unique values in the feed direction and up sampled
from 200 Hz to the power sampling frequency of 1185 Hz using power timestamps.

Machining offers a fast and cost-efficient method for monitoring geometric accuracy in AM. The described
approach can be used intermittently in a hybrid additive and subtractive setup to monitor the geometric
accuracy of the build. In this method, machining passes can be performed after depositing a certain number
of layers to detect build distortions. The method can also be extended for in-situ monitoring of the deposited
height during AM to detect over/under builds. For large-scale metal AM, a sacrificial coupon could be
printed and machined during the build. The difference between expected and detected location of the
coupon could then be used to assess the overall part distortion and geometric accuracy of the build.
Furthermore, the method can also be integrated in a closed-loop control system to enable geometric
compensation to ensure the final geometry is contained in the additive preform.

 8. POROSITY DETECTION IN AM USING TMAC

As noted, in AM, certain combinations of processing parameters can produce site-specific porosities. The
presence of porosity can be detrimental to the component’s mechanical properties and fatigue life. A
method to detect porosities in AM using the TMAC system was developed and validated.

Two Grade 91 (9Cr-1Mo-V) steel samples (71.8 mm x 71.8 mm x 19 mm) were additively manufactured
using laser spot size of 3.5 mm (2144 W laser power, 963 mm/min scan speed, 1.65 mm hatch spacing,
0.45 mm layer height, and 8 g/min powder flowrate) and 6 mm (3216 W, 750 mm/min, 3 mm, 0.5 mm, and
12 g/min) in a blown powder process on the Okuma MU-5000V Laser EX hybrid system. Prior to
machining the parts, the samples were inspected using CT scans (Zeiss Metrotom 800 machine) for spatial
distribution of porosity. The porosity volume ratio was 0.45% for the 3.5 mm laser spot size and 10.29%
for the 6 mm laser spot size sample. Figure 15 shows a composite image of the two samples from the CT
scan for the first 2 mm depth (40 vertical CT images). The colorbar indicates the percentage porosity in a
volume of 0.126 mm × 0.126 mm × 2 mm (0.031 mm3).

Figure 15. Composite image for 2 mm thickness using CT scan data for Grade 91 steel samples at (a) 3.5
mm laser spot size and (b) 6.0 mm laser spot size.

The two AM samples and a wrought sample were machined using a four-flute 9.525 mm diameter endmill
on a Makino a51nx horizontal milling machine in down-milling configuration. The spindle speed was 3000
rpm, axial depth of cut was 2 mm, radial depth of cut was 1.27 mm (20% radial immersion), and the feed
per tooth was 0.025 mm. The test cuts were straight-line cuts at the selected machining parameters. During
machining, the cutting power and tool position were monitored using the TMAC system as described in
Section 6.0. Results showed that the cutting power was sensitive to the porosity in the sample; there is a
reduction in cutting power as the tool passes over a porosity. This is seen in Figure 16. The composite CT
image for the material removed is also shown in Fig. 16. The width of the composite CT image shown in
Fig. 16 is the radial depth of the cut and the tool feed is from left to right in a down-milling configuration.

Figure 16. Power as a function of position for a down-milling machining pass; (a) 3.5 mm and (b) 6 mm
laser spot size sample.

The presence of a porosity along the length of the cut can be detected using the reduction in cutting power.
The reduction in power due to the pore causes a deviation from the mean in the power signal; therefore, it
was characterized by the standard deviation of power in a window (shown in Eq. 4). Figure 17 shows 𝜎𝑝𝑓
in addition to cutting power for (a) wrought sample, (b) 3.5 mm spot size sample, and (c) 6 mm spot size
sample. For the fully dense wrought sample (Fig. 17(a)), the filtered cutting power is approximately
constant, with some variation due to sensor noise, leading to a small value of 𝜎𝑝𝑓 . The wrought sample test
does not exhibit the reduction in power as can be seen for the 3.5 mm (Fig. 17 (b)) and (Fig. 17(c)) 6 mm
spot size sample when the tool cuts through a porosity. Since the selected time-domain feature 𝜎𝑝𝑓 shows
a strong correlation to porosity, porosity could be detected using a threshold-based method. The threshold
value can be calibrated using a single test on a wrought (or fully dense) sample. For the selected parameters,
threshold was set to 𝜎𝑝𝑓𝑡 = 3.6 × 10−4 kW (empirically selected as 20% increase over the maximum value

Although the described approach for porosity detection using machining is a destructive method of
evaluation, it has several benefits and applications. First, the method can be used to check for porosities in
an additive or cast preform by utilizing the rough machining stage prior to finish machining. Monitoring

 20

tool position along with power enables accounting for power reduction due to known geometric features
(such as holes or grooves) in the algorithm. This would serve as a 100% quality check for the preforms and
result in savings by preventing the machining of a defective component due to porosities, especially in
large-scale AM components made by the wire-arc process. Second, in a hybrid (additive and subtractive)
setup, machining passes can be completed intermittently to check the quality of the deposited geometry. If
porosity is detected, multiple layers can be machined and redeposited. This process can be implemented in
a closed-loop control system to enable zero-defect AM preform. Third, the method can be used for rapid
process parameter development in AM. In this approach, multiple coupons or layers could be deposited
with different process parameters and machined to determine the presence of porosities and identify optimal
process parameters. This approach enables rapid identification of parameter combinations that result in high
levels of porosity and would be more economical than ex-situ evaluation of all printed coupons using CT.

 9. CONCLSUIONS

In this technical collaboration, the CARON TMAC system was evaluated for tool wear monitoring, feed-
rate adaptive control, and detection of distortion and porosities in AM components. Results showed that the
system offers a robust approach for monitoring the machining process using spindle power and tool
position. Spindle power can be predicted using analytical approaches. The threshold power for tool
monitoring and adaptive control can be set using the analytical power prediction for the nominal machining
parameters. The system can also be used to detect distortions and defects in AM components to improved
post-AM finish machining efficiency and productivity.
