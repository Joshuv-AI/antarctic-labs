Super-Constant Weight Dicke States in Constant Depth Without Fanout
Lucas Gretta, Meghal Gupta, Malvika Raj Joshi

Abstract
An n n -qubit Dicke state of weight k k , | D k n ⟩ \ket{D^{n}_{k}} , is the uniform superposition over all n n -bit strings of Hamming weight k k . Dicke states are an entanglement resource with important practical applications in the NISQ era and, for instance, play a central role in Decoded Quantum Interferometry (DQI) [ 15 ] . Furthermore, any symmetric state can be expressed as a superposition of Dicke states. First, we give explicit constant-depth circuits that prepare n n -qubit Dicke states for all k ≤ 𝗉𝗈𝗅𝗒𝗅𝗈𝗀 ⁡ ( n ) k\leq{\mathsf{polylog}}(n) , using only multi-qubit Toffoli gates and single-qubit unitaries. This gives the first 𝖰𝖠𝖢 0 {\mathsf{QAC}}^{0} construction of | D k n ⟩ \ket{D^{n}_{k}} for k = ω ⁡ ( 1 ) k=\omega(1) . Previous constant-depth constructions for any super-constant k k required the 𝙵𝙰𝙽𝙾𝚄𝚃 n \mathtt{FANOUT}_{n} gate, while 𝖰𝖠𝖢 0 {\mathsf{QAC}}^{0} is only known to implement 𝙵𝙰𝙽𝙾𝚄𝚃 k \mathtt{FANOUT}_{k} for k k up to 𝗉𝗈𝗅𝗒𝗅𝗈𝗀 ⁡ ( n ) {\mathsf{polylog}}(n) . Moreover, we show that any weight- k k Dicke state can be constructed with access to 𝙵𝙰𝙽𝙾𝚄𝚃 min ⁡ ( k , n − k ) \mathtt{FANOUT}_{\min(k,n-k)} , rather than 𝙵𝙰𝙽𝙾𝚄𝚃 n \mathtt{FANOUT}_{n} . Combined with recent hardness results [ 9 ] , this yields a tight characterization: for k ≤ n / 2 k\leq n/2 , | D k n ⟩ \ket{D^{n}_{k}} can be prepared in 𝖰𝖠𝖢 0 {\mathsf{QAC}}^{0} if and only if 𝙵𝙰𝙽𝙾𝚄𝚃 k ∈ 𝖰𝖠𝖢 0 \mathtt{FANOUT}_{k}\in{\mathsf{QAC}}^{0} . We further extend our techniques to show that, in fact, any superposition of n n -qubit Dicke states of weight at most k k can be prepared in 𝖰𝖠𝖢 0 {\mathsf{QAC}}^{0} with access to 𝙵𝙰𝙽𝙾𝚄𝚃 k \mathtt{FANOUT}_{k} . Taking k = n k=n , we obtain the first O ⁡ ( 1 ) O(1) -depth unitary construction for arbitrary symmetric states. In particular, any symmetric state can be prepared in constant depth on quantum hardware architectures that support 𝙵𝙰𝙽𝙾𝚄𝚃 n \mathtt{FANOUT}_{n} , such as trapped ions with native global entangling operations [ 19 ]

{\mathsf{QAC}}^{0}

The work on Dicke states in the setting of

In the

For a given

nonempty buckets; this is not the same as

for reasons described later.)

(2)

For each such ancilla qubit corresponding to a bucket, map it to
m
target qubits via the map
\ket{0}\ket{0^{m}}\to\ket{0}\ket{0^{m}}
and
\ket{1}\ket{0^{m}}\to\ket{0}\ket{\varphi(s(1),\ldots,s(k))}
. (Although the

’s could in theory depend on

, we had previously set

in the example, but our final construction will set parameters differently.)

(3)

Post-select on strings of weight
k
using Grover’s amplitude amplification.

It remains to choose
t(1),\ldots,t(k)
and
s(1),\ldots,s(k)
to satisfy a few conditions:

•

We can implement the aforementioned map
\ket{0}\ket{0^{m}}\to\ket{0}\ket{0^{m}}
and
\ket{1}\ket{0^{m}}\to\ket{0}\ket{\varphi(s(1),\ldots,s(k))}
.

•

The probability of each string with
k
ones is exactly the same.

•

The total mass on strings of weight
k
is constant (so that we can use Grover’s amplitude amplification).

We will set
s(i):=C\cdot k\binom{m}{i}/(mk)^{i}
, where
C
is chosen such that the

add to 1 (see
Definition

5.1
). (It turns out that
C\approx 1
always.) We will hold off on specifying the
t(j)
’s.

Implementing the map.

We start by constructing the map
\ket{0}\ket{0^{m}}\to\ket{0}\ket{0^{m}}
and
\ket{1}\ket{0^{m}}\to\ket{0}\ket{1/m}^{m}
. This gives us some “approximate” version of the state we want. Then, we mark each string with some qubit of the form
\sqrt{1-\alpha}\ket{0}+\sqrt{\alpha}\ket{1}
to “correct” the ratios of amplitudes. For example, we mark the all
0
branch with
\ket{0}
since that isn’t in the support of
\ket{\varphi(s(1),\ldots,s(k))}
, and similarly for all
\ket{D^{\ell}_{>k}}
branches. We mark the
\ket{W}=\ket{D^{\ell}_{1}}
branch with
\ket{1}
. For every other
\ket{D^{\ell}_{0<i\leq k}}
, we mark it with some
\sqrt{1-\alpha}\ket{0}+\sqrt{\alpha}\ket{1}
so that within the marked branch, the ratio of the amplitude on
\ket{D^{\ell}_{i}}
and
\ket{D^{\ell}_{1}}
branch is
\sqrt{s(i)/s(1)}
. We show in
5.9
that a constant fraction of the state will be marked, and so we can use Grover’s amplitude amplification to construct
\ket{\varphi(s(1),\ldots,s(k))}
exactly. (And we can ensure that the
\ket{0}\ket{0^{m}}\to\ket{0}\ket{0^{m}}
part of the map is unaffected.)

Each weight-
k
string has the same probability.

Each weight-
k
string
x
has some particular number of non-empty buckets
s
, when its indices are partitioned into groups of
m
as we have been doing.

Checking this condition really has two parts:
x
and
x^{\prime}
with the same
s
have the same probability, and
after the post-selection step
, the probability of sampling a string with
j
nonempty buckets is exactly
p(j)
. Essentially, the first condition ensures that the constructed state is some superposition over
\ket{\mathcal{D}^{m,\ell}_{j,k}}
’s while the second condition ensures it is the correct superposition. The former property follows directly from the
p_{i}
’s being of the form
\lambda\binom{m}{i}\beta^{i}
(
5.4
).

The latter property requires setting the
t(j)
’s appropriately. Naively, it would seem that we should just set
t(j):=p(j)
. However, each value of
j
may have a different probability of post-selecting a weight-
k
string, so the post-selection ratios may be different from the pre-selection ones. Define
q(s)
to be the probability of post-selecting a weight-
k
when having
s
non-empty buckets (i.e. when starting with
\ket{D^{\ell}_{j}}
on the ancilla, what mass of the constructed state is
\ket{\mathcal{D}^{m,\ell}_{j,k}}
). Then, we set
t(s)\propto p(s)/q(s)
, and indeed the post-selection probabilities will be proportional to the
p(s)
.

Total weight
k
mass is constant.

Finally, we need to check that the total mass on weight
k
strings is constant, so that the final amplitude amplification step is possible. We discussed in the previous section that we can’t just do amplitude amplification on each
j
separately, because the
q(j)
will not be always constant for any choice of the
s(i)
’s and certainly not for the ones we chose. However, when we do amplitude amplification at the end, we only need to ensure that the total mass over all the
j
’s of the weight
k
branch is constant. Each
j
contributes
t(j)q(j)
to this total mass, because its starting mass is
t(j)
and the conditional probability of the final string being weight
k
is
q(j)
. Thus, we just need to ensure that
\sum_{j}t(j)q(j)=\Theta(1)
, which is done in
5.9
.

Thus, each step of the outlined algorithm indeed works and we can construct
\ket{D^{n}_{k}}
exactly.

Preliminaries

The gateset of
{\mathsf{QAC}}^{0}
is canonically defined as multi-qubit Toffoli (Reversible-AND) gates and single-qubit unitaries
[
22
]
and the depth is given by the number of multi-qubit layers. Equivalent formulations include any multi-qubit reflection gate of the form
I-2\outerproduct*{\vth}{\vth}
for arbitrary product state
\ket{\vec{\theta}}

[
25
]
. Each qubit belongs to at most one gate per layer and just as classical reversible circuits,
{\mathsf{QAC}}^{0}
does not by default include
\mathtt{FANOUT}
, the ability to make (classical) copies of a qubit. A
{\mathsf{QAC}}^{0}
circuit is defined to have constant depth and
{\mathsf{poly}}(n)
ancillae, and thus
{\mathsf{poly}}(n)
gates.

Definition 3.1

(Circuit implementing unitary)

A circuit

(cleanly) implements

n
-qubit unitary

n
-qubit states

.

Definition 3.2

(State preparation circuit)
.

A circuit
C

n
-qubit state
\ket{\psi}
using
m=m(n)
ancillae, if,

All the upper bounds described in this work are

, i.e, the ancillae are returned to

. Thus, any state preparation/unitary implementation circuits we refer to are presumed to be clean unless otherwise specified.

(

)
.

\displaystyle=\frac{1}{\sqrt{2}}\ket{\varphi_{b}}_{T}\ket{b}_{a}\ket{b\oplus 1}_{x}+\frac{1}{\sqrt{2}}\ket{\varphi_{b}}_{T}\ket{b}_{a}\ket{b}_{x}

(from

)

(4.37)

Finally, the state on

and

\displaystyle\ket{\psi_{3}(b)}

\displaystyle:=\mathtt{SWAP}(x,a)H_{x}\ket{\psi_{2}(b)}

(4.38)

\displaystyle=\mathtt{SWAP}(x,a)\ket{\varphi_{b}}_{T}\ket{b}_{a}\ket{0}_{x}

(4.39)

\displaystyle=\ket{\varphi_{b}}_{T}\ket{0}_{a}\ket{b}_{x}.

(4.40)

\mathtt{SWAP}(x,a)=\mathtt{CNOT}(x,a)\mathtt{CNOT}(a,x)
, thus the described

.

Corollary 4.9
.

For any

-qubit state

satisfying

, and

Proof.

Let

. Let

.
We will describe the case when

(i.e

and

of the

Then, apply a

5
Preparing symmetric states in constant depth

In this section, we prove the main theorem of our paper, that one can synthesize
\ket{D^{n}_{k}}
in
{\mathsf{QAC}}^{0}[\mathtt{FANOUT}_{k}]
. Throughout this section, assume that
k
is at least a sufficiently large constant. For ease of exposition, we do not optimize the constants in our analysis.

5.1
Intermediate distributional states

Recall that for a distribution
\mathcal{D}
over
\{0,1\}^{n}
, its associated state
\ket{\mathcal{D}}
is an
n
-qubit state whose amplitudes in the standard basis are given by,

\displaystyle\braket{{x}|\mathcal{D}}=\sqrt{\Pr_{y\sim\mathcal{D}}[y={x}]}.

(5.1)

We will frequently use the notion from
Section

3.3
for the rest of this section.
Any symmetric distribution
\mathcal{D}
is given by a convex combination of Dicke distributions thus can be uniquely defined by the probability masses of
\mathsf{ham}(\mathcal{D})
. Analogously, the corresponding state
\ket{\mathcal{D}}
, can be described as a superposition of Dicke states.
Next we will define an intermediate distribution that forms the key piece of our main construction.

Definition 5.1

(Damped Binomial Distribution (
\mathcal{S}^{m}_{k}
))
.

For
m,k\in\mathbb{N}
,
k\leq m
, let
\mathcal{S}^{m}_{k}
be the symmetric distribution over
\{0,1\}^{m}
defined by probability masses
s(j)
of
\mathsf{ham}(\mathcal{S}^{m}_{k})
supported on
j\in[k]
, as,

s(j)=\lambda\cdot\frac{1}{(mk)^{j}}\cdot\binom{m}{j}

where
\lambda
is chosen to normalize
s(j)
correctly.
The associated state is,

\ket{\mathcal{S}^{m}_{k}}:=\sum_{j\in[k]}\sqrt{s(j)}\ket{D^{m}_{j}}.

First we will show that
\mathcal{S}^{m}_{k}
has the following useful properties.

Claim 5.2

(Bounds on the normalization constant)
.

For any
m,1\leq k\leq m
, let
\lambda
be the normalization constant from
Definition

5.1
.

\frac{k}{k+1}\cdot k\leq\lambda\leq k.

Proof.

By definition,

\displaystyle\lambda^{-1}

\displaystyle=\sum_{r=1}^{k}\binom{m}{r}\left(\frac{1}{mk}\right)^{r}\geq\binom{m}{1}\frac{1}{mk}=\frac{1}{k}.

(5.2)

Hence,
\lambda\leq k
.

For the upper bound, use
\binom{m}{r}\leq\frac{m^{r}}{r!}
to get

\displaystyle\lambda^{-1}

\displaystyle\leq\sum_{r=1}^{k}\frac{1}{r!k^{r}}\leq\sum_{r=1}^{\infty}\frac{1}{r!k^{r}}=e^{1/k}-1\leq 1/k+1/k^{2}.

(5.3)

Rearranging yields
\lambda\geq k\cdot\frac{k}{k+1}
.
∎

Claim 5.3

(pmf of
\mathcal{S}^{m}_{k}
is dominated by a binomial)
.

For any
m\geq 2
,
1\leq k\leq m/2
, let
s(j)
be as defined in
Definition

5.1
, then, there exists a universal constant
c
such that

s(j)\leq c\cdot\Pr[\mathsf{Binom}(m,1/m)=j].

Proof.

For
j\geq 1
,

s(j)=\lambda\cdot(mk)^{-j}\cdot\binom{m}{j}\leq\binom{m}{j}m^{-j}\leq 4\cdot\Pr[\mathsf{Binom}(m,1/m)=j].

∎

Claim 5.4

(Hamming slice of
\mathcal{S}^{m}_{k}
is uniform over support )
.

For any
k\geq 1
and
1\leq j\leq k
let
\mathcal{D}
be the distribution over
\{0,1\}^{mj}
defined by
\mathcal{D}:=(\mathcal{S}^{m}_{k})^{\otimes j}
. Then, for any
x\in\mathrm{supp}(\mathcal{D})
,
\Pr[\mathcal{D}=x]
depends only on
|x|
, the Hamming weight of
x
.

Proof.

Each string
x\in\mathrm{supp}(\mathcal{D})
can be written as
x=x_{1}\dots x_{j}
for
x_{i}\in\{0,1\}^{m}
with
h_{i}:=|x_{i}|\in[k]
. Since each
\mathcal{S}^{m}_{k}
is symmetric,

\displaystyle\Pr[\mathcal{D}=(x_{1},x_{2}\dots x_{j})]

\displaystyle=\prod_{i\in[j]}\Pr[\mathcal{S}^{m}_{k}=x_{i}]

(5.4)

\displaystyle=\prod_{i\in[j]}\binom{m}{h_{i}}^{-1}\cdot s(h_{i})

(5.5)

Substituting from
Definition

5.1
into
Eq.

5.5
for
\tau=1/(mk)
.

\displaystyle\Pr[\mathcal{D}=(x_{1},x_{2}\dots x_{j})]

\displaystyle=\lambda^{j}\prod_{i\in[j]}\binom{m}{h_{i}}^{-1}\cdot\binom{m}{h_{i}}\cdot\tau^{h_{i}}

(5.6)

\displaystyle=\lambda^{j}\prod_{i\in[j]}\tau^{h_{i}}

(5.7)

\displaystyle=\lambda^{j}\cdot\tau^{|x|}

(5.8)

which only depends on
|x|
and is as claimed.
∎

We require a controlled version of the associated state to leverage
Corollary

4.9
. To do so, we will show that a superposition over
\ket{0^{m}}
and
\ket{\mathcal{S}^{m}_{k}}
can be prepared.

Lemma 5.5
.

For any
1\leq k\leq m
, there exists
\gamma\in(0,1)
with
\gamma/(1-\gamma)=\Theta(1)
, such that the state
\ket{\psi}:=\sqrt{1-\gamma}\ket{0^{m}}+\sqrt{\gamma}\ket{\mathcal{S}^{m}_{k}}
can be prepared in
{\mathsf{QAC}}^{0}[\mathtt{FANOUT}_{k}]
.

Proof.

First prepare
\ket{\psi_{0}}=\ket{1/m}^{\otimes m}
. Then, using the
\mathtt{HAM}^{m}_{k}
map from
Lemma

4.5
on a fresh
k+1
-qubit register
Y
, obtain,

\displaystyle\ket{\psi_{1}}

\displaystyle=\sum_{i=0}^{k}\sqrt{a_{i}}\ket{D^{m}_{i}}_{T}\ket{e_{i}}_{Y}+\sum_{i=k+1}^{m}\sqrt{a_{i}}\ket{D^{m}_{i}}\ket{e_{k+1}}_{Y}.

(5.9)

where
a_{i}=\Pr[\mathsf{Binom}(m,1/m)=i]
and recall
e_{0}:=0^{k+1}
.
Since
\Pr[\mathsf{Binom}(m,1/m)\leq k]=\Omega(1)
, we can apply an
X
gate on the last qubit of the
Y
register followed by
3.14
to obtain in
O(1)
depth,

\displaystyle\ket{\psi_{2}}

\displaystyle=\sum_{i=0}^{k}\sqrt{\alpha_{i}}\ket{D^{m}_{i}}_{T}\ket{e_{i}}_{Y},

(5.10)

where
\alpha_{i}=a_{i}/\Pr[\mathsf{Binom}(m,1/m)\leq k]
.

Let
s(j)
be the probability mass function of
\mathsf{ham}(\mathcal{S}^{m}_{k})
as defined in
Definition

5.1
. For each
j\in[k]
, let
\beta_{j}=s(j)/(4\cdot\alpha_{j})
and
\beta_{0}=1
. Then,
\alpha_{i}\geq a_{i}
and due to
5.3
, each
\beta_{j}\in[0,1]
for
j\in[k]
. Additionally,

\sum_{j=0}^{k}\alpha_{j}\beta_{j}=4^{-1}+\alpha_{0}=\Theta(1)
. Therefore, applying
Lemma

4.1
produces the following state
\ket{\psi_{3}}
in depth
O(1)
.

\displaystyle\ket{\psi_{3}}:=\sqrt{\gamma}\cdot\sum_{j\in[k]}\sqrt{s(j)}\ket{D^{m}_{j}}\ket{e_{j+1}}_{Y}+\sqrt{1-\gamma}\ket{0^{m}}\ket{e_{1}}_{Y},

(5.11)

where
\frac{\gamma}{1-\gamma}=\sum_{j\in[k]}\alpha_{j}\beta_{j}/\alpha_{0}=\frac{1}{4\cdot\alpha_{0}}+1=\Theta(1)
, as required.
Finally, we can apply
\mathtt{HAM}^{m}_{k}
again to obtain,

\displaystyle\ket{\psi_{4}}

\displaystyle:=\sqrt{\gamma}\cdot\sum_{j\in[k]}\sqrt{s(j)}\ket{D^{m}_{j}}\ket{0^{k+1}}_{Y}+\sqrt{1-\gamma}\ket{0^{m}}\ket{0^{k+1}}_{Y}

(5.12)

\displaystyle=\left(\sqrt{\gamma}\ket{\mathcal{S}^{m}_{k}}+\sqrt{1-\gamma}\ket{0^{m}}\right)\otimes\ket{0^{k+1}}_{Y},

(5.13)

as claimed.
∎

Corollary 5.6

(Controlled dampened binomial state)
.

For any
k
,
m\geq k
, the following map on an input qubit
x\in\{0,1\}
can be implemented in
{\mathsf{QAC}}^{0}
,

\ket{0}_{x}\ket{0^{m}}\mapsto\ket{0}_{x}\ket{0^{m}},\quad\ket{1}_{x}\ket{0^{m}}\mapsto\ket{1}_{x}\ket{\mathcal{S}^{m}_{k}}

where
\ket{\mathcal{S}^{m}_{k}}
is the state associated with the shifted-truncated binomial.

Proof.

The required map is obtained through
Corollary

4.9
due to
Lemma

5.5
.
∎

5.1.1
Dicke occupancy states

We now describe the preparation of the state corresponding to the Dicke occupancy distribution, induced on each bucket of the Dicke state.
First, we define the occupancy of a bistring distribution under bucketing.

Definition 5.7

(Binomial occupancy distribution,
\mathsf{Occ}(\mathcal{D},\ell)
)
.

Given a distribution
\mathcal{D}
on
\{0,1\}^{n}
, and
\ell
s.t
\ell\mid n
,

\mathsf{Occ}(\mathcal{D},\ell)
is the distribution over
\{0,\ldots,\ell\}
as described below. Partition
n
bits into
\ell
buckets of sizes
n/\ell
each. A bucket is
empty
if all its bits are
0
. For
{x}\in\{0,1\}^{n}
, define
\mathsf{occ}({x})
to be the number of non-empty buckets in
{x}
. Then,

\Pr[\mathsf{Occ}(\mathcal{D},\ell)=k]:=\Pr_{{x}\sim\mathcal{D}}\left[\mathsf{occ}({x})=k\right].

When
\mathcal{D}
is the Dicke distribution, define the corresponding state to track the occupancy as below.

Definition 5.8

(Dicke occupancy state,
\ket{\mathsf{Occ}(\mathcal{D}^{n}_{k},\ell)}
)
.

Let
\mathcal{D}^{n}_{k}
denote the uniform distribution over
n
-bit, Hamming weight
k
strings. For
\ell\mid n
and
k\leq\ell
, this is an
(n+k)
-qubit state corresponding to the occupancy of
\ket{D^{n}_{k}}
with
\ell
buckets given by,

\displaystyle\ket{\mathsf{Occ}(\mathcal{D}^{n}_{k},\ell)}

\displaystyle=\binom{n}{k}^{-1/2}\sum_{{x}\in\{0,1\}^{n},|{x}|=k}\ket{{x}}\ket{e_{\mathsf{occ}}({x})}

\displaystyle=\sum_{j=0}^{k}\sqrt{p(j)}\ket{\mathcal{D}^{m,\ell}_{j,k}}\ket{e_{j}}_{A},

where
m=n/\ell
and
\ket{\mathcal{D}^{m,\ell}_{j,k}}
is the state conditioned on measuring occupancy
j
, and
e_{s}
denotes the
k
-bit string with all but the
j
th bit zero, and
p
is the pmf of
\mathsf{Occ}(\mathcal{D}^{n}_{k},\ell)
.

Note that
\ket{\mathcal{D}^{m,\ell}_{j,k}}
is symmetric within each bucket, and also symmetric across buckets whenever
n\equiv 0\pmod{\ell}
, and symmetric across the first
\ell-1
buckets otherwise.

Our strategy will be to approximate
\ket{\mathsf{Occ}(\mathcal{D}^{n}_{k},\ell)}
by using the map from
Corollary

5.6
and then correct the amplitudes. First, will relate the two distributions as follows.

Claim 5.9

(Hybrid to Dicke occupancy ratio)
.

For any
m
,
1\leq k\leq m
, and
\ell\geq k^{3}
, let
p(j)
be the probability mass function of
\mathsf{Occ}(\mathcal{D}^{m\cdot\ell}_{k},\ell)
. For
j\in[k]
, let

q(j):=\Pr_{{x}\sim(\mathcal{S}^{m}_{k})^{\otimes j}}\bigl[|{x}|=k\bigr].

It holds that,

q(k)=\Theta(1),p(k)=\Theta(1)\quad\text{and}\quad\frac{p(j)}{q(j)}\leq e^{2}\cdot k^{j-k}

Proof.

Let
v=\frac{1}{mk}
. Define,

\displaystyle\Gamma_{j}:=\sum_{\begin{subarray}{c}t_{1},t_{2}\dots t_{j}\in[k]\\
t_{1}+t_{2}\dots+t_{j}=k\end{subarray}}\prod_{i\in[j]}\binom{m}{t_{i}}

(5.14)

Then, we can write
p(j)
and
q(j)
in terms of this quantity as,

\displaystyle q(j)

\displaystyle=\sum_{\begin{subarray}{c}t_{1},t_{2}\dots t_{j}\in[k]\\
t_{1}+t_{2}\dots t_{j}=k\end{subarray}}\prod_{i\in[j]}\left(\binom{m}{t_{i}}\cdot\lambda\cdot v^{t_{i}}\right)

(5.15)

\displaystyle=\lambda^{j}\cdot v^{k}\cdot\Gamma_{j},

(5.16)

and

\displaystyle p(j)

\displaystyle=\binom{\ell}{j}\cdot\binom{m\ell}{k}^{-1}\cdot\Gamma_{j}.

(5.17)

Therefore, letting
n=m\cdot\ell
,

\displaystyle\frac{p(j)}{q(j)}

\displaystyle=\binom{\ell}{j}\cdot\binom{n}{k}^{-1}\cdot\lambda^{-j}\cdot v^{-k}

(5.18)

\displaystyle=\binom{\ell}{j}\cdot\binom{n}{k}^{-1}\cdot\lambda^{-j}\cdot(mk)^{k}

(5.19)

\displaystyle\leq\binom{\ell}{j}\cdot\binom{n}{k}^{-1}\cdot k^{-j}\cdot(mk)^{k}\cdot\left(\frac{k+1}{k}\right)^{j}

(from
5.2
)

\displaystyle\leq e\cdot\frac{\ell^{j}}{j!}\cdot\binom{n}{k}^{-1}\cdot k^{k-j}\cdot m^{k}.

(5.20)

Note,

\displaystyle\binom{n}{k}\geq\frac{(n-k)^{k}}{k!}=\frac{n^{k}}{k!}\cdot\left(1-\frac{k}{n}\right)^{k}.

(5.21)

Substituting into
Eq.

5.20
,

\displaystyle\frac{p(j)}{q(j)}

\displaystyle\leq e\cdot\frac{\ell^{j}}{j!}\cdot\frac{k!}{n^{k}}\cdot\left(1-\frac{k}{n}\right)^{-k}\cdot k^{k-j}\cdot m^{k}

(5.22)

\displaystyle=e\cdot\frac{k!}{j!}\cdot\ell^{j-k}\cdot k^{k-j}\cdot\left(1-\frac{k}{n}\right)^{-k}

(5.23)

\displaystyle\leq e\cdot\ell^{-k+j}\cdot k^{2(k-j)}\cdot\left(1-\frac{k}{n}\right)^{-k}

(5.24)

\displaystyle\leq e\cdot k^{-3(k-j)}\cdot k^{2(k-j)}\cdot\left(1-\frac{k}{n}\right)^{-k}

(
\ell^{-1}\leq k^{-3}
)

\displaystyle\leq e\cdot k^{j-k}\cdot\left(1-\frac{1}{mk^{2}}\right)^{-k}

(5.25)

\displaystyle\leq e^{2}\cdot k^{j-k}

(5.26)

where in the last step, we used that
k<m
. To see
q(j)=\Theta(1)
, note that its upper bounded by
1
, and lower bounded by
(1-1/(k+1))^{k}
. To see
p(j)=Theta(1)
, note that this occupancy distribution stochastically dominates its “balls-and-bins” version, and so standard arguments give
p(j)=\Omega(1)
.
∎

We now describe the construction.

Lemma 5.10

(Binomial occupancy states in
{\mathsf{QAC}}^{0}

(5.31)

The nonzero-bits in each branch of

Let
