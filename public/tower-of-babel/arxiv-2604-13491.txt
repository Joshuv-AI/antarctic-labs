Enhanced Text-to-Image Generation by Fine-grained Multimodal Reasoning
Yongjin Kim, Yoonjin Oh, Yerin Kim, Hyomin Kim, Jeeyoung Yun, Yujung Heo, Minjun Kim, Sungwoong Kim

Abstract
With the rapid progress of Multimodal Large Language Models (MLLMs), unified MLLMs that jointly perform image understanding and generation have advanced significantly. However, despite the inherent reasoning capabilities of unified MLLMs for self-reflection and self-refinement, their use in text-to-image generation remains largely underexplored. Meanwhile, existing multimodal reasoning–based image generation methods mostly rely on holistic image–text alignment judgments, without fine-grained reflection and refinement of detailed prompt attributes, leading to limited fine-grained control. Therefore, we propose Fi ne-grained M ultimodal R easoning ( FiMR ), a framework that leverages decomposed visual question answering (VQA) to break down an input prompt into minimal semantic units—such as entities and attributes—and verify each unit via VQA to generate explicit, fine-grained feedback. Based on this feedback, FiMR then applies targeted, localized refinements. This fine-grained self-reasoning and self-refinement enable MLLMs to achieve more precise improvements in image–prompt alignment and overall generation quality at test time. Extensive experiments demonstrate that FiMR consistently outperforms image generation baselines, including reasoning-based methods, particularly on compositional text-to-image benchmarks. The code and models are available at https://github.com/KU-AGI/FiMR .

However, for the task of text-to-image (T2I) generation, reasoning-based approaches for improving image–prompt alignment and image generation quality remain underexplored. Early research on image reasoning focused mainly on Chain of Thought (CoT) strategies such as prompt augmentation
(
11
;
28

Nevertheless, these approaches cannot revise the generated image, even when it is misaligned with the prompt. To address this limitation, a recent work
(
18
)
has introduced regeneration cycles. It self-evaluates image–prompt alignment for self-generated images and iteratively regenerates the image when misalignment is detected. However, it largely relies on holistic image–prompt alignment evaluation, which makes it difficult to identify and refine specific missing or incorrect prompt details.

To address these limitations, we propose
Fi
ne-grained
M
ultimodal
R
easoning (
FiMR
), a MLLM-based framework that generates explicit fine-grained feedback via Decomposed Visual Question Answering (VQA) to achieve precise prompt-image alignment and enhanced generation quality. The framework consists of three main steps:
(1) Initial Text-to-Image Generation, (2) Fine-grained Feedback Generation, and (3) Localized Image Correction.

In the
Initial Text-to-Image Generation
step, the reasoning MLLM first generates an image from the input prompt. Then, in the
Fine-grained Feedback Generation
step, the input prompt is decomposed into minimal semantic units, such as entities, attributes, and relations. The generated units are then separately evaluated via self-VQA by the MLLM to assess the fine-grained alignment between the prompt and the generated image. When misalignments are identified, explicit feedback is self-generated accordingly to guide the self-refinement process. Finally, in the
Localized Image Correction
step, the MLLM corrects localized errors in the image based on the generated feedback to improve alignment with the original prompt. For realizing this fine-grained multimodal reasoning and refinement, we construct a dedicated reasoning dataset and perform supervised fine-tuning on a base MLLM.

Ultimately, FiMR achieves progressive performance improvements through multi-step iterative corrections, significantly outperforms existing baselines on representative compositional T2I benchmarks including GenEval
(
7
)
, T2I-CompBench
(
10
)
, and DPGBench
(
9
)
.

The main contributions of this work can be summarized as follows:

•

Iterative Fine-grained Multimodal Reasoning Framework.
We propose a Iterative Fine-grained T2I Multimodal Reasoning Framework consisting of three steps: Initial Text-to-Image Generation, Fine-grained Feedback Generation, and Localized Image Correction. This iterative loop leads to progressive self-improvements in MLLM-based image generation by precisely identifying and correcting only the regions that are misaligned with the input text.

•

Fine-grained Feedback through Decomposed VQA.
We propose a methodology to generate fine-grained explicit feedback by leveraging a decomposed VQA on each semantic unit of the input prompt to localize specific misalignments.

•

Empirical Validation on Compositional T2I Benchmarks.
Through extensive experiments on compositional T2I benchmarks, we demonstrate that FiMR progressively enhances image-prompt alignment through a multi-step iterative process, significantly outperforming existing T2I reasoning models.

Related Work

Unified MLLMs

Recent unified MLLMs increasingly integrate image understanding and generation within a single architecture. These models are primarily categorized into two streams. One line of research adopts discrete visual tokens to frame image generation as an autoregressive next-token prediction task, modeling both text and images with a unified cross-entropy loss
(
24
;
22
)
. In contrast, another stream employs continuous visual features for image synthesis by coupling the transformer with diffusion or flow-based processes
(
25
;
16
)
.

Multimodal Reasoning for Text-To-Image Generation

Recent research has begun to explore reasoning capabilities within unified MLLM-based image generation.
While T2I-R1
(
11
)
, ReasonGen-R1
(
28
)
, and GoT-R1
(
4
)
enhance brief user instructions by transforming them into enriched contexts for reasoning, they lack post-generation correction mechanisms, leaving initial semantic misalignments unaddressed.
Consequently, Janus-Pro-R1
(
18
)
overcomes this by leveraging unified MLLMs to assess visual alignment and trigger iterative regeneration using their dual understanding and generation capabilities.

Despite its effectiveness, Janus-Pro-R1 relies on coarse global assessments without fine-grained localization, leading to unnecessary full-image regeneration for otherwise minor errors.
In contrast, our approach decomposes prompts at a finer semantic level to enable localized correction; this allows the model to selectively modify misaligned regions while preserving correct areas, significantly enhancing both precision and efficiency.

3
Preliminary Experiments

Recent multimodal T2I reasoning models, such as Janus-Pro-R1
(
18
)
, have significantly improved prompt–image alignment and generation quality. However, they still rely on holistic image-text alignment judgment, which often overlooks fine-grained semantic errors. Furthermore, these models struggle to effectively utilize self-reflection results for self-refinement, failing to bridge the gap between identifying errors and executing precise visual corrections. In this section, we present two diagnostic experiments to empirically validate these limitations and justify the necessity of FiMR, our fine-grained T2I reasoning.

3.1
Limitation of Global Judgment

We generated images from GenEval prompts
(
7
)
using Janus-Pro-R1
(
18
)
, following the reasoning process shown in Figure
1
, and used GenEval’s automated protocol to assign each image a binary alignment label (Aligned/Misaligned), which we treat as a ground-truth (GT) label. The protocol verifies object presence/counting/relations via detector-derived bounding boxes and checks color attributes via CLIP similarity on cropped object regions. When evaluated against this GT, we observe that Janus-Pro-R1’s global judge exhibits significant misalignments, as it fails to accurately identify fine-grained semantic mismatches.

As shown in Table
1
, global judgment is prone to false acceptance, particularly in categories requiring fine-grained precision. Specifically, the model exhibits high False Positive (FP) rates—reaching 32.50% for counting and 23.50% for color attributes—where misaligned images are incorrectly judged as aligned. With an overall FP rate of 14.21%, the model frequently fails to detect localized semantic discrepancies, indicating that coarse global assessment is insufficient for precise image–prompt alignment verification. Detailed experimental procedures and methodologies are provided in Appendix
A
.

3.2
Rationale Bypass Problem

Beyond global judgment errors, we identify the Rationale Bypass Problem, where models struggle to effectively utilize self-reflection results for practical self-refinement. To test whether regeneration truly depends on the rationale content, we perturb the key semantics of the rationale shown in Figure
1
-for example, changing “green motorcycle” to “yellow motorcycle with a bench”-while keeping the original prompt unchanged. Detailed experimental procedures and methodologies are provided in Appendix
A
.

As shown in Table
2
, image alignment improves even when the rationale is semantically perturbed. This indicates that the model does not meaningfully use the rationale content to guide generation. Consequently, these findings underscore the necessity of explicit feedback.

4
Method

4.1
FiMR: Multi-step multimodal reasoning framework

Based on the motivation in Section
3
, we propose the Fine-grained Multimodal Reasoning (FiMR) framework. For a given prompt, FiMR evaluates prompt-image alignment at a fine-grained level by utilizing a decomposed VQA, provides explicit feedback when alignment fails, and iteratively corrects the image based on the feedback. Our framework follows a systematic three-step self-reasoning procedure: (1) Initial Text-to-Image Generation, (2) Fine-grained Feedback Generation, and (3) Localized Image Correction. Figure
2
provides an overview of the FiMR.

4.1.1
Step 1: Initial Text-to-Image Generation

In Step 1, the MLLM performs initial T2I generation for a given input prompt
P
, following the same procedure as conventional T2I models. The primary objective of this step is to generate images
I
that are well-aligned with the prompt while satisfying the specified constraints.

4.1.2
Step 2: Fine-grained Feedback Generation

Step 2 is the self-reflection stage within our unified framework, where the model performs fine-grained alignment judgment and feedback generation. In this stage, the framework takes the input prompt
P
and the image
I
as inputs to perform decomposed VQA, subsequently generating fine-grained feedback.
Given this input, the model generates a reasoning path
\Phi
=
\{P_{\text{summary}},\mathcal{T},\mathcal{V},F\}
.
Specifically, the model first derives a summarized prompt
P_{\text{summary}}
that removes subjective or non-verifiable details to establish a stable evaluation basis.
It then decomposes
P_{\text{summary}}
into a set of semantic tuples (e.g. whole-entity(oven), attribute-color(oven,pink))
\mathcal{T}=\{\mathcal{T}_{i}\}_{i=1}^{N}
, covering entities, attributes, relationships, and special categories such as counting and text, following prior structured grounding paradigms.
For each tuple
T_{i}
, the model performs image-conditioned verification, generating a rationale and a binary alignment decision, collectively denoted as
\mathcal{V}
. Each element in
\mathcal{V}=\mathcal{\{}\mathcal{V}_{i}\}_{i=1}^{N}
consists of an explicit reasoning trace paired with a binary verdict (“Yes” or “No”) indicating whether the corresponding tuple is satisfied by the image.
Finally, based on the verification outcomes, the model synthesizes feedback
F(\cdot)
: for misaligned images,
F(I_{\text{misalign}})
consolidates the failed rationales into explicit corrective instructions, whereas for aligned images
F(I_{\text{align}})
, it emits a termination signal indicating no further refinement is required.

4.1.3
Step 3: Localized Image Correction

Step 3 constitutes the self-correction phase of the FiMR framework, where fine-grained feedback is utilized to perform localized image correction.
When the generated image is considered aligned with the prompt
P
, denoted as
I_{\text{align}}
, the framework produces a termination signal, thereby closing the iterative correction loop.

In contrast, when the generated image is judged to be misaligned with the prompt, denoted as
I_{\text{misalign}}
, the framework leverages the corrective feedback
F(I_{\text{misalign}})
as an explicit guidance signal.
This feedback specifies which provides actionable instructions for resolving the identified mismatches, enabling the model to perform localized and intent-aware image correction. The resulting image from Step 3 is then re-processed as in Step 2, forming an iterative loop that continues until the alignment is resolved.

4.2
Training

4.2.1
Reasoning Data Construction

To enable effective multi-step reasoning under the FiMR framework, we perform supervised fine-tuning on a base MLLM. For this, we construct a specialized reasoning dataset designed to facilitate the full cycle of self-correction. Central to our approach is the reasoning path
\Phi
, which formalizes the step-by-step reasoning process of the self-judge and feedback mechanism for a given image state
I
and the input text prompt
P
. Formally,
\Phi
is defined as:
\Phi
=
\{P_{\text{summary}},\mathcal{T},\mathcal{V},F\}
.

Here, the reasoning path
\Phi
operates in four sequential stages: prompt summarization
P_{\text{summary}}
, tuple decomposition
\mathcal{T}
, decomposed VQA
\mathcal{V}
, and fine-grained feedback generation
F
. While
P_{\text{summary}}
and
\mathcal{T}
are derived solely from the prompt and remain fixed across
I_{\text{misalign}}
and
F(I_{\text{align}})
, the model verifies each tuple against the image to produce fine-grained alignment judgments, which are subsequently aggregated into corrective feedback
F(I_{\text{align}})
or a termination signal when full alignment is achieved.

We construct data samples as

\{P,I_{\text{misalign}},\allowbreak\Phi(I_{\text{misalign}}),\allowbreak I_{\text{align}},\Phi(I_{\text{align}})\}
,
where
P
is the input prompt,
I_{\text{misalign}}
is an initial image partially unaligned with
P
, and
I_{\text{align}}
is the target image fully aligned with
P
.

4.2.2
Training Loss

For each training step
s\in\{1,2,3\}
, the loss is defined as the average cross-entropy over the output token sequence:

\mathcal{L}_{\mathrm{CE}}^{(s)}=-\frac{1}{T}\sum_{t=1}^{T}\log p(y_{t}\mid\cdot),

(1)

where
T
denotes the sequence length, and
p(y_{t}\mid\cdot)
is the model-predicted probability of the ground-truth token at position
t
.

5
Experiments

Training Datasets

For training, we utilize a total of 200K image-text pairs. This collection consists of 140K samples from FocusDiff
(
17
)
for the edit dataset and 60K samples from our composition-specific synthetic dataset. The synthetic data are generated from prompts adapted from prior work
(
14
;
28
)
via Qwen-Image and Qwen-Image-Edit
(
23
)
. All data are processed into the reasoning data samples as described in Section
4.2.1
. Details of training datasets are provided in Appendix
B
.

Baseline Models

To ensure a fair and rigorous evaluation, we employ Janus-Pro-7B
(
2
)
as the primary backbone for both our proposed FiMR framework and the baseline models. We compare FiMR against two representative reasoning-based methods: Janus-Pro-R1
(
18
)
and T2I-R1
(
11
)
. While all models share the same underlying architecture, the baselines differ fundamentally in their reasoning granularity. Janus-Pro-R1 operates on a global level, performing self-judgment and full-image regeneration, whereas T2I-R1 focuses on text-centric Chain-of-Thought (CoT) prompt augmentation prior to generation. By standardizing the backbone and reproducing all results in an identical environment, we isolate the effectiveness of our fine-grained image reasoning approach. Additionally, beyond the 7B model, we conduct further experiments using Janus-Pro-1B to validate the scalability of our framework.

Benchmarks

To assess the image reasoning capabilities of our models, we utilize three comprehensive benchmarks: DPGBench
(
9
)
, GenEval
(
7
)
, and T2I-CompBench
(
10
)
. For DPGBench, we found issues in the official evaluation code under multi-GPU configurations. To ensure a reliable assessment, we employed a revised version with the corrections. For a fair comparison, we re-evaluated all compared image reasoning models under the same corrected setup. For GenEval and T2I-Compbench, we strictly follow the official implementations to ensure consistency and comparability. Detailed descriptions of each benchmark are provided in Appendix
C
.

Implementation Details

Our models were trained on eight NVIDIA A100 GPUs. For a detailed list of hyperparameter settings, including learning rates and batch sizes, please refer to the Appendix
D
.

5.1
Quantitative Results

In Table
3
and Table
4
, we present a comprehensive evaluation of FiMR against three distinct model families: State-of-the-art diffusion models, Unified MLLMs, and Multimodal Image Reasoning Models. Notably, among the compared baselines, only Janus-Pro-R1 and FiMR are capable of iterative refinement. For these two models, we report performance across three sequential stages: the initial T2I generation (denoted as 1st) and two subsequent refinement rounds (2nd and 3rd). Specifically, if the self-judge determines an image is aligned, subsequent refinement steps are skipped and the preceding image is retained. Conversely, for samples identified as misaligned, the model proceeds with the refinement process.
Unlike Janus-Pro-R1, which relies on full-image regeneration, FiMR achieves superior results by utilizing granular textual feedback for targeted, iterative corrections. This fine-grained approach allows the model to precisely address identified discrepancies while preserving correctly aligned regions, consistently outperforming baselines as the number of refinement steps increases.

GenEval

As the sequential stages progress from the initial generation to the third iteration, GenEval performance improves across nearly all categories, with particularly substantial gains in Counting (i.e., 0.58
\rightarrow
0.65
\rightarrow
0.70).
While existing baselines struggle with Counting due to the difficulty of maintaining discrete object separation during global generation, FiMR overcomes this limitation by strictly enforcing numerical constraints through explicit verification and targeted feedback.

T2I-CompBench

On T2I-CompBench, similar to GenEval, FiMR’s performance consistently improves across iterations, from the initial generation to the third step. The model achieves strong performance across a wide range of categories, demonstrating the effectiveness of the iterative refinement process. However, a marginal decline was noted in the Non-Spatial category. This can be attributed to the inherent characteristics of the CLIP-T score
(
19
;
8
)
used for evaluation, which often exhibits low sensitivity to subtle semantic refinements in text-image alignment
(
13
;
12
)
, potentially failing to capture the granular improvements made during the correction stages.

DPGBench

Unlike other benchmarks, DPGBench is characterized by long and more dense prompts, which require a high degree of compositional accuracy. On this benchmark, FiMR shows progressive performance improvements across all categories as the sequential stages proceed, achieving the highest overall score by the third iteration. These results demonstrate that our iterative reasoning framework is highly effective even when managing the complexity of such long and information-rich prompts.

Qualitative Results

6
Ablation Studies

To provide a deeper understanding of the individual contributions within our framework, we deconstruct the proposed framework and evaluate its core components. The following ablation studies are designed to isolate the impact of fine-grained judgment strategy, the necessity of explicit feedback for image correction, and the robustness of the framework across varying model scales.

6.1

Conclusion

In this work, we introduced FiMR, a Fine-grained Iterative Multistep Multimodal Reasoning framework designed to achieve precise image-text alignment. FiMR operates through three primary steps: (1) initial T2I generation, (2) fine-grained feedback generation, and (3) localized image correction. Unlike previous approaches that rely on holistic self-judge, FiMR utilizes a decomposed VQA mechanism to verify alignment at the level of minimal semantic units. By performing VQA on each unit individually, our framework generates fine-grained, explicit feedback, which enables effective, localized image correction targeted specifically at identified misalignments. Experiments across GenEval, T2I-CompBench, and DPGBench show that FiMR consistently enhances image-prompt alignment and quality.

Impact Statement

This work introduces FiMR, a framework designed to enhance the semantic alignment and quality of text-to-image generation through iterative reasoning.

Positive Societal Impacts:
Our method provides a robust mechanism for ensuring that generated visual content strictly adheres to complex human instructions. This has significant potential in creative industries, enabling users to perform fine-grained visual edits via natural language, thereby lowering the barrier for high-quality digital content creation. Furthermore, the underlying fine-grained verification logic contributes to the broader field of AI safety and reliability by making the generative process more transparent and controllable.

Ethical Considerations:
As with any advanced image generation and editing technology, there is a risk of potential misuse for creating deceptive content or misinformation. We emphasize that this technology should be used in conjunction with robust authentication and deepfake detection methods. Additionally, since our framework relies on large-scale pre-trained models (LLMs and VLMs), it may inadvertently reflect or amplify biases present in its training data. We encourage users and developers to remain vigilant regarding algorithmic fairness and the ethical implications of synthesized visual media.

Appendix A
Details of Preliminary Experiments

In this section, we provide the comprehensive experimental procedures and methodologies employed in the diagnostic studies presented in Section
3
. To validate the necessity of our proposed framework, we detail the ground truth labeling process, the specific implementation of the judgment paradigms (Global vs. Fine-grained), and the setup for the rationale perturbation experiment. These details ensure the reproducibility of our findings regarding judgment inaccuracies and the rationale bypass problem in current reasoning models.

A.1
GenEval Evaluation Protocol as Ground Truth

To establish a reliable gold standard for image-prompt alignment, we utilize the automated evaluation protocol of the GenEval
(
7
)
as our ground truth (GT). The protocol systematically assesses alignment across six categories, utilizing specific vision models to ensure objective and reproducible verification. The detailed mechanisms for each category are as follows:

•

Single and Two Object Alignment
: The protocol employs a pre-trained object detector to extract bounding boxes (Bboxes) from the generated image. Alignment is determined by verifying whether the Bboxes corresponding to the objects specified in the prompt are successfully detected.

•

Counting and Position
: Building upon the initial detection phase, these categories involve higher-level logic. For
Counting
, the protocol verifies the exact number of detected Bboxes against the prompt. For
Position
, it evaluates the spatial relations (e.g., “left of”, “above”) between the extracted Bboxes to confirm semantic alignment.

•

Colors and Color Attributes
: To verify color-related constraints, the protocol first crops the relevant object region using its detected Bbox. It then utilizes the CLIP
(
19
)
model to calculate the similarity between the cropped image region and the color attribute specified in the prompt, issuing an “Align” label only if the similarity exceeds a predefined threshold.

A.2
Implementation of Global Judge

The Global Judge follows the native prompt-image alignment evaluation process for which Janus-Pro-R1 was trained. After generating an image, the model is prompted to evaluate the alignment between the generated image and the prompt at a holistic level. Specifically, we append the trigger phrase,
“Let me think. Does this image match the prompt…”
to initiate the judgment process. The model is trained to provide a binary answer (“Yes” or “No”) followed by a concise explanation of one to two sentences. This approach forces the model to perceive the entire image and the complete prompt as single entities, often leading to the high False Positive rates observed in our experiments due to the omission of subtle details.

A.3
Implementation of Rationale Perturbation Experiment

To verify the Rationale Bypass Problem discussed in Section
3
, we designed a structured perturbation pipeline to decouple the semantic content of the feedback from the regeneration trigger. The experiment follows a three-stage process:

1.

Initial Generation and Reflection
: We first generate an image using Janus-Pro-R1 for a given GenEval prompt. Following the generation, the model enters a reflection phase where we extract its internal
Self-Judge
(Yes/No) and
Self-Feedback
(Rationale) logs. Since only samples judged as “No” by the internal Self-Judge are eligible for the subsequent regeneration phase, we specifically selected these samples to perform our perturbation experiment. These logs represent the model’s native, unperturbed reasoning regarding the alignment of the first iteration.

2.

Automated Perturbation via Qwen3-32B
: To systematically corrupt the semantic details of the feedback, we utilize the Qwen3-32B
(
27
)
model. From the initial pool of 2,212 generated images, we identified 368 samples that were targeted for regeneration based on the model’s internal “No” judgments. Consequently, we applied our perturbation process to the feedback of these 368 specific samples. We provide Qwen3 with a system prompt and specific few-shot examples designed to alter key entities, colors, or spatial relations within the original rationale while maintaining its overall linguistic structure. This ensures that the model receives a plausible but factually incorrect rationale as input for the next step.

3.

Regeneration with Perturbed Feedback
: Finally, we perform the regeneration process by feeding the perturbed feedback back into Janus-Pro-R1. The model is then tasked with generating a refined image based on the corrupted reasoning.

As detailed in Section
3
, the experimental results show that the model’s alignment performance improved from the first iteration even when the feedback was semantically corrupted. The performance gain in the perturbed case was nearly identical to that of the unperturbed case, confirming that the model utilizes the feedback as a binary signal for global regeneration rather than as a semantic guide for localized correction.

Dataset Construction Pipeline

In this section, we provide a comprehensive description of the multi-stage pipeline used for dataset construction and fine-grained judgment. As previously noted, we utilize
Qwen3-Next-80B-A3B

(
27

B.3.1
Prompt Summarization (
P_{\text{summary}}
)

To capture the core intent of long or complex input prompts, we perform a summarization step. The model is prompted to extract the essential semantic elements from the raw input prompt, resulting in a condensed representation
P_{\text{summary}}
. This ensures that subsequent decomposition steps focus on the primary subjects and attributes.

B.3.2
DSG Tuple Decomposition and Refinement

The construction of the fine-grained tuple set
\mathcal{T}
is the cornerstone of our judgment and feedback mechanism. To ensure the accuracy and schema-compliance of these atomic units, we employ a rigorous three-stage refinement process:

1.

Initial Decomposition (Prompt to DSG Tuple)
: The initial step involves decomposing the
P_{sum}
into a set of atomic semantic units following the Davidsonian Scene Graph (DSG)
(
3
)
format. This represents the prompt as a collection of non-divisible attributes and relations.

2.

Tuple Normalization (DSG Tuple Rewrite)
: Raw outputs from LLMs often include undefined schemas or inconsistent formats. In this stage, we prompt the model to normalize the initial tuples into the specific categories and structures defined in Section
4.2.1
. This ensures that the generated tuples are compatible with our fine-grained judge’s logic.

3.

Hallucination Filtering (DSG Tuple Prune)
: A known issue in LLM-based DSG decomposition is the generation of implicit information not present in the original text (e.g., assuming a “next to” relation between two mentioned objects). To mitigate this, we perform a pruning step that strictly removes any tuples containing inferred or implicit spatial/semantic relations, retaining only the information explicitly stated in the input prompt.

Following this refinement, the final tuple set
\mathcal{T}
is converted into a series of verification questions using the few-shot prompting strategy provided by the original DSG framework. These questions serve as the input for the VQA-based alignment check performed by Qwen-VL-32B
(
1
)
.

B.3.3
Feedback Generation

Following the VQA-based alignment check, the resulting verification set
V(I)
serves as the primary input for the final feedback generation stage. The Qwen3-Next-80B-A3B LLM
(
27
)
identifies all tuples assigned a “No” judgment-indicating a misalignment-and translates these discrepancies into a structured sequence of edit instructions. Each feedback item is formulated as a step-by-step action (e.g.,
Add, Change, Reposition
) specifically designed to transform the misaligned elements from “No” to “Yes”. This ensures that the generated feedback provides clear, actionable guidance to achieve full consistency with the original prompt.
