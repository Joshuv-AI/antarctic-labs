Abstract
We study the two-dimensional (geometric) knapsack problem with rotations (2DKR), in which we are given a square knapsack and a set of rectangles with associated profits. The objective is to find a maximum profit subset of rectangles that can be packed without overlap in an axis-aligned manner, possibly by rotating some rectangles by 90 ∘ 90^{\circ} . The best-known polynomial time algorithm for the problem has an approximation ratio of 3 / 2 + ϵ 3/2+\epsilon for any constant ϵ > 0 \epsilon>0 , with an improvement to 4 / 3 + ϵ 4/3+\epsilon in the cardinality case, due to Gálvez, Grandoni, Heydrich, Ingala, Khan, and Wiese (FOCS 2017, TALG 2021). Obtaining a PTAS for the problem, even in the cardinality case, has remained a major open question in the setting of multidimensional packing problems, as mentioned in the survey by Christensen, Khan, Tetali, and Pokutta (Computer Science Review, 2017). In this paper, we present a PTAS for the cardinality case of 2DKR. In contrast to the setting without rotations, we show that there are ( 1 + ϵ ) (1+\epsilon) -approximate solutions in which all items are packed greedily inside a constant number of rectangular containers . Our result is based on a new resource contraction lemma, which might be of independent interest. With our techniques, we also obtain a ( 1 + ϵ ) (1+\epsilon) -approximation algorithm in the weighted case when all given items are skewed , i.e., each of them has sufficiently small height or sufficiently small width. In contrast, for the general weighted case, we prove that this simple type of packing is not sufficient to obtain a better approximation ratio than 1.5 1.5 . However, we break this structural barrier and design a ( 1.497 + ϵ ) (1.497+\epsilon) -approximation algorithm for 2DKR in the weighted case. Our arguments also improve the best-known approximation ratio for the (weighted) case without rotations to 13 / 7 + ϵ ≈ 1.857 + ϵ 13/7+\epsilon\approx 1.857+\epsilon . Finally, we establish a lower bound of n Ω ⁡ ( 1 / ϵ ) n^{\Omega(1/\epsilon)} on the running time of any ( 1 + ϵ ) (1+\epsilon) -approximation algorithm for our problem with or without rotations – even in the cardinality setting, assuming the k k - Sum Conjecture. In particular, this shows that an approximation scheme for the case of rectangles of two-dimensional geometric knapsack requires much more running time than for the case of squares. Appendix D Introduction The (geometric) 2D-Knapsack (2DK) problem is a fundamental problem in combinatorial optimization, computational geometry, and approximation algorithms. In 2DK, we are given a square knapsack K := [ 0 , N ] × [ 0 , N ] K:=[0,N]\times[0,N] for some given value N ∈ ℕ N\in\mathbb{N} and a set of n n (rectangular) items I I . Each item i ∈ I i\in I corresponds to an axis-aligned open rectangle with a width w ⁡ ( i ) ∈ ℕ w(i)\in\mathbb{N} , a height h ⁡ ( i ) ∈ ℕ h(i)\in\mathbb{N} , and an associated profit p ⁡ ( i ) ∈ ℕ p(i)\in\mathbb{N} . The objective is to select a subset S ⊆ I S\subseteq I of the given items and place them non-overlappingly inside the knapsack. Formally, we need to define a bottom-left corner ( left ​ ( i ) , bottom ​ ( i ) ) ∈ K (\text{left}(i),\text{bottom}(i))\in K for each item i ∈ S i\in S such that the resulting rectangle ( left ​ ( i ) , left ​ ( i ) + w ⁡ ( i ) ) × ( bottom ​ ( i ) , bottom ​ ( i ) + h ⁡ ( i ) ) (\text{left}(i),\text{left}(i)+w(i))\times(\text{bottom}(i),\text{bottom}(i)+h(i)) is contained in K K and it does not intersect with any rectangle corresponding to any other item in S S . The objective is to maximize the total profit p ⁡ ( S ) := ∑ i ∈ S p ⁡ ( i ) p(S):=\sum_{i\in S}p(i) . Starting from the classical works of Gilmore and Gomory in the 1960s [ 25 ] , 2DK and its variants have found extensive applications in practice, particularly in domains such as logistics, cutting-stock, and scheduling , see [ 5 ] and references therein. In many practical applications [ 12 , 9 , 54 , 14 ] (e.g., cutting stock, container loading, VLSI/PCB layout), it is important that the items are packed (or cut) parallel to the two coordinate axes. However, it is often beneficial to rotate some of the items by 90 ∘ 90^{\circ} (also called orthogonal rotations), as we might be able to select more items in this way. For example, commercial software tools such as CutList Optimizer [ 13 ] and optiCutter [ 52 ] provide an option to allow orthogonal rotations. Also from a theoretical perspective, orthogonal rotations in geometric packing problems have been extensively studied; see, e.g., [ 18 , 15 , 49 , 33 ] . In fact, this setting was already suggested by Coffman, Garey, Johnson, and Tarjan [ 12 ] in 1980 . In this paper, we study the rotational variant of 2DK (i.e., we allow each item to be rotated by 90 ∘ 90^{\circ} prior to placing it inside the knapsack) which we call the two-dimensional geometric knapsack with rotations (2DKR) problem. Note that there are 2 n 2^{n} options for rotating the n n given items, which potentially allows much more possible solutions. As the setting without rotations, it is strongly NP-hard [ 46 ] . Despite a lot of research [ 35 , 4 , 21 , 23 , 10 , 26 ] , there is still a significant gap in our understanding of this problem. On the one hand, there is a ( 1 + ϵ ) (1+\epsilon) -approximation algorithm with quasi-polynomial running time when the input numbers are quasi-polynomially bounded integers [ 4 ] , which suggests that the problem might admit a polynomial time approximation scheme (PTAS) . On the other hand, the best-known polynomial time approximation ratio is only 3 / 2 + ϵ 3/2+\epsilon , and there is an improvement to 4 / 3 + ϵ 4/3+\epsilon in the cardinality case, i.e., when p ⁡ ( i ) = 1 p(i)=1 for each item i ∈ I i\in I [ 21 ] . When we allow pseudo-polynomial running time, the best-known factors are a bit better, i.e., 4 / 3 + ϵ 4/3+\epsilon and 5 / 4 + ϵ 5/4+\epsilon , respectively [ 23 ] . However, it is open whether a PTAS exists for 2DKR, even in the cardinality case! The survey by Christensen, Khan, Pokutta, and Tetali [ 11 ] lists this as one out of ten major open problems. Also, [ 21 ] explicitly highlighted that “the main problem that remains open is to find a PTAS, if any, for 2DK and 2DKR. This would be interesting even in the cardinality case.” However, despite progress on several special cases and variations [ 23 , 26 , 40 , 39 , 47 , 10 , 38 ] , after the results in [ 20 ] from 2017, there has been no progress on polynomial time approximation algorithms for 2DK or 2DKR, even in the cardinality case. Our result shows that this is not necessary, as our containers are just rectangular boxes, and we even obtain a better approximation ratio and polynomial running time. To prove our resource contraction lemma, we start with a ( 1 + ϵ ) (1+\epsilon) -approximate solution in which the items are placed inside O ϵ ​ ( 1 ) O_{\epsilon}(1) thin corridors (see ) whose existence was proven in [ 4 ] . This improvement is pivotal for our second step. Among the resulting boxes, we temporarily remove those that are relatively thin. We argue that we can shrink the relatively thick boxes by dropping a constant number of items per box (which we can easily afford in the cardinality case) and losing only a factor of 1 + ϵ 1+\epsilon on the number of the remaining items. We show that if we push the resulting boxes maximally to the bottom and to the left, then we free up a thin strip of width Ω ⁡ ( ϵ thin ​ N ) \Omega(\epsilon_{\mathrm{thin}}N) either on the top or on the right of the knapsack. A natural next step is the weighted setting of 2DKR. An important special case arises when all input items are skewed , i.e., no input item is relatively large in both dimensions. For related problems like bin packing [ 42 ] or strip packing [ 19 ] , tight approximation algorithms are known for the case of skewed items, and it was noted in [ 42 ] that the “inherent difficulty of these problems [2DK and another related problem called Maximum Independent Set of Rectangles] lies in instances containing skewed items”. D.2 Other related work The first approximation algorithms for 2DK and 2DKR are due to Jansen and Zhang [ 34 ] and both have an approximation ratio of 2 + ϵ 2+\epsilon . As mentioned above, Gálvez, Grandoni, Ingala, Heydrich, Khan, and Wiese [ 21 ] improved this factor to 17 / 9 + ϵ 17/9+\epsilon for 2DK and to 3 / 2 + ϵ 3/2+\epsilon for 2DKR, with further improvements in the respective cardinality cases. Gálvez, Grandoni, Khan, Ramírez-Romero, and Wiese showed that all of these ratios can be improved further by allowing pseudo-polynomial running time [ 23 ] . Bansal, Caprara, Jansen, Prädel, and Sviridenko [ 7 ] obtained a PTAS for 2DK and 2DKR when the profit-to-area ratio of the rectangles is bounded by a constant. Grandoni, Kratsch, and Wiese [ 26 ] considered parameterized algorithms for 2DK for which the parameter k k is the size of the optimal solution. They showed that 2DK and 2DKR are W[1]-hard for this parameter and provide a parametrized approximation scheme for (the cardinality case of) 2DKR with a running time of k O ⁡ ( k / ϵ ) ​ n O ⁡ ( 1 / ϵ 3 ) k^{O(k/\epsilon)}n^{O(1/\epsilon^{3})} . Buchem, Deuker, and Wiese [ 10 ] presented approximation algorithms for 2DK and 2DKR whose running times are near-linear, i.e., n ​ log 2 ​ n + ( log ⁡ n ) O ϵ ​ ( 1 ) n\log^{2}n+(\log n)^{O_{\epsilon}(1)} . They also provided dynamic algorithms with polylogarithmic query and update times. The geometric knapsack problem has also been investigated for different geometric shapes, including disks and regular polygons [ 2 ] , as well as convex polygons [ 48 ] and also in higher dimensions, for instance, in the context of hypercubes [ 31 ] and cuboids [ 30 ] . It is worth noting that packing rectangles becomes significantly more challenging when arbitrary rotations are permitted (i.e., when items are not required to be axis-aligned); in fact, the existence of even a polynomial time O ⁡ ( 1 ) O(1) -approximation algorithm remains open in this case. A related problem is the 2D-Vector Knapsack problem which admits a PTAS [ 17 ] while there is a lower bound of n o ⁡ ( 1 / ϵ ) n^{o(1/\epsilon)} for the running time of any ( 1 + ϵ ) (1+\epsilon) -approximation for the problem, as shown by Jansen, Land, and Land [ 29 ] (improving a previous lower bound of n o ⁡ ( 1 / ϵ ) n^{o(1/\sqrt{\epsilon})} by Kulik and Shachnai [ 45 ] ). 2DK and 2DKR exhibit rich connections with numerous other geometric packing and covering problems, including geometric bin packing [ 8 , 36 ] , strip packing [ 28 , 33 ] , generalized multidimensional knapsack [ 41 , 40 ] , maximum independent set of rectangles [ 3 , 24 ] , unsplittable flow on a path [ 6 , 27 ] , storage allocation and round-SAP [ 50 , 37 ] , guillotine packing [ 38 , 39 ] , and rectangle stabbing [ 44 , 43 ] . For a comprehensive overview, we refer the reader to the survey in [ 11 ] . For any

We guess the dimensions of the

. Given a collection of

-

(

We reduce a variant of the
k
-

-
PartSum

k
-

\mathcal{A}
of
n

First we show that

Lemma 7
.

Assuming the
k
-
Sum
conjecture, for any odd
k\geq 3
and
\delta>0

PartSum

Proof.

Let
k
be an odd integer and suppose we are given an instance of
(k-1)
-

whose input numbers are the multiset

\mathcal{A}=\{a_{1},\ldots,a_{n}\}
. We consider the
k
-
PartSum
instance
\overline{\mathcal{A}}=\{a_{1}+M^{\prime},\ldots,a_{n}+M^{\prime}\}\cup\{(k-1)M^{\prime}\}

M^{\prime}=k\cdot(\max_{a\in\mathcal{A}}|a|)+1

\overline{\mathcal{A}}
are strictly positive. We show that
k-1

\mathcal{A}

T_{1}

Suppose there exists a (multi-)subset

Conversely, suppose there exists
\overline{T}\subseteq\overline{\mathcal{A}}

|\overline{T}|=k

and
T_{2}
of equal sum.
W.l.o.g. let
|T_{2}|\geq|T_{1}|

Technical Tools

Here we state four technical lemmas that we use throughout the paper.

A.1
Resource augmentation lemma

The following lemma allows us to convert an arbitrary packing inside a rectangular region into a container packing. Informally, if there exists an empty strip whose width is at least a
\delta
-fraction of the width of the region, then the items packed in the region can be rearranged into a constant (depending on
\delta
) number of containers by losing only negligible profit.

Lemma 17

(
[
21
]
)
.

Let
I_{B}
be a collection of
n
items that can be packed into a box of size
a\times b
, and
\epsilon_{\text{ra}}>0
be a given constant. Then there exists a container packing of
I^{\prime}_{B}\subseteq I_{B}
inside a box of size
a\times(1+\epsilon_{\text{ra}})b
(resp.,
(1+\epsilon_{\text{ra}})a\times b
) such that

•

p(I^{\prime}_{B})\geq(1-O(\epsilon_{\text{ra}}))p(I_{B})
;

•

the number of containers is
O_{\epsilon_{\text{ra}}}(1)
and their sizes belong to a set of cardinality
n^{O_{\epsilon_{\text{ra}}}(1)}
that can be computed in time
n^{O_{\epsilon_{\text{ra}}}(1)}
.

A.2
Next-Fit-Decreasing-Height (NFDH)

NFDH is a shelf-based packing algorithm introduced in
[
12
]
. Given a set of items
I
and a rectangular region
C
, the algorithm first sorts the items in non-increasing order of height and then places the items sequentially from left to right on the base of
C
until the next item no longer fits. At this point, a new shelf is started by drawing a horizontal line at the height of the first (i.e., the tallest) item on the current shelf, and the process is repeated until no further items can be packed.

Lemma 18

(
[
21
]
)
.

Let
C
be a rectangular region of height
h
and width
w
. Assume that, for some given parameter
\epsilon\in(0,1)
, for each
i\in I
one has
w(i)\leq\epsilon\cdot w
and
h(i)\leq\epsilon\cdot h
. Then NFDH is able to pack in
C
a subset
I^{\prime}\subseteq I
of area at least
a(I^{\prime})\geq\min\{a(I),(1-2\epsilon)wh\}
. In particular, if
a(I)\leq(1-2\epsilon)wh
, all items in
I
are packed.

A.3
Generalized Assignment Problem (GAP)

GAP is a generalization of the classical one-dimensional Knapsack problem. Here we are given a collection of
k
bins with associated capacities
\{c_{j}\}_{j\in[k]}
, and a set of
n
items where each item
i
has a given size
s_{ij}
and a given profit
p_{ij}
for each bin
j
. The goal is to find a maximum profitable packing of a subset of items, satisfying the capacity constraints, i.e., for each bin
j
, the total size of the items assigned to
j
must not exceed
c_{j}
. The general case of GAP admits a tight
(\frac{e}{e-1}+\epsilon)
-approximation
[
16
]
. However, for the special case when

, there exists a PTAS.

Lemma 19

(
[
21
]
)
.

There exists an algorithm for the Generalized Assignment Problem (GAP) with

A.4

Steinberg’s algorithm is a commonly used area-based packing algorithm for rectangles. Informally, it states that a given collection of rectangles can be packed into a rectangular region whose area is twice the total area of the input rectangles, under certain mild assumptions on the dimensions of the input rectangles.

Lemma 24
.

There exist values
\epsilon_{\mathrm{thin}}^{\mathrm{container}},\epsilon_{\mathrm{thick}}^{\mathrm{container}}

Let

(iii)

the bottom edge of

touches the bottom boundary of the knapsack.

Let
C_{0}
be any vertical container intersecting
\mathcal{S}^{h}
(see

Let the two endpoints of the top edge of

be
(l_{0},y_{0})
and
(r_{0},y_{0})

and

Since each vertical item has a height of at least
\epsilon_{\mathrm{large}}N

\epsilon_{\mathrm{large}}N

inside

Alternate corridor processing.

To begin with, we process all acute subcorridors that are short. Then, all remaining acute subcorridors will be long. We make the following simple observation.

Lemma 33
.

In each of the remaining corridors, all obtuse subcorridors must be short.

Proof.

Suppose there exists an obtuse subcorridor
C_{1}
that is long, and w.l.o.g. assume that
C_{1}
is horizontal. Starting from the left (resp. right) bend of
C_{1}
, we traverse the subcorridors one by one until we reach the first acute subcorridor
C^{\prime}
(resp.
C^{\prime\prime}
). Since all the short acute subcorridors were already processed, it must be the case that both
C^{\prime}
and
C^{\prime\prime}
are long. Since
C_{1}
is a horizontal long subcorridor, neither of
C^{\prime}
and
C^{\prime\prime}
can be horizontal, else the width of the knapsack would exceed
N
. But then both
C^{\prime}
and
C^{\prime\prime}
are vertical long subcorridors having only obtuse subcorridors in between, which is a contradiction.
∎

From the above observation, it follows that in the remaining corridors, all the long subcorridors are acute, while all the short subcorridors are obtuse. Notice also that between any two vertical long subcorridors, there must exist a horizontal long subcorridor, otherwise the height of the knapsack would exceed
N
. We perform two different corridor processings as follows. In the first case, we first process all the horizontal long subcorridors in any order, followed by processing the obtuse subcorridors (which are all short). At the end, only the vertical long subcorridors survive, which we can now directly partition into boxes. In this way, we save all the thin items in the vertical long subcorridors. The other case is symmetric with the roles of the horizontal and vertical long subcorridors reversed. We therefore obtain the following lemma.

Lemma 34
.

We have
p(\mathrm{OPT}_{L\&C})\geq(1-\epsilon)(p(\mathrm{OPT}_{LF})+p(\mathrm{OPT}_{SF})+\frac{1}{2}p(\mathrm{OPT}_{LT}))
.

still holds if we define our sets

Also, note that in all the corridor processing steps, we need to discard a set of
