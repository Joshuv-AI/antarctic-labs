This final technical report describes the activities undertaken through Department of Energy, Office of
Science, Advanced Scientific Computing Research award DE-SC-0019039, “Analyzing Multifaceted Scientific
Data with Topological Analytics,” under the supervision of principal investigator Joshua A. Levine. The
project was performed at the University of Arizona from September 1, 2018 to August 31, 2024.
 Broadly, the goal of this project were to develop new techniques for the analysis of multifaceted data.
We employ a mix of topological analysis and machine learning for this analysis, in particular utilizing the
strengths of one to compensate for the weakness of the other. We call this methodology topological analytics.
 Our technical achievements during this project are organized around three thrusts of work (described
below). Key accomplishments include new methods to compare and extract topological structures, methods
that operate on multifaceted topological structures directly in ML analysis pipelines, and pioneering work
on data representations using implicit neural representations. Central to many of these projects is the PI’s
involvement in the development of the Topological ToolKit (TTK), a large-scale open source project that
brings topological data analysis to ParaView, a key DOE software package.

Thrust 1: Using Topological Analytics for Similarity
This thrust explored two key directions. The first focused on how to compute similarity measures for
topological data analysis of scalar fields. In a multifaceted dataset, one can expect it to contain many
instances of scalar data, and a natural question to ask would be how to compare pairs of instances. We
compare them through a topological lens, first constructing the merge tree, which represents the topology
of level sets within the field. We developed a stable distance measure on merge trees[2]. Merge trees can be
generalized to an object called Reeb graphs, which study level set connectivity across more complex domains.
We also considered metrics on Reeb graphs and surveyed the foundational work in the literature to provide
a centralized view that collected the disparate results on the topic [1].
 We also developed new methods to construct and evaluate topological analysis in new settings. For scalar
fields, we studied the impacts of data transformations when utilizing high-order FEM data seen through a
transformation that reduces it to linear for the topological data analysis step [7]. For vector fields, commonly
used to model flow data, we consider how to visualize the shape of flow with heat kernel signatures [8]. Most
recently, we developed a new method for extracting vector field topology using the framework of discrete
Morse theory, resulting in a localized evaluation that is inexpensive to compute [6]. This method is released
within the TTK software package.

Thrust 2: Investigating Multifaceted Features with Topological Analytics
For investigating topological features in multifaceted data, we asked how ML tools could help extract and
operate on features. In particular, we considered how to cluster point cloud via their persistence diagrams, a
result that was led by two undergraduate students and resulted in an additional software module for TTK [3].
We also considered how to look at distributions of topologies, by constructing autoencoders that learned
across a distribution of topologies and could then be used to visualize the relationships within the set [10].
Optimization is a key operation for any machine learning method, but due to the unstructured nature of
topological structures, new methods we need. We developed a practical solver for optimizing efficiently with

persistence diagrams of scalar fields, which was ultimate used as a mechanism for topological simplification
of scalar fields [9].

Thrust 3: Data Resampling for Topological Analytics
Our third thrust focused on the underlying data representations used for representing multifaceted data, and
the subsequent impacts on topological analytics. On such work in this direction developed generative models
for range-queries in databases, effectively replacing a standard database with a neural network approximate,
which allowed for interactive visual data exploration [12]. We next considered how one can represent field
data with neural networks. By using a coordinate-based MLP, we were able to develop so-called implicit
neural representations (INRs) which directly encode the mapping from spatial position ((x, y, z)) to field
value f (x, y, z) [11]. Using INRs in the setting of data visualization was a key breakthrough of this project,
and it has inspired a new subfield of data visualization where INRs can be used as surrogates for multifaceted
data.
 While considering the data representation, we also looked at the fundamental technology (simulation)
that generates multifaceted data. Specifically, we developed work on new flavors of finite elements, so-called
serendipity elements, that offer advantages of traditional finite elements in terms of compactly representing
degrees of freedom [4]. We implemented this new class of elements in a widely used finite-element solver,
Firedrake. We also considered the nature of solvers, and extended the method of discrete exterior calculus,
studying the advantages of using this framework for computing fractional derivatives [5].

Workforce Development and Professional Service
Four PhD students (Bollen, Crum, Jiang, and J. Li) completed their dissertations in part due to work
conducted for this project. Additionally, two PhD students (Tennakoon, Finken) were funded during the
award and have not yet completed their degrees. Two undergraduate students (Cotsakis, Shaw, at UBC)
conducted capstone research projects and another (Lu, at Vanderbilt) led key research milestones that
factored into their decision to pursue graduate degrees. Additionally, a series of software tutorials on TTK
and topological analysis were conducted at IEEE VIS, the premier conference for data visualization, where
many of the publications from this work appeared.

Software developed during this project.
 • Topology ToolKit (TTK): https://topology-tool-kit.github.io/
 While TTK already was released at the start of this project, numerous extensions to TTK were
 developed and the work was an enabling component.

 • Neurcomp: https://github.com/matthewberger/neurcomp
 This code introduces neural representations for volumetric data, offering advantages for compression.
 • NeuralCubes: https://github.com/hdc-arizona/neuralcubes
 This code demonstrated how database range-queries could be learned through a generative model

 • Trimmed Serendipity Elements: https://zenodo.org/records/4701708
 This code implements a new type of finite element in the Firedrake package.
