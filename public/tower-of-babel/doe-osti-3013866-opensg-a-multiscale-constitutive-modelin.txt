ABSTRACT
The new code, OpenSG, is founded as a novel technique for multiscale structural analysis. Con-
stitutive modeling of Cauchy continua, plates, and beams is established. This initial development
was focused on composite beams since funding was provided from a wind energy program. Novel
beam analysis methods are derived from the mechanics of structure genome. Most notably shell
cross-sectional modeling, tapered beam modeling, and panel buckling which is often a design
driver for thin-walled structures. The performance of OpenSG in terms of accuracy and efficiency
is extensively verified against VABS/SwiftComp and direct numerical simulations. Many of the
examples are developed for a realistic wind turbine blade. Although initial development focused
on turbine blades, OpenSG supports various target fidelities, allowing for seemingly limitless ap-
plications where beam, shell, or solid finite elements are used. OpenSG is made available globally
through a GitHub repository, providing a powerful tool for multiscale modeling.

1. INTRODUCTION

The Mechanics of Structure Genome (MSG) represents a revolutionary paradigm shift in multiscale
modeling, offering a fundamentally different approach from conventional bottom-up approaches.
Unlike traditional methods, MSG employs the rigorous Principle of Minimum Information Loss
(PMIL) to ensure fidelity by systematically avoiding a priori assumptions in kinematics and kinetics.
This powerful theory confines all necessary approximations solely to the constitutive modeling
stage for all structural types, including 3D solids, 2D plates/shells, and 1D beams, thus robustly
linking macroscale structural behavior with complex microstructural details. MSG allows for
flexible scaling, enabling users to choose the starting and ending analysis scales to capture required
details efficiently and affordably. Proven to be significantly faster than the popular alternative,
Representative Volume Element (RVE) analysis, MSG has already been successfully implemented
in commercial software like SwiftComp, VABS for virtual material and structure testing.
To assemble global talent and realize the Integrated Computational Materials Engineering (ICME)
vision, this work introduces OpenSG, a general-purpose, open-source implementation of the MSG
framework. OpenSG is built using FEniCSx, a highly popular open-source computing platform
designed for efficiently solving partial differential equations via the finite element method. By
formulating the core MSG theory using a variational statement suitable for FEniCSx, along with
proper constraints, we developed OpenSG to perform both homogenization and dehomogenization
for heterogeneous structures.
OpenSG supports various target structural analysis fidelities, allowing for the decomposition of
complex problems into downstream finite element models of Beam, Shell, and Solid types (e.g., for
BeamDyn, Abaqus, or ANSYS). The methodology begins with the identification and meshing of
the Structure Gene (SG)—the mathematical building block of the composite structure—which can
be resolved using 1D line, 2D Quad/Tri, or 3D Hex/Tet elements. OpenSG’s capabilities center on
three key stages: Homogenization, where the MSG framework calculates effective material, shell,
or beam properties; subsequent Global Structural Analysis using these properties to determine
overall structural response; and an Dehomogenization step to recover detailed local stress and
strain fields. Furthermore, OpenSG includes specialized functionality for advanced panel buckling
analysis by utilizing dehomogenization results to solve complex eigenvalue buckling problems. The
versatility of OpenSG will be demonstrated through its application to a diverse range of advanced
materials, including composites, 3D printed materials, metamaterials, biomaterials, and auxetic
materials. The performance in terms of accuracy and efficiency of OpenSG will be benchmarked
against SwiftComp. Following extensive verification and validation, OpenSG is made available
globally through GitHub repository, providing a powerful, assumption-free tool for the multiscale
modeling community.
The design of advanced composite structures—such as those used in aircraft, space shuttles, and
wind turbines—necessitates accurate mathematical models to predict their behavior under realistic

 11

operating conditions. This process involves translating complex physical phenomena into a robust
mathematical framework. For components like blades and wings, one-dimensional (1D) aeroelastic
beam formulations offer a computationally efficient alternative in the preliminary design phase.
However, the complexity escalates for composite laminates, as accurately modeling their numerous
anisotropic layers can require solving systems with millions of degrees of freedom (DOF).

INNOVATIONS IN OPENSG: A NEXT-GENERATION MSG IMPLEMENTATION

This work introduces OpenSG, an open-source, general-purpose multiscale modeling code that
significantly enhances the MSG framework. A primary advancement is the ability to directly
analyze non-uniform (a.k.a. non-prismatic) slender structures with an equivalent 1D beam model,
bypassing the intermediate 2D cross-section step. This, for example, enables the prediction of local
buckling across an entire wind turbine blade using a 1D beam model, reducing computational time
from approximately 48 hours to under one hour while maintaining similar 3D accuracy.

Developed in collaboration with Sandia National Laboratories (SNL) and the National Renewable
Energy Laboratory (NREL), OpenSG is part of a comprehensive analysis workflow. The process
involves two key stages:

 1. Homogenization: The pipeline begins by supplying a mesh file that is based on a yaml
 format. The mesh generator pyNuMAD (SNL) was used in this project which provided wind
 blade geometries and material inputs to OpenSG. OpenSG computes the SG and passes this
 simplified, high-fidelity data to a beam analysis codes like BeamDyn (NREL) for a rapid
 system-level analyses.

 2. Dehomogenization: OpenSG then uses the resulting forces and moments from the beam
 analysis to recover detailed local stresses and strains across the original 3D structure, allowing
 for the accurate prediction of local buckling.

ADVANCED METHODOLOGIES AND CAPABILITIES

SHELL ELEMENT COMPATIBILITY

To address a key limitation of existing MSG methods that require solid element meshes, this
work introduces a novel framework based on elastic shell energy. This allows users to provide
computationally efficient shell element meshes, which are ideal for the thin-walled composite
structures typical of blades. OpenSG can therefore process both solid and shell elements for any
tapered 3D geometry to determine the required beam properties.

 12

HOMOGENIZATION OF TAPERED GEOMETRIES

Furthermore, OpenSG overcomes the challenge of analyzing realistic tapered blades—a task diffi-
cult for traditional micromechanics methods limited to prismatic (constant cross-section) geome-
tries. A unique three-step homogenization approach is proposed:
 1. Map the boundary geometry and material information from the 3D tapered segment.
 2. Solve for the MSG at each of the two boundary ends separately.
 3. Apply the solved boundary solutions as displacement constraints to the tapered 3D seg-
 ment. This approach effectively simulates the effect of periodic boundary conditions while
 remaining applicable to general tapered blade segments.

LINE ELEMENT CROSS-SECTION ANALYSIS

Leveraging the MSG shell framework, OpenSG introduces a novel approach for cross-sectional
analysis using simple line elements embedded with detailed layup information. This method effi-
ciently determines structural stiffness and inertial properties, replacing the traditional methodology
of using 2D solid meshes to obtain VABS-like stiffness. Benchmark testing against VABS con-
firms that OpenSG’s approach is significantly more accurate than alternative tools like PreComp
(developed by NREL), representing a revolutionary step forward for cross-sectional analysis.

VALIDATION AND PERFORMANCE

OpenSG has been extensively validated against commercial benchmark tools using realistic wind
turbine blade models. The comparisons show that the structural properties derived from the
direct 3D analysis in OpenSG are more accurate than those from traditional 2D cross-sectional
approaches.
The local buckling predictions, obtained by solving a generalized eigenvalue problem for each
tapered segment, correlate closely with results from established analysis tools like Sierra. A
buckling failure is predicted if any eigenvalue falls below one, and the corresponding eigenvector
can be used to visualize the buckled mode shape.

BROADER IMPACT

OpenSG is publicly available on GitHub (https://github.com/wenbinyugroup/OpenSG/
tree/main), featuring an API-based implementation, comprehensive documentation, and tuto-
rial examples for 1D, 2D, and 3D homogenization cases. This research invites scholars to extend
the application of MSG beyond structural mechanics to other domains characterized by material
heterogeneity, such as thermal and nuclear engineering. As a general-purpose theory rooted in

multiscale modeling applications.

2. CONSTITUTIVE MODELING OF COMPOSITE STRUCTURES

The structural analysis of thin-walled composite structures/additive manufactured parts often re-
quires finite element analysis (FEA) through three-dimensional (3D) solid elements, two-dimensional
(2D) plate, or shell elements, or one-dimensional (1D) beam elements. Here, 1D, 2D, or 3D refers
to the number of coordinates needed to describe the geometry. The constitutive modeling of
these corresponding 1D, 2D, or 3D elements considers deformations in all three directions. For
example, the 1D beam element can define the deformations in three directions. We introduce a
revolutionary, rigorous and unified approach for this micromechanics modeling, called Mechanics
of Structure Genome (MSG) theory which minimizes the differences between the original hetero-
geneous model and the desired global model without any prior assumptions. For example, the
obtained global Timoshenko beam model defines the constitutive relation between beam reaction
force and beam strains without considering any kinematic assumptions. It utilizes the variational
asymptotic method (VAM) to form a semi-analytical formulation which can be numerically solved
for general mesh profiles.

The outline of this chapter consists of brief discussion of Mechanics of Structure Genome theory,
and discussion of open-source automated PDE solver, FEniCSx. Thereafter, we will discuss theo-
retical formulations and numerical implementation with examples of each global model including
continuum solid, plate/shell, and beam model using minimization of original heterogeneous 3D
elasticity energy. We demonstrate this numerical implementation in an open-source general purpose
multiscale modeling code, OpenSG for implementing the MSG theory. The numerical example
involves both homogenization (obtaining structural properties) and dehomogenization (recovering
the detailed stresses and displacement). To clarify, OpenSG provides structural properties for
external structural analysis tools, like Abaqus, BeamDyn. OpenSG thereafter uses their structural
responses to recovers the local stress field for post-processing.

2.1. Mechanics of Structure Genome (MSG)

The Mechanics of Structure Genome (MSG) is a revolutionary theory for a unified constitutive
modeling of composite structures [36]. MSG combine the microscale information with macro-
scopic structural analysis through bottom-up approach for heterogeneous composite laminates as
shown in Figure 2-1. MSG utilizes the structure gene (SG) which is similar to structure DNA,
carrying sufficient heterogeneity and anisotropy for defining the structure behavior. SG refers to
the mathematical building block of the structure which can be 1D (line elements) for composite
laminates (heterogeneity along thickness direction), or 2D (plate elements) for prismatic beam, or
3D (solid elements) for an additive manufactured part. It is unlike the conventional Representative

Volume Element (RVE) method which is restricted to be only 3D geometry and taking separate six
load cases to perform homogenization.

2.2. FEniCSx: Automated PDE Solver

The FEniCSx is a collection of open-source computational software components with an objective
to enable automated solution of partial differential equations (PDE)[]. The Figure shows how
different libraries work in synchronous to formulate and solve the linear systems of equations.
The Unified Form Language (UFL) is a versatile component to translate the abstract mathematical
variational or weak energy form into linear systems of equations using just in time (JIT). The JIT
generates a C++ code in backend to assemble the global matrices and returns the solved unknown
in UFL form output for faster computation.

The choice of FEniCS at initial stage and later completely to FEniCSx for open-source implemen-
tation of MSG was done. The python platform for FEniCS made it suitable to merge existing mesh
generator tool (pyNuMAD) and beam analysis code (BeamDyn) to form a complete pipeline for
wind blade structural analysis. The present work under the project starts with verification of MSG
implementation in FEniCS with solid continuum model, plate/shell and beam model using solid
elements. We will discuss the reason of switching to FEniCSx, for using shell elements. The
FEniCSx uses MPI based platform which makes it suitable for using parallel computing for faster
computation. the application would be to split the entire wind blade into segments/stations, and
each segment is computed parallel. We have both version of all MSG models discussed in this
chapter, however, for updated functionality and making OpenSG general for shell and solids, we
shifted completely towards the FEniCSx.

2.3.2. Periodic boundary conditions: 3D SG

A set of periodic boundary conditions (PBC) are applied separately for 2D and 3D SG. The PBC
require same fluctuation functions on corresponding periodic edges and corners in case of 2D SG
whereas, it require periodic faces, edges and corners in case of 3D SG. For 2D SG, the nodes on the
left edge, bottom edge, and left-bottom corner on the boundary are geometrically equivalent to its
corresponding nodes. Similarly, for 3D SG, the nodes on the left, bottom, and back faces including
respective edges and corners are geometrically equivalent to its corresponding nodes. The clarity
of above brief description can be appreciated by viewing the boundary surfaces of SG in Figure
(5-1) and Figure (5-2). These set of additional constraints are applied in FEniCS for the proposed
3D Cauchy continuum model based on MSG.

We added the capability to use periodic boundary constrains for using 3D SG for the UDFRC, and
found the same results as that of cross-section and that with swiftcomp. The line plots can be found
below in Figure. Note that, for 3D SG, OpenSG is not restricted to periodic boundary conditions as
for general tapered segments, we do encounter aperiodic boundaries. Therefore, we implemented
special approximation of boundary constraint solutions to constraint the boundary. The detailed
discussion can be found in Tapered segment chapter.

We needed to constrain the rigid body motions for minimization of 3D elastic strain energy.

FEniCSx doesn’t have real function space and we used nullspace to remove the corresponding rigid

2.5. MSG-Based Kirchhoff Plate Model

This section discusses the MSG implementation for obtaining the classical plate properties from the
layup information. Here, we choose 1D SG for composite laminates because of having anisotropy
and heterogeneity defined by the thickness direction of the laminate. Therefore, line element mesh
along thickness with each mesh element representing each lamina (heterogeneity) is sufficient
to capture the kinematic behavior of entire composite laminates. We incorporated the scale
separation assumption which considers discontinuity at lamina interface as shown in Figure 4-5.
[13] implemented the MSG without using this scale separation, and showed the comparison with
the 3D FEA (benchmark) solutions. OpenSG uses scale separation assumption for streamlined
implementation of computing plate stiffness for line element cross-section, evaluated in section
4.5.

 Figure 2-13. micro/SG coordinate system

OpenSG has plate model capability implemented for output the MSG based ABD matrix (classical
plate stiffness without Kirchhoff’s assumptions) using layup information [31]. The differences be-
tween using Kirchhoff’s assumption based ABD matrix and MSG based ABD matrix are plausible,
as discussed in section [36] whose benchmark validation for the OpenSG plate model is done using
Swiftcomp. Based on user perspective, the input would be lamina sequence, thickness, and angle
of each lamina. The angle considered here, is with respect to the local normal direction with origin

3. TAPERED SOLID SEGMENT: TIMOSHENKO BEAM STIFFNESS

This chapter continues our discussion of Timoshenko beam model for structural stiffness and iner-
tial properties for the tapered realistic blade segment defined in three-dimensional (3D) space with
curved geometry. The existing approach for 3D RVE or unit cell requires only periodic boundaries
to constrain the neighboring ends. However, this doesn’t apply for the present realistic case where
both boundaries along beam axis axis have different geometries. Therefore, we developed a com-
prehensive approach to resolve this boundary constraints.

For homogenization, we apply unit strains/reaction forces to the SG (structure gene), and the
corresponding deformations for each unit strain case provides us the stiffness properties. This
methodology should follow Hill-mandrel’s theorem [36], and the boundaries are constrained so
that it reflect continuity of geometries in adjacent SG (unit cells) in macroscale structure. When
we use conventional periodic boundary condition for RVE, we infer that we are repeating the SG in
neighboring SGs along beam axis by constraining the same geometric boundary nodes. To infer the
adjacent SGs continuity for non-periodic boundary, we consider knowing the boundary solutions
for the unit strain load cases applied to 3D SG. The MSG theory helps us to solve the 2D SG
(boundary cross-section) and obtain the fluctuating solutions, and use them to constrain the 3D SG.
This procedure assumes that we have an extended constant cross-section geometry (prismatic) at
each boundary of tapered 3D SG connecting the neighboring SGs representing the macroscale beam.

The validation of this boundary solution constraint method is demonstrated for the extruded pris-
matic segments using three approaches to obtain the same Timoshenko beam stiffness using,
 1. Periodic boundary constraints (3D SG)
 2. Boundary solution constraints (3D SG)
 3. Boundary section (2D SG)
This boundary solution constraint approach opens door for OpenSG computed tapered segment
giving more accurate results than VABS like cross-section for Timoshenko beams stiffness as well
as for other global models (like plate/shell, and 3D model) with the best approximation approach.

3.1. Solving Fluctuating Functions

For a 3D blade segment, the solution of PDEs requires two important aspects, 𝑎) constraining rigid
body motions (i.e., 3 translations and one twist for beam), 𝑏) apply unit loads. For the realistic wind
blades, the boundary nodes are not geometrically periodic, which prohibits us from using periodic

 39

boundary conditions. Although, in section 3.3, periodic boundary condition (PBC) approach is
shown implemented in OpenSG for prismatic composite beams, the focus of present work is mainly
to demonstrate the tapered beam segment.
For applying unique boundary loads, the solution lies in MSG versatility to use boundary cross-
sections for computing the beam stiffness where, the 2D SG don’t requires periodic boundary
conditions for Timoshenko beam model unlike conventional RVE. In utilizing this feature, OpenSG
uses the following procedure to constraint boundary loads as

 • OpenSG creates the boundary cross-section mesh and obtain corresponding material data
 from the solid tapered blade segment geometry. This results in the generation of two separate
 end boundary meshes (2D SG) to calculate unknown fluctuating functions 𝑉0𝑏 and 𝑉1𝑏 at
 boundary nodes using MSG (refer equations 1.33, 1.36).

 • Computed exact fluctuating functions 𝑉0𝑏 and 𝑉1𝑏 at boundary dofs, acts as dirchilet boundary
 conditions input to geometrically constraint the tapered segment systems of equations. This
 dirchilet boundary condition automatically restricts the rigid body motion for a tapered
 segment. For evaluating 2D SG, we utilize null spaces to constraint the rigid body motions.

The exact fluctuating displacements solved at the boundary 𝑉0𝑏 and 𝑉1𝑏 acts as initial value problem
for the system of equations for the tapered blade segment to solve unknown 𝑉0 and 𝑉1 . Note that,
zeroth order fluctuating functions, 𝑉0 and first order fluctuating functions, 𝑉1 are computed by
separate linear system of equations equations 1.32, and 1.35 respectively. It is noteworthy that the
boundary cross-sections are extracted using OpenSG geometry and material mapping from 3D SG,
therefore, the cross-sections (2D SG) lies in 3D space with all 3 Euler angle element rotations which
provides additional beam stiffness information in terms of non-zero coupling terms in Timoshenko
stiffness matrix.

The proposed method allows user to provide element orientation by direction cosine matrix (default
for most mesh generators) containing all three Euler rotation angles information. OpenSG thereby
transfers/maps the exact orientations to the generated boundary meshes. Therefore, for computing
boundary stiffness and tapered segment stiffness, same linear system of equations are solved, but
on different mesh domains, which indeed exemplifies the universality of MSG.

4. KIRCHHOFF SHELL: BEAM MODEL

The MSG implementation in chapter 2 considers the original heterogeneous model as 3D elastic
model, and we obtained different macroscopic model by writing the 3D elastic kinematics into
that of macroscopic model (including Cauchy continuum, plate/shell, and beam model). In other
words, we were minimizing the 3D elastic strain energy to obtain the macroscopic strain energy.
This chapter focuses on choosing the 2D elastic shell strain energy as the original heterogeneous
model, and we can thereafter choose the corresponding macroscopic model in a similar manner.

The chapter discusses firstly the formulation the Kirchhoff elastic shell model starting from defining
the kinematics, and the corresponding classical shell strains. Once, we obtain the shell kinematics,
we can implement the MSG to obtain the desired macroscopic beam model. The present chapter
incorporates the Kirchhoff’s assumption of neglecting the transverse shear strain behavior to define
the physics of the original elastic shell model. This in-effect have curvature strains having sec-
ond derivatives of fluctuating functions, making the energy formulation a fourth order PDE. We
would discuss the analytical validation for isotropic cylindrical beam for obtaining the Timoshenko
beam stiffness using Variational Asymptotic method (VAM). Once validated analytically, we will
demonstrate the OpenSG numerical implementation for the cross-section using penalty constraints
of Discontinuous Galerkin approach in detail.

After discussion of bi harmonic example implementation in previous section DG penalty code, we

penalty constraints for the line element mesh (cross-section) has edges as point as shown in Figure.
This makes the normal derivative weak continuity imposition for neighboring line elements at

in upcoming section.

However, for the quad element mesh for tapered segment, we have significant contribution of deriva-
tive components tangent and normal to element surface. This was reflected when we use pure torsion
load which requires continuity of mixed derivative (in-plane) along neighboring edges. In the lit-
erature for exact shape functions, the author of [23] showed the continuity of second derivatives
components in addition to first derivatives as shown in double circles at vertices of Figure 4-3. For
example, a quadrilateral element will have 6 dofs/node 𝑢, 𝜕/𝜕𝑛, 𝜕/𝜕𝑡, 𝜕 2 /𝜕 2 𝑛, 𝜕 2 /𝜕 2 𝑡, 𝜕 2 /𝜕𝑛𝜕𝑡

to exactly capture the 𝐶 1 continuity for general load cases.

On imposing only existing weak continuity of normal component 𝜕/𝜕𝑛, the pure bending and
extension load works well. However, the response was poor for pure torsion load. Therefore,
additional derivative continuity was required to capture the exact torsion behavior.  We added the
similar weak imposition for remaining derivatives 𝜕/𝜕𝑡, 𝜕 2 /𝜕 2 𝑛, 𝜕 2 /𝜕 2 𝑡, 𝜕 2 /𝜕𝑛𝜕𝑡 , and found it
performing better for torsion load. This makes sure the Euler-Bernoulli beam stiffness for tapered
shell segment works fine, whose validation test cases are shown in upcoming section. However,
the transverse shear stiffness for Timoshenko beam model are not reliable and was unsuitable with
penalty constraint.

Based on extensive literature review to compute the torsion behavior using weak DG method, we
do not found any existing and acceptable approach. Babuska [4] mentioned that no existing penalty
approach can be generalized for Kirchhoff-shell models. Existing research focused on specific load
case, but for a single model taking care of all the general load cases like torsion was not found.
This end-point leads us towards the conclusion of getting reliable cross-section Timoshenko beam
stiffness from weak continuity, however, for tapered shell segment, we were able to determine upto
Euler-Bernoulli beam model.

We were not satisfied with only weak continuity of normal derivatives for quad elements. However,
for shell cross-section, these penalty constraints were tested for general Timoshenko beam model
and validated with VABS. For quad elements, we computed tangent vector set of all interior edges in
addition to normal to interior edges, which were not explicitly available as UFL function. Thereby,
we imposed weak continuity of derivatives of all three components, i.e., normal, tangent, and third
orthogonal direction (normal to element plane) having to represent 6 dofs/node.

5. REISSNER-MINDLIN SHELL: BEAM MODEL

This chapter discusses the MSG thin walled implementation by using Reissner-Mindlin elastic shell
theory. In the previous chapter derived formulations, we required penalty approach to impose weak
derivative continuity and is unable to completely capture the torsion deformations correctly for
3D SG (shell segment). This chapter incorporates the transverse shear strains, which gives two
extra degrees of freedoms (shear rotations) at each node and formulate the variational as a second
order PDE (compared to fourth order in Kirchhoff shell formulations). Therefore, it doesn’t require
penalty constraints. However, we are posed with a shear locking challenge that is discussed in this
chapter, making the numerical implementation with additional considerations.
This outlook of this chapter consists of formulating the shell kinematics in a similar way, that we
derived in previous Kirchhoff model chapter. We will obtain two extra strain terms, representing
transverse shear strains, and the curvature strains have only first derivative of fluctuating displace-
ments/rotations. We will introduce a complete new MSG theory to define the fluctuating rotations,
and explain in detail how the beam and shell coordinate systems are correlated. Once we obtain
MSG based thin walled formulations for this Reissner-Mindlin model, the analytical validations for
both isotropic and anisotropic cases are performed to compare them with corresponding analytical
solutions of Kirchhoff’s model.

6. LOCAL BUCKLING USING SOLID ELEMENTS

One of the major application of using OpenSG is to predict the local or shell buckling using beam
analysis. The recovered local stresses over the tapered blade segment would formulate the prestress
distribution over the entire wind blade segment. The advantage we obtain is that we deal entirely
with beam model, without any conversion of beam reaction forces and moments to detailed 3D
stresses. This formulates the generalized eigenvalue problem which is a complete different set of
linear system of equations using elastic material constants of solid elements and recovered local
stress field. This means, the detailed 3D stresses would form the prestress or geometric stiffness
matrix, and the corresponding elastic stiffness matrix would be formed by global assembly of elastic
material properties. This procedure is equivalent to solving the entire wind blade with elasticity
theory, unlike we did the prestress analysis using beam model. The existing approach would help
us to obtain the mode shapes for each segment which would evaluate the relative strength of each
segment to identify which specific segment is weaker and close to buckling failure. We would be
focusing our discussion over generalized eigenvalue formulation from bifurcation equation, and the
corresponding solution for eigen values and eigen vectors representing critical buckling load factor
and corresponding mode shapes.

stability at equilibrium in respect of how they behave after perturbation.

6.4.1. Boundary Conditions

The geometric stiffness matrix, KG is an indeterminant matrix because of zero diagonal terms
at boundary constrained DOFs in addition to zero rows/columns. This zero diagonal prevents
eigenvalue spectrum pollution and ensures that eigenvalues associated with fixed DOFs become
infinite, representing these DOFs cannot participate in buckling. At boundary, where we fixed
the nodes with known displacements 𝑢𝑖 = 𝑢¯𝑖 (fixed), that node cannot move during buckling.
Mathematically, this means the change of displacement 𝛿𝑢 at that node should be zero.
[20] used formulated the similar generalized eigenvalue problem by forming substructures extracted
by dividing the original structure into segments. The author used fixed boundary conditions,
considering the role of boundary nodes is not required in generalized eigenvalue problem (since
known displacement do not contribute to perturbations). He found a extremely good corelation
of obtained buckling load factors (eigen value) from each substructure, and compared them from
solving the entire structure. The author divided the displacement into rigid body displacement
and deformed displacement which makes the deformed displacement as playing role in solving the
eigenvalue problem.

6.7. OpenSG Workflow for Wind Blade

For implementing the local buckling prediction capability using MSG based beam model in a wind
blade high-fidelity structural module, OpenSG computes homogenization and dehomogenization of
the tapered blade segment (as discussed in chapter 3). Therefore, the pre-stress conditions obtained
from MSG based dehomogenization solves the generalized eigenvalue problem to estimate the
buckling load factor. OpenSG thereby uses this capability in forming a comprehensive analysis
workflow as shown in Figure 6-6. The process involves two key stages:

 Figure 6-6. OpenSG workflow for wind blade structural analysis

 1. Homogenization: The pipeline begins with the versatile wind blade mesh generator pyNu-
 MAD, which provides the blade geometry, material layup, and local elemental orientation
 as a .𝑦𝑚𝑎𝑙 input file to OpenSG. Thereafter, OpenSG compute the 3D SG (tapered solid
 segment) for all segments and output this beam properties data to a beam analysis code like
 BeamDyn for a rapid global analysis.
 2. Dehomogenization: Once the beam analysis is performed, OpenSG then recovers the local
 stress and displacement field by using the resultant beam reaction forces/strain obtained from
 the beam analysis across the original 3D SG. OpenSG uses this local stress distribution to
 form the pre-stress matrix for generalized eigenvalue solver.

 92

where pyNuMAD [25] is a holistic mesh generator for wind turbine blades software, and BeamDyn
[28] is a non-linear beam analysis code using Geometrically Exact Beam Theory (GEBT). Note
that, the input mesh requires a .yaml format, which contains all prerequisite information to define
a blade geometry, i.e, mesh, material layup (for shell elements), material properties, and local
material orientation. This input mesh file .𝑦𝑚𝑎𝑙 can represent 1D, 2D or 3D SG mesh for both
solid and shell elements.The process of OpenSG usage and examples are defined in chapter 6. The
𝐻 in Figure 6-6 refers homogenization, and 𝐷 refers dehomogenization.
The computed minimum positive eigen value among all the blade segments would be the buckling
load factor for the entire wind blade. The effect of boundary DOFs in generalized eigenvalue
problem is not computed as discussed in section 6.4. Therefore, we can either use recovered local
displacements from boundary nodes, but we would be considering zero diagonal at constrained
DOFs. This would in effect doesn’t account for the boundary DOFs contribution.

6.7.1. OpenSG Integration With Windio

OpenSG is versatile in the way that the user is free to generate the .𝑦𝑎𝑚𝑙 input file from either
Windio or generate three-dimensional segment for an aircraft wing. The Windio input file is usually
converted to PreComp (stiffness analysis software), through WISDEM code ([24]). However, we
found the PreComp works poorly for obtaining structural deformations compared to OpenSG
and VABS in Figure 4-13. Therefore, the ongoing work of converting Windio blade input file

element blade station data. OpenSG would create the line element cross-section mesh using station
information like coordinates, connectivity sequence (variable s varying form 0 → 1), scale and
rotation about beam axis using WISDEM.
Moreover, the existing dehomogenization pathway of PreComp using beam bending stress formu-

dehomogenization with using fluctuating functions that actually carry the missing information
between the original microscopic model and global macroscopic model. The local orientation co-

data and element sequence. This work is under progress and will be available for wind energy
community for fast and efficient structural analysis using Mechanics of Structure Genome (MSG)
theory.
