 ABSTRACT
Automated particle analysis (APA) is a method for collecting elemental and morphological data on a large
number of particles using SEM with energy-dispersive x-ray spectroscopy (EDX). Often, the resulting
datasets have many thousands of particles, and sifting through the data to find meaningful trends can be
difficult. EDXplorer is a software utility for processing APA data that enables the user to easily load data
and determine the important components and aspects of these datasets using a powerful and versatile
library of data plotting functions, mainly centered around scatter plots and histograms. This software
is intended to fill a void in processing data from certain instruments, for which users must often rely on
their own code or software that is not user-friendly. EDXplorer is intended as a general plotting utility for
browsing through data and discovering data trends.

 1. BACKGROUND
Collecting particulates is a key aspect of obtaining a working history of an area or facility. Such collections,
which contain thousands of particles, are deep wells of elemental and morphological information. The
automated particle analysis (APA) method uses SEM energy-dispersive x-ray spectroscopy (EDX) to
collect information on on potentially tens of thousands of particles, including morphological (e.g., particle
area, average diameter) and elemental information. This method often produces large and complex
datasets, which can be difficult and time-consuming to analyze. Analysis often requires custom-made
code that must be altered for any new output format. Such custom codes are typically not generalized and
therefore must be adapted before they can be used with other collections. EDXplorer aims to address these
challenges.

 2. EDXPLORER OVERVIEW
EDXplorer is a Python-based general plotting utility with a PySide6-based user interface (Figure 1).
The utility is intended to facilitate loading and analyzing APA datasets. It uses the Polars package to
process the data and the Matplotlib package to produce plots and figures. This utility provides a unified,
generalized, and consistent framework for APA analysis by generating plots to identify data trends and
particle classes and enabling dataset comparison to identify similarities or differences between particle
populations.

 Figure 1. Main window of EDXplorer after loading and selecting datasets.

2.1 DATASET INFORMATION
EDXplorer can load Bruker and Tescan data as well as any data saved through EDXplorer.
The Bruker Esprit software controls the EDX detectors and automatically performs peak fitting and
particle classification. Esprit creates an Excel file (.xlsx) containing several sheets of data, including
elemental mass % or atomic % (normalized and not normalized), morphological parameters, and particle
classes. Several of these sheets can be converted to comma-separated values (.csv) files ready for loading.
Desktop Spectrum Analyzer II (DTSA-II) is used to control Tescan instruments and produce header (.hdz)
and data (.pxz) files that contain elemental k-ratios and morphological parameters. Particles are then
grouped into user-defined classes based on their elemental compositions. These classified data are saved
as either a new header/data file pair or a single .csv file.
In either case, a hierarchical list of elemental cutoff values or ranges is used to group each particle into
a user-defined class. Particles can be reclassified manually using EDXplorer (see Section 2.7). The
initial particle classification is not required for EDXplorer to open these files. If the particles have not

 2

been classified, the raw data files from DTSA-II will have a “Class” column with values not based on the
user-defined classes.
When initially produced, each APA dataset is accompanied by files containing spectral information.
Bruker spectra are found in .spx text files, whereas Tescan spectral data are found in the metadata of
.tiff image files. If these files are present when loading the APA data, EDXplorer can load and visualize
the spectral data for analysis (see Section 2.10). Only the APA dataset is required for EDXplorer. If the
spectral files are not present, the rest of the program still functions.
When loaded, the unique portion of the file path for each dataset appears in the list box widget (Dataset
List) on the left side of the interface. Multiple options are available for shortening or simplifying the
listed text. Each dataset is further processed, and particle count information is displayed in the list box
widgets on the right side of the interface. This information includes counts of particles containing specific
elements (Element List) and counts of particles in each class (Class List). Each of these list box widgets is
visible with a blue background in Figure 1.
In the Dataset List, a colored box appears to the left of each entry; the color reflects the relative value of
an aspect of the currently displayed information. By default, the color scale reflects total particle counts in
each dataset. This qualitative scale changes when an element or class is selected in either the Element or
Class Lists. Thus, the box color next to a dataset can reflect total counts of particles that contain a selected
element, particles within a selected class, average elemental fractions for selected elements, average area
of particles containing selected elements, and so forth. The Element List can be changed to show the
average or sum of the elemental fraction within each dataset. Additionally, it can display the average area
or diameter of particles containing each element.
EDXplorer contains a wide variety of features for plotting and analyzing data. To assist the user, each
widget in the GUI has an associated tool tip that appears when the cursor hovers over the widget.
Additionally, an extensive user manual is provided with the program.

2.2 FILTERS
A key feature of EDXplorer is its ability to filter datasets to focus on key parameters of interest. The
following filter capabilities are included:
 • Remove background atoms
 • Set elemental values below threshold to zero
 • Remove particles based on desired cutoff value
 – Elemental fraction
 – Morphological parameters
 – Particle classes
Filter parameters and any other user-defined parameters in EDXplorer can be saved to a text file and
imported in future sessions to apply the same filters. This feature can also be used to save profiles for
different analysis types for use in multiple projects.

2.3 PLOTTING
EDXplorer includes several categories of plots: simple scatter plots, density-related plots, and distributions.
Examples are shown in Figure 2.
Simple scatter plots can be generated using any set of parameters. The software can create binary, ternary,
and 3D scatter plots. Additional parameters can be represented by applying a color or size scale to each
point.
Density-related plots come in two main types. First, heatscatter plots are binary or ternary scatter plots
with a color scale applied to the points based on point density. Second, 2D histograms are binary or
ternary plots that display a color scale according to how many points are in each bin. The number of bins
and smoothing can be changed. A density plot can be made with a heat map with a color scale is based on
point density. Moreover, each point can be given a weight value based on another parameter.

Distribution plot come in two varieties: 1D histograms and X/Y binned average plots. As shown in Figure
3, 1D histograms plot the distribution of the values of a single parameter within the selected dataset(s),
where the distribution is split into bins. Bins can have either user-defined widths or a set number of bins of
equal widths. An X/Y binned average plot is similar to a 1D histogram, but instead uses two parameters; it
plots the average value of the second parameter within each bin of the distribution of the first parameter.
Several additional plotting modalities are provided to enable users to quickly gain information on the
elemental and class composition of each dataset.
Bar graphs (Figure 4) showing particle counts for each class or for each element can be easily produced.
Additional options include the following: heights can be normalized to a single element across multiple
datasets, and different cutoff values can be applied to determine which bars appear in the plot. Datasets
can be compared using difference or ratio bar graphs (relative to a defined reference dataset). Stacked bar
graphs are also available (both absolute and relative values).
Another plot type is based on a determination of the three elements most colocated with a specified
element within the selected dataset (Figure 5). The software will produce a large figure with six heatscatter
plots depicting each combination of the original element and the other three elements.

Finally, another plot function automatically detects the 12 most common elements in all selected datasets

2.4 PRINCIPAL COMPONENT ANALYSIS
EDXplorer also includes basic principal component analysis (PCA) capability (Figure 7). This PCA is
based on a selected class and a list of elements (features). A scree plot can be generated to determine the
ideal number of components to include. Then, any combination of components can be plotted, together
with a biplot overlay showing the directions that correspond to specific elements. A matrix plot can be
generated for a set number of components, showing each combination and a histogram distribution of each
component. Finally, component loadings can be visualized as a function of both elements (features) and

 5

components.
These additional plot types are intended to quickly provide users with a general overview of the elemental
and class data within each dataset to aid in identifying data trends or particle populations.

2.5 POINT SELECTION
In any generated scatter or heatscatter plot, various selector types can be used to highlight a selection of
points. This feature can be used to identify where particles are on a particle map or create a new dataset
with only the selected points.
A more powerful use of this feature is with linked plots. Up to four simple scatter plots or 1D histograms
can be produced with any combination of parameters for a single dataset. A selector can be used on the
points (or histogram) in any one of the resulting plots. Then, the selected points are highlighted in all plots.
This technique is very useful for seeing how certain particle populations correspond to various parameters.

2.7 RECLASSIFICATION
EDXplorer also includes a simple reclassification function. One or more datasets can be reclassified using
an imported classification rule file that uses elemental and morphological information to place particles in
particular classes, typically based on defined elemental composition ranges and cutoff values. This feature
is useful if existing classifications need to be updated with a different rule set or if the dataset(s) have been
filtered. When reclassifying data, EDXplorer will either overwrite each dataset with the new classes or
create a new dataset in the Dataset List. Reclassified datasets can be saved to .csv files.

2.9 PARTICLE SPECTRA
EDXplorer has a simple EDX spectrum viewer utility (Figure 9). Using this tool, users can view the EDX
spectrum corresponding to each particle (assuming the spectral data is present) and generate additional
plots, such as a max particle spectrum, which can be used to find overlooked peaks by determining the
maximum value at each energy level across all particles in a dataset. Elements present in the particle
composition table are labeled on the spectrum. Additional peaks can be identified by selecting an element
and adding the relevant lines, (i.e., K, L, or M lines). Currently, EDXplorer cannot perform peak fitting
analysis on spectra, but this capability may be included in a future version.

2.10 FIGURE LAYOUTS
EDXplorer offers a variety of functions for customizing figure layouts. By default, plots for all selected
datasets are overlaid on the same figure in the central canvas. Users can also choose side-by-side or
grid-style plot layouts as well as create new windows with defined dimensions. Another setting automatically
saves new figures as they are generated.

2.11 DATA OUTPUT
Any figure can be saved to the clipboard or to a file. Additionally, several kinds of statistical information
can be saved to a text file, including particle counts and any data currently shown in the Element and/or
Class Lists. Another useful feature allows users to extract information on particle fractions on particular
element colocations, allowing the user to set which particles will be included and excluded in particles of
interest.

2.12 CREATING AND SAVING DATASETS
At times, it may be useful to create a new dataset from existing data. Datasets can be concatenated to form
a larger dataset, or a smaller dataset can be formed by applying filters or selecting points in a scatter plot.
All new datasets appear in the list of loaded datasets. Any newly created dataset can be saved as a .csv file
that can be loaded into EDXplorer in other sessions.

2.13 FUTURE DEVELOPMENT
In the current version of EDXplorer, users must manually plot their data to analyze data trends and
elemental populations. The reclassification tool uses conditional statements to sort particles into classes.
In the future, EDXplorer may incorporate the ability to reclassify particles on the fly as filters are applied
and background atoms are removed. Additionally, a clustering workflow that clusters particles based on
elemental and morphological parameters will be added to automatically reveal particle classes that may
not be identified using defined conditional statements. Other additional functions may include the ability
to compare particle data (to determine how similar certain data are to a reference), clustering algorithms,
metadata analysis, particle loading analysis, and AI/ML analysis.

 3. CONCLUSION
EDXplorer is a custom-built utility for handling SEM-EDX APA data in multiple formats and quickly
generating useful plots and histograms to discover trends in elemental and morphological parameters. A
key feature of the program is its ability to remove background atoms and easily apply custom filters to
multiple datasets. This feature, combined with a myriad of plotting capabilities, enables users to quickly
and easily parse elemental and morphological information in huge datasets with tens of thousands of rows.
EDXplorer is still under active development and will be of great use for APA datasets in many current and
future projects.
