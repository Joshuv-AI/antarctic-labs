LHEReader : Simplified Conversion from Les Houches Event Files to ROOT Format
Aman Desai

Abstract
We present the LHEReader program that converts an Les Houches Event file into a ROOT file allowing one to subsequently analyze the file using ROOT . We evaluate the performance of this conversion by simulating p ​ p → j ​ j pp\to jj and e + ​ e − → Z ​ H e^{+}e^{-}\to ZH . The application of this program is illustrated through the simulation of p ​ p → Z ​ H pp\rightarrow ZH , with the Z → ℓ + ​ ℓ − Z\to\ell^{+}\ell^{-} and H → b ​ b ¯ H\to b\bar{b} , analyzing the events at the parton level after hard-scatter event generation as well as after the stage of fast simulation using MadAnalysis5 . The analysis is implemented in ROOT demonstrating the use of this program. The program is available here: https://github.com/amanmdesai/LHEReader



I
Introduction

Monte Carlo event generators store parton-level generated event record using a standard file format called the Les Houches Event File (
LHE
File)
2
. These files store all necessary information about an event such as the particle identities, status codes, particle four-momenta, particle’s spin, information about the parent particles, color information. Among other variables, it stores the scale,
\alpha_{\rm{QED}}
,
\alpha_{\rm{QCD}}
, event weight. The parton-level events generated, for example, by
MadGraph5_aMC@NLO

1
are usually passed to parton shower and hadronisation stages, which are handled by general-purpose event generators such as
Pythia8

7
. Moreover, softwares such as
MadAnalysis5

12
can also produce its output in the form of an
LHE
file. To facilitate the reading of these files, a variety of softwares have been proposed and are available for installation, for example, Ref.
18
.

In this paper we present an alternative program, named
LHEReader

15
, to convert an
LHE
file into
ROOT
file
8
which allows one to further analyze the parton level events using functionalities defined within
CERN

ROOT

13
and recently we updated the program to allow additional input types such as
.lhe.gz
. In this paper, we also provide a code snippet with an
EventLoop
code which one can utilize to analyze files. Previously, we presented this program at the Australian Institute of Physics Congress 2024
14

LHEReader
has been used in research projects related to the LHC and FCCee cases

IV
Application

We illustrate application of this program by using an example of Monte Carlo events produced using
MadGraph5_aMC@NLO

1
. We simulate the
pp\rightarrow ZH
process with the
Z
boson decaying to a pair of leptons (electrons or muons) and Higgs boson decaying to a pair of
b
-quarks. With this example, we not only illustrate the usage of
LHEReader
but also
EventLoop
function to process quarks, leptons and also missing energy. A representative Feynman diagram corresponding to the process is given in
Figure 1
. We set the beam energy to 6.8 TeV corresponding to LHC Run 3 and use the PDF4LHC21 PDF set
5
, which is accessed using
Lhapdf6

9
. The cross-section including the decay branching fractions for this process, as obtained from
MadGraph5_aMC@NLO
, is
39.6
fb
-1
. The parton-level events are then processed through
Pythia8

7
for parton shower and hadronisation. Subsequently, we process these through
FastJet

11
for clustering objects into jet, through its interface as provided within
MadAnalysis5

12
. We have used the anti-
k_{T}
algorithm
10
with the radius parameter set to 0.4. We scale events to an integrated luminosity of 300 fb
-1
and the results are shown after normalisation.

A simplified analysis strategy is adopted to demonstrate the application of
LHEReader
and
EventLoop
Function. We select events consisting of exactly two opposite sign same-flavour isolated leptons each satisfying the requirements
p_{T}>25
GeV and
|\eta|<2.5
. Moreover, the invariant mass of leptons is required to be within
[80,100]~\rm{GeV}
, to select events consistent with
Z\to\ell^{+}\ell^{-}
. We require jets with
p_{T}>25
GeV and
|\eta|<2.5
. We select
b
-jets using truth information for parton level analyses and use the PID branch for reconstructed level analysis (for simplicity, we set the
b
-jet identification efficiency to 100%). The selected
b
-jets and leptons are required to have
\Delta R(b,\ell)>0.4
. At least two
b
-jets are required to be present in an event. The leading and sub-leading
b
-jets, with a combined transverse momenta greater than 30 GeV are used to reconstruct the Higgs candidate.

A selected distributions of Kinematic features after the reconstruction stage are summarized in
Figure 3
. The distributions are related to the transverse momenta of the muons, electrons and
b
-jets. In
Figure 4
, we give the distributions of the
Z
boson mass candidate as reconstructed from a pair of selected electrons and muons. The Higgs boson mass distribution, at the parton level is a single bin at the Higgs mass and at the reconstructed level is spread about the Higgs boson mass as shown in
Figure 5
.

V
Conclusions

We presented the
LHEReader
which reads and converts a given
LHE
file into a
ROOT
file. We also presented an example
C++
code that can be used to read the
ROOT
file. As an example, we showed how this program is applied on the
LHE
file output generated by
MadGraph5_aMC@NLO
and also by
MadAnalysis5
. The scripts presented in this paper could be useful for both, research purposes as a tool to quickly test the kinematic distributions and the
LHE
File in general and, also for educational purposes as a lightweight tool to convert an
LHE
file to a
ROOT
.
