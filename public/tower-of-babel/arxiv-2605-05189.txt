Sharp Capacity Thresholds in Linear Associative Memory: From Winner-Take-All to Listwise Retrieval
Nicholas Barnfield, Juno Kim, Eshaan Nichani, [0.25em] Jason D. Lee, Yue M. Lu, [0.5em] Harvard University University of California, Berkeley Princeton University

Abstract
How many key-value associations can a d × d d\times d linear memory store? We show that the answer depends not only on the d 2 d^{2} degrees of freedom in the memory matrix, but also on the retrieval criterion. In an isotropic Gaussian model for the stored pairs, we show that top-1 retrieval, where every signal must beat its largest distractor, requires the logarithmic model-size scale d 2 ≍ n ​ log ⁡ n d^{2}\asymp n\log n . We prove that the correlation matrix memory construction, which stores associations by superposing key-target outer products, achieves this scale through a sharp phase transition, and that the same scaling is necessary for any linear memory. Thus the logarithm is the intrinsic extreme-value price of winner-take-all decoding. We next consider listwise retrieval, where the correct target need not be the unique top-scoring item but should remain among the strongest candidates. To formalize this regime, we propose the Tail-Average Margin (TAM), a convex upper-tail criterion that certifies inclusion of the correct target in a controlled candidate list. Under this listwise retrieval criterion, the capacity follows the quadratic scale d 2 ≍ n d^{2}\asymp n . At load n / d 2 → α n/d^{2}\to\alpha , we develop an exact asymptotic theory for the TAM empirical-risk minimizer through a two-parameter scalar variational principle. The theory has a rich phenomenology: in the ridgeless limit it yields a closed-form critical load separating satisfiable and unsatisfiable phases, and it predicts the limiting laws of true scores, competitor scores, margins, and percentile profiles. Finally, a small-tail extrapolation further leads to the conjectural sharp top-1 threshold d 2 ∼ 2 ​ n ​ log ⁡ n d^{2}\sim 2n\log n .

Introduction

Associative memory refers broadly to the ability of a system to store and retrieve relationships between objects. Given a collection of input-output pairs, one would like the system to recover the correct target when presented with a corresponding cue. This basic mechanism appears in many forms, ranging from the first neural network models for pattern learning
(
34
;
2
;
3
;
28
;
29
)
, to modern key-value retrieval systems
(
50
;
46
;
21
)
. Associative memory has also recently attracted attention as a model of factual recall in large language models
(
8
;
9
;
30
;
45
)
as trained transformer layers have been observed to function as key-value memories
(
22
;
40
;
6
)
.

A central theoretical question in associative memory is: given
n

associations, how large must the memory model be in order to retrieve them
under a prescribed criterion?
In this paper, we study this question in the simple
but already nontrivial setting of
linear associative memory
.
Given pairs of key vectors (embeddings)
v_{i}
and associated targets
(unembeddings)
u_{i}
, we consider a matrix memory model

W\in\mathbb{R}^{d\times d}
and define the score matrix

S=(s_{j,i})_{1\leq i,j\leq n}
as

s_{j,i}=u_{j}^{\top}Wv_{i},\qquad\{(u_{i},v_{i})\}_{i=1}^{n}\subset\mathbb{R}^{d}\times\mathbb{R}^{d},\qquad W\in\mathbb{R}^{d\times d}.

(1)

This score matrix encodes the predictions for the target when decoding to a fixed vocabulary of size
n
.
Rather than requiring the output
Wv_{i}
of the memory model on an input
v_{i}
to be exactly its associated target
u_{i}
, as in classical models for associative memory
(
28
)
, we will consider methods which compare the score for the true target
s_{i,i}
to its competitors
(s_{j,i})_{j\leq i}
.
One main message of the paper is that the answer to the above question depends sharply on the retrieval criterion: as we will see next, controlling the
single largest distractor is fundamentally more expensive than
controlling the average strength of a fixed upper tail.

A standard baseline in the associative memory literature is

top-1 retrieval
, also called exact retrieval

(
34
;
8
;
9
;
45
)
.
Under this criterion, each key must retrieve its matched target with
the largest score:

s_{i,i}>s_{j,i},\qquad\forall j\neq i,\quad\forall i\in[n].

(2)

Operationally, this is the natural criterion for final winner-take-all
decoding. It is also the hard-attention, or low-temperature, limit of softmax attention in transformer-based architectures
(
50
)
; at fixed temperature, the same concentration occurs when the leading score gap is large.

We also study a complementary retrieval regime:
listwise
recoverability
. In many memory architectures, a memory access is an
intermediate computation rather than a final decision; its role is to keep
the correct association salient among high-scoring candidates for subsequent
layers, heads, or rerankers to refine. The most direct listwise condition would require the signal to beat the
k
-th largest competitor. This rank condition is non-convex in the score matrix. We instead use a convex certificate
(
47
;
48
)
: we compare the signal score with the upper-tail average of its competitors. For query
i
, let

s_{(1),i}\geq s_{(2),i}\geq\cdots\geq s_{(n-1),i}

(3)

denote the ordered competing scores, and set
k=\lceil r(n-1)\rceil
for a tail fraction
r
. We call
the resulting upper-tail comparison the
Tail-Average Margin
(TAM)
criterion:

s_{i,i}>\operatorname{TAM}_{r}((s_{j,i})_{j\neq i})\mathrel{\mathop{\ordinarycolon}}=\frac{1}{k}\sum_{\ell=1}^{k}s_{(\ell),i},\qquad\forall i\in[n].

(4)

In other words, for each query, the target score
s_{i,i}
is required to
beat the average of its top-
k
competitors.
Since
\operatorname{TAM}_{r}((s_{j,i})_{j\neq i})\geq s_{(k),i}
, a positive
TAM margin certifies that the matched target lies in the top-
k
candidate
list. The parameter
r
tunes the retrieval statistic: when
r=1/(n-1)
,
TAM reduces to top-1 retrieval, while
r=1
compares the signal with the
average competitor score. Thus top-1 retrieval controls the single largest
distractor, whereas TAM controls the average strength of the upper tail of
the competitor distribution.

This listwise perspective is in the same spirit as list decoding in
coding theory, where the decoder is allowed to retain a controlled list
of plausible messages rather than make a unique decision

(
16
;
25
)
. It is also
aligned with listwise ranking losses in information retrieval, which
optimize criteria defined on ranked candidate lists rather than on a
single pairwise comparison
(
10
)
.

For the two criteria studied in this paper—top-1 retrieval and
TAM—we ask how large the ambient dimension, and hence the
d^{2}

parameters of the linear memory, must be in order to retrieve
n

stored associations. In full generality, the answer depends on the geometry of the stored vectors
and on the rule used to construct the memory
W
. To obtain a sharp
high-dimensional theory, we study the isotropic Gaussian model

u_{i},v_{i}\stackrel{{\scriptstyle\mathrm{i.i.d.}}}{{\sim}}\mathcal{N}(0,I_{d}/d),\qquad i\in[n].

(5)

This model isolates the geometric effect of high-dimensional
interference, without imposing additional structure on the stored
associations.

1.1
Summary of main results

Top-1 retrieval.

For top-1 retrieval (
2
), we rigorously prove in Section
2
that the required model size is governed by the scale

d^{2}\asymp n\log n.

(6)

The positive direction builds on the correlation matrix memory construction,
which stores the associations as a superposition of outer products

(
34
;
15
)
.
Previous work of
45
showed that this
special memory achieves top-1 retrieval with high probability when

d^{2}\geq Cn(\log n)^{4}
for a sufficiently large constant
C
. We improve
this result by proving a sharp transition for correlation matrix
memory: Proposition
1
shows that it
succeeds when
d^{2}>(8+\epsilon)n\log n
and fails when

d^{2}<(8-\epsilon)n\log n
.

The main top-1 result is the negative direction. We prove that the
logarithmic factor is fundamental, not an artifact of the correlation
matrix construction: Theorem
1
(ii)

shows that, for any
C<2/\pi
, if
d^{2}\leq Cn\log n
, then no memory

W\in\mathbb{R}^{d\times d}
can attain top-1 retrieval with high
probability. Thus the logarithmic factor in (
6
) is
unavoidable: it is the inherent price of asking every signal to beat
the largest element in a cloud of
n-1
competitors.

Tail-Average Margin.

For the listwise criterion (
4
), the picture changes qualitatively. TAM replaces the
maximum competitor, governed by extreme-value fluctuations, by the
average of the largest
k=\lceil r(n-1)\rceil
competing scores. This
upper-tail average is no longer controlled by a single maximum when
the tail fraction
r
is fixed, and hence removes the bottleneck
responsible for the logarithmic factor in top-1 retrieval, while still
certifying that the correct target lies in a controlled top-
k

candidate list. The natural model-size scale for TAM is therefore

d^{2}\asymp n.

(7)

We learn the memory matrix for this criterion through empirical risk
minimization. With logistic loss
\ell(t)=\log(1+e^{-t})
, ridge parameter

\lambda\geq 0
, and the TAM functional
\TAM_{r}
, the estimator is

\widehat{W}\in\argmin_{W\in\mathbb{R}^{d\times d}}\left\{\frac{1}{n}\sum_{i=1}^{n}\ell\left(s_{i,i}(W)-\TAM_{r}\bigl((s_{j,i}(W))_{j\neq i}\bigr)\right)+\frac{\lambda}{2d^{2}}\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}^{2}\right\}.

(8)

Section
3
gives the precise convex formulation of this
objective. The main goal of the TAM theory is to understand the
asymptotic behavior of this ERM in the regime

n,d\to\infty,\qquad\frac{n}{d^{2}}\to\alpha\in(0,\infty),\qquad r\in(0,1)\ \text{fixed}.

(9)

Conditional on the six postulates stated in Section
4
,
our main asymptotic conclusions are as follows:

1.

Scalar reduction.
The high-dimensional ERM admits a scalar variational
description involving only two parameters, stated in Result
2
and
justified in Section
4.4
;

2.

Score and margin laws.
The scalar description gives limiting predictions for the
fitting loss, the laws of the true and competing scores, and the
induced margin and percentile profiles, developed in
Section
4
and Section
5
;

3.

Ridgeless phase transition.
In the ridgeless limit, the scalar theory yields a sharp phase
transition at a critical load

\alpha_{c}(r)=\frac{1}{(1+\kappa_{r}^{2})\Phi(\kappa_{r})+\kappa_{r}\varphi(\kappa_{r})},\qquad\kappa_{r}=\frac{\varphi(\Phi^{-1}(1-r))}{r},

(10)

where
\varphi
and
\Phi
denote the standard normal density and
distribution function. When the load
\alpha<\alpha_{c}(r)
, the scalar TAM loss vanishes in the
ridgeless limit; for
\alpha>\alpha_{c}(r)
, the limiting loss remains
positive.

4.

Small-tail top-1 conjecture.
Since TAM with
r=1/(n-1)
is exactly top-1
retrieval, the fixed-tail formula also suggests a tantalizing
small-tail extrapolation back to the top-1 problem. Formally
sending
r
to
1/(n-1)
in the critical-load formula in
(
10
) predicts the exact leading constant
in the top-1 retrieval threshold:

\frac{d^{2}}{n\log n}=2,

(11)

meaning that top-1 retrieval should be feasible when
d^{2}\geq(2+\epsilon)n\log n
and infeasible when

d^{2}\leq(2-\epsilon)n\log n
. We state this prediction separately as a
conjecture in Section
5.4
and give numerical support
there. The same constant is also consistent with a conjecture made
in the concurrent work of
23
using a
simplified decoupled model; see the discussion in
Section
1.2
.

The main technical approach in our work is a leave-one-out analysis. These
methods are central to precise asymptotics for high-dimensional

M
-estimators
(
13
;
37
)
, but
the present problem has a different geometry. The decision variable

W
is a high-dimensional matrix rather than a vector; the effective
features are rank-one tensors
u_{j}v_{i}^{\top}
rather than independent
covariate vectors; and each stored pair appears in two coupled roles,
as its own signal and as a competitor for many other queries.
Consequently, removing one pair changes not only one summand of the
loss, but also the competitor tails, threshold variables, and Hessian
coefficients seen throughout the objective. The leave-one-out analysis
developed in Section
4
isolates the resulting rank-one
perturbation structure, a mechanism that may be useful for other
matrix-valued ERMs with shared random features and endogenous listwise
weights. Establishing the postulates in Sections
4.2

and
4.3
rigorously is the main remaining step
toward a fully unconditional theorem for the TAM optimizer.

1.2
Related Work

Neural associative memory.

Associative memory dates back to
early neural models that store patterns through correlations in the
weights
(
2
;
3
;
44
;
34
;
28
;
29
)
.
The Hopfield network
(
28
)
is the symmetric case,
where the goal is to memorize and retrieve the patterns themselves.
We focus instead on associative recall: a key should retrieve its
paired target, and the two need not coincide
(
2
)
.
In particular,

34
define correlation matrix memory as
a sum of rank-one key-target outer products, the construction analyzed
in Section
2.1
. Bidirectional associative memory
is another paired-pattern model based on outer-product updates

(
35
)
.

Modern versions of neural networks with built-in associative memory capabilities include the neural Turing machine
(
24
)
, memory networks
(
52
)
, dense associative memory
(
36
;
38
)
, MCHN
(
46
)
, MCSDM
(
31
;
7
)
, and universal Hopfield networks
(
43
)
. Binary variants of matrix memory have also been studied in the literature
(
53
;
19
;
27
)
.

Transformers and factual recall.

Transformer models
trained on factual recall tasks have been empirically observed to
implement associative memory through their weight matrices. Feedforward as well as attention layers have been shown to behave like
key-value memories
(
22
;
6
)
,
and linear-memory viewpoints have been used to study factual editing,
induction head tasks, and latent space retrieval

(
40
;
6
;
30
)
.
On the theory side,
45
study a
sequence-based factual recall task where one token functions as the
key, and show that a one-layer transformer solves the task with capacity scaling linearly with parameter count, up to logarithmic factors. This storage scaling has also been empirically observed in large language models
(
1
)
. Related theoretical analyses include optimization dynamics for
a single-layer transformer on a token recall task
(
51
)
,
and a measure-theoretic formulation of transformers with implicit associative
memory mechanisms

(
32
)
.

Storage capacity.

45
study the capacity of linear and MLP
associative memories with random spherical embeddings, showing in
particular that correlation matrix memory succeeds when

d^{2}\gtrsim n(\log n)^{4}
.
8
propose the
exact retrieval criterion and study correlation matrix memory under a
weighted data distribution. From an optimization perspective,
9
study gradient descent under a multiclass logistic formulation, and
33
compare the capacity of memory matrices obtained by different optimizers under Gaussian embeddings. Compared with these works, our top-1 result
identifies the exact statistical logarithmic barrier
d^{2}\asymp n\log n
for arbitrary linear memories. We
also introduce the TAM criterion and, to our knowledge, give the first
capacity theory for linear associative memory under a listwise
retrieval rule.

We also briefly mention that storage capacity has been studied in detail for the Hopfield network and its variants. The capacity
d\asymp n
of Hopfield networks is classical, see e.g.,
39
;
18
and the works cited within, while modern extensions such as dense associative memory have been shown to achieve exponential capacity
(
12
;
46
;
38
)
. The scaling in these works differ from our results since we decode to a fixed vocabulary of size
n
, while the classical Hopfield formulation decodes to the hypercube.

Concurrent work.

Concurrently with this work,
23

independently studied
the capacity of linear associative memory under the top-1 retrieval
criterion through a decoupled model. In this simplified formulation,
the output embeddings
\{u_{j}\}_{j\leq n}
are resampled across
constraints, thus removing the statistical dependence structure among
the retrieval inequalities in (
2
). Based on numerical
evidence comparing training and test errors, and score distributions, they conjecture that
the original and decoupled problems have the same critical capacity.
For the decoupled model, they carry out a Gardner-type statistical
physics calculation and predict the critical threshold

\frac{n\log n}{d^{2}}=\frac{1}{2}
for top-1 retrieval. This provides
independent support for the small-tail extrapolation of our TAM theory
in Section
5
. They further extend both the
decoupling conjecture and the capacity calculation to rank-constrained
memories, corresponding to two-layer linear MLPs.

Classification and leave-one-out methods.

The TAM learning problem is also connected to high-dimensional
classification through its logistic loss. The classical work of

11
computed the separability capacity of
random patterns, and the perceptron capacity was later studied through
statistical physics methods, including margin-constrained variants

(
20
)
. In ordinary unregularized logistic
regression, the existence of the maximum likelihood estimator is
equivalent to nonseparability of the labeled data; equivalently, the
failure of existence is a linear separability, or capacity, event.

49
established a high-dimensional phase transition
for this event under Gaussian covariates. A broader line of work in
statistical physics
studies optimal errors and phase transitions in high-dimensional
generalized linear models via the approximate message passing algorithm

(
5
;
4
;
42
)
.
From a technical point of view, our TAM analysis uses a leave-one-out approach, which has played an important role in precise asymptotics for high-dimensional
M
-estimators

(
13
;
14
;
37
)
.
At a conceptual level, this is also the cavity method from spin glass theory
(
41
)
.

The present problem differs from standard high-dimensional regression
and classification in several ways. The unknown is a matrix rather
than a vector; the effective covariates are rank-one tensors

u_{j}v_{i}^{\top}
with strong dependencies; each sample
contributes both a signal score and a full column of competitor
scores; and the TAM threshold is endogenous, selected by the learned
scores themselves. These couplings prevent existing leave-one-out
theories from applying as black boxes; the resulting cavity
calculation is matrix-valued, listwise, and self-consistent in a way
that does not arise in standard high-dimensional regression.

2
Top-1 retrieval and the logarithmic barrier

Throughout this section, we work under the Gaussian model (
5
) and
the top-1 retrieval criterion (
2
) of Section
1
. For a weight matrix

W\in\mathbb{R}^{d\times d}
, define the top-1 retrieval event

\mathsf{PR}_{n}(W)\coloneqq\bigcap_{i=1}^{n}\left\{u_{i}^{\top}Wv_{i}>u_{j}^{\top}Wv_{i}\ \text{for all }j\neq i\right\},

(15)

and write

\mathsf{PR}_{n}\coloneqq\left\{(U,V)\mathrel{\mathop{\ordinarycolon}}\exists\,W\in\mathbb{R}^{d\times d}\ \text{such that}\ \mathsf{PR}_{n}(W)\ \text{holds}\right\}.

(16)

The event
\mathsf{PR}_{n}
asks whether the observed random instance admits some
matrix
W
satisfying all top-1 retrieval inequalities simultaneously. This is
a pointwise feasibility statement for the realized data: the matrix
W
may
depend arbitrarily on the full instance
(U,V)
.
The main result of this section shows that this event has a logarithmic
model-size threshold.

Theorem 1

(Top-1 retrieval threshold)
.

There exist absolute constants
\varrho_{1}>\varrho_{2}>0
such that, along any sequence
n,d\to\infty
:

(i)

(Achievability.) If
d^{2}\geq\varrho_{1}\,n\log n
, then

\mathbb{P}(\mathsf{PR}_{n})\to 1
.

(ii)

(Impossibility.) If
d^{2}\leq\varrho_{2}\,n\log n
, then

\mathbb{P}(\mathsf{PR}_{n})\to 0
.

In particular, we may take any
\varrho_{1}>8
and
\varrho_{2}<2/\pi
.

The two halves of Theorem
1
are established by essentially independent
arguments. In Section
2.1
, we prove the achievability direction
by a direct analysis of the correlation matrix memory construction, and show
that this construction exhibits a sharp phase transition around

\varrho_{1}=8
. In
Section
2.2
, we prove the impossibility direction for all memories
W\in\mathbb{R}^{d\times d}
, by contrasting the average scale of the target scores
\tr(S)
against the lower bound implied by a uniform anticoncentration of the off-diagonal elements in (
2
).

2.1
Achievability via correlation matrix memory

Recall the Gaussian model (
5
), and write

U=[u_{1}\;\cdots\;u_{n}]
and
V=[v_{1}\;\cdots\;v_{n}]
. Consider the memory

W^{\times}\coloneqq UV^{\top}=\sum_{i=1}^{n}u_{i}v_{i}^{\top},

(17)

obtained by summing the rank-one outer products of the stored pairs.
This solution is known as
correlation matrix memory

(
34
)
and is the direct analogue of the
classical self-organizing network
(
2
)
for asymmetric key and target pairs. It is also easy to update, requiring only a local (rank-one) correction upon the addition or deletion of an association, and thus can be seen as a form of Hebbian learning
(
26
)
.

Clearly,
W^{\times}
enables top-1 retrieval if the (un)embeddings are mutually orthogonal, which requires dimensionality to scale as
d\geq n
. However,
W^{\times}
can also store associations much more efficiently by storing them non-orthogonally, i.e., in
superposition

(
15
)
. Indeed,
45
showed that
W^{\times}
achieves top-1 retrieval with high probability when
d^{2}\geq Cn\,(\log n)^{4}
for a sufficiently large constant
C
.

Here we sharpen this polylogarithmic sufficient condition by determining the
exact threshold for correlation matrix memory. In the regime

d^{2}\asymp n\log n
, the retrieval probability

\mathbb{P}(\mathsf{PR}_{n}(W^{\times}))
has a sharp phase transition at the constant

8
.

Proposition 1

(Retrieval threshold for correlation matrix memory)
.

Consider the limiting regime

\displaystyle n,d\to\infty,\quad\frac{d^{2}}{n\log n}\to\varrho

(18)

for some constant
\varrho\in[0,\infty]
. Then it holds that

\lim_{d\to\infty}\mathbb{P}(\mathsf{PR}_{n}(W^{\times}))=\begin{cases}1&\text{if}\quad\varrho>8,\\
0&\text{if}\quad\varrho<8.\end{cases}

(19)

Proof.

See Appendix
A.3
.
∎

Since
\mathsf{PR}_{n}(W^{\times})\subseteq\mathsf{PR}_{n}
, the case

\varrho>8
immediately establishes
Theorem
1
(i)
. We give an overview of the proof
strategy below.

Reduction to a single coordinate.

Under (
17
), the score matrix becomes

S=U^{\top}UV^{\top}V
with
s_{j,i}=u_{j}^{\top}W^{\times}v_{i}
.
Define the per-coordinate
retrieval failure event

F_{i}=\left\{s_{i,i}\leq\max_{j\neq i}s_{j,i}\right\},\qquad i\in[n]

(20)

so that
\mathsf{PR}_{n}(W^{\times})=\bigcap_{i=1}^{n}F_{i}^{c}
.
Because the joint distribution of
(U,V)
is invariant under simultaneous
permutations of the columns of
U
and
V
, the events
F_{1},\ldots,F_{n}
are

exchangeable
; in particular,
\mathbb{P}(F_{i})=\mathbb{P}(F_{1})
for every
i
. A union bound yields the lower estimate

\mathbb{P}(\mathsf{PR}_{n}(W^{\times}))\;\geq\;1-n\mathbb{P}(F_{1}),

(21)

and in fact this is nearly tight as the events
F_{i}
are only weakly dependent (Lemma
8
). This reduces the behavior of
\mathbb{P}(\mathsf{PR}_{n}(W^{\times}))
to that of the single failure probability
\mathbb{P}(F_{1})
.

A single-coordinate law and extreme values.

The probability
\mathbb{P}(F_{1})
is determined by the first column of the score
matrix. Write

\theta\mathrel{\mathop{\ordinarycolon}}=s_{1,1},\qquad\xi_{j}\mathrel{\mathop{\ordinarycolon}}=s_{j,1},\quad 2\leq j\leq n.

(22)

Appendix
A.1
gives an exact distributional
representation for
(\theta,\xi_{2},\ldots,\xi_{n})
. Its content is simple:
up to chi-distributed normalization factors that concentrate at one (as
n,d\to\infty
), the
signal
\theta
has mean one and Gaussian fluctuations at scale
\sqrt{n/d^{2}}
,
while the competitors
\left\{\xi_{j}\mathrel{\mathop{\ordinarycolon}}2\leq j\leq n\right\}
are approximately independent centered Gaussians at
the same scale. Thus, if
\alpha_{n}\coloneqq n/d^{2}
, the leading-order picture is

\theta\,\approx\,1+\sqrt{\alpha_{n}}\,Z_{0},\qquad\xi_{j}\,\approx\,\sqrt{\alpha_{n}}\,Y_{j},\qquad\text{where}\quad Z_{0},Y_{1},\ldots,Y_{n-1}\overset{\text{i.i.d.}}{\sim}\mathcal{N}(0,1).

(23)

The signal
\theta
and each competitor
\xi_{j}
therefore have the same
fluctuation scale, while the signal has deterministic offset
1
. Thus, the

2.2
A universal upper bound for top-1 retrieval

The lower side of Proposition

rules out

below its
sharp logarithmic threshold. It leaves open whether a more clever

part
(ii)
of Theorem

Section

Theorem 2

(Universal top-1 impossibility bound)
.

Fix any

1

As the proof is short but nontrivial, we present the full argument

can be rewritten in two ways:

We first establish some anticoncentration and concentration lemmas. Without loss of generality, we may suppose

For any fixed

.
∎

Lemma 2

If

are Gaussian, for any fixed

Proof.

We proceed to prove Theorem
2
. Suppose (

) is true for some weight matrix

, (

) implies that
u_{i}^{\top}x_{i}=\max_{j\in[n]}u_{j}^{\top}x_{i}
for all

x_{i}/\mathinner{\!\left\lVert x_{i}\right\rVert}

\displaystyle u_{i}^{\top}Wv_{i}=u_{i}^{\top}x_{i}=\max_{j\in[n]}u_{j}^{\top}x_{i}\geq\sqrt{\frac{(2-\epsilon)\log d}{d}}\mathinner{\!\left\lVert x_{i}\right\rVert}

(29)

We further lower bound the right-hand side in terms of
\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}

\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}^{2}=\sum_{k=1}^{d}s_{k}^{2}

\displaystyle Wv_{i}=\sum_{k=1}^{d}s_{k}(b_{k}^{\top}v_{i})a_{k},\quad\mathinner{\!\left\lVert Wv_{i}\right\rVert}=\left(\sum_{k=1}^{d}s_{k}^{2}(b_{k}^{\top}v_{i})^{2}\right)^{1/2}.

\displaystyle\sum_{k=1}^{d}s_{k}^{2}|b_{k}^{\top}v_{i}|\leq\left(\sum_{k=1}^{d}s_{k}^{2}\right)^{1/2}\left(\sum_{k=1}^{d}s_{k}^{2}(b_{k}^{\top}v_{i})^{2}\right)^{1/2}=\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}\mathinner{\!\left\lVert Wv_{i}\right\rVert}.

Dividing both sides by

and summing over

\displaystyle\sum_{i=1}^{n}\mathinner{\!\left\lVert Wv_{i}\right\rVert}

\displaystyle\sum_{i=1}^{n}u_{i}^{\top}Wv_{i}\geq\frac{2-\epsilon}{\sqrt{\pi}}\,\frac{n\sqrt{\log d}}{d}\,\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}.

On the other hand, by the standard cross-term concentration estimate
recorded as Lemma

\displaystyle\sum_{i=1}^{n}u_{i}^{\top}Wv_{i}=\langle W,UV^{\top}\rangle_{\mathsf{F}}\leq(1+\epsilon)\sqrt{n}\,\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}.

Comparing the two bounds, we have thus proved that

\displaystyle(1+\epsilon)\sqrt{n}\geq\frac{2-\epsilon}{\sqrt{\pi}}\,\frac{n\sqrt{\log d}}{d}\quad\implies\quad n\leq\left(\frac{1+\epsilon}{2-\epsilon}\right)^{2}\frac{\pi d^{2}}{\log d},

3
Listwise retrieval and the Tail-Average Margin

Top-1 retrieval is a winner-take-all criterion: each query must identify
a unique target in a single step. This is natural for final decoding, but
many memory modules are used as intermediate stages. They surface a set
of plausible associations, or form a mixture of high-scoring memories,
which later computation can refine. In this setting, successful retrieval
need not mean that the correct target is already ranked first. It is
enough that the correct association remains salient among the strongest
competitors. This leads to a listwise notion of retrieval, which is the
focus of this section.

A direct listwise requirement would ask the signal score to beat a high
competitor quantile, thereby ensuring that the correct target belongs
to a controlled candidate set. This rank condition is natural, but it
is non-convex and combinatorial. We therefore use a convex certificate:
we ask the signal score to beat the
average
of the strongest
competitors. We call the resulting functional the
Tail-Average
Margin
(TAM). TAM is a listwise retrieval criterion in its own right:
it controls the mass of strong distractors rather than only the single
largest one, while retaining enough convex structure for optimization
and asymptotic analysis.

In this section we define the TAM functional, record its basic
properties, and formulate the corresponding learning problem and
performance criteria for linear associative memory. In the next
section, we derive an asymptotic theory of TAM learning in the
quadratic regime
d^{2}\asymp n
, with a fixed tail fraction

k/(n-1)\to r\in(0,1)
.

3.1
The Tail-Average Margin functional

Let
x=(x_{1},\ldots,x_{m})\in\mathbb{R}^{m}
and fix a tail fraction

r\in(0,1]
. Set
k\coloneqq\lceil rm\rceil
.

Definition 1

(Tail-Average Margin)
.

The
Tail-Average Margin
(TAM) at level
r
is

\TAM_{r}(x)\coloneqq\frac{1}{k}\sum_{j=1}^{k}x_{(j)},

(30)

where
x_{(1)}\geq x_{(2)}\geq\cdots\geq x_{(m)}
are the order
statistics of
x
.

We note two boundary cases:

\TAM_{1/m}(x)=\max_{j}x_{j}
(take
k=1
), and

\TAM_{1}(x)=\tfrac{1}{m}\sum_{j}x_{j}
(take
k=m
). For fixed

r\in(0,1)
, TAM then interpolates strictly between the maximum and
the mean by averaging over the top
r
-fraction of entries.

The TAM criterion is a conservative certificate for top-
k
list
retrieval. Indeed, since

\TAM_{r}(x)=\frac{1}{k}\sum_{j=1}^{k}x_{(j)}\geq x_{(k)},

(31)

the inequality
s_{i,i}>\TAM_{r}((s_{j,i})_{j\neq i})
implies

s_{i,i}>s_{(k),i}
for the ordered competitor scores in column

i
. Hence at most
k-1
competitors can outrank the signal. In this
sense, exact top-1 retrieval implies TAM retrieval, and TAM retrieval
implies inclusion of the correct item in the top-
k
candidate list.

The TAM functional is essentially a reparametrization of the empirical

Conditional Value-at-Risk
(CVaR) studied extensively in the
quantitative risk literature; see e.g.,
47
.
A classical observation is that TAM admits a
convex variational representation,

\TAM_{r}(x)\;=\;\min_{\mu\in\mathbb{R}}\Bigg\{\mu+\frac{1}{k}\sum_{j=1}^{m}(x_{j}-\mu)_{+}\Bigg\},

(32)

where
(x)_{+}=\max\left\{x,0\right\}
is the hinge function.
The minimizer
\mu^{\star}=x_{(k)}
of (
32
) is the empirical

(1-r)
-quantile of
x
, also known as the
Value-at-Risk
. The
optimal value of (
32
) is then the mean of the
exceedances of
x
above this quantile, which recovers the tail-average
interpretation of (
30
). As an immediate consequence of
(
32
), we see that
x\mapsto\TAM_{r}(x)
is convex on
\mathbb{R}^{m}
, as it is the pointwise minimum over
\mu
of functions jointly convex in
(x,\mu)
.

For optimization it is convenient to replace the piecewise-linear
hinge
(\cdot)_{+}
in (
32
) with a differentiable
surrogate. For a smoothing parameter
\beta>0
, let

\phi_{\beta}(t)\;\coloneqq\;\frac{1}{\beta}\log(1+e^{\beta t})

(33)

denote the softplus function, and define the
smoothed
TAM

\TAM_{r,\beta}(x)\;\coloneqq\;\min_{\mu\in\mathbb{R}}\Bigg\{\mu+\frac{1}{k}\sum_{j=1}^{m}\phi_{\beta}(x_{j}-\mu)\Bigg\}.

(34)

Since
\phi_{\beta}
is convex,
\TAM_{r,\beta}
is convex in
x
;
moreover
\phi_{\beta}(t)\to(t)_{+}
pointwise as
\beta\to\infty
,
and hence
\TAM_{r,\beta}(x)\to\TAM_{r}(x)
in the same limit. The
exact TAM is recovered in the limiting notation
\TAM_{r,\infty}=\TAM_{r}
.

Throughout the remainder of the paper we specialize TAM to the
linear associative memory setting: the collection

x_{1},\ldots,x_{m}
is taken to be the competing scores

(s_{j,i})_{j\neq i}
associated with a query
v_{i}
, so that

m=n-1
and
\TAM_{r}
quantifies the strength of the top
r
-fraction
of competitors. The next subsection turns this into a convex learning
objective.

3.2
Learning under the TAM criterion

With the TAM functional in hand, we now formulate retrieval and
learning for the linear associative memory as a convex optimization
problem.

Given stored pairs
\{(u_{i},v_{i})\}_{i=1}^{n}\subset\mathbb{R}^{d}\times\mathbb{R}^{d}
and a memory or weight matrix

W\in\mathbb{R}^{d\times d}
, recall that the score matrix
is
s_{j,i}=u_{j}^{\top}Wv_{i}
. Fix a tail fraction
r\in(0,1)
and set

k=\lceil r(n-1)\rceil
. The
TAM retrieval criterion
asks
that each signal score exceed the TAM-aggregate of its competitors:

s_{i,i}\;>\;\TAM_{r}((s_{j,i})_{j\neq i}),\qquad\forall\,i\in[n].

(35)

For
r=1/(n-1)
, (
35
) reduces to the exact top-1
criterion (
2
) studied in Section
2
; for fixed

r\in(0,1)
, it imposes an upper-tail margin requirement that
controls the mass of strong competitors rather than a single
extreme-value outlier.

Rather than demanding strict satisfaction of (
35
),
we minimize a convex surrogate that penalizes violations softly. Let

\ell(t)\;\coloneqq\;\log(1+e^{-t})

(36)

denote the logistic loss, and let
\beta>0
be the smoothing
parameter of
\TAM_{r,\beta}
. We
consider the regularized objective

\min_{W\in\mathbb{R}^{d\times d}}\Bigg\{\sum_{i=1}^{n}\ell\bigl(s_{i,i}-\TAM_{r,\beta}((s_{j,i})_{j\neq i})\bigr)+\frac{\lambda n}{2d^{2}}\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}^{2}\Bigg\},

(37)

where
\lambda\geq 0
is a ridge penalty. Since each score

s_{j,i}
is linear in
W
and
\TAM_{r,\beta}
is convex, the
margin
s_{i,i}-\TAM_{r,\beta}((s_{j,i})_{j\neq i})
is concave in
W
; composing
with the decreasing convex
\ell
yields a convex function of
W
, so (
37
) is a convex program (strongly
convex whenever
\lambda>0
).

The variational representation (
34
) of
\TAM_{r,\beta}

suggests lifting (
37
) to a joint optimization over

W
and the auxiliary quantile variables

\mu=(\mu_{1},\ldots,\mu_{n})\in\mathbb{R}^{n}
. Substituting (
34
)
into (
37
) yields

\min_{W,\mu}\Bigg\{\sum_{i=1}^{n}\ell\biggl(s_{i,i}-\mu_{i}-\frac{1}{k}\sum_{j\neq i}\phi_{\beta}(s_{j,i}-\mu_{i})\biggr)+\frac{\lambda n}{2d^{2}}\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}^{2}\Bigg\},

(38)

Minimizing (
38
) over
\mu
at fixed
W

recovers (
37
). This is the workhorse formulation
for the leave-one-out analysis of Section
4
.

Remark 1

(Gaussian heuristic for the quadratic scale)
.

The asymptotic distinction between the exact maximum and
\TAM_{r}
can be made
precise under a Gaussian toy model. Suppose the competitor scores

(s_{j,i})_{j\neq i}
were i.i.d.
\mathcal{N}(0,\sigma^{2})
with

\sigma=\Theta(\sqrt{n}/d)
. Then the maximum would concentrate at

\sigma\sqrt{2\log n}
, while
\TAM_{r}
at fixed
r\in(0,1)

would concentrate at
\sigma\cdot\kappa_{r}
with

\kappa_{r}=\mathbb{E}[Z\mid Z\geq\Phi^{-1}(1-r)]=\frac{\varphi(\Phi^{-1}(1-r))}{r},\qquad Z\sim\mathcal{N}(0,1),

(39)

depending only on
r
. Comparing either scale with the
O(1)
signal
strength locates the heuristic retrieval threshold at

d^{2}\asymp n\log n
in the first case—consistent with
Theorem
1
—and
d^{2}\asymp n
in the second.

In this model, the Gaussianity and scale of the competitor scores are not assumed
a priori; they are asymptotically
exact
under the correlation matrix memory solution
of Section
2.1
. The proof of Lemma
9
shows that, in
the regime
n/d^{2}\to\alpha
, the competitor scores are (approximately)
i.i.d.
\mathcal{N}(0,\alpha)
. For the TAM-optimal weight matrix

\widehat{W}
defined below, the same Gaussian structure emerges
asymptotically as an output of the leave-one-out analysis of
Section
4
; in that case the Gaussian variance is no longer
explicit a priori, but is determined self-consistently by the scalar
fixed point equations. In both cases the heuristic above is borne out
by the theory.

It is useful to compare (
37
) with the canonical
convex surrogate for the top-1 retrieval criterion (
2
),
namely the regularized multiclass softmax cross-entropy:

\min_{W\in\mathbb{R}^{d\times d}}\sum_{i=1}^{n}\left[-\,s_{i,i}+\log\sum_{j=1}^{n}e^{s_{j,i}}\right]+\frac{\lambda n}{2d^{2}}\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}^{2}.

(40)

Denote the log-sum-exp aggregate of the competitor scores by

\mathrm{LSE}((s_{j,i})_{j\neq i})\coloneqq\log\sum_{j\neq i}e^{s_{j,i}}
.
A short calculation rewrites each summand in (
40
) as

-\,s_{i,i}+\log\sum_{j=1}^{n}e^{s_{j,i}}\;=\;\ell\Bigl(s_{i,i}-\mathrm{LSE}\bigl((s_{j,i})_{j\neq i}\bigr)\Bigr),

(41)

with the same logistic loss
\ell
used in (
37
). In
this form, (
40
) has precisely the same structure as the TAM
objective (
37
): a logistic loss applied to the
margin between the signal score
s_{i,i}
and a convex aggregate of
the competitor scores
(s_{j,i})_{j\neq i}
. They differ only in the
choice of aggregate. The log-sum-exp is a smoothed maximum, with

\mathrm{LSE}((s_{j,i})_{j\neq i})=\max_{j\neq i}s_{j,i}+O(\log n)
, and therefore inherits the
\sqrt{2\log n}

extreme-value statistics of the top-1 criterion. Replacing it with
the tail average
\TAM_{r,\beta}
, whose fluctuations are
O(\sigma)

(Remark
1
), enables retrieval at the
quadratic model-size scale
d^{2}\asymp n
instead of
d^{2}\asymp n\log n
.

3.3
Performance metrics

With the TAM learning problem in place, we consider three
asymptotic quantities that together characterize retrieval
performance: the empirical average fitting loss, the per-sample TAM
margin, and the distribution of signal percentiles. Throughout this
subsection,
(\widehat{W},\widehat{\mu})
denotes the unique minimizer of
(
38
), with corresponding scores

\widehat{s}_{j,i}=u_{j}^{\top}\widehat{W}v_{i}
.

Empirical average fitting loss.

Let

L_{n}(W,\mu)\;\coloneqq\;\frac{1}{n}\sum_{i=1}^{n}\ell\left(s_{i,i}-\mu_{i}-\frac{1}{k}\sum_{j\neq i}\phi_{\beta}(s_{j,i}-\mu_{i})\right)

(42)

denote the normalized data-fitting part of
(
38
), and write

\widehat{L}_{n}\coloneqq L_{n}(\widehat{W},\widehat{\mu})
for its value at the
optimizer. We will say that the TAM problem is
asymptotically
fit at load

\alpha
if
\widehat{L}_{n}\to 0
in probability as

n,d\to\infty
with
n/d^{2}\to\alpha
and
\lambda\to 0
.
Since
\ell
is nonnegative and vanishes
only in the large-margin limit, asymptotic fit is equivalent to the
TAM retrieval criterion (
35
) holding with a
positive margin for all but a vanishing fraction of keys.

TAM margin distribution.

A finer summary than
\widehat{L}_{n}
is the empirical distribution of
the per-sample TAM margins

\widehat{m}_{i}\;\coloneqq\;\widehat{s}_{i,i}-\widehat{\mu}_{i}-\frac{1}{k}\sum_{j\neq i}\phi_{\beta}(\widehat{s}_{j,i}-\widehat{\mu}_{i}),\qquad i\in[n],

which are precisely the arguments of the logistic loss appearing in

\widehat{L}_{n}
. A positively-supported limiting distribution for
\widehat{m}_{i}

indicates asymptotic fit; its shape shows how comfortably the
signal beats the tail average.

Signal percentile distribution.

As a complementary, rank-based summary, we also ask, for each sample,
what fraction of competitors have score below the signal.
Formally, define the
signal percentile

\Omega_{i}\;\coloneqq\;\frac{1}{n-1}\sum_{j\neq i}\mathbf{1}\{\widehat{s}_{j,i}\leq\widehat{s}_{i,i}\},\qquad i\in[n],

so that
\Omega_{i}
close to
1
signals that the
i
th signal
dominates nearly all of its competitors and
\Omega_{i}=0
that
every competitor beats it. The random probability measure

\nu_{n}\;\coloneqq\;\frac{1}{n}\sum_{i=1}^{n}\delta_{\Omega_{i}}

(43)

on
[0,1]
is our object of study: when does
\nu_{n}
converge in
probability (say, in Wasserstein-
1
) to a deterministic limit?

The next section develops a leave-one-out theory for these three
observables under the TAM optimizer in the quadratic regime

n/d^{2}\to\alpha
with fixed
r\in(0,1)
.

Benchmark: correlation matrix memory.

We close this section with a benchmark calculation. For the
non-optimized correlation matrix memory
W^{\times}
of
Section
2.1
, the percentile law can be computed explicitly.
In the regime
n,d\to\infty
with
n/d^{2}\to\alpha\in(0,\infty)
,
the single-coordinate law, Lemma
3
in
Appendix
A.1
, says that the signal score is
asymptotically Gaussian with mean
1
and variance
\alpha
, while a
typical competitor score is asymptotically Gaussian with mean
0
and
the same variance. Thus the signal is shifted above the competitor
cloud by signal-to-noise ratio
\alpha^{-1/2}
. Writing
\Phi
for the
standard normal CDF, the limiting percentile has the form

\Phi(G+\alpha^{-1/2})
, where
G\sim\mathcal{N}(0,1)
. Equivalently, its CDF is

F_{\alpha}(\omega)\;\coloneqq\;\Phi\!\left(\Phi^{-1}(\omega)-\alpha^{-1/2}\right),\qquad\omega\in(0,1),

(44)

with density
f_{\alpha}(\omega)=\exp(\Phi^{-1}(\omega)/\sqrt{\alpha}-1/(2\alpha))
. The parameter
\alpha^{-1/2}
plays the role of a
signal-to-noise ratio: the law concentrates at
1
as
\alpha\to 0

and tends to
\mathrm{Unif}(0,1)
as
\alpha\to\infty
. Appendix

A.4
upgrades this one-coordinate heuristic
to a law of large numbers for the empirical percentile distribution.

4
Asymptotic theory of TAM

We now study the TAM optimizer in the quadratic regime
n,d\to\infty

with
n/d^{2}\to\alpha
and
k/n\to r\in(0,1)
. Throughout this section
the smoothing parameter
\beta<\infty
and ridge parameter
\lambda>0

are fixed. The goal is to predict the empirical laws of the true scores

s_{i,i}(\widehat{W})
and competitor scores
s_{j,i}(\widehat{W})
, and hence the
limiting TAM loss, margin distribution, and signal-percentile profile
introduced in Section
3.3
.

The main technique is a leave-one-out (LOO) analysis. We compare the TAM
optimizer with the optimizer obtained after removing a held-out pair

(u_{h},v_{h})
, and use this comparison to separate the fresh randomness
of the held-out sample from the remaining problem. The results in this
section are conditional on six postulates stated below. The first three
are leave-one-out stability assumptions, used to justify the rank-one
LOO reduction. The last three are spectral and self-averaging inputs,
used to close the scalar equations. Under these postulates, the
high-dimensional TAM optimizer is described by a two-parameter scalar
variational problem, stated in Result
2
.

The section is organized as follows. We first compute the gradient and
Hessian of the smoothed TAM loss. We then formulate the LOO rank-one
reduction, state the scalar variational prediction, and finally derive
the finite-dimensional equations that lead to this prediction. The
ridgeless limit
\lambda\downarrow 0
and the associated phase transition
are deferred to Section
5
.

4.1
Gradient and Hessian of the TAM loss

Throughout this section the threshold variables are unregularized, and we work with the joint TAM objective of (
38
), written with the reparameterized ridge:

\Psi(W,\mu)=\sum_{i=1}^{n}\ell\Big(s_{i,i}(W)-\mu_{i}-\frac{1}{k}\sum_{j\neq i}\phi_{\beta}\!\bigl(s_{j,i}(W)-\mu_{i}\bigr)\Big)+\frac{\lambda n}{2d^{2}}\,\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}^{2},

(45)

where
s(W)=U^{\top}WV\in\mathbb{R}^{n\times n}
, with entries

s_{j,i}(W)=u_{j}^{\top}Wv_{i}
, and
U=[u_{1}\;\cdots\;u_{n}]
,

V=[v_{1}\;\cdots\;v_{n}]
are the data matrices from the Gaussian
model (
5
). We use lowercase
s_{j,i}
for
finite-dimensional scores, reserving uppercase
S
for scalar limiting
random variables. When the underlying matrix is clear from context, we
write
s_{j,i}
instead of
s_{j,i}(W)
; in particular, at the full
optimizer this means
s_{j,i}=s_{j,i}(\widehat{W})
. Since
\Psi
depends on

W
only through
s(W)
, the chain rule reduces the computation of

\nabla_{W}\Psi
to an
n\times n
matrix of score derivatives,

\nabla_{W}\Psi\;=\;U\,G\,V^{\top}\;+\;\frac{\lambda n}{d^{2}}\,W,\qquad G_{j,i}\mathrel{\mathop{\ordinarycolon}}=\frac{\partial\Psi}{\partial s_{j,i}}.

(46)

The remainder of this subsection evaluates the entries of
G
and rewrites
\nabla_{W}\Psi
in a form convenient for the leave-one-out analysis in Section
4.2
.

The
i
-th summand of
\Psi
equals
\ell(m_{i})
, where the
TAM aggregate
and
margin
associated with sample
i
are

c_{i}\mathrel{\mathop{\ordinarycolon}}=\mu_{i}+\frac{1}{k}\sum_{j\neq i}\phi_{\beta}\!\big(s_{j,i}-\mu_{i}\big),\qquad m_{i}\mathrel{\mathop{\ordinarycolon}}=s_{i,i}-c_{i}.

(47)

The margin
m_{i}
is the only part of the
i
-th summand that depends on column
i
of the score matrix, and the
i
-th summand is the only summand that does. Differentiating
\ell(m_{i})
in
s_{j,i}
therefore yields

G_{j,i}\;=\;\ell^{\prime}(m_{i})\,\frac{\partial m_{i}}{\partial s_{j,i}}\;=\;\begin{cases}\ell^{\prime}(m_{i}),&j=i,\\[2.0pt]
-\tfrac{1}{k}\,\ell^{\prime}(m_{i})\,\phi_{\beta}^{\prime}(s_{j,i}-\mu_{i}),&j\neq i.\end{cases}

(48)

Both
\ell^{\prime}
and
\phi_{\beta}^{\prime}
are conveniently expressed through the sigmoid
\sigma(t)\mathrel{\mathop{\ordinarycolon}}=(1+e^{-t})^{-1}
:

\ell^{\prime}(t)\;=\;\sigma(t)-1\;=\;-\,\sigma(-t),\qquad\phi_{\beta}^{\prime}(t)\;=\;\sigma(\beta t).

(49)

Substituting into (
48
) gives the two scalar weights

a_{i}\;\mathrel{\mathop{\ordinarycolon}}=\;\sigma(-m_{i})\;=\;-\,\ell^{\prime}(m_{i})\;\in\;(0,1),

(50)

and, for
j\neq i
,

q_{j,i}\;\mathrel{\mathop{\ordinarycolon}}=\;\sigma\!\big(\beta\,(s_{j,i}-\mu_{i})\big)\;=\;\phi_{\beta}^{\prime}(s_{j,i}-\mu_{i})\;\in\;(0,1),\qquad j\neq i.

(51)

In these variables (
48
) becomes
G_{j,i}=-a_{i}
for
j=i
and
G_{j,i}=\tfrac{1}{k}q_{j,i}a_{i}
otherwise. Equivalently
G=Q\Lambda_{a}
, where
\Lambda_{a}\mathrel{\mathop{\ordinarycolon}}=\diag(a_{1},\dots,a_{n})
and

Q_{j,i}\;\mathrel{\mathop{\ordinarycolon}}=\;\begin{cases}-1,&j=i,\\[2.0pt]
\dfrac{1}{k}\,q_{j,i},&j\neq i.\end{cases}

(52)

Substituting
G=Q\Lambda_{a}
into (
46
) and performing the analogous calculation for
\mu
— where
\partial m_{i}/\partial\mu_{i}=-1+\tfrac{1}{k}\sum_{j\neq i}q_{j,i}=-(Q^{\top}\mathbf{1}_{n})_{i}
— yields

\nabla_{W}\Psi(W,\mu)=U\,Q\Lambda_{a}\,V^{\top}\;+\;\frac{\lambda n}{d^{2}}\,W,

(53)

\nabla_{\mu}\Psi(W,\mu)=-\Lambda_{a}\,Q^{\top}\mathbf{1}_{n},

(54)

where
\mathbf{1}_{n}\in\mathbb{R}^{n}
is the all-ones vector. Expanding (
53
) by rows of
Q
separates the diagonal and off-diagonal contributions,

\nabla_{W}\Psi\;=\;-\sum_{i=1}^{n}a_{i}\,u_{i}v_{i}^{\top}\;+\;\frac{1}{k}\sum_{i=1}^{n}a_{i}\sum_{j\neq i}q_{j,i}\,u_{j}v_{i}^{\top}\;+\;\frac{\lambda n}{d^{2}}\,W.

(55)

For the Taylor expansion in Section
4.2
we will also need the second derivative of the outer loss at the margin, which is governed by a companion diagonal:

b_{i}\;\mathrel{\mathop{\ordinarycolon}}=\;\ell^{\prime\prime}(m_{i})\;=\;a_{i}(1-a_{i}),\qquad\Lambda_{b}\mathrel{\mathop{\ordinarycolon}}=\diag(b_{1},\dots,b_{n}).

(56)

Definition 2

(Full Hessian)
.

Let
H\mathrel{\mathop{\ordinarycolon}}\mathbb{R}^{d\times d}\to\mathbb{R}^{d\times d}
denote the Hessian operator of
\Psi
in the
W
variable, evaluated at a fixed point
(W,\mu)
. Applied to a perturbation
\Delta
, it is

H[\Delta]\;\mathrel{\mathop{\ordinarycolon}}=\;\frac{\lambda n}{d^{2}}\,\Delta\;+\;U\,M\!\bigl(U^{\top}\Delta V\bigr)\,V^{\top}.

(57)

Here
M\mathrel{\mathop{\ordinarycolon}}\mathbb{R}^{n\times n}\to\mathbb{R}^{n\times n}
acts columnwise,

M(X)_{\mathrel{\mathop{\ordinarycolon}},i}\;=\;M_{i}X_{\mathrel{\mathop{\ordinarycolon}},i},

(58)

where

\displaystyle M_{i}

\displaystyle\mathrel{\mathop{\ordinarycolon}}=\;b_{i}Q_{\mathrel{\mathop{\ordinarycolon}},i}Q_{\mathrel{\mathop{\ordinarycolon}},i}^{\top}\;+\;a_{i}\diag(\widetilde{R}_{\mathrel{\mathop{\ordinarycolon}},i}),

(59)

\displaystyle\widetilde{R}_{j,i}

\displaystyle\mathrel{\mathop{\ordinarycolon}}=\;\begin{cases}\dfrac{\beta}{k}\,q_{j,i}(1-q_{j,i}),&j\neq i,\\
0,&j=i.\end{cases}

The operator
H
is self-adjoint and strictly positive-definite, with smallest eigenvalue at least
\lambda n/d^{2}
.
Under vectorization, writing
\mathcal{D}\mathrel{\mathop{\ordinarycolon}}=\diag(M_{1},\ldots,M_{n})\in\mathbb{R}^{n^{2}\times n^{2}}
, the same operator has matrix representation

H\;=\;\frac{\lambda n}{d^{2}}\,I_{d^{2}}\;+\;(V\otimes U)\,\mathcal{D}\,(V\otimes U)^{\top}.

(60)

4.2
Leave-one-out reduction

We relate the joint minimizer
(\widehat{W},\widehat{\mu})
of (
38
) to a leave-one-out reference point by a first-order expansion. Fix a held-out index
h\in[n]
, and let
(\widehat{W}^{\setminus h},\widehat{\mu}^{\setminus h})
denote the minimizer of the TAM objective with sample
h
removed from both the outer sum and from all inner summations over interferers:

\Psi^{\setminus h}(W,\mu)\;\mathrel{\mathop{\ordinarycolon}}=\;\sum_{i\neq h}\ell\Big(s_{i,i}(W)-\mu_{i}-\frac{1}{k}\!\!\sum_{\begin{subarray}{c}j\neq i\\
j\neq h\end{subarray}}\!\!\phi_{\beta}\bigl(s_{j,i}(W)-\mu_{i}\bigr)\Big)+\frac{\lambda n}{2d^{2}}\,\mathinner{\!\left\lVert W\right\rVert}_{\mathsf{F}}^{2}.

(61)

Write
\Delta W\mathrel{\mathop{\ordinarycolon}}=\widehat{W}-\widehat{W}^{\setminus h}
,
\Delta\mu\mathrel{\mathop{\ordinarycolon}}=\widehat{\mu}-\widehat{\mu}^{\setminus h}
, and
\Delta S\mathrel{\mathop{\ordinarycolon}}=U^{\top}(\Delta W)V\in\mathbb{R}^{n\times n}
for the corresponding perturbations. A hat decoration (e.g.,
\hat{a}_{i},\hat{q}_{j,i},\hat{b}_{i},\hat{m}_{i}
) denotes a quantity from Section
4.1
evaluated at
(\widehat{W},\widehat{\mu})
; a superscript
\setminus h
denotes the same quantity evaluated at
(\widehat{W}^{\setminus h},\widehat{\mu}^{\setminus h})
. We adopt the conventions
a_{h}^{\setminus h}\mathrel{\mathop{\ordinarycolon}}=0
and
q_{j,h}^{\setminus h}\mathrel{\mathop{\ordinarycolon}}=q_{h,i}^{\setminus h}\mathrel{\mathop{\ordinarycolon}}=0
, so that
Q^{\setminus h},\Lambda_{a^{\setminus h}}
extend naturally to
n\times n
arrays.

4.2.1
LOO Hessian and rank-one reduction

The LOO Hessian has the same form as the full Hessian in Definition
2
, with the
h
-th sample removed and all coefficients evaluated at
(\widehat{W}^{\setminus h},\widehat{\mu}^{\setminus h})
. Explicitly,
H^{\setminus h}\mathrel{\mathop{\ordinarycolon}}\mathbb{R}^{d\times d}\to\mathbb{R}^{d\times d}
is defined by

H^{\setminus h}[\Delta]\;\mathrel{\mathop{\ordinarycolon}}=\;\frac{\lambda n}{d^{2}}\,\Delta\;+\;U\,M^{\setminus h}\!\bigl(U^{\top}\Delta\,V\bigr)\,V^{\top},

(62)

where
M^{\setminus h}\mathrel{\mathop{\ordinarycolon}}\mathbb{R}^{n\times n}\to\mathbb{R}^{n\times n}
acts columnwise as

M^{\setminus h}(X)_{\mathrel{\mathop{\ordinarycolon}},i}\;=\;M_{i}^{\setminus h}\,X_{\mathrel{\mathop{\ordinarycolon}},i}\quad(i\neq h),\qquad M^{\setminus h}(X)_{\mathrel{\mathop{\ordinarycolon}},h}\;=\;0.

(63)

In the above display,
M_{i}^{\setminus h}\in\mathbb{R}^{n\times n}
is a symmetric matrix with a rank-one-plus-diagonal form

\displaystyle M_{i}^{\setminus h}

\displaystyle\mathrel{\mathop{\ordinarycolon}}=\;b_{i}^{\setminus h}\,Q_{\mathrel{\mathop{\ordinarycolon}},i}^{\setminus h}(Q_{\mathrel{\mathop{\ordinarycolon}},i}^{\setminus h})^{\top}\;+\;a_{i}^{\setminus h}\,\diag\bigl(\widetilde{R}_{\mathrel{\mathop{\ordinarycolon}},i}^{\setminus h}\bigr)

(64)

\displaystyle\widetilde{R}_{j,i}^{\setminus h}

\displaystyle\mathrel{\mathop{\ordinarycolon}}=\;\begin{cases}\frac{\beta}{k}\,q_{j,i}^{\setminus h}\bigl(1-q_{j,i}^{\setminus h}\bigr)\,&j\neq i,\ j\neq h\\
0,&\text{otherwise}\\
\end{cases}.

Here
b_{i}^{\setminus h}
is the quantity in (
56
) evaluated at
(\widehat{W}^{\setminus h},\widehat{\mu}^{\setminus h})
. The operator
H^{\setminus h}
is self-adjoint and strictly positive-definite on
\mathbb{R}^{d\times d}
: its smallest eigenvalue is at least
\lambda n/d^{2}=\Theta(1)
in the regime
d^{2}\asymp n
, so that
\mathinner{\!\left\lVert(H^{\setminus h})^{-1}\right\rVert}_{\mathrm{op}}=\mathcal{O}_{\prec}(1)
.

Main result.

The leave-one-out perturbation is expected to be governed, to first order, by the held-out feature pair
(u_{h},v_{h})
.

Result 1

(LOO rank-one reduction)
.

Under the postulates
(A1)
–
(A3)
stated below, with high probability,

\widehat{W}-\widehat{W}^{\setminus h}\;=\;\sigma(-\hat{m}_{h})\,\bigl(H^{\setminus h}\bigr)^{-1}\!\bigl[u_{h}v_{h}^{\top}\bigr]\;+\;R_{h},\qquad\bigl\lVert R_{h}\bigr\rVert_{\mathsf{F}}\;=\;\mathcal{O}_{\prec}(d^{-1/2}).

(65)

Here
\hat{m}_{h}
is the TAM margin at the held-out sample evaluated at the full minimizer
(\widehat{W},\widehat{\mu})
:

\hat{m}_{h}\;=\;s_{h,h}(\widehat{W})\;-\;\hat{\mu}_{h}\;-\;\frac{1}{k}\sum_{j\neq h}\phi_{\beta}\!\bigl(s_{j,h}(\widehat{W})-\hat{\mu}_{h}\bigr).

(66)

Thus the leading change in the weight matrix is the inverse LOO Hessian applied to
\sigma(-\hat{m}_{h})\,u_{h}v_{h}^{\top}
, with a Frobenius-norm correction of lower order. In Section
4.3
, this formula is combined with trace concentration for
(H^{\setminus h})^{-1}
to obtain the susceptibility equation.

4.2.2
Justification of Result
1

We derive (
65
) from the following LOO postulates.

LOO postulates.

We assume:

(A1)

\displaystyle\max_{i\neq h}\,\bigl|(\Delta\mu)_{i}\bigr|\;=\;\mathcal{O}_{\prec}(n^{-1})
;

(A2)

\displaystyle\max_{j,i\neq h}\,\bigl|(\Delta S)_{j,i}\bigr|\;=\;\mathcal{O}_{\prec}(d^{-1})
;

(A3)

\displaystyle\max_{j,i\in[n]}\,\bigl|s_{j,i}(\widehat{W})\bigr|\;=\;\mathcal{O}_{\prec}(1)
.

in the sense of stochastic domination, absorbing
d^{\varepsilon}

factors. We use the same postulates after removing any fixed finite set of
samples, uniformly over such sets; in particular, (A3) is imposed on
the optimizer of the problem under consideration. These assumptions control the Taylor
remainder and the coefficient perturbations in the LOO expansion. The
spectral and self-averaging postulates needed to close the scalar
equations are stated separately in Section
4.3
.

Step 1: Subtract the stationarity conditions.

The
W
-components of the stationarity conditions (
53
) at the full and LOO optimizers, subtracted, yield

\frac{\lambda n}{d^{2}}\,\Delta W\;+\;U\,\bigl(\hat{Q}\Lambda_{\hat{a}}-Q^{\setminus h}\Lambda_{a^{\setminus h}}\bigr)\,V^{\top}\;=\;0.

(67)

Step 2: Separate the terms involving the held-out sample.

With the extension conventions on
a^{\setminus h}
and
q^{\setminus h}
, the matrix
\hat{Q}\Lambda_{\hat{a}}-Q^{\setminus h}\Lambda_{a^{\setminus h}}
decomposes entrywise as

\bigl(\hat{Q}\Lambda_{\hat{a}}-Q^{\setminus h}\Lambda_{a^{\setminus h}}\bigr)_{j,i}\;=\;\begin{cases}-\,\hat{a}_{h}&(j,i)=(h,h),\\[2.0pt]
\hat{a}_{h}\,\hat{q}_{j,h}/k&j\neq h,\ i=h,\\[2.0pt]
\hat{a}_{i}\,\hat{q}_{h,i}/k&j=h,\ i\neq h,\\[2.0pt]
\mathcal{R}_{j,i}^{\setminus h}&j,i\neq h,\end{cases}

(68)

where the first three cases are the entries involving the held-out sample: the held-out outer term (
i=h
) and the held-out interferer row (
j=h
, across interior columns) are present in the full objective but absent in the LOO objective. The remaining entries are collected in
\mathcal{R}^{\setminus h}\in\mathbb{R}^{n\times n}
, supported on
\{j,i\neq h\}
:

\mathcal{R}_{j,i}^{\setminus h}\;\mathrel{\mathop{\ordinarycolon}}=\;\begin{cases}\dfrac{\hat{a}_{i}\,\hat{q}_{j,i}\;-\;a_{i}^{\setminus h}\,q_{j,i}^{\setminus h}}{k}&j\neq i,\ j,i\neq h,\\[8.0pt]
a_{i}^{\setminus h}\;-\;\hat{a}_{i}&j=i\neq h.\end{cases}

(69)

Separating these entries inside (
67
),

\frac{\lambda n}{d^{2}}\,\Delta W\;+\;U\,\mathcal{R}^{\setminus h}\,V^{\top}\;=\;\hat{a}_{h}\,u_{h}v_{h}^{\top}\;-\;\hat{a}_{h}\,\eta_{h}\,v_{h}^{\top}\;-\;u_{h}\,\xi_{h}^{\top},

(70)

where

\eta_{h}\;\mathrel{\mathop{\ordinarycolon}}=\;\frac{1}{k}\sum_{j\neq h}\hat{q}_{j,h}\,u_{j},\qquad\xi_{h}\;\mathrel{\mathop{\ordinarycolon}}=\;\frac{1}{k}\sum_{i\neq h}\hat{a}_{i}\,\hat{q}_{h,i}\,v_{i}.

(71)

Step 3: Linearize the common part.

In Appendix
C
, we carry out a first-order Taylor expansion of
\mathcal{R}^{\setminus h}
in the perturbations
\Delta S
and
\Delta\mu
, with all higher-order terms collected into a residual matrix
\hat{E}^{\setminus h}
supported on
\{j,i\neq h\}
. This yields

\mathcal{R}_{\mathrel{\mathop{\ordinarycolon}},i}^{\setminus h}\;=\;M_{i}^{\setminus h}\,\Delta S_{\mathrel{\mathop{\ordinarycolon}},i}\;+\;\hat{E}^{\setminus h}_{\mathrel{\mathop{\ordinarycolon}},i},\qquad i\neq h,

(72)

with
M_{i}^{\setminus h}
as in (
64
). Combining (
72
) with (
70
) and the definition of
H^{\setminus h}
yields

H^{\setminus h}[\Delta W]\;=\;\hat{a}_{h}\,u_{h}v_{h}^{\top}\;-\;\hat{a}_{h}\,\eta_{h}\,v_{h}^{\top}\;-\;u_{h}\,\xi_{h}^{\top}\;-\;U\hat{E}^{\setminus h}V^{\top}.

(73)

Moreover, we show in Appendix
C
that, under
(A1)
–
(A3)
,

\bigl|\hat{E}^{\setminus h}_{i,i}\bigr|\;=\;\mathcal{O}_{\prec}(n^{-1})\ \text{for}\ i\neq h,\qquad\bigl|\hat{E}^{\setminus h}_{j,i}\bigr|\;=\;\mathcal{O}_{\prec}(n^{-2})\ \text{for}\ j\neq i,\ j,i\neq h.

(74)

Step 4: Invert and bound the correction.

Applying
(H^{\setminus h})^{-1}
to (
73
) produces (
65
) with

R_{h}\;=\;\bigl(H^{\setminus h}\bigr)^{-1}\!\Bigl[-\hat{a}_{h}\,\eta_{h}\,v_{h}^{\top}\;-\;u_{h}\,\xi_{h}^{\top}\;-\;U\hat{E}^{\setminus h}V^{\top}\Bigr].

(75)

Since
\mathinner{\!\left\lVert(H^{\setminus h})^{-1}\right\rVert}_{\mathrm{op}}=\mathcal{O}_{\prec}(1)
, it suffices to bound each of the three remaining terms in (
75
) in Frobenius norm at scale
\mathcal{O}_{\prec}(d^{-1/2})
.

Writing
k\,\eta_{h}=U\,\hat{q}_{\mathrel{\mathop{\ordinarycolon}},h}
(with the
h
-th entry of
\hat{q}_{\mathrel{\mathop{\ordinarycolon}},h}
understood to be zero), the Marchenko–Pastur bound
\mathinner{\!\left\lVert U\right\rVert}_{\mathrm{op}}=\mathcal{O}_{\prec}(\sqrt{d})
in the regime
d^{2}\asymp n
, together with the deterministic entrywise bound
\mathinner{\!\left\lVert\hat{q}_{\mathrel{\mathop{\ordinarycolon}},h}\right\rVert}_{2}\leq\sqrt{n-1}
, gives
\mathinner{\!\left\lVert\eta_{h}\right\rVert}_{2}\leq\mathinner{\!\left\lVert U\right\rVert}_{\mathrm{op}}\,\mathinner{\!\left\lVert\hat{q}_{\mathrel{\mathop{\ordinarycolon}},h}\right\rVert}_{2}/k=\mathcal{O}_{\prec}(\sqrt{nd}/n)=\mathcal{O}_{\prec}(d^{-1/2})
; the same argument applies to
\xi_{h}
. Consequently

\mathinner{\!\left\lVert\hat{a}_{h}\,\eta_{h}\,v_{h}^{\top}\right\rVert}_{\mathsf{F}}\;=\;|\hat{a}_{h}|\,\mathinner{\!\left\lVert\eta_{h}\right\rVert}_{2}\,\mathinner{\!\left\lVert v_{h}\right\rVert}_{2}\;=\;\mathcal{O}_{\prec}(d^{-1/2}),\qquad\mathinner{\!\left\lVert u_{h}\,\xi_{h}^{\top}\right\rVert}_{\mathsf{F}}\;=\;\mathcal{O}_{\prec}(d^{-1/2}).

(76)

Next, we consider the term
U\hat{E}^{\setminus h}V^{\top}
in (
75
). Let
\hat{E}^{\mathsf{d}}
and
\hat{E}^{\mathsf{o}}
denote the diagonal and off-diagonal parts of
\hat{E}^{\setminus h}
, respectively. The diagonal part is a diagonal matrix, so
\mathinner{\!\left\lVert\hat{E}^{\mathsf{d}}\right\rVert}_{\mathrm{op}}=\max_{i\neq h}|\hat{E}^{\setminus h}_{i,i}|=\mathcal{O}_{\prec}(n^{-1})
by (
74
). The off-diagonal part is controlled through its Frobenius norm,

\mathinner{\!\left\lVert\hat{E}^{\mathsf{o}}\right\rVert}_{\mathrm{op}}\;\leq\;\mathinner{\!\left\lVert\hat{E}^{\mathsf{o}}\right\rVert}_{\mathsf{F}}\;=\;\Bigl(\sum_{\begin{subarray}{c}j\neq i\\
j,i\neq h\end{subarray}}|\hat{E}^{\setminus h}_{j,i}|^{2}\Bigr)^{1/2}\;\leq\;\sqrt{n^{2}\cdot\mathcal{O}_{\prec}(n^{-4})}\;=\;\mathcal{O}_{\prec}(n^{-1}),

(77)

again by (
74
). Combining,
\mathinner{\!\left\lVert\hat{E}^{\setminus h}\right\rVert}_{\mathrm{op}}=\mathcal{O}_{\prec}(n^{-1})=\mathcal{O}_{\prec}(d^{-2})
. Submultiplicativity with
\mathinner{\!\left\lVert U\right\rVert}_{\mathrm{op}},\mathinner{\!\left\lVert V\right\rVert}_{\mathrm{op}}=\mathcal{O}_{\prec}(\sqrt{d})
yields
\mathinner{\!\left\lVert U\hat{E}^{\setminus h}V^{\top}\right\rVert}_{\mathrm{op}}\leq\mathcal{O}_{\prec}(d\cdot d^{-2})=\mathcal{O}_{\prec}(d^{-1})
. Since
U\hat{E}^{\setminus h}V^{\top}\in\mathbb{R}^{d\times d}
has rank at most
d
,
\mathinner{\!\left\lVert\cdot\right\rVert}_{\mathsf{F}}\leq\sqrt{d}\,\mathinner{\!\left\lVert\cdot\right\rVert}_{\mathrm{op}}
, and

\mathinner{\!\left\lVert U\hat{E}^{\setminus h}V^{\top}\right\rVert}_{\mathsf{F}}\;\leq\;\sqrt{d}\,\mathinner{\!\left\lVert U\hat{E}^{\setminus h}V^{\top}\right\rVert}_{\mathrm{op}}\;=\;\mathcal{O}_{\prec}(d^{-1/2}).

(78)

Combining (
76
) and (
78
) and applying
(H^{\setminus h})^{-1}
establishes (
65
). ∎

4.3
Scalar variational prediction

We now state the asymptotic characterization of the TAM minimizer. In addition to the LOO postulates
(A1)
–
(A3)
, we assume the following spectral and self-averaging postulates
(A4)
–
(A6)
. The derivation is given in Section
4.4
.

Spectral and self-averaging postulates.

We assume:

(A4)

\displaystyle\mathinner{\!\left\lVert\widehat{W}\right\rVert}_{\mathrm{op}}\;=\;\mathcal{O}_{\prec}(\sqrt{d})
;

(A5)

(Empirical-mean concentration.) For the bounded or pseudo-Lipschitz score observables used in the sequel, including the observables generated by the scalar reductions below,

\frac{1}{n}\sum_{i=1}^{n}\psi\bigl(s_{i,i}(\widehat{W})\bigr)-\mathbb{E}\!\left[\frac{1}{n}\sum_{i=1}^{n}\psi\bigl(s_{i,i}(\widehat{W})\bigr)\right]\;=\;\mathcal{O}_{\prec}(d^{-1/2}),

(79)

and

\frac{1}{n(n-1)}\sum_{i\neq j}\psi\bigl(s_{j,i}(\widehat{W})\bigr)-\mathbb{E}\!\left[\frac{1}{n(n-1)}\sum_{i\neq j}\psi\bigl(s_{j,i}(\widehat{W})\bigr)\right]\;=\;\mathcal{O}_{\prec}(d^{-1/2}).

(80)

(A6)

(Trace concentration.)

\frac{1}{d^{2}}\,\tr\!\left(H^{-1}\right)-\mathbb{E}\!\left[\frac{1}{d^{2}}\,\tr\!\left(H^{-1}\right)\right]\;=\;\mathcal{O}_{\prec}(d^{-1/2}).

(81)

Here
(A4)
is the spectral input, while
(A5)
and
(A6)
are self-averaging inputs at the common scale
\mathcal{O}_{\prec}(d^{-1/2})
for empirical means and normalized inverse traces, respectively.
The corresponding trace estimate for a fixed finite LOO Hessian follows from
(A6)
by the same finite-removal stability used in Section
4.2
.

For
\nu>0
, define the scalar TAM functional

c_{r}(\nu)\mathrel{\mathop{\ordinarycolon}}=\min_{\mu\in\mathbb{R}}\left\{\mu+\frac{1}{r}\mathbb{E}_{Z\sim\mathcal{N}(0,1)}\left[\phi_{\beta}(\nu Z-\mu)\right]\right\}.

(82)

Let
\mu_{r}(\nu)
denote the minimizer in (
82
). It is characterized by

r=\mathbb{E}_{Z\sim\mathcal{N}(0,1)}\left[\sigma\!\bigl(\beta(\nu Z-\mu_{r}(\nu))\bigr)\right].

(83)

Definition 3

(Scalar saddle and reduced potentials)

For

M_{r}(\nu,\chi)\mathrel{\mathop{\ordinarycolon}}=\mathbb{E}_{G\sim\mathcal{N}(0,1)}\left[\min_{s\in\mathbb{R}}\left[\frac{(s-\nu G)^{2}}{2\chi}+\ell\bigl(s-c_{r}(\nu)\bigr)\right]\right].

For

(88)

Result 2

(Scalar description of the joint TAM minimizer)

4.4
Justification of Result
2

Define

\nu_{d}^{2}\;\mathrel{\mathop{\ordinarycolon}}=\;\mathbb{E}\!\left[\,\frac{\|\widehat{W}\|_{\mathsf{F}}^{2}}{d^{2}}\,\right].

(95)

With

denoting the full Hessian operator from Definition
2
, evaluated at
(\widehat{W},\widehat{\mu})
, define

\chi_{d}\;\mathrel{\mathop{\ordinarycolon}}=\;\mathbb{E}\!\left[\frac{1}{d^{2}}\,\tr\!\left(H^{-1}\right)\right].

(96)

In this section, we derive the finite-dimensional equations for
\nu_{d}
and
\chi_{d}
that lead to Result
2
. The derivation proceeds in four steps. First, using
(A4)
and the bilinear coupling estimate in Appendix

, we identify the off-diagonal competitor scores with Gaussians of variance
\nu_{d}^{2}
. Second, this Gaussian approximation and the trace input

give the proximal characterization of the diagonal score

. Third,

-stationarity, together with empirical concentration

4.4.1
Gaussian law for competitor scores

We begin with the off-diagonal scores. The statement below gives a finite-dimensional joint Gaussian coupling for any fixed number of competitor scores in a single column, using an iterated leave-one-out reduction and the bilinear coupling estimate of Corollary
1
.

Proposition 2

(Joint Gaussian limit for competitor scores)
.

Fix
i\in[n]
,
m\geq 1
, and distinct
j_{1},\ldots,j_{m}\in[n]\setminus\{i\}
. Assume
(A1)
–
(A6)
. Then, in the joint regime

with
n/d^{2}\to\alpha
and

:
on a common probability space, there exist i.i.d. Gaussians

such that

\bigl\|\bigl(s_{j_{1},i}(\widehat{W}),\ldots,s_{j_{m},i}(\widehat{W})\bigr)-(Y_{1},\ldots,Y_{m})\bigr\|_{2}\;=\;\mathcal{O}_{\prec}(d^{-1/2}).

(97)

Remark 3

(Connection with the limiting statement)
.

Proposition
2
is the finite-dimensional form of the off-diagonal Gaussian law in Result
2
. Empirical-measure consequences, such as weak convergence of

to

, follow by combining exchangeability with concentration of the optimizer. The expectation-level replacements used below are obtained from this coupling for the finite list of bounded or pseudo-Lipschitz observables appearing in the stationarity identities, together with the moment bounds implicit in
(A5)
.

Proof outline.

Throughout, write
X_{k}\mathrel{\mathop{\ordinarycolon}}=s_{j_{k},i}(\widehat{W})
for

. Set
\widehat{W}_{\text{fresh}}\mathrel{\mathop{\ordinarycolon}}=\widehat{W}^{\setminus\{i,j_{1},\ldots,j_{m}\}}
and
V\mathrel{\mathop{\ordinarycolon}}=\|\widehat{W}_{\text{fresh}}v_{i}\|^{2}/d
.

Step 1: Iterated leave-one-out.

Apply (
65
) successively after removing the samples
i,j_{1},\ldots,j_{m}
. The finite-removal version of the LOO postulates, together with the spectral and self-averaging postulates
(A4)
–
(A5)
, gives the same rank-one expansion at each level. The resulting iterated identity expresses

\widehat{W}\;=\;\widehat{W}_{\text{fresh}}\;+\;\sum_{\ell=0}^{m}\Bigl[\,\hat{a}_{i_{\ell}}^{\setminus I_{\ell}}\,(H^{\setminus I_{\ell}})^{-1}\!\bigl[u_{i_{\ell}}v_{i_{\ell}}^{\top}\bigr]+R_{\ell}\,\Bigr],

(98)

where
i_{0}=i
,
i_{\ell}=j_{\ell}
for
\ell\geq 1
,
I_{\ell}\mathrel{\mathop{\ordinarycolon}}=\{i,j_{1},\ldots,j_{\ell}\}
, and each
\|R_{\ell}\|_{\mathsf{F}}=\mathcal{O}_{\prec}(d^{-1/2})
by Section
4.2
applied at the corresponding LOO level.

Step 2: Score decomposition.

For each
k\in[m]
, sandwiching (
98
) with
u_{j_{k}}^{\top}\cdot v_{i}
yields

X_{k}\;=\;u_{j_{k}}^{\top}\widehat{W}_{\text{fresh}}v_{i}\;+\;\mathcal{E}_{k},

(99)

where
\mathcal{E}_{k}
is the sum of
m+1
rank-one bilinear contributions plus residual terms.

Step 3: Bound the corrections.

Each rank-one contribution at level
\ell

\hat{a}_{i_{\ell}}^{\setminus I_{\ell}}\,u_{j_{k}}^{\top}(H^{\setminus I_{\ell}})^{-1}[u_{i_{\ell}}v_{i_{\ell}}^{\top}]\,v_{i}

(100)

admits a self-adjoint rewrite that places one of the held-out vectors —
u_{i}
for
\ell=0
and
v_{i}
for
\ell\geq 1
— on the outer test side, independent of the LOO operator
(H^{\setminus I_{\ell}})^{-1}
(which sees no sample in
I_{\ell}
). Combined with the operator-norm bound
\|(H^{\setminus I_{\ell}})^{-1}\|_{\mathrm{op}}\leq d^{2}/(\lambda n)=O(1)
from the ridge floor and
\|u_{a}v_{b}^{\top}\|_{\mathsf{F}}=O(1)
, the unmatched-Gaussian inner product gives an
\mathcal{O}_{\prec}(d^{-1/2})
bound on each rank-one contribution. The residuals

are bounded by
\|R_{\ell}\|_{\mathsf{F}}\,\|u_{j_{k}}\|\|v_{i}\|=\mathcal{O}_{\prec}(d^{-1/2})
. Summing
m+1
such terms,

|\mathcal{E}_{k}|\;=\;\mathcal{O}_{\prec}(d^{-1/2})\quad\text{uniformly in }k.

(101)

Step 4: Apply the bilinear coupling.

Since
\widehat{W}_{\text{fresh}}
is a function of
\{(u_{l},v_{l})\mathrel{\mathop{\ordinarycolon}}l\notin\{i,j_{1},\ldots,j_{m}\}\}
, it is independent of
u_{j_{1}},\ldots,u_{j_{m}},v_{i}
. The bilinear coupling Corollary
1
requires a Frobenius self-averaging estimate and an operator-norm input for
\widehat{W}_{\text{fresh}}
; both are transferred from
\widehat{W}
by the same finite-removal stability used above. In particular, the stochastic-dominance deviation
\|\widehat{W}_{\text{fresh}}\|_{\mathsf{F}}^{2}/d^{2}-\nu_{d}^{2}=\mathcal{O}_{\prec}(d^{-1/2})
follows from the Frobenius consequence of
(A5)
, while the operator-norm input
\|(\widehat{W}_{\text{fresh}})^{\top}\widehat{W}_{\text{fresh}}\|_{\mathsf{F}}/d^{2}=\mathcal{O}_{\prec}(d^{-1/2})
follows from
(A4)
. Apply Corollary
1
with
W=\widehat{W}_{\text{fresh}}
,
v_{0}=v_{i}
, and
\rho_{f}=\rho_{\mathrm{op}}=O(d^{-1/2})
: there exist i.i.d.
Y_{1},\ldots,Y_{m}\sim\mathcal{N}(0,\nu_{d}^{2})
with

\bigl\|(u_{j_{1}}^{\top}\widehat{W}_{\text{fresh}}v_{i},\ldots,u_{j_{m}}^{\top}\widehat{W}_{\text{fresh}}v_{i})-(Y_{1},\ldots,Y_{m})\bigr\|_{2}\;=\;\mathcal{O}_{\prec}(d^{-1/2}),

(102)

with
Y_{1},\ldots,Y_{m}
i.i.d.
\mathcal{N}(0,\nu_{d}^{2})
.

Step 5: Combine.

Triangle inequality applied to (
99
), (
101
), and (
102
) yields (
97
). ∎

4.4.2
Proximal law for diagonal scores

We next record the finite-dimensional proximal law for the diagonal scores. Set

Proposition 3

(Coupled proximal law for

Assume

–

and
\mu_{d}
in a compact set; on this set the derivative in

Let

5
Ridgeless limit and phase transition

The scalar theory in Section
4.3
gives a limiting
variational problem for each fixed ridge parameter
\lambda>0
and
fixed smoothing parameter
\beta<\infty
. In this section we take the
sequential ridgeless limit: first
n,d\to\infty
with

n/d^{2}\to\alpha
and
k/n\to r
, and then

\lambda\downarrow 0
while keeping
\beta\in(0,\infty)
fixed. The
limit separates two regimes. Below the critical load

\alpha_{c}(r)
defined in (
141
) below, the scalar
norm
\nu
escapes to infinity as
\lambda\downarrow 0
and the limiting fitting loss vanishes; we
call this the satisfiable, or SAT, phase. Above this critical load the
scalar norm remains finite and the limiting fitting loss is positive;
we call this the unsatisfiable, or UNSAT, phase. After deriving the
transition from the variational principle, we describe the score,
margin, and percentile profiles on both sides.

All results in this section concern the scalar saddle problem of
Definition
3
. They translate into
statements about the original TAM minimizer
(\widehat{W},\widehat{\mu})
through the
conditional scalar identification in Result
2
.

5.1
Phase transition

Definition 4

(Ridgeless threshold)
.

Let
G\sim N(0,1)
, and define

\kappa_{r}\mathrel{\mathop{\ordinarycolon}}=\frac{\varphi(\Phi^{-1}(1-r))}{r},

(140)

where
\Phi
and
\varphi
are the CDF and density of a standard
normal random variable. The critical load is

\alpha_{c}(r)=\frac{1}{\mathbb{E}[(\kappa_{r}-G)_{+}^{2}]}=\frac{1}{(1+\kappa_{r}^{2})\Phi(\kappa_{r})+\kappa_{r}\varphi(\kappa_{r})}.

(141)

In what follows, we first explain the
origin and underlying ideas behind the transition at
\alpha_{c}(r)
. The formal proof is then given in
Proposition
7
.

We start from the dual form of the reduced potential in
(
405
), writing the ridge parameter
explicitly:

\displaystyle\mathcal{V}_{\alpha,r,\lambda}(\nu)

\displaystyle=\frac{\lambda}{2}\nu^{2}+\sup_{0\leq a(\cdot)\leq 1}\Bigg\{\mathbb{E}\!\left[a(G)\bigl(c_{r}(\nu)-\nu G\bigr)-I(a(G))\right]

(142)

\displaystyle-\frac{\nu}{\sqrt{\alpha}}\left(\mathbb{E}[a(G)^{2}]\right)^{1/2}\Bigg\},

where
G\sim N(0,1)
and

I(a)=a\log a+(1-a)\log(1-a)
. The supremum is over measurable
functions
a\mathrel{\mathop{\ordinarycolon}}\mathbb{R}\to[0,1]
. We write

\mathcal{V}_{\alpha,r,0}
for the ridgeless potential obtained by
setting
\lambda=0
; explicitly,

\displaystyle\mathcal{V}_{\alpha,r,0}(\nu)=\sup_{0\leq a(\cdot)\leq 1}\Bigg\{\mathbb{E}\!\left[a(G)\bigl(c_{r}(\nu)-\nu G\bigr)-I(a(G))\right]-\frac{\nu}{\sqrt{\alpha}}\left(\mathbb{E}[a(G)^{2}]\right)^{1/2}\Bigg\}.

(143)

The phase transition is determined by the large-
\nu
behavior of the
ridgeless potential
\mathcal{V}_{\alpha,r,0}
. The only input from the
TAM threshold
c_{r}(\nu)
needed for the leading-order calculation is
the asymptotic relation

\frac{c_{r}(\nu)}{\nu}\longrightarrow\kappa_{r}.

(144)

We defer the verification of (
144
) to the
proof of Proposition
7
.
Now set
m_{r}(\nu)\mathrel{\mathop{\ordinarycolon}}=c_{r}(\nu)/\nu
. For fixed
a(\cdot)
, the
linear-in-
\nu
part of (
142
) is

\nu\left[\mathbb{E}\!\left[a(G)(m_{r}(\nu)-G)\right]-\frac{1}{\sqrt{\alpha}}\|a\|_{2}\right],\qquad\|a\|_{2}\mathrel{\mathop{\ordinarycolon}}=\left(\mathbb{E}[a(G)^{2}]\right)^{1/2}.

(145)

The entropy term
I(a)
is not multiplied by
\nu
.
Thus the large-norm behavior is governed by a simple question: can we
choose a nonzero dual profile
a
so that the coefficient of the
leading linear term in
\nu
is positive?

Letting
\nu\to\infty
in this coefficient and using
(
144
), the relevant expression becomes

\mathbb{E}[a(G)(\kappa_{r}-G)]-\frac{1}{\sqrt{\alpha}}\|a\|_{2}.

(146)

Since
a\geq 0
, the negative part of
\kappa_{r}-G
can only hurt, so
the best profile should live on the event
\{G<\kappa_{r}\}
. More
precisely, by Cauchy–Schwarz, for any
0\leq a\leq 1
,

\mathbb{E}[a(G)(\kappa_{r}-G)]\leq\mathbb{E}[a(G)(\kappa_{r}-G)_{+}]\leq\|a\|_{2}\,\left(\mathbb{E}[(\kappa_{r}-G)_{+}^{2}]\right)^{1/2}.

(147)

The upper bound is sharp despite the pointwise constraint
a\leq 1
.
Indeed, equality in Cauchy–Schwarz would ask for

a
proportional to
(\kappa_{r}-G)_{+}
, which is unbounded. We can
approximate this direction by the admissible truncations

a_{M}(G)\mathrel{\mathop{\ordinarycolon}}=\min\left\{\frac{(\kappa_{r}-G)_{+}}{M},1\right\},\qquad M\to\infty.

(148)

The ratio

\mathbb{E}[a_{M}(G)(\kappa_{r}-G)]/\|a_{M}\|_{2}
converges to

\left(\mathbb{E}[(\kappa_{r}-G)_{+}^{2}]\right)^{1/2}
. Hence a positive
large-
\nu
direction exists exactly when

\alpha>\alpha_{c}(r)
, with
\alpha_{c}(r)
as in
(
141
).

Proposition 7

(Ridgeless scalar phase transition)
.

Fix
r\in(0,1)
and
\beta\in(0,\infty)
. For each

\lambda>0
, let
\nu_{\lambda}
be the unique minimizer of

\mathcal{V}_{\alpha,r,\lambda}
.

(i)

If
\alpha<\alpha_{c}(r)
, then

\nu_{\lambda}\to\infty\qquad\text{and}\qquad\mathcal{V}_{\alpha,r,0}(\nu_{\lambda})\to 0

(149)

as
\lambda\downarrow 0
.

(ii)

If
\alpha>\alpha_{c}(r)
, then
\nu_{\lambda}
remains
bounded as
\lambda\downarrow 0
and converges to the unique
minimizer
\nu_{0}<\infty
of
\mathcal{V}_{\alpha,r,0}
. The
ridgeless fitting loss
\mathcal{V}_{\alpha,r,0}(\nu_{0})
is
strictly positive.

Proof.

We first justify (
144
). Rescaling the
definition of
c_{r}
by writing
\mu=\nu t
gives

\frac{c_{r}(\nu)}{\nu}=\min_{t\in\mathbb{R}}\left\{t+\frac{1}{r}\mathbb{E}\!\left[\frac{\phi_{\beta}(\nu(G-t))}{\nu}\right]\right\}.

(150)

For each fixed
y
, the function

\nu\mapsto\phi_{\beta}(\nu y)/\nu
is nonincreasing and converges to

y_{+}
. Thus the limiting problem is

\min_{t\in\mathbb{R}}\left\{t+\frac{1}{r}\mathbb{E}[(G-t)_{+}]\right\}.

(151)

Its minimizer is
t=\Phi^{-1}(1-r)
and its value is
\kappa_{r}
, which proves
(
144
). In fact the convergence is monotone
decreasing.

SAT case:
\alpha<\alpha_{c}(r)
.
By
(
144
) and the definition
(
141
), there are
\delta>0
and
\nu_{0}<\infty

such that, for all
\nu\geq\nu_{0}
,

\left(\mathbb{E}[(m_{r}(\nu)-G)_{+}^{2}]\right)^{1/2}\leq\frac{1}{\sqrt{\alpha}}-\delta.

(152)

Therefore, uniformly over
0\leq a\leq 1
,

\mathbb{E}[a(G)(m_{r}(\nu)-G)]-\frac{1}{\sqrt{\alpha}}\|a\|_{2}\leq-\delta\|a\|_{2}.

(153)

The remaining terms in the dual representation are lower order. More
precisely, for any
p\in(0,1)
there is
C_{p}<\infty
such that

-I(x)\leq C_{p}x^{p}
for
0\leq x\leq 1
, while

\mathbb{E}[a^{p}]\leq\|a\|_{2}^{p}
. Hence

\displaystyle\mathcal{V}_{\alpha,r,0}(\nu)

\displaystyle\leq\sup_{0\leq x\leq 1}\left\{-\delta\nu x+C_{p}x^{p}\right\}\longrightarrow 0\quad\text{as }\nu\to\infty.

(154)

Since
a=0
is admissible,
\mathcal{V}_{\alpha,r,0}(\nu)\geq 0
, and
therefore
\mathcal{V}_{\alpha,r,0}(\nu)\to 0
as
\nu\to\infty
.

To identify the variational value with the scalar fitting loss, fix

\nu
and let
\chi(\nu)
be the unique maximizer of

\mathcal{P}_{\alpha,r,\lambda}(\nu,\cdot)
, whose existence and
uniqueness are given by Proposition
6
.
With the scalar proximal channel
S_{\nu,\chi}
defined in
(
89
), the identity

\mathcal{V}_{\alpha,r,\lambda}(\nu)=\frac{\lambda}{2}\nu^{2}+\mathbb{E}\!\left[\ell(S_{\nu,\chi}-c_{r}(\nu))\right]

(155)

follows from a short cancellation. Writing

A\mathrel{\mathop{\ordinarycolon}}=\sigma(-S_{\nu,\chi}+c_{r}(\nu))
, the proximal equation gives

S_{\nu,\chi}-\nu G=\chi A
, and hence

M_{r}(\nu,\chi)=\frac{\chi}{2}\mathbb{E}[A^{2}]+\mathbb{E}\!\left[\ell(S_{\nu,\chi}-c_{r}(\nu))\right].

(156)

At the maximizing
\chi
, the saddle equation

\nu^{2}=\alpha\chi^{2}\mathbb{E}[A^{2}]
gives

\nu^{2}/(2\alpha\chi)=(\chi/2)\mathbb{E}[A^{2}]
, so the two quadratic terms in

\mathcal{P}_{\alpha,r,\lambda}
cancel. Thus the ridgeless potential
is the scalar fitting loss and is strictly positive at every finite

\nu
.
For any
\varepsilon>0
, choose
N
so large that

\mathcal{V}_{\alpha,r,0}(N)\leq\varepsilon
, and then choose

\lambda
so small that
\lambda N^{2}/2\leq\varepsilon
. This gives

\mathcal{V}_{\alpha,r,\lambda}(\nu_{\lambda})\leq 2\varepsilon.

(157)

Hence the optimal value tends to zero. If
\nu_{\lambda}
remained
bounded along a subsequence, lower semicontinuity would force a
finite point with zero ridgeless fitting loss, contradicting strict
positivity. Therefore
\nu_{\lambda}\to\infty
, and the displayed
identity implies that the per-sample fitting loss tends to zero.

UNSAT case:
\alpha>\alpha_{c}(r)
.
By the sharpness of the
Cauchy–Schwarz bound, there is a bounded measurable

a\mathrel{\mathop{\ordinarycolon}}\mathbb{R}\to[0,1]
and a number
\delta>0
such that

\mathbb{E}[a(G)(\kappa_{r}-G)]-\frac{1}{\sqrt{\alpha}}\|a\|_{2}\geq 2\delta.

(158)

Using
m_{r}(\nu)\to\kappa_{r}
and bounded convergence, the same
a

satisfies, for all sufficiently large
\nu
,

\mathbb{E}[a(G)(m_{r}(\nu)-G)]-\frac{1}{\sqrt{\alpha}}\|a\|_{2}\geq\delta.

(159)

Substituting this fixed test function into
(
142
) gives

\mathcal{V}_{\alpha,r,0}(\nu)\geq\delta\nu-O(1),

(160)

so the ridgeless potential is coercive. The minimizers of

\mathcal{V}_{\alpha,r,\lambda}=\mathcal{V}_{\alpha,r,0}+\lambda\nu^{2}/2
therefore remain in a
compact set as
\lambda\downarrow 0
. Any limit point minimizes

\mathcal{V}_{\alpha,r,0}
by the standard variational argument:
compare
\nu_{\lambda}
against an arbitrary fixed
\nu
and let

\lambda\downarrow 0
.

We now show that the ridgeless minimizer is unique. For finite

\beta
, the TAM threshold
c_{r}
is strictly convex. Indeed, with

w_{\nu}(Z)\mathrel{\mathop{\ordinarycolon}}=\phi_{\beta}^{\prime\prime}\!\bigl(\nu Z-\mu_{r}(\nu)\bigr),

(161)

the envelope theorem and the defining equation for
\mu_{r}(\nu)
give

c_{r}^{\prime\prime}(\nu)=\frac{1}{r}\left\{\mathbb{E}[w_{\nu}(Z)Z^{2}]-\frac{\mathbb{E}[w_{\nu}(Z)Z]^{2}}{\mathbb{E}[w_{\nu}(Z)]}\right\}>0.

(162)

For each finite
\nu
, the dual maximizer in
(
143
) has positive expectation. In
the primal variables this maximizer is

a(G)=\sigma(-S_{\nu,\chi}+c_{r}(\nu))
, and hence

0<a(G)<1
almost surely. Therefore

\mathcal{V}_{\alpha,r,0}
is strictly convex: if

\nu_{\theta}=\theta\nu_{1}+(1-\theta)\nu_{2}
with

0<\theta<1
and
\nu_{1}\neq\nu_{2}
, evaluating the dual formula at the
maximizer for
\nu_{\theta}
and using the strict convexity of
c_{r}

gives

\mathcal{V}_{\alpha,r,0}(\nu_{\theta})<\theta\mathcal{V}_{\alpha,r,0}(\nu_{1})+(1-\theta)\mathcal{V}_{\alpha,r,0}(\nu_{2}).

(163)

Thus the ridgeless minimizer is unique; call it
\nu_{0}
. Hence

\nu_{\lambda}\to\nu_{0}
. Since
\nu_{0}
is finite, the corresponding
scalar logistic loss is strictly positive.
∎

Remark 4

(No dependence on the smoothing parameter)
.

The critical load
\alpha_{c}(r)
does not depend on the smoothing
parameter
\beta\in(0,\infty)
. The parameter
\beta
affects the
finite-
\lambda
scalar channel and the finite ridgeless minimizer in
the UNSAT phase, but it disappears from the large-
\nu
limit
(
144
), where the smoothed logistic tail

\phi_{\beta}(\nu y)/\nu
converges to
y_{+}
.

5.2
Score, margin, and percentile profiles

We next translate the ridgeless phase transition into predictions for
the true scores, the competing scores, the margins, and the percentile
rank of the true score among its competitors. The two phases have
different scaling behavior. In the SAT phase,
Proposition
7
shows that

\nu_{\lambda}\to\infty
. Thus the true scores and the competitor
scores both diverge on the original scale. The meaningful objects are
the normalized scores, obtained by dividing by
\nu_{\lambda}
, and
these have a non-degenerate limit. In the UNSAT phase, by contrast,

\nu_{\lambda}
remains finite, so the ridgeless profiles live on the
original scale.

5.2.1
The SAT phase

We begin with the SAT phase, where the limiting normalized profiles
are explicit. The single parameter controlling them is the number

\rho_{\alpha}>\kappa_{r}
, defined as the unique solution of

\mathbb{E}[(\rho_{\alpha}-G)_{+}^{2}]=\frac{1}{\alpha},\qquad G\sim N(0,1).

(164)

The left-hand side is strictly increasing in
\rho_{\alpha}
, and the
boundary value
\rho_{\alpha}=\kappa_{r}
is exactly
(
141
). Hence
\rho_{\alpha}
is monotone
decreasing in
\alpha
and satisfies

\rho_{\alpha}\downarrow\kappa_{r}
as

\alpha\uparrow\alpha_{c}(r)
.

Proposition 8

(SAT score, margin, and percentile profiles)
.

Assume
\alpha<\alpha_{c}(r)
, and let
\rho_{\alpha}>\kappa_{r}
be the
unique solution of (
164
). In the sequential
ridgeless limit
\lambda\downarrow 0
, the normalized true score
satisfies

\frac{S_{\nu_{\lambda},\chi_{\lambda}}}{\nu_{\lambda}}\Rightarrow\max\{G,\rho_{\alpha}\},\qquad G\sim N(0,1).

(165)

Consequently, the normalized TAM margin satisfies

\frac{S_{\nu_{\lambda},\chi_{\lambda}}-c_{r}(\nu_{\lambda})}{\nu_{\lambda}}\Rightarrow\max\{G,\rho_{\alpha}\}-\kappa_{r},\qquad G\sim N(0,1).

(166)

Here and below,
\Rightarrow
denotes weak convergence of laws as

\lambda\downarrow 0
. The associated percentile variable satisfies

\Omega\Rightarrow\Phi\!\left(\max\{G,\rho_{\alpha}\}\right).

(167)

Equivalently, if
p_{\alpha}\mathrel{\mathop{\ordinarycolon}}=\Phi(\rho_{\alpha})
, then

\mathbb{P}(\Omega\leq\omega)=\begin{cases}0,&\omega<p_{\alpha},\\
\omega,&p_{\alpha}\leq\omega\leq 1.\end{cases}

(168)

Proof.

By Proposition
7
, in the SAT
phase
\nu_{\lambda}\to\infty
and the scalar fitting loss tends to
zero. The proof has three steps. First, we rewrite the proximal
channel in terms of the normalized score and the correction term
created by the loss. Second, we introduce the scalar quantity

\rho_{\lambda}
and use the saddle-point equation to show that it is
bounded. Third, we identify every subsequential limit of

\rho_{\lambda}
; uniqueness of the equation defining
\rho_{\alpha}

then gives the stated weak convergence.

Set
c_{\lambda}\mathrel{\mathop{\ordinarycolon}}=c_{r}(\nu_{\lambda})
. For each deterministic scalar
input
g\in\mathbb{R}
, define

S_{\lambda}(g)\mathrel{\mathop{\ordinarycolon}}=c_{\lambda}+\Prox_{\chi_{\lambda}}(\nu_{\lambda}g-c_{\lambda}),\qquad X_{\lambda}(g)\mathrel{\mathop{\ordinarycolon}}=\frac{S_{\lambda}(g)}{\nu_{\lambda}}.

(169)

The proximal first-order condition is the pointwise identity

S_{\lambda}(g)=\nu_{\lambda}g+\chi_{\lambda}\sigma(-S_{\lambda}(g)+c_{\lambda}).

(170)

We also define the pointwise correction

B_{\lambda}(g)\mathrel{\mathop{\ordinarycolon}}=X_{\lambda}(g)-g=\frac{\chi_{\lambda}}{\nu_{\lambda}}\sigma(-S_{\lambda}(g)+c_{\lambda})\geq 0.

(171)

Only now do we insert the Gaussian variable: when
G\sim N(0,1)
,
the random variables in the scalar channel are

S_{\lambda}(G)
,
X_{\lambda}(G)
, and
B_{\lambda}(G)
. The
\chi

saddle-point equation for the scalar
potential in Definition
3
, recorded in
(
394
) of
Appendix
G
, gives

\mathbb{E}[B_{\lambda}(G)^{2}]=\frac{1}{\alpha}.

(172)

Moreover, the zero-loss statement implies that the normalized score
does not fall below the TAM threshold. Indeed, with

M_{\lambda}(g)\mathrel{\mathop{\ordinarycolon}}=S_{\lambda}(g)-c_{\lambda}
, we have pointwise

\left(\frac{c_{\lambda}}{\nu_{\lambda}}-X_{\lambda}(g)\right)_{+}=\frac{(-M_{\lambda}(g))_{+}}{\nu_{\lambda}}.

(173)

For every
m\in\mathbb{R}
,

(-m)_{+}\leq\ell(m).

(174)

Therefore, since the fitting loss

\mathbb{E}[\ell(M_{\lambda})]
tends to zero and

\nu_{\lambda}\to\infty
,

\mathbb{E}\left[\left(\frac{c_{\lambda}}{\nu_{\lambda}}-X_{\lambda}(G)\right)_{+}\right]\longrightarrow 0.

(175)

Since
c_{\lambda}/\nu_{\lambda}\to\kappa_{r}
by
(
144
), the
1
-Lipschitz property of

x\mapsto x_{+}
gives

\mathbb{E}\left[\left(\kappa_{r}-X_{\lambda}(G)\right)_{+}\right]\longrightarrow 0.

(176)

We now identify the limit of the channel. The useful normalization is
the level at which the sigmoid correction in
(
171
) changes from negligible to order one.
Define

\rho_{\lambda}\mathrel{\mathop{\ordinarycolon}}=\frac{c_{\lambda}+\log(\chi_{\lambda}/\nu_{\lambda})}{\nu_{\lambda}}.

(177)

Combining this definition with
(
171
) and the identity

\sigma(x)=(1+\exp\{-x\})^{-1}
gives the exact formula

B_{\lambda}(g)=\frac{\exp\{\nu_{\lambda}(\rho_{\lambda}-X_{\lambda}(g))\}}{1+\exp\{c_{\lambda}-\nu_{\lambda}X_{\lambda}(g)\}}.

(178)

The sequence
\rho_{\lambda}
is bounded. Indeed, if

\rho_{\lambda}\to-\infty
along a subsequence, then

\chi_{\lambda}/\nu_{\lambda}=\exp\{\nu_{\lambda}\rho_{\lambda}-c_{\lambda}\}\to 0
, and hence

B_{\lambda}(g)\leq\chi_{\lambda}/\nu_{\lambda}\to 0
uniformly in
g
,
contradicting
(
172
). Next suppose that

\rho_{\lambda}\to+\infty
along a subsequence. We claim that, for all
sufficiently small
\lambda
,

B_{\lambda}(g)\geq\frac{\rho_{\lambda}}{2}\qquad\text{for every }g\in[-1,0].

(179)

Indeed, if the reverse inequality held at some
g\in[-1,0]
, then

X_{\lambda}(g)=g+B_{\lambda}(g)\leq\rho_{\lambda}/2
. Using
(
178
) and the boundedness of

c_{\lambda}/\nu_{\lambda}
, we would get

B_{\lambda}(g)\geq\exp\{\nu_{\lambda}\rho_{\lambda}/3\}

(180)

for all sufficiently small
\lambda
, contradicting

B_{\lambda}(g)<\rho_{\lambda}/2
. Hence the claim holds. Since

\mathbb{P}(-1\leq G\leq 0)=\Phi(0)-\Phi(-1)>0
, the claim implies

\mathbb{E}[B_{\lambda}(G)^{2}]\geq\bigl(\Phi(0)-\Phi(-1)\bigr)\frac{\rho_{\lambda}^{2}}{4}\longrightarrow\infty,

(181)

contradicting (
172
).

It remains to identify the possible limits of
\rho_{\lambda}
. Take a
subsequence along which
\rho_{\lambda}\to\rho
. Passing to a further
subsequence, we may assume from
(
176
) that

\liminf_{\lambda\downarrow 0}X_{\lambda}(G)\geq\kappa_{r}\qquad\text{almost surely}.

(182)

The rest of the argument is pointwise in
g
. First, if
g>\rho
,
then
B_{\lambda}(g)\to 0
and
X_{\lambda}(g)\to g
. Indeed, any positive
subsequential limit of
B_{\lambda}(g)
would force

X_{\lambda}(g)=g+B_{\lambda}(g)>\rho_{\lambda}
eventually, and the
right-hand side of (
178
) would then
converge to zero. This excludes
\rho<\kappa_{r}
, because on the
positive-probability event
\{\rho<G<\kappa_{r}\}
it would imply

X_{\lambda}(G)\to G<\kappa_{r}
, contradicting
(
182
). Hence
\rho\geq\kappa_{r}
.

We now identify the channel limit for any subsequential limit

\rho\geq\kappa_{r}
. Along any bounded subsequence of
\rho_{\lambda}
,
(
178
) gives the domination

B_{\lambda}(g)^{2}\leq 1+\left(\sup_{\lambda}\rho_{\lambda}-g\right)_{+}^{2}.

(183)

Indeed, if
B_{\lambda}(g)\leq 1
there is nothing to prove; if

B_{\lambda}(g)>1
, then (
178
) implies

X_{\lambda}(g)\leq\rho_{\lambda}
, and so

B_{\lambda}(g)=X_{\lambda}(g)-g\leq(\rho_{\lambda}-g)_{+}
.

For
g>\rho
, we already proved
X_{\lambda}(g)\to g
. Now fix

g<\rho
. For almost every such
g
, every subsequential limit
x
of

X_{\lambda}(g)
satisfies
x\geq\kappa_{r}
by
(
182
). If
x<\rho
, then the
exponential numerator in (
178
) grows like

\exp\{\nu_{\lambda}(\rho-x+o(1))\}
, while the denominator grows at
most like
\exp\{\nu_{\lambda}(\kappa_{r}-x)_{+}+o(\nu_{\lambda})\}
. Since

\rho\geq\kappa_{r}
and
x\geq\kappa_{r}
, this is impossible. If

x>\rho
, the correction term vanishes by (
178
),
forcing
x=g
, also impossible because
g<\rho
. Hence
x=\rho
.
Thus, with
G\sim N(0,1)
,

X_{\lambda}(G)\longrightarrow\max\{G,\rho\},\qquad B_{\lambda}(G)\longrightarrow(\rho-G)_{+}.

(184)

The domination bound (
183
) allows us to pass to
the second moment in (
172
), so

\mathbb{E}[(\rho-G)_{+}^{2}]=\frac{1}{\alpha}.

(185)

By uniqueness of the solution to (
164
), every
subsequential limit is
\rho_{\alpha}
. Hence the whole sequence
satisfies

X_{\lambda}(G)\Rightarrow\max\{G,\rho_{\alpha}\}
. Subtracting

c_{\lambda}/\nu_{\lambda}\to\kappa_{r}
proves
(
165
) and
(
166
).

The percentile distribution is obtained by comparing the diagonal
score with the limiting competitor field
N(0,\nu_{\lambda}^{2})
. Hence
(
167
). The CDF formula
(
168
) follows by noting that

\Phi(\max\{G,\rho_{\alpha}\})
has an atom of mass

p_{\alpha}=\Phi(\rho_{\alpha})
at
p_{\alpha}
, followed by a uniform tail
on
(p_{\alpha},1)
.
∎

5.2.2
The UNSAT phase

Assume
\alpha>\alpha_{c}(r)
. In this regime the ridgeless limit does
not escape to infinite norm. By
Proposition
7
, the minimizers

\nu_{\lambda}
converge to the unique finite minimizer
\nu_{0}
of the
ridgeless reduced potential. The next proposition records the
corresponding finite-scale profiles. We omit the proof, since the
statement is obtained by specializing the scalar channel from
Section
4.3
at the ridgeless minimizer.

Proposition 9

(UNSAT score, margin, and percentile profiles)
.

Let
\chi_{0}
be the maximizer in the scalar saddle problem
corresponding to
\nu_{0}
, and define

c_{0}\mathrel{\mathop{\ordinarycolon}}=c_{r}(\nu_{0}).

(186)

Then the limiting true score is the finite-scale scalar random
variable

S_{0}\mathrel{\mathop{\ordinarycolon}}=S_{\nu_{0},\chi_{0}}=c_{0}+\Prox_{\chi_{0}}\!\bigl(\nu_{0}G-c_{0}\bigr),\qquad G\sim N(0,1).

(187)

The competing scores remain on the same finite scale, with limiting
Gaussian scale

5.4
A small-tail conjecture for top-1 retrieval

The scalar theory above is derived for a fixed tail fraction

r\in(0,1)
. It therefore does not directly cover top-1 retrieval,
which corresponds to the extreme-tail choice
r=1/(n-1)
. Still,
formally extrapolating the fixed-
r
phase boundary to this vanishing
tail fraction gives an intriguing prediction for the sharp top-1
constant.

As
r\downarrow 0
,

\kappa_{r}=\frac{\varphi(\Phi^{-1}(1-r))}{r}\sim\sqrt{2\log(1/r)}

(190)

and therefore

\alpha_{c}(r)=\frac{1}{\mathbb{E}[(\kappa_{r}-G)_{+}^{2}]}\sim\frac{1}{2\log(1/r)}.

(191)

Setting
r=1/(n-1)
makes TAM coincide with the top-1 criterion, at
least formally. Since the TAM load is
\alpha=n/d^{2}
, the condition

\alpha<\alpha_{c}(r)
then becomes

\frac{n}{d^{2}}\lesssim\frac{1}{2\log n},\qquad\text{or equivalently}\qquad d^{2}\gtrsim 2n\log n.

(192)

Conjecture 1

(Small-tail extrapolation to top-1 retrieval)
.

Along sequences with
n,d\to\infty
, the optimal top-1 retrieval
threshold is

\frac{d^{2}}{n\log n}=2.

(193)

In other words, for every fixed
\epsilon>0
, top-1 retrieval should
be feasible with high probability when

d^{2}>(2+\epsilon)n\log n
, and infeasible with high probability when

d^{2}<(2-\epsilon)n\log n
.

This conjecture is consistent with the logarithmic scale proved in
Section
2
, but predicts a sharper constant than what is currently
proved. The same sharp constant was proposed concurrently by

23
based on a simplified decoupled model of linear associative memory.
It is also supported by numerical experiments in the top-1 regime. We
empirically estimate the threshold by optimizing the regularized
multiclass cross-entropy objective (
40
) with a small ridge
parameter, while sweeping the rescaled load

c=\frac{n\log n}{d^{2}}.

(194)

For each dimension, the norm scale

\|\widehat{W}\|_{\mathsf{F}}/d
develops a pronounced peak near the
transition. We use the location of this peak as a finite-dimensional
estimate
\widehat{c}(d)
of the critical load.

6
Conclusion

We have shown that the capacity of linear associative memory is governed not
only by the number of degrees of freedom in the memory matrix, but also by the
retrieval statistic used to read it out. For exact top-1 retrieval, the relevant
statistic is the largest distractor. This extreme-value requirement forces the
logarithmic model-size scale

d^{2}\asymp n\log n.

The correlation matrix memory achieves this scale, and our universal
impossibility theorem shows that the logarithmic factor cannot be removed by
choosing a more sophisticated linear memory. It is therefore not an artifact of
the specific construction of correlation matrix memory, but the intrinsic price of winner-take-all decoding.

The picture changes for listwise retrieval. We propose the Tail-Average Margin
criterion, which replaces the maximum competitor by the average strength of a
fixed upper tail.
This still certifies that the correct association remains in a controlled
candidate list, but it avoids making success depend on a single extreme
distractor. At fixed tail fraction, the resulting theory operates at the
quadratic scale

d^{2}\asymp n,

the scale suggested by the number of parameters. Conditional on six precise postulates stated in
Section
4
, we show that the TAM optimizer admits a scalar variational description
that predicts the limiting loss, score laws, margin distribution, percentile
profile, and ridgeless phase transition. This scalar theory reveals a rich
phenomenology: a satisfiable/unsatisfiable transition, explicit limiting score
profiles, and percentile laws for where the true association sits among its
competitors. Proving the six postulates would turn this conditional prediction
into a fully rigorous capacity theory for listwise associative memory.

The fixed-tail theory also points back toward exact retrieval. Formally
sending the tail fraction
r
to the extreme value
1/(n-1)
gives a
tantalizing small-tail conjecture: the sharp top-1 threshold should be

d^{2}\sim 2n\log n,

consistent with the concurrent prediction of

23
, based on a simplified decoupled model,
and with the finite-dimensional simulations in
Section
5
. Making this prediction rigorous requires
understanding a singular extreme-tail limit, where the fixed-tail asymptotics
and the top-1 extreme-value regime meet.

Lemma 4

Proposition 10

(Retrieval threshold for correlation matrix memory)
.

Consider the limiting regime

\displaystyle n,d\to\infty,\quad\frac{d^{2}}{n\log n}\to\varrho

(254)

for some constant
\varrho\in[0,\infty]
. Then it holds that

\lim_{d\to\infty}\mathbb{P}(\mathsf{PR}_{n}(W^{\times}))=\begin{cases}1&\text{if}\quad\varrho>8,\\
0&\text{if}\quad\varrho<8.\end{cases}

(255)

Proof.

By symmetry of the solution
W^{\times}
, the events
\{F_{i}\}_{i=1}^{n}
are exchangeable. Hence when
\varrho>8
, by Lemma
7
and a union bound,

\mathbb{P}(\mathsf{PR}_{n}(W^{\times})^{c})\leq n\mathbb{P}(F_{1})\xrightarrow[n\to\infty]{}0.

Now suppose

\displaystyle=\frac{n^{2}\mathbb{P}(F_{1})^{2}}{n\mathbb{P}(F_{1})+n(n-1)\mathbb{P}(F_{1}\cap F_{2})}

where we have used Lemma

, we have

as

and so the right-hand side above tends to

. Consequently
\lim_{n\to\infty}\mathbb{P}(\mathsf{PR}_{n}(W^{\times})^{c})=1
under this regime.

Lemma 10

By optimality of

(291)

Combining (

Lower bound

(High probability lower bound)

Fix

Remark 8

(Strategy)
.

The argument is by objective gap. We exhibit a one-dimensional family
W_{t}=t\,W^{\times}
along the direction

W^{\times}\;\mathrel{\mathop{\ordinarycolon}}=\;UV^{\top}

(293)

along which
\Psi(W_{t},\mu_{0}\mathbf{1})
decreases by
\Theta(n)=\Theta(d^{2})
at small

, and complement this with the convex linearization
\Psi(W,\mu_{0}\mathbf{1})\geq\Psi(0,\mu_{0}\mathbf{1})+\langle\nabla_{W}\Psi(0,\mu_{0}\mathbf{1}),W\rangle
, whose linear term is bounded by
\|\nabla_{W}\Psi(0,\mu_{0}\mathbf{1})\|_{\mathsf{F}}\|W\|_{\mathsf{F}}=O(d\,\|W\|_{\mathsf{F}})
. Comparing the two excludes a Frobenius ball of radius
\eta d
for small

Proof.

The variable
\mu
is unregularized; we choose a fixed
\mu_{0}\in\mathbb{R}
and track the objective along the slice
\mu=\mu_{0}\mathbf{1}_{n}
throughout. Let

\mu_{0}\;\mathrel{\mathop{\ordinarycolon}}=\;-\tfrac{1}{\beta}\log\tfrac{r}{1-r},\qquad q_{0}\mathrel{\mathop{\ordinarycolon}}=\sigma(-\beta\mu_{0})=r,

(294)

so that, with
f(\mu)\mathrel{\mathop{\ordinarycolon}}=-\mu-\tfrac{1}{r}\phi_{\beta}(-\mu)
, we have
f^{\prime}(\mu_{0})=-1+\tfrac{1}{r}q_{0}=0
. Define
a_{0}\mathrel{\mathop{\ordinarycolon}}=\sigma(-f(\mu_{0}))\in(0,1)
, the activation associated with the test profile
(0,\mu_{0}\mathbf{1}_{n})
.

Step 1: Gradient at the test point.

By the gradient formula (
55
) evaluated at
W=0
,
\mu=\mu_{0}\mathbf{1}_{n}
, all
a_{i}=a_{0}
and
q_{j,i}=q_{0}=r
, hence

\nabla_{W}\Psi(0,\mu_{0}\mathbf{1}_{n})\;=\;-a_{0}\,U\,M\,V^{\top},\qquad M_{ii}=1,\quad M_{ij}=-\tfrac{1}{n-1}\ \text{for }j\neq i.

(295)

The matrix

is symmetric with eigenvalues

(on
\mathbf{1}_{n}
) and

(on

, with multiplicity

and

.

By independence of
U
and
V

\mathbb{E}[U^{\top}U]=\mathbb{E}[V^{\top}V]=I_{n}
(since each column has variance

\mathbb{E}\,\|UMV^{\top}\|_{\mathsf{F}}^{2}\;=\;\tr\!\bigl(M\,\mathbb{E}[U^{\top}U]\,M\,\mathbb{E}[V^{\top}V]\bigr)\;=\;\tr(M^{2})\;=\;\tfrac{n^{2}}{n-1}.

(296)

Hanson–Wright applied to the Gaussian quadratic form
\|UMV^{\top}\|_{\mathsf{F}}^{2}
, viewed as a degree-
4
polynomial in the i.i.d.

, yielding sub-exponential concentration: for any

(297)

for a constant

. Hence there exists a constant

such that, for every

\Omega_{d}^{(1)}\;\mathrel{\mathop{\ordinarycolon}}=\;\bigl\{\,\|\nabla_{W}\Psi(0,\mu_{0}\mathbf{1}_{n})\|_{\mathsf{F}}\;\leq\;a_{0}\,K\,d\,\bigr\}

Step 2: Directional derivative along

.

Define

, viewed as a one-dimensional convex function of

. By (

) and the symmetry of

(299)

The quantity

is a degree-

entries of

(by independence of

\Omega_{d}^{(2)}\;\mathrel{\mathop{\ordinarycolon}}=\;\bigl\{\,g^{\prime}(0)\;\leq\;-\tfrac{1}{2}\,a_{0}\,n\,\bigr\},\qquad\mathbb{P}(\Omega_{d}^{(2)})\;\geq\;1-d^{-D},

(300)

for every

Step 3: Curvature along the path.

Computing the curvature

for the smooth function

and bounding

|\phi_{\beta}^{\prime\prime}|\leq\beta/4

(301)

where

, the first two terms collapse into

\tfrac{1}{2}\sum_{i}(S^{\times}_{ii})^{2}\;+\;\Bigl(\tfrac{1}{2rk}+\tfrac{\beta}{4k}\Bigr)\sum_{i,j\neq i}(S^{\times}_{ji})^{2}.

(302)

The summed second moments of

admit the matching expectations

\mathbb{E}\!\sum_{i}(S^{\times}_{ii})^{2}\;\asymp\;n,\qquad\mathbb{E}\!\sum_{i,j\neq i}(S^{\times}_{ji})^{2}\;\asymp\;n^{2},

(303)

both inherited from the Wishart structure of

and

\Omega_{d}^{(3)}\;\mathrel{\mathop{\ordinarycolon}}=\;\Bigl\{\,\sup_{t\in[0,1]}g^{\prime\prime}(t)\;\leq\;L\,n\,\Bigr\}

. (The supremum over

Step 4: Objective gap.

Set

g(t_{\star})\;\leq\;g(0)\;+\;g^{\prime}(0)\,t_{\star}\;+\;\tfrac{1}{2}\sup_{[0,t_{\star}]}g^{\prime\prime}\cdot t_{\star}^{2}.

(305)

On
\Omega_{d}^{(2)}\cap\Omega_{d}^{(3)}
, the bounds (

) reduce (

) to

g(t_{\star})\;\leq\;g(0)\;-\;\tfrac{1}{2}\,a_{0}\,n\,t_{\star}\;+\;\tfrac{1}{2}\,L\,n\,t_{\star}^{2}\;\leq\;g(0)\;-\;\tfrac{1}{4}\,a_{0}\,n\,t_{\star}\;=\mathrel{\mathop{\ordinarycolon}}\;g(0)-c_{1}n,

(306)

with
c_{1}\mathrel{\mathop{\ordinarycolon}}=a_{0}\,t_{\star}/4>0
.

Step 5: Convex linearization and contradiction.

By optimality of
(\widehat{W},\widehat{\mu})
in
\Psi
and convexity of
\Psi(\,\cdot\,,\mu_{0}\mathbf{1}_{n})
in
W
,

\displaystyle g(0)-c_{1}n\;

\displaystyle\geq\;g(t_{\star})\;\geq\;\Psi(\widehat{W},\widehat{\mu})\;\geq\;\Psi(0,\mu_{0}\mathbf{1}_{n})\;+\;\langle\nabla_{W}\Psi(0,\mu_{0}\mathbf{1}_{n}),\,\widehat{W}\rangle

\displaystyle\geq\;g(0)\;-\;\|\nabla_{W}\Psi(0,\mu_{0}\mathbf{1}_{n})\|_{\mathsf{F}}\cdot\|\widehat{W}\|_{\mathsf{F}},

(307)

where the third inequality follows from the convex subgradient inequality around

, and the optimality

at

(which follows from

) eliminates the

\|\widehat{W}\|_{\mathsf{F}}\;\geq\;\frac{c_{1}n}{\|\nabla_{W}\Psi(0,\mu_{0}\mathbf{1}_{n})\|_{\mathsf{F}}}\;\geq\;\frac{c_{1}n}{a_{0}Kd}\;=\mathrel{\mathop{\ordinarycolon}}\;c_{0}\,d,

(308)

using (

Appendix E
A coupling lemma for bilinear Gaussian forms

This appendix establishes a coupling estimate for the joint law of bilinear forms
u_{j}^{\top}Wv_{0}
that share a common right-side Gaussian vector
v_{0}
. The estimate is the technical input behind the joint Gaussian limit for competitor scores derived in Section
4.3
, where it is applied with
W=\widehat{W}^{\setminus i,j_{1},\ldots,j_{m}}
and
v_{0}=v_{i}
.

We first prove the estimate for a deterministic matrix
W
, then transfer it to the random case via concentration of
\|W\|_{\mathsf{F}}^{2}/d^{2}
.

E.1
Deterministic matrix

Lemma 16

(Bilinear Gaussian coupling, deterministic matrix)
.

Let
W\in\mathbb{R}^{d\times d}
be a deterministic matrix with
V_{0}\mathrel{\mathop{\ordinarycolon}}=\|W\|_{\mathsf{F}}^{2}/d^{2}>0
, and let
u_{1},\ldots,u_{m},v_{0}\in\mathbb{R}^{d}
be independent Gaussian vectors with
u_{k},v_{0}\sim\mathcal{N}(0,I_{d}/d)
. Set

X_{j}\;\mathrel{\mathop{\ordinarycolon}}=\;u_{j}^{\top}Wv_{0},\qquad j=1,\ldots,m.

(310)

On a common probability space, there exist i.i.d. random variables
Y_{1},\ldots,Y_{m}\sim\mathcal{N}(0,V_{0})
such that

\bigl\|(X_{1},\ldots,X_{m})-(Y_{1},\ldots,Y_{m})\bigr\|_{2}\;=\;\mathcal{O}_{\prec}\!\bigl(\|W^{\top}W\|_{\mathsf{F}}/(d^{2}\sqrt{V_{0}})\bigr).

(311)

Remark 9

(Interpretation)
.

The deviation
\|W^{\top}W\|_{\mathsf{F}}/d^{2}
measures the spread of the eigenvalues of
W^{\top}W/d^{2}
: when the eigenvalues are concentrated,
\|W^{\top}W\|_{\mathsf{F}}/d^{2}
is small relative to
\|W\|_{\mathsf{F}}^{2}/d^{2}=\tr(W^{\top}W)/d^{2}
. In the proof below it is exactly the Hanson–Wright scale for the random conditional variance
\|Wv_{0}\|^{2}/d
.

Proof.

The argument exploits the conditional Gaussian structure of
\{X_{j}\}
given
v_{0}
.

Step 1: Conditional Gaussian.

Set
w\mathrel{\mathop{\ordinarycolon}}=Wv_{0}\in\mathbb{R}^{d}
. Conditional on
v_{0}
,
w
is deterministic, and
X_{j}=u_{j}^{\top}w
is a Gaussian linear functional of
u_{j}
. Since
u_{1},\ldots,u_{m}\sim\mathcal{N}(0,I_{d}/d)
are independent across
j
,

(X_{1},\ldots,X_{m})\,\big|\,v_{0}\;\sim\;\mathcal{N}\!\bigl(0,\,V\cdot I_{m}\bigr),\qquad V\;\mathrel{\mathop{\ordinarycolon}}=\;\frac{\|Wv_{0}\|^{2}}{d}.

(312)

Step 2: Hanson–Wright on the conditional variance.

We have

\mathbb{E}[V]\;=\;\frac{1}{d}\,\mathbb{E}[v_{0}^{\top}W^{\top}Wv_{0}]\;=\;\frac{1}{d^{2}}\,\tr(W^{\top}W)\;=\;\frac{\|W\|_{\mathsf{F}}^{2}}{d^{2}}\;=\mathrel{\mathop{\ordinarycolon}}\;V_{0},

(313)

using
\mathbb{E}[v_{0}v_{0}^{\top}]=I_{d}/d
. The Hanson–Wright inequality applied to the centered quadratic form
V-V_{0}=(1/d)(v_{0}^{\top}W^{\top}Wv_{0}-\|W\|_{\mathsf{F}}^{2}/d)
in the Gaussian vector
v_{0}
gives

V-V_{0}\;=\;\mathcal{O}_{\prec}\!\bigl(\|W^{\top}W\|_{\mathsf{F}}/d^{2}\bigr),\qquad\var V\;=\;\frac{2}{d^{4}}\,\|W^{\top}W\|_{\mathsf{F}}^{2}.

(314)

Step 3: Coupling.

Define
Y_{j}\mathrel{\mathop{\ordinarycolon}}=X_{j}\cdot\sqrt{V_{0}/V}
for each
j
. Conditional on
v_{0}
,
\{Y_{j}\}
inherit the Gaussianity and independence of
\{X_{j}\}
, with conditional variance
V\cdot(V_{0}/V)=V_{0}
. Since the conditional law
\mathcal{N}(0,V_{0}\cdot I_{m})
is independent of
v_{0}
, the unconditional joint law of
(Y_{1},\ldots,Y_{m})
is i.i.d.
\mathcal{N}(0,V_{0})
as required.

The deviation factors as

X_{j}-Y_{j}\;=\;X_{j}\bigl(1-\sqrt{V_{0}/V}\bigr)\;=\;X_{j}\cdot\frac{\sqrt{V}-\sqrt{V_{0}}}{\sqrt{V}}.

(315)

Two facts: conditional on
v_{0}
, the standardized form
X_{j}/\sqrt{V}\sim\mathcal{N}(0,1)
, so
|X_{j}/\sqrt{V}|=\mathcal{O}_{\prec}(1)
uniformly in
j
; and
|\sqrt{V}-\sqrt{V_{0}}|\leq|V-V_{0}|/\sqrt{V_{0}}
, by
\sqrt{V}+\sqrt{V_{0}}\geq\sqrt{V_{0}}
. Combined with (
314
),

|X_{j}-Y_{j}|\;=\;|X_{j}/\sqrt{V}|\cdot|\sqrt{V}-\sqrt{V_{0}}|\;=\;\mathcal{O}_{\prec}\!\bigl(\|W^{\top}W\|_{\mathsf{F}}/(d^{2}\sqrt{V_{0}})\bigr),

(316)

uniformly in
j
. For fixed
m
, we have

\|(X)-(Y)\|_{2}^{2}=\sum_{j=1}^{m}|X_{j}-Y_{j}|^{2}=\mathcal{O}_{\prec}\!\bigl((\|W^{\top}W\|_{\mathsf{F}}/(d^{2}\sqrt{V_{0}}))^{2}\bigr),

(317)

which gives (
311
).
∎

E.2
Random matrix with concentrated Frobenius norm

Corollary 1

(Bilinear Gaussian coupling, random matrix)
.

Let
W
be a random
d\times d
matrix with
\|W\|_{\mathsf{F}}>0
, independent of
u_{1},\ldots,u_{m},v_{0}
which are i.i.d.
\mathcal{N}(0,I_{d}/d)
. Let
\nu_{d}^{2}>0
be a deterministic constant. Suppose
\rho_{f},\rho_{\mathrm{op}}>0
are deterministic rates such that

\frac{\|W\|_{\mathsf{F}}^{2}}{d^{2}}-\nu_{d}^{2}\;=\;\mathcal{O}_{\prec}(\rho_{f}),\qquad\frac{\|W^{\top}W\|_{\mathsf{F}}}{d^{2}}\;=\;\mathcal{O}_{\prec}(\rho_{\mathrm{op}}).

(318)

Set
X_{j}\mathrel{\mathop{\ordinarycolon}}=u_{j}^{\top}Wv_{0}
for
j=1,\ldots,m
. On a common probability space, there exist i.i.d. random variables
Y_{1},\ldots,Y_{m}\sim\mathcal{N}(0,\nu_{d}^{2})
such that

\bigl\|(X_{1},\ldots,X_{m})-(Y_{1},\ldots,Y_{m})\bigr\|_{2}\;=\;\mathcal{O}_{\prec}\!\bigl((\rho_{\mathrm{op}}+\rho_{f})/\nu_{d}\bigr).

(319)

Proof.

The key observation is that, conditional on
(W,v_{0})
,
X_{j}/\sqrt{V}\overset{\text{iid}}{\sim}\mathcal{N}(0,1)
across
j
, where
V\mathrel{\mathop{\ordinarycolon}}=\|Wv_{0}\|^{2}/d
is the conditional variance.

Define

Y_{j}\;\mathrel{\mathop{\ordinarycolon}}=\;X_{j}\,\sqrt{\nu_{d}^{2}/V},\qquad j=1,\ldots,m.

(320)

Conditional on
(W,v_{0})
,
\{Y_{j}\}
inherit the Gaussianity and independence of
\{X_{j}\}
with variance
V\cdot\nu_{d}^{2}/V=\nu_{d}^{2}
, so the unconditional joint law of
(Y_{1},\ldots,Y_{m})
is i.i.d.
\mathcal{N}(0,\nu_{d}^{2})
as required. The deviation factors as
X_{j}-Y_{j}=X_{j}(1-\sqrt{\nu_{d}^{2}/V})=X_{j}\,(\sqrt{V}-\sqrt{\nu_{d}^{2}})/\sqrt{V}
, and using
|X_{j}/\sqrt{V}|=\mathcal{O}_{\prec}(1)
together with
|\sqrt{V}-\sqrt{\nu_{d}^{2}}|\leq|V-\nu_{d}^{2}|/\sqrt{\nu_{d}^{2}}
,

|X_{j}-Y_{j}|\;=\;|X_{j}/\sqrt{V}|\cdot|\sqrt{V}-\sqrt{\nu_{d}^{2}}|\;=\;\mathcal{O}_{\prec}\!\bigl(|V-\nu_{d}^{2}|/\sqrt{\nu_{d}^{2}}\bigr).

(321)

Decompose

V-\nu_{d}^{2}\;=\;(V-V_{0}(W))\;+\;(V_{0}(W)-\nu_{d}^{2}),\qquad V_{0}(W)\mathrel{\mathop{\ordinarycolon}}=\|W\|_{\mathsf{F}}^{2}/d^{2}.

(322)

Hanson–Wright applied to
V-V_{0}(W)
conditional on
W
gives

V-V_{0}(W)=\mathcal{O}_{\prec}\!\left(\|W^{\top}W\|_{\mathsf{F}}/d^{2}\right)=\mathcal{O}_{\prec}(\rho_{\mathrm{op}}),

(323)

using (
314
). The second piece is
\mathcal{O}_{\prec}(\rho_{f})
by (
318
). Combining with (
321
) and summing over
j
yields (
319
).
∎

Appendix F
A trace estimate for the inverse Hessian

This appendix records several elementary estimates that will be used in the characterization of the susceptibility parameter
\chi
. The first says that a fresh rank-one Gaussian direction probes the normalized trace of a bounded linear operator on
\mathbb{R}^{d\times d}
. The next two show that the normalized inverse trace is stable under the perturbations needed to simplify the TAM Hessian.

We will use the following moment notation. For a sequence of random variables
X_{d}
and deterministic positive numbers
a_{d}
, we write

X_{d}=O_{\mathcal{L}}(a_{d})

(324)

if, for every fixed
p<\infty
, there is a constant
C_{p}<\infty
such that
\|X_{d}\|_{L^{p}}\leq C_{p}a_{d}
for all sufficiently large
d
.

Lemma 17

(Fresh rank-one trace estimate)
.

Let
u,v\in\mathbb{R}^{d}
be independent Gaussian vectors with distribution
\mathcal{N}(0,I_{d}/d)
. Let
T\mathrel{\mathop{\ordinarycolon}}\mathbb{R}^{d\times d}\to\mathbb{R}^{d\times d}
be a random symmetric linear operator, independent of
(u,v)
, and assume that

\|T\|_{\mathrm{op}}=O_{\mathcal{L}}(1).

(325)

Then

\biggl\langle uv^{\top},\,T[uv^{\top}]\biggr\rangle=\frac{\tr(T)}{d^{2}}+O_{\mathcal{L}}(d^{-1/2}).

(326)

Equivalently, for every fixed
p<\infty
,

\left\|\biggl\langle uv^{\top},\,T[uv^{\top}]\biggr\rangle-\frac{\tr(T)}{d^{2}}\right\|_{L^{p}}\leq\frac{C_{p}}{\sqrt{d}}.

(327)

Proof.

Write
u=g/\sqrt{d}
and
v=h/\sqrt{d}
, where
g,h\in\mathbb{R}^{d}
are independent standard Gaussian vectors. Define

F(g,h,T)\;\mathrel{\mathop{\ordinarycolon}}=\;\biggl\langle uv^{\top},\,T[uv^{\top}]\biggr\rangle=\frac{1}{d^{2}}\bigl\langle g\otimes h,\,T[g\otimes h]\bigr\rangle.

(328)

Since
T
is independent of
(g,h)
, we have

\mathbb{E}\!\left[F(g,h,T)\mid T\right]=\frac{\tr(T)}{d^{2}}.

(329)

We first bound the fluctuation in
L^{2}
. By the Gaussian Poincare inequality applied to the variables
(g,h)
, with
T
kept fixed,

\var\!\left(F(g,h,T)\mid T\right)\leq\mathbb{E}\!\left[\|\nabla_{g}F\|^{2}+\|\nabla_{h}F\|^{2}\mid T\right].

(330)

For fixed
h
, define the compressed operator

T_{h}\mathrel{\mathop{\ordinarycolon}}=(I\otimes h)^{\ast}T(I\otimes h)\qquad\text{on }\mathbb{R}^{d},

(331)

where
(I\otimes h)g=g\otimes h
. Then

F(g,h,T)=\frac{1}{d^{2}}g^{\top}T_{h}g,\qquad\nabla_{g}F=\frac{2}{d^{2}}T_{h}g,

(332)

using the symmetry of
T
. It follows that

\mathbb{E}\!\left[\|\nabla_{g}F\|^{2}\mid T\right]=\frac{4}{d^{4}}\,\mathbb{E}\!\left[\tr(T_{h}^{2})\mid T\right].

(333)

Moreover,

where the last step uses (

\chi\to\infty
. By (
393
),
\partial_{\chi}\mathcal{P}
changes sign exactly once, from positive to negative. Hence
\chi\mapsto\mathcal{P}_{\alpha,r}(\nu,\chi)
has a unique global maximizer.

Finally we prove strong convexity of the reduced potential
\mathcal{V}_{\alpha,r}
defined in (
86
). The logistic loss has the Fenchel representation

\ell(t)=\sup_{a\in[0,1]}\left\{-at-I(a)\right\},\qquad I(a)\mathrel{\mathop{\ordinarycolon}}=a\log a+(1-a)\log(1-a),

(403)

with the convention
0\log 0=0
. Applying this pointwise in the Moreau envelope and minimizing over
s
gives

M_{r}(\nu,\chi)=\sup_{a(\cdot)\in[0,1]}\mathbb{E}\left[a(G)\bigl(c_{r}(\nu)-\nu G\bigr)-I(a(G))-\frac{\chi}{2}a(G)^{2}\right].

(404)

Taking the supremum over
\chi>0
yields

\mathcal{V}_{\alpha,r}(\nu)=\frac{\lambda}{2}\nu^{2}+\sup_{a(\cdot)\in[0,1]}\left\{\mathbb{E}\left[a(G)\bigl(c_{r}(\nu)-\nu G\bigr)-I(a(G))\right]-\frac{\nu}{\sqrt{\alpha}}\left(\mathbb{E}[a(G)^{2}]\right)^{1/2}\right\}.

(405)

For each fixed measurable
a(\cdot)
, the expression inside the supremum is a convex function of
\nu
, because
c_{r}
is convex and
\mathbb{E}[a(G)]\geq 0
; adding
\lambda\nu^{2}/2
makes it
\lambda
-strongly convex. The supremum of
\lambda
-strongly convex functions is
\lambda
-strongly convex. This proves the convexity and uniqueness assertions in Proposition
6
.

Remark 11

(Meaning of the dual optimizer)
.

The optimizer
a(G)
in (
404
) is the scalar limit of the sample-wise logistic weights. Indeed, equality in the Fenchel representation (
403
) is attained at

a=\sigma(-t).

(406)

Taking
t=S-c_{r}(\nu)
, where
S=S_{\nu,\chi}(G)
is the proximal minimizer, gives

a_{\ast}(G)=\sigma\!\bigl(-S_{\nu,\chi}(G)+c_{r}(\nu)\bigr).

(407)

Equivalently, the proximal first-order condition gives

S_{\nu,\chi}(G)=\nu G+\chi a_{\ast}(G).

(408)

Thus the dual optimizer is the limiting counterpart of the finite-dimensional coefficients
a_{i}=\sigma(-m_{i})
.
