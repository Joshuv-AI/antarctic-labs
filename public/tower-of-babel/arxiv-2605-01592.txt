Witness Set : A Visibility Problem in 𝖭𝖯 ∩ 𝖷𝖯 {\sf NP}\cap{\sf XP}
Satyabrata Jana, Debabrata Pal, Bodhayan Roy, Sasanka Roy

Abstract
We study the Witness Set problem, a natural dual 1 1 1 The Art Gallery problem is a covering problem, whereas the Witness Set problem can be viewed as a packing problem based on visibility regions. Moreover, the size of a maximum witness set provides a lower bound on the size of a minimum guard set. to the classical Art Gallery problem. In the Witness Set problem, we are given a polygon 𝒫 \mathcal{P} and an integer k k as input, and the objective is to determine whether 𝒫 \mathcal{P} has a witness set of size at least k k . A point set X ⊆ 𝒫 X\subseteq\mathcal{P} is called a witness set if every point in 𝒫 \mathcal{P} is visible from at most one point in X X . For simple polygons, we show that Witness Set lies in both 𝖭𝖯 \mathsf{NP} and 𝖷𝖯 \mathsf{XP} . This stands in sharp contrast to its dual, the Art Gallery problem, which was recently shown to be ∃ R \exists\mathbb{R} -complete by Abrahamsen et al. [ 1 ] , and is therefore neither in NP nor admits a polynomial-size discretization unless 𝖭𝖯 = ∃ R \mathsf{NP}=\exists\mathbb{R} . In contrast, we prove that Witness Set for simple polygons admits a finite discretization of size n f ⁡ ( k ) n^{f(k)} for some function f f . For comparison, even for simple polygons, Efrat and Har-Peled [ 8 ] gave an algorithm for Art Gallery running in time n 𝒪 ⁡ ( k ) n^{\mathcal{O}(k)} using tools from real algebraic geometry, and it appears difficult to obtain such algorithms without this machinery (as discussed in [ 1 ] ). On the other hand, our approach for Witness Set is purely combinatorial and relies on discretization, leading to an n f ⁡ ( k ) n^{f(k)} -time algorithm. Although Amit et al. [ 2 , Section 3.3] claimed more than fifteen years ago that Witness Set is 𝖭𝖯 \mathsf{NP} -hard, no proof or reference was provided. We show that the discrete version of the Witness Set problem – where the witness set must be chosen from a given finite point set Q Q (instead of allowing witnesses to be chosen anywhere in the polygon), referred to as Discrete Witness Set – is 𝖭𝖯 \mathsf{NP} -complete, even when the input is restricted to rectilinear polygons with holes. However, for simple polygons, Discrete Witness Set admits a polynomial-time algorithm by Das et al. [ 6 ] . Thus, it remains an open question whether the Witness Set problem is NP -hard.

Introduction

In a polygon
\mathcal{P}
, two points
p,q\in\mathcal{P}
are said to be
visible
to each other if the line segment
\overline{pq}
lies entirely
within
\mathcal{P}
. A point set
W\subseteq\mathcal{P}
is called a
witness set
if no point
of the polygon is visible from more than one point of
W
(see Figure
1
for an illustration). In contrast to
guarding problems, where the aim is to make every point of
\mathcal{P}
visible from
at least one guard, a witness set enforces exclusivity of visibility:
each location in the polygon “corresponds” to at most one witness. A witness
set is
optimal
if it is of the largest possible size. In
this work, we study the decision version of the problem.

Witness Set

Input:
A polygon
\mathcal{P}
and a non-negative integer
k
.

Question:
Does there exist a set
S
of at least
k
points in
\mathcal{P}

such that every point of the polygon
\mathcal{P}
is visible from at most one point of
S
?

Figure 1:
Example of witnesses
\{w_{1},\ldots,w_{9}\}
in a polygon
\mathcal{P}
.

1.1
Motivation and Related Work

Visibility-based optimization problems are a central theme in computational geometry.
The classical
Art Gallery
problem asks for the minimum number of guards whose visibility regions cover a polygon
[
10
,
13
]
.
Other related problems include the
Hidden Set
problem, which seeks a maximum set of pairwise non-visible points, and the
Convex Cover
problem, which partitions a polygon into convex pieces. Let
\mathtt{ws}(\mathcal{P})
,
\mathtt{gs}(\mathcal{P})
,
\mathtt{hs}(\mathcal{P})
, and
\mathtt{cc}(\mathcal{P})
denote the sizes of optimal witness sets, guard sets, hidden sets, and convex covers, respectively.
These quantities satisfy

\mathtt{ws}(\mathcal{P})\leq\mathtt{gs}(\mathcal{P})
and
\mathtt{ws}(\mathcal{P})\leq\mathtt{hs}(\mathcal{P})\leq\mathtt{cc}(\mathcal{P}),

since witnesses must be mutually exclusive in visibility and at most one hidden point can lie in any convex region.

The
Art Gallery
problem is known to be
\mathsf{NP}
-hard
[
11
]
and APX-hard
[
9
]
.
A major recent breakthrough by Abrahamsen, Adamaszek, and Miltzow
[
1
]
shows that the problem is
\exists\mathbb{R}
-complete, even for polygons with integer coordinates.
This implies that it is not in the complexity class
NP
and unlikely to admit polynomial-size discretization (certificates) or purely combinatorial algorithms unless
\mathsf{NP}=\exists\mathbb{R}
.
Indeed, optimal guard placements may require irrational coordinates, even when only two or three guards suffice.

Despite decades of research, exact algorithms for
Art Gallery
remain limited.
The only known approach, due to Efrat and Har-Peled
[
8
]
, runs in time
n^{\mathcal{O}(k)}
, where
k=\mathtt{gs}(\mathcal{P})
, using tools from real algebraic geometry
[
3
]
, and appears difficult to replicate using purely combinatorial techniques. Furthermore, strong inapproximability results are known: there is no
o(\log n)
-approximation for polygons with holes unless
\mathsf{P}=\mathsf{NP}

[
9
]
. Moreover, under the Exponential Time Hypothesis (
ETH
), there is no
n^{\mathcal{O}(k)}
-time algorithm for
Art Gallery
, even for simple polygons
[
4
]
and for polygons with holes
[
9
]
.

In contrast, the
Witness Set
problem imposes a fundamentally different constraint: instead of covering the polygon, it requires that visibility regions of selected points do not overlap.
Although this definition is simple, it leads to a visibility structure that differs significantly from both guarding and hiding.
This distinction raises the possibility that
Witness Set
admits more tractable combinatorial approaches.

The
Witness Set
problem was introduced by Amit, Mitchell, and Packer
[
2
]
.
Subsequent work has been limited.
Daescu et al.
[
5
]
gave a linear-time algorithm for two restricted subclasses of monotone polygons – uni-monotone polygons and monotone mountains.
In fact, they showed that
\mathtt{ws}(\mathcal{P})=\mathtt{gs}(\mathcal{P})
when
\mathcal{P}
belongs to either of these classes.
More recently, Das et al.
[
6
]
extended these results to monotone polygons.
They presented an exact algorithm for
Witness Set
running in time
r^{\mathcal{O}(k)}\cdot n^{\mathcal{O}(1)}
, based on a discretization approach, where
r
and
n
denote the number of reflex vertices and total vertices of the input polygon, respectively..
In addition, they designed a
(1+\epsilon)
-approximation scheme (
PTAS
) with running time
r^{\mathcal{O}(1/\epsilon)}\cdot n^{2}
.
They also showed that the
Discrete Witness Set
problem can be solved in polynomial time.

Overall, while guarding problems are deeply connected to algebraic and continuous complexity, witness sets appear to admit a more combinatorial structure.
This motivates a systematic study of their algorithmic and complexity-theoretic properties.

1.2
Our Perspective

This work is motivated by the following fundamental questions about Witness Set:

•

Is
Witness Set
in
\mathsf{NP}
?

•

Does
Witness Set
admit a finite discretization of size
n^{f(k)}
for some computable function
f
?

These two questions are motivated by the stark contrast with the
Art Gallery
problem, whose decision version is
\exists\mathbb{R}
-complete
[
1
]
, and therefore not in
NP
as well as unlikely to admit polynomial-size certificates unless
\mathsf{NP}=\exists\mathbb{R}
.

The second question concerns whether the continuous search space of candidate witness points can be reduced to a finite set. More precisely, given an instance of
Witness Set
, can we, in time
n^{f(k)}
, construct a finite point set
Q\subseteq\mathcal{P}
such that whenever
\mathcal{P}
admits a witness set of size at least
k
, the set
Q
also contains one?

A positive answer would have strong algorithmic consequences. Combined with a polynomial-time algorithm for the discrete variant of
Witness Set

[
6
]
, such a discretization would yield an
n^{g(k)}
-time algorithm, for some computable function
g
, for deciding the existence of a witness set of size
k
.

Unlike the
Art Gallery
problem, which is governed by coverage constraints,
Witness Set
enforces pairwise non-overlap of visibility regions. This structural distinction enables a combinatorial discretization approach, which we exploit in this work.

1.3
Our Contributions

We present the first general algorithmic and complexity-theoretic framework
for the
Witness Set
problem in simple polygons. Our main results are summarized below.

Section

4
. Discretization Framework.

We show that
Witness Set
admits a finite discretization scheme.
Our approach is based on a novel geometric ordering of witness points captured by a

neighbor witness graph
, whose chordality property plays a central role.

Theorem 1
.

The
Witness Set
problem in a simple polygon admits a finite discretization computable in

n^{f(k)}
time, for some computable function
f
. Moreover, within the same running time one can construct a finite set

Q
of size
n^{f(k)}
such that
\mathcal{P}
contains a witness set of size
k
if and only if
Q
contains one.

The construction relies on a structural analysis of visibility regions, windows,
and non-visible components. Algorithm
1
incrementally builds the set
Q
by generating maximal visibility chords and their intersections, followed by midpoint insertions that ensure completeness of the discretization.

Section

4.3
. Exact Algorithm.

Using the above discretization, we obtain an exact algorithm for
Witness Set
.

Theorem 2
.

For simple polygons,
Witness Set
can be solved in time
n^{f(k)}
, for some computable function
f
.

This follows by reducing the continuous problem to the discrete instance on
Q
. Since the discrete variant can be solved in polynomial time
[
6
]
, the overall running time becomes
n^{f(k)}
.

In particular, this implies that
Witness Set
belongs to the class
XP
(slice-wise polynomial time). Recall that a parameterized problem is in
XP
if it can be solved in time
n^{f(k)}
for some computable function
f
, where
n
denotes the input size and
k
is the parameter.

Section

6
. Membership in
\mathsf{NP}
.

In contrast to the
Art Gallery
problem, which is not in
\mathsf{NP}
unless
\mathsf{NP}=\exists\mathbb{R}
, we show that
Witness Set
lies in
\mathsf{NP}
.

Theorem 3
.

The
Witness Set
problem in simple polygons is in
\mathsf{NP}
.

The proof is based on a certificate consisting of
k
witness points, whose validity can be verified by computing visibility polygons and checking pairwise intersections in poly-time.

Section

5
. Hardness of the Discrete Variant.

Finally, we establish the computational hardness of the discrete version of the problem.

Theorem 4
.

Discrete Witness Set
is
\mathsf{NP}
-complete for polygons with holes, even when restricted to rectilinear polygons.

The reduction is from
Planar Monotone Rectilinear 3SAT

[
7
]
.

Taken together, these results provide the first cohesive understanding of the algorithmic and complexity landscape of
Witness Set
.
In particular, the problem admits a combinatorial discretization and exact algorithms in simple polygons, while becoming
\mathsf{NP}
-complete in the presence of holes.
We believe that the structural insights developed here may also be useful for other visibility-based optimization problems.

Preliminaries

Definition 5

(Polygon, Polygon with holes, Simple Polygon)
.

A
polygon
is a closed region in the plane bounded by a finite sequence of non-intersecting line segments, called its
edges
. The endpoints of these edges are its
vertices
. A
polygon with holes
is a polygon whose boundary consists of more than one disjoint simple cycle: one outer boundary and one or more interior boundaries. A polygon is
simple
if it is neither self-intersecting nor contains holes.

For a polygon
\mathcal{P}
, we denote its boundary by
\mathsf{\delta}(\mathcal{P})
and its interior by
\mathsf{iN}(\mathcal{P})
. A vertex of
\mathcal{P}
is
convex
if its interior angle is at most
180^{\circ}
; otherwise, it is
reflex
. For a line segment
\overline{ab}
, we denote its interior by
iN(\overline{ab})

\coloneq\overline{ab}\setminus\{a,b\}
and its boundary by
\mathsf{\delta}(\overline{ab})

\coloneq\{a,b\}
.

Definition 6

(Hairy polygon)
.

A
hairy polygon

\mathcal{P}_{h}
(
fig.

2
) consists of (i) a simple polygon
\mathcal{P}
(the
body
), and (ii) a finite set of line segments
\{e_{1},\ldots,e_{k}\}
, called
arms
, each attached to a distinct vertex of
\mathcal{P}
and lying outside of
\mathcal{P}
except at the attachment point.

Figure 2:
Example of a hairy polygon.

Definition 7

(Visibility)
.

Two points
x,y\in\mathcal{P}
are
visible
to each other if the segment
\overline{xy}
is contained entirely in
\mathcal{P}
. The
visibility region
of
p
is
\mathsf{Vis}(p)=\{q\in\mathcal{P}:\overline{pq}\subseteq\mathcal{P}\}
. For a set
S\subseteq\mathcal{P}
,
\mathsf{Vis}(S)=\bigcup_{p\in S}\mathsf{Vis}(p)
.

If
\mathsf{Vis}(p)
is a hairy polygon, there may exist two distinct reflex vertices
r,r^{\prime}\in\mathsf{Vis}(p)
such that
p,r,
and
r^{\prime}
are collinear; see
fig.

3
.

Figure 3:
Example of visibility region which is a hairy polygon.

Definition 8

(Window)
.

A segment
l=[a,b]
is a
window
of
\mathsf{Vis}(p)
if
l\subseteq\mathsf{\delta}(\mathsf{Vis}(p))
,
l\cap\mathsf{\delta}(\mathcal{P})=\{a,b\}
, and
l
is maximal with this property. The endpoint closer to
p
is called the
base
, and the other is called the
end
.. For an illustration, see
fig.

4
.

Definition 9

(Wall)
.

A segment
l\subseteq\mathsf{\delta}(\mathcal{P})\cap\mathsf{\delta}(\mathsf{Vis}(p))
is a
wall
of
\mathsf{Vis}(p)
if it is maximal in
\mathsf{\delta}(\mathcal{P})\cap\mathsf{\delta}(\mathsf{Vis}(p))
. For an illustration see
fig.

4
.

Figure 4:
The red region denotes
\mathsf{Vis}(p)
.
\overline{ab}
represents a window of
\mathsf{Vis}(p)
, whereas
\overline{bc}
corresponds to a wall of
\mathsf{Vis}(p)
.
b
is the base of the window
\overline{ab}
and
a
is the end.

Lemma 10
.

Let
e_{1},e_{2}
be two distinct windows of
\mathsf{Vis}(p)
such that neither of them is part of any arm (
definition

6
) of
\mathsf{Vis}(p)
. Then
e_{1}
and
e_{2}
cannot be consecutive, i.e.,
e_{1}\cap e_{2}=\emptyset
.

Proof.

If these windows are consecutive edges of
\mathsf{Vis}(p)
, then their common endpoint is
p
, since any window is collinear with
p
. From the definition of window,
p\in\mathcal{P}
. However, this is a contradiction, since it cannot happen that
p\in\mathsf{\delta}(\mathcal{P})
while the segments of
\mathsf{\delta}(\mathsf{Vis}(p))
incident to
p
are not walls of
\mathsf{Vis}(p)
.
∎

and

, unless stated otherwise, all polygons are simple.

3
Neighbor Witness Graph is Chordal

In this section, we introduce the
neighbor witness graph
associated with a witness set and establish that this graph is chordal when restricted to simple polygons. The proof relies on structural properties of non-visible components and windows.

Definition 11

(Near polygon)
.

A region
\mathcal{P}^{\prime}
is called a
near polygon
if there is a simple polygon
\mathcal{P}
such that
\mathcal{P}^{\prime}\subseteq\mathcal{P}
and
\mathcal{P}^{\prime}=\mathcal{P}\setminus B
for some
B\subseteq\mathsf{\delta}(\mathcal{P})
. We define
\mathsf{\delta}(\mathcal{P}^{\prime})\coloneq\mathsf{\delta}(\mathcal{P})
. Two near polygons,
\mathcal{P}_{1}
and
\mathcal{P}_{2}
are said to be
attached
to each other if
iN(\mathcal{P}_{1})\cap iN(\mathcal{P}_{2})=\emptyset
and
\mathsf{\delta}(\mathcal{P}_{1})\cap\mathsf{\delta}(\mathcal{P}_{2})\neq\emptyset
. Note that, the closure of a near polygon is always a simple polygon.

Definition 12

(Witness set)
.

In a polygon
\mathcal{P}
, a finite point set
W\subseteq\mathcal{P}
is said to be a
witness set
of
\mathcal{P}
if
\mathsf{Vis}(x)\cap\mathsf{Vis}(y)=\emptyset\text{ for all distinct }x,y\in W.
See Figure
5
.

Definition 13

(Non-visible region)
.

For a witness set
W
of a polygon
\mathcal{P}
, we define its
non-visible region
as
\mathsf{NVis}(W)=\mathcal{P}\setminus\mathsf{Vis}(W)
. For an illustration, see
fig.

5
. Observe that, each component of
\mathsf{NVis}(W)
is a near polygon.

Figure 5:
A polygon
\mathcal{P}
with a witness set
W=\{w_{1},w_{2},...,w_{9}\}
and corresponding visibility region.
\mathsf{NVis}(W)
is defined by the union of the gray regions.

Let
W=\{w_{1},\dots,w_{k}\}
be a witness set of the polygon
\mathcal{P}
.

Lemma 14
.

Let
w\in W
be such that
\mathsf{Vis}(w)
has some arms. Then there exists
w^{\prime}\in\mathsf{Vis}(w)
such that
(W\setminus\{w\})\cup\{w^{\prime}\}
is a witness set of size
|W|
and
\mathsf{Vis}(w^{\prime})
has no arms.

Proof.

Arms of
\mathsf{Vis}(w)
arise only from finitely many pairs of reflex vertices collinear with
w
. Choose
\varepsilon>0
sufficiently small so that for all
w^{\prime}\in B_{\varepsilon}(w)
,
\mathsf{Vis}(w^{\prime})\cap\mathsf{Vis}(v)=\emptyset
for all
v\in W\setminus\{w\}
. The existence of
\varepsilon
is assured since there is always a component of
\mathsf{NVis}(W)
around each
e_{i}
, so if we move
w
slightly in any direction, the new visibility region would not intersect the visibility regions of the other witness points. Pick
w^{\prime}
in the interior of
B_{\varepsilon}(w)
that is not collinear with any such reflex pair. Then
\mathsf{Vis}(w^{\prime})
has no arms, and
W^{\prime}
remains a witness set.
∎

Henceforth, w.l.o.g., we assume that for every
w\in W
,
\mathsf{Vis}(w)
is a simple polygon.

We now introduce a graph, called the neighbor witness graph associated to the witness set
W
, which captures the idea of the neighborhood of a witness point.

Definition 15

(Neighbor witness path)
.

A
neighbor witness path
between a pair of distinct witnesses
w_{i}
and
w_{j}
is a continuous path contained in
\mathsf{Vis}(w_{i})\cup\mathsf{NVis}(W)\cup\mathsf{Vis}(w_{j})
.

Black curves are neighbor witness paths.

See
fig.

6
for an illustration of neighbor witness path. Note that, it is possible that two witness points admit no neighbor witness path between them. For example, in
Figure

6
, there is no neighbor witness path between
w_{1}
and
w_{7}
. The following observation follows immediately from the above definition.

Observation 16
.

If
\gamma_{ij}
is a neighbor witness path between
w_{i}
and
w_{j}
, then
\gamma_{ij}\cap\mathsf{Vis}(w_{k})=\emptyset
for each
w_{k}\in W\setminus\{w_{i},w_{j}\}
.

The graph
\mathsf{GCon}(W)
corresponding to the witness set in

.

Definition 17

(Neighbor witness graph)
.

Let
W
be a witness set. The
neighbor witness graph

\mathsf{GCon}(W)
is the graph with vertex set
W
, where distinct vertices
w_{i},w_{j}
are adjacent if and only if a neighbor witness path exists between them. See
fig.

7
.

Definition 18

(Neighbor witness)
.

For
w\in W
, a point
v\in W\setminus\{w\}
is a
neighbor witness
of
w
if
vw
is an edge of
\mathsf{GCon}(W)
. The set of all such neighbors is denoted by
\mathsf{N}(w)
.

Observe that if a component of
\mathsf{NVis}(W)
attaches to
\mathsf{Vis}(w)
for some

w\in W
, then this attachment can occur only along a window
of
\mathsf{Vis}(w)
. This is because no portion of
\mathsf{\delta}(\mathcal{P})
can serve as a common
boundary between a visibility region and a component of
\mathsf{NVis}(W)
.
Furthermore, whenever a window participates in such an attachment,
the connection necessarily extends over its entire length.

Lemma 19

(Uniqueness of attached component)
.

Let
w\in W
, and let
NV_{1},NV_{2}
be connected components of
\mathsf{NVis}(W)
attached to
\mathsf{Vis}(w)
. Let
e_{1},e_{2}
be the windows of
\mathsf{Vis}(w)
along which
NV_{1},NV_{2}
are attached. Then
NV_{1}=NV_{2}
if and only if
e_{1}=e_{2}.

Proof.

The forward implication is immediate: whenever a component is attached to a visibility region, it is necessarily tied to exactly one window. This is a direct consequence of the fact that
\mathcal{P}
is a simple polygon and, by
lemma

10
, two windows cannot occur consecutively. For the reverse direction, assume that
e_{1}=e_{2}=e
. Observe that both
NV_{1},NV_{2}
are attached to
\mathsf{Vis}(w)
on the same side of
e
, otherwise, if
NV_{1}
and
NV_{2}
are on either side of
e
then one of them must have a non-empty intersection with
\mathsf{Vis}(w)
. Now
NV_{1},NV_{2}
lie on the same side of
e
and the entire length of
e
is involved for both attachments, so it follows that
NV_{1}\cap NV_{2}\neq\emptyset
. Since distinct connected components are necessarily disjoint, we conclude that
NV_{1}=NV_{2}
.
∎

Lemma 20
.

Let
a,b\in\mathcal{P}
, and let
\gamma_{1},\gamma_{2}\subseteq\mathcal{P}
be two simple paths from
a
to
b
. Let
R
be the closed region bounded by
\gamma_{1}\cup\gamma_{2}
. Then the interior of
R
contains no points of
\mathsf{\delta}(\mathcal{P})
.

Proof.

If
\mathsf{\delta}(\mathcal{P})
contained a point strictly inside
R
, then a portion of
\mathsf{\delta}(\mathcal{P})
would lie entirely inside
\mathcal{P}
, contradicting the fact that
\mathcal{P}
is a simple polygon.
∎

Lemma 21

(Unique component between neighbors)
.

Let
v,w\in W
be neighbor witnesses. Then there exists exactly one component of
\mathsf{NVis}(W)
attached to both
\mathsf{Vis}(v)
and
\mathsf{Vis}(w)
.

Proof.

Since
v
and
w
are neighbor witnesses of each other, there must exist a component of
\mathsf{NVis}(W)
that lies between their respective visibility regions. Our goal is to establish the uniqueness of such a component.

.

Assume, for contradiction, that there are two distinct components
NV_{1}
and

of
\mathsf{NVis}(W)
that are attached to both
\mathsf{Vis}(v)
and
\mathsf{Vis}(w)
. Now, using
Lemma

, suppose that
NV_{1}
is attached to
\mathsf{Vis}(v)
via the window
e_{1}
. Similarly, let
NV_{2}
be attached to
\mathsf{Vis}(v)
via the window
e_{2}
. Let
\gamma_{1}
be a neighbor witness path between
v
and
w
that passes through
e_{1}
and
NV_{1}
, and let
\gamma_{2}
be another neighbor witness path that passes through

and
NV_{2}
. Since
e_{1}
and
e_{2}
are both windows of

4

In this section, our aim is to find an algorithm for the

Placing Each Witness to an Algorithmically Generated Point

4.2.1
The Discretization Algorithm

The set
Q
serves as a discretization of all possible witness locations.
The construction is entirely combinatorial and depends only on the input polygon

\mathcal{P}
and given integer parameter
k
, the size of the witness set we plan to
replace. The following algorithm generates the set
Q
.

1

Input :
A simple polygon
\mathcal{P}
and an integer
k\in\mathbb{N}
.

Output :
A finite point set
Q
.

2

set of all edges of
\mathcal{P}
;

R\coloneqq
set of all reflex vertices of
\mathcal{P}
;

3

Initialization:
Q\leftarrow V(\mathcal{P})
;
L\leftarrow E(\mathcal{P})
; ;

4

5

for

i\leftarrow 1

to

2(k-1)

do

set of all maximal chords joining

to

if

is visible from

;

Q^{\prime}\leftarrow\{\,l^{\prime}\cap l\mid l^{\prime}\in L^{\prime},~l\in L,~l^{\prime}\cap l\neq\emptyset\,\}

;

Q\leftarrow Q\cup Q^{\prime}
;

Choose any visible pair

;

M\leftarrow\left\{\,\frac{v_{1}+v_{2}}{2}\,\right\}

Q\leftarrow Q\cup M
;

for

(\mathcal{P},k)
: Generation of the discretizing set

.

Brief Description of the Algorithm :

Here we provide a short description of
Algorithm

1
. Initially, we set
Q=V(\mathcal{P})
and
L=E(\mathcal{P})
. Iteratively, we construct chords from every point in the current set
Q
(as updated in the previous iteration) by joining it with the reflex vertices visible from that point and extending the resulting segment until it meets the boundary of
\mathcal{P}
. We refer to this procedure of generating chords from points in
Q
as forming the

. In each iteration of the first
for
loop (
2(k-1)
times), we draw an arrangement and then update
Q
by adding the intersection points between the newly created chords and the existing line segments of

. These points serve as candidates for replacing the first
k-1
witness points (by clone points, see

37
) among the
k
witness points. A clone of a point refers to another point that lies infinitesimally close to the original one. Observe that the lines produced by the arrangement form a superset of the boundaries of the visibility regions of the points in
Q
from the previous iteration. Next, between the two
for
loops, we compute the midpoints of all pairs of mutually visible points and update
Q
by inserting these midpoints. This step replaces the last witness point with an algorithmically generated point (rather than a clone). In each iteration of the second
for
loop (

times), we construct arrangements, update
Q
, compute the midpoints of all mutually visible pairs of points in
Q
, and insert these midpoints into
Q
. This procedure adjusts the previous positions of the witness points to appropriate points in
Q
(that is, from clones to mid-points).

The following observation is immediate from the construction of

:

Observation 34
.

The following holds for

.
Let

, where

is obtained from an intermediate iteration. Then, in the next iteration,

includes the vertices of
\mathsf{Vis}(v_{i})
for each

, as well as the intersection points of the edges of
\mathsf{Vis}(v_{1})
and
\mathsf{Vis}(v_{2})

.

4.2.2
Correctness of the Construction

To prove the correctness of the algorithm, we consider an arbitrary witness set
W
and show that there exists a corresponding replacement of
W
within
Q
.

Definition 35

(Perfect Elimination Ordering)
.

A
perfect elimination ordering
of a graph
G
on
n
vertices is an ordering
\{v_{1},\ldots,v_{n}\}
of
G
’s vertices such that, for each
i
, the vertex
v_{i}
is simplicial in the subgraph induced by
\{v_{i},\ldots,v_{n}\}
. It is well known that every chordal graph has a perfect elimination ordering, and can be computed in polynomial time. Consequently, every chordal graph contains a simplicial vertex.

Let
|W|=k
and
G_{1}\coloneqq\mathsf{GCon}(W)
. Since
G_{1}
is chordal (from
theorem

24
), let
\{w_{1},\ldots,w_{k}\}
be a perfect elimination ordering of
G_{1}
. Define
G_{i}
to be the subgraph of
G_{1}
induced by the vertex set
W_{i}=\{w_{i},\ldots,w_{k}\}
. Clearly,
w_{i}
is a simplicial vertex of
G_{i}
.

Now consider the analogous argument for the polygon
\mathcal{P}
with the witness set
W=\{w_{1},\dots,w_{k}\}
, similar to the construction of the sequence of graphs
G_{i}
. Initially, we begin with the witness set
W=W_{1}=\{w_{1},\dots,w_{k}\}
and its associated non-visibility region
\mathsf{NVis}(W_{1})=\mathcal{P}\setminus\left(\bigcup_{j=1}^{k}\mathsf{Vis}(w_{j})\right)
. After removing
w_{1}
, we update the witness set to
W_{2}
, and the corresponding non-visible region becomes
\mathsf{NVis}(W_{2})\coloneq\mathsf{NVis}(W_{1})\cup\mathsf{Vis}(w_{1}).
More generally, at the
(i-1)
th step, after removing
w_{i-1}
, the witness set
W_{i-1}
is updated to
W_{i}
and the corresponding non-visible region is updated as
\mathsf{NVis}(W_{i})\coloneq\mathsf{NVis}(W_{i-1})\cup\mathsf{Vis}(w_{i-1}).

From the lemma below, we obtain
G_{i}=\mathsf{GCon}(W_{i})
.
Although this may seem immediate, one might worry that deleting some of the witness points
w_{1},\dots,w_{i-1}
could create new edges between the remaining witnesses; however, this does not occur in our setting.
Thus, deleting a witness point from
\mathsf{GCon}(W_{i})
is equivalent to removing the corresponding node from
G_{i}
. For each
w\in W_{i}
, we define

\mathsf{N}_{i}(w)
as the neighbors of
w
in
G_{i}
.

Lemma 36
.

G_{i}=\mathsf{GCon}(W_{i})
for each
i\in[k]
.

Proof.

We prove this by induction. For the base case we have
G_{1}=\mathsf{GCon}(W_{1})
which follows from the definition of
G_{1}
and
\mathsf{GCon}(W_{1})
.

Let for some
l~(1\leq l<k)
,
G_{l}=\mathsf{GCon}(W_{l})
. We prove
G_{l+1}=\mathsf{GCon}(W_{l+1})
. We have that the vertex set of
\mathsf{GCon}(W_{l+1})
is the same as the vertex set of
G_{l+1}
. Now an edge which is in
G_{l+1}
must be also in
\mathsf{GCon}(W_{l+1})
since for
j_{1},j_{2}>l
, if there is a path
\gamma\subset\mathsf{Vis}(w_{j_{1}})\cup\mathsf{NVis}(W)\cup\mathsf{Vis}(w_{j_{2}})
(which produces an edge in
G_{1}
as well as in
G_{l+1}
) between
w_{j_{1}}
and
w_{j_{2}}
then
\gamma
is also contained inside
\mathsf{Vis}(w_{j_{1}})\cup\mathsf{NVis}(W_{l+1})\cup\mathsf{Vis}(w_{j_{2}})
as
\mathsf{NVis}(W)\subset\mathsf{NVis}(W_{l+1})
.

Now assume, for contradiction, removal of
w_{l}
and addition of
\mathsf{Vis}(w_{l})
with
\mathsf{NVis}(W_{l})
, gives rise to a new edge between
w_{j_{1}}
and
w_{j_{2}}
which was not in
G_{l}
(and hence not in
G_{l+1}
either). Then
w_{j_{1}}
and
w_{j_{2}}
must be in
\mathsf{N}_{l}(w_{l})
. But since
w_{l}
is simplicial in
G_{l}
, so
\mathsf{N}_{l}(w_{l})
forms a clique in
G_{l}
. Thus no new edge can be added between
w_{j_{1}}
and
w_{j_{2}}
which is a contradiction to our assumption. And hence
G_{l+1}=\mathsf{GCon}(W_{l+1})

Discrete Witness Set

We present a polynomial-time reduction from the

problem, which is known to be

[
7

An instance of PMR3SAT is a CNF formula
\Phi
with
n

m

•

each clause of
\Phi
has at most three literals,

•

each clause is monotone (either all-positive or all-negative),

•

the variable–clause incidence graph admits a rectilinear planar embedding where variables are represented by axis-aligned rectangles lying on a common horizontal line, positive clauses are above that line, negative clauses below, and each clause is connected to its variables by vertical segments without crossings.

The objective of

is to determine whether
\Phi

.

Brief Overview of the reduction.

Given a rectilinear embedding of an instance
\Phi
of PMR3SAT (witn
n
variable and
m
clauses) we build a polygon
\mathcal{P}
with holes and a candidate point set
Q\subset\mathcal{P}
with the following properties (see Figure
17
for an illustration): each variable
v
corresponds to a
variable gadget

R_{v}
placed on the variable line; each clause
C
corresponds to a
clause gadget

R_{C}
placed either above (if
C
is positive) or below (if
C
is negative) the variable line; and whenever variable
v
occurs in clause
C
we connect
R_{v}
and
R_{C}
by a thin vertical corridor (a narrow rectilinear strip) that enforces specific visibility relations between points in the two gadgets. We choose the candidate set
Q
so that:

•

every clause gadget
R_{C}
contains exactly three
blue
candidate points (one per incident variable edge position),

•

every variable gadget
R_{v}
contains
m

orange
points and
m

red
points (for a uniform counting argument we place
m
copies of each color per variable).

Thus
|Q|=2mn+3m
.
Intuitively each variable gadget allows us to pick either all orange points (representing truth) or all red points (representing false), but not both. Each blue point in a clause gadget can be selected only if the connected variable gadget has chosen the matching color (so a positive clause’s blue can be selected only if the corresponding variable gadget chose orange; a negative clause’s blue only if that variable chose red). Clause gadgets are arranged so that at most one blue point per clause can be selected (blue points in the same clause conflict pairwise). We set the target threshold
k:=mn+m
. The reduction ensures
\Phi
satisfiable if and only if there exists an witness set
S\subseteq Q
with
|S|\geq k
.

Gadget Construction.

Variable Gadget.

Each variable gadget
R_{v}
is an rectilinear polygon placed on the variable line. Inside

we place two groups of candidate points:
m

R_{v}
,
m

R_{v}
. We placed the red-orange points in such a way that in each variable gadget
R_{v}
the following hold:

1.

Any two orange (resp, red) points have disjoint visibility regions inside
R_{v}
(so they can all be simultaneously chosen).

2.

Any orange point and the next red point (according to there position along the boundary) have intersecting visibility regions, so we cannot choose both of them.

Clause Gadget.

Each clause gadget

is axis-aligned rectangle placed above (for positive) or below (for negative) the variable line. In
R_{C}
we place three blue points corresponding to the three incident variable-edges (if a clause has fewer than three literals we leave unused positions empty). We placed the blue points in such a way that in each clause gadget
R_{C}
the following hold:

1.

Any two blue points in the same clause gadget have intersecting visibility regions, so at most one blue point can be chosen from
R_{C}
).

2.

For each incident variable
v
of

We construct

For each variable

•

For each clause

mn

n

Claim 42

(Soundness)
.

If
\mathcal{P}
has
k=mn+m
witnesses
S\subseteq Q
then
\Phi
is satisfiable.

{claimproof}

First observe that each clause gadget contributes at most one blue point to any valid witness set. Hence the total number of blue points in
S
is at most
m
. Second, within each variable gadget
R_{v}
, we cannot simultaneously choose an orange and a red point. But we can choose up to
m
points in
R_{v}
by selecting all orange or all red assigned copies.

Hence the maximum number of points one can choose while respecting pairwise-disjointness is achieved by, for each variable gadget, choosing all
m
points of one color (either all orange or all red), and for each clause choosing at most one blue; this yields an upper bound of
mn+m
points total. Since
|S|\geq mn+m
, it follows that:

•

For every variable gadget
R_{v}
the set
S
must contain exactly
m
chosen points from
R_{v}
, and these must all be of the same color (otherwise the variable gadget could contribute strictly fewer than
m
points because red and orange conflict pairwise).

•

For every clause gadget,
S
must contain exactly one blue point (because if some clause contributed zero blue points, then even choosing
m
from each variable would give at most
mn<mn+m
total).

Thus from
S
we can extract a truth assignment: set variable
v
to
true
if
S
selects all orange points of
R_{v}
, and set
v
to
false
if
S
selects all red points of
R_{v}
.

It remains to verify that every clause
C
is satisfied by this assignment. Consider the blue point of
R_{C}
that is contained in
S
. By construction of the corridors, that blue point is compatible with the chosen color in the variable gadget at the corridor it sits above/below; specifically:

•

If
C
is a positive clause and the chosen blue point in
R_{C}
is the one adjacent to variable
v
, then that blue point is compatible only when
R_{v}
contributed orange points to
S
(i.e.,
v=\texttt{true}
). Therefore this clause has a true literal.

•

If
C
is negative, the analogous argument shows the adjacent variable
v
contributed red points to
S
(i.e.,
v=\texttt{false}
), so the clause is satisfied.

Hence every clause contains at least one true literal under the derived assignment, and therefore
\Phi
is satisfiable. This proves soundness.

Witness Set
is in

Proving
\mathsf{NP}
-hardness for visibility problems requires care, as the classical
Art Gallery
problem is
\exists\mathbb{R}
-complete
[
1
]
, and therefore not in
\mathsf{NP}
unless
\mathsf{NP}=\exists\mathbb{R}
. In contrast, we show that its dual problem, the
Witness Set
problem, lies in
\mathsf{NP}
. A certificate consists of a finite set of points
S=\{p_{1},\dots,p_{k}\}
inside a polygon
\mathcal{P}
. To verify that
S
is a valid witness set, we proceed as follows.

1.

For each point
p_{i}\in S
, compute its visibility polygon
\mathrm{Vis}(p_{i})
within
\mathcal{P}
. It is well known that the visibility polygon of a point in a polygon with
n
vertices can be computed in linear time
[
12
]
.

2.

For every pair of distinct points
p_{i},p_{j}
, check whether the corresponding visibility polygons
\mathrm{Vis}(p_{i})
and
\mathrm{Vis}(p_{j})
intersect. This can be done by testing for intersection between two polygons, which reduces to checking for edge intersections and containment, and can be solved in polynomial time
[
14
]
.

3.

Accept if and only if for all pairs
p_{i},p_{j}
with
i\neq j
, we have

\mathrm{Vis}(p_{i})\cap\mathrm{Vis}(p_{j})=\emptyset.

7
Conclusion

In this work, we present first discretization framework for the

Witness Set
in simple polygons, together with structural
characterizations that yield an
n^{f(k)}
–time algorithm to solve
Witness Set
with some
f
, where
k
is the desired witness-set size. Several directions for future research remain open.

•

Our discretization produces a finite candidate set

Q
of size
n^{h(k)}
for computable function
h
, the current bounds are unlikely to be tight.
Obtaining substantially smaller discretizations – ideally of size

g(r,k)\,n^{\mathcal{O}(1)}
would significantly strengthen the approach.

•

Determining whether constant-factor approximations or even
PTAS-type algorithms exist for
Witness Set
is an appealing question.

•

While our exact algorithm places the problem in
XP
when
parameterized by
k
, it remains open whether an
FPT
algorithm in
k
is possible.

•

Our
NP
-hardness result is on
Discrete Witness Set
for the polygons with holes. It remains an open question whether the
Witness Set
problem is
NP
-hard.
