Jarod Morris, Xiuzhen Ye, Wentao Tang

Abstract
Despite the popularity of Koopman modeling for nonlinear systems, in the presence of input variables, the evident nonexistence of a fully linear time-invariant model even in infinite dimensions makes Koopman-based control largely an open problem to date. Focusing on discrete-time systems in this paper, which eschews from using operator semigroup and infinitesimal generator notions, it is proven that nonlinear systems, if satisfying appropriate smoothness and regularity conditions, can be expressed exactly as bilinear dynamics , when the state variables and input variables are separately lifted into their reproducing kernel Hilbert spaces (RKHSs). To account for the knowledge of an equilibrium point at the origin, the RKHS is defined by a linear–radial product kernel, and hence the functions belonging to this RKHS are spanned by the multiplications of component functions and Sobolev functions. The stabilization problem, namely the determination of a feedback law that causes a Lyapunov function (expressed as a kernel sum-of-squares form) to decrease, is then posed as an infinite-dimensional optimization problem over state-dependent conditional probability measures over the input space, solved via a discretization scheme.

Introduction

The interest in Koopman operator theory once gave a hope that nonlinear control problems, if using some state lifting, can be converted to that for a linear time-invariant (LTI) system
[
18
,
14
]
.
The shortcoming in this ambiguous LTI postulate and its misleading effect on later literature is evident — given a nonlinear system with inputs in discrete time:
x_{t+1}=f(x_{t},u_{t})
, hereafter simply written as

x^{+}=f(x,u),\kern 5.0ptf:\mathbb{R}^{n}\times\mathbb{R}^{m}\to\mathbb{R}^{n},

(1)

there is clearly no finite-dimensional “lifting”
z=\phi(x)
such that
z^{+}=Az+Bu
can be satisfied for some matrices
A
and
B
.
Indeed, since the Koopman operator

generally must be defined on an infinite-dimensional function space, except for very restrictive cases
[
20
]
, the Koopman model for (
1
) cannot be a finite-dimensional LTI one.
In fact, even in infinite dimensions, an LTI representation is absent, as the effect of inputs on the lifted states cannot be expected to be a constant gain.
Such an observation has been well pointed out by practitioners
[
5
]
, which motivated the use of bilinear Koopman models
[
6
]
among other types of customized linear Koopman models, e.g., for Volterra systems or Hammerstein systems

The bilinearity can be interpreted in the following way. Considering the Koopman operator defined for (
1

, it maps from a space of state-dependent functions into a state-and-input-dependent functions; for the latter space, any function should be spanned by features of states and inputs altogether.
Formally, this can be expressed in the language of reproducing kernel Hilbert spaces (RKHS) — in Bevanda et al.
[
2
]

control Koopman operator

Another approach to formulate a bilinear Koopman model is to use continuous-time input-affine systems
\dot{x}=f(x)+G(x)u

\dot{z}=(\mathrm{D}\phi\cdot f)(x)+(\mathrm{D}\phi\cdot G)(x)u

. Some recent literature that aimed at using bilinear Koopman models for control eluded from such discussions, and retreated to the assumption of a finite-dimensional exact embedding

To the end of a universal Koopman representation of discrete-time system (

Choice of spaces of state-dependent and state-and-input-dependent functions

The domain and codomain of the Koopman operator

The condition for the operator

Noting that equilibrium point plays a special role in dynamical systems and needs to be preserved in the Koopman model for stability analysis, our prior work

These conditions are easy to extend to non-autonomous system (

Separation of state features and input features

Viewing

The limitation remains if the inputs are regarded only as parameters in a parameterized Koopman operator family
[
7
]

The tensor product formulation, which allows the features of states and the features of inputs to be separated into their own spaces, is desirable and has been adopted in some relevant papers (e.g.,
[

[
23
]
considering the closed-loop system using “policy kernels”).
The conditions for meaningfully defining an infinite-dimensional Koopman operator model involving the tensor product RKHS, however, remains to be clarified. In particular, we are interested in finding the conditions for an exact bilinear Koopman model on RKHSs, rather than a “misspecified” approximate model (e.g., from RKHS to

Clearly, to handle problems such as multi-step prediction and control, it is necessary to establish the operator on the same function space.

Explicit solution of typical control problems

Due to the nonlinearity of the input feature map, the control problems of (
1
) remain intrinsically nonlinear and cannot naïvely follow a linear-quadratic control formulation.
As a result, by using receding horizon optimization as an implicit control law, existing literature

focused on model predictive control (MPC) formulations for bilinear Koopman models.
In such settings, recursive feasibility and closed-loop stability guarantees can be deduced only via

To the authors’ knowledge, a rigorous controller

The aim of this paper is to establish that the system (
1

22

), and the infinite-dimensional model involves the Kronecker product of their features that reside in the tensor product RKHS.
The identification of such a bilinear model naturally lends to a kernel regression routine in the spirit of
[
15
]

Furthermore, under the bilinear model (
2

The problem turns out to be convex and therefore computationally tractable by approximation, whose solution provides a
stabilizing controller synthesis
method.

II
Preliminaries

II-A

RKHS and Sobolev Kernel

We call a continuous function
\kappa:\mathbb{X}\times\mathbb{X}\rightarrow\mathbb{R}
a
kernel
on
\mathbb{X}
if for any finite set of points
\left\{x_{i}\right\}_{i=1}^{N}\subset\mathbb{X}
, the matrix defined as
G_{\kappa}=\left[\kappa\left(x_{i},x_{j}\right)\right]_{i,j=1}^{N}
is symmetric and positive semidefinite. The RKHS associated with
\kappa
is defined as

\mathcal{H}_{\kappa}(\mathbb{X})=\overline{\operatorname{span}}\left\{\kappa(x,\cdot):x\in\mathbb{X}\right\},

and its elements
\phi_{x}:=\kappa(x,\cdot)
are called kernel functions or canonical features. The inner product of
\mathcal{H}_{\kappa}(\mathbb{X})
is defined as
\left\langle\kappa(x,\cdot),\,\kappa(x^{\prime},\cdot)\right\rangle=\kappa(x,x^{\prime})
, and consequently the induced norm is
\lVert\kappa(x,\cdot)\rVert^{2}=\kappa(x,x)
. The RKHS has the
reproducing kernel
property: for any
g\in\mathcal{H}_{\kappa}(\mathbb{X})
, the point evaluation at any point
x\in\mathbb{X}
can be written as the inner product with a kernel function, i.e.,
g(x)=\left\langle g,\,\kappa(x,\cdot)\right\rangle
. Similarly, a kernel function function
\varkappa:\mathbb{U}\times\mathbb{U}\rightarrow\mathbb{R}
and its corresponding RKHS can be defined over the input space
\mathbb{U}
, denoted as
\mathcal{H}_{\varkappa}(\mathbb{U})
.

A useful type of Hilbert space is a Sobolev–Hilbert space
H^{s}(\mathbb{X}):=W^{s,2}(\mathbb{X})
, which is the space of such functions that have generalized derivatives up to
s
-th order, all of which being square-integrable over
\mathbb{X}
.
This regularity is important for Koopman analysis, because Koopman operator is known to be well-defined on the Sobolev space under smoothness and nondegeneracy conditions on the dynamics
[
13
]
.

Lemma 1

(Wendland
[
24
]
)
.

Let
\kappa
be a radial kernel on
\mathbb{X}
, that is, a kernel such that
\kappa(x,x^{\prime})=\rho\left(\lvert x-x^{\prime}\rvert\right)
for some
\rho:\mathbb{R}_{+}\rightarrow\mathbb{R}_{+}
with a Fourier transform,
\hat{\rho}(\xi)
, that satisfies
c_{1}\left(1+\lvert\xi\rvert^{2}\right)^{-s/2}\leq|\hat{\rho}(\xi)|\leq c_{2}\left(1+\lvert\xi\rvert^{2}\right)^{-s/2}
for some constants
c_{2}\geq c_{1}>0
for all
\xi\in\mathbb{R}
. If
\mathbb{X}
further has a Lipschitz boundary, then
W^{s,2}(\mathbb{X})=\mathcal{H}_{\kappa}(\mathbb{X)}
up to an equivalence of norms.

Suppose
\kappa:\mathbb{X}\times\mathbb{X}\rightarrow\mathbb{R}
and
\varkappa:\mathbb{U}\times\mathbb{U}\rightarrow\mathbb{R}
are kernels satisfying the conditions in Lemma
1
. Then we define
\mathcal{H}_{x}:=\mathcal{H}_{\kappa}(\mathbb{X})
and
\mathcal{H}_{u}:=\mathcal{H}_{\varkappa}(\mathbb{U})
as the Sobolev–Hilbert spaces over the state and input spaces.
We also introduce the notion of an adjoint operator. Consider a well-defined, bounded linear operator
T:\mathcal{G}\rightarrow\mathcal{H}
between Hilbert spaces. The adjoint operator, denoted
T^{*}:\mathcal{H}\to\mathcal{G}
, is defined by the relation
\left\langle T^{*}h,\,g\right\rangle=\left\langle h,\,Tg\right\rangle
for all
g\in\mathcal{G}
and
h\in\mathcal{H}
.
It is easily provable that the adjoint of the Koopman operator, denoted
K^{*}
and also called the Perron–Frobenius operator, in the case of an autonomous system
x^{+}=f(x)
, gives

K^{*}\mathring{\kappa}(x,\cdot)=\mathring{\kappa}(f(x),\cdot),\qquad\forall x\in\mathbb{X}.

II-B

Tensor Product and Linear–Radial Kernel

Sobolev-type RKHSs are useful for Koopman analysis as they provide a regular function space on which composition with dynamics can be a well-defined, bounded linear operator. However, a radial Sobolev kernel is insensitive to the special role of an
equilibrium point
(at the origin, without loss of generality).
Specifically, if the kernel has the form of
\kappa(x,x^{\prime})=\rho\left(|x-x^{\prime}\rvert\right)
, then
\left\lVert\kappa(x,\cdot)\right\rVert_{\mathcal{H}_{x}}^{2}=\kappa(x,x)=\rho(0)
for every
x\in\mathbb{X}
. Hence the canonical feature at each point has the same norm, and the origin in
\mathbb{X}
does not correspond to the origin in the RKHS. The same undesirable obstruction appears in the controlled setting.

We recall the tensor product spaces of Hilbert spaces, which will be used to both define the linear–radial kernel and the state–input feature used in the bilinear Koopman representation.
Suppose that
\mathcal{H}_{1}
and
\mathcal{H}_{2}
are two Hilbert spaces. Their tensor product is defined as

\mathcal{H}_{1}\otimes\mathcal{H}_{2}=\overline{\operatorname{span}}\left\{g\otimes h:g\in\mathcal{H}_{1},~h\in\mathcal{H}_{2}\right\},

with the elementary tensors of the form
g\otimes h
are ordered pairs in
\mathcal{H}_{1}\times\mathcal{H}_{2}
endowed with an inner product
\left\langle g_{1}\otimes h_{1},\,g_{2}\otimes h_{2}\right\rangle=\left\langle g_{1},\,g_{2}\right\rangle_{\mathcal{H}_{1}}\left\langle h_{1},\,h_{2}\right\rangle_{\mathcal{H}_{2}}
, and then extended by linearity and completion.
When
\mathcal{H}_{1}
and
\mathcal{H}_{2}
are further RKHSs,
\mathcal{H}_{\kappa_{1}}(\Omega_{1})
and
\mathcal{H}_{\kappa_{2}}(\Omega_{2})
, respectively, their tensor product is again an RKHS, whose reproducing kernel is simply the product kernel
\kappa((\omega_{1},\omega_{2}),(\cdot,\cdot))=\kappa_{1}(\omega_{1},\cdot)\kappa_{2}(\omega_{2},\cdot)
. That is,
\mathcal{H}_{\kappa_{1}}(\Omega_{1})\otimes\mathcal{H}_{\kappa_{2}}(\Omega_{2})=\mathcal{H}_{\kappa}(\Omega_{1}\times\Omega_{2})
.
If
\Omega_{1}=\Omega_{2}=\Omega
, we can just force
\omega_{1}=\omega_{2}=\omega\in\Omega
, namely define
\kappa=\kappa_{1}\kappa_{2}
and then
\mathcal{H}_{\kappa_{1}}(\Omega)\otimes\mathcal{H}_{\kappa_{2}}(\Omega)=\mathcal{H}_{\kappa}(\Omega)
.

Using this construction, the linear–radial kernel was introduced in our previous work
[
22
]
. Denote
\kappa_{\mathrm{sob}}(x,x^{\prime})=\rho\left(|x-x^{\prime}\rvert\right)
as the radial Sobolev kernel on
\mathbb{X}
. We define the linear kernel
\kappa_{\mathrm{lin}}(x,x^{\prime})=x^{\top}x^{\prime}
and form the product kernel

\mathring{\kappa}(x,x^{\prime})=\kappa_{\mathrm{lin}}(x,x^{\prime})\kappa_{\mathrm{sob}}(x,x^{\prime})=\left(x^{\top}x^{\prime}\right)\rho\left(\lvert x-x^{\prime}\rvert\right).

Lemma 2

(Tang & Ye
[
22
]
)
.

The function
\mathring{\kappa}
defines an RKHS over
\mathbb{X}
, denoted
\mathring{\mathcal{H}}_{x}
, can be expressed as:

\mathring{\mathcal{H}}_{x}=\left\{\sum_{k=1}^{n}e_{k}g_{k}:g_{k}\in\mathcal{H}_{x}\right\},\left\|\sum_{k=1}^{n}e_{k}g_{k}\right\|_{\mathring{\mathcal{H}}_{x}}^{2}=\sum_{k=1}^{n}\left\|g_{k}\right\|_{\mathcal{H}_{x}}^{2},

where
e_{k}(x)=x_{k}
(
k=1,\cdots,n)
are the projection maps.

Informally, this space comprises of functions that are
locally at least linear
near the equilibrium point, while still globally regular in the Sobolev sense. Since the linear factors now make the canonical feature vanish at the origin, we have
\mathring{\phi}_{0}=0
, and in fact
\|\mathring{\phi}_{x}\|\propto|x|
, since
\|\mathring{\phi}_{x}\|^{2}=\mathring{\kappa}(x,x)=|x|^{2}\rho(0)
).
This linear–radial RKHS is also defined over the input space
\mathbb{U}
, denoted as
\mathcal{H}_{u}
with a linear–radial product kernel
\mathring{\varkappa}(u,u^{\prime})=\varkappa_{\mathrm{lin}}(u,u^{\prime})\varkappa_{\mathrm{sob}}(u,u^{\prime})
where
\varkappa_{\mathrm{sob}}(u,u^{\prime})
is a radial Sobolev kernel, and canonical features denoted as
\mathring{\varphi}_{u}=\mathring{\varkappa}(u,\cdot)\in\mathring{\mathcal{H}}_{u}
.
Furthermore, in the next section, we will use the tensor product
\mathring{\mathcal{H}}_{x}\otimes\mathring{\mathcal{H}}_{u}
, which is an RKHS with kernel
((x,u),(x^{\prime},u^{\prime}))\mapsto\kappa(x,x^{\prime})\varkappa(u,u^{\prime})
. We denote the canonical feature of
(x,u)
in this space as
\phi_{x}\otimes\varphi_{u}
.

II-C

Kernel Quadratic Forms and Kernel SOS Forms

The norm of a canonical feature satisfies
\lVert\mathring{\phi}_{x}\rVert^{2}=\mathring{\kappa}(x,x)=\left(x^{\top}x\right)\rho(0)
, which scales with the
|x|^{2}
. This is clearly in contrast to the purely radial kernel, for which
\lvert\phi_{x}\rvert=\rho(0)
for every
x
. Hence, the linear–radial RKHS is a natural space for constructing “locally at least quadratic functions”, including Lyapunov candidates.
We now define “kernel quadratic forms”, used later for stabilization. In finite dimensions, a standard Lyapunov candidate is a quadratic form
v(x)=x^{\top}Px
, where
P
is a postive semidefinte matrix. In the RKHS setting, the feature
\mathring{\phi}_{x}
plays the role of
x
and a positive operator
P
on the RKHS plays the commensurate role. For precision, the concepts of Hilbert–Schmidt operators are reviewed here.

Definition 1

(Hilbert–Schmidt operators)
.

A symmetric operator
Q=Q^{*}
on a Hilbert space
\mathcal{H}
is a
Hilbert-Schmidt operator
if for an orthonormal basis
\left\{u_{i}\right\}_{i\in\mathbb{N}}\in\mathcal{H}
, we have

\textstyle P=\sum_{i=1}^{\infty}\lambda_{i}u_{i}\times u_{i}

for some
\left\{\lambda_{i}\right\}_{i\in\mathbb{N}}\subset\mathbb{R}
with
\sum_{i}\lambda_{i}^{2}<\infty
. If, in addition,
\left\langle h,\,Ph\right\rangle\geq 0
,
\forall h\in\mathcal{H}
, then
P
is said to be positive and denoted as
P\in\mathrm{HS}_{+}(\mathcal{H})
.

Now, given a positive Hilbert–Schmidt operator
P:\mathring{\mathcal{H}}_{x}\rightarrow\mathring{\mathcal{H}}_{x}
, we define the associated
kernel quadratic form
as
x\mapsto\left\langle\mathring{\phi}_{x},\,P\mathring{\phi}_{x}\right\rangle
.
By the spectral decomposition in the above definition, it can be verified that
\left\langle\mathring{\phi}_{x},\,P\mathring{\phi}_{x}\right\rangle=\sum_{i=1}^{\infty}\alpha_{i}u_{i}(x)^{2}
, which is a (possibly infinite)
sum of squared “locally at least linear” functions
.

III
Bilinear Koopman Model

This section discusses the existence and data-driven estimation of a bilinear Koopman model for system (
1
). The advantages for such a model for control will become clear in the next section. Specifically, we are interested in when a Koopman operator
K:\mathring{\mathcal{H}}_{x}\rightarrow\mathring{\mathcal{H}}_{x}\oplus\mathring{\mathcal{H}}_{u}\oplus\left(\mathring{\mathcal{H}}_{x}\otimes\mathring{\mathcal{H}}_{u}\right):g\mapsto g\circ f
is a well-defined, bounded linear operator.
As such, its adjoint operator
M:\mathring{\mathcal{H}}_{x}\oplus\mathring{\mathcal{H}}_{u}\oplus\left(\mathring{\mathcal{H}}_{x}\otimes\mathring{\mathcal{H}}_{u}\right)\to\mathring{\mathcal{H}}_{x}
is
a bilinear “lifted model” in infinite dimensions, mapping the state canonical feature, input canonical feature, and their tensor product to the canonical feature of the succeeding state
:

\mathring{\phi}_{x^{+}}=\underbrace{\begin{bmatrix}M_{1}&M_{2}&M_{3}\end{bmatrix}}_{M}\begin{bmatrix}\mathring{\phi}_{x}\\
\mathring{\varphi}_{u}\\
\mathring{\phi}_{x}\otimes\mathring{\varphi}_{u}\end{bmatrix}=:M\mathring{\psi}_{(x,u)}.

(2)

It is then shown how such a model can be estimated with data triplets
\left\{(u_{i},x_{i},y_{i})\right\}_{i=1}^{N}
where
y_{i}=f(x_{i},u_{i})
.

III-A

Existence of A Bilinear Koopman Model

Here we present the main result for the existence of an operator model in the form of (
2
).

Theorem 1
.

Assume that (i)
\mathbb{X}\subset\mathbb{R}^{n}
and
\mathbb{U}\subset\mathbb{R}^{m}
are compact and star-convex with respect to the origin, (ii)
f\in[\mathring{C}^{s+1}(\mathbb{X}\times\mathbb{U})]^{n}
with
s>(d_{x}+d_{u})/2
, (iii)
f_{x}:=f(\cdot,0)
is non-degenerate:
\inf_{x\in\mathbb{X}}|\operatorname{det}\mathrm{D}f_{x}(x)|>0
, and (iv) for every Borel set
S\subset\mathbb{X}
and
x\in\mathbb{X}
,
\operatorname{mes}\{u\in\mathbb{U}:f(x,u)\in S\}\leq\operatorname{ms}S
for some constant
c>0
.
Then there exists a bounded linear operator
M
such that (
2
) holds for the system (
1
).

The trick to prove the theorem is to examine the composition of
g\in\mathring{\mathcal{H}}_{x}
with “restricted” controlled dynamics. In particular, the restriction
x\mapsto f(x,0)
captured purely state-dependent contributions, and
u\mapsto f(0,u)
captures purely input-dependent contributions. The remaining component, which depends jointly on
x
and
u
, is then associated with the tensor product feature
\mathring{\phi}_{x}\otimes\mathring{\varphi}_{u}
.
In the same spirit as
[
22
]
, the dynamics must be assumed to be smooth and equilibrium-preserving, for which we define

\displaystyle\begin{aligned} \mathring{C}^{s}(\mathbb{X}\times\mathbb{U})=\Bigg\{\sum_{i=1}^{n}{}_{i}p_{i}+\sum_{i=1}^{m}{}_{n+i}q_{i}\;:&\;p_{i},q_{i}\in C^{s}(\mathbb{X}\times\mathbb{U})\Bigg\},\end{aligned}

which can be seen as the space of
s
-smooth functions that are locally linear around the equilibrium point.

The composition of an observable
g\in\mathring{\mathcal{H}}_{x}
with the dynamics restricted to solely state contributions behaves the same as the case of an autonomous system, which has been analyzed in our previous work
[
22
]
.

Lemma 3
.

Suppose that (i)
\mathbb{X}\subset\mathbb{R}^{n}
is compact, (ii)
f\in\mathring{C}^{s}(\mathbb{X}\times\mathbb{U})
, and (iii)
\inf_{x\in\mathbb{X}}\left\lvert\det\mathrm{D}f_{x}(x)\right\rvert>0
. Then on
\mathring{\mathcal{H}_{x}}
,
\Lambda_{1}:g\mapsto g\circ f_{x}
is a bounded linear operator.

A similar result can also be proven in a similar manner for the composition
g\mapsto g\circ f_{u}
, where
f_{u}:=f(0,\cdot)
.

Lemma 4
.

Suppose that (i)
\mathbb{U}\subset\mathbb{R}^{m}
is compact, (ii)
f\in[\mathring{C}(\mathbb{X}\times\mathbb{U})]^{n}
, and (iii) for any Borel set
S\subset\mathbb{X}
,
\operatorname{mes}f_{u}^{-1}(S)\leq c\operatorname{mes}S
for some constant
c>0
. Then
\Lambda_{2}:\mathring{\mathcal{H}}_{x}\rightarrow\mathring{\mathcal{H}}_{u}:g\mapsto g\circ f_{u}
is a bounded linear operator.

Proof.

For any
g\in\mathring{\mathcal{H}}_{x}
, we will verify that
g\circ f_{u}\in\mathring{\mathcal{H}}_{u}
. It can be verified this composition can be written as:

\textstyle(g\circ f_{u})=\sum_{i=1}^{m}u_{i}\sum_{k=1}^{n}e_{k}\left(q_{i}(0,u)\right)g_{k}\left(f_{u}(u)\right).

Since by the second assumption, all
q_{i}\in C^{s}(\mathbb{X}\times\mathbb{U})
, this composition will be in
\mathring{\mathcal{H}}_{u}
if
g_{k}\circ f_{u}\in\mathring{\mathcal{H}}_{u}
. By the definition of Sobolev spaces,

\textstyle\left\|g_{k}\circ f_{u}\right\|_{H^{s}(\mathbb{X})}^{2}\leq c^{\prime}\sup_{\lvert\alpha\rvert\leq s}\int{U}\left\lvert\partial^{\alpha}g_{k}(f_{u}(u))\right\rvert^{2}\mathrm{d}u,

where
\alpha
is a multi-index and
c^{\prime}>0
. Using the chain rule, this partial derivative is expanded into a finite sum of terms, each containing a product of
\partial^{\gamma}g_{k}
(for a multi-index
\lvert\gamma\rvert<\lvert\alpha\rvert
) and
\partial^{\beta}f_{u}
(for some multi-indices
\lvert\beta\rvert<\lvert\alpha\rvert
). Again, with
f\in\mathring{C}^{s}(\mathbb{X}\times\mathbb{U})
, this is bounded by
\sup_{\lvert\alpha\rvert\leq s}\int{U}\left\lvert\partial^{\alpha}g_{k}(f_{u}(u))\right\rvert^{2}\mathrm{d}u
. Then, by condition (iii), a change of variables can be performed to yield
\int_{\mathbb{X}}\lvert\partial^{\alpha}g_{k}(x)\rvert^{2}\mathrm{d}\mu(x)
, where
\mu(S)=\operatorname{mes}f_{u}^{-1}(S)
for any Borel set
S\subset\mathbb{X}
.
By the third assumption, this is linearly bounded by
\lVert g_{k}\rVert_{\mathring{\mathcal{H}}_{x}}^{2}
.
∎

Lemma 5
.

Suppose that (i)
\mathbb{X}\subset\mathbb{R}^{n}
and
\mathbb{U}\subset\mathbb{R}^{m}
are compact and star-convex with respect to the origin, (ii)
f\in[\mathring{C}^{s+1}(\mathbb{X}\times\mathbb{U})]^{n}
with
s>(d_{x}+d_{u})/2
, and (iii) for every Borel set
S\subset\mathbb{X}
,
\operatorname{mes}f^{-1}(S)\leq c\operatorname{mes}S
. Then the operator
\Lambda_{3}:\mathring{\mathcal{H}}_{x}^{s}\rightarrow\mathring{\mathcal{H}}_{x}^{s}\otimes\mathring{\mathcal{H}}_{u}^{s}:g\mapsto g\circ f-g\circ f_{x}-g\circ f_{u}
is a bounded linear operator, where
f_{x}(x)=f(x,0)
and
f_{u}(u)=f(0,u)
.

Proof.

The composition
g\circ f
can be written as

g(f(x,u))=\sum_{i=1}^{n}\left[\sum_{k=1}^{n}x_{i}p_{ki}(x,u)+\sum_{j=1}^{m}u_{j}q_{ji}(x,u)\right]g_{i}(f(x,u)).

Defining functions
\bar{p}_{k}(x,u):=\sum_{i=1}^{n}e_{i}\left(p_{i}(x,u)\right)g_{i}(f(x,u))
and
\bar{q}_{j}(x,u):=\sum_{i=1}^{n}e_{i}\left(q_{j}(x,u)\right)g_{i}(f(x,u))
, the composition
g\circ f-g\circ f_{x}-g\circ f_{u}
can be expressed with

(\Lambda_{3}g)(x,u)=\sum_{k=1}^{n}x_{k}\left[\bar{p}_{k}(x,u)-\bar{p}_{k}(x,0)\right]+\sum_{j=1}^{m}u_{j}\left[\bar{q}_{j}(x,u)-\bar{q}_{j}(0,u)\right].

By condition (i),
\bar{p}_{k}(x,u)-\bar{p}_{k}(x,0)=\sum_{j=1}^{m}u_{j}\int_{0}^{1}\frac{\partial\bar{p}_{k}}{\partial u_{j}}(x,\tau u)\mathrm{d}\tau
(with a similar result for
\bar{q}_{j}(x,u)
). Thus, this composition becomes
(\Lambda_{3}g)(x,u)=\sum_{k=1}^{n}\sum_{j=1}^{m}x_{k}u_{j}\bar{s}_{kj}(x,u)
, where
\bar{s}_{k,j}
is the integral of first order derivatives of
\bar{p}_{k}
and
\bar{q}_{j}
. It remains to show that for each
k
and
j
,
\bar{s}_{kj}\in\mathring{\mathcal{H}}_{x}\otimes\mathring{\mathcal{H}}_{u}
. By the definitions of
\bar{p}_{k}
and
\bar{q}_{j}
, their first derivatives are finite sums of products involving
p_{ki}
,
q_{ji}
,
f
,
g_{i}
composed with
f
, and all of their first derivatives. We next estimate each coefficient
\bar{s}_{kj}
in the tensor product Sobolev norm. For some
c^{\prime}>0
,

\textstyle\lVert\bar{s}_{kj}\rVert_{H^{s}(\mathbb{X})\otimes H^{s}(\mathbb{U})}^{2}\leq c^{\prime}\sup_{\lvert\alpha\rvert\leq s}\int_{\mathbb{X}\times\mathbb{U}}\left\lvert\partial^{\alpha}\bar{s}_{kj}(x,u)\right\rvert^{2}\mathrm{d}x\mathrm{d}u,

where
\alpha
is a multi-index. By repeated application of the chain rule, each derivative
\partial^{\alpha}\bar{s}_{kj}
is a finite sum of terms involving products of bounded derivatives of
f
,
p_{kr}
, and
q_{jr}
with derivatives of the form
\partial^{\gamma}g_{r}(f(x,u))
, where
\lvert\gamma\rvert\leq s
.
From condition (ii),
f\in\mathring{C}^{s+1}(\mathbb{X}\times\mathbb{U})
and thus
p_{kr}
and
q_{jr}
have the required bounded regularity, this gives

\textstyle\lVert\bar{s}_{kj}\rVert_{H^{s}(\mathbb{X})\otimes H^{s}(\mathbb{U})}^{2}\lesssim c^{\prime}\sup_{\lvert\gamma\rvert\leq s}\int_{\mathbb{X}\times\mathbb{U}}\left\lvert\partial^{\gamma}g_{r}(f(x,u))\right\rvert^{2}\mathrm{d}x\mathrm{d}u

for some
c^{\prime}>0
. By condition (iii) on the measure induced by
f
, with the same rationale as the previous lemma,

\textstyle\lVert\bar{s}_{kj}\rVert^{2}_{H^{s}(\mathbb{X})\otimes H^{s}(\mathbb{U})}\leq c^{\prime}\lVert g\rVert^{2}_{\mathring{\mathcal{H}}_{x}}

for some
c^{\prime}>0
. This result holds for all
k
and
j
, and therefore
\Lambda_{3}
is indeed a bounded linear operator.
∎

III-B

Learning from Snapshot Data

Assume that the model (
2
) is well-defined. Given data triplets
\left\{(x_{i},u_{i},y_{i})\right\}_{i=1}^{N}
where
y_{i}=f(x_{i},u_{i})
, the goal is to learn an operator
\hat{M}
that acts as an approximate Perron–Frobenius operator, that is,
M\mathring{\psi}_{(x_{i},u_{i})}
matches
\mathring{\phi}_{y_{i}}
over the sample. This can be formulated as the following convex learning problem over Hilbert–Schmidt operators:

\min_{M\in\mathrm{HS}\left(\mathring{\mathcal{H}}_{xu},\mathring{\mathcal{H}}_{x}\right)}\frac{1}{N}\sum_{i=1}^{N}\left\lVert M\mathring{\psi}_{(x_{i},u_{i})}-\mathring{\phi}_{y_{i}}\right\rVert_{\mathring{\mathcal{H}}_{x}}^{2}+\beta\left\lVert M\right\rVert_{\mathrm{HS}}^{2},

where
\beta>0
is a regularization parameter and

\mathring{\mathcal{H}}_{xu}:=\mathring{\mathcal{H}}_{x}\oplus\mathring{\mathcal{H}}_{u}\oplus(\mathring{\mathcal{H}}_{x}\otimes\mathring{\mathcal{H}}_{u})
is the Hilbert space associated with the feature
\mathring{\psi}_{(x,u)}=(\mathring{\phi}_{x},\mathring{\varphi}_{u},\mathring{\phi}_{x}\otimes\mathring{\varphi}_{u})
.

By the representer theorem for learning on RKHS, and the fact that the space of Hilbert–Schmidt operators is Hilbert, the optimizer must have the form

\textstyle M=\sum_{i=1}^{N}\sum_{j=1}^{N}\hat{\theta}_{ij}\,\mathring{\phi}_{y_{i}}\times\mathring{\psi}_{(x_{j},u_{j})},

where
\mathring{\phi}_{y_{i}}\times\mathring{\psi}_{(x_{j},u_{j})}
is a rank-
1
operator that maps any
\mathring{\psi}_{(x,u)}
to
\left\langle\mathring{\psi}_{(x_{j},u_{j})},\,\mathring{\psi}_{(x,u)}\right\rangle\mathring{\phi}_{y_{i}}
. Thus, the optimization problem reduces to solving for a matrix
\hat{\Theta}=\left[\hat{\theta}_{ij}\right]
.
Let us denote
G_{\mathring{\psi}}:=[G_{\mathring{\psi},ij}]
as the Gram matrix for the features
\psi_{(x,u)}
, in which
G_{\mathring{\psi},ij}=\left\langle\mathring{\psi}_{(x_{i},u_{i})},\,\mathring{\psi}_{(x_{j},u_{j})}\right\rangle=\mathring{\kappa}(x_{i},x_{j})+\mathring{\varkappa}(u_{i},u_{j})+\mathring{\kappa}(x_{i},x_{j})\mathring{\varkappa}(u_{i},u_{j})
, and
G_{\mathring{\phi}}:=[G_{\mathring{\phi},ij}]
, in which
G_{\mathring{\phi},ij}=\left\langle\mathring{\phi}_{y_{i}},\,\mathring{\phi}_{y_{j}}\right\rangle=\mathring{\kappa}(y_{i},y_{j})
. It can be seen that the problem boils down to the follows:

\min_{\Theta\in\mathbb{R}^{N\times N}}\,\mathrm{tr}\left(\frac{1}{N}G_{\mathring{\psi}}^{\top}\Theta^{\top}G_{\mathring{\phi}}\Theta G_{\mathring{\psi}}-\frac{2}{N}G_{\mathring{\psi}}^{\top}\Theta^{\top}G_{\mathring{\phi}}+\beta\Theta G_{\mathring{\psi}}^{\top}\Theta^{\top}G_{\mathring{\phi}}\right)

(3)

which is indeed a convex optimization problem and actually allows an explicit solution through solving a generalized eigenvalue problem
[
15
,
23
]
, which we omit for brevity here.

Koopman-Based Stabilizing Control under Bilinearity and Input Lifting

The advantage of having a model like (
2
) where the inputs and states are separately lifted into two RKHSs is to facilitate the formulation of control problems. Here, we consider the problem of synthesizing a Lyapunov-based controller.
Specifically, we suppose that a Lyapunov function
v:\mathbb{X}\to\mathbb{R}_{+}
,
v(x)=\left\langle\mathring{\phi}_{x},\,P\mathring{\phi}_{x}\right\rangle
is assigned, where
P\in\mathrm{HS}_{+}(\mathring{\mathcal{H}}_{x})
and look for a feedback control law
u=\alpha(x)
with certain regularity conditions, such that the Lyapunov function decreases along the closed-loop dynamics faster than a prescribed decay rate function
q(x)=\left\langle\mathring{\phi}_{x},\,Q\mathring{\phi}_{x}\right\rangle
, where
Q\in\mathrm{HS}_{+}(\mathring{\mathcal{H}}_{x})
.
2
2

2

The problem can, of course, be posed in alternative ways, such as requiring an linear rate of decay, or maximizing the coefficient
c\geq 0
under a required decay rate of
cq(x)
.

IV-A

Lyapunov Descent under Stochastic Feedback Laws

The problem, hence, is to find a law
\alpha
such that

\left\langle M\mathring{\psi}_{(x,\alpha(x))},\,PM\mathring{\psi}_{(x,\alpha(x))}\right\rangle\leq\left\langle\mathring{\phi}_{x},\,(P-Q)\mathring{\phi}_{x}\right\rangle,\,\forall x\in\mathbb{X}.

Such a problem, however, suffers from the issue that the left-hand-side term and the right-hand-side term cannot be agglomerated due to the nonlinear input feature map
\mathring{\varphi}
contained in
\mathring{\psi}
.
In other words, even if for every
\mathring{\phi}_{x}
we can find an element in
\mathring{\mathcal{H}}_{u}
that satisfies the Lyapunov inequality, we do not have a criterion to verify that this element has a corresponding finite-dimensional admissible control action
u\in\mathbb{U}
.
Essentially, the difficulty here is the lack of convexity in nonlinearly constrained optimization problems.

Motivated by the wide use of nonconvex optimization in machine learning problems and the need to interpret the trained models’ behavior, a “continuum” perspective, viewing the nonconvex problem as the optimization over probability distributions, has been increasingly adopted in the recent literature
[
17
,
19
]
.
Specifically in our problem, we consider the search of a stochastic feedback law, where given any
x
,
u
is a random vector, instead of a deterministic mapping, where
u
is fixed under
x
. With such a consideration, by writing the conditional distribution of input as the probability measure
\mu(\cdot|x)
, we write the Lyapunov function value at the succeeding time averaged over all succeeding states as

\textstyle\mathbb{E}[v(x^{+})]=\int_{\mathbb{U}}\left\langle M\mathring{\psi}_{(x,u)},\,PM\mathring{\psi}_{(x,u)}\right\rangle\mu(\mathrm{}u|x).

The search is then performed on such conditional distributions
\mu(\cdot|\cdot)
defined for
x\in\mathbb{X}
and
u\in\mathbb{U}
.

The resulting problem is clearly convex when regarding the measure
\mu
as the decision, since it is searched in a linear space subject to linear constraints.
In fact, none is lost by randomizing the feedback law, since if for any
x
, a deterministic feedback law
u=\alpha(x)
achieves the Lyapunov descent, then the Dirac conditional distribution
\mu(\cdot|x)=\delta(\cdot-\alpha(x)|x)
over
\mathbb{U}
satisfies the need.
Vice versa, if a condition distribution
\mu(\cdot)
achieves the descent, then there must be an appropriate value for
u
under every
x
, which forms a deterministic feedback law.

Problem 1
.

Find a conditional distribution
\mu(\mathrm{d}u|x)
such that for all
x\in\mathbb{X}
, we have

\textstyle\int_{\mathbb{U}}\left\langle M\mathring{\psi}_{(x,u)},\,PM\mathring{\psi}_{(x,u)}\right\rangle\mu(\mathrm{d}u|x)\leq\left\langle\mathring{\phi}_{x},\,(P-Q)\mathring{\phi}_{x}\right\rangle.

(4)

IV-B

Optimization over Conditional Distributions

For a tractable approximation of (
4
), we must perform a discretization of the conditional distribution
\mu(\mathrm{d}u|x)
. That is, dependent on
x
, we should choose a sufficiently large amount of points
\{u_{j}(x)\}_{j=1}^{N_{j}(x)}\subset\mathbb{U}_{x}
and let
\mu(\mathrm{d}u|x)=\sum_{j=1}^{N_{j}(x)}w_{j}(x)\delta_{u_{j}(x)}
, with all
w_{j}(x)
being nonnegative and summing up to
1
, thus converting the condition (
4
) to

\textstyle\sum_{j=1}^{N_{j}(x)}\left\langle M\mathring{\psi}_{(x,u_{j}(x))},\,PM\mathring{\psi}_{(x,u_{j}(x))}\right\rangle w_{j}(x)\leq\left\langle\mathring{\phi}_{x},\,(P-Q)\mathring{\phi}_{x}\right\rangle.

Denoting
f(x,u_{j}(x))=:x_{j}^{+}
, the above inequality becomes

\textstyle\sum_{j=1}^{N_{j}(x)}\left\langle\mathring{\phi}_{x_{j}^{+}},\,P\mathring{\phi}_{x_{j}^{+}}\right\rangle w_{j}(x)-\left\langle\mathring{\phi}_{x},\,(P-Q)\mathring{\phi}_{x}\right\rangle\leq 0.

(5)

To analyze the soundness of such a discretization on
\mathbb{U}
, we should bound the possible loss when clipping a general distribution (given
x
) onto a discrete distribution.
Such a loss clearly depends on the Lipschitz continuity of the Lyapunov function
v(f(x,u))
on
u\in\mathbb{U}_{x}
(denoted as
\mathrm{lip}(v(f(x,\cdot)),\mathbb{U}_{x})
) and the fill distance of
\{u_{j}(x)\}
on
\mathbb{U}_{x}
(denoted as
\mathrm{fill}(\{u_{j}(x)\},\mathbb{U}_{x})
).
Specifically, if a distribution
\mu(\mathrm{d}u|x)
supported on
\mathbb{U}_{x}
exists to satisfy (
4
), then (
5
) holds with its right-hand-side
0
modified by
\mathrm{lip}(v(f(x,\cdot)),\mathbb{U}_{x})\times\mathrm{fill}(\{u_{j}(x)\},\mathbb{U}_{x})
. On the contrary, if (
5
) holds, then the discrete distribution directly meets (
4
).

It is necessary to preassign the shape of
\mathbb{U}_{x}
under any
x
. Note that
\left\langle M\mathring{\psi}_{(x,u)},\,PM\mathring{\psi}_{(x,u)}\right\rangle
is a positive semidefinite quadratic form over
\{\mathring{\varphi}_{u}:u\in\mathbb{U}_{x}\}
. If the form is further strictly positive semidefinite, then in order that this form does not exceed
\left\langle\mathring{\phi}_{x},\,(P-Q)\mathring{\phi}_{x}\right\rangle
,
\mathring{\varphi}_{u}
must be norm-bounded by a constant multiple of
\|\mathring{\phi}_{x}\|
.
Recalling that
\|\mathring{\varphi}_{u}\|\propto|u|
and
\|\mathring{\phi}_{x}\|\propto|x|
, any input action causing Lyapunov descent at
x
must be bounded in the ball of radius
c|x|
centered at
0
in
\mathbb{U}
(for some constant
c>0
). Hence, let
\mathbb{U}_{x}=\mathbb{U}\cap\mathbb{B}(|x|)\subset\mathbb{U}
satisfies the need.
As such, the sampling strategy on
\mathbb{U}_{x}
can simply be scaling a fixed set of sample points on the unit ball by a constant of
c|x|
, i.e.,
u_{j}(x)=(c|x|)\mathsf{u}_{j}
,
\{\mathsf{u}_{j}\}_{j=1}^{N_{j}}\subset\mathbb{B}(1)
. The fill distance of
\{u_{j}(x)\}
in
\mathbb{U}_{x}
is
c|x|
multiplied by the fill distance of
\{\mathsf{u}_{j}\}
in
\mathbb{B}(1)
, which is a constant.

We further handle the
x
-pointwise constraints (
5
) by a discretization on
\mathbb{X}
. Choosing a number of sample points
\{x_{i}\}_{i=1}^{N_{i}}\subset\mathbb{X}
, we postulate the following form for the weight functions
w_{j}(x)
:

\textstyle w_{j}(x)=\sum_{i=1}^{N_{i}}\theta_{ij}\varrho(x,x_{i}),\kern 5.0ptj=1,\cdots,N_{j},

where
\varrho
is a Gaussian kernel, i.e.,
\varrho(x,x^{\prime})=\exp(-|x-x^{\prime}|^{2}/2\sigma^{2})
for some constant
\sigma>0
. We require
\theta_{ij}\geq 0
for nonnegativity. We hence impose the constraint (
5
) on the sampled points
\{(x_{i},u_{j}(x_{i}),x_{ij}^{+}=f(x_{i},u_{j}))\}
:

\textstyle\sum_{i^{\prime}=1}^{N_{i}}\sum_{j=1}^{N_{j}}\theta_{i^{\prime}j}\varrho(x_{i},x_{i^{\prime}})\left\langle\mathring{\phi}_{x_{ij}^{+}},\,P\mathring{\phi}_{x_{ij}^{+}}\right\rangle-\left\langle\mathring{\phi}_{x_{i}},\,(P-Q)\mathring{\phi}_{x_{i}}\right\rangle\leq 0.

That is,

\textstyle\sum_{i^{\prime}=1}^{N_{i}}\sum_{j=1}^{N_{j}}\theta_{i^{\prime}j}v(x_{ij}^{+})-(v(x_{i})-q(x_{i}))\leq 0.

(6)

In addition to
\theta_{ij}\geq 0
, for normalization, we require that:

\textstyle\sum_{i^{\prime}=1}^{N_{i}}\sum_{j=1}^{N_{j}}\theta_{i^{\prime}j}\varrho(x_{i},x_{i^{\prime}})=1,\kern 5.0pti=1,\cdots,N_{i}.

Finally, by solving all the coefficients
\{\theta_{ij}\}
, we take the deterministic feedback policy as

\textstyle\alpha(x)=\sum_{j=1}^{N_{j}}\sum_{i=1}^{N_{i}}\theta_{ij}\varrho(x,x_{i})u_{j}(x).

V
Conclusions and Open Problems

In conclusion, the present paper has demonstrated that nonlinear discrete-time systems, under certain smoothness conditions, can be exactly represented as a bilinear system where the state and input are separately lifted into an RKHS. As the RKHSs are generated by linear–radial kernels, kernel SOS forms are naturally expressive for Lyapunov functions, thus providing the condition for Lyapunov function descent.
The determination of a stabilizing controller, for a convex synthesis formulation, is cast as the optimization over a state-dependent probability density function over the input space. The solution approach is data-driven.

Due to the nonlinear input feature map
\mathring{\varphi}
, it appears unrealistic to tractably optimize the control law in its original deterministic formulation in finite dimensions.
This is unavoidable in discrete-time systems, where it cannot be anticipated that the input feature map can be a linear one.
The optimal control problem, which we have not addressed in this paper, if formulated under a kernel SOS form of stage cost, must also be solved via the “stochastic mixture” path.
Structurally, this will appear similar to a continuous-time stochastic optimal control problem, whose operator-theoretic solution has been considered for stochastic differential equations with a Wiener noise
[
10
]
.
For system (
2
), the evolution of the density of states and inputs likely should be characterized by their averaged features (i.e., kernel mean embeddings).

For continuous-time systems, one can be more optimistic about the possibility of a fully convex operator-theoretic solution to determine (approximately in a data-driven manner) the optimal controller. Formally, the Koopman model can be made a bilinear one without using input lifting.
Echoing with our Footnote
1
, theoretical efforts are still needed to rigorously formulate the stabilizing control and optimal control problems.
