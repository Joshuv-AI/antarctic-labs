 EXECUTIVE SUMMARY

An extensive database of glass composition and durability data has been compiled at Savannah River
National Laboratory to support the development of nuclear waste glasses. This database is referred to as
the Glass Composition-Properties Database (ComPro).

The ComPro Database, Revision 3, contains 14,134 total rows of data and 125 columns of composition,
durability, as defined by the Product Consistency Test, and other fabrication and characterization
information, if available, for each glass. Of the 14,134 total rows, 8,484 rows have been classified as “Model”
data and 5,650 rows have been classified as “Non-Model” data. An integral supplement to the ComPro
database is the User Guide. The User Guide was developed as a tool to aid the End User in a more effective
use of the ComPro database. The User Guide provides a road-map of the specific datasets that comprise the
ComPro database (both “Model” and “Non-Model” data) as well as a technical basis for the terminology
and definitions the End User will encounter. In this report, a general description of the format and
information contained in the User Guide is provided. In addition, specific terminology used in the User
Guide is also discussed.

1.0 Introduction
The Savannah River National Laboratory (SRNL) supports glass composition development for the Defense
Waste Processing Facility (DWPF) at the Savannah River Site (SRS). Taylor et al. developed an extensive
database containing pertinent glass composition and durability information to aid in this work.1 This
database is the Glass Composition – Properties (ComPro) database.

The ComPro database (Revision 3) contains 14,134 rows of glass composition data, durability results as
defined by the Product Consistency Test (PCT)2, and other fabrication and characterization information if
available. Of the 14,134 total rows, 8,484 have been classified as “Model” data and 5,650 rows have been
classified as “Non-Model” data in Revision 3. An integral supplement to the ComPro database is the User
Guide. The user guide was developed as a tool to aid the End User in a more effective use of the ComPro
database. The User Guide provides a road-map of the specific datasets that comprise the ComPro database
(both “Model” and “Non-Model” data) as well as a technical basis for the terminology and definitions the
user will encounter. In this report, a general description of the format and information contained in the User
Guide is provided. In addition, specific terminology used in the User Guide is also discussed. Table 1-1
provides information regarding the ComPro Database, Revision 3.

3.0 Format of the User Guide
Information in the User Guide is presented in two tables – “Model” data and “Non-Model” data based on
the classification of the data listed in the ComPro database. Specific information contained in each of the
tables includes the report number, a general description of the study, the primary author of the report, and
the QA Level (including the classification of “RW-0333P Compliant”, “RW-0333P Equivalent”, or “Non-
RW-0333P Compliant”), as defined by SRNL-STI-2009-00094, Revision 2.10 A column for notes is also
given in each of the tables. Each of these descriptive columns is discussed in more detail below.

3.1 Report Number
The “Report Number” column lists the primary document(s) from which the data were obtained.
Supplements, such as glass selection reports or memos, are also listed in this column as warranted.

3.2 Study Description
The “Study Description” column provides a high-level summary of the study from which the data were
obtained (e.g., a high-level waste (HLW) or low-activity waste (LAW) study, “generic” glass IDs may be

 1

identified, reference to the Department of Energy (DOE) site for which the work was performed may be
specified, etc.). This information may be beneficial to some End Users who are interested in specific studies
or groups of studies associated with a common DOE site or waste stream.

3.3 Primary Author
The “Primary Author” column lists the primary author of the report from which the specific data or datasets
were obtained.

3.4 QA Level
The “QA Level” column classifies each study or dataset as “RW-0333P Compliant”, “RW-0333P
Equivalent” or “Non-RW-0333P Compliant”. SRNL-STI-2009-00094, Revision 2 provides a detailed
description of the process used to determine this classification.10

The designation of “RW-0333P Compliant” as presented in the “QA Level” column of the User Guide and
ComPro database indicates that the data were originally obtained under a program that met the DOE/RW-
0333P Quality Assurance Requirements and Description (QARD). The designation of “RW-0333P
Equivalent” as presented in the “QA Level” column of the User Guide and ComPro database indicates that
the data is qualified to the DOE/RW-0333P QARD as described by SRNL-STI-2009-00094, Revision 2
using “equivalent controls”.10 The designation of “Non-RW-0333P Compliant” indicates that the data could
not be classified as RW-0333P Compliant or Equivalent based on the information provided.

3.5 Model versus Non-Model
In addition to the QA review, a technical review of the data or datasets was made to assess potential issues
or discrepancies between the database entries and the source from which the data came. The technical
review should not be confused with the verification and validation (V&V) process in which each cell entry
was verified against the original data source (see WSRC-RP-2004-00704).1 The technical review was a
more “global” assessment of the data in terms of consistency. Examples of these inconsistencies or technical
issues, which were cited during the development of Revision 0, are discussed below.

In one case, the electronic data source listed several minor components that were associated with an “Others”
group.a The use of an “Others” group was confirmed by the original source document but the “Others”
compositions were not described. Therefore, confirmation of the electronic values in the database could not
be made. The result was to classify the dataset as “Non-Model” data independent of the QA Level
classification.

Another specific example encountered was where the electronic database listed glass compositions in
weight percent (wt.%) but the original data source listed the glasses in mole percent (mol%). Independent
calculations were made to convert the reported mol% values to wt.% values but these resulted in values that
did not agree with the database entries. Again, the dataset was classified as “Non-Model” data independent
of the QA Level classification.

In another case, the electronic dataset identified a specific oxide and wt.% value for each glass. However,
in the original data source (or report) that oxide was not listed. For those situations in which resolution of
the discrepancies could not be made, the data were technically classified as “Non-Model” data regardless
of “QA Level” classification. Again, the technical review of the data was not a verification of the individual
cell entries but a more “global” assessment to ensure that the data entered into the ComPro database was
reconcilable with the original data source in a broad sense.

a The “Others” component is a group of several oxides whose concentrations are so small (minor components) that instead of

expressing each oxide as an individual component, they are grouped, and the percentage of “Others” is presented in the targeted
composition.

 2

In cases where there were no technical issues or discrepancies with the data, the data were classified as
“Model” data if the QA assessment classified the data as “RW-0333P Compliant or Equivalent”. If the QA
assessment classified a specific dataset as “Non-RW-0333P Compliant” the dataset was classified as “Non-
Model” data by default. Therefore, the terms “Model” data and “Non-Model” data (as used in reference to
the ComPro database) are defined as follows:

 Model Data – Data that may be used for any work that requires compliance with or equivalency to
 DOE/RW-0333P QARD.5 Data designated as “Model” Data were either “RW-0333P Compliant”
 or “RW-0333P Equivalent” and no technical issues were identified with the dataset.

 Non-Model Data – Data that may not be used for work that requires compliance with DOE/RW-
 0333P QARD. These data were either classified as “Non-RW-0333P Compliant” and/or technical
 issues with the dataset were identified and not resolved prior to the issuance of the database.

Section 5.0 provides more specific information regarding the classifications of “Model” and “Non-Model”
data. End Users of this database are encouraged to identify data or datasets which may have been
misclassified based on the technical review. If misclassifications are found or suspected, sufficient evidence
to upgrade or reclassify the data should be presented to the database gatekeeper and/or the appropriate
SRNL personnel. SRNL-STI-2009-00094, Revision 210 provides a detailed discussion of the protocols of
how existing data within the ComPro database can be reclassified. Continual improvement of the database,
whether it be the reclassification of datasets or the importing of new data, is critical as the End User should
have access to the most recent and reliable data available.

3.6 Notes
Perhaps of most interest to the End User is the information presented in the “Notes” column. In the “Model”
data section (or Table 5-1), four potential subsections are listed in this column: (1) Compositions, (2) PCTs,
(3) General, and (4) X-ray diffraction (XRD). For the composition and PCT sections, specific information
(e.g., table numbers) is presented to indicate the precise location from which the data shown in the database
were obtained (and used in the V&V process). Additional information is included in the composition
column when the target composition view was based on an “Others” component.a The information supplied
in the composition section should provide the basis from which the minor component values were computed
and entered into the ComPro database (when applicable). In the “General” section, supplemental
information is provided that was deemed inappropriate for either the composition or PCT sections, but
which provides additional insight into the dataset being reviewed. For example, an attempt to highlight
those studies in which a non-zero reduction/oxidation (REDOX) value was intentionally induced is made
through the User Guide via a statement such as “REDOX associated with these glasses”. This statement
should alert the End Users that REDOX values greater than 0 could be associated with some (or all) of the
study glasses within the dataset. Although a relatively thorough review of the “Model” data has been
performed, it is possible that all the studies or individual glasses have not been “flagged” appropriately in
this revision. This information is provided so that the End User may have the opportunity to partition the
REDOX sensitive species accordingly to more effectively assess the impact of REDOX on durability (or
another property of interest) if desired. In addition to the REDOX information, pH values supporting the
PCT data may be useful to some End Users. Although columns have been developed in the ComPro
database for pH information, specific values were not entered. For those original source documents which
contained pH information, a general statement has been added to the User Guide. In the “Non-Model” data
section (or Table 5-2) the “Notes” column provides a detailed description of the technical issue(s) with the
data or datasets that, if resolved, could reclassify the data assuming it is RW-0333P compliant or RW-
0333P equivalent.

4.0 Terminology and Specific Units
The ComPro database (as well as the User Guide) utilizes several abbreviations, unique terminology, and
standard reference compositions and/or PCT responses for certain glasses. Therefore, it is critical to identify
these issues to ensure that the End User can effectively utilize the database. These items are listed below
with a brief discussion to provide a technical basis.

4.1 “Composition View” Column and Use of “Reference”
Three possible composition views for each glass could be presented in the database. These include target,
measured, and measured bias corrected (msrd bc). Target compositions represent the targeted composition
for a particular glass. When measured (sometimes referred to as “analyzed” in the source report)
compositions were provided, these values were also included in the database. Some reports (in particular
the SRNL reports associated with DWPF studies) also provide a msrd bc composition view. This view is
based on the measured values being bias corrected to an internal glass standard (or standards) which was
analyzed with the “unknown” glasses. In addition to these composition views, the database contains several
entries for the Environmental Assessment (EA) and Approved Reference Material 1 (ARM-1), and
Analytical Reference Glass 1 (ARG-1) glasses. Unless specifically stated by the original source document,
the target composition views for both EA and ARM-1 were based on the reported values.11 The End User
will observe an entry of “Reference” in the “Compositional View” column for these two glasses.

It should be noted that the ARM-1 and EA glasses are typically used to demonstrate “control” or provide a
reference point for the PCT, respectively. Their compositions are not typically re-measured as part of the
control process. Any exceptions to the composition or PCT information for these two glasses are noted in
the User Guide.

4.2 Nomenclature for Shielded Cells Glasses
The work performed in the SRNL Shielded Cells typically involves the fabrication and testing of a single
glass sample from actual HLW in support of the qualification process. A Glass ID nomenclature was
assigned in the database if the report did not provide a succinct labeling scheme.

4.3 Detection Limit Issues
In several original data sources, the composition information (in particular for the measured or msrd bc
composition views) indicated a “<” value or a “blank” entry. In those cases, the corresponding database
entry was “0”. It is noted that for some studies, the author(s) of the original data report elected to handle
the “<” values reported from the supporting analytical service differently. For example, some authors used
½ the detection limit as the reported value. In those cases, the reported value in the original data source
document was entered in the database.

4.4 Screened versus Unscreened PCT Responses
In some original source documents, two tables or two views of the normalized PCT data are presented: (1)
Pre-Screened and (2) After Screened. The use of the terminology “screening” refers to the assessment of
potential water loss as specified by the PCT procedure.2 In all cases where two tables were presented, the
“after-screening” values (i.e., the resulting values where the replicates had been screened for potential water
loss) were entered into the database.

 4

4.5 Units of Normalized PCT Information
In compiling the ComPro database, two units for normalized elemental PCT information were found: (1)
g/L and (2) g/m2. All database entries are presented as g/L values. For those reports that listed the units as
g/m2, each value was converted to g/L through a simple multiplication factor (i.e., multiply the g/m2 value
by 2 to convert to g/L). The User Guide identifies those studies in which the PCT responses were reported
as g/m2.

4.6 Significant Figures
Throughout the ComPro database, values are reported with a larger number of figures than are (or may be)
significant. The End User is only made aware of this potential given they are ultimately responsible for the
model(s) or approach(es) that are potentially developed from these data.

4.7 Converting Oxides
For Revision 3, all SO3 measured, msrd bc, and target compositional data has been converted from reported
SO4 data.
