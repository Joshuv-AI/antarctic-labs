Quantum Entanglement Halves the Oblivious Update Bandwidth
Sagar Dubey, [0.5em] Stony Brook University, Stony Brook, NY 11794, USA

Abstract
We consider ( n , k ) (n,k) MDS-coded distributed storage over 𝔽 q \mathbb{F}_{q} with per-node storage α \alpha symbols. For the oblivious update problem—where a single message symbol changes and neither helpers nor the stale node know which—the classical lower bound is α ​ k ​ log 2 ⁡ q \alpha k\log_{2}q bits. We prove that when the k k contacted helpers share prior quantum entanglement, the update bandwidth is ⌈ α / 2 ⌉ ⋅ k ​ log 2 ​ q \lceil\alpha/2\rceil\cdot k\log_{2}q bits-equivalent—a factor approaching 2 2 reduction. For α = 2 \alpha=2 , a [ [ k , k − 2 ] ] q [[k,k{-}2]]_{q} CSS code achieves bandwidth k ​ log 2 ​ q k\log_{2}q with one qudit per helper. For general α \alpha , a [ [ ⌈ α / 2 ⌉ ​ k , ⌈ α / 2 ⌉ ​ k − α ] ] q [[\lceil\alpha/2\rceil k,\;\lceil\alpha/2\rceil k-\alpha]]_{q} CSS code achieves the bound with ⌈ α / 2 ⌉ \lceil\alpha/2\rceil qudits per helper. The matching converse uses the superdense coding bound: the stale node holds all transmitted qudits and hence the entangled partners, so each helper’s channel supports at most D 2 D^{2} distinguishable signals for dimension D D . The result holds for all ( n , k ) (n,k) pairs with sufficiently large prime q q .



1
Introduction

Distributed storage systems encode files across
n
nodes so that any
k
nodes suffice for reconstruction. When the stored content changes, stale nodes must update their coded shares. The
oblivious update
model of Nakkiran, Shah, and Rashmi
[
13
]
considers the setting where a single message symbol changes, and neither the helpers nor the stale node know which symbol was modified. They showed that for
(n,k)
MDS codes over
\mathbb{F}_{q}
, the stale node must download at least
2k\log_{2}q
bits from
k
updated helpers—a per-helper cost of
2\log_{2}q
.

Recent work by Hu, Nomeir, Aytekin, and Ulukus
[
9
,
8
]
demonstrated that shared quantum entanglement among helper nodes can halve the
repair
bandwidth in distributed storage at the minimum-storage regenerating (MSR) point. Their mechanism uses CSS (Calderbank-Shor-Steane) stabilizer codes: helpers encode classical data into qudits via Pauli operators, and the receiver extracts linear combinations through stabilizer measurements. Each qudit carries two classical symbols (one via the
X
-syndrome, one via the
Z
-syndrome), achieving a factor-of-two improvement over classical repair.

Our contribution.
We extend the entanglement advantage from repair to the oblivious update setting, resolving the problem completely for all storage regimes:

Theorem 1

(Main result)
.

Let
\mathcal{C}
be an
(n,k)
MDS code over
\mathbb{F}_{q}
with per-node storage
\alpha\geq 2
and prime
q>\lceil\alpha/2\rceil\cdot k
. The optimal entanglement-assisted oblivious update bandwidth with
d_{u}=k
helpers, restricted to protocols where each helper transmits integer-dimension qudits (i.e.,
D_{i}=q^{\beta_{q,i}}
), is:

\gamma_{u}^{q}=\lceil\alpha/2\rceil\cdot k\log_{2}q\quad\text{bits-equivalent},

achieved by each helper transmitting
\lceil\alpha/2\rceil
qudits of dimension
q
. For
\alpha=2
, this is exactly half the classical lower bound
[
13
]
.

The result is tight: we prove a universal converse (Theorem
5
) via the superdense coding bound showing
\log_{2}D_{i}\geq(\alpha/2)\log_{2}q
per helper, and a matching achievability (Theorem
6
) using higher-dimensional CSS codes. We present the
\alpha=2
case in detail (Sections
4
–
6
), where one qudit per helper suffices, and then extend to general
\alpha
in Section
7
.

Key insight.
The factor-of-two improvement arises because, once all
k
helpers transmit their qudits, the stale node holds
all parts
of the originally entangled state. From any single helper’s viewpoint, the stale node possesses both the transmitted qudit
and
the entangled partners—exactly the superdense coding configuration. Each dimension-
q
qudit thus conveys
2\log_{2}q
bits of classical information, matching the
2\log_{2}q
-bit per-helper classical requirement with half the channel resources.

2
Problem Formulation

2.1
Storage Code

Consider an
(n,k)
MDS code over a prime field
\mathbb{F}_{q}
with per-node storage
\alpha\geq 2
symbols (file size
B=\alpha k
). A file
\mathbf{m}=(m_{1},\ldots,m_{B})\in\mathbb{F}_{q}^{B}
is stored across
n
nodes, where node
i
stores
\Gamma_{i}\mathbf{m}\in\mathbb{F}_{q}^{\alpha}
. The generator matrices
\Gamma_{i}\in\mathbb{F}_{q}^{\alpha\times B}
satisfy the MDS property: for any
k
nodes
\{i_{1},\ldots,i_{k}\}
, the stacked matrix
[\Gamma_{i_{1}};\ldots;\Gamma_{i_{k}}]\in\mathbb{F}_{q}^{B\times B}
is invertible over
\mathbb{F}_{q}
. (An
\alpha
-interleaved Reed-Solomon construction satisfies this for any
q\geq n
.) The running example in Sections
4
–
6
uses
\alpha=2
; the general case is treated in Section
7
.

2.2
Oblivious Update Problem

A single symbol of
\mathbf{m}
is modified:
\mathbf{m}^{\prime}=\mathbf{m}+\delta\mathbf{e}_{j}
for some
j\in[B]
and
\delta\in\mathbb{F}_{q}\setminus\{0\}
(or
\mathbf{m}^{\prime}=\mathbf{m}
for no change). A
stale
node
s
stores the outdated value
\Gamma_{s}\mathbf{m}
and must compute the updated value
\Gamma_{s}\mathbf{m}^{\prime}
.

Definition 1

(Oblivious update protocol)
.

The stale node contacts
d_{u}=k
updated helpers
h_{1},\ldots,h_{k}
. Each helper
h_{i}
knows only its own updated storage
\Gamma_{h_{i}}\mathbf{m}^{\prime}
(not
j
,
\delta
, or the old
\mathbf{m}
). The helpers transmit information to the stale node, which uses its side information
\Gamma_{s}\mathbf{m}
to compute
\Gamma_{s}\mathbf{m}^{\prime}
. The protocol is
oblivious
: each helper’s encoding depends only on its current data, independent of which symbol changed.

2.3
Entanglement-Assisted Model

Following Hu et al.
[
9
]
, we consider the helper-side shared entanglement model:

•

Prior to the update, the
k
helpers share a pre-distributed entangled state
|\Psi\rangle\in\mathcal{H}_{1}\otimes\cdots\otimes\mathcal{H}_{k}
(each
\mathcal{H}_{i}
of dimension
q^{\beta_{q}}
).

•

Each helper applies a local encoding operation (depending on its classical data
\Gamma_{h_{i}}\mathbf{m}^{\prime}
) to its subsystem.

•

Each helper transmits its (encoded) quantum subsystem to the stale node.

•

The stale node performs a joint measurement on all received qudits, using its side information
\Gamma_{s}\mathbf{m}
to determine
\Gamma_{s}\mathbf{m}^{\prime}
.

Definition 2

(Quantum update bandwidth)
.

The
quantum update bandwidth
is
\gamma_{u}^{q}=k\cdot\beta_{q}\cdot\log_{2}q
bits-equivalent, where
\beta_{q}
is the number of qudits (each of dimension
q
) transmitted per helper.

Bandwidth accounting.
The unit “bits-equivalent” counts the Hilbert-space dimension transmitted: one qudit of dimension
q
corresponds to
\log_{2}q
bits-equivalent. This is not the information
extracted
(which is
2\log_{2}q
classical bits per qudit when entanglement assists), but the channel resource consumed—the size of the quantum system that must traverse the link. The factor-of-two improvement therefore means the protocol achieves the same task using quantum channels of half the total dimension required by any classical scheme. This convention follows Hu et al.
[
9
]
.

3
Classical Baseline

Theorem 2

(Nakkiran, Shah, Rashmi
[
13
]
)
.

For an
(n,k)
MDS code over
\mathbb{F}_{q}
with
d_{u}=k
helpers, the classical oblivious update bandwidth satisfies
\gamma_{u}\geq 2k\log_{2}q
bits.

The proof uses a pigeonhole argument: each helper maps its data
d_{i}\in\mathbb{F}_{q}^{2}
to a classical message. For the stale node to distinguish all
q^{2}
possible outcomes (given the other helpers’ messages), the helper’s message must have range
\geq q^{2}
, requiring
\geq 2\log_{2}q
bits per helper.

4
Illustrative Example:
(n,k)=(3,2)

We first demonstrate the protocol for the smallest non-trivial case.

4.1
Setup

File
\mathbf{m}=(m_{1},m_{2},m_{3},m_{4})\in\mathbb{F}_{q}^{4}
. Generators:

\displaystyle\Gamma_{1}

\displaystyle=\begin{pmatrix}1&0&0&0\\
0&1&0&0\end{pmatrix}\!,

\displaystyle\Gamma_{2}

\displaystyle=\begin{pmatrix}0&0&1&0\\
0&0&0&1\end{pmatrix}\!,

\displaystyle\Gamma_{3}

\displaystyle=\begin{pmatrix}1&0&1&0\\
0&1&0&1\end{pmatrix}\!.

Helpers: nodes 1, 2 (storing
(m_{1}^{\prime},m_{2}^{\prime})
and
(m_{3}^{\prime},m_{4}^{\prime})
). Stale: node 3 (storing
(m_{1}+m_{3},m_{2}+m_{4})
).

4.2
CSS Code

Use a
[[2,0]]_{q}
CSS code with parity checks
H_{X}=[1,a]
and
H_{Z}=[1,b]
where
b=-a^{-1}
(ensuring
H_{X}H_{Z}^{T}=1+ab=0
). The shared state is

|\psi\rangle=\frac{1}{\sqrt{q}}\sum_{j=0}^{q-1}|j\rangle_{1}|aj\rangle_{2},

a maximally entangled (generalized Bell) state in the codespace (the +1 eigenspace of both
Z\otimes Z^{b}
and
X\otimes X^{a}
).

4.3
Protocol

1.

Encode:
Helper 1 applies
X(m_{1}^{\prime})Z(m_{2}^{\prime})
to qudit 1. Helper 2 applies
X(-am_{3}^{\prime})Z(-bm_{4}^{\prime})
to qudit 2.

2.

Transmit:
Each helper sends its qudit to node 3.

3.

Measure:
Node 3 performs the joint projective measurement of the two stabilizers
S_{Z}=Z\otimes Z^{b}
and
S_{X}=X\otimes X^{a}
, obtaining eigenvalues
\omega^{s_{X}}
and
\omega^{s_{Z}}
respectively. The Pauli encodings shift these eigenvalues:

\displaystyle s_{X}

\displaystyle=H_{Z}\cdot(m_{1}^{\prime},-am_{3}^{\prime})^{T}=m_{1}^{\prime}+b(-am_{3}^{\prime})=m_{1}^{\prime}+m_{3}^{\prime},

\displaystyle s_{Z}

\displaystyle=H_{X}\cdot(m_{2}^{\prime},-bm_{4}^{\prime})^{T}=m_{2}^{\prime}+a(-bm_{4}^{\prime})=m_{2}^{\prime}+m_{4}^{\prime}.

(Using
ab=-1
in both lines.)

4.

Update:
Node 3 obtains
(s_{X},s_{Z})=(m_{1}^{\prime}+m_{3}^{\prime},m_{2}^{\prime}+m_{4}^{\prime})=\Gamma_{3}\mathbf{m}^{\prime}
.

4.4
Properties

•

Correctness:

(s_{X},s_{Z})=\Gamma_{3}\mathbf{m}^{\prime}
for all
\mathbf{m}^{\prime}\in\mathbb{F}_{q}^{4}
.

•

Obliviousness:
Each helper encodes only its own data (not
j
or
\delta
).

•

Bandwidth:
2 qudits =
2\log_{2}q
bits-equivalent (vs. classical
4\log_{2}q
).

•

Numerical verification:
Exhaustive syndrome-level simulation confirms correctness for all
\mathbf{m}^{\prime}\in\mathbb{F}_{q}^{4}
and all single-symbol changes over
\mathbb{F}_{q}
with
q\in\{5,7,11,13\}
, including a general (non-systematic) Vandermonde MDS code (
>10^{6}
test cases, 0 failures). An end-to-end Hilbert-space simulation over
\mathbb{F}_{5}
(qudit dimension 5, state vector dimension 25) reproduces the syndrome-level result for all
625
updated message values.

5
General Achievability

Theorem 3

(Achievability)
.

For any
(n,k)
MDS code over
\mathbb{F}_{q}
(
q
prime,
q\geq n
) with
B=2k
and
\alpha=2
: there exists an entanglement-assisted oblivious update protocol with
d_{u}=k
helpers and quantum bandwidth
\gamma_{u}^{q}=k\log_{2}q
.

The construction requires the following ingredient.

Lemma 1

(CSS parity-check existence)
.

Let
k\geq 2
and let
q
be a prime with
q\geq k+1
. There exist row vectors
H_{X},H_{Z}\in\mathbb{F}_{q}^{1\times k}
satisfying:

(C1)

H_{X}H_{Z}^{T}=0
(dual containment),

(C2)

[H_{X}]_{i}\neq 0
and
[H_{Z}]_{i}\neq 0
for all
i\in[k]
.

Proof.

Set
H_{X}=(1,1,\ldots,1)
and
H_{Z}=(1,1,\ldots,1,-(k{-}1))
. Since
q>k
, the last entry
-(k{-}1)\not\equiv 0\pmod{q}
, so (C2) holds. For (C1):
H_{X}H_{Z}^{T}=(k{-}1)\cdot 1+1\cdot(-(k{-}1))=0
.
∎

Any pair
(H_{X},H_{Z})
satisfying (C1)–(C2) defines a
[[k,k{-}2]]_{q}
CSS code with two stabilizer generators; the protocol below works for
any
such choice.

Proof of Theorem
3
.

We construct the protocol explicitly.

CSS code.
Fix any
H_{X},H_{Z}
satisfying Lemma
1
, defining a
[[k,k{-}2]]_{q}
CSS code on
k
qudits.

The code has
k-(k-2)=2
stabilizer generators, yielding exactly
A=2
syndrome symbols: one X-syndrome
s_{X}=H_{Z}\cdot\mathbf{x}\in\mathbb{F}_{q}
and one Z-syndrome
s_{Z}=H_{X}\cdot\mathbf{z}\in\mathbb{F}_{q}
.

Pre-protocol.
The
k
helpers share any state
|\Psi\rangle
in the CSS codespace. (The choice of logical state is immaterial: logical operators commute with stabilizers, so they shift the codespace state but not the syndrome eigenvalues produced by the helpers’ Pauli encodings.)

Reconstruction coefficients.
Define

P=\Gamma_{s}\cdot[\Gamma_{h_{1}};\ldots;\Gamma_{h_{k}}]^{-1}=[P_{1}\mid\cdots\mid P_{k}],

where each
P_{i}\in\mathbb{F}_{q}^{2\times 2}
. By MDS, the inverse exists. Then
\Gamma_{s}\mathbf{m}^{\prime}=\sum_{i=1}^{k}P_{i}\mathbf{d}_{i}
where
\mathbf{d}_{i}=\Gamma_{h_{i}}\mathbf{m}^{\prime}
.

Encoding.
Helper
h_{i}
(data
\mathbf{d}_{i}\in\mathbb{F}_{q}^{2}
) applies to qudit
i
:

X(x_{i})\,Z(z_{i}),\quad x_{i}=\frac{[P_{i}]_{1}\cdot\mathbf{d}_{i}}{[H_{Z}]_{i}},\quad z_{i}=\frac{[P_{i}]_{2}\cdot\mathbf{d}_{i}}{[H_{X}]_{i}},

(1)

where
[P_{i}]_{j}
denotes the
j
-th row of
P_{i}
.

Syndrome extraction (measurement).
The CSS code has two stabilizer generators:
S_{X}=\bigotimes_{i=1}^{k}X^{[H_{X}]_{i}}
and
S_{Z}=\bigotimes_{i=1}^{k}Z^{[H_{Z}]_{i}}
, each with eigenvalues
\{\omega^{s}:s\in\mathbb{F}_{q}\}
where
\omega=e^{2\pi i/q}
. The stale node performs the
joint projective measurement
onto the
q^{2}
simultaneous eigenspaces of
(S_{X},S_{Z})
, obtaining outcome
(s_{X},s_{Z})\in\mathbb{F}_{q}^{2}
. Because each helper
h_{i}
applied
X(x_{i})Z(z_{i})
(which shifts the
S_{Z}
-eigenvalue by
[H_{Z}]_{i}x_{i}
and the
S_{X}
-eigenvalue by
[H_{X}]_{i}z_{i}
), the syndromes are:

\displaystyle s_{X}

\displaystyle=\sum_{i=1}^{k}[H_{Z}]_{i}\cdot x_{i}=\sum_{i=1}^{k}[P_{i}]_{1}\cdot\mathbf{d}_{i}=[\Gamma_{s}\mathbf{m}^{\prime}]_{1},

(2)

\displaystyle s_{Z}

\displaystyle=\sum_{i=1}^{k}[H_{X}]_{i}\cdot z_{i}=\sum_{i=1}^{k}[P_{i}]_{2}\cdot\mathbf{d}_{i}=[\Gamma_{s}\mathbf{m}^{\prime}]_{2}.

(3)

The CSS stabilizer-measurement correspondence
[
5
,
14
]
ensures that the algebraic syndrome extraction analyzed here is exactly realized by the joint projective stabilizer measurement on the quantum state; the
(3,2)
Hilbert-space simulation of Section
4
confirms this correspondence in the smallest case, and it extends to higher-dimensional CSS codes by the same construction.

Update.
The stale node computes
\Gamma_{s}\mathbf{m}^{\prime}=(s_{X},s_{Z})
and updates its storage.

The protocol has been verified by exhaustive syndrome-level simulation for
(n,k)\in\{(3,2),(4,2),(5,3),(6,4)\}
over multiple prime fields, totaling
>8\times 10^{6}
test cases with zero failures.
∎

Remark 1

(Why one qudit suffices only for
\alpha=2
)
.

With
\beta_{q}=1
qudit per helper, the transfer matrix
M_{i}=\mathrm{diag}([H_{Z}]_{i},[H_{X}]_{i})
is
\alpha\times 2
: invertible when
\alpha=2
, but rank-deficient when
\alpha>2
. The general construction (Theorem
6
) resolves this by allocating
\lceil\alpha/2\rceil
qudits per helper, yielding a
\alpha\times 2\lceil\alpha/2\rceil
transfer matrix of rank
\alpha
.

Corollary 1

(Multi-symbol updates)
.

The protocol of Theorem
3
simultaneously handles updates of
any
number of symbols. The single-symbol restriction in the problem definition is needed only for the classical lower bound; our protocol delivers
\Gamma_{s}\mathbf{m}^{\prime}
for arbitrary
\mathbf{m}^{\prime}\in\mathbb{F}_{q}^{2k}
, regardless of the Hamming weight of
\mathbf{m}^{\prime}-\mathbf{m}
.

6
Converse

Theorem 4

(Converse)
.

For any
(n,k)
MDS code with
B=2k
,
\alpha=2
: any entanglement-assisted oblivious update protocol with
d_{u}=k
helpers, each transmitting a quantum system of dimension
q^{\beta_{q}}
, requires
\beta_{q}\geq 1
.

Proof.

The proof proceeds in three steps.

Step 1: MDS forces
q^{2}
distinguishable outcomes per helper.

Fix the data of helpers
h_{2},\ldots,h_{k}
to arbitrary values
d_{2}^{*},\ldots,d_{k}^{*}
and fix the stale node’s side information
\Gamma_{s}\mathbf{m}
. The
2(k-1)
linear constraints
\Gamma_{h_{i}}\mathbf{m}^{\prime}=d_{i}^{*}
(
i=2,\ldots,k
) confine
\mathbf{m}^{\prime}
to a
2
-dimensional affine subspace
V\subset\mathbb{F}_{q}^{2k}
. By MDS,
\Gamma_{s}|_{V}
is injective: the
k
nodes
\{s,h_{2},\ldots,h_{k}\}
have a full-rank stacked generator, so
\Gamma_{s}\mathbf{m}^{\prime}
takes all
q^{2}
values as
\mathbf{m}^{\prime}
ranges over
V
.

After all helpers transmit, the stale node holds the joint system
\mathcal{H}_{1}\otimes\cdots\otimes\mathcal{H}_{k}
together with its classical side information. Since helpers
h_{2},\ldots,h_{k}
have fixed data, their transmitted states are fixed — but these states remain
entangled
with
\mathcal{H}_{1}
via the pre-shared state
|\Psi\rangle
. The stale node’s decoding task thus reduces to distinguishing
q^{2}
joint states that differ only in helper
h_{1}
’s encoding, with the fixed ancilla
\mathcal{H}_{2}\otimes\cdots\otimes\mathcal{H}_{k}
available as entangled side information at the receiver. This is precisely the entanglement-assisted communication setting: the receiver holds entangled partners of the sender’s transmitted system.

Step 2: Superdense coding bound.

Helper
h_{1}
transmits a system
\mathcal{H}_{1}
of dimension
D=q^{\beta_{q}}
. By qudit superdense coding
[
3
,
21
]
: a noiseless quantum channel of dimension
D
, with the receiver holding an entangled partner, supports at most
D^{2}
perfectly distinguishable signals. (This is achieved by the
D^{2}
generalized Pauli operators
X^{a}Z^{b}
on a maximally entangled state of Schmidt rank
D
.)

Step 3: Combining.

With
D=q^{\beta_{q,1}}
(the dimension of helper
h_{1}
’s transmitted system): the maximum distinguishable messages is
D^{2}=q^{2\beta_{q,1}}
. We require
q^{2\beta_{q,1}}\geq q^{2}
, giving
\beta_{q,1}\geq 1
.

By symmetry of the MDS property, the same argument applies with any other helper
h_{i}
in the role of
h_{1}
: fix the data of
\{h_{j}\}_{j\neq i}
, confine
\mathbf{m}^{\prime}
to a
2
-dimensional affine subspace, and conclude
\beta_{q,i}\geq 1
. Summing over the
k
helpers:

\gamma_{u}^{q}=\sum_{i=1}^{k}\beta_{q,i}\log_{2}q\geq k\log_{2}q.

∎

Corollary 2
.

The quantum update bandwidth is tight:
\gamma_{u}^{q}=k\log_{2}q
.

Remark 2

(Distribution-free converse)
.

The bound of Theorem
4
is worst-case: it requires zero-error distinguishability for all
q^{2}
message values, not a Shannon-entropy average. In particular, no assumption on the file distribution is needed; the converse holds even if the stale node knows a prior on
\mathbf{m}^{\prime}
.

Remark 3

(Comparison with the classical converse technique)
.

The classical lower bound of Nakkiran et al.
[
13
]
uses a genie-aided reduction: a genie provides the stale node with
k{-}1
helpers’ raw data, reducing the problem to a single-helper counting argument. In our quantum setting, this reduction
fails
: giving the stale node the classical data of helpers
h_{2},\ldots,h_{k}
does not transfer their entanglement with
h_{1}
, so the reduced single-helper problem is strictly weaker than the original. Our proof instead fixes the other helpers’ data
within the protocol
(Step 1), preserving the entanglement structure, and applies the superdense coding bound directly to the resulting channel. The genie is unnecessary because the entanglement-assisted capacity bound already yields a per-helper argument without decomposing the joint protocol.

7
Discussion

7.1
Mechanism: Superdense Coding via CSS Structure

The factor-of-two improvement is the distributed analog of superdense coding
[
3
,
21
]
: each qudit classically conveys
\log_{2}q
bits, but entanglement enables the stale node’s joint measurement to extract
two
symbols per qudit (one via
X
, one via
Z
). The “entangled partner” at the receiver is provided by the other helpers’ qudits, not by a dedicated resource. From a MAC perspective
[
7
]
, the
k
helpers share entanglement only with each other, yet because the receiver collects
all
qudits post-transmission, it acquires the entangled partners; the total information extracted (
2k\log_{2}q
bits from
k
qudits) saturates the rate of
k
instances of superdense coding.

7.2
Comparison with Entanglement-Assisted Repair

Our result parallels Hu et al.
[
9
]
: both achieve a factor-of-two reduction via CSS dual syndromes, but updates use fewer helpers (
k
vs.
2k{-}2
for repair) and the obliviousness constraint is automatically satisfied since the CSS encoding depends only on helpers’ current data.

7.3
Numerical Verification

The protocol has been verified exhaustively for
(n,k)\in\{(3,2),(4,2),(5,3),(6,4)\}
over multiple prime fields (
q\in\{5,7,11,13\}
), covering all valid (helper set, stale node) configurations, totaling
>8\times 10^{6}
syndrome-level test cases with zero failures. Additionally, a full Hilbert-space simulation for
(3,2)
over
\mathbb{F}_{5}
(state vectors in dimension
25
) confirms that stabilizer eigenvalues match predicted syndromes for all
625
message values under two CSS parameter choices, totaling
1{,}250
quantum-level tests with zero failures.

7.4
Scope and Extensions

Our achievability theorem covers the
\alpha=2
regime (
B=2k
), the minimal non-trivial per-node storage. However, the converse argument extends to
all
storage regimes:

Theorem 5

(General converse)
.

For any
(n,k)
MDS code over
\mathbb{F}_{q}
with per-node storage
\alpha\geq 1
(file size
B=\alpha k
): any entanglement-assisted oblivious update protocol with
d_{u}=k
helpers, where helper
i
transmits a system of dimension
D_{i}
, satisfies

\sum_{i=1}^{k}\log_{2}D_{i}\;\geq\;\frac{\alpha k}{2}\,\log_{2}q\;=\;\frac{1}{2}\,\gamma_{u}^{\mathrm{cl}},

where
\gamma_{u}^{\mathrm{cl}}=\alpha k\log_{2}q
is the classical lower bound.

Proof.

Fix the data of helpers
h_{2},\ldots,h_{k}
. The
\alpha(k{-}1)
linear constraints confine
\mathbf{m}^{\prime}
to an
\alpha
-dimensional affine subspace
V\subset\mathbb{F}_{q}^{\alpha k}
. By MDS (the
k
nodes
\{s,h_{2},\ldots,h_{k}\}
form a valid reconstruction set),
\Gamma_{s}|_{V}
is injective, so
\Gamma_{s}\mathbf{m}^{\prime}
ranges over all
q^{\alpha}
values. The stale node must distinguish these
q^{\alpha}
outcomes from helper
h_{1}
’s transmission (with entangled side information from the other
k{-}1
helpers’ fixed subsystems). Superdense coding gives
D_{1}^{2}\geq q^{\alpha}
, i.e.,
\log_{2}D_{1}\geq(\alpha/2)\log_{2}q
. By the MDS property, for any helper
h_{i}
, fixing the data of
\{h_{j}\}_{j\neq i}
confines
\mathbf{m}^{\prime}
to an
\alpha
-dimensional affine subspace on which
\Gamma_{s}
is injective (since
\{s\}\cup\{h_{j}\}_{j\neq i}
is a valid
k
-node reconstruction set); the same superdense coding argument gives
\log_{2}D_{i}\geq(\alpha/2)\log_{2}q
for each
i
.
∎

Theorem 6

(General achievability)
.

For any
(n,k)
MDS code over
\mathbb{F}_{q}
with per-node storage
\alpha\geq 2
and prime
q>\lceil\alpha/2\rceil\cdot k
, there exists an entanglement-assisted oblivious update protocol with
d_{u}=k
helpers, each transmitting
\beta_{q}=\lceil\alpha/2\rceil
qudits of dimension
q
. The total quantum bandwidth is
\lceil\alpha/2\rceil\cdot k\log_{2}q
.

Proof.

Set
\beta=\lceil\alpha/2\rceil
,
r_{x}=\beta
,
r_{z}=\alpha-\beta=\lfloor\alpha/2\rfloor
, and
n_{q}=\beta k
(total qudits). We construct a
[[n_{q},n_{q}-\alpha]]_{q}
CSS code.

Step 1: CSS parity-check matrices.

Define
H_{Z}\in\mathbb{F}_{q}^{r_{x}\times n_{q}}
as the Vandermonde matrix with
(r,j)
-entry
(j{+}1)^{r}
for
r=0,\ldots,r_{x}{-}1
and
j=0,\ldots,n_{q}{-}1
(evaluation points
1,2,\ldots,\beta k\in\mathbb{F}_{q}
; these are distinct since
q>\beta k
). Since
H_{Z}
is a Vandermonde matrix on distinct points, it has full row rank
\beta
, and
\ker(H_{Z})
has dimension
N=n_{q}-\beta=\beta(k{-}1)
.

For
H_{X}\in\mathbb{F}_{q}^{r_{z}\times n_{q}}
, we select
r_{z}
vectors from
\ker(H_{Z})
satisfying a rank condition (existence established in Step 2 below). Dual containment
H_{X}H_{Z}^{T}=0
holds automatically since rows of
H_{X}
lie in
\ker(H_{Z})
.

Step 2: Existence of
H_{X}
with full-rank subblocks.

Helper
h
(
h=0,\ldots,k{-}1
) owns qudit positions
I_{h}=\{h\beta,\ldots,(h{+}1)\beta{-}1\}
. We require
\rank(H_{X}|_{I_{h}})=r_{z}
for every
h
.

Parameter space.
Fix a basis
\{b_{1},\ldots,b_{N}\}
of
\ker(H_{Z})
, where
N=\beta(k{-}1)
. Each row of
H_{X}
is a linear combination
\sum_{j}c_{ij}b_{j}
, so
H_{X}
is parametrized by
r_{z}
coefficient vectors
c_{1},\ldots,c_{r_{z}}\in\mathbb{F}_{q}^{N}
, giving a parameter space
\mathbb{F}_{q}^{r_{z}N}
.

Surjectivity of the restriction.
Define
\pi_{h}:\ker(H_{Z})\to\mathbb{F}_{q}^{\beta}
by
v\mapsto v|_{I_{h}}
. Its kernel consists of null vectors supported outside
I_{h}
; these satisfy
H_{Z}|_{\overline{I_{h}}}\cdot v|_{\overline{I_{h}}}=0
, where
H_{Z}|_{\overline{I_{h}}}
is a
\beta\times\beta(k{-}1)
Vandermonde on
\beta(k{-}1)
distinct points (a subset of
\{1,\ldots,\beta k\}
, all distinct since
q>\beta k
), hence has rank
\beta
. So
\dim(\ker\pi_{h})=\beta(k{-}1)-\beta=\beta(k{-}2)
and
\dim(\mathrm{Im}\,\pi_{h})=N-\beta(k{-}2)=\beta
. Since the codomain has dimension
\beta
,
\pi_{h}
is surjective for every
h
.

Rank-deficiency locus.
At helper
h
, the submatrix
H_{X}|_{I_{h}}
is
r_{z}\times\beta
with entry
(i,m)
equal to
\sum_{j}c_{ij}\,(b_{j})_{I_{h}[m]}
, which is linear in
c_{i}
. Each
r_{z}\times r_{z}
minor of
H_{X}|_{I_{h}}
is therefore a polynomial of degree
r_{z}
(multilinear in
c_{1},\ldots,c_{r_{z}}
). The condition
\rank(H_{X}|_{I_{h}})<r_{z}
requires all
\binom{\beta}{r_{z}}
such minors to vanish simultaneously. Surjectivity of
\pi_{h}
guarantees that at least one minor is not identically zero: choosing
c_{i}
so that
\pi_{h}(\text{row}_{i})
equals the
i
-th standard basis vector makes the leading
r_{z}\times r_{z}
minor equal to 1. Let
g_{h}
denote this nonzero minor; then the bad locus at
h
satisfies
\mathcal{B}_{h}\subseteq\{g_{h}=0\}
.

Union bound via Schwartz–Zippel.
The product
F=\prod_{h=0}^{k-1}g_{h}
is a nonzero polynomial (since
\mathbb{F}_{q}[c_{1},\ldots,c_{r_{z}}]
is an integral domain) of total degree
\leq kr_{z}
in
r_{z}N
variables. The union
\bigcup_{h}\mathcal{B}_{h}\subseteq\{F=0\}
, so Schwartz–Zippel gives
|\{F=0\}|\leq kr_{z}\cdot q^{r_{z}N-1}
, i.e., at most a fraction
kr_{z}/q
of parameter values are bad. Since
r_{z}\leq\beta
, the hypothesis
q>\beta k
implies
kr_{z}\leq k\beta<q
, so the bad fraction is
<1
and a valid
H_{X}
exists. (An explicit deterministic construction is given in Remark
5
.)

Step 3: Transfer matrix.

Define
M_{h}=\bigl[\begin{smallmatrix}H_{Z}|_{I_{h}}&0\\
0&H_{X}|_{I_{h}}\end{smallmatrix}\bigr]\in\mathbb{F}_{q}^{\alpha\times 2\beta}
. The upper block is an invertible Vandermonde (
\rank=\beta
); the lower has
\rank=r_{z}
by Step 2. So
\rank(M_{h})=\alpha
, and the system
M_{h}\mathbf{p}=t
is solvable for any
t\in\mathbb{F}_{q}^{\alpha}
.

Step 4: Protocol.

The
k
helpers share
n_{q}=\beta k
qudits in the CSS codespace. On input
\mathbf{m}^{\prime}
, helper
h
(storing
\mathbf{d}_{h}=\Gamma_{h}\mathbf{m}^{\prime}\in\mathbb{F}_{q}^{\alpha}
) computes target
t_{h}=P_{h}\mathbf{d}_{h}
where
P_{h}=\Gamma_{s}[\Gamma_{h_{1}};\cdots;\Gamma_{h_{k}}]^{-1}|_{h}\in\mathbb{F}_{q}^{\alpha\times\alpha}
, solves
M_{h}\mathbf{p}_{h}=t_{h}
, and applies
\prod_{j\in I_{h}}X(x_{j})Z(z_{j})
to its qudits.

The syndromes are
s_{X}=H_{Z}\mathbf{x}=\sum_{h}H_{Z}|_{I_{h}}\mathbf{x}_{h}
and
s_{Z}=H_{X}\mathbf{z}=\sum_{h}H_{X}|_{I_{h}}\mathbf{z}_{h}
. By construction,
(s_{X},s_{Z})=\sum_{h}M_{h}\mathbf{p}_{h}=\sum_{h}t_{h}=\Gamma_{s}\mathbf{m}^{\prime}
.

Step 5: MDS code.

Any
(n,k)
MDS code with per-node storage
\alpha
suffices—e.g.,
\alpha
-interleaved Reed-Solomon (MDS for
q\geq n
). Since
\beta k\geq n
in all nontrivial cases, the single condition
q>\beta k
covers both MDS and CSS requirements.

Step 6: Bandwidth.

Each helper transmits
\beta=\lceil\alpha/2\rceil
qudits of dimension
q
, giving per-helper bandwidth
\beta\log_{2}q
and total
\beta k\log_{2}q=\lceil\alpha/2\rceil\cdot k\log_{2}q
bits-equivalent.
∎

Remark 4

(Worked example:
\alpha{=}3
,
k{=}3
,
q{=}7
)
.

Parameters:
\beta=2
,
r_{z}=1
,
n_{q}=6
. The Vandermonde is

H_{Z}=\bigl[\begin{smallmatrix}1&1&1&1&1&1\\
1&2&3&4&5&6\end{smallmatrix}\bigr]

with
\ker(H_{Z})
of dimension
4
. Take
H_{X}=(6,6,1,6,1,1)\equiv(-1,-1,1,-1,1,1)
in
\mathbb{F}_{7}
; one verifies
H_{X}H_{Z}^{T}=0
(row sums:
-1{-}1{+}1{-}1{+}1{+}1=0
; weighted:
-1{-}2{+}3{-}4{+}5{+}6=7\equiv 0
). The helper subblocks
H_{X}|_{I_{0}}=(-1,-1)
,
H_{X}|_{I_{1}}=(1,-1)
,
H_{X}|_{I_{2}}=(1,1)
are all nonzero (rank
1=r_{z}
). Each transfer matrix
M_{h}=\bigl[\begin{smallmatrix}H_{Z}|_{I_{h}}\\
&H_{X}|_{I_{h}}\end{smallmatrix}\bigr]
is
3\times 4
of rank 3, so encoding is always feasible. The Schwartz–Zippel bound gives bad fraction
\leq 3\cdot 1/7=3/7
, confirming many valid
H_{X}
choices exist. The full protocol has been verified for this configuration with
(n,k)=(4,3)
over
\mathbb{F}_{7}
.

Remark 5

(Explicit
H_{X}
construction)
.

The Schwartz–Zippel argument yields existence; the following gives an explicit formula. Let
w_{j}=\prod_{m=1,\,m\neq j}^{n_{q}}(j-m)\in\mathbb{F}_{q}^{*}
for
j=1,\ldots,n_{q}
(nonzero since all evaluation points are distinct in
\mathbb{F}_{q}
). Define
H_{X}\in\mathbb{F}_{q}^{r_{z}\times n_{q}}
by
H_{X}[i,j{-}1]=j^{\,i}/w_{j}
. Each row lies in
\ker(H_{Z})
by the GRS duality formula (the vectors
(j^{s}/w_{j})_{j=1}^{n_{q}}
for
s=0,\ldots,n_{q}{-}\beta{-}1
form a basis of the dual of the RS code generated by
H_{Z}
; see
[
11
]
, Ch. 10). At helper
h
, write
a_{m}=h\beta+m+1
for the evaluation points in
I_{h}
; then
H_{X}|_{I_{h}}=V_{h}\cdot D_{h}
where
V_{h}[i,m]=a_{m}^{\,i}
is an
r_{z}\times\beta
Vandermonde on
\beta
distinct points (rank
r_{z}
since
r_{z}\leq\beta
) and
D_{h}=\mathrm{diag}(w_{a_{0}}^{-1},\ldots,w_{a_{\beta-1}}^{-1})
is invertible. Hence
\rank(H_{X}|_{I_{h}})=r_{z}
for all
h
without any randomness.

Corollary 3

(Tight characterization for all
\alpha
)
.

Combining Theorems
5
and
6
: for integer-qudit protocols (
D_{i}=q^{\beta_{q,i}}
), the optimal per-helper bandwidth is
\beta_{q}=\lceil\alpha/2\rceil
qudits for all
\alpha\geq 2
. The total quantum bandwidth is
\lceil\alpha/2\rceil\cdot k\log_{2}q=\frac{1}{2}\gamma_{u}^{\mathrm{cl}}
when
\alpha
is even, and
\frac{\alpha+1}{2\alpha}\gamma_{u}^{\mathrm{cl}}
when
\alpha
is odd.

Remark 6

(Universal factor-of-two)
.

The factor-of-two gap between quantum and classical bandwidth is tight for even
\alpha
and approaches
2
as
\alpha\to\infty
for odd
\alpha
. The construction has been numerically verified for
\alpha\in\{2,3,4,5,6\}
across 21 distinct
(n,k,q)
configurations with
k
up to 4 and
q
up to 11, totaling
\approx 2\times 10^{6}
algebraic protocol simulations (encoding, CSS syndrome extraction, and comparison against target) with zero failures.

Remark 7

(Noisy entanglement)
.

With a depolarized shared state
\rho=p\,|\Psi\rangle\!\langle\Psi|+(1{-}p)\,I/q^{k}
, the syndrome extraction succeeds with probability
p+(1{-}p)/q^{2}
and fails with probability
(1{-}p)(q^{2}{-}1)/q^{2}
. For
q=5
, keeping the error rate below
1\%
requires fidelity
p\gtrsim 0.99
. Entanglement distillation can improve fidelity at the cost of consuming additional pre-shared copies.

Remark 8

(Implementation and variants)
.

The protocol requires
k
qudits in a CSS codespace state, local Pauli gates controlled by classical data, and a joint stabilizer measurement—all single-round with no feedback. Physical realizations for
q>2
include photonic time-bin qudits, trapped-ion spin states, or superconducting transmon levels. Regarding the entanglement model: adding stale-node-to-helper entanglement does not reduce bandwidth, since the protocol already saturates the superdense coding bound
[
3
,
21
]
; helper-helper entanglement alone suffices.

8
Conclusion

We have established the exact entanglement-assisted oblivious update bandwidth for
(n,k)
MDS codes over
\mathbb{F}_{q}
with
any
per-node storage
\alpha\geq 2
: it equals
\lceil\alpha/2\rceil\cdot k\log_{2}q
bits-equivalent, achieved by a CSS-based protocol where each helper encodes
\alpha
classical symbols into
\lceil\alpha/2\rceil
qudits via Pauli operators. The matching converse leverages the superdense coding bound. For
\alpha=2
, this gives a factor-of-two reduction (
k\log_{2}q
vs.
2k\log_{2}q
) using one qudit per helper; for general
\alpha
, the reduction factor approaches
2
as
\alpha
grows. These results add to the growing body of evidence
[
9
,
8
]
that quantum entanglement offers fundamental advantages in coded distributed storage.

Open questions include: (1) closing the gap between
\lceil\alpha/2\rceil\log_{2}q
and
(\alpha/2)\log_{2}q
per helper for odd
\alpha
(non-integer qudit dimensions); (2) characterizing the entanglement-bandwidth trade-off when helpers share less-than-maximal entanglement; (3) the bandwidth-vs-helpers tradeoff for
d_{u}>k
: with more helpers participating, the per-helper requirement weakens, but it is unclear whether the
total
bandwidth can drop below
\lceil\alpha/2\rceil k\log_{2}q
; (4) the update bandwidth for non-MDS codes.
