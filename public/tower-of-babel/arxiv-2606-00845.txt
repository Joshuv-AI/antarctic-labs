Abstract
. In this article we study the notion of completeness for conjunctive reducibilities. We investigate the relationship between c c -completeness and r r -completeness of computably enumerable (c.e.) sets with respect to various strong reducibilities ≤ r \leq_{r} . By using simplicity properties of sets, we prove that there exist c.e. sets that are simultaneously Q Q -complete and b ​ d bd -complete, yet fail to be c c -complete. Similarly, there exist c.e. sets that are simultaneously Q Q -complete and b ​ w ​ t ​ t bwtt -complete (respectively, b ​ t ​ t btt -complete) but not c c -complete. Furthermore, we study two restrictions of c c -reducibility, namely c 1 c_{1} - and c 1 , N c_{1,N} -reducibility, and show that they are distinct on the c.e. sets. Nevertheless, we prove that the notions of completeness for c c , c 1 c_{1} , and c 1 , N c_{1,N} coincide.

Introduction

In this paper we study conjunctive reducibility (
c
-reducibility), first
proposed by Jockusch
[
11
]
, and its subreducibility (known as

c_{1,N}
-reducibility), suggested by Bulitko
[

reducibility is a

computability relative to an external oracle in which the computing agent
makes use only of positive information about the oracle. In this sense, it is
a restricted version of enumeration reducibility, although it provides a
degree structure whose least degree consists exactly of the decidable sets.
This marks a fundamental difference from the most commonly studied positive
reducibilities, whose least degree consists instead of the computably
enumerable (c.e.) sets.

Formally, a set
A
is

to a set

) if there exists a computable function

such that for all

x\in A\iff D_{f(x)}\subseteq B:

we say in this case that

is a
c
-reduction from

to
B

(Throughout the paper the symbol

denotes the set of natural numbers,
and the symbol

denotes the finite set with canonical index

Interest in studying the algebraic structure of the

[

[

-degrees correspond to properties of classes of finitely generated
subgroups of algebraically closed groups. Degtev
[

of the c.e.

-degrees is not distributive and
is not elementarily equivalent to the structure

of the c.e.

r

[
6
]

proved that every maximal set has minimal

-reduction from

A further restriction of

\displaystyle D_{f_{1}(x)}
