 Problem Statement
●
 Even for the same machine manufacturer, model and configuration,
 each machine has unique process signatures indicative of weld
 attributes
●
 For some processes, obtaining process output signatures is straight-
 forward
 – Arc welding
●
 For other processes, obtaining process output signatures is difficult
 – Electron beam welding
●
 The problem addressed here is to determine if process output
 signatures, indicative of weld attributes, can be obtained from process
 input power

 05/22/23 2

 Objectives
The work in this project
provides answers to the
questions:
– Is there is sufficient
 information within the
 welding process input
 power to understand
 process output power
 characteristics? if so,
– Is there sufficient fidelity or
 resolution within the input
 electrical characteristics to
 infer some measures of
 weld quality?

 Conclusions
●
 a strong numeric correlation exists between the input and output power
●
 a strong visual correlation exists between input power plots and weld bead
 appearance
●
 it is possible to visually discriminate between undisturbed (nominal) and
 disturbed (off-nominal) weld data plots based on trends observed in the
 input powers
●
 the ability to discern trends and features within process input power related
 to welding conditions is not significantly influenced by welding process
 (GMAW and GTAW), welding operation mode (non-pulsed, pulsed, transfer
 mode), and power source type (inverter and SCR)
●
 discrimination of nominal/off-nominal welding conditions could be devised
 based solely on weld input power analysis
                                      05/22/23                                      20

 Conclusions
 The answers the questions posed at the beginning of this
 presentation are:
●
 Is there is sufficient information within the welding process input
 power to understand process output power characteristics? - Yes
●
 Is there sufficient fidelity or resolution within the input electrical
 characteristics to infer some measures of weld quality? - Yes,
 assuming process disturbances related to weld quality are large
 enough to be detected in output and therefore input electrical power
●
 NILM for welding processes warrants additional work to understand
 finer details on its limitations to infer weld quality

                                   05/22/23                                  21

 Future Work
 Important questions to be answered include:
●
 What magnitude of process disturbances cause deleterious weld quality issues?
●
 What magnitude of process disturbances are detectable in process input power
 measurements?
●
 Can subtle process disturbances causing deleterious weld quality issues be detected in
 process input power?

 Follow on work will involve designing a set of experiments for:
●
 targeted welding process application producing many instances of the same weld
●
 targeted important types of weld quality issues
●
 each welding process and power source type does require some data processing
 specific to the process and power source type
