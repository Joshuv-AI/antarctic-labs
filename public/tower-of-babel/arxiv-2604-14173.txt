A criterion for Cauchy sequences in db-metric spaces
Lech Pasicki

Abstract
In this note a criterion for Cauchy sequences is proved which refines the one presented in ‘Cauchy sequences in b-metric spaces’, Topology Appl. 373 (2025) 109477.



MSC: 54E99. Keywords: Cauchy sequence, b-metric space, db-metric space

First, let us recal the following (maybe original) idea from
[
4
]

Definition 1

A mapping
\varrho\colon X\times X\to\mbox{$[0,\infty)$}
is a db-metric (dislocated b-metric) for
X
if
the following conditions are satisfied

\displaystyle\varrho(x,y)=0\textit{ yields }x=y,\quad\mbox{$x,y\in X$},

(1a)

\displaystyle\varrho(x,y)=\varrho(y,x),\quad\mbox{$x,y\in X$},

(1b)

\displaystyle\varrho(x,z)\leq s[\varrho(x,y)+\varrho(y,z)],\quad x,y,z\in X,\textit{ for an }s\geq 1.

(1c)

Then
(X,\varrho)
is a db-metric space (dislocated b-metric space).

The mapping presented above is a natural extension of the dislocated-metric, a notion due to Hitzler and Seda

[
2
]
(
s=1
). For example, each partial metric (introduced by Matthews
[
3
, Definition 3.1]
), if
nonnegative, is a d-metric. As regards b-metric, assumed is the equivalence in (
1a
). It should be noted
that the idea of a b-metric was presented by Czerwik in
[
1
]
(for
s=2
).

Now, let us prove our criterion, which refines
[
4
, Lemma 2.3]
.

Lemma 2

For
X=\{x\mbox{${}_{n}$}\colon\mbox{$n\in\mathbb{N}$}\}
and
\varrho\colon X\times X\to\mbox{$[0,\infty)$}
let (
1b
), (
1c
) be
satisfied. Then
\mbox{$\lim_{m,n\to\infty}$}\varrho(x\mbox{${}_{n}$},x\mbox{${}_{m}$})=0
if and only if the following conditions hold

\displaystyle\mbox{$\lim_{n\to\infty}$}\varrho(x\mbox{${}_{n+1}$},x\mbox{${}_{n}$})=0,

(2a)

\displaystyle\begin{split}&\textit{for each small }\delta>0\textit{ there exist }\mbox{$n_{0}$},p\in\mbox{$\mathbb{N}$}\textit{, and }0<\lambda<1\textit{ such that }\\
&0<\varrho(x\mbox{${}_{n}$},x\mbox{${}_{m}$})<\delta\textit{ yields }\varrho(x\mbox{${}_{n+p}$},x\mbox{${}_{m+p}$})<\delta\lambda/s,\quad m,n>\mbox{$n_{0}$}.\end{split}

(2b)

Proof

If
\mbox{$\lim_{m,n\to\infty}$}\varrho(x\mbox{${}_{n}$},x\mbox{${}_{m}$})=0
, then (
2a
) obviously holds, and for a
p\in\mbox{$\mathbb{N}$}
and all
m,n\in\mbox{$\mathbb{N}$}

we have
\varrho(x\mbox{${}_{n+p}$},x\mbox{${}_{m+p}$})<\delta\lambda/s
, which means that condition (
2b
) is satisfied.

Let
\delta>0
be arbitrary. Now, for a
p
as in (
2b
) and
q\in\{2,\ldots,p\}
(if
p\geq 2
)
conditions (
1c
), (
2a
) imply

\begin{split}&\varrho(x\mbox{${}_{n+q}$},x\mbox{${}_{n}$})=\varrho(x\mbox{${}_{n}$},x\mbox{${}_{n+q}$})\leq s\varrho(x\mbox{${}_{n}$},x\mbox{${}_{n+1}$})+s\varrho(x\mbox{${}_{n+1}$},x\mbox{${}_{n+q}$})\leq\cdots\leq\\
&s\varrho(x\mbox{${}_{n}$},x\mbox{${}_{n+1}$})+\cdots+s^{q-1}\varrho(x_{n+q-1},x\mbox{${}_{n+q}$})\to 0,\textit{ for }n\to\infty.\end{split}

The same holds for
q=0
, as
\varrho(x\mbox{${}_{n}$},x\mbox{${}_{n}$})\leq 2s\varrho(x\mbox{${}_{n+1}$},x\mbox{${}_{n}$})
. Consequently (see (
2a
)), we get

\varrho(x\mbox{${}_{n+q}$},x\mbox{${}_{n}$})<\delta(1-\lambda)/s,\textit{ for all }n>\mbox{$m_{0}$}\geq\mbox{$n_{0}$},\textit{ and }q\in\{0,\ldots,p\}.

(3)

We may put
\mbox{$n_{0}$}=\mbox{$m_{0}$}
in (
2b
).

Now, assume

\varrho(x\mbox{${}_{n+kp}$},x\mbox{${}_{n}$})<\delta,\textit{ for a }k\geq 1.

If
\varrho(x\mbox{${}_{n+kp}$},x\mbox{${}_{n}$})=0
, then (
1c
), (
3
) yield

\begin{split}&\varrho(x\mbox{${}_{n+(k+1)p}$},x\mbox{${}_{n}$})\leq s\varrho(x\mbox{${}_{n+(k+1)p}$},x\mbox{${}_{n+kp}$})+s\varrho(x\mbox{${}_{n+kp}$},x\mbox{${}_{n}$})=\\
&s\varrho(x\mbox{${}_{n+(k+1)p}$},x\mbox{${}_{n+kp}$})<\delta(1-\lambda)<\delta.\end{split}

For
0<\varrho(x\mbox{${}_{n+kp}$},x\mbox{${}_{n}$})<\delta
, from (
2b
) and (
3
) we obtain

\varrho(x\mbox{${}_{n+(k+1)p}$},x\mbox{${}_{n}$})\leq s\varrho(x\mbox{${}_{n+(k+1)p}$},x\mbox{${}_{n+p}$})+s\varrho(x\mbox{${}_{n+p}$},x\mbox{${}_{n}$})<\delta\lambda+\delta(1-\lambda)=\delta.

Thus, by induction we get

\varrho(x\mbox{${}_{n+kp}$},x\mbox{${}_{n}$})<\delta,\quad k\in\mbox{$\mathbb{N}$}.

(4)

Any
m\in\mbox{$\mathbb{N}$}
,
m\geq n
can be written as
m=n+kp+q
, for some
k\in\{0\}\cup\mbox{$\mathbb{N}$}
,

q\in\{0,1,\ldots,p-1\}
. Now, by (
3
), (
4
), for
m,n>\mbox{$n_{0}$}
we obtain

\varrho(x\mbox{${}_{m}$},x\mbox{${}_{n}$})=\varrho(x_{n+kp+q},x\mbox{${}_{n}$})\leq s\varrho(x_{n+kp+q},x\mbox{${}_{n+kp}$})+s\varrho(x\mbox{${}_{n+kp}$},x\mbox{${}_{n}$})<\delta(1-\lambda)+s\delta,

which means that
\mbox{$\lim_{m,n\to\infty}$}\mbox{$\varrho(x_{n},x_{m})$}=0
.

\quad\square

It should be noted that condition (
2a
) cannot be disregarded. Let us consider
x\mbox{${}_{n}$}=n
,
n\in\mathbb{N}
.
Then
0<\varrho(x\mbox{${}_{n}$},x\mbox{${}_{m}$})=|n-m|<\delta
never holds for
\delta<1
. Consequently, condition (
2b
)
is satisfied, while
(x_{n})_{n\in\mathbb{N}}
is not a Cauchy sequence.

Assume that a selfmapping
f\colon X\to X
on a db-metric space
(X,\varrho)
is such that for a
c<1

\varrho(fx,fy)\leq c\varrho(x,y),\quad\mbox{$x,y\in X$}

holds. Then for
x\mbox{${}_{n}$}=\mbox{$f^{n}$}x
,
n\in\mathbb{N}
we have

\varrho(x\mbox{${}_{n+p}$},x\mbox{${}_{m+p}$})\leq c^{p}\varrho(x\mbox{${}_{n}$},x\mbox{${}_{m}$}),

and (
2b
) is satisfied for any
p
such that
c^{p}<\lambda/s
. Thus, the Banach fixed point
theorem is an almost immediate consequence of Lemma
2
.

In
[
4
]
some fixed point theorems are presented. Maybe, Lemma
2
will be a useful tool
to obtain more advanced results.
