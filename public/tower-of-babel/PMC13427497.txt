Coding Challenges Around the Glenohumeral, Acromioclavicular, and Sternoclavicular Joints for the Pediatric Sports Surgeon
Authors: Elise C Bixby, Christine Banks, Lauren H Redler, Jennifer J Beck
Published: 2026

Introduction

Knee pathologies often dominate the practice of pediatric sports surgeons. However, upper extremity injuries and overuse syndromes become more common in adolescents and young adults and thus are often within the pediatric sports surgeon’s scope of practice. Coding for shoulder instability and capitellar osteochondritis dissecans has been previously covered by Niu et al. in a Coding Corner article from February 2022 [1]. Here we address other surgeries of the glenohumeral, acromioclavicular, and sternoclavicular (SC) joints, for which surgeons may be less familiar with coding. We present common case scenarios with clarifications on proper billing. Please note that these scenarios are hypothetical. Ultimate code selection should always align with documentation reflected in the operative report.

Case 1: posterior shoulder impingement

A 17-year-old male baseball pitcher has chronic posterior shoulder pain from throwing, refractory to extensive conservative management. He is undergoing a shoulder arthroscopy with concomitant procedures.

What is the correct Current Procedural Terminology code for debridement of the posterior structures?

It depends on the extent of the debridement. Limited debridement of 1 or 2 structures is coded as Current Procedural Terminology (CPT) code 29822 (Arthroscopy, shoulder, surgical; debridement, limited, 1 or 2 discrete structures). Extensive debridement of 3 or more structures is coded as CPT code 29823 (Arthroscopy, shoulder, surgical; debridement, extensive, 3 or more discrete structures). Discrete structures noted in these codes include for example, humeral bone, humeral articular cartilage, glenoid bone (e.g., a Bennett lesion), glenoid articular cartilage, biceps tendon, biceps anchor complex, labrum, articular capsule, articular side of the rotator cuff, bursal side of the rotator cuff, subacromial bursa, and foreign body(ies). Structures which are involved in other procedures cannot be counted as discrete structures for debridement codes (see examples later in the text). An arthroscopic biceps tenotomy, a subacromial decompression with (when no other procedure is performed) or without acromioplasty, and loose body removal that does not meet the criteria for CPT code 29819 (requiring extension of the portal/cannula beyond what is required for concomitant procedures) are also each considered a structure. As per the National Council on Compensation Insurance (NCCI), most other CPT codes for arthroscopic shoulder surgeries are inclusive of limited debridement but not extensive debridement. For private payors, modifier 59 may need to be attached to 29822 when discrete structures are debrided in addition to separate structural repairs. It is important to recognize the differences between CMS's government payor guidelines and CPT guidelines when billing CPT 29822 and 29823 in addition to other arthroscopic shoulder procedures.

What CPT code is used if the posterior labrum needs to be repaired after debridement, for example, of a Bennett lesion? What about if a more superior anchor is placed for a superior anterior to posterior labral repair? Is this separate?

A labral repair would be CPT code 29806 (Arthroscopy, shoulder, surgical; capsulorrhaphy). Remember that if you code for a labral repair, you can no longer count the labrum, capsule, and posterior glenoid toward a debridement code. The NCCI allows for limited and extensive debridement (of separate structures) to be billed for in addition to a labral repair. However, this is inconsistent across other payors.

A superior anterior to posterior labral (SLAP) repair can be coded for in addition to the labral repair but only if the biceps anchor is noted to be unstable prior to surgical fixation. In this case, CPT code 29807 (Arthroscopy, shoulder, surgical; repair of SLAP lesion) is used. Suture anchors which do not address an unstable biceps anchor are included in the CPT code 29806, regardless of how proximal they might be. Most payors do not reimburse for CPT codes 29807 and 29806 concomitantly. For those that do, the SLAP lesion and the other labral tear must be carefully documented as discrete pathologies.

Biceps tenodeses are typically reserved for older patients. However, if performed arthroscopically, CPT code 29828 (Arthroscopy, shoulder, surgical; biceps tenodesis) would be utilized. An open biceps tenodesis would utilize CPT code 23430 (Tenodesis of long tendon of biceps). Please note that neither CPT nor CMS allows a limited debridement to be billed with a biceps tenodesis. An extensive debridement code (29823) can be used with these tenodesis codes, but debridement of the biceps does not count toward the number of discrete structures debrided. Biceps tenotomy is also included in both CPT codes tenodesis (29828 and 23430) and cannot be billed for separately.

What if the rotator cuff is not only debrided, but a partial thickness tear is repaired?

A rotator cuff repair, whether for a partial or full thickness tear, is billed using CPT code 29827 (Arthroscopy, shoulder, surgical; with rotator cuff repair). This code is inclusive of limited debridement (CPT code 29822) but not of an extensive debridement (29823). However, the bursal and articular rotator cuff as well as the subacromial bursa cannot be counted as any of the 3 discrete structures required to bill for an extensive debridement.

Is a subacromial decompression separately billable?

Correct coding of a subacromial decompression depends on many factors. If a subacromial bursectomy is performed to repair the supraspinatus tendon, the subacromial bursectomy is not separately billable. However, CPT code 29826 (Arthroscopy, shoulder, surgical; decompression of subacromial space with partial acromioplasty, with coracoacromial ligament (i.e. arch) release, when performed) can be used in addition to other codes (e.g., 29806–29825, 29827–29828) when reshaping of the acromion is performed. It is important to describe the morphology of the acromion for reshaping. As per CPT, an excision of a “bone spur” is not an acromioplasty and would be coded as a discrete structure in an arthroscopic debridement.

Case 2: distal clavicle osteolysis

A 15-year-old male judo athlete presents with a traumatic injury to the acromioclavicular joint. Over the course of the following year, he has progressive osteolysis of the distal clavicle, with pain refractory to analgesics, physical therapy, and corticosteroid injections.

What is the correct code for a distal clavicle excision?

Arthroscopic distal clavicle excisions are billed using CPT code 29824 (Arthroscopy, shoulder, surgical; distal claviculectomy including distal articular surface [Mumford procedure]). Open distal clavicle excisions are billed using CPT code 23120 (Open distal clavicle excision). Most insurance companies require documentation of pain with cross-body adduction as well as findings on magnetic resonance imaging to approve these codes. For either code, documentation should confirm the removal of the distal articular surface. CPT code 29824 includes a diagnostic shoulder arthroscopy, but other concomitant procedures (e.g., rotator cuff repair or extensive debridement) can be billed for separately. A limited debridement is separately billable as per CPT (maintained by the American Medical Association) but not as per the NCCI.

Case 3: clavicle fractures

A 16-year-old football player presents with a clavicle fracture after a direct blow to the shoulder during a game.

How is conservative management for a clavicle fracture coded for?

There are two options for coding conservative management. All components of care can be billed for at the patient’s first office visit using either CPT code 23500 (Closed treatment of clavicular fracture; without manipulation) or less commonly CPT code 23505 (Closed treatment of clavicular fracture; with manipulation). Subsequent office visits for conservative management of this clavicle fracture are not billable for 90 days thereafter. Alternatively, each office visit can be billed for using the appropriately leveled Evaluation and Management (E/M) code as discussed in a previous Coding Corner article on general fracture management [2]. What code is used for operative fixation of a clavicle fracture?

CPT code 23515 (open treatment of clavicular fracture, includes internal fixation, when performed) is used for operative fixation of all clavicle fractures, regardless of the fracture location (distal, midshaft, or medial) or fixation method (plate or intramedullary nail). This includes surgical fixation of medial clavicle physeal separations.

Does CPT code 23515 apply to nonunions and malunions?

CPT code 23515 applies to open reduction and internal fixation of acute clavicle fracture as well as non-unions. If an osteotomy is required for clavicle malunions, CPT code 23480 (Osteotomy, clavicle, with or without internal fixation) is used instead of CPT code 23515.

If a coracoclavicular ligament repair or reconstruction is used to augment the fixation of a distal clavicle fracture, how is this coded for?

Whether used to address an isolated acromioclavicular joint dislocation or to augment a distal clavicle fracture fixation, CPT code 23550 (Open treatment of acromioclavicular dislocation, acute or chronic) is used. If an autograft or allograft are used for a coracoclavicular (CC) ligament reconstruction, CPT code 23552 (Open treatment of acromioclavicular dislocation, acute or chronic; with fascial graft (includes obtaining graft) is used instead of CPT code 23550. If a bioinductive implant is used, a −22 modifier is added to the repair or reconstruction code.

Open distal clavicle excisions are sometimes done concomitantly with CC ligament reconstructions in the setting of acromioclavicular joint dislocations without fracture. In this case, both CPT codes 23120 and 23550 (or 23552) are used.

Case 4: SC dislocations

A 12-year-old man motocross competitor presents after a high-energy fall off his all-terrain vehicle with a posterior SC dislocation.

What is the correct CPT code for closed treatment of the SC joint dislocation?

Observation alone uses CPT code 23520 (Closed treatment of sternoclavicular dislocation; without manipulation). This code includes all elements of care for the SC dislocation for up to 90 days. Alternatively, each patient encounter can be billed for using the appropriately leveled E/M code, as described for clavicle fractures earlier.

If the SC dislocation is closed reduced in the emergency department or in the operating room, CPT code 23535 (Closed treatment of sternoclavicular dislocation; without manipulation) is used. If this was performed by an orthopaedic provider in your practice, a 90 day global period applies. If it was performed by emergency department providers, you should bill (E/M) codes for subsequent outpatient visits.

What is the correct CPT code if an open reduction of the SC dislocation is required?

CPT code 23530 (Open treatment of sternoclavicular dislocation, acute or chronic) is used for an open reduction of the SC joint, with or without fixation. If the fixation or an additional SC ligament reconstruction involves a graft (allograft or autograft, including graft harvest), CPT code 23532 (Open treatment of sternoclavicular dislocation, acute or chronic; with fascial graft) is used instead.

Summary

Specific and accurate documentation is required for proper coding of sports medicine procedures around the glenohumeral, acromioclavicular, and SC joints. It is important to include the exact pathology addressed (particularly in the setting of debridement) and the treatment techniques used (e.g., suture fixation versus graft). Careful attention should be paid to bundled procedures, particularly regarding arthroscopic debridement. Table 1 provides a summary of the codes used for the aforementioned cases and may serve as a guide for accurate CPT coding in these scenarios.
