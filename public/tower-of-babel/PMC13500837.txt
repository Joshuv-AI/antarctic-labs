An IBGWO optimized feature selection framework for sentiment analysis-based fraudulent website detection using MLRNN
Authors: Saraswathi Perumal, Anchitaalagammai Jayalakshmi Vishwanathan
Published: 2026

ABSTRACT
Detecting fraudulent websites is critical to ensuring network security and protecting users from online threats. Advanced machine learning algorithms are introduced to analyse patterns, anomalies, and behaviours associated with malicious online activity, which helps detect fraudulent websites. This method only detects scam sites, and there is no practical way to detect new scam websites quickly. The previous methods were not better at handling large amounts of data and could not show accurate results. In addition, fraudulent website detection poses significant threats to online security, and often struggle with high-dimensional feature spaces, feature redundancy and limited generalization to unseen attacks. To resolve these issues, this paper presents a new method for detecting fraudulent websites based on Improved Binary Grey Wolf Optimization feature subset selection based on the Multi-Layer Recognition Neural Network (MLRNN) to enhance quality features and improve overall accuracy. First, fraudulent website detection was collected from the Kaggle repository. After preprocessing, the second step is selecting the features using Attributes-based Recursive Feature Elimination (A-RFE) to select relevant features to improve model performance and minimize overfitting. Next, Subset Feature Selection involves selecting a suitable subset of features from the original dataset and a fitness function that evaluates the quality of the chosen subset using Improved Binary Grey Wolf Optimization (IBGWO). After feature selection, the data is validated using K-10-fold cross-validation, which involves repeating the training and testing procedure 10 times across different data distributions. K-10-fold cross-validation offers a sufficient approximation of the model performance. Multi-Layer Recognition Neural Network (MLRNN) is used for the sentiment analysis process due to its ability to recognize complicated data links and patterns. This model can effectively understand users’ emotion-related features to detect fraud websites efficiently. The proposed model evaluated on the web page phising detection dataset contains 11,430 URLs with 89 features. Based on the confusion matrix, the simulation results can be used to analyse precision, recall, accuracy, error rate, f-measure, and time complexity, showing higher accuracy than previous methods.

Introduction

Machine Learning is used to analyze patterns, anomalies, and behaviors associated with malicious online activity; machine learning plays a key role in detecting fraudulent websites. Supervised learning allows a model to be trained on labeled datasets that include examples of legitimate and fraudulent websites. These models learn to select subtle features and characteristics which differentiate fraudulent websites from genuine ones. Using machine learning for malicious website detection not only improves efficiency in detecting potential threats. Sentiment analysis and fraudulent website detection are independent applications of machine learning, and each serves different purposes. Sentiment analysis concentrates on determining the sentiment expressed in written content, such as Positive, Negative, or Neutral comments. On the other hand, scam website detection involves detecting and preventing malicious or deceptive activity on a website. Although these tasks may seem unrelated, sometimes sentiment analysis can provide additional context and functionality that can improve fraudulent website detection efforts.

Integrating social media-based methods and sentiment analysis to detect fraudulent websites requires leveraging user-generated content and comments across different platforms. Here is a general approach to integrating sentiment analysis to detect scam websites on social media: Data Collection is to collect data from social media platforms, including posts, comments and discussions related to website or online activity. This data may be obtained through APIs, web scraping, or other data collection methods. Preprocessing is to clean and preprocess the text data which helps to remove noise, irrelevant details or any elements that might interfere with the analysis. Perform tasks such as tagging text, stopping word removal, and stemming. Sentiment analysis techniques are applied to evaluate the sentiment expressed in social media content. Common emotion categories include positive, negative, neutral. Tools like NLP libraries or pre-trained sentiment analysis models can be used for this task.

User feedback analysis is pay attention to user feedback and comments regarding a particular website. Any negative sentiment or warnings expressed by users may indicate fraudulent activity. Combine the results of sentiment analysis with other features and concepts to build detailed ML models. Supervised ML models are trained for predicting likelihood of Internet fraud based on a combination of emotional characteristics and other relevant factors. Implement systems that continuously monitor social media channels for changes in sentiment and emerging patterns related to potential fraud. Frequently update your model with new data. By integrating sentiment analysis into fraud detection models, particularly with a focus on public network data, companies can discriminate into user opinions and concerns about specific websites. This approach increases the ability to identify and mitigate potential threats in a timely manner.

Even though ML and DL methods have shown to be very useful in identifying fraudulent websites, there are various weaknesses that exist in the existing studies. The majority of the methods are based on fixed sets of features and traditional ways of feature selection that cannot be applied to high-dimensional data and quickly changing fraudulent trends. Moreover, most of the current models dwell more on structural and lexical points of the websites, as opposed to sentiment-based behavioural signals of the web sites, which are widely used by fraudulent websites to control the users. The feature selection methods that are reported in the literature based on optimisation are also characterised by premature convergence and high-level computational complexity that constrain their scalability and their application to real-life scenarios. Driven by these loopholes, this paper seeks to come up with an emotion-sensitive, optimisation-based system of detection that boosts the quality of features, improves the classification rate, and makes it resistant to the emergence of frauds sites.

Despite significant progress in detecting fraudulent websites, some key challenges remain. Fraudulent websites often modify their content and presentation to evade existing detection mechanisms, thus limiting the effectiveness of traditional models. Furthermore, current methods typically rely on high-dimensional, redundant feature sets, which increase computational complexity and reduce classification performance. Furthermore, emotionally driven persuasive strategies, widely used on fraudulent websites, cannot be adequately captured by traditional feature-extraction methods. These challenges require an improved detection framework that combines sentiment analysis with improved feature selection to improve accuracy and robustness.

Dataset description

This research uses the Web Page Phishing Detection dataset is gathered from Kaggle repository. The available link is https://www.kaggle.com/datasets/shashwatwork/web-page-phishing-detection-dataset. This dataset file size is 3.66MB. The supplied dataset contains 11,430 URLs, from which 87 features were extracted. Features were extracted into three categories: 56 from the URL’s structure and syntax, 24 from the page’s content, and seven from external services. This dataset is balanced, consisting of 50% phishing URLs and 50% legitimate URLs.

Despite its suitability as a benchmark, the Web Page Phishing Detection dataset presents several challenges. The dataset contains a high-dimensional feature space with 87 heterogeneous attributes derived from URL structure, webpage content, and external services, which increases redundancy and computational complexity. Features obtained from external services may introduce latency and dependency issues in real-time applications. Additionally, although the dataset is balanced, real-world phishing scenarios are often highly imbalanced, which may affect model generalization. These challenges motivate the need for effective feature selection and optimization techniques, as addressed in the proposed IBGWO-based framework.

Feature selection using attributes-based recursive feature elimination (A-RFE)

Attribute-based feature selection focuses on evaluating the importance of individual attributes that are associated with fraud websites. Use A-RFE such as correlation analysis, mutual information, and statistical tests to measure relationship between each characteristic and resultant variable. Improved binary grey wolf optimization feature subset selection

Improved Binary Grey Wolf Optimisation (IBGWO) is utilised in feature selection to determine the feature subset that maximises classification accuracy while minimising the number of selected features. As a binary string, represent a subset of each conceivable characteristic. Each bit determines whether the feature is included (1) or excluded (0).

Set Population:

Initialize the number of binary strings representing the different feature subsets.

Start: Start position of binary string (wolf) in search space.

Match Evaluation: Evaluate the match of each binary string using a defined match function.

Rank: Rank binary strings based on matching.

Upgrade Alpha, Beta, and Delta: Alpha, Beta, and Delta upgrades wolves’ status based on their health.

Search for new solutions: adjust the wolf state to create new candidate solutions.

Boundary Handling: Ensuring that binary strings fall within a defined search space.

After convergence or a specified number of iterations, a binary string (feature subset) corresponding to the alpha wolf is extracted, representing the best solution found.Machine learning model can be trained by using features subsetchosen from the training dataset.

K-10 fold cross validation

To assess machine learning models on limited data samples, resampling is done by using cross validation technique. By using K-10-fold cross validation, the original dataset can be divided into K-folds (or subsets) of equal size and this K technique is helpful to train the model. Every time, practice is done on the K–10 fold, and testing and verification are done on the remaining folds. There are K iterations of this method, with each K–10 fold serving as validation data just once.

One can then create a single estimate of the model performance by averaging the K-fold results. Use the entire data set for training and validation to maximize data usage.Averaging the results across multiple folds can provide a more reliable estimate of model performance.Helps to identify potential issues with over-fitting or under-fitting.

Discussion

Experimental results show that the proposed IBGWO-based MLRNN framework consistently outperforms traditional machine learning and deep learning approaches in detecting fraudulent websites. The performance improvement is mainly due to an effective feature optimization strategy that reduces redundancy in the high-dimensional feature space and enhances the discriminatory ability of the classifier. By integrating A-RFE and IBGWO optimization, the model selects the optimal subset of emotion recognition and structural features, achieving superior classification performance.

Accuracy analysis results show that the proposed method achieves 94.3% accuracy, outperforming CNN, SVM, and ReMEMBeR models. This improvement indicates that the optimized feature subset allows MLRNN to capture better more complex patterns associated with fraudulent behavior. Similarly, the 96% sensitivity highlights the model’s impressive ability to correctly identify phishing websites, which is crucial for minimizing security risks in real-world applications. High sensitivity means fewer fraudulent websites escape detection, providing better protection for users.

Specificity analysis further confirmed the robustness of the proposed approach, achieving 93.8% specificity, significantly higher than that of existing methods. The results show that the proposed framework effectively reduces false alarms by correctly classifying legitimate websites. Furthermore, the low misclassification rate of 1.7% demonstrates the proposed system’s ability to distinguish between legitimate and phishing websites, thereby improving its reliability and usability.

The time-complexity evaluation shows that the proposed MLRNN framework requires less computational time than the CNN and ReMEMBeR methods. This time complexity reduction is mainly due to the optimized feature subset, which reduces the dimensionality of the input data and accelerates the training and inference processes. Therefore, the proposed method is suitable for practical deployment where timely detection is essential. The comparative analysis shown in Table 4 further validates the effectiveness of the proposed approach against state-of-the-art techniques such as GAN, CS-OCAN, BiLSTM, and FSTL-SA based models. Although existing approaches have shown reasonable performance, they suffer from limitations such as training instability, low generalization, high computational cost, and lack of web content orientation. In contrast, the proposed IBGWO-MLRNN framework achieves the best overall performance by balancing accuracy, sensitivity, specificity, and computational efficiency.

Despite its good performance, the proposed approach has certain limitations. First, some functionality is derived from external services, which can introduce dependency and latency issues into a real-time phishing detection system. Second, while the evaluation is performed on a balanced benchmark dataset, real-world phishing scenarios are often highly imbalanced, which may affect generalization performance. Furthermore, although the MLRNN model has reduced time complexity compared to other deep learning methods, further optimization may be required for deployment in large-scale real-time environments.

Conclusion

To conclude, Multi-Layer Recognition Neural Networks (MLRNNs) have shown to be a sophisticated and successful technique in the realm of network security for identifying phony websites. Because of their remarkable capacity to recognize intricate patterns and abnormalities in datasets, MLRNNs—which are composed of linked layers of neurons—are ideally adapted to the intricate and dynamic nature of online fraud activity. In order to identify fake websites, MLNN design meticulously incorporates variables like Uniform Resource Locator structure, Domain Age, IP address reputation, Secure Socket Layer certificate data, and the content characteristics. Input layers for pertinent features, hidden layers for nonlinear transformations, and output layers for binary classification (fraudulent or legal) are the typical components of neural network topologies. MLRNN gains the ability to recognize patterns that can point to fraudulent activity through an iterative training procedure that makes use of optimization strategies. MLRNN and IBGWO to combine the best features of reduced complexity and implementation requirements make them difficult to scale. Machine learning models, especially neural networks, hold the promise of detecting fraud by extracting complex patterns from large volumes of data. Effective training requires large volumes of labeled data and processing. The proposed approach effectively addresses key challenges in fraudulent website detection by leveraging sentiment-aware analysis and Improved Binary Grey Wolf Optimization for robust feature selection.Although the proposed IBGWO–MLRNN framework demonstrates improved performance in fraudulent website detection, several enhancements can be explored in future work. The model can be extended to support real-time detection by incorporating online learning mechanisms. Additionally, integrating transformer-based language models may further improve sentiment representation from complex web content. Based on the experimental findings, several avenues for future research can be identified. First, the strong performance gains achieved through optimized feature selection suggest exploring adaptive and dynamic feature optimization strategies for evolving fraudulent patterns. Second, the effectiveness of sentiment-based features indicates potential benefits from integrating advanced language models, such as transformer-based architectures, to capture deeper contextual semantics. Third, future work may focus on extending the proposed framework to real-time and large-scale environments using online learning mechanisms. Finally, evaluating the model on multilingual and cross-domain datasets could further enhance its robustness and generalization capability. Future studies may also investigate adaptive optimisation strategies to handle evolving phishing patterns and evaluate the framework on larger, multilingual, and cross-domain datasets to enhance generalization.
