Property Prediction (Eq 1)
• f(G) = Σ_g f_g
• Breaks molecule into graphlets - small substructures
• Each graphlet gets a learned weight (coefficient f_g)
• Sums all contributions to predict the property
• Model predicts binding energy

Distance-Based Partition
• Code Location:
• ChemicalPartitioner.distance_partition(mol, n_clusters=3, seed=42)
• Algorithm:
• INPUT: Molecule, k partitions
• 1. Select k "seed" atoms randomly
• 2. Compute graph distance matrix (shortest path between all atom pairs)
• 3. FOR each atom i:
• Find nearest seed atom s
• partition[i] = s
• OUTPUT: Partition where each atom assigned to nearest seed
• Select Seeds: Randomly pick n_clusters atoms as "centers"
• Compute Distances: Use RDKit's distance matrix
• dist_matrix[i][j] = shortest bond path length between atoms i and j
• Example: Atom 3 → Atom 7 might be 4 bonds apart

Conclusion
• Partition-based decomposition provides interpretable regional
  explanations for graphlet-based molecular models.
• Greedy optimization improves partition quality compared with random
  and distance methods.
• Metropolis-Hastings based partitioning yields the best scores.
• The implementation reproduces model predictions while
  exposing within- and between-partition graphlet contributions.
• Next steps include:
 • testing the partitioning scheme on multiple properties and datasets
 • Fine tuning partitioning parameters
 • Adjusting the score calculation
