Double Toeplitz codes and their average weight enumerators
Masaaki Harada, Keito Yamaguchi

Abstract
Recently, double Toeplitz codes have been introduced as a generalization of double circulant codes. In this paper, we study the average weight enumerators of double Toeplitz codes. As an application, we consider the existence of double Toeplitz codes over 𝔽 q \mathbb{F}_{q} with some specified minimum weights for q ∈ { 2 , 3 , 4 } q\in\{2,3,4\} . We also give a classification of double Toeplitz codes over 𝔽 q \mathbb{F}_{q} with the largest minimum weights for modest lengths and q ∈ { 2 , 3 , 4 } q\in\{2,3,4\} .

A code

,

, respectively,
where

is the dual code of

Self-dual codes have been studied extensively for many decades
(see e.g.,
[

]
and
[

]
).
Isodual codes and formally self-dual codes have also received considerable interest

]

]

]

]

and the references given therein).
Double circulant codes are a remarkable class of isodual codes.

Recently, double Toeplitz codes have been introduced as
generalizations of double circulant codes in order to construct isodual

.

Weight enumerators of several types have been widely studied (see e.g.,
[

).
Let
\Omega_{q,n}
be the set of all distinct double Toeplitz
[n,n/2]
codes over
\mathbb{F}_{q}
.
The

of double Toeplitz
[n,n/2]
codes over
\mathbb{F}_{q}

is defined as follows:

\Psi_{q,n}(y)=\sum_{C\in\Omega_{q,n}}W_{C}(y),

.
The average weight enumerators of self-dual codes are used to establish the existence of

In this paper, we study the average weight enumerators of double Toeplitz codes,

We say that a double Toeplitz
[n,n/2,d_{q,DT}(n)]

\mathbb{F}_{q}

DT-optimal

It is also a fundamental problem

\mathbb{F}_{q}

In this paper, we give a classification of DT-optimal double Toeplitz codes over

.

2
Preliminaries

In this section, we give definitions, notations and basic results
used throughout this paper.

2.1
Codes and formally self-dual codes

Let
\mathbb{F}_{q}
denote the finite field of order
q
,
where
q
is a prime power.
An
[n,k]

code
C
over
\mathbb{F}_{q}

is a
k
-dimensional vector subspace of
\mathbb{F}_{q}^{n}
.
Codes over
\mathbb{F}_{2}
,
\mathbb{F}_{3}
and
\mathbb{F}_{4}

are called
binary
,
ternary
and
quaternary
,
respectively.
The parameter
n
is called the
length
of
C
.
A
generator matrix
of an
[n,k]
code
C
is a
k\times n

matrix such that the rows of the matrix generate
C
.
Two
[n,k]
codes
C
and
C^{\prime}
over
\mathbb{F}_{q}
are

equivalent
, denoted
C\cong C^{\prime}
,
if there is an
n\times n
monomial matrix
P
over
\mathbb{F}_{q}
with

C^{\prime}=CP
, where
CP=\{xP\mid x\in C\}
.

The
weight

\wt(x)
of a vector
x\in\mathbb{F}_{q}^{n}
is
the number of nonzero components of
x
.
A vector of a code
C
is called a
codeword
of
C
.
The minimum nonzero weight of all codewords in
C
is called
the
minimum weight
of
C
. An
[n,k,d]
code
is an
[n,k]
code with minimum weight
d
.
The
weight enumerator
of
C

is given by the polynomial
W_{C}(y)=\sum_{c\in C}y^{\wt(c)}
.

The
dual code

C^{\perp}
of an
[n,k]
code
C
over
\mathbb{F}_{q}

is defined as follows:

\displaystyle C^{\perp}

\displaystyle=\{x\in\mathbb{F}_{q}^{n}\mid x\cdot y=0\text{ for all }y\in C\},

where

x\cdot y=\sum_{i=1}^{n}x_{i}{y_{i}}

for
x=(x_{1},x_{2},\ldots,x_{n})
and
y=(y_{1},y_{2},\ldots,y_{n})\in\mathbb{F}_{q}^{n}
.
A generator matrix of the dual code
C^{\perp}
of a code
C
is called
a
parity-check matrix
of
C
.
A code
C
is called
self-dual
,
isodual
and

formally self-dual

if
C=C^{\perp}
,
C\cong C^{\perp}
and

W_{C}(y)=W_{C^{\perp}}(y)
, respectively.
Of course, self-dual codes are automatically isodual,
and isodual codes are automatically formally self-dual.

2.2
Double Toeplitz codes

Throughout this paper, let
I_{n}
denote the identity matrix of order
n
.
An
n\times n
matrix of the following form:

\left(\begin{array}[]{cccccc}r_{0}&r_{1}&r_{2}&\cdots&r_{n-2}&r_{n-1}\\
\mu r_{n-1}&r_{0}&r_{1}&\cdots&r_{n-3}&r_{n-2}\\
\mu r_{n-2}&\mu r_{n-1}&r_{0}&\cdots&r_{n-4}&r_{n-3}\\
\vdots&\vdots&\vdots&&\vdots&\vdots\\
\vdots&\vdots&\vdots&&\vdots&\vdots\\
\mu r_{1}&\mu r_{2}&\mu r_{3}&\cdots&\mu r_{n-1}&r_{0}\end{array}\right)

is called
circulant
if
\mu=1
and

negacirculant
if
\mu=-1
.
Codes with generator matrices of the following form:

\left(\begin{array}[]{ccccc}&I_{n}&&A&\\
\end{array}\right)

are called (pure)
double circulant
and
double negacirculant

if the matrices
A
are circulant and negacirculant, respectively.
We denote the codes by

\mathcal{DC}(r)\text{ and }\mathcal{DN}(r)
,
respectively, where
r
denotes the first row of
A
.

An
n\times n
matrix of the following form:

\left(\begin{array}[]{cccccc}t&a_{1}&a_{2}&\cdots&a_{n-2}&a_{n-1}\\
b_{1}&t&a_{1}&\cdots&a_{n-3}&a_{n-2}\\
b_{2}&b_{1}&t&\cdots&a_{n-4}&a_{n-3}\\
\vdots&\vdots&\vdots&&\vdots&\vdots\\
\vdots&\vdots&\vdots&&\vdots&\vdots\\
b_{n-1}&b_{n-2}&b_{n-3}&\cdots&b_{1}&t\end{array}\right)

is called
Toeplitz
.
We denote the above matrix by
T(t,a,b)
,
where
a=(a_{1},a_{2},\ldots,a_{n-1})
and
b=(b_{1},b_{2},\ldots,b_{n-1})
.
Of course,
T(t,a,b)

is circulant and negacirculant if

a_{i}=b_{n-i}\text{ and }a_{i}=-b_{n-i}\ (i=1,2,\ldots,n-1),

respectively.
A code with generator matrix of the following form:

\left(\begin{array}[]{ccccc}&I_{n}&&T(t,a,b)&\\
\end{array}\right)

is called
double Toeplitz
.
We denote the code by

\mathcal{DT}(t,a,b)
.

Let
d_{q,DT}(n)
denote the largest minimum weight among
all double Toeplitz
[n,n/2]
codes over
\mathbb{F}_{q}
.
We say that a double Toeplitz
[n,n/2,d_{q,DT}(n)]
code over
\mathbb{F}_{q}
is

DT-optimal
.
The values
d_{q,DT}(n)
were determined in
[
20
]
for

n\leq 40,30,14,24,24
and
q=2,3,4,5,7
, respectively.

The following characterizations on double Toeplitz codes
are known.

Proposition 2.1

(Shi, Xu and Solé
[
20
]
)
.

(i)

A double Toeplitz code over
\mathbb{F}_{q}
is isodual.

(ii)

A double Toeplitz self-dual code over
\mathbb{F}_{q}
is double circulant
or double negacirculant.

(iii)

A binary double Toeplitz code with only even weights is double circulant.

Further background on double Toeplitz codes and their generalizations can be found
in
[
3
]
,
[
14
]
,
[
15
]
,
[
16
]
,
[
19
]
and
[
21
]
.

3
Average weight enumerators of double Toeplitz codes

Throughout this paper,
let
\Omega_{q,n}
denote the set of all distinct double Toeplitz
[n,n/2]
codes over
\mathbb{F}_{q}
.
The
average weight enumerator
of double Toeplitz
[n,n/2]
codes over
\mathbb{F}_{q}

is defined as follows:

\Psi_{q,n}(y)=\sum_{C\in\Omega_{q,n}}W_{C}(y).

In this section, we theoretically give explicit expressions of the average weight
enumerators
\Psi_{q,n}(y)

without finding
\Omega_{q,n}
.

Let
A^{T}
denote the transpose of a matrix
A
.
Let
\mathbf{0}_{n}
denote the zero vector of length
n
.
For vectors
u
and
v
of
\mathbb{F}_{q}^{n/2}
,
let
\Omega_{q,n}^{(u,v)}
denote the set of all distinct double Toeplitz
[n,n/2]
codes
over
\mathbb{F}_{q}
containing the vector
(u,v)
.

The following important work in
[
20
]
was the major inspiration for this paper.

Theorem 3.1

(
[
20
, Proposition 5, Theorem 6]
)
.

(i)

|\Omega_{q,n}|=q^{n-1}
.

(ii)

Let
u
and
v
be vectors of
\mathbb{F}_{q}^{n/2}
.
If
\wt(u)\neq 0
, then
|\Omega_{q,n}^{(u,v)}|\leq q^{n/2}
.

By following the same line as in the proof of
[
20
, Theorem 6]
,
we have the following improvement.
We give a proof for the sake of completeness.

Lemma 3.2
.

Let
u
and
v
be vectors of
\mathbb{F}_{q}^{n/2}
. Then

|\Omega_{q,n}^{(u,v)}|=\begin{cases}q^{n-1}&\text{ if }\wt(u)=0\text{ and }\wt(v)=0,\\
0&\text{ if }\wt(u)=0\text{ and }\wt(v)\neq 0,\\
q^{n/2-1}&\text{ if }\wt(u)\neq 0.\end{cases}

(1)

Proof.

Let us consider a
double Toeplitz
[n,n/2]
code
\mathcal{DT}(t,a,b)
over
\mathbb{F}_{q}
.
Note that
\mathcal{DT}(t,a,b)
has generator matrix

\left(\begin{array}[]{cc}I_{n/2}&A\\
\end{array}\right)
, where

\displaystyle A

\displaystyle=\left(\begin{array}[]{cccccc}t&a_{1}&a_{2}&\cdots&a_{n/2-2}&a_{n/2-1}\\
b_{1}&t&a_{1}&\cdots&a_{n/2-3}&a_{n/2-2}\\
b_{2}&b_{1}&t&\cdots&a_{n/2-4}&a_{n/2-3}\\
\vdots&\vdots&\vdots&&\vdots&\vdots\\
\vdots&\vdots&\vdots&&\vdots&\vdots\\
b_{n/2-1}&b_{n/2-2}&b_{n/2-3}&\cdots&b_{1}&t\end{array}\right),

\displaystyle a

\displaystyle=(a_{1},a_{2},\ldots,a_{n/2-1})\text{ and }b=(b_{1},b_{2},\ldots,b_{n/2-1}).

Determining the number
|\Omega_{q,n}^{(u,v)}|

is equivalent to counting the triples
(t,a,b)

such that double Toeplitz
[n,n/2]
codes
\mathcal{DT}(t,a,b)
contain the vector
(u,v)
.

Since

\left(\begin{array}[]{cc}-A^{T}&I_{n/2}\\
\end{array}\right)

is a parity-check matrix of
\mathcal{DT}(t,a,b)
, we have that

(u,v)\in\mathcal{DT}(t,a,b)\iff A^{T}u^{T}=v^{T}.

(2)

Let
Q
be the
n/2\times n/2
matrix defined as follows:

Q=\begin{pmatrix}0&0&\cdots&0&0&0&1&\\
0&0&\cdots&0&0&1&0&\\
0&0&\cdots&0&1&0&0&\\
\vdots&\vdots&&\vdots&\vdots&\vdots&\vdots\\
\vdots&\vdots&&\vdots&\vdots&\vdots&\vdots\\
1&0&\cdots&0&0&0&0&\\
\end{pmatrix}.

Since
QA^{T}=AQ
, we have that

A^{T}u^{T}=v^{T}\iff QA^{T}u^{T}=Qv^{T}\iff AQu^{T}=Qv^{T}.

(3)

Let
u^{\prime T}
and
v^{\prime T}
be defined as follows:

\displaystyle u^{\prime T}

\displaystyle=Qu^{T}=(u_{n/2},u_{n/2-1},\dots,u_{1})^{T}\text{ and }

\displaystyle v^{\prime T}

\displaystyle=Qv^{T}=(v_{n/2},v_{n/2-1},\dots,v_{1})^{T}.

From (
2
) and (
3
), we have that

(u,v)\in\mathcal{DT}(t,a,b)\iff AQu^{T}=Qv^{T}\iff Au^{\prime T}=v^{\prime T}.

(4)

Let
D
be the
n/2\times(n-1)
matrix defined as follows:

D=\begin{pmatrix}0&\cdots&\cdots&\cdots&0&u_{n/2}&u_{n/2-1}&\cdots&u_{1}\\
0&\cdots&\cdots&0&u_{n/2}&u_{n/2-1}&\cdots&u_{1}&0\\
0&\cdots&0&u_{n/2}&u_{n/2-1}&\cdots&u_{1}&0&0\\
\vdots&&&&&&&\vdots&\vdots\\
\vdots&&&&&&&\vdots&\vdots\\
u_{n/2}&u_{n/2-1}&\cdots&\cdots&u_{1}&0&\cdots&0&0\\
\end{pmatrix}.

Let
c
be defined as follows:

c=(b_{n/2-1},b_{n/2-2},\ldots,b_{1},t,a_{1},a_{2},\ldots,a_{n/2-1}).

From
Au^{\prime T}=v^{\prime T}
,
we obtain the following system of
n/2
equations:

Dc^{T}=v^{\prime T}.

(5)

From (
4
),

|\Omega_{q,n}^{(u,v)}|
is the number of solutions of (
5
).
If
\wt(u)\neq 0
, then
\rank(D)=n/2
.
Thus, the number of solutions is
q^{n/2-1}
.
If
\wt(u)=0
, then the number of solutions is
q^{n-1}
when
\wt(v)=0

and (
5
) has no solution when
\wt(v)\neq 0
.
This completes the proof.
∎

The above lemma provides a key idea for the following theorem,
which constitutes one of the main results of this paper.

Theorem 3.3
.

Let
\Psi_{q,n}(y)
denote the average weight enumerator of all distinct
double Toeplitz
[n,n/2]
codes over
\mathbb{F}_{q}
.
Then

\Psi_{q,n}(y)=q^{n-1}+q^{\frac{n}{2}-1}\left(\sum_{j=1}^{\frac{n}{2}}\left(\binom{n}{j}-\binom{\frac{n}{2}}{j}\right)(q-1)^{j}y^{j}\right.\\
\left.+\sum_{j=\frac{n}{2}+1}^{n}\binom{n}{j}(q-1)^{j}y^{j}\right).

Proof.

Let
u
and
v
be vectors of
\mathbb{F}_{q}^{n/2}
.
Let
V(j)
be defined as follows:

V(j)=\{x\in\mathbb{F}_{q}^{n}\mid\wt(x)=j\}

and let
S_{i}(j)

(i=1,2,3)
be defined as follows:

\displaystyle S_{1}(j)

\displaystyle=\{(u,v)\in V(j)\mid\wt(u)=0\text{ and }\wt(v)\neq 0\},

\displaystyle S_{2}(j)

\displaystyle=\{(u,v)\in V(j)\mid\wt(u)\neq 0\text{ and }\wt(v)=0\}\text{ and }

\displaystyle S_{3}(j)

\displaystyle=\{(u,v)\in V(j)\mid\wt(u)\neq 0\text{ and }\wt(v)\neq 0\}.

Then we have that

V(j)=S_{1}(j)\sqcup S_{2}(j)\sqcup S_{3}(j)

(6)

for
j\geq 1
.
If
1\leq j\leq n/2
, then we have that

|S_{i}(j)|=\begin{cases}\binom{\frac{n}{2}}{j}(q-1)^{j}&\text{ if }i=1,\\
\binom{\frac{n}{2}}{j}(q-1)^{j}&\text{ if }i=2,\\
\left(\binom{n}{j}-2\binom{\frac{n}{2}}{j}\right)(q-1)^{j}&\text{ if }i=3.\end{cases}

(7)

If
n/2+1\leq j\leq n
, then we have that

|S_{i}(j)|=\begin{cases}0&\text{ if }i=1,\\
0&\text{ if }i=2,\\
\binom{n}{j}(q-1)^{j}&\text{ if }i=3.\end{cases}

(8)

Note that
|\Omega_{q,n}|=q^{n-1}
(Theorem
3.1
(i)).
Hence, we have that

\displaystyle\Psi_{q,n}(y)=\;

\displaystyle\sum_{j=0}^{n}\left(\sum_{C\in\Omega_{q,n}}|\{x\in C\mid\wt(x)=j\}|\right)y^{j}

\displaystyle=\;

\displaystyle\sum_{j=0}^{n}\left(\sum_{\begin{subarray}{c}x\in V(j)\end{subarray}}|\{{C\in\Omega_{q,n}}\mid x\in C\}|\right)y^{j}

\displaystyle=\;

\displaystyle|\{{C\in\Omega_{q,n}}\mid\mathbf{0}_{n}\in C\}|

\displaystyle+\sum_{j=1}^{n}\left(\sum_{x\in S_{1}(j)}|\{{C\in\Omega_{q,n}}\mid x\in C\}|\right.

\displaystyle+\sum_{x\in S_{2}(j)}|\{{C\in\Omega_{q,n}}\mid x\in C\}|

\displaystyle\left.+\sum_{x\in S_{3}(j)}|\{{C\in\Omega_{q,n}}\mid x\in C\}|\right)y^{j}

(by (
6
))

\displaystyle=\;

\displaystyle q^{n-1}+\sum_{j=1}^{n}\left(|S_{1}(j)|\cdot 0+|S_{2}(j)|q^{\frac{n}{2}-1}+|S_{3}(j)|q^{\frac{n}{2}-1}\right)y^{j}

(by (
1
))

\displaystyle=\;

\displaystyle q^{n-1}+\sum_{j=1}^{\frac{n}{2}}\left(\binom{\frac{n}{2}}{j}(q-1)^{j}q^{\frac{n}{2}-1}\right.

\displaystyle\left.+\left(\binom{n}{j}-2\binom{\frac{n}{2}}{j}\right)(q-1)^{j}q^{\frac{n}{2}-1}\right)y^{j}

(by (
7
))

\displaystyle+\sum_{j=\frac{n}{2}+1}^{n}\left(0\cdot q^{\frac{n}{2}-1}+\binom{n}{j}(q-1)^{j}q^{\frac{n}{2}-1}\right)y^{j}

(by (
8
))

\displaystyle=\;

\displaystyle q^{n-1}+q^{\frac{n}{2}-1}\left(\sum_{j=1}^{\frac{n}{2}}\left(\binom{n}{j}-\binom{\frac{n}{2}}{j}\right)(q-1)^{j}y^{j}\right.

\displaystyle\left.+\sum_{j=\frac{n}{2}+1}^{n}\binom{n}{j}(q-1)^{j}y^{j}\right).

This completes the proof.
∎

As described above,
the average weight enumerators of self-dual codes are used to establish the existence of
self-dual codes with specified minimum weights
(see e.g.,
[
4
, Proof of Theorem 4]
).
In the same way, we establish the existence of double Toeplitz codes over
\mathbb{F}_{q}
with
specified minimum weights as an application of Theorem
3.3
.
For this purpose, just as in the case of self-dual codes,
the following proposition is required.
Although the following proposition is somewhat trivial, we give a proof for the sake of completeness.

Proposition 3.4
.

If we write

\Psi_{q,n}(y)=\sum_{i=0}^{n}\psi_{q,n,i}(y)

and we suppose that

\sum_{i=1}^{d-1}\psi_{q,n,i}<|\Omega_{q,n}|(q-1).

Then there is a double Toeplitz
[n,n/2]
code over
\mathbb{F}_{q}
with
minimum weight at least
d
.

Proof.

We may assume without loss of generality that
d=2
.
Suppose that there are
m
distinct double Toeplitz
[n,n/2,1]
codes over
\mathbb{F}_{q}
.
We denote these codes by
C_{1}
,
C_{2},\ldots,C_{m}
.
Let
N_{i,1}
denote the number of codewords of weight
1
in
C_{i}
.
Then we have that
\psi_{q,n,1}=\sum_{i=1}^{m}N_{i,1}
.
It is trivial that
x
is a codeword of weight
1
in
C_{i}
if and only if

\alpha x
is a codeword of weight
1
in
C_{i}
for
\alpha\in\mathbb{F}_{q}\setminus\{0\}
.
This gives that
(q-1)m\leq\sum_{i=1}^{m}N_{i,1}
.

If
\psi_{q,n,1}<|\Omega_{q,n}|(q-1)
, then
we have that

(q-1)m\leq\sum_{i=1}^{m}N_{i,1}=\psi_{q,n,1}<|\Omega_{q,n}|(q-1).

This gives that
m<|\Omega_{q,n}|
.
Then there must be a
double Toeplitz
[n,n/2]
code over
\mathbb{F}_{q}
with
minimum weight at least
2
.
The result follows.
∎

4
Application of average weight enumerators

In this section and the next section, we present numerical results for
double Toeplitz codes over
\mathbb{F}_{2}
,
\mathbb{F}_{3}
and
\mathbb{F}_{4}

obtained by computer calculations.
All computer calculations in these sections
were done using programs in
Magma

[
2
]
.

In this section,
we consider the existence of double Toeplitz codes with specified minimum weights
as an application of Theorem
3.3
.
In particular, we determine the lengths for which there is a double Toeplitz code
over
\mathbb{F}_{2}
and
\mathbb{F}_{3}

with minimum weight at least
d
for
d\leq 10
.
We also determine the lengths for which there is a double Toeplitz code
over
\mathbb{F}_{4}

with minimum weight at least
d
for
d\leq 9
.

Preparations

Throughout this section and the next section,
assume that
q\in\{2,3,4\}

As usual, we take

\mathbb{F}_{2}

\{0,1\}

we present constructions of double circulant codes, double negacirculant codes and double Toeplitz codes,

DT-optimal double Toeplitz codes

In this section, we give a classification of DT-optimal double Toeplitz codes
over
\mathbb{F}_{2}
and
\mathbb{F}_{3}

for lengths up to
40
and
26
, respectively.
We also give a classification of
DT-optimal double Toeplitz codes over
\mathbb{F}_{4}

for lengths up to
20
except
16
,
while determining the values

d_{4,DT}(n)

(n=16,18,\ldots,24)
.
Our classification reveals the existence of
many DT-optimal double Toeplitz codes over
\mathbb{F}_{2}
,
\mathbb{F}_{3}
and
\mathbb{F}_{4}

that are inequivalent
to any of double circulant codes and double negacirculant codes.

5.1
Preparations

Lemma 5.1
.

Suppose that
q\in\{2,3,4\}
.
Let
\mathcal{DT}(t,a,b)
be a double Toeplitz code over
\mathbb{F}_{q}
.
Then

(i)

\mathcal{DT}(t,a,b)\cong\mathcal{DT}(\alpha t,\alpha a,\alpha b)
for
\alpha\in\mathbb{F}_{q}\setminus\{0\}
.

(ii)

\mathcal{DT}(t,a,b)\cong\mathcal{DT}(t,b,a)
.

Proof.

The assertion (i) is trivial.
The assertion (ii) follows from that
\mathcal{DT}(t,a,b)
is isodual (see Proposition
2.1
(i)).
∎

We define a map
g
from
\mathbb{F}_{2}
to
\mathbb{Z}
as follows:

g(0)=0
and
g(1)=1
.
For
a=(a_{1},a_{2},\dots,a_{n})\in\mathbb{F}_{2}^{n}
, we define a map
f
from
\mathbb{F}_{2}^{n}
to
\mathbb{Z}

as follows:
f(a)=\sum_{i=1}^{n}2^{i-1}g(a_{i})
.
Then, for
a,b\in\mathbb{F}_{2}^{n}
,
we define an ordering
a\geq b
based on the natural ordering of
\mathbb{Z}

as
f(a)\geq f(b)
.

Lemma 5.2
.

Let
\mathcal{DT}(t,a,b)
be a binary double Toeplitz code.
Then there is a binary double Toeplitz code
\mathcal{DT}(t^{\prime},a^{\prime},b^{\prime})

satisfying the following conditions:

(C1)

\mathcal{DT}(t,a,b)\cong\mathcal{DT}(t^{\prime},a^{\prime},b^{\prime})
.

(C2)

(t^{\prime},a^{\prime})\geq(t^{\prime},b^{\prime})
.

Proof.

By Lemma
5.1
(ii), we have that

\mathcal{DT}(t,a,b)\cong\mathcal{DT}(t,b,a).

If
(t^{\prime},a^{\prime})<(t^{\prime},b^{\prime})
, then we can take
\mathcal{DT}(t^{\prime},b^{\prime},a^{\prime})
instead of
\mathcal{DT}(t^{\prime},a^{\prime},b^{\prime})
.
This completes the proof.
∎

In a classification of binary (DT-optimal) double Toeplitz codes,
the above lemma significantly reduces the number of candidate codes,
which need be checked for equivalences.
Due to computational speed considerations,
however, we employ the following reduction for the ternary and quaternary cases.

Lemma 5.3
.

Suppose that
q\in\{3,4\}
.
Let
\mathcal{DT}(t,a,b)
be a double Toeplitz code over
\mathbb{F}_{q}
.
Then there is a double Toeplitz code
\mathcal{DT}(t^{\prime},a^{\prime},b^{\prime})
over
\mathbb{F}_{q}

satisfying the following conditions:

(C1)

\mathcal{DT}(t,a,b)\cong\mathcal{DT}(t^{\prime},a^{\prime},b^{\prime})
.

(C3)

The first nonzero component of the vector
(t^{\prime},a^{\prime})
is
1
.

Proof.

By Lemma
5.1
(i), we have that

\mathcal{DT}(t,a,b)\cong\mathcal{DT}(\alpha t,\alpha a,\alpha b)

for
\alpha\in\mathbb{F}_{q}\setminus\{0\}
.
If the first nonzero component of the vector
(t^{\prime},a^{\prime})
is
\alpha
,
then we can take
\mathcal{DT}(\alpha^{-1}t^{\prime},\alpha^{-1}a^{\prime},\alpha^{-1}b^{\prime})
instead of
\mathcal{DT}(t^{\prime},a^{\prime},b^{\prime})
.
This completes the proof.
∎

5.5
Remark

We end this paper with some remark on the classification.
Our classification reveals the existence of
many DT-optimal double Toeplitz
[n,n/2]
codes over
\mathbb{F}_{q}
that are inequivalent
to any of double circulant codes and double negacirculant codes.
There arises a natural question.
Let
d_{q,DC}(n)
(resp.
d_{q,DN}(n)
) denote the largest minimum weight among
all double circulant (resp. negacirculant)
[n,n/2]
codes over
\mathbb{F}_{q}
.
Then
it is worthwhile to determine whether there is a pair
(q,n)
with

d_{q,DT}(n)>d_{q,DC}(n)

or not for
q\in\{2,4\}
.
Also, it is worthwhile to determine whether there is an integer
n
with

d_{3,DT}(n)>\max(d_{3,DC}(n),d_{3,DN}(n))

or not.
Note that
there is no DT-optimal double Toeplitz
[n,n/2]
codes over
\mathbb{F}_{q}
that are inequivalent
to any of the double circulant codes and double negacirculant codes for some pairs
(q,n)
.
