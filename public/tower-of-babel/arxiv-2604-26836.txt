Uncertainty-Aware Predictive Safety Filters for Probabilistic Neural Network Dynamics
Bernd Frauenknecht, Lukas Kesper, Daniel Mayfrank, Henrik Hose, Sebastian Trimpe

Abstract
Predictive safety filters (PSFs) leverage model predictive control to enforce constraint satisfaction during deep reinforcement learning (RL) exploration, yet their reliance on first-principles models or Gaussian processes limits scalability and broader applicability. Meanwhile, model-based RL (MBRL) methods routinely employ probabilistic ensemble (PE) neural networks to capture complex, high-dimensional dynamics from data with minimal prior knowledge. However, existing attempts to integrate PEs into PSFs lack rigorous uncertainty quantification. We introduce the Uncertainty-Aware Predictive Safety Filter (UPSi), a PSF that provides rigorous safety predictions using PE dynamics models by formulating future outcomes as reachable sets. UPSi introduces an explicit certainty constraint that prevents model exploitation and integrates seamlessly into common MBRL frameworks. We evaluate UPSi within Dyna-style MBRL on standard safe RL benchmarks and report substantial improvements in exploration safety over prior neural network PSFs while maintaining performance on par with standard MBRL. UPSi bridges the gap between the scalability and generality of modern MBRL and the safety guarantees of predictive safety filters.

Background

UPSi builds on basics in RL, dynamics modeling, and PSFs that we introduce below.

2.1
Reinforcement Learning

Reinforcement learning (RL) addresses sequential decision-making by having an agent learn through interaction with an environment modeled as a Markov decision process (MDP),
\mathcal{M}=\{\mathcal{S},\mathcal{A},r,p,\mathbb{I},\gamma\}
. At each step
t
, the agent applies action
A_{t}\in\mathcal{A}\subseteq\mathbb{R}^{n_{\mathcal{A}}}
in state
S_{t}\in\mathcal{S}\subseteq\mathbb{R}^{n_{\mathcal{S}}}
, transitions according to
S_{t+1}\sim p(\cdot\mid S_{t},A_{t})
, and receives reward
R_{t+1}=r(S_{t},A_{t},S_{t+1})
.
Starting from
S_{0}\sim\mathbb{I}
, the objective is to find a policy
A_{t}\sim\pi(\cdot|S_{t})
maximizing the expected return discounted by
\gamma
, i.e.,

\max_{\pi}\;\mathbb{E}_{\pi}\!\left[\sum_{t=0}^{\infty}\gamma^{t}R_{t+1}\right].

Where required, we use
S_{t}
,
A_{t}
,
R_{t}
for random variables and
s_{t}
,
a_{t}
,
r_{t}
for their realizations. An episode index
j
is incremented at each environment reset to
\mathbb{I}
, such that
\mathcal{D}^{j}
denotes the replay buffer containing all transitions up to episode
j
.

2.2
Dynamics Modeling

We consider stochastic nonlinear systems with additive heteroscedastic process noise of the form

\displaystyle S_{t+1}=\mu(S_{t},A_{t})+L(S_{t},A_{t})W_{t}\text{ with }W_{t}\in\mathbb{W}\text{ and }\mathbb{E}[W_{t}]=0

(1)

\displaystyle\text{where }\mathbb{W}=\{w\in\mathbb{R}^{n_{\mathcal{S}}}\mid\|w\|_{2}^{2}\leq\epsilon\}\text{ for }\epsilon\geq 0

with nominal dynamics
\mu(S_{t},A_{t})
. The process noise
W_{t}
is bounded within the hyperball
\mathbb{W}
and scaled by a diagonal covariance matrix
\Sigma(S_{t},A_{t})=L(S_{t},A_{t})^{\top}L(S_{t},A_{t})
.

PE models
(
Lakshminarayanan et al. 2017
)
approximate the
dynamics in (
1
) via
E
probabilistic neural networks with parameters

\theta_{e}
, where
e\in\{1,\dots,E\}
. The model state is formulated as

\hat{S}_{t+1}=\mu_{\theta_{e}}(S_{t},A_{t})+L_{\theta_{e}}(S_{t},A_{t})\hat{W}_{t}\text{ with }\hat{W}_{t}\sim\mathcal{N}(0,I),

(2)

which comprises nominal dynamics
\mu_{\theta_{e}}(S_{t},A_{t})
and the diagonal covariance
\Sigma_{\theta_{e}}(S_{t},A_{t})=L_{\theta_{e}}(S_{t},A_{t})^{\top}L_{\theta_{e}}(S_{t},A_{t})
that scales normally distributed process noise
\hat{W}_{t}
.
The PE separates aleatoric uncertainty, representing irreducible process noise, captured by
\Sigma_{\theta_{e}}
, from epistemic uncertainty due to lack of data, estimated via ensemble disagreement. Assuming sufficient model capacity, epistemic uncertainty correlates with predictive accuracy
(
Frauenknecht et al. 2024
)
, enabling the definition of a certain set
\mathbb{C}\subseteq\mathcal{S}\times\mathcal{A}
within which predictions closely capture the environment dynamics (
1
). We denote the certain set of a PE model trained on data
\mathcal{D}^{j}
as
\mathbb{C}^{j}
.

2.3
Predictive Safety Filtering and Model Predictive Control

PSFs are closely related to MPC
(
Rawlings et al. 2024
)
, where a constrained optimal control problem is solved by planning with a dynamics model over a finite horizon
N
in a receding fashion. At each time step
t
, MPC computes a control sequence
\mathcal{U}_{t}=[u_{0|t},\dots,u_{N-1|t}]
and corresponding predicted state sequence
\mathcal{Z}_{t}=[s_{0|t},\dots,s_{N|t}]
by solving

\mathcal{U}^{*}_{t}=\arg\min_{\mathcal{U}_{t}}J(\mathcal{U}_{t},\mathcal{Z}_{t})\quad\text{s.t.}\quad s_{n|t}\in\mathbb{S},\ u_{n|t}\in\mathbb{A},\ s_{N|t}\in\mathbb{T},

(3)

where
s_{n|t}
denotes the predicted state
n
steps ahead from time
t
,
\mathbb{S}\subseteq\mathcal{S}
and
\mathbb{A}\subseteq\mathcal{A}
are the state and input constraint sets, and
\mathbb{T}\subseteq\mathbb{S}
is a terminal set within which the system can be stabilized indefinitely, providing infinite-horizon stability guarantees from finite-horizon predictions. PSFs are a special case of MPC where the objective is solely the distance to the RL action, such that
J(\mathcal{U}_{t},\mathcal{Z}_{t})=\|a_{t}-u_{0|t}\|_{2}
and
u_{0|t}
only deviates from
a_{t}
if necessary to satisfy the constraints in (
3
). The first PSF input
a^{\mathrm{F}}_{t}=u^{*}_{0|t}
is applied as a filtered action, and problem (
3
) is re-solved upon observing
s_{t+1}
.

Robust MPC addresses systems such as (
1
), where the bounded process noise introduces ambiguity. Thus, a control sequence yields a sequence of robustly reachable sets (RRS) as per Definition
1
.

Definition 1

(Robust Reachable Set)
.

Let
\mathcal{R}_{n|t}(s_{t},u_{0|t},\dots,u_{n-1|t}):\mathcal{S}\times\mathcal{A}^{n}\rightarrow\mathcal{S}
for
n\in[1,\dots,N]
be the robust reachable set, such that
s_{t+n}\in\mathcal{R}_{n|t}(s_{t},u_{0|t},\dots,u_{n-1|t})
under dynamics (
1
) for the control sequence
u_{0|t},\dots,u_{n-1|t}
and all possible
w_{t},\dots,w_{t+n-1}\in\mathbb{W}^{n-1}
.

Planning through RRSs is typically performed along a nominal trajectory
\mathcal{Z}_{t}=[z_{0|t},\dots,z_{N|t}]
with
z_{n|t}\in\mathcal{R}_{n|t}
. Growth of the RRS is commonly limited by augmenting the nominal control sequence with an ancillary controller such that
v_{n|t}=u_{n|t}+K_{n|t}(s_{n|t}-z_{n|t})
for all
s_{n|t}\in\mathcal{R}_{n}
. The ancillary feedback controller
K_{n|t}
is typically chosen based on
z_{n|t}
.
To stabilize the stochastic system indefinitely,
\mathbb{T}
needs to be robustly positive invariant as per Definition
2
.

Definition 2

(Robust Positive Invariance)
.

A set
\mathbb{X}\subseteq\mathcal{S}
is robustly positive invariant under a control law
a_{t}=\kappa(s_{t})
for the dynamics in (
1
), i.e.,
s_{t+1}=\mu(s_{t},\kappa(s_{t}))+L(s_{t},\kappa(s_{t}))w_{t}
and
w_{t}\in\mathbb{W}
, if for every
s_{t}\in\mathbb{X}
,
\mu(s_{t},\kappa(s_{t}))+L(s_{t},\kappa(s_{t}))\mathbb{W}\subseteq\mathbb{X}
(see
Rawlings et al. 2024
, Definition 3.7).

3
Related Work

Various approaches address exploration safety in RL. Constrained MDP formulations
(
Achiam et al. 2017
;
As et al. 2025
)
impose constraints on expected cumulative constraint violations. This, however, encourages safe behavior rather than enforces it, which is insufficient for many applications.

Safety filters provide stronger guarantees by ensuring constraint satisfaction with high probability. At every time step, the RL action is evaluated and, if necessary, projected onto the closest safe action. Existing approaches can be clustered into Hamilton-Jacobi reachability (HJR) methods
(
Bansal et al. 2017
)
, control barrier functions (CBFs)
(
Ames et al. 2019
)
, and predictive safety filters (PSFs)
(
Wabersich & Zeilinger 2018
)
with a comprehensive overview provided in
Wabersich et al. 2023
and
Brunke et al. 2022
. While HJR methods require substantial domain knowledge and scale poorly with dimension, CBFs become increasingly difficult to find for high-dimensional systems. We focus on PSFs, which generally scale more favorably
(
Wabersich et al. 2023
)
.

PSFs are closely related to MPC and typically rely on first-principles models
(
Wabersich & Zeilinger 2018
;
Bejarano et al. 2025
)
or data-driven models such as Bayesian linear regression
(
Wabersich & Zeilinger 2021
;
Wabersich et al. 2022
)
or Gaussian processes
(
Koller et al. 2018
;
Goodall & Belardinelli 2026
)
. While these enable rigorous reachable set computation, they either require substantial domain knowledge or scale poorly with large datasets.
Gronauer et al. 2024
integrate PE dynamics models into PSFs, with minor extensions presented in
Güzelkaya et al. 2024
. However, both works neglect potential model exploitation under high epistemic uncertainty, resulting in heuristic reachable set computation. The consequences are frequent failures of the resulting PSF as presented in Section
6
. UPSi provides a rigorous reachable set computation comparable to common MPC model classes while leveraging the strong representational capacity of PE models.

4
Problem Setting

Similar to
Koller et al. 2018
, we assume access to an initial data-generating controller as stated in Assumption
1
that induces an initial certain set
\mathbb{C}^{0}
within which UPSi can operate.

Assumption 1

(Initial controller)
.

Let
\kappa
be a controller with
\kappa(\mathbb{S})\subseteq\mathbb{A}
that forms a terminal set
\mathbb{T}^{0}\subseteq\mathbb{S}
robustly positively invariant around the set of initial states
\mathbb{I}
. Data
\mathcal{D}^{0}
is generated via
\kappa
and training the PE model on
\mathcal{D}^{0}
yields an initial certain set
\mathbb{C}^{0}
, such that
\mathbb{T}^{0}\times\kappa(\mathbb{T}^{0})\subseteq\mathbb{C}^{0}
.

Starting from this initialization, UPSi guides exploration by ensuring the system remains in the constraint-satisfying subsets
\mathbb{S}\subseteq\mathcal{S}
and
\mathbb{A}\subseteq\mathcal{A}
.
This is achieved by solving a robust PSF problem

\displaystyle\min_{u_{0|t},\dots,u_{N-1|t}}

\displaystyle\|a_{t}-u_{0|t}\|_{2}^{2}

(4a)

s.t.

\displaystyle\mathcal{R}_{n|t}(s_{t},u_{0|t},\dots,u_{n-1|t})\times v_{n|t}\subseteq\mathbb{S}\times\mathbb{A}\cap\mathbb{C}^{j}\quad\forall n\in[1,\dots,N-1]

(4b)

\displaystyle\mathcal{R}_{N|t}(s_{t},u_{0|t},\dots,u_{N-1|t})\subseteq\mathbb{T}^{j},

(4c)

that differs from standard formulations solely by the certainty constraint in
\mathbb{C}^{j}
. Throughout training,
\mathbb{C}^{j}
gradually grows as data is observed.
Given
\mathcal{R}_{n|t}
,
\mathbb{C}^{j}
, and
\mathbb{T}^{j}
, several robust MPC schemes
(
Cannon et al. 2011
;
Köhler et al. 2021
;
Houska & Villanueva 2018
)
are well suited to solve (
4
).

The key contribution of this work is obtaining these ingredients from a learned neural network model. Leveraging properties of the PE architecture, we specifically derive:

(i) an overapproximation of the reachable set sequence
\mathcal{R}_{n}(s_{t},u_{0|t},\dots,u_{n-1|t})
;

(ii) the certain set
\mathbb{C}^{j}
for episode
j
; and

(iii) a data-driven expansion of the terminal set
\mathbb{T}^{j}
.

5
Uncertainty-Aware Predictive Safety Filtering

Below, we introduce the notion of the certain set
\mathbb{C}^{j}
in Section
5.1
. Within
\mathbb{C}^{j}
, we develop the overapproximation to reachable sets
\mathcal{R}_{n}(s_{t},u_{0|t},\dots,u_{n-1|t})
in Section
5.2
. We present UPSi in Section

and introduce the expansion of
\mathbb{T}^{j}
in Section
5.4
.

We require several assumptions for our reachable sets overapproximation.
Assumptions
2
and
3
address the approximation behavior of the PE model within its certain set, originally formulated and validated by
Frauenknecht et al. 2025
. Assumption
4
states monotonic improvement of the model as more data is gathered and is common in episodic methods
(
Didier et al. 2021
)
. Finally, Assumption
5
states regularity of the environment and model.

Assumption 2

(Consistent estimator)
.

The model is a consistent estimator of process noise, i.e.,

\left(\Sigma_{\theta^{j}}(s_{t},a_{t})-\Sigma(s_{t},a_{t})\right)\succcurlyeq 0\text{ for all }(s_{t},a_{t})\in\mathbb{C}^{j}\text{ and }e\in\{1,\dots,E\}

within the certain set
\mathbb{C}^{j}\subseteq\mathcal{S}\times\mathcal{A}
, following the definition of
Julier & Uhlmann 2001
.

Assumption 3

(Unbiased estimator)
.

Within the certain set
\mathbb{C}^{j}\subseteq\mathcal{S}\times\mathcal{A}
, model bias is negligible, i.e.

\mathbb{E}[\hat{S}_{t+1}\mid s_{t},a_{t}]=\mathbb{E}[S_{t+1}\mid s_{t},a_{t}]\text{ for all }(s_{t},a_{t})\in\mathbb{C}^{j}
.

Assumption 4

(Monotonic improvement)
.

The process noise estimation monotonically improves, such that

\Sigma_{\theta^{j}_{e}}(s_{t},a_{t})\succcurlyeq\Sigma_{\theta^{j+1}_{e}}(s_{t},a_{t})\succcurlyeq\Sigma(s_{t},a_{t})\text{ for all }(s_{t},a_{t})\in\mathbb{C}^{j},\text{ and }e\in\{1,\dots,E\}

and the certain set monotonically grows over the episode iterations
j
, that is,

\mathbb{C}^{j}\subseteq\mathbb{C}^{j+1}\subseteq\mathcal{S}\times\mathcal{A}.

Assumption 5

(Regularity of dynamics, noise scale, and certainty measure)
.

The nominal dynamics
\mu
are twice continuously differentiable. Further, the nominal dynamics
\mu
, process noise scale
L
, and certainty measure

g(s,a):=\tfrac{1}{n_{\mathcal{S}}}\mathrm{tr}(G(s,a))
, as will be introduced in Section
5.1
,
are Lipschitz continuous.
That is, there exist constants
\ell_{\nabla\mu},\ell_{\Sigma},\ell_{G}
such that for all
(s_{1},a_{1}),(s_{2},a_{2})\in\mathcal{S}\times\mathcal{A}
,

\tfrac{\|\nabla\mu(s_{1},a_{1})-\nabla\mu(s_{2},a_{2})\|_{F}}{\|(s_{1},a_{1})-(s_{2},a_{2})\|_{2}}\leq\ell_{\nabla\mu}
,

\tfrac{\|L(s_{1},a_{1})-L(s_{2},a_{2})\|_{F}}{\|(s_{1},a_{1})-(s_{2},a_{2})\|_{2}}\leq\ell_{L}
,
and
\tfrac{|g(s_{1},a_{1})-g(s_{2},a_{2})|}{\|(s_{1},a_{1})-(s_{2},a_{2})\|_{2}}\leq\ell_{G}
.

5.1
Uncertainty Quantification and Certain Set

Under Assumptions
2
and
3
,
Frauenknecht et al. 2025
propose to leverage ideas from sensor fusion
(
Julier & Uhlmann 2001
)
to separate epistemic stochasticity due to model error from aleatoric stochasticity describing the environment, and solely propagate the latter to closely capture the real system. We adopt their formulation of aleatoric variance
\bar{\Sigma}(z_{n\mid t},u_{n\mid t})=(\frac{1}{E}\sum_{e=1}^{E}(\Sigma_{\theta_{e}}(z_{n\mid t},u_{n\mid t}))^{-1})^{-1}
, nominal dynamics
\bar{\mu}(z_{n\mid t},u_{n\mid t})=\bar{\Sigma}(z_{n\mid t},u_{n\mid t})(\frac{1}{E}\sum_{e=1}^{E}(\Sigma_{\theta_{e}}(z_{n\mid t},u_{n\mid t}))^{-1}\mu_{\theta_{e}}(z_{n\mid t},u_{n\mid t}))
and epistemic variance
\hat{\Sigma}(z_{n\mid t},u_{n\mid t})=\frac{1}{E}\sum_{e=1}^{E}(\mu_{\theta_{e}}(z_{n\mid t},u_{n\mid t})-\bar{\mu}(z_{n\mid t},u_{n\mid t}))(\mu_{\theta_{e}}(z_{n\mid t},u_{n\mid t})-\bar{\mu}(z_{n\mid t},u_{n\mid t}))^{\top}
over the PE model.
Under Assumption
2
, the aleatoric variance estimate
\bar{\Sigma}
is a consistent estimator of the real process noise variance
\Sigma
in (
1
)
(
Julier & Uhlmann 1997
)
.
For predicting the reachable sets in Section
5.2
, solely the nominal dynamics
\bar{\mu}
and the aleatoric variance
\bar{\Sigma}
will be required.

The Kalman gain

G(z_{n\mid t},u_{n\mid t})=\bar{\Sigma}(z_{n\mid t},u_{n\mid t})\left(\bar{\Sigma}(z_{n\mid t},u_{n\mid t})+\hat{\Sigma}(z_{n\mid t},u_{n\mid t})\right)^{-1}

yields the ratio of aleatoric variance to total predictive variance. We define the sufficiently certain set

\mathbb{C}:=\{(s,a)\in\mathcal{S}\times\mathcal{A}|n_{\mathcal{S}}^{-1}\mathrm{tr}(G(s,a))\geq\xi\}

(5)

as the set of state-action pairs with sufficiently high Kalman gain. The average dimension-wise Kalman gain
1/n_{\mathcal{S}}\cdot\mathrm{tr}(G(s,a))\in[0,1]
approaches
1
when epistemic uncertainty is negligible and
0
under high model uncertainty, providing a bounded, easy-to-tune certainty measure for the PSF.

5.2
Reachable Sets

To predict future environment behavior, we overapproximate the robustly reachable sets by separating the nominal trajectory
z
from an error region
\mathcal{B}
resulting from accumulated process noise

\mathcal{R}(s_{t},u_{t|t},\dots,u_{n|t})\subseteq z_{n|t}\oplus\mathcal{B}_{n|t}.

(6)

This standard approach from robust MPC literature
(
Soloperto et al. 2018
;
Koller et al. 2018
;
Köhler et al. 2021
)
makes our formulation compatible with existing robust MPC schemes. Our key contribution is providing a reachable set formulation that provably overapproximates the environment (
1
) by propagating the Gaussian random variable
\hat{S}_{n|t}\sim\mathcal{N}(z_{n|t},P_{n|t})
of the model state along the nominal trajectory
z_{n|t}
with covariance
P_{n|t}
and truncating its support appropriately.

Starting from
\hat{S}_{0|t}\sim\mathcal{N}(z_{0|t},P_{0|t})
with
z_{0|t}=s_{t}
and
P_{0|t}=0
, we propagate the predictive distribution of
\hat{S}_{n|t}
forward in time. The mean is propagated through the nominal dynamics

z_{n+1\mid t}=\bar{\mu}(z_{n\mid t},u_{n\mid t}).

(7)

The variance
P_{n\mid t}
is propagated via a first-order Taylor approximation of the nominal dynamics
(
Hewing et al. 2018
;
Koller et al. 2018
)
, which preserves the Gaussian structure of
\hat{S}_{n|t}
at low computational cost.
The required Jacobians with respect to the state
A_{n\mid t}=\frac{1}{E}\sum_{e=1}^{E}\nabla_{s}\mu_{\theta_{e}}(s,a)|_{s=z_{n\mid t},a=u_{n\mid t}}
and and action
B_{n\mid t}=\frac{1}{E}\sum_{e=1}^{E}\nabla_{a}\mu_{\theta_{e}}(s,a)|_{s=z_{n\mid t},a=u_{n\mid t}}
, are computed as the average partial derivatives of the model.
Considering the ancillary controller
K_{n\mid t}
discussed in Section
2.3
yields linearized dynamics
F_{n\mid t}:=A_{n\mid t}+B_{n\mid t}K_{n\mid t}
, as shown in Lemma
12
of Supp.
B.2
.
Propagating the predictive variance through
F_{n\mid t}
, however, introduces a linearization error that can lead to a systematic underestimation of
P_{n\mid t}
such that the environment stochasticity is potentially no longer overapproximated. As presented in Lemma
2
,
3
, and
4
of Appendix
A

e^{\mathrm{max}}_{n\mid t}:=\frac{\epsilon\ell_{\nabla\mu}}{2}(\sqrt{\lambda_{\mathrm{max}}(P_{n\mid t})}+\sqrt{\lambda_{\mathrm{max}}(K_{n\mid t}P_{n\mid t}K_{n\mid t}^{\top})})^{2}+\ell_{L}\epsilon\sqrt{\lambda_{\mathrm{max}}(P_{n\mid t})+\lambda_{\mathrm{max}}(K_{n\mid t}P_{n\mid t}K_{n\mid t}^{\top})}
.

The predictive variance overapproximating this error is derived in Lemma
5
of Appendix
A
, as

P_{n+1\mid t}=(1+\sqrt{\tfrac{n_{\mathcal{S}}\,(e^{\mathrm{max}}_{n\mid t})^{2}}{\epsilon\,\mathrm{tr}(Q_{n+1\mid t})}})Q_{n+1\mid t}+(1+\sqrt{\tfrac{\epsilon\,\mathrm{tr}(Q_{n+1\mid t})}{n_{\mathcal{S}}\,(e^{\mathrm{max}}_{n\mid t})^{2}}})\tfrac{(e^{\mathrm{max}}_{n\mid t})^{2}}{\epsilon}I:=\Phi(P_{n\mid t},K_{n\mid t},z_{n\mid t},u_{n\mid t})

(8)

for

with the naive predictive variance
Q_{n+1\mid t}=F_{n\mid t}P_{n\mid t}F_{n\mid t}^{\top}+\bar{\Sigma}(z_{n\mid t},u_{n\mid t})
comprising the linearly transformed predictive variance and the aleatoric variance.
In particular,

if we assume the linearization error to be negligible, e.g., for
\ell_{\nabla\mu}=\ell_{L}=0

Propagating
\hat{S}_{n|t}

) and (

\epsilon
-level set, corresponding to the noise scale

7
Conclusion

Exploration safety is a fundamental challenge in RL that can be efficiently addressed via PSFs. However, standard PSF methods rely on common MPC models requiring substantial domain knowledge or scaling poorly with data. On the contrary, PE models have proven their capability to model high-dimensional systems with nonlinear dynamics, problems in which deep RL methods excel. UPSi addresses the gap between these fields. We present a novel construction of reachable sets from PE models that seamlessly integrates into robust PSF formulations and introduce model certainty as a PSF constraint to avoid model exploitation.
Further, we present a consistent overapproximation of reachable sets using UPSi and report its effectiveness under practical simplifications when integrated into MBRL.
The main limitation of the presented approach is the slow convergence of the PSF problem. Future work should focus on optimizing the MPC mechanism to enable real-time feasibility, and thus hardware deployment of UPSi.

(z_{n|t}+L_{n|t}w_{n|t}-\hat{z}_{n|t})^{\top}(\rho\hat{P}_{n|t})^{-1}(z_{n|t}+L_{n|t}w_{n|t}-\hat{z}_{n|t})\leq\tfrac{1}{\rho}w_{n|t}^{\top}w_{n|t}\leq\tfrac{\epsilon}{\rho}\leq 1

Thus
\rho=\epsilon
yields a valid level set, and substituting in (
28

Lemma 7

(Reformulation of an Ellipsoid as a Minkowski sum)
.

Let
\epsilon P
be a symmetric positive definite matrix with Cholesky decomposition

\epsilon P=M^{\top}M
. Then the ellipsoidal set

\mathcal{P}=\left\{s\in\mathcal{S}\mid(s-z)^{\top}(\epsilon P)^{-1}(s-z)\leq 1\right\}

(29)

is equivalent to the set
\mathcal{Q}=\left\{z\oplus M^{\top}q\mid q\in\mathbb{R}^{n_{\mathcal{S}}},\,\|q\|_{2}\leq 1\right\}.

Proof.

We show set equivalence by proving both inclusions
\mathcal{Q}\subseteq\mathcal{P}

and
\mathcal{P}\subseteq\mathcal{Q}
. By the definition of the Minkowski sum,
\mathcal{Q}
can be written as

\mathcal{Q}=\left\{z\oplus M^{\top}q\mid\|q\|_{2}\leq 1\right\}=\left\{z+M^{\top}q\mid\|q\|_{2}\leq 1\right\},

(30)

i.e.,
\mathcal{Q}
consists of all points of the form
s=z+M^{\top}q

where
q
lies in the unit ball.

Part 1:
\mathcal{Q}\subseteq\mathcal{P}
.
Let
s\in\mathcal{Q}
be arbitrary. By (
30
), there exists a

q\in\mathbb{R}^{n_{\mathcal{S}}}
with
\|q\|_{2}\leq 1
such that
s=z+M^{\top}q
.
Substituting this expression for
s
into the quadratic form in (
29
)
and using the Cholesky decomposition
\epsilon P=M^{\top}M
yields
(s-z)^{\top}(\epsilon P)^{-1}(s-z)=(M^{\top}q)^{\top}(\epsilon P)^{-1}(M^{\top}q)=(M^{\top}q)^{\top}(M^{\top}M)^{-1}(M^{\top}q)=q^{\top}q=\|q\|_{2}^{2}.

Since
\|q\|_{2}\leq 1
by assumption, it follows
\|q\|_{2}^{2}\leq 1
, and therefore
(s-z)^{\top}(\epsilon P)^{-1}(s-z)=\|q\|_{2}^{2}\leq 1,

which means
s\in\mathcal{P}
. Since
s\in\mathcal{Q}
was arbitrary,
we have
\mathcal{Q}\subseteq\mathcal{P}
.

Part 2:
\mathcal{P}\subseteq\mathcal{Q}
.
Let
s\in\mathcal{P}
be arbitrary, so that

(s-z)^{\top}(\epsilon P)^{-1}(s-z)\leq 1
.
Since
\epsilon P
is symmetric positive definite, its Cholesky factor
M

is invertible. We can therefore define
q:=(M^{\top})^{-1}(s-z),

which by construction satisfies
s=z+M^{\top}q
, i.e.,
s
is of
the form required by (
30
). It remains to show that
\|q\|_{2}\leq 1
.
Expanding
\|q\|_{2}^{2}
and using the Cholesky decomposition gives
\|q\|_{2}^{2}=q^{\top}q=((M^{\top})^{-1}(s-z))^{\top}((M^{\top})^{-1}(s-z))=(s-z)^{\top}(M^{\top}M)^{-1}(s-z)=(s-z)^{\top}(\epsilon P)^{-1}(s-z)\leq 1,

where we used
((M^{\top})^{-1})^{\top}=M^{-1}
in the third line,
and the last inequality holds since
s\in\mathcal{P}
. Therefore
\|q\|_{2}^{2}\leq 1
,
which implies
\|q\|_{2}\leq 1
. Since
s=z+M^{\top}q
with
\|q\|_{2}\leq 1
,
we conclude
s\in\mathcal{Q}
. Since
s\in\mathcal{P}
was arbitrary,
we have
\mathcal{P}\subseteq\mathcal{Q}
.

Since
\mathcal{Q}\subseteq\mathcal{P}
and
\mathcal{P}\subseteq\mathcal{Q}
,
we conclude
\mathcal{P}=\mathcal{Q}
, which yields the desired result.
∎

Lemma 8

(One-step ellipsoidal propagation)
.

Fix
t
and a nominal pair
(z_{n|t},u_{n|t})
.
Let Assumptions
3
and
2
hold.
Let

be obtained by the outer-ellipsoid inflation (Lemma

).

(31)

Then for every

and every
w\in\mathbb{W}
, the successor
s^{+}

satisfies

Proof.

Take any

Using the definition

Lemma 10

(Constraint tightening for model uncertainty)
.

Let Assumption
5
hold. Define the certain set
\mathbb{C}:=\{(s,a)\in\mathcal{S}\times\mathcal{A}\;|\;\tfrac{1}{n_{\mathcal{S}}}\,\mathrm{tr}\!(G(s,a))\geq\xi\},

and let
\mathcal{P}:=\left\{s\in\mathcal{S}\;\Big|\;(s-z)^{\top}(\epsilon\,P)^{-1}(s-z)\leq 1\right\}
. Then for
s\in\mathcal{P}
,
v=u+K(s-z)
, and
\mathbb{Q}_{\mathcal{S}\times\mathcal{A}}=\{q\in\mathbb{R}^{n_{\mathcal{S}}+n_{\mathcal{A}}}\mid\|q\|_{2}\leq 1\}
,
the pair
(s,v)\in\mathbb{C}
, provided that

(z,\,u)\oplus\mathbb{Q}_{\mathcal{S}\times\mathcal{A}}\,\ell_{G}\sqrt{\epsilon\left(\lambda_{\mathrm{max}}\left(P\right)+\lambda_{\mathrm{max}}\left(KPK^{\top}\right)\right)}\subseteq\mathbb{C}
.

Proof.

We can upper bound the increase in uncertainty, indicated by the reduction of the normalized trace of the Kalman gain matrix, as
\lambda_{\mathrm{max}}\left(KPK^{\top}\right)

\displaystyle\tfrac{1}{n_{\mathcal{S}}}\mathrm{tr}(G(z,u))-\tfrac{1}{n_{\mathcal{S}}}\mathrm{tr}(G(s,v))\leq\ell_{G}\|(z,u)-(s,v)\|_{2}=\ell_{G}\sqrt{\|s-z\|_{2}^{2}+\|v-u\|_{2}^{2}}

(33)

\displaystyle=\ell_{G}\sqrt{\|s-z\|_{2}^{2}+\|u+K(s-z)-u\|_{2}^{2}}\leq\ell_{G}\sqrt{\epsilon\left(\lambda_{\mathrm{max}}\left(P\right)+\lambda_{\mathrm{max}}\left(KPK^{\top}\right)\right)}

Consequently, we can lower bound
\tfrac{1}{n_{\mathcal{S}}}\mathrm{tr}(G(s,v))
as
\tfrac{1}{n_{\mathcal{S}}}\mathrm{tr}(G(s,v))\geq\tfrac{1}{n_{\mathcal{S}}}\mathrm{tr}(G(z,u))-\ell_{G}\sqrt{\epsilon\left(\lambda_{\mathrm{max}}\left(P\right)+\lambda_{\mathrm{max}}\left(KPK^{\top}\right)\right)}
.
The Minkowski sum
(z,u)\oplus\mathbb{Q}_{\mathcal{S}\times\mathcal{A}}\,\ell_{G}\sqrt{\epsilon(\lambda_{\mathrm{max}}(P)+\lambda_{\mathrm{max}}(KPK^{\top}))}\subseteq\mathbb{C}

ensures that for all
q\in\mathbb{Q}_{\mathcal{S}\times\mathcal{A}}
, we have
\tfrac{1}{n_{\mathcal{S}}}\mathrm{tr}\!(G\!(z+\ell_{G}\sqrt{\epsilon(\lambda_{\mathrm{max}}(P)+\lambda_{\mathrm{max}}(KPK^{\top}))}\,q_{s},\,u+\ell_{G}\sqrt{\epsilon(\lambda_{\mathrm{max}}(P)+\lambda_{\mathrm{max}}(KPK^{\top}))}\,q_{a}))\geq\xi.

Combining this with the bound above, we conclude
\xi\overset{!}{\leq}\tfrac{1}{n_{\mathcal{S}}}\mathrm{tr}(G(z,u))-\ell_{G}\sqrt{\epsilon(\lambda_{\mathrm{max}}(P)+\lambda_{\mathrm{max}}(KPK^{\top}))}\leq\tfrac{1}{n_{\mathcal{S}}}\mathrm{tr}(G(s,v)),

which establishes
(s,v)\in\mathbb{C}
.
∎

Lemma 13

(Linearization error bound on the nominal dynamics)

\displaystyle e

\displaystyle=\left[e_{1},e_{2},\dots,e_{n_{\mathcal{S}}}\right]^{\top}=\frac{1}{2}\left[\delta^{\top}(K\delta)^{\top}\right]\mathcal{H}\begin{bmatrix}\delta\\

Lemma 16

(Linearization error compensated variance)
.

Let the reachable set

\mathcal{Q}:=\left\{s\in\mathcal{S}\big|(s-z)^{\top}(\epsilon Q)^{-1}(s-z)\leq 1\right\}

(58)

resulting from linearized prediction through dynamics (
1

, and for the special case
Q=0

Proof.

The upper bound

(61)

To be a valid overapproximation, we need to find
P
such that the support of
\mathcal{Q}\oplus\mathcal{E}
lies within the support of
\mathcal{P}
for any arbitrary direction vector
v
. That is

\displaystyle h_{\mathcal{P}}(v)

\displaystyle\overset{!}{\geq}h_{\mathcal{Q}\oplus\mathcal{E}}(v)=h_{\mathcal{Q}}(v)+h_{\mathcal{E}}(v)

(62)

\displaystyle\sqrt{v^{\top}(\epsilon P)v}

\displaystyle\overset{!}{\geq}\sqrt{v^{\top}(\epsilon Q)v}+\sqrt{v^{\top}((e^{\mathrm{max}})^{2}I)v}

\displaystyle v^{\top}(\epsilon P)v

\displaystyle\overset{!}{\geq}\left(\sqrt{v^{\top}(\epsilon Q)v}+\sqrt{v^{\top}((e^{\mathrm{max}})^{2}I)v}\right)^{2}.

We use the following outer approximation from

. To find the minimal valid overapproximation, we determine

to minimize

\displaystyle\nabla_{\beta}\left[(1+\beta)\mathrm{tr}(Q)+\left(1+\frac{1}{\beta}\right)\frac{(e^{\mathrm{max}})^{2}}{\epsilon}\mathrm{tr}(I)\right]

\displaystyle\overset{!}{=}0

(65)

\displaystyle\mathrm{tr}(Q)-\frac{1}{\beta^{2}}\frac{n_{\mathcal{S}}\,(e^{\mathrm{max}})^{2}}{\epsilon}

\displaystyle=0.

which yields the final expression for

:

\displaystyle\beta

\displaystyle=\sqrt{\frac{n_{\mathcal{S}}\,(e^{\mathrm{max}})^{2}}{\epsilon\,\mathrm{tr}(Q)}}.

(66)

Inserting (
26
) into (
25
) yields the desired result.

Lemma 18

(Reformulation of an Ellipsoid as a Minkowski sum)
.

Let
\epsilon P
be a symmetric positive definite matrix with Cholesky decomposition

\epsilon P=M^{\top}M
. Then the ellipsoidal set

\mathcal{P}=\left\{s\in\mathcal{S}\mid(s-z)^{\top}(\epsilon P)^{-1}(s-z)\leq 1\right\}

(73)

is equivalent to the set

\mathcal{Q}=\left\{z\oplus M^{\top}q\mid q\in\mathbb{R}^{n_{\mathcal{S}}},\,\|q\|_{2}\leq 1\right\}.

(74)

Proof.

We show set equivalence by proving both inclusions
\mathcal{Q}\subseteq\mathcal{P}

and
\mathcal{P}\subseteq\mathcal{Q}
.

By the definition of the Minkowski sum,
\mathcal{Q}
can be written as

\mathcal{Q}=\left\{z\oplus M^{\top}q\mid\|q\|_{2}\leq 1\right\}=\left\{z+M^{\top}q\mid\|q\|_{2}\leq 1\right\},

(75)

i.e.,
\mathcal{Q}
consists of all points of the form
s=z+M^{\top}q

where
q
lies in the unit ball.

Part 1:
\mathcal{Q}\subseteq\mathcal{P}
.
Let
s\in\mathcal{Q}
be arbitrary. By (
30
), there exists a

q\in\mathbb{R}^{n_{\mathcal{S}}}
with
\|q\|_{2}\leq 1
such that
s=z+M^{\top}q
.
Substituting this expression for
s
into the quadratic form in (
29
)
and using the Cholesky decomposition
\epsilon P=M^{\top}M
yields

\displaystyle(s-z)^{\top}(\epsilon P)^{-1}(s-z)=(M^{\top}q)^{\top}(\epsilon P)^{-1}(M^{\top}q)=(M^{\top}q)^{\top}(M^{\top}M)^{-1}(M^{\top}q)=q^{\top}q=\|q\|_{2}^{2}.

(76)

Since
\|q\|_{2}\leq 1
by assumption, it follows that
\|q\|_{2}^{2}\leq 1
, and therefore

(s-z)^{\top}(\epsilon P)^{-1}(s-z)=\|q\|_{2}^{2}\leq 1,

(77)

which means
s\in\mathcal{P}
. Since
s\in\mathcal{Q}
was arbitrary,
we have
\mathcal{Q}\subseteq\mathcal{P}
.

Part 2:
\mathcal{P}\subseteq\mathcal{Q}
.
Let
s\in\mathcal{P}
be arbitrary, so that

(s-z)^{\top}(\epsilon P)^{-1}(s-z)\leq 1
.
Since
\epsilon P
is symmetric positive definite, its Cholesky factor
M

is invertible. We can therefore define

q:=(M^{\top})^{-1}(s-z),

(78)

which by construction satisfies
s=z+M^{\top}q
, i.e.,
s
is of
the form required by (
30
). It remains to show that
\|q\|_{2}\leq 1
.
Expanding
\|q\|_{2}^{2}
and using the Cholesky decomposition gives

\displaystyle\|q\|_{2}^{2}

\displaystyle=q^{\top}q=\left((M^{\top})^{-1}(s-z)\right)^{\top}\left((M^{\top})^{-1}(s-z)\right)

(79)

\displaystyle=(s-z)^{\top}(M^{\top}M)^{-1}(s-z)=(s-z)^{\top}(\epsilon P)^{-1}(s-z)\leq 1,

where we used
\left((M^{\top})^{-1}\right)^{\top}=M^{-1}
in the third line,
and the last inequality holds since
s\in\mathcal{P}
. Therefore
\|q\|_{2}^{2}\leq 1
,
which implies
\|q\|_{2}\leq 1
. Since
s=z+M^{\top}q
with
\|q\|_{2}\leq 1
,
we conclude
s\in\mathcal{Q}
. Since
s\in\mathcal{P}
was arbitrary,
we have
\mathcal{P}\subseteq\mathcal{Q}
.

Since
\mathcal{Q}\subseteq\mathcal{P}
and
\mathcal{P}\subseteq\mathcal{Q}
,
we conclude
\mathcal{P}=\mathcal{Q}
, which yields the desired result.
∎

C.1
Implementation of Terminal Set Expansion

As highlighted in Section
5.4
, we approximate (
14
) via a sampling-based scheme inspired by
Rosolia & Borrelli 2017
. To this end, we store initial points
z_{0|t}^{*}
at which (
96
) is feasible, and construct a terminal set
\mathbb{T}^{j}
based on the stored solutions. However, not all solutions to (
96
) are eligible for the terminal set expansion. Because we use soft constraints and truncated episodes, we must verify that solution points
z_{0|t}^{*}
actually yield accurate predictions according to (
96
). By introducing a parameter
slack threshold
, we set a limit on the maximum values of slack variables for
z_{0|t}^{*}
to be stored, where low slack variables indicate that state, action, and certainty constraints were satisfied and the terminal set was reached. In addition, using a
proximity threshold
, we remove all solutions
z_{0|t}^{*}
from the estimation that are close to a truncation.

In practice, the expansion of
\mathbb{T}^{j}
must remain highly conservative.. To this end, we use the following heuristic: via k-Nearest-Neighbors (
k=10,p=0.95
), we remove outliers of
z_{0|t}^{*}
, followed by set estimation based on the reduced number of solution points.
Two methods are available for set estimation:
polytope
uses the convex outer hull of all data, and
ellipsoid
computes the variance of the data, which enables the scaling of a terminal ellipsoid (probability level
0.7
). Finally, for the integration of the resulting sets as
\mathbb{T}^{j}
in (
96
), we translate their outer contour into linear facets, for which (
96g
) can be verified using numerical optimization. A visualization of both methods is shown in Figure
3
.
We note that the methods presented above are approximate, and their conservatism needs to be manually verified in practice.
