Abstract
. We obtain sharp estimates for functions harmonic with respect to x x -dependent rectilinear stable processes in balls, under the assumption that the Dirichlet exterior data are radial about the center. The main idea of the proof is based on the construction of global barrier functions for the x x -dependent rectilinear fractional Laplacian in balls.



1.
Introduction

Let
\alpha\in(0,2)
,
d\in{\mathds{N}}
,
d\geq 2
and
Z_{t}=(Z_{t}^{(1)},\ldots,Z_{t}^{(d)})^{T}
be the rectilinear
\alpha
-stable process on
\mathds{R}^{d}
, that is
Z_{t}^{(1)},\ldots,Z_{t}^{(d)}
are independent one-dimensional symmetric
\alpha
-stable processes. We consider a stochastic differential equation

(1)

dX_{t}=A(X_{t-})\,dZ_{t},\quad X_{0}=x\in\mathds{R}^{d},

where
A(x)=(a_{ij}(x))
is a
d\times d
matrix and there are constants
\eta_{1},\eta_{2}>0
, such that for any
x\in\mathds{R}^{d}
,
i,j\in\{1,\ldots,d\}

|a_{ij}(x)|\leq\eta_{1},

\det(A(x))\geq\eta_{2},

and for any
i,j\in\{1,\ldots,d\}
the functions
\mathds{R}^{d}\ni x\to a_{ij}(x)
are continuous.

It is well known (see
[
2
]
) that SDE (
1
) has a unique weak solution
X
, which we call
the
x
-dependent rectilinear
\alpha
-stable process on
\mathds{R}^{d}
. It is a typical example of a pure jump process, whose Lévy measure depends on the position and is singular with respect to the Lebesgue measure on
\mathds{R}^{d}
.

Let
\mathds{E}^{x}
,
\mathds{P}^{x}
denote respectively the expected value and the probability of the process
X
starting from
x\in\mathds{R}^{d}
. By
\tau_{D}=\inf\{t\geq 0:\,X_{t}\notin D\}
we denote the first exit time of an open set
D\subset\mathds{R}^{d}
by
X
.

We say that a function
u
that is Borel measurable and bounded in
\mathds{R}^{d}
is
harmonic
with respect to
X
in a bounded open set
D\subset\mathds{R}^{d}
if

u(x)=\mathds{E}^{x}(u(X_{\tau_{D}}))\quad\text{for every $x\in D$.}

Clearly, if
D\subset\mathds{R}^{d}
is a bounded open set and
g:D^{c}\to\mathds{R}
is a bounded Borel function then
u
given by

(2)

u(x)=\left\{\begin{array}[]{lll}\mathds{E}^{x}(g(X_{\tau_{D}})),&\text{for}&x\in D,\\
g(x),&\text{for}&x\in D^{c}\end{array}\right.

is harmonic with respect to
X
on
D
. The function
g
may be treated as Dirichlet exterior data for
u
.

By Proposition 4.1 of
[
2
]
, the infinitesimal generator of the Markov process
X
determined by (
1
) is

(3)

\displaystyle\mathcal{L}f(x)

\displaystyle=

\displaystyle\mathcal{A}_{\alpha}\sum_{i=1}^{d}\int_{\mathds{R}\setminus\{0\}}\left[f(x+a_{i}(x)w)-f(x)-w1_{\{|w|\leq 1\}}\nabla f(x)a_{i}(x)\right]\,\frac{dw}{|w|^{1+\alpha}},

\displaystyle=

\displaystyle\frac{\mathcal{A}_{\alpha}}{2}\sum_{i=1}^{d}\int_{\mathds{R}\setminus\{0\}}\left[f(x+a_{i}(x)w)+f(x-a_{i}(x)w)-2f(x)\right]\,\frac{dw}{|w|^{1+\alpha}},

where
\mathcal{A}_{\alpha}=\alpha 2^{\alpha-1}\pi^{-1/2}\Gamma((1+\alpha)/2)/\Gamma(1-\alpha/2)
and
a_{i}(x)=(a_{1i}(x),\ldots,a_{di}(x))
is the
i
th column of
A(x)
. We call
\mathcal{L}

the
x
-dependent rectilinear fractional Laplacian
. This operator is often presented in the following form

\mathcal{L}=-\sum_{i=1}^{d}\left(-\partial_{a_{i}(x)}^{2}\right)^{\alpha/2},

see e.g. (1.9) in
[
13
]
.
-\mathcal{L}
is a typical example of a nonlocal elliptic operator, which is not translation invariant and whose
Lévy measure is singular with respect to the Lebesgue measure on
\mathds{R}^{d}
(see page 115 in
[
12
]
). When
A(x)
is the identity matrix for each
x\in\mathds{R}^{d}
then
\mathcal{L}
is called
the rectilinear fractional Laplacian
(see
[
8
]
). Such operators have been extensively studied in recent years. It is well known that if
D\subset\mathds{R}^{d}
is an open set,
f:\mathds{R}^{d}\to\mathds{R}
is a bounded Borel function and
f\in C_{b}^{2}(D)
then
\mathcal{L}f(x)
is well defined for any
x\in D
. One may show (see Corollary
3.2
) that if
D
,
f
are as above and additionally
D
is bounded and
\mathcal{L}f(x)=0
for any
x\in D
then
f
is harmonic with respect to
X
on
D
.

As usual, we denote a ball with center at
z\in\mathds{R}^{d}
and radius
r>0
by
B(z,r)
. For any set
D\subset\mathds{R}^{d}
we denote its complement by
D^{c}
. For any
r>0
, we say that
g:B^{c}(z,r)\to\mathds{R}
is radial with respect to
z\in\mathds{R}^{d}
when there exists a radial profile function
\tilde{g}:[r,\infty)\to\mathds{R}
such that for any
x\in B^{c}(z,r)
we have
g(x)=\tilde{g}(|x-z|)
.

The main result of this paper is the following theorem, which provides estimates for functions harmonic with respect to
X
in balls, under the assumption that the Dirichlet exterior data are radial about the center.

Theorem 1.1
.

Let
z\in\mathds{R}^{d}
,
r>0
,
D=B(z,r)
and
g:D^{c}\to\mathds{R}
be a bounded Borel function, which is radial with respect to
z
. Denote by
\tilde{g}
the radial profile function of
g
. Let
u
be the function harmonic with respect to
X
on
D
, which is given by (
2
). For each fixed
z\in\mathds{R}^{d}
,
r>0
and
x\in D
there exists a Borel function
f_{D}^{x}:[r,\infty)\to[0,\infty)
such that

u(x)=\int_{r}^{\infty}f_{D}^{x}(y)\tilde{g}(y)\,dy.

Moreover, there exist constants
C_{1},C_{2}>0
which depend only on
\alpha
,
d
,
\eta_{1}
,
\eta_{2}
such that for any
y\in(r,\infty)
we have

C_{1}\varphi_{D}^{x}(y)\leq f_{D}^{x}(y)\leq C_{2}\varphi_{D}^{x}(y),

where

(4)

\varphi_{D}^{x}(y)=\frac{\delta_{D}^{\alpha/2}(x)r^{\alpha/2}}{(y-r)^{\alpha/2}y^{\alpha/2}(y+\delta_{D}(x)-r)}

and
\delta_{D}(x)=r-|x-z|
.

Remark 1.2
.

For each fixed
z\in\mathds{R}^{d}
,
r>0
,
x\in D=B(z,r)
and any Borel set
W\subset[r,\infty)
put

(5)

\kappa_{D}^{x}(W)=\mathds{P}^{x}(|X_{\tau_{D}}-z|\in W).

Clearly,
\kappa_{D}^{x}
is a probability measure on
[r,\infty)
. The function
f_{D}^{x}
is a density of
\kappa_{D}^{x}
that is
\kappa_{D}^{x}(W)=\int_{W}f_{D}^{x}(y)\,dy
for any Borel set
W\subset[r,\infty)
.

As far as we know, Theorem
1.1
provides the first sharp two-sided estimates for harmonic functions associated with nonlocal elliptic operators which are not translation invariant and whose Lévy measures are singular with respect to the Lebesgue measure on
\mathds{R}^{d}
. The novelty of the result lies in obtaining explicit boundary decay rates for harmonic functions of
x
-dependent rectilinear fractional Laplacians in balls under minimal regularity assumptions on the coefficients and under radial exterior data.
Although we focus on balls and on harmonic functions, the construction of global barrier functions developed in this paper is flexible and suggests possible extensions to other classes of domains and equations.

The regularity theory of harmonic functions for operators
\mathcal{L}
was initiated by Bass and Chen in
[
1
]
. In that work, Hölder continuity of harmonic functions was established, and it was shown that the Harnack inequality fails in this setting.

Subsequent developments considered broader classes of
x
-dependent nonlocal elliptic operators, including operators with singular kernels. Within this more general framework, weak Harnack inequalities and Hölder regularity results were obtained in
[
6
,
10
]
. In parallel, heat kernel estimates for such operators were studied extensively; see, for example,
[
15
,
16
,
18
,
14
,
17
]
and the references therein. More recently, Schauder-type and Cordes–Nirenberg-type estimates for solutions of
x
-dependent nonlocal elliptic equations with singular kernels were proved in
[
13
]
, focusing on local regularity properties of solutions. For the (translation invariant) rectilinear fractional Laplacians, Dirichlet heat kernel estimates in
C^{1,1}
domains were established in
[
8
]
.

Despite this substantial body of work, sharp two-sided estimates describing the boundary behaviour of harmonic functions for
x
-dependent nonlocal elliptic operators with singular Lévy measures appear to be unavailable, even in simple geometric domains such as balls.

The remainder of the paper is organized as follows.
Section 2 introduces the notation and collects some facts that will be needed later. Section 3 is devoted to the proof of our main result, Theorem
1.1
. The crucial step, the verification that two auxiliary functions
f_{b_{1},\theta}
and
F_{b_{2},\Theta}
are, respectively, superharmonic and subharmonic with respect to the process
X
in the ball
B(z,r)
, is deferred to Section 4. Finally, in the Appendix we construct certain one-dimensional
C^{2}
functions that underlie the definition of
f_{b,\theta}
.

3.
Proof of the main result

In this section we present the proof of our main result, Theorem
1.1
. The key steps are Theorem
3.1
and Proposition
3.6
. Theorem
3.1
is a localized Dynkin formula in martingale form (stopped at
\tau_{U}
). This result may be of independent interest. Proposition
3.6
concerns estimates of harmonic functions with respect to
X
when Dirichlet exterior data are indicators of rings. The key idea to obtain Proposition
3.6
is the construction of global barrier functions
f_{b_{1},\theta}-u
and
u-F_{b_{2},\Theta}
with respect to the
x
-dependent rectilinear fractional Laplacian for the ball
D
. Part of the proof of Proposition
3.6
, namely Proposition
3.7
, is deferred to Section 4.

Theorem 3.1
.

If
D\subset\mathds{R}^{d}
is an open set,
U
is open and bounded,
\bar{U}\subset D
and a function
f:\mathds{R}^{d}\to\mathds{R}
is bounded and Borel and
f\in C_{b}^{2}(D)
then

f(X_{t\wedge\tau_{U}})-f(X_{0})-\int_{0}^{t\wedge\tau_{U}}\mathcal{L}f(X_{s})\,ds

is a martingale under
\mathds{P}^{x}
for each
x\in U
.

Proof.

We adapt the proof of Proposition 4.1 in
[
2
]
; the main additional point is to handle the merely local regularity assumption
f\in C_{b}^{2}(D)
, which requires a careful localization of the argument. Fix
x\in U
and let
X
be the weak solution to (
1
) under
\mathds{P}^{x}
.
We apply the local Itô formula (see, e.g.,
[
5
, Lemma 3.8]
) to
f
, and obtain

(15)

\displaystyle f(X_{t\wedge\tau_{U}})-f(X_{0})

\displaystyle=

\displaystyle\int_{0}^{t\wedge\tau_{U}}\nabla f(X_{u-})dX_{u}+\sum_{u\leq t\wedge\tau_{U},|\Delta X_{u}|>0}f(X_{u})-f(X_{{u-}})-\nabla f(X_{u-})\cdot\Delta X_{u}

\displaystyle=

\displaystyle I(t)+J(t).

We split
I(t)
into the small jump part and the large jump part. Let
Z^{1}_{t}
and
Z^{2}_{t}
be two independent processes with Lévy measures
\mu_{1}=\mu|_{B_{1}}
and
\mu_{2}=\mu-\mu_{1}
, respectively. Then we may assume that

Z_{t}=Z^{1}_{t}+Z^{2}_{t}\ \text{and}\ X_{t}=X^{1}_{t}+X^{2}_{t},

where

(16)

dX^{i}_{t}=A(X_{t-})\,dZ^{i}_{t},\quad X_{0}=x\in\mathds{R}^{d}.

It follows that

I(t)=\int_{0}^{t\wedge\tau_{U}}\nabla f(X_{u-})dX^{1}_{u}+\int_{0}^{t\wedge\tau_{U}}\nabla f(X_{u-})dX^{2}_{u}=I_{1}(t)+I_{2}(t).

Note that
Z_{t}^{2}
is a compound Poisson process and its jumps are the big jumps of the process
Z_{t}
, hence

I_{2}(t)=\sum_{u\leq t\wedge\tau_{U},|\Delta Z_{u}|>1}\nabla f(X_{u-})\cdot\Delta X_{u}.

Hence we can rewrite (
15
) as

(17)

\displaystyle f(X_{t\wedge\tau_{U}})-f(X_{0})

\displaystyle=

\displaystyle I_{1}(t)+\sum_{u\leq t\wedge\tau_{U},|\Delta X_{u}|>0}f(X_{u})-f(X_{{u-}})-\nabla f(X_{u-})\cdot\Delta X_{u}\,1_{\{|\Delta Z_{u}|\leq 1\}}

\displaystyle=

\displaystyle I_{1}(t)+J_{1}(t).

We claim that
I_{1}(t)
is a martingale. This follows from the fact that its quadratic variation process
[I_{1},I_{1}]_{t}
is integrable (see e.g.
[
21
, Corollary 3, p.73]
). Note that on the event
u\leq t\wedge\tau_{U}

|\Delta X_{u}|=|A(X_{u-})\Delta Z_{u}|\leq\sup_{x\in U}|A(x)||\Delta Z_{u}|

and

|\nabla f(X_{u-})|\leq\sup_{x\in U}|\nabla f(x)|.

Hence,

\displaystyle\mathds{E}^{x}[I_{1},I_{1}]_{t}

\displaystyle\leq

\displaystyle\mathds{E}^{x}\sum_{u\leq t\wedge\tau_{U},|\Delta Z_{u}|\leq 1}\max_{v\leq t\wedge\tau_{U}}(|\nabla f(X_{v-})|)^{2}|\Delta X_{u}|^{2}

\displaystyle\leq

\displaystyle C\mathds{E}^{x}\sum_{u\leq t,|\Delta Z_{u}|\leq 1}|\Delta Z_{u}|^{2}

\displaystyle=

\displaystyle Ct\int_{|x|\leq 1}|x|^{2}\mu(dx)<\infty,

which proves integrability of quadratic variation process.

Next, we observe that
J_{1}(t)
can be rewritten as

J_{1}(t)=\sum_{u\leq t\wedge\tau_{U},|\Delta Z_{u}|>0}f(X_{u-}+A(X_{u-})\Delta Z_{u})-f(X_{{u-}})-\nabla f(X_{u-})\cdot A(X_{u-})\Delta Z_{u}\,1_{\{|\Delta Z_{u}|\leq 1\}}.

Since the coordinates cannot jump at the same time we can split
J_{1}(t)
into
d
parts

J_{1}(t)=\sum_{j=1}^{d}J^{j}_{1}(t),

where

J^{j}_{1}(t)=\sum_{u\leq t}g(u)\left[f(X_{u-}+a_{j}(X_{u-})\Delta Z^{(j)}_{u})-f(X_{{u-}})-\nabla f(X_{u-})\cdot a_{j}(X_{u-})\Delta Z^{(j)}_{u}\,1_{\{|\Delta Z^{(j)}_{u}|\leq 1\}}\right]

.
Let, for

F_{j}(w,u)=g(u)\left[f(X_{u-}+a_{j}(X_{u-})w)-f(X_{{u-}})-\nabla f(X_{u-})\cdot a_{j}(X_{u-})w1_{\{|w|\leq 1\}}\right].

Note that

is a predictable process. Hence
F_{j}(w,u)

is jointly measurable with respect to the product of Borel
\sigma
-field and a predictable

\sigma
-field generated by the process

. Note that

\mathds{E}\int_{0}^{t}\int_{\mathds{R}}|F_{j}(w,u)|\frac{1}{|w|^{1+\alpha}}dw<\infty.

This is justified by the following estimate

where

. This follows from the fact that
\bar{U}\subset D
and

.

By the compensation formula

M_{j}(t)=F_{j}(\Delta Z^{(j)}_{t},t)-\int_{0}^{t}\int_{\mathds{R}}F_{j}(w,u)\frac{\mathcal{A}_{\alpha}}{|w|^{1+\alpha}}dwdu

is a martingale.

Next, note that

M_{j}(t)=J^{j}_{1}(t)-\int_{0}^{t\wedge\tau_{U}}\mathcal{L}_{j}f(X_{{u}})du,

where

\mathcal{L}_{j}f(x)=\mathcal{A}_{\alpha}\int_{\mathds{R}\setminus\{0\}}\left(f(x+a_{j}(x)w)-f(x)-\nabla f(x)\cdot a_{j}(x)w1_{\{|w|\leq 1\}}\right)\frac{dw}{|w|^{1+\alpha}}.

Summing up we see that

J_{1}(t)-\int_{0}^{t\wedge\tau_{U}}\mathcal{L}f(X_{{u}})du

is a martingale.
Since
I_{1}(t)
is a martingale, we arrive at the conclusion of the theorem.
∎

We say that a function

Corollary 3.2

Lemma 3.8
.

Let
z_{0}\in\mathds{R}^{d}
and let
y\in\mathds{R}^{d}

Proof.

We may assume that
z_{0}=0

i\in\{1,2,\dots,d\}

a=a_{i}=a_{i}(y)

v

We would like to solve
|y+av|=R

|y+av|^{2}=R^{2}
which reads

|y|^{2}+2v(y\cdot a)+|a|^{2}v^{2}=R^{2}.

Denote
\lambda^{2}=|y|^{2}-(a/|a|\cdot y)^{2}
.
Then we can write the positive solutions as

(32)

v_{+}(R)=\frac{1}{|a|}\left(\sqrt{R^{2}-\lambda^{2}}-(a/|a|\cdot y)\right),

while the negative solution is

(33)

v_{-}(R)=\frac{1}{|a|}\left(-\sqrt{R^{2}-\lambda^{2}}-(a/|a|\cdot y)\right).

Hence

\displaystyle v_{+}(R+\eta)-v_{+}(R)

\displaystyle=

\displaystyle\frac{1}{|a|}\left(\sqrt{(R+\eta)^{2}-\lambda^{2}}-\sqrt{R^{2}-\lambda^{2}})\right)

\displaystyle=

\displaystyle\frac{1}{|a|}\frac{(R+\eta)^{2}-R^{2}}{\sqrt{(R+\eta)^{2}-\lambda^{2}}+\sqrt{R^{2}-\lambda^{2}})}

Observe that for
|y|\leq r\leq(4/5)R
we have

\frac{3}{5}(R+\eta)\leq\sqrt{(R+\eta)^{2}-\lambda^{2}}+\sqrt{R^{2}-\lambda^{2}}\leq(R+\eta)+R.

which implies

\frac{\eta}{|a|}\leq v_{+}(R+\eta)-v_{+}(R)\leq 4\frac{\eta}{|a|}.

Similarly

\frac{\eta}{|a|}\leq v_{-}(R)-v_{-}(R+\eta)\leq 4\frac{\eta}{|a|}.

Next, if

R\leq|y+av|\leq R+\eta
, by the triangle inequality, we have

\frac{R-r}{|a|}\leq|v|\leq\frac{R+2r}{|a|}.

Let
P_{i}=\{v:\,R\leq|y+va_{i}|\leq R+\eta\}=[v_{-}(R+\eta),v_{-}(R)]\cup[v_{+}(R),v_{+}(R+\eta)]

\mu(\{w\in\mathds{R}^{d}:\,R\leq|y+wA(y)|\leq R+\eta\})=\mathcal{A}_{\alpha}\sum_{i=1}^{d}\int_{P_{i}}\frac{1}{|v|^{1+\alpha}}dv\approx\sum_{i=1}^{d}|a_{i}|^{\alpha}\frac{\eta}{R^{1+\alpha}}.
