Adaptive inference and function vectors in deep transformers
Ravin Raj, Gautam Reddy

Abstract
Transformers are widely used as a general-purpose substrate for learning complex correlations between a large collection of coupled variables, but their internal mechanisms have remained mysterious. We introduce a theory of a deep transformer as a mean-field interacting system that implements distributed inference, subject to constraints on communication, locality and depth. We show that such a system can exploit internal state representations (‘function vectors’) to infer a latent context variable at increasingly finer scales over its layers. In an in-context regression task, the theory predicts a non-trivial relationship between non-Gaussian, hierarchical structure in the latent context variable, and transformer depth. Predictions are tested using constrained linear attention transformers and demonstrate adaptive inference in deep architectures. Feedforward blocks and depth enable transformers to implement a much richer class of in-context learning algorithms than previously described.

The flexibility of a transformer arises from two operations that are repeated across layers. The first is a global interaction, mediated by self-attention, in which each vector (or ‘token’) in the input sequence extracts information from other tokens through learned interaction maps. The second is a local nonlinear computation, usually implemented as a multi-layer perceptron (MLP), which acts independently and identically on each vector.
Once its parameters are optimized, a transformer can adapt its predictions to a novel sequence or dataset in a single forward pass, without further updates to its parameters. This phenomenon, called in-context learning, suggests that the transformer has learned a generic procedure for inferring structure from context

In this Letter, we propose a theory of collective computation mediated by function vectors in multi-layer (deep) transformers.
The theory is built on the hypothesis that a transformer, once optimized on a large dataset, implements distributed inference over a set of vectorized tokens, subject to architectural constraints on communication, locality, and depth.
The theory makes specific predictions about the role of non-Gaussianity in latent context variables, and the value offered by depth and MLP blocks. These predictions are confirmed in numerical experiments with constrained linear attention transformers.

II
Results

We begin by considering a standard in-context learning paradigm
18
;
2
;
55
;
31
. We wish to learn the joint distribution of a collection of
N
random variables (‘tokens’),
\mathcal{Z}_{N}=\{\bm{z}_{1},\bm{z}_{2},\dots,\bm{z}_{N}\}
. The tokens are coupled by a latent context variable
\bm{\theta}
, drawn from
\rho_{0}(\bm{\theta})
. That is,
P(\{\bm{z}_{i}\})=\int d\bm{\theta}\rho_{0}(\bm{\theta})\prod_{i}p(\bm{z}_{i}|\bm{\theta})
. The model is trained to predict a masked out component in a separate query token using the context
\mathcal{Z}_{N}
. Specifically, each token is split into two components,
\bm{z}=(\bm{x},\bm{y})
, where
p(\bm{z}|\bm{\theta})=q(\bm{x}|\bm{\theta})\pi(\bm{y}|\bm{x},\bm{\theta})
. Given
\mathcal{Z}_{N}
and an independently drawn query token
\bm{x}
from the same
\bm{\theta}
, the model is trained to construct a predictive distribution
\hat{\pi}(\bm{y}|\bm{x},\mathcal{Z}_{N})\approx\pi(\bm{y}|\bm{x},\bm{\theta})
by optimizing a prediction loss
\langle\mathcal{L}(\hat{\pi})\rangle
.
\mathcal{L}
is typically a cross-entropy loss or a mean-squared-error loss, and the expectation is over samples of
\bm{\theta}\sim\rho_{0}
, a new set of contextual tokens
\mathcal{Z}_{N}
given
\bm{\theta}
, and a new query
\bm{x}\sim q(.|\bm{\theta})
.

We introduce a model for distributed Bayesian inference mediated by mean-field interactions between a collection of tokens (Figure
1
). The model consists of
L
layers, where each layer is a round of interactions between tokens and a local nonlinear operation that processes each token separately. Importantly, interactions are constrained to a channel dimension
d
. We assume a common masking scheme where the context tokens cannot interact with the query, whereas the query can access the shared communication channel among the context tokens. We first show how this model can implement adaptive inference and later map this model to a transformer architecture with a simplified attention operation.

First, suppose
L=1
. Since
\bm{\theta}
is a shared variable, the tokens should exchange information to perform inference. We assume interactions are mediated through a shared pool:

\displaystyle\bm{\varphi}_{1}=\frac{1}{N}\sum_{i=1}^{N}\bm{\lambda}_{1}(\bm{z}_{i}),

(1)

where
\bm{\lambda}_{1}
is a
d
-dimensional nonlinear embedding of each token and
\bm{\varphi}_{1}
is a globally accessible statistic that carries information about
\bm{\theta}
. The query
\bm{x}
can access
\bm{\varphi}_{1}
to form a posterior
\rho(\bm{\theta}|\bm{x},\bm{\varphi}_{1})
and thereby generate a predictive distribution
\hat{\pi}(\bm{y}|\bm{x},\mathcal{Z}_{N})=\int d\bm{\theta}\rho(\bm{\theta}|\bm{x},\bm{\varphi}_{1})\pi(\bm{y}|\bm{x},\bm{\theta})
. Since information about the context is shared to the query entirely through
\bm{\varphi}_{1}
, we call
\bm{\varphi}_{1}
the
function vector
corresponding to the context
\mathcal{Z}_{N}
. This definition of a function vector aligns with empirically motivated definitions of function/task vectors
48
;
24
;
22
: an internal representation of a model is deemed a function vector if patching in the function vector from context
\mathcal{Z}_{N}
into a different context
\mathcal{Z}^{\prime}_{N}
produces a response to a novel query
\bm{x}
in context
\mathcal{Z}^{\prime}_{N}
that aligns with context
\mathcal{Z}_{N}
. In other words, a function vector is a compact summary of the information in the context for predicting the target
\bm{y}
for any novel query
\bm{x}
.

Now, suppose
L\geq 1
. After the first
\ell
layers, define

\displaystyle\bm{\Phi}_{\ell}=\bm{\varphi}_{1}\oplus\bm{\varphi}_{2}\oplus\dots\oplus\bm{\varphi}_{\ell},\qquad\bm{\Phi}_{0}=\varnothing,

(2)

where
\oplus
denotes a direct sum of vectors and
\bm{\varphi}_{\ell+1}=\frac{1}{N}\sum_{i=1}^{N}\bm{\lambda}_{\ell+1}(\bm{z}_{i},\bm{\Phi}_{\ell})
. Importantly,
\bm{\Phi}_{\ell}
acts as a state variable for implementing adaptive inference for the following reasons.
Let us say we want to adaptively select the embedding at the next layer
\bm{\lambda}_{\ell+1}
to optimize the final prediction loss after
L
rounds of interaction. One may imagine, however, that making this choice requires keeping track of the embeddings at all preceding layers,
\bm{\lambda}_{1},\bm{\lambda}_{2},\dots,\bm{\lambda}_{\ell}
(which, recall, are functions rather than statistics). Fortunately, this is not necessary;
\bm{\Phi}_{\ell}
preserves all statistics acquired so far, and because the embedding at each layer is chosen as a function of the previous state, it also implicitly records the choices of embeddings
\{\bm{\lambda}_{1:\ell}\}
that produced those statistics.

To see how
\bm{\Phi}_{\ell}
can be used to choose
\bm{\lambda}_{\ell+1}
, let
\hat{\pi}_{L}(\bm{y}|\bm{x},\bm{\Phi}_{L})=\int d\bm{\theta}\,\rho(\bm{\theta}|\bm{x},\bm{\Phi}_{L})\pi(\bm{y}|\bm{x},\bm{\theta})

be the predictive distribution after the final layer. We define the terminal value
V_{L}(\bm{\Phi}_{L})=\int d\bm{\theta}\rho(\bm{\theta}|\bm{\Phi}_{L})\int d\bm{z}p(\bm{z}|\bm{\theta})\mathcal{L}(\hat{\pi}_{L})
, which is the expected loss averaged over the posterior of possible latent context variables
\bm{\theta}
and queries
\bm{x}
.

For
\ell<L
, write
\bm{\varphi}
for the random statistic generated by a candidate next-layer embedding
\bm{\lambda}
, and let

P_{\bm{\lambda}}(\bm{\varphi}|\bm{\Phi}_{\ell})
denote its conditional distribution.
P_{\bm{\lambda}}(\bm{\varphi}|\bm{\Phi}_{\ell})
implicitly includes an average over all possible contexts
\mathcal{Z}_{N}
compatible with
\bm{\Phi}_{\ell}
. The optimal value formally satisfies a dynamic programming equation solved using backward induction:

\displaystyle V_{\ell}(\bm{\Phi}_{\ell})=\min_{\bm{\lambda}}\left\langle V_{\ell+1}(\bm{\Phi}_{\ell}\oplus\bm{\varphi})\right\rangle_{\bm{\varphi}\sim P_{\bm{\lambda}}(\cdot|\bm{\Phi}_{\ell})}.

(3)

This equation is generally difficult to solve, but shows that the optimal embedding
\bm{\lambda}_{\ell+1}
, which is the minimizer in Eq. (
3
), should be interpreted as an experimental design strategy for adaptive inference
11
;
14
. At layer
\ell+1
, the model then appends the corresponding statistic
\bm{\varphi}_{\ell+1}
to the state, so that
\bm{\Phi}_{\ell+1}=\bm{\Phi}_{\ell}\oplus\bm{\varphi}_{\ell+1}
. After
L
layers, the query
\bm{x}
uses
\bm{\Phi}_{L}
to form
\hat{\pi}_{L}(\bm{y}|\bm{x},\bm{\Phi}_{L})
. We call
\bm{\Phi}_{L}
the function vector for a multi-layer model.

Mapping this model to the transformer architecture, this theory assigns two distinct computational roles to the MLP blocks at optimality (given the above constraints on interactions): (i) as implementing the communication strategy (or a ‘router’) that chooses which information in its token should be conveyed to the other tokens, i.e.,
(\bm{z},\bm{\Phi}_{\ell})\to\bm{\lambda}_{\ell+1}
and (ii) as a decoder that processes information gathered from other tokens to generate a prediction,
(\bm{x},\bm{\Phi}_{L})\to\hat{\pi}
. The attention operation mediates interactions and builds the function vector by pooling information across tokens,
\{\bm{\lambda}_{\ell}(\bm{z}_{i},\bm{\Phi}_{\ell-1})\}\to\bm{\varphi}_{\ell}
. The model further requires that the residual stream retains information about the original token
\bm{z}_{i}
whereas the function vector is written into an independent subspace with at least
dL
dimensions. We discuss a constrained linear attention transformer that implements this procedure further below.

We now show that the model predicts a non-trivial relationship between the structure of the prior
\rho_{0}
and the advantage offered by depth and MLP blocks in transformers. We examine this relationship in more detail in an in-context linear regression task
18
. In each context, we sample
\bm{\theta}\sim\rho_{0}
, and generate tokens such that
\bm{x}\sim\mathcal{N}(\bm{0},I_{K})
,
y=\bm{\theta}^{\top}\bm{x}+\eta
, where
y
is a scalar and
\eta
is noise with variance
\sigma^{2}
. For a context
\mathcal{Z}_{N}
drawn from
\bm{\theta}
, the loss is
\mathcal{L}=(\bm{\theta}^{\top}\bm{x}-\hat{y}(\bm{x},\mathcal{Z}_{N}))^{2}
, where
\hat{y}(\bm{x},\mathcal{Z}_{N})
is the predicted output for query
\bm{x}
. We take
N\to\infty
and the noise variance is scaled by fixing
\sigma^{2}/N=\tau^{2}
to retain noise in this limit.

Consider embeddings of the form
\bm{\lambda}_{\ell}=y\bm{W}_{\ell}\bm{x}
. The rows of
\bm{W}_{\ell}
form the subspace along which
\bm{\theta}
is measured, and the function vectors are noisy projections:
\bm{\varphi}_{\ell}=\bm{W}_{\ell}(\bm{\theta}+\bm{\xi})
with
\bm{\xi}\sim\mathcal{N}(\bm{0},\tau^{2}I_{K})
fixed across all layers. The function vector at layer
\ell
is
\bm{\Phi}_{\ell}=\bm{A}_{\ell}(\bm{\theta}+\bm{\xi})
, where
\bm{A}_{\ell}=\bm{W}_{1}\oplus\bm{W}_{2}\oplus\dots\oplus\bm{W}_{\ell}
. For an adaptive strategy,
\bm{A}_{\ell}
depends on
\bm{\Phi}_{\ell-1}
. The Bayesian minimum mean squared error (MMSE) loss averaged over query tokens for a given
\bm{\Phi}_{L}

is
\text{Tr}(\bm{C}_{\bm{\theta}|\bm{\Phi}_{L}})
, where
\bm{C}_{\bm{\theta}|\bm{\Phi}_{L}}
is the covariance of the Bayesian posterior
\rho(\bm{\theta}|\bm{\Phi}_{L})
. The total MMSE loss is
\langle\text{Tr}(\bm{C}_{\bm{\theta}|\bm{\Phi}_{L}})\rangle
, averaged over contexts
\mathcal{Z}_{N}
. The total communication budget
M=dL
is fixed.

Gaussian prior.
Let us first consider a Gaussian prior
\bm{\theta}\sim\mathcal{N}(\bm{0},\bm{C}_{0})
, for which

\bm{C}_{\bm{\theta}|\bm{\Phi}_{\ell}}=\bm{C}_{0}-\bm{C}_{0}\bm{A}_{\ell}^{\top}\left[\bm{A}_{\ell}(\bm{C}_{0}+\tau^{2}I_{K})\bm{A}_{\ell}^{\top}\right]^{\dagger}\bm{A}_{\ell}\bm{C}_{0}
(End Matter). This implies
\text{Tr}(\bm{C}_{\bm{\theta}|\bm{\Phi}_{L}})
does not depend on the function vector
\bm{\Phi}_{L}
. The expected posterior covariance is fully determined by the choices of which measurements the strategy chooses in subsequent layers rather than the observed outcomes of measurements. The optimal adaptive strategy at layer
\ell
is thus to pick a
\bm{W}_{\ell+1}
with
d
rows in the span of the top
d(L-\ell)
eigenvectors of
\bm{C}_{\bm{\theta}|\bm{\Phi}_{\ell}}
. However, the total MMSE loss from this adaptive strategy is identical to the non-adaptive strategy of choosing
\bm{A}_{L}
from the top
dL
eigenvectors of
\bm{C}_{0}
from the outset. Thus, given a communication budget
M
,
L
layers of channel dimension
d
cannot outperform a single layer with channel dimension
dL
.

Tree prior.
Next, we construct a hierarchically structured prior where depth does indeed offer a significant advantage. Let

be a balanced binary tree of depth

\displaystyle\bm{\theta}(\sigma)=\kappa\sum_{m=0}^{h-1}\alpha^{m/2}s_{m+1}\bm{e}_{s_{1}s_{2}\dots s_{m}},

where

\kappa

\bm{\theta}
, and
\bm{e}_{s_{1}s_{2}\dots s_{m}}
is the coordinate of internal node
s_{1}s_{2}\dots s_{m}

\bm{A}_{L}
as the top
M

have variance proportional to
\left(\alpha/2\right)^{m}
. The top eigenvectors are the shallowest tree coordinates. Because the multiplicity at level

is
2^{m}

\displaystyle\bm{\mu}_{m}=2^{-m/2}\sum_{v\in\mathcal{V}_{m}}\bm{e}_{v},

where

\bm{\mu}_{m}^{\top}\bm{\theta}(\sigma)=\kappa(\sqrt{\alpha/2})^{m}s_{m+1}
. If
\bm{A}_{L}=\bm{\mu}_{0}\oplus\bm{\mu}_{1}\oplus\dots\oplus\bm{\mu}_{M-1}

Now, consider an adaptive strategy. The optimal adaptive strategy is difficult to compute, but a simpler heuristic is sufficient to explain why depth is useful. Assume
d=1
(so
L=M
). The heuristic strategy first measures the root coordinate
e_{\varnothing}
. If
\varphi_{1}
is positive, the next measurement routes to the
+1
child, and otherwise to the
-1
child. Repeating this procedure, at layer
\ell
, the strategy measures the coordinate of the node selected by the previous signs and routes to the next child according to the sign of that noisy measurement. Thus, the
M
measurements trace a data-dependent path through the tree until depth
M
, which suggests an MMSE loss that scales as
\alpha^{M}
. Noise will eventually limit the level to which spins can be resolved, but crucially, noise now acts only along a single axis. In this case, a spin cannot be resolved when
\kappa\alpha^{m/2}\lesssim\tau
, which leads to a cutoff
m^{\star}_{\text{ada}}\approx 2\log(\tau/\kappa)/\log\alpha
. Thus, the MMSE loss
\sim\alpha^{\min(M,m_{\text{ada}}^{\star})}
still decays exponentially but has a higher cutoff.

\displaystyle\bm{\varphi}_{\ell}

\displaystyle=\frac{1}{N}\sum_{j=1}^{N}\left(\bm{V}_{\ell}\bm{z}_{j}\right)\odot\left(\bm{K}_{\ell}\bm{z}_{j}\right),\quad\bm{K}_{\ell}=\bar{\bm{\phi}}_{\ell}(\bar{\bm{p}}_{\ell}),

\displaystyle\bm{p}_{\ell+1}

\displaystyle=\bm{p}_{\ell}+\frac{1}{\sqrt{d}}\,\bm{O}_{\ell}\left(\bm{\varphi}_{\ell}\odot\bm{Q}_{\ell}\bm{p}_{\ell}\right),

(6)

III
Discussion

A prominent view is that in-context learning emulates Bayesian inference over a latent context variable
33
;
52
, whereas mechanistic studies of in-context linear regression have shown how attention circuits can implement algorithms such as preconditioned gradient descent
2
;
36
;
55
. We make progress towards reconciling the gap between these two perspectives by showing that deep transformers can implement Bayesian inference as a distributed, adaptive, layerwise procedure: function vectors act as compressed state variables, MLP blocks choose which statistic should be measured next, and attention pools that statistic across the context. This mechanism places function vectors
48
;
24
;
25
;
53
;
22
in a circuit-level framework and shows that depth and MLP blocks enable a much richer class of in-context learning algorithms than preconditioned gradient descent.

The theory ignores a key element of typical transformer architectures, softmax attention, which allows tokens to retrieve information from specific tokens in the context at the expense of a quadratic scaling of computation with context size
32
. Softmax attention is analogous to an implementation of a key-value memory over the context
8
;
46
, and plays an important role in implementing attention-based circuit computations for in-context learning
34
;
7
;
42
;
22
. The pooling-based operation in our theory is linear in context size while respecting exchangeability
15
;
54
;
17
, namely, permutation invariance of the data conditional on the latent context variable, and thus may be sufficient to implement in-context learning in such scenarios. Recent analyses that treat self-attention as an interacting-particle system similarly emphasize a collective description of token dynamics, but focus on the evolution of the empirical distribution of token representations and the emergence of clustering or metastable macroscopic states
20
;
10
;
44
. In a complementary direction, in-context denoising identifies regimes in which attention implements a context-dependent associative-memory or score-like denoising update
46
;
43
. Integrating these perspectives with the constrained Bayesian framework developed here may clarify how transformers combine local memory retrieval with adaptive inference using feedforward blocks.

VI.2
Bayesian MMSE of the posterior

For the linear regression task
y=\bm{\theta}^{\top}x
, the posterior mean estimator given the function vector
\bm{\Phi}
is

\hat{\bm{\theta}}(\bm{\Phi})=\int\differential\bm{\theta}\,\bm{\theta}\rho(\bm{\theta}\mid\bm{\Phi}).

(7)

The query-averaged squared prediction error conditioned on
\bm{\Phi}
is

\displaystyle\left\langle(y-\hat{y})^{2}\right\rangle_{x,\bm{\theta}|\bm{\Phi}}

\displaystyle=\left\langle[(\bm{\theta}-\hat{\bm{\theta}}(\bm{\Phi}))^{\top}x]^{2}\right\rangle_{x,\bm{\theta}|\bm{\Phi}}

(8)

\displaystyle=\left\langle x^{\top}(\bm{\theta}-\hat{\bm{\theta}}(\bm{\Phi}))(\bm{\theta}-\hat{\bm{\theta}}(\bm{\Phi}))^{\top}x\right\rangle_{x,\bm{\theta}|\bm{\Phi}}.

(9)

Using
\mathbb{E}_{x}[xx^{\top}]=I_{K}
, we thus obtain

\displaystyle\left\langle(y-\hat{y})^{2}\right\rangle_{x,\bm{\theta}|\bm{\Phi}}

\displaystyle=\Tr\quantity[\left\langle(\bt-\hat{\bt}(\bm{\Phi}))(\bt-\hat{\bt}(\bm{\Phi}))^\top\right\rangle]

\displaystyle=\Tr(\bm{C}_{\bt\mid\bm{\Phi}}).

(10)

VI.3
Posterior covariance for the Gaussian prior

We set up the Gaussian prior with
\theta\sim\rho_{0}=\mathcal{N}(\bm{0},\bm{C}_{0})
and suppose that the accumulated function vector after
\ell
layers is a noisy linear measurement

\bm{\Phi}_{\ell}=\bm{A}_{\ell}(\bm{\theta}+\bm{\xi}),\quad\bm{\xi}\sim\mathcal{N}(0,\tau^{2}I_{K}),

(11)

where
\bm{A}_{\ell}=\bm{W}_{1}\oplus\bm{W}_{2}\oplus\cdots\oplus\bm{W}_{\ell}
. Since
\bm{\theta}
and
\bm{\Phi}_{\ell}
are jointly Gaussian, the posterior
\rho(\bm{\theta}\mid\bm{\Phi}_{\ell})
is also Gaussian. Its covariance reads

\bm{C}_{\bm{\theta}|\bm{\Phi}}=\bm{C}_{0}-\mathrm{Cov}(\bm{\theta},\bm{\Phi}_{\ell})\mathrm{Cov}(\bm{\Phi}_{\ell},\bm{\Phi}_{\ell})^{\dagger}\mathrm{Cov}(\bm{\Phi}_{\ell},\bm{\theta}).

(12)

The required covariances are

\displaystyle\mathrm{Cov}(\bm{\theta},\bm{\Phi}_{\ell})

\displaystyle=\mathrm{Cov}(\bm{\Phi}_{\ell},\bm{\theta})^{\top}=\bm{C}_{0}\bm{A}_{\ell}^{\top},

(13)

\displaystyle\mathrm{Cov}(\bm{\Phi}_{\ell},\bm{\Phi}_{\ell})

\displaystyle=\bm{A}_{\ell}(\bm{C}_{0}+\tau^{2}I_{K})\bm{A}_{\ell}^{\top}.

(14)

Plugging these in returns

\bm{C}_{\bm{\theta}|\bm{\Phi}_{\ell}}=\bm{C}_{0}-\bm{C}_{0}\bm{A}_{\ell}^{\top}\left[\bm{A}_{\ell}(\bm{C}_{0}+\tau^{2}I_{K})\bm{A}_{\ell}^{\top}\right]^{\dagger}\bm{A}_{\ell}\bm{C}_{0},

(15)

which is the expression used in the main text.

VI.4
MMSE loss of different strategies for the tree prior

The tree prior is uniform over leaves
\sigma=s_{1}s_{2}\dots s_{h}
of a depth
h
balanced binary tree with
s_{m}=\pm 1
, and:

\displaystyle\bm{\theta}(\sigma)=\kappa\sum_{m=0}^{h-1}\alpha^{m/2}s_{m+1}\bm{e}_{s_{1}s_{2}\dots s_{m}},\quad\kappa=\sqrt{\frac{1-\alpha}{1-\alpha^{h}}}.

(16)

Each
\bm{e}_{s_{1}s_{2}\dots s_{m}}
is an independent coordinate for a total of
2^{h}-1
coordinates. Suppose we perform a measurement
\bm{W}
, which is an
M\times K
matrix such that
\bm{W}\bm{W}^{\top}=I_{M}
. The function vector given
\bm{\theta}\sim\rho_{0}
is
\bm{\Phi}=\bm{W}(\bm{\theta}+\bm{\xi})
, where
\bm{\xi}\sim\mathcal{N}(\bm{0},\tau^{2}I_{K})
. Given the posterior covariance
\bm{C}_{\bm{\theta}|\bm{\Phi}}
, the MMSE loss for a given
\bm{W}
is

\displaystyle\mathcal{L}(\bm{W})=\langle\text{Tr}(\bm{C}_{\bm{\theta}|\bm{\Phi}})\rangle_{\bm{\xi},\bm{\theta}}=\langle\text{Tr}(\bm{C}_{\bm{\theta}(\sigma)|\bm{W}(\bm{\theta}(\sigma)+\bm{\xi})})\rangle_{\bm{\xi},\sigma}.

(17)

The posterior over
\sigma
given
\bm{\Phi}
is:

\displaystyle\rho_{\bm{W}}(\sigma|\bm{\Phi})=\frac{e^{-||\bm{\Phi}-\bm{W}\bm{\theta}(\sigma)||^{2}/2\tau^{2}}}{\sum_{\sigma^{\prime}}e^{-||\bm{\Phi}-\bm{W}\bm{\theta}(\sigma^{\prime})||^{2}/2\tau^{2}}}.

(18)

The posterior mean and trace of the covariance are

\displaystyle\bar{\bm{\theta}}(\bm{\Phi})

\displaystyle=\sum_{\sigma}\bm{\theta}(\sigma)\rho_{\bm{W}}(\sigma|\bm{\Phi}),

(19)

\displaystyle\text{Tr}\left(\bm{C}_{\bm{\theta}|\bm{\Phi}}\right)

\displaystyle=\sum_{\sigma}||\bm{\theta}(\sigma)-\bar{\bm{\theta}}(\bm{\Phi})||^{2}\rho_{\bm{W}}(\sigma|\bm{\Phi}).

(20)

The loss is therefore

\displaystyle\mathcal{L}(\bm{W})

\displaystyle=\left\langle 2^{-h}\sum_{\sigma}\text{Tr}\left(\bm{C}_{\bm{\theta}|\bm{W}(\bm{\theta}(\sigma)+\bm{\xi}))}\right)\right\rangle_{\bm{\xi}}

(21)

In practice, we sample a large batch of
\bm{\xi}
and evaluate the average of the term inside for a given
\bm{W}
over this batch.

Optimized non-adaptive.
In the optimized non-adaptive strategy, we restrict the measurement matrix to a hybrid subspace. Let

\displaystyle\mathcal{H}

\displaystyle=\text{span}\left(\{\bm{e}_{v}:\text{depth}(v)<g\}\oplus\{\bm{\mu}_{m}\}_{m=0}^{h-1}\right),

(22)

where

\displaystyle\bm{\mu}_{m}=2^{-m/2}\sum_{v\in\mathcal{V}_{m}}\bm{e}_{v},

(23)

where the first set contains the top
2^{g}-1
prior-PC coordinates (with
g=4
in Figure
2
b). We compute a row-orthonormal basis
\bm{D}
for
\mathcal{H}
and take
\bm{W}=\bm{U}\bm{D}
with
\bm{U}\bm{U}^{\top}=I_{M}
. For fixed
\bm{U}
, all leaves are enumerated exactly in the posterior, and the Monte Carlo objective is

\displaystyle J(\bm{U})=\left\langle\left\|\sum_{\sigma}\bm{\theta}(\sigma)\rho_{\bm{U}\bm{D}}\!\left(\sigma\,\middle|\,\bm{U}\bm{D}(\bm{\theta}(\sigma_{0})+\bm{\xi})\right)\right\|^{2}\right\rangle_{\sigma_{0},\bm{\xi}}.

(24)

Since
||\bm{\theta}(\sigma)||=1
, minimizing the MMSE is equivalent to maximizing
J(\bm{U})
. We optimize
\bm{U}
using simultaneous perturbation stochastic approximation (SPSA) on the row-orthonormal constraint
\bm{U}\bm{U}^{\top}=I_{M}
. At each step, for a random sign matrix
\Delta
, we evaluate
J
at the two re-orthonormalized perturbations
\mathcal{R}(\bm{U}\pm c_{k}\Delta)
and form the finite-difference estimate
\bm{G}
. We project
\bm{G}
onto the space of all matrices
\bm{Z}
such that
\bm{Z}\bm{U}^{\top}+\bm{U}\bm{Z}^{\top}=0
(known as the Stiefel tangent space)
using
\Pi_{\bm{U}}(\bm{G})=\bm{G}-\operatorname{Sym}(\bm{G}\bm{U}^{\top})\bm{U}
, update
\bm{U}\leftarrow\bm{U}+a_{k}\Pi_{\bm{U}}(\bm{G})
, and re-orthonormalize the rows. Here,
a_{k}=\eta k^{-0.602}
and
c_{k}=\epsilon k^{-0.101}
are the SPSA step-size and perturbation schedules.

Adaptive along tree coordinates.
In this adaptive strategy, first pick
\bm{w}_{1}=\bm{e}_{\varnothing}
. For
\sigma
, we get the first measurement
\varphi_{1}=\kappa s_{1}+\tau\xi_{\varnothing}
, where
\xi_{\varnothing}
is the projection of the noise along
\bm{e}_{\varnothing}
. If
\varphi_{1}>0
, pick
\bm{e}_{+1}
or otherwise pick
\bm{e}_{-1}
. This procedure continues for
M
steps. Let
\hat{\sigma}=\hat{s}_{1}\hat{s}_{2}\dots\hat{s}_{M}
where
\hat{s}_{m}
is the inferred spin at step
m
. Thus,
\bm{\Phi}=\varphi_{1}\oplus\varphi_{2}\oplus\cdots\oplus\varphi_{M}
and
\bm{W}=\bm{e}_{\varnothing}\oplus\bm{e}_{\hat{s}_{1}}\oplus\cdots\bm{e}_{\hat{s}_{M-1}}
. If the wrong side is picked at some step, then every subsequent measurement measures noise. Estimating the loss for this strategy can be simplified by noting that the average loss over samples of
\bm{\xi}
needs to be measured for only one leaf. The rest of the leaves will have identical loss by symmetry.

VI.5
Relation to linear attention transformers

The architecture in Eq. (
6
) can be understood as a constrained linear attention transformer which isolates low-dimensional communication between tokens. Here, we briefly explain how it arises from a standard linear attention update. Consider a residual stream activation
\bm{u}_{i,\ell}\in\mathbb{R}^{D}
for token
i
at layer
\ell
. The standard linear attention update is written as

\bm{u}_{i,\ell+1}=\bm{u}_{i,\ell}+\bm{O}_{\ell}\quantity[\qty(\frac{1}{N}\sum_{j=1}^N (\bm{V}_\ell\bm{u}_{j,\ell})(\bm{K}_\ell\bm{u}_{j,\ell})^\top)\bm{Q}_\ell\bu_{i,\ell}]

(25)

where
\bm{Q}_{\ell},\bm{K}_{\ell},\bm{V}_{\ell},\bm{O}_{\ell}
are learned matrices. We now restrict the model to
d
independent attention heads with query/key dimension 1 each, as opposed to a single attention head with query/key dimension
d
. In this case, each attention head communicates a single scalar channel, and the linear attention update becomes

\displaystyle\bm{u}_{i,\ell+1}

\displaystyle=\bm{u}_{i,\ell}+\bm{O}_{\ell}\quantity[\bvp{\ell} \odot(\bm{Q}_\ell\bu_{i,\ell})],

(26)

\displaystyle\bm{\varphi}_{\ell}

\displaystyle=\frac{1}{N}\sum_{j=1}^{N}(\bm{V}_{\ell}\bm{u}_{j,\ell})\odot(\bm{K}_{\ell}\bm{u}_{j,\ell}),

(27)

where
\bm{\varphi}_{\ell}
is the pooled key-value statistic that acts as a global context-dependent representation of the present information. The elementwise product preserves all
d
communication channels independently, in contrast to the standard matrix-vector contraction which mixes the channels.

We next partition the residual stream into two as

\bm{u}_{i,\ell}=\bm{z}_{i}\oplus\bm{p}_{\ell},

(28)

where
\bm{z}_{i}=(\bm{x}_{i},\bm{y}_{i})
stores the contextual token information and
\bm{p}_{\ell}
is a shared internal workspace that evolves across layers. The workspace
\bm{p}_{\ell}
is identical across all tokens and acts as the state variable which stores a representation of the accumulated information about the context. Only
\bm{p}_{\ell}
is updated across layers, while the token representation
\bm{z}_{i}
remains fixed. Once this separation is made, the useful information for the regression task is contained entirely in
\bm{z}_{i}
, while
\bm{p}_{\ell}
controls how information is processed and routed across layers.

The theory developed in the main text predicts that later measurements should depend on information acquired in earlier layers. To implement this adaptive measurement strategy, we let the key matrix
\bm{K}_{\ell}
depend on the workspace

\bm{K}_{\ell}=\bar{\bm{\phi}}_{\ell}(\bar{\bm{p}}_{\ell}),

(29)

where
\bar{\bm{\phi}}_{\ell}
is a feedforward block (MLP). Thus, the current internal state determines which measurement is performed at the next layer. The update to the workspace thus reads

\bm{p}_{\ell+1}=\bm{p}_{\ell}+\bm{O}_{\ell}\quantity[\bvp{\ell}\odot(\bm{Q}_\ell\bm{p}_\ell)].

(30)

We finally include a factor of
1/\sqrt{d}
as a form of width normalization for the residual update, ensuring that the magnitude of the communicated signal remains
\mathcal{O}(1)
as the channel dimension
d
is varied, leading to the form of Eq. (
6
) in the main text.

VI.6
MMSE loss of a one-layer linear attention transformer.

A one-layer linear attention transformer without MLPs (model C) generates a prediction
\hat{y}(\bm{x};\bm{\theta}+\bm{\xi})=\left(\bm{K}(\bm{\theta}+\bm{\xi})\right)^{\top}\bm{Q}\bm{x}
for a context
\bm{\theta}+\bm{\xi}
and
M\times K
matrices
\bm{Q},\bm{K}
. The loss averaged over queries
\bm{x}
is

\displaystyle\mathcal{L}_{\text{C}}(\bm{Q}^{\top}\bm{K})=\langle||\bm{\theta}-\bm{Q}^{\top}\bm{K}(\bm{\theta}+\bm{\xi})||^{2}\rangle_{\bm{\xi},\bm{\theta}},

(31)

\displaystyle=\text{Tr}((I_{K}-\bm{Q}^{\top}\bm{K})^{\top}(I_{K}-\bm{Q}^{\top}\bm{K})\bm{C}_{0})+\tau^{2}||\bm{Q}^{\top}\bm{K}||^{2}_{F},

(32)

where
\bm{C}_{0}
is the covariance of
\rho

\bm{C}_{0}
and optimizing over rank-
M
matrices
\bm{Q}^{\top}\bm{K}
leads to

\displaystyle\bm{Q}^{\top}\bm{K}=\sum_{i=1}^{M}\frac{\sigma_{i}^{2}}{\sigma_{i}^{2}+\tau^{2}}\bm{e}_{i}\bm{e}_{i}^{\top},

(33)

where
\sigma_{i}^{2}
and

are the

respectively. The minimum achievable loss is

\displaystyle\mathcal{L}_{\text{C}}^{*}=\text{Tr}(\bm{C}_{0})-\sum_{i=1}^{M}\frac{\sigma_{i}^{4}}{\sigma_{i}^{2}+\tau^{2}}.

(34)
