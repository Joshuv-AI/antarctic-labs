Microgrids

 Microgrid Definition

 A group of interconnected loads and distributed energy resources
 within clearly defined electrical boundaries that acts as a single
 controllable entity with respect to the grid.

Source: Ton and MA Smith, “The US Department of Energy’s Microgrid Initiative,” The Electricity Journal Vol 25, No 8, pp 84-94 (2012)

                                                                                                                                        National Laboratory of the Rockies | 9

 Microgrid Sizes and Modes
 Type 1: Microgrid for Backup Only
 • Operates only when the main electric grid is down
 • Generation is sized to cover critical loads only for a limited duration

 Type 2: Always Islanded Microgrid
 • Never connected to the main electric grid (e.g., a remote system far
 from the main grid)
 • Has enough local generation to cover all local load

 Type 3: Hybrid Microgrid
 • Operates grid-connected part of the time and islanded part of the
 time
 • Operation mode determined by factors including costs, main grid
 outage, fuel supply, etc.
 • Has enough local generation to cover all local critical loads, at
 minimum, for a specific duration

Credit: Brooke Marshall-Garcia, Sandia National Laboratory
