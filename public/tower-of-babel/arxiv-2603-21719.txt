Probing How Scalable Table Data Enhances General Long-Context Reasoning
Huaibing Xie, Guoliang Zhao, Yang Liu, Shihan Dou, Siming Huang, Yanling Xiao, Shaolei Wang, Yiting Liu, Cheng Zhang, Shaofan Liu, Pluto Zhou

Abstract
As real-world tasks grow increasingly complex, long-context reasoning has become a core capability for Large Language Models (LLMs). However, few studies explore which data types are effective for long-context reasoning and why. We find that structured table data with periodic structures shows strong potential for long-context reasoning. Motivated by this observation, we mathematically analyze tabular dependency structures using mutual information, revealing periodic non-vanishing dependencies in table data. Furthermore, we systematically analyze the capabilities of structured table data, conduct relevant scaling experiments, and validate its underlying mechanisms for enhancing long-context reasoning, yielding several meaningful insights. Leveraging these insights, we propose a simple yet scalable pipeline(TableLong) for synthesizing high-quality, diverse, and verifiable structured table data to boost long-context reasoning via RL. Extensive experimental results demonstrate that table data significantly enhances the long-context reasoning capability of LLMs across multiple long-context benchmarks (+8.24% on average), and even improves performance on out-of-domain benchmarks (+8.06% on average). We hope that our insights provide practical guidance for effective post-training data to enhance long-context reasoning in LLMs.

Introduction

As real-world tasks become increasingly complex, long-context reasoning has emerged as a fundamental capability of Large Language Models (LLMs)
(
17
)
. Reinforcement Learning (RL) for long-context reasoning requires LLMs to retrieve and ground key information from long-context inputs, and then generate Chain-of-Thought (CoT) reasoning based on the integrated information
(
11
;
27
;
35
;
30
)
. Existing studies on long-context reasoning in LLMs primarily focus on training strategies and methodologies
(
42
;
32
;
5
;
48
;
35
;
30
)
.In addition, some emerging works have started to focus on synthetic data pipelines for long-context reasoning tasks
(
52
;
43
;
49
)
. Furthermore, table data has also been introduced as a benchmark to evaluate long-context capabilities
(
36
)
. However, few studies have analyzed how the intrinsic characteristics of different types of data influence the long-context reasoning capability of LLMs, which holds significant implications for effective post-training data to enhance long-context reasoning in LLMs.

Ideal long-context reasoning data should possess long-range dependencies, scalability, and verifiability. However, natural text, and even some synthetic plain text, often fail to satisfy all of these abilities simultaneously. In contrast, table data with periodic non-vanishing structural property demonstrates strong scalability, verifiability, multi-hop reasoning ability, and knowledge grounding ability, which exhibits strong potential for adapting to long-context reasoning capability in LLMs
(
39
;
14
)
. Therefore, our work aims to investigate the impact of structured table data on the long-context reasoning capability of LLMs and to dissect the underlying mechanisms driving this effect.

To achieve the aforementioned objectives, we first mathematically analyze tabular dependency structures via mutual information, revealing the existence of periodic non-vanishing dependencies. We then validate the mechanisms by which table data enhances long-context reasoning through systematic scaling experiments. Leveraging these insights, we propose a simple yet scalable pipeline(TableLong) for synthesizing high-quality, diverse, and verifiable structured table data to boost long-context reasoning via RL. Specifically, we synthesize diverse SQL tasks with verifiable execution results, applying a consistency-based filter to prune noise and retain challenging samples. By incorporating structured table data into RL training, we observe significant performance improvements across the majority of long-context benchmarks, and further validate its generalization capability on Out-of-Domain (OOD) benchmarks, such as Math (AIME 2025)
(
2
)
and Code (LiveCodeBench)
(
13
)
.
Overall, our key contributions are as follows:

1.

We are the first to mathematically analyze tabular dependency using mutual information, revealing periodic non-vanishing structural property of table data.

2.

We propose a simple yet scalable pipeline for synthesizing high-quality, diverse, and verifiable structured table data tailored for long-context reasoning.

3.

Results demonstrate that table data significantly enhances the long-context reasoning capability of LLMs, generalizes to other domains, and we systematically decompose and analyze it to derive meaningful insights.

2
Mutual Information Analysis of Table Data

Table data is widely used in real-world applications, yet its structural properties for LLM training remain underexplored. Unlike natural language with sequential tokens and decaying contextual relevance, table data exhibits rigid column-wise structures that induce distinct dependency patterns.

We provide an information-theoretic framework to analyze long-context dependencies in table data. We show that tables preserve
periodic non-vanishing
structural dependencies, in contrast to the power-law decay observed in natural language. To our knowledge, this is the first mutual information-based analysis of tabular dependency structures. These properties make table data well suited for training long-context reasoning capability of LLMs.

2.1
Background: Dependency Decay in Natural Language

For natural language sequences, empirical studies
(
19
;
20
)
demonstrate that Mutual Information (MI) between tokens decays polynomially with distance (
d
):

I_{text}(d)\sim C\cdot d^{-\alpha},\quad\text{with }\alpha\approx 0.5

(1)

This power-law decay, which we adopt as a modeling assumption for natural language throughout this work, implies
\lim_{d\rightarrow\infty}I_{text}(d)=0
. A natural question arises:
does table data exhibit the same decay pattern?

2.2
Setup: Table Data and Linearization

A table
\mathcal{T}
is an
n\times m
structure with column headers
\mathcal{H}=\{H_{1},\ldots,H_{m}\}
and cells
\{T_{i,j}\}_{i\in[n],j\in[m]}
, where
[n]:=\{1,\ldots,n\}
and each cell
T_{i,j}
is drawn from a column-specific distribution
P_{j}
. The row-major linearization
\phi:\mathcal{T}\rightarrow W_{1:L}
maps a table to a token sequence
\phi(\mathcal{T})
:

[H_{1},\ldots,H_{m},\underbrace{T_{1,1},\ldots,T_{1,m}}_{\text{row 1}},\underbrace{T_{2,1},\ldots,T_{2,m}}_{\text{row 2}},\ldots,T_{n,m}]

with total length
L=m(n+1)
, where
W_{t}
denotes the
t
-th token. For position
t>m
in the data region, let
\text{col}(t)\in[m]
denote its column index.

For lag
d\in\{1,\ldots,L-m-1\}
, define the average MI over the data region:

\displaystyle\bar{I}_{table}(d)

\displaystyle=\frac{1}{|\mathcal{S}_{d}|}\sum_{t\in\mathcal{S}_{d}}I(W_{t};W_{t+d}),

\displaystyle\mathcal{S}_{d}

\displaystyle=\{t:m<t\leq L-d\}

Our analysis rests on the following assumptions (formal statements in Appendix
A.2
):

(A1)

Column Semantic Consistency
: All cells in column
j
share the same distribution
P_{j}
.

(A2)

Column Distribution Distinctiveness
: Different columns have distinguishable distributions, i.e.,
D_{KL}(P_{j}\|P_{k})>0
for
j\neq k
, where
D_{KL}
denotes the Kullback-Leibler divergence.

We do
not
assume that cells within the same column are conditionally independent; our results hold regardless of intra-column dependencies (see Remark
A.7
in the Appendix).

2.3
Periodic Non-Vanishing Dependencies

We first introduce a key factor. Let
J\sim\text{Uniform}([m])
be a randomly chosen column index.

Definition 2.1

(Same-Column Mutual Information)
.

The same-column MI is defined as:

I^{same}:=I(T_{i,J};T_{k,J})

(2)

As shown in Lemma
A.8
, under Assumptions (A1)–(A2): (i)
I^{same}>0
, and (ii)
I(T_{i,J};T_{k,J})=I^{same}
for any
i\neq k
, i.e., same-column MI is independent of row distance.

The magnitude of
I^{same}
depends on how distinguishable the column distributions are. As characterized in Proposition
A.11
,
I^{same}
is determined by the cross-column variance
\sum_{a}\text{Var}_{j}[P_{j}(a)]
, where
\text{Var}_{j}[\cdot]
denotes variance across columns. When column distributions are highly distinct, this variance is large, yielding larger
I^{same}
.

Theorem 2.2

(Periodic Non-Vanishing Dependency)
.

Under Assumptions (A1)–(A2), for any table with
n
rows and
m
columns:

\bar{I}_{table}(km)=I^{same}>0,\quad\forall k\in\{1,2,\ldots,n-1\}

(3)

That is,
\bar{I}_{table}(d)
attains periodic peaks of constant height
I^{same}
at every multiple of the column count
m
.

Note that non-vanishing property holds
specifically at periodic lags

d=km
; at others, average MI may be smaller.

Corollary 2.3

(Asymptotic Non-Decay)
.

For a sequence of tables with
n\to\infty
rows and fixed
m
columns, under Assumptions (A1)–(A2):

\liminf_{d\rightarrow\infty}\bar{I}_{table}(d)\geq I^{same}>0

(4)

This contrasts starkly with natural language, where
\lim_{d\rightarrow\infty}I_{text}(d)=0
based on Eq. (
1
).

Corollary 2.4

(Asymptotic Dominance over Natural Language)
.

Under the power-law assumption Eq. (
1
) for natural language and Assumptions (A1)–(A2) for tables:

\lim_{k\rightarrow\infty}\frac{\bar{I}_{table}(km)}{I_{text}(km)}=+\infty

(5)

2.4
Effective Dependency Distance

Definition 2.5

(Effective Dependency Distance
(
23
)
)
.

Given threshold
\tau>0
:
D_{eff}(\tau)=\sup\{d:I(d)\geq\tau\}
.

Theorem 2.6

(Effective Distance Comparison)
.

Under the power-law assumption Eq. (
1
) for natural language and Assumptions (A1)–(A2) for tables, for any
\tau\in(0,I^{same})
:

D_{eff}^{table}(\tau)=+\infty,\quad\text{while}\quad D_{eff}^{text}(\tau)<+\infty

(6)

This result shows that for any threshold
\tau<I^{same}
, tabular dependencies exceed
\tau
at infinitely many lags (specifically, at all
d=km
), whereas natural language dependencies eventually fall below
\tau
permanently.

These results indicate that structured table data with periodic non-vanishing structures exhibits strong potential for long-context reasoning.

3
TableLong: a Scalable and Verifiable Pipeline for Long-context Reasoning

In this section, we propose a simple yet scalable pipeline, namely TableLong, to construct high-quality, diverse, and verifiable structured table data, tailored for RL.

3.1
Overview of the Construction Pipeline

As illustrated in Figure
1
, our framework achieves a pipeline to transform hybrid tabular sources into high-quality RL tasks. The pipeline proceeds in three stages:

•

Environment Initialization:
We first aggregate a diverse repository of tables from both open-source datasets and documents, parsing them into executable SQL environments.

•

Sample Construction:
Leveraging these environments, we employ LLMs to generate diverse SQL queries and corresponding natural language questions, and subsequently execute the SQL queries to obtain verifiable answers. We construct each instance as a tuple: (Raw Table, Question, Answer).

•

Verification and Filtration:
We then apply a consistency-based filtration mechanism to prune noise (
P=0
) and triviality (
P=1
), ensuring the selected tasks offer optimal training value.

Figure 1
:
Overview of TableLong: An end-to-end table data construction pipeline for long-context reasoning.

3.2
Environment Setup

To ensure the diversity and realism of the reasoning environment, we construct a hybrid repository by aggregating over 10,000 real-world tables from established datasets (e.g., BIRD
(
16
)
, CoSQL
(
46
)
, Spider
(
47
)
) and extracting scalable table data from information-dense documents via LLMs.

Following rigorous cleaning and sampling, the resulting corpus exhibits high diversity in both content and structure. Thematically, the data spans a broad spectrum of domains, including Finance, Sports, Healthcare, and Science. Linguistically, it covers both English and Chinese. Crucially, the corpus is tailored for long-context reasoning: context lengths range from a few hundred up to 32k tokens, with an average cell density of 5.2 tokens. Furthermore, to support complex structural grounding, the number of tables per instance ranges from single to 30 tables, creating a challenging multi-table environment. Finally, all collected tables are parsed into a unified SQLite database to support executable SQL queries.

3.3
Sample Construction

We generate diverse SQL queries by scalable prompt constraints, targeting
three distinct dimensions
of table tasks for long-context reasoning:

•

Precise Retrieval:
Targeting atomic information locating. We constrain the generation to
SELECT
queries with specific
WHERE
clauses, requiring the model to filter and extract precise values from contexts.

•

Multi-hop Reasoning:
Targeting long-range multi-hop reasoning. We constrain the generation to column-wise aggregation and calculation (e.g.,
SUM
,
AVG
), requiring the model to attend to non-adjacent tokens separated by substantial distances due to table linearization.

•

Grounding:
Targeting query-to-table association. We constrain the generation to multi-table operations (e.g.,
JOIN
), requiring the model to distinguish specific tables distributed across the long context as “grounding”.

Upon generating diverse SQL queries and corresponding natural language questions, we execute the queries to obtain verifiable answers. Finally, we construct each training sample as a triplet: (Raw Table, Question, Answer).

3.4
Verification and Filtration

To ensure appropriate task difficulty, we implement a consistency-based filtration mechanism. For each instance
(x,y_{gt})
, we generate
N
candidate responses using the model and evaluate their correctness against the ground truth
y_{gt}
. Based on the calculated pass rate (
P
), we apply a
dual-sided filter
:

•

Discard
P=0
:
Eliminates tasks that are ambiguous, erroneous, or exceed reasoning capacity.

•

Discard
P=1
:
Prunes trivial tasks that the model has already mastered, ensuring high training efficiency.

•

Retain
0<P<1
:
Preserves non-trivial tasks within the effective learning boundary, offering optimal gradient signals for RL training.

4.2
Main Results

In this subsection, we evaluate the effectiveness of our TableLong in enhancing the general long-context reasoning capabilities of LLMs across multiple OOD general long-context reasoning benchmarks using several open-source backbone models.

(a) Scalable table data is effective for long-context reasoning.
Specifically, as shown in Table
1
, for Deepseek-R1-Distill-Qwen-32B, our TableLong achieves a remarkable improvement, with an average accuracy gain of 8.24% across seven OOD benchmarks of long contexts. Similarly, for other backbones (Qwen3-32B, Qwen2.5-32B-Instruct, and Deepseek-R1-Distill-Qwen-14B), the improvements are 4.94%, 4.79%, and 8.93%, respectively. Deepseek-R1-Distill-Qwen-32B with our TableLong clearly outperforms Qwen-Long-L1 and approaches the performance of Deepseek-v3.1. This demonstrates the robustness of our TableLong in enhancing long-context reasoning capabilities.

(b) Length Scalability: Train short, generalize long.
Table data is inherently scalable in length. To investigate the effect of length scalability of table data on long-context reasoning, we conduct RL training with input lengths of 4k, 8k, and 16k. The results show consistent performance improvements across multiple long-context benchmarks as the length of structured table data scales up. Specifically, for Deepseek-R1-Distill-Qwen-32B, we observe relative gains of 0.48% and 1.39% at 8k and 16k, respectively, compared with the 4k experiment in Figure
8
.
The 14B results are similar, with details in Appendix
D
.

Moreover, we investigate the impact of length scaling on accuracy across different benchmark length ranges in Appendix
E.2
. The results show that TableLong, when trained on sequences within 16k, generalizes effectively to contexts beyond 16k and even up to 128k, with performance further improving as the training length scales.

(c) Significantly improved long-context retrieval.
We adopt the Needle-in-a-Haystack benchmark to evaluate the gains of our TableLong in long-context retrieval, which measures a model’s ability to locate a “needle” embedded at different depths within long documents.

As shown in Figure
3
, compared with Deepseek-R1-Distill-Qwen-14B, our TableLong significantly improves long-context retrieval performance by 31.60%, increasing the retrieval score from 69.30% to 91.20%. Moreover, compared with Deepseek-R1-Distill-Qwen-32B, the retrieval score increases by 13.02%, from 87.95% to 99.40%, approaching near-perfect retrieval performance. These results indicate that structured table data, potentially benefiting from its periodic non-vanishing structural properties, can substantially enhance long-context retrieval for RL-based post-training.

4.3
Decomposing Tabular Capabilities for Long-Context Reasoning

In this subsection, we further decompose the capabilities of tabular data from three perspectives, including structural properties, multi-hop reasoning, and grounding. We also systematically analyze their contributions to the long-context reasoning capabilities of LLMs, yielding several inspiring insights.

4.3.1
structural property

To investigate the effect of the periodic non-vanishing structural properties inherent to table data, we design and conduct experiments from two perspectives: the semantics of table cell contents and the visible delimiter structures of tables, yielding the following insights:

Insight 1

The inherent structure of table data serves as a foundation for long-range dependencies, while semantic content provides the reasoning signal for complex long-context reasoning.

Specifically, we construct “no semantic” table data (Figure
11
) and “no visible delimiters” table data (Figure
12
), with details provided in Appendix
F
.

Figure
4
(a) shows that, relative to the baseline, “no semantic” with simple instruction prompting achieves an average performance improvement of 1.67%, indicating that the enhancement in long-context reasoning mainly stems from the table’s inherent organizational structure, namely its periodic non-vanishing structural properties.

Relative to “Ours”, the “no semantic” with only simple instruction prompting converges rapidly (within approximately 40 steps) in Figure
4
(b), leading to an average performance drop of 6.57%. This indicates that both the semantic content of the table and the complexity of the instructions are also crucial for long-context reasoning.

Insight 2

The visible delimiter structures do not affect the inherent structural properties of tables during RL training.

Figure
4
shows that the “no visible delimiters” setting does not exhibit a significant performance drop compared to “Ours”, with a reduction of about 0.77%, and exhibits a similar asymptotic performance. in the RL reward curve. This indicates that visible delimiter structures do not affect the intrinsic periodic non-vanishing structural properties of tables, which are the key factor.

Moreover, the lower initial reward and consistently inferior performance of “no visible delimiters” suggest that removing visible delimiters makes table data harder for LLMs to interpret during training.

We further randomly replace delimiters with noise text (illustrated in Figure
13
) and observe results that are largely consistent with the “no visible delimiters” setting. This further demonstrates the robustness of table data for RL training.

4.3.2
multi-hop reasoning

Insight 3

Table linearization induces multi-hop reasoning that enhances long-context reasoning, and increasingly multi-hop patterns further strengthen this effect.

We characterize the “multi-hop” reasoning behavior of LLMs by the number of table cells involved in instruction operations, particularly along the column dimension. Specifically, when a two-dimensional table is linearized into a one-dimensional token sequence
\phi(\mathcal{T})
, cells within the same column become widely separated, forcing LLMs to attend to non-adjacent tokens and perform “multi-hop” reasoning. Representative examples are shown in Figure
9
, and further details are in Appendix
F
.

As shown in Table
2
, the model maintains strong long-context reasoning performance even with a small number of involved table cells (46.30% on average for the 0
\sim
30 range). Moreover, scaling up the number of involved cells further improves performance on OOD long-context reasoning benchmarks. These findings suggest that the “multi-hop” property induced by table linearization effectively enhances long-context reasoning, and that increasing task complexity and multi-hop behavior can further strengthen this capability.

4.3.3
grounding

Insight 4

Tables in
\phi(\mathcal{T})
provide “grounding”, and scaling up quantity strengthens these signals, guiding attention to key tokens and improving long-context reasoning.

Similarly, the number of tables in the prompt reflects the “grounding” capability of LLMs. Specifically, multi-table instruction operations compel the model to distinguish tables distributed across long contexts and to
associate
natural language queries with specific tables, making these tables act as sources of “grounding”.

The results show that even a single table enables strong long-context reasoning in Table
3
. As the number of tables scales up, the model achieves better performance on OOD long-context reasoning benchmarks, with gains of +0.45% for 1
\sim
5 tables and +1.7% for “all” tables compared to the single-table setting. This indicates that linearized tables in the token sequence
\phi(\mathcal{T})
act as “grounding” elements that the model need to attend to. As their number scales up, the distributed grounding signals across
\phi(\mathcal{T})
increase, forcing the model to learn to allocate attention to key tokens in the sequence, thereby further enhancing long-context reasoning capability.

Conclusion and Future Work

In this work, we systematically investigate why scalable table data enhances long-context reasoning. Based on these, we propose a simple and scalable pipeline, namely TableLong, for synthesizing high-quality, diverse, and verifiable structured table data to improve long-context reasoning via RL. Specifically, we mathematically analyze tabular dependency structures using mutual information, revealing periodic non-vanishing dependencies in table data, and experimentally validate the underlying mechanisms with comprehensive empirical studies. Extensive results show that table data significantly improves long-context reasoning across multiple benchmarks and generalizes well to diverse OOD tasks. In future work, we will further explore other data types to deepen data-centric understanding of long-context reasoning. We hope our findings provide practical guidance for effective post-training data design in LLMs.

Appendix A
Theoretical Details and Proofs

A.1
Information-Theoretic Preliminaries

Definition A.1

(Mutual Information
(
6
)
)
.

For random variables
X
and
Y
with joint distribution
P_{X,Y}
and marginals
P_{X}
,
P_{Y}
, the mutual information is:

I(X;Y)=D_{KL}(P_{X,Y}\|P_{X}\otimes P_{Y})=\sum_{x,y}P(x,y)\log\frac{P(x,y)}{P(x)P(y)}

(7)

Mutual information is symmetric, non-negative, and equals zero if and only if
X\perp Y
.

Definition A.2

(Kullback-Leibler Divergence)
.

For distributions
P
and
Q
over the same space:

D_{KL}(P\|Q)=\sum_{x}P(x)\log\frac{P(x)}{Q(x)}

(8)

D_{KL}(P\|Q)\geq 0
with equality if and only if
P=Q
.

Definition A.3

(Mixture Distribution)
.

Given column distributions
\{P_{j}\}_{j=1}^{m}
, the mixture distribution is:

Q(v)=\frac{1}{m}\sum_{j=1}^{m}P_{j}(v)

(9)

This is the marginal distribution of a cell
T_{i,J}
when
J\sim\text{Uniform}([m])
.

Definition A.4

(Position-to-Column Mapping)
.

For positions in the data region of a linearized table (
t>m
), define:

\text{col}(t)=((t-m-1)\mod m)+1\in[m]

(10)

A.2
Assumptions

Assumption A.5

(Column Semantic Consistency)
.

All cells in column
j
are drawn from the same distribution:

T_{i,j}\sim P_{j},\quad\forall i\in[n],\,\forall j\in[m]

(11)

Assumption A.6

(Column Distribution Distinctiveness)
.

Different columns have statistically distinguishable distributions:

D_{KL}(P_{j}\|P_{k})>0,\quad\forall j\neq k

(12)

Equivalently, for each pair
j\neq k
, there exists some value
v
such that
P_{j}(v)\neq P_{k}(v)
.

Remark A.7

(On Intra-Column Independence)
.

We do
not
assume
T_{i,j}\perp T_{k,j}\mid j
(conditional independence within columns). Real tables often exhibit intra-column dependencies (e.g., sorted data, time series). Our proofs analyze the conditional independence case to establish a
lower bound
on
I^{same}
; any intra-column dependency strictly increases the mutual information.

A.3
Some Lemmas

Lemma A.8

(Same-Column Pair Mutual Information)
.

Let
J\sim\text{Uniform}([m])
. Under Assumptions
A.5
and
A.6
:

(i)

I^{same}:=I(T_{1,J};T_{2,J})>0

(ii)

For any
i\neq k
:
I(T_{i,J};T_{k,J})=I^{same}

That is, the same-column mutual information is strictly positive and independent of row indices.

Proof.

We prove both parts simultaneously.

Step 1: Marginal distributions.

For any row index
i
, by Assumption
A.5
and
J\sim\text{Uniform}([m])
:

P(T_{i,J}=a)=\sum_{j=1}^{m}P(J=j)P_{j}(a)=\frac{1}{m}\sum_{j=1}^{m}P_{j}(a)=Q(a)

(13)

This holds for all
i
, so all
T_{i,J}
share the same marginal distribution
Q
.

Step 2: Joint distribution.

For any
i\neq k
, conditioning on the column:

P(T_{i,J}=a,T_{k,J}=b)=\sum_{j=1}^{m}P(J=j)\cdot P(T_{i,j}=a,T_{k,j}=b\mid J=j)

(14)

To establish a lower bound independent of intra-column structure, consider the case where
T_{i,j}\perp T_{k,j}\mid j
. Then:

P(T_{i,J}=a,T_{k,J}=b)=\frac{1}{m}\sum_{j=1}^{m}P_{j}(a)P_{j}(b)=:R(a,b)

(15)

Note that
R(a,b)
depends only on the column distributions
\{P_{j}\}
, not on
i
or
k
. If
T_{i,j}\not\perp T_{k,j}\mid j
, the actual joint distribution differs from
R
, but we will show
R\neq Q\otimes Q
, which implies
I(T_{i,J};T_{k,J})>0
in all cases.

Step 3: Comparison with product of marginals.

Under independence, we would have:

Q(a)Q(b)=\frac{1}{m^{2}}\sum_{j=1}^{m}\sum_{l=1}^{m}P_{j}(a)P_{l}(b)

(16)

Consider the diagonal
a=b
:

\displaystyle R(a,a)-Q(a)^{2}

\displaystyle=\frac{1}{m}\sum_{j=1}^{m}P_{j}(a)^{2}-\frac{1}{m^{2}}\left(\sum_{j=1}^{m}P_{j}(a)\right)^{2}

\displaystyle=\frac{1}{m^{2}}\left[m\sum_{j=1}^{m}P_{j}(a)^{2}-\left(\sum_{j=1}^{m}P_{j}(a)\right)^{2}\right]

\displaystyle=\frac{\text{Var}_{j}[P_{j}(a)]}{m}

(17)

where
\text{Var}_{j}[P_{j}(a)]=\frac{1}{m}\sum_{j}P_{j}(a)^{2}-\left(\frac{1}{m}\sum_{j}P_{j}(a)\right)^{2}
is the variance of
P_{j}(a)
across columns.

Step 4: Positivity.

By Assumption
A.6
, there exist
j\neq l
with
P_{j}\neq P_{l}
. Hence there exists some
a
with
P_{j}(a)\neq P_{l}(a)
, implying
\text{Var}_{j}[P_{j}(a)]>0
.

Therefore
R(a,a)>Q(a)^{2}
for some
a
, so
R\neq Q\otimes Q
.

Step 5: Conclusion.

Since the joint distribution differs from
Q\otimes Q
:

I(T_{i,J};T_{k,J})=D_{KL}(P_{T_{i,J},T_{k,J}}\|Q\otimes Q)>0

(18)

Moreover, under conditional independence, the joint is exactly
R(a,b)
from (
15
), which is independent of
i,k
. Thus
I(T_{i,J};T_{k,J})
is constant for all
i\neq k
, proving part (ii).
∎

Lemma A.9

(Periodic Structure)
.

For a table with
n
rows and
m
columns, and any
k\in\{1,\ldots,n-1\}
:

\bar{I}_{table}(km)=I^{same}

(19)

Proof.

Step 1: Same-column positions.

For
t,t^{\prime}>m
in the data region:

\text{col}(t)=\text{col}(t^{\prime})\iff t^{\prime}-t\equiv 0\pmod{m}

(20)

Step 2: Structure at lag
km
.

When
d=km
with
1\leq k\leq n-1
, for each
t\in\mathcal{S}_{km}=\{t:m<t\leq L-km\}
:

•

W_{t}=T_{r_{1},c}
for some row
r_{1}
and column
c=\text{col}(t)

•

W_{t+km}=T_{r_{1}+k,c}
(same column, row differs by
k
)

By Lemma
A.8
(ii):

I(W_{t};W_{t+km})=I(T_{r_{1},c};T_{r_{1}+k,c})=I^{same}

(21)

Step 3: Averaging.

Since every pair contributes equally:

\bar{I}_{table}(km)=\frac{1}{|\mathcal{S}_{km}|}\sum_{t\in\mathcal{S}_{km}}I^{same}=I^{same}

(22)

∎

Lemma A.10

(Cross-Column Independence)
.

Let
J,L\sim\text{Uniform}([m])
be independent. Then
T_{i,J}\perp T_{k,L}
, and hence
I(T_{i,J};T_{k,L})=0
.

Proof.

When
J\perp L
:

\displaystyle P(T_{i,J}=a,T_{k,L}=b)

\displaystyle=\sum_{j,l}P(J=j)P(L=l)P_{j}(a)P_{l}(b)

\displaystyle=\left(\frac{1}{m}\sum_{j}P_{j}(a)\right)\left(\frac{1}{m}\sum_{l}P_{l}(b)\right)=Q(a)Q(b)

(23)

Hence
T_{i,J}\perp T_{k,L}
.
∎

A.4
Characterization of
I^{same}

Proposition A.11

(Characterization of Same-Column MI)
.

Under Assumptions
A.5
and
A.6
, in the conditional independence case (
T_{i,j}\perp T_{k,j}\mid j
):

I^{same}=D_{KL}(R\|Q\otimes Q)

(24)

where
R(a,b)=\frac{1}{m}\sum_{j=1}^{m}P_{j}(a)P_{j}(b)
and
Q=\frac{1}{m}\sum_{j}P_{j}
.

The magnitude of
I^{same}
is governed by the
cross-column variance
:

\sigma^{2}:=\sum_{a}\text{Var}_{j}[P_{j}(a)]=\sum_{a}\left(\frac{1}{m}\sum_{j}P_{j}(a)^{2}-Q(a)^{2}\right)

(25)

Specifically:

•

I^{same}>0
if and only if
\sigma^{2}>0
(i.e., columns are not all identical)

•

I^{same}
increases monotonically with
\sigma^{2}

•

When columns are highly distinct (large
\sigma^{2}
),
I^{same}
is correspondingly large

Proof.

The expression
I^{same}=D_{KL}(R\|Q\otimes Q)
follows directly from the proof of Lemma
A.8
.

For the characterization, note from (
17
) that
R(a,a)-Q(a)^{2}=\frac{\text{Var}_{j}[P_{j}(a)]}{m}
. The KL divergence
D_{KL}(R\|Q\otimes Q)
is determined by how much
R
differs from
Q\otimes Q
. Since the diagonal differences
R(a,a)-Q(a)^{2}
are proportional to
\text{Var}_{j}[P_{j}(a)]
, the total cross-column variance
\sigma^{2}=\sum_{a}\text{Var}_{j}[P_{j}(a)]
governs the magnitude of
I^{same}
.

By Assumption
A.6
,
\sigma^{2}>0
, ensuring
I^{same}>0
.
∎

Remark A.12
.

The cross-column variance
\sigma^{2}
can be interpreted as a measure of column heterogeneity. For example:

•

If all columns have the same distribution (
P_{j}=P
for all
j
), then
\sigma^{2}=0
and Assumption
A.6
is violated.

•

If columns have disjoint supports (e.g., column 1 contains only integers, column 2 contains only strings), then
\sigma^{2}
is maximal and
I^{same}
is large.

(Positive Column-Type MI)
.

Appendix H
Limitation

Our work offers a pioneering perspective on data design for RL training tailored to long-context reasoning. Nevertheless, several limitations remain. First, this study primarily focuses on the impact of structured tabular data on long-context reasoning, while other data modalities (e.g., documents and graphs) remain largely unexplored and merit further investigation. Moreover, future research should systematically examine the coupling effects among different types of RL training data, as well as develop specialized reinforcement learning algorithms, to further maximize the long-context reasoning capabilities of LLMs.
