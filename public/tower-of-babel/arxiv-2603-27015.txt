Sheaf-Cohomological Program Analysis: Unifying Bug Finding, Equivalence, and Verification via Čech Cohomology
Halley Young

Abstract
. We present a framework in which program analysis—type checking, bug finding, and equivalence verification—is organized as computing the Čech cohomology of a semantic presheaf over a program’s site category . The presheaf assigns refinement-type information to observation sites (argument boundaries, branch guards, call results, error sites) and restricts it along data-flow morphisms. The zeroth cohomology group H ˇ 0 \check{H}^{0} is the space of globally consistent typings. The first cohomology group H ˇ 1 \check{H}^{1} classifies gluing obstructions —bugs, type errors, and equivalence failures—each localized to a specific pair of disagreeing sites. This formulation yields three concrete results unavailable in prior work: (1) rk ⁡ H ˇ 1 \operatorname{rk}\,\check{H}^{1} over 𝔽 2 \mathbb{F}_{2} equals the minimum number of independent fixes needed to resolve all errors; (2) H ˇ 1 ​ ( 𝒰 , ℐ ​ 𝑠𝑜 ) = 0 \check{H}^{1}(\mathcal{U},\mathcal{I}\mathit{so})=0 is a sound and complete criterion (relative to the cover) for behavioral equivalence of two programs; (3) the Mayer-Vietoris exact sequence provides compositional obstruction counting, enabling incremental analysis. We prove soundness, completeness relative to the cover, and fixed-point convergence. We implement the framework in Deppy , a Python analysis tool, and evaluate it on a suite of 375 benchmarks: 133 bug-detection programs, 134 equivalence pairs, and 108 specification-satisfaction checks. Deppy achieves 100% bug-detection recall (69% precision, F1 = 81%), 99% equivalence accuracy with zero false equivalences , and 98% spec accuracy with zero false satisfactions —outperforming mypy and pyright, which report zero findings on unannotated code. The analysis models Python semantics as algebraic geometry: variables live on the generic fiber (non-None) unless on the closed nullable subscheme, integers form Spec( ℤ \mathbb{Z} ) with no bounded section (no overflow), and short-circuit evaluation defines an open-set topology on the presheaf. Key metatheorems are mechanized in 1 259 lines of Lean 4.

3.
Formal Framework

We formalize program analysis as computing the Čech cohomology of a
semantic presheaf. All definitions in this section are mechanized in
Lean 4 (see supplementary material).

3.1.
Program Site Category

Definition 3.1 (Site kind).

A
site kind
is one of five families:

(1)

ArgBoundary
: function argument sites.

(2)

BranchGuard
: conditional/assertion sites.

(3)

CallResult
: inter-procedural call sites.

(4)

OutBoundary
: function output / return sites.

(5)

ErrorSite
: sites where partial operations may fail.

Definition 3.2 (Program site category).

Given a program
P
, the
program site category

\mathbf{S}_{P}
is
the category where:

•

Objects
are program sites
s=(\kappa,n)
where

\kappa
is a site kind and
n
is a unique identifier (function
name + line number).

•

Morphisms

f:s\to t
are
data-flow edges
:

f
exists iff information at
s
is available at
t
. Each
morphism carries a
projection

\pi_{f}:\mathrm{Keys}(t)\to\mathrm{Keys}(s)
mapping refinement keys at
t
to those at
s
.

•

Composition
:
(g\circ f).\pi=f.\pi\circ g.\pi

(contravariantly, as for a presheaf).

•

Identity
:
\mathrm{id}_{s}.\pi=\mathrm{id}
.

3.2.
Semantic Presheaf

Definition 3.3 (Refinement lattice).

A
refinement lattice

(\mathcal{R},\sqsubseteq,\sqcap,\sqcup,\top,\bot)
is a complete lattice where:

•

\top
= “no information” (any value is possible).

•

\bot
= “contradiction” (no value is possible).

•

\sqcap
= conjunction of refinement predicates.

•

\sqcup
= disjunction of refinement predicates.

•

The
information order
:
\phi\sqsubseteq\psi
iff
every state satisfying
\psi
also satisfies
\phi
(i.e.,

\psi
is more informative).

Definition 3.4 (Local section).

A
local section
at site
s
is a pair

\sigma=(\tau,\phi)
where
\tau
is a carrier type
(e.g.,
int
,
list[T]
) and
\phi\in\mathcal{R}

is a refinement predicate. A section
abstracts
a set of
concrete states:
\gamma(\sigma)\coloneqq\{v:\tau\mid\phi(v)\}
.

Definition 3.5 (Semantic presheaf).

The
semantic presheaf
is a contravariant functor

\mathcal{S}\mathit{em}:\mathbf{S}_{P}^{\mathrm{op}}\longrightarrow\mathbf{Lat}

where
\mathbf{Lat}
is the category of complete lattices and monotone maps.

•

For each site
s
,
\mathcal{S}\mathit{em}(s)
is the lattice of local sections
at
s
, ordered by information content.

•

For each morphism
f:s\to t
, the
restriction map

\mathcal{S}\mathit{em}(f):\mathcal{S}\mathit{em}(t)\to\mathcal{S}\mathit{em}(s)
restricts a section at
t
to
what is observable at
s
. Concretely:
\mathcal{S}\mathit{em}(f)(\tau,\phi)=(\tau|_{s},\phi\circ\pi_{f})
where
\pi_{f}
is the projection.

Functoriality:
\mathcal{S}\mathit{em}(\mathrm{id}_{s})=\mathrm{id}
and

\mathcal{S}\mathit{em}(g\circ f)=\mathcal{S}\mathit{em}(f)\circ\mathcal{S}\mathit{em}(g)
.

3.3.
Grothendieck Topology

Definition 3.6 (Covering family).

A
covering family
for site
s
is a finite set of morphisms

\mathcal{U}=\{u_{i}\xrightarrow{f_{i}}s\}_{i\in I}
satisfying
the
local determination property
: the natural map

\mathcal{S}\mathit{em}(s)\longrightarrow\prod_{i\in I}\mathcal{S}\mathit{em}(u_{i})

is injective (separation) and, when composed with the equalizer
of the double restriction

\prod_{i}\mathcal{S}\mathit{em}(u_{i})\rightrightarrows\prod_{i<j}\mathcal{S}\mathit{em}(u_{i}\times_{s}u_{j})
,
is surjective (gluing).

Definition 3.7 (Grothendieck topology on
\mathbf{S}_{P}
).

The collection of covering families defines a Grothendieck topology
J

on
\mathbf{S}_{P}
satisfying:

(1)

Identity.

\{\mathrm{id}_{s}:s\to s\}
is a covering family for
s
.

(2)

Stability.

If
\mathcal{U}=\{u_{i}\to s\}
is covering and
t\to s
is any
morphism, then the pullback family

\{u_{i}\times_{s}t\to t\}
is covering for
t
.

(3)

Transitivity.

If
\{u_{i}\to s\}
is covering and each
\{v_{ij}\to u_{i}\}

is covering, then
\{v_{ij}\to s\}
is covering.

Remark 1
.

In the program setting: (1) Identity holds trivially.
(2) Stability corresponds to
specialization
: if a cover works
for site
s
, restricting it to a sub-site
t
(e.g., a branch of a
conditional) still works.
(3) Transitivity corresponds to
interprocedural composition
:
if a function
f
is covered by its call sites, and each call site is
covered by its arguments, then
f
is covered by the transitive closure.
This is exactly the Grothendieck axiom that justifies summary-based
interprocedural analysis (cf. IFDS/IDE
(
RepsHorwitzSagiv95
)
).

3.4.
Čech Cohomology

Given a covering family
\mathcal{U}=\{u_{i}\to s\}
and presheaf

\mathcal{S}\mathit{em}
, the Čech complex is:

C^{0}(\mathcal{U},\mathcal{S}\mathit{em})\xrightarrow{\delta^{0}}C^{1}(\mathcal{U},\mathcal{S}\mathit{em})\xrightarrow{\delta^{1}}C^{2}(\mathcal{U},\mathcal{S}\mathit{em})

Definition 3.8 (Čech cochains).

\displaystyle C^{0}(\mathcal{U},\mathcal{S}\mathit{em})

\displaystyle\coloneqq\prod_{i}\mathcal{S}\mathit{em}(u_{i})

(one section per site)

\displaystyle C^{1}(\mathcal{U},\mathcal{S}\mathit{em})

\displaystyle\coloneqq\prod_{i<j}\mathcal{S}\mathit{em}(u_{i}\times_{s}u_{j})

(one section per overlap)

\displaystyle C^{2}(\mathcal{U},\mathcal{S}\mathit{em})

\displaystyle\coloneqq\prod_{i<j<k}\mathcal{S}\mathit{em}(u_{i}\times_{s}u_{j}\times_{s}u_{k})

(one section per triple)

Definition 3.9 (Coboundary operators).

\displaystyle(\delta^{0}\sigma)_{ij}

\displaystyle\coloneqq\mathcal{S}\mathit{em}(\mathrm{pr}_{2})(\sigma_{j})-\mathcal{S}\mathit{em}(\mathrm{pr}_{1})(\sigma_{i})

(disagreement on overlap)

\displaystyle(\delta^{1}\tau)_{ijk}

\displaystyle\coloneqq\tau_{jk}-\tau_{ik}+\tau_{ij}

(cocycle condition on triples)

where subtraction is in the lattice (complement of meet).

Definition 3.10 (Čech cohomology groups).

\displaystyle\check{H}^{0}(\mathcal{U},\mathcal{S}\mathit{em})

\displaystyle\coloneqq\ker\delta^{0}=\{\sigma\in C^{0}\mid\text{all overlaps agree}\}

\displaystyle\check{H}^{1}(\mathcal{U},\mathcal{S}\mathit{em})

\displaystyle\coloneqq\ker\delta^{1}/\operatorname{im}\delta^{0}

The key interpretations:

•

\check{H}^{0}
= the set of
globally consistent type
assignments
(compatible families that glue).

•

\check{H}^{1}
= the set of
gluing obstructions
modulo
those removable by local adjustment (coboundaries).

•

\check{H}^{1}=0
iff the sheaf condition holds for the cover:
every compatible family glues uniquely.

3.5.
The Sheaf Condition

Definition 3.11 (Sheaf condition).

The presheaf
\mathcal{S}\mathit{em}
is a
sheaf
with respect to
topology
J
if, for every covering family
\mathcal{U}
and every
compatible family
(\sigma_{i})_{i\in I}
(i.e.,
\delta^{0}\sigma=0
),
there exists a unique
\sigma\in\mathcal{S}\mathit{em}(s)
such that

\mathcal{S}\mathit{em}(f_{i})(\sigma)=\sigma_{i}
for all
i
.

Proposition 0.

\mathcal{S}\mathit{em}
satisfies the sheaf condition for cover
\mathcal{U}
if and
only if
\check{H}^{1}(\mathcal{U},\mathcal{S}\mathit{em})=0
.

Proof.

(\Rightarrow)
: If
\mathcal{S}\mathit{em}
is a sheaf, every cocycle
\tau\in\ker\delta^{1}
arises from a compatible family (by definition of the
Čech complex), which glues to a global section. Adjusting the
local sections to the glued section shows
\tau\in\operatorname{im}\delta^{0}
.

(\Leftarrow)
: If
\check{H}^{1}=0
, every
1
-cocycle is a

1
-coboundary. Given a compatible family
(\sigma_{i})
, the
disagreements on overlaps form a
1
-cocycle. Since it is a
coboundary, there exist adjusted sections
\sigma^{\prime}_{i}
with zero
disagreement, which by the separation property of the cover determine
a unique global section. (Formalized in Lean:
DeppyProofs.Presheaf.h0_lifts_to_section
.)
∎

5.
Three Applications

5.1.
Bug Finding via
\check{H}^{1}

Theorem 5.1 (Bugs as gluing obstructions).

A program
P
has a bug of class
\mathcal{B}
if and only if

\check{H}^{1}(\mathcal{U}_{P},\mathcal{S}\mathit{em}_{\mathcal{B}})\neq 0
, where

\mathcal{S}\mathit{em}_{\mathcal{B}}
is the presheaf encoding the safety property
for bug class
\mathcal{B}
.

Each bug class defines a presheaf by specifying viability predicates at
error sites: division-by-zero requires divisor
\neq 0
, index
out-of-bounds requires
0\leq i<\mathit{len}(a)
, null dereference
requires receiver
\neq\texttt{None}
, etc.

Proposition 0 (
\operatorname{rk}\,\check{H}^{1}
= minimum fixes).

Over
\mathbb{F}_{2}
,
\operatorname{rk}\,\check{H}^{1}(\mathcal{U}_{P},\mathcal{S}\mathit{em})
equals the minimum
number of independent code changes needed to resolve all obstructions.

Proof.

Build the coboundary matrix
\partial_{0}:C^{0}(\mathbb{F}_{2})\to C^{1}(\mathbb{F}_{2})

with rows indexed by overlaps and columns by sites:

(\partial_{0})_{(i,j),k}=1
iff
k\in\{i,j\}
.
Then
\operatorname{rk}\,\check{H}^{1}=\dim\ker\delta^{1}-\dim\operatorname{im}\delta^{0}
.
Each independent generator of
\check{H}^{1}
is an obstruction that cannot
be removed by adjusting sections at a single site (it is not a
coboundary). Therefore, resolving all obstructions requires at least

\operatorname{rk}\,\check{H}^{1}
independent modifications. Conversely, modifying

\operatorname{rk}\,\check{H}^{1}
sites suffices: by linear algebra over
\mathbb{F}_{2}
,
the space of coboundaries has codimension
\operatorname{rk}\,\check{H}^{1}
in the
kernel, so
\operatorname{rk}\,\check{H}^{1}
generators span all non-trivial
obstructions.
∎

5.2.
Equivalence via Descent

Theorem 5.3 (Descent for equivalence).

Let
f,g
be two programs with semantic presheaves
\mathcal{S}\mathit{em}_{f},\mathcal{S}\mathit{em}_{g}

over a common cover
\mathcal{U}
. Then
f
and
g
are equivalent
(there exists a natural isomorphism
\eta:\mathcal{S}\mathit{em}_{f}\xrightarrow{\sim}\mathcal{S}\mathit{em}_{g}
) if and only if
\check{H}^{1}(\mathcal{U},\mathcal{I}\mathit{so}(\mathcal{S}\mathit{em}_{f},\mathcal{S}\mathit{em}_{g}))=0
.

Proof sketch.

(\Leftarrow)
: The local isomorphisms
\{\eta_{i}:\mathcal{S}\mathit{em}_{f}(u_{i})\xrightarrow{\sim}\mathcal{S}\mathit{em}_{g}(u_{i})\}
define transition functions

g_{ij}=\eta_{j}|_{u_{ij}}\circ\eta_{i}^{-1}|_{u_{ij}}
.

\check{H}^{1}=0
means all
g_{ij}
satisfy the cocycle condition and are
coboundaries, so they can be “straightened” to identities. The
adjusted local isomorphisms agree on overlaps and glue (by the sheaf
condition for
\mathcal{I}\mathit{so}
) to a global isomorphism.

(\Rightarrow)
: A global isomorphism
\eta
restricts to local
isomorphisms with trivial transition functions (
g_{ij}=\mathrm{id}
),
so the
1
-cocycle is zero.

\mathcal{U}=\{(p_{i},c_{j})\}_{i\leq k,j\leq m}

creates one site per path-conjunct pair. Each verification condition
(VC) is small: one path, one conjunct.

Proposition 0 (VC reduction).

Let
n_{\mathrm{overlap}}
be the number of non-trivial overlaps in
the product cover. Then
\check{H}^{1}
-based elimination reduces the
number of VCs from
O(km)
to
O(n_{\mathrm{overlap}})
.
Proof transfer across overlaps further reduces the count:
if
(p_{1},c_{j})
is proved and
p_{1}\cap p_{2}\neq\emptyset
,
then
(p_{2},c_{j})
is discharged.

Metatheory

6.1.
Soundness

We define the concrete semantics
\llbracket P\rrbracket
as the
collecting semantics: for each site
s
, the set of concrete states
reachable at
s
during any execution. The abstraction function

\alpha:\wp(\mathrm{State})\to\mathcal{S}\mathit{em}(s)
maps a set of states to
the tightest section describing them. The concretization

\gamma:\mathcal{S}\mathit{em}(s)\to\wp(\mathrm{State})
maps a section to the
states it admits. The pair
(\alpha,\gamma)
forms a Galois
connection:
\alpha(S)\sqsubseteq\sigma\iff S\subseteq\gamma(\sigma)
.

Theorem 6.1 (Soundness).

If
\check{H}^{1}(\mathcal{U}_{P},\mathcal{S}\mathit{em})=0
, then for every error site
e

with viability predicate
\psi_{e}
, every concrete state reachable
at
e
satisfies
\psi_{e}
. That is: the program has no bugs of the
analyzed class.

Proof.

Suppose for contradiction that some concrete state
c
reaches error
site
e
and violates
\psi_{e}
. Since the analysis is sound
(each local section overapproximates the reachable states),

c\in\gamma(\sigma_{e})
. But
\sigma_{e}
was computed to satisfy the
viability predicate:
\gamma(\sigma_{e})\subseteq\psi_{e}
.

Now,
c
reached
e
via a path through sites
s_{1},\ldots,s_{k}=e
.
At each site, the section overapproximates
c
. At the overlap between

s_{k-1}
and
e
, the section at
s_{k-1}
includes
c
(which
violates
\psi_{e}
) while the viability predicate at
e
excludes it.
Therefore, the restrictions of
\sigma_{s_{k-1}}
and
\sigma_{e}
to
the overlap disagree: there is a nonzero
1
-cocycle. Since this
cocycle cannot be resolved by local adjustment (the concrete state
c

witnesses the genuine disagreement), it represents a nonzero class
in
\check{H}^{1}
, contradicting
\check{H}^{1}=0
.

Formalized in Lean:
DeppyProofs.Soundness.soundness
.
∎

6.2.
Completeness Relative to the Cover

Theorem 6.2 (Relative completeness).

If a concrete bug exists (a reachable state at an error site violates
the viability predicate) and the cover
\mathcal{U}
is

fine enough
(every concrete execution path passes through at
least one cover site), and the refinement lattice
\mathcal{R}
is

expressive enough
(every viability predicate violation is
expressible as a lattice element), then
\check{H}^{1}\neq 0
.

Proof.

By the bug hypothesis, there exists a state
c
at error site
e

violating
\psi_{e}
. By “fine enough,”
c
is abstracted at some site

s
adjacent to
e
. By “expressive enough,” the section at
s

distinguishes
c
from safe states. Therefore, the overlap
(s,e)
has
a genuine disagreement (nonzero
1
-cocycle) that is not a coboundary.
∎

6.3.
Mayer-Vietoris

Theorem 6.3 (Mayer-Vietoris for programs).

Decompose the cover
\mathcal{U}
at a branch into sub-covers

\mathcal{A}
and
\mathcal{B}
with overlap

\mathcal{A}\cap\mathcal{B}
. There is an exact sequence:

0\to\check{H}^{0}(\mathcal{U})\to\check{H}^{0}(\mathcal{A})\oplus\check{H}^{0}(\mathcal{B})\to\check{H}^{0}(\mathcal{A}\cap\mathcal{B})\xrightarrow{\delta}\check{H}^{1}(\mathcal{U})\to\check{H}^{1}(\mathcal{A})\oplus\check{H}^{1}(\mathcal{B})\to\check{H}^{1}(\mathcal{A}\cap\mathcal{B})

When the cover has no non-trivial triple overlaps
(
\check{H}^{2}(\mathcal{U})=0
, which holds when each pair of sites
has at most one overlap), the rank formula simplifies to:

\operatorname{rk}\,\check{H}^{1}(\mathcal{U})=\operatorname{rk}\,\check{H}^{1}(\mathcal{A})+\operatorname{rk}\,\check{H}^{1}(\mathcal{B})-\operatorname{rk}\,\check{H}^{1}(\mathcal{A}\cap\mathcal{B})+\operatorname{rk}\,\operatorname{im}(\delta)

Proof sketch.

The semantic presheaf
\mathcal{S}\mathit{em}
takes values in
\mathbb{F}_{2}
-vector spaces
(each overlap is “agree” or “disagree”). The sub-covers

\mathcal{A},\mathcal{B}
form an excisive pair (their union
is
\mathcal{U}
and their intersection is a sub-cover of both).
The Mayer-Vietoris sequence is a standard consequence of the
short exact sequence of Čech complexes:

0\to C^{\bullet}(\mathcal{U})\to C^{\bullet}(\mathcal{A})\oplus C^{\bullet}(\mathcal{B})\to C^{\bullet}(\mathcal{A}\cap\mathcal{B})\to 0
.
The connecting homomorphism
\delta
maps an element of

\check{H}^{0}(\mathcal{A}\cap\mathcal{B})
(a compatible family on the
overlap that extends to both branches independently but not globally)
to the obstruction in
\check{H}^{1}(\mathcal{U})
.
∎

Engineering consequence.

Modify branch
\mathcal{A}
: recompute
\check{H}^{1}(\mathcal{A})

and
\check{H}^{0}(\mathcal{A}\cap\mathcal{B})
; the global
\check{H}^{1}

follows algebraically. This is the formal basis for

Deppy
’s incremental analysis.

6.4.
Fixed-Point Convergence

Theorem 6.4 (Convergence).

If the refinement lattice
\mathcal{R}
has finite height
h
and
the cover
\mathcal{U}
has
n
sites, then the bidirectional
synthesis (Algorithms
1
–
2
)
converges in at most
O(n\cdot h)
iterations.

Proof.

Each iteration of the backward pass strictly increases the information
content (in the
\sqsubseteq
order) of at least one section, or
leaves all sections unchanged (convergence). Since
\mathcal{R}
has
height
h
, each section can be strengthened at most
h
times. With

n
sites, the total number of strengthening steps is at most
n\cdot h
.
Each forward pass is similarly bounded. Alternating backward and
forward passes therefore converges in
O(n\cdot h)
total iterations.

In practice, the refinement lattice is the lattice of predicates in
linear arithmetic over a finite set of program variables. Quantifier
elimination ensures the predicate domain is finite, giving a
concrete bound on
h
.
∎

7.7.
Separation Results

We identify three problems where the sheaf-cohomological approach is
provably more capable than traditional program analysis.

Theorem 7.1 (Polynomial minimum-fix count).

Given a program with
n
sites and
m
overlaps, the minimum number of
independent code changes needed to eliminate all bugs is computed in

O(m^{2}n)
time via Gaussian elimination on the coboundary matrix

\partial_{0}:C^{0}(\mathbb{F}_{2})\to C^{1}(\mathbb{F}_{2})
.

In contrast, computing the minimum fix count from the output of a
traditional abstract interpretation (a set of error sites with
no overlap structure) is NP-hard: it reduces to
Minimum
Hitting Set
on the family of error-contributing site subsets.

Proof.

The coboundary matrix
\partial_{0}
has
m
rows (overlaps) and
n

columns (sites).
\operatorname{rk}\,\check{H}^{1}=\dim\ker\delta^{1}-\operatorname{rk}\,\partial_{0}
,
computable by Gaussian elimination in
O(m^{2}n)
. This directly equals
the minimum number of independent fixes (Proposition
5.2
).

For traditional analysis: the output is a set
E
of error sites.
Each possible fix modifies one site and eliminates the errors at that
site. Finding the minimum number of sites to modify so that every
error in
E
is covered is
Minimum Hitting Set
, which is
NP-hard even to approximate within factor
(1-\epsilon)\ln|E|

(Dinur & Steurer, 2014)
. The sheaf approach avoids this
because the coboundary matrix algebraically encodes the

dependencies
between errors—two errors that share a
coboundary (are resolvable by the same local adjustment) are
identified by the quotient
\ker\delta^{1}/\operatorname{im}\delta^{0}
, collapsing
the combinatorial search to a linear-algebra computation.
∎

Theorem 7.2 (Exact incremental update).

Let
\mathcal{U}=\mathcal{A}\cup\mathcal{B}
be a cover
decomposition at a branch point. If only sub-cover
\mathcal{A}
is
modified, the updated global cohomology is computed by:

\check{H}^{1}(\mathcal{U}^{\prime})=\check{H}^{1}(\mathcal{A}^{\prime})\oplus\check{H}^{1}(\mathcal{B})\oplus\operatorname{im}(\delta^{\prime})\;/\;\check{H}^{1}(\mathcal{A}^{\prime}\cap\mathcal{B})

requiring only recomputation of
\check{H}^{1}(\mathcal{A}^{\prime})
and the
connecting homomorphism. This is
exact
: no precision is
lost.

Abstract interpretation’s incremental re-analysis, by contrast, must
re-solve the global fixpoint (since widening at join points

destroys the algebraic structure
needed for local update),
incurring
O(n\cdot h)
cost for the full program even when only

O(|\mathcal{A}|)
sites change.

Proof.

Exactness follows directly from the Mayer-Vietoris exact sequence
(Theorem
6.3
): the sequence is natural in the
sub-covers, so replacing
\mathcal{A}
with
\mathcal{A}^{\prime}
yields a
new exact sequence from which
\check{H}^{1}(\mathcal{U}^{\prime})
is determined.
Sub-cover
\mathcal{B}
is unchanged, so
\check{H}^{1}(\mathcal{B})
is
reused. Only
\check{H}^{1}(\mathcal{A}^{\prime})
,
\check{H}^{0}(\mathcal{A}^{\prime}\cap\mathcal{B})
, and the connecting homomorphism
\delta^{\prime}
need
recomputation.

For abstract interpretation: the fixpoint equation at a join point
is
x=f(x)\sqcup g(x)
where
f
depends on
\mathcal{A}
and

g
on
\mathcal{B}
. Widening replaces
\sqcup
with
\nabla
,
which is non-algebraic (non-associative, non-commutative in general).
When
f
changes, the widened fixpoint must be recomputed globally
because
\nabla
does not distribute over the decomposition.
∎

Theorem 7.3 (Complete equivalence criterion).

The descent criterion
\check{H}^{1}(\mathcal{U},\mathcal{I}\mathit{so})=0
is both

sound
and
complete
for equivalence relative to the
cover:
f\equiv_{\mathcal{U}}g
if and only if
\check{H}^{1}=0
.

No finite abstract domain
D
yields a complete equivalence
criterion: for any
D
, there exist equivalent programs
f\equiv g

such that
\alpha_{D}(f)\neq\alpha_{D}(g)
(the abstractions differ
even though the concrete semantics agree).

Proof.

Soundness and completeness of descent were proved in
Theorem
5.3
.

For the incompleteness of abstract domains: let
D
be any finite
abstract domain and
\gamma:D\to\wp(\text{State})
its
concretization. Since
D
is finite,
\gamma
partitions states into
finitely many equivalence classes. For any such partition, there
exist programs
f,g
with
\llbracket f\rrbracket=\llbracket g\rrbracket
(identical denotational semantics) but

\alpha(f)\neq\alpha(g)
: choose
f
that exercises the abstract
domain’s precision limits differently from
g
(e.g.,
f
uses a
loop,
g
uses recursion; both compute the same function, but the
widening trajectories of
f
and
g
in

converge to different
fixpoints).

The sheaf approach avoids this because the isomorphism presheaf

\mathcal{I}\mathit{so}
checks
local
equivalence (at each site) and the
descent theorem glues local equivalences into a global one.
The cover, not the abstract domain, determines the precision.
∎

condition. The novelty is the
cohomological structure
:
\check{H}^{1}

provides obstruction counting, localization, and compositionality
(Mayer-Vietoris) that flat abstract interpretation lacks.

(

)
and Flux
(

but adds the sheaf structure: sections are organized into covers with

\check{H}^{1}
-based error localization. Liquid Haskell
has no analogue of “minimum independent fixes.”

Sheaves in other domains.

Goguen
(

)
proposed sheaf semantics for concurrent programs,
modeling information flow as a sheaf over a poset of security levels.
This is a

use of sheaves; our work uses sheaves for

.
Ghrist and colleagues
(

9.
Conclusion

We have shown that program analysis can be organized as Čech
cohomology of a semantic presheaf over the program’s site category.
This yields three results unavailable in prior work:

\operatorname{rk}\,\check{H}^{1}
counts minimum independent fixes, descent provides
sound and complete equivalence checking, and Mayer-Vietoris enables
compositional incremental analysis. The implementation,

Deppy
, demonstrates these capabilities on real Python
programs.

Mechanized proofs.

Soundness, the sheaf condition equivalence,
\check{H}^{0}
characterization,
the descent theorem, Mayer-Vietoris localization, incremental
soundness, and fixed-point convergence are formalized in Lean 4
with Mathlib (1 259 lines across 7 modules).

Limitations.

Completeness is relative to the cover and predicate domain.
Bug-detection precision (69%) is limited by false positives on safe
programs with complex guard patterns (defaultdict, loop-bounded
indexing, numerical stability tricks). The H
1
rank prediction
(77%) is limited by spurious obstructions inflating the rank.
The framework currently targets single-threaded Python; full
concurrency support (beyond race-condition detection) would require
extending the site category with synchronization morphisms.
