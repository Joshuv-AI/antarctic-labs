Learning Bilevel Policies over Symbolic World Models for Long-Horizon Planning
Dillon Z. Chen, Till Hofmann, Toryn Q. Klassen, Sheila A. McIlraith

Abstract
We tackle the challenge of building embodied AI agents that can reliably solve long-horizon planning problems. Imitation learning from demonstrations has shown itself to be effective in training robots to solve a diversity of complex tasks requiring fine motor control and manipulation over low-level (LL), continuous environments. Yet, it remains a difficult endeavour to generate long-horizon plans from imitation learning alone. In contrast, high-level (HL), symbolic abstractions facilitate efficient and interpretable long-horizon planning. We propose to combine the strengths of LL imitation learning for manipulation and control, and HL symbolic abstractions for long-horizon planning. We realise this idea via bilevel policies of the form ( π hl , π ll ) (\pi^{\mathrm{hl}},\pi^{\mathrm{ll}}) , consisting of a neural policy π ll \pi^{\mathrm{ll}} learned from LL demonstrations, and an HL symbolic policy π hl \pi^{\mathrm{hl}} that is constructed from symbolic abstractions of the LL demonstrations combined with inductive generalisation. We implement these ideas in the BISON system. Experiments on extended MetaWorld benchmarks demonstrate that BISON generalises to long horizons and problems with greater numbers of objects than those solved by VLA and end-to-end methods, and is more time and memory efficient in training and inference. Notably, when ignoring LL execution, BISON’s HL policies can solve HL problems with 10,000 relevant objects in under a minute. Project page: https://dillonzchen.github.io/bison

\mathcal{L}

Bilevel Planning

A
planning problem
is a tuple
\mathbf{P}=\langle\mathbf{S},\mathbf{A},\mathbf{s}_{0},\mathbf{g}\rangle
where
\mathbf{S}
is a set of states,
\mathbf{A}
is a set of actions,
\mathbf{s}_{0}
is the initial state and
\mathbf{g}\subseteq\mathbf{S}
is a set of goal states.
An action
\mathbf{a}\in\mathbf{A}
is a function
\mathbf{a}:\mathbf{S}\to\Delta(\mathbf{S}\cup\left\{\bot\right\})
that maps to a distribution of possible next states or
\bot
indicating the action is not applicable.
A policy is a distribution over actions
\pi(\mathbf{a}\mid\mathbf{s},\ast)
conditioned on a state and other arguments
\ast
.
A policy is a
solution
for a planning problem if it achieves a goal state from the initial state
\mathbf{s}_{0}
with an expected probability of 1.
A
bilevel planning problem
is a tuple
\mathbb{P}=\langle\mathbf{P}^{\mathrm{ll}},\mathbf{P}^{\mathrm{hl}},\mathcal{L}\rangle
consisting of an HL and LL planning problem and a
labelling function

\mathcal{L}:\mathbf{S}^{\mathrm{ll}}\to\mathbf{S}^{\mathrm{hl}}
such that
\mathit{g}^{\mathrm{hl}}=\{\mathcal{L}(\mathbf{s}^{\mathrm{ll}})\mid\mathbf{s}^{\mathrm{ll}}\in\mathbf{g}^{\mathrm{ll}}\}
.
We next depict conditions on
\mathcal{L}
for ensuring useful HL abstractions of LL problems, followed by representations of HL and LL planning problems for our work.

Downward Refinement Property

We next introduce a property of our bilevel planning paradigm that establishes when the HL abstraction is useful for constructing bilevel planning solutions.
The downward refinement property (DRP)
(
9
)
states that any solution for an HL problem can be refined into a solution for the LL problem.
We extend this notion to the general nondeterministic setting.
Given a state
\mathbf{s}
and policy
\pi
, we denote
\mathbf{exec}(\mathbf{s},\pi)
to be the set of all possible successor states achievable by applying some action with non-zero support in
\pi(\cdot\mid\mathbf{s})
.

A bilevel planning problem

\displaystyle\forall\mathbf{s}\in\mathbf{exec}(\mathbf{s}^{\mathrm{ll}},\pi^{\mathrm{ll}}),\mathcal{L}(\mathbf{s})\in\mathbf{exec}(\mathcal{L}(\mathbf{s}^{\mathrm{ll}}),\pi^{\mathrm{hl}})\cup\{\mathcal{L}(\mathbf{s}^{\mathrm{ll}})\}.

(1)

HL Representation: Relational State and Action Abstractions

We represent our HL problems

via state and temporal abstractions of the world in a relational form, inspired by the STRIPS

Specifically, LL states can be abstracted into HL states represented as symbolic databases and LL actions can be temporally abstracted into HL actions via an action schema language.
We define a planning

A

A fact is a predicate whose argument terms are all instantiated with objects denoted

We concern ourselves with

We assume that all LL goal states can be abstracted into a single HL

An HL state

is a goal state if
\mathit{g}^{\mathrm{hl}}\subseteq\mathit{s}^{\mathrm{hl}}

An
action schema
is a temporally-abstracted, nondeterministic action that can be parameterised by objects, given by a tuple
\langle\mathit{var}(a),\mathit{pre}(a),\{\mathit{add}_{i}(a),\mathit{del}_{i}(a)\}_{i=1}^{n}\rangle

\mathit{var}(a)
is a set of parameter variables, and the preconditions

An HL action

is an action schema

Learning Bilevel Policies for Bilevel Planning

We learn bilevel policies from the given HL-goal labelled LL demonstrations
\mathbb{T}

\mathcal{D}
and labelling function
\mathcal{L}

A
bilevel policy
(BP) consists of a pair of policies
(\pi^{\mathrm{hl}},\pi^{\mathrm{ll}})
of the forms
\pi^{\mathrm{hl}}(\mathit{a}^{\mathrm{hl}}\mid\mathit{s}^{\mathrm{hl}},\mathit{g}^{\mathrm{hl}})

\pi^{\mathrm{ll}}(\mathbf{a}^{\mathrm{ll}}\mid\mathbf{s}^{\mathrm{ll}},\mathit{a}^{\mathrm{hl}},\mathit{g}^{\mathrm{hl}})

Both policies are goal-conditioned and can be reused across different problems.
Together with the labelling function
\mathcal{L}

\displaystyle\textstyle\pi(\mathbf{a}^{\mathrm{ll}}\mid\mathbf{s}^{\mathrm{ll}},\mathit{g}^{\mathrm{hl}})=\sum_{\mathit{a}^{\mathrm{hl}}}\pi^{\mathrm{ll}}(\mathbf{a}^{\mathrm{ll}}\mid\mathbf{s}^{\mathrm{ll}},\mathit{a}^{\mathrm{hl}},\mathit{g}^{\mathrm{hl}})\cdot\pi^{\mathrm{hl}}(\mathit{a}^{\mathrm{hl}}\mid\mathcal{L}(\mathbf{s}^{\mathrm{ll}}),\mathit{g}^{\mathrm{hl}}).

(3)

4.1
Learning HL Policies via Goal Regression and Inductive Generalisation

We construct HL policies
\pi^{\mathrm{hl}}(\mathit{a}^{\mathrm{hl}}\mid\mathit{s}^{\mathrm{hl}},\mathit{g}^{\mathrm{hl}})
from LL demonstrations paired with HL goals in 3 steps illustrated in
Figure

2
:
(1) we first generate HL traces that are abstractions of our LL demonstrations;
(2) we then utilise goal regression to extract a set of condition-action rules from such HL traces; and
(3) we finally utilise inductive generalisation to produce interpretable symbolic policies in the form of first-order, condition-action rules.
Steps 2 and 3 are achieved in milliseconds.
In what follows, we first define the form of our HL policies and a means of grounding them for execution with respect to a particular problem instance.
We then elaborate on the 3 steps required to generate HL policies.

HL policy representation

Our HL policies
\pi^{\mathrm{hl}}
consist of sets of first-order, condition-action rules
r
with associated priority values related to goal proximity.
These first-order, condition-action rules are tuples of the form
\langle\mathit{val}(r),\allowbreak\mathit{var}(r),\allowbreak\mathit{sCond}(r),\allowbreak\mathit{gCond}(r),\allowbreak\mathit{action}(r)\rangle
where

\mathit{val}(r)
denotes the rule priority,

\mathit{var}(r)
denotes a set of variables,

\mathit{sCond}(r)
and
\mathit{gCond}(r)
are first-order conjunctive formulas over predicates in

Step 1: construct HL traces

From an LL trace
\langle\mathit{g}^{\mathrm{hl}}_{i},\mathbf{s}^{\mathrm{ll}}_{0},\mathbf{a}^{\mathrm{ll}}_{0},\mathinner{.\mkern-1.0mu.\mkern-1.0mu.},\mathbf{s}^{\mathrm{ll}}_{m},\mathbf{a}^{\mathrm{ll}}_{m}\rangle\in\mathbb{T}

The following theorem establishes the conditions under which

Each subproblem class exhibits a finite policy and we can compose all such policies into a single, finite policy that can solve every problem in

Learning method

Following the HL learning method, we can compute a single dataset consisting of tuples

In place of MSE optimisation, we could alternatively learn a generative diffusion policy
(

18

6
Discussion, Limitations, and Conclusion

We introduced BISON, a system to learn bilevel policies
(\pi^{\mathrm{hl}},\pi^{\mathrm{ll}})
from LL demonstrations paired with HL goals that generalise to long-horizon problems.
We learn
\pi^{\mathrm{hl}}
policies from abstracted symbolic traces of the LL demonstrations using goal regression and inductive generalisation to produce first-order, condition-action rules that can generalise to arbitrary numbers of objects, and
realise our
\pi^{\mathrm{ll}}
policies via graph neural networks with fewer than 33k parameters for executing HL actions returned by
\pi^{\mathrm{hl}}
in the LL action space.
The novelty of our approach is at least two-fold: (1) in contrast to existing bilevel planning approaches that search for HL plans over symbolic abstractions before refining them in the LL environment, BISON inductively generalises HL policies from LL demonstrations without the need for search, and (2) the encoding of our policies as first-order, condition-action rules is novel in the context of bilevel planning and facilitates open-world planning and generalisation. Through this novel insight and approach, we can learn compact policies that demonstrate strong generalisation capabilities and efficiency compared to state-of-the-art VLA, end-to-end, and planning baselines on extended MetaWorld benchmarks.

Limitations

Our approach inherits the limitations of bilevel planning, in particular, the assumption of a learned or given HL abstraction that provides useful guidance for LL planning (there is much research on how to find good abstractions as discussed in
Section

3
).
Another limitation of our approach is that we have no guarantees of optimality and generalisation of the LL policies.

\displaystyle F(\mathit{s}^{\mathrm{hl}}):=\{p(f(o_{1}),\ldots,f(o_{n}))\mid p(o_{1},\ldots,o_{n})\in\mathit{s}^{\mathrm{hl}}\}

B.3
Generalisation Result

We can now state the formal version of the informal theorem in

Theorem 1

\mathcal{D}=\langle\mathcal{P},\mathcal{A}\rangle
be an HL domain,
\mathcal{L}
a labelling function, and

.
There exists a finite dataset

\mathbb{T}
via

conforming to
\mathcal{D}
and satisfying

Proof.

Let
N=\max_{a\in\mathcal{A}}\left|\mathit{var}(a)\right|
and

denote the maximum schema and predicate arities, respectively.

Up to
\sim
, the set of singleton-goal HL problems on
\mathcal{D}
is finite.
A singleton goal is a single fact
p(o_{1},\ldots,o_{n_{p}})
which, modulo bijective renaming of objects, is determined by a choice of
p\in\mathcal{P}
together with an arrangement of its at most
M
argument positions among at most
M

\left|\mathcal{P}\right|\cdot M^{M}

\sim
.
By the
\text{GI}_{C}

and hence cycle-less trajectories with size less than
C
.
A length-

distinct objects, since each of the
k

N

M
further positions.
By
Proposition

1
it suffices to count action sequences up to
\sim

k

\left(kN+M\right)^{N}

\displaystyle n\;\leq\;\left|\mathcal{P}\right|\cdot M^{M}\cdot\sum_{k=0}^{C}\bigl(\left|\mathcal{A}\right|\cdot\left(kN+M\right)^{N}\bigr)^{k}.

(8)

Choose
\mathbb{T}
to contain, for each equivalence class of singleton-goal subproblem encountered as a step (a) instance in

2

for a representative of that class.

.

Now fix any HL problem

The task requires producing blocks of specific colours from a gacha box (close lid, roll, open lid, then extract block) and placing them on matching trays.
The policy has nine priority levels.
Rule 1: if holding a block
x

c
, place it on the matching tray
t

Rule 2: if the gacha
d
is open and contains a block of the needed colour, pick it.
Rule 3: if the gacha contains a block of the needed colour but is closed, open it.
Rule 4: if the gacha is closed and empty, roll it to produce a new block of random colour.
Rule 5: if the gacha is open but does not contain a useful block, close it so that it can be rolled again.
Rules 6–8 cover
opportunistic
actions when the currently pursued goal colour is
c^{\prime}

c

c

c^{\prime}

The policy is more complex than Blocks
