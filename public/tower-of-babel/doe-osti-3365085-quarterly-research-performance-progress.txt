 ACCOMPLISHMENTS & MILESTONE UPDATE

Project Status Summary:
The goal of this project is to develop a high temperature, high-pressure well integrity evaluation
device that can operate in enhanced geothermal system (EGS) boreholes without active cooling
or substantial mitigation of borehole conditions. The product must provide consistent high-
resolution data regarding the efficacy of wellbore casing and cement for long-term operation.
This project aims to deliver a ruggedized tool that can withstand a corrosive geothermal
environment with pressure ranges up to 15,000 psi and temperatures up to 250°C for a 24-hour
operating period.

This quarterly report marks the end of Y1, Q4 of this project, and the completion of Milestone 4
per the Statement of Project Objectives. Previously in Y1 of this project, Milestone 1 was
submitted, which identified key performance metrics and outlined verification methods.
Additionally, Milestone 2 provided an in-depth survey of existing technologies in the industry
which were measured against the stated performance metrics. Recently Milestone 3 showed
progress towards signal processing in the geothermal borehole. This report submitted for Y1/Q4
summarizes further progress towards imaging in the inhospitable geothermal environment,
related to task 2.2: waveform inversion and imaging. The results compare new imaging results
with raw data methods using test data obtained from existing borehole test pieces.

Task 2. Signal Processing
Task 2.2: Signal Processing for inhospitable media

1. Planned Activities:
This task relates to the signal processing of full-waveform sonic data to resolve fractures, or
other scatters created within the wellbore, to indicate compromised borehole integrity. First,
recorded sonic data from the receiver array is used to monitor the wellbore. From this data, the
physical properties of the wellbore are determined using direct waveform inversion (DWI), and
then a Gaussian beam migration (GBM) is implemented for high-resolution reflectivity imaging.
These steps are further enhanced by using machine learning (ML) and various other processing
steps to enhance signal to noise ratio. This imaging routine will reveal fractures or other defects
within the wellbore, if any.

2. Actual Accomplishments:

The work shown below serves as a progress update for the image processing task described
above. The new set of data first performs multichannel nonlinear signal comparison (MNLSC)
on the raw data, followed by a direct waveform inversion (DWI) to determine layer properties,
and then a Gaussian beam migration (GBM) for imaging. The previous quarterly report’s results
followed a similar procedure, however before, the borehole waves and reflections from the
casing were removed by simple subtraction – which was a good starting point, but is not a robust
signal processing method. Therefore, we implement a new pre-filtering process that uses
multichannel nonlinear signal comparison (MNLSC) to remove borehole waves from the data,
median filtering to remove other waves including casing reflections, and refraction statistics to
set source and receiver to datum on borehole wall.

Description of model and common offset and common shot gathers
The set of results presented are representative of the proposed tool geometry and borehole
dimensions. A finite difference modeling scheme was used to record synthetic borehole data.
The model for the borehole is axisymmetric and includes radial layers of water (52 mm), steel
casing (13 mm), a cement layer (19mm), and surrounding granite. The model also incorporates
proposed tool geometry, which consists of a transmitter and an array of 15 receivers. The
receivers are spaced vertically 15 mm from each other and offset from the transmitter 47 mm
horizontally and 80 mm vertically. The transmitter is a Boston Piezo Optics PZT-5A disc
measuring 50 mm across with a fundamental frequency of 1 MHz. The transmitter can be
adjusted to change the angle of emitted waves. Receivers are Boston Piezo Optics PZT-5A
transducers measuring 12.7 mm and 500 kHz. Tool Geometry and borehole model are pictured
below.

Some of the results figures shared below are described as common offset gathers, and others are
described as common shot gathers. The common offset gather is a set of time domain results,
side-by-side, for a single receiver in the array at different depths as the tool is descending the
borehole. The common shot gather is a similar set of results from one shot at a single depth,
representing all the receivers in the array simultaneously.

implementing inversion and migration algorithms. This is important, because the borehole
waves create significant artifacts that can obscure useful signatures that describe the underlying

Direct Waveform Inversion (DWI) and Gaussian Beam Migration (GBM)
Direct Waveform Inversion is used to map the layered structure of the borehole and to determine
from the received waveforms the properties and layouts for each layer. Once the layer
thicknesses and properties have been determined with DWI, a Gaussian Beam Migration
technique is performed to map defects beneath the surface of the borehole. GBM is a ray-based
migration technique that uses Gaussian beam propagators to map the recorded amplitudes into
the model space. This type of beam, which has a Gaussian transverse pressure amplitude, is a
major improvement on point-source assumptions and standard migration techniques because it is
a close simplification of the physical collimated source that is used for borehole integrity
monitoring. The side view of the Gaussian beam is pictured in Figure 5.

To perform GBM, a gaussian beam is traced from the transmitter and from each receiver through
the layered media to compute a travel-time matrix for each receiver. The travel-time matrix
maps the received time-domain amplitude signals to distances on a spatial grid, thus constructing
an image. These steps are illustrated in Figure 6. Note that for the results below, the beam
traced from the receiver is used only for analysis in computing the travel-time matrix, and the
receiver is not physically exciting pressure waves as such. Preliminary results for this technique
are shown in Figure 7 which depicts an image that locates a washout defect in the cement layer.

3. Explanation of Variance:
Per the statement of objectives, the accomplishments up to milestone 4 were to show progress
towards new approaches for imaging in inhospitable media, with verification comparing new
imaging results with raw data methods using test data obtained from existing borehole test
pieces.

Compared with the previous quarterly report, the results presented here implement an improved
imaging technique that uses multichannel nonlinear signal comparison (MNLSC) to distinguish
and filter-out borehole waves from the raw data. The results vary from the proposed plan in that
data is synthetically generated using a numerical model of a borehole, and not with borehole test
pieces. This variance is due to not having a prototype to collect laboratory data.

4. Plans for Next Quarter:

for Y2/Q1 will report on preliminary choice of active materials, and the report for Y2/Q2 will be
on passive materials choice. Meanwhile, work is underway to prepare for mechanical design and
prototyping tasks.
