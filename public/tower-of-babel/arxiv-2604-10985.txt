Back to the Barn with LLAMAs: Evolving Pretrained LLM Backbones in Finetuning Vision‑Language Models
Sameera Horawalavithana*, Lauren Phillips, Ian Stewart, Sai Munikoti, & Karl Pazdernik

Abstract
Vision-Language Models (VLMs) have rapidly advanced by leveraging powerful pre-trained Large Language Models (LLMs) as core reasoning backbones. As new and more capable LLMs emerge with improved reasoning, instruction-following, and generalization, there is a pressing need to efficiently update existing VLMs to incorporate these advancements. However, the integration of new LLMs into VLMs, particularly how the evolving LLMs contribute to multimodal reasoning, alignment, and task-specific performance remains underexplored. Addressing this gap is important for VLM development, given the rapid evolution of pretrained LLM backbones. This study presents a controlled and systematic investigation of how changes in the pretrained LLM backbone affect downstream VLM task performance. By having the vision encoder, training data, and post-training algorithm remain same across LLAMA-1, LLAMA-2, and LLAMA-3 based VLMs, we find that newer LLM backbones do not always lead to better VLMs, but the performance depends on the downstream VLM task. For example, in visual question and answering tasks, newer LLM backbones tend to solve different questions rather than just more questions, and our analysis shows this is driven by differences in how the models process information, including better calibrated confidence and more stable internal representations. We also find that some VLM capabilities appear only in the newest LLM generation, while tasks that depend mainly on visual understanding see little benefit from a newer LLM backbone.

Existing research comparing LLM impact on VLM performance suffers from significant confounding variables.

3
Experimental Setup

In this section, we outline an experimental setup to evaluate the effects of evolving LLM backbones, such as Meta’s LLAMA series, on the performance of VLMs in downstream tasks.
The goal is to understand how improvements in LLMs impact tasks that combine vision and language understanding.

3.1
VLM Architecture

More recently, VLMs follow a consistent model architecture comprising of a visual encoder that extracts visual features, a connector module for modality alignment, and an LLM backbone that serves as the primary reasoning component.
The LLM backbone used for language-based reasoning and text generation, allowing models to achieve effective vision-language grounding.

The VLM architecture consists of three main components.
First, the LLM backbone serves as the language decoder. We use different versions of an evolving LLM, such as Meta’s LLAMA series (e.g., LLAMA-1, LLAMA-2, LLAMA-3.1), to study the impact of their advancements in architecture, size, or training data.
Second, a pre-trained visual encoder (i.e.,
clip-vit-large-patch14
), processes input images and extracts visual features.
Visual encoder is kept consistent across experiments to focus on the effect of the LLM backbone.
Third, a simple neural network, called a projector, aligns the visual features from the encoder with the text embeddings of the LLM.
We use the NVIDIA-NeMo codebase
(
28
)
and adopt the NeVA model architecture
(
26
)
for the experiments.
NeVA leverages the features of the NeMo framework such as model parallelism, activation checkpointing, AMP O2, Flash Attention, and more
(
15
)
.

3.2
Finetuning Process

The training process is divided into two stages to improve the VLM’s performance.
In the first stage, known as the warm-up or alignment stage, the goal is to align the visual encoder and LLM decoder.
We use an image captioning dataset, SciCap
(
11
)
, for this stage.
In this stage, the model learns to generate descriptive text for technical plots, building a basic understanding of visual-language relationships.
This approach is inspired by prior research, which shows that such pre-training on captioning data improves zero-shot performance
(
24
)
.
Specifically, previous research
(
25
;
30
;
17
)
suggested that pre-training on similar technical plots improves performance on other domains (e.g., business, medical, remote sensing).
Training in this stage involves fine-tuning the projector, the LLM and visual encoder.
We train for a fixed number of epochs (e.g., 1-3) or until performance on a validation set stabilizes.
All the VLM checkpoints record a comparable performance in the captioning tasks after this pre-training stage (see Appendix
B
for more details).

The second stage focuses on adapting the model to specific vision-language tasks through Supervised Fine-Tuning (SFT).
We selected SFT as the post-training method for this ablation study because it provides most stable, and computationally efficient experimental setup in comparison to the RL-based methods
(
7
)
.

We use three domain-specific datasets for evaluation

ScienceQA, which includes science-related questions and images, requiring reasoning over visual and textual information

•

Seismic, a multimodal dataset related to seismic events capturing geographical images, and textual description of events.
This work focuses on interpreting geological images with an open-ended question/answering dataset created manually by subject matter experts.

•

VQA-Scene, a dataset for Visual Question Answering (VQA) centered on scene understanding
(
38
)
. We use a random sample of 1000 instances from the validation split of the VQA-Scene dataset

We evaluate models on these datasets chosen for their diversity, which is important for comparing different LLM backbones.
In particular, ScienceQA emphasizes memorization‑driven language reasoning
(
37
;
10

, while Seismic and VQA‑Scene minimize vision and language priors, respectively

.

3.3
Evaluation Metrics

To assess the model’s performance, we use standard metrics for each downstream task.
For ScienceQA, we measure the accuracy for predicting the right choice.
We use 2017 test instances from the ScienceQA dataset where the question, image and context are included in the input prompt.
For the Seismic dataset, we use the standard text-evaluation metrics (e.g., BLEU, ROUGE) for text outputs excluding the predictions for the latitude and longitude coordinates.
We calculate Haversine distance for the latitude and longitude values predicted by the model after parsing from the text output.
We normalize the distance to a score between 0 and 1 using a linear decay.
Any distance exceeding a pre-defined maximum of 5,000 km is assigned a score of 0.
For all other values, the score is calculated by the ratio of the distance to the maximum threshold, where a distance of 0 km yields a score of 1.
We used the VQA evaluation metric
(
2
)
which is computed based on the number of human subjects who provided the predicted answer (scaled by 3 and
clipped at 1).
For binary yes/no questions in the VQA-Scene dataset, we used the 10 human answers as provided in the dataset
(
2
)
.

4.1
Overall Performance Across LLM Backbones

We compare mean accuracy across the three datasets for each LLAMA backbone (Figures
1(a)
to
1(c)
).
There is no consistent pattern where a newer LLM leads to a better VLM.
For example, ScienceQA accuracy drops from 71.8% (LLAMA-1) to 68.4% (LLAMA-3).
VQA-Scene accuracy increases from 61.8% to 65.6% over LLAMA-1 to LLAMA-3.
Seismic text-output accuracy remains mixed, where the accuracy decreases from 78.5% to 74.0% and back to 77.8% over the base LLAMA backbones.

Since the vision encoder, and training data are held constant, these differences reflect how each task interacts with the evolving capabilities of the LLM backbone.
We found different categories of VLM tasks have different impacts from LLM upgrades, as they will not always improve performance.

Takeaway 1: Newer LLMs do not uniformly improve VLM performance.

Under controlled conditions, newer LLMs do not uniformly improve VLM performance. Accuracy increases on VQA-Scene (+3.8%), decreases on ScienceQA (
-
3.4%), and stays comparable on Seismic. The performance trend depends on the downstream task.

4.2
Same Modality, Different Outcomes on Reasoning Tasks

Both ScienceQA and VQA-Scene require reasoning over visual and textual information, yet they exhibit opposite performance trend to LLM evolution.
On ScienceQA, accuracy drops by 3.4 percentage points from LLAMA-1 to LLAMA-3.
On VQA-Scene, accuracy improves by 3.8 percentage points over the same LLM backbones.
It is the only dataset where we observe that better LLM backbones result better VLM performance.

Several factors may explain the performance drop on ScienceQA.
ScienceQA training examples follows a structured format where a
LECTURE
block provides background knowledge, followed by a solution that applies this knowledge to arrive at the answer.
At test time, the model is expected to recall the relevant
LECTURE
content and generate a solution conditioned on it
(
21
)
.
This setup largely tests memorization-driven language reasoning, the model’s ability to store and reproduce structured text patterns from training rather than genuine visual understanding of the input image
(
10
;
20
)
.
Due to these characteristics, ScienceQA seems highly amenable to SFT, given it leads to strong in-distribution memorization
(
7
)
.
Once the VLM learns effective image-to-text projection and reasoning patterns, further LLM improvements (better pre-training data, longer context, or architectural tweaks in LLAMA-3) yield diminishing returns.
It is also possible that stronger language priors in newer LLMs cause the model to rely more on textual shortcuts rather than attending to the visual input, a known failure mode where the language model overrides visual evidence
(
32
)
.
On the other hand, VQA-Scene requires grounded visual reasoning about everyday scenes, where improved language understanding translates more directly to better answers.

Takeaway 2: Not all VLM reasoning tasks benefit equally from LLM upgrades

ScienceQA and VQA-Scene both require reasoning over visual input, yet they respond oppositely to LLM upgrades. The nature of the reasoning, memorization-driven versus grounded visual determines whether a newer LLM helps or not. Stronger LLMs do not universally improve reasoning-dependent VLM tasks.

This means LLAMA-3 does not simply lose accuracy on a fixed set of questions.
It gets some questions right that LLAMA-1 misses, and misses others that LLAMA-1 gets right.
LLAMA-1 and LLAMA-2 are nearly interchangeable (

The higher overall accuracy of LLAMA-3 does not come from solving the same questions plus a few more, but it comes from solving a largely

Because VQA-Scene is designed so that language priors are controlled and vision plays an essential role

On Seismic, all correlations remain high (

Takeaway 3: Overall accuracy hides instance-level model behavioral shifts

On VQA-Scene, LLAMA-3 achieves higher accuracy than LLAMA-1/2 but is negatively correlated at the instance level. It succeeds on a largely different set of questions. Reporting only overall accuracy can hide substantial shifts in what the model actually solves.

4.4
When Vision Is the Bottleneck, the LLM Backbone Has Minimal VLM Performance Advantage

On the Seismic dataset, we evaluate two types of output: text-based descriptions of geological features and numerical predictions of latitude and longitude coordinates.
As shown in Figure
1(c)
, the text-based metrics show no systematic trend across LLM backbones.
Accuracy is 78.5% for LLAMA-1, 74.0% for LLAMA-2, and 77.8% for LLAMA-3.
Instance-level correlations are consistently high (
r>0.85
), meaning all three models succeed and fail on nearly the same instances (Figure
1(f)
).

Interpreting geological images depends primarily on the visual encoder’s ability to extract domain-specific features.
In this setup, LLM backbone generates texts primarily based on whatever the visual encoder provides as geological features.
Since CLIP is held constant across experiments, the vision perception challenges stay the same, and LLM improvements have little room to make a difference.
This finding is consistent with prior work calling for advances in vision encoders to improve VLM performance on perception-heavy tasks
(
34
)
.

Takeaway 4: LLM backbones have minimal performance advantage over perception-heavy VLM tasks

On the Seismic text-based evaluation, all three LLAMA backbones solve nearly identical instances (
r>0.85
). When the bottleneck is at the visual feature extraction, upgrading the LLM backbone offers minimal returns. For such tasks, improving the vision encoder is more likely to yield meaningful gains.

4.5
Newer LLM Backbones Exhibit New VLM Capabilities That Older LLMs Lack

While the text-based Seismic results suggest that LLM backbone evolution has little effect on the text-output performance, the coordinate prediction task demonstrate a different performance pattern.
In this task, we evaluate the model’s ability to predict latitude and longitude values from geological images using the Haversine-based scoring described in Section
3.3
.
LLAMA-1 and LLAMA-2 both score exactly 0.0% on this metric—they are completely unable to predict valid coordinate predictions, instead predict the text listing the city and state names (see Appendix
E
).
LLAMA-3, by contrast, records 76.5% accuracy on the same instances (Figure
3
).

There are several possible explanations for this performance increase.
LLAMA-3 was pre-trained on a substantially larger and more diverse corpus, which likely includes more geospatial data, coordinate formats, and structured numerical content.
Its larger vocabulary (128K tokens) may also represent numerical values more effectively.
Additionally, the improved instruction-following capabilities of LLAMA-3 may allow it to parse and respond to the structured output format required for coordinate prediction, a task that demands accurate geospatial formatting rather than open-ended generation.

This result re-emphasizes the perception-based conclusion from the previous subsection.
The text-based description of geological features is indeed bottlenecked by the visual encoder where all three LLMs perform similarly.
But the coordinate prediction task also needs another skill where the LLM needs to predict formatted numbers that match specific locations on the map.

Takeaway 5: Newer LLM backbones introduce new VLM capabilities

On the Seismic coordinate prediction task, LLAMA-1 and LLAMA-2 score 0.0% while LLAMA-3 scores 76.5%. VLM capabilities which require structured numerical output or domain-specific knowledge may emerge only with sufficiently advanced LLM backbones.

The instance-level analysis in the previous section revealed that LLAMA-3 solves a largely different set of VQA-Scene questions compared to LLAMA-1 and LLAMA-2.
To understand the mechanisms behind this behavioral shift, we conduct additional analysis on the VQA-Scene predictions.
We examine two aspects of the model’s internals: the token-level confidence of generated answers, and the layer-wise representations within the decoder.

4.6.1
LLAMA-3 based VLM Is Less Confident but More Accurate

We extract log-probabilities of the generated answer tokens and convert them to confidence scores using
c=\exp(\mathsf{log\_prob})
.
A confidence of 1.0 means the model assigns near-certain probability to its predicted answer.
Figure
3
shows the mean confidence scores across VQA-Scene instances for each model.

LLAMA-1 and LLAMA-2 both produce confidence scores of 1.0, meaning they assign near-certain probability to their answers on every instance.
LLAMA-3, by contrast, has a mean confidence of 0.73, substantially lower score.
Yet LLAMA-3 achieves the highest accuracy on this dataset (65.6% vs. 61.8% and 63.3%).
The model that is least sure of its answers is the one that gets the most answers right.

LLAMA-1 and LLAMA-2 are overconfident where they assign maximum probability to their outputs regardless of whether they are correct.
LLAMA-3 distributes probability mass more carefully across possible answers, resulting in lower per-token confidence but better overall performance.
It also helps explain the negative instance-level correlation: if LLAMA-1 and LLAMA-2 always commit fully to one answer while LLAMA-3 hedges differently, the models will naturally arrive at different answers on many instances even when the underlying visual information is the same.

Takeaway 7: Higher accuracy does not require higher confidence

On VQA-Scene, LLAMA-3 achieves the highest accuracy while being the least confident (0.73 vs. 1.0 for LLAMA-1/2). Older LLM backbones produce overconfident VLMs that commit fully to answers regardless of correctness. Newer LLMs yield better-calibrated predictions, which partly explains why they solve different instances.

4.6.2
Internal Representations Diverge Across LLM Generations

To further understand how the three models differ, we examine the internal representations produced during answer generation.
Specifically, we record the context layer output, the final representation vector after self-attention at each of the 32 decoder layers for the generated answer token.
Each context vector has dimensionality 4096.
We analyze two properties: the magnitude of these representations across layers, and the similarity of representations across models at each layer.

Contextual representation magnitude.

Figure
4(a)
shows the mean magnitude of the context vectors across layers for each model.
The three models show qualitatively different activation profiles.
LLAMA-1 produces the largest activations, with magnitudes growing steeply through deeper layers and peaking at 82.2 in layer 31 before dropping to 50.2 in the final layer.
LLAMA-2 follows a similar growth pattern but at roughly half the scale, peaking at 46.5.
LLAMA-3’s magnitudes remain much smaller throughout, growing slowly and reaching only 14.6 at layer 31.

This progression from large growing activations in LLAMA-1 to small activations in LLAMA-3 may reflect the architectural and training improvements across models.
LLAMA-3 uses grouped query attention and was trained with improved normalization strategies, both of which contribute to more stable and compact internal representations.
Three LLM backbones process visual and textual information through very different internal dynamics, even when given identical inputs.
A model with small activations is unlikely to produce the same outputs as one with large, variable activations consistent with the different instance-level behavior we observed earlier.

Layer-to-layer contextual representation transition.

Beyond magnitude, we measure how each model transforms its context representations from one layer to the next.
For each model, we compute the cosine similarity between the context vectors of consecutive layers, layer
l
and layer
l{+}1
across all 32 decoder layers (Figure
4(b)
).
High similarity between adjacent layers means the representation changes gradually; low or negative similarity means the representation has an significant transformation at that transition.

The three models exhibit distinct layer-to-layer transition profiles.
LLAMA-1 shows moderate similarities in the early and middle layers (roughly 0.1–0.2), but in the deeper layers from around layer 20 onward the similarities drop sharply, reaching near-zero and negative values.
This means the representation has significant transformations in the later layers where the final answer is being formed.
LLAMA-2 follows a broadly similar pattern where moderate-to-high similarities in the middle layers (peaking at 0.36 around layer 11), followed by a drop to near-zero in the deeper layers, with a brief spike at layer 28 before turning negative again.
This aligns with their high instance-level correlation (
r=0.907
) (see Figure
1(e)
) as they process information through a similar internal pathway and arrive at the same answers.

LLAMA-3’s layer-to-layer similarities are higher and more stable in the early layers (0.15–0.39), and while they drops gradually in the deeper layers.
LLAMA-3 has no negative layer transitions at all.
This aligns with the negative instance-level correlation (
r=-0.266
and
r=-0.209
) (see Figure
1(e)
) as the model predicts its answers through a qualitatively different internal process.

This means LLAMA-3 builds its answer representation through incremental refinements at every layer, while LLAMA-1 and LLAMA-2 have significant contextual representational shifts in the deeper layers.
In older LLM backbones, the later decoder layers appear to significantly reorganize the contextual representation before producing the final answer, a process that may be less stable and more prone to committing to incorrect outputs with high confidence.
LLAMA-3’s processing pipeline is consistent with both its better calibration (it does not overcommit) and its different instance-level behavior (it arrives at answers through a different internal pathway).
This has implications for how we evaluate VLM progresss, two models with similar aggregate accuracy can have very different internal mechanisms, and a model with higher accuracy may achieve it through an entirely different route than its predecessor.

Takeaway 8: VLMs with newer LLM backbones process information through a different internal pathway

LLAMA-3 based VLMs predict the answer through incremental refinements over the layers. LLAMA-1 and LLAMA-2 rely on large activations and significant contextual shifts in the deeper layers. These internal differences may provide a mechanistic explanation for why the models solve different instances despite receiving identical visual and textual inputs.

5
Conclusion

In this work, we study whether newer LLM backbones lead to better VLM downstream task performance.
To answer this question, we designed a controlled study where we change the LLM backbone from LLaMA-1 through LLaMA-2 to LLaMA-3 while the vision encoder, training data, and codebase remain the same when training a VLM.
We evaluated the resulting VLMs on three downstream tasks spanning different domains.

Our main takeaways are as follows.
First, a newer LLM backbone does not consistently produce a better VLM, but the performance depends entirely on the downstream task.
Second, newer LLM backbones do not just solve the same questions better.
They solve
different
questions, and aggregate accuracy alone can hide these behavioral shifts.
Third, we noticed that newer LLM backbones process information through a qualitatively different pathway with better-calibrated confidence.
Fourth, certain VLM capabilities can emerge in newer LLM generations rather than improving gradually, particularly those requiring structured numerical output or domain-specific knowledge.
Finally, when a task is bottlenecked by visual perception, the LLM backbone is largely interchangeable, and improving the vision encoder is more likely to yield meaningful gains.

VQA-Scene Test Examples

Note that, each question is annotated with ten human answers, denoted

\mathcal{A}=\{a_{i}\}_{i=1}^{10}
. Let
\hat{a}
be the model’s predicted answer.
We first count how many human annotations exactly match the prediction:

\text{matching\_count}\;=\;\bigl|\{\,i\in\{1,\dots,10\}\;:\;a_{i}=\hat{a}\,\}\bigr|.

The VQA accuracy for this question is then computed as

\text{score}\;=\;\min\!\left(\frac{\text{matching\_count}}{3},\,1.0\right).

In words, if at least three out of ten humans provided the same answer as the model,
the prediction is considered fully correct (
\text{score}=1
); otherwise,
partial credit is awarded in increments of
\frac{1}{3}
(e.g., one match
\frac{1}{3}
,
two matches
\frac{2}{3}
).

Consider the question:
“Is the table sturdy?”
applied to the scene shown in the image (see fourth row in Table
4
).
The ground‐truth annotations consist of ten human answers.
In this example, seven annotators responded “yes” and three responded “no.”
Let
\hat{a}
be the model’s predicted answer. If the model also predicts “no,”
the number of matching human responses is

\text{matching\_count}=3.

Following the standard VQA accuracy protocol, the item score is computed as

\text{score}=\min\!\left(\frac{\text{matching\_count}}{3},\,1.0\right)=\min\!\left(\frac{3}{3},\,1.0\right)=1.0.

Because at least three annotators provided the same answer as the model, the prediction
is considered fully correct under the original VQA metric.
This illustrates a known caveat of the VQA metric, whenever at least three annotators agree on an answer, that answer is treated as fully correct.
The metric intentionally behaves this way to reflect the
inherent ambiguity and abstractness of certain visual questions, where multiple human answers can be considered valid and the level of agreement serves as a proxy for collective confidence.
