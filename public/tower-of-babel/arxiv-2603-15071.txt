On the equivalence between additive and linear codes
Kanat Abdukhalikov

Abstract
Additive codes have attracted considerable attention for their potential to outperform linear codes. However, distinguishing strictly additive codes from those that are equivalent to linear codes remains a fundamental challenge. To resolve this ambiguity, we introduce a deterministic test that requires only the generator matrix of the code. We apply this test to verify the strict additivity of several quaternary additive codes recently reported in the literature. Conversely, we demonstrate that a previously known additive complementary dual (ACD) code is equivalent to a linear Hermitian LCD code, thereby improving the best-known bounds for such linear codes.



Keywords
: Additive codes, linear complementary dual (LCD) codes, additive complementary dual (ACD) codes, quaternary codes, quasi-cyclic codes.

Mathematics subject classification
: 94B05, 94B15, 94B60.

1
Introduction

Additive codes have long been a subject of significant research interest, primarily due to their application in the construction of binary quantum codes, first shown in
[
11
]
. Additive codes have recently attracted renewed attention because they can provide examples of codes that outperform their linear counterparts, as demonstrated in
[
7
,
14
,
17
]
.

The relationship between additive and linear codes remains an active area of research. In
[
7
]
, it was established that every optimal quaternary additive code of dimension
k\leq 3
shares the same parameters as an optimal linear quaternary code. However, recent developments have demonstrated that this equivalence does not hold for higher dimensions. Notably,
[
5
]
and
[
17
]
constructed new additive codes with minimum distances exceeding the Griesmer bound for the corresponding linear codes, proving that they are strictly additive and not equivalent to any linear code.

A significant contribution to this field is the work of Guan, Li, Liu, and Ma
[
14
]
, who constructed numerous quaternary additive codes based on quasi-cyclic codes possessing higher minimum distances than the best-known linear codes of the same length and dimension.
This development raises a fundamental question: when a new additive code is constructed, how can one determine that it is not equivalent to an existing linear code with the same parameters? In
[
5
]
, Ball and Popatia noted that it remains unclear whether linear codes exist with the same parameters as those presented in
[
14
]
.

In this paper, we provide an answer to this question by formulating a deterministic test to determine whether an additive code is equivalent to a linear code.
Our approach is purely algebraic and requires only the generator matrix of the code.
Using this framework, we computationally verify that the additive codes constructed in
[
14
]
and
[
18
]

are not equivalent to any linear codes.
Furthermore, in
[
12
]
, it was established that for
q>4
, every linear code is equivalent to a Hermitian LCD code.
Motivated by this result, we investigate whether quaternary additive complementary dual (ACD) codes constructed in
[
14
]
can be equivalent to linear Hermitian LCD codes.
We provide one such example where a quaternary ACD code is shown to be equivalent to a linear Hermitian LCD code.

To the best of our knowledge, existing methods for distinguishing strictly additive codes from those that are equivalent to linear codes rely primarily on geometric techniques, as seen in
[
1
,
3
,
4
,
5
,
8
]
.
In the case of MDS codes, Adriaensen and Ball
[
1
]
established sufficient conditions under which an additive MDS code must be equivalent to a linear code, using geometric techniques based on pseudo-arcs and Desarguesian spreads.
In contrast, we provide an algebraic method based on the generator matrix that applies to any additive code.

The content of the paper is organized as follows.
In Section 2, we recall preliminary results and definitions.
In Section 3, we develop the algebraic framework for the equivalence test, including characterizations of when an additive code is equivalent to a linear code, and present a deterministic algorithm based on the generator matrix of the code.
In Section 4, we demonstrate the applicability of this test to known additive codes.

All computations in this paper have been done with the computer algebra system MAGMA
[
10
]
.

2
Preliminaries

Let
\mathbb{F}_{q}
be a finite field of
q
elements, and let
\mathbb{F}_{q^{2}}^{*}=\langle\omega\rangle
, where
\omega
is a primitive element of
\mathbb{F}_{q^{2}}
. We denote by
\mathbb{F}_{q}^{n\times m}
the
\mathbb{F}_{q}
-vector space of matrices of size
n\times m
with entries in
\mathbb{F}_{q}
. While the algebraic framework introduced in this paper can be naturally generalized to additive codes over
\mathbb{F}_{q^{h}}
for any
h\geq 2
, we restrict our attention to the case
h=2
to directly address the significant interest in quaternary codes found in the recent literature.

2.1
Additive codes

We fix
\{1,\omega\}
as a basis of
\mathbb{F}_{q^{2}}
over
\mathbb{F}_{q}
. Hence, any element
z_{i}\in\mathbb{F}_{q^{2}}
can be uniquely written as
z_{i}=x_{i}+\omega y_{i}
for
x_{i},y_{i}\in\mathbb{F}_{q}
. For any vector
z=(z_{1},z_{2},\dots,z_{n})\in\mathbb{F}_{q^{2}}^{n}
, we define
\phi:\mathbb{F}_{q^{2}}^{n}\to\mathbb{F}_{q}^{2n}
as

\phi(z)=(x_{1},y_{1}\mid x_{2},y_{2}\mid\dots\mid x_{n},y_{n}),

where the vertical bars separate the
n
coordinate pairs.

We follow the notation of additive codes from
[
5
]
and
[
17
]
. An
[n,k/2]_{q}^{2}
additive code
C
is an
\mathbb{F}_{q}
-linear subgroup of
\mathbb{F}_{q^{2}}^{n}
of size
q^{k}
. Its image
\phi(C)
is a
k
-dimensional
\mathbb{F}_{q}
-linear subspace of
\mathbb{F}_{q}^{2n}
.
The subspace
\phi(C)
can be described in terms of a
generator matrix

G\in\mathbb{F}_{q}^{k\times 2n}
of rank
k
, whose rows form an
\mathbb{F}_{q}
-basis for
\phi(C)
.
We then define the generator matrix of the additive code
C
to be this same matrix
G
.

The Hamming distance
d_{H}(u,v)
between two vectors
u,v\in\mathbb{F}_{q^{2}}^{n}
is defined as the number of coordinates in which they differ. The Hamming weight
\text{wt}_{H}(z)
of a vector
z=(z_{1},\dots,z_{n})\in\mathbb{F}_{q^{2}}^{n}
is defined as the number of non-zero coordinates, i.e.,
\text{wt}_{H}(z)=|\{1\leq i\leq n\mid z_{i}\neq 0\}|
. Because an additive code is closed under addition, its minimum Hamming distance is equal to the minimum Hamming weight among all its non-zero codewords. An
[n,k/2]_{q}^{2}
additive code with a minimum Hamming distance
d
is denoted as an
[n,k/2,d]_{q}^{2}
code. Thus, an
[n,k,d]_{q}^{1}
code is a standard linear code. Under the map
\phi
, the condition
z_{i}\neq 0
holds if and only if the corresponding pair
(x_{i},y_{i})\neq(0,0)
in
\mathbb{F}_{q}^{2n}
.

2.2
Equivalence of additive codes

We first define the standard notion of equivalence for additive codes over
\mathbb{F}_{q^{2}}
, see for example in
[
6
, Section 9.3]
.

Definition 2.1

(Monomial Equivalence)
.

Let
C,D\subseteq\mathbb{F}_{q^{2}}^{n}
be two additive codes.
We say that
C
and
D
are
monomially equivalent
if there exist a permutation
\pi\in S_{n}
and elements
A_{i}\in\mathrm{GL}_{2}(\mathbb{F}_{q})
such that

(z_{1},z_{2},\dots,z_{n})\in C\implies(z_{\pi(1)}A_{1},z_{\pi(2)}A_{2},\dots,z_{\pi(n)}A_{n})\in D

for all
z=(z_{1},z_{2},\dots,z_{n})\in C
. Here, we view each
A_{i}
as an
\mathbb{F}_{q}
-linear automorphism of
\mathbb{F}_{q^{2}}
acting on the right, where the elements of
\mathbb{F}_{q^{2}}
are represented as row vectors with respect to the basis
\{1,\omega\}
.

In terms of generator matrices,
C
and
D
are monomially equivalent if there exist
\mathbb{F}_{q}
-generator matrices
G
and
G^{\prime}
of their respective images
\phi(C)
and
\phi(D)
, an
n\times n
permutation matrix
P
, and a block-diagonal matrix
A=\mathrm{diag}(A_{1},A_{2},\dots,A_{n})
with
A_{i}\in\mathrm{GL}_{2}(\mathbb{F}_{q})
for
1\leq i\leq n
, such that

G^{\prime}=GA(P\otimes I_{2}).

(1)

Throughout this paper, when we say two codes are equivalent, we mean that they are monomially equivalent. We are interested in determining whether a given additive code is equivalent to a linear code over
\mathbb{F}_{q^{2}}
. We say that an additive code is
strictly additive
if it is not equivalent to any linear code over
\mathbb{F}_{q^{2}}
.

Definition 2.2

(
\mathrm{SL}
-Equivalence)
.

Two additive codes
C,D\subseteq\mathbb{F}_{q^{2}}^{n}
are
\mathrm{SL}
-equivalent
if they are monomially equivalent and the matrices
A_{i}
in Definition
2.1
belong to
\mathrm{SL}_{2}(\mathbb{F}_{q})
instead of
\mathrm{GL}_{2}(\mathbb{F}_{q})
.

Remark 1
.

By
[
20
, Lemma 13.3.8]
, any matrix
A_{i}\in\mathrm{GL}_{2}(\mathbb{F}_{q})
can generally be factored as
A_{i}=B_{i}D_{i}
, where
B_{i}\in\mathrm{SL}_{2}(\mathbb{F}_{q})
and
D_{i}=\mathrm{diag}(1,\det(A_{i}))
is a diagonal matrix. Applying the
\mathbb{F}_{q}
-linear automorphism corresponding to right-multiplication by
D_{i}
scales only one component of the row vector representation, and so it does not preserve
\mathbb{F}_{q^{2}}
-linearity. Consequently, for odd
q
, one must consider the full monomial equivalence.

However, when
q
is even, we can obtain a more convenient factorization. Because every element in a field of even characteristic is a perfect square, there always exists a unique
c\in\mathbb{F}_{q}^{*}
such that
c^{2}=\det(A_{i})
. This allows us to factor
A_{i}
instead as
A_{i}=B_{i}D_{i}
, where
B_{i}\in\mathrm{SL}_{2}(\mathbb{F}_{q})
and
D_{i}=cI_{2}
is a scalar matrix. In this case, right-multiplication by
D_{i}
acts as scalar multiplication by
c\in\mathbb{F}_{q}^{*}\subset\mathbb{F}_{q^{2}}^{*}
and preserves
\mathbb{F}_{q^{2}}
-linearity. Thus, when
q
is even, it is sufficient to check only for
\mathrm{SL}
-equivalence.

Conversely, applying a monomial equivalence transformation to an
\mathbb{F}_{q^{2}}
-linear code can result in an additive code that is not
\mathbb{F}_{q^{2}}
-linear (for example, see
[
16
, Exercise 558]
).

2.3
Inner products and ACD codes

For
\mathbf{x}=(x_{1},\dots,x_{n})
and
\mathbf{y}=(y_{1},\dots,y_{n})
in
\mathbb{F}_{q^{2}}^{n}
, the
alternating form
is defined by

\langle\mathbf{x},\mathbf{y}\rangle_{a}=\sum_{i=1}^{n}\frac{x_{i}y_{i}^{q}-x_{i}^{q}y_{i}}{\omega^{q}-\omega}.

For
\mathbf{u}=(a_{1},b_{1}\mid\dots\mid a_{n},b_{n})
and
\mathbf{v}=(c_{1},d_{1}\mid\dots\mid c_{n},d_{n})
in
\mathbb{F}_{q}^{2n}
, the
symplectic inner product
is defined as

\langle\mathbf{u},\mathbf{v}\rangle_{s}=\sum_{i=1}^{n}(a_{i}d_{i}-b_{i}c_{i}).

It can be checked that
\langle\mathbf{x},\mathbf{y}\rangle_{a}=\langle\phi(\mathbf{x}),\phi(\mathbf{y})\rangle_{s}
for any
\mathbf{x},\mathbf{y}\in\mathbb{F}_{q^{2}}^{n}
.
The
dual
of an additive code
C\subseteq\mathbb{F}_{q^{2}}^{n}
with respect to the alternating form is defined as

C^{\perp_{a}}=\{\mathbf{y}\in\mathbb{F}_{q^{2}}^{n}\mid\langle\mathbf{x},\mathbf{y}\rangle_{a}=0\text{ for all }\mathbf{x}\in C\}.

The
hull
of
C
is defined as
\mathrm{Hull}_{a}(C)=C\cap C^{\perp_{a}}
. An additive code
C
is called an
additive complementary dual
(ACD) code if its hull is trivial, i.e.,
\mathrm{Hull}_{a}(C)=\{\mathbf{0}\}
. Because
\phi
preserves the inner product, an additive code
C\subseteq\mathbb{F}_{q^{2}}^{n}
is an ACD code if and only if its image
\phi(C)
is a symplectic linear complementary dual (LCD) code (that is,
\phi(C)\cap\phi(C)^{\perp_{s}}=\{\mathbf{0}\}
).

Remark 2
.

Our consideration of SL-equivalence is motivated by the characterization of symplectic isometries over local Frobenius rings by Gluesing-Luerssen and Pllaha
[
13
, Theorem 7.1]
. As noted in
[
13
, Section 7]
, symplectic isometries preserve both the symplectic inner product and the symplectic distance. Since finite fields are local Frobenius rings, two additive codes are SL-equivalent if and only if they are related by a symplectic isometry.
Furthermore, since SL-equivalence preserves the symplectic inner product, any two SL-equivalent codes have the same hull dimension.

3
Equivalence test for linearity of codes

Let the minimal polynomial of
\omega
over
\mathbb{F}_{q}
be
x^{2}+c_{1}x+c_{0}
.
Following
[
20
, Section 13.2]
, we define the
2\times 2
companion matrix of
\omega
over
\mathbb{F}_{q}
as

\mathbf{M}_{\omega}=\begin{pmatrix}0&1\\
-c_{0}&-c_{1}\end{pmatrix}.

Since
\omega
generates the multiplicative group
\mathbb{F}_{q^{2}}^{*}
, the matrix
\mathbf{M}_{\omega}
generates a cyclic subgroup of
\textrm{GL}_{2}(\mathbb{F}_{q})
of order
q^{2}-1
, commonly known as a
Singer group
(or Singer cycle). The mapping
\Phi:\mathbb{F}_{q^{2}}\to\mathbb{F}_{q}^{2\times 2}
uniquely determined by
\Phi(\omega)=\mathbf{M}_{\omega}
defines a ring homomorphism, known as the regular representation of the field.

Under this representation, multiplying by any non-zero element
\alpha\in\mathbb{F}_{q^{2}}^{*}
corresponds to matrix multiplication within the Singer group. Since every non-zero element can be written as
\alpha=\omega^{i}
for some integer
i
, its corresponding matrix representation is
\mathbf{M}_{\alpha}=\mathbf{M}_{\omega}^{i}
. Alternatively, writing
\alpha
in the basis
\{1,\omega\}
as
\alpha=a+b\omega
, its matrix representation takes the linear form
\mathbf{M}_{\alpha}=aI_{2}+b\mathbf{M}_{\omega}
.

To extend this action to
\mathbb{F}_{q}^{2n}
, we define the
2n\times 2n
block-diagonal matrix
M_{\omega}=I_{n}\otimes\mathbf{M}_{\omega}
.

Theorem 3.1
.

Let
C\subseteq\mathbb{F}_{q^{2}}^{n}
be an additive code of
\mathbb{F}_{q}
-dimension
k
, and let
G\in\mathbb{F}_{q}^{k\times 2n}
be a generator matrix of
C
.
Then
C
is equivalent to an
\mathbb{F}_{q^{2}}
-linear code if and only if there exist
R\in\textrm{GL}_{k}(\mathbb{F}_{q})
and a block-diagonal matrix
A=\operatorname{diag}(A_{1},\dots,A_{n})
with

A_{i}\in\textrm{GL}_{2}(\mathbb{F}_{q})

such that

RG=G(AM_{\omega}A^{-1}).

Proof.

1. Assume that
C
is equivalent to an
\mathbb{F}_{q^{2}}
-linear code
C^{\prime}
. Since
G
is a generator matrix of
C
, there exists a generator matrix
G^{\prime}
of
C^{\prime}
such that
G^{\prime}=GA(P\otimes I_{2})
. Let
M=A(P\otimes I_{2})
, and so
G^{\prime}=GM
.

Since
C^{\prime}
is
\mathbb{F}_{q^{2}}
-linear, its image
\phi(C^{\prime})
is closed under scalar multiplication by
\omega
. This implies there exists
R\in\textrm{GL}_{k}(\mathbb{F}_{q})
such that
RG^{\prime}=G^{\prime}M_{\omega}
.
Substituting
G^{\prime}=GM
gives
R(GM)=(GM)M_{\omega}
, which implies
RG=G(MM_{\omega}M^{-1})
. Expanding
M
, we have

\displaystyle MM_{\omega}M^{-1}

\displaystyle=A(P\otimes I_{2})(I_{n}\otimes\mathbf{M}_{\omega})(P^{-1}\otimes I_{2})A^{-1}

\displaystyle=A(PI_{n}P^{-1}\otimes I_{2}\mathbf{M}_{\omega}I_{2})A^{-1}

\displaystyle=A(I_{n}\otimes\mathbf{M}_{\omega})A^{-1}

\displaystyle=AM_{\omega}A^{-1},

and so
RG=G(AM_{\omega}A^{-1}).

2. Assume that there exist
R\in\textrm{GL}_{k}(\mathbb{F}_{q})
and
A=\operatorname{diag}(A_{1},\dots,A_{n})

with
A_{i}\in\textrm{GL}_{2}(\mathbb{F}_{q})

such that
RG=G(AM_{\omega}A^{-1})
.
Let
C^{\prime}
be the code generated by
G^{\prime}=GA
.
By Definition
2.1
, the code
C^{\prime}
is equivalent to
C
.
Then

RG^{\prime}=R(GA)=(RG)A=G(AM_{\omega}A^{-1})A=GAM_{\omega}=G^{\prime}M_{\omega}.

This shows that
C^{\prime}
is an
\mathbb{F}_{q^{2}}
-linear code.
∎

For each
i=1,\dots,n
, let
G_{i}\in\mathbb{F}_{q}^{k\times 2}
denote the
i
-th block column of
G
, formed by the
(2i{-}1)
-th and
2i
-th columns, and let
U_{i}
denote the column space of
G_{i}
.
From the equation
RG=G(AM_{\omega}A^{-1})
, we have

RG_{i}=G_{i}T_{i},

where
T_{i}=A_{i}\mathbf{M}_{\omega}A_{i}^{-1}
. If
G_{i}
is the zero matrix for some
i
, then the
i
-th coordinate of every codeword is zero, and we may puncture this coordinate.
From now on we assume that
G_{i}
is nonzero for all
i
.
Define

\mathcal{R}=\{R\in\mathbb{F}_{q}^{k\times k}:R\,U_{i}\subseteq U_{i}\text{ for all }i=1,\dots,n\}.

It can be checked that
\mathcal{R}
is an
\mathbb{F}_{q}
-subspace of
\mathbb{F}_{q}^{k\times k}
.

Theorem 3.2
.

If
C
is equivalent to a linear code over
\mathbb{F}_{q^{2}}
, then there exists
R\in\mathcal{R}
that has no eigenvalue in
\mathbb{F}_{q}
.
In particular, if
\operatorname{rank}(G_{i})=1
for some
i
, then
C
is not equivalent to any linear code over
\mathbb{F}_{q^{2}}
.

Proof.

Assume that
C
is equivalent to a linear code over
\mathbb{F}_{q^{2}}
.
By Theorem
3.1
, there exists
R\in\mathcal{R}
with
RG_{i}=G_{i}T_{i}
for all
i
, where each
T_{i}
is conjugate to
\mathbf{M}_{\omega}
.
We recall that the minimal polynomial of
\omega
over
\mathbb{F}_{q}
is
x^{2}+c_{1}x+c_{0}
.
Since each
T_{i}
is conjugate to
\mathbf{M}_{\omega}
, we have
T_{i}^{2}+c_{1}T_{i}+c_{0}I_{2}=\mathbf{0}
for all
i
.
Then

(R^{2}+c_{1}R+c_{0}I_{k})\,G_{i}=G_{i}\,(T_{i}^{2}+c_{1}T_{i}+c_{0}I_{2})=\mathbf{0}.

Since
G
has rank
k
, the columns of
G_{1},\dots,G_{n}
span
\mathbb{F}_{q}^{k}
, so
R^{2}+c_{1}R+c_{0}I_{k}=\mathbf{0}
.
Therefore the minimal polynomial of
R
is also
x^{2}+c_{1}x+c_{0}
. Then
\mathbb{F}_{q}[R]=\{aI_{k}+bR:a,b\in\mathbb{F}_{q}\}\cong\mathbb{F}_{q^{2}}
is a field.
In particular,
R
has no eigenvalue in
\mathbb{F}_{q}
.

For the last statement, if
\operatorname{rank}(G_{i})=1
for some
i
, then every
R\in\mathcal{R}
preserves the one-dimensional subspace
U_{i}
, so every
R\in\mathcal{R}
has an eigenvalue in
\mathbb{F}_{q}
.
∎

We now assume that
\operatorname{rank}(G_{i})=2
for all
i
.
To compute
\mathcal{R}
, we transform the matrix equation
RG_{i}=G_{i}T_{i}
into a standard homogeneous
linear system using Kronecker products and vectorization, see for example
[
19
, Subsection 2.4]
.
For any matrix
X
, let
\mathrm{vec}(X)
denote its vectorization, defined as the single column vector containing the entries of
X
in column-major order.
Applying the vectorization identity
\mathrm{vec}(XYZ)=(Z^{T}\otimes X)\,\mathrm{vec}(Y)
(see
[
19
, Theorem 2.2]
) to both sides of
RG_{i}=G_{i}T_{i}
, we obtain

(G_{i}^{T}\otimes I_{k})\,\mathrm{vec}(R)-(I_{2}\otimes G_{i})\,\mathrm{vec}(T_{i})=\mathbf{0}.

In other words, we obtain the system
S\,\mathbf{x}=\mathbf{0}
, where

\mathbf{x}=\begin{pmatrix}\mathrm{vec}(R)\\
\mathrm{vec}(T_{1})\\
\vdots\\
\mathrm{vec}(T_{n})\end{pmatrix},

and
S
is the
2nk\times(k^{2}+4n)
matrix

S=\begin{bmatrix}G_{1}^{T}\otimes I_{k}&-(I_{2}\otimes G_{1})&0&\cdots&0\\
G_{2}^{T}\otimes I_{k}&0&-(I_{2}\otimes G_{2})&\cdots&0\\
\vdots&\vdots&\vdots&\ddots&\vdots\\
G_{n}^{T}\otimes I_{k}&0&0&\cdots&-(I_{2}\otimes G_{n})\end{bmatrix}.

(2)

Since
\operatorname{rank}(G_{i})=2
, the matrix
T_{i}
is uniquely determined by
R
from the relation
RG_{i}=G_{i}T_{i}
. Conversely, given any
R\in\mathcal{R}
, defining
T_{i}
by this relation gives a vector
\mathbf{x}=(\mathrm{vec}(R),\mathrm{vec}(T_{1}),\dots,\mathrm{vec}(T_{n}))^{T}
in the null space of
S
. This is a bijection between
\mathcal{R}
and the null space of
S
. Since both are
\mathbb{F}_{q}
-vector spaces, we have

\dim_{\mathbb{F}_{q}}(\mathcal{R})=\mathrm{nullity}(S).

Theorem 3.3
.

Let
C\subseteq\mathbb{F}_{q^{2}}^{n}
be an additive code of
\mathbb{F}_{q}
-dimension
k
, and let
G\in\mathbb{F}_{q}^{k\times 2n}
be a generator matrix of
C
.
Assume that
\operatorname{rank}(G_{i})=2
for all
i
, and let
S
be the matrix defined in (
2
).
If
\mathrm{nullity}(S)
is odd, then
C
is not equivalent to any linear code over
\mathbb{F}_{q^{2}}
.

Proof.

Suppose for contradiction that
C
is equivalent to a linear code over
\mathbb{F}_{q^{2}}
.
By Theorem
3.1
, there exists
R\in\mathcal{R}
with
RG_{i}=G_{i}T_{i}
for all
i
, where each
T_{i}
is conjugate to
\mathbf{M}_{\omega}
.
From the proof of Theorem
3.2
, we have the isomorphism

\mathbb{F}_{q}[R]=\{aI_{k}+bR:a,b\in\mathbb{F}_{q}\}\cong\mathbb{F}_{q^{2}}.

In particular, every nonzero element
aI_{k}+bR
is invertible with inverse in
\mathbb{F}_{q}[R]
.

We now show
\dim_{\mathbb{F}_{q}}(\mathcal{R})
is even by constructing a basis in pairs.
Choose a nonzero
M_{1}\in\mathcal{R}
.
If
(aI_{k}+bR)M_{1}=\mathbf{0}
for some
(a,b)\neq(0,0)
, then
aI_{k}+bR
is invertible, giving
M_{1}=\mathbf{0}
, a contradiction. So
M_{1}
and
RM_{1}
are linearly independent.
If
\{M_{1},RM_{1}\}
does not span
\mathcal{R}
, choose
M_{2}\not\in\langle M_{1},RM_{1}\rangle
.
Suppose that
\{M_{1},RM_{1},M_{2},RM_{2}\}
is linearly dependent, that is

aM_{1}+bRM_{1}+cM_{2}+dRM_{2}=\mathbf{0},

for some
a,b,c,d\in\mathbb{F}_{q}
.
Rewriting,

(aI_{k}+bR)M_{1}+(cI_{k}+dR)M_{2}=\mathbf{0}.

If
(c,d)\neq(0,0)
, then
cI_{k}+dR
is invertible, and we can solve

M_{2}=-(cI_{k}+dR)^{-1}(aI_{k}+bR)\,M_{1}.

Since
(cI_{k}+dR)^{-1}\in\mathbb{F}_{q}[R]
, the product
(cI_{k}+dR)^{-1}(aI_{k}+bR)
also lies in
\mathbb{F}_{q}[R]
and hence equals
eI_{k}+fR
for some
e,f\in\mathbb{F}_{q}
.
This gives
M_{2}=eM_{1}+fRM_{1}\in\langle M_{1},RM_{1}\rangle
, a contradiction.
Hence

Conclusion

In this paper, we developed an algebraic framework for determining whether an additive code over
\mathbb{F}_{q^{2}}
is equivalent to a linear code. Our main contributions are the following.

1.

We characterized when an additive code is equivalent to a linear code (Theorem
3.1
), and derived a necessary eigenvalue condition for equivalence (Theorem
3.2
).

2.

We introduced the matrix
S
derived from the generator matrix of the code, and proved that odd nullity of
S
implies that the code is strictly additive (Theorem
3.3
). These results are summarized in Algorithm
1
.

3.

We applied our test to verify that all quaternary additive codes from
[
14
, Table II]
are strictly additive (Table
1
), and that all ten quaternary ACD codes from
[
18
, Table 2]
are strictly additive (Table
3
).

4.

We demonstrated that the
[22,10,9]^{2}_{2}
ACD code from
[
14
, Table IV]
is equivalent to a
[22,10,9]_{4}
Hermitian LCD code, improving the corresponding entry in
[
2
, Table 6]
.
