Optimized stacked ensemble approach for detecting position falsification in VANETs
Authors: K. Saranya, S. Ramakrishnan
Published: 2026

ABSTRACT
The road safety and traffic efficiency is enhanced by providing communication between Vehicles in Vehicle Ad hoc networks (VANETs). Position falsification attacks represent a significant threat in VANETs, where the accuracy and integrity of location-based information are critical for safe and efficient transportation. The misbehavior detection frameworks can effectively identify position falsification attacks. The frameworks employ machine learning classifiers trained on features derived from inter-vehicular communication data. Optimization can enhance a stacked ensemble model for misbehaviour detection by hyperparameter tuning of classifiers. The proposed methodology involves constructing a stacked ensemble model composed of five diverse base classifiers, such as K Nearest Neighbours Classifier (KNN), Ada Boost Classifier (ADA), Extra Trees Classifier (ETC), Random Forest (RF), and Extreme Gradient Boosting Classifier (XGBC). Meta Classifier is used to combine predictions from the individual classifiers with logistic regression. To achieve the highest accuracy, Artificial Bee Colony (ABC) optimization is used to enhance the hyperparameters for the base classifiers. The optimized stacked ensemble model shows that our model provides the best results when compared with the existing methods.

Introduction

Intelligent Transport Systems is an advanced technology that can enable efficient wireless communication to improve road safety. Moving nodes are connected to the network by an on-board unit mounted on the vehicle. The unit allows for vehicle-to-vehicle communication. There are also roadside units that help the vehicles to communicate with infrastructure1. Vehicles become possible targets for malicious people because these networks allow them to exchange information with infrastructure and with one another.

Network communication between vehicles, pedestrians, and the network infrastructure is made possible via VANET. VANETs can be classified into the following types of communication2, which are depicted in Fig. 1. Data transmission between two vehicles can be done without the need for any infrastructure, and is known as vehicle-to-vehicle communication. Communication between different infrastructures and vehicles is referred to as vehicle-to-infrastructure, infrastructure-to-vehicle, and vehicle-to-RSU. In order to exchange critical information and real-time traffic updates, network infrastructures must communicate with one another through infrastructure-to-infrastructure communication3. Reliability and Safety are ensured by detecting and mitigating these attacks in VANET.Fig. 1Types of VANET communication.

Types of VANET communication.

Misbehaviour detection in VANET while using the VeReMi Dataset can be categorized into 3 types: position falsification detection, speed manipulation detection, and message replay detection. Position falsification detection is used to identify the vehicles that report fake or altered GPS positions, which can disrupt traffic flow or cause safety hazards4. Speed manipulation detection is used to detect a vehicle that reports incorrect speed values to influence traffic reports. Message replay detection is used to identify a vehicle sending previously captured valid messages repeatedly to confuse or flood the network.

The accuracy can be compared with RF, LR, KNN, NB, and SVM models using the VeReMi dataset, experimenting with voting and stacking to increase accuracy. The overall performance of the method is improved by combining multiple models. However, detection performance was notably lower for some types of attacks5. Hyperparameter optimization has a direct impact on model performance, generalization, and reliability; it is essential for machine learning (ML) models. Hyperparameters are manually set and regulate the model’s learning process, in contrast to model parameters, which are learned from data.

Hyperparameter tuning using ABC optimization

The misbehavior detection models must process large volumes of vehicular communication data generated in dynamic traffic environments. The Artificial Bee Colony Algorithm was selected for the proposed framework because it provides efficient optimization with stable convergence and lower computational overhead when compared with algorithms such as Genetic Algorithm (GA), Particle Swarm Optimization (PSO), Grey Wolf Optimizer (GWO), and Whale Optimization Algorithm (WOA). The adaptive exploration mechanism of the Artificial Bee Colony algorithm enables efficient search in high-dimensional feature spaces while maintaining scalability, making it suitable for optimizing feature selection and classifier parameters in VANET misbehavior detection systems16,17. Meta-classifier (logistic regression (LR))

Logistic Regression is commonly used as the meta-classifier because it learns the optimal weights for each base classifier’s prediction, allowing the ensemble to emphasize more reliable models while reducing the influence of weaker ones. Logistic regression is one of the most widely adopted meta-learners in stacking ensembles, particularly in classification tasks and imbalanced datasets. The popularity is due to its capability to efficiently combine heterogeneous classifiers and produce robust predictions with low computational complexity28.

The base classifiers independently estimate class probabilities using diverse learning mechanisms such as bagging (RF, ETC), instance-based learning (KNN), and boosting (XGBoost, AdaBoost). The formulation enables the stacked ensemble to effectively integrate heterogeneous model predictions and improve detection performance in VANET misbehavior scenarios.

The ABC optimization technique is employed to fine-tune hyperparameters for each base classifier, as described in Algorithm 1. Results and discussion

Dataset description

VeReMi is the first publicly available and extensible dataset32, generated using the Luxembourg SUMO Traffic (LuST) scenario through a VEINS-based co-simulation environment. Simulation of Urban Mobility (SUMO) models realistic vehicle mobility (e.g., position, speed, and traffic dynamics), while OMNeT + + handles vehicular communication aspects such as message exchange, delay, and packet loss. VEINS links the two simulators, allowing them to work together in real-time. The setup lets the mobility and communication layers interact, which is key for creating realistic scenarios. The dataset is further enhanced using the F2MD framework, which supports the simulation and evaluation of diverse misbehaviour detection scenarios.

Each simulation was executed with varying traffic densities to emulate realistic vehicular environments. Three density levels were analyzed, namely low, medium, and high traffic conditions. In the low-density scenario, the number of vehicles ranged between 35 and 39, generating up to 1,144 Basic Safety Message (BSM) records. The medium-density configuration included approximately 97 to 108 vehicles, producing nearly 4,489 BSM records. For the high-density environment, the number of vehicles varied from 491 to 519, resulting in a significantly larger dataset with up to 21,878 BSM records. The dataset contains multiple communication-related features extracted from vehicle beacon messages, including receiving time, transmission time, sender identifier, message identifier, RSSI value, position coordinates (x, y, z), speed components (x, y, z), as well as position and speed noise vectors. To simulate malicious behavior in the vehicular network, different attacker densities were introduced, where 10%, 20%, and 30% of the vehicles were configured as attackers in each scenario31.

The dataset contains 22,165,610 samples with 21 features, which after preprocessing were divided into 17,732,488 training samples (20 features) and 4,433,122 testing samples (20 features) using a stratified split to preserve the original class distribution across the 19 attack categories. Since the class frequencies range from 1,143,918 to 1,246,576 instances, the minority classes were balanced only in the training set using the Synthetic Minority Oversampling Technique (SMOTE) to prevent information leakage. SMOTE generates synthetic samples between nearest-neighbour instances of minority classes, increasing classes such as ConstPos, RandomPos, and EventualStop (~ 1,143,918 samples) toward the majority class GridSybil (1,246,576 samples). The balancing strategy improves the representation of less frequent attack behaviors while maintaining the original distribution in the test data for unbiased evaluation. Consequently, the classifiers in the stacked ensemble model are trained on a more balanced dataset, enabling better detection performance across all 19 misbehavior categories. The VeReMi Dataset contains vehicular communication attributes including rcvTime, senderID, receiverID, msgType, vehicleType, and attackerType, which describe the message transmission details and node identity in the network. It also provides spatial position information through pos_x, pos_y, and pos_z, representing the vehicle’s coordinates within the simulated road environment. In addition, motion-related parameters such as spd_x, spd_y, spd_z, heading, and acceleration capture the dynamic movement behavior of vehicles, enabling the analysis and detection of abnormal or falsified position reports in vehicular ad hoc networks.

The dataset contains several types of data collected from vehicular communication, including both benign and attack data. The dataset’s class categories are organized into three groups: Normal, Fault, and Attack. In that each group represents a specific type of vehicle behaviour, along with the total number of sequences for each type. The Normal group contains a single class (Type 0), which represents standard, correct vehicle behaviour without any errors or harmful actions32. The Fault category, which includes Types 1 through 8, captures unintentional yet erroneous behaviors that typically arise from issues like sensor failures or GPS inaccuracies. In contrast, the Attack category (Types 9 to 17) involves deliberate actions meant to compromise the integrity of the network, deceive participants, or degrade overall performance. Together, these categories provide a comprehensive basis for simulating both inadvertent faults and deliberate attacks, supporting the design and evaluation of effective misbehavior detection systems in VANETs.

Conclusion

To effectively detect the position falsification attacks using the VeReMi dataset, the proposed method uses a practical solution for enhancing security in vehicular networks. The ABC optimization algorithm is integrated with a stacked ensemble of machine learning models, which is used to improve the predictive accuracy, recall, precision, and F1-score. The ensemble model comprises the base classifiers such as RF, ETC, KNN, XGBC, and ADA, with Logistic Regression serving as the meta-classifier. Among the base classifiers, XGBoost and Random Forest demonstrated strong performance, but the stacking ensemble outperformed individual models in accuracy, recall, precision, and F1 Score. The AUC-ROC values confirmed that the ensemble approach reduced, making it highly effective for real-world applications. The method improves the security of vehicular networks against position falsification attacks. Real-world deployment faces challenges like dynamic network conditions, limited computing power in vehicles, differences from simulated data, and security risks. These are addressed using lightweight models, continuous learning, diverse real-world training data, and combining ML with rule-based methods for better reliability.

Practical implications

This model provides a viable and scalable solution for Intelligent Transport Systems and can increase the ability to accurately detect malicious vehicles while also improving the overall trust and security in the network.

Advantages

Higher detection accuracy due to the use of ensemble learning, increased reliability through collective learning and the ability to efficiently optimise the network using ABC makes the framework suitable for a wide range of different dynamic vehicular systems.

Limitations

The approach relies on a single meta-classifier and dataset-specific validation, which may limit generalizability across diverse real-world scenarios and large-scale deployments. The VeReMi dataset has limitations when it comes to using machine learning methods for detecting misbehavior in VANETs. These limitations include the usage of simulation-based data, a small number of attack types, and imbalanced classes. Each of these may have an impact on the capability of models to perform in real-life environments. The rapid change between vehicles can result in the effectiveness of models degrading as time passes. In addition, there is a limit on the available computational power and the potential for models to be manipulated by an intelligent adversary that can affect detection.

Future work

Future enhancements include extending to a dual meta-layer architecture with deep learning-based meta-learners and incorporating spatio-temporal modeling using graph-based approaches such as Graph Neural Networks to further improve detection capability. And the model will be extended to handle scenarios where multiple vehicles are compromised and colluding to falsify position data.
