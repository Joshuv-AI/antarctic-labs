PMF-CL: Pareto-Minimal-Forgetting Continual Learner for Conflicting Tasks
Srijith Nair, Atilla Eryilmaz, Jia (Kevin) Liu

Abstract
In the literature, many continual learning (CL) algorithms have been proposed to address the issue of catastrophic forgetting in ML models (i.e., learning new tasks leads to the loss of performance on previously learned tasks). Although all CL approaches use some form of memory to retain information about past tasks, a grounded understanding of what information needs to be stored to minimize catastrophic forgetting remains elusive. Recently, it has been recognized that under the strong assumption of the existence of a common global minimizer over all tasks, catastrophic forgetting can be completely avoided. However, in practice, tasks rarely have a common global minimizer, and a certain amount of forgetting is inevitable. In this paper, we propose a foundational framework for principled and systematic CL of conflicting tasks using a multi-task learning (MTL) perspective. The approach is based on finding Pareto-optimal solutions, i.e., the solutions which, by definition, minimally forget the previous tasks in the Pareto sense. We derive Pareto-minimal-forgetting CL algorithms for linear and basis-function regression, and general loss functions which have a quadratic upper bound, e.g., logistic regression. For quadratic problems, PMF-CL uses memory-efficient iterative updates with a static memory footage of 𝒪 ⁡ ( d 2 ) \mathcal{O}\left(d^{2}\right) for models with d d parameters.

3
Continual Learning as a Multi-Task Optimization Problem

In this section, we prove using first principles that continual learning
(CL) can be viewed as a sequential counterpart of Multi-Task Learning (MTL)

10
;
39
.
This connection allows us to derive a general CL meta-algorithm that achieves minimal catastrophic forgetting by finding the same solution as the MTL problem in hindsight.

3.1
Notation

In this paper, we consider a supervised CL setting with
T

sequential tasks.
Each task
t
has an associated dataset of
n_{t}
input-output pairs

\mathcal{D}_{t}=\{(\boldsymbol{x}_{i}^{t},\boldsymbol{y}_{i}^{t})\}_{i=1}^{n_{t}}

We consider a global model
\boldsymbol{f}_{\boldsymbol{\theta}}(\cdot):\mathcal{X}\to\mathcal{Y}
where
\boldsymbol{\theta}\in\mathcal{W}
is the set of model parameters
of
\boldsymbol{f}
.
The loss function for task
t
is defined as:

L_{t}(\boldsymbol{\theta}):=\mathcal{L}(\boldsymbol{\theta};\mathcal{D}_{t})=\frac{1}{n_{t}}\sum_{i=1}^{n_{t}}\ell(\boldsymbol{f}_{\boldsymbol{\theta}}(\boldsymbol{x}_{i}^{t}),\boldsymbol{y}_{i}^{t})

(1)

where
\ell:\mathcal{Y}\times\mathcal{Y}\to\mathbb{R}_{\geq 0}
is a
sample-wise loss function and remains fixed across tasks.
Notably, the model parameters
\boldsymbol{\theta}
and the loss functions

\mathcal{L}(\cdot;\cdot)
and
\ell(\cdot,\cdot)
are shared across all tasks,
with the task-specific dataset
\mathcal{D}_{t}
influencing the shape and
properties of each task’s loss function.

3.2
Multi-Task Learning

We begin by defining a few key concepts related to MTL and CL.

Definition 3.1

(Multi-task Learning)
.

The unconstrained Multi-Task Learning (MTL) problem for
T
tasks with
corresponding loss functions
L_{t}(\theta)
is defined as:

\min_{\theta\in\mathcal{W}}\left\{L_{1}(\theta),L_{2}(\theta),\ldots,L_{T}(\theta)\right\}

which is a joint optimization of all potentially conflicting task losses over the shared parameter
space.

Since the objectives in MTL can be in conflict with each other, zero-forgetting
is impossible in general, and one would seek a
Pareto optimal
solution or even the entire
Pareto frontier
(i.e., the collection of all Pareto optimal solutions) rather than a common global minimum for all objectives, which does
not
exist in general.
This is in contrast to gradient-projection-based approaches in the CL literature

49
;
34
;
44
, which assume a
common global minimizer, or approximate each task’s loss function until such an
approximation exists.

Since we will heavily rely on the concept of Pareto optimality, we formally
define these notions next.

Definition 3.2

(Pareto Dominance)
.

For the MTL problem defined in Definition
3.1
, a solution
\boldsymbol{\theta}_{a}
is
said to
Pareto dominate
another solution
\boldsymbol{\theta}_{b}
, denoted as

\boldsymbol{\theta}_{a}\succ\boldsymbol{\theta}_{b}
, iff:

L_{t}(\theta_{a})\leq L_{t}(\theta_{b}),\quad\forall t=1,2,\ldots,T

and there exists at least one task
t^{\prime}
such that:

L_{t^{\prime}}(\theta_{a})<L_{t^{\prime}}(\theta_{b}).

Based on the notion of Pareto dominance, we can now define Pareto optimality as
follows:

Definition 3.3

(Pareto Optimality)
.

For the MTL problem defined in Definition
3.1
, the Pareto optimal set, denoted
by
\mathcal{W}^{\star}
, is the set of all parameters in
\mathcal{W}
that
are not Pareto dominated by any other parameters in
\mathcal{W}
.

Definition 3.4

(Pareto Front)
.

The set of all non-dominated solutions in the loss space is called the

Pareto Front
(PF):

\mathcal{P}:=\{(L_{1}(\boldsymbol{\theta}),\dots,L_{T}(\boldsymbol{\theta})):\boldsymbol{\theta}\in\mathcal{W}^{\star}\}.

The most common approach to solving MTL problems is
linear scalarization

23
;
39
.
For convex problems, it is known that any Pareto optimal solution on the Pareto
front can be found by appropriately choosing a
preference vector

\boldsymbol{\alpha}^{(T)}\in\Delta^{T}
from the standard simplex and optimizing the preference-weighted sum of tasks as follows:

\boldsymbol{\theta}_{T}^{\star}:=\argmin_{\boldsymbol{\theta}\in\mathcal{W}}\sum_{t=1}^{T}\alpha_{t}^{(T)}L_{t}(\boldsymbol{\theta}).

(2)

Choosing the preference vector
\boldsymbol{\alpha}^{(T)}
in (
2
) in
terms of the number of training samples as:

\alpha_{t}^{(T)}=\frac{n_{t}}{\sum_{k=1}^{T}n_{k}},

(3)

we can retrieve the global empirical risk minimization (ERM) solution over all
tasks, as stated by the next lemma.
The proof is quite straightforward and is provided in Appendix
D.2
.

Lemma 3.5

(MTL for Global ERM)
.

The solution to the linearly-scalarized MTL problem in
(
2
) with preferences chosen as in
(
3
) is equivalent to the solution of the global
optimization problem
\boldsymbol{\theta}^{\star}=\argmin_{\boldsymbol{\theta}\in\mathcal{W}}\mathcal{L}(\boldsymbol{\theta};\mathcal{D}),

where
\mathcal{D}
is a concatenation of all datasets
\{\mathcal{D}_{1},\dots,\mathcal{D}_{T}\}
.

Remark 3.6
.

In the scenario where tasks repeat over time, the preference vector in
(
3
) automatically weights the repeated tasks more,
which is arguably desirable, and is analogous to having repeated
samples/batches in the global dataset
\mathcal{D}
.

3.3
Continual Learning as Sequential MTL

The key difference between MTL and CL is in the availability of the data.
In MTL, data from all tasks are available simultaneously, so the goal is to find a Pareto optimal solution.
In CL, there are two key differences from MTL:

1)
data from tasks are available
sequentially
, one at a time.

2)
the model must
evolve
after each task, without forgetting previous tasks.
Thus, a CL algorithm must maintain some
memory
of older tasks during optimization.
Here, we derive a general meta-algorithmic framework called
P
areto-
M
inimal-
F
orgetting
C

L

(PMF-CL).

First, we address the question:
What is the
necessary and sufficient amount of memory
to be stored of past tasks, to minimize forgetting in the Pareto sense for conflicting tasks?

Toward this end, we first concretely define ‘forgetting’:

Definition 3.7

(Forgetting)
.

We define the
degree of forgetting
of the
{t}^{\text{th}}
task by a
parameter
\boldsymbol{\theta}\in\mathcal{W}
in terms of the loss function

F_{t}(\boldsymbol{\theta}):=L_{t}(\boldsymbol{\theta})-\inf_{\boldsymbol{\theta}^{\prime}\in\mathcal{W}}L_{t}(\boldsymbol{\theta}^{\prime}),

and the
average forgetting
for the first
k

\overline{F}_{k}(\boldsymbol{\theta}):=\frac{1}{k}\sum_{t=1}^{k}F_{t}(\boldsymbol{\theta}).

Next, the task loss function defined in (
1

function of
\boldsymbol{\theta}
and fully characterized by the dataset

Consider an equivalent notation of the task loss in terms of the

We formally define the notion of MSI below:

Definition 3.8

(Minimal Sufficient Information; MSI)
.

For a given model
\boldsymbol{f}_{\boldsymbol{\theta}}(\cdot)
and sample loss
\ell(\cdot,\cdot)
, the

for task

Formally,
\mathcal{I}_{t}

0<|\mathcal{I}_{t}|\leq|\mathcal{D}_{t}|

\mathcal{\widetilde{L}}(\boldsymbol{\theta};\mathcal{I}_{t})=\mathcal{L}(\boldsymbol{\theta};\mathcal{D}_{t}),\forall~\boldsymbol{\theta}\in\mathcal{W}

and there exists no set
\mathcal{I}_{t}^{\prime}

\mathcal{\widetilde{L}}(\boldsymbol{\theta};\mathcal{I}_{t}^{\prime})=\mathcal{L}(\boldsymbol{\theta};\mathcal{D}_{t}),~\forall~\boldsymbol{\theta}\in\mathcal{W}

The minimal task information

is fully determined by the

\ell(f_{\boldsymbol{\theta}}(\cdot),\cdot)

In the following section, we show that for loss functions with a quadratic structure,

can be compact (such as the

In the worst case where the loss surfaces have a complex dependency on the data, the minimal information might require the entire dataset
\mathcal{D}_{t}

However, since the field of ML relies on the assumption that a finite-sized model can map arbitrary functions, there is reason to believe that most loss functions should have MSI much smaller than the dataset.

Based on the notion of MSI, we can propose the PMF-CL meta-algorithm

4.1
Linear Regression

In linear regression, the model is given by
f_{\boldsymbol{\theta}}(\boldsymbol{x})=\boldsymbol{\theta}^{\top}\boldsymbol{x}
where
\boldsymbol{\theta}\in{\mathbb{R}}^{d\times 1}
and the output is a scalar.
Under the mean squared error (MSE) loss function, task loss
L_{t}
can be written as:

L_{t}(\boldsymbol{\theta})=\mathcal{L}(\boldsymbol{\theta};\mathcal{D}_{t})=\frac{1}{2n_{t}}\left\|\boldsymbol{X}_{t}\boldsymbol{\theta}-\boldsymbol{y}_{t}\right\|_{2}^{2},

(4)

where
\boldsymbol{X}_{t}\in{\mathbb{R}}^{n_{t}\times d}
(resp.
\boldsymbol{Y}_{t}\in{\mathbb{R}}^{n_{t}\times 1}
) is a matrix with the inputs
\boldsymbol{x}_{t,i}
as rows (resp. vector of outputs

\boldsymbol{y}_{t,i}
).
In order to obtain the MSI of the quadratic loss function, we characterize the task data matrix
\boldsymbol{X}_{t}
via the
singular value decomposition
(SVD).

SVD and economy SVD.

For the task data matrix
\boldsymbol{X}_{t}
, we define the SVD in two ways:

\boldsymbol{X}_{t}=\boldsymbol{U}_{t}\boldsymbol{\Sigma}_{t}\boldsymbol{V}_{t}^{\top}=\boldsymbol{U}_{t}^{e}\boldsymbol{\Sigma}_{t}^{e}{\boldsymbol{V}_{t}^{e}}^{\top},

where
\boldsymbol{U}_{t}\in{\mathbb{R}}^{n_{t}\times n_{t}}
and
\boldsymbol{V}_{t}\in{\mathbb{R}}^{d\times d}
are orthonormal matrices, i.e.,
\boldsymbol{V}^{\top}\boldsymbol{V}=\boldsymbol{V}\boldsymbol{V}^{\top}=\boldsymbol{I}_{d}
, and
\boldsymbol{U}^{\top}\boldsymbol{U}=\boldsymbol{U}\boldsymbol{U}^{\top}=\boldsymbol{I}_{n_{t}}
, and the singular values are the
diagonal elements of
\boldsymbol{\Sigma}_{t}\in{\mathbb{R}}^{n_{t}\times d}
.
The
economy SVD
(eSVD) stores only the singular vectors corresponding to the
non-zero singular values in
\Sigma_{t}
.
Suppose that the rank of
\boldsymbol{X}_{t}
is
r_{t}
.
Then, the matrices
\boldsymbol{U}_{t}^{e}\in{\mathbb{R}}^{n_{t}\times r_{t}}
and
\boldsymbol{V}_{t}^{e}\in{\mathbb{R}}^{d\times r_{t}}
can be truncated to contain the first
r_{t}
columns of

\boldsymbol{U}_{t}
and
\boldsymbol{V}_{t}
, respectively, and
\boldsymbol{\Sigma}_{t}^{e}\in{\mathbb{R}}^{r_{t}\times r_{t}}
is a diagonal matrix of positive reals.

Lemma 4.1

(MSI for Linear Regression)
.

Using the eSVD of
\boldsymbol{X}_{t}
, we can write the loss
function for linear regression as:

L_{t}(\boldsymbol{\theta})=\frac{1}{2n_{t}}\left\|{\boldsymbol{V}_{t}^{e}}^{\top}\boldsymbol{\theta}-\widetilde{\boldsymbol{y}}_{t}\right\|_{\boldsymbol{\Sigma}_{t}^{e}}^{2}+\min_{\boldsymbol{\theta}^{\prime}\in\mathcal{W}}L_{t}(\boldsymbol{\theta}^{\prime}),

(5)

where we use the notation
\left\|\boldsymbol{z}\right\|_{\boldsymbol{A}}^{2}:=\left\|\boldsymbol{A}\boldsymbol{z}\right\|_{2}^{2}
and
\boldsymbol{\widetilde{y}}={\boldsymbol{\Sigma}_{t}^{e}}^{-1}\boldsymbol{U}_{t}^{e}\boldsymbol{y}_{t}
.
Thus, the MSI for linear regression is
\mathcal{I}_{t}^{\mathrm{lin}}:=(\boldsymbol{V}_{t}^{e},\boldsymbol{\Sigma_{t}^{e}},\boldsymbol{\widetilde{y}})
, with memory

\mathrm{size}(\mathcal{I}_{t}^{\mathrm{lin}})=r_{t}(d+2)
.

The proof of Lemma
4.1

B.1.2
.
Since the last term in the RHS does not depend on
\boldsymbol{\theta}
, PMF-CL does not need to remember it.
Note that any representative set smaller than
\mathcal{I}_{t}^{\mathrm{lin}}

would inevitably forget the loss function shape, leading to forgetting in a CL

Thus,
\mathcal{I}_{t}^{\mathrm{lin}}
is indeed the
minimal
information
required to remember the
{t}^{\text{th}}

Based on the rank of
\boldsymbol{X}_{t}
:

•

If
\boldsymbol{X}_{t}
is rank-deficient, i.e.,

,

If

is full-column-rank, i.e.,

, and

Quadratic Upper Bounded Loss Functions

In general, it may not be easy to derive a specialized PMF-CL algorithm for any given loss functions, since the MSI
\mathcal{I}_{t}

Assumption 5.1

(Quadratic Upper Bound)
.

We assume that the loss function function
\mathcal{L}(\boldsymbol{\theta};\mathcal{D}_{t})
has a quadratic upper bound (QUB), i.e., for some p.s.d. Hessian matrix
\boldsymbol{H}_{t}
and task minimizer

\boldsymbol{\theta}_{t}^{\min}:=\argmin_{\boldsymbol{\theta}\in\mathcal{W}}\mathcal{L}(\boldsymbol{\theta};\mathcal{D}_{t})

L_{t}^{\mathrm{qub}}(\boldsymbol{\theta}):=L_{t}(\boldsymbol{\theta}_{t}^{\min})+\frac{1}{2}(\boldsymbol{\theta}-\boldsymbol{\theta}_{t}^{\min})^{T}\boldsymbol{H}_{t}(\boldsymbol{\theta}-\boldsymbol{\theta}_{t}^{\min}).

(9)

h>0

\forall\boldsymbol{\theta},\boldsymbol{\theta}^{\prime}\in\mathcal{W}

the linear regression case.

6
Conclusion

In this paper, we proposed a solution to the problem of continual
learning with conflicting tasks through the lens of multi-task learning, whereby the learner remembers loss surface representations of older tasks, and jointly optimizes them when learning new tasks.
Our approach is generally applicable to any loss function, provided they can be
represented by some minimal sufficient information to enable incremental updates.
We derive explicit iterative algorithms for PMF-CL linear and basis-function
regression, and for general loss functions with quadratic upper bounds (QUB), which subsumes linear classification problems.
PMF-CL enjoys constant memory costs with respect to the number of tasks.
Future directions include deriving PMF-CL algorithms for more complex models, such as standard deep neural networks
without
the QUB property.

Limitations

This paper presents a fundamental perspective on the problem of continual
machine learning and a principled approach to deriving Pareto-optimal solutions
after each task.
Currently, our idea generates efficient algorithms for problems with quadratic,
or quadratic upper bounded loss structures, and extensions to more general
domains, especially ones which diverge significantly from quadratic
approximations, remains an open problem to be addressed in future work.

Appendix A
Extended Literature Review

Foundations of Continual Learning.

The field of CL, or lifelong learning, emerged from early research in robotic agents and task rehearsal
52
;
53
;
51
. It is deeply rooted in cognitive science, as the ability to consolidate new information without overwriting existing knowledge is a hallmark of human intelligence
18
. In modern applications, maintaining this stability is critical for large-scale models in production, particularly in the biomedical sector
48
;
6
.

Empirical Methodologies.

The literature distinguishes three primary algorithmic families to mitigate forgetting
58
:

•

Replay-buffer Methods:

36
;
11
;
4
;
9
utilize a fixed memory buffer to store representative samples or generative features. Despite their success, these methods face challenges regarding memory sufficiency and lack a formal geometric intuition
56
.

•

Regularization Methods:

28
;
64
;
3
introduce penalty terms that constrain model updates. By identifying parameters critical to previous tasks—often via the Fisher Information Matrix—they ensure the model stays within low-loss regions for past objectives.

•

Gradient-Projection Methods:
Works such as
49
;
34
;
33
focus on the geometry of the gradient space, projecting updates onto the Null space of past feature correlations to ensure zero interference between tasks.

Theoretical Perspectives.

Understanding CL through loss geometry has gained significant traction.
35
argue that flatter minima promote better task transferability, while
7
provide a unifying framework for regularization. Recent work by
17
and
31
has established formal forgetting rates, with
31
achieving optimal
O(1/k)
rates via specific regularization schedules. Furthermore,
57
and
32
have analyzed how overparameterization and task signal alignment influence whether forgetting is benign.

Theoretical Limits and PMF-CL.

While
29
established that perfect avoidance of forgetting is NP-hard, PMF-CL navigates this by reformulating CL as a multi-task learning (MTL) problem. Unlike existing methods that do not guarantee Pareto-optimality, PMF-CL uses a quadratic upper-bound framework to compute solutions that are consistent with joint optimization in hindsight, operating within a polynomial time complexity.

.
In other words
\overline{\boldsymbol{V}}-\boldsymbol{V}(\boldsymbol{p})
is positive semi-definite.

Substituting the bound
\boldsymbol{V}(\boldsymbol{p})\preceq\overline{\boldsymbol{V}}
into
(
62
), we obtain the Hessian upper bound as:

\boldsymbol{H}_{t}:=\frac{1}{n_{t}}\overline{\boldsymbol{V}}\otimes\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t}

(64)

Computing the Loss Upper Bound.

From (
64
), we can compute the iterative PMF-CL update
for multi-class classification as follows. First, the upper bound for the

{t}^{\text{th}}
task is given by:

\displaystyle L_{t}^{\mathrm{ub}}(\boldsymbol{\Theta})

\displaystyle=L_{t}(\boldsymbol{\Theta}_{t}^{\min})+\frac{1}{2n_{t}}\mathrm{vec}(\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})^{\top}\left(\overline{\boldsymbol{V}}\otimes\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t}\right)\mathrm{vec}(\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})

(65)

\displaystyle=L_{t}(\boldsymbol{\Theta}_{t}^{\min})+\frac{1}{2n_{t}}\mathrm{Tr}((\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})^{\top}(\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t})(\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})\overline{\boldsymbol{V}})

(66)

\displaystyle=L_{t}(\boldsymbol{\Theta}_{t}^{\min})+\frac{1}{2n_{t}}\mathrm{Tr}((\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})^{\top}(\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t})(\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})\overline{\boldsymbol{V}})

(67)

where
\mathrm{vec}(\cdot)
is the vectorization operator.
We use the property that
\mathrm{vec}(\boldsymbol{A})^{\top}(\boldsymbol{B}\otimes\boldsymbol{C})\mathrm{vec}(\boldsymbol{A})=\mathrm{Tr}(\boldsymbol{A}^{\top}\boldsymbol{C}\boldsymbol{A}\boldsymbol{B})
for any
matrices
\boldsymbol{A}\in{\mathbb{R}}^{d\times K}
, symmetric matrix
\boldsymbol{B}\in{\mathbb{R}}^{K\times K}
, and gram matrix

\boldsymbol{X}^{\top}\boldsymbol{X}=:\boldsymbol{C}\in{\mathbb{R}}^{d\times d}
.

Iterative PMF-CL Update.

Computing the linear scalarization of the upper bounds, and setting its
derivative with respect to
\boldsymbol{\Theta}
to zero, we get the following linear
equation:

\left(\sum_{t=1}^{k}\frac{\alpha_{t}^{(k)}}{n_{t}}(\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t})\boldsymbol{\Theta}\right)\overline{\boldsymbol{V}}=\left(\sum_{t=1}^{k}\frac{\alpha_{t}^{(k)}}{n_{t}}\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t}\boldsymbol{\Theta}_{t}^{\min}\right)\overline{\boldsymbol{V}}

(68)

Since
\overline{\boldsymbol{V}}
is full-rank, it can be dropped, resulting in the simplified form:

\left(\sum_{t=1}^{k}\frac{\alpha_{t}^{(k)}}{n_{t}}\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t}\right)\boldsymbol{\Theta}=\left(\sum_{t=1}^{k}\frac{\alpha_{t}^{(k)}}{n_{t}}(\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t})\boldsymbol{\Theta}_{t}^{\min}\right)

(69)

An iterative solution can be determined by defining the accumulation matrix
\boldsymbol{A}_{k}
as:

\boldsymbol{A}_{k}:=\sum_{t=1}^{k}\frac{\alpha_{t}^{(k)}}{n_{t}}\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t}=\frac{N_{k-1}}{N_{k}}\boldsymbol{A}_{k}+\frac{\alpha_{k}^{(k)}}{n_{k}}\boldsymbol{V}_{t}^{e}{\boldsymbol{\Sigma}_{t}^{e}}^{2}{\boldsymbol{V}_{t}^{e}}^{\top}

(70)

where we expand the economy-SVD form of
\boldsymbol{X}_{t}
.
Then, the iterative PMF-CL update follows from (
11
) with

\boldsymbol{H}_{k}
replaced by
\frac{1}{n_{k}}\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t}
, i.e.:

\boldsymbol{A}_{k}\Delta\boldsymbol{\Theta}_{k}=\frac{\alpha_{k}^{(k)}}{n_{k}}\boldsymbol{V}_{t}^{e}{\boldsymbol{\Sigma}_{t}^{e}}^{2}{\boldsymbol{V}_{t}^{e}}^{\top}(\boldsymbol{\Theta}_{k}^{\min}-\boldsymbol{\Theta}_{k-1}^{\star})

(71)

which is identical to the iterative update of linear regression with
\widetilde{y}_{t}
replaced with
{\boldsymbol{V}_{t}^{e}}^{\top}\boldsymbol{\Theta}_{k}^{\min}
.
This iterative update enables us to compute the
PMF-CL solution with a worst-case static memory footprint of
\mathcal{O}\left(d^{2}\right)
to
store the singular values and the right singular matrix.

Forgetting bound.

From the loss upper bound obtained in (
67
), we can get the forgetting bound of task
t
after training upto task
k
as:

F_{t}^{(k)}\leq\frac{1}{2n_{t}}\mathrm{Tr}((\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})^{\top}(\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t})(\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})\overline{\boldsymbol{V}}).

(72)

Note that
2\overline{\boldsymbol{V}}
is an idempotent matrix, i.e.,
(2\overline{\boldsymbol{V}})^{2}=2\overline{\boldsymbol{V}}
; thus, we can write
\overline{\boldsymbol{V}}=\overline{\boldsymbol{V}}^{1/2}\overline{\boldsymbol{V}}^{1/2}
.
Hence, we get:

\displaystyle F_{t}^{(k)}

\displaystyle\leq\frac{1}{2n_{t}}\mathrm{Tr}((\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})^{\top}(\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t})(\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})\overline{\boldsymbol{V}}^{1/2}\overline{\boldsymbol{V}}^{1/2})

(73)

\displaystyle=\frac{1}{2n_{t}}\mathrm{Tr}(\overline{\boldsymbol{V}}^{1/2}(\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})^{\top}(\boldsymbol{X}_{t}^{\top}\boldsymbol{X}_{t})(\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})\overline{\boldsymbol{V}}^{1/2})

(74)

\displaystyle=\frac{1}{2n_{t}}\left\|\boldsymbol{X}_{t}(\boldsymbol{\Theta}-\boldsymbol{\Theta}_{t}^{\min})\overline{\boldsymbol{V}}^{1/2}\right\|_{F}^{2}

(75)

where the last equality is because
\overline{\boldsymbol{V}}
is symmetric.
The final bound is obtained by replacing
\boldsymbol{\Theta}
with the value computed by PMF-CL, which is
\boldsymbol{\Theta}=\boldsymbol{A}_{k}^{\dagger}\boldsymbol{\nu}_{k}
.
Then, we obtain the final forgetting bound as:

F_{t}^{(k)}\leq\frac{1}{2n_{t}}\left\|\boldsymbol{X}_{t}(\boldsymbol{A}_{k}^{\dagger}\boldsymbol{\nu}-\boldsymbol{\Theta}_{t}^{\min})\overline{\boldsymbol{V}}^{1/2}\right\|_{F}^{2}

(76)

Appendix G
Experimental Simulation Results

To empirically validate the efficacy of our proposed PMF-CL framework, we evaluate its performance against several established continual learning baselines.
Our experiments aim to answer the following questions: (1) How well does PMF-CL mitigate catastrophic forgetting compared to rehearsal and regularization-based methods?
(2) Can PMF-CL successfully converge to the global Pareto-optimal parameter set across multiple tasks?
(3) What are the computational trade-offs regarding memory footprint and execution time?

G.1
Experimental Setup and Implementation

Task Design:
We evaluate the proposed methods on a synthetic continual learning benchmark consisting of 10 sequential tasks.
For each task
k
, the input features
X_{k}
are sampled from a Gaussian distribution, while regression targets
y_{k}
are generated using ground truth parameters
\theta_{k}^{*}
that undergo a controlled stochastic shift between tasks.
Specifically, for task
k=1
,
\theta_{1}^{*}
is initialized randomly, and for subsequent tasks
k>1
, the parameters are updated via
\theta_{k}^{*}=\theta_{k-1}^{*}+\epsilon
, where
\epsilon\sim\mathcal{N}(0,\sigma^{2}I)
simulates drifting local minimizers.

PMF-CL Implementation:
Our framework utilizes a Pareto-minimal forgetting approach implemented within the
Mammoth
continual learning framework
2
.
The model employs Singular Value Decomposition (SVD) on task-specific data to facilitate efficient parameter updates by storing only the decomposed components (
V_{t},\Sigma_{t}
) rather than full covariance matrices.
These components are used to incrementally update an aggregate curvature matrix
A_{t}=(N_{t-1}/N_{t})A_{t-1}+\alpha^{(t)}V_{t}\Sigma_{t}^{2}V_{t}^{T}
, where
\alpha^{(t)}
serves as a preference weight to modulate task importance.
To ensure numerical stability, we apply Tikhonov regularization by adding
\lambda I
(with
\lambda=10^{-6}
) to the curvature matrix before solving for the Pareto-optimal parameter shift
\Delta\theta
.
The final update
\theta_{t}=\theta_{t-1}+\Delta\theta
allows the model to shift toward the global optimum of all observed tasks without requiring access to previous raw datasets.

Evaluation Protocol:
All reported metrics and plotted learning curves represent the average performance across 10 independent trials using randomly generated synthetic datasets.
Shaded regions in the plots denote
\pm 1
standard deviation from the mean.

Baselines:
We evaluate the performance of PMF-CL against three standard CL approaches, and a naive SGD baseline which completely forgets previous tasks:

•

SGD (Naive Fine-Tuning):
Sequential training on new tasks using Stochastic Gradient Descent without any memory or regularization.
This serves as an empirical lower bound, illustrating the maximum extent of catastrophic forgetting.

•

Experience Replay (ER)

12
:
A rehearsal strategy that maintains a fixed-size memory buffer of past episodic data, randomly interleaving it with the current task’s data to anchor historical knowledge.

•

Dark Experience Replay (DER)

9
:
An advanced rehearsal baseline that stores past data alongside their pre-softmax logits, enforcing consistency by penalizing deviations from historical outputs.

•

Synaptic Intelligence (SI)

64
:
A regularization-based approach that computes the importance of individual parameters online, applying a surrogate loss penalty to restrict updates on weights deemed critical for preceding tasks.

Compute resources.
All experiments were conducted using a single workstation equipped with an NVIDIA H100 GPU.
Numerical operations were implemented using the PyTorch framework
43
in Python.

G.3
Computational Complexity Analysis

Continual learning algorithms must carefully balance predictive performance with resource constraints.
We analyze the memory and time complexities of the evaluated methods in Figure

Memory Footprint:
As shown in Figure

While the replay buffer size for ER/DER aligns with the data retained by our method in this specific setting, PMF-CL offers a distinct structural advantage: its memory footprint is deterministic and fixed entirely by the problem’s dimensionality, whereas the memory requirements for rehearsal methods are heavily setting- and buffer-dependent.

Future iterations of PMF-CL could integrate approximate SVD methods to drastically reduce this overhead.
Furthermore, it should be noted that the baseline execution times are heavily parameterized by the chosen number of training iterations per task, making relative speed comparisons partially dependent on hyperparameter configurations.
