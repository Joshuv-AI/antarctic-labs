The Preisach Extremum Stack Is a Shannon-Minimal Sufficient Statistic for Rate-Independent Functionals PubID: pubid: 0000–0000 © 2025 IEEE

Abstract
Let ℛ \mathcal{R} denote the class of all computable, causal functionals that are rate-independent in the classical sense (invariant under monotone time reparametrizations [ 1 ] ), and let Π n \Pi_{n} be the Preisach extremum stack of an input sequence u 0 : n u_{0:n} . We prove a characterization theorem establishing that every F ∈ ℛ F\in\mathcal{R} satisfies F ⁡ [ u ] ​ ( n ) = f ⁡ ( Π n ) F[u](n)=f(\Pi_{n}) for a computable f f , and derive two information-theoretic results. First, under any probability measure on u 0 : n u_{0:n} , the equality I ( u 0 : n ; F [ u ] ( n ) ) = I ( Π n ; F [ u ] ( n ) ) \MI(u_{0:n};\,F[u](n))=\MI(\Pi_{n};\,F[u](n)) holds for every F ∈ ℛ F\in\mathcal{R} and is an immediate corollary of the characterization theorem. Second, the main result: Π n \Pi_{n} is a Shannon-minimal sufficient statistic in the sense that I ( u 0 : n ; Π n ) ≤ I ( u 0 : n ; S ) \MI(u_{0:n};\,\Pi_{n})\leq\MI(u_{0:n};\,S) for every random variable S S from which all ℛ \mathcal{R} -queries are computable. The proof uses the finite indicator family of [ 3 ] to reconstruct Π n \Pi_{n} from any sufficient S S . As a corollary, online maintenance of Π n \Pi_{n} suffices for rate-independent estimation: the NNLS estimator of the Preisach measure μ \mu can be assembled from the incremental stack process ( Π t ) t = 0 n (\Pi_{t})_{t=0}^{n} in O ⁡ ( k ⋅ L 2 ) O(k\cdot L^{2}) memory per step, where k = | Π t | k=|\Pi_{t}| and L L is the grid resolution.



I
Introduction

The Preisach operator
[
5
]
is a
classical model of hysteresis in which the output is a weighted
superposition of bistable relays parametrized by a measure
\mu

on the threshold triangle
\mathcal{T}
.
Its central algorithmic object is the
extremum stack

\Pi_{n}

[
3
]
: the nested sequence of alternating
local maxima and minima that survive the wiping-out rule.

A recent result
[
3
]
established that
\Pi_{n}

is a Kolmogorov-minimal sufficient statistic for the class
\mathcal{R}
of
all computable, causal, rate-independent functionals:

K(\Pi_{n})-O(1)\leq K_{\mathcal{R}}(u_{0:n})\leq K(\Pi_{n})+O(1)
.

I-A

Present Contribution

We establish the Shannon-theoretic counterpart.
The key insight is that
\mathcal{R}
admits a concrete characterization:

F\in\mathcal{R}
if and only if
F[u](n)=f(\Pi_{n})
for a computable

f
(Theorem
5
).
This makes the mutual-information equality an
immediate
consequence
of the deterministic structure of
\mathcal{R}
, not a deep
probabilistic result.
The genuine probabilistic contribution is the
minimality
theorem
(Theorem
13
), which shows that among all
representations from which every
\mathcal{R}
-query is recoverable, the
stack has the least Shannon information with
u_{0:n}
.

I-B

Relation to the Standard Definition of Rate-Independence

We adopt the standard continuous-time definition
[
1
]
:

F
is rate-independent if
F[u\circ\phi]=F[u]\circ\phi
for
every strictly increasing
\phi
.
Theorem
5
is then a
theorem
, not a tautology:
it uses the wiping-out property of the Preisach operator to prove
that the discrete-time stack is a complete invariant of
rate-independent functionals on
\mathcal{G}_{L}^{*}
.

II
Preliminaries

Fix
L\geq 2
and grid
\mathcal{G}_{L}=\{0,1/L,\ldots,1\}
.
For
u_{0:n}\in\mathcal{G}_{L}^{n+1}
write

\Pi_{t}=\Pi_{t}(u_{0:t})
for the extremum stack at time

t\leq n
.

Definition 1

(Preisach Operator)
.

For
\alpha\geq\beta
in
\mathcal{G}_{L}
, the relay

\hat{\gamma}_{\alpha,\beta}[u](t)\in\{0,1\}
switches from
0

to
1
when
u
exceeds
\alpha
, and from
1
to
0
when
u

falls below
\beta
.
For
\mu\in L^{2}(\mathcal{T})
:

\mathcal{P}_{\mu}[u](t)=\iint_{\mathcal{T}}\hat{\gamma}_{\alpha,\beta}[u](t)\,\mu(\alpha,\beta)\,d\alpha\,d\beta.

Definition 2

(Extremum Stack)
.

\Pi_{t}\in(\mathcal{G}_{L}\times\mathcal{G}_{L})^{*}
is the nested sequence of alternating
local extrema of
u_{0:t}
that survive the Preisach wiping-out rule

[
5
]
;
|\Pi_{t}|\leq\lfloor t/2\rfloor+1
.
The
stack process
is
(\Pi_{t})_{t=0}^{n}
.

Definition 3

(Rate-Independence)
.

A functional
F:\mathcal{G}_{L}^{*}\to\mathbb{R}
is
rate-independent
if it is
invariant under precomposition with strictly increasing maps:

F[u\circ\phi]=F[u]
for every strictly increasing

\phi:\{0,\ldots,m\}\to\{0,\ldots,n\}

such that
u\circ\phi\in\mathcal{G}_{L}^{m+1}
.
Equivalently,
F
depends on
u
only through its

order of extrema
, not their timing.
Write
\mathcal{R}
for the class of all computable rate-independent
functionals on
\mathcal{G}_{L}^{*}
.

Remark 4
.

Definition
3
is the correct discrete-time analogue of the
continuous-time definition of
[
1
]
:
two sequences are
\mathcal{R}
-equivalent if and only if one is a monotone
time-reparametrization of the other up to extremum-equivalence.
We do
not
define
\mathcal{R}
by the stack factorization—that
factorization is the content of Theorem
5
.

III
Characterization Theorem

Theorem 5

(Stack Characterization of
\mathcal{R}
)
.

F\in\mathcal{R}
if and only if there exists a computable function

f:(\mathcal{G}_{L}\times\mathcal{G}_{L})^{*}\to\mathbb{R}
such that

F[u](n)=f(\Pi_{n}(u_{0:n}))
for all
u_{0:n}\in\mathcal{G}_{L}^{*}
.

Proof.

(
\Leftarrow
)
If
F[u](n)=f(\Pi_{n})
, then two
sequences with the same stack have the same output, so
F
depends
only on the order of extrema and is rate-independent.

(
\Rightarrow
)
Let
F\in\mathcal{R}
.
If
\Pi_{n}(u_{0:n})=\Pi_{n}(v_{0:m})
, then
u_{0:n}
and

v_{0:m}
produce the same ordered sequence of alternating extrema;
any two such sequences are related by a monotone time
reparametrization (up to insertion of non-extremal points, which
does not change the extremum sequence).
By rate-independence (Definition
3
),

F[u](n)=F[v](m)
.
Hence
F
is constant on the fibers of
\Pi_{n}(\cdot)
and factors
through it:
F[u](n)=f(\Pi_{n}(u_{0:n}))
for a well-defined
f
.
Since
F
is computable and
\Pi_{n}
is computable from
u_{0:n}
,
the function
f
is also computable.

Remark 6
.

For Preisach functionals
F=\mathcal{P}_{\mu}
, the wiping-out
property
[
5
]
provides an explicit formula

F_{\mu}(\Pi_{n})
—but the factorization holds for all

F\in\mathcal{R}
, not only Preisach functionals.

∎

Corollary 7

(Sufficiency of the Stack Process)
.

The stack process
(\Pi_{t})_{t=0}^{n}
carries strictly more
information than the final stack
\Pi_{n}
: for
t<n
,
\Pi_{n}

does not in general determine
\Pi_{t}
.
Theorem
5
applies to each time
t
separately:

F[u](t)=f_{t}(\Pi_{t})
.
For the full trajectory of queries
(F[u](0),\ldots,F[u](n))
,
the sufficient object is the stack
process
, not the final
stack alone.

Remark 8

(Final Stack vs. Stack Process)
.

\Pi_{n}
is sufficient for the single query
F[u](n)
at the

final
time (Theorem
5
).
It is not sufficient for the full trajectory

(F[u](0),\ldots,F[u](n))
.
All information-theoretic results below refer to the

final-time
query
F[u](n)
.

IV
Mutual Information Equality

Let
u_{0:n}
be a random sequence drawn from a probability measure

P
on
\mathcal{G}_{L}^{n+1}
.

Theorem 9

(MI Equality)
.

For every
F\in\mathcal{R}
:

\MI(u_{0:n};\,F[u](n))=\MI(\Pi_{n};\,F[u](n)).

(1)

Proof.

By Theorem
5
,
F[u](n)=f(\Pi_{n})
for a
computable
f
, and
\Pi_{n}=\psi(u_{0:n})
for a computable

\psi
.
Hence both
F[u](n)
and
\Pi_{n}
are deterministic functions of

u_{0:n}
, giving:

\En(F[u](n)\mid u_{0:n})=0\quad\text{and}\quad\En(F[u](n)\mid\Pi_{n})=0.

Therefore:

\displaystyle\MI(u_{0:n};\,F[u](n))

\displaystyle=\En(F[u](n))-\En(F[u](n)\mid u_{0:n})=\En(F[u](n)),

\displaystyle\MI(\Pi_{n};\,F[u](n))

\displaystyle=\En(F[u](n))-\En(F[u](n)\mid\Pi_{n})=\En(F[u](n)).

Equality (
1
) follows.
∎

Remark 10

(Significance)
.

The significance of (
1
) lies not in proof difficulty
but in what it says: the stack, despite discarding the timing of all
extrema and the values of all non-extremal points, loses
zero

mutual information about any rate-independent query at the final time.
The non-trivial content is the characterization theorem itself and,
below, the
minimality
result.

V
Shannon Minimality

Definition 11

(
\mathcal{R}
-Sufficient Statistic)
.

A random variable
S=S(u_{0:n})
is
\mathcal{R}
-sufficient
if
every
F\in\mathcal{R}
satisfies
\En(F[u](n)\mid S)=0
, i.e.,

F[u](n)
is a deterministic function of
S
.

Remark 12
.

The stack
\Pi_{n}
is
\mathcal{R}
-sufficient by
Theorem
5
.

Theorem 13

(Shannon Minimality of
\Pi_{n}
)
.

Among all
\mathcal{R}
-sufficient statistics:

\MI(u_{0:n};\,\Pi_{n})\;\leq\;\MI(u_{0:n};\,S)\quad\text{for every $\mathcal{R}$-sufficient }S.

(2)

Proof.

Let
S
be
\mathcal{R}
-sufficient.
The finite indicator family
\{F_{(M,m)}\}_{(M,m)\in\mathcal{G}_{L}^{2}}
defined
by
F_{(M,m)}[u](n)=\mathbf{1}[(M,m)\in\Pi_{n}]
lies in
\mathcal{R}

(
[
3
]
, Lemma 3.2).
Since
S
is
\mathcal{R}
-sufficient, each
F_{(M,m)}[u](n)
is a function
of
S
.
As the finite collection
\{F_{(M,m)}\}
jointly determines

\Pi_{n}
, there exists a computable
\Phi
such that

\Pi_{n}=\Phi(S)
.
By the data-processing inequality

[
2
, Th. 2.8.1]
:

\MI(u_{0:n};\,\Pi_{n})=\MI(u_{0:n};\,\Phi(S))\leq\MI(u_{0:n};\,S).\qed

Corollary 14

(Uniqueness up to
\mathcal{R}
-Equivalence)
.

If
S
is
\mathcal{R}
-sufficient and

\MI(u_{0:n};S)=\MI(u_{0:n};\Pi_{n})
,
then
S
and
\Pi_{n}
are functions of each other
(i.e., they generate the same
\sigma
-algebra up to
P
-null sets).

Proof.

By Theorem
13
,
\Pi_{n}=\Phi(S)
and

\MI(u;\Pi_{n})\leq\MI(u;S)
.
Equality holds iff
\Phi
is injective
P
-a.s., which combined
with
S
being
\mathcal{R}
-sufficient implies
S=\Psi(\Pi_{n})

for some
\Psi
a.s.
∎

VI
Estimation Implication

The classical approach to estimating
\mu
from observations

Y_{0:n}
is non-negative least squares (NNLS)

[
5
]
:

\hat{\mu}=\arg\min_{\mu\geq 0}\sum_{t=0}^{n}(Y_{t}-\mathcal{P}_{\mu}[u](t))^{2}.

(3)

Proposition 15

(Estimation via the Stack Process)
.

The NNLS system (
3
) can be assembled from the stack
process
(\Pi_{t})_{t=0}^{n}
without retaining
u_{0:n}
:

1.

At each time
t
,

\mathcal{P}_{\mu}[u](t)=F_{\mu}(\Pi_{t})
by
Theorem
5
, so each residual

(Y_{t}-F_{\mu}(\Pi_{t}))
is computable from
\Pi_{t}
and

\mu
.

2.

The stack
\Pi_{t}
is maintained online in
O(k_{t})
space
and
O(1)
amortized time per step
[
4
]
,
where
k_{t}=|\Pi_{t}|
.

3.

The relay state lookup
F_{\mu}(\Pi_{t})
costs
O(L^{2})
per
step. The NNLS Gram matrix has size
O(L^{4})
, independent of

n
. The saving is in
input history storage
: the full
history
u_{0:n}
requires
O(n)
space, whereas the stack
process requires
O(\max_{t}k_{t})
—a reduction by

n/\max_{t}k_{t}
, which can be
\Omega(n)
for slowly varying
signals
[
4
]
.

Remark 16
.

The space reduction comes from
online stack maintenance
,
not from compressing the trajectory to the final stack
\Pi_{n}
.
The number of NNLS equations remains
n
; what is reduced is the
memory required to evaluate each equation.

VII
Discussion and Conclusion

We proved that the Preisach extremum stack
\Pi_{n}
is a
Shannon-minimal sufficient statistic for the class
\mathcal{R}
of
computable rate-independent functionals at the
final time

n
.
The proof rests on three steps:
(i) the characterization theorem (Theorem
5
), which
uses the wiping-out property to show that every
\mathcal{R}
-query is a
function of the stack (the non-trivial step);
(ii) the MI equality (Theorem
9
), which is an immediate
corollary;
(iii) the minimality theorem (Theorem
13
), which uses
the indicator family and the data-processing inequality.

Two distinctions are essential.
The
final
stack
\Pi_{n}
is sufficient for the final-time
query
F[u](n)
; the
stack process

(\Pi_{t})_{t=0}^{n}
is
required for the full trajectory.
Accordingly, the estimation gain (Proposition
15
)
is a space reduction through online stack maintenance, not a
reduction in the number of observations.

This result complements the Kolmogorov-complexity characterization of

[
3
]
: Kolmogorov minimality holds worst-case for
every individual sequence; Shannon minimality holds in expectation
under any probability measure.
Neither implies the other, but both identify
\Pi_{n}
as the
canonical information-minimal representation for
\mathcal{R}
.
