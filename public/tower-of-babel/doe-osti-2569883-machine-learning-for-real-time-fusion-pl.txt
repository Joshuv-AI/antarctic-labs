Background/Introduction
The goal of this project is to implement real-time analysis of 2D Beam Emission Spectroscopy (BES)
data to predict and control transient and high-bandwidth events at DIII-D. In essence, we wish to bring
high-bandwidth fluctuation diagnostics into the realm of real-time measurements and control. The BES
ML models will necessarily be deep neural networks (DNN) with a “data flow” architecture for
compatibility with high-throughput, low-latency evaluation on a field-programmable gate array (FPGA)
or other emerging processor technologies. The real-time output will be fed to the plasma control system
(PCS) for real-time control tasks, specifically for ELM control and avoidance and for QH-mode access
and sustainment.
We anticipate that the real-time analysis of fluctuation diagnostics will create new enabling technologies
to predict and control transient events such as confinement mode transitions, edge-localized modes,
Alfven eigenmode events, and disruptions. The proposed research is aligned with ITER research needs
and DIII-D programmatic goals. For instance, the prediction and avoidance of ELM events is critical for
ITER machine safety [Laggner]. Also, H-mode access with RMP ELM suppression in ITER is an active
research area due to high separatrix density, narrow SOL width [Kukushkin], and elevated LH transition
power threshold [Schmitz].

Project Objectives
The existing UW scope within the broader ML + Control collaboration is:
 • Development of machine learning (ML) models compatible with real-time, high-bandwidth
 inference using the BES data stream for the following applications
 o Real-time ELM (type-I) onset prediction
 o Real-time confinement mode identification, with a focus on QH-mode control
 • Implementation of ML models on a compute accelerator (such as an FPGA) for real-time, high-
 throughput inference using the BES data stream
 • Application of ML explainability techniques to distill the salient features in BES data that are
 predictive of ELM events and the confinement mode

Progress Report
The UW team is actively developing ML models compatible with real-time, high-bandwidth inference
using the BES data stream (64 channels at 1 MHz) for real-time (RT) ELM (type-I) onset prediction and
RT confinement mode identification. The high-bandwidth character of the application requires high-
throughput compute accelerators, such as an FPGA, which imposes the constraint for a “data flow” model
architecture. ELM onset prediction with a ~10 ms forecast horizon has proven to be more difficult than
we anticipated, and we have had several iterations of expanding the hand-labelled dataset. In fact, our
SLAC collaborators are exploring unsupervised ML methods to automate the ELM labelling effort. The
dataset is now sufficiently large that we must perform multi-node training on Perlmutter (~2-8 nodes with
4 A100s/node) to obtain sufficient training epochs (~500) for a single model in a reasonable amount of
time. Figure 1 shows the performance of a recent model for time-to-ELM prediction, but the model
performance on this test ELM event is among the best in the test dataset. We feel that the partial success
of existing models demonstrates the feasibility of time-to-ELM prediction using fluctuation diagnostics,
but additional improvement is clearly needed for a reliable and accurate predictor. The model uses a 128
µs window of BES data and shows reasonable ability to predict time-to-ELM for time horizons around 8
ms. The 8 ms prediction horizon is marginally adequate for activating RMP coils for ELM suppression

on DIII-D. However, ELM time scales will be longer on ITER due to larger spatial scales and higher
density, so ELM control with time-to-ELM prediction from fluctuation diagnostics will be easier, in some
sense. Given the challenge of ELM onset prediction using only the BES data stream, we are now
exploring the addition of RT Te and ne profiles from Thomson scatting (TS) at the model input layer.
The sample rate for RT TS is considerable slower at ~10 ms, so the RT TS profile would be used for BES
model evaluations until the next RT TS profile is acquired. With assistance from our PU and PPPL
collaborators, it is feasible for the PCS to relay RT TS to the BES inference engine such that RT ELM
onset prediction uses RT BES and RT TS data.
