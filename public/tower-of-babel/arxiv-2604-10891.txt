The Gated-Service M/GI/1 Queue with Single Vacations
and Its Application to Batch-Service Queues

Abstract




Abstract

In this paper, we consider the M/GI/1 queue with single vacations
under the gated service discipline. We obtain the probability
generating function of the stationary queue length, the
Laplace-Stieltjes transform of the system delay distribution in steady
state, and the joint transform of the busy cycle length and the number
of customers served in the busy cycle. Furthermore, as an application,
we consider a batch-service M/G/1 queue, where service times depend on
the number of customers in batch.

Keywords
M/GI/1 queue, gated service, single vacations,
batch-service, branching process, limiting distribution, final value
theorem

Mathematics Subject Classification

60K25, 60J80

Introduction

We consider the M/G/1 queue with single vacations under the gated
service discipline. Customers arrive according to a Poisson process
with rate
\lambda
. Service times of customers are independent and
identically distributed (i.i.d.) according to a general distribution

H(x)
(
x\geq 0
). We assume
\rho=\lambda\mathrm{E}[H]<1
, where
H

denotes a generic random variable for service times. Let

h^{*}(s)=\mathrm{E}[\exp(-sH)]
(
s>0
). The server serves customers
according to the gated service discipline with single vacations.

(i)

When the system is empty and the server is idle, the server waits for
the next arrival and starts the service as soon as the next customer
arrives. After the service completion, the server takes a vacation.

(ii-a)

If there are
k
(
k=1,2,\ldots
) waiting customers on return from a vacation,
the server serves those
k
customers successively and takes another vacation.

(ii-b)

If the system is empty on return from a vacation,
the server becomes idle.

We assume that vacation lengths are i.i.d. according to a general
distribution
V(x)
(
x\geq 0
) and
\mathrm{E}[V]<\infty
, where
V

denotes a generic random variable for vacation lengths. Let

v^{*}(s)=\mathrm{E}[\exp(-sV)]
(
s>0
).

M/GI/1 queues with gated vacations have been studied in the
literature, e.g.,
[
6
]
and references therein. Most of
them, however, consider so-called multiple-vacation queues, where if
the server finds the empty system on return from a vacation, the
server takes another vacation immediately, and to the best of our
knowledge, the above-mentioned single-vacation model has not been
considered. In
[
5
]
and
[
7
]
, the following model
is called the gated-service M/G/1 queue with single vacations: The
server becomes idle after taking a vacation if no customers arrive
during the vacation, regardless of whether waiting customers (who
arrived during services of other customers) exist or not, and the
server starts to serve customers when the next arrival occurs.

In what follows, we first consider the queue length and system delay
distributions in steady state. We then consider the joint distribution
of the length of a busy cycle and the number of customers served in
the busy cycle. Finally, we provide some remarks on the MAP/GI/1 queue
with gated vacations. For convenience, let
\{H_{i}\}_{i=1,2,\ldots}

(resp.
\{V_{i}\}_{i=1,2,\ldots}
) denote a sequence of i.i.d. random
variables whose distribution function is given by
H(x)

(resp.
V(x)
).

2
Queue length and system delay distributions

Let
N_{\lambda}(x)
(
x\geq 0
) denote the number of Poisson
arrivals with rate
\lambda
during an interval of length
x
. We
then define the probability generating functions (PGF)
a_{H}^{*}(z)
and

a_{V}^{*}(z)
as

a_{H}^{*}(z)=\mathrm{E}[z^{N_{\lambda}(H)}]=h^{*}(\lambda-\lambda z),\qquad a_{V}^{*}(z)=\mathrm{E}[z^{N_{\lambda}(V)}]=v^{*}(\lambda-\lambda z).

Let
L_{\rm B}
and
L_{\rm E}
denote the number of customers at the
beginning of a vacation and at the end of a vacation in steady state.
We define
\ell_{\rm B}^{*}(z)
and
\ell_{\rm E}^{*}(z)
as PGF’s of

L_{\rm B}
and
L_{\rm E}
.

\ell_{\rm B}^{*}(z)=\mathrm{E}[z^{L_{\rm B}}],\qquad\ell_{\rm E}^{*}(z)=\mathrm{E}[z^{L_{\rm E}}].

By definition, we have

\ell_{\rm E}^{*}(z)=\ell_{\rm B}^{*}(z)a_{V}^{*}(z),\qquad\ell_{\rm B}^{*}(z)=\ell_{\rm E}^{*}(a_{H}^{*}(z))-\ell_{\rm E}^{*}(0)+\ell_{\rm E}^{*}(0)a_{H}^{*}(z).

(1)

Let
L
denote the stationary queue length. It is clear that the
model is a special case of the M/GI/1 queue with generalized vacations

[
2
]
, so that the stochastic decomposition holds.

L=L_{\rm M/G/1}+L_{\rm V},

(2)

where
L_{\rm M/G/1}
denote the stationary queue length in the
ordinary M/GI/1 queue characterized by the arrival rate
\lambda
and
the service time distribution
H(x)
and
L_{\rm V}
denote the
conditional queue length in steady state, given that the server does
not serve customers. Note that
L_{\rm M/G/1}
and
L_{\rm V}
are
independent. Because

\Pr(\mbox{the server is idle}\mid\mbox{the server is not serving customers})=\frac{\ell_{\rm E}^{*}(0)\times 1/\lambda}{\mathrm{E}[V]+\ell_{\rm E}^{*}(0)\times 1/\lambda},

we have

L_{\rm V}=\begin{cases}0,&\mbox{with probability }\displaystyle\frac{\ell_{\rm E}^{*}(0)}{\lambda\mathrm{E}[V]+\ell_{\rm E}^{*}(0)},\\[11.38109pt]
L_{\rm B}+N_{\lambda}(\hat{V}),&\mbox{with probability }\displaystyle\frac{\lambda\mathrm{E}[V]}{\lambda\mathrm{E}[V]+\ell_{\rm E}^{*}(0)},\end{cases}

(3)

where
\hat{V}
denotes the equilibrium random variable of
V
, which is
independent of
L_{\rm B}
.

We define
\ell^{*}(z)
as the PGF of the stationary queue length
L
.

\ell^{*}(z)=\mathrm{E}[z^{L}],\quad|z|<1.

It then follows from (
2
) and
(
3
) that

\ell^{*}(z)=\ell_{\rm M/G/1}^{*}(z)\bigg[\frac{\ell_{\rm E}^{*}(0)}{\lambda\mathrm{E}[V]+\ell_{\rm E}^{*}(0)}+\frac{\lambda\mathrm{E}[V]}{\lambda\mathrm{E}[V]+\ell_{\rm E}^{*}(0)}\ell_{\rm B}^{*}(z)\frac{1-a_{V}^{*}(z)}{\lambda\mathrm{E}[V](1-z)}\bigg],\quad|z|<1,

(4)

where
\ell_{\rm M/G/1}^{*}(z)
denotes the PGF of the stationary queue
length in the ordinary M/GI/1 queue.

\ell_{\rm M/G/1}^{*}(z)=\frac{(1-\rho)(z-1)a_{H}^{*}(z)}{z-a_{H}^{*}(z)},\quad|z|<1.

(5)

We observe from (
1
) and
(
4
) that if
\ell_{\rm E}^{*}(z)
is
obtained,
\ell^{*}(z)
is determined completely. In what follows, we
derive
\ell_{\rm E}^{*}(z)
.

Let
Q_{n}
(
n=0,1,\ldots
) denote the number of customers at the end
of the
n
th vacation. It is clear that
\{Q_{n}\}
forms a
discrete-time Markov chain on
\mathbbm{Z}^{+}=\{0,1,\ldots\}
.
Because

\displaystyle\Pr(Q_{n+1}=j\mid Q_{n}=0)

\displaystyle>\Pr(N_{\lambda}(H)=0)\Pr(N_{\lambda}(V)=j)>0,

\displaystyle\Pr(Q_{n+1}=j\mid Q_{n}=i)

\displaystyle>\Pr(N_{\lambda}(H_{1}+H_{2}+\cdots+H_{i})=0)\Pr(N_{\lambda}(V)=j)>0,\quad i=1,2,\ldots,

for all
j\in\mathbbm{Z}^{+}
, the Markov chain
\{Q_{n}\}
is irreducible and
aperiodic. Furthermore, because
\rho<1
,
\mathrm{E}[V]<\infty
, and
for
j=1,2,\ldots
,

\mathrm{E}[Q_{n+1}\mid Q_{n}=j]<j\ \Leftrightarrow\ \lambda\big(j\mathrm{E}[H]+\mathrm{E}[V]\big)<j\ \Leftrightarrow\ j>\frac{\lambda\mathrm{E}[V]}{1-\rho},

there exists
j^{*}
such that
\mathrm{E}[Q_{n+1}\mid Q_{n}=j]<j
for all
j\geq j^{*}
, so that
\{Q_{n}\}
is positive recurrent. Therefore, if

\rho<1
and
\mathrm{E}[V]<\infty
, the limiting distribution of

\{Q_{n}\}
exists, i.e.,

\lim_{n\to\infty}\Pr(Q_{n}=k)=\Pr(L_{\rm E}=k),\quad k=0,1,\ldots.

(6)

Note that the limiting distribution is independent of the initial
state
Q_{0}
.

We define
q_{n}^{*}(z)
(
n=0,1,\ldots
) as the PGF of
Q_{n}
.

q_{n}^{*}(z)=\mathrm{E}[z^{Q_{n}}],\quad n=0,1,\ldots.

Theorem 1
.

The PGF
q_{n}^{*}(z)
(
n=1,2,\ldots
) satisfies

q_{n}^{*}(z)=q_{0}^{*}(\psi_{n}^{H}(z))\prod_{k=1}^{n}\psi_{k}^{V}(z)-\sum_{j=1}^{n}q_{n-j}^{*}(0)\big(1-\psi_{j}^{H}(z)\big)\prod_{k=1}^{j}\psi_{k}^{V}(z),\quad n=1,2,\ldots,

(7)

where
\psi_{n}^{H}(z)
and
\psi_{n}^{V}(z)
(
n=1,2,\ldots
) are defined
recursively as

\displaystyle\psi_{1}^{H}(z)

\displaystyle=a_{H}^{*}(z),\qquad\psi_{n}^{H}(z)=a_{H}^{*}\big(\psi_{n-1}^{H}(z)\big)=\psi_{n-1}^{H}\big(a_{H}^{*}(z)\big),\quad n=2,3,\ldots,

(8)

\displaystyle\psi_{1}^{V}(z)

\displaystyle=a_{V}^{*}(z),\qquad\psi_{n}^{V}(z)=a_{V}^{*}\big(\psi_{n-1}^{H}(z)\big),\quad n=2,3,\ldots.

(9)

Remark 2
.

If we model customers served in a busy period of the ordinary M/G/1
queue by a Galton-Watson branching process
[
1
]
,

\psi_{n}^{H}(z)
denote the number of customers in the
n
th
generation. Similarly,
\psi_{n}^{V}(z)
can be related to the number of
customers in the
n
th generation in a delayed busy period, where the
service time of the first customer follows the distribution
V(x)

Proof.

We prove Theorem
1
by induction.
By definition, we have

q_{1}^{*}(z)=\big(q_{0}^{*}(a_{H}^{*}(z))-q_{0}^{*}(0)+q_{0}^{*}(0)a_{H}^{*}(z)\big)a_{V}^{*}(z)=q_{0}^{*}(\psi_{1}^{H}(z))\psi_{1}^{V}(z)-q_{0}^{*}(0)\big(1-\psi_{1}^{H}(z)\big)\psi_{1}^{V}(z),

so that Theorem
1
holds for
n=1
.
Suppose Theorem
1
holds for some
n

(
n=1,2,\ldots
). It then follows that

\displaystyle q_{n+1}^{*}(z)

\displaystyle=\big(q_{n}^{*}(a_{H}^{*}(z))-q_{n}^{*}(0)+q_{n}^{*}(0)a_{H}^{*}(z)\big)a_{V}^{*}(z)

(10)

\displaystyle=\bigg[q_{0}^{*}(\psi_{n}^{H}(a_{H}^{*}(z)))\prod_{k=1}^{n}\psi_{k}^{V}(a_{H}^{*}(z))-\sum_{j=1}^{n}q_{n-j}^{*}(0)\big(1-\psi_{j}^{H}(a_{H}^{*}(z))\big)\prod_{k=1}^{j}\psi_{k}^{V}(a_{H}^{*}(z))\bigg]a_{V}^{*}(z)

\displaystyle\qquad{}-q_{n}^{*}(0)\big(1-a_{H}^{*}(z)\big)a_{V}^{*}(z)

\displaystyle=q_{0}^{*}(\psi_{n+1}^{H}(z))\bigg(\prod_{k=1}^{n}\psi_{k+1}^{V}(z)\bigg))\psi_{1}^{V}(z)-\sum_{j=1}^{n}q_{n-j}^{*}(0)\big(1-\psi_{j+1}^{H}(z)\big)\bigg(\prod_{k=1}^{j}\psi_{k+1}^{V}(z)\bigg)\psi_{1}^{V}(z)

\displaystyle\qquad{}-q_{n}^{*}(0)\big(1-\psi_{1}^{H}(z)\big)\psi_{1}^{V}(z)

\displaystyle=q_{0}^{*}(\psi_{n+1}^{H}(z))\prod_{k=1}^{n+1}\psi_{k+1}^{V}(z)-\sum_{j=2}^{n+1}q_{n+1-j}^{*}(0)\big(1-\psi_{j}^{H}(z)\big)\prod_{k=1}^{j}\psi_{k}^{V}(z)-q_{n}^{*}(0)\big(1-\psi_{1}^{H}(z)\big)\psi_{1}^{V}(z),

which shows that
Theorem
1
holds for
n+1
.

Lemma 3

(Final value theorem of the
Z
-transform)
.

If
\{a_{n}\}_{n=1,2,\ldots}
has a finite limit

, then

a^{*}=\lim_{n\to\infty}a_{n}=\lim_{\omega\to 1-}(1-\omega)\sum_{n=1}^{\infty}a_{n}\omega^{n}

For completeness, we provide the proof of Lemma

Theorem 4
.

If
\rho=\lambda\mathrm{E}[H]<1
and
\mathrm{E}[V]<\infty
,
\ell_{E}^{*}(z)
is given
by

\ell_{E}^{*}(z)=\prod_{k=1}^{\infty}\psi_{k}^{V}(z)-\ell_{E}^{*}(0)\sum_{n=1}^{\infty}\big(1-\psi_{n}^{H}(z)\big)\prod_{k=1}^{n}\psi_{k}^{V}(z),

(12)

where

\ell_{E}^{*}(0)=\displaystyle\frac{\displaystyle\prod_{k=1}^{\infty}\psi_{k}^{V}(0)}{1+\displaystyle\sum_{n=1}^{\infty}\big(1-\psi_{n}^{H}(0)\big)\displaystyle\prod_{k=1}^{n}\psi_{k}^{V}(0)}.

(13)

Proof.

We apply Lemma
3
to (
7

Specifically, multiplying both sides of (
7

(1-\omega)\omega^{n}
(

) and summing up both sides from

\displaystyle(1-\omega)\sum_{n=1}^{\infty}q_{n}^{*}(z)\omega^{n}

\displaystyle=(1-\omega)\sum_{n=1}^{\infty}\bigg(q_{0}^{*}\big(\psi_{n}^{H}(z)\big)\prod_{k=1}^{n}\psi_{k}^{V}(z)\bigg)\omega^{n}

\displaystyle\qquad\qquad\qquad{}-(1-\omega)\sum_{n=1}^{\infty}q_{n}^{*}(0)\omega^{n}\times\sum_{n=1}^{\infty}\bigg(\big(1-\psi_{n}^{H}(z)\big)\prod_{k=1}^{n}\psi_{k}^{V}(z)\bigg)\omega^{n}.

Taking the limit

Note here that

On the other hand,

\lim_{\omega\to 1-}\sum_{n=1}^{\infty}\bigg(\big(1-\psi_{n}^{H}(z)\big)\prod_{k=1}^{n}\psi_{k}^{V}(z)\bigg)\omega^{n}=\sum_{n=1}^{\infty}\bigg(\big(1-\psi_{n}^{H}(z)\big)\prod_{k=1}^{n}\psi_{k}^{V}(z)\bigg),

\displaystyle\leq\mbox{the mean number of customers served in a busy period of the ordinary

\displaystyle=\frac{1}{1-\rho}.

L
.
We define
\overline{L}^{(n)}

.
It then follows that

To compute
\overline{L}^{(n)}

\ell^{*}(z)a_{V}^{*}(z)=\ell_{\rm M/G/1}^{*}(z)\bigg[\frac{\ell_{\rm E}^{*}(0)}{\lambda\mathrm{E}[V]+\ell_{\rm E}^{*}(0)}\cdot a_{V}^{*}(z)+\frac{\lambda\mathrm{E}[V]}{\lambda\mathrm{E}[V]+\ell_{\rm E}^{*}(0)}\cdot\frac{1-a_{V}^{*}(z)}{\lambda\mathrm{E}[V](1-z)}\cdot\ell_{\rm E}^{*}(z)\bigg].

We then define

\overline{A}_{H}^{(n)}

\displaystyle\overline{L}^{(n)}

Remark 6

In the stationary M/G/1 queue with multiple vacations under the gated

3
Busy Cycle

The queue length process after the start of an idle period is
independent of the past history and the lengths of idle periods are
i.i.d. according to an exponential distribution with parameter

\lambda
. We define a busy cycle as an interval from the end of an
idle period to the start of the next idle period. Note that the system
is in an idle period and in a busy period alternately, and we can
regard this as an alternating renewal process.

For convenience, we assume that an arrival occurs at time 0, which
breaks an idle period, and we define
T^{*}
as

T^{*}=\mbox{the time when the busy cycle ends after time 0}.

We are interested in the joint distribution of
N^{*}
,
T^{*}
, and

M^{*}

\displaystyle N^{*}

\displaystyle=\mbox{the total number of customers served in $(0,T^{*}]$},

\displaystyle M^{*}

\displaystyle=\mbox{the number of vacations before time $T^{*}$}.

\theta_{n}(z,\omega)=\mathrm{E}\big[z^{N^{*}}e^{-\omega T^{*}}\mathbbm{1}_{\{M^{*}=n\}}\big],\quad n=1,2,\ldots.

(
n=2,3,\ldots

following delayed regenerative process. During the interval

policy, i.e., the service of the single customer arriving at time 0

T^{*}

vacation to the multiple vacation. Specifically, if there are no
waiting customers at the end of a vacation, the server takes another
vacation immediately. We note that the regenerative cycle in the
gated-service M/G/1 queue with multiple vacations is studied in

[
6

2

5
Remarks on gated-service MAP/GI/1 vacation queues

We remark on the inapplicability of the analytical approach in this
paper to gated-service MAP/GI/1 vacation queues. Let
\bm{e}
denote a
column vector of ones with an appropriate dimension. We assume that
customers arrive according to a MAP with representation

(\bm{C},\bm{D})
, where
\bm{D}\geq\bm{O}
,
\bm{D}\neq\bm{O}
,

(\bm{C}+\bm{D})\bm{e}=\bm{0}
, and
(-\bm{C})^{-1}\bm{D}
is an
irreducible stochastic matrix. Note that
\bm{C}+\bm{D}
represents
the infinitesimal generator of a continuous-time Markov chain

\{Y(t)\}
on the finite state space
\mathcal{M}=\{1,2,\ldots,|\mathcal{M}|\}
, and
customers arrive when transitions driven by
\bm{D}
occur.

As shown in Section
3
, as well as in

[
6
]
for the multiple-vacation case, the queue length
process in gated-service M/GI/1 vacation queues is closely related to
the superposition of the
independent
branching processes with
shifted generations. Note here that the independence of those
branching processes comes from the independent increment property of
Poisson arrivals. In the case of MAP arrivals, however, arrivals in
consecutive intervals are correlated, so that those branching
processes are correlated. As a result, the analytical approach in this
paper is not applicable to gated-service MAP/GI/1 vacation queues.

To clarify our claim, we consider a gated-service MAP/G/1 queue with
single vacations. Let
\tau_{n}
denote the end of the
n
th vacation
and we define
\bm{q}_{n}^{*}(z)
as

\bm{q}_{n}^{*}(z)=\big(q_{n,1}^{*}(z)\ \ q_{n,2}^{*}(z)\ \ \cdots\ \ q_{n,|\mathcal{M}|}^{*}(z)\big),

where

q_{n,i}^{*}(z)=\mathrm{E}\big[z^{L_{E}(\tau_{n})}\mathbbm{1}_{\{Y(\tau_{n})=i\}}\big],\quad i\in\mathcal{M}.

It then follows that (cf. (
10
))

\bm{q}_{n}^{*}(z)=\bm{q}_{n-1}^{*}\big(\bm{A}^{*}(z)\big)\bm{V}^{*}(z)-\bm{q}_{n-1}^{*}(0)\big[\bm{I}-\bm{A}^{*}(z)\big]\bm{V}^{*}(z),\quad n=1,2,\ldots,

(31)

where

\bm{A}^{*}(z)=\sum_{k=0}^{\infty}\bm{A}(k)z^{k}=\int_{0}^{\infty}\exp[(\bm{C}+z\bm{D})x]\mathrm{d}H(x),\qquad\bm{V}^{*}(z)=\sum_{k=0}^{\infty}\bm{V}(k)z^{k}=\int_{0}^{\infty}\exp[(\bm{C}+z\bm{D})x]\mathrm{d}V(x).

Note that our approach requires that (
31
) still holds
even if
\bm{A}^{*}(z)
is substituted for
z
, i.e.,

\bm{q}_{n}^{*}\big(\bm{A}^{*}(z)\big)=\bm{q}_{n-1}^{*}\big(\bm{A}^{*}\big(\bm{A}^{*}(z)\big)\big)\bm{V}^{*}\big(\bm{A}^{*}(z)\big)-\bm{q}_{n-1}^{*}(0)\big[\bm{I}-\bm{A}^{*}\big(\bm{A}^{*}(z)\big)\big]\bm{V}^{*}\big(\bm{A}^{*}(z)\big),\quad n=1,2,\ldots.

(32)

Unfortunately, however, (
32
) does not hold in
general. See Appendix
B
for details.
Therefore, the results in
[
8
]
are not correct in
general.

The left-hand side of (

) is then given by

\displaystyle\bm{q}_{n}^{*}\big(\bm{A}^{*}(z)\big)

\displaystyle=\sum_{k=0}^{\infty}\bigg[\sum_{j=0}^{k}\bm{f}_{n-1}(j)\bm{V}(k-j)\bigg]\big(\bm{A}^{*}(z)\big)^{k}

\displaystyle\qquad\qquad{}-\bm{g}_{n-1}(0)\bm{V}^{*}\big(\bm{A}^{*}(z)\big)+\bm{g}_{n-1}(0)\sum_{k=0}^{\infty}\bigg[\sum_{j=0}^{k}\bm{A}(j)\bm{V}(k-j)\bigg]\big(\bm{A}^{*}(z)\big)^{k}

\displaystyle=\sum_{j=0}^{\infty}\bm{f}_{n-1}(j)\sum_{k=0}^{\infty}\bm{V}(k)\big(\bm{A}^{*}(z)\big)^{j}\big(\bm{A}^{*}(z)\big)^{k}

\displaystyle\qquad\qquad{}-\bm{g}_{n-1}(0)\bm{V}^{*}\big(\bm{A}^{*}(z)\big)+\bm{g}_{n-1}(0)\sum_{j=0}^{\infty}\bm{A}(j)\sum_{k=0}^{\infty}\bm{V}(k)\big(\bm{A}^{*}(z)\big)^{j}\big(\bm{A}^{*}(z)\big)^{k},

(35)

\displaystyle\bm{q}_{n-1}^{*}\big(\bm{A}^{*}\big(\bm{A}^{*}(z)\big)\big)\bm{V}^{*}\big(\bm{A}^{*}(z)\big)-\bm{q}_{n-1}^{*}(0)\big[\bm{I}-\bm{A}^{*}\big(\bm{A}^{*}(z)\big)\big]\bm{V}^{*}\big(\bm{A}^{*}(z)\big)

\displaystyle=\bm{f}_{n-1}^{*}\big(\bm{A}^{*}(z))\big)\bm{V}^{*}\big(\bm{A}^{*}(z)\big)-\bm{q}_{n-1}^{*}(0)\bm{V}^{*}\big(\bm{A}^{*}(z)\big)+\bm{q}_{n-1}^{*}(0)\bm{A}^{*}\big(\bm{A}^{*}(z)\big)\bm{V}^{*}\big(\bm{A}^{*}(z)\big)

Note that (

For example, we assume
\bm{A}^{*}(z)\bm{V}(0)=\bm{V}(0)\bm{A}^{*}(z)

i.e.,

\int_{0}^{\infty}\exp[(\bm{C}+z\bm{D})x]\mathrm{d}H(x)\int_{0}^{\infty}\exp[\bm{C}y]\mathrm{d}V(y)=\int_{0}^{\infty}\exp[\bm{C}y]\mathrm{d}V(y)\int_{0}^{\infty}\exp[(\bm{C}+z\bm{D})x]\mathrm{d}H(x).

(38)

It is readily verified that (
38
) holds if

\bm{C}
and
\bm{D}
are commutative.

Suppose
\bm{C}
and
\bm{D}
are commutative. We then have

\bm{C}\bm{D}=\bm{D}\bm{C}\ \ \Leftrightarrow\ \ \bm{D}(-\bm{C})^{-1}=(-\bm{C})^{-1}\bm{D},

so that

\bm{D}(-\bm{C})^{-1}\bm{e}=(-\bm{C})^{-1}\bm{D}\bm{e}=(-\bm{C})^{-1}(-\bm{C})\bm{e}=(-\bm{C})(-\bm{C})^{-1}\bm{e},

which is equivalent to

(\bm{C}+\bm{D})\times(-\bm{C})^{-1}\bm{e}=\bm{0}.

(39)

Because
\bm{C}+\bm{D}
is an infinitesimal generator of an irreducible,
finite-state Markov chain, we have

(\bm{C}+\bm{D})\bm{x}=\bm{0}\ \ \Rightarrow\ \ \bm{x}=\alpha\bm{e},

(40)

where
\alpha
is an arbitrarily constant. It then follows from
(
39
),
(-\bm{C})^{-1}\bm{e}>\bm{0}
, and
(
40
) that there exists
\lambda>0
such that

(-\bm{C})^{-1}\bm{e}=\frac{1}{\lambda}\bm{e}.

Therefore, we have

\lambda\bm{e}=(-\bm{C})\bm{e}=\bm{D}\bm{e},

(41)

which implies that the arrival rate is independent of the underlying
Markov chain
\{Y_{t}\}
. We thus conclude that if
\bm{C}
and

\bm{D}
are commutative, the MAP with representation

(\bm{C},\bm{D})
is reduced to a Poisson process with rate

\lambda
. In fact, if
\bm{C}\bm{D}=\bm{D}\bm{C}
, we have
(
41
) and

\displaystyle\bm{A}^{*}(z)\bm{e}=\sum_{k=0}^{\infty}\bm{A}(k)\bm{e}z^{k}

\displaystyle=\int_{0}^{\infty}\exp[(\bm{C}+z\bm{D})x]\mathrm{d}H(x)\bm{e}=\int_{0}^{\infty}\exp[(\bm{C}x]\sum_{k=0}^{\infty}\frac{z^{k}\bm{D}^{k}\bm{e}x^{k}}{k!}\mathrm{d}H(x)

\displaystyle=\int_{0}^{\infty}\exp[(\bm{C}x]\bm{e}\sum_{k=0}^{\infty}\frac{z^{k}x^{k}\lambda^{k}}{k!}\mathrm{d}H(x)=\int_{0}^{\infty}\sum_{j=0}^{\infty}\frac{\bm{C}^{j}\bm{e}x^{j}}{j!}\sum_{k=0}^{\infty}\frac{z^{k}\lambda^{k}x^{k}}{k!}\mathrm{d}H(x)

\displaystyle=\int_{0}^{\infty}\sum_{j=0}^{\infty}\frac{(-\lambda)^{j}\bm{e}x^{j}}{j!}\sum_{k=0}^{\infty}\frac{z^{k}\lambda^{k}x^{k}}{k!}\mathrm{d}H(x)=\int_{0}^{\infty}e^{-\lambda x}\sum_{k=0}^{\infty}\frac{\lambda^{k}x^{k}}{k!}\mathrm{d}H(x)\bm{e}z^{k},

so that

\bm{A}(k)\bm{e}=\int_{0}^{\infty}e^{-\lambda x}\frac{(\lambda x)^{k}}{k!}\mathrm{d}H(x)\bm{e},\quad k=0,1,\ldots.
