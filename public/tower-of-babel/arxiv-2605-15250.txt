GQLA: Group-Query Latent Attention for Hardware-Adaptive Large Language Model Decoding
Fanxu Meng

Abstract
Multi-head Latent Attention (MLA), deployed in DeepSeek-V2/V3, jointly compresses keys and values into a low-rank latent and nearly saturates the H100 roofline. Its trained weights, however, expose only one decoding path—an absorbed MQA form—which couples efficient inference to H100-class compute-to-bandwidth ratios and forfeits head-axis tensor parallelism. We propose Group-Query Latent Attention (GQLA) , a minimal MLA variant whose trained weights expose two algebraically equivalent decoding paths: an MQA-absorb path identical to MLA’s, and a GQA path with a per-group expanded cache. The runtime selects the path that matches the target hardware—no retraining, no custom kernels—so a single set of weights pins the rooflines of both H100 (MQA-absorb) and H20 (GQA + MTP), while supporting 8 8 -way zero-redundancy tensor parallelism on the GQA path. To avoid pretraining from scratch we extend TransMLA into TransGQLA , converting both pretrained GQA and MLA checkpoints: on LLaMA-3-8B it compresses the KV cache to 28.125 % 28.125\% on the MQA-absorb path; on GLM-4.7 a calibration-only per-group activation PCA loses only ∼ 4.7 {\sim}4.7 Avg. points on commonsense reasoning with no gradient updates.

3.2.1
From GQA to GQLA

This route reuses the entire TransMLA pipeline (head merging, RoRoPE, FreqFold, KV-norm balancing) with one change at head merging.

Merging grouped heads to a latent head.

TransMLA folds GQA’s
g
KV heads into a latent and
replicates

W^{UK},W^{UV}
across all
h_{q}
query heads, so the merged module behaves as MHA. TransGQLA drops the replication:
W^{UK},W^{UV}
remain indexed by
j\in[1,g]
, so the merged module is standard GQA identical to the GQA path of §
3.1
, with MQA-absorb still reachable exactly as in MLA. Group-axis TP is therefore preserved, whereas MLA loses it once the up-projections are absorbed into
Q/O
.

The merged GQA attention is re-expressed as

\displaystyle\mathbf{q}_{t}=W^{Q}\mathbf{x}_{t},\;\;\mathbf{c}_{t}^{KV}=[\mathbf{c}_{t}^{K};\mathbf{c}_{t}^{V}]=W^{DKV}\mathbf{x}_{t},

\displaystyle\mathbf{\hat{q}}_{t,i}^{R}=\overline{\text{RoPE}}_{t}\!\left((W^{UK}_{j(i)})^{\!\top}\mathbf{q}_{t,i}\right),

\displaystyle\mathbf{\hat{k}}_{t}^{R}=\overline{\text{RoPE}}_{t}(\mathbf{c}_{t}^{K}),\;\;\mathbf{\hat{v}}_{t}=\mathbf{c}_{t}^{V},

\displaystyle\mathbf{\hat{o}}_{t,i}=\sum_{s=1}^{t}\softmax_{s}\!\left(\tfrac{\mathbf{\hat{q}}^{R^{\top}}_{t,i}\mathbf{\hat{k}}_{s}^{R}}{\sqrt{d_{h}}}\right)\mathbf{\hat{v}}_{s},

\displaystyle\mathbf{y}_{t}=W^{O}[W^{UV}_{j(1)}\mathbf{\hat{o}}_{t,1};\dots;W^{UV}_{j(h_{q})}\mathbf{\hat{o}}_{t,h_{q}}],

(4)

where
j(i)=\lceil i/(h_{q}/g)\rceil
routes head
i

\overline{\text{RoPE}}
folds the
g

d_{h}
dimensions. The cache stays at
2gd_{h}

RoRoPE: aligning per-head RoPE bases.

After the GQA-preserving merge each of the
g
KV heads still carries its own RoPE basis, blocking a single shared decoupled key. RoRoPE applies a per-head orthogonal rotation
R_{j}\in\mathbb{R}^{d_{h}\times d_{h}}
to
\mathbf{k}_{t,j}
and absorbs
R_{j}^{\top}
into the matching
W^{UQ}_{i}

\overline{\text{RoPE}}
in Eq. (
4

d_{h}
dimensions of the latent in place of
g

FreqFold: frequency-aware PCA.

A naive PCA on the merged
gd_{h}
-dim K/V matrix would mix rotated and non-rotated coordinates and destroy the RoPE pair structure. FreqFold partitions dimensions by RoPE frequency band and applies PCA
within
each band, so the resulting low-rank basis cleanly factorises into a NoPE part (compressed into the latent
\mathbf{c}^{KV}_{t}\in\mathbb{R}^{r_{kv}}

\mathbf{k}^{R}_{t}\in\mathbb{R}^{d_{h}^{R}}

K_{\text{nope}}/V
norm balancing and joint compression.

The NoPE part of
K
and the value tensor
V
have very different activation norms, so a joint PCA over
[K_{\text{nope}};V]
wastes rank on whichever side has larger variance and starves the other. We rescale each side to comparable Frobenius norm and absorb the inverse scale back into
W^{UK},W^{UV}
(forward pass unchanged); a single joint PCA then compresses both sides to
r_{kv}
while retaining nearly all reconstruction energy on each.

All three stages operate purely on the merged
gd_{h}

(
12
)

From MLA to GQLA

A pretrained MLA model shares the joint latent with GQLA but exposes only the MQA-absorb path, because its

The converted checkpoint runs the standard GQA kernel with no custom code:

3.3
Sparse GQLA

Following DSA
(
11
)
, fine-grained sparse attention attends only over
\mathcal{S}_{t}=\mathrm{top}\text{-}k(I_{t,:})
, with per-head output
\mathbf{u}_{t,j}=\sum_{s\in\mathcal{S}_{t}}\softmax(\mathbf{q}_{t,j}^{\top}\mathbf{k}_{s,\,g(j)}/\sqrt{d_{h}})\,\mathbf{v}_{s,\,g(j)}

Sparse MLA is locked into MQA-absorb.

Because

varies per query, each token’s attention must be issued as a single GEMM. Tensor Cores require MMA tiles with
m\!\geq\!16
(e.g.
m16n16k16
), i.e. at least
16
query heads sharing one KV head. MLA in MHA mode has only one query head per KV head (
m\!=\!1
), so the GEMM degenerates to a GEMV and falls off Tensor Cores entirely. Sparse MLA is therefore forced into MQA-absorb on every device, inheriting dense MLA’s H20 compute overhead and TP loss.

Sparse GQLA preserves the GQA path.

GQLA’s canonical
h_{q}/g\!=\!16
matches the
m\!=\!16
tile exactly, so Eq. (
3.3
) runs on Tensor Cores at full efficiency along the GQA path. The dense rule still applies: memory-bound hardware switches to sparse MQA-absorb, compute-bound hardware stays in sparse GQA—no custom kernels are needed either way.

Composing with HISA.

The
O(L)
indexer that produces

dominates runtime at
L\!\geq\!64
K. HISA
(
17
)
is a training-free hierarchical replacement that matches the original top-

set at IoU
>99\%
; it accelerates the “before top-
k
” indexer, while GQLA keeps the “after top-
k
” attention filling the MMA tile.

6
Conclusion

We identified three coupled hardware drawbacks of MLA’s MQA-absorb-only design—hardware coupling to H100-class ratios, loss of head-axis tensor parallelism, and zero MTP gain on commodity GPUs—and proposed GQLA as a minimal architectural fix: indexing the up-projections by group rather than by query head yields trained weights that admit two algebraically equivalent decoding paths (a compact-latent MQA-absorb path identical to MLA’s, and a per-group expanded GQA path). With
(h_{q},g)\!=\!(128,8)
and one MTP head, the same weights pin both H100 and H20 rooflines simultaneously, enable
8
-way zero-redundancy tensor parallelism on the GQA path, and—via the
h_{q}/g\!=\!16
Tensor-Core MMA match—carry the dual-path benefit into sparse attention, which sparse MLA cannot.

TransGQLA makes the design accessible from pretrained checkpoints with no gradient updates on either route: MLA
\to
GQLA loses only
\sim\!4.7
Avg. pts on GLM-4.7 at zero tokens, and GQA
\to
GQLA on LLaMA-3-8B reaches a
0
-token state numerically identical to TransMLA’s, inheriting its reported
30
B-token recovery (within
0.5
pts of the source) as the baseline cost to close any residual gap. More broadly, exposing multiple algebraically equivalent decoding paths over a single set of trained weights is a practical design principle for hardware-adaptive attention.
