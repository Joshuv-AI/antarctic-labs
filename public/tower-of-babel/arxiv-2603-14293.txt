Improved Online Hitting Set Algorithms for Structured and Geometric Set Systems
Sujoy Bhore, Anupam Gupta, Amit Kumar

Abstract
In the online hitting set problem, sets arrive over time, and the algorithm has to maintain a subset of elements that hit all the sets seen so far. Alon, Awerbuch, Azar, Buchbinder, and Naor (SICOMP 2009) gave an algorithm with competitive ratio O ⁡ ( log ⁡ n ​ log ⁡ m ) O(\log n\log m) for the (general) online hitting set and set cover problems for m m sets and n n elements; this is known to be tight for efficient online algorithms. Given this barrier for general set systems, we ask: can we break this double-logarithmic phenomenon for online hitting set/set cover on structured and geometric set systems? We provide an O ⁡ ( log ⁡ n ​ log ⁡ log ​ n ) O(\log n\log\log n) -competitive algorithm for the weighted online hitting set problem on set systems with linear shallow-cell complexity , replacing the double-logarithmic factor in the general result by effectively a single logarithmic term. As a consequence of our results we obtain the first bounds for weighted online hitting set for natural geometric set families, thereby answering open questions regarding the gap between general and geometric weighted online hitting set problems.

Introduction

In the
hitting set problem
, we are given a set system

\mathcal{I}=(U,\mathcal{F})
, with ground set
U
and a collection
of subsets
\mathcal{F}
of
U

e
has a cost
c_{e}

\mathcal{F}

because it serves as a test-bed for new techniques. The hitting set
problem is equivalent to the
set cover
problem on a “dual”
set system
\mathcal{I}^{*}
, which contains an element
e_{S}
for each
original set
S\in\mathcal{F}
, and a set
S_{e}
for each element

e\in U

e\in S\iff e_{S}\in S_{e}
; i.e., we flip the
roles of

and
\mathcal{F}
. Henceforth, we focus on hitting set.

In the offline setting, the hitting set (or the set cover) problem has
been widely studied, with
(1\pm o(1))\,\ln|U|

algorithms in the worst-case, which are best-possible if

P\neq NP

19

extensively studied for special set systems—most notably, those with

or bounded

(SCC)

11
;
6

17
;
10
;
9
;
25

7

approximations for set systems like pseudo-disks and half-spaces in

and combinatorial settings, but also in non-geometric problems like
job scheduling
4
.

The progress for structured set systems in the
online

setting—where sets arrive over time, and must be hit as they
arrive—has been more limited. While results are known for online
hitting set (and set cover) for specific problems like intervals in

\mathbb{R}
or
2

- competitiveness

m=|\mathcal{F}|

the only general result for weighted online hitting set, even for set

Can we achieve better competitive ratios for broad classes of
set systems? Specifically, can we match the performance gains seen
in structured offline settings?

1.1
Our Results

Our main results answer this question positively. Recall that the VC
dimension of a set system is the largest set of elements that can be
shattered. The
shallow cell complexity

\varphi_{\mathcal{F}}(\cdot,\cdot)
is a finer-grained notion,
bounding the number of sets of size
k

\ell

The Unweighted Case.

For unit-cost instances, we adapt the offline Net-Finder
algorithm

Theorem 1.1

(Unweighted Hitting Set)

There is a randomized online algorithm for (unweighted) hitting set

O(\log n\cdot(d+\log(d\cdot\varphi(d\,{\sf OPT}\,\log n,d))))

where
\varphi(\cdot,\cdot)
is the shallow cell complexity (SCC)
and

For set systems with

O(\log n)

\mathbb{R}
, lines
and pseudo-disks—which includes disks and axis-aligned

\mathbb{R}^{2}
, and half-spaces in

\mathbb{R}^{3}

1.2
Our Techniques

We demonstrate that online relax-and-round approaches can be
successfully combined with net-finding and quasi-uniform sampling offline algorithms to resolve open problems in the area. The first step in both the unweighted and weighted cases is to use an
online algorithm for fractional hitting set, losing an

O(\log n)
-factor in the competitive ratio. Starting
from
17
, we know that rounding a fractional
solution reduces to finding an
\varepsilon
-net in a set-system,
where each element
e
with fractional value
x_{e}
is replaced by

\lceil nx_{e}\rceil

clones
. Since the fractional solution is
feasible, each set in the original instance now contains at least
n

clones, so finding a hitting set in the original instance reduces to
finding an
\varepsilon
-net (for
\varepsilon=1/n
) that hits all sets of size at least
n

in this new set system
\mathcal{J}
.
We start with the elegant algorithm of

22
, which first samples each element with a
certain base probability; now, for any large set
T
not hit by this
sample, it selects elements of
T
independently with probability
proportional to
1/|T|
into the sample.

Carrying out this procedure
in the online setting has two main issues: firstly, the fractional
solution evolves over time, and the
x_{e}
values may increase as sets
arrive. As a result, if an element
e
is contained in sets
S_{1}
and

S_{2}
, the number of clones of
e
in the corresponding sets in the
new set system
\mathcal{J}
may be different, which affects the VC
dimension and the SCC of
\mathcal{J}
. Secondly, the initial sampling step
in
22
requires knowledge of all the elements
in the set system; but in the online setting, new clones of an element
appear when its fractional value increases. We handle the first issue
by showing that the VC dimension and the SCC of the new set system

\mathcal{J}
can be related to those of the original instance, and for the
second issue, we replace the sampling step by a
deferred

sampling step.

Our algorithm for weighted hitting set adapts the quasi-uniform
sampling algorithm of
7
to the online setting. This algorithm
builds a chain of nested sets of clones, starting with the entire set

V_{0}
of clones, with each subsequent set
V_{\ell}
having size

(\nicefrac{{1}}{{2}}+\delta_{\ell})
times the size of
V_{\ell-1}
. Here

\delta_{\ell}
is a small bias term, which ensures that most sets
S

of the hitting set instance have at least half their elements survive
to the next level. Sets whose size falls below
n/2^{\ell}
are said to
be “dangerous” and must select a “backup” element to hit them. The choice
of this backup element is done to ensure that no element is picked too
often. Apart from the challenge of the new clones arriving online,
finding the backups seems like an inherently offline problem, since it
seems to require knowing the entire set system. However, we view the
problem of finding backup elements as a load-balancing problem, and
show how to choose backups that increases the probability by a
logarithmic factor. Existing presentations of the algorithm also build
the layers iteratively, discarding sets that are covered by each layer
to get the set system for the next layer—we observe that these
optimizations are inessential, and removing them allows a clean online
implementation. (See
Algorithm

4
in
Section

5
.)

2.1
Shallow Cell Complexity

For a set system

(U,\mathcal{F})
and a subset
U^{\prime}\subset U
, denote the induced
collection of sets as

\mathcal{F}_{U^{\prime}}:=\{S\cap U^{\prime}\mid S\in\mathcal{F}\}
.

Definition 2.1

(Shallow Cell Complexity)
.

A set system
\mathcal{I}=(U,\mathcal{F})
is said to have
shallow cell
complexity
(
SCC
)
\varphi:\mathbb{Z}_{+}\times\mathbb{Z}_{+}\to\mathbb{Z}_{+}
if
for any
\ell,k\in\mathbb{Z}_{+}
, and for any subset
U^{\prime}\subset U
with
|U^{\prime}|=\ell
, the
number of distinct subsets of size at most
k
in
\mathcal{F}_{U^{\prime}}
is at most
\ell\cdot\varphi(\ell,k).

Crucially, the number of distinct sets in
\mathcal{F}_{U^{\prime}}
is bounded by

\ell\cdot\varphi(\ell,k)
rather than the worst-case
{\ell\choose k}
.
If the VC dimension of the set system

\mathcal{I}
is
d
, the shattering lemma

(
24
, Ch. 15)
implies that

\ell\cdot\varphi(\ell,k)\leq{\ell\choose d}\approx(\textrm{e}\ell/d)^{d}
.

We focus on functions
\varphi
which are well-behaved, in the sense of
23
.

Definition 2.2

(Well-Behaved SCC)
.

A function
\varphi(\cdot,\cdot)
is
(a,b)
-
well-behaved
for
constants
a\in(1,2)
and
b\geq 2
if it is non-decreasing in
both arguments, and for all positive integers
\ell\geq k\geq b
,
we have
\varphi(\ell,k)\leq(\varphi(\nicefrac{{\ell}}{{2}},\nicefrac{{k}}{{2}}))^{a}
.

Well-behavedness is easy to verify for the common case of

\varphi(\ell,k)=k^{c}
for some constant
c\geq 0
. Henceforth,
our focus will be on such functions.

.

. We set
\gamma_{\ell}
to be the resulting online
map
\gamma:\mathcal{G}_{\ell}\rightarrow V_{\ell}
. Observe that the set
Q

defined in
Lemma

5.1
is same as the set
Q_{\ell}

defined in
Algorithm

4
. We show next
that maps
\gamma_{\ell}
(and the resulting backup sets

Q_{\ell}
) ensure a low probability of picking elements.

5.4
Probability of Picking Elements

To bound the probability of selecting an element
e
in the
hitting set constructed by
Algorithm

4
, we first relate

h_{\mathcal{G}}\big(N_{\ell},B_{\ell}\big)
for varying values of
\ell
.

Claim 5.3
.

For any
\ell<L^{*}
we have

h_{\mathcal{G}}\big(N_{\ell+1},B_{\ell+1}\big)\geq\sqrt{\frac{2}{a}}\cdot h_{\mathcal{G}}\big(N_{\ell},B_{\ell}\big).

Proof.

The proof is similar to that of

(
23
, Claim 8.16)
. Since
B_{\ell}\geq c_{1}>b

for all
\ell\leq L^{*}
, the
(a,b)
well-behaved property of

\varphi
implies that

\varphi_{\mathcal{G}}(N_{\ell},B_{\ell})\leq\varphi_{\mathcal{G}}(N_{\ell+1},B_{\ell+1})^{a}.
Since
c_{1}
is a large enough constant,

c_{1}\leq(c_{1}/2)^{a}
. For
a>1
and sufficiently large
c_{1}
, the
condition
B_{\ell}\geq c_{1}
implies

B_{\ell}\leq(B_{\ell}/2)^{a}=B_{\ell+1}^{a}
. Similarly, we know that

\log N_{\ell}\geq\log c_{1}.
Again, assuming
c_{1}
is large enough,
it follows that

\lceil\log N_{\ell}\rceil\leq((\lceil\log N_{\ell}\rceil)/2)^{a}\leq(\lceil\log(N_{\ell}/2)\rceil)^{a}=(\lceil\log N_{\ell+1}\rceil)^{a}
.

Using
Equation

3
, we see that

h_{\mathcal{G}}\big(N_{\ell},B_{\ell}\big)
is at most

\sqrt{\frac{8\ln((B_{\ell+1})^{a}\cdot(\lceil\log(N_{\ell+1})\rceil)^{a}\cdot\varphi_{\mathcal{G}}(N_{\ell+1},B_{\ell+1})^{a})}{2B_{\ell+1}}}=\sqrt{\frac{a}{2}}\cdot h_{\mathcal{G}}\big(N_{\ell+1},B_{\ell+1}\big).

∎

Claim 5.4
.

For any
\ell\leq L^{*}
we have
|V_{\ell}|\leq c_{1}\,N/2^{\ell}
, and for each
e\in V
,

Pr[e\in V_{\ell}]\leq\frac{c_{1}}{2^{\ell}}.

Proof.

The proof is essentially the same as that of
(
23
, Claim 8.17)
.
∎

Theorem 5.5
.

In
Algorithm

4
, each element
e\in V
is selected in the set
H
with
probability at most

O\big(\frac{1}{B}\cdot\log(B_{L^{*}}\cdot\log N\cdot\varphi_{\mathcal{G}}(N_{L^{*}},B_{L^{*}}))\big).

Proof.

Recall that if
L^{*}=0
, we return the entire set
V
as the
solution (which clearly hits all sets of size at least
B
);
using (
4
), we get

\displaystyle\Pr[e\in H]=1\leq O\bigg(\frac{\log(B_{L}\cdot\log N\cdot\varphi_{\mathcal{G}}(c_{1}N,N))}{B}\bigg).

(7)

Else, by a union bound, the probability that
e\in H
is

\displaystyle\sum_{\ell=0}^{L^{*}-1}\Big(\Pr[e\in V_{\ell}]\Pr[e\in Q_{\ell}\mid e\in V_{\ell}]\Big)+\Pr[e\in V_{L}^{*}]=\sum_{\ell=0}^{L^{*}-1}\frac{c_{1}}{2^{\ell}}\cdot(B_{\ell})^{-2}+\frac{c_{1}}{2^{L^{*}}},

where we used
5.4
and

Lemma

5.2
(ii)
for the first
expressions, and
5.4
again for the second. Now
simplifying using the definition (
2
) for the first
term, and the inequality (
4
) for the
second, we get

\displaystyle\Pr[e\in H]

\displaystyle\leq\frac{c_{1}}{B^{2}}\cdot\sum_{\ell=0}^{L^{*}-1}2^{\ell}+O\bigg(\frac{\log(\log N\cdot B_{L^{*}}\cdot\varphi_{\mathcal{G}}(N_{L^{*}},B_{L^{*}}))}{B}\bigg).

Finally, the geometric sum gives
2^{L^{*}}\leq\frac{B}{c_{1}}
,
and results in the claimed bounds.
∎

5.5
The Algorithm for Weighted Hitting Sets

We now combine
Algorithm

1
and
Algorithm

4
to get an
online weighted hitting set algorithm. We first give a simple
observation about
Algorithm

1
.

Claim 5.6
.

Let
\mathcal{I}=(U,\mathcal{F})
be an instance of the weighted online hitting
set problem. Then,
Algorithm

1
can be implemented such that (let
x_{e}
be the solution at the end of the
instance) (i)
\sum_{e}c_{e}x_{e}\leq 4\rho\,{\sf OPT}(\mathcal{I})
, (ii) if

x_{e}^{t}\neq 0
for any time
t
and element
e
, then

x_{e}^{t}\geq\nicefrac{{1}}{{n}}
.

Proof.

We divide the execution of
Algorithm

4
into phases. In phase

i
,
{\sf OPT}(\mathcal{I})
lies in the range
[2^{i},2^{i+1})
. Let phase
i

start at time
b_{i}
and end at time
e_{i}
. Now we make the following
changes to
Algorithm

4
:

(i)

Until time
e_{i}
, the online algorithm
\mathcal{A}
increases

x_{e}
values for only those elements
e
with
c_{e}\leq 2^{i+1}

(in other words, for every arriving set
S_{t}
, we exclude all such
heavy elements from it as far as
\mathcal{A}
is concerned).

(ii)

At time
b_{i}
, we set
x_{e}^{t}=1
for all
e
with

c_{e}\leq 2^{i}/n
and
x_{e}^{t}=1/n
for all elements
e
with

2^{i}/n<c_{e}<2^{i+1}
. In other words, if
x_{e}^{t}
were the
original fractional values maintained by
\mathcal{A}
, we replace these
by
\max(1,x_{e}^{t})
if
c_{e}\leq 2^{i}/n
; and by
\max(1/n,x_{e}^{t})

if
2^{i}/n<c_{e}<2^{i+1}
.

We now verify the claimed conditions. Crucially, the offline
optimum cannot select elements with cost
\geq 2^{i+1}
during phase

i
.
Consequently, removing such elements for an arriving set
S_{t}
where

t\leq e_{i}
does not change the optimal value. Thus, if
x_{t}^{e}

were the fractional solution maintained by
\mathcal{A}
with the
modification in step
(i)
above (and excluding the changes
in step
(ii)
), we would still have

\sum_{e}c_{e}x_{e}^{t}\leq\rho\cdot{\sf OPT}(\mathcal{I})
.

Now we account for the increase in cost due to step
(ii)

above. Setting
x_{e}^{b_{i}}=1
for all
e
with
c_{e}\leq 2^{i}/n

increases the cost by at most
2^{i}
. Similarly increasing

x_{e}^{b_{i}}
by at most
1/n
for all
e
with

2^{i}/n<c_{e}<2^{i+1}
increases the cost by at most

2^{i+1}
. Summing over all
i
, we get the desired result.
∎

The online weighted hitting set algorithm is as
follows:
Algorithm

1
(with the changes
in
5.6
) takes an instance
\mathcal{I}=(U,\mathcal{F})
of the
weighted hitting set problem and outputs an online instance

\mathcal{J}=(V,\mathcal{G})
(which has the properties stated
in
Theorem

3.2
). Since the backup maps
\gamma_{\ell}
can
be defined in an online manner,
Algorithm

4
can be implemented on
the instance
\mathcal{J}
in an online manner. This gives us an online
hitting set
H
. The hitting set for
\mathcal{I}
is just
\textsf{proj}(H)
. We
now state the main result about the competitive ratio of this
algorithm.

Theorem 5.7
.

Given an online
\rho
-competitive algorithm for fractional online
hitting set, there is an online randomized algorithm for
(weighted) online hitting set that has expected competitive
ratio

O\big(\rho\cdot\log(B_{L^{*}}\log n\cdot\varphi_{\mathcal{F}}(N_{L^{*}},B_{L^{*}}))\big).

Here

L^{*}
is the level associated with the instance
(V,\mathcal{G})

as given by (
3
).

Proof.

Let
e
be an element in
V
. If
e
does not appear in any of the
sets
\cup_{t}T_{t}
, then it is not selected
by
Algorithm

4
. Otherwise its selection probability is upper
bounded by
Theorem

5.5
.

Consider an element
e\in U
(note that
U
is the ground set of
the original instance
\mathcal{I}
). We now bound the probability that it
gets selected. Let
x_{e}
be the final fractional value of
e

in
Algorithm

1
. If
x_{e}=0
, then no clones of
e
appear
in any of the sets in the instance
\mathcal{G}
, and hence, none of these
clones gets added to
H
in
Algorithm

4
. Therefore probability
of
e
getting selected is
0
. Now suppose

x_{e}>0
.
5.6
shows that
x_{e}\geq 1/n
. Let
Y_{e}

be the set of clones corresponding to
e
in the set
V
. In other
words,
Y_{e}=\{(e,i):i\leq\lceil\min(1,nx_{e})\rceil\}
. Since

x_{e}\geq 1/n
,
|Y_{e}|\leq 2nx_{e}
. Now, any clone
(e,i)
gets
added to
H
with probability at most

O\Big(\frac{1}{B}\cdot\log(B_{L^{*}}\log N\cdot\varphi_{\mathcal{G}}(N_{L^{*}},B_{L^{*}}))\Big).

Therefore,
the probability that any of the clones of
e
gets added to
H
is
at most
|Y_{e}|
times the above expression. Thus, the probability of
selection of
e
is at most (recall that
B=n
)

O\big(\log(B_{L^{*}}\log N\cdot\varphi_{\mathcal{G}}(N_{L^{*}},B_{L^{*}}))\big)x_{e}.

The
desired result now follows from the fact that

\sum_{e}c_{e}x_{e}=4\rho\cdot{\sf OPT}

(using
5.6
), that
N=O(n^{2})
and that

\varphi_{\mathcal{G}}(N_{L^{*}},B_{L^{*}})\leq B_{L^{*}}\cdot\varphi_{\mathcal{F}}(N_{L^{*}},B_{L^{*}})

due to
Theorem

3.2
.
∎

The guarantee of
Theorem

5.7
depends on the value of

L^{*}
, which depends on the form of
\varphi
. We now apply the
above result for the most interesting case: that of set systems with
linear SCC, i.e., where
\varphi_{\mathcal{F}}(\ell,k)=\operatorname{poly}(k)
.

Corollary 5.8

(Linear SCC)
.

Suppose we are given an online
\rho
-competitive algorithm for
fractional online weighted hitting set and the arriving instance

\mathcal{I}=(U,\mathcal{F})
,
n:=|U|
, satisfies

\varphi_{\mathcal{F}}(\ell,k)=\operatorname{poly}(k)
. Then there is an online
randomized algorithm for (weighted) online hitting set that has
expected competitive ratio
O\big(\rho\log\log n\big).

Proof.

The competitive ratio stated in
Theorem

5.7
simplifies to

O\big(\rho\cdot\log(B_{L^{*}}\log n)\big)
.
It remains to bound
B_{L^{*}}
. If
L^{*}=\log(B/c_{1})
, then

B_{L^{*}}=B/2^{L^{*}}=c_{1}
. This implies the desired bound.

Now suppose
L^{*}<\log(B/c_{1})
. Then (
3
) implies
that
h_{\mathcal{G}}(N_{L^{*}+1},B_{L^{*}+1})\geq 1/2
. Since

\varphi_{\mathcal{G}}(\ell,k)\leq k\cdot\varphi_{\mathcal{F}}(\ell,k)=k^{O(1)}
, this implies:

B_{L^{*}+1}=O(\log(B_{L^{*}+1}\cdot\log n)).

Thus, we get
B_{L^{*}+1}=O(\log n)
. Since

B_{L^{*}}=2B_{L^{*}+1},
we get the desired result.
∎

Corollary

5.8
immediately implies
Theorem

1.2
.
