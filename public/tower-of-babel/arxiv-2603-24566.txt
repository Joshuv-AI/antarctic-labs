Integral Control Barrier Functions with Input Delay: Prediction, Feasibility, and Robustness
Adam K. Kiss, Ersin Daş, Tamas G. Molnar, Aaron D. Ames

Abstract
Time delays in feedback control loops can cause controllers to respond too late, and with excessively large corrective actions, leading to unsafe behavior (violation of state constraints) and controller infeasibility (violation of input constraints). To address this problem, we develop a safety-critical control framework for nonlinear systems with input delay using dynamically defined (integral) controllers. Building on the concept of Integral Control Barrier Functions (ICBFs), we concurrently address two fundamental challenges: compensating the effect of delays, while ensuring feasibility when state and input constraints are imposed jointly. To this end, we embed predictor feedback into a dynamically defined control law to compensate for delays, with the predicted state evolving according to delay-free dynamics. Then, utilizing ICBFs, we formulate a quadratic program for safe control design. For systems subject to simultaneous state and input constraints, we derive a closed-form feasibility condition for the resulting controller, yielding a compatible ICBF pair that guarantees forward invariance under delay. We also address robustness to prediction errors (e.g., caused by delay uncertainty) using tunable robust ICBFs. Our approach is validated on an adaptive cruise control example with actuation delay.



I
Introduction

Control Barrier Functions (CBFs)
[
5
]
provide a principled approach to safety-critical control by enabling the design of controllers that enforce the forward invariance of a safe set in the state space.
This is typically implemented through safety filters, formulated as a quadratic program (QP) that minimally modifies a given nominal controller.
This framework has been applied to autonomous vehicles, robotics, and multi-agent systems
[
3
,
10
,
23
,
9
]
.

One of the key challenges in applying CBFs to real systems is input delay.
Actuation, computation, and communication all introduce delays that cause the commanded input to take effect only after some time.
A controller unaware of this delay evaluates the CBF condition at the current state, while the effect of the input will only be realized later—this mismatch can cause safety violations.
Predictor feedback
[
13
]
addresses this problem by forward-integrating the system over the delay interval to obtain the predicted state at which the CBF condition is evaluated
[
17
,
1
]
.
In practice, however, the delay is often uncertain,
which may induce a prediction error that acts as a disturbance.
Robustness to this error can be achieved through integral quadratic constraints
[
21
,
20
]
, input-to-state safety
[
15
]
, or robust CBFs
[
19
,
8
]
, while online delay estimation may further reduce conservatism
[
11
]
.

The standard CBF framework
[
5
]
considers
state constraints only,
which limits its applicability when input constraints (such as actuator bounds) or actuator dynamics are present.
This is especially important for systems with delays, because a delayed response may become more excessive with higher inputs.
Integral Control Barrier Functions (ICBFs)
[
4
]
overcome input constraints by allowing the barrier function to depend on both the system state and the control input, so that input constraints and actuator dynamics can be encoded alongside the state constraint
[
7
]
. ICBFs, however, have not yet been adapted to time delay systems.

Furthermore, ICBFs present another challenge.
For multiple constraints (both state and input limits), the combined QP may be infeasible even if each constraint individually admits a solution.
This phenomenon is well-known for CBF-based safety filters
[
18
]
: when constraints are incompatible, the QP may have no solution, or undesired equilibria may appear on the safe set boundary
[
22
]
.
The compatibility (or joint feasibility) of constraints has been studied for intersections of safe sets
[
16
,
6
]
and for explicit safety filter formulations
[
14
]
.
Deriving a closed-form feasibility condition for ICBF-based safety filters with joint state and input constraints is still missing from the literature.

In this paper, we develop an ICBF framework for nonlinear control systems with input delay and joint state and input constraints.
First, we incorporate predictor feedback into the ICBF framework so that the safety filter operates on the predicted state, compensating for the delay.
Second, we derive a closed-form feasibility condition for the two-constraint QP arising from joint state and input limits,
constituting a compatible ICBF pair that guarantees feasibility and forward invariance under delay.
Third, we handle uncertain delay via a robust ICBF formulation based on
[
19
,
8
]
that treats prediction errors as a disturbance, yielding safety guarantees that improve with prediction accuracy. We illustrate the framework on a safe adaptive cruise control example.

Section

II-B

State and Input Constraints

In practice, we often need to enforce two
separate
constraints simultaneously: a state constraint and an input constraint. Let the safe sets for the state and input be

\displaystyle\mathcal{S}_{x}

\displaystyle:=\{(\mathbf{x},\mathbf{u})\in\mathbb{R}^{n}\times\mathbb{R}^{m}:h_{x}(\mathbf{x})\geq 0\},

(11)

\displaystyle\mathcal{S}_{u}

\displaystyle:=\{(\mathbf{x},\mathbf{u})\in\mathbb{R}^{n}\times\mathbb{R}^{m}:h_{u}(\mathbf{u})\geq 0\},

(12)

with continuously differentiable
{h_{x}:\mathbb{R}^{n}\!\to\!\mathbb{R}}

{h_{u}:\mathbb{R}^{m}\!\to\!\mathbb{R}}

and

(14)

Making

guarantees

{\mathcal{S}_{e}\cap\mathcal{S}_{x}}
, enforcing state constraints.

Let

and

be ICBFs.
Applying (
6
) to
h_{e}
and

yields:

\displaystyle\mathbf{b}_{e}(\mathbf{x},\mathbf{u})

\displaystyle:=\left(\tfrac{\partial h_{e}}{\partial\mathbf{u}}(\mathbf{x},\mathbf{u})\right)^{\top},

(15)

\displaystyle a_{e}(\mathbf{x},\mathbf{u})

\displaystyle:=-\tfrac{\partial h_{e}}{\partial\mathbf{x}}(\mathbf{x},\mathbf{u})\,\mathbf{f}(\mathbf{x},\mathbf{u})

\displaystyle\;\;\quad-\tfrac{\partial h_{e}}{\partial\mathbf{u}}(\mathbf{x},\mathbf{u})\,\bm{\phi}(\mathbf{x},\mathbf{u})-\alpha_{e}\big(h_{e}(\mathbf{x},\mathbf{u})\big),

\displaystyle\mathbf{b}_{u}(\mathbf{x},\mathbf{u})

\displaystyle:=\left(\tfrac{\partial h_{u}}{\partial\mathbf{u}}(\mathbf{u})\right)^{\top},

(16)

\displaystyle a_{u}(\mathbf{x},\mathbf{u})

\displaystyle:=-\tfrac{\partial h_{u}}{\partial\mathbf{u}}(\mathbf{u})\bm{\phi}(\mathbf{x},\mathbf{u})-\alpha_{u}(h_{u}(\mathbf{u})).

One may enforce both constraints on the safety correction
\mathbf{v}

\displaystyle\mathbf{q}(\mathbf{x},\mathbf{u})=\argmin_{\mathbf{v}\in\mathbb{R}^{m}}

\displaystyle\quad\left\lVert\mathbf{v}\right\rVert^{2}

(17)

\displaystyle\mathrm{s.t.}

\displaystyle\quad\mathbf{b}_{e}^{\top}(\mathbf{x},\mathbf{u})\mathbf{v}\geq a_{e}(\mathbf{x},\mathbf{u}),

III
Integral CBFs with Input Delay

In this section, we present our main results: we extend the ICBF framework to systems with input delay.
We address joint state and input constraints, and robustness to uncertain prediction. The general case
is stated first, while the cases of perfect prediction
and no delay
follow as special cases.

Consider the system (
1
) with a constant input delay
\tau>0

\dot{\mathbf{x}}(t)=\mathbf{f}\big(\mathbf{x}(t),\,\mathbf{u}(t{-}\tau)\big).

(18)

We assume (
18

\mathbf{x}(t)
for
t\geq 0
given
\mathbf{x}(0)
and a continuous input history
{\mathbf{u}_{t}(\vartheta):=\mathbf{u}(t+\vartheta)}
,
{\vartheta\in[-\tau,0)}
.
Due to the delay, the command

computed at time

takes effect only at
{t+\tau}
, and during

the system evolves under the history
\mathbf{u}_{t}
, which cannot be altered retroactively.
Evaluating the safety condition at
\mathbf{x}(t)
is therefore inadequate for choosing
\mathbf{u}(t)
.

Instead, we require that the physical pair
(\mathbf{x}(t),\mathbf{u}(t{-}\tau))
– the current state and the delayed input that is currently acting on the system –
satisfies the safety constraint:

h_{i}\big(\mathbf{x}(t),\mathbf{u}(t-\tau)\big)\geq 0,

(19)

where

may refer to a single constraint with

or each of the two constraints with

and

. With a slight abuse of notation, a barrier depending on a single variable is identified with its trivial extension to
{\mathbf{x},\mathbf{u}}
.
The delayed system must evolve inside a safe set
\mathcal{S}_{i}
, so that

{(\mathbf{x}(t),\mathbf{u}(t{-}\tau))\in\mathcal{S}_{i}}
,
with

\mathcal{S}_{i}:=\big\{(\mathbf{x},\mathbf{u})\in\mathbb{R}^{n}\times\mathbb{R}^{m}:h_{i}(\mathbf{x},\mathbf{u})\geq 0\big\}.

(20)

We require the following regularity condition for
h_{i}
.

Assumption 1
.

Any nonpositive number is a regular value of
h_{i}
, that is,

{[\tfrac{\partial h_{i}}{\partial\mathbf{x}}(\mathbf{x},\mathbf{u}),\,\tfrac{\partial h_{i}}{\partial\mathbf{u}}(\mathbf{x},\mathbf{u})]\neq\mathbf{0}}

for all
{(\mathbf{x},\mathbf{u})\in\mathbb{R}^{n}\times\mathbb{R}^{m}}
satisfying
{h_{i}(\mathbf{x},\mathbf{u})\leq 0}
.

III-A

Predictor Feedback

To overcome the effect of delay,
we employ predictor feedback
[
17
]
.
Assuming access to
\mathbf{x}(t)
and the stored history
\mathbf{u}_{t}
,
the predicted state
{\mathbf{x}_{\mathrm{p}}(t):=\mathbf{x}(t+\tau)}
is obtained by forward-integrating (
18
) over the delay interval:

\mathbf{x}_{\mathrm{p}}\!=\!\Psi(\tau,\mathbf{x},\mathbf{u}_{t})\!:=\!\mathbf{x}+\!\int_{0}^{\tau}\!\!\mathbf{f}\big(\Psi(s,\mathbf{x},\mathbf{u}_{t}),\mathbf{u}_{t}(s{-}\tau)\big)\mathrm{d}s,

(21)

where
{\mathbf{u}_{t}(s-\tau)}
is the known past input.
A key property
[
13
]
is that
\mathbf{x}_{\mathrm{p}}
has delay-free dynamics:

{\dot{\mathbf{x}}_{\rm p}(t)=\mathbf{f}(\mathbf{x}_{\mathrm{p}}(t),\mathbf{u}(t))}
.

The integral controller is designed with the predicted state:

\dot{\mathbf{u}}(t)=\bm{\phi}(\mathbf{x}_{\mathrm{p}}(t),\,\mathbf{u}(t))+\mathbf{v}(t),

(22)

where
\bm{\phi}
is the integral controller and
{\mathbf{v}=\mathbf{q}(\mathbf{x}_{\mathrm{p}},\mathbf{u})}
is the auxiliary safety correction evaluated with the predicted state.
This controller is designed with two goals: ensuring that
\mathbf{u}
tracks a desired nominal law through
\bm{\phi}
, and enforcing safety via
\mathbf{v}
.
Because
\bm{\phi}
acts on the predicted state
\mathbf{x}_{\mathrm{p}}
rather than the current state
\mathbf{x}
, delay compensation is embedded in the nominal dynamics.
For instance, for a static state feedback law
{\mathbf{u}=\mathbf{k}_{\mathrm{d}}(\mathbf{x})}
, a common choice in the delay setting is:

\bm{\phi}(\mathbf{x}_{\mathrm{p}},\mathbf{u})=\frac{\partial\mathbf{k}_{\mathrm{d}}}{\partial\mathbf{x}}(\mathbf{x}_{\mathrm{p}})\,\mathbf{f}(\mathbf{x}_{\mathrm{p}},\mathbf{u})+\frac{\alpha_{\phi}}{2}\left(\mathbf{k}_{\mathrm{d}}(\mathbf{x}_{\mathrm{p}})-\mathbf{u}\right),

(23)

for
{\alpha_{\phi}>0}
, making
\mathbf{u}
converge to
\mathbf{k}_{\mathrm{d}}(\mathbf{x}_{\mathrm{p}})
exponentially.

Prediction requires the delay
\tau
and the dynamics
\mathbf{f}
to be accurately known.
However, in practice, the exact delay and dynamics are seldom known, which may lead to a
prediction error
: a mismatch between the true future state
\mathbf{x}_{\mathrm{p}}
and its estimation
\hat{\mathbf{x}}_{\mathrm{p}}
.
For example, if
\mathbf{f}
is known but the controller uses a delay estimate
\hat{\tau}
, the estimated predicted state

\hat{\mathbf{x}}_{\mathrm{p}}(t):=\Psi\big(\hat{\tau},\mathbf{x}(t),\,\mathbf{u}_{t}\big)

(24)

differs from
\mathbf{x}_{\mathrm{p}}(t)=\Psi(\tau,\mathbf{x}(t),\mathbf{u}_{t})
whenever
\hat{\tau}\neq\tau
.

While the physical system (
18
) is driven by the input
\mathbf{u}(t{-}\tau)
and its dynamics remain undisturbed, the prediction error
{\hat{\mathbf{x}}_{\mathrm{p}}-\mathbf{x}_{\mathrm{p}}}
affects the integral control law in (
22
).
Namely, both the controller
\bm{\phi}
and the safety correction
\mathbf{q}
are evaluated at the uncertain
\hat{\mathbf{x}}_{\mathrm{p}}
instead of the true
\mathbf{x}_{\mathrm{p}}
:

\dot{\mathbf{u}}(t)=\bm{\phi}\big(\hat{\mathbf{x}}_{\mathrm{p}}(t),\,\mathbf{u}(t)\big)+\mathbf{q}(\hat{\mathbf{x}}_{\mathrm{p}}(t),\,\mathbf{u}(t)).

(25)

The effect of the prediction mismatch can be viewed as a matched disturbance propagated into (
22

\displaystyle\dot{\mathbf{u}}(t)

\displaystyle=\bm{\phi}\big(\mathbf{x}_{\mathrm{p}}(t),\,\mathbf{u}(t)\big)+\mathbf{q}(\mathbf{x}_{\mathrm{p}}(t),\,\mathbf{u}(t))+\mathbf{d}(t),

(26)

\displaystyle\mathbf{d}

\displaystyle:=\bm{\phi}(\hat{\mathbf{x}}_{\mathrm{p}},\mathbf{u})+\mathbf{q}(\hat{\mathbf{x}}_{\mathrm{p}},\mathbf{u})-\bm{\phi}(\mathbf{x}_{\mathrm{p}},\mathbf{u})-\mathbf{q}(\mathbf{x}_{\mathrm{p}},\mathbf{u}).

(27)

We assume that the disturbance (i.e., the effect of prediction errors) stays bounded.

Assumption 2
.

{\left\lVert\mathbf{d}(t)\right\rVert\leq\delta}
for all
{t\geq 0}
, for some
{\delta\geq 0}
.

Knowing a bound
{\left\lVert\hat{\mathbf{x}}_{\mathrm{p}}-\mathbf{x}_{\mathrm{p}}\right\rVert\leq\delta_{x}}
on the prediction error, the disturbance bound
\delta
can be estimated, for example, as
{\delta=(L_{\phi}+L_{\mathbf{q}})\delta_{x}}
, where
L_{\phi}
and
L_{\mathbf{q}}
are the Lipschitz constants of
\bm{\phi}
and
\mathbf{q}
, respectively.
Notice that when
{\hat{\mathbf{x}}_{\mathrm{p}}=\mathbf{x}_{\mathrm{p}}}
(i.e.,
\hat{\tau}=\tau
), we have
\mathbf{d}\equiv\mathbf{0}
and
{\delta=0}
.

To provide robust safety even in the presence of disturbance,
we adopt the robust CBF framework of
[
19
]

For each barrier
h_{i}
,
we enforce a robust ICBF condition

\mathbf{b}_{i}^{\top}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\mathbf{v}\geq a_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u})+r_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u}),

(28)

with the additional robustness term

\displaystyle r_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u})

\displaystyle:=\mu_{i}\big(h_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\big)\left\lVert\mathbf{b}_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\right\rVert

(29)

\displaystyle+\sigma_{i}\big(h_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\big)\left\lVert\mathbf{b}_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\right\rVert^{2},

where

{\mu_{i},\sigma_{i}:\mathbb{R}\!\to\!\mathbb{R}_{>0}}
are continuously differentiable and monotonously decreasing.
A common choice is
{\mu_{i}(h_{i})=\mu_{0}e^{-\lambda h_{i}}}
,
{\sigma_{i}(h_{i})=\sigma_{0}e^{-\lambda h_{i}}}
with
{\mu_{0},\sigma_{0},\lambda>0}

Using the tunability idea of

]
,
with
\mu_{i}
and

we concentrate robustness near the safe set boundary (
{h_{i}\approx 0}
), while leaving the controller unchanged far inside the set (
{h_{i}\gg 0}

This finally leads to the following QP for ensuring robust safety in the presence of input delay and prediction errors:

\displaystyle\mathbf{q}(\mathbf{x}_{\mathrm{p}},\mathbf{u})=\argmin_{\mathbf{v}\in\mathbb{R}^{m}}

\displaystyle\quad\left\lVert\mathbf{v}\right\rVert^{2}

(30)

\displaystyle\mathrm{s.t.}

\displaystyle\quad\mathbf{b}_{i}^{\top}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\mathbf{v}\geq a_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u})+r_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u}),

where the constraint is enforced for all

in case of two constraints (with

h_{u}
), while the index

III-B

Feasibility

First, we establish feasibility conditions for the proposed controller.
In the case of a single constraint, we require that
there exists

{\alpha\in\mathcal{K}^{\rm e}}
such that
for all
{(\mathbf{x}_{\mathrm{p}},\mathbf{u})\in\mathbb{R}^{n}\times\mathbb{R}^{m}}

\sup_{\mathbf{v}\in\mathbb{R}^{m}}\Big[\dot{h}(\mathbf{x}_{\mathrm{p}},\mathbf{u},\mathbf{v})+\alpha\big(h(\mathbf{x}_{\mathrm{p}},\mathbf{u})\big)-r(\mathbf{x}_{\mathrm{p}},\mathbf{u})\Big]\geq 0,

\mathbf{b}(\mathbf{x}_{\mathrm{p}},\mathbf{u})=\mathbf{0}\implies a(\mathbf{x}_{\mathrm{p}},\mathbf{u})\leq 0.

Note that
{r(\mathbf{x}_{\mathrm{p}},\mathbf{u})\!=\!0}

This implies that any ICBF is automatically a robust ICBF

This condition is required for the feasibility of the single-constraint QP.

\mathbf{b}_{u}^{\top}\mathbf{v}\geq a_{u}
, if and only if

\lambda_{e}\mathbf{b}_{e}+\lambda_{u}\mathbf{b}_{u}=\mathbf{0}\implies\lambda_{e}a_{e}+\lambda_{u}a_{u}\leq 0,

(33)

for all
{\lambda_{e},\lambda_{u}\geq 0}
.

Applying Lemma
1
to the two-constraint QP
yields the following easy-to-check condition.

Proposition 1
.

The pair
(h_{e},h_{u})
is a compatible robust ICBF pair and the QP in (
30
) is feasible if and only if

\displaystyle\mathbf{b}_{e}=\mathbf{0}\implies a_{e}\leq 0,

(34a)

\displaystyle\mathbf{b}_{u}=\mathbf{0}\implies a_{u}\leq 0,

(34b)

\displaystyle\left\lVert\mathbf{b}_{e}\right\rVert\left\lVert\mathbf{b}_{u}\right\rVert+\mathbf{b}_{e}^{\top}\mathbf{b}_{u}=0\implies

(34c)

\displaystyle\qquad(a_{e}+r_{e})\left\lVert\mathbf{b}_{u}\right\rVert+(a_{u}+r_{u})\left\lVert\mathbf{b}_{e}\right\rVert\leq 0,

where all quantities are evaluated at
(\mathbf{x}_{\mathrm{p}},\mathbf{u})
.

Proof.

We use Lemma
1
, by replacing
a_{i}
with
a_{i}+r_{i}
.
We show that (
33
) holds for all cases where
{\lambda_{e}\mathbf{b}_{e}+\lambda_{u}\mathbf{b}_{u}=\mathbf{0}}

with
{\lambda_{e},\lambda_{u}\geq 0}
.
This means
\mathbf{b}_{e}
and
\mathbf{b}_{u}
are anti-parallel or zero (or
{\lambda_{e}=\lambda_{u}=0}
, for which (
33
) holds trivially).

Case
\mathbf{b}_{e}=\mathbf{0}
,
\mathbf{b}_{u}\neq\mathbf{0}
:

{\lambda_{e}\mathbf{b}_{e}+\lambda_{u}\mathbf{b}_{u}=\mathbf{0}}
holds if
\lambda_{u}=0
, so (
33
) requires
\lambda_{e}(a_{e}+r_{e})\leq 0

for all
\lambda_{e}\geq 0
, giving (
34a
).

Case
\mathbf{b}_{e}\neq\mathbf{0}
,
\mathbf{b}_{u}=\mathbf{0}

is symmetric and gives (
34b
).

Case
\mathbf{b}_{e}=\mathbf{0}
,
\mathbf{b}_{u}=\mathbf{0}
is covered by (
34a
) and (
34b
).

Anti-parallel case (
{\left\lVert\mathbf{b}_{e}\right\rVert\left\lVert\mathbf{b}_{u}\right\rVert\!+\!\mathbf{b}_{e}^{\top}\mathbf{b}_{u}=0}
, while
{\mathbf{b}_{e}\neq\mathbf{0}}
,
{\mathbf{b}_{u}\neq\mathbf{0}}
):

We have
{\mathbf{b}_{e}\!=\!-c\,\mathbf{b}_{u}}
with

{c\!=\!\left\lVert\mathbf{b}_{e}\right\rVert/\left\lVert\mathbf{b}_{u}\right\rVert>0}
.
So
{\lambda_{e}\mathbf{b}_{e}\!+\!\lambda_{u}\mathbf{b}_{u}=\mathbf{0}}
gives
{\lambda_{u}=c\lambda_{e}}
, and
(
33
) yields (
34c
).
∎

Conditions (
34a
)–(
34b
) coincide with the individual robust ICBF conditions (
32
) for
h_{e}
and
h_{u}
.
Hence, they are satisfied when
h_{e}
and
h_{u}
are ICBFs.
However, two ICBFs need not form a compatible ICBF pair: condition (
34c
)
may fail when
\mathbf{b}_{e}
and
\mathbf{b}_{u}
are anti-parallel.
Furthermore, even if compatibility holds without robustness terms, it may not hold with
{r_{e},r_{u}>0}
: unlike the single-constraint case, a compatible ICBF pair is not automatically a compatible robust ICBF pair.
Condition (
34c
) must therefore be explicitly verified or enforced through the design of
\bm{\phi}
.
Tuning
\bm{\phi}
directly shapes
a_{e}
and
a_{u}
and can be used to ensure compatibility.

III-C

Robust Safety

Having established feasibility, we now state the formal safety guarantees provided by the proposed controller.
Since the input history over
[0,\tau]
is already committed and cannot be altered by the safety filter, we require an assumption.

Assumption 3
.

The initial input history satisfies
(\mathbf{x}(\vartheta),\,\mathbf{u}(\vartheta{-}\tau))\in\mathcal{S}_{i}
for all
\vartheta\in[0,\tau]
.

This requirement is stronger than
(\mathbf{x}(0),\mathbf{u}(0))\in\mathcal{S}
for the delay-free case: with delay, the safety filter has no authority over
[0,\tau]
since the input history is already committed.

Under Assumptions
1
–
3
, we establish the safety of the time delay system (
18
) with the integral controller (
25
) in the presence of prediction errors.
Specifically, we show that the set
\mathcal{S}_{i}
is forward invariant if the disturbance caused by prediction errors is small (i.e.,
{\delta\leq\mu_{i}(0)}
).
Moreover, even if the disturbance is large (i.e.,
{\delta>\mu_{i}(0)}
), we can show that trajectories remain within a neighborhood of the safe set by using the concept of input-to-state safety
[
12
]
.
For each barrier
h_{i}
, we define the inflated set

\mathcal{S}_{i,\delta}:=\big\{(\mathbf{x},\mathbf{u})\in\mathbb{R}^{n}\!\times\mathbb{R}^{m}:h_{i,\delta}(\mathbf{x},\mathbf{u})\geq 0\big\},

(35)

where

h_{i,\delta}(\mathbf{x},\mathbf{u}):=h_{i}(\mathbf{x},\mathbf{u})-\alpha_{i}^{-1}\!\left(-\frac{(\mu_{i}(0)-\delta)^{2}}{4\,\sigma_{i}(h_{i}(\mathbf{x},\mathbf{u}))}\right).

(36)

Note that the set
\mathcal{S}_{i,\delta}
grows with
\delta
(if
{\delta>\mu(0)}
), while
\delta
itself grows with the prediction error
{\hat{\mathbf{x}}_{\mathrm{p}}-\mathbf{x}_{\mathrm{p}}}
.
A more accurate prediction, therefore, directly reduces conservatism
[
15
]
.

The following theorem establishes the forward invariance of
\mathcal{S}_{i}
and
\mathcal{S}_{i,\delta}
for both the single- and two-constraint cases.

Theorem 2
.

Consider the system (
18
),
the predicted state
\mathbf{x}_{\mathrm{p}}
in (
21
),
its estimation
\hat{\mathbf{x}}_{\mathrm{p}}
,
the safe set
\mathcal{S}_{i}
in (
20
),
and the inflated set
\mathcal{S}_{i,\delta}
in (
35
).
Let Assumptions
1
,
2
, and
3
hold.

If the condition in (
32
) holds,
then any locally Lipschitz controller
{\mathbf{v}=\mathbf{q}(\mathbf{x}_{\mathrm{p}},\mathbf{u})}
, with
{\mathbf{q}:\mathbb{R}^{n}\!\times\!\mathbb{R}^{m}\to\mathbb{R}^{m}}
, satisfying

\mathbf{b}^{\top}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\mathbf{v}\geq a(\mathbf{x}_{\mathrm{p}},\mathbf{u})+r(\mathbf{x}_{\mathrm{p}},\mathbf{u})

(37)

for all
{(\mathbf{x}_{\mathrm{p}},\mathbf{u})\in\mathcal{S}_{\delta}}
,
renders
\mathcal{S}_{\delta}
forward invariant for (
18
)–(
25
).
Further, if
{\delta\leq\mu(0)}
, then
\mathcal{S}
is also forward invariant,
i.e.,

{(\mathbf{x}(0),\mathbf{u}(-\tau))\in\mathcal{S}\implies(\mathbf{x}(t),\mathbf{u}(t{-}\tau))\in\mathcal{S}}
,
{\forall\,t\geq 0}
.

If the conditions in (
34
) hold,
then any locally Lipschitz controller
{\mathbf{v}=\mathbf{q}(\mathbf{x}_{\mathrm{p}},\mathbf{u})}
, with
{\mathbf{q}:\mathbb{R}^{n}\!\times\!\mathbb{R}^{m}\to\mathbb{R}^{m}}
, satisfying

\mathbf{b}_{i}^{\top}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\mathbf{v}\geq a_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u})+r_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u}),\quad\forall i\in\{e,u\},

(38)

for all
{(\mathbf{x}_{\mathrm{p}},\mathbf{u})\in\mathcal{S}_{e,\delta}\cap\mathcal{S}_{u,\delta}}
,
renders
\mathcal{S}_{e,\delta}\cap\mathcal{S}_{u,\delta}
forward invariant for (
18
)–(
25
).
Further, if
{\delta\leq\min\{\mu_{e}(0),\mu_{u}(0)\}}
, then
{\mathcal{S}_{e}\cap\mathcal{S}_{u}}
is also forward invariant,
i.e.,

(\mathbf{x}(0),\mathbf{u}(-\tau))\in\mathcal{S}_{e}\cap\mathcal{S}_{u}\implies(\mathbf{x}(t),\mathbf{u}(t{-}\tau))\in\mathcal{S}_{e}\cap\mathcal{S}_{u},\ \forall\,t\geq 0
.

Proof.

We follow
[
17
, Appendix]
,
[
2
]
and give the argument for a single barrier
h
; the two-barrier case follows by applying the same reasoning to
h_{e}
and
h_{u}
.
Shifting time by
\tau
, the predicted pair
(\mathbf{x}_{\mathrm{p}},\mathbf{u})
obeys the delay-free dynamics

{\dot{\mathbf{x}}_{\rm p}(t)=\mathbf{f}(\mathbf{x}_{\mathrm{p}}(t),\mathbf{u}(t))}
,
with
{\dot{\mathbf{u}}=\phi(\mathbf{x}_{\mathrm{p}},\mathbf{u})+\mathbf{q}(\mathbf{x}_{\mathrm{p}},\mathbf{u})+\mathbf{d}}
based on (
25
).
We prove forward invariance using Nagumo’s theorem.
First, we compute
\dot{h}
along the disturbed dynamics

\displaystyle\dot{h}\big(\mathbf{x}_{\mathrm{p}},\mathbf{u},\mathbf{q}(\mathbf{x}_{\mathrm{p}},\mathbf{u})+\mathbf{d}\big)

\displaystyle=-\alpha\big(h(\mathbf{x}_{\mathrm{p}},\mathbf{u})\big)-a(\mathbf{x}_{\mathrm{p}},\mathbf{u})+\mathbf{b}^{\top}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\big(\mathbf{q}(\mathbf{x}_{\mathrm{p}},\mathbf{u})+\mathbf{d}\big).

For ease of notation, we omit the argument of
\dot{h}
and the arguments
(\mathbf{x}_{\mathrm{p}},\mathbf{u})
from now on.
Substituting (
37
), we get

\displaystyle\dot{h}\geq-\alpha\big(h\big)+r+\mathbf{b}^{\top}\mathbf{d}.

Then, we substitute
r
from (
29
), and we write
{\mathbf{b}^{\top}\mathbf{d}\!\geq\!-\left\lVert\mathbf{b}\right\rVert\delta}
based on the Cauchy–Schwarz inequality and Assumption
2
:

\displaystyle\dot{h}\geq-\alpha(h)+\big(\mu(h)-\delta\big)\|\mathbf{b}\|+\sigma(h)\|\mathbf{b}\|^{2}.

(39)

Further, by completing the square, it can be shown that:

\displaystyle\dot{h}\geq-\alpha(h)+\big(\mu(h)-\mu(0)\big)\|\mathbf{b}\|-\frac{(\mu(0)-\delta)^{2}}{4\sigma(h)}.

(40)

We prove the forward invariance of
\mathcal{S}
by considering
{h=0}
.
Substituting into (
39
) and using
{\delta\leq\mu(0)}
:

\displaystyle\dot{h}\geq\big(\mu(0)-\delta\big)\|\mathbf{b}\|+\sigma(0)\|\mathbf{b}\|^{2}\geq 0.

Since zero is a regular value of
h
based on Assumption
1
, Nagumo’s theorem yields forward invariance for
\mathcal{S}
.
Similarly, to show the invariance of
\mathcal{S}_{\delta}
, we take
{h_{\delta}=0}
.
This implies

{h\leq 0}
and

{\alpha(h)\!+\!\frac{(\mu(0)-\delta)^{2}}{4\sigma(h)}\!=\!0}
,
thus (
40
) yields

\displaystyle\dot{h}\geq\big(\mu(h)-\mu(0)\big)\|\mathbf{b}\|\geq 0,

where
{\mu(h)\geq\mu(0)}
as
\mu
is monotonously decreasing.
Based on
[
2
, proof of Thm. 3]
,
{\dot{h}_{\delta}\geq 0\iff\dot{h}\geq 0}
, and zero is a regular value of
h_{\delta}
via Assumption
1
.
Hence, Nagumo’s theorem yields forward invariance for
\mathcal{S}_{\delta}
.
These give safety for
{t\geq\tau}
, while Assumption
3
covers
{t\in[0,\tau]}
.
∎

Remark 1

(Special Cases)
.

In case of accurate prediction (
{\hat{\mathbf{x}}_{\mathrm{p}}=\mathbf{x}_{\mathrm{p}}}
),
one could set
{r_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u})=0}
,
reducing (
28
) to the standard ICBF conditions evaluated at the predicted state
\mathbf{x}_{\mathrm{p}}
:

\mathbf{b}_{i}^{\top}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\mathbf{v}\geq a_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u}).

(41)

The corresponding minimum-norm safety filter is:

\displaystyle\mathbf{q}(\mathbf{x}_{\mathrm{p}},\mathbf{u})=\argmin_{\mathbf{v}\in\mathbb{R}^{m}}

\displaystyle\quad\left\lVert\mathbf{v}\right\rVert^{2}

(42)

\displaystyle\mathrm{s.t.}

\displaystyle\quad\mathbf{b}_{i}^{\top}(\mathbf{x}_{\mathrm{p}},\mathbf{u})\mathbf{v}\geq a_{i}(\mathbf{x}_{\mathrm{p}},\mathbf{u}),

cf. (
30
).
Additionally, in case of zero delay (
{\tau=0}
), we have
{\mathbf{x}_{\mathrm{p}}=\mathbf{x}}
,
thus Assumption
3
holds automatically, and
(
41
)
reduces to the delay-free ICBF condition in
Section
II
.

IV
Adaptive Cruise Control with Delay

We illustrate the proposed framework on an adaptive cruise control (ACC) system
[
5
]
.
Consider an automated vehicle (AV) following a lead vehicle.
The AV’s state,
\mathbf{x}=[D~v]^{\top}
, includes the distance to the lead vehicle,
D
, and the AV’s speed,
v
.
With actuation delay
\tau>0

\dot{D}=v_{\rm L}-v,\qquad\dot{v}=u(t{-}\tau)-p(v),

(43)

where
v_{\rm L}
is the lead vehicle’s speed,

is the commanded acceleration,
and
{p(v)=c_{0}+c_{1}v+c_{2}v^{2}}

V
Conclusion

This paper developed an ICBF framework for the safety-critical control
of nonlinear systems with input delay and joint state and input constraints. Three contributions were presented.
First, predictor feedback was incorporated so that the safety filter compensates for the delay.
Second, a closed-form feasibility condition was derived for the two-constraint QP arising from simultaneous state and input constraints.
Third, a robust ICBF formulation was proposed to address prediction errors caused by, for example, delay uncertainty.
The framework was validated on an adaptive cruise control example, where delay compensation and robustness to a
50\%
delay estimation error were demonstrated in simulation.
Future research directions include experimental validation on embedded platforms with online delay estimation.
