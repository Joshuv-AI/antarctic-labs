Learning Adaptive Reasoning Paths for Efficient Visual Reasoning
Yixu Huang, Tinghui Zhu, Muhao Chen

Abstract
Visual reasoning models (VRMs) have recently shown strong cross-modal reasoning capabilities by integrating visual perception with language reasoning. However, they often suffer from overthinking, producing unnecessarily long reasoning chains for any tasks. We attribute this issue to Reasoning Path Redundancy in visual reasoning: many visual questions do not require the full reasoning process. To address this, we propose AVR , an adaptive visual reasoning framework that decomposes visual reasoning into three cognitive functions: visual perception, logical reasoning, and answer application. It further enables models to dynamically choose among three response formats: Full Format, Perception-Only Format, and Direct Answer. AVR is trained with FS-GRPO, an adaptation of Group Relative Policy Optimization that encourages the model to select the most efficient reasoning format while preserving correctness. Experiments on multiple vision-language benchmarks show that AVR reduces token usage by 50–90% while maintaining overall accuracy, especially in perception-intensive tasks. These results demonstrate that adaptive visual reasoning can effectively mitigate overthinking in VRMs. Code and data are available at: https://github.com/RunRiotComeOn/AVR .

Introduction

Visual reasoning models (VRMs;
15
) have recently demonstrated strong capabilities in multimodal reasoning by integrating visual perception with language reasoning.
These models exhibit emerging reasoning abilities in visually grounded settings, handling compositional
(
16
)
, multi-hop
(
11
)
, and logic-intensive tasks
(
27
)
.
Existing techniques focus on improving the reasoning ability of VRMs.
They borrow the idea from the Reasoning Language Models (RLMs;
13
), adopting Reinforcement Learning with Verifiable Reward (RLVR;
19
;
8
) to enhance reasoning on language
(
13
;
8
)
.
One line of work decomposes the response of VRMs by separating perception from reasoning
(
52
;
60
;
21
)
and ask the model to ground its reasoning based on its perceptual outputs.
Through these techniques, VRMs are able to conduct long, complex reasoning with visual inputs.

Despite these performance gains, recent studies show that LRMs frequently suffer from
overthinking

(
34
;
3
;
45
;
42
)
.
While extended reasoning can improve performance on challenging problems, models often produce unnecessarily long Chain-of-Thought (CoT) reasoning even for simpler ones, leading to excessive token consumption and sometimes even reducing accuracy due to errors introduced in intermediate reasoning steps
(
54
)
.
Existing attempts to address this issue
(
53
;
48
)
largely rely on heuristic strategies derived from RLMs, overlooking the distinct cognitive structure of visual reasoning, particularly the tight relationship between perception and reasoning.

In this work, we argue that a key cause of overthinking in VRMs lies in the cognitive structure of visual reasoning itself.
Unlike purely textual reasoning, solving a visual question typically involves three cognitive functions: visual perception, logical reasoning, and answer application
(
14
;
52
)
.
However, not all tasks require the full set of these cognitive functions. We observe a phenomenon termed
Reasoning Path Redundancy
: many questions can be correctly answered without invoking the reasoning function or both perception and reasoning functions. This finding suggests that selectively invoking cognitive functions can reduce redundant reasoning and even improve performance by reducing accumulated errors.

Motivated by this observation, we propose
AVR
, an adaptive visual reasoning framework that enables VRMs to dynamically allocate reasoning effort based on the task.
AVR decomposes visual reasoning into the previously described cognitive functions and defines three corresponding response formats with different token efficiency:
Full Format
,
Perception-Only Format
, and
Direct Answer
. Rather than enforcing the model to use all cognitive functions, AVR allows the model to adaptively select among these formats according to task requirements.
To enable this adaptive format selection, we adopt a two-stage training pipeline. First, we perform supervised fine-tuning (SFT) on format-annotated data to teach the model to produce responses in different formats. Second, we apply reinforcement learning (RL) using an adapted Group Relative Policy Optimization (GRPO) objective
(
40
)
, which we refer to as Format-Selection GRPO (FS-GRPO), to encourage the model to select the most efficient reasoning format while preserving correctness.

Experiments across multiple benchmarks demonstrate that AVR substantially reduces token consumption while maintaining overall accuracy, outperforming conventional VRMs and prior methods. On perception-intensive tasks like OCRBench, the model predominantly uses direct-answer and perception-only formats, reducing token usage by over 80% with improved accuracy. On reasoning-intensive benchmarks such as MathVista, it allocates more full-format responses when necessary, reducing token usage while maintaining accuracy.

Our contributions are summarized as follows:

•

We identify
Reasoning Path Redundancy
in VRMs and provide evidence that some visual questions can be solved without reasoning or even through direct answering.

•

We propose
AVR
, an adaptive visual reasoning framework that combines multi-format SFT with
FS-GRPO
, an RL objective that jointly optimizes correctness, token efficiency, and format diversity to enable dynamic format selection.

•

AVR achieves
50–90% token reduction
across seven benchmarks, while matching or improving accuracy compared to thinking models and other baselines, and generalizes across different model scales and families.

3
Preliminary

Based on previous work
(
65
;
39
;
1
)
, the outputs of VRMs follow three structured cognitive functions:

•

Visual Perception
: Visual perception extracts task-relevant information from the input image, including objects, attributes, spatial relations, and textual content.

•

Logical Reasoning
: Logical reasoning performs intermediate inference over perception, including multi-step deduction, comparison, counting, or commonsense reasoning.

•

Answer Application
: Answer application maps the inferred result to the final answer format required by the task.

However, not all questions require all functions. We refer to this overthinking phenomenon
Reasoning Path Redundancy
, as defined in Definition
1
.

Definition 1

(Reasoning Path Redundancy)
.

A reasoning path is
redundant
if a shorter path that contains a subset of its functional components can produce the same correct answer.

By analyzing 1,000 randomly sampled instances, we observe that VRMs often fail to adaptively select cognitive functions based on task requirements, instead overusing the full set of cognitive functions. In Qwen3-VL-4B-Thinking, 36.7% of questions can be correctly answered without invoking the reasoning function, and 32.1% can be solved through direct answering without explicit perception or reasoning (see Appendix
A.1
for details).

To further quantify this phenomenon, we introduce an
Overthinking Score
inspired by the compression ratio from previous works
(
44
;
46
)
as a diagnostic tool to demonstrate the extent of redundancy in reasoning paths. Formally, we define it as the ratio between the token length of the original model response with the correct answer and that of its compressed counterpart:

\text{Overthinking Score}=\frac{T_{\text{original}}}{T_{\text{compressed}}}

(1)

Overthinking Score Distribution.

where
T_{\text{original}}
denotes the number of tokens in the original model response, and
T_{\text{compressed}}
represents the number of tokens in the minimally sufficient response that preserves correctness generated by GPT-4o-mini
(
35
)
(see Appendix
A.1
for implementation details). Based on this metric, we observe that 35.4% of instances exhibit an overthinking score greater than 3, while 41.8% fall within the range of 1 to 3 as demonstrated in Figure
2
. These results further highlight the prevalence and severity of reasoning path redundancy in VRMs.

These results suggest that selectively invoking cognitive functions can preserve response correctness while reducing token consumption. Therefore, adaptive selection of reasoning formats based on task requirements becomes optimal in balancing cost and performance.

4
Method

We propose AVR, an RL training framework that enables VRMs to adaptively select efficient formats during visual reasoning process.
Our key idea is to explicitly decompose the reasoning pipeline into three cognitive functions and construct corresponding formats with different levels of reasoning effort. Based on these formats, we train the model to dynamically select the most appropriate reasoning path for each task.

The framework consists of two stages.

Stage 1: SFT for format understanding
. We first fine-tune the model on 11k diverse questions with three-format annotations. This stage enables the model to understand different reasoning formats and produce responses in multiple formats.

Stage 2: RL for efficient format switching
. We then employ FS-GRPO algorithm to train the model to dynamically switch between formats, allowing it to select the most efficient reasoning format based on task requirements while maintaining accuracy.

4.1
Decomposition of Reasoning Paths

We decompose the VRM reasoning process into three cognitive functions as previously stated in Section
3
:
Perception
,
Reasoning
, and
Answer
. Unlike the monolithic structure of traditional CoT, this decoupled architecture encourages explicit visual grounding and structured logical deduction. Such a design has been shown to improve accuracy on complex visual tasks
(
14
;
50
)
and provides an explicit mechanism for mitigating overthinking in VRMs (see Appendix
A.1
for details).

We implement this structure using functional special tokens (
<perception>
,
<reasoning>
, and
<answer>
), which allow us to define three distinct formats (
k
indexes the format; see Appendix
A.3
for details):

•

Full Format (
k=1
)
: A comprehensive sequence encompassing all components (
<perception>...<reasoning>...<answer>
).

•

Perception-Only Format (
k=2
)
: A streamlined path combining perception with answer (
<perception>...<answer>
), bypassing exhaustive reasoning.

•

Direct Answer (
k=3
)
: A minimalist output (
<answer>
) that targets immediate response efficiency.

4.2
Stage 1: SFT for Format Understanding

In this stage, we leverage SFT as a warm start to introduce the model to the formats it can utilize for solving VQA, using processed data in the formats described in Section
4.1
. After SFT, the model is able to generate all three formats, providing a strategic initialization for subsequent RL training.

4.3
Stage 2: RL for Efficient Format Switching

While SFT enables the model to follow defined formats, it often fails to dynamically switch between them based on task complexity. To address this, we propose FS-GRPO algorithm that encourages the model to select the most efficient format for a given problem.

For a given prompt
q
, the model generates a group of
G
outputs
\{o_{1},o_{2},\dots,o_{G}\}
. The efficiency and correctness of each output are evaluated through a multi-faceted reward function
r_{i}
.The total reward
r_{i}
for each response
o_{i}
is defined as:

r_{i}=s_{L,i}\cdot(r_{\text{format},i}+r_{\text{div},i}),

(2)

where
r_{\text{format},i}
incentivizes correct answers with efficient formats,
s_{L,i}
penalizes verbosity, and
r_{\text{div},i}
maintains format diversity.

Format Reward (
r_{format}
)

The base reward evaluates the correctness of the answer while incorporating format-specific rewards:

r_{\text{format}}=\begin{cases}1+f_{k},&\text{if the answer is correct},\\
-f_{k},&\text{otherwise}.\end{cases}

(3)

f_{k}
is the specific bonus for format
k\in\{1,2,3\}
as defined in Section
4.1
.
We use simple fixed values satisfying
f_{3}>f_{2}>f_{1}\geq 0
to impose a monotonic preference over formats, as higher bonuses encourage shorter responses. The exact magnitudes are not critical (see Section
6.3
for details); they simply establish a coarse hierarchy that favors more token-efficient formats (direct answers first, followed by perception-only reasoning) while penalizing incorrect answers in compressed formats. This encourages the model to use more concise format when confidence level is high, while falling back to longer formats otherwise.

Diversity Reward (
r_{div}
)

To prevent
Format Collapse

(
51
)
, where the model converges exclusively to one particular format (see Section
6.2
for details), we introduce a diversity reward that rewards less frequent formats within a sample group. For a group of
G
responses, let
c_{k}
be the count of responses using format
k
. The bonus is defined as:

r_{div}=d(t)\cdot(1-\text{freq}_{k}),

(4)

where
\text{freq}_{k}=\frac{c_{k}}{G}
. We employ a time-dependent decay factor
d(t)=\frac{1}{2}\left(1+\cos\left(\frac{\pi t}{T}\right)\right)
, where
t
is the current training step and
T
is the total steps. This decay gradually reduces the influence of the diversity reward, allowing the model to focus on optimal format selection rather than exploration in the later stages of training.

Length Scaling Factor (
s_{L}
)

To discourage verbosity, we scale the reward based on the response length
n_{tok}
relative to a length tolerance
L
:

s_{L}=\begin{cases}1.0&\text{if }n_{tok}\leq L\\
\frac{L}{n_{tok}}&\text{otherwise}.\end{cases}

(5)

Then, the group advantage
\hat{A}_{i,k}
for all tokens in each output is computed based on the relative rewards within the sampled group to reduce variance:

\hat{A}_{i,k}=\frac{r_{i}-\text{mean}(\{r_{1},r_{2},\dots,r_{G}\})}{\text{std}(\{r_{1},r_{2},\dots,r_{G}\})}.

(6)

Finally, we optimize the model by maximizing the following FS-GRPO objective, which incorporates the PPO-style clipping
(
38
)
mechanism and a KL divergence penalty
(
36
)
to ensure training stability:

\displaystyle\mathcal{J}_{\text{FS-GRPO}}(\theta)

\displaystyle=\mathbb{E}\left[q\sim P(Q),\{o_{i}\}_{i=1}^{G}\sim\pi_{\theta_{\text{old}}}(O|q)\right]\Bigg[\frac{1}{\sum_{i=1}^{G}|o_{i}|}\sum_{i=1}^{G}\sum_{k=1}^{|o_{i}|}\bigg\{

(7)

\displaystyle\min\left(\frac{\pi_{\theta}(o_{i,k}|q,o_{i,<k})}{\pi_{\theta_{\text{old}}}(o_{i,k}|q,o_{i,<k})}\hat{A}_{i,k},\text{clip}\left(\frac{\pi_{\theta}(o_{i,k}|q,o_{i,<k})}{\pi_{\theta_{\text{old}}}(o_{i,k}|q,o_{i,<k})},1-\epsilon,1+\epsilon\right)\hat{A}_{i,k}\right)

AVR v.s. Other Methods.

As shown in Table
2
, AVR consistently outperforms existing selective reasoning approaches across multiple benchmarks while maintaining competitive token efficiency. Compared with TON, which adopts a binary strategy between direct answering and full CoT reasoning, AVR achieves higher accuracy on most benchmarks (33.0% on MathVista and 41.3% on MMMU). Compared with ARM2, AVR achieves both higher accuracy and lower token consumption on most benchmarks.
For instance, on MMMU, AVR-4B reduces the average token usage from 285.0 to 128.7 while improving accuracy from 50.4% to 59.8%.
These results demonstrate that decomposing reasoning paths enables more efficient and adaptive visual reasoning.

Dynamic Format Selection Across Tasks.

To understand how AVR allocates reasoning effort, we analyze the distribution of reasoning formats across tasks (Figure

For perception-intensive tasks, the model tends to prefer lightweight formats such as direct answers (25.4%) and the perception-only format (25.1%), while the use of the full format is reduced after training. In contrast, for reasoning-intensive tasks, AVR models shift strongly toward the full format (78.3%), indicating that deeper reasoning is invoked when necessary. For general tasks, the model adopts a mixed strategy with moderate use of the full format while still achieving improvements in accuracy. Detailed analysis of format selection and case studies is provided in Appendix

These results suggest that AVR adaptively allocates reasoning effort based on task requirements rather than uniformly applying long reasoning chains.

Conclusion

We investigate overthinking in VRMs and identify Reasoning Path Redundancy as a key inefficiency driver. To address this, we propose AVR, which decomposes VRM reasoning into cognitive functions and trains models via SFT and FS-GRPO to dynamically select among three reasoning formats. Experiments across diverse benchmarks demonstrate that AVR achieves a 50–90% token reduction while maintaining or improving accuracy, generalizing across model scales and families. Our results highlight the promise of adaptive, task-aware reasoning for more efficient multimodal inference.

A.1.2
Overthinking Score Implementation

The Overthinking Score is intended as a
diagnostic metric
to quantify the prevalence of reasoning redundancy in existing VRMs. It is not used as a training signal or evaluation criterion for our method; its sole purpose is to motivate the need for adaptive reasoning formats.
We detail the construction procedure below. Given a visual question, we first prompt the evaluated VRM Qwen3-VL-4B-Thinking to generate a response using its default reasoning mode. We then filter for correctness by comparing the model’s answer against the ground-truth label via exact match. Only instances with correct original responses are retained, as redundancy is meaningful only when the original reasoning already succeeds.
For each retained response, we apply a controlled compression procedure using GPT-4o-mini. The model is instructed to rewrite the response under a minimal sufficiency constraint: removing unnecessary intermediate reasoning steps, retaining only the information essential for deriving the final answer, and producing the shortest possible response that still yields the correct answer (see the full prompt in Box
A.1.2
).
After compression, we verify whether the compressed response preserves correctness by prompting GPT-4o-mini to compare the compressed answer with the ground-truth label. Instances where the compressed response is judged incorrect are discarded from the Overthinking Score computation. We compute
T_{\text{original}}
and
T_{\text{compressed}}
using the same tokenizer as the evaluated model to ensure consistency.

We acknowledge that exact minimality cannot be guaranteed by this procedure. However, the compressed response represents a practical upper bound on the minimal sufficient length, meaning our Overthinking Scores are likely conservative estimates of the true redundancy. To validate the reliability of this approximation, we conduct human spot-checking on a random subset of 100 compressed instances.

Requirements:

- Keep only the essential information required to derive the final answer.

- The response should be as short as possible.

A.3
Format Construction

The three reasoning formats are designed to correspond to the minimal functional decomposition of visual reasoning in vision-language models. In most VQA-style tasks, solving a problem typically involves three conceptual stages: perception, reasoning, and answer generation. However, not all questions require the full pipeline. Some tasks can be solved directly from prior knowledge or simple visual recognition, similar to how humans can answer certain questions without explicit reasoning.

Based on this observation, we define three response formats with increasing computational depth: Direct Answer, Perception-Only, and Full Format. These formats correspond respectively to using none, a subset, or the complete reasoning pipeline. This design forms a minimal basis for representing different reasoning pathways while keeping the action space compact enough for stable reinforcement learning. In contrast, using fewer formats (e.g., full reasoning only) fails to explicitly capture visual information, which may lead to reasoning based on incomplete evidence. Introducing more formats would unnecessarily enlarge the decision space without providing additional functional benefit. Therefore, the three-format design provides a principled and efficient decomposition of visual reasoning behaviors.

A.4
SFT Dataset Construction

To construct the multi-format SFT dataset, we processed 44k image-text pairs through a three-step pipeline: response generation, functional format verification, and quality filtering.

Step 1: Response Generation.

We prompt GPT-4o
(
12
)
to generate responses following our decoupled reasoning architecture consisting of
<perception>
,
<reasoning>
, and
<answer>
(see Box
A.4
). Responses whose final answers do not match the ground-truth label (via exact match) are discarded.

Step 2: Functional Format Verification.

We emphasize that format assignment is not based on GPT-4o’s subjective judgment about whether reasoning is “needed.” Instead, we apply functional tests that rely solely on answer correctness:

•

Perception-Only Test.
We provide a separate model with only the generated
<perception>
text and the original question,
withholding the image entirely
. If the model consistently derives the correct answer from this textual description alone, the reasoning stage is functionally redundant for this instance, and the sample is assigned the perception-only format (see Box
A.4
).

•

Direct Answer Test.
We prompt the model with the image and question but instruct it to answer directly without intermediate reasoning. If the correct answer is produced, the sample is assigned the direct answer format (see Box
A.4
).

•

Full Format.
Samples that fail both tests above—i.e., require explicit reasoning beyond perception to reach the correct answer—are retained in the full decoupled format containing
<perception>
,
<reasoning>
, and
<answer>
.

This verification logic is self-contained: it depends only on whether the correct answer can be recovered under a restricted input condition, not on any model’s opinion about task difficulty.

Step 3: Quality Filtering.

After format assignment, we perform additional filtering including format distillation and human inspection. The final SFT dataset contains 11k high-quality samples distributed across the three formats.

Note on SFT Label Sensitivity.

We note that the SFT stage serves as a warm start to teach the model format competency, the ability to generate well-formed responses in all three formats, instead of optimal format policy. The selection of which format to use for a given task is learned during the subsequent RL stage, where the reward signal is based on verifiable answer correctness, not on SFT labels. Therefore, even if some SFT format labels are noisy, the RL stage can correct suboptimal format assignments through its own optimization. This design makes the overall framework robust to moderate label noise in the SFT data.

presents a detailed breakdown of format usage and corresponding accuracy across three representative benchmarks. We observe that the preferred reasoning format strongly correlates with the intrinsic task requirements.

Perception-Intensive Tasks.

On OCRBench, the model predominantly adopts the perception-only format (47.5%), which also achieves the highest accuracy (90.3%). In contrast, full format achieves only 75.2%, suggesting that introducing unnecessary reasoning may harm performance due to error accumulation. Direct answers also remain competitive (86.2%), indicating that many instances can be solved with minimal reasoning.

Reasoning-Intensive Tasks.

On MathVista, the full format dominates (78.3%) and yields the best accuracy (43.7%), confirming that complex tasks benefit from explicit reasoning. Lightweight formats such as direct answer are rarely selected and perform significantly worse, demonstrating that insufficient reasoning leads to suboptimal results.

General Tasks.

On MMMU, the model adopts a more balanced strategy, distributing predictions across all three formats. Except from full format, but both perception-only (59.2%) and direct answer (55.6%) remain competitive. This suggests that general-domain tasks exhibit heterogeneous reasoning requirements, where adaptive format selection becomes particularly beneficial.

Overall, these results highlight that no single reasoning format is universally optimal. Instead, effective performance arises from dynamically matching the reasoning format to task complexity: lightweight formats are preferred for perception-heavy problems, while full reasoning is reserved for tasks requiring multi-step inference. This validates the design of AVR in enabling adaptive reasoning path selection.

A.11.2
Reasoning Path Robustness

A potential concern is that the model may superficially conform to the predefined formats while implicitly performing hidden reasoning within earlier stages (e.g., embedding reasoning inside the perception block, as shown in Case 3 of Box
A.11.1
). Such behavior would undermine the intended decomposition and reduce the interpretability of the framework.

To evaluate this, we conduct a manual inspection of 1000 randomly sampled evaluation instances and examine whether stage boundaries are violated. We find that only 4.3% of cases exhibit any form of stage mixing, indicating that the model largely adheres to the intended functional separation between perception, reasoning, and answer generation.

This result suggests that the learned format control is not merely superficial, but reflects a genuine structural decomposition of the reasoning process. The low rate of stage violation provides evidence that AVR enforces meaningful modularization rather than format-level mimicry.
