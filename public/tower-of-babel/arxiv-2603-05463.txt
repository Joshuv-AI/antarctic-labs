EdgeDAM: Real-time Object Tracking for Mobile Devices
Syed Muhammad Raza, Syed Murtaza Hussain Abidi, Khawar Islam, Muhammad Ibrahim, Ajmal Mian

Abstract
Single-object tracking (SOT) on edge devices is a critical computer vision task, requiring accurate and continuous target localization across video frames under occlusion, distractor interference, and fast motion. However, recent state-of-the-art distractor-aware memory mechanisms are largely built on segmentation-based trackers and rely on mask prediction and attention-driven memory updates, which introduce substantial computational overhead and limit real-time deployment on resource-constrained hardware; meanwhile, lightweight trackers sustain high throughput but are prone to drift when visually similar distractors appear. To address these challenges, we propose EdgeDAM, a lightweight detection-guided tracking framework that reformulates distractor-aware memory for bounding-box tracking under strict edge constraints. EdgeDAM introduces two key strategies: (1) Dual-Buffer Distractor-Aware Memory (DAM), which integrates a Recent-Aware Memory to preserve temporally consistent target hypotheses and a Distractor-Resolving Memory to explicitly store hard negative candidates and penalize their re-selection during recovery; and (2) Confidence-Driven Switching with Held-Box Stabilization, where tracker reliability and temporal consistency criteria adaptively activate detection and memory-guided re-identification during occlusion, while a held-box mechanism temporarily freezes and expands the estimate to suppress distractor contamination. Extensive experiments on five benchmarks, including the distractor-focused DiDi dataset, demonstrate improved robustness under occlusion and fast motion while maintaining real-time performance on mobile devices, achieving 88.2% accuracy on DiDi and 25 FPS on an iPhone 15. Code will be released.

Introduction

Visual object tracking (VOT) is a fundamental video understanding task that requires continuously localizing a target across frames given only its initial bounding box. Despite recent progress with transformer-based and memory-augmented trackers
32
;
28
;
26
, real-world deployment still suffers from two persistent failure modes:
occlusion-induced drift
and
distractor confusion
. In cluttered scenes, partial or full occlusions weaken the target evidence, and visually similar objects become competing hypotheses, leading to identity switches that subsequently propagate and compound over time.

These challenges are further amplified on mobile and edge platforms, where strict latency and energy budgets limit the use of dense attention, high-resolution feature fusion, and mask-propagation pipelines commonly adopted by top-performing trackers. This creates a clear robustness–efficiency gap: state-of-the-art methods such as SAM2.1++
26
and SAMURAI
28
improve distractor resilience by maintaining segmentation-based memory banks with dense per-frame representations and retrieving them via cross-frame attention, but the resulting compute and memory overhead often prevents real-time on-device tracking.
However, as shown in Fig.
1
, these methods operate at 2–8 FPS even on high-end GPUs far below the real-time threshold for mobile applications.
At the other extreme, efficient trackers such as EdgeTAM
32
and OSTrack
29
sacrifice robustness for speed: both report approximately 0.78 IoU on occlusion-heavy benchmarks while running at 10–15 FPS.
This exposes a fundamental gap in existing VOT research:
heavy memory-based designs
improve robustness under occlusion and distractors but are often too slow for real-time edge deployment, whereas
efficient box-based designs
achieve high throughput yet remain fragile in the same challenging conditions. To date, no method achieves both robustness and efficiency simultaneously
without
relying on segmentation supervision or large pretrained encoders. In practice, the computational bottleneck of memory-based trackers stems mainly from two factors: (i) dense mask propagation across frames, and (ii) global cross-attention over high-dimensional memory tokens.

We argue that for
bounding-box
tracking, neither mechanism is necessary. Distractor-aware reasoning can be performed directly on axis-aligned boxes using lightweight geometric and appearance cues, eliminating the need for segmentation supervision. This motivates a different design paradigm: a detection-driven pipeline in which a compact
Distractor-Aware Memory (DAM)
operates at the bounding-box level, explicitly separating temporally stable target hypotheses from distractor candidates through geometric gating rather than attention.

Based on this insight, we introduce EdgeDAM, a lightweight single-object tracking framework tailored for real-time deployment on mobile and edge devices. EdgeDAM combines a flexible YOLO-based detector with the classical CSRT tracker
21
, and introduces a bounding-box DAM module that is inspired by, yet substantially redesigned from, the mask-based DAM in SAM2.1++
26
. A key distinction is that our DAM replaces dense feature memory with a dual-buffer structure: a Recent-Aware Memory (RAM) that stores geometrically verified target states using IoU and area-consistency gating, and a Distractor-Resolving Memory (DRM) that maintains stable appearance anchors to support recovery after occlusion. Unlike SAM2.1++, which updates memory through attention over segmentation features, EdgeDAM updates both buffers using lightweight geometric gating criteria, requiring no mask supervision, no transformer inference, and no GPU-intensive cross-frame attention.

To enable category-agnostic tracking, the detector is trained as a single-class object detector by unifying all category labels into a single target index, making the framework compatible with standard tracking benchmarks regardless of object category. Moreover, EdgeDAM is detector-agnostic by design: any Ultralytics YOLO variant from YOLOv8 onward can be substituted without architectural changes. Our main contributions are:

•

We propose a bounding-box Distractor-Aware Memory (DAM) with dual RAM/DRM buffers that separates verified target states from distractor hypotheses via geometric gating, requiring no segmentation masks or attention layers.

•

We introduce a confidence-driven switching criterion and a held-box recovery mechanism that suppresses distractor contamination during occlusion and enables reliable re-identification via DRM-based scoring.

•

We present a detector-agnostic, edge-deployable tracking framework using a single-class YOLO backbone, achieving real-time performance at 25 FPS on an iPhone 15 Pro Max with strong accuracy across five benchmarks.

Related Work

Tracking arbitrary objects in unconstrained video remains a longstanding challenge, particularly under long-term occlusion, distractor interference, and appearance changes. Classical approaches such as Siamese networks
14
;
13
;
25
;
30
;
2
and regression-based trackers
6
match features between a template and a search region but are prone to model drift during occlusion. Transformer-based trackers
19
;
5
improve robustness via cross-frame attention but rely on high-dimensional memory tokens and deep encoders, which limit their applicability to resource-constrained platforms.

Memory-based tracking has emerged as a dominant paradigm for robust tracking under occlusions. Such methods maintain temporal buffers of features or masks and retrieve contextual cues for re-identification
32
;
26
;
24
. For example, SAM2
24
extends the Segment Anything Model with memory attention to propagate masks across frames. While effective for lengthy video segmentation
7
;
11
;
17
;
23
;
27
, it suffers from high inference latency due to dense cross-attention over memory banks, making it unsuitable for real-time applications.

Edge focused variants such as EdgeTAM
32
and SAM2.1++
26
reduce latency through architectural optimizations. EdgeTAM compresses spatial memory using Perceiver modules, while SAM2.1++ introduces a distractor-aware memory structure (DAM). Both methods still rely on segmentation masks and global memory fusion, which impose non-negligible computational overhead and reduce flexibility.

Recent work on efficient, detection-driven trackers such as KeepTrack
22
, TransT
3
, and MixFormer
4
seeks to improve speed and generalization. Yet, many fail to explicitly handle occlusion or suffer from slow inference due to dense transformer blocks. SAMURAI
28
, though pretrained on large-scale video datasets, faces similar latency bottlenecks due to its hierarchical memory design. In contrast, our proposed method integrates a YOLOv11s-based detection backbone with a lightweight DAM module. Instead of relying on global memory fusion or segmentation supervision, we introduce a post-processing strategy that applies spatial freezing and bounding box scaling to preserve tracking coherence under uncertainty, without increasing inference cost.

Our Proposed EdgeDAM

EdgeDAM adapts a detection-guided single-object tracking paradigm.
Given the first-frame bounding box
b_{0}
, the objective is to estimate
the target box
b_{t}
for each frame
I_{t}
under occlusion and distractor
interference.
The system combines (i) a single-class YOLO detection backbone that proposes
candidate boxes, (ii) a lightweight CSRT correlation-filter
tracker
21
that propagates the target between
detections, and (iii) a Distractor-Aware Memory (DAM) module that stabilizes
updates and enables recovery when the tracker becomes unreliable.

Detection Backbone.

Given a frame
I_{t}\in\mathbb{R}^{H\times W\times 3}
, the detector

\mathcal{G}
outputs axis-aligned bounding boxes with confidence scores:

\mathcal{B}_{t}=\{(b_{i}^{t},\,s_{i}^{t})\}_{i=1}^{N_{t}},\quad b_{i}^{t}\in\mathbb{R}^{4},\quad s_{i}^{t}\in[0,1].

(1)

Confidence filtering retains high-quality proposals:

\mathcal{B}_{t}^{+}=\{(b_{i}^{t},\,s_{i}^{t})\in\mathcal{B}_{t}\mid s_{i}^{t}\geq\tau_{s}\}.

(2)

To reduce computational cost, detection is scheduled by stride
\Delta
:

\delta_{t}=\mathbb{I}\!\left[t\bmod\Delta=0\right].

(3)

When
\delta_{t}=0
, the system reuses
\mathcal{B}_{t-1}^{+}
and
propagates with CSRT.
During stable tracking, detection is restricted to an ROI crop
R_{t}

centered on the current estimate
\hat{b}_{t-1}=(x,y,w,h)
:

R_{t}=\!\left(c_{x}-\tfrac{\kappa w}{2},\;c_{y}-\tfrac{\kappa h}{2},\;\kappa w,\;\kappa h\right),

(4)

where
c=(x+w/2,\,y+h/2)
and
\kappa
is the crop scale factor.
Predicted boxes are mapped back to full-frame coordinates by adding crop
offsets
(x_{c},y_{c})
.

ROI-cropping is disabled when the tracker enters occlusion or recovery,
since the target may reappear outside the local neighborhood; a full-frame
detection pass is forced whenever
\mathrm{occ}_{t-1}=1
.
The resulting
\mathcal{B}_{t}^{+}
serves two purposes: (1) providing
candidate boxes for CSRT re-alignment, and (2) supplying the detection
stream for DAM updates (Sec.
3.1
).

3.1
Distractor-Aware Memory for Bounding Boxes

DAM4SAM
26
introduced a RAM/DRM decomposition
for SAM2-based segmentation tracking, but is redesigned for bounding-box, where RAM stores dense per-frame
mask-conditioned memory tokens and DRM retains hard-negative mask features
retrieved via cross-frame attention.

Our DAM adopts the same two-buffer philosophy but fundamentally redesigns
both components for bounding-box operation, as summarized in
Table
1
.
Concretely, we replace (i) dense mask features with compact geometric
descriptors, (ii) attention-based memory retrieval with IoU and
area-consistency gating, and (iii) mask-conditioned promotion with a
cosine-similarity stability test over appearance descriptors.
These changes reduce memory and compute requirements by orders of magnitude
while preserving the core distractor-rejection capability of the
dual-buffer design.

Each memory item stores a lightweight appearance descriptor

\phi(I_{t},b)
extracted from the image patch inside box
b
.
Let
\mathbf{p}(I_{t},b)=\mathrm{vec}(\mathrm{resize}(\mathrm{gray}(I_{t}[b])))

be a vectorised grayscale patch and

\mathbf{h}(I_{t},b)=\mathrm{hist}_{HSV}(I_{t}[b])
an HSV colour histogram.
The descriptor is their
\ell_{2}
-normalised concatenation:

\phi(I_{t},b)=\mathrm{norm}\!\bigl([\,\mathbf{p}(I_{t},b),\;\mathbf{h}(I_{t},b)\,]\bigr).

(5)

This compact descriptor avoids deep feature extraction while retaining
sufficient discriminative power for geometric and colour-based matching. RAM stores a short history of verified target boxes:

\mathcal{R}_{t}=\{(r_{j},\,\phi_{j},\,t_{j})\}_{j=1}^{|\mathcal{R}_{t}|}.

(6)

A candidate
b
is admitted to RAM only when it is geometrically consistent
with the previous hypothesis:

\mathrm{IoU}(b,\,\hat{b}_{t-1})\geq\tau_{\mathrm{in}}\;\;\wedge\;\;\left|\frac{a(b)-\tilde{a}_{t}}{\tilde{a}_{t}+\epsilon}\right|\leq\tau_{a},

(7)

where
a(b)=wh
is the box area,
\tilde{a}_{t}
is the running median
area in RAM, and
\epsilon=10^{-6}
is a numerical stability constant.
This gate prevents distractor boxes from polluting the recent target model
during short occlusions. DRM stores a compact set of
anchor
entries stable enough to serve
as recovery references:

\mathcal{D}_{t}=\{(d_{k},\,\psi_{k},\,\rho_{k})\}_{k=1}^{|\mathcal{D}_{t}|},

(8)

where
\rho_{k}
is the promotion timestamp.
Unlike RAM, DRM encodes no temporal proximity; it acts as a time-decayed
prior valid across extended occlusions.
A RAM entry is promoted to DRM only when at least
m_{\min}
of the last

W
RAM descriptors mutually agree in appearance:

\sum_{j=t-W+1}^{t}\mathbb{I}\!\bigl[\cos(\phi_{j},\phi_{t})\geq\tau_{\mathrm{sim}}\bigr]\;\geq\;m_{\min},

(9)

which acts as a stability filter against anchoring a corrupted state. Let
b^{\mathrm{ref}}=b_{t}^{\mathrm{hold}}
if the system is in occlusion
mode, and
b^{\mathrm{ref}}=\hat{b}_{t-1}^{\mathrm{trk}}
otherwise.
Each anchor
d_{k}
is scored against
b^{\mathrm{ref}}
:

\displaystyle S(d_{k})\;=

\displaystyle\lambda_{\mathrm{iou}}\,\mathrm{IoU}(d_{k},b^{\mathrm{ref}})+\lambda_{\mathrm{app}}\cos\!\bigl(\psi_{k},\,\phi(I_{t},b^{\mathrm{ref}})\bigr)

(10)

\displaystyle+\lambda_{\mathrm{mot}}\,\pi_{t}+\lambda_{\mathrm{time}}\exp\!\bigl(-\alpha(t-\rho_{k})\bigr),

where
\pi_{t}
is the short-term motion prior and the exponential term
down-weights stale anchors.
The appearance term
\lambda_{\mathrm{app}}\cos(\psi_{k},\phi(\cdot))

uses the compact HSV and grayscale descriptor from
Eq. (
5
); no deep feature extraction is required.
To suppress known distractors, a negative bank

\mathcal{N}_{t}=\{\nu_{\ell}\}
is accumulated from overlapping detections
during occlusion, and the penalized score is:

\tilde{S}(d_{k})=S(d_{k})-\gamma\max_{\nu_{\ell}\in\mathcal{N}_{t}}\cos(\psi_{k},\nu_{\ell}).

(11)

The highest-scoring entry is accepted if
\tilde{S}(\cdot)
exceeds a
minimum margin; otherwise, the system retains the held box.

3.2
Integration of DAM in the Tracking Pipeline

CSRT computes a Peak-to-Sidelobe Ratio (PSR)
\sigma_{t}^{\mathrm{trk}}

from its correlation response map at each frame.
Tracker failure is signaled when:

\delta_{t}^{\mathrm{sw}}=\mathbb{I}\!\left[\begin{aligned} &\sigma_{t}^{\mathrm{trk}}<\tau_{\mathrm{conf}}\;\vee\\
&\|\hat{b}_{t}^{\mathrm{trk}}-\hat{b}_{t-1}\|_{\mathrm{norm}}>\tau_{\mathrm{jump}}\;\vee\\
&|\mathcal{O}_{t}|\geq 2\end{aligned}\right].

(12)

When
\delta_{t}^{\mathrm{sw}}=1
, EdgeDAM transitions from CSRT
propagation to detector-guided re-identification via DAM.
A matched detection updates both the tracker state and RAM via the gate
in Eq. (
7
). Occlusion is detected when two or more high-confidence detections overlap
the current hypothesis:

\mathcal{O}_{t}=\bigl\{b\mid(b,s)\in\mathcal{B}_{t}^{+},\;\mathrm{IoU}(b,\hat{b}_{t-1})\geq\tau_{\mathrm{occ}}\bigr\}.

(13)

When
|\mathcal{O}_{t}|\geq 2
, the system outputs a
held
box

b_{t}^{\mathrm{hold}}
whose center is propagated by a motion estimate
and whose size is smoothly expanded:

\displaystyle c_{t}

\displaystyle=c_{t-1}+v_{t-1},

(14)

\displaystyle(w_{t},h_{t})

\displaystyle=(1{-}\beta)(w_{t-1},h_{t-1})+\beta(\bar{w}_{t},\bar{h}_{t}),

where
v_{t-1}
is the short-term velocity estimated via sparse
Lucas–Kanade optical flow
20
on Shi–Tomasi
keypoints within
\hat{b}_{t-1}
, computed between frames
I_{t-1}

and
I_{t}
.
The expansion target
(\bar{w}_{t},\bar{h}_{t})
is dynamically set to the
bounding box of
\bigcup_{b\in\mathcal{O}_{t}}b
, ensuring the held box
adapts to the spatial extent of all overlapping detections rather than
applying a fixed scale factor.
Overlapping detections are simultaneously added to
\mathcal{N}_{t}
as
distractor candidates for penalization during recovery. When
\delta_{t}^{\mathrm{sw}}=1
, EdgeDAM executes a three-stage
recovery cascade.

Stage 1:
DRM scoring via Eq. (
10
); if the
best-scoring entry
d_{k^{*}}
exceeds the acceptance margin, the tracker
is reinitialized with
d_{k^{*}}
.

Stage 2:
If no DRM entry qualifies, a descriptor-based snap-back
selects the detection in
\mathcal{B}_{t}^{+}
most consistent with the
compact histogram appearance and the motion-direction prior from
v_{t-1}
.

Stage 3:
If Stage 2 also fails, a normalized cross-correlation
(NCC) template search is performed over an expanded region around

b_{t}^{\mathrm{hold}}
.
If all stages fail, the held box is maintained and evidence continues to
accumulate until a valid recovery candidate emerges.

Experiments

4.1
Implementation Details

4.1.1
Training Setup

YOLOv11s is fine-tuned as a single-class detector by mapping all object
categories in each benchmark’s training split to a unified target label,
making the backbone category-agnostic at test time.
Benchmarks with mask or polygon annotations are normalized to axis-aligned
bounding boxes prior to fine-tuning: tight enclosing rectangles for mask
annotations and vertex extrema for polygon annotations.
Validation and test splits are never used during training.
All data augmentations are applied during fine-tuning only and disabled
at evaluation.
The framework is detector-agnostic and supports any YOLO variant
(YOLOv8–YOLOv26) without architectural changes.

4.1.2
Inference Configuration

Detector inputs are resized to
640{\times}640
with confidence threshold

\tau_{s}{=}0.45
, NMS IoU threshold
0.50
, detection stride
\Delta{=}3
,
and ROI crop scale
\kappa{=}2.0
.
Half-precision inference with model fusion is applied to reduce operator
overhead.
DAM uses
|\mathrm{RAM}|{=}10
,
|\mathrm{DRM}|{=}10
with FIFO eviction;
each entry stores a
16{\times}16
grayscale patch concatenated with a

16{\times}16
HSV histogram,
\ell_{2}
-normalised.
Switching thresholds are
\tau_{\mathrm{conf}}{=}0.35
and

\tau_{\mathrm{jump}}{=}0.30
.
DRM scoring weights are
\lambda_{\mathrm{iou}}{=}0.4
,

\lambda_{\mathrm{app}}{=}0.3
,
\lambda_{\mathrm{mot}}{=}0.2
,

\lambda_{\mathrm{time}}{=}0.1
, with decay
\alpha{=}0.05
and
distractor penalty
\gamma{=}0.25
.
RAM admission uses
\tau_{\mathrm{in}}{=}0.50
and area tolerance

\tau_{a}{=}0.20
; occlusion detection uses
\tau_{\mathrm{occ}}{=}0.40
;
DRM promotion requires cosine similarity
\tau_{\mathrm{sim}}{=}0.85

over a window of
W{=}5
frames with
m_{\min}{=}3
.

4.1.3
Mobile Deployment

Detector weights are exported to ONNX and converted to CoreML for
execution on an iPhone 15 Pro Max.
Throughput optimizations include fixed
640{\times}640
inputs,
half-precision inference, model fusion, adaptive detection stride
scheduling, and ROI-crop inference during stable tracking,
collectively achieving real-time performance at
25
FPS on-device.

4.8
DAM Buffer Capacity

Table
8
reports the effect of varying
RAM and DRM buffer sizes on IoU, recovery latency (RecF), and FPS.
Smaller buffers (5–5) achieve high IoU (0.981) with low latency and
real-time throughput (24.89 FPS).
The 10–10 configuration yields the best IoU (0.991) and highest FPS
(25.81), representing the optimal trade-off for edge deployment.
Larger buffers (15–15 and 20–20) cause a notable IoU drop to 0.870
and 0.880, respectively, despite wider memory capacity.
This counter-intuitive degradation arises because FIFO eviction retains
stale or partially corrupted entries as the buffer grows; under FIFO,
older hypotheses that no longer reflect the current target appearance
accumulate in DRM and compete with valid anchors during recovery scoring,
increasing the probability of selecting an incorrect candidate.
Larger buffers also increase per-frame matching cost, reducing FPS below
the real-time threshold.
The 10–10 setting balances anchor diversity against staleness and is
used as the default throughout.

5
Conclusion

We presented EdgeDAM, a lightweight and efficient visual object tracker designed for robust occlusion handling in resource-constrained environments. Our model integrates a DAM module within a YOLOv11s-based detection and CSRT tracking pipeline, enabling reliable recovery from long-term occlusions, abrupt appearance changes, and distractor interference. To further enhance temporal stability, we introduced a post-processing strategy that adaptively freezes and enlarges the bounding box during uncertain states, maintaining localization continuity until re-identification. Our results validate the effectiveness of structured memory and hybrid detection-tracking integration for real-time, occlusion-resilient performance. In future work, we plan to extend EdgeDAM to multi-object and 3D occlusion-aware tracking, and explore its integration with vision-language models for more context-aware tracking.
