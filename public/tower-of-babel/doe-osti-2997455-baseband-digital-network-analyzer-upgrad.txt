 APPLICATIONS
 The transfer function measurement is used to tune the
OTFB loop using regression optimization. Python is used
to compare a model of the system response to the network
analyzer measurement. The script runs regression functions
to fit the model to the measurement. From the fitted model,
we can derive the loop delay to setup the feedback loop [5].
