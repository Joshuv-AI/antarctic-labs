 Executive Summary of CRADA Work:

 Contractor will perform a computational fluid dynamics (CFD) analysis of the Participant’s
 CETO wave energy converter (WEC) in an extreme wave environment. The load cases will be
 based on model test data that will be used for validation.

 Task 2: CFD Setup

 Contractor will develop a Computational Fluid Dynamics (CFD) model based on the design
 specifications provided by the Participant. The model will be checked for proper implementation
 of the power take off (PTO) system by comparing the PTO forces as a function of WEC motions,
 compared to reduced-order model results provided by the Participant. Contractor will perform a
 convergence study to assess whether the critical spatial and temporal discretization and domain
 parameters are sufficient.

 2

 Task 2 Results: A 2D precursor CFD run was used to generate the nonlinear extreme sea state
 wave fields used in this project. The 2D wave domains were 6 wavelengths long based on the
 relevant peak period. A region 1 significant wave height above and 1 significant wave height
 below the still water level was refined to resolve the free surface. This region used a vertical cell
 height of 20 cells per significant wave height and a cell aspect ratio of 2. The cell size was
 refined to 10 cells per significant wave height down to a depth of 3 significant wave heights
 below the still water level.

 Fig. 1. 2D domain length with color showing horizontal velocity component in an irregular wave field.

 The time step was set as the smaller of two criteria. The first criterion was a vertical wave
 particle velocity courant number of 0.1. The second criterion was a minimum of sixty time steps
 per period of the minimum relevant wave period from the wave spectrum. This minimum
 relevant period was quantified as the point in the wave spectrum where 95% of the energy occurs
 at lower frequencies.

 The volume of fluid fraction, horizontal velocity component, vertical velocity component, and
 pressure were prescribed throughout the domain for the initial condition. The volume of fluid
 fraction, horizontal velocity component, and vertical velocity component were prescribed at all
 time steps for the inlet boundary condition.

 The wave time series is known at one or multiple points in the domain. This is either the position
 of the undisplaced WEC or a set of wave gauges from wave basin experiments. The ultimate
 load case prescription is based on the extreme wave field that the WEC will experience. The inlet
 boundary condition needs to be set such that the propagated wave at the point of interest has the
 correct phasing. Multiple techniques were tested to best match the desired wave field at the WEC
 location, including 1st order theory, 2nd order theory, reflected wave identification with multiple
 wave gauges, averaging of multiple wave gauges, time domain tuning, and frequency domain
 tuning. A preprocessing code, ‘CustomWave.py’, takes as input the elevation time series at a
 defined position or positions, and generates files for initial and boundary conditions for the 2D
 CFD. ‘CustomWave.py’ is included on Marine and Hydrokenetic Data Repository (MHKDR)
 and can optionally include 1st order theory only, 2nd order theory, reflected wave identification,
 and averaging of multiple wave gauges.

 A mesh convergence study was performed using forced oscillations of the WEC in the surge
 direction. The net hydrodynamic forces on the body in the x, y, and z directions are shown in the

 overset region in millions. The final entry uses the same outer resolution as the 2.2 million cell
 mesh, but with increased boundary layer refinement around the WEC, for a minimum y+ value
 of 1.0 instead of 2.0 that were observed for the other meshes. The y-direction force was most
 strongly influenced by the mesh and was used as the criterion for convergence.

 PTO controls were implemented in the 3D CFD simulations following specifications from the
 Participant. Extensive checks were performed to ensure the controller logic matched the
 Participant’s design. This involved running motions from the Participant’s model through the
 Contractor’s model and comparing the output PTO forces at each time. Some custom
 modification of how the CFD model was run was required, but the resulting controller provided
 the correct loads.

 Task 5: Structural Analysis

 Contractor will set up the Finite Element Analysis (FEA) model for the structure specified by the
 Participant and evaluate that it is sufficiently well discretized. Contractor will run the FEA load
 cases for the load history recorded in the fluids simulations.

 Task 5 Results: FEA was not performed due to budget constraints. Additional effort was
 required to ensure accurate wave generation and PTO control logic. These tasks were prioritized
 over structural modeling, since FEA based on inaccurate hydrodynamic loads would not provide
 meaningful value to the Participant.
