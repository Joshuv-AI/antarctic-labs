 ABSTRACT
Routine event-based processing is one of the strengths of neutron scattering experiments at Oak Ridge
National Laboratory (ORNL) (Peterson et al. 2015, Granroth et al. 2018, Peterson et al. 2018).
Multi-Dimensional Event (MDE) workflows are already well-established for single-crystal Direct
Geometry Spectroscopy (DGS) and diffraction experiments. This report demonstrates how the same
formalism can be extended to powder measurements.

 2. IMPLEMENTATION DETAILS
Particular implementation details are described in terms of the Mantid software (Arnold et al. 2014) in
use at Oak Ridge National Laboratory (ORNL), but the formalism is entirely general. The workflow starts
with a set of neutron events, labeled by momentum and energy transfer. The storage container in Mantid
is an Multi-Dimensional Event (MDE) workspace. It contains information about instrument geometry
and various experimental parameters. At minimum, the procedure below requires knowledge of incident
energy 𝐸 𝑖 , and the minimum and maximum energy transfer that was used for each detector. Similar to
the single crystal case, the first step is binning the neutron events into a Multi-Dimensional Histogram
(MDH). One needs to create on the same grid a histogram with the normalization factors (denominator
in the equation 2). The final, normalized intensity is the ratio of these histograms.

2.1 CALCULATING INTERSECTIONS
For each detector (or detector group) one calculates intersections with constant energy transfer lines in
exactly the same way as we calculate the trajectories, but uses only energy transfers that are bin edges. In
addition, one needs to consider the points that are at the minimum/maximum available energy transfer.
These might not be on a bin boundary.
In the case of DGS, the intersections with constant 𝑄 lines yield final momentum values from equation 4.

When processing data, including the transformation to |𝑄| and Δ𝐸, each detector trajectory covers a
limited range in energy transfer. This can be stored as 𝑀 𝐷𝑁𝑜𝑟𝑚_𝑙𝑜𝑤 and 𝑀 𝐷𝑁𝑜𝑟𝑚_ℎ𝑖𝑔ℎ logs in the

and the lowest Δ𝐸 for the grid. Similarly, for the upper bound, all intersections have to be less than
𝑀 𝐷𝑁𝑜𝑟𝑚_ℎ𝑖𝑔ℎ for the detector and the highest Δ𝐸 for the grid.

they differ in the |𝑄| value one should assign intensity to the box that the center between these intersections
falls into. corresponding to (𝐸 𝑖 + 𝐸 𝑖+1 )/2 and (|𝑄| 𝑖 + |𝑄| 𝑖+1 )/2. Because the trajectories are non-linear,

function of either 𝑘 𝑖 or 𝑘 𝑓 . Consequently, any momentum value lying between two solutions corresponding
to the same original |𝑄| 2 will yield a smaller momentum transfer. Therefore, the intensity should be
assigned to the bin on the lower-|𝑄| side.

2.3 NORMALIZATION CONTRIBUTION
The denominator of equation 2 is a normalization factor for the neutron counts. For each detector (or
detector group), and for every run, the number of events scattered in a particular bin is proportional to
the solid angle, the incident neutron flux that can contribute to that particular bin, and the length of the
trajectory along the energy transfer direction.
As mentioned in previous sections, the solid angle is proportional to the neutron counts measurements of
incoherent scatterers.
For DGS measurements all incident neutrons can contribute to scattering. If one uses a single energy/
configuration of the incident beam, the flux is proportional to the integrated proton charge. This approach
provides better statistical precision than relying on integrated monitor counts, especially for short runs.
However, it does not account for different incident flux as function of selected fixed energy/ configuration
of incident beam.
For IGS measurements, due to conservation of momentum and energy, not all incident neutrons can
contribute to scattering in a particular histogram bin. We have identified in section 2.1 the intersection
of the detector trajectories with histogram bins. Neutrons with incident energies between consecutive
intersections contribute to the histogram bins identified in section 2.2.

 3. ALGORITHM STEPS
Mantid MDE workspaces can store information from separate measurements. Instrument geometry and
experimental sample logs are stored in "experiment info" structures.
 • The first step is validation. If one uses grouped detectors for the input MDE workspace, one must
 use the same grouping for the incoherent (Vanadium) workspace. The Vanadium workspace must be
 integrated into a single bin corresponding to the elastic line.
 • Histogram the events.
 • Create a similar grid for normalization, initialized to 0.
 • Additional dimensions should be processed similar to the MDNorm algorithm in Mantid. We can
 use temperature as an example. For every experiment info check first if the temperature log value
 falls into one of the bins along the temperature grid. That particular experiment info will contribute
 only to one temperature bin.
 • For every experiment info, loop over detectors or detector groups, calculate intersections. Discard
 any negative 𝑘 𝑓 values, or any values that fall outside the histogram edges. For each consecutive
 intersections, assign the intensity to the corresponding box (inside the histogram). The intensity to
 be added is equal to the proton charge in the experiment info, multiplied with the vanadium intensity
 for that particular detector group, and the energy transfer difference between intersections. For the
 case of IGS, the flux is proton charge multiplied with integrated flux spectrum between intersections.

3.1 NOTES:
 • The Mantid implementation of the algorithm relies on the MDE workspace storing correctly the
 detector grouping. This needs to be persisted during saving/loading from files.
 • For IGS, the energy dependence of the incident flux can be found from a monitor spectrum. It is
 important to correct it for the energy response of the monitor itself. Similarly, for the DGS one needs
 to correct the counts for the energy dependence of the detectors.
 • Since DGS instruments at ORNL use a large number of finely pixelated detectors, one can group
 detectors with similar scattering angle in order to decrease the number of calculations.
 • For DGS one can use multiple incident energies, as seen in super-resolution measurements (Islam
 et al. 2019). In this case one needs to account for incident beam flux energy dependence.
