Dynamic convolutional neural networks for altitude aware UAV object detection
Authors: Michalis Piponidis, Theocharis Theocharides
Published: 2026

ABSTRACT
Object detection in Unmanned Aerial Vehicles (UAVs) is inherently challenging due to the wide variation in altitudes and viewpoints, coupled with the limited computational resources of onboard embedded systems. Traditional Convolutional Neural Networks (CNNs), while accurate, are often over-parameterized and inefficient for real-time UAV deployment due to their high computational and memory demands. Designed for all types of inputs, they perform redundant operations that strain the limited processing power, memory, and energy resources available on UAV platforms. This work addresses these limitations by modeling UAV object detection as a context-aware task, using altitude as a primary adaptive parameter. We train specialized CNN configurations for discrete altitude ranges, exploring the impact of key parameters—input image resolution, network width, and kernel size—on detection performance and efficiency. Dynamic parameter switching based on altitude enables resource-efficient deployment without compromising accuracy. Using two altitude-diverse datasets, we demonstrate that optimal CNN settings vary significantly across altitudes, underscoring the need for altitude-specific adaptation. We introduce a threshold-based switching mechanism and perform a detailed analysis of how varying these altitude thresholds affects both detection accuracy and system efficiency. Our results show that well-chosen thresholds result in minimal accuracy loss and maximal resource savings compared to an equivalent non-dynamic CNN. The proposed dynamic CNN framework offers a scalable, energy-efficient solution for UAV-based applications such as surveillance, search and rescue, and environmental monitoring, where adaptability to context is essential.

Introduction

Unmanned Aerial Vehicles (UAVs) have become integral to modern applications such as search and rescue1, infrastructure inspection2, emergency management3, agricultural monitoring4, and environmental surveillance5. Their ability to rapidly deploy, capture aerial imagery at multiple altitudes, and operate in challenging environments has made UAVs indispensable for real-time situational awareness and decision-making.

Object detection plays a pivotal role in UAV missions by enabling autonomous navigation, obstacle avoidance, and mission-specific tasks. Recent advancements in cross-view geo-localization, UAV imaging, and remote sensing have been driven by innovative methodologies that leverage deep learning and computer vision techniques6–9. However, effective object detection on UAVs presents unique challenges. These include real-time processing requirements under constrained onboard resources, image degradation due to environmental factors (e.g., haze, glare, or low light), and substantial variation in image appearance caused by changing flight altitudes and viewing angles10,11. Conventional Convolutional Neural Networks (CNNs), although accurate, are typically designed to generalize across a wide spectrum of input scenarios, resulting in large, static models that may underperform or consume excessive resources when deployed in dynamic UAV environments.

This work addresses these limitations by treating UAV object detection as a context-aware task, using altitude as a key contextual variable. This is not merely a scale generalisation problem: even with multi-scale training or feature pyramids, a static model’s computational graph is fixed, so it cannot dynamically reallocate FLOPs or memory bandwidth according to the instantaneous operating altitude.

Rather than designing a single architecture that tries to span all scales, we propose a dynamic model switching framework that selects, at runtime, a specialised CNN configuration θ (a) based on the current altitude. This is distinct from and complementary to existing strategies. Multi-scale training (e.g., random image resizing) improves robustness but does not change the model’s computational cost per image. Feature Pyramid Networks (FPNs) add overhead at all altitudes and still rely on a single static backbone. Adaptive input resolution can reduce compute, but it does not alter network width or kernel size — dimensions that strongly affect memory and energy (Sect. “Experimental results”). Our dynamic switching, by contrast, adjusts multiple architectural parameters (resolution, width, kernel size) simultaneously and only loads the necessary weights for the current altitude, directly tackling the accuracy-efficiency trade-off under distribution shift.

We treat altitude as a proxy for scale distribution shift, and we show that even with a simple threshold-based switching policy, this approach outperforms any single static model on both accuracy and efficiency under realistic mission profiles (Sect. “Case studies & discussion”). The main objective of this manuscript is to assess the potential benefits of implementing a dynamic approach with varied, context-optimized models, versus training and deploying one model for all inputs.

To enable transitions between models, we introduce a threshold-based switching mechanism and perform a detailed analysis of how different threshold values affect detection performance and hardware efficiency. While the underlying CNN backbone (Tiny YOLOv7) is not itself novel, the contribution of this work lies in the proposed context-aware dynamic inference framework, which systematically exploits altitude information to adapt model complexity at runtime. The results demonstrate that adaptive CNN switching yields substantial gains over non-dynamic deployments, particularly when transitions are governed by well-calibrated thresholds.

This work builds on our prior studies:12 demonstrated that optimal CNN configurations vary with altitude in UAV object detection, and13 analyzed which parameters best balance accuracy and efficiency across datasets. Here, we extend this line of work by evaluating that trade-off at the hardware level.

Related work

UAV-based object detection has seen substantial advancements in recent years, particularly in addressing the unique challenges posed by aerial imagery, such as small object detection10,14, high object densities, and viewpoint variability due to altitude changes.

A considerable body of work has focused on improving detection algorithms and CNN architectures tailored to UAV data. Tan et al.15 introduced a multi-scale detection strategy that incorporates adaptive feature fusion to enhance small object detection in UAV imagery. Their method integrates an adaptive feature extraction module into the backbone network, boosting localization precision. Similarly, Xiaohu et al.16 proposed an FPN-based detector augmented with Deformable Convolution Lateral Connection Modules (DCLCMs) and Attention-based Multi-Level Feature Fusion Modules (A-MLFFMs), targeting improved multi-scale feature integration. Liu et al.17 further optimized YOLOv3 by modifying the darknet architecture to enlarge the receptive field and enhance spatial representation, thereby improving detection performance for small targets.

Several surveys have consolidated developments in UAV-based detection, emphasizing the need for lightweight models suitable for real-time inference on resource-constrained UAV platforms. Wu et al.18 reviewed popular CNN frameworks such as YOLO and Faster R-CNN, highlighting the trade-offs between accuracy and computational cost. Mittal et al.19 conducted a focused analysis on low-altitude UAV datasets, identifying persistent challenges and open research questions.

Real-time object detection is particularly relevant in time-critical applications such as disaster response and smart agriculture. Cao et al.20 surveyed real-time detection pipelines, discussing both algorithmic strategies and hardware implementations. Their review underscores the importance of lightweight convolutions and efficient edge computing hardware, such as embedded GPUs, to achieve low-latency performance.

Recent developments in dynamic neural networks offer promising directions for improving efficiency and adaptability. Zhang et al.21 proposed a framework leveraging deformable convolutions to dynamically adjust receptive fields based on object density and size, enhancing performance in complex UAV imagery. Du et al.22 presented an adaptive sparse convolutional network with global context enhancement, which modulates sparsity levels in real-time to reduce computation without compromising accuracy.

Beyond object detection, recent work in remote sensing change detection23 has shown that combining foundation models like SAM with limited data can improve generalisation. These ideas are complementary to our altitude‑adaptive strategy and may inform future extensions.

Parallel to algorithmic advances, hardware-aware optimization has also gained traction. Approaches include quantization, pruning, and the use of custom hardware accelerators, particularly FPGAs24,25. While many of these works focus on modifying the network structure or training methodology, our work adopts a complementary perspective: dynamically selecting optimal CNN parameters based on contextual UAV information (i.e., altitude), with evaluation metrics that extend beyond accuracy to include latency and power consumption.

By leveraging dynamic parameter adjustment and reconfigurable hardware platforms, our approach aims to deliver context-aware detection performance—an essential capability for real-world UAV deployments operating across variable altitudes and computational constraints. We expand on our previous work:12 presented an initial investigation confirming that different CNN parameter configurations yield optimal results at different altitudes for UAV object detection, while13 explored which parameters most effectively balance performance and accuracy across multiple datasets. In this work, we extend the analysis to the hardware level, evaluating the performance-to-accuracy trade-off in terms of deployment efficiency.

Baseline CNN models

This study adopts Tiny YOLOv726 as the baseline CNN architecture. Designed for real-time applications, this lightweight detector offers an effective balance between accuracy and efficiency, making it ideal for deployment on resource-constrained UAV platforms.

We employ two specialized datasets: the Multi-Altitude Aerial Vehicles Dataset27 and the Aerial Water Buoys Dataset28. Both contain annotated images captured at varying flight altitudes and feature single-class object detection—vehicles and buoys, respectively. These altitude-based variations introduce significant changes in object scale, shape, and density. Representative annotated samples are shown in Figs. 1 and 2.

The best-performing configuration across the full training set of each dataset (denoted as mix_alt) is used as the non-adaptive baseline for comparison in our case studies. This configuration is selected based on a balance of accuracy and efficiency; specifically, it corresponds to the most lightweight model (i.e., lowest input resolution and width multiplier) that still meets or exceeds a predefined target accuracy threshold. This choice ensures a fair and practical baseline, emphasizing minimal resource usage without compromising detection performance.

In this work, the focus is placed on optimizing the parameters of a specific CNN architecture, rather than proposing a new network design. As such, comparisons are intentionally restricted to the baseline Tiny YOLOv7 architecture and its parameter variants, ensuring that performance differences can be attributed solely to context-aware parameter adaptation rather than architectural changes.

Each subset is treated as an independent training scenario to learn altitude-optimized detection models.

Experimental results

Detection performance

Detection performance was evaluated using mean Average Precision (mAP) at an Intersection over Union (IoU) threshold of 0.5, where mAP reflects the overall accuracy of object detection across classes, and IoU measures the overlap threshold between predicted and ground-truth bounding boxes. The corresponding results for the Aerial Vehicles and Aerial Water Buoys datasets are shown in Figs. 5 and 6, respectively.

As anticipated, models evaluated on images captured at lower altitudes achieve higher accuracy with relatively fewer parameters. This behavior is attributed to the increased object scale and clarity at lower altitudes, which simplify the detection task. In contrast, detection performance deteriorates at higher altitudes unless more complex models are employed. This is due to reduced object scale and visual distinctiveness at elevated viewpoints, which necessitate deeper and wider models for effective feature extraction.

Interestingly, the mix_alt dataset consistently exhibits intermediate or superior accuracy relative to altitude-specific subsets. This is likely due to the inclusion of low-altitude samples in the training set, which guides model learning with clearer object features. Conversely, high-altitude-specific models, trained solely on more challenging instances, tend to underperform.

To illustrate why a single static model fails under altitude variation, we compare the performance of the mix_alt baseline (Table 2) across altitudes. At 50–100 m, the mix_alt model achieves 0.997 mAP but consumes 16.35 M MACs per image — 19× more than the specialised low-altitude model (0.86 M MACs). Conversely, at 450–500 m, the same mix_alt model delivers only 0.417 mAP, which is about half the specialised high-altitude model (0.897 mAP using 896p and 100% width). Thus, a static model either wastes compute at low altitudes or sacrifices accuracy at high altitudes. This degradation (visualised in Figs. 5 and 8) is not an artefact of a particular architecture; it stems from the fundamental mismatch between a fixed model capacity and a continuously varying input distribution. Computational efficiency

Computational efficiency was assessed using two primary metrics: Multiply-Accumulate (MAC) operations and model size. MAC operations quantify the total number of computations required to process a single image, directly impacting processing speed and power consumption. Model size, measured in megabytes (MB), reflects the memory footprint of the network’s weights, which is a critical constraint for onboard UAV deployment.

Figure 8 illustrates the scaling behavior of MAC operations and model size across different configurations. Both metrics increase with higher resolution and wider networks. However, model size exhibits greater sensitivity to changes in the width multiplier compared to input resolution. This implies that reducing the width multiplier is a more effective strategy for decreasing the memory footprint without severely impacting accuracy—especially when high resolution is needed for capturing fine object details.Fig. 8Computational efficiency results, including MAC operations and model size, across all model configurations. Practical implications

These findings highlight that model selection based purely on altitude may not always be ideal. Incorporating contextual thresholds, such as energy budget or operational urgency, enables dynamic switching strategies that optimize performance under constraints. For example, during extended missions with limited power reserves, a UAV system could prioritize a “Lower” strategy to significantly reduce energy use with only a minor compromise in accuracy. Conversely, in critical surveillance scenarios where detection precision is paramount, a more aggressive switching approach like “150” or “250” could provide a favorable middle ground.

Discussion

Our results demonstrate the effectiveness of a context-aware, dynamic CNN model selection strategy based on altitude for UAV object detection. Using a threshold-based switching method, the dynamic approach consistently outperformed a general fixed model across all performance metrics.

In Case Study 1, which used the dataset’s real distribution, the dynamic configuration achieved a slight accuracy decrease (1.4%), while significantly reducing MAC operations (19.1%). These results emphasize the ability of altitude-specific models to better align computational effort with task complexity.

Case Study 2, simulating missions with predominantly low-altitude images, further highlighted the benefits of the dynamic configuration. Compared to the fixed model, accuracy improved by 1.6%, while MAC operations were reduced by 62.8%. These efficiency gains stem from the increased use of lightweight models in lower-altitude scenarios, which offer sufficient accuracy at a fraction of the cost.

Additionally, our threshold exploration analysis confirmed that switching mechanisms based on hand-picked altitude thresholds can yield substantial benefits. Although we used manually defined thresholds in this study, the effectiveness of this approach opens the door to more intelligent thresholding techniques or learning-based selection strategies that could further improve performance and adaptability.

These findings validate our hypothesis that altitude is a valuable contextual cue for efficient model selection. The improvements achieved without complex control mechanisms make the approach practical for resource-constrained UAV platforms operating in real time.

However, relying solely on altitude may not be optimal in all scenarios. Other environmental factors such as lighting, occlusion, or weather can also influence detection difficulty. Incorporating additional contextual inputs—such as camera metadata or scene understanding—could further improve model selection strategies.

Comparison with multi-scale architectures

We note that our baseline comparisons are limited to variants of the same backbone architecture (Tiny YOLOv7) to isolate the effect of altitude-aware parameter adaptation. A direct comparison with a standard multi-scale detector, such as a constrained Feature Pyramid Network (FPN)29 or a lightweight FPN-based architecture, is not provided in this work. While our results consistently show that altitude-specific switching outperforms a static, mixed-altitude Tiny YOLOv7 model, we acknowledge that the claimed “context-aware superiority” may not fully extend to architectures that already incorporate multi-scale feature fusion. In fact, such multi-scale designs could potentially reduce the need for altitude adaptation by implicitly handling scale variations. Nevertheless, they typically come with higher computational overhead, and the combination of multi-scale fusion with dynamic altitude switching remains an interesting direction for future work. We therefore view our contribution as complementary to, rather than a replacement of, multi-scale detection methods.

Challenges and future directions

A key challenge is ensuring seamless model transitions during inference, as switching between models optimized for different altitudes can introduce latency that affects real-time performance. While a full dynamic reconfiguration implementation is deferred to future work, we provide a theoretical bound on the switching latency to demonstrate its feasibility. The largest model explored in this work—1920×1920 p input resolution and 100% width multiplier—requires 28.4 MB of weight data. On the AMD Kria KV260 SoC used for the energy measurements, the DDR4 memory interface provides a peak bandwidth of 19.2 GB/s, yielding a maximum model loading time of approximately 1.55 ms. The smallest model (256×256 p, 1% width multiplier) requires only 0.39 MB and loads in approximately 0.02 ms. Both durations are negligible compared to the per-frame inference latency of Tiny YOLOv7 (typically tens of milliseconds on embedded platforms), confirming that altitude-driven model switching can operate well within real-time constraints. We plan to integrate such dynamic reconfiguration mechanisms in future hardware prototypes.

In addition to minimizing transition latency, we also aim to explore the impact of switching frequency—that is, how often the system dynamically adjusts its network parameters (e.g., model weights, width, or resolution) in response to altitude changes. Our current threshold-based switching scheme, although effective, relies on manually defined breakpoints and follows a rule-based design. This approach primarily serves as a proof of concept for altitude-aware model selection, demonstrating the feasibility and benefits of dynamic CNN switching in UAV object detection. Frequent reconfigurations, while potentially improving task-specific accuracy, may incur cumulative power and resource overheads, diminishing the benefits of adaptive inference. To address stability concerns during rapid altitude fluctuations (e.g., sensor noise or aggressive maneuvers), we will investigate hysteresis-based switching mechanisms and spatiotemporal smoothing strategies. In particular, contingency-aware optimization approaches30, which explicitly model uncertainty and enforce temporal consistency in decision-making, provide a principled framework for mitigating abrupt switching behavior and reducing output flickering. Such approaches are especially well-suited for UAV platforms, where rapid motion, sensor noise, and environmental disturbances can lead to highly non-stationary perception inputs, making temporally consistent decision-making critical for reliable operation. By incorporating such techniques, transient altitude variations can be filtered, leading to more stable perception outputs for downstream autonomous tasks. As part of future work, we will quantify the trade-off between switching frequency, power consumption, and detection performance to develop intelligent policies that balance reconfiguration costs with application demands.

Another challenge lies in the manual selection of optimal parameters, which is computationally intensive and scales poorly as the number of configurations grows. Future work will explore automated parameter selection strategies using optimization algorithms or lightweight policy networks that dynamically select the best model based on mission constraints and contextual cues. Additionally, integrating semantic and geometric features can further enhance robustness by filtering dynamic noise and improving detection stability in unstructured environments. For example, methods such as DPL-SLAM31 leverage dense point-line representations and semantic cues to improve robustness in dynamic scenes by distinguishing between static and moving elements. This capability is particularly relevant for UAV-based perception, where viewpoint changes, moving objects, and background clutter are more pronounced due to altitude variation and wide-area coverage. Incorporating similar semantic and geometric priors into our framework could help suppress dynamic noise and reduce detection inconsistencies under such conditions. This multi-modal approach would complement altitude-based adaptation, offering a more comprehensive framework for UAV perception in dynamic scenarios.

Furthermore, the limited diversity of our current dataset, in both altitude range and environmental variation, restricts generalizability. We plan to expand our dataset to include a broader range of conditions, including different weather scenarios, lighting conditions, terrain types, altitudes, and multiple classes of objects. This will help improve model robustness and provide a more rigorous benchmark for future research.

Addressing the challenges of dynamic adaptability, intelligent model selection, and dataset diversity is essential for advancing UAV-based object detection. Through the integration of algorithmic innovation, adaptive hardware, and richer datasets, our goal is to enable high-performance, context-aware perception systems suitable for real-world deployment.

Conclusions

This work introduced a context-aware dynamic CNN framework for UAV-based object detection, utilizing altitude as a real-time contextual input to guide model selection. By designing and training custom networks tailored for specific altitude ranges, we demonstrated the feasibility and benefits of dynamically selecting models based on mission context.

Our experiments revealed that input image resolution and network width significantly influence performance across different altitudes. Fixed, general-purpose models struggled to balance accuracy and efficiency, whereas dynamically selected, altitude-optimized models achieved notable improvements in detection accuracy and resource usage. Specifically, compared to a static mixed-altitude Tiny YOLOv7 model, the dynamic approach reduced power consumption, memory usage, and inference latency while maintaining competitive or better accuracy under several altitude ranges.

Even with a simple threshold-based model switching strategy, the dynamic configuration outperformed the fixed model across all case studies. This reinforces the practicality of using altitude as a primary contextual cue for on-the-fly model adaptation and lays the foundation for more advanced, intelligent selection strategies.

Looking forward, we aim to explore more sophisticated model switching strategies using reinforcement learning or lightweight context-aware controllers, as well as to incorporate additional environmental cues beyond altitude. Furthermore, expanding the dataset to include diverse scenes, altitudes, and weather conditions will improve robustness and generalization.

In summary, this study demonstrates the value of altitude-specific model adaptation for UAV object detection and establishes a foundation for developing flexible, efficient, and intelligent perception systems for future UAV applications.
