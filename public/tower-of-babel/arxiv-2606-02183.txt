Efficiently Listing Projected Trees, and Equivalence of Listing and Enumeration
Karl Bringmann, Nick Fischer, Yanheng Wang *

Abstract
The subgraph isomorphism problem and its generalizations such as conjunctive queries, where some nodes are projected, are among the most fundamental problems in graph algorithms and database theory. In this paper, we study the listing and enumeration variants of these problems and present two main results. (1) We present the first algorithms for enumerating projected trees with polynomial preprocessing time ( O ~ ​ ( n 17.42 ) \widetilde{O}(n^{17.42}) ) and polylogarithmic delay ( \polylog ​ ( n ) \polylog(n) ). Prior to this work, all algorithms in the literature required time Ω ⁡ ( n Ω ⁡ ( k ) + t ) \Omega(n^{\Omega(k)}+t) or t ⋅ n Ω ⁡ ( 1 ) t\cdot n^{\Omega(1)} to list all copies of a k k -node tree with projections, where t t is the number of solutions. Our result generalizes to arbitrary projected hypergraphs, achieving enumeration in preprocessing time O ~ ​ ( m 17.42 ⋅ subw ⁡ ( H ) ) \widetilde{O}(m^{17.42\cdot\operatorname{subw}(H)}) and polylogarithmic delay, where subw ⁡ ( H ) \operatorname{subw}(H) is the submodular width of the pattern hypergraph H H . We heavily rely on fast (rectangular and output-sensitive) matrix multiplication, which we complement by fine-grained lower bounds indicating that any algorithm beating time Ω ⁡ ( n Ω ⁡ ( k ) + t ) \Omega(n^{\Omega(k)}+t) must rely on fast matrix multiplication. (2) As our second main result, we present a generic enumeration-to-listing reduction, establishing that listing and enumeration are equivalent under natural assumptions. For (colored) subgraph isomorphism, our reduction transforms any listing algorithm running in time O ⁡ ( f ⁡ ( n , m ) + t ⋅ g ⁡ ( n , m ) ) O(f(n,m)+t\cdot g(n,m)) into an enumeration algorithm with preprocessing time O ⁡ ( ( f ⁡ ( n , m ) + g ⁡ ( n , m ) + m ) ​ log 2 ​ n ) O((f(n,m)+g(n,m)+m)\log^{2}n) and delay O ⁡ ( g ⁡ ( n , m ) ) O(g(n,m)) . We utilize this equivalence as a tool for proving our first main result, and we expect that our generic reduction will find many future applications.

1.1.1
Comparison with Prior Work

Let us discuss why our result is extremely surprising given the state of the art. For any tree on
k
nodes,
(H,I)
-Listing is trivially in time
O(n^{k})
and
O(m^{k-1})

and, slightly less trivially, by
m^{k-1}
.
Some prior work considered listing algorithms in time

or enumeration algorithms with delay
m^{\Omega(1)}
(e.g.
[
32

25
]

or output-linear listing time

In this setting, to the best of our knowledge no algorithm in the literature unconditionally beats the trivial time bounds. Specifically, consider the
projected-
(k-1)
-star

\text{pattern $(H,I)$ with }V(H)=\set{0,1,\dots,k-1},\;E(H)=\Set{\set{0,i}:i\in[k-1]},\;I=[k-1].

No algorithm for projected-
(k-1)
-Listing in the literature unconditionally runs in time
\widetilde{O}(n^{k-\eps}+t)
or
\widetilde{O}(m^{k-1-\eps}+t)
, for any
\eps>0

Appendix

A
we verify this claim for some algorithms for which it is particularly difficult to check. Generally, we will argue below that fast matrix multiplication is necessary to beat the trivial time bounds, so since most algorithms do not use fast matrix multiplication they cannot beat the trivial time bounds. Fast matrix multiplication is a frequent tool in algorithm theory (e.g.
[
11
,
23
]
), and has also been explored in the database community
[

25

(k-1)

-star-Listing in time

assuming

(where we used

). This is the first algorithm beating the trivial time bound—however, it is conditioned on
\omega=2
, which is conjectured by some researchers but far from proven. Using currently known matrix multiplication algorithms, the algorithm’s running time deteriorates to

Summarizing, no prior work unconditionally solves projected-

In contrast, our running time is a fixed polynomial in

Conditioned on
\omega=2
, we improve from the non-fixed-parameter-tractable time
\Omega(n^{\Omega(k)}+t)
to the fixed-parameter tractable time
\widetilde{O}(n^{3}+t)

Unconditionally, we improve from the trivial time bounds

\widetilde{O}(n^{17.42})
and polylogarithmic delay. For the colored setting, our running times are even polynomial in

We remark that the use of fast matrix multiplication normally improves the running time exponent by at most a factor 2/3. Indeed, if
\omega=2
then fast matrix multiplication improves over trivial matrix multiplication by a factor 2/3 in the exponent, so this factor is what we can hope to gain for applications of fast matrix multiplication. In this light, Hu’s

(or enumeration with polylogarithmic delay).

Finally, let us compare with the Colored
(H,I)

1.1.2
Discussion of Drawbacks

In comparison with the classic results that trees without projections can be listed in time
O(m+t)
and enumerated in preprocessing time
O(m)
and delay
O(1)
, our result has three drawbacks, most of which are necessary:

Superlinear Preprocessing Time

Unlike the linear preprocessing time
O(m)
for trees without projections, we need preprocessing time
\widetilde{O}(n^{17.42})\leq\widetilde{O}(m^{17.42})
, and conditioned on very fast matrix multiplication we still need preprocessing time
\widetilde{O}(n^{3})\leq\widetilde{O}(m^{3})
. This is a necessary relaxation, because our algorithm works for all projected trees
(H,I)
, in particular also for non-free-connex
(H,I)
, for which

preprocessing time and constant (or polylogarithmic) delay is impossible by the known fine-grained classification mentioned above
[
9
]

Polylogarithmic Delay

While constant delay is possible for trees without projections, we need polylogarithmic delay
\widetilde{O}(1)
. At the core, this comes from polylogarithmic factors in the running time of a fast rectangular matrix multiplication algorithm that we are using. We leave it open whether the delay can be improved to
O(1)
without significantly worsening the preprocessing time.

Fast Matrix Multiplication

Finally, our algorithms are impractical due to the use of fast (rectangular) matrix multiplication. However, we show that any algorithm that breaks the trivial time bounds
n^{k}
or
m^{k-1}

must
be impractical, as it
must
use fast matrix multiplication. Specifically, we consider combinatorial algorithms, which intuitively are algorithms that do not use fast matrix multiplication, and show that if projected-
(k-1)
-star-Listing has a fast combinatorial algorithm then so does

-Clique, contradicting the Combinatorial

-Clique Hypothesis. See
Section

11

Theorem 2.

Let

-Clique Hypothesis, no combinatorial algorithm solves (Colored or Uncolored) projected-
(k-1)
-star-Listing in time
\widetilde{O}(n^{k-\eps}+t)
or
\widetilde{O}(m^{k-1-\eps}+t)

This lower bound is similar to

and
[

1.2
Towards Further Improvements for Projected Trees

At this point one might ask: Can the preprocessing time
\widetilde{O}(n^{17.42})

Theorem 3.

-star-Listing in time

This is based on a standard fine-grained hypothesis, but does not match our upper bound (no matter how fast matrix multiplication can be solved). Next, we show a barrier that would match the

So far we have discussed running time in terms of

1.4
Equivalence of Listing and Enumeration

Listing and enumeration are widely studied in the database community and in the algorithm theory community.
So far they have been studied separately. Here we show that under natural assumptions listing and enumeration are
equivalent
.

Recall that reducing listing to enumeration is trivial: If we have an enumeration algorithm with preprocessing time
T_{P}
and delay
T_{D}
then we obtain a listing algorithm in time
O(T_{P}+(t+1)\cdot T_{D})
by running the enumeration algorithm until it has printed all
t
solutions and terminates.
Reducing enumeration to listing is the difficult direction. So far, all attempts at this direction were restricted to specific classes of listing algorithms (e.g.
[
54
]
and
[
16
, Section 3.3]
presented a conversion of so-called flashlight listing algorithms).
As our second main result, we present the first
enumeration-to-listing reduction
which makes no assumptions on the structure of the listing algorithm. It makes some natural assumptions on the listing problem, which are typically satisfied for colored problems. Applying our reduction to Colored
(H,I)
-Sub(hyper)graph yields the following result.

Theorem 8.

Let

be monotone functions such that

A Simple Algorithm for
d
-Stars

To illustrate the main ideas behind our algorithm, we first describe a particularly simple and clean algorithm for the special case of listing projected-

Observe that (the support of) the product

From Restricted Trees to Arbitrary Trees

From this point on, the remainder of our algorithm is a sequence of reductions, reducing more and more general problems to the algorithm for restricted trees from the previous paragraph.

From Listing to Enumeration

So far we discussed Colored
(H,I)
-Listing.
We can extend the algorithm to Colored

-Enumeration by applying our enumeration-to-listing reduction. This reduction roughly works as follows. Suppose there is a listing algorithm that solves an instance

and delay

Here we described a variant of our

8

From Colored to Uncolored Problems

So far we discussed the colored problems.
The classic color coding technique
[
8
]
converts algorithms from the colored setting to the uncolored setting. Specifically, it replaces a given uncolored problem instance by several uncolored problem instances, such that the union of the solution sets of the constructed uncolored instances is the solution set of the original uncolored instance. This readily reduces uncolored listing to colored listing: Run the colored listing algorithm on all colored problem instances constructed by color coding, then compute the union of the listed solutions, e.g., by sorting and deduplicating. For enumeration, by following the same recipe we obtain a “cheating” enumeration algorithm which may print the same solution multiple times. The Cheater’s Lemma
[
18
]
then converts such a cheating enumeration algorithm into a proper enumeration algorithm, see
Section

9
.

This finishes the outline of the proof of
Theorem

7
.

(i,2j-1)\in\supp(AB)
or
(i,2j)\in\supp(AB)
.

4.

S=\bigcup_{(i,j)\in\supp(A_{L^{\prime}}B^{\prime})}\Set{(i,2j-1),(i,2j)}
by the inductive assumption (ii). Hence
S\supseteq\supp(A_{L^{\prime}}B)
by (iii).

5.

2\kappa\geq\max_{i\in L^{\prime}}\Card{\set{j\in[z]:(i,j)\in S}}
. Indeed, each row
i\in L^{\prime}
in
AB^{\prime}
is light by the inductive assumption (i). In other words, it contains at most
\kappa
non-zeros. Each non-zero in row

contributes two elements in
\set{j\in[z]:(i,j)\in S}
, while each zero does not contribute any. So the set has cardinality at most
2\kappa
.

Observations (iv) and (v) verify the preconditions of
recover(
A_{L^{\prime}},B,S,2\kappa
)
, so it computes
C=A_{L^{\prime}}B
by
Lemma

11
. Hence, the returned matrix is

, which establishes (ii).
To establish (i), note that if row

is light in
AB
, then it is also light in
AB^{\prime}
by (iii), so
i\in L^{\prime}
by the induction assumption (i). Consequently, every light row of
AB
appears in
C
, so
L
(the set of light rows in
C=A_{L^{\prime}}B
) is exactly the set of light rows of
AB
. The induction is complete.

Let us bound the running time. As we descend in the recursion, the parameters
x,\kappa
stay the same, and we have
|AB^{\prime}|\leq|AB|
by (iii). Hence the parameter
s:=\set{|AB|,x\kappa}
does not increase. Besides, the parameter

halves on each level, so the depth of the recursion is
\log z=\widetilde{O}(1)
.

Now we focus on a fixed recursion level. In the case

, computing

by the trivial algorithm takes time
O(|A|)
because

is just a column vector. In the case
z\geq 2
, we can bound
|S|=2|C^{\prime}|\leq 2|AB^{\prime}|\leq 2|AB|
by definition, and
|S|\leq 2x\kappa
by (v). Hence
|S|\leq 2s
. Constructing the matrix

takes time
O(|B|)
. Computing
S
takes time
O(|S|)\leq O(s)
. Computing

takes time

\widetilde{O}\Bigg(|A|+|B|+s+\max_{\begin{subarray}{c}x^{\prime}\leq x,z^{\prime}\leq 8\kappa,\\
x^{\prime}z^{\prime}\leq 8s\end{subarray}}\mathrm{MM}(x^{\prime},y,z^{\prime})\Bigg)

by
Lemma

11
. Computing

. Summing all these terms over all

levels, the total running time is as claimed.

The “in particular” part of the lemma follows by plugging in the bound from Proposition
10
.

5
Listing Restricted Projected Trees

In this section, we present an algorithm that solves
(H,I)
-Listing for any rooted full binary tree
H
and
I
being its set of leaves.
A
rooted tree
is a tree with a designated root node. We think of the edges being directed away from the root, although in reality all graphs in this paper are undirected. Accordingly the
children
of a node are its neighbors that have larger distance to the root than the node itself. The
leaves
of a rooted tree are the nodes without children. Note that the leaves of a rooted tree are almost the same as the leaves of the corresponding unrooted tree, except that if the root has exactly one child then it becomes a leaf in the unrooted tree, while the root is no leaf of the rooted tree (unless the tree is a single node).
A
rooted binary tree
is a rooted tree where every node has at most two children.
A
rooted full binary tree
is a rooted tree where every node has either no child or exactly two children.

Our correctness proofs will use a simple fact about non-negative integer matrix products.

Lemma 13.

Let
A\in\N^{x\times y}
,
B\in N^{y\times z}
and
\kappa\geq 1
; we say that a row is light if it contains at most
\kappa
non-zeros. Let
L\subseteq[y]
be the set of light rows of
B
. Let
B^{\prime}
be the matrix
B
restricted to rows in
L
, and let
A^{\prime}
be the matrix
A
restricted to columns in
L
. Then the set of light rows of
AB
is exactly
\Lambda=\Set{i\in[x]:\text{$i$ is a light row of $A^{\prime}B^{\prime}$ and $A_{ik}=0$ for all $k\notin L$}}
. Moreover,
AB
and
A^{\prime}B^{\prime}
agree on rows
\Lambda
.

Proof.

We make the following claim: If
A_{ik}=0
for all
k\notin L
, then
(AB)_{ij}=(A^{\prime}B^{\prime})_{ij}
for all
j\in[z]
.
Indeed, we have

(A^{\prime}B^{\prime})_{ij}=\sum_{k\in L}A^{\prime}_{ik}B^{\prime}_{kj}=\sum_{k\in L}A_{ik}B_{kj}=\sum_{k\in[y]}A_{ik}B_{kj}

where the last step used that
A_{ik}=0
for all
k\notin L
.
This shows that
AB
and
A^{\prime}B^{\prime}
agree on
\Lambda
. It remains to prove that the set of light rows in
AB
is exactly
\Lambda
.

For one direction, consider any
i\in\Lambda
. Since
A_{ik}=0
for all
k\notin L
, the claim implies that row
i
has the same number of non-zeros in
AB
and
A^{\prime}B^{\prime}
. Since
i
is a light row in
A^{\prime}B^{\prime}
, it is also a light row in
AB
.

For the other direction, consider any light row
i
of
AB
. First, suppose that there exists
k\notin L
with
A_{ik}>0
. Then for all
j\in[y]
we have
(AB)_{ij}\geq A_{ik}B_{kj}\geq B_{kj}
since the matrix is integral. Hence the number of non-zeros of row
i
in
AB
is at least the number of non-zeros of row
k
in
B
. Since
k\notin L
, row
k
in
B
has more than
\kappa
non-zeros. Hence,
i
is not a light row of
AB
, a contradiction.

Therefore, we can now assume that
A_{ik}=0
for all
k\notin L
. Then the claim implies that row
i
has the same number of non-zeros in
AB
and
A^{\prime}B^{\prime}
. Since
i
is light in
AB
, it is also light in
A^{\prime}B^{\prime}
.
∎

Before we can present our algorithm, we discuss two subroutines.

Lemma 14.

There is an algorithm

•

Case 1:

For the correctness analysis, we extend the matrix

On the other hand,

to

Case 2:

Now we are ready to solve the main problem

|S|=|R_{a}|\cdot|R_{b}|\leq\kappa
.

For each
\mathbf{v}\in R_{a}
, computing
X_{\mathbf{v}}
takes time
O(m)\leq O(n^{2})
by
Lemma

15
. Similarly, for each
\mathbf{w}\in R_{b}
, computing
Y_{\mathbf{w}}
takes time
O(n^{2})
. Hence, computing all these sets takes time
O(n^{2}\sqrt{\kappa})
in total. The subroutine
light
takes time
\Otilde\left(n^{2-{\widetilde{\alpha}}}\kappa+n^{2}\kappa^{1-{\widetilde{\alpha}}}\right)
by
Lemma

14
. The matrix
A
has
|S|\leq\kappa
rows and
n
columns, so it can be built in
O(\kappa n)
time. The matrix
B
has
n
rows, and each row contains at most
\kappa
non-zeros by the definition of
L
, so it can built in
O(n\kappa)
time as well. The subroutine
multiply
takes time
\Otilde(n\kappa+t+nt^{1-{\widetilde{\alpha}}}\kappa^{{\widetilde{\alpha}}})
by
Lemma

12
since
|AB|\leq t
and
A
has at most
\kappa
rows. The time to compute
L_{i}
and to print solutions is
O(t)
.

Gathering all terms and recalling
\kappa=\Theta(t^{2/3})
and
0<{\widetilde{\alpha}}\leq 1
, the running time is

\displaystyle\Otilde\left(n^{2}\kappa^{1/2}+n^{2-{\widetilde{\alpha}}}\kappa+n^{2}\kappa^{1-{\widetilde{\alpha}}}+nt^{1-{\widetilde{\alpha}}}\kappa^{\widetilde{\alpha}}+t\right)

\displaystyle=\Otilde\left(n^{2}t^{1/3}+n^{2-{\widetilde{\alpha}}}t^{2/3}+n^{2}t^{2(1-{\widetilde{\alpha}})/3}+nt^{1-{\widetilde{\alpha}}/3}+t\right).

We bound each term by the weighted AM-GM inequality:

\displaystyle n^{2}t^{1/3}

\displaystyle\leq\frac{2}{3}n^{3}+\frac{1}{3}t,

\displaystyle n^{2-{\widetilde{\alpha}}}t^{2/3}

\displaystyle\leq\frac{1}{3}n^{3(2-{\widetilde{\alpha}})}+\frac{2}{3}t,

\displaystyle n^{2}t^{2(1-{\widetilde{\alpha}})/3}

\displaystyle\leq\frac{1+2{\widetilde{\alpha}}}{3}n^{6/(1+2{\widetilde{\alpha}})}+\frac{2(1-{\widetilde{\alpha}})}{3}t,

\displaystyle nt^{1-{\widetilde{\alpha}}/3}

\displaystyle\leq\frac{{\widetilde{\alpha}}}{3}n^{3/{\widetilde{\alpha}}}+\left(1-\frac{{\widetilde{\alpha}}}{3}\right)t.

It is easy to verify that
\frac{3}{x}\geq\max\Set{3,3(2-x),\frac{6}{1+2x}}
for all
0<x\leq 1
. Hence the running time is bounded by
\Otilde(t+n^{3/{\widetilde{\alpha}}})
as claimed.
It can be checked that the dependence on
k
hidden by
\Otilde
-notation is polynomial.
∎

6
From Restricted Trees to General Trees

The previous section forms the core of our algorithm, showing that if
H
is a rooted full binary tree and
I
is its set of leaves then
(H,I)
-Listing is in time
\widetilde{O}(t+n^{3/{\widetilde{\alpha}}})
. In this and the next sections we generalize it further and further by a sequence of reductions. By the end of this section, we will be able to handle general projected trees, i.e.,
H
is any tree and
I
is any subset of its nodes. Parts of this reduction are similar to arguments by Hu
[
32
]
.

As our first step, we generalize from rooted full binary trees to general trees
H
while insisting that
I
is still the subset of leaves. In the reduction, we replace nodes with more than two children by a path of nodes each of which has two children (for each new edge in
H
, we introduce a perfect matching in the host graph), and we attach a new dummy child to each node with one child (corresponding to a fully connected singleton vertex in the host graph).

Lemma 17.

Assume that for every rooted full binary tree
H
and
I
being its set of leaves we can solve
(H,I)
-Listing in time
\Otilde(t+f(n,m))
. Then for every tree
H
and
I
being its set of leaves we can solve
(H,I)
-Listing in time
\Otilde(t+f(n,m)+n+m)
.

Proof.

Let
H=([k],\mathcal{E})
be a tree and
G=(\bigcup_{i\in[k]}V_{i},E)
be a host graph.

If
k=1
then
H
is a single node, so the problem is about listing the vertices of
G
, which can be done in time
O(n)
. If
k=2
then
H
is a single edge, so the problem is about listing the edges of
G
, which can be done in time
O(m)
.

From now on we assume
k\geq 3
. Then there exists a node
\rho\in[k]
that is not a leaf of
H
. We pick
\rho
as the root. Note that
\rho
has at least two children, so the rooted and unrooted version of
H
have the same set of leaves
I
.

In what follows, we turn the rooted tree
H
with leaves
I
step by step into a rooted full binary tree
H^{\prime}
with leaves
I^{\prime}
. We also turn the host graph
G
accordingly to
G^{\prime}
. We will ensure that (i)
(H,I)
-Subgraphs of
G
are in one-to-one correspondence with
(H^{\prime},I^{\prime})
-Subgraphs of
G^{\prime}
; (ii)
H^{\prime}
consists of
|H^{\prime}|\leq 2|H|
nodes; and (iii)
G^{\prime}
can be computed from
G
in time
O(m)
.

Write
c(i)
for the number of children of node
i\in[k]
. We consider two cases.

Case 1:

There is a node
i
with
c(i)=1
. Say the child of
i
is
j
. We construct the new pattern
H^{\prime}
by modifying
H
as follows: We add a new node
i^{\prime}
and attach it as a child to
i
. Thus, the set of leaves becomes
I^{\prime}=I\cup\{i^{\prime}\}
. We construct the new host graph
G^{\prime}
by modifying
G
as follows: Create a new part
V_{i^{\prime}}=\{0\}
containing a single vertex
0
; and put an edge between
0
and every
v_{i}\in V_{i}
.
Observe that for every
(H,I)
-Subgraph
\mathbf{v}
of
G
,
(v_{i^{\prime}},\mathbf{v})
for
v_{i^{\prime}}:=0\in V_{i^{\prime}}
is an
(H^{\prime},I^{\prime})
-Subgraph of
G^{\prime}
, and vice versa. In particular,
(H,I)
-Subgraphs of
G
are in one-to-one correspondence with
(H^{\prime},I^{\prime})
-Subgraphs of
G^{\prime}
.

Case 2:

There is a node
i
with
c(i)\geq 3
. Say the children of
i
are
j_{1},\dots,j_{c(i)}
. We construct the new pattern
H^{\prime}
by modifying
H
as follows: Create a new node
i^{\prime}
, designate it as the parent of
j_{1}
and
j_{2}
, and designate
i
as the parent of
i^{\prime},j_{3},\ldots,j_{c(i)}
. This does not change the set of leaves,
I^{\prime}=I
. We construct the new host graph
G^{\prime}
by modifying
G
as follows: Create a new part
V_{i^{\prime}}
as a copy of
V_{i}
; for each
j\in\set{j_{1},j_{2}}
rewire the edges between
V_{i},V_{j}
so that they lie between
V_{i^{\prime}},V_{j}
instead; and connect every pair of corresponding vertices in
V_{i},V_{i^{\prime}}
by an edge (note that this adds
O(n)
edges). Observe that
(H,I)
-Subgraphs of
G
are in one-to-one correspondence with
(H^{\prime},I^{\prime})
-Subgraphs of
G^{\prime}
.

In both cases, the modification reduces
|c(i)-2|
by one, does not change
c(x)
for any other node
x
, and adds a new node
i^{\prime}
with
c(i^{\prime})\in\{0,2\}
children. By repeatedly applying this modification, we eventually obtain a rooted full binary tree. The number of repetitions is exactly
\sum_{i\in[k]:c(i)\geq 1}|c(i)-2|\leq\sum_{i\in[k]}c(i)=k-1
. In each repetition, we add one node to the pattern and one part to the host graph, spending time
O(m)
. The bounds on pattern size and running time thus follow.
∎

As our next step, we generalize from
I
being exactly the set of leaves of
H
to an arbitrary subset of leaves. This reduction removes leaves that are not part of
I
. It is a rephrasing of the
cleanse
procedure of
[
32
]
.

Lemma 18.

Assume that for every tree
H
and
I
being its set of leaves we can solve
(H,I)
-Listing in time
\Otilde(t+f(n,m))
. Then for every tree
H
and every subset of its leaves
I
we can solve
(H,I)
-Listing in time
\Otilde(t+f(n,m)+n+m)
.

Proof.

We use induction on
k=|H|
. For
k=1
,
(H,I)
-Listing is trivially in time
O(n)
. For
k\geq 2
, if
I
is exactly the set of leaves of
H
, then the claim follows from the assumption. Otherwise, there exists a leaf
i\notin I
. Let
j
be the unique neighbor of
i
. We remove all vertices
v_{j}\in V_{j}
that do not have a neighbor in
V_{i}
, and then solve
(H-i,I)
-Listing on
G^{\prime}:=G[V_{l}:l\neq i]
. Note that every
(H-i)
-copy in
G^{\prime}
extends to an
H
-copy in
G
. Hence, every solution to the new instance is a solution to the old instance, and vice versa. The running time is clearly
\widetilde{O}(t+f(n,m)+n+m)
.
∎

Finally, we generalize to
I
being any subset of the nodes of
H
. To this end, for any non-leaf
i\in I
we observe that the problem splits at
i
into subproblems on the connected components of
H-i
. This lemma is a rephrasing of the
decompose
procedure of
[
32
]
.

Lemma 19.

Assume that for every tree
H
and every subset of its leaves
I
we can solve
(H,I)
-Listing in time
\Otilde(t+f(n,m))
. Then for every tree
H
and every subset of its nodes
I
we can solve
(H,I)
-Listing in time
\Otilde(t+f(n,m)+n+m)
.

Proof.

We use induction on
k=|H|
. If
I
is a subset of the leaves, then the claim follows from the assumption. Otherwise, there exists an non-leaf
i\in I
. The node
i
separates the tree into
r\geq 2
connected components, whose node sets we denote by
C_{1},\dots,C_{r}
. To solve
(H,I)
-Listing, we do the following:

1.

Apply
Lemma

9
to remove all vertices in
G
that do not extend to any solution.

2.

For each
a\in[r]
, let
C_{a}^{+}:=C_{a}\cup\set{i}
and notice that
|C_{a}^{+}|\leq k-1
, so we can apply induction to solve
(H[C_{a}^{+}],I\cap C_{a}^{+})
-Listing in
G[V_{j}:j\in C_{a}^{+}]
and obtain a set of solutions
\mathcal{S}_{a}
. We partition
\mathcal{S}_{a}=\bigcup_{v_{i}\in V_{i}}\mathcal{S}_{a}[v_{i}]
where
\mathcal{S}_{a}[v_{i}]
collects all solutions in
\mathcal{S}_{a}
that use the vertex
v_{i}
. Importantly, none of
\mathcal{S}_{a}[v_{i}]
is empty, as otherwise we would have removed
v_{i}
in the first step.

3.

Compute the solutions to
(H,I)
-Listing in
G
by
\mathcal{S}=\bigcup_{v_{i}\in V_{i}}\prod_{a\in[r]}\mathcal{S}_{a}[v_{i}]
.

The correctness of the algorithm is clear. Let us analyze the time complexity. Step 1 takes time
\tau_{1}=O(n+m)
by
Lemma

9
. In step 2, each iteration
a
takes time
\tau_{2,a}=\Otilde(|\mathcal{S}_{a}|+f(n,m)+n+m)
by induction. Step 3 takes time
O(\tau_{3})
for
\tau_{3}=\sum_{v_{i}\in V_{i}}\prod_{a\in[r]}|\mathcal{S}_{a}[v_{i}]|
. Note that for any fixed
a\in[r]
we have

\tau_{3}\geq\sum_{v_{i}\in V_{i}}|\mathcal{S}_{a}[v_{i}]|=|\mathcal{S}_{a}|,

where the inequality uses that
\mathcal{S}_{b}[v_{i}]\neq\emptyset
for all
b
.
Hence,
\sum_{a\in[r]}|\mathcal{S}_{a}|\leq r\cdot\tau_{3}=O(\tau_{3})
, since
r\leq k
is constant.
Thus,
\tau_{2}:=\sum_{a\in[r]}\tau_{2,a}\leq\Otilde(\tau_{3}+f(n,m)+n+m)
. Finally, observe that the terms in
\tau_{3}
correspond to distinct solutions in
\mathcal{S}
, thus
\tau_{3}\leq t
. Putting everything together, the total running time is bounded by
\tau_{1}+\tau_{2}+\tau_{3}=\Otilde(t+f(n,m)+n+m)
.
∎

By chaining the above three lemmas with the algorithm for restricted trees from the previous section, we are able to handle general projected trees:

Theorem 20 (
Theorem

1
on Colored Listing).

For every tree
H
and every
I
, Colored
(H,I)
-Listing can be solved in time
\Otilde(t+n^{3/{\widetilde{\alpha}}})
.
The dependence on
k
hidden by
\widetilde{O}
-notation is
\poly(k)
.

Proof.

Combine
Theorem

16
with
Lemma

17
,
Lemma

18
, and
Lemma

19
. It can be checked that these lemmas only incur a
\poly(k)
blowup in the factor hidden by
\widetilde{O}
-notation.
∎

7
From Trees to Hypergraphs

We generalize our algorithm further, from trees to arbitrary hypergraphs.

First, we generalize from trees to acyclic hypergraphs without isolated nodes. A hypergraph
H
is
\EMPH
acyclic if there exists a tree
T
with
V(T)=E(H)
such that for every
i\in V(H)
, the hyperedges
J\in E(H)
with
i\in J
form a connected subtree of
T
. A hypergraph does not have isolated nodes if every node is contained in some hyperedge.

Lemma 21.

Assume that for every tree
H
and every
I
we can solve
(H,I)
-Listing in time
\Otilde(t+f(n,m))
. Then for every acyclic hypergraph
H
without isolated node and every
I
, we can solve
(H,I)
-Listing in time
\Otilde(t+f(m,m^{2})+m^{2})
.

Proof.

Let
H
be an acyclic hypergraph without isolated nodes, and
G
a host hypergraph. We will construct a tree
H^{\prime}
and a graph
G^{\prime}
such that
H
-copies in
G
are in one-to-one correspondence with
H^{\prime}
-copies in
G^{\prime}
. Moreover,
G^{\prime}
has
O(m)
vertices and can be computed from
G
in time
O(m^{2})
.

Write
H=([k],\mathcal{E})
and
G=\left(\bigcup_{i\in[k]}V_{i},E\right)
.
Let
T
be a tree that witnesses the acyclicity of
H
, in particular
V(T)=\mathcal{E}
. We choose
H^{\prime}:=T
.
We construct a graph
G^{\prime}=(V^{\prime},E^{\prime})
where
V^{\prime}:=\bigcup_{I\in\mathcal{E}}E^{I}
with
E^{I}:=E\cap\prod_{i\in I}V_{i}
. The edge set
E^{\prime}
is defined as follows. For every tree edge
\set{I,J}\in E(T)
, we put an edge between
(u_{i})_{i\in I}\in E^{I}
and
(v_{i})_{i\in J}\in E^{J}
if and only if
u_{i}=v_{i}
for all
i\in I\cap J
. Clearly the graph has
O(m)
vertices and can be constructed in time
O(m^{2})
.

We show a bijection between
H
-copies in
G
and
H^{\prime}
-copies in
G^{\prime}
. Specifically, we map each
H
-copy
(v_{1},\dots,v_{k})
to the tuple
((v_{i})_{i\in I})_{I\in\mathcal{E}}
. The mapping is injective because there are no isolated nodes. Also note that the tuple is an
H^{\prime}
-copy in
G^{\prime}
. Indeed,
(v_{i})_{i\in I}\in E^{I}
for all
I\in\mathcal{E}
because
(v_{1},\dots,v_{k})
is an
H
-copy; moreover,
(v_{i})_{i\in I}
and
(v_{j})_{j\in J}
are adjacent for all
\set{I,J}\in E(T)
by definition of
E^{\prime}
.

It remains to argue that the mapping is surjective. To this end, consider an arbitrary
H^{\prime}
-copy
((v^{I}_{i})_{i\in I})_{I\in\mathcal{E}}
. By definition,
v^{I}_{i}=v^{J}_{i}
for all
\set{I,J}\in E(T)
and all
i\in I\cap J
. Now fix any
i\in[k]
and recall the property of the tree
T
: the hyperedges
I\in\mathcal{E}
with
i\in I
are connected by
E(T)
. These together imply the consistency of the assignments. That is, there exists some
v_{i}
such that
v^{I}_{i}=v_{i}
for all
I\in\mathcal{E}
containing
i
. In particular,
v_{i}\in V_{i}
. Therefore, the
H^{\prime}
-copy in consideration has the form
((v_{i})_{i\in I})_{I\in\mathcal{E}}
. Then
(v_{1},\dots,v_{k})
is an
H
-copy in
G
since
(v_{i})_{i\in I}=(v^{I}_{i})_{i\in I}\in E^{I}\subseteq E
for all
I\in\mathcal{E}
. Therefore, every
H^{\prime}
-copy is an image of an
H
-copy. This shows that the mapping is surjective and finishes the proof.
∎

Note that the reduction above changes the running time bound, as we replace
n
by
m
. Next, we get rid of isolated nodes via a straightforward reduction:

Lemma 22.

Assume that for every acyclic hypergraph
H
without isolated node and every
I
, we can solve
(H,I)
-Listing in time
\Otilde(t+f(m))
. Then for every acyclic hypergraph
H
and every
I
we can solve
(H,I)
-Listing in time
\Otilde(t+f(m))
.

Proof.

Let
H=([k],\mathcal{E})
be an acyclic hypergraph,
I\subseteq[k]
, and
G=\left(\bigcup_{i\in[k]}V_{i},E\right)
a host graph. Without loss of generality, we assume that the isolated nodes in
H
are
1,\dots,i
. Let
H^{\prime}:=H[\set{i+1,\dots,k}]
,
I^{\prime}:=I\cap\set{i+1,\dots,k}
and
G^{\prime}=G\left[\bigcup_{i<j\leq k}V_{j}\right]
. Clearly
H^{\prime}
does not have isolated nodes. Let
\mathcal{S},\mathcal{S}^{\prime}
be the sets of solutions to
(H,I)
-Listing in
G
and
(H^{\prime},I^{\prime})
-Listing in
G^{\prime}
, respectively. Observe that
\mathcal{S}=\mathcal{S}^{\prime}\times\prod_{j\in I\cap\set{1,\dots,i}}V_{j}
and thus
t=|\mathcal{S}|\geq|\mathcal{S}^{\prime}|
. Hence we can list all solutions in
\mathcal{S}
by constructing
H^{\prime},I^{\prime},G^{\prime}
in time
O(m)
, computing
\mathcal{S}^{\prime}
in time
\Otilde(|\mathcal{S}^{\prime}|+f(m))\leq\Otilde(t+f(m))
, and then printing
(\mathbf{u},\mathbf{v})
for every
\mathbf{u}\in\mathcal{S}^{\prime}
and
\mathbf{v}\in\prod_{j\in I\cap\set{1,\dots,i}}V_{j}
in time
O(t)
.
∎

For the generalization from acyclic hypergraphs to general hypergraphs we rely on the seminal PANDA algorithm
[
41
,
42
]
, see also
[
43
,
39
]
. We use the following phrasing of the PANDA algorithm as a reduction, cf.
[
32
, Section 5]
. Here,
\operatorname{subw}(H)
is the submodular width, see
Appendix

A
for a definition.

Theorem 23 (Rephrasing
[
41
,
42
]
).

For every pattern hypergraph
H
, there exist acyclic hypergraphs
H_{1},\ldots,H_{r}
where
r=r(|V(H)|
is a constant,
V(H_{i})=V(H)
for each
i\in[r]
, with the following property. Given a host hypergraph
G
, in time
\widetilde{O}(m^{\operatorname{subw}(H)})
we can compute host hypergraphs
G_{1},\ldots,G_{r}
such that
\mathcal{S}=\bigcup_{i\in[r]}\mathcal{S}_{i}
, where
\mathcal{S}
is the set of colored
H
-copies in
G
and
\mathcal{S}_{i}
is the set of colored
H_{i}
-copies in
G_{i}
.

Lemma 24.

Assume that for every acyclic hypergraph
H
and every
I
we can solve
(H,I)
-Listing in time
\Otilde(t+f(m))
. Then for every hypergraph
H
and every
I
we can solve
(H,I)
-Listing in time
\Otilde(t+f(\widetilde{O}(m^{\operatorname{subw}(H)})))
.

Proof.

Given a host hypergraph
G
for
H
, we construct the patterns
H_{1},\ldots,H_{r}
and hosts
G_{1},\ldots,G_{r}
from
Theorem

23
.
For a tuple
\mathbf{v}=(v_{i})_{i\in[k]}
we denote its projection to
I
by
\mathbf{v}|_{I}:=(v_{i})_{i\in I}
; for a set of tuples
\mathcal{S}
we denote its projection to
I
by
\mathcal{S}|_{I}:=\set{\mathbf{v}|_{I}\;:\;\mathbf{v}\in\mathcal{S}}
.
Note that the goal of
(H,I)
-Listing is to compute the projection
\mathcal{S}|_{I}
, where
\mathcal{S}
is the set of
H
-copies in
G
. By
Theorem

23
, we can compute this set as
\mathcal{S}|_{I}=\bigcup_{i\in[r]}\mathcal{S}_{i}|_{I}
, where
\mathcal{S}_{i}
is the set of
H_{i}
-copies in
G_{i}
.
That is, we solve
(H_{i},I)
-Listing on each
G_{i}
and return the union of all listed solutions; this solves
(H,I)
-Listing on
G
.
Since
G_{1},\ldots,G_{r}
can be computed in time
\widetilde{O}(m^{\operatorname{subw}(H)})
, their number of edges is bounded by the same term. The running time bound thus follows.
∎

Chaining the above two lemmas extends the algorithm for general trees from the previous section to arbitrary hypergraphs.

Theorem 25 (
Theorem

7
on Colored Listing).

For every hypergraph
H
and every
I
, Colored
(H,I)
-Listing can be solved in time
\Otilde(t+m^{\operatorname{subw}(H)\cdot 3/{\widetilde{\alpha}}})
.

Proof.

Combine
Theorem

20
with
Lemma

21
,
Lemma

, and
Lemma

24
. The running time changes from
\widetilde{O}(t+n^{3/{\widetilde{\alpha}}})
via
\widetilde{O}(t+m^{3/{\widetilde{\alpha}}})
to
\widetilde{O}(t+m^{\operatorname{subw}(H)\cdot 3/{\widetilde{\alpha}}})
.
∎

8
From Listing to Enumeration

For search and decision problems that are classically studied in complexity theory, a simple, yet fundamental result is a search-to-decision reduction, which we will review in
Section

8.2
. For listing and enumeration problems, we prove an analogous result, namely an enumeration-to-listing reduction. It works in almost the same general setting as the classic search-to-decision reduction, except that the running time bounds also need to be constructible.

8.1
Technical Setup

Throughout
Section

8
, we consider a generic setup of a computational problem where any instance
I
is associated to a search space
U=\set{0,1}^{d}
and a set of solutions
S\subseteq U
. We denote by
t=t(I):=|S|
the number of solutions and we call
d=d(I)
the depth.

The following definition formalizes that we can split a given instance
I
by fixing the first bit of the search space to
0
or
1
, generating corresponding subinstances
I_{0}
and
I_{1}
.

Definition 26.

A
\EMPH
splitting algorithm is an algorithm that given an instance
I
of depth
d>0
computes instances
I_{0}
and
I_{1}
of depth
d-1
such that for every
b,x_{1},\dots,x_{d-1}\in\set{0,1}
the tuple
(x_{1},\dots,x_{d-1})
is a solution to
I_{b}
if and only if
(b,x_{1},\dots,x_{d-1})
is a solution to
I
.

For a splitting algorithm
split
, a function
f
that maps instances to nonnegative integers is
\EMPH
split
-monotone if
f(I_{0})\leq f(I)
and
f(I_{1})\leq f(I)
for every instance
I
and
(I_{0},I_{1})=\text{{{split(}}{\emph{$I$}}{{)}}}
.

We call

an
\EMPH
s
-splitting algorithm, for a function
s

is a splitting algorithm, its running time on instance

is bounded by

, and

split
-monotone.

8.2
Classic Search-to-Decision Reduction

Let us start by reviewing the classic search-to-decision reduction. A
decision algorithm
decides whether the given instance
I
has a solution, i.e., it returns true if
t>0
and false otherwise. A
search algorithm
returns an arbitrary solution if there exists one, and
\bot
otherwise. Clearly, a search algorithm running in time
f(I)
yields a decision algorithm running in time
O(f(I))
. Conversely, it is folklore that a decision algorithm running in time
f(I)
yields a search algorithm running in time
O((f(I)+s(I))\cdot d)
:

Theorem 27 (Search-to-Decision Reduction).

Let
split
be an
s
-splitting algorithm and
f
be a
split
-monotone function.
If there is a decision algorithm running in time
O(f(I))
, then there is a search algorithm running in time
O\left((f(I)+s(I))\cdot d\right)
.

Proof.

For a given instance
I
of depth
d
, we first run the decision algorithm to check if
I
has a solution; if not then we return
\bot
. Otherwise
I
has at least one solution, and we describe a recursive function that returns a solution:

\Function
search(
I
)

//
finds a solution to
I
, assuming one exists

if

d(I)=0

then

return
the empty string;

construct subinstances
(I_{0},I_{1}):=\text{{{split(}}{\emph{$I$}}{{)}}}
;

use the decision algorithm to decide whether
I_{0}
has a solution;

if

I_{0}
has a solution

then

return

search(
I_{0}
)
prepended by
0
;

else

return

search(
I_{1}
)
prepended by
1
;

Correctness is immediate. We show by induction on the depth
d=d(I)
that the algorithm runs in time
O((f(I)+s(I))\cdot d)
. For
d=0
the claim is trivial. For
d\geq 1
, the subinstances are constructed in time
O(s(I))
, and the decision algorithm runs in time
O(f(I))
. The recursive call takes time
O\left(\max_{b\in\set{0,1}}(f(I_{b})+s(I_{b}))\cdot(d-1)\right)
by induction. Since both
f
and
s
are
split
-monotone, we have
f(I_{b})\leq f(I)
and
s(I_{b})\leq s(I)
, so the time is
O\left((f(I)+s(I))\cdot(d-1)\right)
. Summing up all terms, the algorithm runs in time
O\left((f(I)+s(I))\cdot d\right)
as claimed.
∎

The proof demonstrates that the notion of splitting algorithm is indeed natural, as it allows the search procedure to fix a bit in the search space. Note that the requirements that
f
and
s
are
split
-monotone are necessary to avoid blowing up the running time of the decision algorithm and the splitting algorithm in the recursion.

8.3
Our Result: Enumeration-to-Listing Reduction

Analogously to the search-to-decision reduction, we prove an enumeration-to-listing reduction. We start by introducing different meanings of listing and enumeration.

We work with the same technical setup defined in
Section

8.1
.
A
\EMPH
listing algorithm is given an instance
I
and computes the set of solutions
S
. A
\EMPH
strong listing algorithm is given an instance
I
and a number
t^{\prime}
and computes
\min\set{t,t^{\prime}}
solutions to
I
. For listing algorithms and strong listing algorithms we are interested in bounding the total running time.

An
\EMPH
enumeration algorithm has the same correctness guarantee as a listing algorithm, but instead of studying the total running time, we focus on bounding the
\EMPH
preprocessing time (the time until the first solution is printed) and the
\EMPH
delay (the maximum time between two consecutive solutions are printed). The time after printing the last solution can also be assumed to be bounded by the delay.

It is clear that any enumeration algorithm with preprocessing time
f(I)
and delay
g(I)
yields a strong listing algorithm running in time
O(f(I)+\min\set{t^{\prime},t+1}\cdot g(I))\leq O(f(I)+g(I)+\min\set{t^{\prime},t}\cdot g(I))
, by simply running the enumeration algorithm until it has printed
t^{\prime}
solutions (or until it has printed all
t
solutions and terminates). Moreover, a strong listing algorithm running in time
O(f(I)+\min\set{t,t^{\prime}}\cdot g(I))
yields a listing algorithm running in time
O(f(I)+t\cdot g(I))
, by simply setting
t^{\prime}:=2^{d}
. Our result is a converse to these simple reductions.

Definition 28.

A pair of functions
(f,g)
, each mapping instances to nonnegative integers, is
\EMPH
constructible if
f(I)
and
g(I)
can be computed in time
O(f(I)+g(I)+1)
, for a given instance
I
.

Theorem 29 (Enumeration-to-Listing Reduction).

Let
split
be an
s
-splitting algorithm,
f,g
be constructible,
split
-monotone functions, and
\beta\in[0,1]
be a constant.
If there is a listing algorithm running in time
O(f(I)+t\cdot g(I))
, then there is an enumeration algorithm with preprocessing time
O((f(I)+g(I)+s(I))\cdot d^{2-\beta})
and delay
O(g(I)\cdot d^{\beta})
.

We stress that
Theorem

29
assumes that the given listing algorithm is deterministic, and the resulting enumeration algorithm is also deterministic.

The choice of
\beta\in[0,1]
describes a tradeoff. At one extreme
\beta=1
, we obtain preprocessing time
O((f(I)+g(I)+s(I))\cdot d)
and delay
O(g(I)\cdot d)
; at the other extreme
\beta=0
, we obtain preprocessing time
O((f(I)+g(I)+s(I))\cdot d^{2})
and delay
O(g(I))
.

Let us discuss the requirements of
Theorem

29
. First, it assumes splittability (specifically, that there is an
s
-splitting algorithm
split
and
f,g
are
split
-monotone). This is a well-motivated requirement, because it is also used in the classic search-to-decision reduction (
Theorem

27
), and because Colored
(H,I)
-Subhypergraph has this property as we will verify soon.
In addition to splittability,
Theorem

29
requires the time bounds
f,g
to be constructible, which is used in our reduction to set certain parameters. This requirement is also satisfied for typical listing algorithms, as most time bounds are expressed in terms of the input size
n
, and it is typically assumed that
n
can be read from the input instance in constant time, so if
f
and
g
are simple enough then
f(I)
and
g(I)
can even be computed in constant time.

8.5
Open Directions

We leave the following open questions on the enumeration-to-listing reduction.

Improvements

Can the overhead factors be further improved? Specifically, is it possible to improve the overheads in preprocessing time and delay from the current tradeoff
(O(d^{2-\beta}),O(d^{\beta}))
to, e.g.,
(O(d^{1.99}),O(1))
or
(O(d),O(d^{0.99}))
or even
(O(d),O(1))
?

It is natural to expect that the overhead in preprocessing time must be at least
d
, at least in the general setting considered here, as this is the overhead of the classic search-to-decision reduction. Can one prove this?

Non-constructible time bounds

Is there a similar reduction without the assumption that the time bounds are constructible? Note that, e.g., treewidth is a subgraph-monotone parameter, but it cannot be computed efficiently, so time bounds involving treewidth are not constructible, which shows a limitation of the current reduction.

Uncolored problems

While we demonstrated our reduction for Colored
(H,I)
-Listing, it is not directly applicable to Uncolored
(H,I)
-Listing, since the uncolored problem does not have a self-reduction and is not splittable in the sense of
Definition

26
. Could there be a variant of
Theorem

29
that would work for uncolored problems?

More applications

Does our reduction have applications beyond subgraph listing and conjunctive queries, such as enumerating spanning trees, matchings, etc.? Or is there some variant of the reduction that would admit more applications?

Randomized algorithms

Theorem

29
assumes that the given listing algorithm is deterministic, and yields a deterministic enumeration algorithm. In some settings of randomized algorithms it might be possible to avoid the factor
d
overhead altogether.

8.6
Proof Preparations

We will make use of the Cheater’s Lemma from
[
18
]
, which formalizes ways in which an enumeration algorithm may cheat so that it can still be converted into a proper enumeration algorithm. The original statement of this lemma uses very specific running time bounds, therefore here we rework it to allow more general time bounds. (Later in this paper we will need yet another variant, which we call variant II.)

Lemma 33 (Cheater’s Lemma, Variant I).

Let
f,g
be constructible functions with
f(I)\geq g(I)
for all
I
. Suppose there is a listing algorithm that for any
1\leq j\leq t
prints the
j
-th solution in time at most
f(I)+j\cdot g(I)
. Then there exists an enumeration algorithm with preprocessing time
O(f(I))
and delay
O(g(I))
.

Proof.

We augment the listing algorithm with a counter that is incremented after each step, so it counts the number of steps performed by the algorithm. We run this augmented algorithm, gathering its listed solutions. After the
(f(I)+j\cdot g(I))
-th time step, we print the
j
-th gathered solution. If at this point less than
j
solutions have been gathered, then we terminate.

Note that to run this algorithm we need to know
f(I)
and
g(I)
, and we can indeed compute
f(I)
and
g(I)
in time
O(f(I)+g(I))
, since
f,g
is constructible.

The guarantee of the listing algorithm ensures that
j
solutions are gathered in time at most
f(I)+j\cdot g(I)
, so after the
(f(I)+j\cdot g(I))
-th time step we can print the
j
-th gathered solution. This holds for any
1\leq j\leq t
. Thus, if at this point less than
j
solutions have been gathered, then
j>t
, in which case we have already listed all
j-1=t
solutions and correctly terminate.

Clearly, the first solution is printed in time
O(f(I)+g(I))=O(f(I))
and the time between printing two solutions is
O(g(I))
. The time between printing the last solution and terminating is also
O(g(I))
. That is, we obtained an enumeration algorithm with preprocessing time
O(f(I))
and delay
O(g(I))
.
∎

For the remainder of
Section

8
we fix an
s
-splitting algorithm

.

Let

Warmup:

To build intuition for the general argument, in this section we present a simplified proof for the special case of

We will need the following tool.

Lemma 34.

Let

be constructible functions. If there is a listing algorithm running in time at most

, then there is an algorithm

)

and

and

in time

In this section, we show how to convert a listing or enumeration algorithm for Colored
(H,I)
-Subgraph into one for Uncolored
(H,I)
-Subgraph, with only a factor
\polylog(n)
overhead (in preprocessing time and delay).

The following lemma phrases the classic color coding technique
[
8
]
(specifically, its deterministic version) as a reduction.

Lemma 38.

Let
H=([k],\mathcal{E})
be a pattern hypergraph. Given a host hypergraph
G=(V,E)
, we can compute
r=O(\log n)
partitions
\mathcal{P}_{1},\ldots,\mathcal{P}_{r}
of
V
, in time
O(n\log n)
, with the following property. Let
\mathcal{S}
be the set of uncolored
H
-copies in
G
. Let
\mathcal{S}_{l}
be the set of colored
H
-copies in
G
with respect to partition
\mathcal{P}_{l}
. Then
\mathcal{S}=\bigcup_{l\in[r]}\mathcal{S}_{l}
.

We remark that the constant factor hidden in
r=O(\log n)
is of the form
k^{k}
.

Proof.

We compute a
k
-perfect family of hash functions
\set{h_{l}}_{l\in[r]}
, where each function
h_{l}
maps
V\to[k]
, and for every tuple
(v_{1},\dots,v_{k})\in\binom{V}{k}
there is an
l\in[r]
such that
h_{l}(v_{1}),\dots,h_{l}(v_{k})
are distinct. It is known that such such a family exists for
r=O(\log n)
and can be computed deterministically in time
O(n\log n)
; moreover, every
h_{l}
can be evaluated in constant time. See Section 4 in
[
8
]
.

Each function
h_{l}
induces a partition of
V
, namely,
\mathcal{P}_{l}=\Set{h_{l}^{-1}(1),\dots,h_{l}^{-1}(k)}
. Computing these partitions takes time
O(rn)
in total. By the definition of the family, for every uncolored
H
-copy
(v_{1},\dots,v_{k})\in V^{k}
, there is an
l\in[r]
such that
h_{l}(v_{1}),\dots,h_{l}(v_{k})
are distinct, so
(v_{1},\dots,v_{k})
is a colored
H
-copy in
G
with respect to partition
\mathcal{P}_{l}
. Hence,
\mathcal{S}\subseteq\bigcup_{l\in[r]}\mathcal{S}_{l}
. For the converse direction
\supseteq
, note that every colored
H
-copy in
G
with respect to any partition is also an uncolored
H
-copy in
G
.
∎

A direct application of
Lemma

38
allows us to obtain listing algorithms for uncolored problems from listing algorithms for colored problems.

Lemma 39.

If Colored
(H,I)
-Listing can be solved in time
\widetilde{O}(t+f(n,m))
then Uncolored
(H,I)
-Listing can be solved in time
\widetilde{O}(t+f(n,m))
.

Proof.

Use
Lemma

38
to construct partitions
\mathcal{P}_{1},\ldots,\mathcal{P}_{r}
. Run the algorithm for Colored
(H,I)
-Listing on
G
with respect to partition
\mathcal{P}_{l}
to compute the set of solutions
\mathcal{S}_{l}
. Finally, compute
\mathcal{S}=\bigcup_{l\in[r]}\mathcal{S}_{l}
, e.g., by sorting and deduplicating.
∎

In order to obtain uncolored

[

. Compared to the variant we used in

(

Lemma 40 (Cheater’s Lemma, Variant II).

Let
f,g,h
be functions such that
f(n,m),g(n,m),h(n,m)
can be computed in time
O(f(n,m)+g(n,m)h(n,m))
. Suppose there is an algorithm that, given an instance
G
of Colored
(H,I)
-Subgraph, (1) prints all solutions to
G
, (2) the time to print the
j
-th answer is bounded by
f(n,m)+j\cdot g(n,m)
, for all
j\in[t]
, and (3) every solution is printed at most
h(n,m)
times. Then there exists an enumeration algorithm with preprocessing time
\widetilde{O}(f(n,m)+g(n,m)h(n,m))
and delay
\widetilde{O}(g(n,m)h(n,m))
.

Proof.

Suppose that algorithm
\mathfrak{A}
satisfies (1), (2), and (3). We will simulate
\mathfrak{A}
and redirect its output stream to a buffer. Initially, the buffer is empty. We run
\mathfrak{A}
for
f(n,m)+g(n,m)h(n,m)
steps and aggregate some solutions(s) in the buffer. Then we repeat until the buffer depletes:

•

While the next item in the buffer is a duplicate to what was printed before, discard it.

•

Print the next solution in the buffer.

•

Run
\mathfrak{A}
for another
g(n,m)h(n,m)
steps.

We claim that the buffer never depletes unless we have printed all solutions. Consider the beginning of the
i
-th repetition. We have already run
\mathfrak{A}
for a total of
f(n,m)+i\cdot g(n,m)h(n,m)
steps. Unless we have printed all solutions, property (2) implies that
\mathfrak{A}
has fed at least
i\cdot h(n,m)
items to the buffer, hence at least
i
distinct solutions by property (3). On the other hand, we have printed only
i-1
distinct solutions from the buffer (one for each previous repetition). The claim thus follows.

Since we have listed every solution without duplicate, this gives an enumeration algorithm. Note that checking whether the next item in the buffer is a duplicate requires a data structure such as a binary search tree, which results in an additional factor
\log(t)\leq\log(n^{k})=O(\log n)
in the running time, where
k=|V(H)|
.
Hence, the resulting enumeration algorithm has preprocessing time
\widetilde{O}(f(n,m)+g(n,m)h(n,m))
and delay
\widetilde{O}(g(n,m)h(n,m))
.
∎

\mu(\mathbf{v}):=\sum_{v_{0}\in[N_{0}]}\prod_{i\in[d]}\mu_{i}(v_{0},v_{i}).

These tuples are called
\EMPH

for each solution

. The algorithm runs in time
\Otilde(t+m^{2/{\widetilde{\alpha}}})

As usual, we assume that the functions are sparsely represented: each

Observe that the counting problem specializes to Colored projected-

Proof of

.

We emphasize that if

At a high level, we prove

by designing an algorithm for “dense” instances via matrix multiplication, and then reducing general instances to dense ones via hashing and iterative recovery. The two pieces are discussed in the next two subsections.

10.1
Counting in Dense Instances

Write
N_{I}=\prod_{i\in I}N_{i}
. We show that we can efficiently count in the “dense” case, where the dimensions
N_{1},\dots,N_{d}
are relatively small.

Lemma 43.

Let
\Delta\geq 1
and assume that
N_{I}\leq N_{0}\Delta^{|I|}
for all
I\subseteq[d]
. There is a deterministic algorithm
dcount(
\mu_{1},\dots,\mu_{d}
)
that, given functions
\mu_{i}:[N_{0}]\times[N_{i}]\to\N
for
i\in[d]
, computes
\mu(\mathbf{v})
for each tuple
\mathbf{v}\in\prod_{i\in[d]}[N_{i}]
and runs in time
\Otilde(N_{[d]}+(N_{0}\Delta)^{2/{\widetilde{\alpha}}})
.

The proof of
Lemma

43
relies on the following partition lemma.

Lemma 44.

Let
\Delta\geq 1
and assume that
N_{I}\leq N_{0}\Delta^{|I|}
for all
I\subseteq[d]
. For every
c\geq 1
there is a partition
[d]=I\cup\overline{I}
such that

\max\Set{N_{I},N_{\overline{I}}}\;\leq\;\frac{N_{[d]}}{N_{0}^{c}}+N_{0}^{c}\Delta^{c+1}\;\leq\;\frac{N_{[d]}}{N_{0}^{c}}+N_{0}^{c}\Delta^{2c}

Proof.

The second inequality follows just from the assumption
c\geq 1
, so we focus on showing the first inequality. If
d<2c
then the partition is trivial. Indeed, split
[d]
arbitrarily into two parts
I,\overline{I}
of size at most
\ceil{\frac{d}{2}}\leq\ceil{c}
. Under the premise of the lemma, this partition satisfies

\max\Set{N_{I},N_{\overline{I}}}\leq N_{0}\Delta^{\ceil{c}}\leq N_{0}^{c}\Delta^{c+1}.

So suppose that
d\geq 2c
. In this case we construct the partition by induction. Reorder the numbers so that
N_{d}=\min\set{N_{1},\dots,N_{d}}
, and inductively obtain a partition
[d-1]=J\cup\overline{J}
such that

\max\Set{N_{J},N_{\overline{J}}}\leq\frac{N_{[d-1]}}{N_{0}^{c}}+N_{0}^{c}\Delta^{c+1}.

Without loss of generality assume that
N_{J}\leq N_{\overline{J}}
. Then let
I=J\cup\set{d}
. Note that
\overline{I}=\overline{J}
and thus
N_{\overline{I}}=N_{\overline{J}}\leq\frac{N_{[d]}}{N_{0}^{c}}+N_{0}^{c}\Delta^{c+1}
as required. It remains to analyze
N_{I}
. We have

N_{I}=N_{J}\cdot N_{d}\leq\sqrt{N_{J}N_{\overline{J}}}\cdot N_{d}=\sqrt{N_{[d-1]}}\cdot N_{d},

so in the following we will bound
\sqrt{N_{[d-1]}}\cdot N_{d}
. We distinguish two cases:

•

If
N_{[d-1]}>N_{0}^{2c}
, then

\sqrt{N_{[d-1]}}\cdot N_{d}=\frac{N_{[d]}}{\sqrt{N_{[d-1]}}}<\frac{N_{[d]}}{N_{0}^{c}}.

•

If
N_{[d-1]}\leq N_{0}^{2c}
, then

N_{d}\leq(N_{[d]})^{\frac{1}{d}}\leq\left(N_{0}\Delta^{d}\right)^{\frac{1}{d}}=N_{0}^{\frac{1}{d}}\Delta

by the assumption
N_{d}=\min\set{N_{1},\dots,N_{d}}
and the premise of the lemma. Besides this bound, we have
N_{[d-1]}\leq N_{0}\Delta^{d}
(again by the premise of the lemma) and
N_{[d-1]}\leq N_{0}^{2c}
(by the case assumption). Let
\gamma=\frac{2c}{d}
, and note that
0<\gamma\leq 1
. Taking a geometric mean of both bounds with weights
\gamma
and
1-\gamma
,

N_{[d-1]}\leq(N_{0}\Delta^{d})^{\gamma}\cdot N_{0}^{2c(1-\gamma)}=N_{0}^{2c+\gamma(1-2c)}\Delta^{2c}\leq N_{0}^{2c-\frac{2}{d}}\Delta^{2c},

where the last step used
c\geq 1
. Therefore,

\sqrt{N_{[d-1]}}\cdot N_{d}\leq N_{0}^{c-\frac{1}{d}}\Delta^{c}\cdot N_{0}^{\frac{1}{d}}\Delta=N_{0}^{c}\Delta^{c+1}.

This completes the proof.
∎

Proof of
Lemma

43
.

Let
[d]=I\cup\overline{I}
be a partition guaranteed by
Lemma

44
; we compute this partition in constant time by enumerating and testing all partitions of
[d]
. Construct a matrix
A\in\N^{(\prod_{i\in I}[N_{i}])\times[N_{0}]}
where
A_{\mathbf{v},v_{0}}=\prod_{i\in I}\mu_{i}(v_{0},v_{i})
. Similarly, construct a matrix
B\in\N^{[N_{0}]\times(\prod_{i\in\overline{I}}[N_{i}])}
where
B_{v_{0},\mathbf{w}}=\prod_{i\in\overline{I}}\mu_{i}(v_{0},w_{i})
. Compute their product
C=AB
via
Proposition

10
. By definition, each entry
C_{\mathbf{v},\mathbf{w}}
in the product is exactly
\mu((\mathbf{v},\mathbf{w}))
.

The running time is dominated by the matrix multiplication. By Proposition
10
and
Lemma

44
applied with
c=1/{\widetilde{\alpha}}\geq 1
,

\displaystyle\mathrm{MM}(N_{I},N_{0},N_{\overline{I}})

\displaystyle=\Otilde\left(N_{I}N_{\overline{I}}+N_{0}\left(N_{I}N_{\overline{I}}\right)^{1-{\widetilde{\alpha}}}\left(N_{I}^{\widetilde{\alpha}}+N_{\overline{I}}^{\widetilde{\alpha}}\right)\right)

\displaystyle=\Otilde\left(N_{[d]}+N_{0}N_{[d]}^{1-{\widetilde{\alpha}}}\max\set{N_{I},N_{\overline{I}}}^{\widetilde{\alpha}}\right)

\displaystyle\leq\Otilde\left(N_{[d]}+N_{0}N_{[d]}^{1-{\widetilde{\alpha}}}\left(\frac{N_{[d]}}{N_{0}^{1/{\widetilde{\alpha}}}}+N_{0}^{1/{\widetilde{\alpha}}}\Delta^{2/{\widetilde{\alpha}}}\right)^{\widetilde{\alpha}}\right)

\displaystyle=\Otilde\left(N_{[d]}+N_{[d]}^{1-{\widetilde{\alpha}}}\left(N_{[d]}+N_{0}^{2/{\widetilde{\alpha}}}\Delta^{2/{\widetilde{\alpha}}}\right)^{\widetilde{\alpha}}\right).

By the weighted AM-GM inequality
x^{1-{\widetilde{\alpha}}}y^{\widetilde{\alpha}}\leq O(x+y)
, the time can be further bounded by
\Otilde(N_{[d]}+N_{0}^{2/{\widetilde{\alpha}}}\Delta^{2/{\widetilde{\alpha}}})
, as the lemma claimed.
∎

10.2
Densification via Contractions

To densify a general instance, the key definition is that of a contraction, which compresses the universe
[N_{1}]\times\cdots\times[N_{d}]
independently along each dimension into a smaller universe
[n_{1}]\times\cdots\times[n_{d}]
.

Definition 45.

A
\EMPH
contraction is a tuple of functions
h=(h_{1},\dots,h_{d})
where
h_{i}:[N_{i}]\to[n_{i}]
. The
\EMPH
volume of the contraction is
\prod_{i\in[d]}n_{i}
. The
\EMPH
image of a point
\mathbf{v}=(v_{1},\dots,v_{d})\in\prod_{i\in[d]}[N_{i}]
under
h
is defined as

h(\mathbf{v})=(h_{1}(v_{1}),\dots,h_{d}(v_{d}))\;\in\;\prod_{i\in[d]}[n_{i}].

Two points are said to
\EMPH
collide under
h
if they have the same image under
h
.

Definition 46.

Let
P\subseteq\prod_{i\in[d]}[N_{i}]
and let
h
be a contraction. A point
q\in\prod_{i\in[d]}[N_{i}]
is
\EMPH
isolated from
P
under
h
if it does not collide with any
p\in P\setminus\set{q}
under
h
. For a family of contractions
\mathcal{H}
, we say that a point is
\EMPH
isolated from
P
under
\mathcal{H}
if it is isolated from
P
under some
h\in\mathcal{H}
.

Theorem 47.

There is a deterministic algorithm
contractions(
P
)
that, given a set
P\subseteq\prod_{i\in[d]}[N_{i}]
, computes a family
\mathcal{H}
of
\Otilde(1)
contractions, each of volume
\Otilde(|P|)
, such that all but
|P|/4
points in
P
are isolated from
P
under
\mathcal{H}
. The algorithm runs in time
\Otilde\left(|P|+\sum_{i\in[d]}N_{i}\right)
.

Let us emphasize again that
d
is considered a constant throughout. The
\Otilde
-notation in the above theorem hides polylogarithmic factors of the form
(\log|P|)^{2^{d}}
.

Our algorithm
contractions
employs incremental
orthogonal range searching
. This is a deterministic data structure that maintains a point set
P\subset\R^{d^{\prime}}
under insertions. Upon an
orthogonal range query
of the form
B=[a_{1},b_{1}]\times\cdots\times[a_{d^{\prime}},b_{d^{\prime}}]
, the data structure reports the count
|P\cap B|
. It is known that such a data structure with update and query time
\Otilde(1)
exists.

Towards a proof of
Theorem

47
, we start with a lemma that generalizes
[
3
, Lemma 3.7]
. It deterministically constructs a family of
\Otilde(1)
contractions that isolates every point in a given point set. Note, however, that the volume bound in this lemma depends on the structure of the point set. So to close the proof of
Theorem

47
we still need an argument about the point set structure, which will come later.

Lemma 48.

Let
Q\subseteq P\subseteq\prod_{i\in[d]}[N_{i}]
. Let
n_{1},\dots,n_{d}
be integers such that
\card{\set{p\in P:p_{I}=q_{I}}}\leq\prod_{i\notin I}n_{i}
for all
q\in Q
and
I\subseteq[d]
. There is a deterministic algorithm that computes a family
\mathcal{H}
of
O(\log|Q|)
contractions, each with volume
O(\prod_{i\in[d]}n_{i})
, such that every
q\in Q
is isolated from
P
under
\mathcal{H}
. The algorithm runs in time
\Otilde\left(|P|+\sum_{i\in[d]}N_{i}\right)
.

Proof.

For each
i\in[d]
, let
M_{i}
be the smallest power of two such that
M_{i}\geq 5dn_{i}
. We start with a simple randomized algorithm:

\mathcal{H}:=\emptyset
;

while

Q\neq\emptyset

do

sample
h=(h_{1},\dots,h_{d})
where each
h_{i}:[N_{i}]\to[M_{i}]
is drawn uniformly at random;

add
h
to
\mathcal{H}
;

remove all points in
Q
that are isolated from
P
under
h
;

return

\mathcal{H}

Consider one round of the loop. Let
Z
be the number of points in
Q
not isolated from
P
under
h
. We claim that
\Pr(Z\geq|Q|/2)<1/2
. To see this, write
\operatorname{eq}(p,q):=\set{i\in[d]:p_{i}=q_{i}}
and note that two points
q\in Q
and
p\in P\setminus\set{q}
collide with probability
\prod_{i\notin\operatorname{eq}(p,q)}\Pr(h_{i}(p_{i})=h_{i}(q_{i}))=\prod_{i\notin\operatorname{eq}(p,q)}\frac{1}{M_{i}}
. Hence the expected number of points in
P\setminus\set{q}
colliding with
q
is at most

\sum_{I\subsetneq[d]}\frac{|\set{p\in P:p_{I}=q_{I}}|}{\prod_{i\notin I}M_{i}}\leq\sum_{I\subsetneq[d]}\frac{1}{(5d)^{d-|I|}}=\left(1+\frac{1}{5d}\right)^{d}-1<\frac{1}{4}.

Here, we used the premise of the lemma and
M_{i}\geq 5dn_{i}
. This implies
\E Z<|Q|/4
, so
\Pr(Z\geq|Q|/2)<1/2
by Markov’s inequality. In other words, with probability
1/2
at least half of the points in
Q
are isolated from
P
under
h
(and thus are removed from
Q
at the end of this round). Hence with high probability, the algorithm terminates in
O(\log|Q|)
rounds and returns a family
\mathcal{H}
of
O(\log|Q|)
contractions, each of volume
\prod_{i\in[d]}M_{i}=O(\prod_{i\in[d]}n_{i})
, such that every
q\in Q
is isolated from
P
.

The only randomness of the algorithm comes from sampling
h
. It is convenient to refine this sampling process as follows:

for

i=1,\dots,d

do

for

x=1,\dots,N_{i}

do

initialize an interval
Y:=[M_{i}]
;

for

l=1,\dots,\log M_{i}

do

partition the interval
Y
into two halves
Y_{0}\cup Y_{1}
;

sample a random bit
b
and let
Y:=Y_{b}
;

assign
h_{i}(x)
to be the unique element in
Y
;

Observe that the refined process generates uniformly random functions
h_{i}:[N_{i}]\to[M_{i}]
indeed.

To derandomize the process, we follow the method of condition expectations. Consider the time when iteration
(i,x,l)
starts. Note that
h_{1},\dots,h_{i-1}
were determined,
h_{i+1},\dots,h_{d}
are fully random, and
h_{i}
is just partially random:
h_{i}(1),\dots,h_{i}(x-1)
were fixed,
h_{i}(x+1),\dots,h_{i}(N_{i})
are fully random, and
h_{i}(x)
is uniformly distributed over the current interval
Y
. Let random variable
Z^{i,x,l}
count the number of points in
Q
not isolated from
P
under the (partially random) contraction
h=(h_{1},\dots,h_{d})
at this time. By the law of total expectation,

\E\left(Z^{i,x,l}\right)=\frac{1}{2}\E\left(Z^{i,x,l+1}\mid b=0\right)+\frac{1}{2}\E\left(Z^{i,x,l+1}\mid b=1\right).

Hence, there exists a choice of
b\in\set{0,1}
that makes the conditional expectation of
Z^{i,x,l+1}
at most
\E(Z^{i,x,l})
. With this insight, we can derandomize the process by letting
b:=0
if
\E\left(Z^{i,x,l+1}\mid b=0\right)\leq\E\left(Z^{i,x,l+1}\mid b=1\right)
, and
b:=1
otherwise. This ensures that the expected number of non-isolated points never increases over time, so in the end we deterministically obtain a contraction
h
under which at most
|Q|/4
points are not isolated. Replacing the sampling process in the original algorithm with this derandomized process, the number of rounds is bounded by
O(\log|Q|)
deterministically.

It remains to show how to compare
\E\left(Z^{i,x,l+1}\mid b=0\right)
with
\E\left(Z^{i,x,l+1}\mid b=1\right)
efficiently. Let us first analyze the probability that a point
q\in Q
collides with another point
p\in P\setminus\set{q}
under
h
.

•

If
h_{j}(p_{j})\neq h_{j}(q_{j})
for some
j<i
, then the probability is clearly zero.

•

Otherwise, the probability can be expressed as
\gamma(p,q)\cdot\theta(p,q)
, where

\gamma(p,q)=\prod_{\begin{subarray}{c}j>i\\
j\notin\operatorname{eq}(p,q)\end{subarray}}\frac{1}{M_{j}}\quad\text{and}\quad\theta(p,q)=\Pr\left[h_{i}(p_{i})=h_{i}(q_{i})\right].

We further analyze
\theta(p,q)
by a case distinction. If
p_{i}=q_{i}
then
\theta(p,q)=1
. Otherwise:

–

If
p_{i},q_{i}<x
then both
h(p_{i})
and
h(q_{i})
have been fixed, so
\theta(p,q)=\mathbb{1}[h_{i}(p_{i})=h_{i}(q_{i})]
.

–

If
p_{i}>x
or
q_{i}>x
, then
h_{i}(p_{i})
or
h_{i}(q_{i})
is uniform over
[M_{i}]
, so
\theta(p,q)=1/M_{i}
.

–

If
p_{i}<q_{i}=x
then
h_{i}(q_{i})
is uniform over
Y_{b}
. Since
|Y_{b}|=M_{i}/2^{l}
, we have
\theta(p,q)=\mathbb{1}[h_{i}(p_{i})\in Y_{b}]\cdot 2^{l}/M_{i}
. Symmetrically, if
q_{i}<p_{i}=x
then
\theta(p,q)=\mathbb{1}[h_{i}(q_{i})\in Y_{b}]\cdot 2^{l}/M_{i}
.

Observe that the bit
b
only matters in the last case of
\theta(p,q)
, so for the sake of comparing the conditional expectations under different choices of
b
, it suffices to compute
\sum_{(p,q)\in S\cup S^{\prime}}\gamma(p,q)
where

S:=\left\{(p,q)\;\;\middle|\;\;\begin{aligned} &q\in Q,\;p\in P\setminus\set{q}\\
&\forall j<i,\;h_{j}(p_{j})=h_{j}(q_{j})\\
&p_{i}<q_{i}=x,\;h_{i}(p_{i})\in Y_{b}\end{aligned}\right\},\quad S^{\prime}:=\left\{(p,q)\;\;\middle|\;\;\begin{aligned} &q\in Q,\;p\in P\setminus\set{q}\\
&\forall j<i,\;h_{j}(p_{j})=h_{j}(q_{j})\\
&q_{i}<p_{i}=x,\;h_{i}(q_{i})\in Y_{b}\end{aligned}\right\}.

We will focus on computing the sum over
S
; the sum over
S^{\prime}
can be computed analogously. To this end, for every
J\subseteq[d]
we define a subset
S_{J}:=\Set{(p,q)\in S:\operatorname{eq}(p,q)=J}
. Then

\sum_{(p,q)\in S}\gamma(p,q)=\sum_{J\subseteq[d]}\sum_{(p,q)\in S_{J}}\gamma(p,q)=\sum_{J\subseteq[d]}|S_{J}|\cdot\prod_{\begin{subarray}{c}j>i\\
j\notin J\end{subarray}}\frac{1}{M_{j}}.

Hence the problem reduces to computing
|S_{J}|
for each
J\subseteq[d]
. This can be done as follows. At the start of iteration
i
, we initialize a
(d+i)
-dimensional range searching data structure, and then proceed with the inner iterations. As soon as we determine
h_{i}(x)
at the end of iteration
x
, we insert the point
(p_{1},\dots,p_{d},h_{1}(p_{1}),\dots,h_{i}(p_{i}))
into the data structure, for each
p\in P
with
p_{i}=x
. To compute
|S_{J}|
at iteration
(i,x,l)
, we enumerate all
q\in Q
with
q_{i}=x
and aim to count the number of
p\in P
such that
(p,q)\in S_{J}
. Laying out all the constraints explicitly, we require

•

h_{j}(p_{j})=h_{j}(q_{j})
for all
j<i
;

•

h_{i}(p_{i})\in Y_{b}
;

•

p_{i}<x
;

•

p_{j}=q_{j}
for all
j\in J
;

•

p_{j}\neq q_{j}
for all
j\notin J
.

Recall that
q
is fixed and
p\in P
is a free variable. All but the last constraint are orthogonal range constraints on
(p_{1},\dots,p_{d},h_{1}(p_{1}),\dots,h_{i}(p_{i}))
. The last constraint, on the other hand, can be compiled to the disjunction of
2^{|J|}
orthogonal range constraints by trying all possible comparisons between
p_{j}
and
q_{j}
. Therefore, we can extract the count by querying the orthogonal range searching data structure
2^{|J|}=O(1)
times.

Let us bound the running time. In each iteration
i
, we insert and query the data structure
O\left(\sum_{x\in[N_{i}]}|P[x]|\right)=O(|P|)
times, where
P[x]=\set{p\in P:p_{i}=x}
. Each insertion and query takes
\Otilde(1)
time. Therefore, the overall running time is
\Otilde\left(|P|+\sum_{i\in[d]}N_{i}\right)
.
∎

Now we turn to study the structure of a point set
P
. Our plan is to classify points
q\in P
into a small number of types based on the measures
|\set{p\in P:p_{I}=q_{I}}|
for
I\subseteq[d]
. We say that a type is “captured” if it results in a volume bound of
\Otilde(|P|)
in
Lemma

48
. The main challenge is in showing that most points have captured types, which we argue via projection inequalities and LP duality.

Definition 49.

Let
P\subseteq\prod_{i\in[d]}[N_{i}]
be a point set and denote
\lambda:=d2^{d}\log\left(2\log(|P|+1)\right)
. A
\EMPH
type is a tuple
l=(l_{I}:I\subseteq[d])
where
l_{[d]}=0
and
l_{I}\in\set{0,\dots,\ceil{\log|P|}}
for
I\subset[d]
. The type is
\EMPH
captured if there exist
x_{1},\dots,x_{d}\geq 0
such that

1.

\sum_{i\in[d]}x_{i}\leq\log|P|+\lambda
;

2.

\sum_{i\notin I}x_{i}\geq l_{I}
for all
I\subseteq[d]
.

For a point
q\in P
, we let
\EMPH{C_{I}(q)}:=\Card{\set{p\in P:p_{I}=q_{I}}}
and associate
\EMPH{\operatorname{type}(q)}:=\left(\ceil{\log C_{I}(q)}:I\subseteq[d]\right)
.

Lemma 50.

There is a deterministic algorithm with running time
\Otilde\left(|P|+\sum_{i\in[d]}N_{i}\right)
and the following guarantees. The input is a point set
P
and a captured type
l
along with the witnesses
x_{1},\dots,x_{d}
. The algorithm computes a family
\mathcal{H}
of
O(\log|P|)
contractions, each with volume
\Otilde(|P|)
, such that all points in
P
of type
l
are isolated from
P
under
\mathcal{H}
.

Proof.

First we compute
Q:=\set{q\in P:\operatorname{type}(q)=l}
. To this end, we build an orthogonal range searching data structure on
P
. For each
q\in P
and
I\subseteq[d]
we can compute
C_{I}(q)
by querying the data structure, and as a result we also obtain
\operatorname{type}(q)
. Therefore,
Q
can be computed in time
\Otilde(|P|)
.

Next we let
n_{i}=2^{\ceil{x_{i}}}
for
i\in[d]
. By condition (ii), for all
q\in Q
and
I\subseteq[d]
we have

C_{I}(q)\leq 2^{l_{I}}\leq 2^{\sum_{i\notin I}x_{i}}\leq\prod_{i\notin I}n_{i}.

We may therefore apply
Lemma

48
to compute a family
\mathcal{H}
of
O(\log|Q|)
contractions that isolates
Q
from
P
. Each contraction has volume
O\left(\prod_{i\in[d]}n_{i}\right)\leq O\left(2^{\sum_{i\in[d]}x_{i}}\right)\leq O(2^{\log|P|+\lambda})=\Otilde(|P|)
by property (i). This takes time
\Otilde\left(|P|+\sum_{i\in[d]}N_{i}\right)
.
∎

The remaining task is to argue that most points have captured types. We need the following lemma known as Shearer’s inequality (see
[
21
]
for the original formulation, and e.g.,
[
52
]
for the distributional version).

Lemma 51 (Shearer).

Let
q=(q_{1},\dots,q_{d})
be a discrete random variable. If
\mathcal{I}
is a probability distribution over subsets of
[d]
such that
\Pr_{I\sim\mathcal{I}}(i\in I)\geq r
for all
i\in[d]
, then
\E_{I\sim\mathcal{I}}[\entropy(q_{I})]\geq r\entropy(q)
.

Corollary 52.

Let
Q\subseteq\Z^{d}
. If
\mathcal{I}
is a probability distribution over subsets of
[d]
so that
\Pr_{I\sim\mathcal{I}}(i\in I)\geq r
for all
i\in[d]
, then
\E_{I\sim\mathcal{I}}[\log|Q_{I}|]\geq r\log|Q|
, where
Q_{I}=\set{q_{I}:q\in Q}
is the projection of
Q
to the coordinates in
I
.

Proof.

Let
q
be a uniformly random point from
Q
. Its entropy is
\entropy(q)=\log|Q|
. Its projection
q_{I}
is a random variable taking values in
Q_{I}
, and we can trivially bound
\entropy(q_{I})\leq\log|Q_{I}|
. Therefore,

\E_{I\in\mathcal{I}}[\log|Q_{I}|]\geq\E_{I\in\mathcal{I}}[\entropy(q_{I})]\geq r\entropy(q)=r\log|Q|,

where we applied
Lemma

51
in the second step.
∎

We also recall Farkas’ Lemma of linear programming (see e.g.
[
30
, Proposition 6.4.3]
): If a linear system
A\mathbf{x}\leq\mathbf{b}
does not have a solution
\mathbf{x}\geq\mathbf{0}
, then there exists
\mathbf{y}\geq\mathbf{0}
such that
\mathbf{y}^{\mathrm{T}}\mathbf{b}<\mathbf{0}
and
\mathbf{y}^{\mathrm{T}}A\geq\mathbf{0}
. Now we are ready to show the following:

Lemma 53.

There are at most
|P|/4
points
p\in P
for which
\operatorname{type}(p)
is uncaptured.

Proof.

Let
l=(l_{I}:I\subseteq[d])
be an uncaptured type, and let
Q:=\Set{q\in P:\operatorname{type}(q)=l}
. Our goal is to upper bound
|Q|
in terms of
|P|
.

Consider an arbitrary
I\subseteq[d]
. By definition, each point
q_{I}\in Q_{I}
extends to at least
C_{I}(q)\geq 2^{l_{I}-1}
points in
P
. Therefore,
|P|\geq|Q_{I}|\cdot 2^{l_{I}-1}
. Taking logarithm on both sides, we obtain

\forall I\subseteq[d],\;\;\log|Q_{I}|\leq\log|P|+1-l_{I}.

(2)

Next we relate
\log|Q|
with
\log|Q_{I}|
. Recall that
l
is uncaptured, so the linear system (i)(ii) does not have a solution
x_{1},\dots,x_{d}\geq 0
. By Farkas’ Lemma, there exist
(y_{I})_{I\subseteq[d]}\geq\mathbf{0},z\geq 0
such that

(\log|P|+\lambda)\cdot z-\sum_{I\subseteq[d]}l_{I}y_{I}<0\qquad\text{and}\qquad\forall i\in[d],\;\;z-\sum_{I\subseteq[d]\setminus\set{i}}y_{I}\geq 0.

We may assume
y_{[d]}=0
since
l_{[d]}=0
. By moving the terms and scaling the variables, we can further ensure
(y_{I})_{I\subseteq[d]}\geq\mathbf{0},z=1
and

\sum_{I\subseteq[d]}l_{I}y_{I}>\log|P|+\lambda\qquad\text{and}\qquad\forall i\in[d],\;\;\sum_{I\subseteq[d]\setminus\set{i}}y_{I}\leq 1.

Let us define a probability distribution
\mathcal{I}(I):=y_{I}/M
with normalizing constant
M:=\sum_{I\subset[d]}y_{I}
. Observe that
1<M\leq d
. Indeed, since
l_{I}\leq\log|P|+1
for all
I\subseteq[d]
, the first constraint implies
M>1
. On the other hand,
M\leq\sum_{i\in[d]}\sum_{I\subseteq[d]\setminus\set{i}}y_{I}\leq\sum_{i\in[d]}1=d
by the second constraint.

Rephrasing the constraints in terms of this distribution, we have

\E_{I\sim\mathcal{I}}(l_{I})>\frac{\log|P|+\lambda}{M}\qquad\text{and}\qquad\forall i\in[d],\;\;\Pr_{I\sim\mathcal{I}}(i\notin I)\leq\frac{1}{M},

In particular,
\Pr_{I\sim\mathcal{I}}(i\in I)\geq 1-\frac{1}{M}
, so Corollary
52
implies that
\left(1-\frac{1}{M}\right)\log|Q|\leq\E_{I\sim\mathcal{I}}[\log|Q_{I}|]
. Plugging (
2
) into this bound, we get

\displaystyle\left(1-\frac{1}{M}\right)\log|Q|

\displaystyle\leq\log|P|+1-\E_{I\sim\mathcal{I}}(l_{I})

\displaystyle<\log|P|+1-\frac{\log|P|+\lambda}{M}

\displaystyle=\left(1-\frac{1}{M}\right)\log|P|+\frac{M-\lambda}{M}.

Rearranging, we obtain
\log\frac{|Q|}{|P|}\leq\frac{M-\lambda}{M-1}
. Recall that
1<M\leq d
and
\lambda=d2^{d}\log\left(2\log(|P|+1)\right)
, so the numerator
M-\lambda
is negative and the denominator
M-1
is positive. Hence

\log\frac{|Q|}{|P|}\leq\frac{d-\lambda}{d-1}\leq-2^{d}\log\left(2\log(|P|+1)\right).

In other words,
|Q|\leq|P|/\left(2\log(|P|+1)\right)^{2^{d}}
.

Since the argument works for any uncaptured type
l
, by a union bound over all
\left(\log(|P|+1)\right)^{2^{d}}
types, we conclude that at most
|P|/2^{2^{d}}\leq|P|/4
points have uncaptured types.
∎

Proof of
Theorem

.

For each type
l
, we solve the linear system (i)(ii) by the simplex method (which takes constant time as the number of variables and constraints are both constant). If the system has a solution
x_{1},\dots,x_{d}
, then
l
is captured and we call
Lemma

50
to compute a family of contractions
\mathcal{H}_{l}
with volume
\Otilde(|P|)
, isolating all points of type
l
from
P
. In the end, output
\mathcal{H}:=\bigcup_{l}\mathcal{H}_{l}
. By
Lemma

53
all but
|P|/4
points in
P
have a captured type, and consequently all but
|P|/4
points in
P
are isolated from

under
\mathcal{H}
. The running time is clearly as claimed.
∎

10.3
The Full Algorithm

We are finally ready to complete our algorithm
count
and prove
Theorem

42
. For
v_{0}\in[N_{0}]
, the
\EMPH
degree of
v_{0}
in the instance
\mu_{1},\dots,\mu_{d}
is defined as
\max_{i\in[d]}|\set{v_{i}\in[N_{i}]:\mu_{i}(v_{0},v_{i})>0}|
. Assume without loss of generality that
N_{1},\dots,N_{d}
are powers of two. We also assume that
m\geq N_{0}
, as we can remove all elements
v_{0}\in[N_{0}]
that do not participate in any non-zero entry of the input functions.

If
N_{1}=\cdots=N_{d}=1
, then we simply compute the number
\sum_{v_{0}\in[N_{0}]}\prod_{i\in[d]}\mu_{i}(v_{0},1)
, and return it if it is positive. Otherwise, the idea is similar to that of sparse matrix multiplication (
Lemma

12
): Fold the space in half and solve the subinstance recursively; unfold the solutions from the subinstance into a superset of solutions in the original instance; and finally, recover the actual solutions.

In detail, let
\phi(i):\N\to\N
be the permutation that swaps each odd number
2x-1
with the even number
2x
. For example,
\phi(5)=6
and
\phi(6)=5
. The algorithm
count(
\mu_{1},\dots,\mu_{d}
)
works recursively:

•

Fix an arbitrary
j\in[d]
with
N_{j}\geq 2
.

•

Construct a function
\eta_{j}:[N_{0}]\times[N_{j}/2]\to\N
by
\eta_{j}(v_{0},u_{j}):=\mu_{i}(v_{0},2u_{j}-1)+\mu_{i}(v_{0},2u_{j})
. For
i\neq j
, let
\eta_{i}:=\mu_{i}
.

•

Recursively compute
(\mathcal{R},\eta):=\text{{{count(}}{\emph{$\eta_{1},\dots,\eta_{d}$}}{{)}}}
.

•

Let
S:=\Set{(u_{1},\dots,u_{j-1},2u_{j}-b,u_{j+1},\dots,u_{d})\>:\>(u_{1},\dots,u_{d})\in\mathcal{R},b\in\set{0,1}}
.

•

Partition
[N_{0}]
into
\ceil{\log n}
parts such that each part contains elements with degree more than
D/2
and at most
D
, for
D\in\set{2^{0},2^{1},\dots,2^{\ceil{\log n}}}
. We deal with these parts separately. To simplify notation, we focus on an arbitrary part in the following.

•

Initialize a set
R:=\emptyset
and an all-zero function
f:S\to\N
. Repeat until
R=S
:

–

Let
P=S\setminus R
and
\Delta=4D\cdot(\log|P|)^{c}
for some sufficiently large constant
c>0
.

–

Let
\mathcal{H}:=\text{{{contractions(}}{\emph{$P$}}{{)}}}
.

–

For each
h=(h_{1},\dots,h_{d})\in\mathcal{H}
:

1.

Write
h_{i}:[N_{i}]\to[n_{i}]
. Check if
\prod_{i\in[d]}n_{i}\leq N_{0}\Delta^{|I|}
for all
I\subseteq[d]
. If not then continue with the next
h
.

2.

Compute the set
Q\subseteq P
of tuples that are isolated from
P
under
h
.

3.

For each
i\in[d]
, define a function
\mu_{i}^{\prime}:[N_{0}]\times[n_{i}]\to\N
by

\mu_{i}^{\prime}(v_{0},v_{i}^{\prime}):=\sum_{v_{i}\in h_{i}^{-1}(v_{i}^{\prime})}\mu_{i}(v_{0},v_{i}).

and compute
\mu^{\prime}:=\text{{{dcount(}}{\emph{$\mu_{1}^{\prime},\dots,\mu_{d}^{\prime}$}}{{)}}}
.

4.

For each
\mathbf{v}=(v_{1},\dots,v_{d})\in Q
, let
\mathbf{w}:=(v_{1},\dots,v_{j-1},\phi(v_{j}),v_{j+1},\dots,v_{d})
. Add both
\mathbf{v}
and
\mathbf{w}
to
R
, and assign

\displaystyle f(\mathbf{v})

\displaystyle:=\mu^{\prime}(h(\mathbf{v}))-\sum_{\begin{subarray}{c}\mathbf{u}\in R\setminus\set{\mathbf{v}}\\
h(\mathbf{u})=h(\mathbf{v})\end{subarray}}f(\mathbf{u})

\displaystyle f(\mathbf{w})

\displaystyle:=\eta\left(v_{1},\dots,v_{j-1},\floor{v_{j}/2},v_{j+1},\dots,v_{d}\right)-f(\mathbf{v})

•

Return
\set{\mathbf{v}\in S:f(\mathbf{v})>0}
, along with
f
restricted to this set.

Correctness

Let us denote the set of solutions by
\mathcal{S}:=\Set{\mathbf{v}\in\prod_{i\in[d]}[N_{i}]:\mu(\mathbf{v})>0}
. Observe that if
(v_{1},\dots,v_{d})\in\mathcal{S}
, then
(v_{1},\dots,v_{j-1},\floor{v_{j}/2},v_{j+1},\dots,v_{d})\in\mathcal{R}
. Conversely, if
(v_{1},\dots,v_{j-1},u_{j},v_{j+1},\dots,v_{d})\in\mathcal{R}
, then at least one of
(v_{1},\dots,v_{j-1},2u_{j}-1,v_{j+1},\dots,v_{d})
and
(v_{1},\dots,v_{j-1},2u_{j},v_{j+1},\dots,v_{d})
is in
\mathcal{S}
. Therefore,
\mathcal{S}\subseteq S
and
|S|\leq 2|\mathcal{S}|
.

Next, we analyze the repeat-until loop, in particular step (d). We argue that the step assigns
f(\mathbf{v})=\mu(\mathbf{v})
and
f(\mathbf{w})=\mu(\mathbf{w})
. Indeed, we have

\displaystyle\mu^{\prime}(h(\mathbf{v}))

\displaystyle=\sum_{v_{0}\in[N_{0}]}\prod_{i\in[d]}\mu_{i}^{\prime}(v_{0},h_{i}(v_{i}))

\displaystyle=\sum_{v_{0}\in[N_{0}]}\prod_{i\in[d]}\sum_{u_{i}:h_{i}(u_{i})=h_{i}(v_{i})}\mu_{i}(v_{0},u_{i})

\displaystyle=\sum_{v_{0}\in[N_{0}]}\sum_{\mathbf{u}:h(\mathbf{u})=h(\mathbf{v})}\prod_{i\in[d]}\mu_{i}(v_{0},u_{i})

\displaystyle=\sum_{\mathbf{u}:h(\mathbf{u})=h(\mathbf{v})}\sum_{v_{0}\in[N_{0}]}\prod_{i\in[d]}\mu_{i}(v_{0},u_{i})

\displaystyle=\mu(\mathbf{v})+\sum_{\begin{subarray}{c}\mathbf{u}\neq\mathbf{v}\\
h(\mathbf{u})=h(\mathbf{v})\end{subarray}}\mu(\mathbf{u})

Recall that
\mu(\mathbf{u})>0
only when
\mathbf{u}\in\mathcal{S}\subseteq S
. Also recall that the point
\mathbf{v}\in Q
is isolated from
P
, so it can only collide with points in
S\setminus P=R
. Using these two facts, we have

\sum_{\begin{subarray}{c}\mathbf{u}\neq\mathbf{v}\\
h(\mathbf{u})=h(\mathbf{v})\end{subarray}}\mu(\mathbf{u})=\sum_{\begin{subarray}{c}\mathbf{u}\in R\setminus\set{\mathbf{v}}\\
h(\mathbf{u})=h(\mathbf{v})\end{subarray}}\mu(\mathbf{u})

As previous iterations have assigned
f(\mathbf{u})=\mu(\mathbf{u})
correctly for the tuples
\mathbf{u}
of concern, we conclude that the step correctly assigns
f(\mathbf{v})=\mu(\mathbf{v})
.

Finally, recall from definition that

\displaystyle\eta\left(v_{1},\dots,v_{j-1},\floor{v_{j}/2},v_{j+1},\dots,v_{d}\right)

\displaystyle=\sum_{v_{0}\in[N_{0}]}\eta_{j}(v_{0},\floor{v_{j}/2})\cdot\prod_{i\neq j}\mu_{i}(v_{0},v_{i})

\displaystyle=\sum_{v_{0}\in[N_{0}]}\left(\mu_{j}(v_{0},v_{j})+\mu_{j}(v_{0},\phi(v_{j}))\right)\cdot\prod_{i\neq j}\mu_{i}(v_{0},v_{i})

\displaystyle=\mu(\mathbf{v})+\mu(\mathbf{w}).

Hence, the step also correctly assigns
f(\mathbf{w})=\mu(\mathbf{w})
.

When the algorithm terminates, the function
\mu
is correctly computed and stored in
f
. So the algorithm is correct (if it terminates).

Parameters in the recursion

The recursion has depth
O(\sum_{i\in[d]}\log N_{i})=\widetilde{O}(1)
because each level halves
N_{j}
for some
j
. Also, note that the parameters
t,m
do not increase as we descend in the recursion. Now we focus on analyzing a fixed level of the recursion.

Time outside the loop

Computing
j
takes constant time. Constructing the functions
\eta_{i}
takes time
O(m)
. Computing
S
takes time
O(|\mathcal{R}|)=O(t)
. Computing the degrees and partitioning
[N_{0}]
takes time
O(m+N_{0})=O(m)
.

Time of each round of the loop

Computing
P
takes time
O(|S|)
. Calling
contractions
takes time
\Otilde\left(|P|+\sum_{i\in[d]}N_{i}\right)
by
Theorem

47
. By the same theorem, the family
\mathcal{H}
contains
\Otilde(1)
contractions, each of volume
\Otilde(|P|)
. For each
h\in\mathcal{H}
, step (a) takes constant time; step (b) takes time
\Otilde(|P|)
by querying the image of each point in a binary search tree containing all images; step (d) takes time
\Otilde(|Q|+|R|)
by standard bookkeeping. Step (c) takes time
O(m)
to construct the functions, and time
\Otilde\left(\prod_{i\in[d]}n_{i}+(N_{0}\Delta)^{2/{\widetilde{\alpha}}}\right)
for
dcount
by
Lemma

43
. Recall that
\prod_{i\in[d]}n_{i}
is the volume of
h
, so it is at most
\Otilde(|P|)
. Moreover, each element in
[N_{0}]
has degree at least
D/2
, so
m\geq N_{0}D/2
and thus
N_{0}\Delta\leq\Otilde(m)
. Gathering all these bounds and recalling
|P|,|Q|,|R|\leq|S|\leq O(t)
, a single round runs in time
\Otilde(t+m^{2/{\widetilde{\alpha}}})
.

Number of rounds

We will bound the number of rounds by
\Otilde(1)
. First note that
|P\cap\mathcal{S}|\geq|P|/2
, as we always recover pairs
\mathbf{v},\mathbf{w}
together and at least one of them is a solution. The family
\mathcal{H}
is guaranteed to isolate all but
|P|/4
tuples from
P
by
Theorem

47
. In particular, in
P\cap\mathcal{S}
there are at least
|P|/2-|P|/4=|P|/4
tuples isolated under
\mathcal{H}
. Hence by the pigeonhole principle, there is a function
h\in\mathcal{H}
that isolates at least
|P|/(4|\mathcal{H}|)
tuples from
P\cap\mathcal{S}
. We fix this function
h
and consider the corresponding inner iteration.

We claim that the condition
\prod_{i\in I}n_{i}\leq N_{0}\Delta^{|I|}
holds for all
I\subseteq[d]
.

Let
\xi,\zeta>0
be sufficiently large constants such that
|\mathcal{H}|\leq(\log|P|)^{\xi}
and
\prod_{i\in[d]}n_{i}\leq|P|\cdot(\log|P|)^{\zeta}
. Note that every
v_{0}\in[N_{0}]
still has degree at most
D
in the subinstance. That is,
\mu_{i}^{\prime}(v_{0},\cdot)
has at most
D
non-zeros for all
i\in[d]
and
v_{0}\in[N_{0}]
. In particular, the number of solutions
t^{\prime}
in the subinstance
(\mu_{1}^{\prime},\dots,\mu_{d}^{\prime})
can be bounded by
t^{\prime}\leq N_{0}D^{|I|}\prod_{i\not\in I}n_{i}
. On the other hand,
t^{\prime}\geq|P|/(4|\mathcal{H}|)
because
h
isolates at least this many solutions in the original instance, and by the definition of isolation each original solution leads to a distinct solution in the subinstance. Putting both bounds together,

\prod_{i\not\in I}n_{i}\geq\frac{|P|}{4N_{0}D^{|I|}|\mathcal{H}|}\geq\frac{|P|}{4N_{0}D^{|I|}\cdot(\log|P|)^{\xi}}.

As a result,

\prod_{i\in I}n_{i}=\frac{\prod_{i\in[d]}n_{i}}{\prod_{i\notin[d]}n_{i}}\leq\frac{|P|\cdot(\log|P|)^{\zeta}}{|P|/\left(4N_{0}D^{|I|}\cdot(\log|P|)^{\xi}\right)}=4N_{0}D^{|I|}\cdot(\log|P|)^{\xi+\zeta}.

By choosing
\Delta:=4D\cdot(\log|P|)^{\xi+\zeta}
, the right hand side is at most
N_{0}\Delta^{|I|}
. This establishes the claim.

The claim means that the algorithm executes (b)–(d) in iteration
h
, so the at least
|P|/(4|\mathcal{H}|)
tuples isolated under
h
are added to
R
. Hence
|P|
decreases by a factor of
1-\frac{1}{4|\mathcal{H}|}\leq 1-\frac{1}{4(\log|P|)^{\xi}}
in each round, and thus the number of rounds is
O\left((\log|P|)^{\xi+1}\right)=\Otilde(1)
.

Putting all the bounds together, the proof of
Theorem

42
is now complete.

11
Conditional Lower Bounds

The starting point of our lower bounds is the
\mathrm{Clique}(k,n_{1},\dots,n_{k})
problem. Here, the input is a
k
-partite graph
G=(V_{1}\cup\cdots\cup V_{k},E)
where
|V_{i}|=n_{i}
for all
i\in[k]
, and the goal is to decide if
G
contains a
k
-clique. Clearly, any
k
-clique in
G
(if exists) must pick exactly one vertex from each part.

For
n_{1}=\ldots=n_{k}=n
, the fastest known algorithm for the problem works by grouping the
k
parts into 3 roughly balanced groups, which induce a tripartite graph on
n^{k/3+O(1)}
vertices, then running a triangle detection algorithm on this tripartite graph. Since triangle detection can be solved in matrix multiplication time, this gives an
n^{\omega k/3+O(1)}
-time algorithm for
\mathrm{Clique}(k,n,\dots,n)
. If only “combinatorial” algorithms are allowed (i.e., fast matrix multiplication is disallowed), then the state of the art is essentially brute-force. This gives rise to the following frequently used hypotheses in fine-grained complexity; see e.g.
[
2
,
1
,
14
]
.

Combinatorial
k
-Clique Hypothesis.

Let
k\geq 3
and
\delta>0
. No combinatorial algorithm can solve
\mathrm{Clique}(k,n,\dots,n)
in time
O(n^{k-\delta})
.

k
-Clique Hypothesis.

Let
k\geq 3
and
\delta>0
. No algorithm can solve
\mathrm{Clique}(k,n,\dots,n)
in time
O(n^{\omega k/3-\delta})
.

Next we pose a new hypothesis that has not been previously used.

Lopsided 4-Clique Hypothesis.

Let
\beta\geq 1
and
\delta>0
. No algorithm can solve
\mathrm{Clique}(4,n,n,n,n^{\beta})
in time
O(n^{2+\beta-\delta})
.

The known algorithms solve
\mathrm{Clique}(4,n,n,n,n^{\beta})
by building a (possibly dense)
n^{2}\times n^{\beta}
matrix, and thus take time
\Omega(n^{2+\beta})
. The hypothesis formalizes this running time barrier, postulating that no algorithm can be faster. Naturally, the level of trust in a new hypothesis is significant lower. Nevertheless, we use it as a barrier towards faster listing algorithms.

After discussing the relevant hypotheses, we now present our main reduction. This is a generic reduction from
\mathrm{Clique}(k,n_{1},\dots,n_{k})
to listing projected-
(k-1)
-stars.

Lemma 54.

Let
k\geq 3
.

•

If there is an algorithm for Colored projected-
(k-1)
-star-Listing in time
\Otilde(t+f(n,m))
, then there is an algorithm for
\mathrm{Clique}(k,n,\dots,n,N)
in time
\Otilde(n^{k-1}+f(N,nN)+nN)
.

•

If there is an algorithm for Uncolored projected-
(k-1)
-star-Listing in time
\Otilde(t+f(n,m))
, then there is an algorithm for
\mathrm{Clique}(k,n,\dots,n,N)
in time
\Otilde((n+N)^{k-1}+f(N,nN))
.

Proof.

We denote the projected-
(k-1)
-star by
H=([k],\{(i,k):1\leq i<k\},I=[k-1]
.
Consider the following generic algorithm for
\mathrm{Clique}(k,n,\dots,n,N)
.

Given a graph
G=(V,E)
with partition
V=V_{1}\cup\cdots\cup V_{k}
, obtain a subgraph
G^{\prime}
by keeping only the edges adjacent to
V_{k}
. Solve Colored or Uncolored projected-
(k-1)
-star-Listing on
G^{\prime}
and let
\mathcal{S}
be the set of solutions. For each
\mathbf{v}\in\mathcal{S}
, if
\mathbf{v}
is a
(k-1)
-clique in
G
then output true and terminate. At the end of the loop, output false.

In the colored setting, we have
\mathcal{S}\subseteq V_{1}\times\ldots\times V_{k-1}
. A tuple

Further Comparison with Prior Work

In this appendix, we discuss prior works from
[
9
]
and
[
41
,
42
,
43
,
39
]
, which solve conjunctive queries with a running time that is bounded in terms of the so-called free-connex treewidth and free-connex submodular width, respectively. We show that both algorithms only achieve the trivial running times

A.1
Free-Connex Treewidth

Definition 55.

A
\EMPH
tree decomposition of a hypergraph
H=(V,E)
is a tree such that

•

every tree node
x
is associated with a subset
\operatorname{bag}(x)\subseteq V
;

•

for every
e\in E
, there is a node
x
such that
e\subseteq\operatorname{bag}(x)
;

•

for every
v\in V
, the nodes
\set{x:v\in\operatorname{bag}(x)}
form a connected subtree.

Definition 56.

Let
H=(V,E)
be a hypergraph and
I\subseteq V
. A
\EMPH
free-connex tree decomposition of
(H,I)
is a tree decomposition of
H
which contains a connected subtree
T^{\prime}
with
\bigcup_{x\in T^{\prime}}\operatorname{bag}(x)=I
.

Denote by
T(H)
the set of tree decompositions of
H
. The
\EMPH
treewidth of
H
is defined as

\operatorname{tw}(H)=\min_{T\in T(H)}\max_{x\in T}|\operatorname{bag}(x)|-1.

Similarly, denote by
T(H,I)
the set of free-connex tree decompositions of
(H,I)
. The
\EMPH
free-connex treewidth of
(H,I)
is defined as

\operatorname{fc-tw}(H,I)=\min_{T\in T(H,I)}\max_{x\in T}|\operatorname{bag}(x)|-1.

It is well known that every tree, in particular the
(k-1)
-star, has treewidth
1
. In contrast, the free-connex treewidth can be much larger:

Proposition 57.

Consider the projected-
(k-1)
-star
H=([k],\,\set{\set{i,k}:i\in[k-1]})
,
I=[k-1]
. Any free-connex tree decomposition of
(H,I)
has a node
y
with
[k]\subseteq\operatorname{bag}(y)
. Hence,
\operatorname{fc-tw}(H,I)=k-1
.

Proof.

Consider a free-connex tree decomposition
T\in T(H,I)
. By definition, it contains a connected subtree
T^{\prime}
such that
\bigcup_{x\in V(T^{\prime})}\operatorname{bag}(x)=I
; in particular,
k\notin\operatorname{bag}(x)
for all nodes
x\in V(T^{\prime})
.
On the other hand, the third property of tree decomposition implies a connected subtree
T^{\prime\prime}
of
T
where
V(T^{\prime\prime})=\set{x:k\in\operatorname{bag}(x)}
. Since
T^{\prime}
and
T^{\prime\prime}
are disjoint subtrees of
T
, there is a node
y\in V(T^{\prime\prime})
that separates the two subtrees.

For each
i\in I
, the second property of tree decompositions implies the existencce of some node
x_{i}
with
\set{i,k}\subseteq\operatorname{bag}(x_{i})
. Note that
x_{i}\in T^{\prime\prime}
, so node
y
separates it from
T^{\prime}
. Since
i\in\bigcup_{x\in V(T^{\prime})}\operatorname{bag}(x)
and
i\in\operatorname{bag}(x_{i})
, we also have
i\in\operatorname{bag}(y)
by the third property of tree decompositions. Moreover, since
y\in V(T^{\prime\prime})
we have
k\in\operatorname{bag}(y)
. Hence,
[k]\subseteq\operatorname{bag}(y)
.
∎

The
(H,I)
-enumeration algorithm from
[
9
]
has preprocessing time
O(n^{\operatorname{fc-tw}(H,I)+1}+m)
and constant delay. By Proposition
57
, on the projected-
(k-1)
-star this algorithm requires preprocessing time
O(n^{k})
, which is the same as the trivial algorithm.

A.2
Free-Connex Submodular Width

Let
H=(V,E)
be a hypergraph. Let
F(H)
be the set of functions
h:2^{V}\to\R^{+}
that satisfy the following properties:

1.

h(\emptyset)=0
.

2.

h(X)\leq h(Y)
for all
X\subseteq Y\subseteq V
.

3.

h(X)+h(Y)\geq h(X\cap Y)+h(X\cup Y)
for all
X,Y\subseteq V
.

4.

h(e)\leq 1
for all
e\in E
.

The
\EMPH
submodular width of
H
is defined as

\operatorname{subw}(H)=\sup_{h\in F(H)}\min_{T\in T(H)}\max_{x\in T}h(\operatorname{bag}(x)).

The
\EMPH
free-connex submodular width of
(H,I)
is the same restricted to free-connex tree decompositions:

\operatorname{fc-subw}(H,I)=\sup_{h\in F(H)}\min_{T\in T(H,I)}\max_{x\in T}h(\operatorname{bag}(x)).

It is known that submodular width is upper bounded by treewidth; see for example
[
46
, Section 3]
. Since the
(k-1)
-star has treewidth
1
, its submodular width is also
1
. In contrast, the free-connex submodular width can be much larger.

Proposition 58.

For the projected-
(k-1)
-star
H=([k],\,\set{\set{i,k}:i\in[k-1]})
,
I=[k-1]
, we have
\operatorname{fc-subw}(H,I)=k-1
.

Proof.

We define a function
h:2^{[k]}\to\R^{+}
by
h(X):=|X\setminus\set{k}|
. Clearly
h
satisfies properties (i) and (ii). It satisfies (iii) since
h(X)+h(Y)=|X\setminus\set{k}|+|Y\setminus\set{k}|=|(X\cup Y)\setminus\set{k}|+|(X\cap Y)\setminus\set{k}|=h(X\cup Y)+h(X\cap Y)
. It satisfies (iv) since for every edge
e=\set{i,k}
, we have
h(e)=1
. Therefore,
h\in F(H)
.

For any
T\in T(H,I)
, there exists a node
y\in T
such that
[k]\subseteq\operatorname{bag}(y)
by Proposition
57
. In particular, we have
h(\operatorname{bag}(y))\geq k-1
, which witnesses that
\operatorname{fc-subw}(H,I)\geq k-1
.
∎

The PANDA algorithm
[
41
,
42
]
for
(H,I)
-listing runs in time
\Otilde(t+m^{\operatorname{fc-subw}(H,I)})
. (The authors called the parameter submodular width and denoted it by
\operatorname{subw}
, but in fact they refer to the free-connex submodular width as clarified in
[
42
]
.) By Proposition
58
, on the projected-
(k-1)
-star this algorithm takes time
\Otilde(t+m^{k-1})=\Otilde(m^{k-1})
, which is the same as the trivial algorithm.
