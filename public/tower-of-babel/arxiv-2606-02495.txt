Construction of Lyapunov Functions for Switched Systems using Meshfree Collocation
Jay Ward 1 , Nicos Georgiou 1 and Peter Giesl 1

Abstract
. Switched systems are a family of dynamical systems where a switching rule indicates which system is “switched on” . This rule can be dependent on time and/or position in the state space. Stability of switched systems is a property that is often investigated using the existence of one (or multiple) Lyapunov function(s). We develop an algorithm using a scattered approximation method to construct a Lyapunov function for switched systems, accompanied with stability results. The construction adapts a previous method for autonomous ODEs that uses meshfree collocation and quadratic programming.

1.
Introduction

Lyapunov functions characterise the behaviour of a dynamical system. Expressing a dynamical system as a system of differential equations, a (strict) Lyapunov function is a function that decreases along solutions of this system. For a smooth function this is equivalent to it having a negative orbital derivative. Existence of a Lyapunov function implies stability and attractivity of an equilibrium and, moreover, determines the basin of attraction through sublevel sets. For relevant definitions and results see
7
,
16
and
9
.

It is therefore a useful endeavour to investigate methods of obtaining a Lyapunov function.
3
introduced a meshfree collocation method to construct Lyapunov functions for autonomous ODEs with equilibrium at the origin by approximating a solution to the PDE
DV(\mathbf{x})=-\|\mathbf{x}\|^{2}
;
D
represents the orbital derivative. In this method, a finitely many collocation points are selected and the goal is to find the norm-minimal function such that the PDE is satisfied at these points. The advantages of this method are numerous (
4
,
2
): scattered points can be added, no triangulation of the state space is needed, the approximating function is smooth, the method works in any dimension and the resulting interpolation problem is uniquely solvable when expressed in terms of radial basis functions.
2
extended this approach using quadratic programming to find an approximation that satisfies a system of partial differential inequalities, i.e.
DV(\mathbf{x})\leq{0}
.

We further generalize the method to address switched systems, an important class of dynamical systems where discrete switching events occur between continuous-time systems. These systems arise in a wide range of applications in sciences, engineering and economics, e.g. modeling cellular processes, air traffic control transitions, or thermostat regulation. We define a construction method for a Lyapunov function of a switched system with time- and state-dependent switching using meshfree collocation and quadratic programming.

Section
2
reviews types of switched systems and existing construction methods. Section
3
defines a switched system and its Lyapunov function, and presents our construction method, summarised in Algorithm
1
. Theorem
3.1
links Lyapunov functions to asymptotic stability, while Theorem
3.4
confirms that our function satisfies the Lyapunov conditions. Section
4
shows examples using Algorithm

for three systems.

2.
Switched systems

A switched system is a family of dynamical systems where the system that describes the dynamics changes with time and/or the position in the state space.
A system where time-dependent uncontrolled switching takes place is referred to as an arbitrary switched system, and a system with state-dependent switching is referred to as a variable structure system. An overview of both can be found in
11
. Results for arbitrary switched systems can be found in
5
, where Lyapunov’s direct method was generalised.

We consider switched systems that allow for both time- and state-dependent switching. Systems will be defined on subsets of the state space, with the union of these subsets making up the whole state space.
The subsets may overlap; wherever this occurs, the system may switch arbitrarily to a different evolution.
In
11
, stability conditions for such a system are described. It states that these conditions are achieved if a Lyapunov function exists for each system in the subset where it is defined. This means that multiple Lyapunov functions can be considered. The method used to prove stability for a similar switched system found in
8
also uses multiple Lyapunov functions; solution trajectories are described as a sequence of switching times paired with the index of the system that is being switched to. The switched system is then stable if there exist functions that decrease wherever their respective system is
“switched on”
.

The method in
5
constructs Lyapunov functions for arbitrary switched systems, with an extension to a variable structure example. In
6
, differential inclusions are used to construct Lyapunov functions for variable structure systems.

3.
Construction using Quadratic programming

Let

(1)

A Lyapunov function of the switched system (

This can be shown using methods similar to classical Lyapunov proofs that can be found in

3.2.
Reproducing Kernel Hilbert Spaces

We construct a function
v
as a solution of the minimisation problem (
8

\Phi:\Omega\times\Omega\rightarrow{\mathbb{R}}

Definition 3.2
.

(Reproducing Kernel Hilbert Space (RKHS))

Let
\Omega\subseteq{\mathbb{R}}^{d}
. A Hilbert space
H=H(\Omega)
of continuous functions
f:\Omega\rightarrow{\mathbb{R}}
with inner product
\langle\cdot,\cdot\rangle_{H}
is called a reproducing kernel Hilbert space, abbreviated RKHS, if there is a function
\Phi:\Omega\times\Omega\rightarrow{\mathbb{R}}
with

(1)

\Phi(\cdot,\mathbf{x})\in{H}
for all
{\mathbf{x}\in\Omega}

(2)

g(\mathbf{x})=\langle{g(\cdot),\Phi(\cdot,\mathbf{x})}\rangle_{H}
for all
g\in{H}
and all
\mathbf{x}\in\Omega
.

The function
\Phi
is called the reproducing kernel of
H
. The reproducing kernel is called positive definite, if for any pair of pairwise distinct points
\{x_{1},...,x_{N}\}\subseteq\Omega
the matrix
(\Phi(x_{i},x_{j}))_{i,j=1,...,N}
is positive definite.

In our case, the reproducing kernel is given by a radial basis function
\Psi_{0}
through
\Phi(\mathbf{x},\mathbf{y}):=\Psi_{0}(\|\mathbf{x}-\mathbf{y}\|_{2})
. We choose this radial basis function to be a Wendland function
\phi_{\ell,k}(cr)
(
13
;
14
) where
c>0
,
k\in{\mathbb{N}}
is a smoothness parameter and
\ell=\lfloor\frac{d}{2}\rfloor+k+1
. These are smooth functions with compact support, which are polynomials on their support. We can then define recursively
\Psi_{i}(r)=\frac{1}{r}\frac{d\Psi_{i-1}(r)}{dr}
for
i=1,2
and
r>0
. Note that
\lim_{r\rightarrow{0}}\Psi_{i}(r)
exists if the smoothness parameter
k
of the Wendland function is sufficiently large.

3.3.
Minimisation problem

Using this set-up, we will construct a Lyapunov function for our switched system using quadratic programming, as done for autonomous ODEs in
2
. There they construct a Lyapunov function for a single system by finding a solution to the system of partial differential inequalities
DV(\mathbf{x})\leq{r}(\mathbf{x})
where
D
denotes the orbital derivative, and
r(\mathbf{x})
is negative. This method can be generalised in order to construct a Lyapunov function for a switched system. We define for all
\theta=1\dots,\Theta
and
i=1,\dots,{\mathcal{P}}^{\theta}
the linear differential operator

(4)

D_{p_{i}^{\theta}}V(\mathbf{x}):=\nabla{V}(\mathbf{x})\cdot\mathbf{f}_{p_{i}^{\theta}}(\mathbf{x})\text{ }\forall\mathbf{x}\in\Omega^{P^{\theta}}.

Our system of partial differential inequalities is then written as

(5)

D_{p_{i}^{\theta}}V(\mathbf{x})\leq{b_{p_{i}^{\theta}}}(\mathbf{x})

where
b_{p_{i}^{\theta}}(\mathbf{x})
is negative for all
\mathbf{x}\in\Omega^{P^{\theta}}\setminus{\{\mathbf{0}\}}
,
b_{p_{i}^{\theta}}(\mathbf{0})=0
. Finding a function that satisfies these inequalities is then equivalent to finding a Lyapunov function as in (
2
).

We now discretise our problem by choosing collocation points

\mathbf{x}^{1,\theta},\dots,\mathbf{x}^{N^{\theta},\theta}\in\Omega^{P^{\theta}}

and values

b_{i}^{1,\theta}=b_{p_{i}^{\theta}}(\mathbf{x}^{1,\theta}),\dots,b_{i}^{N^{\theta},\theta}=b_{p_{i}^{\theta}}(\mathbf{x}^{N^{\theta},\theta})\in{\mathbb{R}}_{0}^{+}.

We seek to find a function
v
that satisfies

(6)

D_{p_{i}^{\theta}}v(\mathbf{x}^{\ell,\theta})\leq b_{i}^{\ell,\theta}\text{ for all }\ell=1,\dots,N^{\theta}

for
\theta=1,\dots,\Theta
and
i=1,\dots,{\mathcal{P}}^{\theta}
, where
N^{\theta}
is the number of collocation points chosen in the subset
\Omega^{P^{\theta}}
.

Another way to write this that is more suitable for our purpose would be to say we look to find an appropriate function
v\in{H}
using the information
b_{i}^{\ell,\theta}\in{\mathbb{R}}
given by the functionals
\lambda_{i}^{\ell,\theta}\in{H}^{*}
, i.e.
\lambda_{i}^{\ell,\theta}(v)\leq b_{i}^{\ell,\theta}
for all
\theta=1,\dots,\Theta
,
i=1,\dots,{\mathcal{P}}^{\theta}
and
\ell=1,\dots,N^{\theta}
. These functionals are defined as our differential operator (
4

(7)

(\lambda_{i}^{\ell,\theta})v(\cdot):=(\delta_{\mathbf{x}^{\ell,\theta}}\circ{D_{p_{i}^{\theta}}})v(\cdot)=\nabla{v}(\mathbf{x}^{\ell,\theta})\cdot\mathbf{f}_{p_{i}^{\theta}}(\mathbf{x}^{\ell,\theta})

for all
\theta=1,\dots,\Theta
,
\ell=1,\dots,N^{\theta}
and
i=1,\dots,{\mathcal{P}}^{\theta}
, with
\delta
being Dirac’s delta distribution. Note that the elements of the set
P^{\theta}
will be reordered for each collocation point in the following section when we select a basis of the functions
\mathbf{f}_{i}
at this point, see (
9

The optimal reconstruction of

is given by the solution of the problem

(8)

\min\{\|v\|_{H}:v\in{H}\text{, }\lambda_{i}^{\ell,\theta}(v)\leq b_{i}^{\ell,\theta}\text{ for all }\theta=1,\dots,\Theta\text{, }\ell=1,\dots,N^{\theta}\text{ and }i=1,\dots,{\mathcal{P}}^{\theta}\}

It can be shown that this problem has at most one solution, using a similar proof to that of Lemma 5.1 in

3.4.
Selection of Basis

If the functionals are linearly independent, we can use techniques from

Lemma 3.3

Proof.

are determined by the solution of the problem (
14
).

Proof.

Define
v
by (
13
) where the coefficients are determined by (
14
) (see Lemma
3.3
). Let
s\in{H}
be any function satisfying the constraints of the minimisation problem (
8
). We wish to show that
\|v\|_{H}\leq\|s\|_{H}
. We know that
s
satisfies

(18)

\lambda_{i}^{\ell,\theta}(s)=:r_{i}^{\ell,\theta}\leq b_{i}^{\ell,\theta}

for all
\theta=1,\dots,\Theta
,
\ell=1,\dots,N^{\theta}
and
i=1,\dots,{\mathcal{P}}^{\theta}
. For the rest of the lemma we set elements of
\mathbf{r}
to be
r_{i}^{\ell,\theta}
for
i=1,\dots,\rho^{\ell,\theta}
, and elements of
\tilde{\mathbf{r}}
to be
r_{s+\rho^{\ell,\theta}}^{\ell,\theta}
for
s=1,\dots,{\mathcal{P}}^{\theta}-\rho^{\ell,\theta}
.

Consider the new minimisation problem

\begin{cases}\text{\rm{minimise }}\|v\|_{H}\\
\text{\rm{subject to }}\lambda_{i}^{\ell,\theta}(v)=r_{i}^{\ell,\theta}\text{, }\forall\theta=1,\dots,\Theta\text{, }\ell=1,\dots,N^{\theta}\\
\phantom{ccccccccccccccccccccccccc}\text{ and }i=1,\dots,\rho^{\ell,\theta}\end{cases}

Now using Theorem 16.1 from
15
we can see that the solution of this problem is given by

\tilde{s}(\mathbf{x})=\sum_{\theta=1}^{\Theta}\sum_{\ell=1}^{N^{\theta}}\sum_{i=1}^{\rho^{\ell,\theta}}\tilde{\beta}_{i}^{\ell,\theta}(\lambda_{i}^{\ell,\theta})^{\mathbf{y}}\Phi(\cdot,\mathbf{y})

where
A\tilde{\beta}=\mathbf{r}
,
A
has entries (
15
), and
\tilde{\beta}
has the same structure as
\beta
from (
14
). We will show that these
\tilde{\beta}
satisfy
\tilde{Q}A\tilde{\beta}=\tilde{\mathbf{r}}
, which is equivalent to showing that
\tilde{Q}\mathbf{r}=\tilde{\mathbf{r}}
. Indeed, using (
10
) we can rewrite the equations in (
18
) for
\sigma=\rho^{\ell,\theta}+1,\dots,{\mathcal{P}}^{\theta}
as

\sum_{i=1}^{\rho^{\ell,\theta}}\alpha_{\sigma,i}^{\ell,\theta}\lambda_{i}^{\ell,\theta}(s)=r_{\sigma}^{\ell,\theta}\Rightarrow\sum_{i=1}^{\rho^{\ell,\theta}}\alpha_{\sigma,i}^{\ell,\theta}r_{i}^{\ell,\theta}=r_{\sigma}^{\ell,\theta}\Rightarrow\tilde{Q}\mathbf{r}=\tilde{\mathbf{r}}

using the definition of the elements of
\tilde{Q}
. Therefore
\tilde{s}
is also the minimiser for the problem

\begin{cases}\text{\rm{minimise }}\|v\|_{H}\\
\text{\rm{subject to }}\lambda_{i}^{\ell,\theta}(v)=r_{i}^{\ell,\theta}\text{, }\forall\theta=1,\dots,\Theta\text{, }\ell=1,\dots,N^{\theta}\\
\phantom{ccccccccccccccccccccccccc}\text{ and }i=1,\dots,{\mathcal{P}}^{\theta}\end{cases}

which shows that
\|\tilde{s}\|_{H}\leq\|s\|_{H}
.

Now both
v
and
\tilde{s}
are of the form (
13
) and the coefficients
\beta
and
\tilde{\beta}
both satisfy the constraints of problem (

). However, the coefficients
\beta
of

\beta^{T}A\beta=\|v\|_{H}^{2}
so that
\|v\|_{H}^{2}\leq\|\tilde{s}\|_{H}^{2}=\tilde{\beta}^{T}A\tilde{\beta}
. Therefore altogether we have that

\|v\|_{H}\leq\|\tilde{s}\|_{H}\leq\|s\|_{H}.

Since the minimiser is unique (see statement after (
8
)),

v
is the minimiser.
∎

This means that the function

from (

5.
Conclusion

This paper presents a new method for the construction of a Lyapunov function for switched systems. The method is applicable to both arbitrary switched and variable structure systems, as well as systems that employ both time- and state-dependent switching. We have shown that the existence of a Lyapunov function implies that the origin is an asymptotically stable equilibrium point of the switched system. An algorithm to construct a Lyapunov function is presented which finds an approximate solution to a system of partial differential inequalities using meshfree collocation and quadratic programming.

Future work (
12
) will prove the existence of
a Lyapunov function, and therefore the feasibility of problem (
14
).
Moreover, we will study the convergence of the algorithm presented in this paper, i.e. we will show that the sequence of functions
v_{n}
strongly converges to a solution
V
of the original system of partial differential inequalities (
5
). Here,
v_{n}
is the solution of the discretised problem with
N_{n}
collocation points, such that the appropriate fill distances converge to zero.
