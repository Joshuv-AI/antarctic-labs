PyEncode: An Open-Source Library for Structured Quantum State Preparation
Krishnan Suresh, Sanjay Suresh

Abstract
Quantum algorithms require encoding classical vectors as quantum states, a step known as amplitude encoding. General-purpose state preparation routines accept any input vector of length N = 2 m N=2^{m} and produce circuits with 𝒪 ⁡ ( 2 m ) \mathcal{O}(2^{m}) gates. However, vectors arising in scientific and engineering applications often exhibit mathematical structure that admits far more efficient encoding. Recent theoretical work has established closed-form circuits for several structured vector classes, but without open-source implementations. We present PyEncode , an open-source Python library that implements this body of theory in a unified, immediately deployable framework. The library covers sparse, step, square (general interval), Walsh, geometric, and Fourier patterns, and supports weighted superpositions of pattern states via the linear combination of unitaries (LCU) protocol, enabling exact preparation of piecewise-structured vectors such as multi-interval Hamiltonians. PyEncode exposes a single function encode(VectorObj, N) that maps a typed parameter declaration directly to a verified Qiskit circuit, with no vector materialization and no approximation. Sparse, step, and Walsh vectors require only 𝒪 ⁡ ( m ) \mathcal{O}(m) gates; geometric (exponential-decay) vectors require 𝒪 ⁡ ( m ) \mathcal{O}(m) gates with zero two-qubit gates; square (general interval) vectors require 𝒪 ⁡ ( m 2 ) \mathcal{O}(m^{2}) gates via a QFT-based constant adder, with 𝒪 ⁡ ( m ) \mathcal{O}(m) special cases; Fourier (sinusoidal) vectors require 𝒪 ⁡ ( m 2 ) \mathcal{O}(m^{2}) gates via the inverse Quantum Fourier Transform — all exponentially fewer than the 𝒪 ⁡ ( 2 m ) \mathcal{O}(2^{m}) cost of general state preparation. LCU combines r r component circuits whose total gate cost is the sum of individual component costs, with success probability p ∈ ( 0 , 1 ] p\in(0,1] determined analytically. The library is available at https://github.com/UW-ERSL/PyEncode .

Prior Work

General-purpose state preparation

The problem of preparing an arbitrary
N=2^{m}
-dimensional quantum
state has been studied extensively.
Shende, Bullock, and Markov
[
23
]
established the

\mathcal{O}(2^{m})
lower bound on gate count and gave an explicit
constructive procedure.
Araujo et al.
[
2
]
reduce circuit depth to

\mathcal{O}(\log^{2}N)
via a divide-and-conquer strategy, at the cost
of
\mathcal{O}(N)
ancilla qubits.
Gui et al.
[
11
]
propose a deterministic

\mathcal{O}(\log N)
-depth protocol with optimal spacetime allocation

\mathcal{O}(N)
.
All of these methods treat the input vector as an opaque array and
do not exploit any structure in the amplitudes.

Approximate state preparation

Several methods achieve sub-exponential complexity by allowing a
controlled approximation error.
Welch et al.
[
27
]
established the connection between Walsh
functions and diagonal unitary circuits, showing that truncated
Walsh–Fourier series yield approximately minimal-depth circuits.
Holmes and Matsuura
[
14
]
showed that smooth, differentiable
functions admit linear-depth circuits via matrix product state (MPS)
approximations.
O’Brien and Sünderhauf
[
22
]
achieve efficient approximate
state preparation for piecewise-defined functions — whose amplitudes are
well approximated by piecewise polynomials — via quantum singular value
transformation (QSVT).
Marin-Sanchez et al.
[
17
]
reduce the
Gröver–Rudolph circuit complexity from
\mathcal{O}(2^{n})
to

\mathcal{O}(2^{k_{0}(\epsilon)})
for smooth, real-valued functions.
Zylberman and Debbasch
[
29
]
introduce the Walsh
Series Loader (WSL), achieving circuit depth
\mathcal{O}(1/\sqrt{\epsilon})

independent of the number of qubits.
All of these methods are approximate, working from either the numerical
vector or a smoothness assumption. PyEncode targets the complementary
regime: vectors whose structure is
declared

a priori
,
for which it produces exact, closed-form circuits with zero approximation
error.

Structure-exploiting state preparation

A smaller body of work exploits specific structural properties to reduce
gate complexity.
Grover and Rudolph
[
10
]
showed that if the
cumulative amplitudes
\sum_{i=0}^{k}f_{i}^{2}
can be computed
efficiently — as they can for any analytically defined vector —
the state can be prepared with
\mathcal{O}(m)
circuit
depth
via
a sequence of controlled
R_{y}
rotations determined by cumulative
integrals.
However, the full binary tree structure means the gate
count

remains
\mathcal{O}(2^{m})
, whereas PyEncode’s synthesizers exploit the algebraic structure
of each pattern directly — such as the binary decomposition
underlying
STEP
— to achieve
\mathcal{O}(\mathrm{poly}(m))

gate count and, for several patterns, depth 1.
Gleinig and Hoefler
[
8
]
give an exact

\mathcal{O}(sm)
-gate algorithm for sparse states with
s

nonzero coefficients.
Shukla and Vedula
[
24
]

derive closed-form circuits for
interval uniform superpositions

— quantum states encoding a uniform amplitude over a contiguous index
range — and establish their
\mathcal{O}(m)
gate complexity using
multi-controlled operations and the binary structure of the interval
endpoints.
PyEncode’s
SQUARE
synthesizer extends this to general intervals

[k_{1},k_{2})
via a Draper QFT-based constant adder
[
6
]
.
PyEncode’s
FOURIER
synthesizer prepares sinusoidal vectors
exactly by loading their DFT coefficients as a
SPARSE
state
and applying the inverse QFT
[
21
]
.

3.6.1
Construction

The product-state structure of geometric sequences is a direct

used as an intermediate construction in prior

Each factor depends on a single bit

|\psi\rangle\propto\bigotimes_{j=0}^{m-1}\bigl(|0\rangle+r^{\,2^{j}}|1\rangle\bigr).

Each qubit

The full circuit is

validated synthesizer, making it immediately composable with
the
LCU

finance, as an exponentially decaying source term in diffusion problems,

3.7
LCU (Linear Combination of Unitaries)

A weighted superposition of
r

|\psi\rangle\propto\sum_{j=1}^{r}w_{j}\,|\hat{f}^{(j)}\rangle,

(10)

where each

is a normalized state prepared by

Constructor:

All weights

Signed weights can be accommodated by absorbing the sign into the

\sum_{j}\beta_{j}|j\rangle_{\text{anc}}

with
\beta_{j}=\sqrt{w_{j}\|f^{(j)}\|}\,/\,Z
.

2.

SELECT
: apply each component circuit

U_{j}
controlled on ancilla state
|j\rangle
.

3.

PREP
†
: apply the inverse
R_{y}
-tree
to uncompute the ancilla.

4.

Post-select
ancilla on
|0\rangle^{\otimes n_{\text{anc}}}
.

The choice
\beta_{j}\propto\sqrt{w_{j}\|f^{(j)}\|}
ensures that the
post-selected data-register state is proportional to

\sum_{j}w_{j}|\hat{f}^{(j)}\rangle
, as required.

3.7.2
Success probability

After PREP
†
, the amplitude in the
|0\rangle_{\text{anc}}

subspace is
\sum_{j}\beta_{j}^{2}\,|\hat{f}^{(j)}\rangle
.
The post-selection succeeds with probability:

p=\left\|\sum_{j}\beta_{j}^{2}\,|\hat{f}^{(j)}\rangle\right\|^{2}=\sum_{i,j}\beta_{i}^{2}\,\beta_{j}^{2}\,\langle\hat{f}^{(i)}|\hat{f}^{(j)}\rangle.

(11)

Since
\sum_{j}\beta_{j}^{2}=1
, the set
\{\beta_{j}^{2}\}
is a probability
distribution over the
r
component states, and

p=\|\text{convex combination of unit vectors}\|^{2}\leq 1
by the
triangle inequality, with equality if and only if all component states
are identical.

3.7.3
Disjoint versus overlapping support

PyEncode detects analytically whether the component vectors have
disjoint support:

•

and
SQUARE

disjointness is checked by interval non-overlap in

\mathcal{O}(r^{2})
time.

•

SPARSE
: support is an index set; disjointness is
checked by set intersection.

•

WALSH
and
FOURIER
: support is always the
full register
[0,N)
— never disjoint with anything.

For disjoint-support components

\langle\hat{f}^{(i)}|\hat{f}^{(j)}\rangle=0
for
i\neq j
,
so (
11
) reduces to
p=\sum_{j}\beta_{j}^{4}
.
For
r

\beta_{j}=1/\sqrt{r}
and

p=r\cdot(1/r)^{2}=1/r
.
For overlapping components, the inner products are positive, so
p

is higher — but a
UserWarning
is issued since the
post-selection overhead is non-trivial and amplitude amplification
may be warranted.

4
Patterns Not Covered and Why

PyEncode produces exact, closed-form circuits for vectors that are either
piecewise constant with
\mathcal{O}(1)
pieces, sparse in the Fourier
basis, or multiplicatively separable over the bits of the index (the

GEOMETRIC
pattern). Four practically important vector types
fall outside this library.
For each, approximate encoding via MPS truncation
[
14
]
or
piecewise-QSVT
[
22
]
provides the natural alternative.

4.1
Ramp (linear)

The vector
f_{i}=i/N
arises as a discretized pressure gradient or
linearly tapered structural load. Although the computational basis
already encodes the index
i
, routing a register value into an
amplitude requires an oracle whose cost is
\mathcal{O}(2^{m})
in the
worst case, and the DFT of the ramp has
N
nonzero coefficients,
ruling out a QFT shortcut.

4.2
Poiseuille (parabolic)

The laminar pipe-flow profile
f_{i}\propto 1-(2i/N-1)^{2}

combines a ramp term and a quadratic term, both of which resist exact
compact encoding. No
\mathcal{O}(\mathrm{poly}(m))
exact circuit is
known for general parabolic profiles.

4.3
Hat (tent) function

The piecewise-linear FEM basis function centered at
i_{0}
with
half-width
h

[
25
]
has linearly graded amplitudes within
its support, inheriting the ramp obstruction on each half. No exact

\mathcal{O}(\mathrm{poly}(m))
circuit is known.

4.4
Gaussian

The vector
f_{i}=\exp(-\alpha(i-i_{0})^{2}/N^{2})
appears as an initial
condition in turbulence simulations and as a probability distribution in
quantum Monte Carlo
[
19
]
. Its DFT is also Gaussian-shaped
with
\mathcal{O}(N)
effectively nonzero coefficients, precluding both
exact encoding and a QFT shortcut.
In contrast, the simple exponential
e^{-\alpha i}
is multiplicatively
separable over the bits of
i
and admits an exact
\mathcal{O}(m)

product-state circuit (Section
3.6
);
Xie and Ben-Ami
[
28
]
exploit this product state
as an intermediate step for approximate Gaussian preparation via a
subsequent QFT. The quadratic
exponent in the Gaussian destroys this separability.
Holmes and Matsuura
[
14
]

showed that smooth functions including the Gaussian admit approximate

\mathcal{O}(\mathrm{poly}(m))
circuits via MPS truncation; this is the
recommended path.

7
Conclusions

PyEncode provides an open-source implementation of theoretical work on
structured quantum state preparation that until now lacked runnable
code. The library exposes a single function
encode(VectorObj, N)

that maps a typed parameter declaration directly to a closed-form Qiskit
circuit, without code parsing and without materializing a classical vector.

The library implements the following pattern synthesizers, each mapping
a typed parameter declaration to an exact, closed-form Qiskit circuit
with no vector materialization:

•

SPARSE
— Gleinig–Hoefler
\mathcal{O}(sm)

sparse state preparation
[
8
]
.

•

STEP
— Shukla–Vedula
\mathcal{O}(m)
prefix
uniform superposition
[
24
]
.

•

SQUARE
— general interval
[k_{1},k_{2})
via

STEP
(w)
composed with a Draper QFT-based constant
adder
[
6
]
;
\mathcal{O}(m^{2})
in general,

\mathcal{O}(m)
for power-of-2-aligned blocks.

•

WALSH
— two-level piecewise-constant state via

R_{y}(\theta)+H^{\otimes m}

[
27
]
, with the
generalized form supporting asymmetric levels
c_{+}\neq-c_{-}
.

•

GEOMETRIC
— exponential decay / geometric sequence

f_{i}=c\,r^{\,i}
as a product state
[
28
]
;

\mathcal{O}(m)
gates, zero two-qubit gates.

•

FOURIER
— exact sinusoidal state preparation via
inverse QFT
[
9
,
20
]
, at

\mathcal{O}(m^{2})
cost independent of the number of modes.

•

LCU
— LCU
[
3
]
for weighted
superpositions of
r
component states, with analytically
computed success probability and automatic disjoint-support
detection.

Several vector types common in practice — ramp, hat, Gaussian —
do not admit exact
\mathcal{O}(\mathrm{poly}(m))
circuits and fall
outside the pattern library; approximate encoding via MPS
truncation
[
14
]
or piecewise-QSVT
[
22
]

is recommended for these cases, and is planned for a future

pyencode.approx
submodule.
In particular, the Walsh Series Loader of Zylberman and
Debbasch
[
29
]
provides a natural foundation for
approximate encoding of smooth functions via truncated
Walsh–Hadamard series, extending the single-term exact construction
already implemented in
WALSH
.

Characterizing which classes of vectors admit
\mathcal{O}(\mathrm{poly}(m))

exact circuits remains an open and potentially rich theoretical question.
The pattern library presented here — six closed-form families and one
composition rule — provides a concrete starting point.
