RooAgent : An LLM Agent for Root -Based High Energy Physics Analysis
Aman Desai

Abstract
We present RooAgent as a natural-language interface for Root -based high energy physics data analysis. The package provides physics analysis functions as tools that an LLM agent invokes in response to plain-language prompts. Two operating modes are supported: a LangGraph -based agent compatible with OpenAI ’s GPT-4.1 via GitHub Copilot and with DeepSeek-V3 via Ollama , and a Model Context Protocol server for use with the Anthropic Claude CLI ( Sonnet 4.6 ). In both modes the analysis logic is implemented in PyRoot and the LLM selects tools and supplies the required arguments. The package supports histogram inspection, event selection, visualisation of kinematic distributions, fitting, and significance estimation, among other tasks. We illustrate RooAgent with tests based on Monte Carlo simulations of p ​ p → Z ​ H pp\to ZH ( Z → ℓ + ​ ℓ − Z\to\ell^{+}\ell^{-} , H → b ​ b ¯ H\to b\bar{b} ), a multi-task signal-background workflow, a toy statistical analysis, and an application to ATLAS open data for H → Z ​ Z ∗ → 4 ​ ℓ H\to ZZ^{*}\to 4\ell . The package is available on PyPI and the source code is hosted at https://github.com/amanmdesai/RooAgent .

3.1
Monte Carlo Sample

Development and testing used two Monte Carlo samples. The signal sample corresponds to
pp\to Z(\to\ell^{+}\ell^{-})H(\to b\bar{b})

[

[

[

[

6
Conclusions

We presented
RooAgent
a natural-language interface that bridges plain-language prompts and
Root
-based HEP analysis through an LLM agent. The package supports two backends—a
LangGraph
-based agent compatible with
OpenAI
’s
GPT-4.1

[
45
]
(via GitHub Copilot
[
28
]
) and
DeepSeek-V3

[
20
]
(via
Ollama

[
44
]
), and an MCP server for the Anthropic
Claude
CLI
[
6
]
—while sharing the same
PyRoot
implementations across both, so switching models requires no changes to the analysis code.

The benchmark tests demonstrated successful completion of a range of tasks, including file inspection, histogram visualisation, event selection, kinematic comparisons, fitting, and significance estimation, across Monte Carlo simulations of
pp\to ZH
(
Z\to\ell^{+}\ell^{-}
,
H\to b\bar{b}
), a multi-task signal-background workflow, a toy statistical analysis, and ATLAS open data for
H\to ZZ^{*}\to 4\ell
. In all cases the LLM handled orchestration and argument selection while the
PyRoot
tools produced the numerical results.

The tool set is modular and can be extended by registering new
PyRoot
functions. Natural directions for future work include LLM-guided identification of optimal event-selection variables, integration of machine learning algorithms as callable tools, and validation on more complex, realistic analysis workflows.
