Nonstationary Generalized Linear Bandits with Discounted Online Mirror Descent
Joongkyu Lee, Min-hwan Oh

Abstract
We study nonstationary generalized linear bandits (GLBs), where the expected reward is modeled through a nonlinear link function with an unknown time-varying parameter. This framework encompasses a broad class of reward models, including linear, Bernoulli, and binomial rewards. Existing approaches are predominantly based on maximum-likelihood estimation (MLE), using sliding-window, restart, or discounting mechanisms to handle nonstationarity. Although these methods achieve statistically efficient regret guarantees, they generally require revisiting past observations at every round, which leads to computation and memory costs that grow with time; moreover, several of them rely on a non-convex projection step. In this paper, we propose DOMD-GLB , a new algorithm for nonstationary GLBs that utilizes discounted online mirror descent (DOMD) for parameter estimation, thereby incurring only 𝒪 ⁡ ( 1 ) \mathcal{O}(1) computation and memory costs per round. We prove dynamic regret bounds of order 𝒪 ~ ( c μ − 1 / 2 d 3 / 4 P T 1 / 4 T 3 / 4 ) \tilde{\mathcal{O}}\big(c_{\mu}^{-1/2}d^{3/4}P_{T}^{1/4}T^{3/4}\big) in drifting environments and 𝒪 ~ ( c μ − 1 / 3 d 2 / 3 Γ T 1 / 3 T 2 / 3 ) \tilde{\mathcal{O}}\big(c_{\mu}^{-1/3}d^{2/3}\Gamma_{T}^{1/3}T^{2/3}\big) in piecewise-stationary environments, where d d denotes the feature dimension, T T the time horizon, P T P_{T} the path length, Γ T \Gamma_{T} the number of change points, and c μ c_{\mu} a curvature parameter associated with the link function, while substantially improving computational efficiency over prior work. To the best of our knowledge, this is the first algorithm for nonstationary GLBs with per-round computation and memory costs independent of time.

To handle nonstationarity, all existing GLB methods rely on MLE-based approaches, including restart
(
37
;
34
)
and weighted (or discounted)
(
23
;
7
;
24
;
32
)
strategies (see Table
1
).
Consequently, each round requires revisiting past observations, so the per-round computation and memory costs of these methods typically grow with
t
, or, for restart-based approaches, with the restart period, which is typically tuned to be of order
\mathcal{O}(T^{2/3})

(
37
)
.
Moreover, several prior works
(
7
;
23
;
32
)
rely on a
non-convex projection step
of the form
\widetilde{\theta}_{t}\in\mathop{\mathrm{argmin}}_{\theta}\bigl\|\sum_{s}(\mu(x_{s}^{\top}\theta)-\mu(x_{s}^{\top}\widehat{\theta}_{t}))x_{s}\bigr\|_{V_{t}^{-1}}
, where
V_{t}\in\mathbb{R}^{d\times d}
is positive definite.
This projection is generally difficult to compute in polynomial time, making it highly desirable to avoid.

On the other hand, recent work on
stationary
GLBs
(
36
)
showed that online mirror descent (OMD) can estimate the model parameter in a
one-pass
manner, without storing past data.
This yields constant per-round computation and memory costs while retaining confidence guarantees comparable to those of statistically efficient MLE-based methods, such as
18
.
This suggests OMD as a natural starting point for developing computationally efficient algorithms for nonstationary GLBs.
This leads to the following question:

Can we design a nonstationary GLB algorithm with constant computation and memory costs?

In this paper, we answer this question affirmatively by proposing
DOMD-GLB
, a discounted OMD (DOMD)-based algorithm that achieves both statistical and computational efficiency.

Technical difficulties.

Establishing this result is nevertheless nontrivial, since the stationary OMD analysis of
36
does not directly extend to the discounted setting.
The first challenge lies in the
mirror-descent geometry
.
In OMD, the choice of Bregman divergence is crucial, since it determines the geometry with respect to which the update is performed.
For stationary GLBs
(
36
)
, the additively accumulated Hessian naturally induces the relevant mirror-descent geometry.
In the nonstationary setting, however, this geometry must account for forgetting: past curvature should be downweighted over time, rather than accumulated uniformly.
Consequently, the stationary geometry cannot be directly applied to the discounted update structure.
As a result, it is not clear
a priori
what the correct discounted analogue of the stationary Bregman divergence should be.
Establishing such a mirror-descent geometry is therefore a central difficulty in extending OMD to nonstationary GLBs.

The second challenge lies in the
concentration analysis
.
The confidence analysis of
36
is based on a
mix-loss
argument
(
29
)
, which constructs a suitable exponentiated stochastic process and shows that it forms a supermartingale, thereby allowing the use of
Ville’s inequality

(
28
)
to derive an anytime concentration bound.
In the discounted setting, however, the corresponding discounted process is generally not a supermartingale, and this argument therefore breaks down.
As a result, a different concentration analysis is required (see Remark
A.1
).

The third challenge is to control the
loss drift
induced by nonstationarity.
In the DOMD confidence analysis, the reference parameter is no longer fixed over time, since the current parameter may differ from the parameters underlying past observations.
This mismatch creates an additional
loss-drift term
that is absent in the stationary setting.
The main difficulty is therefore to isolate and control this term within the DOMD confidence argument.
Unlike prior nonstationary MLE-based analyses (e.g.,
32
), where the effect of parameter drift can be isolated as an explicit additive
parameter-bias term
, DOMD requires controlling the drift in
loss space
, through terms of the form
\ell_{s}(\theta_{t}^{\star})-\ell_{s}(\theta_{s}^{\star})
.
Thus, controlling loss drift requires a separate analysis tailored to the DOMD estimator.

Contributions.
To address these difficulties, we develop a proper discounted mirror-descent geometry (Subsection
4.1
),
a new mix-loss-based analysis tailored to DOMD (Lemma
A.2
),
and a separate loss-drift bound in terms of the nonstationarity measure (Lemma
A.4
).
Together, these yield a high-probability confidence bound for the DOMD estimator (Theorem
1
), which in turn leads to dynamic regret guarantees in both drifting (Theorem
2
) and piecewise-stationary environments (Theorem
3
).
Our contributions are summarized as follows:

•

We propose a DOMD method for parameter estimation in nonstationary generalized linear bandits (GLBs). The resulting update requires only
\mathcal{O}(d^{3})
computation and
\mathcal{O}(d^{2})
memory per round, both independent of the time index
t
(Subsection
4.1
).

•

We establish a new confidence bound for DOMD in nonstationary GLBs by extending the
mix-loss
method
(
29
)
to the discounted recursion and by explicitly controlling the drift terms that arise from nonstationarity (Theorem
1
).

•

In the drifting setting, we prove the dynamic regret bound
\tilde{\mathcal{O}}\big(c_{\mu}^{-1/2}d^{3/4}P_{T}^{1/4}T^{3/4}\big)
, matching the best-known regret order among discounted MLE-based methods
(
32
)
while using a substantially more efficient update (Theorem
2
).

•

In the piecewise-stationary setting, we obtain the regret bound
\tilde{\mathcal{O}}\big(c_{\mu}^{-1/3}d^{2/3}\Gamma_{T}^{1/3}T^{2/3}\big)
, showing that the DOMD framework also provides a strong statistical guarantee when nonstationarity is measured by the number of parameter changes (Theorem
3
).

Nonstationary parametric bandits.

Nonstationary parametric bandits have been studied extensively across linear and generalized linear models

Among restart-based approaches,

.
Although these methods enjoy strong statistical guarantees, they typically require repeated re-optimization over past data, leading to computation and memory costs that grow with time, the window size, or the restart period.
Moreover, some also rely on a non-convex projection step that is generally not computable in polynomial time.

Stationary generalized linear bandits.

The stationary GLB literature has long faced a trade-off between statistical sharpness and computational efficiency.
The pioneering optimism-based algorithm of
8
requires repeated maximum likelihood
estimation (MLE) over the full history,
and its regret scales with the global slope parameter
1/c_{\mu}
, which can be exponentially large in the parameter-norm bound.
Subsequent work has pursued two complementary directions: statistical sharpness and computational efficiency.
On the statistical side, recent MLE-based analyses use self-concordance and local curvature to replace this global dependence with sharper instance-dependent quantities, yielding nearly optimal regret bounds in terms of local parameters such as
\kappa^{\star}

(
18
;
21
;
26
)
.
On the computational side, efficient methods such as
GLOC

(
13
)
use online updates and achieve constant per-round cost, but their regret bounds still depend linearly on
1/c_{\mu}
.
More recently,
36
showed that these two goals can be achieved
simultaneously
, obtaining nearly optimal regret while maintaining fully online updates with constant time and memory per round.

OMD in bandits and reinforcement learning.

Online mirror descent (OMD) has recently emerged as a useful tool for designing jointly efficient bandit algorithms, replacing repeated batch MLE by one-pass updates whose per-round cost remains independent of time.
In logistic bandits,
6
;
35
developed computationally efficient UCB-type algorithms based on OMD.
This approach has since been extended to broader settings, including multinomial logit (MNL) bandits
(
14
;
16

and GLBs
(
36
)
.
Related OMD-style ideas have also been explored in other online decision-making problems, including heavy-tailed linear bandits

[T]:=\{1,\dots,T\}
.

A\succeq B

3.1
Nonstationary Generalized Linear Bandit

We consider a
T
-round contextual bandit problem.
At each round
t\in[T]
, the learner observes a feasible action set
\mathcal{X}_{t}\subset\mathbb{R}^{d}
, chooses an action
x_{t}\in\mathcal{X}_{t}
, and then receives a stochastic reward
r_{t}\in\mathbb{R}
. The environment is governed by an unknown time-varying parameter sequence
\{\theta_{t}^{\star}\}_{t=1}^{\infty}
.
Conditioned on the chosen action
x_{t}
, the reward follows a canonical exponential-family distribution whose natural parameter is given by the linear predictor
x_{t}^{\top}\theta_{t}^{\star}
, i.e.,

\text{Pr}\left[r_{t}|x_{t},\theta_{t}^{\star}\right]=\exp\!\left(\frac{r_{t}x_{t}^{\top}\theta_{t}^{\star}-m(x_{t}^{\top}\theta_{t}^{\star})}{g(\tau)}+h(r_{t},\tau)\right),

where
m:\mathbb{R}\to\mathbb{R}
is convex and three times continuously differentiable,
g(\tau)>0
is a known dispersion term that controls the variability of the distribution, and
h(\cdot,\tau)
is the base measure.
Let

\mu(z):=m^{\prime}(z)
.
Then the conditional mean satisfies

\mathbb{E}[r_{t}|x_{t},\theta_{t}^{\star}]=\mu(x_{t}^{\top}\theta_{t}^{\star})
(Proposition 3.1 of
30
).
We assume that the parameter path
\{\theta_{t}^{\star}\}_{t\geq 1}
is fixed independently of the reward noise process, following the standard exogenous-drift formulation in the nonstationary bandit literature
(
2
;
25
;
24
;
37
;
32
)
.

We make the following standard assumptions used in GLBs
(
8
)
:

Assumption 1

(Boundedness)
.

For all
t\geq 1
, we assume
\theta_{t}^{\star}\in\Theta:=\{\theta\in\mathbb{R}^{d}:\|\theta\|_{2}\leq S\}
,

\|x\|_{2}\leq 1
for all
x\in\mathcal{X}_{t}
,
and

r_{t}\in[0,R]
almost surely for some known
R\in\mathbb{R}
.

Assumption 2

(Bounded link function)
.

The link function
\mu
is twice differentiable over its feasible domain. Moreover, there exist constants
c_{\mu},k_{\mu}>0
such that
c_{\mu}\leq\mu^{\prime}(z)\leq k_{\mu}
for all
z\in[-S,S]
.
Consequently, the function
m
is strictly convex and
\mu
is strictly increasing.

Proposition 1

(Self-concordance, Lemma 2.2 of
26
)
.

For any GLM supported on
[0,R]
almost surely, the link function
\mu(\cdot)
satisfies
|\mu^{\prime\prime}(z)|\leq R\cdot\mu^{\prime}(z)
for all
z\in\mathbb{R}
.

Therefore, under the bounded rewards in Assumption
1
, self-concordance is automatically satisfied.
As a result, in previous works such as
(
24
;
32
)
, the self-concordance assumption is in fact redundant, since bounded rewards are already imposed.
More importantly, this induced self-concordant property is essential for obtaining regret bounds with improved dependence on
1/c_{\mu}
, which can be exponentially large in the parameter-norm bound, i.e.,
1/c_{\mu}=\mathcal{O}(e^{S})
.

In this paper, we consider two standard forms of nonstationarity.

Setting 1: Drifting environment.

The environment exhibits gradual drift over time, and nonstationarity is measured by the path length

P_{T}:=\sum_{t=1}^{T-1}\|\theta_{t+1}^{\star}-\theta_{t}^{\star}\|_{2},

which quantifies the cumulative variation of the underlying parameter sequence.

Setting 2: Piecewise-stationary environment.

The environment is piecewise stationary over time, and nonstationarity is measured by the number of parameter changes

\Gamma_{T}:=\sum_{t=1}^{T-1}\mathbbm{1}\!\left\{\theta_{t+1}^{\star}\neq\theta_{t}^{\star}\right\},

which counts how many times the underlying parameter changes over the horizon.

Our goal is to minimize the cumulative
dynamic (pseudo) regret
:

\displaystyle\textup{{Reg}}_{T}:=\sum_{t=1}^{T}\left(\mu((x_{t}^{\star})^{\top}\theta_{t}^{\star})-\mu(x_{t}^{\top}\theta_{t}^{\star})\right),\qquad\text{where}\quad x_{t}^{\star}\in\mathop{\mathrm{argmax}}_{x\in\mathcal{X}_{t}}\mu(x^{\top}\theta_{t}^{\star})=\mathop{\mathrm{argmax}}_{x\in\mathcal{X}_{t}}x^{\top}\theta_{t}^{\star}.

Algorithm and Main Results

In this section, we first introduce a DOMD method (Subsection
4.1
), then present the OMD-based nonstationary GLB algorithm
DOMD-GLB
(Subsection
4.2
), and finally establish dynamic regret guarantees for both drifting (Subsection
4.3
) and piecewise-stationary (Subsection
4.4
) settings.

4.1
Discounted Online Mirror Descent

We estimate the current parameter via
discounted online mirror descent
(DOMD).
For each round
t
, we define the loss function as the negative log-likelihood

\ell_{t}(\theta):=\left(m(x_{t}^{\top}\theta)-r_{t}x_{t}^{\top}\theta\right)/g(\tau).

Given the current iterate
\theta_{t}
, we use the local quadratic surrogate

\widetilde{\ell}_{t}(\theta):=\ell_{t}(\theta_{t})+\langle\nabla\ell_{t}(\theta_{t}),\,\theta-\theta_{t}\rangle+\frac{1}{2}\|\theta-\theta_{t}\|_{\nabla^{2}\ell_{t}(\theta_{t})}^{2}.

Let

H_{t}=\lambda I_{d}+\sum_{s=1}^{t-1}\gamma^{t-1-s}\nabla^{2}\ell_{s}(\theta_{s+1})
,
and
A_{t}:=\gamma H_{t}+(1-\gamma)\lambda I_{d},

where
\gamma\in(0,1)
is the discount factor.
At each round
t
, we update the parameter via:

\theta_{t+1}\in\mathop{\mathrm{argmin}}_{\theta\in\Theta}\left\{\widetilde{\ell}_{t}(\theta)+\frac{1}{2\eta}\|\theta-\theta_{t}\|_{A_{t}}^{2}\right\},\qquad\text{where}\,\,\eta:=1+RS,

(1)

and subsequently update the curvature matrix via

H_{t+1}=A_{t}+\nabla^{2}\ell_{t}(\theta_{t+1})=A_{t}+\frac{\mu^{\prime}(x_{t}^{\top}\theta_{t+1})}{g(\tau)}x_{t}x_{t}^{\top}.

Role of the surrogate loss.

The surrogate loss
\widetilde{\ell}_{t}(\theta)
plays a central role in balancing statistical efficiency and computational efficiency.
Unlike a purely first-order linearization,
\widetilde{\ell}_{t}(\theta)
retains the local curvature of the current loss through
\nabla^{2}\ell_{t}(\theta_{t})
, which is important for capturing the nonlinear geometry of the GLM.
At the same time, it converts the round-
t
update into a quadratic optimization problem.
Indeed, after removing terms independent of
\theta
, (
1
) is equivalent to

\theta_{t+1}\in\mathop{\mathrm{argmin}}_{\theta\in\Theta}\left\{\left\langle\nabla\ell_{t}(\theta_{t}),\,\theta-\theta_{t}\right\rangle+\frac{1}{2}\|\theta-\theta_{t}\|_{\nabla^{2}\ell_{t}(\theta_{t})+\eta^{-1}A_{t}}^{2}\right\}.

Thus, the algorithm preserves second-order information from the current sample while avoiding the need to solve a global weighted MLE problem over the entire historical dataset.

Discounted curvature versus stationary curvature.

To highlight the role of discounting, consider the curvature matrix that would arise in a stationary environment,

H_{t}^{\mathrm{stat}}:=\lambda I_{d}+\sum_{s=1}^{t-1}\nabla^{2}\ell_{s}(\theta_{s+1})
(e.g.,
36
).
In the stationary case, such an undiscounted accumulation is natural, since all past observations are generated under the same underlying parameter and should contribute equally to the local geometry.
In contrast, in a nonstationary environment, old observations are collected under outdated parameters and should therefore have progressively less influence on the current update.
For this reason, we use the discounted curvature matrix
H_{t}=\lambda I_{d}+\sum_{s=1}^{t-1}\gamma^{t-1-s}\nabla^{2}\ell_{s}(\theta_{s+1})
,
which exponentially downweights stale curvature information.
This discounting allows the estimator to adapt to drift while still retaining enough historical curvature to stabilize estimation.

Why
A_{t}
instead of
H_{t}
?

A further distinction, specific to the discounted setting, is that the update rule in (
1
) uses
A_{t}
, not
H_{t}
, in the proximal geometry.
This is important.
The matrix
H_{t}
is the
post-round-
(t-1)
discounted curvature matrix, whereas the actual geometry needed for the round-
t
update is the
pre-update
matrix

A_{t}=\gamma H_{t}+(1-\gamma)\lambda I_{d}=\lambda I_{d}+\sum_{s=1}^{t-1}\gamma^{t-s}\nabla^{2}\ell_{s}(\theta_{s+1}).

Hence,
A_{t}
is exactly the one-step-aged version of
H_{t}
: every past curvature contribution receives one additional factor of
\gamma
before the new sample is incorporated.
This is the correct geometry at round
t
, since historical information from round
s
should enter the round-
t
update with weight
\gamma^{t-s}
, not
\gamma^{t-1-s}
.

Remark 1

(Constant computation and memory costs)
.

The DOMD update has a recursive form: it depends only on the current sample, the current estimate
\theta_{t}
, and the maintained curvature matrix
H_{t}
.
Thus, it can be implemented without storing or revisiting past observations, requiring only
\mathcal{O}(d^{2})
memory and
\mathcal{O}(d^{3})
computation per round, both independent of
t
.
By contrast, window-based methods
(
23
)
must store and process a window of past observations, so their costs scale with the window size
\tau=\mathcal{O}(T^{2/3})
.
Weighted MLE-based methods
(
24
;
32
)
similarly revisit past weighted observations, leading to costs that grow with
t
.

Theorem 1

(Discounted-OMD confidence bound)
.

Let

\eta=1+RS
,

\alpha=\frac{3\eta}{2}
and

\iota=\sqrt{\frac{2\eta k_{\mu}}{g(\tau)}}.

Suppose

\lambda\geq\max\left\{\frac{6\eta Rk_{\mu}S}{g(\tau)},\frac{32\alpha dR^{2}}{7}\right\}.

For each
t\geq 2
, define the confidence set

\mathcal{C}_{t}(\delta):=\left\{\theta\in\mathbb{R}^{d}\mid\|\theta-\theta_{t}\|_{H_{t}}\leq\beta_{t}(\delta)+\iota\mathcal{V}_{t}\right\},

where

\mathcal{V}_{t}:=\sum_{p=1}^{t-1}\gamma^{(t-1-p)/2}\sqrt{\frac{1-\gamma^{p}}{1-\gamma}}\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}
,
and

Discussion of Theorem
1
.

Theorem
1
shows that one can construct an ellipsoidal confidence set
\mathcal{C}_{t}(\delta)
around the DOMD iterate
\theta_{t}
that is both
statistically efficient
, in the sense that the radius has no explicit
1/c_{\mu}
dependence, and
computationally efficient
, with constant per-round computation and storage costs.
In contrast to non-discounted OMD
(
36
)
, which treats all past observations equally and is therefore better suited to stationary environments, our confidence bound explicitly incorporates forgetting through the discounted matrix
H_{t}
and the drift term
\mathcal{V}_{t}
.
As a result, stale data are progressively downweighted, so the confidence set tracks the current parameter more accurately in nonstationary environments.
The proof is deferred to Appendix

.

Proof sketch of Theorem
1
.

We provide a proof sketch and highlight the technical novelties.

1) Reduction to discounted inverse regret.

We first upper bound the estimation error of
\theta_{t}
as:

\displaystyle\|\theta_{t}-\theta_{t}^{\star}\|_{H_{t}}^{2}

\displaystyle\leq 4\lambda S^{2}+2\eta\underbrace{\sum_{s=1}^{t-1}\gamma^{t-1-s}\bigl(\ell_{s}(\theta_{t}^{\star})-\ell_{s}(\theta_{s+1})\bigr)}_{\text{discounted inverse-regret}}-\frac{2}{3}\sum_{s=1}^{t-1}\gamma^{t-1-s}\|\theta_{s+1}-\theta_{s}\|_{A_{s}}^{2}.

(2)

Note that the last term on the right-hand side is measured in the
A_{s}
-norm because the DOMD update uses the pre-update geometry
A_{s}
, whereas the left-hand side is measured in the post-update matrix
H_{t}
.
This geometric mismatch is specific to the discounted setting and is absent in the stationary OMD analysis
(
35
;
14
;
16
;
36
)
.

2) Decomposition of discounted inverse regret.

To analyze the discounted inverse-regret,
we introduce the mix loss

m_{s}(\Pi_{s})\!:=\!-\log\mathbb{E}_{\theta\sim\Pi_{s}}\!\left[e^{-\ell_{s}(\theta)}\right]
,
where

\Pi_{s}\!:=\!\mathcal{N}(\theta_{s},\alpha A_{s}^{-1})
.
Then, we have

\displaystyle\sum_{s=1}^{t-1}\!\gamma^{t-1-s}\bigl(\ell_{s}(\theta_{t}^{\star})-\ell_{s}(\theta_{s+1})\bigr)

\displaystyle\!=\underbrace{\sum_{s=1}^{t-1}\!\gamma^{t-1-s}\bigl(\ell_{s}(\theta_{s}^{\star})-m_{s}(\Pi_{s})\bigr)}_{\text{concentration term}}\!+\!\sum_{s=1}^{t-1}\!\gamma^{t-1-s}\bigl(m_{s}(\Pi_{s})-\ell_{s}(\theta_{s+1})\bigr)\!+\!\underbrace{\sum_{s=1}^{t-1}\!\gamma^{t-1-s}\bigl(\ell_{s}(\theta_{t}^{\star})-\ell_{s}(\theta_{s}^{\star})\bigr)}_{\text{loss-drift term}}.

Unlike the stationary setting of
36
, our decomposition contains an additional
loss-drift
term due to the time-varying comparator
\theta_{t}^{\star}
.
The middle term is controlled by Lemma
A.3
, which yields a discounted log-determinant term and a movement term; with
\alpha=3\eta/2
, the latter is canceled by the negative last term in Equation (
2
).
Therefore, the main remaining difficulties are to control the concentration term and the loss-drift term.

3) Fixed-time exponential bound for the concentration term.

For the concentration term, the stationary OMD analysis of
36
based on a supermartingale and Ville’s inequality
(
28
)
no longer applies.
Indeed, letting

Z_{s}:=\ell_{s}(\theta_{s}^{\star})-m_{s}(\Pi_{s})

and

S_{t}:=\sum_{s=1}^{t-1}\gamma^{t-1-s}Z_{s}
,
the discounted recursion becomes
S_{t+1}=\gamma S_{t}+Z_{t}
, so the process
e^{S_{t}}
is generally not a supermartingale.
We therefore first derive a
fixed-time
exponential bound, and then obtain a uniform-in-
t
statement by applying a union bound.
Specifically, fixing the time
t
and writing
w_{s,t}:=\gamma^{t-1-s}\in(0,1]
, the likelihood-ratio identity gives

\mathbb{E}[e^{Z_{s}}\mid\widetilde{\mathcal{F}}_{s}]=1
,
where
\widetilde{\mathcal{F}}_{s}

denotes a suitable filtration; its precise definition is given in the appendix.
Since
x\mapsto x^{w_{s,t}}
is concave on
\mathbb{R}_{+}
, conditional Jensen yields

\mathbb{E}[e^{w_{s,t}Z_{s}}\mid\widetilde{\mathcal{F}}_{s}]\leq\bigl(\mathbb{E}[e^{Z_{s}}\mid\widetilde{\mathcal{F}}_{s}]\bigr)^{w_{s,t}}\!=\!1.

Iterating over
s
gives

\mathbb{E}[e^{\sum_{s=1}^{t-1}w_{s,t}Z_{s}}]\leq 1
,
and therefore Markov’s inequality implies that the concentration term is at most
\log(1/\delta)
with probability at least
1-\delta
.
Thus, unlike the stationary case, concentration is obtained through a fixed-time exponential argument tailored to discounting.
Applying this fixed-time bound with
\delta_{t}=6\delta/(\pi^{2}t^{2})
, one can then take a union bound over
t
to obtain the desired guarantee uniformly over
t
(see Lemma
A.2
).

4) Control of the loss-drift term.

The main difficulty is that the drift of the comparator is measured through past losses
\ell_{s}
, rather than directly through parameter differences.
This gives rise to an additional loss-space error term that does not appear in the stationary OMD analysis
(
36
)
.
It is also structurally different from the explicit parameter-bias terms used in nonstationary MLE-based analyses
(
32
)
.
We control this term directly in loss space by writing

\ell_{s}(\theta_{t}^{\star})-\ell_{s}(\theta_{s}^{\star})=\underbrace{\frac{m(x_{s}^{\top}\theta_{t}^{\star})-m(x_{s}^{\top}\theta_{s}^{\star})-\mu(x_{s}^{\top}\theta_{s}^{\star})x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})}{g(\tau)}}_{\text{deterministic term}}-\underbrace{\frac{\eta_{s}\,x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})}{g(\tau)}}_{\text{stochastic term}}.

The first term on the right-hand side is deterministic.
By the smoothness of the GLM loss under Assumption
2
, it is bounded by

\frac{k_{\mu}}{2g(\tau)}\sum_{s=1}^{t-1}\gamma^{t-1-s}\bigl(x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})\bigr)^{2}\leq\frac{k_{\mu}}{2g(\tau)}\mathcal{V}_{t}^{2}.

Furthermore, the second term is stochastic.
Since the comparator path is
oblivious
, i.e., the entire sequence
\{\theta_{u}^{\star}\}_{u\geq 1}
is independent of the realized rewards, the coefficients

\gamma^{t-1-s}x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})

are predictable.
Therefore, a discounted Hoeffding–Chernoff argument yields a deviation term of order

\sqrt{\mathcal{V}_{t}^{2}\log(1/\delta)}
.
By Young’s inequality, this term is split into a quadratic variation term, which is absorbed into the deterministic variation bound, and a logarithmic confidence penalty.
Combining the deterministic and stochastic parts, we obtain

\sum_{s=1}^{t-1}\gamma^{t-1-s}\bigl(\ell_{s}(\theta_{t}^{\star})-\ell_{s}(\theta_{s}^{\star})\bigr)\leq\frac{k_{\mu}}{g(\tau)}\mathcal{V}_{t}^{2}+\frac{R^{2}}{4g(\tau)k_{\mu}}\log\frac{1}{\delta}.

Therefore, the loss-drift term is controlled by the discounted variation measure
\mathcal{V}_{t}
(Lemma
A.4
).

6
Conclusion

In this paper, to the best of our knowledge, we introduce the first algorithm for nonstationary GLBs built on a novel discounted online mirror descent (DOMD) method.
Using this DOMD method,
DOMD-GLB
achieves

\tilde{\mathcal{O}}(c_{\mu}^{-1/2}d^{3/4}P_{T}^{1/4}T^{3/4})

and

\tilde{\mathcal{O}}(c_{\mu}^{-1/3}d^{2/3}\Gamma_{T}^{1/3}T^{2/3})

dynamic regret bounds in the drifting and piecewise-stationary settings, respectively, while requiring only constant per-round computation and memory costs.
We believe this opens a new and promising research direction toward nonstationary parametric bandit algorithms that are both computationally and statistically efficient.

\sum_{s=1}^{t-1}\gamma^{t-1-s}Z_{s}

Z_{s}:=\ell_{s}(\theta_{s}^{\star})-m_{s}(\Pi_{s})
.
For each fixed
t
, one can show that
\mathbb{E}[e^{\sum_{s=1}^{t-1}\gamma^{t-1-s}Z_{s}}]\leq 1
, and hence a fixed-time high-probability bound follows by Markov’s inequality.
However, the process
(e^{\sum_{s=1}^{t-1}\gamma^{t-1-s}Z_{s}})_{t\geq 2}
is generally not a supermartingale, so Ville’s inequality cannot be applied.
To see this, define
S_{t}:=\sum_{s=1}^{t-1}\gamma^{t-1-s}Z_{s}
.
Then, the obstruction is the discounted recursion
S_{t+1}=\gamma S_{t}+Z_{t}
, which gives
e^{S_{t+1}}=e^{\gamma S_{t}}e^{Z_{t}}
.
Since
\mathbb{E}[e^{Z_{t}}|\widetilde{\mathcal{F}}_{t}]=1
, we get
\mathbb{E}[e^{S_{t+1}}|\widetilde{\mathcal{F}}_{t}]=e^{\gamma S_{t}}
.
A supermartingale argument would require
\mathbb{E}[e^{S_{t+1}}|\widetilde{\mathcal{F}}_{t}]\leq e^{S_{t}}
, but this is not guaranteed because
\gamma<1
and
S_{t}
need not be nonnegative.
Therefore, unlike Lemma 5 of
36
, our discounted analysis yields concentration only for each fixed
t
, rather than an anytime bound uniform over all
t
.

Lemma A.3

(Discounted mix-loss gap bound)
.

Define
\Pi_{t}:=\mathcal{N}(\theta_{t},\alpha A_{t}^{-1})
and

m_{t}(\Pi_{t}):=-\log\mathbb{E}_{\theta\sim\Pi_{t}}\!\left[e^{-\ell_{t}(\theta)}\right]
.
Let
\lambda\geq 32\alpha dR^{2}/7
.
Then, for every
t\geq 2
,
under Assumption
1
,
we have

\displaystyle\sum_{s=1}^{t-1}\gamma^{t-1-s}\bigl(m_{s}(\Pi_{s})-\ell_{s}(\theta_{s+1})\bigr)

\displaystyle\leq\left(3\eta+\frac{1}{2}\right)d\log\!\left(1+\frac{k_{\mu}(1-\gamma^{t-1})}{\lambda d\,g(\tau)(1-\gamma)}\right)

\displaystyle+\frac{1}{3\eta}\sum_{s=1}^{t-1}\gamma^{t-1-s}\|\theta_{s+1}-\theta_{s}\|_{A_{s}}^{2}.

The proof is provided in Appendix
A.2.3
.

Lemma A.4

(Drift-loss bound)
.

Under Assumptions
1
and
2
, for
t\geq 2
, with probability at least
1-\delta
, we have

\sum_{s=1}^{t-1}\gamma^{t-1-s}\bigl(\ell_{s}(\theta_{t}^{\star})-\ell_{s}(\theta_{s}^{\star})\bigr)\leq\frac{k_{\mu}}{g(\tau)}\,\mathcal{V}_{t}^{2}+\frac{R^{2}}{4\,g(\tau)\,k_{\mu}}\log\frac{1}{\delta},

where
\mathcal{V}_{t}=\sum_{p=1}^{t-1}\gamma^{(t-1-p)/2}\sqrt{\frac{1-\gamma^{p}}{1-\gamma}}\|\theta^{\star}_{p+1}-\theta^{\star}_{p}\|_{2}
.

The proof is provided in Appendix
A.2.4
.

Consequently, on the right-hand side of (
A.2
),
the first term is bounded by Lemma
A.2
with probability
1-\delta/2
;
the second term is bounded deterministically by Lemma
A.3
;
the third term is bounded by Lemma
A.4
with probability
1-\delta/2
.
Substituting these three bounds into (
A.1
) and using

2\eta\cdot\frac{1}{2\alpha}=2\eta\cdot\frac{1}{3\eta}=\frac{2}{3},

we obtain, on an event of probability at least
1-\delta
,

\displaystyle\|\theta_{t}-\theta_{t}^{\star}\|_{H_{t}}^{2}

\displaystyle\leq 4\lambda S^{2}+2\eta\log\frac{2}{\delta}+2\eta\left(3\eta+\frac{1}{2}\right)d\log\!\left(1+\frac{k_{\mu}(1-\gamma^{t-1})}{\lambda d\,g(\tau)(1-\gamma)}\right)

\displaystyle\quad+\frac{2\eta R^{2}}{g(\tau)k_{\mu}}\log\frac{2}{\delta}+\frac{2\eta k_{\mu}}{g(\tau)}\mathcal{V}_{t}^{2},\qquad\forall t\geq 2.

To obtain an anytime statement, for each
t\geq 2
, set

\delta_{t}:=\frac{6\delta}{\pi^{2}t^{2}}.

Applying the above fixed-time bound with
\delta
replaced by
\delta_{t}
, we obtain that, for each fixed
t\geq 2
, the desired inequality holds with probability at least
1-\delta_{t}
. Moreover,

\sum_{t=2}^{\infty}\delta_{t}=\frac{6\delta}{\pi^{2}}\sum_{t=2}^{\infty}\frac{1}{t^{2}}\leq\frac{6\delta}{\pi^{2}}\sum_{t=1}^{\infty}\frac{1}{t^{2}}=\delta.

Therefore, by a union bound over all
t\geq 2
, with probability at least
1-\delta
, the stated inequality holds simultaneously for all
t\geq 2
. This completes the proof of Theorem
1
.
∎

\displaystyle m_{s}(\Pi_{s})-\ell_{s}(\theta_{s+1})\leq\left(2\alpha+\frac{1}{2}\right)\Bigl(\log\det(H_{s+1})-\log\det(A_{s})\Bigr)+\frac{1}{2\alpha}\|\theta_{s+1}-\theta_{s}\|_{A_{s}}^{2}.

(A.15)

For simplicity, let

L_{s}:=\log\det(H_{s})
.
Since

A_{s}=\gamma H_{s}+(1-\gamma)\lambda I_{d}
,
concavity of
\log\det(\cdot)
implies

\log\det(A_{s})\geq\gamma L_{s}+(1-\gamma)d\log\lambda.

Therefore

\displaystyle\log\det(H_{s+1})-\log\det(A_{s})=L_{s+1}-\log\det(A_{s})\leq L_{s+1}-\gamma L_{s}-(1-\gamma)d\log\lambda.

(A.16)

Multiplying both sides of (
A.16
) by
\gamma^{t-1-s}
and summing over
s=1,\dots,t-1
yields

\displaystyle\sum_{s=1}^{t-1}\gamma^{t-1-s}\Bigl(\log\det(H_{s+1})-\log\det(A_{s})\Bigr)

\displaystyle\leq\sum_{s=1}^{t-1}\gamma^{t-1-s}L_{s+1}-\sum_{s=1}^{t-1}\gamma^{t-s}L_{s}

\displaystyle\quad-(1-\gamma)d\log\lambda\sum_{s=1}^{t-1}\gamma^{t-1-s}.

The first two sums can be telescoped as follows:

\sum_{s=1}^{t-1}\gamma^{t-1-s}L_{s+1}-\sum_{s=1}^{t-1}\gamma^{t-s}L_{s}=L_{t}-\gamma^{t-1}L_{1}=L_{t}-\gamma^{t-1}d\log\lambda,

where the last equality holds since
L_{1}=d\log\lambda
.
Moreover, evaluating the geometric sum gives

(1-\gamma)\sum_{s=1}^{t-1}\gamma^{t-1-s}=1-\gamma^{t-1}.

Hence, we get

\displaystyle\sum_{s=1}^{t-1}\gamma^{t-1-s}\Bigl(\log\det(H_{s+1})-\log\det(A_{s})\Bigr)

\displaystyle\leq L_{t}-\gamma^{t-1}d\log\lambda-(1-\gamma^{t-1})d\log\lambda

\displaystyle=L_{t}-d\log\lambda.

(A.17)

On the other hand, by the definition of
H_{t}=\lambda I_{d}+\sum_{s=1}^{t-1}\gamma^{t-1-s}\frac{\mu^{\prime}(x_{s}^{\top}\theta_{s+1})}{g(\tau)}x_{s}x_{s}^{\top}
,
we have

\displaystyle\mathop{\mathrm{Tr}}(H_{t})

\displaystyle=\lambda d+\sum_{s=1}^{t-1}\gamma^{t-1-s}\frac{\mu^{\prime}(x_{s}^{\top}\theta_{s+1})}{g(\tau)}\|x_{s}\|_{2}^{2}

\displaystyle\leq\lambda d+\frac{k_{\mu}}{g(\tau)}\sum_{s=1}^{t-1}\gamma^{t-1-s}

(
\|x\|_{2}\leq 1
, Assumption
1
)

\displaystyle=\lambda d+\frac{k_{\mu}(1-\gamma^{t-1})}{g(\tau)(1-\gamma)}.

(
\sum_{s=1}^{t-1}\gamma^{t-1-s}=(1-\gamma^{t-1})/(1-\gamma)
)

Therefore, we obtain

\displaystyle L_{t}-d\log\lambda

\displaystyle=\log\det(H_{t})-d\log\lambda\leq\log\left(\frac{\mathop{\mathrm{Tr}}(H_{t})}{d}\right)^{d}-d\log\lambda

(AM-GM inequality)

\displaystyle\leq d\log\!\left(1+\frac{k_{\mu}(1-\gamma^{t-1})}{\lambda d\,g(\tau)(1-\gamma)}\right).

(A.18)

Finally, summing (
A.15
) with weights
\gamma^{t-1-s}
yields

\displaystyle\sum_{s=1}^{t-1}

\displaystyle\gamma^{t-1-s}\bigl(m_{s}(\Pi_{s})-\ell_{s}(\theta_{s+1})\bigr)

\displaystyle\leq\left(2\alpha+\frac{1}{2}\right)\sum_{s=1}^{t-1}\gamma^{t-1-s}\Bigl(\log\det(H_{s+1})-\log\det(A_{s})\Bigr)+\frac{1}{2\alpha}\sum_{s=1}^{t-1}\gamma^{t-1-s}\|\theta_{s+1}-\theta_{s}\|_{A_{s}}^{2}

\displaystyle\leq\left(2\alpha+\frac{1}{2}\right)\bigl(L_{t}-d\log\lambda\bigr)+\frac{1}{2\alpha}\sum_{s=1}^{t-1}\gamma^{t-1-s}\|\theta_{s+1}-\theta_{s}\|_{A_{s}}^{2}

(Eqn. (
A.17
))

\displaystyle\leq\left(2\alpha+\frac{1}{2}\right)d\log\!\left(1+\frac{k_{\mu}(1-\gamma^{t-1})}{\lambda d\,g(\tau)(1-\gamma)}\right)+\frac{1}{2\alpha}\sum_{s=1}^{t-1}\gamma^{t-1-s}\|\theta_{s+1}-\theta_{s}\|_{A_{s}}^{2}.

(Eqn. (
A.18
))

Finally, substituting
\alpha=\frac{3\eta}{2}
completes the proof.
∎

Proof of Lemma

.

Fix

.
Using the definition of
\ell_{s}
, we obtain

\displaystyle\ell_{s}(\theta_{t}^{\star})-\ell_{s}(\theta_{s}^{\star})

\displaystyle=\frac{m(x_{s}^{\top}\theta_{t}^{\star})-r_{s}\,x_{s}^{\top}\theta_{t}^{\star}-m(x_{s}^{\top}\theta_{s}^{\star})+r_{s}\,x_{s}^{\top}\theta_{s}^{\star}}{g(\tau)}

\displaystyle=\frac{m(x_{s}^{\top}\theta_{t}^{\star})-m(x_{s}^{\top}\theta_{s}^{\star})-r_{s}\,x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})}{g(\tau)}

\displaystyle=\frac{m(x_{s}^{\top}\theta_{t}^{\star})-m(x_{s}^{\top}\theta_{s}^{\star})-\mu(x_{s}^{\top}\theta_{s}^{\star})\,x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})}{g(\tau)}-\frac{\eta_{s}\,x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})}{g(\tau)}.

(
r_{s}=\mu(x_{s}^{\top}\theta_{s}^{\star})+\eta_{s}

Therefore, we get

\sum_{s=1}^{t-1}\gamma^{t-1-s}\bigl(\ell_{s}(\theta_{t}^{\star})-\ell_{s}(\theta_{s}^{\star})\bigr)=B_{t}^{\mathrm{det}}-M_{t},

where the deterministic term is defined by

B_{t}^{\mathrm{det}}:=\frac{1}{g(\tau)}\sum_{s=1}^{t-1}\gamma^{t-1-s}\Bigl(m(x_{s}^{\top}\theta_{t}^{\star})-m(x_{s}^{\top}\theta_{s}^{\star})-\mu(x_{s}^{\top}\theta_{s}^{\star})\,x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})\Bigr),

and the stochastic term is

M_{t}:=\frac{1}{g(\tau)}\sum_{s=1}^{t-1}\gamma^{t-1-s}\eta_{s}\,x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star}).

i) Deterministic part.

By Assumption
1
, both
x_{s}^{\top}\theta_{t}^{\star}
and
x_{s}^{\top}\theta_{s}^{\star}
belong to
[-S,S]
.
Since

m^{\prime}=\mu
,

m^{\prime\prime}=\mu^{\prime}
,
and Assumption
2
gives
\mu^{\prime}(z)\leq k_{\mu}
for all
z\in[-S,S]

Taylor’s theorem implies that

\displaystyle m(x_{s}^{\top}\theta_{t}^{\star})-m(x_{s}^{\top}\theta_{s}^{\star})-\mu(x_{s}^{\top}\theta_{s}^{\star})\,x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})\leq\frac{k_{\mu}}{2}\bigl(x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})\bigr)^{2}.

Consequently, we can bound
B_{t}^{\mathrm{det}}
as follows:

\displaystyle B_{t}^{\mathrm{det}}

\displaystyle\leq\frac{k_{\mu}}{2g(\tau)}\sum_{s=1}^{t-1}\gamma^{t-1-s}\bigl(x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})\bigr)^{2}

\displaystyle\leq\frac{k_{\mu}}{2g(\tau)}\,\mathcal{V}_{t}^{2}.

(Lemma
A.9
)

ii) Stochastic part.

For fixed
t
, let

c_{s,t}:=\gamma^{t-1-s}\,x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star}),\qquad s=1,\dots,t-1.

Define the filtration before observing
r_{t}
by

\mathcal{F}_{t}:=\sigma(x_{1},r_{1},\dots,x_{t-1},r_{t-1},x_{t}),

and the enlarged filtration

\widetilde{\mathcal{F}}_{t}:=\mathcal{F}_{t}\vee\sigma(\theta_{u}^{\star}:u\geq 1)
.
Since the path
\{\theta_{u}^{\star}\}_{u=1}^{T}
is
oblivious
, i.e.,
the entire sequence of underlying parameters does not depend on the realized rewards or on the learner’s internal randomness,
and
x_{s}
is

\widetilde{\mathcal{F}}_{s}
-measurable, each
c_{s,t}
is

\widetilde{\mathcal{F}}_{s}
-measurable.

Moreover, because
r_{s}\in[0,R]
almost surely (Assumption
1
) and

\mu(x_{s}^{\top}\theta_{s}^{\star})=\mathbb{E}[r_{s}|\widetilde{\mathcal{F}}_{s}]\in[0,R]
, we have

\eta_{s}\in[-\mu(x_{s}^{\top}\theta_{s}^{\star}),\,R-\mu(x_{s}^{\top}\theta_{s}^{\star})]

almost surely.
Thus, conditioned on
\widetilde{\mathcal{F}}_{s}
, the centered random variable
\eta_{s}

lies in an interval of length
R
.
Hence, by Hoeffding’s lemma, for every
\bar{\lambda}>0
, we get

\mathbb{E}\!\left[\exp(-\bar{\lambda}c_{s,t}\eta_{s})\,\middle|\,\widetilde{\mathcal{F}}_{s}\right]\leq\exp\!\left(\frac{\bar{\lambda}^{2}c_{s,t}^{2}R^{2}}{8}\right).

Let

Y_{t}:=\sum_{s=1}^{t-1}c_{s,t}\eta_{s}.

Iterating conditional expectations from
s=t-1
down to
s=1
yields

\mathbb{E}\!\left[e^{-\bar{\lambda}Y_{t}}\right]\leq\exp\!\left(\frac{\bar{\lambda}^{2}R^{2}}{8}\sum_{s=1}^{t-1}c_{s,t}^{2}\right).

Therefore, for every
u>0
and every
\bar{\lambda}>0
, Chernoff’s bound gives

\displaystyle\mathbb{P}(-M_{t}\geq u)

\displaystyle=\mathbb{P}\!\left(-\sum_{s=1}^{t-1}c_{s,t}\eta_{s}\geq g(\tau)u\right)

\displaystyle\leq\exp\!\left(-\bar{\lambda}g(\tau)u\right)\mathbb{E}\!\left[e^{-\bar{\lambda}Y_{t}}\right]

(Chernoff’s bound)

\displaystyle\leq\exp\!\left(-\bar{\lambda}g(\tau)u+\frac{\bar{\lambda}^{2}R^{2}}{8}\sum_{s=1}^{t-1}c_{s,t}^{2}\right).

Optimizing over
\bar{\lambda}>0
gives

\bar{\lambda}^{\star}=\frac{4g(\tau)u}{R^{2}\sum_{s=1}^{t-1}c_{s,t}^{2}},

and thus

\mathbb{P}(-M_{t}\geq u)\leq\exp\!\left(-\frac{2g(\tau)^{2}u^{2}}{R^{2}\sum_{s=1}^{t-1}c_{s,t}^{2}}\right).

Hence, with probability at least
1-\delta
, we have

\displaystyle-M_{t}

\displaystyle\leq\frac{R}{g(\tau)}\sqrt{\frac{1}{2}\log\frac{1}{\delta}\sum_{s=1}^{t-1}c_{s,t}^{2}}

\displaystyle=\frac{R}{g(\tau)}\sqrt{\frac{1}{2}\log\frac{1}{\delta}\sum_{s=1}^{t-1}\gamma^{2(t-1-s)}\bigl(x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})\bigr)^{2}}

\displaystyle\leq\frac{R}{g(\tau)}\sqrt{\frac{1}{2}\log\frac{1}{\delta}}\,\mathcal{V}_{t}.

(Lemma
A.9
)

Applying Young’s inequality
ab\leq\frac{\varepsilon}{2}a^{2}+\frac{1}{2\varepsilon}b^{2}

with

a=\mathcal{V}_{t}
,

b=\frac{R}{g(\tau)}\sqrt{\frac{1}{2}\log\frac{1}{\delta}}
,
and
\varepsilon=\frac{k_{\mu}}{g(\tau)}
,
we obtain

-M_{t}\leq\frac{k_{\mu}}{2g(\tau)}\mathcal{V}_{t}^{2}+\frac{R^{2}}{4g(\tau)k_{\mu}}\log\frac{1}{\delta}.

Combining the bounds on
B_{t}^{\mathrm{det}}
and
-M_{t}
, we conclude that,
with probability at least
1-\delta
,

\sum_{s=1}^{t-1}\gamma^{t-1-s}\bigl(\ell_{s}(\theta_{t}^{\star})-\ell_{s}(\theta_{s}^{\star})\bigr)\leq\frac{k_{\mu}}{g(\tau)}\,\mathcal{V}_{t}^{2}+\frac{R^{2}}{4g(\tau)k_{\mu}}\log\frac{1}{\delta}.

This completes the proof.

Lemma A.5

(Self-concordance control)
.

Under Assumption
1
,
for every
v,z_{1},z_{2}\in\mathbb{R}
,

\int_{0}^{1}(1-s)\mu^{\prime}\bigl(v+s(z_{1}-z_{2})\bigr)\,\mathrm{d}s\geq\frac{\mu^{\prime}(v)}{2+R|z_{1}-z_{2}|},

(A.19)

and

\int_{0}^{1}(1-s)\mu^{\prime}\bigl(v+s(z_{1}-z_{2})\bigr)\,\mathrm{d}s\leq\exp\!\left(\frac{R^{2}(z_{1}-z_{2})^{2}}{4}\right)\mu^{\prime}(v).

(A.20)

Proof of Lemma
A.5
.

Under the bounded rewards assumption (Assumption
1
),
Proposition
1
implies that

|\mu^{\prime\prime}(z)|\leq R\,\mu^{\prime}(z)
for all
z\in\mathbb{R}
.
Equivalently,

\left|\frac{d}{du}\log\mu^{\prime}(u)\right|=\left|\frac{\mu^{\prime\prime}(u)}{\mu^{\prime}(u)}\right|\leq R.

Hence, for any
s\in[0,1]
,

\displaystyle\log\mu^{\prime}\bigl(v+s(z_{1}-z_{2})\bigr)-\log\mu^{\prime}(v)

\displaystyle=\int_{0}^{1}\frac{d}{dw}\log\mu^{\prime}\bigl(v+ws(z_{1}-z_{2})\bigr)\,\mathrm{d}w

\displaystyle=\int_{0}^{1}\frac{\mu^{\prime\prime}\bigl(v+ws(z_{1}-z_{2})\bigr)}{\mu^{\prime}\bigl(v+ws(z_{1}-z_{2})\bigr)}\,s(z_{1}-z_{2})\,\mathrm{d}w.

Therefore,

\left|\log\mu^{\prime}\bigl(v+s(z_{1}-z_{2})\bigr)-\log\mu^{\prime}(v)\right|\leq\int_{0}^{1}R\,s|z_{1}-z_{2}|\,\mathrm{d}w=Rs|z_{1}-z_{2}|,

which implies

e^{-Rs|z_{1}-z_{2}|}\mu^{\prime}(v)\leq\mu^{\prime}\bigl(v+s(z_{1}-z_{2})\bigr)\leq e^{Rs|z_{1}-z_{2}|}\mu^{\prime}(v).

For the lower bound, let
u:=R|z_{1}-z_{2}|
.
Then

\displaystyle\int_{0}^{1}(1-s)\mu^{\prime}\bigl(v+s(z_{1}-z_{2})\bigr)\,\mathrm{d}s

\displaystyle\geq\mu^{\prime}(v)\int_{0}^{1}(1-s)e^{-us}\,\mathrm{d}s

\displaystyle=\mu^{\prime}(v)\frac{u-1+e^{-u}}{u^{2}}\qquad(u>0),

where the last equality follows from a direct calculation.

Hence it suffices to show

\frac{u-1+e^{-u}}{u^{2}}\geq\frac{1}{2+u}\qquad\forall u>0.

Define

q(u):=(2+u)(u-1+e^{-u})-u^{2}.

Then
q(0)=0
, and

q^{\prime}(u)=1-(1+u)e^{-u}\geq 0\qquad\forall u>0,

because
e^{u}>1+u
.
Therefore
q(u)>0
for all
u>0
, which proves (
A.19
).

For the upper bound,
using

\mu^{\prime}\bigl(v+s(z_{1}-z_{2})\bigr)\leq e^{us}\mu^{\prime}(v),

we obtain

\int_{0}^{1}(1-s)\mu^{\prime}\bigl(v+s(z_{1}-z_{2})\bigr)\,\mathrm{d}s\leq\mu^{\prime}(v)\int_{0}^{1}(1-s)e^{us}\,\mathrm{d}s.

Let
B\sim\mathrm{Beta}(1,2)
, whose density is
2(1-s)\mathbf{1}\{0\leq s\leq 1\}
. Then

\int_{0}^{1}(1-s)e^{us}\,\mathrm{d}s=\frac{1}{2}\mathbb{E}[e^{uB}].

Since
B\in[0,1]
, Hoeffding’s lemma yields

\mathbb{E}[e^{u(B-\mathbb{E}B)}]\leq e^{u^{2}/8}.

(A.21)

Using
\mathbb{E}B=1/3
, we get

\displaystyle\int_{0}^{1}(1-s)e^{us}\,\mathrm{d}s

\displaystyle=\frac{1}{2}\mathbb{E}[e^{uB}]=\frac{1}{2}e^{u\mathbb{E}B}\mathbb{E}[e^{u(B-\mathbb{E}B)}]=\frac{1}{2}e^{u/3}\mathbb{E}[e^{u(B-\mathbb{E}B)}]

\displaystyle\leq\frac{1}{2}\exp\!\left(\frac{u}{3}+\frac{u^{2}}{8}\right).

(Eqn. (
A.21

Moreover,

\frac{u^{2}}{8}+\frac{2}{9}-\frac{u}{3}=\frac{(3u-4)^{2}}{72}\geq 0,

so

.

(

which proves (
A.20

Lemma A.6

(Gaussian exponential moment)
.

,

W_{s+1}=\Sigma_{s}^{1/2}\xi,\qquad\xi\sim\mathcal{N}(0,I_{d}).

Therefore,

W_{s+1}^{\top}\nabla^{2}\ell_{s}(\theta_{s+1})W_{s+1}=\xi^{\top}M_{s}\xi.

Now diagonalize
M_{s}
as

M_{s}=U\Lambda U^{\top},\qquad\Lambda=\mathrm{diag}(\rho_{1},\dots,\rho_{d}),

where
U
is an orthogonal matrix
and
\rho_{1},\dots,\rho_{d}\geq 0
are the eigenvalues of
M_{s}
.
Since
U^{\top}\xi\sim\mathcal{N}(0,I_{d})
, letting

\zeta:=U^{\top}\xi
,
we obtain

W_{s+1}^{\top}\nabla^{2}\ell_{s}(\theta_{s+1})W_{s+1}=\xi^{\top}M_{s}\xi=\zeta^{\top}\Lambda\zeta=\sum_{i=1}^{d}\rho_{i}\zeta_{i}^{2},

where
\zeta_{1},\dots,\zeta_{d}
are i.i.d. standard Gaussian random variables.
Hence

\|W_{s+1}\|_{\nabla^{2}\ell_{s}(\theta_{s+1})}^{4}=(\xi^{\top}M_{s}\xi)^{2}=\left(\sum_{i=1}^{d}\rho_{i}\zeta_{i}^{2}\right)^{2}=\sum_{i=1}^{d}\rho_{i}^{2}\zeta_{i}^{4}+\sum_{i\neq j}\rho_{i}\rho_{j}\zeta_{i}^{2}\zeta_{j}^{2}.

Taking expectations and using

\mathbb{E}[\zeta_{i}^{4}]=3
and

\mathbb{E}[\zeta_{i}^{2}\zeta_{j}^{2}]=1
for

i\neq j
,
we get

\displaystyle\mathbb{E}\!\left[\|W_{s+1}\|_{\nabla^{2}\ell_{s}(\theta_{s+1})}^{4}\right]

\displaystyle=\mathbb{E}\left[(\xi^{\top}M_{s}\xi)^{2}\right]=3\sum_{i=1}^{d}\rho_{i}^{2}+\sum_{i\neq j}\rho_{i}\rho_{j}

\displaystyle=2\sum_{i=1}^{d}\rho_{i}^{2}+\left(\sum_{i=1}^{d}\rho_{i}\right)^{2}

\displaystyle=2\mathop{\mathrm{Tr}}(M_{s}^{2})+\mathop{\mathrm{Tr}}(M_{s})^{2}.

Recall that
M_{s}=\Sigma_{s}^{1/2}\nabla^{2}\ell_{s}(\theta_{s+1})\Sigma_{s}^{1/2}
.
Since

\nabla^{2}\ell_{s}(\theta_{s+1})=\frac{\mu^{\prime}(x_{s}^{\top}\theta_{s+1})}{g(\tau)}x_{s}x_{s}^{\top},

the matrix
M_{s}
is positive semidefinite and has rank at most one. Hence,
if
\lambda_{s}(M_{s})
denotes its unique possibly nonzero eigenvalue, then

\mathop{\mathrm{Tr}}(M_{s})=\lambda_{s}(M_{s}),\qquad\mathop{\mathrm{Tr}}(M_{s}^{2})=\lambda_{s}(M_{s})^{2},

and therefore

\mathop{\mathrm{Tr}}(M_{s})^{2}=\mathop{\mathrm{Tr}}(M_{s}^{2}).

Therefore, we obtain

\displaystyle\mathbb{E}\!\left[\|W_{s+1}\|_{\nabla^{2}\ell_{s}(\theta_{s+1})}^{4}\right]

\displaystyle=2\mathop{\mathrm{Tr}}(M_{s}^{2})+\mathop{\mathrm{Tr}}(M_{s})^{2}

\displaystyle=3\mathop{\mathrm{Tr}}(M_{s})^{2}

(
M_{s}
is rank-one)

\displaystyle=3\mathop{\mathrm{Tr}}\!\left(\Sigma_{s}\nabla^{2}\ell_{s}(\theta_{s+1})\right)^{2}

(cyclicity of trace)

\displaystyle=3\alpha^{2}\mathop{\mathrm{Tr}}\!\left(H_{s+1}^{-1}\nabla^{2}\ell_{s}(\theta_{s+1})\right)^{2}.

(A.26)

Substituting (
A.25
) and (
A.26
)) into (
A.24
), we obtain

\displaystyle\mathbb{E}_{Q_{s}}\bigl[D_{\ell_{s}}(\theta,\theta_{s+1})\bigr]\leq 2\alpha\,\mathop{\mathrm{Tr}}(H_{s+1}^{-1}\nabla^{2}\ell_{s}(\theta_{s+1})).

(A.27)

Now write

H_{s+1}=A_{s}+\omega_{s}x_{s}x_{s}^{\top}
and

u_{s}:=x_{s}^{\top}A_{s}^{-1}x_{s}
.
By the Sherman–Morrison formula,

\displaystyle\mathop{\mathrm{Tr}}(H_{s+1}^{-1}\nabla^{2}\ell_{s}(\theta_{s+1}))

\displaystyle=\omega_{s}x_{s}^{\top}H_{s+1}^{-1}x_{s}

\displaystyle=\omega_{s}\!\left(x_{s}^{\top}A_{s}^{-1}x_{s}-\frac{\omega_{s}\,x_{s}^{\top}A_{s}^{-1}x_{s}\,x_{s}^{\top}A_{s}^{-1}x_{s}}{1+\omega_{s}x_{s}^{\top}A_{s}^{-1}x_{s}}\right)

\displaystyle=\omega_{s}\!\left(u_{s}-\frac{\omega_{s}u_{s}^{2}}{1+\omega_{s}u_{s}}\right)=\frac{\omega_{s}u_{s}}{1+\omega_{s}u_{s}}.

(A.28)

On the other hand, we have

\displaystyle\log\det(H_{s+1})-\log\det(A_{s})

\displaystyle=\log\det(A_{s}+\omega_{s}x_{s}x_{s}^{\top})-\log\det(A_{s})

\displaystyle=\log\Bigl(\det(A_{s})\bigl(1+\omega_{s}x_{s}^{\top}A_{s}^{-1}x_{s}\bigr)\Bigr)-\log\det(A_{s})

\displaystyle=\log(1+\omega_{s}u_{s}).

(A.29)

Since
\log(1+y)\geq y/(1+y)
for every
y>-1
, it follows that

\displaystyle\mathop{\mathrm{Tr}}(H_{s+1}^{-1}\nabla^{2}\ell_{s}(\theta_{s+1}))

\displaystyle=\frac{\omega_{s}u_{s}}{1+\omega_{s}u_{s}}

(Eqn. (
A.28
))

\displaystyle\leq\log(1+\omega_{s}u_{s})

(
\log(1+y)\geq y/(1+y)
)

\displaystyle=\log\det(H_{s+1})-\log\det(A_{s}).

(Eqn. (
A.29
))

Combining this with (
A.27
) completes the proof.
∎

Lemma A.8

(Variational formula for mix loss, Lemma 12 of
36
)
.

Let
P
be a probability distribution defined over
\mathbb{R}^{d}
and
\Delta
be the set of all measurable distributions. For any loss function
\ell:\mathbb{R}^{d}\to\mathbb{R}
, we have

-\frac{1}{\alpha}\log\!\left(\mathbb{E}_{\theta\sim P}\!\left[e^{-\alpha\ell(\theta)}\right]\right)=\mathbb{E}_{\theta\sim P_{\star}}[\ell(\theta)]+\frac{1}{\alpha}\mathrm{KL}(P_{\star}\|P),

where

P_{\star}=\mathop{\mathrm{argmin}}_{P^{\prime}\in\Delta}\,\mathbb{E}_{\theta\sim P^{\prime}}[\ell(\theta)]+\frac{1}{\alpha}\mathrm{KL}(P^{\prime}\|P)

is the optimal solution. Furthermore, for any distribution
Q
defined over
\mathbb{R}^{d}
, we have

-\frac{1}{\alpha}\log\!\left(\mathbb{E}_{\theta\sim P}\!\left[e^{-\alpha\ell(\theta)}\right]\right)=\mathbb{E}_{\theta\sim Q}[\ell(\theta)]+\frac{1}{\alpha}\mathrm{KL}(Q\|P)-\frac{1}{\alpha}\mathrm{KL}(Q\|P_{\star}).

Lemma A.9

(Kernel compression)
.

For
t\geq 2
, define

\mathcal{V}_{t}:=\sum_{p=1}^{t-1}\gamma^{(t-1-p)/2}\sqrt{\frac{1-\gamma^{p}}{1-\gamma}}\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}
.
Assume that
\|x_{s}\|_{2}\leq 1
for all
s\in[T]
.
Then, we have

\sum_{s=1}^{t-1}\gamma^{t-1-s}\left(x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})\right)^{2}\leq\mathcal{V}_{t}^{2}\qquad\text{and}\qquad\sum_{s=1}^{t-1}\gamma^{2(t-1-s)}\left(x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})\right)^{2}\leq\mathcal{V}_{t}^{2}.

Proof of Lemma
A.9
.

Fix
t\geq 2
.
For simplicity, define

\zeta_{s,t}:=x_{s}^{\top}(\theta_{t}^{\star}-\theta_{s}^{\star})=x_{s}^{\top}\sum_{p=s}^{t-1}\left(\theta_{p+1}^{\star}-\theta_{p}^{\star}\right)
.
Then, for each
s\in\{1,\dots,t-1\}
, we have

\zeta_{s,t}=x_{s}^{\top}\sum_{p=s}^{t-1}(\theta_{p+1}^{\star}-\theta_{p}^{\star})=\sum_{p=1}^{t-1}\mathbbm{1}\{s\leq p\}\,x_{s}^{\top}(\theta_{p+1}^{\star}-\theta_{p}^{\star}).

Define

u_{t}:=\bigl(\gamma^{(t-1-s)/2}\zeta_{s,t}\bigr)_{s=1}^{t-1}\in\mathbb{R}^{t-1},

and, for each
p\in\{1,\dots,t-1\}
,

v_{p,t}:=\Bigl(\mathbbm{1}\{s\leq p\}\,\gamma^{(t-1-s)/2}\,x_{s}^{\top}(\theta_{p+1}^{\star}-\theta_{p}^{\star})\Bigr)_{s=1}^{t-1}\in\mathbb{R}^{t-1}.

Then, by the above decomposition of
\zeta_{s,t}
, we have

u_{t}=\sum_{p=1}^{t-1}v_{p,t}.

We now bound
\|v_{p,t}\|_{2}
.
For each
p
, we get

\displaystyle\|v_{p,t}\|_{2}^{2}

\displaystyle=\sum_{s=1}^{t-1}\mathbbm{1}\{s\leq p\}\,\gamma^{t-1-s}\bigl(x_{s}^{\top}(\theta_{p+1}^{\star}-\theta_{p}^{\star})\bigr)^{2}

\displaystyle=\sum_{s=1}^{p}\gamma^{t-1-s}\bigl(x_{s}^{\top}(\theta_{p+1}^{\star}-\theta_{p}^{\star})\bigr)^{2}

\displaystyle\leq\sum_{s=1}^{p}\gamma^{t-1-s}\,\|x_{s}\|_{2}^{2}\,\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}^{2}

\displaystyle\leq\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}^{2}\sum_{s=1}^{p}\gamma^{t-1-s}.

(
\|x_{s}\|_{2}^{2}\leq 1
)

Since

\sum_{s=1}^{p}\gamma^{t-1-s}=\gamma^{t-1-p}\sum_{r=0}^{p-1}\gamma^{r}=\gamma^{t-1-p}\frac{1-\gamma^{p}}{1-\gamma},

it follows that

\|v_{p,t}\|_{2}\leq\gamma^{(t-1-p)/2}\sqrt{\frac{1-\gamma^{p}}{1-\gamma}}\,\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}.

Next, by the triangle inequality in
\mathbb{R}^{t-1}
, we obtain

\displaystyle\|u_{t}\|_{2}=\left\|\sum_{p=1}^{t-1}v_{p,t}\right\|_{2}\leq\sum_{p=1}^{t-1}\|v_{p,t}\|_{2}\leq\sum_{p=1}^{t-1}\gamma^{(t-1-p)/2}\sqrt{\frac{1-\gamma^{p}}{1-\gamma}}\,\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}=\mathcal{V}_{t}.

Therefore, by the definition of
u_{t}
, we get

\|u_{t}\|_{2}^{2}=\sum_{s=1}^{t-1}\gamma^{t-1-s}\zeta_{s,t}^{2}\leq\mathcal{V}_{t}^{2},

which proves the first inequality.

It remains to prove the second inequality. Since
\gamma\in(0,1)
, for every
s\leq t-1
,

\gamma^{2(t-1-s)}\leq\gamma^{t-1-s}.

Therefore,

\sum_{s=1}^{t-1}\gamma^{2(t-1-s)}\zeta_{s,t}^{2}\leq\sum_{s=1}^{t-1}\gamma^{t-1-s}\zeta_{s,t}^{2}\leq\mathcal{V}_{t}^{2}.

This completes the proof.

Lemma B.1

(Prediction bound under the discounted-OMD confidence event)

Under the same parameter choices as in Theorem

, and under Assumptions
1

2

\mathcal{E}

(Discounted elliptical potential)

Assume
\lambda\geq c_{\mu}/g(\tau)
.
Then for every

\displaystyle\sum_{t=1}^{T}\|x_{t}\|_{H_{t}^{-1}}^{2}\leq\frac{2g(\tau)}{c_{\mu}}\left[d\log\!\left(1+\frac{k_{\mu}}{\lambda d\,g(\tau)(1-\gamma)}\right)+Td\log\frac{1}{\gamma}\right].

B.2.2
.

B.3
provides a bound on the cumulative drift kernel

\mathcal{V}_{t}
, similarly to prior work such as
32
.
The geometric discounting suppresses the influence of past parameter changes, so the total contribution is controlled by the path length
P_{T}
.

Lemma B.3

Let
\mathcal{V}_{t}:=\sum_{p=1}^{t-1}\gamma^{(t-1-p)/2}\sqrt{\frac{1-\gamma^{p}}{1-\gamma}}\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}
.

The proof is provided in Appendix
B.2.3

Proof of Theorem
2
.

Throughout the proof, we condition on the event

\mathcal{E}:=\bigcap_{t\geq 2}\left\{\theta_{t}^{\star}\in\mathcal{C}_{t}(\delta)\right\},

defined in (
B.1
),
which holds with probability at least
1-\delta
by Theorem

.

Let

R_{t}:=\mu((x_{t}^{\star})^{\top}\theta_{t}^{\star})-\mu(x_{t}^{\top}\theta_{t}^{\star})

be the instantaneous pseudo-regret.
Then, by Lemma
B.1
, with probability at least
1-\delta
, for every

\displaystyle R_{t}

\displaystyle=\mu((x_{t}^{\star})^{\top}\theta_{t}^{\star})-\mu(x_{t}^{\top}\theta_{t}^{\star})

\displaystyle\leq k_{\mu}\left((x_{t}^{\star}-x_{t})^{\top}\theta_{t}^{\star}\right)

(

-Lipschitz continuity of

)

\displaystyle\leq k_{\mu}\left((x_{t}^{\star})^{\top}\theta_{t}+\beta_{t}(\delta)\|x_{t}^{\star}\|_{H_{t}^{-1}}+\frac{\iota}{\sqrt{\lambda}}\mathcal{V}_{t}-\left(x_{t}^{\top}\theta_{t}-\beta_{t}(\delta)\|x_{t}\|_{H_{t}^{-1}}-\frac{\iota}{\sqrt{\lambda}}\mathcal{V}_{t}\right)\right)

(Lemma
B.1
)

\displaystyle\leq 2k_{\mu}\beta_{t}(\delta)\|x_{t}\|_{H_{t}^{-1}}+2\frac{k_{\mu}\iota}{\sqrt{\lambda}}\mathcal{V}_{t}.

(action-selection rule in Eqn. (
3
))

Summing over
t=1,\dots,T
yields

\displaystyle\textup{{Reg}}_{T}

\displaystyle\leq R_{1}+2k_{\mu}\sum_{t=2}^{T}\beta_{t}(\delta)\|x_{t}\|_{H_{t}^{-1}}+2\frac{k_{\mu}\iota}{\sqrt{\lambda}}\sum_{t=2}^{T}\mathcal{V}_{t}

\displaystyle\leq R_{1}+2k_{\mu}\beta_{T}(\delta)\sum_{t=2}^{T}\|x_{t}\|_{H_{t}^{-1}}+2\frac{k_{\mu}\iota}{\sqrt{\lambda}}\sum_{t=2}^{T}\mathcal{V}_{t}

(
\beta_{t}(\delta)
is nondecreasing)

\displaystyle\leq R_{1}+2k_{\mu}\beta_{T}(\delta)\sqrt{T\sum_{t=2}^{T}\|x_{t}\|_{H_{t}^{-1}}^{2}}+2\frac{k_{\mu}\iota}{\sqrt{\lambda}}\sum_{t=2}^{T}\mathcal{V}_{t}

(Cauchy-Schwarz inequality)

\displaystyle\leq R_{1}+2k_{\mu}\beta_{T}(\delta)\sqrt{T\frac{2g(\tau)}{c_{\mu}}\left(d\log\!\left(1+\frac{k_{\mu}}{\lambda d\,g(\tau)(1-\gamma)}\right)+Td\log\frac{1}{\gamma}\right)}+2\frac{k_{\mu}\iota}{\sqrt{\lambda}}\sum_{t=2}^{T}\mathcal{V}_{t}

(Lemma
B.2
)

\displaystyle\leq R_{1}+2k_{\mu}\beta_{T}(\delta)\sqrt{T\frac{2g(\tau)}{c_{\mu}}\left[d\log\!\left(1+\frac{k_{\mu}}{\lambda d\,g(\tau)(1-\gamma)}\right)+Td\log\frac{1}{\gamma}\right]}

\displaystyle\quad+\frac{4k_{\mu}\iota}{\sqrt{\lambda}}\frac{P_{T}}{(1-\gamma)^{3/2}}

(Lemma
B.3
)

\displaystyle\leq 2k_{\mu}S+2k_{\mu}\beta_{T}(\delta)\sqrt{T\frac{2g(\tau)}{c_{\mu}}\left[d\log\!\left(1+\frac{k_{\mu}}{\lambda d\,g(\tau)(1-\gamma)}\right)+Td\log\frac{1}{\gamma}\right]}

\displaystyle\quad+\frac{4k_{\mu}\iota}{\sqrt{\lambda}}\frac{P_{T}}{(1-\gamma)^{3/2}},

where the last inequality holds because

.

, under

\lambda\geq\max\left\{\frac{6\eta Rk_{\mu}S}{g(\tau)},\frac{32\alpha dR^{2}}{7},\frac{c_{\mu}}{g(\tau)}\right\},\quad\eta=1+RS,\quad\alpha=\frac{3\eta}{2},\quad\iota=\sqrt{\frac{2\eta k_{\mu}}{g(\tau)}},

\displaystyle\beta_{T}(\delta)=\tilde{\mathcal{O}}(\sqrt{d})\qquad\text{and}\qquad\frac{k_{\mu}\iota}{\sqrt{\lambda}}=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}^{3/2}}{\sqrt{c_{\mu}}}\right).

(B.3)

Moreover,

\displaystyle\sqrt{\frac{2g(\tau)T}{c_{\mu}}\left[d\log\!\left(1+\frac{k_{\mu}}{\lambda d\,g(\tau)(1-\gamma)}\right)+Td\log\frac{1}{\gamma}\right]}=\tilde{\mathcal{O}}\!\left(\sqrt{\frac{Td}{c_{\mu}}}+T\sqrt{\frac{d(1-\gamma)}{c_{\mu}}}\right).

This proves the first bound.

Now we prove the second bound.
For the tuned choice, let

\gamma=1-\min\left\{1-\frac{1}{T},\;\max\left\{\frac{1}{T},\;\sqrt{\frac{\sqrt{k_{\mu}}P_{T}}{dT}}\right\}\right\}.

, and therefore the first bound applies.

\frac{d}{\sqrt{k_{\mu}}\,T}\leq P_{T}\leq\frac{dT}{\sqrt{k_{\mu}}}\left(1-\frac{1}{T}\right)^{2},

then

1-\gamma=\sqrt{\frac{\sqrt{k_{\mu}}P_{T}}{dT}}.

This implies that

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT\sqrt{1-\gamma}=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}^{9/8}}{\sqrt{c_{\mu}}}\,d^{3/4}P_{T}^{1/4}T^{3/4}\right),

and

\frac{k_{\mu}^{3/2}}{\sqrt{c_{\mu}}}\frac{P_{T}}{(1-\gamma)^{3/2}}=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}^{9/8}}{\sqrt{c_{\mu}}}\,d^{3/4}P_{T}^{1/4}T^{3/4}\right).

Moreover, under

P_{T}\geq\frac{d}{\sqrt{k_{\mu}}\,T}
,
the first term

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,d\sqrt{T}

is dominated by the same quantity.
Therefore, we get

\textup{{Reg}}_{T}=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}^{9/8}}{\sqrt{c_{\mu}}}\,d^{3/4}P_{T}^{1/4}T^{3/4}\right).

Case 2.

If

0\leq P_{T}<\frac{d}{\sqrt{k_{\mu}}\,T},

then

1-\gamma=\frac{1}{T}.

In this case, we have

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT\sqrt{1-\gamma}=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,d\sqrt{T}\right),

and

\frac{k_{\mu}^{3/2}}{\sqrt{c_{\mu}}}\frac{P_{T}}{(1-\gamma)^{3/2}}=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}^{3/2}}{\sqrt{c_{\mu}}}\,P_{T}T^{3/2}\right)<\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,d\sqrt{T}\right).

Hence, we obtain

\textup{{Reg}}_{T}\leq\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,d\sqrt{T}\right).

Case 3.

If

P_{T}>\frac{dT}{\sqrt{k_{\mu}}}\left(1-\frac{1}{T}\right)^{2},

then

1-\gamma=1-\frac{1}{T},

that is,

\gamma=\frac{1}{T}.

In this case, we have

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT\sqrt{1-\gamma}=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT\right),

and

\frac{k_{\mu}^{3/2}}{\sqrt{c_{\mu}}}\frac{P_{T}}{(1-\gamma)^{3/2}}=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}^{3/2}}{\sqrt{c_{\mu}}}\,P_{T}\right).

Moreover, the first term

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,d\sqrt{T}

is dominated by

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT.

Since
T\geq 2
, we have

\left(1-\frac{1}{T}\right)^{2}\geq\frac{1}{4},

and thus

P_{T}>\frac{dT}{\sqrt{k_{\mu}}}\left(1-\frac{1}{T}\right)^{2}\geq\frac{dT}{4\sqrt{k_{\mu}}}.

Therefore, the first term can be bounded as

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,d\sqrt{T}\leq\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT\leq 4\frac{k_{\mu}^{3/2}}{\sqrt{c_{\mu}}}\,P_{T}.

Hence, all three terms are dominated by

\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}^{3/2}}{\sqrt{c_{\mu}}}\,P_{T}\right),

and we obtain

\textup{{Reg}}_{T}\leq\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}^{3/2}}{\sqrt{c_{\mu}}}\,P_{T}\right).

This completes the proof of Theorem
2
.

Remark B.1

(On the clipped choice of
\gamma
)
.

The clipped definition of
\gamma
is necessary because our generic regret bound is proved only for admissible
\gamma\in[1/T,1)
, whereas the unconstrained minimizer of the simplified upper bound need not belong to this interval.
Earlier works often stated only the interior regimes and implicitly assumed that the resulting choice of
\gamma
was feasible.
For example,
7
effectively restrict to a sublinear-
P_{T}
regime in the proof, which allows them to exclude the large-
P_{T}
case and thus ensures that the tuned choice
\gamma=1-\left(\frac{P_{T}}{dT}\right)^{2/3}
remains admissible.
Similarly,
32
first derives generic bounds for admissible
\gamma\in(1/T,1)
, but then states tuned two-case corollaries without an explicit feasibility check.
A similar issue also appears in
23
,
24
for the piecewise-stationary setting, where the tuning implicitly relies on a sublinear-
\Gamma_{T}
regime so that the proposed choice
\gamma\approx 1-\left(\frac{\Gamma_{T}}{dT}\right)^{2/3}
remains admissible.
By contrast, our three-case bound is fully rigorous: the clipping step enforces admissibility explicitly, so the resulting bound applies uniformly over all parameter regimes. If the same feasibility check were made explicit in the earlier analyses, their tuned bounds would likewise take an analogous multi-case form, rather than covering only the interior one- or two-case regimes.

Proof of Theorem

In this section, we prove Theorem

The overall argument closely follows that of Appendix

the only additional ingredient is a sharper bound on
\sum_{t}\mathcal{V}_{t}
over rounds that are sufficiently far from the most recent change point.

C.1
Main Proof of Theorem

As in the proof of Theorem
2
, we condition on the good event

\mathcal{E}:=\bigcap_{t\geq 2}\left\{\theta_{t}^{\star}\in\mathcal{C}_{t}(\delta)\right\},

which, by Theorem
1
, holds with probability at least
\Pr(\mathcal{E})\geq 1-\delta
.
We further use Lemma
B.1
and Lemma
B.2
from Appendix
B
.

For each integer
D\geq 1
, let
\mathcal{G}_{D}
denote the set of rounds
t\in[T]
such that the environment parameter has not changed during the previous
D
rounds.
More precisely,

\mathcal{G}_{D}:=\big\{t\in[T]:\theta_{s}^{\star}=\theta_{t}^{\star}\ \text{for all }s\in\{\max\{t-D,1\},\ldots,t-1\}\big\}.

Equivalently,
t\in\mathcal{G}_{D}
if the parameter value at round
t
coincides with its value at every round in the most recent
D
-step history prior to
t
(or from round
1
onward when
t\leq D
).

We first quantify how many rounds fail to belong to
\mathcal{G}_{D}
.
Under piecewise stationarity, a round is excluded from
\mathcal{G}_{D}
only if a changepoint occurred within its most recent
D
-step history.
Therefore, each changepoint can affect only a length-
D
window of subsequent rounds, which yields the following bound on the number of such “bad” rounds.

Lemma C.1

(Bad-round count under piecewise stationarity)
.

For every integer
D\geq 1
, we have

|[T]\setminus\mathcal{G}_{D}|\leq\Gamma_{T}D.

The proof is deferred to Appendix
C.2.1
.

We next control the cumulative drift term over the complementary set of “good” rounds
\mathcal{G}_{D}
.
On these rounds, the parameter has remained unchanged throughout the most recent
D
rounds, so any contribution to the drift quantity
\mathcal{V}_{t}
must come from changes that occurred strictly earlier.
Because the discounted kernel downweights older rounds geometrically, those remote changes are suppressed by a factor of order
\gamma^{D/2}
, leading to the following estimate.

Lemma C.2

(Piecewise drift-kernel sum)
.

Under the piecewise-stationary assumption, for every integer
D\geq 1
,

\sum_{t\in\mathcal{G}_{D}\cap\{2,\dots,T\}}\mathcal{V}_{t}\leq\frac{2\gamma^{D/2}}{(1-\gamma)^{3/2}}\,P_{T}\leq\frac{4S\Gamma_{T}\,\gamma^{D/2}}{(1-\gamma)^{3/2}}.

The proof is deferred to Appendix
C.2.2
.

Now, we are ready to provide the proof of Theorem
3
.

so that

for all

\displaystyle 2k_{\mu}\beta_{T}(\delta)

\displaystyle\qquad\qquad\qquad\qquad\qquad\qquad\qquad=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,d\sqrt{T}+\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT\sqrt{1-\gamma}\right).

\gamma\in[1/T,1)

and therefore

\Gamma_{T}\geq\frac{k_{\mu}d}{\sqrt{c_{\mu}T}},

the first term

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,d\sqrt{T}

is dominated by the same quantity.
Therefore, we get

\textup{{Reg}}_{T}=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}^{2/3}}{c_{\mu}^{1/3}}\,d^{2/3}\Gamma_{T}^{1/3}T^{2/3}\right).

Hence, we obtain

\textup{{Reg}}_{T}\leq\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,d\sqrt{T}\right).

Case 3.
If

\Gamma_{T}>\frac{k_{\mu}dT}{\sqrt{c_{\mu}}}\left(1-\frac{1}{T}\right)^{3/2},

then

\left(\frac{\Gamma_{T}\sqrt{c_{\mu}}}{k_{\mu}dT}\right)^{2/3}>1-\frac{1}{T},

and thus

that is

\gamma=\frac{1}{T}.

In this case, we have

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT\sqrt{1-\gamma}=\tilde{\mathcal{O}}\!\left(\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT\right),

and

\frac{\Gamma_{T}}{1-\gamma}=\tilde{\mathcal{O}}\!\left(\Gamma_{T}\right).

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,d\sqrt{T}

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT.

\left(1-\frac{1}{T}\right)^{3/2}\geq\frac{1}{2\sqrt{2}}.

Therefore,

\Gamma_{T}>\frac{k_{\mu}dT}{\sqrt{c_{\mu}}}\left(1-\frac{1}{T}\right)^{3/2}\geq\frac{1}{2\sqrt{2}}\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT,

\frac{k_{\mu}}{\sqrt{c_{\mu}}}\,dT\leq 2\sqrt{2}\,\Gamma_{T}.

Hence, all three terms are dominated by

and we obtain

\textup{{Reg}}_{T}\leq\tilde{\mathcal{O}}\!\left(\Gamma_{T}\right).

This completes the proof of Theorem

.

\displaystyle=\frac{1}{\sqrt{1-\gamma}}\sum_{p=1}^{T-1}\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}\sum_{t=p+D+1}^{T}\gamma^{(t-1-p)/2}

\displaystyle\leq\frac{1}{\sqrt{1-\gamma}}\sum_{p=1}^{T-1}\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}\sum_{k=D}^{\infty}\gamma^{k/2}

\displaystyle=\frac{\gamma^{D/2}}{\sqrt{1-\gamma}(1-\sqrt{\gamma})}\sum_{p=1}^{T-1}\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}=\frac{\gamma^{D/2}}{\sqrt{1-\gamma}(1-\sqrt{\gamma})}\,P_{T},

For each fixed
p
,
where

P_{T}:=\sum_{p=1}^{T-1}\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}.

Using

1-\sqrt{\gamma}=\frac{1-\gamma}{1+\sqrt{\gamma}}\qquad\text{and}\qquad 1+\sqrt{\gamma}\leq 2,

we obtain

\sum_{t\in\mathcal{G}_{D}\cap\{2,\dots,T\}}\mathcal{V}_{t}\leq\frac{2\gamma^{D/2}}{(1-\gamma)^{3/2}}\,P_{T}.

(C.6)

It remains to bound
P_{T}
under piecewise stationarity.
Let
\nu_{1},\dots,\nu_{\Gamma_{T}}
be the change points. If

p\notin\{\nu_{1}-1,\dots,\nu_{\Gamma_{T}}-1\}
, then

\theta_{p+1}^{\star}=\theta_{p}^{\star}
, so

\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}=0.

On the other hand, if
p=\nu_{j}-1
for some
j\in[\Gamma_{T}]
, then by the triangle inequality,

\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}\leq\|\theta_{p+1}^{\star}\|_{2}+\|\theta_{p}^{\star}\|_{2}\leq 2S,

since
\theta_{p}^{\star},\theta_{p+1}^{\star}\in\Theta\subseteq\{\theta:\|\theta\|_{2}\leq S\}
.
Because there are exactly
\Gamma_{T}
such indices,

P_{T}=\sum_{p=1}^{T-1}\|\theta_{p+1}^{\star}-\theta_{p}^{\star}\|_{2}\leq 2S\Gamma_{T}.

Substituting this into (
C.6
) yields

\sum_{t\in\mathcal{G}_{D}\cap\{2,\dots,T\}}\mathcal{V}_{t}\leq\frac{4S\Gamma_{T}\,\gamma^{D/2}}{(1-\gamma)^{3/2}}.

This completes the proof.
∎
