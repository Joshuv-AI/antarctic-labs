 EXECUTIVE SUMMARY
The US Department of Energy (DOE) Nuclear Energy Advanced Modeling and Simulation (NEAMS)
program has invested in the Shift Monte Carlo radiation transport code for the past 5 years to serve the
program in two capacities: generate multigroup cross sections for two-step reactor physics calculations
and generate reactor physics reference solutions. To achieve these two goals, Shift must be able to
run efficiently on current and future computing architectures. In this vein, work was undertaken this
past year to enable the aforementioned capabilities to seamlessly and efficiently run on CPUs, GPUs,
and with multithreading. This effort also enabled the implementation of a new general overlay tally
and investigation of more accurate high-order anisotropic scattering matrices. A demonstration of the
architecture-agnostic and new general overlay tally capabilities in Shift is shown using a previously
developed Advanced Burner Test Reactor model. The initial investigation of the new methodology for
generating multigroup anisotropic scattering matrices has shown promising results for simple problems.

 viii

 ABSTRACT
This report provides the details of the new capabilities enabled in Shift to produce multigroup (MG)
cross sections and reference solutions for nuclear reactors by taking advantage of multiple computing
architectures. A new tally type was enabled in Shift that allows the user to specify an overlaid simplified
geometry (constructive solid geometry) and produce the requested reference responses on this simplified
geometry. A simple demonstration and verification is shown on a 3D Advanced Burner Test Reactor
utilizing CPUs and GPUs. Related to the production of MG cross sections, some new methodologies to
produce more accurate higher-order MG anisotropic scattering matrices were developed and tested with
Shift. The agreement (less than 10% in low-flux regions and less than 1% in high-flux regions), between
the FY 2024, CPU, and GPU results confirms and verifies the proper implementation of the new general
overlay tally capability.

 1. INTRODUCTION
The reactor physics technical area under the US Department of Energy (DOE) Nuclear Energy Advanced
Modeling and Simulation (NEAMS) program focuses on the development of modeling and simulation
tools for modeling reactor physics phenomena. In this particular work, the focus is on enabling the
generation of multigroup (MG) cross sections and reference solutions with the Monte Carlo (MC) code
Shift, as run on varying computing architectures (CPU, GPU, multithreaded).
To efficiently produce few-group cross section sets and reactor physics reference solutions for advanced
reactor models, Shift must be able to utilize current and future architecture types based on the reactor
problem and computational resources available. Therefore, the geometry tracking and tallying features of
Shift must be able to properly run and produce the expected solutions using CPUs, GPUs, multithreading,
and a combination. The “architecture-agnostic” geometry tracking feature set includes the following:
 • Unified algorithms for particle dynamics, including ray tracing, volume calculation, and MC
 transport;
 • Efficient tracking algorithms for random distributions of pebble-in-core, TRISO-in-pebble, and
 TRISO-in-compact geometries;
 • Robust user diagnostics that report input provenance of geometry definitions where errors occur
Similarly, the unified tally feature set includes the following:
 • New data structure designs for both tally filters and tally post-processors, previously coupled to each
 tally type implementation, that provides a scalable and reusable set of tally operations used by all
 Shift tally types,
 • full support of each Shift tally type on the CPU and GPU, including the physical geometry and/or
 overlay geometry,
 • in follow-on work, batch-mode implementation of variance estimators across all tally types and
 architectures.
This document is organized as follows. Section 2 discusses a summary of the previously developed
architecture-agnostic plan (Tara Pandya et al. 2025) and the specific implementation in Shift. Section 3
presents the 3D Advanced Burner Test Reactor (ABTR) Shift model, and Section 4 presents the
verification of the new Shift overlay tally applied to the ABTR model. Section 5 provides a new
methodology for generating more accurate higher-order anisotropic scattering matrices with preliminary
results. Finally, Section 6 discusses the main takeaways from this work and future research.

 2.2 IMPLEMENTATION
 To achieve these architecture-agnostic capabilities, a refactor of the tallying infrastructure of Shift was
 undertaken. The number of tally types supported by Shift has increased dramatically over the period of
 time from its initial implementation. In addition, the creation and maintenance of a GPU solver has added
 complexity to the overall code base. Software design decisions that were reasonable for an MC code with
 Shift’s original focus are not necessarily optimal for a more general application space. Refactoring the
 tally infrastructure has the following benefits:
 • faster time to deliver new features by simplifying the addition of new tallies,
 • improved maintainability by allowing more reuse of code across use cases,
 • increased reliability by enabling higher granularity of software testing, and
 • better performance portability through tighter integration between CPU and GPU solvers.
 The fundamental idea of the new tally approach is the separation of regions being tallied (referred to as
 filters) from the specific quantities being tallied. For instance, a user may want to compute macroscopic
 reaction rates on the geometric cells of the problem geometry or alternatively to compute the same reaction
 rates homogenized onto a coarse Cartesian mesh. In the original Shift approach, these operations were
 represented by two separate tally classes with two different implementations. With the new design, a filter
 is implemented to extract the geometric cells from a particle, and a second filter is implemented to locate
 and track the particle on a secondary geometry. Then a single tally class can perform the functions of
 both the original “cell union” and “Cartesian mesh” tallies. Furthermore, the new geometry tracking filter
 (known as an overlay geometry) has been designed so that it does not specifically rely on the type of the
 geometry. It is possible to not only supply a Cartesian mesh but alternatively use a second constructive
 solid geometry (CSG) geometry for computing tallies. This option gives the user tremendous flexibility
 in computing desired output quantities without relying on complicated user-defined mappings between a
 high-fidelity definition of the problem and coarser geometric regions where the solution is desired. Thus,
 the new design has unlocked new tally options that were not available originally while reducing the amount
 of code necessary to enable them. It is anticipated that the new general overlay geometry capability will be
 an extremely valuable analysis tool for Shift users.
 The overlay tally approach was previously introduced as an “OVERLAYMGXS” tally to compute MG
 cross sections. However, the original approach was limited to MG cross sections and did not support
 multithreading or GPU execution. With the new design, the overlay filter implementation can be used
 to enable the computation of the flux, microscopic or macroscopic reaction rates, and microscopic or
 macroscopic cross sections. Despite requiring tracking particles on two separate geometry representations,
 this approach typically results in only a small performance overhead because the cost of evaluating
 continuous-energy (CE) nuclear data generally still dominates the computational effort. Listing 1 shows
 an example Shift input block for the new general “OVERLAY” tally.

of results for reaction rates and flux spectrum are compared to previous results for the 3D ABTR model

‘OVERLAYMGXS’ tally capability in Shift. In the figures below, the previous results are denoted as
“FY 2024.” All simulations were run with 500 cycles (400 active, 100 inactive) with 100,000 particles per
cycle.

 5. ANISOTROPIC SCATTERING MATRICES
Progress was made this FY on the generation of MG anisotropic scattering matrices (ASMs) using Shift.
A future journal article will fully document the existing scalar flux normalized (SFN) method and two new
methods: the scatter rate minimization (SRM) method and the net rate minimization (NRM) method. A
brief summary is provided here with results for a simple sodium-cooled fast reactor (SFR) slab model
adopted from Lin and Yang 2020. These methods and results were presented at ICTT-26, the International
Conference on Transport Theory, in June 2026 in Aix-en-Provence, France.

5.2 RESULTS
The SFN, SRM, and NRM methods were tested for a simple sodium-cooled fast reactor (SFR) slab model
adopted from Lin and Yang 2020. One-group, nine-group, and 32-group structures were assessed, but only
32-group results are presented here. The 32-group structure is a slightly modified version of the 33-group
Argonne structure used in MC2 -3. The energy group boundaries in the thermal range were slightly adjusted
to improve statistics. The Griffin 𝑆 𝑁 model used a 32-point quadrature with a uniform 0.04 cm mesh.
The Shift model used 10𝑀 active particle histories (200 cycles) and 8 polar groups for tallies. The slab
model is shown in Figure 6. The reference 𝑘-eigenvalue computed in Shift is 1.13986(13).
Griffin-computed 𝑘-eigenvalues and zone-wise energy-integrated total and nu-fission reaction rates
are compared to Shift in Table 7. The SFN results show consistent agreement with the Serpent and
VARIANT results provided in Lin and Yang 2020. The SRM results are similar to the SFN results. The
NRM results show significant improvement in 𝑘-eigenvalue comparisons (less than 200 pcm) and a factor
of 2× improvement in zone-wise reaction rates. Griffin-computed 32-group zone-wise flux values were
also compared to reference Shift flux profiles. Flux comparisons are summarized in Table 8. The NRM
results show an improvement in the overall flux agreements.
5.3 FUTURE WORK
The NRM method shows promise for computing ASMs. The work appears to be consistent with recent
investigations by Wu et al. 2023, which the authors discovered after the ICTT conference. The key
consideration is the use of angular flux tallies (angular binning or functional expansion) of both the total
and scattering reaction rates, and then adjustment of the ASMs to account for the angle dependencies of
the collision term. This adjustment needs to be accounted for as part of the microscopic ASM generation
in the future, along with a thorough exploration of the NRM problem for a larger set of reactor models.

 6. CONCLUSIONS AND FUTURE WORK
6.1 CONCLUSIONS
The ability to use Shift for two-step neutronics calculations and reference solutions utilizing CPUs,
GPUs, and multithreading has been significantly advanced with the completion of this work. The number
of tally types supported by Shift has increased dramatically over the period of time from its initial
implementation, and the addition of the GPU solver has added complexity to the overall code base. This
report summarizes the enhancements to the Shift tally infrastructure to more efficiently add, maintain,
and reuse tally mechanics across multiple compute architectures.
One of the main features of the tally infrastructure enhancement is the reorganization of tally filters and
tally postprocessors to be reused across multiple tally types. The new design increases code reuse and
shared implementation for calculations on the CPU and GPU while allowing new filters to be easily added
in future development. This design also enables new tally workflows, as demonstrated in this report, where
new reaction rate and flux tallies were computed on the overlay geometry for the ABTR model. In the
previous implementation, only a subset of cross sections could be tallied on the overlay geometry.
In T. Pandya et al. 2024 and Lin and Yang 2020, MC generation of anisotropic scattering matrices
and subsequent use in MG transport calculations produced large 𝑘-eigenvalue and flux distribution
differences depending on energy group structure and reactor model. This issue is significant for fast
reactor calculations. Preliminary investigations in this report focused on the use of angle-dependent
tallies to generate ASMs versus the conventional approach of using scalar flux normalization. The results
reveal improved 𝑘-eigenvalue and reaction rate agreement between Shift and two-step Shift-Griffin
calculations when accounting for angle-dependent effects in the MG total cross section. This work
was presented at the ICTT conference in June 2026, and it aligns with recent work performed by Wu
et al. 2023.

6.2 FUTURE WORK
The areas for continuing work and future work exist in several different categories. First, completion of
the full architecture-agnostic tallying and modeling capabilities in Shift, as outlined in Tables 3 and 4, is
needed. Completion in this sense means full implementation, testing, and integration into the main Shift
source code.
Second, once implementation is fully complete, investigation and documentation of performance using
CPUs, GPUs, and multithreading with Shift applied to relevant advanced reactor physics calculations
will be produced in a future journal publication.
Third, pertaining to some of the model tracking enhancements in Shift mentioned in Section 2, the
ongoing work on tristructural-isotropic (TRISO)-based simulations and simulations that feature boundaries
with a union of a large number of shapes will also be fully documented in a future publication. This
publication will feature performance comparisons highlighting the runtime improvements in Shift
between CPU and GPU model tracking for relevant advanced reactor problems.
Finally, as noted in Section 5, further investigation is needed into the application of the NRM methodology
for computing ASMs on a large set of reactor problems beyond the simple fast-spectrum slab test problem.
This methodology and the SRM method will be fully documented and explored in a planned future journal
paper that builds upon the work presented herein and at ICTT.
