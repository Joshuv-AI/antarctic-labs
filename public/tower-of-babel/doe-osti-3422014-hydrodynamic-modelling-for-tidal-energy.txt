 Executive Summary of CRADA Work:

 The primary goal of the work is to improve accuracy of hydrodynamic loads acting on the lifting
 surface of the kite turbine due to complex air-water-lifting body interaction in a low-order
 numerical model using high-fidelity numerical input. The result of this study will help the
 Participant better design control algorithms for the kite turbine so that the turbine can harvest
 more energy while maintaining stability of the platform as well as its reliability. The use of
 hydrodynamic coefficients/load components from computational fluid dynamic simulation will
 inform better inputs for a medium-fidelity dynamic model (specifically an OrcaFlex model)
 which is intended for use in rapid design iterations in the design process.

 Summary of Research Results:

 Task 1: Participant will provide the OrcaFlex model, single-phase CFD model, and shape
 data describing aspects of the Manta kite hydrokinetic turbine system. The Parties will
 identify interesting design parameters (e.g., current speed, interfacial waves, prescribed
 kite path).

 Task 1 Results:

 The Participant has provided all necessary initial inputs such as the OrcaFlex model, Computer-
 Aided Design (CAD) model, submerged depths, inflow velocity speed and angle, kite
 orientation, and other relevant parameters. Figure 1 displays a CAD illustration of Manta Kite
 Hydrokinetic Turbine used for the project described in the rest of this document.

 Task 2: Contractor will create a two-phase 3-D Computational Fluid Dynamics (CFD)
 simulation baseline model using the input conditions provided by the Participant. The
 Contractor will quantify simulation uncertainties including spatial and temporal
 discretization.

 Task 2 Results:

 Figure 2 presents a graphic of two-phase CFD simulation baseline model conducted by the
 Contractor in this project. The CFD model applied an overset grid approach which allows users
 to simulate significant motion of the kite body as well as its variations in body orientation in this
 project. The Contractor conducted spatial discretization study to ensure the reasonable results, as
 shown in Figure 3. Before doing this baseline model simulation, the Contractor validated the
 simulation model using previous study and the results were in excellent agreement (shown in
 Figure 4).

 Task 3: Contractor will conduct 3D CFD simulation for fixed kite orientations, providing
 hydrodynamic patterns (e.g. streamlines, wake behind body). Additionally, Contractor will
 do data post-processing to characterize hydrodynamic load/coefficient components for each
 orientation.

 Task 3 Results:

 The Contractor conducted 3D CFD simulation for the Manta Kite Hydrokinetic System
 considering different kite body orientations such as roll, pitch and yaw angles. Figure 5 displays
 an example of CFD simulation results for each orientation condition with respect to different
 angle conditions which were provided by the Participant in Task 1. As can be seen, the pitch and
 yaw orientation of the kite body tend to affect its hydrodynamic loads whereas the roll
 orientation had a very minimal impact. The effect of submergence depth was also investigated
 and displayed in Figure 6 for yaw cases.

 Task 4: Contractor will complete an OrcaFlex simulation using a set of hydrodynamic
 coefficients/loads from CFD simulations from Task 3.

 Task 4 Results:

 Figures 7 and 8 present the OrcaFlex simulation model comparison between the Participant’s
 version and the current one, in which the hydrodynamic coefficients computed by CFD model
 were input for the current OrcaFlex model. Overall, there was agreement between the two
 models in static cases. As shown in Figure 7, the lift and drag coefficients computed by the CFD
 model showed agreement, specifically at low angle of attacks (AoAs), while there are some
 discrepancies in higher AoAs where dynamic stall tended to have significant impact. Whole
 static hydrodynamic forces acting on the kite body between two models show agreement in
 Figure 8.

 Task 5: Contractor will conduct 3D CFD simulation for prescribed motion of the kite
 system’s lifting body, providing hydrodynamic patterns. Additionally, Contractor will do
 data post-processing and analysis to calculate hydrodynamic load/coefficient and compare
 these against the fixed-orientation results from Task 3.

 Task 5 Results:

 No work was completed under this task because the Contractor and Participant agreed the best
 use of time was to run more static CFD cases.

 Task 6: Contractor will do an OrcaFlex simulation using a set of hydrodynamic
 coefficients/loads from CFD simulations from Task 5.

 Task 6 Results:

 No work was completed under this task because this task is relied on the Task 5 result.
