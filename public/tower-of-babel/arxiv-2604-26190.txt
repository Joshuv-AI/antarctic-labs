Flashback: A Reversible Bilateral Run-Peeling Decomposition of Strings
Thomas Konstantinovsky, Gur Yaari

Abstract
We introduce Flashback , a reversible string decomposition that repeatedly peels the maximal leading and trailing character runs from a sentinel-wrapped input, recording each pair as one bilateral token . Decomposition and reconstruction both run in O ⁡ ( n ) O(n) time and space. Our central result is a run-pairing theorem : Flashback is equivalent to pairing the first run of the string with the last, the second with the second-to-last, and so on. This gives an exact token count of 1 + ⌈ r / 2 ⌉ 1+\lceil r/2\rceil for a string with r r maximal runs, and matches a lower bound that holds for any admissible bilateral run-peeling scheme. From the run-pairing theorem the main structural properties follow as corollaries: the irreducible peeling kernel uses at most two symbols; palindromes are precisely the strings whose run-length encoding is symmetric with an odd number of runs; the image of the decomposition admits an explicit finite-state characterisation; and changing one run length rewrites exactly one content token.



1
Introduction

Most string decompositions process the input from one end to the other.
Lempel–Ziv
[
3
,
6
,
7
]
parses left-to-right against a dictionary
of previously seen substrings; the Burrows–Wheeler
Transform
[
1
]
permutes characters to cluster identical symbols;
run-length encoding walks the string once and collapses adjacent duplicates.
Each of these captures something real (repetition, clustering, local
homogeneity), but none exposes the
outside-in
structure of a string:
the way a string’s boundary runs can be peeled away, layer by layer, to
reveal an inner core.

We study one such decomposition.
Flashback
wraps the input in
sentinels and, at each step, removes the maximal run from each end at
once, recording the two peeled runs as a single
bilateral token

together with the split between them. The companion procedure

\mathcal{F}^{-1}
reconstructs the string by nesting the tokens from the
inside out. The algorithm is deterministic, runs in
O(n)
time and space,
and is exactly reversible.

The algorithm is short; the structural theory it opens up is the point
of this paper. Once the decomposition is phrased at the run level, a
single observation drives most of what follows: Flashback is equivalent
to pairing the first run of the string with the last, the second with
the second-to-last, and so on. From that one identification the token
count, the irreducible kernel, a palindrome test, a description of the
image of
\mathcal{F}
, and an exact edit-locality theorem all fall out
as corollaries. Flashback is not a compression scheme (the total
character count across tokens equals
n+2
); it is a structural tool for
reasoning about run-level symmetry, and to our knowledge the
decomposition has not been studied before.

3
The Flashback Algorithm

Flashback consists of two procedures: a
decomposition

\mathcal{F}
that turns a string into a token sequence, and a

reconstruction

\mathcal{F}^{-1}
that inverts it exactly.

3.1
Decomposition

The idea is simple. We wrap the input string in two sentinel characters,
and then repeatedly remove the maximal runs at the two ends, emitting each
pair as a single token. The sentinels
@
and
$
are
there only to make the algorithm uniform: without them a string that
already begins and ends with the same character would need a special case.

Concretely: on an active span, find the leading run and the trailing run;
concatenate them into a symbol string and record the split position
(the length of the leading run); then recurse on the middle. The
recursion stops when the middle is empty: either the span itself is
empty, or the front and back runs together cover it.

Reconstruction

4
Correctness

This section establishes the two facts that make Flashback a genuine
decomposition: the token sequence is an exact inverse of the string, and
it is the only token sequence consistent with the rules. We then collect
the small set of invariants that subsequent sections will use repeatedly.

Throughout, let
s\in\Sigma^{*}
with
|s|=n
and

T=\mathcal{F}(s)=[\tau_{0},\ldots,\tau_{k-1}]
with

\tau_{d}=(\sigma_{d},p_{d})
; let
[\mathit{lo}_{d},\mathit{hi}_{d})
be the
active span at depth
d
.

Remark 4.1

(Empty string)
.

For
s=\varepsilon
,
\hat{s}=\texttt{@\$}
is a single span whose leading
and trailing runs cover it entirely, so
Peel
emits one terminal
token
\tau_{0}=(\texttt{@\$},0)
. This is the only degenerate case; all
later statements assume
|s|\geq 1
unless noted.

4.1
Reversibility and Uniqueness

Theorem 4.2

(Reversibility)
.

\mathcal{F}^{-1}\bigl(\mathcal{F}(s)\bigr)=s
for every
s\in\Sigma^{*}
.

Proof.

We prove the stronger local claim that
Peel
and
Nest
are
inverses level by level. Induct on the span length

m=\mathit{hi}-\mathit{lo}
: the tokens emitted by
Peel
on

\hat{s}[\mathit{lo}..\mathit{hi})
are exactly what
Nest
needs
to reconstruct that span.

Base
(
m\leq 1
, or the span is a single run).
Peel
emits
one terminal token
(\sigma,0)
with
\sigma=\hat{s}[\mathit{lo}..\mathit{hi})
;

Nest
returns
\sigma
verbatim.

Inductive step.
Let the leading run have length
\ell\geq 1
and the
trailing run start at
r
, with
b=\mathit{hi}-r\geq 1
.
Peel
emits

\tau_{d}=(\sigma_{d},\ell)
with

\sigma_{d}=\hat{s}[\mathit{lo}..\mathit{lo}{+}\ell)\,\|\,\hat{s}[r..\mathit{hi})

and recurses on the middle
\hat{s}[\mathit{lo}{+}\ell..r)
, whose length

m-\ell-b<m
gives the inductive hypothesis.
Nest
at depth
d

computes

\sigma_{d}[1..\ell]\;\|\;\textsc{Nest}(T,d{+}1)\;\|\;\sigma_{d}[\ell{+}1..|\sigma_{d}|]=\hat{s}[\mathit{lo}..\mathit{hi}).

Applying the claim to the full span and stripping sentinels yields
s
.
∎

Theorem 4.3

(Uniqueness)
.

\mathcal{F}(s)
is the unique sequence of bilateral tokens consistent with
the decomposition rules.

Proof.

At each depth, maximality fixes the leading and trailing runs uniquely, so

\sigma_{d}
,
p_{d}
, and the middle boundaries are all forced. The active span
strictly shrinks at every non-terminal depth (
Proposition

4.4
), so the
recursion terminates in finitely many steps, producing a unique finite
sequence.
∎

4.2
Structural Invariants

The following three invariants are used throughout the rest of the paper:
the active spans form a nested chain, the token symbol strings partition
the characters of
\hat{s}
, and the sentinel and terminal tokens occupy
fixed positions in
T
. All three are straightforward consequences of the
algorithm, but stating them explicitly pays off later.

Proposition 4.4

(Nested spans)
.

The active spans form a strictly decreasing chain

[\mathit{lo}_{0},\mathit{hi}_{0})\supsetneq[\mathit{lo}_{1},\mathit{hi}_{1})\supsetneq\cdots
, with

\mathit{lo}_{d+1}=\mathit{lo}_{d}+\ell_{d}
and
\mathit{hi}_{d+1}=r_{d}
.

Proof.

At each non-terminal depth,
\ell_{d}\geq 1
and
\mathit{hi}_{d}-r_{d}\geq 1
, so
the new span is a proper subinterval of the current one.
∎

Proposition 4.5

(Alphabet partition)
.

The token symbol strings form a multiset partition of
\hat{s}
:

\biguplus_{d=0}^{k-1}\mathrm{chars}(\sigma_{d})=\mathrm{chars}(\hat{s})
.
In particular,

\sum_{d=0}^{k-1}|\sigma_{d}|=n+2.

Proof.

At every depth,
\sigma_{d}
contains the characters of the leading and
trailing runs; the middle, passed to the next level, is disjoint from both.
By
Proposition

4.4
, induction covers all characters exactly once.
∎

Proposition 4.6

(Sentinel and terminal tokens)
.

For
|s|\geq 1
the first token is
\tau_{0}=(\texttt{@\$},1)
, non-terminal
with split position
1
. A terminal token (
p=0
) can appear only as the
last element of
T
.

Proof.

Since
\texttt{@}\neq\texttt{\$}
and neither lies in
\Sigma
, both runs at
depth 0 have length 1; the middle is
s
, which is non-empty, so the token
is non-terminal with
\sigma_{0}=\texttt{@\$}
and
p_{0}=1
. A terminal token
is emitted only when
Peel
does not recurse, hence no further tokens
follow.
∎

5
Complexity

5.1
Time and Space

Theorem 5.1

(Linear time and space)
.

Both
\mathcal{F}
and
\mathcal{F}^{-1}
run in
\Theta(n)
time and use

O(n)
space in the word-RAM model.

Proof.

Decomposition.
At depth
d
, scanning the leading and trailing runs
performs
\ell_{d}+b_{d}
successful comparisons and at most two failing ones.
The
\ell_{d}+b_{d}
matched characters are consumed into
\sigma_{d}
and never
revisited. By
Proposition

their total is
n+2
; failing
comparisons sum to at most
2k\leq n+O(1)
. Token emission is

O(|\sigma_{d}|)
, again summing to
n+2
.

Reconstruction.

Nest
writes each character directly to its
final position, totalling
n+2
writes (
Proposition

4.5
),
with
O(1)
bookkeeping per token.

Space.
The sentinel-wrapped string, token list, and output buffer
are each
O(n)
. Decomposition is tail-recursive and admits an iterative
rewrite in
O(1)
auxiliary space (
Section

A.1
).
∎

5.2
Expected Token Count for Random Strings

Theorem 5.2

(Expected token count)
.

Let
s
have length
n\geq 2
with each character drawn i.i.d. uniformly
from an alphabet of size
\sigma\geq 2
, and set
p=(\sigma-1)/\sigma
. Then

r(s)-1\sim\mathrm{Bin}(n{-}1,p)
and

\mathbb{E}[k]\;=\;1+\frac{1+(n-1)p}{2}+\frac{1+\bigl((2-\sigma)/\sigma\bigr)^{n-1}}{4}\;=\;\frac{n(\sigma-1)}{2\sigma}+O(1).

Proof.

Adjacent characters differ independently with probability
p
, so

X:=r-1\sim\mathrm{Bin}(n{-}1,p)
. By
Theorem

6.2
,

k=1+\lceil r/2\rceil=1+\lceil(X+1)/2\rceil
and

\lceil(X+1)/2\rceil=(X+1+\mathbf{1}_{X\text{ even}})/2
. For
X\sim\mathrm{Bin}(n{-}1,p)
,
\Pr(X\text{ even})=\tfrac{1}{2}(1+(1-2p)^{n-1})
,
and
1-2p=(2-\sigma)/\sigma
. Substituting
\mathbb{E}[X]=(n{-}1)p
gives
the formula; the asymptotic follows from
|(2-\sigma)/\sigma|<1
for

\sigma\geq 3
(and vanishing for
\sigma=2
).
∎

The full distribution of
k
is available in closed form since

k=1+\lceil(1+X)/2\rceil
; the exact variance and kernel-alphabet
statistics are recorded in
Section

A.2
.

6
Structural Analysis

The algorithm described so far is short, but its real content is
structural: Flashback acts on the run-level shape of a string, not on
individual characters. Once we make this observation precise in the

run-pairing theorem
below, most other properties of the
decomposition follow almost mechanically: kernel size, palindromes, edit
locality, and the image of
\mathcal{F}
are all corollaries of the same
pairing identity. The rest of the section is organised around that
theorem: first its statement, then a matching lower bound, and finally
the downstream consequences.

6.1
Flashback as Bilateral Run Pairing

Definition 6.1

(Maximal runs and RLE)
.

For a non-empty string
s
, the
run-length encoding
(RLE) is the
unique decomposition

s\;=\;a_{1}^{m_{1}}\,a_{2}^{m_{2}}\,\cdots\,a_{r}^{m_{r}},

where each
a_{i}\in\Sigma
is the symbol of the
i
-th run, each

m_{i}\geq 1
is its length, and consecutive symbols differ:

a_{i}\neq a_{i+1}
. The integer
r=r(s)
is the number of maximal
runs of
s
. Here
a^{m}
abbreviates the string consisting of
a

repeated
m
times; for example
\mathtt{CASSAYFF}
has RLE

\mathtt{C}^{1}\,\mathtt{A}^{1}\,\mathtt{S}^{2}\,\mathtt{A}^{1}\,\mathtt{Y}^{1}\,\mathtt{F}^{2}
and
r=6
.

Theorem 6.2

(Run-pairing theorem)
.

Let
s
have
r
maximal runs, and write
h=\lceil r/2\rceil
. Then

\mathcal{F}(s)
has exactly

k\;=\;1+h

tokens, arranged as follows.

•

Sentinel token.

\tau_{0}=(\texttt{@\$},\;1)
.

•

Content tokens.
For
1\leq j\leq h-1
, token
\tau_{j}

pairs the
j
-th run from the left with the
j
-th run from the
right:

\tau_{j}\;=\;\bigl(a_{j}^{m_{j}}\cdot a_{r+1-j}^{m_{r+1-j}},\;m_{j}\bigr).

•

Terminal token.

\tau_{k-1}
records the middle run, or
the two middle runs if
r
is even:

\tau_{k-1}\;=\;\begin{cases}\bigl(a_{h}^{m_{h}},\;0\bigr)&\text{if }r\text{ is odd},\\[3.0pt]
\bigl(a_{h}^{m_{h}}\cdot a_{h+1}^{m_{h+1}},\;0\bigr)&\text{if }r\text{ is even}.\end{cases}

In particular,
k\leq\lceil n/2\rceil+1
, with equality exactly when
every run has length
1
(i.e.
r=n
).

Proof.

The sentinels
@
and
$
are distinct and lie outside

\Sigma
, so at depth
0
they always peel as
\tau_{0}=(\texttt{@\$},1)
,
with the middle being
s
itself. It therefore suffices to count the
tokens
Peel
emits on a bare (unsentineled) span with
r
runs,
and show this equals
h
with the claimed shape.

We proceed by induction on
r
. Since
a_{i}\neq a_{i+1}
in any RLE, the
leading run of the span is always exactly
a_{1}^{m_{1}}
and the trailing
run is exactly
a_{r}^{m_{r}}
.

Base cases.

•

r=1
: the span is one run, so
Peel
emits a single
terminal token
\tau_{k-1}=(a_{1}^{m_{1}},\,0)
. Count:
h=1
.

•

r=2
: the leading and trailing runs are adjacent and cover the
entire span, so
Peel
emits the terminal token

\tau_{k-1}=(a_{1}^{m_{1}}a_{2}^{m_{2}},\,0)
. Count:
h=1
.

Inductive step
(
r\geq 3
).
Peel
emits one content token

\tau_{1}=(a_{1}^{m_{1}}a_{r}^{m_{r}},\,m_{1})
and recurses on the middle, which
is the RLE
a_{2}^{m_{2}}\cdots a_{r-1}^{m_{r-1}}
with
r-2
runs and the
alternation property preserved. By the inductive hypothesis the
recursion contributes
\lceil(r-2)/2\rceil

6.2
Optimality of Maximal Peeling

Flashback always peels the entire boundary run on each side. A natural
question is whether peeling less aggressively (taking only part of the
front or back run at some level) could reduce the token count. It cannot:
the greedy choice is in fact globally optimal. To make the question precise
we first say what "admissible" means.

Definition 6.3

(Admissible bilateral run-peeling)
.

An
admissible bilateral run-peeling decomposition
of a non-empty
string
s
is built by applying the following rule to an active span until
the span is consumed.

•

Termination.
If the active span consists of a single run or
two adjacent runs, emit one terminal token for the span and stop.

•

Peeling step.
Otherwise let
L
be the length of the span’s
leading run and
R
the length of its trailing run. Choose any
integers
x\in\{1,\ldots,L\}
and
y\in\{1,\ldots,R\}
,
emit the token formed by the peeled prefix of length
x
and the
peeled suffix of length
y
, and recurse on the remaining middle.

Flashback is the special case
x=L
,
y=R
at every step: the two
boundary runs are always consumed in full.

Theorem 6.4

(Greedy optimality)
.

Every admissible bilateral run-peeling decomposition of
s
uses at least

\lceil r/2\rceil
content tokens, and Flashback attains this minimum.

Proof.

The idea is to track how many of the original RLE runs of
s
the active
span still intersects as peeling proceeds. Let
N
denote that count;
initially
N=r
.

Step 1: each non-terminal step decreases
N
by at most
2
.

A peeling step removes a prefix of length
x\geq 1
from the current
leading run and a suffix of length
y\geq 1
from the current trailing run.
Advancing the left endpoint of the span by
x
positions moves it across
at most one original run boundary, so at most one original run falls out
of the span on the left; symmetrically on the right.

Step 2: at termination,
N\leq 2
.
The termination rule fires
only when the active span is one run or two adjacent runs, hence
intersects at most two original RLE runs.

Step 3: arithmetic.
Suppose the decomposition emits
t
content
tokens in total. The last is the terminal token, so there are exactly

t-1
non-terminal steps. By Steps 1 and 2,

r\;-\;2(t-1)\;\leq\;N_{\text{final}}\;\leq\;2,

which rearranges to
t\geq 1+(r-2)/2
. Since
t
is an integer this
gives
t\geq\lceil r/2\rceil
.

By
Theorem

6.2
, Flashback produces exactly
\lceil r/2\rceil

content tokens, so the lower bound is tight.
∎

Corollary 6.5

(Even-run uniqueness)
.

If
r
is even, Flashback is the unique token-minimal admissible
decomposition.

Proof.

Write
r=2m
. A token-minimal decomposition uses
m
content tokens
and hence
m-1
non-terminal steps. The inequality
r-2(t-1)\leq 2

from the proof of
Theorem

6.4
is then an equality, so every
non-terminal step must reduce
N
by exactly
2
. This forces each step
to remove an original run from each side, i.e. to peel both boundary
runs completely, which is the Flashback rule.
∎

6.3
The Peeling Kernel

After all the pairing is done, one small piece is left over: the terminal
token’s symbol string. This residue is what remains once bilateral peeling
can no longer make progress, and we call it the
peeling kernel
.

Definition 6.6

(Peeling kernel)
.

The
peeling kernel
of
s
is
\mathcal{K}(s)=\sigma_{k-1}
, the
terminal token’s symbol string.

Corollary 6.7

(Kernel structure)
.

With
h=\lceil r/2\rceil
as in
Theorem

6.2
, the peeling
kernel is

\mathcal{K}(s)\;=\;\begin{cases}a_{h}^{m_{h}}&\text{if }r\text{ is odd,}\\[3.0pt]
a_{h}^{m_{h}}\cdot a_{h+1}^{m_{h+1}}&\text{if }r\text{ is even.}\end{cases}

In either case
|\mathrm{alphabet}(\mathcal{K})|\leq 2
.

Proof.

The formula for
\mathcal{K}(s)
is the symbol string of the terminal
token
\tau_{k-1}
in
Theorem

6.2
. Each case involves at
most two distinct symbols.
∎

Palindromes.

Flashback recovers a classical fact about run-length encoding: a string

s
is a palindrome if and only if
r
is odd and its RLE is symmetric
(
a_{j}=a_{r+1-j}
and
m_{j}=m_{r+1-j}
for
1\leq j\leq\lfloor r/2\rfloor
).
The equivalence follows from RLE uniqueness alone and does not use the
run-pairing theorem; we mention it because in Flashback terms it has a
clean form:
\mathcal{K}(s)
is a single run and every non-terminal
token has matching front and back symbols with equal-length pairs.

6.4
Edit Locality

Because
k
is a function of
r
alone and each content token depends
only on its paired pair of runs, edits have sharply local effects. The
cleanest statement concerns edits that preserve the RLE skeleton,
i.e. changes to run lengths that do not alter run symbols.

Proposition 6.8

(Run-length locality)
.

Let
s=a_{1}^{m_{1}}\cdots a_{r}^{m_{r}}
and
t=a_{1}^{m^{\prime}_{1}}\cdots a_{r}^{m^{\prime}_{r}}

have the same run symbols
a_{1},\ldots,a_{r}
(possibly with different
multiplicities), and let

D\;=\;\{\,i:m_{i}\neq m^{\prime}_{i}\,\}.

Then
\mathcal{F}(s)
and
\mathcal{F}(t)
differ at exactly the
content-token depths

\{\,\min(i,\,r+1-i):i\in D\,\}.

In particular, changing a single run length
m_{i}
rewrites exactly one
content token, at depth
\min(i,\,r+1-i)
.

Proof.

By
Theorem

6.2
, the content token at depth
d
pairs runs
d

and
r+1-d
(for non-terminal depths), and the terminal token
records the middle run or two middle runs. In both cases the token is
determined entirely by the lengths of its paired runs. Consequently,

\tau_{d}\neq\tau^{\prime}_{d}
if and only if at least one paired run has a
different length in
s
and
t
.

It remains to identify the depth at which run
i
is paired. Run
i

shares a token with run
r+1-i
, and that token sits at the smaller
of the two indices, namely
\min(i,\,r+1-i)
. Hence
\tau_{d}\neq\tau^{\prime}_{d}
iff
d=\min(i,\,r+1-i)
for some
i\in D
, giving
exactly the displayed set.
∎

Character-level edits are weaker but still bounded. A single insertion,
deletion, or substitution changes at most two run boundaries (merging or
creating them), so
|\Delta r|\leq 2
and, since
k=1+\lceil r/2\rceil
,

|\Delta k|\leq 1
. The token
count
is therefore stable under
local character edits, though individual token
contents
may shift
at several depths because the deeper active spans realign.

6.5
Image Characterisation

We close by identifying which token sequences actually arise. The
constraints are all local: each content token is a pair of runs, the
terminal is one or two runs, and consecutive depths must alternate
symbols on each side. These conditions can be checked in a single pass,
so membership in
\mathrm{Im}(\mathcal{F})
is decidable in linear time.

Theorem 6.9

(Valid token sequences)
.

Let
T=[(\texttt{@\$},1),\,(\sigma_{1},p_{1}),\,\ldots,\,(\sigma_{k-1},p_{k-1})]

be a candidate token sequence with
k\geq 2
and all non-sentinel
characters drawn from
\Sigma
. For each non-terminal depth

1\leq d\leq k-2
, write

a_{d}\;=\;\text{front symbol of $\tau_{d}$}\;=\;\sigma_{d}[1],\qquad c_{d}\;=\;\text{back symbol of $\tau_{d}$}\;=\;\sigma_{d}[|\sigma_{d}|].

Then
T
lies in the image of
\mathcal{F}
if and only if the following
conditions hold.

1.

Token form.
For each non-terminal depth
1\leq d\leq k-2
:

•

p_{d}\geq 1
and
|\sigma_{d}|-p_{d}\geq 1
(both the front
part
\sigma_{d}[1..p_{d}]
and the back part

\sigma_{d}[p_{d}+1..|\sigma_{d}|]
are non-empty);

•

the front part is a single run of
a_{d}
, and the back
part is a single run of
c_{d}
.

2.

Terminal form.

p_{k-1}=0
and
\sigma_{k-1}
is either
a single run
a^{m}
or two adjacent runs
a^{\ell}c^{b}
with
a\neq c
.

3.

Alternation
(only when
k\geq 3
):

•

Interior:
for
1\leq d\leq k-3
,

a_{d+1}\neq a_{d}
and
c_{d+1}\neq c_{d}
.

•

Boundary:
the first character of
\sigma_{k-1}

differs from
a_{k-2}
, and the last character of

\sigma_{k-1}
differs from
c_{k-2}
.

When
k=2
, only conditions (1) and (2) apply. Moreover,

\mathcal{F}(\mathcal{F}^{-1}(T))=T
for every valid
T
.

Proof sketch.

Necessity
is immediate from
Theorem

6.2
(giving (1)
and (2)) and RLE alternation (giving (3)).
Sufficiency
uses a
direct reassembly: the fronts, terminal, and reversed backs concatenate
into a string whose RLE is forced to be valid by conditions (1)–(3);
the full reassembly is given in
Section

A.3
.
∎

7
Related Work

Run-length encoding.

RLE replaces each maximal run
a^{k}
with the pair
(a,k)
.

Theorem

6.2
shows that Flashback is, in a precise sense, a
bilateral pairing of the RLE: it pairs the first run with the last, the second
with the second-to-last, and so on. Where RLE processes runs left-to-right,
Flashback processes them outside-in, capturing the nesting structure that RLE
discards. The token count
k=1+\lceil r/2\rceil
is determined entirely
by the number of runs
r
.

Lempel–Ziv decompositions.

The LZ76 factorisation
[
3
]
and its descendants
LZ77
[
6
]
/LZ78
[
7
]
parse left-to-right, greedily extending
each factor against a dictionary of previously seen substrings. LZ exploits

repetitive
structure across positions; Flashback exploits

bilateral boundary
structure. The two are complementary: LZ76 produces

O(n/\log n)
factors for random strings
[
3
]
, while Flashback
produces
\Theta(n)
tokens. Flashback is not a compression scheme.

Burrows–Wheeler Transform.

The BWT
[
1
]
is a reversible permutation that clusters identical
characters. It does not produce variable-length tokens. Flashback produces
an ordered token sequence with split positions that directly encode
reconstruction.

Bidirectional macro schemes.

Storer and Szymanski
[
5
]
introduced bidirectional macro schemes,
where substrings may reference each other in both directions. Computing the
smallest such scheme is NP-hard. Flashback uses no references: each token is
self-contained.

Lyndon factorisation.

The Lyndon factorisation
[
2
,
4
]
decomposes a string into
a non-increasing sequence of Lyndon words in linear time. It is based on
lexicographic properties and produces a sequential factorisation; Flashback’s
tokens encode bilateral boundary structure with an explicit nesting.

8
Conclusion

Flashback
is a small, deterministic decomposition that runs in

O(n)
time and space and is exactly reversible. Once phrased at the run
level, it turns out to be bilateral pairing of the run-length encoding
(
Theorem

6.2
), and that single observation is what carries the
rest of the paper: the
1+\lceil r/2\rceil
token count, the matching
lower bound over all admissible bilateral run-peeling schemes
(
Theorem

6.4
), the two-symbol kernel, the palindrome test,
and the image characterisation all follow as corollaries. One less
expected property is token-level edit locality: under a
skeleton-preserving run-length change, exactly one content token is
rewritten (
Proposition

6.8
). We see Flashback primarily
as a structural tool for reasoning about run-level symmetry rather than
as a competitor to existing string-compression or indexing schemes.
