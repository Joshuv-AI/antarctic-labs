 Executive Summary of CRADA Work:
 This collaboration between Lawrence Livermore National Security, LLC (LLNS) as manager and
 operator of Lawrence Livermore National Laboratory (LLNL) and Chevron USA Inc., acting through its
 Chevron Technical Center division, aimed at developing next-generation computational methods for the
 Elastic Stochastic Full Waveform Inversion (eSFWI). Seismic imaging is heavily used in the oil and gas
 industry for identifying and operating subsurface reservoirs. Improved seismic imaging methods can
 improve productivity, lower costs, and improve operational and environmental safety. This CRADA
 demonstrated that new high-performance computing (HPC) architectures being rolled out over the next
 five years can enable unprecedented seismic imaging resolution when using eSFWI techniques to process
 active seismic data. An open-source computational mini-application was developed, capable of
 demonstrating near-peak performance for eSFWI algorithms on CPU and GPU enabled HPC platforms.
 Performance was demonstrated on LLNL HPC systems such as Lassen, as well as on Chevron systems.
 This project benefited Chevron USA Inc. by demonstrating the potential computational efficiency of
 their full waveform inversion capabilities used to characterize oil/gas reservoirs, which in turn benefits

 Technical Objectives:
The main objective was to develop a portable open-source computational framework capable of
demonstrating near-peak performance for eSFWI algorithms on current and next-generation HPC platforms,
and to test performance on both LLNL HPC systems such as Lassen, and on Chevron systems. Another goal
is the integration of the portable eSFWI optimization framework into existing Chevron workflow scripting
frameworks used to evaluate the performance capabilities of various computational platforms.

 Actual Accomplishments:
First task was to establish a collaborative infrastructure to support code development and performance
benchmarking throughout the project lifetime. To that effect a private Github repository was created, and a
selected number of seismic wave propagation kernels were integrated into a portable framework. These are
representative of the domain representation classical used in an industrial FWI code. Additionally, these
kernels allowed to isolate key computational challenges and were used to provide an initial benchmark of
performance.
The second task focused on one seismic wave propagation kernel to assess the computational speed ups
obtained using a portable programming model based using RAJA. This setup allowed to fine tune
performance optimization, running simulations on LLNL Lassen cluster (see Figure 1). Task 3 was focusing
on further performance optimization with alternative algorithms. Higher order schemes were introduced.
Figures 2 & 3 illustrates weak scaling with and without the use of gpuDirect option for two different
rheologies, isotropic and transverse isotropic kernels. These results show that the kernels asymptote to
efficiencies above 60%.
Finally, task 4 aimed at performing a large-scale, reservoir-size, demonstration of full waveform inversion
plugging developed kernels in Chevron automatic Julia FWI wrapper. While we (LLNL) didn’t run the FWI
on an originally planned Chevron model, this framework was successfully installed on LLNL HPC system
and tested on a 2D Marmousi model for synthetic tests.
