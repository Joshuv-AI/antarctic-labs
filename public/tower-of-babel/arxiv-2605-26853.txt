A reparametrization invariant


Abstract
We introduce a nonabelian surface holonomy that is constructed from a one-form gauge potential that takes values in a loop algebra of the U ⁡ ( N ) U(N) gauge group. The surface holonomy parallel transports a nonabelian string. Although it is not manifest in our formulation, we will see that our nonabelian surface holonomy is invariant under reparametrizations of the surface.

Introduction

The question whether we can have a nonabelian generalization of the abelian Wilson surface

\displaystyle W(\Sigma)

\displaystyle=

\displaystyle\exp\left(ie\int_{\Sigma}B\right)

(1.1)

for a closed surface
\Sigma
was analyzed in
[
1
]
. It was shown, by using the method of
[
2
]
, that a nonabelian generalization can not be foliation invariant. If we foliate the surface by closed loops, then as we change the foliation infinitesimally, it was shown that the Wilson surface will be invariant only if the gauge group is abelian. However, this argument relies on the assumption that the nonabelian generalization involves a two-form gauge field of the form
B=B^{a}t_{a}
where
t_{a}
are generators of the gauge group satisfying a Lie algebra

\displaystyle[t_{a},t_{b}]

\displaystyle=

\displaystyle if_{ab}{}^{c}t_{c}

(1.2)

In this paper we will by-pass the no-go result of
[
1
]
by instead of
B
using a one-form gauge field
A=A^{a}t_{a}(s)
, where these generators satisfy a loop algebra without central extension.
The fact that
A
is a one-form might seem strange since we would naively expect that we shall have a two-form since we have a surface. Nevertheless, we will demonstrate that our Wilson surface, and more generally, surface holonomy, is invariant under reparametrizations of the surface.

Since gauge symmetry is a central concept in the construction, we begin in section
2
with presenting how the gauge symmetry transforms a wave function of a heavy closed string. Then in section
3
we present our definition of the surface holonomy that transports the string wave function gauge covariantly. In section
4
we show that the surface holonomy is invariant under deformation of the foliation of the surface. In section
5
we combine the foliation symmetry with reparametrization symmetry along each loop, to show that we have full reparametrization symmetry of the surface.

2
The nonabelian string

We consider a closed string that is embedded in spacetime as
s\mapsto C^{M}(s)
for some embedding functions
C^{M}(s)
in spacetime. We introduce an infinite-dimensional loop algebra extension of the
U(N)
Lie algebra that is generated by loop algebra generators
t_{a}(s)
that are parametrized by a continuous parameter
s
around a closed loop and that satisfy

\displaystyle[t_{a}(s),t_{b}(s^{\prime})]

\displaystyle=

\displaystyle i\delta(s-s^{\prime})f_{ab}{}^{c}t_{c}(s)

(2.1)

We next introduce a wave function
\psi^{i}(s)
where
i=1,...,N
transforms in the fundamental representation of
U(N)
. We define an action of the generator on the wave function element as follows,

\displaystyle t_{a}(s)\psi^{i}(s^{\prime})

\displaystyle=

\displaystyle\delta(s-s^{\prime})(t_{a})^{i}{}_{j}\psi^{j}(s)

(2.2)

where on the right-hand side appears the generators
(t_{a})^{i}{}_{j}
of the
U(N)
Lie algebra, satisfying

\displaystyle[t_{a},t_{b}]

\displaystyle=

\displaystyle if_{ab}{}^{c}t_{c}

(2.3)

One may check that (
2.1
) is realized on these wave function elements by using (
2.2
).

We define a
U(N)
gauge group element
g(C)
as

\displaystyle g(C)

\displaystyle=

\displaystyle\exp\left(ie\int ds\Lambda^{a}(C(s))t_{a}(s)\right)

(2.4)

No path ordering is needed in order to define this exponent unambiguously, that is, in a reparametrization invariant way, since
t_{a}(s)
commute at any two different points along the loop.

The group element acts on the wave function as

\displaystyle g(C)\psi^{i}(s)

\displaystyle=

\displaystyle g^{i}{}_{j}(C(s))\psi^{j}(s)

(2.5)

where we define

\displaystyle g^{i}{}_{j}(C(s))

\displaystyle=

\displaystyle\left(e^{ie\Lambda^{a}(C(s))t_{a}}\right){}^{i}{}_{j}

(2.6)

Now this can be generalized to an arbitrary representation. All that we need to do, is to replace
i
with an index
\alpha
that transforms in the given representation. Then starting out from

\displaystyle t_{a}(s)\psi^{\alpha}(s^{\prime})

\displaystyle=

\displaystyle\delta(s-s^{\prime})(t_{a})^{\alpha}{}_{\beta}\psi^{\beta}(s)

(2.7)

we derive

\displaystyle g(C)\psi^{\alpha}(s)

\displaystyle=

\displaystyle g^{\alpha}{}_{\beta}(C(s))\psi^{\beta}(s)

(2.8)

For an integrated wave function over an interval, this implies that its gauge transformation is given by

\displaystyle g(C)\int_{I}ds\psi^{\alpha}(s)

\displaystyle=

\displaystyle\int_{I}dsg^{\alpha}{}_{\beta}(C(s))\psi^{\beta}(s)

(2.9)

Now we like to generalize in another direction. We consider a wave function that is a product,

\displaystyle\psi^{\alpha_{1}\alpha_{2}\cdots\alpha_{K}}(s_{1},s_{2},\dots,s_{K})

\displaystyle=

\displaystyle\psi^{\alpha_{1}}(s_{1})\psi^{\alpha_{2}}(s_{2})\cdots\psi^{\alpha_{K}}(s_{K})

(2.10)

Its gauge transformation is

\displaystyle g(C)\psi^{\alpha_{1}\alpha_{2}\cdots\alpha_{K}}(s_{1},s_{2},\dots,s_{K})

\displaystyle=

\displaystyle g^{\alpha_{1}}{}_{\beta_{1}}(C(s_{1}))\cdots g^{\alpha_{K}}{}_{\beta_{K}}(C(s_{K}))

(2.12)

\displaystyle\psi^{\beta_{1}\dots\beta_{K}}(s_{1},s_{2},\dots,s_{K})

We have introduced
K
different particles that live on a circle and shown that the group element
g(C)
has a natural action on the wave function on this system. One might now want to ask whether we can reinterpret this multi-particle wave function as a wave function of a closed nonabelian string, perhaps by taking the large
K
limit. However, we will not attempt to answer this question here. Instead we will adopt the viewpoint that the wave function on which
g(C)
and also the surface holonomy
U(C,C_{0})
, to be introduced shortly, have a natural action, could very well be the wave function that describes certain degrees of freedom that may or may not exist in the theory with the given surface holonomy.

We can now understand from this wave function representation that the group composition rule

\displaystyle g_{1}(C)g_{2}(C)

\displaystyle=

\displaystyle g_{3}(C)

(2.13)

gets inherited from the group composition rule of corresponding group elements in Yang-Mills theory,

\displaystyle g_{1}(x)g_{2}(x)

\displaystyle=

\displaystyle g_{3}(x)

(2.14)

where
g(x)=e^{ie\Lambda^{a}(x)t_{a}}
. Two gauge parameters
\Lambda_{1}
and
\Lambda_{2}
are mapped into a third gauge parameter
\Lambda_{3}
in some rather complicated way. From this computation of
\Lambda_{3}
from
\Lambda_{1,2}
in the Yang-Mills case, we immediately obtain the structure of the
g_{3}(C)
loop group element,

\displaystyle e^{ie\int ds\Lambda_{1}^{a}(C(s))t_{a}(s)}e^{ie\int ds^{\prime}\Lambda_{2}^{b}(C(s^{\prime}))t_{b}(s^{\prime})}

\displaystyle=

\displaystyle e^{ie\int ds\Lambda_{3}^{a}(C(s))t_{a}(s)}

(2.15)

Namely
\Lambda_{1,2,3}(C(s))
are nothing but the gauge parameters in the Yang-Mills case evaluated at a point
C(s)
on the string, so the mapping from
\Lambda_{1,2}
to
\Lambda_{3}
will be also the same as in the Yang-Mills case. As a by-product, we have now essentially shown that
g(C)
are acting like group elements, where multiplying two such elements gives us a new element of the same type. Strictly speaking, what we have shown is that whenever
g(C_{1})g(C_{2})
acts on a wave function of the product form (
2.10
) for any
K
then we have the group property. But does that mean that we always have the group property? In fact it is not very difficult to prove the group property in general using the Baker–Campbell–Hausdorff formula. To second order we find that

\displaystyle\Lambda_{3}^{c}(C(s))

\displaystyle=

\displaystyle\Lambda_{1}^{c}(C(s))+\Lambda_{2}^{c}(C(s))-\frac{e}{2}f_{ab}{}^{c}\Lambda_{1}^{a}(C(s))\Lambda_{2}^{b}(C(s))+{\cal{O}}(e^{2})

(2.16)

with a similar local structure that is extending to all higher orders.

In appendix
B
we show that when a string splits into two strings, the group element factorizes into two factors where each factor is a group element associated to each closed string.

3
The nonabelian surface holonomy

A surface holonomy
U(C,C_{0})
parallel transports the string from an initial string configuration
C_{0}
to a final string configuration
C
by acting on the wave function of the string as

\displaystyle\psi(C_{0})\rightarrow\psi(C)=U(C,C_{0})\psi(C_{0})

(3.1)

A gauge transformation acts on the wave function and on the surface holonomy together as

\displaystyle\psi(C)

\displaystyle\rightarrow

\displaystyle\psi^{g}(C)=g(C)\psi(C)

(3.2)

\displaystyle U(C,C_{0})

\displaystyle\rightarrow

\displaystyle U^{g}(C,C_{0})=g(C)U(C,C_{0})g(C_{0})^{-1}

(3.3)

To construct the surface holonomy explicitly, we will assume that we are given a gauge potential
A_{M}^{a}(x)
on spacetime that takes values in the adjoint representation of the
U(N)
gauge group. We define a gauge field on a closed string
C
as

\displaystyle{\cal{A}}(C)

\displaystyle=

\displaystyle\int ds\;A_{M}^{a}(C(s))\delta C^{M}(s)t_{a}(s)

(3.4)

This gauge field is invariant under a reparametrization of the loop
C
. We explain this in detail in the appendix.

We shall now foliate the surface with a family of closed strings that are parametrized by a time variable
t

\displaystyle t\mapsto C^{M}(t)

(3.5)

and we will then express a point on a given loop as
X^{M}(t,s):=C^{M}(t)(s)
. We define the time component of the gauge potential as

\displaystyle{\cal{A}}_{t}(C(t))

\displaystyle=

\displaystyle\int ds\;A_{M}^{a}(X(t,s))\frac{\partial X^{M}(t,s)}{\partial t}t_{a}(s)

(3.6)

We define the surface holonomy
U(C(t),C(t_{0});\Sigma)
from an initial string configuration
C(t_{0})
at an initial time
t_{0}
to a string configuration
C(t)
at time
t
along a surface
\Sigma
connecting the two strings. The string at any given time
t
can be a set of several disjoint closed strings, and the number of disjoint strings at a given time can change as we traverse the surface
\Sigma
in time by processes where one string splits into two strings or where two strings merge into one. This results in a surface
\Sigma
with holes in it, similar to a higher genus Riemann surface, but where this surface is open and in Lorentzian signature. Regardless of the topology of surface
\Sigma
, the surface holonomy will be characterised by the transport equation

\displaystyle\frac{dU(C(t),C(t_{0}))}{dt}

\displaystyle=

\displaystyle ie{\cal{A}}_{t}(C(t))U(C(t),C(t_{0}))

(3.7)

together with the initial condition
U(C(t_{0}),C(t_{0}))=1
. The solution is a path-ordered exponent

\displaystyle U(C(t),C(t_{0}))

\displaystyle=

\displaystyle P\exp\left(ie\int_{t_{0}}^{t}dt\int dsA_{M}^{a}(X(t,s))t_{a}(s)\frac{\partial X^{M}(t,s)}{\partial t}\right)

(3.8)

Notice that the tangential derivative to each loop,
\frac{\partial X^{M}(t,s)}{\partial s}
at a given time
t
, does not appear in the surface holonomy. Instead what plays the role of this tangential derivative is
t_{a}(s)
. On a more philosophical note, this shows that the spatial direction along the loop has disappeared from sight and instead we only see the internal gauge indices. Could this be a hint that space in a final formulation of the theory may not appear at all, much like the ether before Einstein’s theory of special relativity?

From the gauge transformation

\displaystyle U(C(t),C(t_{0});\Sigma)\rightarrow U^{g}(C(t),C(t_{0});\Sigma)=g(C(t))U(C(t),C(t_{0});\Sigma)g^{-1}(C(t_{0}))

(3.9)

of the surface holonomy, we derive the gauge transformation

\displaystyle{\cal{A}}(C)\rightarrow{\cal{A}}^{g}(C)=g(C){\cal{A}}(C)g^{-1}(C)-\frac{i}{e}dg(C)\;g^{-1}(C)

(3.10)

of the gauge potential for an arbitrary closed string
C
. Here the differential operator is defined as

\displaystyle d

\displaystyle=

\displaystyle\int ds\delta C^{M}(s)\frac{\delta}{\delta C^{M}(s)}

(3.11)

If we are given a time-parametrized family of closed loops
t\mapsto C(t)
, then for the time-component of the gauge field, we have a very similar transformation rule,

\displaystyle{\cal{A}}_{t}^{g}(C(t))

\displaystyle=

\displaystyle g(C(t)){\cal{A}}_{t}(C(t))g^{-1}(C(t))-\frac{i}{e}\frac{dg(C(t))}{dt}g^{-1}(C(t))

(3.12)

For an infinitesimal gauge variation, we may expand the gauge parameter to first order,

\displaystyle g(C)

\displaystyle=

\displaystyle 1+ie\Lambda(C)+{\cal{O}}(\Lambda(C)^{2})

(3.13)

We then obtain the infinitesimal gauge variation

\displaystyle\delta_{\Lambda}{\cal{A}}(C)=d\Lambda(C)-ie[{\cal{A}}(C),\Lambda(C)]+{\cal{O}}(\Lambda(C)^{2})

(3.14)

We may then also define a gauge covariant derivative as

\displaystyle D

\displaystyle=

\displaystyle d-ie{\cal{A}}(C)

(3.15)

that acts in a certain representation of the loop algebra, as determined by the object on which it acts. For an infinitesimal gauge parameter
\Lambda
we then have the infinitesimal gauge variation of the gauge field

\displaystyle\delta_{\Lambda}{\cal{A}}=D\Lambda=d\Lambda-ie[{\cal{A}},\Lambda]

(3.16)

which explicitly becomes

\displaystyle\delta_{\Lambda}{\cal{A}}

\displaystyle=

\displaystyle\int ds\left(\partial_{M}\Lambda^{a}+eA_{M}^{b}\Lambda^{c}f_{bc}{}^{a}\right)\delta C^{M}t_{a}(s)

(3.17)

The gauge algebra can be obtained from this infinitesimal version of the gauge variation by making a second variation and then by commuting the order of these two variations. In this way we get

\displaystyle[\delta_{\Lambda^{\prime}},\delta_{\Lambda}]{\cal{A}}

\displaystyle=

\displaystyle D\Lambda^{\prime\prime}

(3.18)

where the gauge parameter is

\displaystyle\Lambda^{\prime\prime}

\displaystyle=

\displaystyle-ie[\Lambda^{\prime},\Lambda]

(3.19)

Its explicit form is

\displaystyle\Lambda^{\prime\prime}(C)

\displaystyle=

\displaystyle e\oint ds\Lambda^{\prime b}(C(s))\Lambda^{c}(C(s))f_{bc}{}^{a}t_{a}(s)

(3.20)

For the finite gauge transformations, they form a group. If we make a second gauge transformation,

A^{g}
and transforms it into
(A^{g})^{g^{\prime}}
. The second view (that we adopt here) is that the second gauge variation again acts on

(A^{g^{\prime}})^{g}
.
we find that

\displaystyle({\cal{A}}^{g^{\prime}})^{g}

\displaystyle=

\displaystyle{\cal{A}}^{gg^{\prime}}

(3.21)

The gauge covariant field strength is

\displaystyle{\cal{F}}

\displaystyle=

\displaystyle d{\cal{A}}-ie{\cal{A}}\wedge{\cal{A}}

(3.22)

which transforms as

\displaystyle{\cal{F}}^{g}

\displaystyle=

\displaystyle g{\cal{F}}g^{-1}

(3.23)

The explicit form of the field strength is

\displaystyle{\cal{F}}(C)

\displaystyle=

\displaystyle\frac{1}{2}\int dsF_{MN}^{a}(C(s))\delta C^{M}(s)\wedge\delta C^{N}(s)t_{a}(s)

(3.24)

where

\displaystyle F_{MN}^{a}

\displaystyle:=

\displaystyle\partial_{M}A_{N}^{a}-\partial_{N}A_{M}^{a}+eA_{M}^{b}A_{N}^{c}f_{bc}{}^{a}

4
Foliation independence of the surface holonomy

From the defining equation (
3.7
), it follows that

\displaystyle\frac{d}{dt}\left(U^{-1}(t,t_{0})\delta U(t,t_{0})\right)

\displaystyle=

\displaystyle ieU^{-1}(t,t_{0})\delta{\cal{A}}_{t}(t)U(t,t_{0})

(4.1)

where, in this section, we are using a short-hand notation
U(t,t_{0})
, for the surface holonomy
U(C(t),C(t_{0});\Sigma)
. Let us now integrate the above relation from the initial time
t_{0}
up to some final time
t_{1}
,

\displaystyle U^{-1}(t_{1},t_{0})\delta U(t_{1},t_{0})

\displaystyle=

\displaystyle ie\int_{t_{0}}^{t_{1}}dtU^{-1}(t,t_{0})\delta{\cal{A}}_{t}(t)U(t,t_{0})

(4.2)

where we have noted that
U(t_{0},t_{0})=1
, whose variation vanishes.

For the right-hand side we need to obtain how
{\cal{A}}_{t}
varies as we make an infinitesimal variation of the loop
C
at a given time
t
,

\displaystyle\delta C^{M}(t,s)

\displaystyle=

\displaystyle\xi^{M}(t,s)

(4.3)

The variation is computed as
\delta{\cal{A}}_{t}(C):={\cal{A}}_{t}(C+\xi)-{\cal{A}}_{t}(C)
so it is varying like a scalar field under this specific variation of the loop where we do not change the parametrization of the time variable
t
. We compute this variation with the result

\displaystyle\delta{\cal{A}}_{t}(C)

\displaystyle=

\displaystyle\int ds\left(\partial_{M}A_{N}^{a}-\partial_{N}A_{M}^{a}\right)\xi^{M}\frac{\partial C^{N}}{\partial t}t_{a}(s)+\frac{d}{dt}\int ds\left(A_{M}^{a}\xi^{M}\right)t_{a}(s)

(4.4)

To make the notation more convenient, we will now absorb
t_{a}(s)
into the gauge field and use a short notation as
A_{M}:=A_{M}^{a}(C(t,s))t_{a}(s)
and similarly, for the field strength we will write it as
F_{MN}:=F_{MN}^{a}(C(t,s))t_{a}(s)
where we define
F_{MN}^{a}
as in equation (
3.25
). We then get

\displaystyle U^{-1}(t_{1},t_{0})\delta U(t_{1},t_{0})

\displaystyle=

\displaystyle ie\int_{t_{0}}^{t_{1}}dtU(t,t_{0})^{-1}\int ds\left(\partial_{M}A_{N}-\partial_{N}A_{M}\right)\xi^{M}\frac{\partial C^{N}}{\partial t}U(t,t_{0})

(4.8)

\displaystyle+ie\left[\int dsU^{-1}A_{M}U\xi^{M}\right]^{t_{1}}_{t_{0}}

\displaystyle+ie\int_{t_{0}}^{t_{1}}dtU^{-1}\frac{dU}{dt}\int dsU^{-1}A_{M}U\xi^{M}

\displaystyle-ie\int_{t_{0}}^{t_{1}}dt\int dsU^{-1}A_{M}\frac{dU}{dt}\xi^{M}

The two last lines, when we apply the defining equation (
3.7
), give us a commutator,

\displaystyle-e^{2}\int_{t_{0}}^{t_{1}}dtU^{-1}\left[{\cal{A}}_{t},\int dsA_{M}\xi^{M}\right]U

(4.9)

\displaystyle=

\displaystyle ie\int_{t_{0}}^{t_{1}}dtU^{-1}\int dseA_{M}^{a}A_{N}^{b}f_{ab}{}^{c}t_{c}(s)\xi^{M}\frac{\partial C^{N}}{\partial t}U

(4.10)

and then that combines with the remaining linear terms into the field strength tensor and we get

\displaystyle U^{-1}(t_{1},t_{0})\delta U(t_{1},t_{0})

\displaystyle=

\displaystyle ie\int_{t_{0}}^{t_{1}}dtU^{-1}\int dsF_{MN}\xi^{M}\frac{\partial C^{N}}{\partial t}U

(4.12)

\displaystyle+ie\left[\int dsU^{-1}A_{M}\xi^{M}U\right]^{t_{1}}_{t_{0}}

We now multiply both sides with
U(t_{1},t_{0})
and apply the relation

\displaystyle U(t_{1},t_{0})U^{-1}(t,t_{0})

\displaystyle=

\displaystyle U(t_{1},t)

(4.13)

The final result is

\displaystyle\delta U(t_{1},t_{0})

\displaystyle=

\displaystyle ie\int_{t_{0}}^{t_{1}}dtU(t_{1},t)\int dsF_{MN}(t)\xi^{M}(t)\frac{\partial C^{N}(t)}{\partial t}U(t,t_{0})

(4.14)

\displaystyle+ie\left[\int dsU(t_{1},t)A_{M}(t)\xi^{M}(t)U(t,t_{0})\right]^{t_{1}}_{t_{0}}

(4.15)

We now let the variation of the loop at each time be given by

\displaystyle\xi^{M}(t,s)

\displaystyle=

\displaystyle{\cal{\varepsilon}}(t,s)\frac{\partial X^{M}(t,s)}{\partial t}

(4.16)

where we impose Dirichlet boundary conditions at the initial and final time,

\displaystyle{\cal{\varepsilon}}(t_{1},s)

\displaystyle=

\displaystyle 0

(4.17)

\displaystyle{\cal{\varepsilon}}(t_{0},s)

\displaystyle=

\displaystyle 0

(4.18)

which means that the boundary terms vanish, and we get only a contribution from the points
t
in the open interval
t_{1}>t>t_{0}
. But there we see that antisymmetry of
F_{MN}
when contracted with the symmetric combination
\partial_{t}C^{M}\partial_{t}C^{N}
gives zero. So we conclude that, with this particular variation, we get a vanishing variation of the surface holonomy,

\displaystyle\delta U(t_{1},t_{0})

\displaystyle=

\displaystyle 0

(4.19)

This means that the surface holonomy is invariant under transverse deformations of the loops that are foliating the surface, while we keep the initial and final loops fixed. That is to say that we keep the geometric shape of the surface fixed while we change how it is foliated by loops.

5
Reparametrization of the surface

Our surface is parametrized by two parameters,
s
and
t
. Let us first study the deformation

\displaystyle\delta X^{M}(t,s)

\displaystyle=

\displaystyle{\cal{\varepsilon}}(t,s)\frac{\partial X^{M}(t,s)}{\partial t}

(5.1)

We view these as
D
scalar fields on the surface. As such, they transform as

\displaystyle X^{\prime M}(t^{\prime},s^{\prime})

\displaystyle=

\displaystyle X^{M}(t,s)

(5.2)

Let us make an infinitesimal reparametrization of the surface of the form

\displaystyle t^{\prime}

\displaystyle=

\displaystyle t-{\cal{\varepsilon}}(t,s)

(5.3)

\displaystyle s^{\prime}

\displaystyle=

\displaystyle s

(5.4)

Then

\displaystyle\delta X^{M}(t,s)

\displaystyle=

\displaystyle{\cal{\varepsilon}}(t,s)\frac{\partial X^{M}(t,s)}{\partial t}

(5.5)

This is exactly the variation that we considered above, for which we showed that the surface holonomy is invariant, if we also impose Dirichlet boundary conditions at the initial and final time. After the deformation, the constant time slices are

\displaystyle(t^{\prime},s^{\prime})

\displaystyle=

\displaystyle(t-{\cal{\varepsilon}}(t,s),s)

(5.6)

for constant
t
.

But we also have reparametrization invariance along each constant time slice. So we can change the parameter
s
to another parameter
s_{1}
on each constant time slice. That means that we transform the initial coordinates as

\displaystyle(t,s)\rightarrow(t,s_{1})

(5.7)

where we define, for each constant
t
and arbitrary
s
along that constant
t
slice, a new variable
s_{1}
along that slice such that

\displaystyle s

\displaystyle=

\displaystyle f(t,s_{1})

(5.8)

\displaystyle s_{1}

\displaystyle=

\displaystyle h(t,s)

(5.9)

where the latter is the inverse relation to the former and both
f
and
h
are smooth nondegenerate functions of two variables. Still, also for the new parameter
s_{1}
, the constant time slices will be for constant
t
.

Now let us again make the transformation

\displaystyle(t^{\prime},s^{\prime})

\displaystyle=

\displaystyle(t-{\cal{\varepsilon}}(t,f(t,s_{1})),f(t,s_{1}))

(5.10)

Here
{\cal{\varepsilon}}(t,s)
is arbitrary so if we put

\displaystyle g(t,s_{1})

\displaystyle=

\displaystyle t-{\cal{\varepsilon}}(t,f(t,s_{1}))

(5.11)

then
g(t,s)
is also arbitrary, subject to the Dirichlet boundary conditions

\displaystyle g(t_{0},s_{1})

\displaystyle=

\displaystyle t_{0}

(5.12)

\displaystyle g(t_{1},s_{1})

\displaystyle=

\displaystyle t_{1}

(5.13)

We have obtained a general reparametrization of the form

\displaystyle t^{\prime}

\displaystyle=

\displaystyle g(t,s_{1})

(5.14)

\displaystyle s^{\prime}

\displaystyle=

\displaystyle f(t,s_{1})

(5.15)

relating the old parameters
(t,s_{1})
to the new parameters
(t^{\prime},s^{\prime})
. Since both
f
and
g
are arbitrary functions of the old parameters, subject to suitable boundary conditions, we see that we have now obtained a rather general reparametrization of the surface.

It remains to understand whether we can extend the reparametrization symmetry to allow for a general reparametrization of the surface at a boundary, say the final boundary at
t=t_{1}
. To this end, let us start by noting that if we do not impose the Dirichlet condition at this boundary, then we need to keep the boundary term in the variation of the surface holonomy, which from (
4.15
) and (
4.16
), becomes

\displaystyle\delta U(t_{1},t_{0})

\displaystyle=

\displaystyle ie\int dsA_{M}(t_{1},s)\xi^{M}(t_{1},s)U(t_{1},t_{0})

(5.16)

This is nothing but a gauge variation of the surface holonomy with the gauge parameter
\Lambda=A_{M}\xi^{M}
where
\xi^{M}(t,s)={\cal{\varepsilon}}(t,s)\frac{\partial X^{M}(t,s)}{\partial t}
. But now as we lifted the Dirichlet boundary condition, the surface itself has been slightly deformed at the boundary, by the amount

\displaystyle\delta X^{M}(t_{1},s)

\displaystyle=

\displaystyle{\cal{\varepsilon}}(t_{1},s)\frac{\partial X^{M}(t_{1},s)}{\partial t}

(5.17)

While this allowed us to perform a general reparametrization locally around
t=t_{1}
it thus came with the cost of creating a physical deformation of the geometric surface, which is not just a reparametrization of the surface. It is a physical deformation at the boundary. Now to conclude that we can have a general reparametrization of the surface at the boundary, we need to demonstrate that the surface holonomy is exactly invariant, not just invariant up to gauge, but actually invariant, if we do not physically deform the geometry of the surface. In order to answer that question, we need to understand exactly how the physical deformation of the surface changed the surface holonomy and then we can subtract that variation to obtain the surface holonomy of the original geometric surface, now with a general reparametrization all the way out to its boundary at
t=t_{1}
. This step is surprisingly easy. When we physically deform the surface by the amount
\delta X^{M}(t_{1},s)=\xi^{M}(t_{1},s)
, then our surface holonomy changes by the amount

\displaystyle\delta_{geom}U(t_{1},t_{0})

\displaystyle=

\displaystyle ie\int dsA_{M}(t_{1},s)\xi^{M}(t_{1},s)U(t_{1},t_{0})

(5.18)

This result is independent of how we parametrize the surface as it only depends on the variation
\delta X^{M}=\xi^{M}
of the embedding coordinates of the surface in spacetime. Now if we subtract this geometric variation from the reparametrization variation in (
5.16
), the net result is a vanishing variation of the surface holonomy. By a very similar argument one can also understand that we have general reparametrization invariance at the initial boundary at
t=t_{0}
. We conclude that the surface holonomy is fully reparametrization invariant.

6
The surface holonomy acting on the wave function

The starting point to obtain how the surface holonomy acts on the wave function is the following result,

\displaystyle{\cal{A}}_{t}(C(t))\psi^{\alpha}(t^{\prime},s^{\prime})

\displaystyle=

\displaystyle\int dsA_{M}^{a}(X(t,s))\frac{\partial X^{M}(t,s)}{\partial t}t_{a}(s)\psi^{\alpha}(t^{\prime},s^{\prime})

(6.1)

\displaystyle=

\displaystyle A_{M}^{a}(X(t,s^{\prime}))\frac{\partial X^{M}(t,s^{\prime})}{\partial t}(t_{a})^{\alpha}{}_{\beta}\psi^{\beta}(t^{\prime},s^{\prime})

(6.2)

The surface holonomy can be written as a Dyson series

\displaystyle U(C(t),C(t_{0}))

\displaystyle=

\displaystyle P\;\exp\left(ie\int dt{\cal{A}}_{t}\right)

(6.3)

\displaystyle=

\displaystyle 1+\sum_{n=1}^{\infty}(ie)^{n}\int_{t_{0}}^{t}dt_{1}\int_{t_{0}}^{t_{1}}dt_{2}\cdots\int_{t_{0}}^{t_{n-1}}dt_{n}

(6.5)

\displaystyle{{\cal{A}}}_{t}(t_{1}){{\cal{A}}}_{t}(t_{2})\dots{{\cal{A}}}_{t}(t_{n})

From these two results, we can immediately see that the surface holonomy will act on
\psi^{\alpha}(t_{0},s)
at an initial time in the way that a line holonomy acts. Namely, by acting on
\psi^{\alpha}(t_{0},s)
, each
{\cal{A}}_{t}(t_{k})
gets transformed into

\displaystyle{\cal{A}}_{t}(C(t_{k}))\mapsto{\cal{A}}_{t}(t_{k})=A_{M}^{a}(x(t_{k}))\frac{dx^{M}(t_{k})}{dt}t_{a}

(6.6)

where
t_{a}
now become ordinary Lie algebra generators and where the trajectory here is defined as

\displaystyle x(t)

\displaystyle=

\displaystyle X(t,s)

(6.7)

where
s
labels the point-particle. So the surface holonomy will transport a one-particle wave function just as if it was a line holonomy. Of course the surface holonomy is not a line holonomy in general. But indeed it acts like a line holonomy when it acts on a one-particle wave function.

This argument generalizes to a system of
K
point-particles described by the wave function
\psi^{\alpha_{1}\cdots\alpha_{K}}(s_{1},\dots,s_{K})
. For this system the surface holonomy acts as
K
independent line holonomies that transport each particle along its own trajectory

\displaystyle x_{n}(t)

\displaystyle=

\displaystyle X(t,s_{n})

(6.8)

These particle trajectories now appear to depend on the parametrization of the surface by
s
and
t
and as such it would be impossible to assign a physical relevance to such particles. It is interesting, however, to note that if we consider a tensionless string, then there will be a geometric null vector field on the string worldsheet that generates a null trajectory for each
s_{n}
and this null trajectory does not depend on the parametrization of the string worldsheet but appears in all aspects as a physical particle trajectory, which is independent of any coordinate choices. Specifically, in
[
4
]
a tensionless bosonic as well as a tensionless superstring was studied and it was shown that the classical equation of motion of the string, for each point of the string, satisfies the equation of motion of a massless point-particle. While any connection between that result and our string that also appears to be a collection of particles, will be a speculation, we can not rule out the possibility that our surface holonomy might be relevant for transporting tensionless strings that conjecturally may exist in the theory of multiple coincident M5 branes. But in any case, in order for our wave function to describe a smooth string, it is plausible that we will need to understand the limit
K\rightarrow\infty
. We will leave this problem as an open problem here. It would be also interesting if we could relate in a natural way our surface holonomy to the surface holonomy in the discrete lattice formulation
[
3
]
.

Appendix A
Reparametrization of the string

In this appendix we will show that for any Lie algebra valued spacetime field
f^{a}(x)
, the corresponding loop algebra valued integral is reparametrization invariant in the sense that

\displaystyle\int dsf^{a}(C(s))t_{a}(s)=\int ds^{\prime}f^{a}(C^{\prime}(s^{\prime}))t^{\prime}_{a}(s^{\prime})

(A.1)

where
s^{\prime}=s^{\prime}(s)
is a new parameter satisfying

\displaystyle\frac{ds^{\prime}}{ds}>0

(A.2)

at each point
s
on the loop. This reparametrization symmetry is true regardless of how
f^{a}(x)
transforms under spacetime diffeomorphisms. We could for example have

\displaystyle f^{a}(C(s)(t))=A_{M}^{a}(C(s)(t))\frac{\partial C^{M}(s)(t)}{\partial t}

(A.3)

where
X^{M}(t,s)=C^{M}(s)(t)
. The reparametrization invariance follows immediately if we assume that

\displaystyle t^{\prime}_{a}(s^{\prime})ds^{\prime}

\displaystyle=

\displaystyle t_{a}(s)ds

(A.4)

together with coordinate functions transforming as scalar fields under the reparametrization,

\displaystyle C^{\prime M}(s^{\prime})

\displaystyle=

\displaystyle C^{M}(s)

(A.5)

Let us also comment that the transformation of
t_{a}(s)ds
as a one-form together with the assumption (
A.2
) implies that the loop algebra is invariant. To see that, we use

\displaystyle\delta(s^{\prime}_{1}-s^{\prime}_{2})

\displaystyle=

\displaystyle\frac{\delta(s_{1}-s_{2})}{\left|\frac{ds^{\prime}}{ds}\right|}

(A.6)

Let us also obtain the infinitesimal version of the reparametrization symmetry where we take
s^{\prime}=s+{\cal{\varepsilon}}(s)
. Since
s
is an integration variable that we can freely rename, we have
2
2

2

We also need to adjust the range over which we integrate accordingly, thus if the range is
[s_{0},s_{1}]
for
s
, then the corresponding range will be
[s^{\prime}_{0},s^{\prime}_{1}]
for
s^{\prime}
. Of course here
s_{1}
and
s_{0}
are periodically identified through periodic boundary conditions, and these boundary conditions need to also be adjusted accordingly as we change the parameter so that for example
t_{a}(s_{1})=t_{a}(s_{0})

C(s_{1})=C(s_{0})

\displaystyle\int ds^{\prime}f^{a}(C^{\prime}(s^{\prime}))t^{\prime}_{a}(s^{\prime})=\int dsf^{a}(C^{\prime}(s))t^{\prime}_{a}(s)
