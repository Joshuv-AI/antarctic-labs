Beyond Linear Attention: Softmax Transformers Implement In-Context Reinforcement Learning
Zixuan Xie, Xinyu Liu, Claire Chen, Shuze Daniel Liu, Rohan Chandra, Shangtong Zhang

Abstract
In-context reinforcement learning (ICRL) studies agents that, after pretraining, adapt to new tasks by conditioning on additional context without parameter updates. Existing theoretical analyses of ICRL largely rely on linear attention, which replaces the softmax function in the standard attention with an identity mapping. This paper provides the first theoretical understanding of ICRL without making the unrealistic linear attention simplification. In particular, we consider the standard softmax attention used in practice. We show that, with certain parameters, the layerwise forward pass of a Transformer with such softmax attention is equivalent to iterative updates of a weighted softmax temporal difference (TD) learning algorithm. Here, weighted softmax TD is a new RL algorithm that performs policy evaluation in kernel space and adopts both linear TD and tabular TD as special cases. We also prove that under a certain contraction condition, the policy evaluation error decays as the number of layers grows, with the identified parameters above. Finally, we prove that those parameters are a global minimizer of a pretraining loss, explaining their emergence in our numerical experiments.

Introduction

Recent works on in-context reinforcement learning (ICRL,
36
) suggest that an RL agent can adapt to a new task at inference time without updating its parameters.
In this framework, an agent network is pretrained on a distribution of tasks and then deployed with fixed pretrained parameters.
At test time, the agent conditions on additional context generated within the new task, such as an interaction history
\tau_{t}\doteq(S_{0},A_{0},R_{1},\ldots,S_{t-1},A_{t-1},R_{t})
,
and outputs actions or value estimates
(
52
;
11
;

)
.
Such fixed-parameter adaptation has been observed in
algorithm distillation
(
26
)
, human-timescale adaptation
(
2
)
, long-context embodied agents
(
12
)
, Transformer-based adaptive agents
(
41
;
16
;
17
;
45
)
, and continuous-control or locomotion agents
(
31
;
3
)
.
Since the pretrained parameters do not change at test time, any adjustment in actions or value estimates must be produced by the
forward pass using the new context.
This motivates the question we study: what RL process is implemented by the fixed agent network when it uses the context for adaptation?

We study this question in the reinforcement-pretraining regime.
This regime differs from supervised pretraining, where the desired
update rule is already present in the training targets
(
26
;
44
;
60
;
9
;
24
;
27
;
29
)
.
In reinforcement pretraining, the agent is instead optimized through task-level RL objectives, such as producing good actions in control or accurate value estimates in policy evaluation
(
11
;
52
;
16
)
.
Thus, any context-dependent update implemented in the forward pass should be understood as an emergent computation induced by the pretraining objective, rather than as a imitated update rule.

To make this question concrete, we follow
53
;
54

In each task, a fixed policy
\pi
induces a value function
v_{\pi}
.
The agent receives a query state
s

\tau_{t}
of transitions collected under
\pi
, and outputs an estimate of
v_{\pi}(s)
using its fixed pretrained parameters.
The same agent network must handle a family of evaluation tasks whose transition dynamics, reward functions, and policies may differ. Temporal difference learning (TD,
49
) is a
standard algorithm for policy evaluation, making it a natural candidate for the RL process implemented in the forward pass.

53

Transformers is equivalent to step-by-step TD updates.

54

However, these results largely rely on linear self-attention where the softmax function in attention is replaced by an identity mapping to simplify analysis.
In this work, we remove this simplification by studying the standard
softmax attention
(
50

used in practice.
We ask whether comparable in-context policy evaluation behavior can still arise under this setting.

This observation leads to three central questions.

(Q1)

What specific policy-evaluation algorithm is being implemented by
\text{TF}_{\theta_{*}}
?

(Q2)

What convergence guarantees hold as the number of layers grows?

(Q3)

What kind of pretraining could give rise to these parameters?

In this paper, we address the above questions by providing the first theoretical analysis of in-context policy evaluation under standard softmax attention.
We show that the empirical pattern in Figure

We provide a constructive design of a dual-head Transformer layer whose forward pass implements a batch analogue of the nonparametric TD update

Taken together, our contributions answer

For
(Q1)

For

For

Background

We begin by establishing the technical foundations for our work. All vectors are treated as column vectors. We denote the identity matrix in
\mathbb{R}^{n\times n}
by
I_{n}
.
We use
0_{m\times n}
and
1_{m\times n}
to denote zero matrix and all-ones matrix.
Let
e_{i}
be the standard basis vector for the
i
-th row.
The transpose of a matrix
Z
is denoted by
Z^{\top}
. The inner product of two vectors
x
and
y
is denoted by either
\langle x,y\rangle
or
x^{\top}y
.

2.1
Transformers and Softmax Self-Attention

A Transformer’s core innovation is the self-attention mechanism
(
50
)
.
Given a prompt
Z\in\mathbb{R}^{(d+3)\times(n+1)}
, a standard single-head
self-attention layer processes the prompt via

\textstyle\text{Attn}_{W_{v},W_{q},W_{k}}(Z)\doteq W_{v}Z\,\mathrm{softmax}\bigl(Z^{\top}W_{k}^{\top}W_{q}Z+M\bigr),

(1)

where
W_{v}\in\mathbb{R}^{(d+3)\times(d+3)}
,
W_{k}\in\mathbb{R}^{m\times(d+3)}
,
and
W_{q}\in\mathbb{R}^{m\times(d+3)}
are the value, key, and query weight
matrices, and
\mathrm{softmax}
is applied column-wise.
The mask
M\in\mathbb{R}^{(n+1)\times(n+1)}
isolates the query column from the context columns

\textstyle M[i,j]=\begin{cases}0,&i\leq n,\\
-\infty,&i=n+1,\end{cases}

(2)

so that the query column does not contribute as a source token.
For analytical convenience, we follow
7
by reparameterizing
W_{v}
as
V_{l}
and denoting the query-key score matrix
W_{k}^{\top}W_{q}
by
A_{l}
.
An
L
-layer Transformer with parameters
\{(V_{l},A_{l})\}_{l=0,\ldots,L-1}

updates the representation at layer
l+1
recursively from an initial
prompt
Z_{0}\in\mathbb{R}^{(d+3)\times(n+1)}
as

\textstyle Z_{l+1}\doteq Z_{l}+V_{l}Z_{l}\,\mathrm{softmax}\bigl(Z_{l}^{\top}A_{l}Z_{l}+M\bigr).

(3)

We define the attention matrix at layer
l
by

\textstyle\widetilde{K}_{l}\doteq\mathrm{softmax}\bigl(Z_{l}^{\top}A_{l}Z_{l}+M\bigr)\in\mathbb{R}^{(n+1)\times(n+1)}.

(4)

Its entry
\widetilde{K}_{l}[i,j]
specifies the attention weight assigned to source token
i
when aggregating into token
j
. By construction of
M
,
\widetilde{K}_{l}[n+1,j]=0
for all
j
.
For notational simplicity, we suppress
M
in the remainder of the paper, with the understanding that the mask in (
2
) is applied throughout.
Since policy evaluation requires a scalar prediction, we extract a single entry from the final representation matrix.
Following prior work
(
1
;
53
)
, we define

\text{TF}_{L}\left(Z_{0};\{V_{l},A_{l}\}_{l=0}^{L-1}\right)\doteq Z_{L}[d+3,n+1],

(5)

to denote the output of the
L
-layer Transformer given an input
Z_{0}
.

For comparison, the existing ICRL theory of
53
;
54
uses linear attention, replacing the masked softmax in (
3
) with the identity map:

\textstyle Z_{l+1}^{\mathrm{lin}}=Z_{l}+V_{l}Z_{l}\,(Z_{l}^{\top}A_{l}Z_{l}).

(6)

In the broader in-context learning literature,
7
further replace the softmax with a general activation
h
, giving

Z_{l}+V_{l}Z_{l}\,h(Z_{l}^{\top}A_{l}Z_{l})
.
We instead retain the standard softmax
(
50
)
, bringing our analysis closer to the architecture used in practice.

2.2
Reinforcement Learning and Policy Evaluation

Since we focus on the policy evaluation problem with a fixed policy, we work directly with the induced Markov Reward Process (MRP,
4
).
An MRP is a tuple
(\mathcal{S},p,r,\gamma,p_{0})
consisting of a finite state space
\mathcal{S}
, a transition kernel
p:\mathcal{S}\times\mathcal{S}\to[0,1]
, a reward function
r:\mathcal{S}\to\mathbb{R}
, a discount factor
\gamma\in[0,1)
, and an initial distribution
p_{0}
.
Equivalently, an MRP arises from a Markov Decision Process
(\mathcal{S},\mathcal{A},p_{\text{MDP}},r_{\text{MDP}},\gamma,p_{0})
under a fixed policy
\pi:\mathcal{S}\times\mathcal{A}\to[0,1]
by marginalizing over actions:
p(s^{\prime}|s)=\sum_{a}\pi(a|s)p_{\text{MDP}}(s^{\prime}|s,a)
and
r(s)=\sum_{a}\pi(a|s)r_{\text{MDP}}(s,a)
.
A trajectory
(S_{0},R_{1},S_{1},R_{2},\dots)
is sampled by drawing

S_{0}\sim p_{0}
and, at each step,
S_{t+1}\sim p(\cdot|S_{t})
with

R_{t+1}\doteq r(S_{t})
.
Define the state transition matrix
P_{\pi}\in\mathbb{R}^{|\mathcal{S}|\times|\mathcal{S}|}
by
P_{\pi}[s,s^{\prime}]=p(s^{\prime}|s)
,
and assume the Markov chain induced by
P_{\pi}
is ergodic on
\mathcal{S}
with unique stationary distribution
\mu_{\pi}:\mathcal{S}\to[0,1]
.
We aim to estimate the value function
v_{\pi}(s)\doteq\mathbb{E}\quantity[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \mid S_t = s]
.

One fundamental task in RL is policy evaluation, where the goal is estimating the value function
v_{\pi}
. It is well-known that
v_{\pi}
is the unique fixed point of the Bellman expectation operator
\mathcal{T}^{\pi}:\mathbb{R}^{\absolutevalue{\fS}}\to\mathbb{R}^{\absolutevalue{\fS}}
defined as

(\mathcal{T}^{\pi}v)(s)\doteq\mathbb{E}_{\pi}[R_{t+1}+\gamma v(S_{t+1})|S_{t}=s].

(7)

Temporal-Difference learning (TD,
49
) is among the most influential and widely used algorithms for policy evaluation.
For large or continuous state spaces where tabular representations are
impractical, a long line of work has combined RL with kernel methods to
obtain non-parametric value function approximation

(
37
;
14
;
25
;
5
)
. We follow the formulation of

5
. Let
\mathcal{X}
be a measurable state
space and
\kappa:\mathcal{X}\times\mathcal{X}\to\mathbb{R}
a positive-definite
kernel with associated reproducing kernel Hilbert space
\mathcal{H}
.
Define the TD error at a transition
(x,x^{\prime})
by

\delta(x,x^{\prime})\doteq r(x)+\gamma v(x^{\prime})-v(x).

(8)

Given a sampled transition
(X_{t},X_{t+1})
, non-parametric TD updates the value estimate
v_{t}\in\mathcal{H}
at every query state
y\in\mathcal{X}
via

v_{t+1}(y)=v_{t}(y)+\alpha_{t}\,\delta(X_{t},X_{t+1})\,\kappa(X_{t},y),

(9)

where
\{\alpha_{t}\}
is a sequence of learning rates.
In this paper we work with the finite state space
\mathcal{S}
. Restricting (
9
) to

\mathcal{X}=\mathcal{S}
and to a query state
S_{n}\in\mathcal{S}
yields the update

v_{t+1}(S_{n})=v_{t}(S_{n})+\alpha_{t}\,\delta(S_{t},S_{t+1})\,\kappa(S_{t},S_{n}),

(10)

which is the form we build on in the rest of the paper.

3
Transformers Can Implement In-Context Weighted Softmax TD

We now answer
(Q1)
by introducing a new RL algorithm,
weighted softmax TD
, and constructing a dual-head Transformer that implements its update in the forward pass. Notably, this construction reveals the parameters we use to generate the results in Figure
1
.

Weighted softmax TD.

Given a trajectory
\tau_{n}=(S_{0},R_{1},\dots,S_{n})
sampled from an MRP, weighted softmax TD forms TD errors using (
8
) with the sampled reward instantiated by
R_{k}
:

\delta_{k}^{(t)}\doteq R_{k}+\gamma v_{t}(S_{k})-v_{t}(S_{k-1}),

(11)

where
k
indexes transitions within
\tau_{n}
and
t
indexes the iteration.
Non-parametric TD in (
10
) updates value estimates using a single transition.
We introduce weighted softmax TD as a batch variant that aggregates
\delta_{k}^{(t)}
over
\tau_{n}
through softmax weights.
Specifically, for the trajectory states
\{S_{j}\}_{j=0}^{n}
, define the softmax weight assigned to the
k
-th transition by

\textstyle K(S_{k-1},S_{j})\doteq\frac{\exp(g(S_j,S_{k-1}))}{\sum_{m=1}^{n}\exp(g(S_j,S_{m-1}))},\quad k=1,\dots,n,

(12)

where
g:\mathcal{S}\times\mathcal{S}\to\mathbb{R}
is a score function.
Thus, the value estimates
\{v_{t}(S_{j})\}_{j=0}^{n}
are updated by

\displaystyle\textstyle v_{t+1}(S_{j})=v_{t}(S_{j})+\alpha_{t}\sum_{k=1}^{n}\delta_{k}^{(t)}K(S_{k-1},S_{j}).

(weighted softmax TD)

In particular, if
g(S_{j},S_{k-1})=\log\kappa(S_{j},S_{k-1})
for some positive similarity function
\kappa
, then the weights reduce to

K(S_{k-1},S_{j})=\frac{\kappa(S_{j},S_{k-1})}{\sum_{m}\kappa(S_{j},S_{m-1})}
, recovering a normalized form of (
10
).

We next show that the dual-head Transformer used in generating Figure
1
implements the (
weighted softmax TD
) in a single forward pass.
We begin by specifying the prompt construction and the layerwise update rule.
We encode the trajectory
\tau_{n}
into a prompt matrix
Z_{0}\in\mathbb{R}^{(d+3)\times(n+1)}
,
where the last column corresponds to the query state
S_{n}
.
Using shorthands
x_{k}\doteq x(S_{k})
, we set

Z_{0}\doteq\begin{bmatrix}x_{0}&x_{1}&\cdots&x_{n-1}&x_{n}\\
R_{1}&R_{2}&\cdots&R_{n}&0\\
0&0&\cdots&0&0\\
0&0&\cdots&0&0\end{bmatrix}=\begin{bmatrix}X\\
R\\
\mathbf{0}\\
\mathbf{0}\end{bmatrix}.

(13)

Following

We consider an
L
-layer Transformer indexed by
l=0,1,\dots,L-1
.
Each layer consists of two attention heads, both taking
Z_{l}
as input.
To state the layer update clearly, we define

Current-value head.

Let
\quantity{(V_l, A_l)}_{l=0,1,\dots,L-1}

It writes an additive update to row

\Delta Z_{l}[d+3,:]=\big(V_{l}Z_{l}\,\mathrm{softmax}(Z_{l}^{\top}A_{l}Z_{l})\big)[d+3,:].

We choose

\textstyle V_{l}\doteq\begin{bmatrix}0_{(d+2)\times d}&0_{(d+2)\times 3}\\
0_{1\times d}&\begin{bmatrix}1&1&-1\end{bmatrix}\end{bmatrix},\,\,A_{l}\doteq\begin{bmatrix}I_{d}&0_{d\times 3}\\

(15)

By construction, the only non-zero row of

With the choice of

This head writes an additive update to row

Each layer computes two heads that share the same term

Specifically, (

) applies
\Pi
to the same aggregated quantities in (

) and scales them by
\gamma

Motivated by this observation, we reparameterize the block as a single-head attention followed by a parameter-free temporal shift module (TSM;

Using

\textstyle Z_{l+\frac{1}{2}}\doteq Z_{l}+V_{l}Z_{l}\mathrm{softmax}\bigl(Z_{l}^{\top}A_{l}Z_{l}\bigr),

\textstyle U\doteq I-e_{d+2}e_{d+2}^{\top},\qquad W\doteq\gamma\,e_{d+2}e_{d+3}^{\top}.

(22)

Recall from (

\Pi\in\mathbb{R}^{(n+1)\times(n+1)}
is the one-step predecessor shift matrix.
Therefore,

5
Inference-Time Convergence

We now address
(Q2)
by establishing the convergence of softmax ICTD
to the true value function
v_{\pi}
as the number of layers
L\to\infty

and the context length
n\to\infty
. Throughout the rest of the paper,
we assume the trajectory
\tau_{n}=(S_{0},R_{1},\ldots,S_{n})
visits every state,
i.e.,
\{S_{0},S_{1},\ldots,S_{n-1}\}=\mathcal{S}
.

To analyze the recursion (
20
) on
\mathcal{S}
, for a given context
trajectory
\tau_{n}
, we define

\textstyle\widehat{M}_{n}(s,s^{\prime})\doteq\sum_{k=1}^{n}K(S_{k-1},s)\,\mathbbm{1}\{S_{k-1}=s^{\prime}\},\quad\widehat{P}_{n}(s,s^{\prime})\doteq\sum_{k=1}^{n}K(S_{k-1},s)\,\mathbbm{1}\{S_{k}=s^{\prime}\}.

(24)

Here
\widehat{M}_{n}
aggregates the softmax weights according to the predecessor
state
S_{k-1}
, and
\widehat{P}_{n}
aggregates the same weights according to
the successor state
S_{k}
. Then (
20
) can be written compactly as

\textstyle\widehat{\mathcal{T}}_{\widetilde{K}}(v)=(I-\widehat{M}_{n}+\gamma\widehat{P}_{n})v+\widehat{M}_{n}r,

(25)

and stacking layers corresponds to repeated application of
\widehat{\mathcal{T}}_{\widetilde{K}}
:

\textstyle v_{l+1}=\widehat{\mathcal{T}}_{\widetilde{K}}(v_{l}).

(26)

The empirical operator
\widehat{\mathcal{T}}_{\widetilde{K}}
contracts whenever
\widehat{M}_{n}
has
sufficiently large diagonal entries. To formalize this, we introduce the
population counterpart of
\widehat{M}_{n}
, obtained by replacing the empirical
state frequencies in
K
with the stationary distribution
\mu_{\pi}
:

\textstyle M_{\pi}(s,s^{\prime})\doteq\frac{\mu_{\pi}(s^{\prime})\,\exp(\langle x(s), x(s') \rangle)}{\sum_{u\in\mathcal{S}}\mu_{\pi}(u)\,\exp(\langle x(s), x(u) \rangle)},

(27)

where
\mu_{\pi}
is the stationary distribution of
P_{\pi}
. We impose the
following contraction assumption.

Assumption 5.1
.

There exists a constant
C_{\ref{ass:diagonal-margin}}\in\bigl(0,\frac{1-\gamma}{2}\bigr)
such that

\textstyle\min_{s\in\mathcal{S}}M_{\pi}(s,s)\geq\frac{1+\gamma}{2}+C_{\ref{ass:diagonal-margin}}.

(28)

Assumption
5.1
is a kernel diagonality condition on
M_{\pi}
, requiring
M_{\pi}(s,s)
to dominate the off-diagonal mass at every state
s
.
It is expected to hold when the score function
g(s,s^{\prime})=\langle x(s),x(s^{\prime})\rangle
separates self-pairs from cross-pairs, i.e.,
g(s,s)-g(s,s^{\prime})
is sufficiently positive for
s^{\prime}\neq s
, which sharpens the softmax in (
12
) toward the diagonal.
We will see in Section
8
that this self-concentration emerges empirically over pretraining.

When
n
is large enough,
\widehat{M}_{n}
inherits the diagonal margin of
M_{\pi}
, which together with a high-probability bound on the bias
\|\widehat{\mathcal{T}}_{\widetilde{K}}(v_{\pi})-v_{\pi}\|_{\infty}
yields our main convergence result.

Theorem 2
.

Under Assumption
5.1
, for any
\delta\in(0,1)
,
there exist constants
C_{\text{Thm}\ref{thm:finite-n},1},C_{\text{Thm}\ref{thm:finite-n},2},C_{\text{Thm}\ref{thm:finite-n},3}>0

such that if
n\geq C_{\text{Thm}\ref{thm:finite-n},1}\log(1/\delta)
,
then with probability at least
1-\delta
, for all
L\geq 0
,

\textstyle\|v_{L}-v_{\pi}\|_{\infty}\leq(1-C_{\ref{ass:diagonal-margin}})^{L}\|v_{0}-v_{\pi}\|_{\infty}+C_{\text{Thm}\ref{thm:finite-n},2}\sqrt{\frac{\log(C_{\text{Thm}\ref{thm:finite-n},3}/\delta)}{n}}.

(29)

The proof is in Section
D.4
, which combines an

\ell_{\infty}
-contraction of
\widehat{\mathcal{T}}_{\widetilde{K}}
around
v_{\pi}

(Lemma
5
) with a high-probability bound on the bias

\|\widehat{\mathcal{T}}_{\widetilde{K}}(v_{\pi})-v_{\pi}\|_{\infty}
(Lemma
6
),
both deferred to Appendix
D.2
and
D.3

respectively. The first term of (
29
) decays geometrically with
the number of layers
L
, while the second term is a statistical floor
that vanishes as
n\to\infty
. That is, the softmax ICTD recursion
converges to
v_{\pi}
in the double limit where both depth and context
length grow.

6
Emergence of Softmax ICTD under Reinforcement Pretraining

We now answer
(Q3)
by showing that, as the depth
L\to\infty
and the context length
n\to\infty
, the parameters
\{(V_{l},A_{l})\}_{l=0}^{L-1}
constructed in (
15
) are one of the global minimizers of the reinforcement pretraining loss.

To avoid specializing to a single task, we pretrain on a distribution of MRPs drawn from a joint distribution
\Delta
over transition probabilities and reward functions, i.e.,
(p,r)\sim\Delta
.
For each sampled MRP, we draw a trajectory
\tau_{n+1}=(S_{0},R_{1},S_{1},\ldots,R_{n+1},S_{n+1})
from the stationary Markov chain induced by
\pi
(i.e.,
S_{0}\sim\mu_{\pi}
).
We construct the prompt
Z_{0}
from the first
n
transitions
(S_{0},R_{1},\ldots,R_{n},S_{n})
as in (
13
), and denote the scalar output of the
L
-layer Transformer by
v_{L}(S_{n};\theta)
.
Similarly,
v_{L}(S_{n+1};\theta)
denotes the output on the shifted prompt built from
(S_{1},R_{2},\ldots,R_{n+1},S_{n+1})
with query
S_{n+1}
. The TD error at the query state is

\textstyle\delta_{L}(\theta)\doteq R_{n+1}+\gamma v_{L}(S_{n+1};\theta)-v_{L}(S_{n};\theta).

(30)

The norm of the expected update (NEU) is a fundamental objective in TD methods
(
47
;
48
)
. Its zeros characterize TD fixed points, making it a natural pretraining loss for studying whether the constructed parameters
\theta_{*}
attain global optimality. Following
54
, we adopt its extension to arbitrary function approximation, defined as the
\ell_{1}
-norm of the expected TD update direction:

\displaystyle\textstyle J_{L,n}(\theta)\doteq\bigl\|\mathbb{E}_{(p,r),\,\tau_{n+1}}[\delta_{L}(\theta)\nabla_{\theta}v_{L}(S_{n};\theta)]\bigr\|_{1}.

(31)

Following common practice in the in-context learning theory literature
(
51
;
1
;
33
;
58
;
7
;
15
;
20
;
54
)
, we analyze NEU on a looped Transformer and restrict the parameters to a structured sparse space.
Concretely, we tie the parameters across layers by sharing the same pair
(V,A)
, i.e.,
(V_{l},A_{l})=(V,A)
for all
l\in\{0,\dots,L-1\}
, and search over the following parameter space:

\textstyle\Theta^{\text{Looped}}\doteq\bigg\{\theta=(V,A)^{L}\bigg|V=\begin{bmatrix}0_{(d+2)\times d}&0_{(d+2)\times 3}\\
0_{1\times d}&u\end{bmatrix},A=\begin{bmatrix}B&0_{d\times 3}\\
0_{3\times d}&0_{3\times 3}\end{bmatrix}\bigg\},

(32)

where
u\in\mathbb{R}^{1\times 3}
and
B\in\mathbb{R}^{d\times d}
.
Note that the parameter choice constructed in (
15
) lies in
\Theta^{\text{Looped}}
; for convenience, we denote it by
\theta_{*}
.
We now state the main emergence result.

Theorem 3
.

Under Assumption
5.1
holding uniformly over
\Delta
,
there exist a constant
n_{0}>0
and constants

C_{\text{Thm}\text{\ref{thm:emergence}},2},C_{\text{Thm}\text{\ref{thm:emergence}},3}>0

such that for every
L\geq 1
and
n\geq n_{0}
,

\textstyle J_{L,n}(\theta_{*})\leq C_{\text{Thm}\text{\ref{thm:emergence}},2}\quantity[
(1-C_{\ref{ass:diagonal-margin}})^L
+
\sqrt{\frac{\log n}{n}}
]+C_{\text{Thm}\text{\ref{thm:emergence}},3}\frac{L(2+\gamma)^{2L}}{n}.

(33)

In particular,

\textstyle\lim_{L\to\infty}\limsup_{n\to\infty}J_{L,n}(\theta_{*})=0.

The proof is in Section
E.4
. The argument relies on a uniform bound on
\nabla_{\theta}v_{L}(S_{n};\theta_{*})
across all depths (Lemma
10
in Appendix
E.3
), which in turn uses Assumption
5.1
together with the layer-invariance of
\widetilde{K}(\theta)
for
\theta\in\Theta^{\text{Looped}}
.
Since
J_{L,n}(\theta)\geq 0
for all
\theta
, Theorem
3

implies that
\theta_{*}
is a global minimizer of the NEU loss in the iterated regime where the context length grows first and the depth grows afterward.

Related Works

The theoretical study of ICRL has largely relied on the linear-attention abstraction, which replaces the softmax with the identity map to make the forward pass tractable
(
53
;
54
)
.
This simplification is also pervasive in the broader in-context learning (ICL) literature, where it has been used to show that Transformers can implement gradient-based algorithms in their forward pass
(
1
;
58
;
15
)
.
A smaller line of work keeps a nonlinearity explicit, either through general activation operators
VZ\,h(Z^{\top}AZ)

(
7
)
or by relating softmax attention to kernel-based learning rules
(
42
;
10
)
.
Other results under standard softmax attention show that fixed-weight softmax attention can simulate multi-step gradient descent on deep networks
(
55
)
, emulate prompt-programmable algorithms in a two-layer module
(
19
)
, or serve as a sequence-to-sequence universal approximator with in-context gradient-descent approximation
(
18
)
.
While these results inform supervised in-context computation, they do not address reinforcement-pretrained policy evaluation, and the standard softmax used in practical Transformers remains largely unanalyzed in the ICRL setting.
Our work closes this gap, complementing
54
by removing the linear-attention simplification.

A concurrent submission
(
56
)
similarly builds on
53
;
54
, but takes a fundamentally different route: it analyzes linear attention with autoregressive chain-of-thought generation and linear function approximation, where each generated token implements one batch TD update on the context,
whereas we analyze softmax attention with depth-based computation for finite-state policy evaluation.
As a result, the two works draw on largely disjoint technical tools.
For convergence, our analysis is driven by a kernel diagonality condition (Assumption
5.1
) and is then lifted to finite contexts via concentration, whereas
56
provide a finite-sample analysis on a single Markovian trajectory.
For emergence, we control how the value prediction depends on the parameters, whereas
56
control how the algorithmic iterates depend on the parameters.
The two works share the Boyan’s chain task setup of
53
.

ICRL has been studied under both supervised and reinforcement pretraining
(
36
)
.
Supervised pretraining trains a sequence model to imitate trajectories from existing RL algorithms
(
26
;
30
;
44
;
24
;
60
;

;

;
9
;
61
;
40
)
,
with theoretical accounts of the resulting in-context behavior

(
29
;
27
)
.
Reinforcement pretraining instead trains the model with an RL objective and observes that test-time adaptation still emerges
(
11
;
52
;
35
;
43
;
46
;
59
;

)
, with empirical demonstrations across diverse tasks
(

;

;

;

;

;

;

)
.
Theoretical results under reinforcement pretraining remain limited:
39
analyze a regret-minimization objective, and
54
establish convergence and emergence under linear attention. Our paper falls in this regime, with softmax attention.

9
Conclusion

We provide the first theoretical analysis of in-context policy evaluation beyond the linear-attention simplification, under softmax attention.
We show by construction that a Transformer layer can be configured to implement a weighted softmax TD update step in its forward pass.
We prove an inference-time convergence guarantee as the number of layers increases under a suitable contraction condition, and show that the desired parameters are one of the global minimizers of a pretraining loss, explaining their emergence with increasingly diagonal attention in our experiments.
Future work includes relaxing the contraction requirement and extending the theory and experiments to sampled trajectories and control settings.

Mask on

Emergence metrics

We quantify how closely the first softmax ICTD layer matches the ideal TD update
using two scalar scores
V_{\mathrm{em},t}
and
A_{\mathrm{em},t}
in
[0,1]
.
A score of
1
corresponds to the ideal TD block.

F.4.1
V-emergence score.

At training step
t
, let

(p_{r,t},p_{\gamma v^{\prime},t},p_{v,t})\doteq(V_{0,t})_{d+3,d{:}d+3}

denote the three coefficients that the first layer applies to the reward
U
,
bootstrap value
\gamma v^{\prime}
, and current value
v
in its value update.

Sign check.

We enforce the TD sign pattern via

\mathbb{I}_{V,t}\doteq\mathbb{I}\bigl\{p_{r,t}>0,\;p_{\gamma v^{\prime},t}>0,\;p_{v,t}<0\bigr\}.

(109)

Comparability.

We encourage comparable magnitudes.
Let

m_{V,t}\doteq\frac{|p_{r,t}|+|p_{\gamma v^{\prime},t}|+|p_{v,t}|}{3}.

We define the magnitude-ratio score

C_{V,t}\doteq\max\Biggl\{0,\;1-\frac{\bigl||p_{r,t}|-m_{V,t}\bigr|+\bigl||p_{\gamma v^{\prime},t}|-m_{V,t}\bigr|+\bigl||p_{v,t}|-m_{V,t}\bigr|}{3\max\{m_{V,t},\varepsilon\}}\Biggr\}\in[0,1],

(110)

where
\varepsilon>0
is a small constant.
This score is maximized when the three coefficients have the same magnitude. When
m_{V,t}=0

the definition yields
C_{V,t}=0
.

The V-emergence score at step
t
is

V_{\mathrm{em},t}\doteq\mathbb{I}_{V,t}\,C_{V,t}\in[0,1].

F.4.2

Let
A_{0,t}^{\mathrm{feat}}\doteq(A_{0,t})_{0{:}d,\,0{:}d}\in\mathbb{R}^{d\times d}
at training step
t
.
For diagnostics we work with a column-normalized nonnegative version.
For
j\in[d]
, define

(\widehat{A}_{t})[:,j]\doteq\begin{cases}\frac{\bigl|(A_{0,t}^{\mathrm{feat}})[:,j]\bigr|}{\|(A_{0,t}^{\mathrm{feat}})[:,j]\|_{2}}&\|(A_{0,t}^{\mathrm{feat}})[:,j]\|_{2}>0,\\
0&\text{otherwise},\end{cases}

that is, we divide each column by its
l_{2}
-norm and take absolute values.

Diagonality.

From
\widehat{A}_{t}
we measure how much of the

A_{\mathrm{diag},t}\doteq\frac{\sum_{i=1}^{d}(\widehat{A}_{t})_{ii}}{\max\Bigl\{\sum_{i,j=1}^{d}(\widehat{A}_{t})[i,j],\,\varepsilon\Bigr\}}\in[0,1],

where
\varepsilon>0
is a small constant.
This quantity is close to

is nearly diagonal.

Comparability.

Let
a_{t}\doteq\mathrm{diag}(A_{0,t}^{\mathrm{feat}})\in\mathbb{R}^{d}
.
We encourage the diagonal entries to be comparable in magnitude.
Let

m_{A,t}\doteq\frac{1}{d}\sum_{i=1}^{d}(a_{t})_{i},\qquad C_{A,t}\doteq\max\Biggl\{0,\;1-\frac{\sum_{i=1}^{d}|(a_{t})_{i}-m_{A,t}|}{d\,\max\{m_{A,t},\varepsilon\}}\Biggr\}.

By construction,
C_{A,t}
measures whether the raw diagonal entries
are close to a common value, but it does not separately enforce that
this common value is positive.

The A-emergence score at step
t
is

A_{\mathrm{em},t}\doteq A_{\mathrm{diag},t}\cdot C_{A,t}\in[0,1].
