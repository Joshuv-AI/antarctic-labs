Average Case Graph Searching in Non-Uniform Cost Models
Michał Szyfelbein

Abstract
We consider the following generalization of the classic Binary Search Problem: a searcher is required to find a hidden target vertex x x in a graph G G , by iteratively performing queries about vertices. A query to v v incurs a cost c ⁡ ( v , x ) c(v,x) and responds whether v = x v=x and if not, returns the connected component in G − v G-v containing x x . The goal is to design a search strategy that minimizes the average-case search cost. Firstly, we consider the case when the cost of querying a vertex is independent of the target. We develop a ( 4 + ϵ ) \mathopen{}\left(4+\epsilon\right) -approximation FPTAS for trees running in O ⁡ ( n 4 / ϵ 2 ) O(n^{4}/\epsilon^{2}) time and an O ⁡ ( log ⁡ n ) O({\sqrt{\log n}}) -approximation for general graphs. Additionally, we give an FPTAS parametrized by the number of non-leaf vertices of the graph. On the hardness side we prove that the problem is NP-hard even when the input is a tree with bounded degree or bounded diameter. Secondly, we consider trees and assume c ⁡ ( v , x ) c(v,x) to be a monotone non-decreasing function with respect to x x , i.e. if u ∈ P v , x u\in P_{v,x} then c ⁡ ( u , x ) ≤ c ⁡ ( v , x ) c(u,x)\leq c(v,x) . We give a 2 2 -approximation algorithm which can also be easily altered to work for the worst-case variant. This is the first constant factor approximation algorithm for both criterions. Previously known results only regard the worst-case search cost and include a parametrized PTAS as well as a 4 4 -approximation for paths. At last, we show that when the cost function is an arbitrary function of the queried vertex and the target, then the problem does not admit any constant factor approximation under the UGC, even when the input tree is a star.

Graph Searching, Average Case, Approximation Algorithms, Binary Search, Separators

Motivations and Applications

Fast retrieval of information in graph structures is a well-studied problem,
beginning with the seminal work of Knuth

When the underlying search space provides non-local information about the target,
the search process can be accelerated, since each query rules out a large set of
possible target locations. The goal of designing search strategies is to find ways of exploiting this property as effectively as possible.

Searching arises in various practical problems, but it can also be reformulated, to fit a wide range of real-life applications. Searching in graphs can be used to model a variety of problems, that may initially appear unrelated. These include: scheduling of parallel database join operations

We focus on the average-case version of the problem rather than the worst-case,
since it is natural to assume that the search strategies we design are intended
to be used repeatedly.
This motivates the introduction of a weight function, as some vertices may serve
as targets more frequently than others.
We also allow arbitrary query costs, since performing a query may require
significant resources, such as time or money.

Studying cost functions with the monotonicity property is motivated by the problem of detecting a hidden source of a spreading pollution in a network. The pollution spreads from the source along the edges of the network in a way which causes a dilution of the pollutant concentration with increasing distance from the source. The searcher is allowed to take samples at various nodes of the network. Each sample reveales a direction towards the source. However, since at larger distances the concentration of the pollutant is lower, taking samples further away from the source is more costly. Additionally, since the amount of the pollutant released into the network is unknown, the searcher cannot predict the distance from the source based on the concentration measured at a given node. The goal of the searcher is to find a strategy of taking samples to find the source of the pollution as efficiently as possible.

v,u\in V\mathopen{}\left(T\right)

S\mathopen{}\left(v\right)\cap S\mathopen{}\left(u\right)\cap P_{v,u}\neq\emptyset
(neither
u
and
v
nor
u^{\prime}
and
v^{\prime}
must be different). The existence of a common vertex for subtrees of
T
is not required. We will be concerned with finding a good separator assignment minimizing either average-case cost:

\sum_{x\in V\mathopen{}\left(T\right)}w\mathopen{}\left(x\right)\cdot\sum_{v\in S\mathopen{}\left(x\right)}c\mathopen{}\left(v,x\right)

or worst-case cost:

\max_{x\in V\mathopen{}\left(T\right)}\sum_{v\in S\mathopen{}\left(v\right)}c\mathopen{}\left(v,x\right).

We further relax the condition on the separator assignment as follows:
A
pseudo-separator assignment
is a function
S\colon V\to 2^{V\mathopen{}\left(T\right)}
such that: For any
v,u\in V\mathopen{}\left(T\right)
(not necessarily different), there exist vertices
v^{\prime}\in S\mathopen{}\left(v\right)
and
u^{\prime}\in S\mathopen{}\left(u\right)
such that
u^{\prime}\in P_{v,v^{\prime}}
. and
v^{\prime}\in P_{u,u^{\prime}}
. This notion will come useful while constructing a resulting decision tree during the rounding step of our LP based approximation algorithms.

2.2
Cuts and separators

To obtain a tight lower bound on the cost of our solution for the case when the cost function does not depend on the target,
we establish a connection between GSP and vertex cuts/separator problems. Our analysis is inspired by the edge query variant of the GSP
[
10
]
. However, since the query model is different, to obtain our results we use connection to the vertex separation instead of edge cutting.

Any subset
S\subseteq V\mathopen{}\left(G\right)
is called
\alpha
-separator
if for every
H\in G-S
we have
w\mathopen{}\left(H\right)\leq w\mathopen{}\left(G\right)/\alpha
. Any partition
\mathopen{}\left(A,S,B\right)
of
V\mathopen{}\left(G\right)
is called a
vertex-cut
if there are no
u\in A
and
v\in B
for which
uv\in E\mathopen{}\left(G\right)
.
The
Weighted
\alpha
-Separator Problem
is as follows:

Weighted
\alpha
-Separator Problem

Input:
Graph
G=\mathopen{}\left(V\mathopen{}\left(G\right),E\mathopen{}\left(G\right)\right)
, a cost function
c\colon V\to\mathbb{N}
, a weight function
w\colon V\to\mathbb{N}
and
\alpha\in\mathbb{R}^{+}
.

Output:
An
\alpha
-separator such that
c\mathopen{}\left(S\right)
is minimized.

We also define the Min-Ratio Vertex Cut Problem:

Min-Ratio Vertex Cut Problem

Input:
Graph
G=\mathopen{}\left(V\mathopen{}\left(G\right),E\mathopen{}\left(G\right)\right)
, the cost function
c\colon V\to\mathbb{N}
and the weight function
w\colon V\to\mathbb{N}
.

Output:
A vertex cut
\mathopen{}\left(A,S,B\right)
of
V\mathopen{}\left(G\right)
minimizing the ratio:

\alpha_{c,w}\mathopen{}\left(A,S,B\right)=\frac{c\mathopen{}\left(S\right)}{w\mathopen{}\left(A\cup S\right)\cdot w\mathopen{}\left(B\cup S\right)}.

2.3
Levels of
OPT
and basic bounds

We start by introducing the following reinterpretation of the cost function.
For each node
v\in D
, let
G_{D,v}
be the subgraph of
G
in which

v
is queried when using
D
. For any graph
G
and decision tree
D
, denote by

\mathcal{R}_{D}\mathopen{}\left(G\right)=\mathopen{}\left\{V\mathopen{}\left(G_{D,v}\right)\colon v\in V\mathopen{}\left(G\right)\right\}

the family of all candidate subsets which can occur while searching according to
D
in
G
.

Let
D^{*}
be an arbitrary decision tree for the Graph Search Problem such that

c_{G}\mathopen{}\left(D^{*}\right)=\texttt{OPT}\mathopen{}\left(G\right)
.
We denote by
\mathcal{L}_{k}^{*}
the subfamily of
\mathcal{R}_{D^{*}}\mathopen{}\left(G\right)

consisting of all maximal elements
H
of
\mathcal{R}_{D^{*}}\mathopen{}\left(G\right)
with
w\mathopen{}\left(H\right)\leq k
,
that is, if some superset
H^{\prime}
of
H
belongs to
\mathcal{R}_{D^{*}}\mathopen{}\left(G\right)
,
then
w\mathopen{}\left(H^{\prime}\right)>k
.
We call such a set the
k
-th
level
of
\texttt{OPT}\mathopen{}\left(G\right)
.
Let
S_{k}^{*}=V\mathopen{}\left(G\right)-\mathcal{L}_{k}^{*}
.
These are the vertices that we describe as belonging to the separator at the
k
-th level of
D^{*}
.

Notice that
S_{k}^{*}
forms a Weighted
w\mathopen{}\left(G\right)/k
-separator of
G
.
Furthermore, for any
H_{1},H_{2}\in\mathcal{R}_{D}\mathopen{}\left(G\right)
, we have

H_{1}\cup H_{2}\neq\emptyset
if and only if
H_{1}\subseteq H_{2}
or

H_{2}\subseteq H_{1}
, so
\mathcal{R}_{D}\mathopen{}\left(G\right)
is laminar.
Therefore, for any
k_{1}\neq k_{2}
, we have

\mathcal{L}_{k_{1}}^{*}\cap\mathcal{L}_{k_{2}}^{*}=\emptyset
.

For the rest of this section assume that the cost function does not depend on the target, i.e., for every
v,x\in V\mathopen{}\left(G\right)
,
c\mathopen{}\left(v,x\right)=c\mathopen{}\left(v\right)
.
We observe that for any
v\in V\mathopen{}\left(G\right)
the query cost of
v
contributes to the search cost of every
u\in V\mathopen{}\left(G_{D,v}\right)
so the total contribution of
v
to the cost is
w\mathopen{}\left(G_{D,v}\right)\cdot c\mathopen{}\left(v\right)
,
and therefore it is easy to see that:

Lemma 2.1
.

c_{G}\mathopen{}\left(D\right)=\sum_{v\in V\mathopen{}\left(G\right)}w\mathopen{}\left(G_{D,v}\right)\cdot c\mathopen{}\left(v\right).

Using the latter we get the following lemma, which allows us to decompose the value of
\texttt{OPT}\mathopen{}\left(G\right)
into cost of the separators at each level:

Lemma 2.2
.

\texttt{OPT}\mathopen{}\left(G\right)=\sum_{k=0}^{w\mathopen{}\left(G\right)-1}c\mathopen{}\left(S_{k}^{*}\right).

Proof.

Consider any vertex
v
. For every
0\leq k<w\mathopen{}\left(G_{D^{*},v}\right)
,
v\notin\bigcup_{H\in\mathcal{L}_{k}^{*}}H
, so
v\in S_{k}^{*}
and the contribution of
v
to the cost is
w\mathopen{}\left(G_{D^{*},v}\right)\cdot c\mathopen{}\left(v\right)
:

\sum_{k=0}^{w\mathopen{}\left(G\right)-1}c\mathopen{}\left(S_{k}^{*}\right)=\sum_{v\in V\mathopen{}\left(G\right)}\sum_{k=0}^{w\mathopen{}\left(G_{D^{*},v}\right)-1}c\mathopen{}\left(v\right)=\texttt{OPT}\mathopen{}\left(G\right)

where the second equality is by Lemma
2.1
.
∎

Using the above lemma one easily obtains the following lower bound on the cost of the optimal solution:

Lemma 2.3
.

2\cdot\texttt{OPT}\mathopen{}\left(G\right)=2\cdot\sum_{k=0}^{w\mathopen{}\left(T\right)-1}c\mathopen{}\left(S_{k}^{*}\right)\geq\sum_{k=0}^{w\mathopen{}\left(T\right)}c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\right).

Intuitively, the above reindexing allows us to lower bound the value of
\texttt{OPT}\mathopen{}\left(G\right)
by the sum of minimal costs required to separate each candidate subgraph at some level
k
into candidate subgraphs on levels at most
\mathopen{}\left\lfloor k/2\right\rfloor
.

In order to upper bound the cost of decision trees produced by our algorithms we will use the following lemma:

Lemma 2.4
.

Let
\mathcal{G}
be any subgraph of
G
and
0\leq\beta\leq 1
. Then:

\beta\cdot w\mathopen{}\left(\mathcal{G}\right)\cdot c\mathopen{}\left(S_{\mathopen{}\left\lfloor w\mathopen{}\left(\mathcal{G}\right)/2\right\rfloor}^{*}\cap\mathcal{G}\right)\leq\sum_{k=\mathopen{}\left(1-\beta\right)w\mathopen{}\left(\mathcal{G}\right)+1}^{w\mathopen{}\left(\mathcal{G}\right)}c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap\mathcal{G}\right).

Proof.

The inequality is due to the fact that as
k
decreases, more vertices belong to the separator.
∎

The following lemma qill be required in order to attach decision trees
below already constructed partial decision trees without ambiguity:

Lemma 2.5
.

Let
\mathcal{G}
be a connected subgraph of a graph
G
and
D
be a partial decision tree for
G
having no queries to vertices of
\mathcal{G}
, but containing at least one query to
N_{G}\mathopen{}\left(V\mathopen{}\left(\mathcal{G}\right)\right)
. Additionally, let

be the set of all queries to vertices from

in

D\mathopen{}\langle Q\rangle
forms a path in

Proof.

Let

be any query in
D
. There are two cases:

1.

q\in V\mathopen{}\left(G-V\mathopen{}\left(\mathcal{G}\right)-N_{G}\mathopen{}\left(V\mathopen{}\left(\mathcal{G}\right)\right)\right)
. Then, for every
x\in N_{G}\mathopen{}\left(V\mathopen{}\left(\mathcal{G}\right)\right)
being the target, the answer is the same connected component of

. Therefore,
q
has at most one child
u
in

, such that
V\mathopen{}\left(D_{u}\right)\cap Q\neq\emptyset
.

2.

q\in N_{G}\mathopen{}\left(V\mathopen{}\left(\mathcal{G}\right)\right)
. After a query to
q

x=q
. Then the response is
x
itself, in which case no further queries are needed, and again

has at most one child
u
in

, such that
V\mathopen{}\left(D_{u}\right)\cap Q\neq\emptyset
.

∎

This lemma will become useful in the following scenario:
Let
D
be a partial decision tree for

satisfying the conditions of the lemma and
D_{\mathcal{G}}
be any partial decision tree for a subgraph
\mathcal{G}
of

.
Since all of the queries in

to

.

To achieve this result, we use the connection between searching in trees and
the Weighted
\alpha
-Separator Problem.
This connection provides a lower-bounding scheme for our recursive algorithm,
which at each level of recursion, constructs a decision tree using the

\alpha

Theorem 3.1

Let

Proof.

We devise a dynamic programming procedure similar to the one in

and combine it with a rounding trick to obtain a bi-criteria FPTAS.
Note that the authors considered only the case in which all weights are uniform. We generalize their algorithm to arbitrary integer weights and introduce an additional case that
was previously lacking

Probably due to an oversight.

Theorem 3.2

Let

Assume that the input tree is rooted at an arbitrary vertex

. We want to find a separator
S

Define

T_{v}

under the condition that
v\in S_{v}

We immediately have:

C_{v}^{in}=c\mathopen{}\left(v\right)+\sum_{c\in\mathcal{C}_{T,v}}C_{c}.

Assume that
v\notin S_{v}
.
Let
H_{v}\in T_{v}-S_{v}
be the component containing
v

For every integer

T_{v}
,

Then:

For any vertex

and any integer

For

C_{v,1}^{out}[w]=\begin{cases}\infty,&\text{if }w<w\mathopen{}\left(v\right),\\
\min\mathopen{}\left\{C_{c_{1}}^{in},C_{c_{1}}^{out}[0]\right\},&\text{if }w=w\mathopen{}\left(v\right),\\

For

C_{v,i}^{out}[w]=\min\mathopen{}\left\{C_{v,i-1}^{out}[w]+C_{c_{i}}^{in},\min_{0\leq j\leq w}\mathopen{}\left\{C_{v,i-1}^{out}[w-j]+C_{c_{i}}^{out}[j]\right\}\right\}.

,

.
The second term considers the alternative, checking all possible partitions of

Computation is performed in a bottom-up, left-to-right manner, starting from the leaves.
For a leaf

Let

\mathcal{T}

k
. Their contribution to the cost is
c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap\mathcal{T}\right)
. Consider which candidate subtrees contribute such a term. As
S_{\mathcal{T}}
is a weighted
\frac{2}{1+\delta}
-separator, we have that
\mathcal{T}
is the minimal candidate subtree, such that
w\mathopen{}\left(\mathcal{T}\right)\geq k\geq\frac{\mathopen{}\left(1+\delta\right)\cdot w\mathopen{}\left(\mathcal{T}\right)}{2}+1>w\mathopen{}\left(H\right)
, for every
H\in\mathcal{T}-S_{\mathcal{T}}
. This means that if for every
H\in\mathcal{T}-S_{\mathcal{T}}
,
w\mathopen{}\left(H\right)<k
, then
\mathcal{T}
contributes such a term. Since for all
H_{1},H_{2}\in\mathcal{T}-S_{\mathcal{T}}
we have that
H_{1}\cap H_{2}=\emptyset
,
\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap H_{1}\right)\cup\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap H_{2}\right)=\emptyset
, the claim follows by summing over all values of
k
.
∎

We are now ready to bound the cost of the solution. Let
D
be the decision tree returned by the procedure. Using the fact that by definition
\frac{4}{1-\delta}=4+\epsilon
, we have:

\displaystyle c_{T}\mathopen{}\left(D\right)

\displaystyle\leq\sum_{\mathcal{T}}w\mathopen{}\left(\mathcal{T}\right)\cdot c\mathopen{}\left(S_{\mathcal{T}}\right)\leq\frac{2}{1-\delta}\cdot\sum_{\mathcal{T}}\sum_{k=\frac{1+\delta}{2}\cdot w\mathopen{}\left(\mathcal{T}\right)+1}^{w\mathopen{}\left(\mathcal{T}\right)}c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap\mathcal{T}\right)

\displaystyle\leq\frac{2}{1-\delta}\cdot\sum_{k=0}^{w\mathopen{}\left(T\right)}c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\right)\leq\frac{4}{1-\delta}\cdot\texttt{OPT}\mathopen{}\left(T\right)=\mathopen{}\left(4+\epsilon\right)\cdot\texttt{OPT}\mathopen{}\left(T\right)

where the third inequality is due to Lemma
3.6
and the last inequality is by Lemma
2.3
.

As
1/\delta=\frac{4+\epsilon}{\epsilon}=1+4/\epsilon
and each
v\in V\mathopen{}\left(T\right)
belongs to the set
S_{\mathcal{T}}
exactly once, we have that the overall running time is at most
O\mathopen{}\left(n^{4}/\epsilon^{2}\right)
as required.
∎

4
Graphs, cost function nondependent on the target

In this section we shift out attention towards general graphs. We present an
O\mathopen{}\left(\sqrt{\log n}\right)
-approximation algorithm as well as an FPTAS parametrized by the number of non-leaf vertices of the input graph.

4.1
O\mathopen{}\left(\sqrt{\log n}\right)
-approximation algorithm

To obtain the first result we exploit a connection to a different problem,
namely the Min-Ratio Vertex Cut Problem.
Let
\alpha_{c,w}\mathopen{}\left(G\right)
denote the optimal value of such a vertex cut.
We invoke the following result:

Theorem 4.1

(
[
32
]
)
.

Given a graph
G=\mathopen{}\left(V\mathopen{}\left(G\right),E\mathopen{}\left(G\right)\right)
, the cost function
c:V\to\mathbb{N}
and the weight function
w:V\to\mathbb{N}
, there exists a
polynomial-time algorithm, which computes a partition
(A,S,B)
, such that:

\alpha_{c,w}\mathopen{}\left(A,S,B\right)=O\mathopen{}\left(\sqrt{\log n}\right)\cdot\alpha_{c,w}\mathopen{}\left(G\right).

Combining the latter procedure, with the following result, yields a general
O\mathopen{}\left(\sqrt{\log n}\right)
-approximation algorithm for the Graph Search Problem:

Theorem 4.2
.

Let
f_{n}
be the approximation ratio of any polynomial time algorithm for the Min-Ratio Vertex Cut Problem. Then, there exists an
O\mathopen{}\left(f_{n}\right)
-approximation algorithm for the GSP, running in polynomial time.

Proof.

Let
AlgorithmMinCut
be the procedure which achieves the
f_{n}
-approximation ratio for the Min-Ratio Vertex Cut Problem.
The algorithm is as follows:

Procedure

\textnormal{{DecisionTree}}\mathopen{}\left(G,c,w\right)
:

A_{G},S_{G},B_{G}\leftarrow\textnormal{{AlgorithmMinCut}}\mathopen{}\left(G,c,w\right)
.

D_{G}\leftarrow
arbitrary partial decision tree for
G
, built from vertices of
S_{G}
.

foreach

H\in G-S_{G}

do

D_{H}\leftarrow\textnormal{{DecisionTree}}\mathopen{}\left(H,c,w\right)
.

Hang
D_{H}
in
D_{G}
below the last query to
v\in N_{G}\mathopen{}\left(H\right)
.

return

D_{G}
.

Algorithm 3

The
f_{n}
-approximation algorithm for the Graph Search Problem.

Let
\mathcal{G}
be any subgraph of
G
, for which the procedure was called and let
S_{\mathcal{G}}^{*}=S_{\mathopen{}\left\lfloor w\mathopen{}\left(\mathcal{G}\right)/2\right\rfloor}^{*}\cap\mathcal{G}
. The next lemma, shows that we can use
S_{\mathcal{G}}^{*}
and
\mathcal{G}-S_{\mathcal{G}}^{*}
to build a vertex cut of
\mathcal{G}
, thus providing us with an upper bound on the cost of the solution built by the algorithm:

Lemma 4.3
.

Let
\mathcal{H}=\mathcal{G}-S_{\mathcal{G}}^{*}
and let
\lambda=6+2\sqrt{5}
be the unique, positive solution of the equation
\frac{1}{4}-\frac{1}{2\sqrt{\lambda}}=\frac{1}{\lambda}
. Then, we can partition
\mathcal{H}
into two sets,
\mathcal{A}
and
\mathcal{B}
such that for
A=\bigcup_{H\in\mathcal{A}}V\mathopen{}\left(H\right)
and
B=\bigcup_{H\in\mathcal{B}}V\mathopen{}\left(H\right)
, we have:

w\mathopen{}\left(A\cup S_{\mathcal{G}}^{*}\right)\cdot w\mathopen{}\left(B\cup S_{\mathcal{G}}^{*}\right)\geq w\mathopen{}\left(\mathcal{G}\right)^{2}/\lambda.

Proof.

There are two cases:

1.

w\mathopen{}\left(S_{\mathcal{G}}^{*}\right)\geq w\mathopen{}\left(\mathcal{G}\right)/\sqrt{\lambda}
. In this case we take arbitrary partition
\mathcal{A},\mathcal{B}
of
\mathcal{H}
. We have:

w\mathopen{}\left(A\cup S_{\mathcal{G}}^{*}\right)\cdot w\mathopen{}\left(B\cup S_{\mathcal{G}}^{*}\right)\geq w\mathopen{}\left(S_{\mathcal{G}}^{*}\right)^{2}\geq w\mathopen{}\left(\mathcal{G}\right)^{2}/\lambda.

2.

w\mathopen{}\left(S_{\mathcal{G}}^{*}\right)\leq w\mathopen{}\left(\mathcal{G}\right)/\sqrt{\lambda}
.
For any choice of the partition
\mathcal{A},\mathcal{B}
of
\mathcal{H}
, we have
\frac{w\mathopen{}\left(A\cup B\right)}{w\mathopen{}\left(\mathcal{G}\right)}\geq 1-\frac{1}{\sqrt{\lambda}}
. We pick
\mathcal{A},\mathcal{B}
to be a partition of
\mathcal{H}
, such that
w\mathopen{}\left(A\right)\geq w\mathopen{}\left(B\right)\geq\mathopen{}\left(\frac{1}{2}-\frac{1}{\sqrt{\lambda}}\right)\cdot w\mathopen{}\left(\mathcal{G}\right)
(this is always possible as
\frac{1}{2}-\frac{1}{\sqrt{\lambda}}>0
and for each
H\in\mathcal{H}
,
w\mathopen{}\left(H\right)\leq w\mathopen{}\left(\mathcal{G}\right)/2
). We have:

\displaystyle w\mathopen{}\left(A\cup S_{\mathcal{G}}^{*}\right)\cdot w\mathopen{}\left(B\cup S_{\mathcal{G}}^{*}\right)

\displaystyle\geq w\mathopen{}\left(A\right)\cdot w\mathopen{}\left(B\right)\geq\mathopen{}\left(\mathopen{}\left(1-{1}/{\sqrt{\lambda}}\right)\cdot w\mathopen{}\left(\mathcal{G}\right)-w\mathopen{}\left(B\right)\right)\cdot w\mathopen{}\left(B\right)

\displaystyle\geq{w\mathopen{}\left(\mathcal{G}\right)^{2}}/{2}\cdot\mathopen{}\left({1}/{2}-{1}/{\sqrt{\lambda}}\right)={w\mathopen{}\left(\mathcal{G}\right)^{2}}/{\lambda}

where the third inequality follows since the function
f\mathopen{}\left(w\mathopen{}\left(B\right)\right)=w\mathopen{}\left(B\right)\cdot\mathopen{}\left(\mathopen{}\left(1-\frac{1}{\sqrt{\lambda}}\right)\cdot w\mathopen{}\left(\mathcal{G}\right)-w\mathopen{}\left(B\right)\right)
is concave and reaches its minimum in the interval

\left[\mathopen{}\left({1}/{2}-{1}/{\sqrt{\lambda}}\right)\cdot w\mathopen{}\left(\mathcal{G}\right),w\mathopen{}\left(\mathcal{G}\right)/2\right]

when
w\mathopen{}\left(B\right)=\mathopen{}\left(\frac{1}{2}-\frac{1}{\sqrt{\lambda}}\right)\cdot w\mathopen{}\left(\mathcal{G}\right)
.

∎

Using the fact, that the partition
\mathopen{}\left(A,S_{\mathcal{G}}^{*},B\right)
in the above lemma is a vertex cut of
\mathcal{G}
, we have the following upper bound on the optimal value of the min-ratio-vertex cut of
\mathcal{G}
,
\alpha_{c,w}\mathopen{}\left(\mathcal{G}\right)
:

\alpha_{c,w}\mathopen{}\left(\mathcal{G}\right)\leq\alpha_{c,w}\mathopen{}\left(A,S_{\mathcal{G}}^{*},B\right)=\frac{c\mathopen{}\left(S_{\mathcal{G}}^{*}\right)}{w\mathopen{}\left(A\cup S_{\mathcal{G}}^{*}\right)\cdot w\mathopen{}\left(B\cup S_{\mathcal{G}}^{*}\right)}\leq\frac{\lambda\cdot c\mathopen{}\left(S_{\mathcal{G}}^{*}\right)}{w\mathopen{}\left(\mathcal{G}\right)^{2}}.

Let
\mathopen{}\left(A_{\mathcal{G}},S_{\mathcal{G}},B_{\mathcal{G}}\right)
, be the partition returned by
\textnormal{{AlgorithmMinCut}}\mathopen{}\left(\mathcal{G},c,w\right)
. Using Theorem
4.1
, we get that:

\alpha_{c,w}\mathopen{}\left(A_{\mathcal{G}},S_{\mathcal{G}},B_{\mathcal{G}}\right)=\frac{c\mathopen{}\left(S_{\mathcal{G}}\right)}{w\mathopen{}\left(A_{\mathcal{G}}\cup S_{\mathcal{G}}\right)\cdot w\mathopen{}\left(B_{\mathcal{G}}\cup S_{\mathcal{G}}\right)}\leq f_{n}\cdot\frac{\lambda\cdot c\mathopen{}\left(S_{\mathcal{G}}^{*}\right)}{w\mathopen{}\left(\mathcal{G}\right)^{2}}.

Without loss of generality we may assume that
w\mathopen{}\left(A_{\mathcal{G}}\right)\geq w\mathopen{}\left(B_{\mathcal{G}}\right)
. Let
\beta=w\mathopen{}\left(B_{\mathcal{G}}\cup S_{\mathcal{G}}\right)/w\mathopen{}\left(\mathcal{G}\right)
. We have that
\mathopen{}\left(1-\beta\right)\cdot w\mathopen{}\left(\mathcal{G}\right)=w\mathopen{}\left(A_{\mathcal{G}}\right)
, so we conclude that the contribution of the decision tree
D_{\mathcal{G}}
is bounded by:

\displaystyle w\mathopen{}\left(\mathcal{G}\right)\cdot c\mathopen{}\left(S_{\mathcal{G}}\right)

\displaystyle\leq\lambda\cdot f_{n}\cdot\frac{w\mathopen{}\left(A_{\mathcal{G}}\cup S_{\mathcal{G}}\right)\cdot w\mathopen{}\left(B_{\mathcal{G}}\cup S_{\mathcal{G}}\right)}{w\mathopen{}\left(\mathcal{G}\right)}\cdot c\mathopen{}\left(S_{\mathcal{G}}^{*}\right)\leq\lambda\cdot f_{n}\cdot w\mathopen{}\left(B_{\mathcal{G}}\cup S_{\mathcal{G}}\right)\cdot c\mathopen{}\left(S_{\mathcal{G}}^{*}\right)

\displaystyle\leq\lambda\cdot f_{n}\cdot\sum_{k=w\mathopen{}\left(A_{\mathcal{G}}\right)+1}^{w\mathopen{}\left(\mathcal{G}\right)}c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap\mathcal{G}\right)

where the last inequality is by Lemma
2.4
.

As before, to bound the cost of the whole solution we will firstly show the following lemma. The argument is mostly the same as for the Lemma
3.6
, however, there are few differences and we include it for completeness:

Lemma 4.4
.

\sum_{\mathcal{G}}\sum_{k=w\mathopen{}\left(A_{\mathcal{G}}\right)+1}^{w\mathopen{}\left(\mathcal{G}\right)}c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap\mathcal{G}\right)\leq\sum_{k=0}^{w\mathopen{}\left(G\right)}c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\right).

Proof.

Fix a value of
\mathcal{G}
and
k
. Their contribution to the cost is
c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap\mathcal{G}\right)
. Consider which candidate subgraphs contribute such a term. By definition of
S_{\mathcal{G}}
, we have that
\mathcal{G}
is the minimal subgraph, such that
w\mathopen{}\left(\mathcal{G}\right)\geq k\geq w\mathopen{}\left(A_{\mathcal{G}}\right)+1>w\mathopen{}\left(H\right)
, for every
H\in\mathcal{G}-S_{\mathcal{G}}
. This means that if for every
H\in\mathcal{G}-S_{\mathcal{G}}
,
w\mathopen{}\left(H\right)<k
, then
\mathcal{G}
contributes such a term. Since for all
H_{1},H_{2}\in\mathcal{G}-S_{\mathcal{G}}
,
H_{1}\cap H_{2}=\emptyset
, we have that
\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap H_{1}\right)\cup\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap H_{2}\right)=\emptyset
, the claim follows by summing over all values of
k
.
∎

We are now ready to bound the cost of the solution. Let
D
be the decision tree returned by the procedure. We have:

\displaystyle c_{G}\mathopen{}\left(D\right)

\displaystyle\leq\sum_{\mathcal{G}}w\mathopen{}\left(\mathcal{G}\right)\cdot c\mathopen{}\left(S_{\mathcal{G}}\right)\leq\lambda\cdot f_{n}\cdot\sum_{\mathcal{G}}\sum_{k=w\mathopen{}\left(A_{\mathcal{G}}\right)+1}^{w\mathopen{}\left(\mathcal{G}\right)}c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\cap\mathcal{G}\right)

\displaystyle\leq\lambda\cdot f_{n}\cdot\sum_{k=0}^{w\mathopen{}\left(G\right)}c\mathopen{}\left(S_{\mathopen{}\left\lfloor k/2\right\rfloor}^{*}\right)\leq 2\cdot\lambda\cdot f_{n}\cdot\texttt{OPT}\mathopen{}\left(G\right)=\mathopen{}\left(12+4\sqrt{5}\right)\cdot f_{n}\cdot\texttt{OPT}\mathopen{}\left(G\right)

where the third inequality is due to Lemma
4.4
and the last inequality is by Lemma
2.3
.
∎

It should be noted that for multiple classes of graphs, better approximation algorithms for the Min-Ratio Vertex Cut Problem are known. For example if
G
excludes
H
as a minor for some fixed graph
H
, then an
O\mathopen{}\left(\mathopen{}\left|V\mathopen{}\left(H\right)\right|^{2}\right)
-approximation algorithm for the Min-Ratio Vertex Cut Problem is given in
[
32
]
. This immediately implies constant factor algorithms for multiple classes of graphs, for example planar graphs or graphs with bounded treewidth. Observe that the analysis of our algorithm loses a factor of
2\lambda=12+4\sqrt{5}\approx 20.94
times

. We would like to bring
\lambda
closer to 1. Below we show an improved version of Lemma
4.3
showing that
\lambda
can be reduced to roughly
5.95
.

Lemma 4.5
.

Let
\mathcal{H}=\mathcal{G}-S_{\mathcal{G}}^{*}
and let
\lambda=\frac{22+2\sqrt{5}+\mathopen{}\left(1+\sqrt{5}\right)\cdot\sqrt{38+2\sqrt{5}}}{8}\approx 5.95
. Then, we can partition
\mathcal{H}
into two sets,
\mathcal{A}
and
\mathcal{B}
such that for
A=\bigcup_{H\in\mathcal{A}}V\mathopen{}\left(H\right)
and
B=\bigcup_{H\in\mathcal{B}}V\mathopen{}\left(H\right)
, we have:

w\mathopen{}\left(A\cup S_{\mathcal{G}}^{*}\right)\cdot w\mathopen{}\left(B\cup S_{\mathcal{G}}^{*}\right)\geq w\mathopen{}\left(\mathcal{G}\right)^{2}/\lambda.

Proof.

Let
x,y\in\mathbb{R}
be two real numbers, such that
2<x\leq y
.
There are three cases:

1.

w\mathopen{}\left(S_{\mathcal{G}}^{*}\right)\geq w\mathopen{}\left(\mathcal{G}\right)/x
. In this case we take arbitrary partition
\mathcal{A},\mathcal{B}
of
\mathcal{H}
. We have:

w\mathopen{}\left(A\cup S_{\mathcal{G}}^{*}\right)\cdot w\mathopen{}\left(B\cup S_{\mathcal{G}}^{*}\right)\geq w\mathopen{}\left(S_{\mathcal{G}}^{*}\right)^{2}\geq w\mathopen{}\left(\mathcal{G}\right)^{2}/x^{2}.

2.

w\mathopen{}\left(\mathcal{G}\right)/y\leq w\mathopen{}\left(S_{\mathcal{G}}^{*}\right)\leq w\mathopen{}\left(\mathcal{G}\right)/x
. For any choice of the partition
\mathcal{A},\mathcal{B}
of
\mathcal{H}
, we have
\frac{w\mathopen{}\left(A\cup B\right)}{w\mathopen{}\left(\mathcal{G}\right)}\geq 1-\frac{1}{x}
.
We pick
\mathcal{A},\mathcal{B}
to be a partition of
\mathcal{H}
, such that
w\mathopen{}\left(A\right)\geq w\mathopen{}\left(B\right)\geq\mathopen{}\left(\frac{1}{2}-\frac{1}{x}\right)\cdot w\mathopen{}\left(\mathcal{G}\right)
(this is always possible as
\frac{1}{2}-\frac{1}{x}>0
and for each
H\in\mathcal{H}
,
w\mathopen{}\left(H\right)\leq w\mathopen{}\left(\mathcal{G}\right)/2
).
We have:

\displaystyle w\mathopen{}\left(A\cup S_{\mathcal{G}}^{*}\right)\cdot w\mathopen{}\left(B\cup S_{\mathcal{G}}^{*}\right)

\displaystyle\geq w\mathopen{}\left(A\right)\cdot w\mathopen{}\left(B\right)+w\mathopen{}\left(S_{\mathcal{G}}^{*}\right)\cdot w\mathopen{}\left(A\cup B\right)+w\mathopen{}\left(S_{\mathcal{G}}^{*}\right)^{2}

\displaystyle\geq w\mathopen{}\left(\mathcal{G}\right)^{2}\cdot\mathopen{}\left(\frac{1}{4}-\frac{1}{2x}+\frac{1}{y}-\frac{1}{xy}+\frac{1}{y^{2}}\right).

3.

w\mathopen{}\left(S_{\mathcal{G}}^{*}\right)\leq w\mathopen{}\left(\mathcal{G}\right)/y
. For any choice of the partition
\mathcal{A},\mathcal{B}
of
\mathcal{H}
, we have
\frac{w\mathopen{}\left(A\cup B\right)}{w\mathopen{}\left(\mathcal{G}\right)}\geq 1-\frac{1}{y}
. We pick
\mathcal{A},\mathcal{B}
to be a partition of
\mathcal{H}
, such that
w\mathopen{}\left(A\right)\geq w\mathopen{}\left(B\right)\geq\mathopen{}\left(\frac{1}{2}-\frac{1}{y}\right)\cdot w\mathopen{}\left(\mathcal{G}\right)
(this is always possible as
\frac{1}{2}-\frac{1}{y}>0
and for each
H\in\mathcal{H}
,
w\mathopen{}\left(H\right)\leq w\mathopen{}\left(\mathcal{G}\right)/2
). We have:

w\mathopen{}\left(A\cup S_{\mathcal{G}}^{*}\right)\cdot w\mathopen{}\left(B\cup S_{\mathcal{G}}^{*}\right)\geq w\mathopen{}\left(A\right)\cdot w\mathopen{}\left(B\right)\geq w\mathopen{}\left(\mathcal{G}\right)^{2}\cdot\mathopen{}\left(\frac{1}{4}-\frac{1}{2y}\right).

We then find the values
x,y
, such that
\frac{1}{x^{2}}=\frac{1}{4}-\frac{1}{2x}+\frac{1}{y}-\frac{1}{xy}+\frac{1}{y^{2}}=\frac{1}{4}-\frac{1}{2y}
. The only pair of solutions to this equation, for which
2\leq x\leq y
, is:

\begin{cases}x=\frac{1}{4}\cdot\mathopen{}\left(1+\sqrt{5}+\sqrt{38+2\sqrt{5}}\right)\approx 2.43828\\
y=\frac{1}{4}\cdot\mathopen{}\left(-1+3\sqrt{5}+\sqrt{38+2\sqrt{5}}\right)\approx 6.11263\end{cases}

and one can easily check that
\lambda=x^{2}
, so the claim follows.
∎

We get that the approximation ratio of our algorithm is at most
2\cdot\lambda\cdot f_{n}\approx 11.89\cdot f_{n}
.

4.2
FPTAS for graphs with bounded number of non-leaf vertices

In this section, we present an FPTAS for the Graph Search Problem running in time parameterized by the number of non-leaf vertices of the input graph
k
. To showcase the main ideas, we firstly present a simplified version of the FPTAS for stars (
k=1
). Then, we extend the result to general graphs with
k
non-leaf vertices.
In this section we treat the decision tree as a form of a schedule in which each query to
v\in V\mathopen{}\left(G\right)
is a job. After performing a query to
v
in subgraph
G^{\prime}
the machine processing it is replaced by
\mathopen{}\left|G^{\prime}-v\right|
copies of that machine, each processing queries in one connected component of
G^{\prime}-v
. In order to build our schedules effectively we will allow the decision tree to contain idle times between queries. By
C_{v}
we shall denote the completion time of a query to
v
, which includes these idle times. Note that upon termination of our procedures, if such idle times are present in the resulting decision tree, we can always remove them without increasing the cost of the solution.

Theorem 4.6
.

For any
0<\epsilon\leq 3
there exists an FPTAS for the Tree Search Problem on stars running in time
O\mathopen{}\left(n^{2}\cdot\log^{2}c\mathopen{}\left(T\right)/\mathopen{}\left(\epsilon\cdot\log\mathopen{}\left(1+\epsilon\right)\right)\right)
(Note that
\log\mathopen{}\left(c\mathopen{}\left(T\right)\right)
is the number of bits required to represent
c
so the running time is polynomial).

Proof.

Let
r=r\mathopen{}\left(T\right)
be the center of the star and let
\mathopen{}\left(v_{1},v_{2},\ldots,v_{m}\right)
be its leaves. We devise a following dynamic program which finds an almost optimal decision tree for this case. Let
A[t]
be the cost of the optimal decision tree assuming that
r
is queried at the moment
t
. Ideally, to find the global optimum we would like to compute
\min_{t}A[t]
. However, since the only reasonable upper bound on
t
is
c\mathopen{}\left(T\right)
, we would only like to consider some of the values of
t
to keep the running time polynomial. Let
\delta=\epsilon/3
. Consider the following set of moments
\mathcal{M}=\mathopen{}\left\{0,1,(1+\delta)^{1},(1+\delta)^{2},\ldots,(1+\delta)^{\mathopen{}\left\lceil\log c\mathopen{}\left(T\right)/\log\mathopen{}\left(1+\delta\right)\right\rceil}\right\}
. We have the following lemma:

Lemma 4.7
.

Let
t^{*}
be the optimal moment to query
r
. There exists
t^{\prime}\in\mathcal{M}
such that
A[t^{\prime}]\leq\mathopen{}\left(1+\delta\right)\cdot A[t^{*}]
.

Proof.

Assume that
t^{*}\neq 0
and
t^{*}\neq\mathopen{}\left(1+\delta\right)^{\mathopen{}\left\lceil\log c\mathopen{}\left(T\right)/\log\mathopen{}\left(1+\delta\right)\right\rceil}
, since otherwise we are done. Let
j
be such that
(1+\delta)^{j-1}<t^{*}\leq(1+\delta)^{j}
. Let
D^{*}
be the optimal decision tree assuming that
r
is queried at the moment
t^{*}
. We will construct a decision tree
D^{\prime}
in which
r
is queried at the moment
t^{\prime}=(1+\delta)^{j}
and show that for every vertex
x\in V\mathopen{}\left(T\right)
,
c\mathopen{}\left(D^{\prime},x\right)\leq\mathopen{}\left(1+\delta\right)\cdot c\mathopen{}\left(D^{*},x\right)
. The decision tree
D^{\prime}
is constructed as follows: We start with
D^{*}
and delay the query to
r
to the moment
t^{\prime}=(1+\delta)^{j}
. This changes the contribution of
r
and previous queries to the cost each vertex
v\in T_{D^{*},r}
from at least
\mathopen{}\left(1+\delta\right)^{j-1}+c\mathopen{}\left(r\right)
to at most
\mathopen{}\left(1+\delta\right)^{j}+c\mathopen{}\left(r\right)
. Since
\frac{\mathopen{}\left(1+\delta\right)^{j}+c\mathopen{}\left(r\right)}{\mathopen{}\left(1+\delta\right)^{j-1}+c\mathopen{}\left(r\right)}\leq 1+\delta
and the contribution of other vertices to the cost remains unchanged, the claim follows.
∎

Now we notice that for every
t\in\mathcal{M}
,
A[t]
is an instance of the following problem known as
Scheduling with Rejection
. In this problem we are given a set of jobs
[n]
where each job
i
has processing time
p_{i}
and rejection cost
e_{i}
. The goal is to find a subset of jobs
S\subseteq[n]
which are chosen to be scheduled. It is additionally assumed that all jobs which are scheduled finish at time at most
\tau
. The objective is to minimize
\sum_{i\in S}w_{i}C_{i}+\sum_{i\notin S}e_{i}
where
C_{i}
is the completion time of job
i
in the schedule. For this problem an FPTAS running in
O\mathopen{}\left(n^{2}/\delta\cdot\log\sum_{i}p_{i}\right)
time exists
[
30
]
.

To see that
A[t]
is a special case of scheduling with rejection, for every leaf
v_{i}
, we create job
i
with
p_{i}=c\mathopen{}\left(v_{i}\right)
,
w_{i}=w\mathopen{}\left(v_{i}\right)
and
e_{i}=w\mathopen{}\left(v_{i}\right)\cdot\mathopen{}\left(t+c\mathopen{}\left(r\right)+c\mathopen{}\left(v_{i}\right)\right)
. Additionally, we set
\tau=t
and we create job
0
with
p_{0}=\infty
and
e_{0}=w\mathopen{}\left(r\right)\cdot\mathopen{}\left(t+c\mathopen{}\left(r\right)\right)
. To see that these problems are equivalent notice that in any feasible solution of the scheduling with rejection instance, job

must be rejected, which corresponds to the fact that

is always queried at moment

which are processed in a sequential manner. The cost of rejecting a job is the contribution of the leaves which are assumed to be queried after

in the decision tree. Therefore, we can use the algorithm of
[
30
]
to compute an
\mathopen{}\left(1+\delta\right)
-approximation of

for every

in time
O\mathopen{}\left(n^{2}/\delta\cdot\log c\mathopen{}\left(T\right)\right)
. By choosing the best solution among all

and using the above lemma, we get an
\mathopen{}\left(1+\delta\right)^{2}\leq\mathopen{}\left(1+3\delta\right)=\mathopen{}\left(1+\epsilon\right)
-approximation. The running time is
O\mathopen{}\left(\mathopen{}\left|\mathcal{M}\right|\cdot n^{2}\cdot\log c\mathopen{}\left(T\right)/\delta\right)=O\mathopen{}\left(n^{2}\cdot\log^{2}c\mathopen{}\left(T\right)/\mathopen{}\left(\epsilon\cdot\log\mathopen{}\left(1+\epsilon\right)\right)\right)
as required.

∎

In order to extend the above result to graphs with a bounded number of non-leaf vertices, we use a similar idea, however we need a stronger dynamic program for the individual subproblems. To do so, we generalize the aforementioned FPTAS for scheduling with rejection.

Theorem 4.8
.

For any
0<\epsilon\leq 1
there exists an FPTAS for the Graph Search Problem for graphs with
k
non-leaf vertices running in time

Proof.

In order for the state space to have polynomial size, we will use the following aligning technique. Recall, that for the case of stars, we have only considered decision trees which query the center of the star at a moment which is a power of
\mathopen{}\left(1+\delta\right)
. In what follows, we employ a similar idea, however this time we will require that each query ends at a moment which is a power of
\mathopen{}\left(1+\delta\right)
for some value of
\delta
to be defined later. We say that a decision tree is

if for every query in the decision tree, the query ends at a moment
\tau_{j}=\mathopen{}\left(1+\delta\right)^{j}
. We have the following lemma:

Lemma 4.9
.

Let

be an optimal decision tree for the Graph Search Problem on a graph

such that for every vertex

,

Proof.

We construct

from

as follows: We start with the root of
D^{*}
and we process the decision tree in a top-down manner. Whenever we reach a query of a vertex

which ends at a moment which is not a power of
\mathopen{}\left(1+\delta\right)

v
to the next such moment. Let
h
be the depth of the query to
v
in
D^{*}
, i. e., its distance from the root (measured in the number of vertices). We show by induction on

that after aligning queries up to

, for every vertex

,

. We notice that whenever a query finished at time

after all queries preceeding it, have already been aligned its completion time is changed to
\mathopen{}\left(1+\delta\right)\cdot t
.
This established the base case for

. Assume that the claim holds for some

be a query at depth

increased by an additive factor of at most
[\mathopen{}\left(1+\delta\right)^{h}-1]\cdot C_{p}

\mathopen{}\left(1+\delta\right)\cdot\mathopen{}\left(C_{v}+[\mathopen{}\left(1+\delta\right)^{h}-1]\cdot C_{p}\right)\leq\mathopen{}\left(1+\delta\right)^{h+1}\cdot C_{v}

∎

In what follows we set

. Observe that

for any

is convex and therefore always lesser than or equal to a linear function

\mathopen{}\left(1+\delta\right)^{n}=\mathopen{}\left(1+\frac{\epsilon\cdot\ln 2}{n}\right)^{n}\leq e^{\epsilon\cdot\ln 2}=2^{\epsilon}\leq 1+\epsilon.

Similarly, as for the star case we wish to guess the moments at which the queries to the inner vertices are finished. Since there are

\mathopen{}\left(1+\delta\right)^{n}\cdot c\mathopen{}\left(G\right)

\mathopen{}\left\lceil n\cdot\log c\mathopen{}\left(G\right)/\log\mathopen{}\left(1+\delta\right)\right\rceil=O\mathopen{}\left(n^{2}\cdot\log c\mathopen{}\left(G\right)/\log\mathopen{}\left(1+\epsilon\right)\right)

Let

For every valid

5
Trees, monotone cost functions

Below we show an integer linear programming formulation of the separator assignment. This will allow us to build a
2
-approximation algorithm for the case when the cost function is monotone, non-decreasing with respect to the target. The ILP is inspired by the approach of
[
1
]
for the Hub Labeling Problem which for uniform costs is equivalent to finding a sequence assignment with small cost.
We introduce a binary variable
x_{u,v}
for every ordered pair of vertices
u,v\in V\mathopen{}\left(T\right)
, which indicates whether
u\in S\mathopen{}\left(v\right)
. We also introduce binary variables
y_{u,v,w}
for every ordered triple of vertices
u,v,w\in V\mathopen{}\left(T\right)
, which indicates whether
u\in S\mathopen{}\left(v\right)\cap S\mathopen{}\left(w\right)
. Note that
y_{u,v,w}
and
y_{u,w,v}
encode the same event, however for the sake of simplicity of writing we include both variables. The ILP is as follows:

min

\displaystyle\sum_{v\in V\mathopen{}\left(T\right)}w\mathopen{}\left(v\right)\cdot\sum_{u\in V\mathopen{}\left(T\right)}c\mathopen{}\left(u,v\right)\cdot x_{u,v}

subject to

\displaystyle y_{u,v,w}\leq x_{u,v}

\displaystyle\forall u,v,w\in V\mathopen{}\left(T\right)

\displaystyle y_{u,v,w}\leq x_{u,w}

\displaystyle\forall u,v,w\in V\mathopen{}\left(T\right)

\displaystyle\sum_{u\in P_{v,w}}y_{u,v,w}\geq 1

\displaystyle\forall v,w\in V\mathopen{}\left(T\right)

\displaystyle x_{u,v}\in\mathopen{}\left\{0,1\right\}

\displaystyle\forall u,v\in V\mathopen{}\left(T\right)

\displaystyle y_{u,v,w}\in\mathopen{}\left\{0,1\right\}

\displaystyle\forall u,v,w\in V\mathopen{}\left(T\right)

The objective function is to minimizes the min sum cost of the separator assignment. The first two constraints ensure that
y_{v,u,w}
can only be non-zero if both
x_{v,u}
and
x_{w,u}
are non-zero, which corresponds to
u
being in both
S\mathopen{}\left(v\right)
and
S\mathopen{}\left(w\right)
. The third constraint ensures that for any pair of vertices
v
and
w
, there exists at least one vertex
u
on the path between them that is both in

S\mathopen{}\left(v\right)
and
S\mathopen{}\left(w\right)
, which corresponds to the separator assignment property.

The algorithm

The Algorithm

works as follows: We first solve the linear programming relaxation of the above ILP. Then, for each vertex
v\in V\mathopen{}\left(T\right)

by rerooting

at
v
. We then use the
PseudoSepAssignment

and the obtained fractional variables
\mathbf{x}
to construct a pseudo-separator assignment

in a bottom-up manner. Notably, despite the fact that for each vertex

the assignment

T^{v}
and the last inequality is by the fact that the sets
H_{w}^{v}
are disjoint for different
w
. This concludes the proof.
∎

5.3
Reconstructing the decision tree

Lemma 5.4
.

Given a tree
T
and a pseudo-separator assignment
S
, there exists a polynomial time algorithm
ReconstructDecisionTree
which constructs a decision tree
D
such that for every
x\in V\mathopen{}\left(T\right)
,
c_{T}\mathopen{}\left(D,x\right)\leq c\mathopen{}\left(S\mathopen{}\left(x\right),x\right)
.

Proof.

The algorithm is recursive and takes as an input a tree
T
and a pseudo-separator assignment
S
and outputs a decision tree
D
. The algorithm works in a bottom-up manner. It starts by constructing a tree
T^{S\mathopen{}\left(v\right)}=\bigcup_{u\in S\mathopen{}\left(v\right)}P_{v,u}
for each vertex
v
. By definition of the pseudo-separator assignment, the resulting family of trees satisfies the
Helly
property
[
35
]
, i.e., for every
u,v\in V\mathopen{}\left(T\right)
, we have that
V\mathopen{}\left(T^{S\mathopen{}\left(v\right)}\right)\cap V\mathopen{}\left(T^{S\mathopen{}\left(u\right)}\right)\neq\emptyset
. Therefore, there exists a vertex
r\in\bigcap_{v\in V\mathopen{}\left(T\right)}V\mathopen{}\left(T^{S\mathopen{}\left(v\right)}\right)
. The root of
D
is set to be
r
. Then, for each connected component
H\in T-r
, the subtree of
D
corresponding to
H
is built recursively and hanged below
r
in
D
. Finally, the resulting decision tree
D
is returned.

Procedure

\textnormal{{ReconstructDecisionTree}}\mathopen{}\left(T,S\right)
:

for

v\in V\mathopen{}\left(T\right)

do

T^{S\mathopen{}\left(v\right)}\leftarrow\bigcup_{u\in S\mathopen{}\left(v\right)}P_{v,u}
.

r\leftarrow
an arbitrary node in
\bigcap_{v\in V\mathopen{}\left(T\right)}T^{S\mathopen{}\left(v\right)}
.

D\leftarrow\mathopen{}\left(r,\emptyset\right)
.

for

H\in T-r

do

D_{H}\leftarrow\textnormal{{ReconstructDecisionTree}}\mathopen{}\left(H,S\right)
.

Hang
D_{H}
below
r
in
D
.

return

D
.

Algorithm 6

The algorithm to reconstruct a decision tree from a pseudo-separator assignment.

We show that for every
x\in V\mathopen{}\left(T\right)
,
c_{T}\mathopen{}\left(D,x\right)\leq c\mathopen{}\left(S\mathopen{}\left(x\right),x\right)
. Consider any
x\in V\mathopen{}\left(T\right)
. Since
r\in V\mathopen{}\left(T^{S\mathopen{}\left(x\right)}\right)
, there exists a vertex
s\in S\mathopen{}\left(x\right)
such that
s\in P_{r,x}
. If
r=s
, then the cost of the query sequence of
x
built based on
S\mathopen{}\left(x\right)
remains unchanged. Otherwise, notice that after query to
r
,
x
and
s
belong to different connected components of
T-r
. This in turn implies that
s
will never be queried when searching for
x
and by the monotonicity of costs we have that
c\mathopen{}\left(r,x\right)\leq c\mathopen{}\left(s,x\right)
. Therefore, the cost of the query sequence of
x
built based on
S\mathopen{}\left(x\right)
does not increase. Since the same also holds inductively for the subtrees of
D-r
, we get that
c_{T}\mathopen{}\left(D,x\right)\leq c\mathopen{}\left(S\mathopen{}\left(x\right),x\right)
as required.
∎

Theorem 5.5
.

There exists a 2-approximation algorithm for the Average-Case Tree Search Problem running in polynomial time.

Proof.

By combining Lemmas
5.1
and
5.4
, we get that for every
v\in V\mathopen{}\left(T\right)
, the cost of the query sequence of
v
in the decision tree
D
constructed by Algorithm
4
is at most
2\cdot\sum_{u\in V\mathopen{}\left(T\right)}c\mathopen{}\left(u,v\right)\cdot x_{u,v}
. Therefore, the cost of

is at most:

\sum_{v\in V\mathopen{}\left(T\right)}w\mathopen{}\left(v\right)\cdot c_{T}\mathopen{}\left(D,v\right)\leq 2\cdot\sum_{v\in V\mathopen{}\left(T\right)}w\mathopen{}\left(v\right)\cdot\sum_{u\in V\mathopen{}\left(T\right)}c\mathopen{}\left(u,v\right)\cdot x_{u,v}\leq 2\cdot\texttt{OPT}\mathopen{}\left(T\right).

∎

Using a very similar approach we can also obtain a

min

\displaystyle\forall u,v,w\in V\mathopen{}\left(T\right)

6
Hardness

6.1
Trees, costs nondependent on target

We begin by showing that the Tree Search Problem with target independent cost functions is NP-complete. The decision version of the Tree Search Problem is to determine whether,
for a given instance
\mathopen{}\left(T,c,w\right)
, there exists a decision tree of cost at most
K
.

Theorem 6.1
.

The Decision Tree Search Problem is NP-complete even when restricted to trees with
\Delta\mathopen{}\left(T\right)\leq 16
and to trees with
\operatorname{diam}\mathopen{}\left(T\right)\leq 6
.

Proof.

The problem is in NP since, given a decision tree
D
, one can verify in polynomial time
whether all the requirements are satisfied.

To show hardness, we use a black-box reduction from the edge-query, uniform-cost,
and non-uniform-weight variant, which is NP-complete even when restricted to trees with
\Delta\mathopen{}\left(T\right)\leq 16
and to trees with
\operatorname{diam}\mathopen{}\left(T\right)\leq 4

[
38
]
.
Let
\mathopen{}\left(T,w,K\right)
be such an instance.
We construct a new instance
\mathopen{}\left(T^{\prime},c,w,K^{\prime}\right)
for the Tree Search Problem as follows:
for every
v\in V\mathopen{}\left(T\right)
, we set
c\mathopen{}\left(v\right)=K+1
.
If neither of the edge endpoints is a leaf, we subdivide each edge
e\in E\mathopen{}\left(T\right)
by adding a new vertex
v_{e}
with

w\mathopen{}\left(v_{e}\right)=0
and
c\mathopen{}\left(v_{e}\right)=1
. If otherwise, we set
w\mathopen{}\left(v_{e}\right)=w\mathopen{}\left(u\right)
where
u
is the leaf endpoint of
e
and set
c\mathopen{}\left(v_{e}\right)=1
. Let
w_{\ell}\mathopen{}\left(T\right)=\sum_{u\text{ is a leaf}}w\mathopen{}\left(u\right)
.
We set
K^{\prime}=K+\mathopen{}\left(w\mathopen{}\left(T\right)-w_{\ell}\mathopen{}\left(T\right)\right)\cdot\mathopen{}\left(K+1\right)
.

Assume that we have a decision tree
D
of cost at most
K
for the original instance.
To obtain a decision tree
D^{\prime}
for the new instance, we replace each query in
D

with a query to the vertex that subdivides the corresponding edge (or the leaf endpoint if the edge has one).
Additionally, (if needed) below each leaf of
D
, we attach the appropriate queries to the original vertices.
As
D
contains a query to every edge of
T
, each vertex is separated, so for every

v\in V\mathopen{}\left(T\right)
, one such additional query is added whenever
v
is not a leaf.
This results in a decision tree
D^{\prime}
of cost at most
K+\mathopen{}\left(w\mathopen{}\left(T\right)-w_{\ell}\mathopen{}\left(T\right)\right)\cdot\mathopen{}\left(K+1\right)=K^{\prime}
,
as required.

Observe that in the new instance, for every non leaf vertex
v\in T
, the cost of searching for
v

is at least
K+1
since
c\mathopen{}\left(v\right)=K+1
.
Therefore, for these vertices, at least
\mathopen{}\left(w\mathopen{}\left(T\right)-w_{\ell}\mathopen{}\left(T\right)\right)\cdot\mathopen{}\left(K+1\right)
cost is required.
This implies that each such vertex has exactly one such query in its query sequence,
namely the query to
v
itself. Otherwise, the cost would exceed
K^{\prime}
, and we conclude
that every such
v
is queried only when the candidate subset consists solely of
v
.
Assume there exists a decision tree
D^{\prime}
of cost at most
K^{\prime}
for the new instance.
We show how to obtain a decision tree
D
for the original instance.
We replace each query to a vertex
v_{e}
with a query to edge
e
,
and delete all queries to vertices
v\in V\mathopen{}\left(T\right)
.
Since each
v\in V\mathopen{}\left(T\right)
was the last query in
Q_{D^{\prime}}\mathopen{}\left(T^{\prime},v\right)
, performed
when the candidate set consisted only of
v
, the resulting
D
is a valid decision tree
for the original instance. Additionally, the cost of
D
is at most
K^{\prime}-\mathopen{}\left(w\mathopen{}\left(T\right)-w_{\ell}\mathopen{}\left(T\right)\right)\cdot\mathopen{}\left(K+1\right)=K
,
as required.

Finally, note that subdividing each edge (except those containing leaf vertices) results in a tree with diameter
\operatorname{diam}\mathopen{}\left(T^{\prime}\right)=2\cdot\operatorname{diam}\mathopen{}\left(T\right)-2
of the tree while leaving the largest degree unchanged,
so the claim follows.

∎

6.2
Stars, costs dependent on target

Assume that the cost is allowed to be an arbitrary function
c\colon V\mathopen{}\left(T\right)\times V\mathopen{}\left(T\right)\to\mathbb{N}
. It should be noted that in this most general variant, the weight function is redundant since for every
u,v\in V\mathopen{}\left(T\right)
, one can set
c^{\prime}\mathopen{}\left(v,u\right)=w\mathopen{}\left(u\right)\cdot c\mathopen{}\left(v,u\right)
and therefore we can omit the weight function from the input.

The Unique Games Conjecture (UGC) introduced by Khot
[
40
]
is a statement about the hardness of a certain type of constraint satisfaction problems. An instance
\mathcal{L}=\mathopen{}\left(G\mathopen{}\left(V,W,E\right),[n],\mathopen{}\left\{\pi_{vw}\right\}_{vw\in E}\right)
of UGC consists of a regular bipartite graph
G\mathopen{}\left(V,W,E\right)
and a set of viable labels
[n]
. Each edge
vw\in E
is associated with a permutation
\pi_{v,w}\colon[n]\to[n]
. A labeling is a function
f\colon V\cup W\to[n]
assigning a label to each vertex. An edge
vw
is satisfied by labeling
f
if
\pi_{v,w}\mathopen{}\left(f\mathopen{}\left(v\right)\right)=f\mathopen{}\left(w\right)
. The goal is to find a labeling that maximizes the fraction of satisfied edges. The UGC states that for every
\zeta,\gamma>0
, there exists an integer
n=n\mathopen{}\left(\zeta,\gamma\right)
such that it is NP-hard to distinguish between the following two cases for an instance of UGC with label set
[n]
:

•

YES Case:
There exists a labeling satisfying at least
1-\zeta
fraction of edges.

•

NO Case:
Every labeling satisfies at most
\gamma
fraction of edges.

The Minimum Cost Feedback Arc Set Problem is the following: Given a directed graph
G\mathopen{}\left(V,E\right)
and a cost funtion
c\colon E\to\mathbb{N}
, find a subset of edges
E^{\prime}\subseteq E
of minimum size such that the graph
\mathopen{}\left(V,E\setminus E^{\prime}\right)
is acyclic. By
[
34
]
, the problem does not admit any constant factor approximation under the UGC. The Minimum Linear Ordering Problem is the following: Given a matrix
A\in\mathbb{N}^{n\times n}
, find a permutation
\pi
of
[n]
minimizing
\sum_{i<j}A_{\pi\mathopen{}\left(i\right),\pi\mathopen{}\left(j\right)}
. In fact the Minimum Linear Ordering Problem is equivalent to the Minimum Cost Feedback Arc Set Problem
[
46
]
, which yields the same hardness of approximation result for the latter.
We show that Minimum Linear Ordering is a special case of the Average-Case Tree Search Problem with arbitrary costs.

Theorem 6.2
.

The Average-Case Tree Search Problem with arbitrary costs is NP-hard and does not admit any constant factor approximation under the UGC even when the input tree is a star.

Proof.

Given an instance
A\in\mathbb{N}^{n\times n}
of the Minimum Linear Ordering Problem, we construct an instance
\mathopen{}\left(T,c,w\right)
of the Average-Case Tree Search Problem as follows: We start with a vertex
r
which will be the center of the star. For every
1\leq i\leq n
, we create a leaf
v_{i}
connected to
r
. For every
i,j\in[n],i\neq j
, we set:
c\mathopen{}\left(v_{i},v_{j}\right)=A_{i,j}
,
c\mathopen{}\left(r,v_{i}\right)=\infty
for every
i\in[n]
and
c\mathopen{}\left(v_{i},r\right)=0
for every
i\in[n]
, and
c\mathopen{}\left(v,v\right)=0
for every
v\in V\mathopen{}\left(T\right)
.

It is easy to observe, that any reasonable strategy firstly queries all leafs (in some order) and then queries
r
. Additionally, notice that the contribution of
r
to the objective function in such scenario is 0. Now, see that a given query results in a cost of
A_{i,j}
if and only if the query to
v_{i}
is performed before the query to
v_{j}
. Therefore, the cost of the decision tree is exactly
\sum_{i<j}A_{\pi\mathopen{}\left(i\right),\pi\mathopen{}\left(j\right)}
where
\pi
is the permutation of
[n]
corresponding to the order of queries to leafs. This concludes the proof.
∎

The state of the art algorithm for the Minimum Feedback Arc Set Problem achieves an approximation ratio of
O\mathopen{}\left(\log n\cdot\log\log n\right)

[
31
]
. This suggests that the introduction of the target dependent costs makes the problem significantly harder to approximate. We leave as an open question whether any polylogarithmic approximation is achievable beyond paths, for which one can easily easily find the optimal solution using dynamic programming, since for
P=\mathopen{}\langle v_{1},\dots,v_{n}\rangle
,
\texttt{OPT}[P]=\min_{1\leq i\leq n}\mathopen{}\left\{\sum_{j=1}^{n}c\mathopen{}\left(v_{i},v_{j}\right)+\sum_{P^{\prime}\in P-v_{i}}\texttt{OPT}[P^{\prime}]\right\}
which can be solved in
O\mathopen{}\left(n^{3}\right)
time.
