ABSTRACT
 Environmental sampling methods developed by the Savannah River
 National Laboratory (SRNL) employ collectors with sorbent media tubes set at
 various locations to collect airborne emissions. Laboratory analyses of these tubes
 results in one-dimensional signals regarding what chemicals are being released
 and transported within the atmosphere. The analysis process is time consuming
 especially when analyzing a full year’s worth of tubes (hourly sample collection
 results in nearly 9,000 tubes per year). Using a signal processing method such as
 compressed sensing allows for recreation of the full signal while greatly reducing
 the number of analyzed samples required. Due to the sparsity of data retrieved
 from the air tubes, it is possible to use measurements a fraction of the size of the
 original data to gain much of the same information. This would improve the overall
 time and cost of analysis when modeling one-dimensional sampling signals.

I. INTRODUCTION
 Compressed sensing is a recent addition to applied mathematics research which provides
an advanced method of one-dimensional signal compression and reconstruction. By assuming the
original signal is sparse in some domain (contains very few non-zero values) and compressible 1
we are able to create a linear system of equations to compress the signal. We hypothesize it is
possible to take a limited number of random samples from some sparse vector derived from the
original signal and reconstruct a full signal of the original’s size.
 Using random sampling to determine which measurements to use in the computation
allows us to essentially bypass the Shannon-Nyquist sampling theorem which states that in order
to fully represent some initial function, it must be sampled at no less than twice the highest
frequency present in the function 2. Typically, sampling done at lower than this value results in
aliasing 2, which provides a reconstruction that appears at a far lower frequency than expected,
wildly misrepresenting the initial function. Using randomness to our advantage will yield
measurements both close together and spread apart to be used, allowing both low and high
frequencies to be accounted for.

 Because the number of measurements is far fewer than the original signal’s length, the
linear equation produced by this calculation is an underdetermined system, meaning that there
will be infinite sparse vectors that satisfy the equation with some given measurement vector. In
order to constrain this to one correct vector, we aim to minimize the error to find the sparsest

 2

vector. This is done via an L1 regularization or minimization algorithm such as Least Absolute
Shrinkage and Selection Operator (LASSO)3.
 Some assumptions regarding the data must be confirmed before any computations are
made in order to properly use compressed sensing methods: the original signal must be sparse,
and the matrices used in the equation (the custom sensing matrix and the basis matrix) must be
incoherent. This means that the values in the sensing matrix should act unitary and independent
to those in the basis matrix 4. This implies that sensing matrix would also follow the Restricted
Isometry Property (RIP) which is a necessary and sufficient condition that states that the matrix
must act orthogonal, or map two different signals to two different measurements 5, 6.Though it is
computationally difficult to prove RIP, there are some matrices (generally random matrices) that
are known to satisfy the property. If these conditions hold, then compressed sensing would be
feasible for the data set.

 We apply compressed sensing methods to a one-dimensional signal retrieved from a
previously collected data set comprised of consecutive hourly air samples at Savannah River Site
(SRS) taken over the course of one year. This will allow us to test our hypothesis that a small
number of measurements can be taken from the full signal comprised of 8,640 samples and
generate a faithful reconstruction of the original data. By refining the number of measurements
taken, we are able to reduce the error in the reconstructed signal while maintaining a
significantly reduced number of measurements, which will result in greatly reduced analysis
costs.

 For general cases of compressed sensing, the linear system appears as the following:
 y = CΨx (5)
 In the scenario where the original signal is sparse in the time domain (as is here),
substitution using equation 3 shows that the linear system above can be written simply as
 y = Cx (6)
 The matrix C will simply pick values from the sparse vector to compute y, thus there are
a couple of ways to create and tailor C. In order to satisfy RIP, it is simplest to make C a random
matrix. Two of the most common for this use are the Gaussian matrix or Bernoulli matrix 1. A
Gaussian matrix is some M×N matrix filled with random values centered at 0 with a standard
deviation of 1. The Bernoulli matrix is comprised of 0’s and 1’s, where each cell in the matrix
and some probability p (0 < p < 1) of being 1 and probability 1-p of being 0. Both matrices will
produce very similar results simply because they both satisfy RIP, but the Gaussian matrix is
computationally expensive due to the number of calculations required, especially with high-
dimensional data. Thus, in this project, we use a Bernoulli matrix with a probability of 0.1 as the
random matrix C.

 B. Calculations and Algorithms
 Once the measurement vector y is created via Equation 6, we are able to proceed to
reconstruction via minimizing the error in the x vector. We want the vector with the most
sparsity, so we ideally should choose to optimize the L0-norm. Though this would be ideal, the
L0-norm is non-convex and NP-Hard, meaning it is a combinatorially hard question that cannot
be solved in polynomial time with an algorithm 9. To circumvent this, we aim to minimize the L1-
norm instead which is a convex relaxation of the L0-norm that typically yields the same answer1.
Due to its convexity10, there are many algorithms used for L1 minimization, in this project, we
use the LASSO regularization algorithm.
 LASSO is a regression technique that uses the L1-norm’s convex property and its ability
to promote sparsity to do L1 regularization in order to achieve the sparsest possible solution. As
opposed to typical least squares methods, this algorithm also uses a parameter called the L1
penalty (λ) which optimizes the balance between bias and variance and is found through cross-
validation 11. An excess of bias leads to an over-simplified reconstruction which does not capture
enough of the true data, while too much variance overfits the reconstruction and creates a far too
complex recreation3. As found in Brunton’s textbook ‘Data Driven Science and Engineering’ 1,
taking this variable into account results in the following optimization equation:
                                       x = argmin(x’) ||Cx’-y||2 + λ||x||1                        (7)

This equation translates to finding the optimized x’ vector such that Cx’-y is close to zero and x is
as sparse as possible.

 After the reconstructed signal is calculated, we are able to simply plot the signal without
any inverse transformation functions because no domain transfer occurred. To additionally
reduce the error of the new signal, we can add bounds that naturally appear in the original signal.
In this case, we know that it is impossible for the original signal to contain negative values 12. We
are able iterate through the reconstructed signal vector and manually replace any negative values
with zeros, further reducing the sparsity as well as the error to the original data.

IV. CONCLUSION
 Typical uses of compressed sensing include image and audio signal compression 13, but
further explored utilization have been achieved in recent years to include all corners of science.

 8

Applications stretching to seismic waves14 and financial trends15 have also been used, showing
that compressed sensing can be used on many data types, as long as it is a one-dimensional
signal. This exploration led to the concept of applying these techniques to emission collectors,
and applicably current air sample methods with one-dimensional signals where little research has
been presented. By being able to produce a signal accurate to the original using only a small
portion of the total data, analysis of these samples would greatly reduce in time and cost,
allowing for these reconstructions to be made more rapidly. Creating a program to investigate the
random sensing matrix and determine which of the values in the original x vector will be used to
create the measurement vector could prove incredibly useful by making this short analysis time
possible and applicable. Knowing which few random samples to analyze and being able to input
only those values so the algorithm could calculate the recreated signal would be further steps into
making this full process successful.

 This project has shown that one dimensional data collected from emission collectors is
sparse in the time domain, making compressed sensing not only possible, but successful in being
able to make a faithful reconstruction of the original signal by using only 20% of the total
measurement amount, proving our hypothesis. Application of this research can lead to reduced
analysis costs of future collected air tubes, reducing analytical cost for Savannah River National
Laboratory without sacrificing valuable data.
