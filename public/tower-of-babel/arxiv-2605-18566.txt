HJ-Gauss: A Monte-Carlo HJ Reachability Scheme
Lekan Molu, Venkatraman Renganathan, Namhoon Cho

Abstract
Backward reachable tubes (BRTs), computed via viscous Hamilton-Jacobi (HJ) partial differential equations, provide principled safety certificates for learned controllers and planning algorithms in trustworthy machine learning. However, classical grid-based HJ solvers require O ⁡ ( M n ) O(M^{n}) memory footprint for M M grid points per n n state dimension. This renders them impractical for high-dimensional systems. We address this bottleneck with a local PDE linearization that enables a frozen-coefficient sampling scheme for the viscous HJ PDE: a generalized Cole-Hopf-type transformation reduces the nonlinear HJ equation to a sequence of linear heat equations whose solutions admit Gaussian heat-kernel representations. The value function and its spatial gradient are then recovered via roll-outs of Monte Carlo expectations on Gaussian densities, yielding a storage and grid-free algorithm that scales as N ⋅ n N\cdot n for N N samples. This decoupling of memory from dimensionality enables reachability analysis on problems where grid-based methods are simply impossible. We prove a finite-sample concentration bound O ( N − 1 / 2 ) O(N^{-1/2}) error and conditional linear convergence for the introduced Monte-Carlo Picard iterative scheme. Numerical validation on pursuit-evasion games demonstrates relative L rel 2 L^{2}_{\text{rel}} errors of 0.03 − 0.20 0.03-0.20 , with 14 − 26 14-26 second wall-clock times per 2D slice on a CPU. Crucially, the method scales with validation on up to (but not limited to) n = 45 n=45 -dimensional multi-agent games.

Central Contribution: Monte-Carlo Trajectory Optimization of Quasi-Linear BRTs

A
backward reachable tube
(BRT) is the set of initial states from which a controlled system is guaranteed to reach a target set within a given time horizon, for all adversarial inputs. Given system dynamics
\dot{\bm{x}}=f(t;\bm{x},\bm{u},\bm{w})

that solves the viscous HJI PDE (

). Classical grid-based solvers
(
23
;
28
)
discretize the state space on a grid with
M
points per dimension; the resulting memory cost is
O(M^{n})
, which grows exponentially in the state dimension
n

n=6
with
M=100
, this already requires
10^{12}
grid cells. The proposed method replaces the grid with
N
Monte Carlo samples of state space trajectories, reducing spatial memory to
O(N\cdot n)
.

The major bottleneck for realizing the solutions to the BRT of complex systems is computational: classical HJ solvers scale as
O(M^{n})
in memory, where
M
is the number of grid points per dimension and
n
is the state dimension. While GPU-accelerated implementations
(
27
;
28
)
reduce wall-clock time, they retain the same exponential memory footprint. Self-supervised, PINN-based approaches such as DeepReach
(
1
)
train a neural network to minimize the HJ PDE residual directly via a physics-informed loss, without requiring a reference grid solution. However, the method scales moderately in dimensions (reportedly 9D) and accuracy degrades in the limit of higher-dimensional data. We introduce a fundamentally different approach that replaces grid storage with a sampling scheme so that the memory cost is
O(N\cdot n)
and the algorithm is grid-free.

We consider first-order nonlinear scalar HJ PDEs of the form

\displaystyle\bm{v}_{t}+\bm{H}(t;\bm{x},D\bm{v})=0\text{ in }\Omega\times(0,T],\quad\bm{v}(0;\bm{x})=\bm{g}(0;\bm{x})\text{ on }\partial\Omega\times\{t=0\}

\displaystyle\sup_{t\in(0,T]}\sup_{\bm{x}\in\mathbb{R}^{n}}\left|\bm{v}(t;\bm{x})-\bm{v}^{\delta}(t;\bm{x})\right|\leq k\sqrt{\delta}

HJ Sign Convention

Throughout this paper we adopt the backward-reachability viscosity-solution convention:

\bm{v}_{t}+\bm{H}(t;\bm{x},D\bm{v})=0,

where the Hamiltonian is defined via the zero-sum differential game formulation (Appendix A.5):

\bm{H}(t;\bm{x},p)=\max_{\bm{u}}\min_{\bm{w}}\langle p,f(t;\bm{x},\bm{u},\bm{w})\rangle.

Negative signs appearing in the Hamiltonian expressions in

(
24

and the min-over-max structure of reachability propagation. This convention is standard in reachability literature
(
23

and is consistent with the viscosity solution.

2.1
Exact Reduction and Quasi-Linearization: Two Cases

Let us first distinguish for the interpretation of our contribution.

Exact case (
\bm{H}=\tfrac{1}{2}|p|^{2}

When the Hamiltonian is purely quadratic in the co-state, setting
\bm{c}=1/\delta
(a constant) and

Quasi-linearization.

For a general Hamiltonian
\bm{H}(t;\bm{x},p)
, define the spatially-varying coefficient,

\displaystyle\bm{c}(t;\bm{x})=\frac{2}{\delta}\cdot\bm{H}^{\delta}/|D\bm{v}^{\delta}|^{2},

(2)

where
\bm{H}^{\delta}:=\bm{H}(t;\bm{x},D\bm{v}^{\delta})

applied to (

(see
Appendix B
for the derivation). Our proposed algorithm treats this as a

: at iteration

\bm{c}^{(k)}
is

at the current iterate, the resulting linear heat equation is solved for

\bm{v}^{(k+1)}

effectively. There is no joint solve of
\bm{c}
with the unknown iterate; the apparent circularity in (

Weighted Importance Sampling of Reachable Sets

While we may not recover the exact value function system, the mean and variance of its derivatives can be evaluated with the kernel expectations of Lemma
2.2

2.3
. Previously, self-supervised physics-informed neural network (PINN) approaches such as DeepReach
(
1

train neural networks to minimize the HJ PDE residual directly without requiring external supervision or a reference grid solution. However, neural network-based approximation methods encounter inherent scaling limitations; DeepReach scales only to moderate dimensions (reported to 9D/10D in
(
1

Our sampling-based scheme addresses this bottleneck by decoupling the memory cost from dimensionality.

We propose a sequential importance sampling (IS) scheme for a high-dimensional
\bm{x}
. Consequently,
\bm{v}^{\delta}
can be devised for the target density
\mathbb{P}_{y\sim\mathcal{N}(\bm{x},\delta t)}
to induce a chain-like decomposition
\bm{v}^{\delta}:=(\bm{v}^{\delta}_{1},\cdots,\bm{v}^{\delta}_{d}),1\leq d\leq T
i.e. ,
\bm{v}^{\delta}(t;\bm{x})=\bm{v}^{\delta}(d_{1};\bm{x}_{1})\prod_{d=2}^{T}\bm{v}^{\delta}(d;\bm{x}_{d})|\bm{v}^{\delta}(d;\bm{x}_{[1:d-1]})

from which we can build an importance sampling scheme such as
q^{\delta}(t;\bm{x})=q_{1}^{\delta}(d_{1};\bm{x}_{1})\prod_{d=2}^{T}q_{d}^{\delta}(d;\bm{x}_{d})|q_{d}^{\delta}(d;\bm{x}_{[1:d-1]}).

4
Conclusion

We have presented a quasi-linearized, frozen-coefficient sampling scheme for the viscous Hamilton-Jacobi PDE arising in safety analysis of dynamical systems. By applying a generalized Cole-Hopf-type transformation — exact when
\bm{H}=\tfrac{1}{2}|p|^{2}
and iteratively approximated via Picard quasi-linearization for general Hamiltonians — the nonlinear HJ equation is reduced to a sequence of linear heat equations whose solutions are Gaussian heat-kernel expectations. The value function and its spatial gradient are recovered from these expectations via Monte Carlo sampling, yielding a storage-free, grid-free algorithm with memory cost
O(N\cdot n)
rather than the
O(M^{n})
cost of classical grid-based solvers.

Theorem
2.5
provides a finite-sample concentration bound for the frozen-coefficient Monte Carlo estimator, establishing a standard
O(N^{-1/2})
error rate under explicit boundedness conditions on the terminal cost. Theorem
2.10
establishes conditional linear convergence of the Picard fixed-point iteration under Lipschitz and nondegeneracy assumptions, with an explicit contraction constant and a posteriori error estimate. Neither result claims unconditional global convergence for arbitrary Hamiltonians.
Numerical experiments on three benchmark reachability problems i.e. a 3D rocket pursuit-evasion game, a 3D Dubins two-car game, and a double integrator plant confirm convergence with residuals of
0.14-0.22
.

The connection to safe reinforcement learning, policy certification, and model-based control with learned dynamics suggests several directions for future work. These include adaptive importance sampling to reduce variance in high dimensions, extension to systems with stochastic dynamics, and tighter integration with deep learning pipelines for scalable safety certification of learned policies.

Reachability analysis is one of many verification methods that allows us to reason about (control-affine) dynamical systems. The verification problem may consist in finding a

.
From a set of initial and unsafe state sets, the time-bounded safety verification problem is to determine if there is an initial state and a particular time within the bound that the solution to HJI PDE enters the unsafe set
.

Reachability could be analyzed in a

(i)

(ii)

backward

(iii)

(iv)

Backward reachability consists in avoiding an unsafe set of states under the worst-possible disturbance at all times; relying on nonanticipative control strategies. Backward reachable sets (BRS) and backward reachable tubes (BRTs) are popularly analyzed in a game of two vehicles with non-stochastic dynamics

\displaystyle\psi_{m}(s)\triangleq-\frac{1}{s}\log M_{m}(s),\qquad M_{m}(s)\triangleq\mathbb{E}_{\bm{\zeta}\sim\mathcal{N}(\bm{x}_{m},\delta(T-t)I_{n})}\left[\exp\left(-s\bm{g}(\bm{\zeta})\right)\right].

Then
(\Phi(c))_{m}=\psi_{m}(c_{m})
. Since

,

\displaystyle\frac{d}{ds}(\psi_{m}(s))=\frac{1}{s^{2}}\log M_{m}(s)-\frac{1}{s}\frac{M_{m}^{\prime}(s)}{M_{m}(s)}.

(B.29)

Differentiating under the expectation gives

\displaystyle\frac{d}{ds}(M_{m}(s))=\mathbb{E}_{\bm{\zeta}\sim\mathcal{N}(\bm{x}_{m},\delta(T-t)I_{n})}\left[-\bm{g}(\bm{\zeta})\exp\left(-s\bm{g}(\bm{\zeta})\right)\right].

(B.30)

Thus,

\displaystyle-\frac{M_{m}^{\prime}(s)}{M_{m}(s)}=\frac{\mathbb{E}\left[\bm{g}(\cdot)e^{-s\bm{g}(\cdot)}\right]}{\mathbb{E}\left[e^{-s\bm{g}(\cdot)}\right]},

(B.31)

which is a weighted expectation of
\bm{g}
; and possesses absolute value of at most
G
by assumption
1
. In addition,
|\bm{g}|\leq G
implies that

\displaystyle e^{-sG}\leq M_{m}(s)\leq e^{sG}.

(B.32)

We can therefore write
|\log M_{m}(s)|\leq sG
. Substituting these two bounds into the derivative formula yields

\displaystyle|\psi_{m}^{\prime}(s)|\leq\frac{1}{s^{2}}(sG)+\frac{1}{s}G=\frac{2G}{s}\leq\frac{2G}{c_{\min}}

(B.33)

for every
s\in[c_{\min},c_{\max}]
. By the mean-value theorem,

\displaystyle|\psi_{m}(c_{m})-\psi_{m}(\widetilde{c}_{m})|\leq\frac{2G}{c_{\min}}|c_{m}-\widetilde{c}_{m}|.

(B.34)

Taking the maximum over
m
, we must have

\displaystyle\|\Phi(c)-\Phi(\widetilde{c})\|_{\infty}\leq\frac{2G}{c_{\max}}\|c-\widetilde{c}\|_{\infty}.

(B.35)

Step 2: Lipschitz continuity of the coefficient-update map
\Gamma
.

Fix
m
and write
p\triangleq p_{m}(v)
,
q\triangleq p_{m}(w)
. Then

\displaystyle|(\Gamma(v))_{m}-(\Gamma(w))_{m}|=\frac{2}{\delta}\left|\frac{\bm{H}(t;\bm{x}_{m},p)}{|p|^{2}}-\frac{\bm{H}(t;\bm{x}_{m},q)}{|q|^{2}}\right|.

(B.36)

Add and subtract
\bm{H}(t;\bm{x}_{m},q)/|p|^{2}
to obtain

\displaystyle\left|\frac{\bm{H}(t;\bm{x}_{m},p)}{|p|^{2}}-\frac{\bm{H}(t;\bm{x}_{m},q)}{|q|^{2}}\right|

\displaystyle\leq\frac{|\bm{H}(t;\bm{x}_{m},p)-\bm{H}(t;\bm{x}_{m},q)|}{|p|^{2}}+|\bm{H}(t;\bm{x}_{m},q)|\left|\frac{1}{|p|^{2}}-\frac{1}{|q|^{2}}\right|.

(B.37)

By assumption (ii),
|p|,|q|\geq m_{0}
, so that
|p|^{2},|q|^{2}\geq m_{0}^{2}
. Using assumption (iii), the first term is bounded by

\displaystyle\frac{|\bm{H}(t;\bm{x}_{m},p)-\bm{H}(t;\bm{x}_{m},q)|}{|p|^{2}}\leq\frac{L_{H}}{m_{0}^{2}}|p-q|.

(B.38)

For the second term, note that

\displaystyle\left|\frac{1}{|p|^{2}}-\frac{1}{|q|^{2}}\right|=\frac{\bigl||q|^{2}-|p|^{2}\bigr|}{|p|^{2}|q|^{2}}\leq\frac{\bigl||q|-|p|\bigr|(|q|+|p|)}{m_{0}^{4}}\leq\frac{2P_{*}}{m_{0}^{4}}|p-q|,

(B.39)

where the final inequality uses
|p|,|q|\leq P_{*}
from assumption (ii). Using
|\bm{H}(t;\bm{x}_{m},q)|\leq H_{*}
from assumption (iii), we conclude that

\displaystyle\left|\frac{\bm{H}(t;\bm{x}_{m},p)}{|p|^{2}}-\frac{\bm{H}(t;\bm{x}_{m},q)}{|q|^{2}}\right|\leq\left(\frac{L_{H}}{m_{0}^{2}}+\frac{2H_{*}P_{*}}{m_{0}^{4}}\right)|p-q|.

(B.40)

Therefore

\displaystyle|(\Gamma(v))_{m}-(\Gamma(w))_{m}|\leq\frac{2}{\delta}\left(\frac{L_{H}}{m_{0}^{2}}+\frac{2H_{*}P_{*}}{m_{0}^{4}}\right)|p-q|.

(B.41)

Finally, by assumption (iv),

\displaystyle|p-q|\leq\|\mathcal{G}(v)-\mathcal{G}(w)\|_{\infty}\leq L_{D}\|v-w\|_{\infty}.

(B.42)

Taking the maximum over
m
yields

\displaystyle\|\Gamma(v)-\Gamma(w)\|_{\infty}\leq\frac{2L_{D}}{\delta}\left(\frac{L_{H}}{m_{0}^{2}}+\frac{2H_{*}P_{*}}{m_{0}^{4}}\right)\|v-w\|_{\infty}.

(B.43)

Step 3:
\Lambda=\Phi\circ\Gamma
is a contraction.

Combining (
B.35
) and (
B.43
), we obtain

\displaystyle\|\Lambda(v)-\Lambda(w)\|_{\infty}

\displaystyle=\|\Phi(\Gamma(v))-\Phi(\Gamma(w))\|_{\infty}\leq\frac{2G}{c_{\min}}\|\Gamma(v)-\Gamma(w)\|_{\infty},

(B.44)

\displaystyle\leq\frac{2G}{c_{\min}}\cdot\frac{2L_{D}}{\delta}\left(\frac{L_{H}}{m_{0}^{2}}+\frac{2H_{*}P_{*}}{m_{0}^{4}}\right)\|v-w\|_{\infty}=q\|v-w\|_{\infty}.

(B.45)

Assumption (v) states that
q<1
, hence
\Lambda
is a contraction on
\mathcal{A}
.

Step 4: Existence, uniqueness, and linear convergence.

Since
\mathcal{A}
is closed in the Banach space
(V,\|\cdot\|_{\infty})
and invariant under
\Lambda
, Banach’s fixed-point theorem applies. Therefore there exists a unique
v^{*}\in\mathcal{A}
such that
\Lambda(v^{*})=v^{*}
. Moreover, for every

, the sequence generated by
v^{(k+1)}=\Lambda(v^{(k)})
converges to
v^{*}
and satisfies

\displaystyle\|v^{(k+1)}-v^{*}\|_{\infty}\leq q\|v^{(k)}-v^{*}\|_{\infty}\leq q^{k+1}\|v^{(0)}-v^{*}\|_{\infty}.

(B.46)

This proves the first convergence statement.

Step 5: Convergence of the coefficients.

Applying (
B.43
) with
w=v^{*}
gives

\displaystyle\|\Gamma(v^{(k)})-\Gamma(v^{*})\|_{\infty}\leq\frac{2L_{D}}{\delta}\left(\frac{L_{H}}{m_{0}^{2}}+\frac{2H_{*}P_{*}}{m_{0}^{4}}\right)\|v^{(k)}-v^{*}\|_{\infty}.

(B.47)

Step 6: Residual decay.

Since
v^{(k+1)}=\Lambda(v^{(k)})
and
\Lambda
is a contraction,

\displaystyle\|v^{(k+1)}-v^{(k)}\|_{\infty}=\|\Lambda(v^{(k)})-\Lambda(v^{(k-1)})\|_{\infty}\leq q\|v^{(k)}-v^{(k-1)}\|_{\infty}.

(B.48)

Applying this recursively yields

\displaystyle\|v^{(k+1)}-v^{(k)}\|_{\infty}\leq q^{k}\|v^{(1)}-v^{(0)}\|_{\infty}.

(B.49)

Step 7: A posteriori error estimate.

Because

, we may write

\displaystyle v^{*}-v^{(k)}=\sum_{j=k}^{\infty}(v^{(j+1)}-v^{(j)}).

(B.50)

Taking sup norms and using the triangle inequality,

\displaystyle\|v^{*}-v^{(k)}\|_{\infty}

\displaystyle\leq\sum_{j=k}^{\infty}\|v^{(j+1)}-v^{(j)}\|_{\infty}\leq\sum_{j=k}^{\infty}q^{j-k}\|v^{(k+1)}-v^{(k)}\|_{\infty}

(B.51)

\displaystyle=\frac{1}{1-q}\|v^{(k+1)}-v^{(k)}\|_{\infty}.

(B.52)

Using once more that

, we conclude that

\displaystyle\|v^{(k)}-v^{*}\|_{\infty}\leq\frac{q}{1-q}\|v^{(k)}-v^{(k-1)}\|_{\infty}.

(B.53)

A fortiori, this completes the proof.

Rearranging by control terms:

\displaystyle\bm{H}

\displaystyle=-\max_{u_{e}\in[-1,1]}\min_{u_{p}\in[-1,1]}\left[p_{1}a\cos\theta+p_{2}a(1+\sin\theta)-p_{2}g+(p_{1}x+p_{3})u_{p}+(p_{2}x-p_{3})u_{e}\right].

(C.28)

Since the pursuer minimizes over
u_{p}
, it chooses
u_{p}=-\text{sign}(p_{1}x+p_{3})
to minimize the linear term. Similarly, the evader maximizes over
u_{e}
, choosing
u_{e}=\text{sign}(p_{2}x-p_{3})
. For bang-bang optimal controls, these become:

\displaystyle\min_{u_{p}}(p_{1}x+p_{3})u_{p}

\displaystyle=-|p_{1}x+p_{3}|,

(C.29)

\displaystyle\max_{u_{e}}(p_{2}x-p_{3})u_{e}

\displaystyle=|p_{2}x-p_{3}|.

(C.30)

Thus the simplified Hamiltonian becomes:

\displaystyle\bm{H}(t;\bm{x},p)

\displaystyle=-\left[ap_{1}\cos\theta+p_{2}(a+a\sin\theta-g)-|p_{1}x+p_{3}|-|p_{2}x-p_{3}|\right],

(C.31)

which, when substituted into the HJ PDE yields the simplified rockets HJI equation used in the numerical experiments (cf. Section
3.3
).
