Global Convergence of the Return Dynamics in the Class 𝒪 C \mathcal{O}_{C}
M. Barkatou, M. El Morsalani

Abstract
In previous work we introduced a return map generated by a geometric round-trip between the boundary of a convex core C C and the boundary of an admissible domain Ω \Omega belonging to the class 𝒪 C \mathcal{O}_{C} (see Definition 1.2). The associated transformation F : ∂ C → ∂ C F:\partial C\to\partial C defines a discrete dynamical system whose first-order expansion reveals a variable-step gradient descent structure for the thickness function d : ∂ C → ℝ + . d:\partial C\to\mathbb{R}_{+}. The purpose of the present paper is to analyze the global dynamical properties of this transformation. Under natural regularity and nondegeneracy assumptions on the thickness function, we prove that every trajectory of the return map converges to a critical point of d d . The proof combines the first-order expansion of the return map, a Lyapunov dissipation estimate for the energy V ⁡ ( c ) = 1 2 ​ d ​ ( c ) 2 , V(c)=\frac{1}{2}d(c)^{2}, and a compactness argument based on the isolation of the critical points. These results show that the geometry of the domain Ω \Omega induces a gradient-like dynamical system on ∂ C \partial C whose long-term behavior is completely organized by the critical points of the thickness landscape. In particular, the phase space decomposes into basins of attraction associated with these critical points, and nontrivial periodic orbits cannot occur.

Introduction

The principal contribution of the present article is a global convergence theorem for the return dynamics. Under natural regularity and nondegeneracy assumptions on the thickness function
d
, we prove that every trajectory of the iteration

c_{k+1}=F(c_{k})

converges to a critical point of
d
.

More precisely, assuming that
d
is sufficiently smooth, bounded away from zero, and has only nondegenerate critical points, the dynamics generated by the return map is globally organized by the critical set of the thickness function. In particular, the phase space
\partial C
decomposes into basins of attraction associated with these critical points, and no nontrivial periodic orbits can occur.

The proof combines three ingredients. First, the first-order expansion of the return map obtained in
[
2
]
reveals an approximate gradient descent structure. Second, we construct a Lyapunov function whose dissipation along trajectories controls the long-term behavior of the iteration. Finally, compactness of
\partial C
together with the isolation of critical points yields the global convergence result.

In this way, the geometric round-trip mechanism between
\partial C
and
\partial\Omega
generates a gradientlike dynamical system on
\partial C
whose asymptotic behavior is completely governed by the thickness landscape.

The class
\mathcal{O}_{C}
.

The geometric framework considered in this paper relies on a class of admissible domains introduced in
[

]
, which we recall for completeness.

Definition 1.1

(C-geometric normal property)
.

Let
C
be a compact convex set. An open set
\Omega
containing
C
satisfies the
C
-geometric normal property if for almost every
x\in\partial\Omega
where the inward normal
n(x)
exists, the half-line

\{x+tn(x):t\geq 0\}

intersects
C
.

Definition 1.2

(Class
\mathcal{O}_{C}
)
.

The class
\mathcal{O}_{C}
consists of open sets
\Omega\subset\mathbb{R}^{N}
such that:

1.

\operatorname{int}(C)\subset\Omega
,

2.

\partial\Omega
is Lipschitz outside
C
,

3.

for any

there exists an outward normal ray
\Delta_{c}
such that
\Delta_{c}\cap\Omega
is connected,

4.

\Omega

C

These conditions ensure that the geometric round-trip between
\partial C
and
\partial\Omega
is well-defined. In particular, the geometric normal property ensures that the reciprocal map is well-defined, while the connectivity condition guarantees that the radial construction does not produce ambiguities.

Remark 1.3
.

The Lipschitz regularity assumption ensures the existence of inward normals almost everywhere on
\partial\Omega

2
Geometric Framework

In this section we briefly recall the geometric setting introduced in
[
2
]
. Only the elements needed for the dynamical analysis developed in the present paper are summarized.

2.1
Convex Core and Admissible Domains

Let
C\subset\mathbb{R}^{N}
be a compact convex set with non-empty interior and boundary
\partial C
of class
C^{2}
. We denote by

\nu(c)

(2.1)

the outward unit normal vector to
\partial C
at
c\in\partial C
.

Let
\Omega\subset\mathbb{R}^{N}
be an open set containing
C
. We consider domains
\Omega\in\mathcal{O}_{C}
as introduced in the Introduction
[
1
]
: for almost every point
x\in\partial\Omega
where the inward unit normal
n(x)
exists, the half-line

D(x,n(x))=\{x+tn(x):t\geq 0\}

(2.2)

intersects the convex set
C
.

This condition guarantees that inward normal rays from the boundary
\partial\Omega
reach the convex core
C
.

We refer to domains
\Omega\in\mathcal{O}_{C}
as admissible domains.

2.2
Thickness Function

The geometry of the region between
\partial C
and
\partial\Omega
is encoded by the thickness function

d:\partial C\to\mathbb{R}_{+},

(2.3)

defined by

d(c)=\sup\{r\geq 0:c+r\nu(c)\in\Omega\}.

(2.4)

Geometrically,
d(c)
measures the distance from the boundary
\partial C
to
\partial\Omega
along the outward normal direction.

2.3
Radial Map

The thickness function provides a parametrization of the outer boundary through the radial map

\Phi:\partial C\to\partial\Omega,

(2.5)

defined by

\Phi(c)=c+d(c)\nu(c).

(2.6)

2.4
Reciprocal Map

Let
x\in\partial\Omega
and denote by
n(x)
the inward unit normal to
\partial\Omega
at
x
. Let
t(x)
be the smallest non-negative number such that

x+t(x)n(x)\in C.

(2.7)

The reciprocal map is then defined by

\pi:\partial\Omega\setminus C\to\partial C,\qquad\pi(x)=x+t(x)n(x).

(2.8)

2.5
Return Map

The composition of the radial and reciprocal maps defines the return map

F:\partial C\to\partial C,\qquad F=\pi\circ\Phi.

(2.9)

Starting from a point
c\in\partial C
, the map first moves to the outer boundary
\partial\Omega
along the outward normal direction via
\Phi
, and then returns to
\partial C
along the inward normal to
\partial\Omega
via
\pi
. The resulting transformation generates a discrete dynamical system

c_{k+1}=F(c_{k}).

(2.10)

on the hypersurface
\partial C
. The purpose of the present paper is to analyze the global asymptotic behavior of this dynamical system.

3
First-Order Structure of the Return Map

The dynamical interpretation of the return map originates from the first-order expansion derived in
[
2
]
. For completeness we briefly recall this result.

3.1
First-Order Expansion

Let the thickness function

d:\partial C\to\mathbb{R}_{+}

(3.1)

be of class
C^{2}
. The return map

F:\partial C\to\partial C

(3.2)

defined by
F=\pi\circ\Phi
admits the expansion

F(c)=c-2d(c)\nabla_{\partial C}d(c)+R(c),

(3.3)

where the remainder term satisfies

\|R(c)\|\leq K\,d(c)\|\nabla_{\partial C}d(c)\|^{2}.

(3.4)

Equation (
3.3
) shows that the leading displacement of a point under the return map is proportional to the negative gradient of the thickness function.

3.2
Gradient Descent Interpretation

The expansion (
3.3
) reveals that the return dynamics behaves, to leading order, like a gradient descent iteration on the hypersurface
\partial C
. Indeed, neglecting the higher-order remainder term, the iteration

c_{k+1}=F(c_{k})

(3.5)

formally reduces to

c_{k+1}\approx c_{k}-2d(c_{k})\nabla_{\partial C}d(c_{k}).

(3.6)

Thus the return map may be interpreted as a variable-step gradient descent for the thickness function, with step size

\alpha(c)=2d(c).

(3.7)

3.3
Dynamical Consequences

This gradient structure immediately suggests the existence of a natural Lyapunov function for the dynamics. Define

V(c)=\frac{1}{2}d(c)^{2}.

(3.8)

As will be shown in the next section, the function
V
decreases along trajectories of the return map. This observation provides the key tool for analyzing the global asymptotic behavior of the iteration.

4
Lyapunov Structure of the Return Dynamics

The first-order expansion of the return map suggests that the dynamics behaves as a gradient descent for the thickness function. In this section we formalize this idea by introducing a Lyapunov function for the return dynamics.

4.1
Energy Function

Let
d:\partial C\to\mathbb{R}_{+}
be the thickness function introduced in Section 2, assumed of class
C^{2}
. We define the energy functional

V:\partial C\to\mathbb{R}_{+},\qquad V(c)=\frac{1}{2}d(c)^{2}.

(4.1)

This quantity measures the squared thickness between the two boundaries along the outward normal direction.

4.2
Energy Variation Along the Dynamics

Let
(c_{k})
be a trajectory of the return map

c_{k+1}=F(c_{k}).

(4.2)

Using the first-order expansion (
3.3
), we obtain the displacement

c_{k+1}-c_{k}=-2d(c_{k})\nabla_{\partial C}d(c_{k})+R(c_{k}).

(4.3)

A Taylor expansion of the thickness function gives

\displaystyle d(c_{k+1})

\displaystyle=d(c_{k})+\langle\nabla_{\partial C}d(c_{k}),c_{k+1}-c_{k}\rangle

(4.4)

\displaystyle+\frac{1}{2}\langle\nabla^{2}_{\partial C}d(\xi_{k})(c_{k+1}-c_{k}),c_{k+1}-c_{k}\rangle,

where
\xi_{k}
lies on the geodesic segment between
c_{k}
and
c_{k+1}
.

Substituting (
4.3
) into (
4.4
) and using the remainder estimate (
3.4
), we obtain, after squaring and collecting terms,

V(c_{k+1})-V(c_{k})=-2d(c_{k})^{2}\|\nabla_{\partial C}d(c_{k})\|^{2}+\mathcal{O}\!\left(d(c_{k})^{2}\|\nabla_{\partial C}d(c_{k})\|^{3}\right).

(4.5)

More precisely, under the assumption that
\nabla_{\partial C}d
is Lipschitz and that the curvature of
\partial C
is bounded, one obtains the following uniform estimate.

Proposition 4.1
.

There exist constants
a,b>0
depending only on
d_{\min}
,
d_{\max}
and the Lipschitz bound of
\nabla_{\partial C}d
such that for all
c\in\partial C
,

V(F(c))-V(c)\leq-a\|\nabla_{\partial C}d(c)\|^{2}+b\|\nabla_{\partial C}d(c)\|^{4}.

(4.6)

Thus the Lyapunov function decreases whenever the gradient of the thickness function is non-zero, provided the gradient is sufficiently small.

4.3
Energy Dissipation

The inequality (
4.6
) implies that the Lyapunov function
V(c_{k})
is nonincreasing to leading order, and the energy cannot increase when the gradient is nonzero.

Since
\partial C
is compact, the trajectory
(c_{k})
admits accumulation points. Moreover, any accumulation point must satisfy

\nabla_{\partial C}d(c)=0.

(4.7)

5
Global Convergence of the Return Dynamics

In this section we establish a convergence theorem for the return dynamics. The result shows that, under suitable regularity and nondegeneracy assumptions, the iteration generated by the return map converges to a critical point of the thickness function.

5.1
Assumptions

We assume throughout this section that the thickness function

d:\partial C\to\mathbb{R}_{+}

(5.1)

satisfies the following properties.

1.

d\in C^{2}(\partial C)
.

2.

There exist constants
d_{\min},d_{\max}>0
such that

0<d_{\min}\leq d(c)\leq d_{\max}\quad\text{for all }c\in\partial C.

(5.2)

3.

The tangential gradient
\nabla_{\partial C}d
is Lipschitz.

4.

The critical points of
d
are nondegenerate (Morse condition)
[
3
]
.

5.

The gradient of the thickness function is uniformly small:

\|\nabla_{\partial C}d\|_{L^{\infty}(\partial C)}\leq\varepsilon_{0},

(5.3)

for
\varepsilon_{0}>0
sufficiently small (to be chosen below).

Remark 5.1
.

The small-gradient condition is not an independent assumption on the domain
\Omega
; it is automatically satisfied, for instance, when
\Omega
is sufficiently close to
C
in the
C^{2}
topology. Indeed, if the Hausdorff distance between
\partial\Omega
and
\partial C
is small and the normals are close, then
d
is uniformly close to a constant and its gradient is small.

5.2
Lyapunov Estimate

From Proposition
4.1
we have

V(F(c))-V(c)\leq-a\|\nabla_{\partial C}d(c)\|^{2}+b\|\nabla_{\partial C}d(c)\|^{4},

(5.4)

with constants
a,b>0
.

5.3
Uniform Descent

Under the small-gradient assumption (
5.3
), we have

b\|\nabla_{\partial C}d(c)\|^{4}\leq b\varepsilon_{0}^{2}\|\nabla_{\partial C}d(c)\|^{2}.

(5.5)

Choosing
\varepsilon_{0}
sufficiently small so that
b\varepsilon_{0}^{2}<a
, we obtain

V(F(c))-V(c)\leq-\eta\|\nabla_{\partial C}d(c)\|^{2},

(5.6)

for some constant
\eta>0
and for all
c\in\partial C
.

5.4
Summability of the Gradient

Let
(c_{k})
be a trajectory of the return map
c_{k+1}=F(c_{k})
. Summing (
5.6
) over
k
yields

\sum_{k=0}^{\infty}\|\nabla_{\partial C}d(c_{k})\|^{2}<\infty.

(5.7)

Therefore

\|\nabla_{\partial C}d(c_{k})\|\to 0.

(5.8)

5.5
Descent Away from Critical Points

Let

\mathrm{Crit}(d)=\{c\in\partial C:\nabla_{\partial C}d(c)=0\}.

(5.9)

Since
d
is Morse on the compact manifold
\partial C
, this set is finite
[
3
]
.

Let
U
be an open neighborhood of
\mathrm{Crit}(d)
. Because
|\nabla_{\partial C}d|
is continuous and nonzero on the compact set
\partial C\setminus U
, there exists
\varepsilon_{U}>0
such that

\|\nabla_{\partial C}d(c)\|\geq\varepsilon_{U}\quad\text{for all }c\in\partial C\setminus U.

(5.10)

Using (
5.6
), we obtain a uniform decrease: there exists
\gamma_{U}>0
such that

V(F(c))\leq V(c)-\gamma_{U}\quad\text{for all }c\in\partial C\setminus U.

(5.11)

5.6
Eventual Trapping Near the Critical Set

Since
V
is bounded below and strictly decreases by at least
\gamma_{U}
whenever the trajectory lies in
\partial C\setminus U
, the sequence
(c_{k})
can visit
\partial C\setminus U
only finitely many times. Therefore every trajectory eventually enters the neighborhood
U
and remains in
U
for all sufficiently large
k
.

5.7
Limit Points

Since
\partial C
is compact, the sequence
(c_{k})
admits accumulation points. Let
c^{*}
be such a point. By continuity of
\nabla_{\partial C}d
and (
5.8
), we obtain

\nabla_{\partial C}d(c^{*})=0.

(5.12)

Thus every accumulation point is a critical point of the thickness function.

5.8
Convergence

We now prove that the entire sequence converges.

Theorem 5.2

(Global convergence)
.

Under the assumptions stated above, every trajectory of the return map

c_{k+1}=F(c_{k})

(5.13)

converges to a critical point of the thickness function
d
.

Proof.

Let
c^{(1)},\ldots,c^{(m)}
denote the finitely many critical points of
d
. Choose pairwise disjoint neighborhoods
U_{1},\ldots,U_{m}
of these points and set

U=\bigcup_{i=1}^{m}U_{i}.

(5.14)

From the trapping property established above, the trajectory eventually remains in
U
.

Suppose that the trajectory visits two distinct neighborhoods
U_{i}
and
U_{j}
infinitely many times. Then it must cross the complement
\partial C\setminus U
infinitely often. However, each such crossing produces a decrease of at least
\gamma_{U}
in the Lyapunov function by (
5.11
). Since
V
is bounded below, this is impossible.

Therefore the trajectory eventually remains in a single neighborhood
U_{i^{*}}
. Because this neighborhood contains exactly one critical point, the sequence
(c_{k})
converges to that point.
∎

6
Stability and Basins of Attraction

In the previous section we established that every trajectory of the return dynamics converges to a critical point of the thickness function. In this section we analyze the local behavior of the dynamics near such points and describe the structure of the associated basins of attraction.

6.1
Fixed Points of the Return Map

Recall that the return map is defined by
F=\pi\circ\Phi
. A point
c^{*}\in\partial C
is a fixed point of the dynamics if
F(c^{*})=c^{*}
.

Proposition 6.1
.

A point
c^{*}\in\partial C
is a fixed point of the return map if and only if

\nabla_{\partial C}d(c^{*})=0.

(6.1)

Thus the equilibrium configurations of the dynamical system coincide with the critical points of the thickness function.

6.2
Linearization of the Dynamics

We now study the behavior of the return map near a critical point. Let
c^{*}
be a critical point of
d
, i.e.,

\nabla_{\partial C}d(c^{*})=0.

(6.2)

Consider a small perturbation

c=c^{*}+\xi,\qquad\xi\in T_{c^{*}}\partial C.

(6.3)

Expanding the gradient of
d
gives

\nabla_{\partial C}d(c)=\nabla_{\partial C}^{2}d(c^{*})\,\xi+o(|\xi|).

(6.4)

Moreover, since (
6.2
) holds, the thickness function satisfies

d(c)=d(c^{*})+o(|\xi|).

(6.5)

Using the first-order expansion (
3.3
), we obtain

F(c)=c-2d(c)\nabla_{\partial C}d(c)+R(c).

(6.6)

Substituting (
6.4
) and (
6.5
) into (
6.6
), we obtain

F(c)=c-2d(c^{*})\,\nabla_{\partial C}^{2}d(c^{*})\,\xi+o(|\xi|).

(6.7)

Therefore,

F(c)-c^{*}=\bigl(I-2d(c^{*})\,\nabla_{\partial C}^{2}d(c^{*})\bigr)\xi+o(|\xi|).

(6.8)

Hence the Jacobian matrix of the return map at
c^{*}
is

DF(c^{*})=I-2d(c^{*})\,\nabla_{\partial C}^{2}d(c^{*}).

(6.9)

6.3
Stability Classification

Let
\lambda_{1},\ldots,\lambda_{N-1}
be the eigenvalues of the tangential Hessian
\nabla_{\partial C}^{2}d(c^{*})
. The eigenvalues of the linearized return map are therefore

\mu_{i}=1-2d(c^{*})\lambda_{i}.

(6.10)

Theorem 6.2
.

Let
c^{*}
be a critical point of the thickness function.

1.

If
|\mu_{i}|<1
for all
i
, then
c^{*}
is a locally attracting fixed point.

2.

If
|\mu_{i}|>1
for all
i
, then
c^{*}
is a repelling fixed point.

3.

If the eigenvalues
\mu_{i}
lie on both sides of the unit circle, then
c^{*}
is a saddle point.

The classification follows from the linearization (
6.9
) and standard results in dynamical systems. For hyperbolic fixed points, the stable manifold theorem
[
5
]
guarantees the existence of local stable and unstable manifolds.

6.4
Basins of Attraction

Let
c^{*}
be a critical point of the thickness function. If
c^{*}
is attracting, the linearization satisfies

\rho(DF(c^{*}))<1,

(6.11)

where
\rho
denotes the spectral radius. Since the Hessian of
d
at a nondegenerate critical point is invertible, the linearization has no eigenvalue equal to
1
, and the fixed point is isolated.

Moreover, if
|\mu_{i}|\neq 1
for all
i
, the fixed point is hyperbolic and the stable manifold theorem
[
5
]
applies. In that case there exists a neighborhood
U\subset\partial C
such that every trajectory starting in
U
converges to
c^{*}
.

The basin of attraction of
c^{*}
is defined as

\mathcal{B}(c^{*})=\{c_{0}\in\partial C:\lim_{k\to\infty}c_{k}=c^{*}\}.

(6.12)

Proposition 6.3
.

The basins of attraction associated with the critical points of
d
form a partition of the hypersurface
\partial C
.

Proof.

By Theorem
5.2
, every trajectory converges to a critical point. Hence for every initial condition
c_{0}
there exists a critical point
c^{*}
such that
c_{0}\in\mathcal{B}(c^{*})
. Thus

\partial C=\bigcup_{c^{*}\in\mathrm{Crit}(d)}\mathcal{B}(c^{*}).

If a point belonged to two distinct basins, the trajectory would converge to two different limits, which is impossible. Hence the basins are disjoint.
∎

Thus the return dynamics induces a decomposition of
\partial C
into basins of attraction associated with the critical points of the thickness function.

7
Absence of Periodic Orbits

The global convergence property of the return dynamics imposes strong restrictions on the possible long-term behavior of the iteration. Such behavior is typical of gradient-like dynamical systems
[
4
]
.

Theorem 7.1
.

Under the assumptions of Theorem
5.2
, the return map admits no nontrivial periodic orbits.

Proof.

Let
(c_{k})
be a periodic orbit of period
p
, i.e.,

c_{k+p}=c_{k}\quad\text{for all }k.

(7.1)

By the Lyapunov estimate (
5.6
), we have

V(c_{k+1})-V(c_{k})\leq-\eta\|\nabla_{\partial C}d(c_{k})\|^{2}.

(7.2)

Summing over one period and using (
7.1
), we obtain

0=V(c_{k+p})-V(c_{k})\leq-\eta\sum_{j=0}^{p-1}\|\nabla_{\partial C}d(c_{k+j})\|^{2}.

(7.3)

Since
\eta>0
, it follows that

\|\nabla_{\partial C}d(c_{k+j})\|=0\quad\text{for all }j=0,\dots,p-1.

(7.4)

Thus every point of the orbit is a critical point of
d
. By Proposition
6.1
, each such point is a fixed point of the return map. Therefore

c_{k+1}=c_{k}\quad\text{for all }k,

and the orbit is constant.

Hence every periodic orbit reduces to a fixed point.
∎

8
Gradient-Like Structure of the Return Map

In this section we summarize the dynamical consequences of the previous results and show that the return map defines a gradient-like discrete dynamical system on the hypersurface
\partial C

[
4
,
5
]
.

Theorem 8.1

(Gradient-like structure)
.

Assume that the thickness function

d:\partial C\to\mathbb{R}_{+}

(8.1)

satisfies the assumptions of Theorem
5.2
. Then the return map

F:\partial C\to\partial C

(8.2)

defines a gradient-like discrete dynamical system on
\partial C
with Lyapunov function

V(c)=\frac{1}{2}d(c)^{2}.

(8.3)

More precisely:

1.

The set of fixed points of
F
coincides with the critical set of
d
.

2.

For every critical point
c^{*}
of
d
, one has
F(c^{*})=c^{*}
.

3.

For every trajectory
(c_{k})
generated by

c_{k+1}=F(c_{k}),

(8.4)

the sequence
(c_{k})
converges to a critical point of
d
.

4.

The return map admits no nontrivial periodic orbits.

5.

The phase space
\partial C
decomposes into basins of attraction associated with the critical points of
d
.

Proof.

We verify the defining properties of a gradient-like dynamical system.

First, by the Lyapunov estimate (
5.6
), the function
V
satisfies

V(F(c))\leq V(c),

with strict inequality whenever
\nabla_{\partial C}d(c)\neq 0
. Thus
V
is a strict Lyapunov function.

Item (1) follows from Proposition
6.1
, and item (2) is immediate.

Item (3) is precisely Theorem
5.2
.

Item (4) follows from Theorem
7.1
.

Finally, item (5) follows from Proposition
6.3
.
∎

9
Geometry-Dynamics Correspondence

The results obtained in the previous sections reveal a precise relationship between the geometry of the domain
\Omega
and the dynamical system generated by the return map on the hypersurface
\partial C
.

9.1
The Thickness Landscape

The geometry of the region between the convex core
C
and the outer boundary
\partial\Omega
is encoded by the thickness function

d:\partial C\to\mathbb{R}_{+}.

(9.1)

This function defines a scalar landscape on the manifold
\partial C
. The gradient
\nabla_{\partial C}d
describes the directions along which the thickness increases most rapidly, while the critical points

\nabla_{\partial C}d(c)=0

(9.2)

correspond to locations where the thickness is locally extremal.

9.2
Geometric Origin of the Dynamics

The return map arises from the geometric round-trip

\partial C\xrightarrow{\Phi}\partial\Omega\xrightarrow{\pi}\partial C.

(9.3)

Starting from a point
c\in\partial C
, the radial map
\Phi
moves along the outward normal direction until reaching the boundary
\partial\Omega
. The reciprocal map
\pi
then follows the inward normal of
\partial\Omega
until returning to the convex core.

Although the resulting transformation acts entirely on
\partial C
, its generator lies in the surrounding geometry of the domain
\Omega
. The dynamics on
\partial C
is therefore induced by the geometry of the region between the two boundaries.

9.3
Gradient Structure

The first-order expansion (
3.3
) of the return map shows that

F(c)=c-2d(c)\nabla_{\partial C}d(c)+R(c),

(9.4)

where the remainder term is of higher order in
\|\nabla_{\partial C}d(c)\|
.

Thus the leading behavior of the dynamics is governed by the negative gradient of the thickness function. The return dynamics therefore acts as a variable-step gradient descent whose step size is proportional to the local thickness
d(c)
on the manifold
\partial C
.

Moreover, the Lyapunov estimate (
5.6
) implies that the energy

V(c)=\frac{1}{2}d(c)^{2}

(9.5)

decreases along trajectories, confirming that the dynamics is gradient-like.

9.4
Geometric Organization of the Dynamics

The global convergence result (Theorem
5.2
) shows that, under suitable regularity and nondegeneracy assumptions, every trajectory converges to a critical point of the thickness function.

The stability analysis (Theorem
6.2
) further shows that the nature of each equilibrium is determined by the Hessian of
d
at the corresponding point. In particular:

•

local minima of
d
correspond to attracting configurations,

•

saddle points generate unstable directions,

•

local maxima correspond to repelling configurations.

In this way, the geometry of the domain
\Omega
organizes the phase space
\partial C
through the structure of the thickness landscape. The asymptotic behavior of the return dynamics is therefore fully determined by the geometric properties of the region between
\partial C
and
\partial\Omega
.

9.5
Illustrative Example

To illustrate that the hypotheses are nonempty, consider a simple setting where
C
is the unit sphere in
\mathbb{R}^{3}
and
\Omega
is a slightly deformed sphere given in radial coordinates by

\Omega=\{r\omega:\omega\in S^{2},\;0\leq r\leq 1+\varepsilon f(\omega)\},

(9.6)

with
\varepsilon>0
sufficiently small and
f:S^{2}\to\mathbb{R}
a smooth Morse function with nondegenerate critical points
[
3
]
.

In this setting, the thickness function satisfies

d(\omega)=\varepsilon f(\omega)+\mathcal{O}(\varepsilon^{2}),

(9.7)

uniformly on
S^{2}
. In particular,

\nabla_{\partial C}d(\omega)=\varepsilon\nabla_{S^{2}}f(\omega)+\mathcal{O}(\varepsilon^{2}),

(9.8)

so that the gradient of
d
is of order
\varepsilon
. Therefore the small-gradient condition (
5.3
) is satisfied for sufficiently small
\varepsilon
.

Moreover, the critical points of
d
coincide with those of
f
, and the nondegeneracy of
f
implies that
d
satisfies the Morse condition.

By choosing
f
with a single nondegenerate minimum (for instance, a localized bump), the thickness function admits a unique global minimizer. In this case, Theorem
5.2
implies that every trajectory converges to this point, yielding a global attractor.

Furthermore, the return map
F
is a small perturbation of the identity, with leading behavior governed by the gradient structure (
3.3
). This example shows that the hypotheses of the convergence theorem are realizable and that the dynamics indeed drives the system toward the thinnest region of the shell.

9.6
Perspectives

The geometric mechanism uncovered here suggests several directions for further investigation.

•

The classification of dynamical systems generated by domains in the class
\mathcal{O}_{C}

[
1
]
.

•

The study of inverse problems relating the geometry of
\Omega
to the structure of the induced return map.

•

Extensions of the round-trip construction to other geometric settings where boundary interactions generate hidden dynamical systems.

These directions indicate that the interaction between geometry and induced dynamics provides a natural framework for analyzing hidden geometric transformations through their associated dynamical systems.
