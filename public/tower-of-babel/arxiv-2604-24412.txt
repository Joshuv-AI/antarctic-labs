Note on polychromatic coloring of hereditary hypergraph families II
Dömötör Pálvölgyi

Abstract
We extend a recent construction concerning polychromatic colorings of hereditary hypergraph families. For every integer h ≥ 4 h\geq 4 we construct a ( 2 ​ h − 1 ) (2h-1) -uniform hypergraph which has no polychromatic 3 3 -coloring, but all of whose h h -heavy restricted subhypergraphs are 2 2 -colorable. Together with the previously known case h = 3 h=3 , this gives examples with uniformity 2 ​ h − 1 2h-1 for every h ≥ 3 h\geq 3 . The construction is based on complements of suitable h h -uniform hypergraphs on 3 ​ h − 1 3h-1 vertices. For h ≥ 9 h\geq 9 we prove existence by a simple probabilistic argument; the remaining cases 4 ≤ h ≤ 8 4\leq h\leq 8 are certified by a short exhaustive computer check, whose fully reproducible description and source code are included in the appendix.

1
A complement construction

The construction is most naturally described through complements.
Fix an integer
h\geq 2
and put

n=3h-1.

Let
V
be an
n
-element set.
We shall choose a family
\mbox{$\mathcal{K}$}\subset{V\choose h}
.
The sets in
\mathcal{K}
will be the missing
h
-sets of an auxiliary hypergraph. Define

\mbox{$\mathcal{G}$}={V\choose h}\setminus\mbox{$\mathcal{K}$},

and then define a
(2h-1)
-uniform hypergraph
\mathcal{H}
by

E(\mbox{$\mathcal{H}$})=\{V\setminus B:B\in\mbox{$\mathcal{G}$}\}.

Thus the edges of
\mathcal{H}
are the complements of the edges of
\mathcal{G}
.

We need three properties of
\mathcal{K}
.

(K1)

For every
A\in{V\choose h-1}
, not all
h
-sets of the form
A\cup\{v\}
,
v\in V\setminus A
, belong to
\mathcal{K}
. Equivalently, among the
2h
extensions of
A
to an
h
-set, at least one is not in
\mathcal{K}
.

(K2)

For every
X\in{V\choose 2h}
, there is an
h
-set
R\subset X
such that

R\in\mbox{$\mathcal{K}$}\quad\hbox{and}\quad X\setminus R\in\mbox{$\mathcal{K}$}.

(K3)

For every
Y\in{V\choose h}
, there is a set
U\subset V\setminus Y
,
|U|=h-1
, such that

U\cup\{y\}\in\mbox{$\mathcal{K}$}\qquad\hbox{for every }y\in Y.

Lemma 3
.

If
\mbox{$\mathcal{K}$}\subset{V\choose h}
satisfies
(K1)
,
(K2)
, and
(K3)
, then the hypergraph
\mathcal{H}
defined above has no polychromatic
3
-coloring, but all of its
h
-heavy restricted subhypergraphs are
2
-colorable.

Proof.

First we show that
\mathcal{H}
has no polychromatic
3
-coloring.
Consider any
3
-coloring of
V
.
One color class
S
has size at most

\left\lfloor{3h-1\over 3}\right\rfloor=h-1.

Extend
S
, if necessary, to an
(h-1)
-set
A
.
By (K1), some set
A\cup\{v\}
with
v\in V\setminus A
does not belong to
\mathcal{K}
.
Hence

B=A\cup\{v\}\in\mbox{$\mathcal{G}$}.

The corresponding edge
V\setminus B
of
\mathcal{H}
misses the color class
S
.
Thus the coloring is not polychromatic.

It remains to prove that every
h
-heavy trace of
\mathcal{H}
is
2
-colorable.
Since every subhypergraph of a
2
-colorable hypergraph is
2
-colorable, it is enough to color the
h
-heavy part of every trace
\mbox{$\mathcal{H}$}[X]
.

Let
X\subset V
.
We give a red-blue coloring of
X
with no monochromatic trace edge of size at least
h
.

If
|X|\leq 2h-2
, color

as evenly as possible.
Then both color classes have size at most

, so no monochromatic

-heavy trace can occur.

Suppose next that
|X|=2h-1
.
Let

, so
|Y|=h
.
By (K3), there is a set
U\subset X

|U|=h-1
, such that

U\cup\{y\}\in\mbox{$\mathcal{K}$}\qquad\hbox{for every }y\in Y.

Color
U

The blue class has size

, so it contains no monochromatic
h
-heavy trace.
If there were a red monochromatic trace of size at least
h
, then, since the red class has size exactly

, there would be some
B\in\mbox{$\mathcal{G}$}
such that

X\setminus B=X\setminus U.

Equivalently,

B\cap X=U.

As
B
has size

and
U
has size

, this means

for some

, contradicting the choice of

\mathcal{K}
.

Now suppose that
|X|=2h
.
By (K2), write
X=R\sqcup S
with

|R|=|S|=h,\qquad R,S\in\mbox{$\mathcal{K}$}.

Color
R

S

If there were a red monochromatic trace of size at least
h
, then it would have to be all of

, and hence for some

we would have

X\setminus B=R.

Thus

.
Since
|B|=|S|=h
, this forces
B=S
, contradicting
S\in\mbox{$\mathcal{K}$}
and
B\in\mbox{$\mathcal{G}$}
.
The blue case is symmetric.

Finally suppose that
|X|\geq 2h+1
.
Choose any
2h
-subset
X_{0}\subset X
.
By (K2), there is an
h
-set
R\subset X_{0}
with
R\in\mbox{$\mathcal{K}$}
.
Color
R

X\setminus R

A red monochromatic trace of size at least
h
would have to be exactly
R
.
This would imply
X\setminus R\subset B
for some
B\in\mbox{$\mathcal{G}$}
, impossible because

|X\setminus R|\geq h+1\quad\hbox{while}\quad|B|=h.

A blue monochromatic trace would imply
R\subset B
for some
B\in\mbox{$\mathcal{G}$}
.
Since
|R|=|B|=h
, this would force

, contradicting

.
This completes the proof.
∎

2
The random construction

We now prove that suitable families
\mathcal{K}
exist for all
h\geq 9
.

Choose every
h
-subset of
V
, independently, to belong to
\mathcal{K}
with probability
q
.
We estimate the probability that one of (K1), (K2), (K3) fails.

For a fixed
(h-1)
-set
A
, the probability that all
2h
extensions
A\cup\{v\}
belong to
\mathcal{K}
is
q^{2h}
.
Thus the expected number of violations of (K1) is

{3h-1\choose h-1}q^{2h}.

For a fixed
2h
-set
X
, the complementary pairs

R,\ X\setminus R\qquad(R\in{X\choose h})

partition the family
{X\choose h}
into
\frac{1}{2}{2h\choose h}
pairs.
The events that a given complementary pair has both members in
\mathcal{K}
are therefore mutually independent, since every
h
-set of
X
appears in exactly one pair.
Hence the probability that no complementary pair has both members in
\mathcal{K}
is

(1-q^{2})^{\frac{1}{2}{2h\choose h}}.

Thus the expected number of violations of (K2) is at most

{3h-1\choose 2h}(1-q^{2})^{\frac{1}{2}{2h\choose h}}.

Finally fix
Y\in{V\choose h}
.
For a fixed
U\subset V\setminus Y

|U|=h-1

U\cup\{y\}\in\mbox{$\mathcal{K}$}\qquad\hbox{for all }y\in Y

has probability
q^{h}
.
For different choices of
U
, these events involve disjoint

-sets: an

-set with exactly one point in
Y
determines both its unique point of
Y
and its

-set outside
Y
.
Hence the events are independent.
There are
{2h-1\choose h-1}
choices for
U
.
Therefore the probability that

violates (K3) is

(1-q^{h})^{{2h-1\choose h-1}}.

The expected number of violations of (K3) is

{3h-1\choose h}(1-q^{h})^{{2h-1\choose h-1}}.

Consequently, if

\displaystyle\Phi_{h}(q)=

\displaystyle{\displaystyle 3h-1\choose h-1}q^{2h}+{3h-1\choose 2h}(1-q^{2})^{\frac{1}{2}{2h\choose h}}

\displaystyle+{3h-1\choose h}(1-q^{h})^{{2h-1\choose h-1}}<1,

Remark 5
.

The construction is not meant to optimize the number of edges.
For
h\geq 9
, the random family
\mathcal{K}
has density about
q
, and hence the auxiliary family
\mbox{$\mathcal{G}$}={V\choose h}\setminus\mbox{$\mathcal{K}$}
is quite dense.
The point is that the complements of the edges of
\mathcal{G}
have exactly the uniformity
2h-1
, matching the previously known example for
h=3
.

3
A barrier for this method beyond
2h

Let us examine whether the same complement-covering method could plausibly give uniformity

m=2h+c,

where
c\geq 0
is fixed. The first plausible value of
n
in this framework is

n=3h+3c+2.

Indeed, for smaller values of
n
the covering condition itself forces a monochromatic
h
-heavy trace on a suitable set
X
of size about
2h+c
. With this choice of
n
, the auxiliary blocks have size

n-m=h+2c+2

and must cover every
(h+c)
-set.
The case
c=0
is exactly the first possible improvement over Theorem
2
: it asks for a
2h
-uniform construction on
3h+2
vertices whose auxiliary
h+2
-sets cover all
h
-sets.

A near-optimal random covering has local density roughly

{1\over{2h+2c+2\choose c+2}},

the reciprocal of the number of auxiliary blocks containing a fixed
(h+c)
-set. Now fix a
(2h-1)
-set
X
and an
(h-1)
-set
U\subset X
. The number of auxiliary blocks
B
with
B\cap X=U
is

{h+3c+3\choose 2c+3}.

Therefore the expected number of blocks realizing this particular
U
is

{{h+3c+3\choose 2c+3}\over{2h+2c+2\choose c+2}}=\Theta_{c}(h^{c+1}).

On the other hand, the number of possible choices of
U
is

{2h-1\choose h-1}=\exp(\Theta(h)).

Thus for
c\geq 1
the expected number of realizations of each fixed
U
is already superlinear in
h
, and the heuristic probability that
U
remains a hole is
\exp(-\Theta_{c}(h^{c+1}))
. This is much smaller than the inverse of the number of possible
U
’s. Consequently, even for one fixed
X
, a locally random near-Steiner covering should leave no holes at all with high probability. Then the trace of
\mathcal{H}
on
X
contains the complete
h
-uniform hypergraph
K_{2h-1}^{(h)}
, and hence is not
2
-colorable.

This is not a non-existence result for
(2h+c)
-uniform examples; a more structured construction might avoid the random-covering behaviour described above. It does show, however, that the covering-design method has a natural barrier after
m=2h
. For every fixed
c\geq 1
, the expected number of holes in the decisive
(2h-1)
-traces becomes negligible. For
c=0
, the same calculation gives only
\Theta(h)
realizations of a fixed
U
, so it does not rule out the possibility of many holes. This suggests that the
2h
-uniform case might still be accessible, but probably only through a carefully constructed near-Steiner covering, such as one produced by a random-greedy or nibble-type argument rather than by independent random selection.

For a subset

Appendix B
Verification code

The following Python program verifies the finite cases
4\leq h\leq 8
and prints the numerical union bounds used for
9\leq h\leq 30
.
It uses no external packages.

from itertools import combinations
from math import comb, exp, log, log1p

MASK64 = (1 << 64) - 1
SMCONST = 0x9e3779b97f4a7c15

# Finite constructions for h=4,...,8.
# K consists of those h-sets whose hash value is below threshold/10^6.
PARAMS = {
4: (600, 650000),
5: (102, 550000),
6: (77, 550000),
7: (55, 520000),
8: (3, 470000),
}

# Values of q used in the union bound for h=9,...,30.
QVALUES = {
9: .447, 10: .430, 11: .415, 12: .403, 13: .393,
14: .384, 15: .376, 16: .369, 17: .363, 18: .357,
19: .350, 20: .350, 21: .350, 22: .350, 23: .350,
24: .350, 25: .350, 26: .350, 27: .350, 28: .350,
29: .350, 30: .350,
}

def splitmix64(x):
x = (x + SMCONST) & MASK64
x = ((x ^ (x >> 30)) * 0xbf58476d1ce4e5b9) & MASK64
x = ((x ^ (x >> 27)) * 0x94d049bb133111eb) & MASK64
return (x ^ (x >> 31)) & MASK64

def mask(c):
ans = 0
for i in c:
ans |= 1 << i
return ans

def masks(n, r):
for c in combinations(range(n), r):
yield mask(c)

def in_K(S, seed, threshold):
z = splitmix64(seed ^ ((S * SMCONST) & MASK64))
return (z % 1000000) < threshold

def finite_construction(h):
seed, threshold = PARAMS[h]
n = 3*h - 1
hsets = list(masks(n, h))
K = {S for S in hsets if in_K(S, seed, threshold)}
return n, hsets, K

def verify_finite_case(h):
n, hsets, K = finite_construction(h)
full = (1 << n) - 1

# (K1): for every (h-1)-set A, not all extensions A+v are in K.
for A in masks(n, h-1):
if all((A | (1 << v)) in K for v in range(n) if not (A >> v) & 1):
return False, "K1"

# (K3): every h-set Y is covered by some star U+Y.
# Mark all Y that are contained in N_K(U) for some (h-1)-set U.
covered = set()
for U in masks(n, h-1):
N = [v for v in range(n)
if not (U >> v) & 1 and (U | (1 << v)) in K]
if len(N) >= h:
for Y in combinations(N, h):
covered.add(mask(Y))
if len(covered) != len(hsets):
return False, "K3"

# (K2): every 2h-set has a complementary pair R, X-R in K.
for X_tuple in combinations(range(n), 2*h):
X = mask(X_tuple)
first, rest = X_tuple[0], X_tuple[1:]
ok = False
for sub in combinations(rest, h-1):
R = (1 << first) | mask(sub)
if R in K and (X ^ R) in K:
ok = True
break
if not ok:
return False, "K2"

return True, "OK"

def logsumexp(values):
m = max(values)
return m + log(sum(exp(x-m) for x in values))

def union_bound(h, q):
n = 3*h - 1
N = comb(2*h, h) // 2
M = comb(2*h - 1, h - 1)
logs = [
log(comb(n, h-1)) + 2*h*log(q),
log(comb(n, 2*h)) + N*log1p(-q*q),
log(comb(n, h)) + M*log1p(-(q**h)),
]
return exp(logsumexp(logs))

ok, reason = verify_finite_case(h)
n, hsets, K = finite_construction(h)
