TinyDark-YOLO for adaptive and lightweight object detection in low-light conditions
Authors: Xuefang Zheng, Lifang Chen, Jiechi Zhang
Published: 2026

ABSTRACT
Low-light object detection frequently suffers from weak contrast, high noise, and poor performance on small objects. Existing methods often adopt image enhancement to improve detection performance, which results in substantial computational resource consumption. To address these challenges, we propose TinyDark-YOLO, an adaptive and efficient low-light object detection algorithm based on YOLO11. First, we design an Adaptive Gamma Enhancement (AGE) module to adaptively adjust the brightness of input images. Second, we introduce an Attention-based Intra-scale Feature Interaction (AIFI) module to construct global context modeling on high-level features and capture long-range spatial dependencies, improving the detection accuracy of small objects. Finally, we propose a Lite Efficient Head (LEHead) to reduce computational overhead while enhancing the model’s ability to capture weak features in dark environments. We conduct validation and ablation experiments on the ExDark dataset. The results demonstrate that the proposed model achieves an mAP@0.5 of 67.20% on the ExDark dataset, yielding an improvement of 2.39% over the baseline YOLO11n, while reducing computational complexity from 6.3 to 5.8 GFLOPs. TinyDark-YOLO also achieves competitive performance on the DarkFace dataset.

Introduction

Object detection in low-light environments is an important research direction in computer vision, with far-reaching applications in autonomous driving, intelligent surveillance, drone inspection. With advances in deep learning, object detection algorithms have reached maturity under normal illumination. Classic detectors including Faster R-CNN1, SSD2 and the YOLO series3–8 achieve competitive performance and attain a desirable trade-off between detection accuracy and inference speed. However, in low-light scenarios including nighttime, tunnels, cloudy days, and dim indoor environments, insufficient illumination results in weak contrast, missing fine-grained details, and pervasive noise, significantly impairing the performance of traditional detection models. With expanding applications in autonomous systems and intelligent surveillance, improving detection robustness in low-light conditions has become a pivotal research direction for bridging the gap between laboratory performance and real-world utility.

Current low-light object detection methods can be generally classified into four categories: image enhancement-based methods, end-to-end enhancement-detection collaborative methods, detector structure optimization methods, and lightweight low-light detection models.

The first category refers to image enhancement-based detection methods. These methods preprocess images through enhancement algorithms such as RetinexNet9, Zero-DCE10, EnlightenGAN11, SCI12, and RetinexFormer13 to improve brightness and contrast. Object detection is then conducted on the processed images. With more distinct feature information available, detection models can identify and locate targets with higher accuracy. This method is seldom used, as there is a mismatch between the optimization goals of image enhancement and object detection. The visual improvement achieved by enhancement cannot always be converted into effective features for detection models, which limits the further improvement of detection performance.

The second category refers to end-to-end enhancement-detection collaborative methods. Cascading image enhancement and object detection modules enables collaborative optimization through joint training, effectively improving detection performance. Jiang et al.14 developed the LOL-YOLO model by cascading SCI12 with YOLOv8n, which improves detection accuracy while effectively controlling computational cost. Liu et al.15 proposed the IA-YOLO model for adverse weather conditions, which predicts image enhancement parameters via a lightweight neural network and cascades the image enhancement module with YOLOv3, boosting detection performance in adverse weather. Yin et al.16 presented the PE-YOLO low-light object detection framework, which decomposes images into four components of different resolutions using a Laplacian pyramid, and designs a detail processing module and a low-frequency enhancement filter to enhance component at each scale separately, further improving detection performance.While these end-to-end frameworks enable joint optimization of enhancement and detection, the additional enhancement modules greatly increase the overall computational load.

The third category refers to detector structure optimization methods. Rather than relying on external image enhancement, these methods achieve superior low-light detection performance by optimizing the detector’s internal network. Luo et al.17 proposed VnDark, which constructs a feature enhancement sub-network via an iterative light enhancement curve mechanism and adopts a U-shaped encoder-decoder to extract distinct edge features from nighttime images, thereby improving the detection accuracy of objects in night scenes. Han et al.18 proposed the 3L-YOLO model adopting Switchable Atrous Convolution(SAC)and a multi-scale attention fusion mechanism, which greatly improves detection accuracy for multi-scale targets. Sun et al.19 improved the YOLO11 framework by introducing the Feature Fusion Attention Network (FFA-Net) and a triple attention mechanism, which effectively enhances the detection performance in low-light environments. Most detector optimization schemes only adjust network structures and lack dedicated designs for low-light scenarios, resulting in limited improvement in detection performance.

The fourth category refers to lightweight detection models. Such methods simplify network architectures to reduce model parameters and computational overhead, thereby enabling efficient deployment on edge devices.Hui et al.20 proposed the WSA-YOLO model by introducing a lightweight weighted spatial attention mechanism into YOLOv7. It enhances object-region features at low computational cost while preserving detection accuracy. Zhuo et al.21 presented SCL-YOLOv11, a lightweight low-light detection model. It optimizes feature extraction modules to cut computational consumption and deliver reliable performance in low-light environments. Lightweight models simplify network layers and feature extraction branches to reduce parameters and computational overhead, and may show insufficient robustness in complex low-light environments.

Although current methods perform adequately in low-light environments, complex scenarios still induce frequent missed and false detections. Detection accuracy degrades further when dealing with blurred or small objects in extreme darkness. We propose an adaptive low-light object detection algorithm named TinyDark-YOLO, which is based on YOLO11. The main contributions are as follows:

(1)We develop TinyDark-YOLO, an adaptive end-to-end framework designed for low-light object detection. By adaptively learning optimal Gamma coefficient for different low-light images and utilizing a Lite Efficient Head, it achieves a superior balance between detection accuracy and computational efficiency.

(2)We design an Adaptive Gamma Enhancement (AGE) module in the YOLO11 backbone to restore structural and detailed information of objects in low-light scenarios. Meanwhile, the Attention-based Intra-scale Feature Interaction (AIFI) module is introduced to model global contextual relations from high-level features. The two modules work together to enhance small object detection performance in low-light environments.

(3)We design a Lite Efficient Head (LEHead), which employs a lightweight feature enhancement branch based on two-layer 3 × 3 group convolution for feature maps of each detection scale. LEHead achieves significant gains in inference speed and resource efficiency without compromising detection robustness.

Related work

Learnable illumination-aware enhancement technology

Low-light images often suffer from insufficient brightness and missing details, which degrade the performance of object detection models. As a mainstream method for low-light image processing, illumination-aware enhancement technology adjusts brightness and restores image quality according to the illumination distribution of images.

Adaptive gamma enhancement is a widely adopted method of learnable illumination-aware enhancement. Different from traditional gamma transformation with fixed correction coefficients, this method dynamically calculates gamma values pixel by pixel or in local regions based on regional brightness features, so as to balance global brightness and preserve local details. With the advancement of deep learning, data-driven approaches are capable of learning illumination transformation and image enhancement strategies automatically, achieving better adaptability to complex low-light scenarios. Debnath et al.22 proposed a low-light image enhancement method combining gamma coefficient learning and attention-based encoder-decoder network. The optimal gamma coefficients are obtained via network training, which promotes the evolution of gamma correction towards a learnable paradigm.

At present, various learnable designs have been extensively applied in computer vision. Xue et al.23 adopted a learnable frequency-aware interaction module and multi-expert fusion mechanism to improve the model robustness against illumination variation, object occlusion and other complex interferences. In large vision model tasks, learnable visual prompts and prompt pruning strategies enable efficient fine-tuning of pre-trained models24. For Mirror Detection25,26, researchers utilize learnable depth calibration, dynamic prompt strategies and feature decoupling modules to make models adapt to feature distributions of various scenarios. Some scholars also proposed a recognition framework based on learnable nearest centroids27, which explores feature patterns in a data-driven manner and effectively improves the generalization and interpretability of algorithms.

The above concepts, learnable architectures, dynamic feature interaction and adaptive modules provide valuable references for low-light image enhancement. In this paper, a learnable adaptive gamma enhancement module is designed. It adopts a lightweight neural network to predict gamma coefficients dynamically and realize pixel-level illumination correction. This method can effectively enhance low-light images while meeting the practical requirements of object detection tasks.

Feature interaction and attention enhancement methods

An important approach to boosting the accuracy of low-light object detection is to strengthen feature representation and explore inter-feature correlations. Feature interaction and attention mechanisms can guide models to focus on valid information and suppress background noise, which have been widely adopted in various visual tasks and have become a mainstream research direction in low-light detection.

Low-light images generally suffer from degradation problems such as blurred details and mixed noise. Various feature interactions can connect local textures and global semantic information, making up for the insufficient representation capability of a single feature branch. Pan et al.28 proposed MedCTM, a hybrid CNN-Transformer-Mamba network, which divides feature learning into three modules: local feature extraction, long-range dependency modeling and cross-branch feature interaction. A bidirectional channel interaction attention is designed to enable dynamic information interaction between CNN and Mamba branches, achieving excellent detection performance.

The attention mechanism assigns adaptive weights to make the model focus on target regions and reduce the negative impacts caused by irrelevant backgrounds and noise. For ship detection under complex backgrounds29, researchers introduce an improved Transformer structure and build a four-scale residual feature fusion network, which effectively solves the problems of missed and false detection of small ship in complex scenarios. In addition, methods based on clustering and prototype learning also provide new ideas for feature optimization30,31. Reconstructing Transformer cross-attention can enhance feature discrimination and algorithm interpretability, and meet the requirements of unified modeling for multiple tasks. For scenarios with poor image quality and severe noise interference32, heterogeneous experts and hierarchical perception networks model texture details and global structures separately via multi-branch architectures, which greatly improves the model’s anti-interference capability.

Overall, feature interaction and attention enhancement methods can significantly optimize model feature representation. In this paper, an attention-based feature interaction module is introduced into the YOLO11 framework to adapt to low-light scenarios, which enhances feature representation.

Lightweight model design

How to compress model parameters and cut computational overhead while guaranteeing detection accuracy has become an important research direction for low-light object detection algorithms.

Current lightweight detection methods are mainly developed from module simplification, network structure optimization and feature fusion strategies.Targeting industrial defect detection, Pan et al.33 designed a task-gated detection head to decouple classification and regression via lightweight architecture.The model only has 2.63 M parameters and realizes model slimming while retaining noise robustness and boundary awareness. To meet real-time detection requirements, YOLO-ROC34 adopts hierarchical channel compression, reducing parameters to 0.89 M and GFLOPs to 2.6, which balances small object accuracy and inference speed. RT-DSAFDet35, constructed with three components including flexible attention feature extraction, dynamic scale-aware fusion, and efficient spatial downsampling, achieves 1.8 M parameters and 4.6G FLOPs, boosting multi-scale detection performance with significantly reduced computational cost.

The above researches verify that embedding efficient attention mechanisms and dynamic fusion structures into lightweight networks is an effective solution to balance detection accuracy, inference speed and model size, which provides references for lightweight detector design under low-light and complex scenarios.

With the attention-based feature interaction module introduced to strengthen feature representation, we utilize group convolution to build a lightweight efficient detection head, further reducing model parameters and computational complexity.

Method

TinyDark-YOLO is based on YOLO11. In its backbone, we design an AGE module to solve the problems of insufficient brightness and poor object discriminability in low-light images. The AGE module adaptively predicts Gamma coefficient through a lightweight neural network, then performs illumination correction on the low-light input image based on the predicted coefficient. To address the missed detection of small objects in extremely low-light environments, we replace the original SPPF module in the backbone with the AIFI module from RT-DETR. This simplifies the spatial pyramid pooling structure and strengthens feature representation through global context interaction, achieving more accurate detection of multi-scale objects. We design the detect head LEHead using two-layer 3 × 3 group convolution to improve the feature representation of blurred, weak-textured, and low-contrast objects in low-light environments. LEHead enhances semantic feature representation, improving detection accuracy while lowering computational complexity. The structure diagram of TinyDark-YOLO is shown in Fig. 1.

Adaptive gamma enhancement module (AGE)

Inspired by IA-YOLO, we redesign the first convolutional layer of the YOLO11 backbone and replace it with AGE module. AGE module improves target discriminability through adaptive brightness enhancement, enhancing object detection accuracy. In AGE module, we design a lightweight neural network named CNN-Gamma as a Gamma coefficient predictor, CNN-Gamma can adaptively predict the Gamma coefficient based on the brightness of the input image. This design effectively prevents excessive noise enhancement and image detail loss, and ensures stable Gamma prediction throughout the training process.

Attention-based intra-scale feature interaction module (AIFI)

In low-light environments, YOLO11 still faces challenges in detecting small objects and edge-blurred objects. To enhance the attention of YOLO11 on small and blurred objects in low-light conditions, we introduce the AIFI module to achieve dynamic fusion of local and global information and optimize the correlated feature expression of targets.

The AIFI module is a key component in the RT-DETR36 model. It only operates on the highest semantic feature layer, enabling intra-scale feature interactions through a single-scale Transformer encoder. It uses the Multi-Head Self-Attention mechanism (MHSA)37 to encode the highest feature layer, which effectively reduces the computational complexity. Compared with low-level feature maps, high-level feature maps contain richer semantic information. Performing self-attention operations on high-level feature maps can effectively capture the global correlations between target entities, which helps subsequent modules locate and recognize targets.

Lite efficient head(LEHead)

In low-light environments, object textures suffer from severe degradation and feature responses are significantly attenuated. This inevitably leads to suboptimal detection accuracy and a high incidence of missed and false detections. To address these issues, we design the LEHead for low-light scenarios, as shown in Fig. 4. Unlike the original detection head of YOLO11, which performs independent convolution on the channel dimension using depthwise convolution (DWConv), LEHead achieves feature enhancement by two-layer 3 × 3 group convolution, enabling it to fully capture local contextual information and edge contour features of low-light objects. This effectively strengthens the discriminability of weak features and improves the model’s detection performance in extremely low-light and complex lighting conditions.

Fig. 4Structure diagram of LEHead. LEHead is constructed on group convolution. The input feature map is divided into G groups according to channel number C, and each group independently performs a 3 × 3 convolution followed by feature concatenation. Features processed by two layers of group convolution are fed into classification and regression branches for category and bounding box prediction.

Experiments

Datasets

We used the public dataset Exclusively-Dark-Image-Dataset (ExDark)38 to evaluate the performance of our model. ExDark is a professional low-light dataset released by the Loh team in 2019. It contains 7,363 low-light images, covering 10 different lighting conditions ranging from extremely dark to dimly lit environments, providing a comprehensive test platform for low-light object detection research. The dataset includes 12 common object categories: bicycle, boat, bottle, bus, car, cat, chair, cup, dog, motorcycle, people, and table.We set the random seed to 42 and split the dataset at a 7:1:2 ratio, resulting in 5,154 images for training, 736 for validation, and 1,473 for testing. All ablation and comparative experiments adopted this same split to eliminate the influence of random perturbations, thereby ensuring reliable and reproducible results.

We also adopt the public dataset DarkFace39 to evaluate the robustness of TinyDark-YOLO. DarkFace dataset was released by Peking University in 2019, it is an authoritative dataset specifically for low-light and night-time face detection. All images in the DarkFace dataset are captured in real night-time scenes, covering complex environments such as teaching buildings, streets, bridges, and parks. The dataset contains 6,000 images with 50,399 annotated face boxes. For our experiments, this dataset was also split at a ratio of 7:1:2 with the random seed set to 42, obtaining 4200 training, 600 validation and 1200 test images. All subsequent experiments on the DarkFace dataset adopted this partition method.

The confidence threshold was set to 0.25 and the NMS threshold to 0.7 for inference. Detailed experimental parameters are presented in Table 2.

Evaluation metrics

We adopt GFLOPs and parameters (Params) to assess the complexity of the model, and use precision (P), recall (R), and mean average precision (mAP) to evaluate the detection accuracy of the model. A smaller number of parameters indicates a more lightweight model, a lower GFLOPs means a lower computational complexity of the algorithm. Precision indicates the proportion of true positive samples among all samples predicted as positive by the model. A higher precision value indicates a lower false detection rate of the model. Recall represents the ratio of correctly predicted positive samples to all actual positive samples. Higher recall indicates fewer missed detections. The calculation formulas are shown in Equations (16)~(17).16\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\:P=\frac{TP}{TP+FP}\times\:100\%$$\end{document}17\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\:R=\frac{TP}{TP+FN}\times\:100\%$$\end{document}

where TP(True Positive) is the number of positive samples correctly predicted by the model, FP(False Positive) is the number of negative samples incorrectly predicted as positive, and FN (False Negative) is the number of positive samples incorrectly predicted as negative.

In object detection, multiple classes are usually detected, each with an average precision(AP), AP represents the average precision under different recall rates and corresponds to the area under the P-R curve. The mean AP of all classes is denoted as mAP, as shown in Equations (18)~(19). The model’s mAP is usually evaluated using two metrics: mAP@0.5 and mAP@0.5:0.95. To verify the effectiveness of AGE, AIFI and LEHead modules in our TinyDark-YOLO, we conduct ablation experiments on the ExDark dataset. These results demonstrate that the introduction of AGE enhances the model’s ability to perceive objects. Introducing the AIFI module alone improves the mAP@0.5 to 66.86%, outperforming the baseline by 2.05%. Meanwhile, the recall is improved by 2.29%. These results show that the attention-based feature interaction mechanism effectively captures global contextual information, improving object localization and recognition performance. Integrating LEHead alone elevates the mAP@0.5 from 64.81% to 66.18%, outperforming the baseline by 1.37%. Furthermore, the computational cost is reduced from 6.3 to 5.1 GFLOPs. These results suggests that the model’s detection capability under extremely low-light and complex illumination conditions is enhanced, with a significant decrease in computational cost.

The combination of AGE and AIFI achieves a mAP@0.5 of 66.55%, representing an improvement of 1.74% over the baseline model, while recall is increased to 61.15%. Both mAP@0.5 and recall are significantly improved with a slight increase in computational cost. The combination of AGE and LEHead yields a mAP@0.5 of 66.24%, which is 1.43% higher than the baseline model. Meanwhile, computational cost is reduced by 1.1 GFLOPs and parameters is decreased by 3.9%. The combination of AIFI and LEHead improves mAP@0.5 and mAP@0.5:0.95 to 66.63% and 40.30% respectively, reduces computational cost by 0.9 GFLOPs and increases parameters by 0.36 M, achieving a balance between accuracy improvement and acceptable parameter increment.

Ultimately, TinyDark-YOLO integrates the three modules, achieves a mAP@0.5 of 67.20% on the ExDark dataset, outperforming the baseline by 2.39%. In addition, precision, recall and mAP@0.5:0.95 are increased by 1.58%, 2.51% and 1.56% respectively, while computational cost is reduced by 0.5 GFLOPs.

The ablation experiments show that the AGE, AIFI and LEHead are all effective and can work collaboratively. The joint use of these modules achieves superior performance, realizing a balanced improvement in performance metrics while maintaining the lightweight advantage of the model.

Analysis of experimental limitations

Although the TinyDark-YOLO model achieves notable performance in low-light scenarios, it still has several limitations in complex scenarios. The model is prone to false detections for objects with highly similar features, such as cats and dogs, bicycles and motorcycles, as illustrated in Fig. 7 (a). Meanwhile, missed detections frequently occur in cases of target occlusion and densely distributed targets, as shown in Fig. 7(b). We will conduct targeted optimizations in future research to mitigate the above problems, further improving the detection robustness and generalization ability of the model in complex practical environments.

Conclusion

To address the challenges of low detection accuracy, frequent false and missed detections, and inaccurate localization caused by degraded images in low-light environments, we propose TinyDark-YOLO, an adaptive low-light object detection algorithm that does not need to cascade image enhancement modules, with a simple structure and low computational cost. We design the AGE module in the backbone of YOLO11 to automatically perceives illumination changes in low-light environments. Furthermore, We introduce the AIFI module, which effectively enhances the structural and detailed features of small objects in low-light environments and improves the model’s small object detection performance under extremely low-light conditions. Finally, we design LEHead based on two-layer group convolution, which significantly reduces computational cost while ensuring detection accuracy in low-light scenarios. Experiments on the ExDark and DarkFace datasets show that TinyDark-YOLO achieves notably detection performance in low-light environments.

Although TinyDark-YOLO achieves promising detection results, future work will focus on two aspects: first, conducting experiments on multiple datasets and real-world scenarios to further verify the model’s generalization capability; second, exploring feature interaction and attention enhancement approaches to alleviate false detections for similar-feature objects and missed detections under dense occlusion, thus improving the model’s robustness and practicability.
