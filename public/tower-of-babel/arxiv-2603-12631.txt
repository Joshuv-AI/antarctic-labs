Collaborative Multi-Agent Optimization for Personalized Memory System
Wenyu Mao, Haoyang Liu, Zhao Liu, Haosong Tan, Yaorui Shi, Jiancan Wu, An Zhang, Xiang Wang ∗

Abstract
Memory systems are crucial to personalized LLMs by mitigating the context window limitation in capturing long-term user-LLM conversations. Typically, such systems leverage multiple agents to handle multi-granular memory construction and personalized memory retrieval tasks. To optimize the system, existing methods focus on specializing agents on their local tasks independently via prompt engineering or fine-tuning. However, they overlook cross-agent collaboration, where independent optimization on local agents hardly guarantees the global system performance. To address this issue, we propose a Collaborative Reinforcement Learning Framework for Multi-Agent Memory Systems (CoMAM), jointly optimizing local agents to facilitate collaboration. Specifically, we regularize agents’ execution as a sequential Markov decision process (MDP) to embed inter-agent dependencies into the state transition, yielding both local task rewards ( e.g., information coverage for memory construction) and global rewards ( i.e., query-answer accuracy). Then, we quantify each agent’s contribution via group-level ranking consistency between local and global rewards, treating them as adaptive weights to assign global credit and integrate local-global rewards. Each agent is optimized by these integrated rewards, aligning local improvements with the global performance. Experiments show CoMAM outperforms leading memory systems, validating the efficacy of our proposed collaborative reinforcement learning for joint optimization.

Introduction

Construction and retrieval agents, optimized on local tasks independently, yield lower global system performance than those under joint optimization.

Memory systems
(
Chhikara et al. 2025
;
Zhong et al. 2024
;
Hu et al. 2025
)
have emerged as a pivotal frontier for personalized large language models (LLMs), which preserve users’ long-term conversational history beyond LLMs’ context window and selectively integrate it to tailor personalized responses
(
Chen et al. 2024a
;
Zhang et al. 2025
)
.
Typically, the memory system comprises multiple specialized agents: several
construction agents
summarize and store user history into multi-granular memories (
e.g.,
long/short or coarse/fine), respectively
(
Li et al. 2025
;
Wang & Chen 2025
;
Wang et al. 2025
)
; and
retrieval agents
select and integrate relevant memories for subsequent queries via RAG
(
Lewis et al. 2020
)
or search-based reasoning
(
Yu et al. 2026
;
Jin et al. 2025
)
.
To enhance system effectiveness, existing methods focus on optimizing these agents for their respective tasks independently: Prompt engineering approaches
(
Li et al. 2025
;
Zhong et al. 2024
)
specialize each agent for its local task with well-crafted prompts, while reinforcement learning methods
(
Wang et al. 2025
;
Zhou et al. 2026
;
Yan et al. 2025b
)
train agents separately using rewards such as the query-answer accuracy.

Despite local successes, they overlook cross-agent collaboration, treating the memory system as a “collection of local experts” rather than a collaborative team that evolves together for a global goal.
Critically, independent optimization on local agents hardly guarantees global system performance
(
Akella 2025
;
Wu et al. 2026
)
. While individual agents may excel at their respective tasks, their independent strategies can conflict when combined in the global pipeline.
To be more specific, if the fine-grained construction agent is optimized by treating retrieval agents as fixed environment components, it may store redundant or noisy content that impairs retrieval effectiveness. Conversely, if retrieval agents are trained without considering construction strategies, they may over-filter information and miss critical details during retrieval. As illustrated in Figure
1
, even with independently well-trained agents (rewards converged), the combined system consistently underperforms that with joint optimization across different conversational history lengths.
This motivates us to explore jointly optimizing multiple agents in the memory system to facilitate collaboration, which faces two challenges (see Figure
2
):

Figure 2
:
Illustration of challenges for joint optimization.

•

Heterogeneity and Asynchrony:

Multi-granular construction and retrieval agents operate with heterogeneous configurations and asynchronous executions across different tasks. Their discrete parameter space and inherent structural complexity complicate end-to-end optimization.

•

Local-Global Alignment:

Fostering collaboration requires aligning local improvement with the global performance. However, directly assigning equal shares of the global objective to individual agents introduces ambiguity in task execution, as agents’ contributions are divergent.

To address these challenges, we introduce CoMAM, a Collaborative reinforcement learning framework for Multi-Agent Memory systems.
Specifically, we formulate a standard memory system with three specialized agents for multi-granular memory construction and retrieval: an extraction agent to construct fine-grained memories (
e.g.,
key events and facts), a profile agent to construct coarse-grained memories (
e.g.,
users’ personalized preferences), and a retrieval agent to retrieve memories and answer queries. To optimize these heterogeneous agents jointly, we frame their asynchronous execution as a sequential Markov decision process (MDP), which embeds inter-agent dependencies into state transitions and yields both local task-specific rewards (
e.g.,
information coverage for memory construction) and global system rewards (
i.e.,
query answer accuracy). To achieve local-global alignment, CoMAM quantifies each agent’s system contribution by measuring group-level ranking consistency between its local and global rewards, then adaptively allocates global rewards to agents based on this consistency. Each agent is ultimately optimized with a combination of its task-specific reward and adaptively assigned global reward share, driving end-to-end collaboration toward the global objective.
Extensive experiments on long-term personalized conversational tasks show CoMAM outperforms leading memory baselines, validating the efficacy of our collaborative reinforcement learning for jointly optimizing multi-agent memory systems.

Related work

Memory System for Personalized LLMs

Beyond delivering general knowledge, personalized LLMs generate personalized responses to users
(
Chen et al. 2024a
;
Zhang et al. 2025
)
, such as recalling past conversational experiences or producing preference-aligned suggestions
(
Jiang et al. 2025
)
, based on user-LLM conversational histories. To address LLMs’ context window limitation on long-term conversational data, recent work adopts memory systems
(
Hu et al. 2025
;
Li et al. 2025
;
Chhikara et al. 2025
;
Yan et al. 2025b
)
to manage user-specific conversational histories, which are composed of multiple agents to handle memory construction and retrieval subtasks separately.
For example, MIRIX
(
Wang & Chen 2025
)
designs a meta agent and six specialized agents to manage memory. Mem
-\alpha

(
Wang et al. 2025
)
and Mem1
(
Zhou et al. 2026
)
leverage reinforcement learning (RL) to optimize the memory construction and memory retrieval agents, respectively.

Optimization of Multi-agent System

Multi-agent Systems (MAS)
(
Sun et al. 2024
;
Chen et al. 2024b
)
leverage multiple specialized agents with heterogeneous configurations and asynchronous execution to tackle complex tasks beyond the capacity of a single agent. To boost MAS performance, existing methods focus on independent optimization, primarily via prompt engineering
(
Patil et al. 2024
;
Wu et al. 2024
)
or fine-tuning of agents on specific tasks
(
Subramaniam et al. 2025
;
Yan et al. 2025b
)
. Yet such methods yield only marginal gains, as they overlook the value of joint optimization for inter-agent collaboration. Consequently, recent research has shifted to reinforcement learning (RL)-based collaborative training for end-to-end system optimization, such as MAPoRL
(
Park et al. 2025
)
and MARFT
(
Liao et al. 2025
)
.

Credit Assignment

Credit assignment
(
Zhou et al. 2020
;
Bo et al. 2024a
;
Tseng et al. 2022
)
concerns properly attributing a team’s global outcome to the specific agents in Multi-Agent Reinforcement Learning (MARL). This is particularly difficult in quantifying agents’ contributions to the outcome, which is often obscured by the actions of other agents and environmental noise.
Naive credit assignment approaches evenly distribute global team rewards across agents
(
Zhao et al. 2026
;
Hong et al. 2025
)
. Though simple, this leads to significant credit assignment ambiguity: agents cannot distinguish their specific impact, resulting in high variance in policy updates and unstable convergence.

3.1
Task Formulation for Multi-agent Memory System

We define the user’s long-term conversational history as
\mathcal{H}=\{h_{1},\dots,h_{N}\}
, which consists of
N
-turn interactions that exceed the LLM’s context window. To facilitate personalization, the Memory System transforms the history
\mathcal{H}
into multi-granular memories
\mathcal{M}
that can be retrieved to answer users’ subsequent queries
q
, realized by diverse agents on construction and retrieval tasks
(
Hu et al. 2025
)
:

•

Memory Construction:
The agents
(
Li et al. 2025
)
under policies
\{\pi_{\theta}^{\text{cons}_{g}}\}
, distill the raw conversational history
\mathcal{H}
at different granularities
g
, respectively, finally constructing a multi-granular memory set
M
:

\displaystyle\mathcal{M}_{g}=\pi_{\theta}^{\text{cons}_{g}}(\mathcal{H}),

(1)

\displaystyle\mathcal{M}=\{\mathcal{M}_{g}\}.

(2)

•

Memory Retrieval:
Given a subsequent query
q
, retrieval agents
(
Zhou et al. 2026
)
under policies
\{\pi_{\theta}^{\text{ret}}\}
identify the
K
most relevant memories from
\mathcal{M}
. Then, the agent with policy
\pi_{\theta}^{\text{LLM}}
generates a response
p
for the query
q
using the retrieved
K
memories. Formally:

\displaystyle\{\bm{m}_{k}\}_{k=1}^{K}=\pi_{\theta}^{\text{ret}}(q,\mathcal{M},K),

(3)

\displaystyle p=\pi_{\theta}^{\text{LLM}}\left(q,\{\bm{m}_{k}\}_{k=1}^{K}\right).

(4)

For efficiency,
\pi_{\theta}^{\text{ret}}
and
\pi_{\theta}^{\text{LLM}}
can be unified into a single policy that performs both memory retrieval and personalized response generation for query
q
.

The global goal of the memory system is to align the generated response
p
with the user’s personalized preferences and experiences. Formally, given a dataset
\mathcal{D}
with input pairs
(\mathcal{H},q)
and a performance evaluation function
\mathcal{F}
, the optimization objective is to find the optimal policy set
\Pi^{*}
that maximizes the expected global performance:

\displaystyle\Pi^{*}=\arg\max_{\Pi}\mathbb{E}_{(\mathcal{H},q)\sim\mathcal{D}}\left[\mathcal{F}\left(p^{*},\Pi(\mathcal{H},q)\right)\right].

(5)

Here,
\Pi=\{\pi_{\theta}^{\text{cons}_{g}},\pi_{\theta}^{\text{ret}}\}
denotes the policy set, and
p^{*}
denotes the ground-truth response.

3.2
Reinforcement Learning for LLMs

To optimize LLMs’ policy
\pi_{\theta}
, Reinforcement Learning (RL)
(
Ouyang et al. 2022
;
Zheng et al. 2023
)
is typically used to maximize the expected reward while maintaining stability relative to a reference model
\pi_{\text{ref}}
. In this work, we primarily build upon Group Relative Policy Optimization (GRPO)
(
Shao et al. 2024
)
, an efficient RL algorithm that eliminates the need for a separate value function (critic) through group-based relative rewards. Given the input
x
, GRPO samples a group of outputs
\left\{o_{1},\ldots,o_{G}\right\}
from the current policy
\pi_{\theta}
and optimizes the objective function:

\displaystyle\mathcal{J}_{GRPO}\left(\pi_{\theta}\right)=

(6)

\displaystyle\frac{1}{G}\sum_{i=1}^{G}\frac{1}{\left|o_{i}\right|}\sum_{t=1}^{\left|o_{i}\right|}\left\{\min\left[\rho_{i,t}\hat{A}_{i,t},\hat{\rho}_{i,t}\hat{A}_{i,t}\right]-\beta\mathbb{D}_{KL}\right\},

where
\rho_{i,t}=\frac{\pi_{\theta}\left(o_{i,t}\mid x,o_{i,<t}\right)}{\pi_{\theta_{\text{old }}}\left(o_{i,t}\mid x,o_{i,<t}\right)}
is the importance sampling ratio,
\hat{\rho}_{i,t}=\operatorname{clip}\left(\rho_{i,t};1-\epsilon,1+\epsilon\right)
is the clipped ratio. The advantage
\hat{A}_{i,t}
for each output
o_{i}
is computed by normalizing its reward
r_{i}
relative to the group mean and the standard deviation. Formally, we have:

\displaystyle\hat{A}_{i,t}=\frac{r_{i}-\text{mean}(r)}{\text{std}(r)}.

(7)

The KL divergence is defined as:

\displaystyle\mathbb{D}_{KL}=\frac{\pi_{ref}(o_{i,t}|x,o_{i,<t})}{\pi_{\theta}(o_{i,t}|x,o_{i,<t})}-\log\frac{\pi_{ref}(o_{i,t}|x,o_{i,<t})}{\pi_{\theta}(o_{i,t}|x,o_{i,<t})}-1.

(8)

Method

Figure 3
:
The overview of our proposed framework, CoMAM, which regularizes agents’ execution as MDP trajectories for joint RL optimization and fosters collaboration via adaptive credit assignment to achieve local-global alignment.

In this section, we present our proposed CoMAM, a Collaborative Reinforcement Learning Framework designed to address the key challenges of jointly optimizing the multi-agent memory systems, as shown in Figure
3
. We begin by defining the task-specific agents alongside the local and global rewards in Sec
4.1
. Then, we elaborate on regularizing the execution trajectory as a Markov decision process (MDP) in Sec
4.2
, which enables joint optimization despite agent heterogeneity and asynchrony. Finally, we present the adaptive credit assignment mechanism in Sec
4.3
, which quantifies individual agent contributions and aligns local improvements with global performance.

4.1
Task-Specific Agents Definition

Building on existing multi-agent memory paradigms
(
Hu et al. 2025
;
Li et al. 2025
)
, we define a standard memory system consisting of three specialized agents: Extraction Agent, Profile Agent, and Retrieval Agent.

Extraction Agent
extracts fine-grained memory
\mathcal{M}_{f}
with policy
\pi_{\theta}^{\text{cons}_{f}}
from the raw conversational history
\mathcal{H}
. Formally, we define the set of evident information relevant to query
q
as
\mathcal{E}_{q}\subseteq\mathcal{H}
. The agent’s objective is to maximize relevant evidence coverage with the reward function:

\displaystyle r_{\text{cons}_{f}}=\alpha\cdot\frac{|{\mathcal{M}_{f}}\cap\mathcal{E}_{q}|}{|\mathcal{E}_{q}|}+(1-\alpha)\cdot\frac{|{\mathcal{M}_{f}}\cap\mathcal{E}_{q}|}{|{\mathcal{M}_{f}}\cup\mathcal{E}_{q}|},

(9)

where
r_{\text{cons}_{f}}
balances the coverage of relevant information and the filtering of irrelevant content. To prioritize coverage,
\alpha
is set to
0.8
.

Profile Agent
abstracts coarse-grained memory
\mathcal{M}_{c}
(
e.g.,
user’s preferences or behavioral patterns) from
\mathcal{M}_{f}
, guided by policy
\pi_{\theta}^{\text{cons}_{c}}
. The agent aims to maximize abstraction rationality, quantified by the model-based reward function:

\displaystyle r_{\text{cons}_{c}}=\mathcal{V}(\mathcal{M}_{c},\mathcal{H})\in[0,1],

(10)

where
r_{\text{cons}_{c}}
evaluates the quality of
\mathcal{M}_{c}
relative to the conversation history
\mathcal{H}
according to predefined rubrics (
e.g.,
scenario, preference, and user profile).
\mathcal{V}
denotes a frozen pre-trained LLM for reward generation. Finally, the comprehensive memory set is defined as
\mathcal{M}=\{\mathcal{M}_{f},\mathcal{M}_{c}\}
.

Retrieval Agent
retrieves top-
k
relevant memories
\mathcal{E}_{q}^{\prime}=\{\bm{m}_{k}\}_{k=1}^{K}
from memory set
\mathcal{M}
and generate personalized response
p
for user’s subsequent query
q
, guided by policy
\pi_{\theta}^{\text{ret}}
. To evaluate the retrieval performance, we define a rule-based reward function that enables precise matching between the recalled
\mathcal{E}_{q}^{\prime}
and ground-truth evidence
\mathcal{E}_{q}
:

\displaystyle r_{\text{ret}}=\beta\cdot\frac{|\mathcal{E}_{q}^{\prime}\cap\mathcal{E}_{q}|}{|\mathcal{E}_{q}|}+(1-\beta)\cdot\frac{|\mathcal{E}_{q}^{\prime}\cap\mathcal{E}_{q}|}{|\mathcal{E}_{q}^{\prime}\cup\mathcal{E}_{q}|},

(11)

where
r_{\text{ret}}
balances the coverage and precision of retrieval. To prioritize retrieval precision while minimizing noise,
\beta
is set to
0.2
.

To evaluate the memory system’s global performance, we define the rule-based reward for
\pi_{\theta}^{\text{ret}}
to evaluate its answering accuracy for query
q
. Formally, let
p^{*}
denote the ground-truth response for the personalized query
q
, we have:

\displaystyle r_{\text{ans}}=\mathbb{I}\left(p^{*}=p\right)

(12)

where
\mathbb{I}
denotes the indicator function that measures alignment between the generated response
p
and ground-truth answer
p^{*}
, yielding
1
if
p^{*}=p
and
0
otherwise.

Notably, the number and tasks of these agents can be further expanded to meet diverse application requirements in a multi-agent memory system.

4.2
Execution Trajectory Regularization

Usually, construction agents run periodically to manage historical conversations, while retrieval agents are activated for incoming queries. To enable joint training under such heterogeneous and asynchronous settings, we model the entire construction and retrieval pipeline of the multi-agent memory system as a sequential Markov Decision Process (MDP)
(\mathcal{S},\mathcal{A},T,R)
, where each step is executed by a heterogeneous agent.
Formally, let
\pi_{\theta}^{0}=\pi_{\theta}^{\text{cons}_{f}}
,
\pi_{\theta}^{1}=\pi_{\theta}^{\text{cons}_{c}}
,
\pi_{\theta}^{2}=\pi_{\theta}^{\text{ret}}
denote the policies at step
n=1,2,3
, respectively.
Then, for each MDP trajectory
\tau
, we have:

•

\mathcal{S}
: State space, capturing the system state at each step in the MDP. Specifically,
s_{0}=\mathcal{H}
denotes the Extraction Agent’s initial state of raw conversational history
\mathcal{H}
.
s_{1}=\mathcal{M}_{f}
denotes the Profile Agent’s state, where
\mathcal{M}_{f}
is the fine-grained memory extracted by the prior Extraction Agent.
s_{2}=(\mathcal{M},q)
denotes the Retrieval Agent’s state, with
\mathcal{M}=\{\mathcal{M}_{f},\mathcal{M}_{c}\}
as the multi-granular memory set and
q
as the incoming user query.
s_{3}=(\mathcal{E}_{q}^{\prime},p)
denotes the system’s final state, comprising retrieved information
\mathcal{E}_{q}
and generated response
p
.

•

\mathcal{A}
: Action space, defining executable actions of each heterogeneous agent in the MDP. Specifically,
a_{0}
denotes extracting fine-grained memory by the Extraction Agent.
a_{1}
denotes abstracting coarse-grained memory by the Profile Agent.
a_{2}
denotes the Retrieval Agent’s action, which involves retrieving top-
k
relevant memories and generating a personalized response.

•

T
: State transition function, where
s_{n+1}=T(s_{n},a_{n})
and
a_{n}=\pi_{\theta}^{n}(s_{n})
. Specifically, the Extraction Agent transitions to the Profile Agent via
s_{1}=T(s_{0},a_{0})
and
a_{0}=\pi_{\theta}^{0}(\mathcal{H})
; the Profile Agent then transitions to the Retrieval Agent through
s_{2}=T(s_{1},a_{1})
and
a_{1}=\pi_{\theta}^{1}(\mathcal{M}_{f})
; finally, the Retrieval Agent produces the system’s final state
s_{3}=T(s_{2},a_{2})
where
a_{2}=\pi_{\theta}^{2}(\mathcal{M},q)
.

•

R
: Reward function, quantifying the rewards of agent actions in the MDP. As detailed in Sec
4.1
, the local task rewards for each step are
r_{0}=r_{\text{cons}_{f}}
for the Extraction Agent,
r_{1}=r_{\text{cons}_{c}}
for the Profile Agent, and
r_{2}=r_{\text{ret}}
for the Retrieval Agent. And, the global system reward is defined as
r_{3}=r_{\text{ans}}
.

Within this formulation, CoMAM embeds inter-agent dependencies into state transitions along the optimization trajectory. The multi-agent memory system operates sequentially to generate local and global rewards, enabling end-to-end RL optimization with simultaneous updates of heterogeneous policies.
The task-specific capabilities and inter-agent dependencies learned in this MDP enable agents to perform well in more complex inference environments, where divergent operating frequencies demand enhanced collaboration.

4.3
Adaptive Credit Assignment Mechanism

To align local improvements with global performance during joint optimization, we propose an adaptive credit assignment mechanism to allocate global system rewards to local agents. Instead of assigning global rewards equally to each agent
(
Hong et al. 2025
;
Zhao et al. 2026
)
, CoMAM quantifies agents’ varying contributions to the system and treats them as adaptive weights for allocation.

Formally, for each input
(\mathcal{H},q)
, we sample a group of MDP trajectories
\{\tau_{i}\}_{i=1}^{G}
, collecting the local rewards for each agent
n
,
\mathcal{R}_{\text{local},n}=\{r_{n}^{(i)}\}_{i=1}^{G}
, and the corresponding global rewards,
\mathcal{R}_{\text{global}}=\{r_{3}^{(i)}\}_{i=1}^{G}
, where
n\in\{0,1,2\}
.

To quantify agent
n
’s contribution to the memory system, we compute the ranking consistency score between
\mathcal{R}_{\text{local},n}
and
\mathcal{R}_{\text{global}}
using the Normalized Discounted Cumulative Gain (NDCG) metric.
Specifically, the NDCG-based consistency score for agent
n
is defined as:

\displaystyle v_{n}=\text{NDCG}(\sigma(\mathcal{R}_{\text{local},n}),\sigma(\mathcal{R}_{\text{global}})),

(13)

where the global reward ranking
\sigma(\mathcal{R}_{\text{global}})
serves as the ideal ranking for the local reward ranking
\sigma(\mathcal{R}_{\text{local},n})
.
We then normalize
v_{n}
to obtain adaptive credit weights
w_{n}
that satisfy
\sum_{n}w_{n}=1
:

\displaystyle w_{n}=\frac{\exp(v_{n})}{\sum_{n^{\prime}}\exp(v_{n^{\prime}})}.

(14)

The final optimization signal for agent
n
is the combination of its local rewards and allocated global credit, weighted by the adaptive weight
w_{n}
:

\displaystyle r_{\text{final},n}^{(i)}=r_{n}^{(i)}+w_{n}\cdot r_{3}^{(i)}.

(15)

After the adaptive credit assignment, we apply the GRPO algorithm (as defined in Sec
3.2
) on each agent based on the integrated rewards
r_{\text{final}}
. Formally, the objective function for the agent
n
is defined as:

\displaystyle\mathcal{J}_{GRPO}\left(\pi_{\theta}^{n}\right)=

(16)

\displaystyle\frac{1}{G}\sum_{i=1}^{G}\min\left[\rho_{n}^{(i)}A_{n}^{(i)},\;\text{clip}\left(\rho_{n}^{(i)},\;1\pm\epsilon\right)A_{n}^{(i)}\right],

where
\rho_{n}^{(i)}=\frac{\pi_{\theta}^{n}\left(a_{n}^{(i)}\mid s_{n}^{(i)}\right)}{\pi_{\theta_{\text{old}}}^{n}\left(a_{n}^{(i)}\mid s_{n}^{(i)}\right)}
is the importance sampling
ratio, the advantage
A_{n}^{(i)}
for each agent’s action
a_{n}^{(i)}
is computed by normalizing its reward
r_{\text{final},n}^{(i)}
. By optimizing each agent with both local task-specific rewards and allocated global system rewards, we can align local improvements with global performance and foster collaboration.

Experimental Settings

Dataset

We conduct experiments on the PersonaMem benchmark
(
Jiang et al. 2025
)
, a large-scale dataset including over 180 long-term user-LLM interaction histories and about 6,000 multiple-choice questions as subsequent queries. The benchmark is split into three experimental settings with varying history lengths (
i.e.,
32K, 128K, and 1M tokens), each paired with subsequent queries spanning seven distinct types: (1) Recall user-shared facts, (2) Suggest new ideas, (3) Acknowledge latest user preferences, (4) Track full preference evolution, (5) Revisit reasons for preference updates, (6) Provide preference-aligned recommendations, and (7) Generalize to new scenarios. Compared to existing benchmarks
(
Maharana et al. 2024
;
Wu et al. 2025
)
, PersonaMem’s strengths in long context history and personalized query type enable rigorous assessment of memory systems in personalized conversational scenarios. Dataset processing details are provided in Appendix
B.1
.

Baselines

We conduct a comprehensive evaluation of CoMAM against multiple leading baselines, including methods without a memory system “No memory”, methods of building memory systems via dedicated prompts “Prompt-based memory”, and methods of optimizing the memory systems with RL “RL-based memory”. Detailed introductions and implementations of baselines are provided in Appendix
B
.

•

“Base” represents directly injecting raw conversations as LLMs’ input for query answering; RAG
(

)

•

To verify the necessity and contribution of the three core agents (Extraction Agent, Profile Agent, and Retrieval Agent), we designed targeted ablation experiments, with results presented in Table

We further evaluate the training efficiency of CoMAM by comparing the convergence steps of joint optimization and independent optimization across 32K, 128K, and 1M context length settings, with results presented in Table

Conclusion

In this paper, we propose CoMAM, a collaborative reinforcement learning framework for jointly optimizing agents in personalized memory systems. It tackles the issue that independent agent optimization can not ensure global system performance without cross-agent collaboration.
To enable joint optimization, we regularize the asynchronous executions of heterogeneous agents as a sequential MDP, which embeds
inter-agent dependencies into state transitions and yields both local and global rewards. To align local improvement with global performance, we introduce an adaptive credit assignment mechanism that allocates global rewards to individual agents based on group-level ranking consistency between global and local rewards.
Experiments on long-term personalized conversational benchmarks demonstrate that CoMAM outperforms leading memory baselines, validating the effectiveness of our collaborative RL framework. The limitation is discussed in Appendix
E
.

Details of Experimental Settings

B.1
Dataset

In the PersonaMem benchmark, each interaction history consists of 10, 20, or 60 multi-turn sessions (corresponding to 32k, 128k, or 1M tokens) to form varying context lengths. Each session contains 15–30 conversation turns, designed to naturally reveal or update user preferences. In addition, each history is paired with a suite of subsequent queries across seven types, enabling comprehensive evaluation of personalized response capabilities.
For PersonaMem’s three context length settings (32k, 128k, and 1M tokens), we partition their training and validation sets based on these queries. The statistical breakdown of training and validation queries is summarized in Table
6
.

To process the training set, we first identify the specific session within the full conversational history that contains explicit evidence relevant to each query
q
, and we define this session as the query’s targeted conversational history
\mathcal{H}
. We then construct
(\mathcal{H},q)
data pairs required for generating individual MDP trajectories as the core training data. The position of each target session within the complete interaction history is specified in the original benchmark. Ground-truth evidence
\mathcal{E}_{q}
for each query
q
is extracted using the Seed-1.6 model and validated through human evaluation. For evaluation, multiple distinct queries may share the same full conversational history that includes multiple sessions. This design enables further evaluation in complex inference scenarios where memory construction agents operate on a full conversational history with multiple sessions, while retrieval agents are activated for subsequent queries at varying frequencies.

Joint optimization with adaptive credit assignment not only enhances global system performance but also promotes the specialization of each agent’s local tasks. As illustrated in Figure

Appendix D
Discussion

D.1
Difference with existing memory framework

Existing memory systems and our CoMAM differ fundamentally in optimization paradigm and reward design:

•

Optimization Paradigm:
Independent Optimization vs. Joint Optimization

Existing frameworks primarily adopt independent optimization. For example, MIRIX
(
Wang & Chen 2025
)
designs a meta-agent and six specialized agents for memory management, optimizing each via tailored prompts; Memagent
(
Yu et al. 2026
)
focuses on a single retrieval agent, training it with query-answer accuracy as the reward; Memory-R1
(
Yan et al. 2025b
)
splits the system into a Memory Manager and Answer Agent, training them in separate stages—first optimizing the Manager with the Agent frozen, then freezing the Manager to optimize the Agent. This approach ignores inter-agent collaboration: memory construction is not adjusted based on retrieval needs, and the Agent can only adapt to a fixed Manager’s output, leading to “local optimal but global suboptimal” outcomes.

CoMAM proposes end-to-end joint optimization via MDP regularization. We model the asynchronous execution of Extraction, Profile, and Retrieval Agents as a sequential MDP trajectory, where each agent’s output directly serves as the next agent’s input. All three agents are updated simultaneously during training, with inter-agent dependencies embedded into state transitions, ensuring they evolve collaboratively toward the global goal of query-answer accuracy.

•

Reward Design:
Single Global Reward vs. Adaptive Credit Assignment

Existing frameworks that optimize memory agents with RL primarily rely solely on final query-answer accuracy as the reward for all agents. For example, Mem-
\alpha
and Mem1
(
Zhou et al. 2026
)
use this single reward to train construction and retrieval agents respectively.
Memory-R1
(
Yan et al. 2025b
)
and GAM
(
Yan et al. 2025a
)
also adopt this design, using only answer accuracy to optimize their agents separately. This ambiguous credit assignment prevents agents from distinguishing their individual contributions, leading to unstable convergence.

CoMAM introduces adaptive integration of local and global rewards. We design task-specific local rewards (e.g., Extraction Agent’s information coverage, Profile Agent’s abstraction rationality, Retrieval Agent’s retrieval precision) and combine them with the global reward (answer accuracy). Using NDCG to quantify the ranking consistency between each agent’s local rewards and the global reward, we dynamically allocate global credit based on this consistency. This ensures agents are rewarded both for excelling at their local tasks and contributing to global performance, avoiding ambiguous optimization.

D.2
Difference with existing multi-agent system RL

•

Heterogeneous Policy vs. Homogeneous Policy
: Some multi-agent reinforcement learning (RL) methods adopt a shared policy across all agents. For instance, CORY
(
Ma et al. 2024
)
proposes an RL framework featuring “Pioneer” and “Observer” agents that share a single policy model. These agents co-evolve through multi-agent collaboration and periodic role-swapping. In contrast, considering the heterogeneity and asynchrony of a memory system, CoMAM employs heterogeneous policies tailored to distinct agents.

•

Workflow: Sequential vs. Concurrent
: Existing multi-agent system (MAS) methods often adopt a debate-style pipeline for reasoning tasks, such as math tasks. For instance, MAPoRL
(
Park et al. 2025
)
models agent interactions as concurrent debate, where multiple agents generate responses in parallel, focusing on persuasive collaboration for general reasoning. In contrast, CoMAM explicitly formulates agents’ executions as a sequential Markov Decision Process (MDP), embedding inter-agent dependencies into state transitions, ensuring that memory construction quality dynamically adapts to retrieval requirements and vice versa.

•

Collaboration Paradigm: Joint Optimization vs. Independent Alignment
:
Existing methods, such as Optimas
(
Wu et al. 2026
)
, foster collaboration by aligning local rewards with global objectives via heuristic reward shaping for compound AI systems. However, it optimizes individual agents separately, leveraging locally-global aligned rewards rather than through end-to-end joint training. In contrast, CoMAM adopts a joint optimization paradigm: it regularizes the asynchronous execution of heterogeneous agents into a sequential MDP trajectory and updates all agents simultaneously.

•

Credit Assignment: Adaptive Assignment vs. Equal Allocation
: Most existing systems use static credit assignment mechanisms without quantifying agents’ varying contributions: AT-GRPO
(
Zhao et al. 2026
)
distributes rewards equally across agents using fixed weights, ignoring task differences; CoMAS
(
Xue et al. 2026
)
adopts a zero-sum adversarial reward scheme that pits agents against each other, which is misaligned with the cooperative nature of memory systems; In contrast, CoMAM’s credit assignment is grounded in group-level ranking consistency (NDCG) between each agent’s local task rewards (
e.g.,
coverage for extraction, rationality for profiling, precision for retrieval) and the global system reward (query-answer accuracy). This design quantifies each agent’s contribution to the global system. It dynamically adjusts weights according to agent performance, ensuring adaptive credit allocation that aligns local improvements with global performance.

Appendix E
Limitation

While CoMAM enables effective joint optimization for multi-agent memory systems, it is worth noting that our current implementation focuses on verifying the core logic of collaborative RL, with certain extended capabilities reserved for future exploration to better adapt to more complex scenarios.

1. Limited Agent Task Scope:

The framework currently leverages a compact agent set (Extraction, Profile, Retrieval) to focus on verifying the efficacy of collaborative RL for personalized memory tasks. To prioritize the core verification goal, we reserve extended agent capabilities (such as memory modification for consistency maintenance and redundant memory deletion) for future work.

2. Static MDP Regularization for Training:

Current MDP regularization models agent execution as a static sequential trajectory, enabling joint training of heterogeneous and asynchronous agents. Compared with the existing independent optimization training paradigm, this design can better enhance the collaborative capabilities of agents beyond task-specific capabilities. While effective in boosting inter-agent collaboration, we can further consider the dynamic deployment of agents in real-world scenarios, such as dynamic invocation frequencies and real-time memory updates. Future work will integrate these real-world dynamics into the joint training process to improve the consistency between training and deployment.

3. Lack of Explicit local-local Alignment:

The adaptive credit assignment is specifically designed to align local agent improvements with global system goals, enabling agents’ collaboration towards the global goal. Since all agents’ local subtasks are oriented towards the consistent global system goal, the alignment between their local tasks is implicitly modeled. In the future, we will explore explicitly modeling this local-local alignment for agents’ local subtasks, which will further boost inter-agent collaboration.
