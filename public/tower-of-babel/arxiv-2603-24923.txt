Normal forms in cubical type theory
Xu Huang

Abstract
. This note documents the specification of normal forms in cubical type theory. The definition is already present in the proof of normalization for cubical type theory [ 6 , 8 ] , but we present it in a more traditional style explicitly for reference.



1
Introduction

Cubical type theory is an extension of Martin-Löf type theory
that supports Voevodsky’s
univalence axiom
,
and the notion of
higher inductive types
,
while maintaining nice syntactic properties such as normalization.

To achieve this, cubical type theory introduces a lot of judgmental equalities
that makes it non-trivial to extend traditional normalization proofs.
The language of
synthetic Tait computability

[
7
]

is introduced with the purpose of organizing the cubical normalization proof,
given by
6
, and elaborated by
8
.

While this language makes it more practical to construct and verify the proof,
it may still be of value to write down at least the definition of normal forms
in cubical type theory using a more traditional syntax.
It may also serve as a bridge for readers to understand synthetic Tait computability.

We will be considering Cartesian (a.k.a. ABCFHL) cubical type theory
[
1
]
,
following the presentation by
8
,
although it can be adapted to de Morgan (a.k.a. CCHM) type theory
[
2
]
.
All bold section numbers such as
(0.3*3)
refer to
8
.

2
Martin-Löf type theory

We begin by discussing the normal forms in Martin-Löf type theory.
Recall the syntax of Martin-Löf type theory defines
a set of contexts
\mathrm{Ctx}
,
a set of types
\mathrm{Tp}(\Gamma)
for each context
\Gamma\in\mathrm{Ctx}
,
and a set of terms
\mathrm{Tm}(\Gamma,A)
for each context
\Gamma\in\mathrm{Ctx}
and type
A\in\mathrm{Tp}(\Gamma)
,
considered up to judgmental equality.
We conventionally write elements of these sets using turnstiles, a.k.a. sequents:

\Gamma\in\mathrm{Ctx}

\iff

\Gamma\vdash

A\in\mathrm{Tp}(\Gamma)

\iff

\Gamma\vdash A\;\mathsf{type}

t\in\mathrm{Tm}(\Gamma,A)

\iff

\Gamma\vdash t:A

The definition usually proceeds by a collection of inference rules,
which can be seen as a kind of quotient inductive definition.

Remark 1
.

3
proposes a framework to define type theories
where the notion of contexts is demoted as secondary.
It greatly simplifies the presentation of a large class of type theories,
and is in fact used in the normalization proof.
See
\hyper@link
citecite.sterling:2021:thesis
(Ch. 1)
for an exposition.

In older literature, normal forms are sometimes defined as expressions
with no applicable reduction rules.
However, this definition is often unsuitable in type theories with
\eta
laws,
and certainly unsuitable for cubical type theory, where a lot of equations are
hard to orient as reduction rules.
(See
\hyper@link
citecite.sterling:2021:thesis
(§6.5.1)
for a discussion on its problems.)
Instead, normal forms are defined inductively for each type,
and mutually recursively with another set called
neutral forms
.

Our goal is to define sets
\mathrm{Tm}_{\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}(\Gamma,A)
of normal terms
and
\mathrm{Tp}_{\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}(\Gamma)
of normal types,
where
\Gamma\in\mathrm{Ctx}
and
A\in\mathrm{Tp}(\Gamma)
.
Note that the type for a normal term is a general type.
We will simultaneously define the set of neutral terms
\mathrm{Tm}_{\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}(\Gamma,A)

and types
\mathrm{Tp}_{\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}(\Gamma)
.
We similarly write

A\in\mathrm{Tp}_{\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}(\Gamma)

\iff

\Gamma\vdash A\;\mathsf{type}\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}

A\in\mathrm{Tp}_{\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}(\Gamma)

\iff

\Gamma\vdash A\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}

t\in\mathrm{Tm}_{\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}(\Gamma,A)

\iff

\Gamma\vdash t:A\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}

t\in\mathrm{Tm}_{\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}(\Gamma,A)

\iff

\Gamma\vdash t:A\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}

These are also given by a quotient inductive definition,
but the difference is that the equations over normal forms and neutral forms
are much simpler than that of terms and types,
so that determining whether two normal forms are equal is straightforward.
In many cases, there are no equations imposed at all
(apart from
\alpha
equivalence, if the presentation uses named variables).

Neutral and normal forms come equipped with inclusion functions into
ordinary terms and types
\mathrm{Tm}_{\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}(\Gamma,A)\hookrightarrow\mathrm{Tm}(\Gamma,A)
etc.
In most cases, the definition for this function will be obvious.
We will also implicitly apply this function when we e.g. use a normal term
in a place where a term is expected.

We now begin to give the inductive definition of normal and neutral forms,
which is a transcription of
\hyper@link
citecite.sterling:2021:thesis
(§5.4.1)
.

\frac{\Gamma\vdash x:A\;\mathsf{\color[rgb]{0.5,0.5,0.5}var}}{\Gamma\vdash x:A\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}\qquad\frac{\Gamma\vdash A\;\mathsf{type}\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}\Gamma\vdash t:A\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}{\Gamma\vdash t:A\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\qquad\frac{\Gamma\vdash A\;\mathsf{type}\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}{\Gamma\vdash A\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}

(
\star
)

Strictly speaking, these rules define conversion functions from
variables to neutral forms, and from neutral forms to normal forms, respectively.
If we denote the functions as
\operatorname{\uparrow}
,
then the conclusions of the inference rules should be written as

\Gamma\vdash\operatorname{\uparrow}x:A\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}
and
\Gamma\vdash\operatorname{\uparrow}t:A\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}
, etc.
In most presentations, this conversion is left implicit,
although we shall see that it is not the case for cubical type theories.

2.1
\Pi
-types

The rules for
\Pi
-types in MLTT reads

\frac{\Gamma\vdash A\;\mathsf{type}\Gamma,x\mathbin{:}A\vdash B\;\mathsf{type}}{\Gamma\vdash(x:A)\to B\;\mathsf{type}}\\
\frac{\Gamma,x\mathbin{:}A\vdash t:B}{\Gamma\vdash\lambda x\mathpunct{.}t:(x:A)\to B}\frac{\Gamma\vdash f:(x:A)\to B\Gamma\vdash t:A}{\Gamma\vdash f\,t:B[t/x]}\\
\text{($\beta,\eta$ rules omitted)}

Generally speaking, each introduction rule corresponds to a rule for normal forms,
while each elimination rule corresponds to a rule for neutral forms.

\frac{\Gamma\vdash A\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}\Gamma,x\mathbin{:}A\vdash B\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}{\Gamma\vdash(x:A)\to B\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\\
\frac{\Gamma,x\mathbin{:}A\vdash t:B\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}{\Gamma\vdash\lambda x\mathpunct{.}t:(x:A)\to B\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\frac{\Gamma\vdash f:(x:A)\to B\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}\Gamma\vdash t:A\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}{\Gamma\vdash f\,t:B[t/x]\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}

As a reminder,
\Gamma\vdash t:A\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}
does not presuppose
A
is in normal form.
It only requires
\Gamma\vdash A\;\mathsf{type}
to hold.

2.2
\Sigma
-types

The rules for
\Sigma
-types in MLTT reads

\frac{\Gamma\vdash A\;\mathsf{type}\Gamma,x\mathbin{:}A\vdash B\;\mathsf{type}}{\Gamma\vdash(x:A)\times B\;\mathsf{type}}\\
\frac{\Gamma\vdash a:A\Gamma\vdash b:B[a/x]}{\Gamma\vdash(a,b):(x:A)\times B}\frac{\Gamma\vdash p:(x:A)\times B}{\Gamma\vdash\pi_{1}(p):A\Gamma\vdash\pi_{2}(p):B[\pi_{1}(p)/x]}\\
\text{($\beta,\eta$ rules omitted)}

To save space, we write multiple conclusions for an inference rule
to mean multiple inference rules with the same premises.

\frac{\Gamma\vdash A\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}\Gamma,x\mathbin{:}A\vdash B\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}{\Gamma\vdash(x:A)\times B\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\frac{\Gamma\vdash a:A\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}\Gamma\vdash b:B[a/x]\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}{\Gamma\vdash(a,b):(x:A)\times B\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\frac{\Gamma\vdash p:(x:A)\times B\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}{\Gamma\vdash\pi_{1}(p):A\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}\Gamma\vdash\pi_{2}(p):B[\pi_{1}(p)/x]\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}

2.3
Boolean type

The rules for the Boolean type
\boldsymbol{2}
are given by

\frac{}{\Gamma\vdash\boldsymbol{2}\;\mathsf{type}}\frac{}{\Gamma\vdash\mathrm{true}:\boldsymbol{2}}\frac{}{\Gamma\vdash\mathrm{false}:\boldsymbol{2}}\frac{\Gamma,x\mathbin{:}\boldsymbol{2}\vdash P\;\mathsf{type}\Gamma\vdash b:\boldsymbol{2}\Gamma\vdash t:P[\mathrm{true}/x]\Gamma\vdash f:P[\mathrm{false}/x]}{\Gamma\vdash\mathrm{if}_{x\mathpunct{.}P}(b,t,f):P[b/x]}\text{($\beta$ rule omitted)}

which corresponds to the following rules for normal and neutral forms:

\frac{}{\Gamma\vdash\boldsymbol{2}\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\frac{}{\Gamma\vdash\mathrm{true}:\boldsymbol{2}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\frac{}{\Gamma\vdash\mathrm{false}:\boldsymbol{2}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\frac{\Gamma,x\mathbin{:}\boldsymbol{2}\vdash P\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}\Gamma\vdash b:\boldsymbol{2}\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}\quad\Gamma\vdash t:P[\mathrm{true}/x]\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}\Gamma\vdash f:P[\mathrm{false}/x]\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}{\Gamma\vdash\mathrm{if}_{x\mathpunct{.}P}(b,t,f):P[b/x]\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}

However, since the Boolean type doesn’t have an
\eta
law,
we also include a rule to convert neutral terms into normal terms.

\frac{\Gamma\vdash b:\boldsymbol{2}\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}{\Gamma\vdash b:\boldsymbol{2}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}.

Again, strictly speaking the conclusion should read
\Gamma\vdash\operatorname{\uparrow}b:\boldsymbol{2}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}
,
but the inclusion function is usually suppressed.

2.4
Universes

There are several different presentations for universes.
We will consider Coquand universes and ignore size issues,
but it is straightforward to deal with other formulations.

\frac{}{\Gamma\vdash\mathcal{U}\;\mathsf{type}}\frac{\Gamma\vdash C:\mathcal{U}}{\Gamma\vdash\operatorname{El}(C)\;\mathsf{type}}\frac{\Gamma\vdash A\;\mathsf{type}}{\Gamma\vdash\left\lceil A\right\rceil:\mathcal{U}}\\
\frac{\Gamma\vdash C:\mathcal{U}}{\Gamma\vdash\left\lceil\operatorname{El}(C)\right\rceil=C:\mathcal{U}}\frac{\Gamma\vdash A\;\mathsf{type}}{\Gamma\vdash\operatorname{El}\left\lceil A\right\rceil=A\;\mathsf{type}}

Here,
\operatorname{El}
acts as the eliminator for
\mathcal{U}
,
while
\left\lceil-\right\rceil
acts as the constructor.
In a consistent type theory using Coquand universes,
the type judgments would be indexed by universe levels
\Gamma\vdash A\;\mathsf{type}_{i}

so that not every type has a code in the universe.

\frac{}{\Gamma\vdash\mathcal{U}\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\frac{\Gamma\vdash C:\mathcal{U}\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}{\Gamma\vdash\operatorname{El}(C)\;\mathsf{type}\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}\frac{\Gamma\vdash A\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}{\Gamma\vdash\left\lceil A\right\rceil:\mathcal{U}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}

In a Tarski universe, instead of having a single
\left\lceil-\right\rceil
constructor,
we have a series of codes for each type connective that the universe is closed under.
There is then a “
\beta
equality” stating that
\operatorname{El}
turns these codes
into the actual type connectives,
and there is no
\eta
equality.
Thus, similar to Boolean types, Tarski universes have the rule

\frac{\Gamma\vdash C:\mathcal{U}\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}{\Gamma\vdash C:\mathcal{U}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}},

while Coquand universes do not.

3
Cubical type theory

In general, neutral forms in Martin-Löf type theory are given by
a stack of eliminators nested on the primary argument,
often referred to as the spine.
The innermost expression is a variable of some type without
\eta
laws, such as the Booleans.
Computationally, a neutral form is
stuck
on this variable,
and the computation can only proceed when the value for this variable is known.

The situation is drastically different for cubical type theory.
Here, the path type between two elements acts as a function type from the interval
\mathbb{I}
,
which has two endpoints
0,1:\mathbb{I}
.
If
p:\mathrm{Path}_{A}(x,y)
,
then
p(0)
is supposed to be judgmentally equal to
x
, and
p(1)
to
y
.
Looking at the rules for function types,
we are tempted to say if
p
is neutral, then
p(i)
should also be neutral.
However, even when
p
is a variable,
p(0)
still computes to
x
,
despite being nominally stuck on
p
!
See
Remark

5
for why this is a problem in the proof of normalization.

For this reason, the definition for neutral forms are greatly complicated.
Instead of defining a set of neutral forms
\mathrm{Tm}_{\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}(\Gamma,A)
for each
\Gamma
and
A
,
we introduce a third parameter
\mathrm{Tm}_{\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}^{{\color[rgb]{0,0.5,0.1}\varphi}}(\Gamma,A)
,
where
{\color[rgb]{0,0.5,0.1}\varphi}
records the condition when the neutral term becomes
unstable and “decays” into some other potentially unrelated term.

{\color[rgb]{0,0.5,0.1}\varphi}
is called the
frontier of instability
,
and the sequent notation for
t\in\mathrm{Tm}_{\mathsf{\color[rgb]{0.8,0.3,0.1}ne}}^{{\color[rgb]{0,0.5,0.1}\varphi}}(\Gamma,A)

is written
\Gamma\vdash t:A\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}^{{\color[rgb]{0,0.5,0.1}\varphi}}
.

Before we actually define
{\color[rgb]{0,0.5,0.1}\varphi}
, it should be clear that
the type connectives from Martin-Löf type theory can simply leave this parameter alone.
For example, the rules for
\Pi
-types (
Section

2.1
) become

\frac{\Gamma\vdash A\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}\Gamma,x\mathbin{:}A\vdash B\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}{\Gamma\vdash(x:A)\to B\;\mathsf{type}\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\\
\frac{\Gamma,x\mathbin{:}A\vdash t:B\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}{\Gamma\vdash\lambda x\mathpunct{.}t:(x:A)\to B\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}\frac{\Gamma\vdash f:(x:A)\to B\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}^{{\color[rgb]{0,0.5,0.1}\varphi}}\Gamma\vdash t:A\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}{\Gamma\vdash f\,t:B[t/x]\;\mathsf{\color[rgb]{0.8,0.3,0.1}ne}^{{\color[rgb]{0,0.5,0.1}\varphi}}}

Hence most of the rules can be straightforwardly adjusted.
Notable exceptions include rules that turn a neutral form into a normal form,
which we will address later.

3.1
Interval and cofibrations

In cubical type theory, the contexts can contain
interval variables

i:\mathbb{I}
, that intuitively represent the coordinates
in an
n
-dimensional cube
[0,1]^{n}
.
However, it should be noted that the interval is not a type,
in the sense that we do not have any element
\mathbb{I}\in\mathrm{Tp}(\Gamma)
,
and it is not valid to write
\mathrm{Tm}(\Gamma,\mathbb{I})
.
Instead, we introduce a separate family of sets
\mathrm{Tm}_{\mathbb{I}}(\Gamma)

of interval expressions in a given context,
1
1

1

However, an element
i\in\mathrm{Tm}_{\mathbb{I}}(\Gamma)

is still written as
\Gamma\vdash i:\mathbb{I}
in the sequent notation.

and a separate context extension operation
\Gamma,i\mathbin{:}\mathbb{I}
.

There are multiple reasons for this distinction.
One is that the interval should not participate in any type formers,
so for example we cannot have functions
f:\mathbb{N}\to\mathbb{I}
which
easily make type-checking undecidable.
Another reason is the interval is not Kan,
i.e. we cannot define a composition structure (
Section

3.4
) on it,
and it cannot be interpreted semantically as a space.

Remark 2
.

In Cartesian cubical type theory, the only structures we assume on the interval
is the endpoints
0,1:\mathbb{I}
.
So an expression
\Gamma\vdash r:\mathbb{I}

is essentially either an interval variable
i\in\Gamma
, or an endpoint
0,1
.
The situation is more complicated in de Morgan cubical type theory.

To specify portions of a cube, we introduce judgments

\Gamma\vdash\varphi\;\mathsf{cof}\qquad\Gamma\vdash\varphi\;\mathsf{true},

where the former states that

\varphi
is a formula that is true on the specified portion,
and the latter states the formula is actually true.
We allow contexts to be extended by an assumption of
\varphi
,
written
\Gamma,\varphi
.
These formulas are called
cofibrations
,
because they semantically represent inclusions
\Gamma,\varphi\hookrightarrow\Gamma

that are intended to act as cofibrations in homotopy theory.

Note that we do not have terms witnessing the proof of
\Gamma\vdash\varphi\;\mathsf{true}
,
nor do we assign variable names to the assumptions
\Gamma,\varphi\vdash J
.
The type-checker needs to determine the truth of cofibration formulas automatically.
The cofibrations belong to sets
\varphi\in\operatorname{Cof}(\Gamma)
,
and we can consider the true cofibrations as a subset.
Alternatively, we can consider a family of sets
\operatorname{True}(\Gamma,\varphi)

such that every pair of elements
u,v\in\operatorname{True}(\Gamma,\varphi)
are equal.
Then
\Gamma\vdash\varphi\;\mathsf{true}
if and only if

\operatorname{True}(\Gamma,\varphi)
contains a (necessarily unique) element.

In Cartesian cubical type theory, the cofibrations can either be
an atomic cofibration, or finite conjunctions and disjunctions of cofibrations.
An atomic cofibration is given by
(r=s)
where
\Gamma\vdash r,s:\mathbb{I}
,
and it is true when
r
is in fact equal to
s
.
Conjunctions hold if and only if each component holds,
and we have the nullary conjunction
\Gamma\vdash\top\;\mathsf{cof}
.
Disjunctions are slightly trickier.

Similar to the disjoint union type, disjunctions have introduction rules

\frac{\Gamma\vdash\varphi\;\mathsf{true}}{\Gamma\vdash\varphi\vee\psi\;\mathsf{true}}\frac{\Gamma\vdash\psi\;\mathsf{true}}{\Gamma\vdash\varphi\vee\psi\;\mathsf{true}}

The elimination rule for disjunctions is given by a case split.
Whenever
\Gamma\vdash\varphi\vee\psi\;\mathsf{true}

and some expression is expected, we can instead write

\begin{cases}\varphi\hookrightarrow M\\
\psi\hookrightarrow N\end{cases}\quad\text{or}\quad[\varphi\hookrightarrow M;\psi\hookrightarrow N].

Naturally, if
\varphi
is true, then this expression is equal to
M
, and similarly for
\psi
.
Since cofibrations are proof irrelevant, the case split is only allowed
when
M=N
judgmentally if
\varphi
and
\psi
happen to both hold.

This construction is stronger than the rule for the disjoint union type in two ways.
One is that the case split can happen anywhere,
in types, terms, interval expressions, cofibrations,
and (irrelevant) proofs of cofibrations.
Another difference is we require a form of
\eta
law to hold for these case splits.
If
\Gamma,\varphi\vee\psi\vdash t:A
,
then
t
is judgmentally equal to a case split

[\varphi\hookrightarrow t;\psi\hookrightarrow t]
.

Remark 3
.

Many implementations restrict the places a cofibration case split can occur,
to simplify the syntax and type-checking.
We follow the definition of
8
,
which includes these case splits, see
\hyper@link
citecite.sterling:2021:thesis
(6.2*14)
,
\hyper@link
citecite.sterling:2021:thesis
(6.4*1)
.

For the nullary disjunction
\bot
, we have no introduction rules,
and the elimination rule is given by an empty case split
[]
,
which means for example
\mathrm{Tm}((\Gamma,\bot),A)
always have an element
[]
.
Furthermore, the
\eta
law demands that every element is equal to
[]
,
which means every judgmental equality holds when
\Gamma\vdash\bot\;\mathsf{true}
.

We additionally require cofibrations to satisfy an extensionality rule

\frac{\Gamma,\varphi\vdash\psi\;\mathsf{true}\Gamma,\psi\vdash\varphi\;\mathsf{true}}{\Gamma\vdash\varphi=\psi\;\mathsf{cof}}

So for example
\varphi\wedge\psi
is interchangeable with
\psi\wedge\varphi
,
and
(0=1)
is the same cofibration as
\bot
.
This implies in particular
the type-checker needs to decide the theory of distributive lattices.

3.2
Cofibration assumptions

Since case splits can occur anywhere within a term,
it poses a problem for normal forms.
For example, under the context
\Gamma,i\mathbin{:}\mathbb{I},(i=0)\vee(i=1)
,

f\left(\begin{cases}(i=0)\hookrightarrow s\\
(i=1)\hookrightarrow t\end{cases}\right)\quad\text{and}\quad\begin{cases}(i=0)\hookrightarrow f(s)\\
(i=1)\hookrightarrow f(t)\end{cases}

are judgmentally equal, if
f
is a function and
s,t
are terms.
To normalize this, we require case splits to always occur
up front

\hyper@link
citecite.sterling:2021:thesis
(7.1*4)
.
More generally, when a cofibration is about to be introduced into the context,
we require the normal form to completely decompose the cofibration,
so whenever we write
\Gamma\vdash t:A\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}
we can safely assume

\Gamma
does not actually contain any cofibration.

Concretely, we recursively define sets
[\varphi]\,\mathrm{Tm}_{\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}(\Gamma,A)
,
whose elements
t\in[\varphi]\,\mathrm{Tm}_{\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}(\Gamma,A)
will be written as

\Gamma,[\varphi]\vdash t:A\;\mathsf{\color[rgb]{0.2,0.4,0.9}nf}
.
In addition, we can convert
t
into a term
\Gamma,\varphi\vdash\operatorname{\uparrow}t:A
.
We will still suppress this conversion function, unless it causes confusion.
An element
t\in[\varphi]\,\mathrm{Tm}_{\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}(\Gamma,A)
is required to be a function

\varphi^{\prime}\mapsto t_{\varphi^{\prime}}
whose domain is a subset of
\operatorname{Cof}(\Gamma)
,
satisfying the following conditions.

•

t\in[\top]\,\mathrm{Tm}_{\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}(\Gamma,A)
iff its domain
\{\top\}
, and
t_{\top}\in\mathrm{Tm}_{\mathsf{\color[rgb]{0.2,0.4,0.9}nf}}(\Gamma,A)

Ordinary inductive types bifurcate into two variants in cubical type theory,
based on how
\operatorname{hcomp}
interacts with them.
One version has

schematically written as

\operatorname{hcomp}^{\varphi}_{r\rightsquigarrow s}(i\mathpunct{.}\mathrm{cons}(t))=\mathrm{cons}(\operatorname{hcomp}^{\varphi}_{r\rightsquigarrow s}(i\mathpunct{.}t))

This is valid because for inductive types,
different constructors are distinct,
and constructors are injective functions (or embeddings, homotopically speaking).
Therefore if argument of
\operatorname{hcomp}

defined in the context of
\varphi

evaluates to a constructor at any point in the cube,
then it has to evaluate to the same constructor everywhere,
and we can uniquely recover the arguments of the constructor.

The other version comes from considering inductive types as a special case
of higher inductive types, and directly copying their rules.
Crucially, it is possible for an expression

to be
a constructor when

, and a different one when

,
so

Instead, we consider

The composition structure on glue types (see
5
)
involves the universal quantification operation on cofibrations,
written
(\forall i\mathpunct{.}\varphi)
,
which holds if and only if
\varphi
holds regardless of
i
.

Fortunately, cubical type theories usually enjoy
a form of
quantification elimination

[
2
]
,
so
(\forall i\mathpunct{.}\varphi)
is equivalent to a cofibration not involving
\forall
.

•

The cofibration
\forall i\mathpunct{.}\varphi\wedge\psi
is
always equivalent to
(\forall i\mathpunct{.}\varphi)\wedge(\forall i\mathpunct{.}\psi)

by the inference rules.

•

If
\forall i\mathpunct{.}\varphi\vee\psi
is true,
then
(\forall i\mathpunct{.}\varphi)\vee(\forall i\mathpunct{.}\psi)
holds,
because it is impossible to cover an entire interval using two cofibrations,
unless one of them already covers the interval.

•

If
\forall i\mathpunct{.}(r=s)
is true,
we can remove the quantification if
r,s
don’t involve
i
,
and otherwise the cofibration must be equivalent to
\top
or
\bot
.

Hence, we can regard this operation as a syntactic transformation
on the meta-language level.

4
Equality on normal forms

There are many equality constructors in the quotient-inductive definition
of cubical normal forms,
so it is not entirely obvious that equality between normal forms are decidable.
Here we give a rough justification.
The equalities in normal forms fall into three classes:

•

For cleaning up destabilized neutrals, including stuck
\operatorname{hcomp}
and
\operatorname{coe}
;

•

For computing
\operatorname{hcomp}
terms on higher inductive types;

•

For the boundary of path constructors such as
\mathrm{loop}_{r}
.

However, we have carefully constructed these equations so there is
always a clear direction in which the complexity of (raw, unquotiented) terms decreases.
Therefore, it suffices to recursively rewrite using these equations.

The other source of non-trivial equalities in normal forms
is indirectly through interval and cofibration sub-expressions.
These are decidable using the theory of distributive lattices.

Remark 6
.

Deciding equality for normal forms has mostly theoretical value,
since practical implementations of type-checkers check for
judgmental equality directly on values,
which are essentially given by the computability structures in a normalization proof.
