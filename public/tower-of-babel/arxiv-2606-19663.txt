Counterexample to a conjecture on the pairwise independent correlation gap using AI
Arjun Ramachandra, Karthik Natarajan

Abstract
Aided by the AI tool GPT5.5 Pro, we provide a counterexample to a conjecture made by Ramachandra and Natarajan (2025) [Pairwise independent correlation gap, Operations Research Letters, 107255, 6040].



1
Introduction

Let
N
denote a ground set with
|N|=n
elements and
f:2^{N}\rightarrow\mathbb{R}_{+}
be a nonnegative set function. The function is submodular if
f(S)+f(T)\geq f(S\cap T)+f(S\cup T)
for all
S,T\subseteq N
or equivalently
f(S\cup\{i\})-f(S)\geq f(T\cup\{i\})-f(T)
for all
S\subseteq T
,
i\in N\backslash T.
The function is monotone (non-decreasing) if
f(S)\leq f(T)
for all
S\subseteq T
. The concave closure of the set function is given by
f^{+}:[0,1]^{n}\rightarrow\mathbb{R}_{+}
where
f^{+}(\mbox{\boldmath$x$})
is the maximum expected value of the function over all joint distributions of the elements where each
i\in N
is selected with probability
x_{i}
:

\begin{array}[]{rlllll}\displaystyle f^{+}(\mbox{\boldmath$x$})=\max\Big\{\sum_{S\subseteq N}\theta(S)f(S)\ \Big|\ \sum_{S\subseteq N:S\ni i}\theta(S)=x_{i},\forall i\in N,\\
\displaystyle\sum_{S\subseteq N}\theta(S)=1,\theta(S)\geq 0,\forall S\subseteq N\Big\}.\end{array}

(1)

The pairwise independent extension of the set function is given by
f^{++}:[0,1]^{n}\rightarrow\mathbb{R}_{+}
where
f^{++}(\mbox{\boldmath$x$})
is the maximum expected value of the function over all pairwise independent distributions where each element
i\in N
is selected with probability
x_{i}
:

\begin{array}[]{rlllll}\displaystyle f^{++}(\mbox{\boldmath$x$})=\max&\displaystyle\sum_{S\subseteq N}\theta(S)f(S)\\
\mbox{s.t}&\displaystyle\sum_{S\subseteq N:S\ni i,j}\theta(S)=x_{i}x_{j},&\forall i<j,i,j\in N\\
&\displaystyle\sum_{S\subseteq N:S\ni i}\theta(S)=x_{i},&\forall i\in N\\
&\displaystyle\sum_{S\subseteq N}\theta(S)=1&\\
&\theta(S)\geq 0,&\forall S\subseteq N.\end{array}

(2)

The pairwise independent correlation gap is defined as the ratio
{f^{+}(\mbox{\boldmath$x$})}/{f^{++}(\mbox{\boldmath$x$})}
. Here we cite directly from page 6 in
[
9
]
:

We end the paper with a conjecture and invite readers to prove or disprove the conjecture.

Conjecture 1

(Ramachandra and Natarajan
[
9
]
)
.

For any
n
, any nonnegative monotone submodular function
f:2^{N}\rightarrow\mathbb{R}_{+}
and any
\mbox{\boldmath$x$}\in[0,1]^{n}
:

\frac{f^{+}(\mbox{\boldmath$x$})}{f^{++}(\mbox{\boldmath$x$})}\leq\frac{4}{3}.

2
A counterexample

N=\{1,2,3,4,5\}
. Define a coverage function
f:2^{N}\to\mathbb{R}_{+}
over a universe of four features
\{A,B,C,D\}

\displaystyle E_{1}=\{A,B\},E_{2}=\{A,B,C,D\},E_{3}=\{C,D\},E_{4}=\{A,C\},E_{5}=\{B,D\}.

\displaystyle f(S)=\left|\cup_{i\in S}E_{i}\right|.

\displaystyle\mathbb{E}[\lambda(S)]={}

\displaystyle-(x_{1}x_{2}+x_{2}x_{3})-\frac{3}{2}(x_{2}x_{4}+x_{2}x_{5})+\frac{1}{2}(x_{1}x_{3}+x_{4}x_{5})

by substituting in the marginal probabilities, we get:

\mathbb{E}[\lambda(S)]=\frac{479}{160}.

Hence

f^{++}(\mbox{\boldmath$x$})\leq\frac{479}{160}.

Combining the two bounds,

\frac{f^{+}(\mbox{\boldmath$x$})}{f^{++}(\mbox{\boldmath$x$})}\geq\frac{4}{479/160}=\frac{640}{479}>\frac{4}{3}.

Therefore the
4/3
upper bound does not hold in this instance.

3
Remarks

The conjecture in
[
9
]
builds on a related upper bound of
{1}/({1-(1-1/n)^{n})}\leq{e}/{(e-1)}
that is known to hold on the correlation gap for these class of functions where the denominator is the expected value of a set function with independent random variables rather than pairwise independent random variables (see
[
5
,
2
]
). With pairwise independence, the bound of
{4}/{3}
is known to
hold in special cases such as: (i) in low dimensions (
n=2
and
n=3
; Theorem 5 in
[
9
]
) or (ii) for particular marginal probabilities (Theorem 8 in
[
9
]
) or (iii) for particular submodular functions (rank function of a uniform matroid of rank 1; Proposition 2.5 in
[
8
]
).
Before using the AI tool, we the authors, did not know if the answer to the conjecture is YES or NO. This is in contrast to the recent First Proof project (see
[
1
]
) where the answers to the ten mathematical research questions posed to AI tools were known to the researchers.
Below is the single prompt that we provided to GPT5.5 Pro:

Prove or disprove the conjecture that the ratio of the maximum expected value of a set function computed over all joint distributions with fixed marginal probabilities and the maximum expected value of a set function computed over all joint pairwise independent distributions with the same fixed marginal probabilities is at most 4/3 for all nonnegative nondecreasing submodular set functions.

After 12 minutes, GPT5.5 Pro came back with the counterexample, which we then validated. On prompting the AI tool on how much time it spent on proof and disproof attempts, it came back with an estimate of 5 to 6 minutes on proof attempts and 6 to 7 minutes on disproof attempts. In the Appendix, we also report on the synopsis of the methods that the AI tool used to try prove and disprove the conjecture, as reported by the tool. In these attempts, it auto-generated linear programming formulations using Python’s SciPy’s linprog function, generated random instances, solved the linear programs with the HiGHS freely available LP solver and refined the instances. Our openness to using AI tools was partly due to recent progress reported by OpenAI
[
7
]
using their internal AI models to disprove the longstanding unit distance conjecture and efforts by these tools in tackling the First Proof project.
Our initial attempts using the free versions of ChatGPT and Claude to tackle the conjecture provided no progress. Our findings are consistent with recent findings that these tools are now becoming useful in being able to disprove research conjectures when possible by accesing a variety of computational methods in conjunction with large language models (see the discussion by various mathematicians in
[
1
]
).
At this point, we have not been able to aided by these AI tools either prove or disprove the validity of the upper bound for
n=4
(see Table
3
). This remains an open question. Another interesting question is to characterize the tightest upper bound for values of
n
when it is 5 and above for these classes of functions. We leave these for future research.
