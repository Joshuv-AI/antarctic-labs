Critical Simulation Pipeline for COG Suites
 Ian Snider, Jesse Norris (LLNL)
 The CRItical Simulation Pipeline (CRISP) is a Python package for automating validation of reactor criticality benchmarks. CRISP supplies
 COG—a multi-particle radiation transport code maintained by the Nuclear Criticality Safety Division—with a pipeline to calculate keff
 performance for 400+ benchmark experiments with 3,400+ configurations from the International Criticality Safety Benchmark Evaluation
 Project (ICSBEP). The pipeline includes four stages: materials configuration, input card templating, cluster submission, and results
 analysis. CRISP includes a command-line interface to facilitate user interaction.
