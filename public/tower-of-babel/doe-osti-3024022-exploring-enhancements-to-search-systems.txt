 Science Search: User Experience (UX) as a
 Trustworthy-System Problem
  What is science search?
  Science search is ﬁnding, comparing, and reusing scientiﬁc data from instruments, simulations, and
  observations so researchers can discover insights within or across disciplines, reproduce results, and build
  on prior work.

  Where AI helps and where UX matters:
  AI can improve metadata retrieval, but UX determines trust by shaping interpretation through ranking,
  evidence, context, and provenance.

  This executive summary synthesizes ﬁndings and provides design guidelines for trustworthy
  AI-enabled search.

More background on the ScienceSearch project @
https://sciencesearch.lbl.gov/

Project Overview — Science Search User Experience
Overarching project applied machine learning to improve metadata for better
search experience via usable web interfaces.
 Thrust 1: Developing Machine Learning Algorithms to Enable Search
 AI/ML for better search: generate/augment metadata for datasets and data sources that are currently hard or
 impossible to search.

 Thrust 2: Enhancing User Experience (UX)
 Build user-centered web interfaces and use UX research to make AI-powered search clear, trustworthy, and actionable
 based on research on scientists’ search behavior and needs.
