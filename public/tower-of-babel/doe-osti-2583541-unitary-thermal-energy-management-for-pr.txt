Executive Summary of CRADA Work:

NREL will work with Delphi to develop technology that integrates the thermal management of
electric drive vehicle sub-systems into a unified thermal system that reduces auxiliary loads and
increases vehicle range. The ultimate goal is to create a cost-effective system which improves
climate control efficiency through heat pump operation and waste heat recovery, while
maintaining occupant thermal comfort and meeting powertrain thermal requirements. The
technology will also aim to reduce the number of independent cooling systems required in
electric drive vehicles.

Summary of Research Results:

Task 1: Baseline Thermal System Model

Develop a baseline thermal system and cabin model for the baseline vehicle and validate against
experimental data.

Task 2: Baseline Vehicle Model

Develop a baseline vehicle model which incorporates the thermal system and component models
and validate against experimental data.

Task 3: Develop UTEMPRA System Thermal Model

Conduct modeling simulations of UTEMPRA thermal system concept to predict system
performance.

Assess impact of UTEMPRA thermal system concept on vehicle range using vehicle model .

Task 4: System Bench Performance Tests

Modify NREL bench test apparatus to install UTEMPRA thermal system prototype Conduct
steady state and transient drive cycle testing of UTEMPRA thermal system performance under
heating and cooling conditions.

Task 5: Vehicle Testing

NREL participation and assistance with vehicle level testing of UTEMPRA thermal system.

Task 6: Validation of UTEMPRA vehicle model

Confirm UTEMPRA thermal and vehicle model accuracy using final vehicle wind tunnel test
data.

Modification 1:

The project scope and tasks are outlined in the following work breakdown structure:

1. Analysis scenarios
 • -Max Heating Capacity at -10°C ambient temperature,
 • Complete detailed Mode 17 analysis study to determine expected system performance
 under max heating conditions, including cabin, components and battery warm-up.
 • Max Cooling Capacity at 43°C ambient temperature.
 • Complete detailed Mode 12 analysis study with active battery and cabin cooling to
 determine expected system performance under max cooling conditions.

2. Fiat 500e FastSim model
 • Create a Fiat 500e FASTSim model using information as available. Set up model for
 range estimation for two drive cycles. Will need temperatures and drive cycles defined.

3. Support Controls and Hand-off to MAHLE engineer
 • Complete model-hand off, where the model and knowledge ofmodel software usage is
 transferred to MAHLE; follow up with continued but limited guidance.

Deliverables

 • Periodic project updates once a month (or as needed). The reviews will be conducted
 through conference calls.
 • CoolSim Matlab/Simulink Model ofUTEMPRA system.
 • FASTSim model for Fiat 500e capable ofrange impact assessment.
