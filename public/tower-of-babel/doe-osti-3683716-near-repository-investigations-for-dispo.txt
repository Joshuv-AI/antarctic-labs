 EXECUTIVE SUMMARY

 1 SUMMARY INTRODUCTION

 The Spent Fuel and Waste Science and Technology Campaign (SFWST) of the U.S. Department of
 Energy (DOE) Office of Nuclear Energy (NE) is conducting research and development on safety analysis
 of a generic deep geologic repository. Two priorities for SFWST are design concept development and
 disposal system modeling. These priorities are directly addressed in the Geologic Disposal Safety
 Assessment (GDSA) control account, which is charged with developing a geologic repository system
 modeling and analysis capability, and the associated software, GDSA Framework, for evaluating
 disposal system performance for nuclear waste in geologic media.
 This report describes a subset of the specific activities in the Fiscal Year (FY) 2025 associated with
 the Argillite GDSA Baseline Model Implementation and GDSA Uncertainty and Sensitivity Analysis
 Methods work packages. This report fulfills the Argillite GDSA Baseline Model Implementation work
 package (SF-25SN01030409) level 4 milestone (M4SF-25SN010304095). This work was closely
 coordinated with the other Sandia National Laboratory GDSA work packages: the GDSA Framework
 Development work package (SF-25SN01030408), the GDSA Sensitivity Analysis Methods work
 package (SF-25SN01030407), and the GDSA PFLOTRAN Development work package (SF-
 25SN01030410). This report was completed in parallel with the Sensitivity Analysis Methods work
 package milestone “Uncertainty and Sensitivity Analysis Methods and Applications in the GDSA
       Framework (FY2025)” (SF-25SN01030407).

 1.1 HIGH-LEVEL PURPOSE OF THIS WORK:
 Performance assessment (PA) for underground geologic disposal is an iterative process for
 determining the safety relevant set of features, events, and processes (FEPs) to include in a PA model.
 The purpose of the Argillite GDSA Baseline Model Implementation work package is to develop
 conceptual and numerical models, based on generic FEPs, that are relevant to argillite geological
 formations in the US.
 The purpose of this report is to document the development, in collaboration with the GDSA Uncertainty
 and Sensitivity Analysis Methods work package, of a deterministic and stochastic numerical model to
 investigate the range of temperatures and pressures in the near-repository region associated with
 disposal of high-heat load waste packages in argillite formations. Very high temperature and pressure
 in an argillite repository was raised as a potential issue in LaForce et al. (2024). A highly refined near-
 repository system model and range of uncertain parameters are described in this work, while the
 detailed results of the sensitivity and uncertainty analysis are in Swiler et al. (2025) Section 4.
 The findings from this quarter WP shale case have implications for the design and operational strategy
 of hot repositories in argillite formations. Understanding the thermal and pressure dynamics is
 important for ensuring the long-term safety and stability of the repository. The potential for elevated
 temperatures and pressures necessitates careful consideration of the engineered barrier system's
 materials and configurations to withstand these conditions. By providing a clearer picture of the near-
 field behavior under various thermal loads, we can better evaluate the safety margins and
 performance expectations of the repository system.

 1 INTRODUCTION

 The Spent Fuel and Waste Science and Technology Campaign (SFWST) of the U.S. Department of
 Energy (DOE) Office of Nuclear Energy (NE) is conducting research and development on safety analysis
 of a generic deep geologic repository. Two priorities for SFWST are design concept development and
 disposal system modeling. These priorities are directly addressed in the Geologic Disposal Safety
 Assessment (GDSA) control account, which is charged with developing a geologic repository system
 modeling and analysis capability, and the associated software, GDSA Framework, for evaluating
 disposal system performance for nuclear waste in geologic media.
 This report describes a subset of the specific activities in the Fiscal Year (FY) 2025 associated with
 the Argillite GDSA Baseline Model Implementation and GDSA Uncertainty and Sensitivity Analysis
 Methods work packages. This report was completed in parallel with the Sensitivity Analysis Methods
 work package milestone “Uncertainty and Sensitivity Analysis Methods and Applications in the GDSA
 Framework (FY2025)” (SF-25SN01030407). This report fulfills the Argillite GDSA Baseline Model
 Implementation work package (SF-25SN01030409) level 4 milestone (M4SF-25SN010304095).

 1.1 HIGH-LEVEL PURPOSE OF THIS WORK:
 Performance assessment (PA) for underground geologic disposal of nuclear waste is an iterative
 process for determining the safety relevant set of features, events, and processes (FEPs) to include in
 a PA model. The purpose of the Argillite GDSA Baseline Model Implementation work package is to
 develop conceptual and numerical models, based on generic FEPs, that are relevant to disposal in
 argillite geological formations in the US.
 The presence of high temperature and pressure in a shale repository was raised in LaForce et al.
 (2024) after several stochastic simulations which failed to complete were observed to have high
 temperature or pressure at the time the simulations stopped. A very simplified small-scale study in
 that work verified the possibility of very high temperature and pressure using the coarse reference-
 case simulation mesh. However, that study was not sufficiently refined to determine whether this result
 was a potentially realistic outcome, or the result of the very coarse simulation mesh in the reference
 case model and the particular set of sampled parameters used.
 The purpose of this report is to document the development, in collaboration with the GDSA Uncertainty
 and Sensitivity Analysis Methods work package, of a deterministic and stochastic numerical model to
 investigate the range of temperatures and pressures in the near-repository region associated with
 disposal of high-heat load waste packages in argillite formations. The highly refined near-repository
 system model and range of uncertain parameters are described in this work. Temperature, pressure,
 and liquid saturation at many observation points in the waste package, the buffer, the disturbed rock
 zone, and the near-field shale region are investigated for a deterministic realization. The detailed
 results of the sensitivity and uncertainty analysis are in Swiler et al. (2025) Section 4.

 affecting deep geologic repository performance, uncertainty and sensitivity analysis, pre- and post-
 processing, and visualization. The overall objectives of GDSA Framework development are to:
 • Create a framework that is flexible enough to take advantage of future advances in hardware,
 software, simulation, and analysis methods.
 • Leverage existing high-performance computing capabilities (e.g., meshing, simulation,
 analysis, and visualization).
 • Enable increasingly coupled, mechanistic multi-physics modeling.
 • Provide analysis methods for prioritization of SFWST Disposal Research activities.
 • Provide transparent implementation of simulation and analysis methods.
 • Develop and distribute in an open-source environment so that software is freely available to
 stakeholders (e.g. see GDSA reports from 2015 through 2024: (Mariner, Gardner, Hammond,
 Sevougian, & Stein, 2015), (Mariner, et al.,, 2016), (Mariner, Stein, Frederick, Sevougian, &
            Hammond,, 2017), (Swiler L. P., et al., 2021), (Swiler L. P., et al., 2024).

 1.3.3 AUTOMATED ANALYSIS WORKFLOW DEVELOPMENT FOR GDSA
 Uncertainty Quantification analysis workflows are not trivial to define and get running, even when using
 tools such as Dakota to generate nested studies involving sampling loops over both aleatory and
 epistemic samples. To address this, a set of workflows which couple Dakota, PFLOTRAN, and NGW
 (the Next-Generation Workflow software) were developed, which are available at
 (https://gitlab.com/iwf/ngw ). The workflows present the user with a unified graphical user interface
 (GUI) where the workflow can be dictated and automated in an easy-to-use graphical format. This
 workflow also allows greater reproducibility and traceability of the actual files and scripts used for a
 particular study.

 2.1 LITERATURE REVIEW
 The model domain encompasses a quarter of a waste package and half the spacing between adjacent
 drifts and waste packages within the shale host rock. It is a finely meshed control volume model of the
 inner repository. By applying closed symmetry conditions at all side boundaries, this configuration
 effectively simulates a waste package positioned at the center of an infinite, symmetrical repository
 system.

 A comprehensive literature search, Appendix A – Literature Review for Shale Repository, was
 performed to help inform the quarter waste package (WP) model for the shale case. The literature
 search resulted in a range of WP/buffer/disturbed rock zone (DRZ) measurements. Dimensions in the
 literature reviewed included length/width/height, while other reports specified radial measurements
 for the WP, buffer, and DRZ. The quarter WP shale model that will be developed for this study will
 implement radial measurements for the WP, buffer and DRZ.

 Figure 2-1, Figure 2-2, Figure 2-3, and Figure 2-4 show a cross section of a drift for shale models found
 in the literature search. Figure 2-1 and Figure 2-2 include a concrete liner, whereas Figure 2-3 and
 Figure 2-4 instead incorporate a DRZ. Figure 2-4 shows an existing quarter WP shale model from
 LaForce et al. (2021) that will be used as a starting point and modified with values found from the
 conducted literature search presented in this section.

 2.1.1 WASTE PACKAGE
 The literature review resulted in a range of 5 to 5.6 m for the length of the WP, and a range of 0.42 to
 1 m in radial measurements. The larger difference in radial measurements is due to the type of waste
 package that was assumed in the literature. Hardin et al. (2013) provides measurements for the
 nominal 4-, 12-, 21- and 32-pressurized water reactor (PWR) sizes that assumed to have a radius of
 0.48, 0.645, 0.8 and 1 m, respectively. Recent full scale (half-symmetry) shale reference case models
 use the eight-string waste package order that consists of 32-PWRs, 89-boiling water reactors (BWRs),
 5-HLW Short, and 5-HLW Long waste packages or all 37 PWRs (LaForce et al. 2024; Swiler et al. 2024;
 Price et al. 2024). These recent full-scale shale models all assume measurements for all WPs in the
 referenced models in to be 1.67 x 1.67 x 5 m which were adjusted from referenced values to facilitate
 gridding and originally set up for 12-PWR repository layout (Mariner et al. 2017). The referenced WP
 outer diameter for a 12-PWR case taken from Hardin and Kalinina (2016) was specified to be 1.37 m.
 Greene et al. (2013) specifies the cross section of an 80-BWR Multi-Purpose Canister Humbolt Bay
 (MPC-HB) to be 68.5 in (1.73 m) which is very similar to the measurements in recent shale models
 (1.67m). For additional comparison, a 32 PWR/68 BWR capacity DPC is approximately 70 in (1.78 m)
 and larger 37/89 DPC’s are in the realm of 75 in (1.91 m).
 The decay heat generation of the waste package needs to be considered, as the combination of waste
 package decay heat, waste package and drift spacing influence maximum repository temperature,
 which is particularly of concern in high heat cases. Mariner et al. (2017) states that 12-PWR, 100 y
 out-of-reactor (OoR), waste packages have an initial value of 3084 W. This initial wattage for 12-PWR

 Shale models reviewed from the literature search implement a buffer material surrounding the WPs in

 2.1.3 DISTURBED ROCK ZONE
 Excavation of a repository alters the stress state and physical properties of the intact host rock, causing
 fracturing in the surrounding area. This fractured region, known as the disturbed rock zone (DRZ), lies
 between the buffer and the undisturbed host rock.
 Literature search reveals that older shale models did not consider the DRZ but instead a concrete liner
 that was primarily for security from rockfalls during emplacement operations, while more recent
 studies omit the liner and include the DRZ. The quarter WP shale model considered for this study uses
 a DRZ instead of a concrete liner.
 All past shale models reviewed in the literature search (Mariner et al., 2017; Sevougian et al., 2019b;
       LaForce et al., 2020; 2021; 2022; 2023; 2024) set the thickness of the DRZ to be 1.67 m, therefore
 the base case model set up also implements this measurement.

September 30, 2025                                                                                                   21

 2.1.4 SHALE HOST ROCK
 The literature search considering a repository within shale host rock specified a minimum of 150 m
 thickness with a preferred maximum available thickness (Gonzales and Johnson 1985; Mariner et
 al., 2015; Perry and Kelly 2017). Shale models reviewed set host rock thicknesses between 450 and
 585 m. Mariner et al. (2017) shale model implemented a repository with 12-PWRs within a 585-m
 thick shale host rock layer that included a 90 m thick silty shale unit. Sevougian et al. (2019b) shale
 model implemented a repository with 24- and 37-PWRs within a 450-m thick sealing shale that
 included a 45 m thickness of a silty shale unit.

 2.1.5 REPOSITORY DEPTH
 The ideal repository depth is between 300 and 900 m (Gonzales and Johnson 1985; Mariner et al.
 2015; 2017; Perry and Kelly 2017). Shale models reviewed consider repository depths between 400
 and 650 m, while most set the depth to about 500 m. Gonzales and Johnson (1985) states that a
 repository should be deep enough below the present land surface to ensure that its contained waste
 will not be exposed to the biosphere through erosion or denudation during its hazardous period.

 2.1.7 WASTE PACKAGE AND DRIFT CENTER-TO-CENTER SPACINGS
 The literature search includes a range between 10 to 30 m WP and 15 to 70 m drift center-to-center
 spacings. Jove Colon et al. (2014) states that WP and drift spacing are dictated by thermal loading,

 Additionally, Hardin et al. (2013) determined drift and waste package spacing based on a thermal limit
 at the rock wall of 100℃.

 2.3 CONCLUSION
 Key Findings
 The refined quarter waste package shale reference case presented in this study provides critical
 insights into the thermal and pressure dynamics associated with the disposal of high-heat load waste
 packages in shale-hosted repositories. By focusing on a single waste package within a highly refined
 model, we have been able to isolate and analyze the effects of various parameters on the near-field
 environment, thereby enhancing our understanding of the conditions that could lead to elevated
 temperatures and pressures in the repository.
 The results from the five baseline PFLOTRAN simulations reveal that the maximum temperature
 reached in the waste package region was 209°C, observed in the scenario with the highest thermal
 output (Run 5). This finding aligns with our expectations, as higher thermal outputs are anticipated to
 result in increased thermal gradients and, consequently, higher temperatures in the vicinity of the
 waste package. The recorded maximum pressure of 6.47 MPa in the same run further underscores
 the interplay between thermal output and pressure buildup, indicating that as the thermal load
 increases, so too does the potential for pressurization of the repository.

September 30, 2025                                                                                               33

 The observed dryout phenomenon in the waste package region is particularly noteworthy. The rapid
 decrease in liquid saturation to zero within the first year of simulation suggests that the thermal
 output from the waste packages significantly influences the hydrological conditions in the near-field
 environment. This dryout condition could have implications for the integrity of the engineered barrier
 system, as the absence of liquid could affect the thermal conductivity and overall performance of the
 buffer material. The subsequent resaturation observed after approximately 1000 years indicates a
 dynamic interaction between thermal and hydrological processes, which may be critical for long-term
 performance assessments of the repository.
 Sensitivity to Parameters
 The quarter WP model allows for a detailed sensitivity analysis of key parameters such as porosity,
 permeability, and thermal conductivity of the buffer, DRZ, and shale. For instance, an increase in the
 thermal conductivity of the buffer could enhance heat dissipation, potentially mitigating the peak
 temperatures observed. Conversely, lower permeability in the DRZ may restrict fluid movement,
 leading to higher localized pressures. The results of the sensitivity analysis in Swiler et al., (2025) and
 summarized in subsequent sections indicate that variations in these parameters can significantly
 influence both temperature and pressure conditions in the repository.
 The incorporation of additional observation points around the waste package has proven invaluable
 in capturing the maximum liquid pressure and temperature conditions. This refined approach not
 only enhances the granularity of our analysis but also allows for a more comprehensive
 understanding of the spatial variability of thermal and pressure responses in the near-field
 environment.
 Implications for Repository Design
 The findings from this quarter WP shale case have significant implications for the design and
 operational strategies of repositories. Understanding the thermal and pressure dynamics is important
 for ensuring the long-term safety and stability of the repository. The potential for elevated
 temperatures and pressures necessitates careful consideration of the engineered barrier system's
 materials and configurations to withstand these conditions.
 Moreover, the insights gained from this study can inform regulatory frameworks and risk
 assessments associated with high-heat load waste disposal. By providing a clearer picture of the
 near-field behavior under various thermal loads, we can better evaluate the safety margins and
 performance expectations of the repository system.
 Future Work
 The model concept developed in this work can be utilized to study the interplay of additional uncertain
 parameters that are beyond the scope of the current study, such as temperature-dependent thermal
 conductivity, and waste package spacing in-drift and between-drifts.

 3.2 CURVE FIT TO SCALED HEAT OUTPUT
 The nine curves scaled to have thermal output 5kW at 100 years are shown in Figure 3-2. The number
 5kW was chosen as five of the curves under consideration have thermal output greater than this at
 100 years OoR, and four have thermal output lower. The time was chosen for scaling since it is
 anticipated that most waste will be disposed of 50-100 years OoR, but seven of the datasets had no
 data earlier than 100 years OoR.
 The curves are scaled by linearly interpolating the thermal output, T100, at 100 years OoR (if it was not
 in the dataset) and then scaling the entire dataset by (T100/5000). From 100-200 years and after
 2,000 years of the curves collapse nicely onto each other, with the largest spread in the curves
 occurring around 400 years with a spread of 710 (-), about a 35% difference between the highest
 (10th) and the lowest (60GWd) scaled curves. This is considered to be an acceptable collapse of the
 curves onto a single trend.
 The curves are all exponential decay curves, so they are combined into a single dataset that is fit to
 exponential functions of the form: 𝑻 = 𝑨𝒕𝒃
 Early time is when temperature is the highest and most important for thermally-driven flow, so the data
 is fit to three parts of the time series. The first 10,000 years, the first 100,000 years, and the full
 dataset. As can be seen in

 Table 3-2 there is not much difference in the parameters, and the trend lines essentially plot on top of
 each other. The R2 value increases as the number of data points is increased. This is because the
 datasets collapse onto each other and have a very low value at late time. The middle data fit is used
 because it has a higher R2 value and fits to all the data points during the thermal phase, when heat
 output is above 50 (-), which is 1% of the initial scaled value. It also matches the desired initial heat
 output of 5kW at 100 years OoR the most closely.

 5 SENSITIVITY ANALYSIS: HIGH LEVEL SUMMARY
 Swiler et al. (2025) details a sensitivity analysis conducted on uncertain input parameters and output
 quantities of interest (QoIs) as part the 200-sample study on the quarter WP shale reference case
 detailed in this report. We note that of the 200 PFLOTRAN simulations, 195 completed successfully.
 The others had parameter combinations that resulted in computationally infeasible runs with very
 rapid dry out. This study still provided enough completed simulations (195) compared to the dimension
 of the input space (10) for Sobol’ index estimation to be feasible.
 The analysis investigates ten parameters listed in Table 4-1. The simulations were set for a final time
 of 50,000 years, contrasting the base case of one million years. The study focuses on three main QoIs:
 maximum pressure, maximum temperature, and liquid saturation, evaluated at various observation
 points. The maximum pressure and temperature are critical for understanding the thermal and
 hydraulic behavior of the shale repository.

 The sensitivity analysis found that:
 • The shale thermal conductivity anisotropy ratio is a key parameter influencing both
 maximum temperature and pressure at multiple observation points (Figure 5-1-Figure 5-3).
 • Though shale thermal conductivity anisotropy ratio was a dominant uncertainty for
 pressure, it had significant interaction effects with other thermal conductivity parameters,
 permeabilities, and porosities, depending on the observation point.
 • Higher thermal conductivity anisotropy ratios result in lower vertical thermal conductivity,
 and correlate with lower temperatures and pressures. Other uncertain thermal
 conductivity parameters also impacted temperature, but parameters associated with
 other physical processes (e.g., permeabilities, porosities) did not.
 • Temperature significantly affects pressure, especially near the waste package, but the
 pressure results exhibit more variability due to complex interactions among various
 physical processes, including thermal conductivity, permeability, and porosity.
 • Liquid saturation is predominantly influenced by permeability parameters, with some
 realizations experiencing dry out in specific buffer regions, while others maintain
 saturation. Some realizations experienced dry out at observation points near the waste
 package in the buffer, but the buffer never fully dried out in any of the simulations that
 completed.
 The study emphasizes the intricate relationships between thermal conductivity and their collective
 impact on the model's outputs, underscoring the need for careful consideration of uncertainties in
 future analyses. For a more detailed look at this sensitivity study refer to Swiler et al. (2025).

 6 SUMMARY AND FUTURE WORK

 This report described collaborative activities performed in fiscal year 2025 associated with the Argillite
 GDSA Baseline Model Implementation and GDSA Uncertainty and Sensitivity Analysis work packages
 in the Disposal R&D Program under U.S. DOE NE-81. This report describes a subset of the specific
 activities in the Fiscal Year (FY) 2025 associated with these work packages: the development of a
 sensitivity analysis for a quarter WP shale case with increased resolution in the modeling domain near
 the waste package.
 The findings from this study and Swiler et al., (2025) have implications for the design and operational
 strategy of hot repositories in argillite formations. Understanding the thermal and pressure dynamics
 is important for ensuring the long-term safety and stability of the repository. The potential for elevated
 temperatures and pressures necessitates careful consideration of the engineered barrier system's
 materials and configurations to withstand these conditions. By providing a clearer picture of the near-
 field behavior under various thermal loads, we can better evaluate the safety margins and
 performance expectations of the repository system.

 6.1 CONCLUSIONS
 A highly refined ¼ waste package model was developed that had the full vertical extent of the
 reference case domain and represents the centermost waste package in an infinite array of identical
 and equally-spaced waste packages. Generic heat input curves were created for the waste package
 thermal output. Five deterministic simulations were conducted on this model with the 4 kW generic
 thermal output curve. The simulation results for the deterministic 7kW thermal output curve,
 approximating the 99% hottest waste package in inventory, was explored in detail. The results of this
 study indicate that, for this case, the waste package region dries out for approximately 1000 years,
 reaches a maximum temperature of 290 °C, and a maximum pressure of 6.47×106 Pa. However, the
 buffer region does not completely dry out, despite reaching a temperature of 170 °C, due to thermal
 pressurization.
 The uncertain quantities of interest in this study were the liquid saturation, temperature, and maximum
 pressure at observation points at the waste package, and in the buffer, DRZ, shale, lower sandstone,
 limestone, silt, and sandstone. 200 realizations of the model were run. Sensitivity analysis was
 performed using Sobol’ indices estimated with polynomial chaos expansion, scatterplots, and time
 series plots colored by uncertain input parameters. Sensitivity to the input parameters was analyzed
 in (Swiler et al., 2025) to investigate how uncertainties lead to high temperature and pressure near
 the repository and very briefly summarized here. Swiler et al., (2025) showed that the shale thermal
 conductivity anisotropy ratio was the dominant uncertainty driving maximum temperature variability.
 This was also a prominent driving uncertainty on the maximum pressure, however, there were
 interaction effects with other uncertain parameters. Liquid saturation was affected by thermal
 conductivity at the waste package, but elsewhere it is driven by the uncertain permeabilities.

 6.2 FUTURE WORK
 Future work on this model should include:
 1. Running the same 200 realizations of the model with the 1 kW and 7kW thermal output curves to
 create a nested sampling study. This would enable a clearer understanding of the input
 parameters that result in very high temperature and pressure near the repository.
 2. Investigating the impact of changing the waste package spacing from 40 m between drifts and
 30 m along drifts on the results of the uncertainty analysis simulations, as this has been shown
 to impact maximum temperature and pressure near the repository (Price et al., 2024).

 APPENDIX B-5 – NGW: RUN_PFLOTRAN_TEMPLATE
 Appendix B-5 shows the run_pflotran_template file that is used to submit samples into the HPC
 queue. This file is read into the PFLOTRAN_workflow.iwf, Appendix B-2, as a node which is linked to
 a “dpreproSBATCH” node that handles the preprocessing and results in a “run_pflotran.sh” batch
 script that includes actual values and text with the braces ({ }) found in the file.

 #!/bin/bash
 #SBATCH --nodes={n_nodes} # Number of nodes
 #SBATCH --time={runtime_hours}:{runtime_minutes}:00 # Wall clock time
 #SBATCH --account={WCID} # HPC WCID
 #SBATCH --job-name={job_name} # Name of job
 #SBATCH --mail-type=ALL
 #SBATCH --mail-user={username}@sandia.gov
 #SBATCH --partition={partition}
 #SBATCH --output={job_name}.%j.out
 #SBATCH --qos=normal
 #SBATCH --licenses=gpfs

 n_nodes={n_nodes}
 cores_per_node={cores_per_node}
 NTotalCores=$(( n_nodes * cores_per_node ))
 NAttempts=3 # How many times to loop over the sequence
 NSeq=4 # How many elements in the sequence
 CoreIncrement=2 # How many cores to decrement by in the sequence
 first=$(( NTotalCores )) # Starting number of cores
 last=$(( NTotalCores - (NSeq-1)*CoreIncrement )) # Ending number of cores
 CoreSeq=`seq $first -$CoreIncrement $last` # List of cores to try in a loop
 FullCoreSeq="$( for i in `seq $NAttempts`; do echo $CoreSeq; done )"

 module purge
 module load cmake
 module load gnu/11.2.1
 module load anaconda3/2022.05
 module load intel/21.3.0
 module load mkl/21.3.0
 module load openmpi-intel/4.0

 export PETSC_ARCH=intel_O
 export PETSC_DIR=/projects/ADSM/software/petsc-v3.20.0

 for ncores in $FullCoreSeq; do
 echo "Attempting with $ncores cores"
 mpirun -n $ncores /projects/ADSM/software/pflotran-master-petsc-v3.21/src/pflotran/pflotran -
 file_output FALSE >& pflotran.stdout
 SUCCESS_FLAG=`grep -c "Wall Clock Time" pflotran.stdout`
 if [ $SUCCESS_FLAG -gt 0 ]; then
 echo "Job completed successfully. Exiting."
 break # Exit the loop if any attempt finishes successfully
 else
 echo "Job failed. Retrying with the next core count."
 rm -f *.pft
 fi
 done

 echo done>job_status.txt
