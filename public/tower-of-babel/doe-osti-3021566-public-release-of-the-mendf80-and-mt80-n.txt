 Abstract

 This document describes the MENDF80 and MT80 data libraries, which are multi-group
 neutron cross section libraries based on ENDF/B-VIII.0 for LANL’s Nuclear Data Interface (NDI).
 MENDF80 is a downscatter-only library, while MT80 is multi-temperature. Both libraries also
 have 30-group pre-collapsed versions, MENDF80 30 and MT80 30.

1 Introduction
The MENDF80 downscatter-only nuclear data library was released on February 25, 2020 [1], along
with the MT80 multi-temperature library. Both libraries are based on the ENDF/B-VIII.0 data library
[2]. The ENDF data was processed for NDI using NDVV and NJOY 2016 [3] to the 618 lanl
group structure [4]. More information can be found in [1].
These libraries provide cross section data for incident neutrons. They use the ZAID extensions:
    • MENDF80: .800nm ,

    • MT80: .801nm-.823nm ,

    • MENDF80 30: .830nm ,

    • MT80 30: .831nm-.853nm .

Information on the changes in ENDF/B-VIII.0 can be found in [2]. MT80 has data at the standard
LANL twenty-three temperatures
