New Bounds for Exact Penalized Cardinality-Constrained Optimization with Pseudonormality Conditions
Lili Pan, Huilin Xie, Xianchao Xiu, Jiyuan Tao

Abstract
Cardinality-constrained optimization (CCO) is a popular topic in sparse learning and signal recovery, yet remains challenging due to the inherent nonconvexity and discontinuity of cardinality constraints. This paper investigates the exact penalty theory for CCO problems with general equality and inequality constraints. In particular, we extend the pseudonormality condition to the cardinality-constrained framework and establish the local exact penalization without imposing Lipschitz continuity on the objective function. We further analyze both the projected subgradient method and its stochastic variant with convergence guarantees for the derived exact penalty formulation. Compared with the existing results, we give some more precise bounds of the iterate sequence and the objective function value. Keywords: Cardinality constrained optimization, optimality condition, exact penalization, projected subgradient method.



1
Introduction

In this paper, we consider the cardinality-constrained optimization (CCO) problem

\displaystyle\min_{\mathbf{x}\in\mathbb{R}^{n}}

\displaystyle f(\mathbf{x})

(1.1)

\displaystyle\mathrm{s.t.}

\displaystyle g(\mathbf{x})\leq 0,~h(\mathbf{x})=0,

\displaystyle\|\mathbf{x}\|_{0}\leq s,

where
f(\mathbf{x}):\mathbb{R}^{n}\rightarrow\mathbb{R}
is a continuously differentiable and bounded from below function,

g(\mathbf{x})=(g_{1}(\mathbf{x}),\cdots,g_{m}(\mathbf{x}))^{\top}:\mathbb{R}^{n}\rightarrow\mathbb{R}^{m}
and

h(\mathbf{x})=(h_{1}(\mathbf{x}),\cdots,h_{p}(\mathbf{x}))^{\top}:\mathbb{R}^{n}\rightarrow\mathbb{R}^{p}

are continuously differentiable functions,
\|\mathbf{x}\|_{0}
denotes the cardinality of
\mathbf{x}\in\mathbb{R}^{n}
(number of nonzero entries of
\mathbf{x}
), and
s<n
is a positive integer. Over the past decade, CCO has been widely applied in inverse problems
[
bruckstein2009sparse
,
wang2013multi
]
, feature selection
[
zou2018selective
,
hazimeh2023grouped
]
, portfolio selection
[
bertsimas2022scalable
,
anis2025end
]
and network pruning
[
he2023structured
,
benbaki2023fast
]
.
We refer the reader to
[
tillmann2024cardinality
]
for a comprehensive survey.

1.1
Literature review

From an optimization perspective, problem (
1.1
) poses significant challenges due to the presence of the cardinality constraint. Below, we outline three primary approaches to addressing this issue.

•

The first approach
involves reformulating problem (
1.1
) as a mixed-integer programming problem by introducing appropriate binary variables, which can then be solved directly using discrete optimization techniques
[
bonami2009exact
,
burdakov2016mathematical
]
. However, these methods often suffer from limited computational efficiency, particularly for large-scale instances.
By applying standard relaxations to the binary constraints, problem (
1.1
) is reformulated into a relaxed continuous nonlinear optimization problem with an orthogonality-type constraint.
In
[
vcervinka2016constraint
]
, some problem-tailored constraint qualifications were defined
and shown how these constraint qualfications can be used to obtain suitable optimality conditions for problem (
1.1
).
And then the authors in
[
kanzow2021augmented
]

investigated the viability of using a standard safeguarded multiplier penalty method without any problem-tailored modifications to solve the reformulated problem.
More recent works in this direction can be found in
[
liang2024relaxed
,
kanzow2025sparse
]
.

•

The second approach
directly tackles problem (
1.1
) using continuous optimization ideas, leveraging the special structure of cardinality constraints.
We enumerate some works on the cardinality constrained problems (
1.1
) with different constraints.
For problem (
1.1
) with nonnegative constraints, an iterative hard thresholding method with rigorous convergence analysis was proposed in
[
pan2017convergent
]
. For problem (
1.1
) with symmetric set constraints, an efficient method based on the framework in
[
beck2013sparsity
]
was developed
[
beck2015minimization
]
. For problem (
1.1
) with cone constraints, optimality conditions were established under suitable constraint qualifications
[
pan2017restricted
]
. In the linear case of problem (
1.1
), Lagrange duality and saddle point results were obtained using piecewise linear convex optimization
[
zhao2022lagrange
]
. For problem (
1.1
) with general constraints, second-order optimality conditions for the existence of augmented Lagrangian multipliers were provided in
[
kan2024second
]
. Additionally, for the quadratic-constrained quadratic programming variant of problem (
1.1
), an efficient semi-smooth Newton method with convergence guarantees was proposed in
[
li2025sparse
]
.

•

The third approach
employs penalty methods, which are highly effective for problems with complex constraints.
Exact penalization refers to a scenario where the solution of the penalized problem coincides with that of the original problem without requiring the penalty parameter to tend to infinity.
In particular, we say that problem (
1.1
) admits an exact penalty at the
feasible point
\mathbf{x}^{*}
if
\mathbf{x}^{*}
is a strict local minimum of (
1.1
) for every smooth function
f
, and there is a scalar
\tau>0
such that
\mathbf{x}^{*}
is also a local minimum of the following problem

\displaystyle\min_{\mathbf{x}\in\mathbb{R}^{n}}

\displaystyle F_{\tau}(\mathbf{x}):=f(\mathbf{x})+{\tau}\left(\|g^{+}(\mathbf{x})\|_{1}+\|h(\mathbf{x})\|_{1}\right)

(1.2)

\displaystyle\mathrm{s.t.}

\displaystyle\|\mathbf{x}\|_{0}\leq s,

where
\|g^{+}(\mathbf{x})\|_{1}=\sum_{i=1}^{m}\max\{0,g_{i}(\mathbf{x})\}
and
\|h(\mathbf{x})\|_{1}=\sum_{j=1}^{p}|h_{j}(\mathbf{x})|
.
This concept has been extensively studied in literature.
Exact penalization for nonlinear programming problems with Lipschitz continuous objective functions was investigated in
[
nocedal2006numerical
]
, while exact penalization for problems with nonconvex and non-Lipschitz objective functions was explored in
[
chen2016penalty
,
guo2018necessary
]
.

The conditions for the admittance of an exact penalization for problem (
1.1
) are called constraint qualifications.
For example, based on the relaxed constant positive linear dependence (CCOP-RCPLD) condition, it was shown in
[
xiao2024optimality
]
that problem (
1.1
) admits an exact penalization. Some other constraint qualifications for problem (
1.1
) were proposed
in
[
vcervinka2016constraint
,
burdakov2016mathematical
,
pan2017optimality
,
kanzow2025sparse
]
.
It was worth noting that the pseudonormality and quasinormality were not considered for problem (
1.1
), which are two central conditons within the taxonomy of the constraint qualifications for constrained optimization problems.
Although the pseudonormality implies the quasinormality in the constrained optimization, quasinormality fails to provide
the desired theoretical unification when the abstract constraint is not regular and
pseudonormality admits an insightful geometrical interpretation in contrast with quasinormality
[
bertsekas2002pseudonormality
]
.

To solve problem (
1.2
), several greedy methods have been proposed. For instance, the binary iterative hard thresholding (BIHT) method was applied to one-bit compressive sensing
[
jacques2013robust
]
. Furthermore, the adaptive iterative hard thresholding (AIHT1) method was developed to solve the constrained least absolute deviation problem with cardinality constraints
[
li2023adaptive
]
. Notably, stochastic methods require significantly less storage and computation compared to general subgradient methods
[
liu2019one
]
, making stochastic gradient descent methods widely attractive for optimization problems with cardinality constraints, see
[
nguyen2017linear
,
zhou2018efficient
,
shang2021efficient
,
li2024stochastic
]
.

This naturally raises the question: Can we further explore the exact penalty theory for problem (
1.1
) utilizing the concept of pseudonormality for cardinality constrained optimization and improve the bounds for projected subgradient methods associated with problem (
1.2
)?

1.2
Contributions

In this paper, we first define two constraint qualifications for problem (
1.1
) to ensure the exactness of the penalized problem (
1.2
), which are closely related to the stationarity of the original problem and the error bound of the feasible region. We then employ the projected subgradient method and the stochastic projected subgradient method to solve the penalized problem (
1.2
). It should be noted that the projected subgradient method is a classical method for minimizing a nondifferentiable convex function subject to a compact and convex set
[
alber1998projected
,
auslender2009projected
]
, while the cardinality-constrained set is nonconvex, rendering the convergence analysis of the projected subgradient method highly challenging for such constrained problems. Besides, the convergence results of stochastic gradient descent established in
[
nguyen2017linear
,
li2024stochastic
]
cannot be directly applied to stochastic iterative methods, as they rely on the assumptions that the objective function is constrained strongly convex (RSC) and smooth (RSS).

The contributions of this paper can be summarized as follows:

(1)

We propose the cardinality-constrained Mangasarian-Fromovitz constraint qualification (CC-MFCQ) and cardinality-constrained pseudonormality (CC-pseudonormality) for problem (
1.1
), where CC-MFCQ implies CC-pseudonormality. We rigorously prove that CC-pseudonormality is a sufficient condition for ensuring the exact penalization of problem (
1.2
). Notably, CC-pseudonormality does not imply the CCOP-RCPLD condition proposed in
[
xiao2024optimality
]
.

(2)

We develop the projected subgradient method and the stochastic projected subgradient method to deal with problem (
1.2
). Moreover, we provide a convergence analysis that does not require the objective function to be RSC or RSS. Compared with the results in
[
liu2019one
]
, our findings yield tighter bounds on the iterative sequence and smaller corresponding objective function values, as illustrated in Table

2.2
Tangent and normal cones

Let
A\subseteq\mathbb{R}^{n}
be an arbitrary closed set and
\mathbf{x}^{*}\in A
. According to
[
rockafellar1998variational
]
, the Bouligand (also contingent or tangent) cone

to set

T_{A}(\mathbf{x}^{*}):=\left\{\mathbf{d}\in\mathbb{R}^{n}\mid\exists\{\mathbf{x}^{k}\}\xrightarrow{A}\mathbf{x}^{*}~\mathrm{and}~\{t_{k}\}\downarrow 0~\mathrm{such~that}\underset{k\rightarrow\infty}{\lim}\frac{\mathbf{x}^{k}-\mathbf{x}^{*}}{t_{k}}=\mathbf{d}~\right\},

\{\mathbf{x}^{k}\}\xrightarrow{A}\mathbf{x}^{*}

and
\{\mathbf{x}^{k}\}
converges to

\mathbf{x}^{*}
.
The Fr
\acute{e}
chet (also regular) normal cone is defined as the polar of the Bouligand tangent cone, i.e.,

\widehat{N}_{A}(\mathbf{x}^{*}):=T_{A}(\mathbf{x}^{*})^{\circ}=\big\{\mathbf{v}\in\mathbb{R}^{n}\mid\langle\mathbf{v},\mathbf{d}\rangle\leq 0,~\mathbf{d}\in T_{A}(\mathbf{x}^{*})\big\}.

The Mordukhovich (also limiting or basic) normal cone is given by

N_{A}(\mathbf{x}^{*}):=\big\{\mathbf{d}\in\mathbb{R}^{n}\mid\exists\{\mathbf{x}^{k}\}\xrightarrow{A}\mathbf{x}^{*},~\mathbf{d}^{k}\in\widehat{N}_{A}(\mathbf{x}^{k})~\mathrm{such~that}~\mathbf{d}^{k}\to\mathbf{d}\big\}.

From
[
pan2017restricted
,
pan2017optimality
]
, the Bouligand tangent cone, Fr
\acute{e}
chet normal cone, and Mordukhovich normal cone for

\displaystyle{T}_{S}(\mathbf{x}^{*})

\displaystyle=\left\{\begin{array}[]{*{20}c}S_{\Gamma^{*}},&\textup{if}~~|\Gamma^{*}|=s,\\
\underset{J\in\mathcal{J}^{*}}{\bigcup}S_{J},&\textup{if}~~|\Gamma^{*}|<s,\end{array}\right.

\displaystyle\widehat{N}_{S}(\mathbf{x}^{*})

\displaystyle=\left\{\begin{array}[]{*{20}c}S_{\overline{\Gamma}^{*}},&\textup{if}~~|\Gamma^{*}|=s,\\
\{0\},&\textup{if}~~|\Gamma^{*}|<s,\end{array}\right.

\displaystyle N_{S}(\mathbf{x}^{*})

\displaystyle=\left\{\begin{array}[]{cl}S_{\overline{\Gamma}^{*}},&\textup{if}~~|\Gamma^{*}|=s,\\
\underset{J\in\mathcal{J}^{*}}{\bigcup}S_{\overline{J}},&\textup{if}~~|\Gamma^{*}|<s,\end{array}\right.

where
\Gamma^{*}:=\Gamma(\mathbf{x}^{*})
. The linearized cone of
\Omega
at
\mathbf{x}^{*}\in\Omega
is

L_{\Omega}(\mathbf{x}^{*}):=\big\{\mathbf{d}\in\mathbb{R}^{n}\mid\langle\nabla g_{i}(\mathbf{x}^{*}),\mathbf{d}\rangle\leq 0,~\forall i\in\mathcal{I}(\mathbf{x}^{*}),~\langle\nabla h_{j}(\mathbf{x}^{*}),\mathbf{d}\rangle=0,~\forall j=1,\cdots,p\big\}

L_{\Omega}(\mathbf{x}^{*})^{\circ}:=\left\{\sum_{i\in\mathcal{I}(\mathbf{x}^{*})}\lambda_{i}\nabla g_{i}(\mathbf{x}^{*})+\sum_{i=1}^{p}\mu_{j}\nabla h_{j}(\mathbf{x}^{*})\mid\lambda_{i}\geq 0,~\forall i\in\mathcal{I}(\mathbf{x}^{*}),~\mu_{j}\in\mathbb{R},~j=1,\cdots,p\right\}.

2.3
Constraint qualifications

Consider the following nonlinear programming problem

\min~f(\mathbf{x})\quad\mathrm{s.t.}\quad\mathbf{x}\in\Omega.

(2.1)

Definition 2.1
.

We say that
\mathbf{x}^{*}\in\Omega
satisfies Mangasarian-Fromovitz constraint qualification (MFCQ) if
\nabla h_{1}(\mathbf{x}^{*}),\cdots,\nabla h_{p}(\mathbf{x}^{*})
are linearly independent and there exists
\mathbf{d}\in\mathbb{R}^{n}
such that

\langle\nabla g_{i}(\mathbf{x}^{*}),\mathbf{d}\rangle<0,~\forall i\in\mathcal{I}(\mathbf{x}^{*}),~\langle\nabla h_{j}(\mathbf{x}^{*}),\mathbf{d}\rangle=0,~j=1,\cdots,p.

Definition 2.2
.

We say that
\mathbf{x}^{*}\in\Omega
is pseudonormal if there do not exist
\lambda_{1},\cdots,\lambda_{m},\mu_{1},\cdots,\mu_{p}
and
\{\mathbf{x}^{k}\}\subseteq\Omega
such that

(1)

-\left[\sum_{i=1}^{m}\lambda_{i}\nabla g_{i}(\mathbf{x}^{*})+\sum_{j=1}^{p}\mu_{j}\nabla h_{j}(\mathbf{x}^{*})\right]=0
;

(2)

\lambda_{i}\geq 0
for all
i=1,\cdots,m
, and
\lambda_{i}=0
for all
i\notin\mathcal{I}(\mathbf{x}^{*})
;

(3)

\{\mathbf{x}^{k}\}\to\mathbf{x}^{*}
and
\sum_{i=1}^{m}\lambda_{i}g_{i}(\mathbf{x}^{k})+\sum_{j=1}^{p}\mu_{j}h_{j}(\mathbf{x}^{k})>0
,
\forall k
.

Definition 2.3
.

We say that
\mathbf{x}^{*}\in\Omega
satisfies the Abadie CQ if
T_{\Omega}(\mathbf{x}^{*})=L_{\Omega}(\mathbf{x}^{*})
.

Following
[
andreani2012relaxed
,
guo2014new
]
, the relationships among the above three CQs are

\mathrm{MFCQ}\quad\Rightarrow\quad\mathrm{pseudonormality}\quad\Rightarrow\quad\mathrm{Abadie~CQ}.

2.4
Optimality conditions

Based on the above MFCQ, the following Karush-Kuhn-Tucker (KKT) conditions hold.

Lemma 2.1
.

If the MFCQ holds at
\mathbf{x}^{*}\in\Omega
, then
\mathbf{x}^{*}
is a KKT point of problem (
2.1
), that is,

-\nabla f(\mathbf{x}^{*})\in L_{\Omega}(\mathbf{x}^{*})^{\circ}.

Furthermore, inspired by the pseudonormality, it is not hard to obtain the exact penalization theory.

Lemma 2.2
.

If
\mathbf{x}^{*}\in\Omega
is pseudonormal, then
\Omega
admits an exact penalty at
\mathbf{x}^{*}
. That is, if
\mathbf{x}^{*}
is a strictly local minimum of the smooth function
f
over
\Omega
, there exists
\tau>0
such that
\mathbf{x}^{*}
is also a local minimum of
F_{\tau}(\mathbf{x})
.

See
[
bertsekas2002pseudonormality
, Proposition 4.2]
for more details.

3
Exact penalization for problem (
1.1
)

A variety of CQs for the nonlinear programming problem (
2.1
) have been extended to analyze the corresponding CCO problem. In
[
xiao2024optimality
]
, it was shown that the RCPLD condition provides a sufficient condition for error bounds of problem (
1.1
), which in turn implies exact penalization when the objective function is Lipschitz continuous. In addition, the relationships between RCPLD and other CQs were discussed and established.

3.1
Constraint qualifications

Definition 3.1
.

We say that the cardinality constrained Mangasarian-Fromovitz constraint qualification (CC-MFCQ) holds at
\mathbf{x}^{*}\in\Omega\cap S

\nabla_{J}h_{1}(\mathbf{x}^{*}),\cdots,\nabla_{J}h_{p}(\mathbf{x}^{*})

\langle\nabla g_{i}(\mathbf{x}^{*}),\mathbf{d}\rangle<0,~i\in\mathcal{I}(\mathbf{x}^{*}),~\langle\nabla h_{j}(\mathbf{x}^{*}),\mathbf{d}\rangle=0,~j=1,\cdots,p.

From Motzkin’s theorem, for each

,

\sum_{i\in\mathcal{I}(\mathbf{x}^{*})}\lambda_{i}\nabla_{J}g_{i}(\mathbf{x}^{*})+\sum_{j=1}^{p}\mu_{j}\nabla_{J}h_{j}(\mathbf{x}^{*})=0

\mu_{j}=0

,

Let
\mathbf{x}^{*}\in\Omega\cap S
satisfy CC-MFCQ, from
[
rockafellar1998variational
, Theorem 6.14]
, it holds

N_{\Omega\cap S}(x^{*})\subseteq N_{\Omega}(\mathbf{x}^{*})+N_{S}(\mathbf{x}^{*})=L_{\Omega}(\mathbf{x}^{*})^{\circ}+N_{S}(\mathbf{x}^{*}),

(3.1)

where the equality dues to the fact that CC-MFCQ of
\Omega\cap S
results in MFCQ of
\Omega
.
Using (
3.1
) and
[
rockafellar1998variational
, Theorem 6.12]
, we obtain the following optimality condition for problem (
1.1
).

Theorem 3.1
.

Suppose that
\mathbf{x}^{*}\in\Omega\cap S
is a local minimizer of problem (
1.1
) and CC-MFCQ holds at
\mathbf{x}^{*}
. Then
\mathbf{x}^{*}
is a KKT point of problem (
1.1
), i.e.,
there exist
\lambda^{*}\in\mathbb{R}^{m}
and
\mu^{*}\in\mathbb{R}^{p}
such that

\displaystyle\begin{cases}-\nabla f(\mathbf{x}^{*})-\sum_{i=1}^{m}\lambda_{i}^{*}\nabla g_{i}(\mathbf{x}^{*})-\sum_{j=1}^{p}\mu_{j}^{*}\nabla h_{j}(\mathbf{x}^{*})\in\widehat{N}_{S}(\mathbf{x}^{*}),\\
\lambda^{*}_{i}\geq 0,~g_{i}(\mathbf{x}^{*})\leq 0,~\lambda^{*}_{i}g_{i}(\mathbf{x}^{*})=0,~i=1,\cdots,m,\\
\|\mathbf{x}^{*}\|_{0}\leq s.\end{cases}

Now, we extend pseudonormality in Definition
2.2
to problem (
1.1
).

Definition 3.2
.

We say that
\mathbf{x}^{*}
is CC-pseudonormal if here do not exist
\lambda_{1},\cdots,\lambda_{m},\mu_{1},\cdots,\mu_{p}
and sequence
\{\mathbf{x}^{k}\}\subseteq S
such that

(1)

-\left[\sum_{i=1}^{m}\lambda_{i}\nabla g_{i}(\mathbf{x}^{*})+\sum_{j=1}^{p}\mu_{j}\nabla h_{j}(\mathbf{x}^{*})\right]\in N_{S}(\mathbf{x}^{*})
;

(2)

\lambda_{i}\geq 0
for all
i=1,\cdots,m
, and
\lambda_{i}=0
for all
i\notin\mathcal{I}(\mathbf{x}^{*})
;

(3)

\{\mathbf{x}^{k}\}\to\mathbf{x}^{*}
and
\sum_{i=1}^{m}\lambda_{i}g_{i}(\mathbf{x}^{k})+\sum_{j=1}^{p}\mu_{j}h_{j}(\mathbf{x}^{k})>0
,
\forall k
.

3.2
Theoretical guarantee

In
[
xiao2024optimality
]
, local error boundedness and local exact penalization for problem (
1.1
) were established under RCPLD and Lipschitz continuity of the objective function. Notice that pseudonormality does not imply RCPLD
[
andreani2012relaxed
]
in nonlinear programming problems.
In this regard, we prove local exact penalization under CC-pseudonormality without requiring Lipschitz continuity.

Theorem 3.2
.

Assume that
\mathbf{x}^{*}\in\Omega\cap S
is CC-pseudonormal and is a strictly local minimizer of problem (
1.1
). Then there exists
\tau^{*}>0
such that
\mathbf{x}^{*}
is also a local minimizer of problem (
1.2
) for all
\tau>\tau^{*}
.

Proof.

Suppose for contradiction that
\mathbf{x}^{*}
is a strict local minimizer of problem (
1.1
) but not a local minimizer of

\min~~f(\mathbf{x})+k[\|g^{+}(\mathbf{x})\|_{1}+\|h(\mathbf{x})\|_{1}]\quad\mathrm{s.t.}\quad\mathbf{x}\in S

(3.2)

for all
k=1,2,\cdots
. Let
\epsilon>0
and
\mathbf{x}^{*}
is a strict minimizer of

\min~~f(\mathbf{x})\quad\mathrm{s.t.}\quad\mathbf{x}\in\Omega\cap S,~\|\mathbf{x}-\mathbf{x}^{*}\|\leq\epsilon.

(3.3)

Suppose that
\mathbf{x}^{k}\in S
is the minimizer of problem (
3.2
) in the neighborhood
N(\mathbf{x}^{*},\epsilon)
. As
\mathbf{x}^{*}
is not a local minimizer of problem (
3.2
), we can see that
\mathbf{x}^{k}\neq\mathbf{x}^{*}
, which derives that
\mathbf{x}^{k}\notin\Omega
.
Otherwise, if
\mathbf{x}^{k}\in\Omega\cap S
, or
\|g^{+}(\mathbf{x}^{k})\|_{1}=\|h(\mathbf{x}^{k})\|_{1}=0
, it implies that

f(\mathbf{x}^{k})=f(\mathbf{x}^{k})+k[\|g^{+}(\mathbf{x}^{k})\|_{1}+\|h(\mathbf{x}^{k})\|_{1}]\leq f(\mathbf{x}^{*})+k[\|g^{+}(\mathbf{x}^{*})\|_{1}+\|h(\mathbf{x}^{*})\|_{1}]=f(\mathbf{x}^{*}),

which contradicts with
\mathbf{x}^{*}
being a strictly local minimizer of problem (
1.1
).
Thus
\|g^{+}(\mathbf{x}^{k})\|_{1}+\|h(\mathbf{x}^{k})\|_{1}>0
and

f(\mathbf{x}^{k})+k[\|g^{+}(\mathbf{x}^{k})\|_{1}+\|h(\mathbf{x}^{k})\|_{1}]\leq f(\mathbf{x}^{*}).

(3.4)

It follows that
\|g^{+}(\mathbf{x}^{k})\|_{1}+\|h(\mathbf{x}^{k})\|_{1}\to 0
as
k\to\infty
. Since
\{\mathbf{x}^{k}\}
is bounded, let
\overline{\mathbf{x}}
be an accumulation point. Then
\overline{\mathbf{x}}\in\Omega\cap S
and (
3.4
) gives
f(\overline{\mathbf{x}})\leq f(\mathbf{x}^{*})
. Combining this with the fact that
\mathbf{x}^{*}
being a strict minimizer of problem (
3.3
), it is not hard to show that
\overline{\mathbf{x}}=\mathbf{x}^{*}
. Without loss of generality, assume that
\mathbf{x}^{k}
converges to
\mathbf{x}^{*}
. Then for sufficiently large
k
, it holds
\|\mathbf{x}^{k}-\mathbf{x}^{*}\|<\epsilon
. This leads to the the following optimality condition

-\left[\frac{1}{k}\nabla f(\mathbf{x}^{k})+\sum_{i=1}^{m}\lambda_{i}^{k}\nabla g_{i}(\mathbf{x}^{k})+\sum_{j=1}^{p}\mu_{i}^{k}\nabla h_{j}(\mathbf{x}^{k})\right]\in\widehat{N}_{S}(\mathbf{x}^{k}),

(3.5)

where

\lambda_{i}^{k}\left\{\begin{array}[]{lc}=1,&g_{i}(\mathbf{x}^{k})>0,\\
=0,&g_{i}(\mathbf{x}^{k})<0,\\
\in[0,1],&g_{i}(\mathbf{x}^{k})=0,\end{array}\right.\qquad\textrm{and}\qquad\mu_{j}^{k}\left\{\begin{array}[]{lc}=1,&h_{j}(\mathbf{x}^{k})>0,\\
=-1,&h_{j}(\mathbf{x}^{k})<0,\\
\in[-1,1],&h_{j}(\mathbf{x}^{k})=0.\end{array}\right.

(3.6)

Since
\|g^{+}(\mathbf{x}^{k})\|_{1}+\|h(\mathbf{x}^{k})\|_{1}>0
, there exists a subsequence
\{\lambda^{k},\mu^{k}\}_{k\in\mathcal{K}}
such that for all
k\in\mathcal{K}
,
\lambda_{i}^{k}=1
and
g_{i}(\mathbf{x}^{k})>0
for some index
i\in\{1,\cdots,m\}
and
|\mu_{j}^{k}|=1
and
h_{j}(\mathbf{x}^{k})\neq 0
for some index
j\in\{1,\cdots,p\}
. Thus

\sum_{i=1}^{m}\lambda_{i}g_{i}(\mathbf{x}^{k})+\sum_{j=1}^{p}\mu_{j}h_{j}(\mathbf{x}^{k})>0,~\forall k\in\mathcal{K}.

Let
(\lambda^{*},\mu^{*})
be a limit point of this subsequence of
\{(\lambda^{k},\mu^{k})\}
.
Then it holds that
(\lambda^{*},\mu^{*})\neq 0
and
\lambda^{*}\geq 0
.
Passing to the limit in (
3.5
) as
k\to\infty
and using
\widehat{N}_{S}(\mathbf{x}^{k})\to N_{S}(\mathbf{x}^{*})
, we obtain

-\sum_{i=1}^{m}\lambda_{i}^{*}\nabla g_{i}(\mathbf{x}^{*})-\sum_{j=1}^{p}\mu_{j}^{*}\nabla h_{j}(\mathbf{x}^{*})\in N_{S}(\mathbf{x}^{*}).

This contradicts the CC-pseudonormality of
\Omega
at
\mathbf{x}^{*}
. The proof is completed.
∎

New bounds for convergent methods

In this section, we employ the projected subgradient method (PSM) and the corresponding stochastic projected subgradient method (SPSM) to solve problem (

). Furthermore, we derive improved bounds for the convergence analysis.

4.1
Projected subgradient method

The projected subgradient method was adopted in
[
liu2019one
]
to solve problems with cardinality constraints, where the sequence was shown to be bounded, the objective function sequence non-increasing, and convergent to the minimal value. Here, we also apply the projected subgradient method to solve problem (
1.2
), as summarized in Algorithm

. Under the same condition that the objective function of problem (

) is Lipschitz continuous, we establish a tighter bound for the generated sequence than those provided in
[
liu2019one
]

[
allen1987generalization
]
for problems with convex constraints is convergent.

, let

Algorithm 1

Projected subgradient method (PSM) for problem (
1.2
)

Unlike the ordinary gradient method for differentiable objective functions, the subgradient method is not a descent method. Furthermore, the stepsizes in the subgradient method are fixed in advance
[
boyd2003subgradient
]
, rather than being selected via a line search as in the ordinary gradient method. The following types of stepsize rules are commonly used

\alpha_{k}=\alpha;

(4.1)

\alpha_{k}=s/\|\mathbf{d}^{k}\|;

(4.2)

\alpha_{k}\geq 0,~\sum_{i=1}^{\infty}\alpha_{k}=\infty,~\sum_{i=1}^{\infty}\alpha_{k}^{2}<\infty;

(4.3)

\alpha_{k}=s_{k}(F_{\tau}^{k}-\rho)/\|\mathbf{d}^{k}\|^{2},

(4.4)

where
\mathbf{x}^{*}
is an optimal solution of problem (
1.2
) and
F_{\tau}^{*}=F_{\tau}(\mathbf{x}^{*})
satisfying

\rho\geq F_{\tau}^{*}+L_{\tau}\|\mathbf{x}^{*}\|,~F_{\tau}^{k}>\rho,~0<s_{k}\leq\beta<2,~\sum_{i=1}^{\infty}s_{i}=\infty

(4.5)

and
\beta
is a fixed constant
[
allen1987generalization
]
.

Throughout this section, we make the following assumption for problem (
1.1
).

Assumption 4.1
.

Functions
f
,
g_{i}~(i=1,\cdots,m)
, and
h_{j}~(j=1,\cdots,p)
are Lipschitz continuous and convex on
\mathbb{R}^{n}
.

If Assumption
4.1
holds, then there exists a constant
L_{\tau}>0
such that

\|F_{\tau}(\mathbf{y})-F_{\tau}(\mathbf{x})\|\leq L_{\tau}\|\mathbf{y}-\mathbf{x}\|,\ \forall\ \mathbf{x},\mathbf{y}\in\mathbb{R}^{n},

which is equivalent to
\|\mathbf{d}\|\leq L_{\tau}
for each
\mathbf{d}\in\partial F_{\tau}(\mathbf{x})
and
\mathbf{x}\in\mathbb{R}^{n}
. It is easy to see that if functions
f
,
g_{i}~(i=1,\cdots,m)
, and
h_{j}~(j=1,\cdots,p)
are convex, then the function
F_{\tau}
is also convex.

In order to prove the convergence of PSM, we need the following lemma. This lemma makes us give tighter bounds of the generating sequence than the bounds in
[
liu2019one
]
and the objective values are smaller at the same time.

Lemma 4.1
.

Let sequence
\{\mathbf{x}^{k}\}
be generated by PSM and denote
\mathbf{z}^{k}:=\mathbf{x}^{k}-\alpha_{k}\mathbf{d}^{k}
. Then for any
k\geq 1
, we have

\displaystyle\|\mathbf{x}^{k+1}-\mathbf{x}^{*}\|^{2}

\displaystyle=\|\mathbf{x}^{k}-\mathbf{x}^{*}\|^{2}+\alpha_{k}^{2}\|\mathbf{d}^{k}\|^{2}-\|\mathbf{x}^{k+1}-\mathbf{z}^{k}\|^{2}

(4.6)

\displaystyle-2\langle\mathbf{x}^{k+1}-\mathbf{z}^{k},\mathbf{x}^{*}\rangle+2\alpha_{k}\langle\mathbf{d}^{k},\mathbf{x}^{*}-\mathbf{x}^{k}\rangle.

Proof.

From
\mathbf{x}^{k+1}=\mathrm{\Pi}_{S}(\mathbf{z}^{k})
and the property of projection onto sparse set,
if we denote
\Gamma^{k+1}=\Gamma(\mathbf{x}^{k+1})
, then

\mathbf{x}^{k+1}=((\mathbf{x}^{k+1})_{\Gamma^{k+1}},{\bf{0}})=((\mathbf{z}^{k})_{\Gamma^{k+1}},\bf{0})
, which
yields that

\|\mathbf{x}^{k+1}-\mathbf{z}^{k}\|^{2}=\|(\mathbf{z}^{k})_{\overline{\Gamma}^{k+1}}^{k+1}\|^{2}
.
Then it holds that

\langle\mathbf{x}^{k+1}-\mathbf{z}^{k},\mathbf{z}^{k}\rangle=-\|\mathbf{x}^{k+1}-\mathbf{z}^{k}\|^{2}.

(4.7)

We can deduce that

\displaystyle\|\mathbf{x}^{k+1}-\mathbf{x}^{*}\|^{2}

\displaystyle=\|\mathbf{x}^{k+1}-\mathbf{x}^{k}+\mathbf{x}^{k}-\mathbf{x}^{*}\|^{2}

\displaystyle=\|\mathbf{x}^{k}-\mathbf{x}^{*}\|^{2}+\|\mathbf{x}^{k+1}-\mathbf{x}^{k}\|^{2}+2\langle\mathbf{x}^{k+1}-\mathbf{x}^{k},\mathbf{x}^{k}-\mathbf{x}^{*}\rangle

\displaystyle=\|\mathbf{x}^{k}-\mathbf{x}^{*}\|^{2}+\|\mathbf{x}^{k+1}-\mathbf{z}^{k}+\mathbf{z}^{k}-\mathbf{x}^{k}\|^{2}+2\langle\mathbf{x}^{k+1}-\mathbf{z}^{k}+\mathbf{z}^{k}-\mathbf{x}^{k},\mathbf{x}^{k}-\mathbf{x}^{*}\rangle

\displaystyle=\|\mathbf{x}^{k}-\mathbf{x}^{*}\|^{2}+\|\mathbf{x}^{k+1}-\mathbf{z}^{k}\|^{2}+\alpha_{k}^{2}\|\mathbf{d}^{k}\|^{2}+2\langle\mathbf{x}^{k+1}-\mathbf{z}^{k},\mathbf{z}^{k}-\mathbf{x}^{k}\rangle

\displaystyle+2\langle\mathbf{x}^{k+1}-\mathbf{z}^{k},\mathbf{x}^{k}-\mathbf{x}^{*}\rangle+2\langle\mathbf{z}^{k}-\mathbf{x}^{k},\mathbf{x}^{k}-\mathbf{x}^{*}\rangle

\displaystyle=\|\mathbf{x}^{k}-\mathbf{x}^{*}\|^{2}+\|\mathbf{x}^{k+1}-\mathbf{z}^{k}\|^{2}+\alpha_{k}^{2}\|\mathbf{d}^{k}\|^{2}+2\langle\mathbf{x}^{k+1}-\mathbf{z}^{k},\mathbf{z}^{k}\rangle-2\langle\mathbf{x}^{k+1}-\mathbf{z}^{k},\mathbf{x}^{k}\rangle

\displaystyle+2\langle\mathbf{x}^{k+1}-\mathbf{z}^{k},\mathbf{x}^{k}\rangle-2\langle\mathbf{x}^{k+1}-\mathbf{z}^{k},\mathbf{x}^{*}\rangle-2\langle\alpha_{k}\mathbf{d}^{k},\mathbf{x}^{k}-\mathbf{x}^{*}\rangle

\displaystyle\hbox{}\hfill{{\hbox{$\begin{array}[c]{@{}c@{}}\overset{\eqref{projS1}}{=}\end{array}$}}}\hfill\hbox{}\|\mathbf{x}^{k}-\mathbf{x}^{*}\|^{2}+\|\mathbf{x}^{k+1}-\mathbf{z}^{k}\|^{2}+\alpha_{k}^{2}\|\mathbf{d}^{k}\|^{2}-2\|\mathbf{x}^{k+1}-\mathbf{z}^{k}\|^{2}

\displaystyle-2\langle\mathbf{x}^{k+1}-\mathbf{z}^{k},\mathbf{x}^{*}\rangle+2\alpha_{k}\langle\mathbf{d}^{k},\mathbf{x}^{*}-\mathbf{x}^{k}\rangle

\displaystyle=\|\mathbf{x}^{k}-\mathbf{x}^{*}\|^{2}+\alpha_{k}^{2}\|\mathbf{d}^{k}\|^{2}-\|\mathbf{x}^{k+1}-\mathbf{z}^{k}\|^{2}-2\langle\mathbf{x}^{k+1}-\mathbf{z}^{k},\mathbf{x}^{*}\rangle+2\alpha_{k}\langle\mathbf{d}^{k},\mathbf{x}^{*}-\mathbf{x}^{k}\rangle.

The proof is finished.
∎

where

\underline{F}^{k}_{\tau}:=\min\{F_{\tau}(\mathbf{x}^{1}),\cdots,F_{\tau}(\mathbf{x}^{k})\}.

(4.8)

Under the same conditions, we have the following results.

Proof.

It follows from the convexity of
