 Abstract
 Heavy-flavor jets, which are initiated from heavy quarks, are ideal probes for studying flavor-
 dependent parton energy loss. We report on the performance of jet flavor tagging using two
 Neural Network Machine Learning (ML) models: the Long Short-Term Memory (LSTM) model
 and an Attention-based Neural Network, in simulations of 200 GeV p + p collisions. The tagging
 performance of bottom quark initiated jets with both ML models surpasses that of the traditional
 cut-based method. Technical details, including sample and kinematic variable selections, the
 machine learning training and testing setup with parameter tuning, and outcome comparisons,
 will be discussed.

1 Motivation
Heavy quarks, such as charm and beauty, produced in the early stages of collisions serve as excellent
probes for studying the Quark-Gluon Plasma (QGP). Due to their large current mass, their produc-
tion cross section can be directly compared with perturbative Quantum Chromodynamics (pQCD)
calculations, offering a valuable test of theoretical predictions. The study of heavy-flavor (HF) jets
provides crucial insights into several key QGP phenomena, including collisional energy loss, the fla-
vor and mass dependence of jet quenching, and the modification of HF hadronization, fragmentation,
and flow within the QGP medium. These investigations contribute to a deeper understanding of the
fundamental properties of strongly interacting matter under extreme conditions.

2 Data set and Cuts
At sPHENIX, two heavy flavor jet tagging methods have been developed. The first treats heavy flavor
hadron seeded jets, such as D0 tagged jets, as heavy flavor jets [1]. The second scans charged particle
decay related kinematic variables (such as the Distance of Closest Approach) within the jets to tag
their flavor [2]. For studies in this analysis note, we adopt the second method. We use the Run 22 and
23 simulation dataset consists of proton-proton (p+p) collisions at 200 GeV, generated using PYTHIA
8 and GEANT 4. We selected the inclusive jet dataset sample without pile-up effects, and focus on
10 and 30 GeV jet events with track-only jets, as processed by Jakub. Jet reconstruction is performed
using the anti-kT algorithm with a radius parameter of R = 0.4. The simulation initially includes
approximately 3 million 10 GeV jet events. After the truth-matching jet selection, around 1.74 million
reconstructed jet samples remain, providing a robust dataset for detailed jet analysis. Here is the
detailed cuts:
 • Truth jet pT > 10(30) GeV/c

    • Reco. jet pT > 5(15) GeV/c
    • Jet area > 0.3, Jet |η| < 0.7
 • Jet constituents:

 – Track pT > 0.2 GeV/c

 1

 – χ2 /NDF < 5
 – Number of MVTX hits ≥ 2
 – Number of INTT hits ≥ 1
 – Number of TPC hits ≥ 30
 The jet identification (Jet ID) is determined based on the presence of truth hadronic constituents,
categorizing jets according to their flavor content.
 • ID = 0: Light flavor jet (no heavy-flavor hadrons)
 • ID = 1: Jet containing a charm hadron

 • ID = 2: Jet containing a bottom hadron (including cases with charm hadrons)
If a jet contains a bottom hadron, it is labeled ID = 2, regardless of whether it also includes a charm
hadron.

3 Data driven signed sDCAT approach
To identify the flavor of jets, we use signed significance of the track-to-primary-vertex distance
of closest approach (DCA) in the transverse plane, denoted as SDCA2D . Mathematically, the
signed significance of the transverse DCA is defined as:

 Its significance is given by the DCA in the transverse plane between the track and the primary
vertex, divided by its uncertainty. This normalization ensures that the value represents a statistical
measure of deviation. The sign is determined by the signum function(sgn) of the scalar product
between the jet axis and the DCA vector. Ideally, tracks originating from the primary vertex should
have sgn = 0. However, due to finite detector resolution, some tracks will exhibit both positive
(+1) and negative (-1)) values, even if they originated from the primary vertex. In contrast, tracks
originating from secondary decays, such as those from charm or bottom hadrons, will predominantly

4 Machine Learning Approach
4.1 LSTM neural networks
Long Short-Term Memory (LSTM) neural networks are designed to handle variable-length sequential
input by utilizing cell states that retain memory of previous inputs. The architecture consists of gates
that regulate the flow of information. At each time step t, the previous hidden state (ht−1 ) and the
current input (Xt ) contribute to the computation of four key components: the forget gate (ft ), the
input gate (it ), the cell candidate (C̃t ), and the output gate (Ot ). These gates control how information
is updated, remembered, or discarded.

number of true events. It measures how well the model is identifying the relevant signals from the

 • True Positive: A HF jet (b-jet) correctly identified as an HF jet (b-jet).

4.2.1 Model architecture
An another model has been developed to perform the classification. We propose a hybrid neural
architecture that combines global jet-level and event-level features with track-level features using dual-
encoder structure followed by a joint classification head. The model is designed to capture effectively
both summary-level information and variable per-track dynamics within the jets.
 The track encoder architecture is following: First each track is linearly projection into hidden
space of dimension d. After, a single-head self-attention layer [?] is applied to capture the relation
between tracks. Finally, a query-based attention pooling layer [?] is added to perform cross-attention

aggregating the track information into a single vector. To handle variable-length track sequences, a
binary padding mask is computed over the track input. This mask is passed to both self-attention and
pooling-attention layers ensuring the model ignores padded (zeroed) tracks.
 The jet classifier consist of fully connected feed-forward network with ReLU activation to project
the jet-wise and event-wise features into hidden dimension d. a shared representation is created by
concatenating the two encoded branches into a dimension 2d. This is passed though two layer Multi-
layer Perceptron (MLP), first layer 2d → d with ReLU activation, and second layer d → N , where
N = 1 while classifying LF vs HF jets or N = 3 while classifying LF vs C vs B. The hidden dimension
d was a sampled hyperparameter.
 BCEWithLogitsLoss loss function with sigmoid activation function was used for the binary classifi-
cation and CrossEntropyLoss function with softmax was used in the multiclass classification. Since the
distribution of flavors in a dataset is heavily imbalanced a class weighting parameter was provided and
sampled during tuning. Adam optimizer was used for the minimization. The main metric to evaluate
the quality of the model is AUC-PRC.

5 Summary
We analyzed 10 GeV and 30 GeV jet samples from p + p collisions at 200 GeV using sPHENIX
simulations. Charm and bottom jets can ben successfully identified at large signed-DCA values by
employing the data-driven signed-DCA method. Additionally, the application of machine learning

 10

approaches, meaning both the LSTM and the ANN models, can significantly enhance the bottom jet
tagging efficiency at comparable jet tagging purity with the cut method. The heavy jet tagging ML
methods will be applied in calibrated sPHENIX 200 GeV p+p data and will be optimized for the 200
GeV Au+Au data set.
