Abstract
. We establish new quantitative estimates for general systems of functions with wavelet-type dyadic structure. These estimates are applied to obtain the optimal growth of various types of Weyl multipliers for certain wavelet-type systems. Some of our results are sufficiently general to allow the orthogonality assumption to be removed. In particular, as a consequence of these estimates we show that the condition ∑ n = 1 ∞ 1 n ​ w ​ ( n ) < ∞ \sum_{n=1}^{\infty}\frac{1}{nw(n)}<\infty is necessary and sufficient for an increasing sequence w ⁡ ( n ) w(n) to be an almost everywhere unconditional convergence Weyl multiplier for an arbitrary wavelet-type system. We also prove that log ⁡ n \log n is an almost everywhere convergence Weyl multiplier for any rearranged wavelet-type system, and that this bound is optimal.

1.2.
New results

In the present paper, we establish certain quantitative estimates for wavelet-type systems of both convergence and divergence type. These results are then applied to the characterization of RC and UC multipliers for such systems. Some of the results are sufficiently general to allow the orthogonality assumption to be dropped.

We now state the main results of the paper. We call a constant admissible if it is either an absolute constant or depends only on the parameters from the definition of wavelet-type system. Then the notation
a\lesssim b
will stand for the inequality
a<cb
, where
c
is an admissible constant. Let
\Phi\in L^{1}(\mathbb{R})
be an arbitrary function. For integers

\Phi_{m,l}(x)=2^{m/2}\Phi(2^{m}x-l).

Let

Lemma 2.1

\displaystyle\left\|f_{k}\right\|_{L^{2}(E_{m+1})}^{2}\leq\frac{1}{2}\cdot\|f_{k}\|_{L^{2}(E_{m})}^{2},\quad k\leq m<N.

Then

(2.21)

\left\|\sum_{k=1}^{N}f_{k}\right\|_{2}^{2}\leq 3\sum_{k=1}^{n}\left\|f_{k}\right\|_{2}^{2}.

Proof.

If
1\leq k<m\leq N
, then using (
2.20
), we obtain

(2.22)

\displaystyle\left|\int_{0}^{1}f_{k}f_{m}\right|=

\displaystyle\left|\int_{E_{m}}f_{k}f_{m}\right|

(2.23)

\displaystyle\leq\|f_{k}\|_{L^{2}(E_{m})}\|f_{m}\|_{L^{2}}\leq 2^{k-m}\|f_{k}\|_{2}\|f_{m}\|_{2}

(2.24)

\displaystyle\leq 2^{k-m-1}(\|f_{k}\|_{2}^{2}+\|f_{m}\|_{2}^{2}).

Therefore,

\displaystyle\left\|\sum_{k=1}^{N}f_{k}\right\|_{2}^{2}

\displaystyle\leq\sum_{k=1}^{N}\|f_{k}\|_{2}^{2}+\sum_{m\neq k}\left|\int_{0}^{1}f_{k}f_{m}\right|

\displaystyle\leq\sum_{k=1}^{N}\|f_{k}\|_{2}^{2}+\sum_{m\neq k}2^{|k-m|-1}(\|f_{k}\|_{2}^{2}+\|f_{m}\|_{2}^{2})

\displaystyle\leq 3\sum_{k=1}^{N}\|f_{k}\|_{2}^{2}.

∎

3.
Tree system of functions

Recall the following definition from
[
12
]
.

Definition 3.1
.

A finite or countable family of functions on
\mathbb{R}
is called a tree system if it admits an ordering
\{f_{n}:\,n=1,2,\ldots\}
(which we call a canonical ordering) such that for any
n
there exist pairwise disjoint sets
U_{n}^{+},U_{n}^{-}\subset\mathbb{R}
with the following properties: for any positive integers
n
and
k<n
one of the following three conditions holds:

(3.1)

U_{n}\subset U_{k}^{+},\quad U_{n}\subset U_{k}^{-},\quad U_{n}\cap U_{k}=\varnothing\quad(\text{where }U_{n}=U_{n}^{+}\cup U_{n}^{-}).

Moreover,

(3.2)

\displaystyle\{x:\,f_{n}(x)>0\}\subset U_{n}^{+},\quad\{x:\,f_{n}(x)<0\}\subset U_{n}^{-}.

Definition 3.2
.

A partition of
\mathbb{R}
is a collection of intervals
\mathcal{F}=\{I_{j}=[a_{j-1},a_{j}):\,j\in\mathbb{Z}\}
, where

(3.3)

a_{k}\to+\infty,\quad a_{-k}\to-\infty\text{ as }k\to+\infty.

For two partitions
\mathcal{F}
and
{\mathcal{C}}
we write
\mathcal{F}\prec{\mathcal{C}}
if every intervals of
\mathcal{F}
is a union of some intervals of
{\mathcal{C}}
.

Definition 3.3
.

An interval
I=[a,b)
is said to be sign-preserving for a function
f\in C(\mathbb{R})
, if one of these conditions

f(x)\geq 0,\quad f(x)\leq 0

holds for every
x\in I
. A partition
\mathcal{F}
is called sign-preserving for a function
f\in C(\mathbb{R})
, is each interval from
\mathcal{F}
is sign-preserving for
f
.

Lemma 3.1
.

Let
\mathcal{F}_{n}=\{J_{n,j}:\,j\in\mathbb{Z}\}
and
{\mathcal{C}}_{n}=\{I_{n,j}:\,j\in\mathbb{Z}\}
,
n\in\mathbb{Z}
, be sequences of partitions such that
\mathcal{F}_{n}\prec{\mathcal{C}}_{n}\prec\mathcal{F}_{n+1}
, and suppose that a function system

(3.4)

\{f_{n,j},\quad n,j\in\mathbb{Z}\}

satisfies the conditions

(3.5)

\displaystyle{\rm supp\,}(f_{n,j})\subset J_{n,j},

(3.6)

\displaystyle{\mathcal{C}}_{n}\text{ is a sign-preserving partition for all functions }f_{n,j},\,j\in\mathbb{Z}.

Then the system (
3.4
) is a tree system.

Proof.

Consider an ordering

(3.7)

\ldots,g_{-n},g_{-n+1},\ldots,g_{0},g_{1},\ldots,g_{m},\ldots

of the system (
3.4
) with a property that a function
f_{n,j}
precedes
f_{m,i}
whenever
n<m
. Suppose that
g_{k}=f_{n,j}
. Since
{\mathcal{C}}_{n}
is a sign-preserving partition for
f_{n,j}
, we define
U_{k}^{+}
to be the union of those intervals
I\in{\mathcal{C}}_{n}
on which
f_{n,j}\geq 0
and is not identically zero, and
U_{k}^{-}
to be the union of those interval, where
f_{n,j}\leq 0
and is not identically zero. With this definition the conditions in (
3.2
) are satisfied. Let
g_{k}=f_{s,j}
,
g_{n}=f_{t,i}
and
k<n
. If
s=t
, then by (
3.5
) we have
U_{n}\cap U_{k}=\varnothing
, thus the third condition in (
3.1
) is satisfied. Otherwise we have
s<t
and clearly one of two first conditions in (
3.1
) holds. Indeed, by the definition both
U_{k}^{+}
and
U_{k}^{-}
are union of some elements of
{\mathcal{C}}_{n}
, while
U_{n}
is contained in an interval in
\mathcal{F}_{n}
. Since
\mathcal{F}_{n}\prec{\mathcal{C}}_{k}
we will either have
U_{n}\subset U_{k}^{+}
or
U_{n}\subset U_{k}^{-}
. Therefore the system (
3.4
) is a tree system.
∎

The following lemma is a version of a lemma from
[
12
]
.

Lemma 3.2
.

If

(3.8)

\{f_{k}:\,k=1,2,\ldots,N\}

is a finite tree system on
\mathbb{R}
, then there exists a permutation
\sigma
(a one to one mapping from the set
\{1,2,\ldots,N\}
onto itself) such that

\max_{1\leq p<q\leq N}\left|\sum_{k=p}^{q}f_{\sigma(k)}(x)\right|\geq\frac{1}{2}\sum_{k=1}^{N}|f_{k}(x)|\text{ for all }x\in\mathbb{R}.

Proof.

Without loss of generality, we may assume that (
3.8
) is the canonical ordering of the given tree system. To construct the desired permutation
\sigma
we rearrange the functions in (
3.8
) so that

(3.9)

\displaystyle U_{k}\subset U^{+}_{n}\Rightarrow f_{k}\text{ precedes }f_{n},

(3.10)

\displaystyle U_{k}\subset U^{-}_{n}\Rightarrow f_{k}\text{ follows }f_{n}.

Assume inductively we found an ordering for the first
m
functions
f_{j}
such that (
3.9
) and (
3.10
) hold for all indices
1\leq k,n\leq m
. We determine the position of
f_{m+1}
relative to the functions

(3.11)

f_{1},f_{2},\ldots,f_{m}

as follows. We partition the functions in (
3.11
) into three groups. The first groups consists of those
f_{n}
for which
U_{m+1}\subset U_{n}^{-}
. The second group consists of those
f_{k}
such that
U_{m+1}\subset U_{k}^{+}
. The remaining functions form the third group. Observe that for any
f_{n}
from the first group and
f_{k}
from the second group, we have, we have
U_{k}^{+}\cap U_{n}^{-}\neq\varnothing
. Then, by the definition of tree system (see (
3.1
)), one of the following relations must hold:

(3.12)

U_{k}\subset U_{n}^{-},\quad U_{n}\subset U_{k}^{+}.

In view of (
3.9
) and (
3.10
), both cases imply that
f_{k}
follows
f_{n}
. Furthermore, if
f_{j}
belongs to the third group, then by property (
3.1
),
U_{m+1}\cap U_{j}=\varnothing
. Consequently, we may place
f_{m+1}
after all elements of the first group and before all elements of the second group, while its position relative to the third group is irrelevant. It is straightforward to verify that the relations (
3.9
) and (
3.10
) are then satisfied for all indices
1\leq k,n\leq m+1
. Hence we complete the induction that yields an ordering satisfying (
3.9
) and (
3.10
). This defines the permutation
\sigma
such that

(3.13)

\displaystyle U_{k}\subset U^{+}_{n}\Rightarrow\sigma(k)<\sigma(n),

(3.14)

\displaystyle U_{k}\subset U^{-}_{n}\Rightarrow\sigma(k)>\sigma(n).

For any
x\in\mathbb{R}
there are mutually disjoint subsets
A
and
B
of
\{1,2,\ldots,N\}
, such that

\displaystyle x\in U^{-}_{j},\text{ if }j\in A,

\displaystyle x\in U^{+}_{j},\text{ if }j\in B,

\displaystyle x\not\in U_{j}\text{ if }j\not\in A\cup B.

Observe that if
n\in A
and
k\in B
then
\sigma(k)>\sigma(n)
. Indeed, since
x\in U^{+}_{k}\cap U^{-}_{n}\neq\varnothing
, by property (
3.1
) one of the conditions in (
3.12
) holds. Using (
3.13
), (
3.14
) both cases of (
3.12
) yield
\sigma(k)>\sigma(n)
. Since we also have
f_{j}(x)=0
as
j\notin A\cup B
, for an appropriate integer
l=l(x)
we have

\sum_{k=1}^{l}f_{\sigma(k)}(x)=\sum_{j\in A}f_{j}(x),\quad\sum_{k=l+1}^{n}f_{\sigma(k)}=\sum_{j\in B}f_{j}(x).

Moreover, the terms in the first sum are all non-positive, while in the second sum are non-negative. This implies that

(3.15)

\displaystyle\max_{1\leq p<q\leq n}\left|\sum_{k=p}^{q}f_{\sigma(k)}(x)\right|

\displaystyle\geq\max\left\{\sum_{j=1}^{l}|f_{\sigma(j)}(x)|,\sum_{j=l+1}^{n}|f_{\sigma(j)}(x)|\right\}

(3.16)

\displaystyle\geq\frac{1}{2}\cdot\sum_{k=1}^{m}|f_{k}(x)|

that completes the proof of lemma.
∎

Applying Theorem
1.1
with
\Phi(x)=\xi(x)
, we get

(6.4)

\displaystyle\left\|\delta_{k}\right\|_{2}

\displaystyle\leq\left\|\sum_{j=2^{k}+1}^{2^{k+1}}|a_{j}\phi_{j}(x)|\right\|_{2}\lesssim\left\|\sum_{j=2^{k}+1}^{2^{k+1}}|a_{j}|\Phi_{m_{n},l_{n}}\right\|_{2}^{2}\lesssim k\sum_{j=2^{k}+1}^{2^{k+1}}a_{j}^{2}.

Therefore,

\displaystyle\sum_{k=1}^{\infty}\int_{\mathbb{R}}\delta_{k}^{2}(t)dt\lesssim\sum_{k=1}^{\infty}k\sum_{j=2^{k}+1}^{2^{k+1}}a_{j}^{2}\lesssim\sum_{n=1}^{\infty}a_{n}^{2}\log n<\infty.

This implies that

(6.5)

\lim_{k\to\infty}\max_{2^{k}\leq m<2^{k+1}}\left|\sum_{j=2^{k}}^{m}a_{j}\phi_{j}(x)\right|=0\text{ almost everywhere.}

Let

\sum_{k=1}^{\infty}\int_{\mathbb{R}}\left|f(t)-S_{2^{k}}(t)\right|^{2}dt=\sum_{k=1}^{\infty}\sum_{j=2^{k+1}+1}^{\infty}a_{j}^{2}\lesssim\sum_{j=1}^{\infty}a_{j}^{2}\log j<\infty.

This implies almost everywhere convergence of the sequence

).
