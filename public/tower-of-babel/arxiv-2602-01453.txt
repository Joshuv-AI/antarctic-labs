Provable Cooperative Multi-Agent Exploration for Reward-Free MDPs
Idan Barnea, Orin Levy, Yishay Mansour

Abstract
We study cooperative multi-agent reinforcement learning in the setting of reward-free exploration, where multiple agents jointly explore an unknown MDP in order to learn its dynamics (without observing rewards). We focus on a tabular finite-horizon MDP and adopt a phased learning framework. In each learning phase, multiple agents independently interact with the environment. More specifically, in each learning phase, each agent is assigned a policy, executes it, and observes the resulting trajectory. Our primary goal is to characterize the tradeoff between the number of learning phases and the number of agents, especially when the number of learning phases is small. Our results identify a sharp transition governed by the horizon H H . When the number of learning phases equals H H , we present a computationally efficient algorithm that uses only O ~ ​ ( S 6 ​ H 6 ​ A / ϵ 2 ) \tilde{O}(S^{6}H^{6}A/\epsilon^{2}) agents to obtain an ϵ \epsilon approximation of the dynamics (i.e., yields an ϵ \epsilon -optimal policy for any reward function). We complement our algorithm with a lower bound showing that any algorithm restricted to ρ < H \rho<H phases requires at least A H / ρ A^{H/\rho} agents to achieve constant accuracy. Thus, we show that it is essential to have an order of H H learning phases if we limit the number of agents to be polynomial.

Introduction

Modern learning systems increasingly rely on multiple agents that cooperate to explore and learn about an unknown dynamic environment.
Such cooperative multi-agent settings arise naturally in robotics and distributed control

(
18
)
,
as well as in large language model (LLM) fine-tuning, where a central challenge lies in constructing a high-quality dataset.
This dataset is typically collected once and subsequently reused to train models across a wide range of downstream objectives (see, e.g.,
(
6
;
12
)
).

The above scenarios motivate the study of
cooperative multi-agent reinforcement learning (RL)

(
13
)
, in which multiple agents interact with an unknown environment in parallel.
This literature extends the classical RL framework based on tabular finite-horizon Markov decision processes (MDPs) to settings where several agents operate on independent copies of the same MDP and share the information they collect.

Finite-horizon MDPs are defined by finite state and action spaces, initial state, transition dynamics and reward function. The action selection strategy of an agent is referred to as
policy
.
Each single-agent episode is defined by
H
interaction steps with the MDP, described by a single
trajectory
. At each step, every agent observes the current state it reaches and selects an action according to its own policy, which may differ across agents.
The agent then observes a reward associated with the current state and action and transitions to a next state.
All agents experience rewards and transitions governed by the same reward function and transition dynamics of the shared MDP.
The learning algorithm has access to the trajectories generated by all agents and can leverage this aggregated experience to update the agents’ policies.

However, in many realistic settings as described earlier, the reward function is not specified during data collection, or multiple reward functions may later be of interest for the same environment.
This naturally motivates adopting the
reward-free exploration
setup
(
10
)
.

In reward-free exploration, the goal is to learn the transition dynamics of the environment itself. Rather than optimizing the environment’s particular cumulative reward collected during an episode, the learner ignores rewards and focuses on collecting data that enables an accurate estimation of the underlying dynamics.

Crucially, the learned model should be accurate enough so that, for any reward function revealed after data collection, it can be used to reliably evaluate and optimize policies. In particular, planning with the learned dynamics should yield an accurate approximation of the optimal expected cumulative reward, i.e., the
value
of the best policy under the true dynamics of the environment and the given reward function.
Since interaction with the environment is often costly, a central objective in reward-free exploration is to achieve this guarantee using as few trajectories as possible.

In this work, we study the novel setting of
cooperative multi-agent reward-free exploration
;
In which, multiple agents explore the environment in parallel under the coordination of a centralized reward-free exploration algorithm, with the shared objective of efficiently learning the underlying dynamics.
To model parallel interaction, we gather parallel episodes into

learning phases
, where a learning phase consists of a round of simultaneous
m
single-agent episodes in which each of the
m
agents interacts with an independent environment and collects a trajectory without observing the rewards.
The centralized learning algorithm aggregates the data collected by all agents in each phase to update its estimate of the environment dynamics and the agents’ exploration policies in the next phase.

In this setting, learning efficiency is governed by two key resources.
The first is the
parallel time
, measured by the number of learning phases, which determines the distributed computation time required for data collection.
The second is the
agent complexity
, measured by the number of agents interacting with the environment in each learning phase, which captures the degree of parallelism available to the learning algorithm.
These two resources are inherently coupled, giving rise to a fundamental trade-off between parallel time and agent complexity.
At one extreme, when parallel time is unlimited, reward-free exploration can be done sequentially using a single agent (recovering the classical reward-free literature, e.g.,
(
10
;
15
;
11
)
).
At the other extreme, aggressively limiting parallel time, e.g., to a constant number of learning phases, requires deploying an exponential number of agents (as shown by our lower bound, presented in the sequel).

In this work, we study the fundamental question of
how to balance parallel time and agent complexity to achieve reward-free guarantees as efficiently as possible
, characterizing how parallelism can accelerate exploration and identifying regimes with a favorable trade-off between these two resources.

Our contributions.

We study cooperative multi-agent reward-free exploration in tabular Markov decision processes (MDPs) with
S
states and
A
actions, where each episode has a finite horizon of length
H
.
Our central focus is understanding the trade-off between
parallel time
, measured by the number of learning phases
\rho
, and
agent complexity
, measured by the number of agents
m
in each learning phase.

Our results reveal a sharp transition in this trade-off at the horizon scale
H
.
Specifically, when
\rho=H

In contrast, when the number of learning phases is reduced below the horizon, i.e.,
\rho\ll H
, any reward-free algorithm necessarily requires that the number of agents grows exponentially in
H/\rho
.
Concretely, our main technical contributions are:

•

Upper bound.

We present
MARFE
, a computationally efficient cooperative multi-agent reward-free exploration algorithm that performs layer-wise exploration of the unknown dynamics.
The algorithm operates using exactly
\rho=H
learning phases.
We prove that, when deploying

m=\tilde{O}(S^{6}H^{6}A/\epsilon^{2})
agents per phase, the learned dynamics model guarantees for any given reward function an
\epsilon
-optimality of the resulting policy, with high probability.

•

Lower bound.

We prove that reducing the number of learning phases significantly below the horizon fundamentally limits parallel efficiency.
In particular, any algorithm that uses
\rho\ll H
learning phases must deploy at least

m=\Omega\left(A^{H/\rho}/\rho\right)
agents.
This lower bound shows that
H

Preliminaries

We study
reward-free exploration in a cooperative multi-agent reinforcement learning setting
.
We begin by defining the single-agent MDP and the notion of reward-free exploration, which will later be extended to the multi-agent case.

Markov Decision Process.

An episodic finite-horizon
Markov Decision Process
(MDP)
\mathcal{M}
is formally defined as a tuple

\mathcal{M}=(\mathcal{S},s_{0},\mathcal{A},H,P,r)

where
\mathcal{S}
is a finite state space with
S
states,
s_{0}\in\mathcal{S}
is the initial state
2
2

2

Without loss of generality, we assume an initial-state distribution at the first timestep.
,
\mathcal{A}
is a finite action space contains
A
actions,
H
is the episode horizon length,

P=\{P_{h}\}_{h=0}^{H-1}
is the transition dynamics, and
r=\{r_{h}\}_{h=0}^{H-1}
is the reward function.

The transition dynamics
P
are stochastic and unknown.
They specify the transition probabilities at each timestep
h\in[H-1]
(where
[H-1]:=\{0,\ldots,H-1\}
).
At each timestep
h
, for a given state
s
and action
a
, the next state
s^{\prime}
is drawn according to

P_{h}(s^{\prime}\mid s,a)
.

The expected reward at timestep
h
is given by

r_{h}(s,a)=\mathbb{E}\left[R_{h}(s,a)\right],

where
R_{h}(s,a)\in[0,1]
is a random variable sampled from an unknown reward distribution associated with
(h,s,a)
.

An episode is a single run of interaction with the MDP.
The sequence of states visited, actions chosen and reward observed defines the trajectory observed in the episode,
(s_{0},a_{0},r_{0},s_{1},a_{1},r_{1},\ldots,s_{H})
, where
s_{h},a_{h},r_{h}
denote state, action and reward observed at timestep
h
.

Policies and values.

A (deterministic Markovian)
policy
defines a mapping from timestep
h
and state
s
to an action. i.e.,

\pi:\mathcal{S}\times[H-1]\rightarrow\mathcal{A}
.
We denote by
\pi_{h}(s)=\pi(s,h)
the action selected by
\pi
for state
s
at timestep
h
.
For MDP
\mathcal{M}
with dynamics
P
and reward
r
, the value of a policy
\pi
from the initial state
s_{0}
is given by,

V^{\pi}_{P,r}\;:=\;\mathbb{E}_{P,\pi}\left[\sum_{h=0}^{H-1}r_{h}(s_{h},a_{h})\mid s_{0}\right].

We explicitly index the value function by
(P,r)
to emphasize that our focus is on learning the dynamics.
The
optimal policy

\pi^{\star}
satisfies
\pi^{\star}\in\argmax_{\pi}V^{\pi}_{P,r}
. We note that there always exists an optimal deterministic policy
(
19
)
. The optimal value for
P,r
is denoted by
V^{\star}_{P,r}:=V^{\pi^{\star}}_{P,r}
.
A policy
\pi
is
\epsilon
-optimal
if
it holds that
V^{\star}_{P,r}-V^{\pi}_{P,r}\leq\epsilon.

In addition, for any policy
\pi
, the implied transition matrix, denoted
P^{\pi}_{h}\in\mathbb{R}^{S\times S}
, is a row stochastic matrix where
P^{\pi}_{h}[s,s^{\prime}]=P_{h}(s^{\prime}\mid s,\pi(s))
.

Occupancy measures.

For a policy
\pi
and dynamics
P
, we define the occupancy measure at timestep
h
as the joint distribution over states and actions induced by
\pi
under
P
.
Formally,

q_{h}(s,a|\pi,P):=\mathbb{P}\left(s_{h}=s,a_{h}=a|P,\pi\right)
. We also denote
q_{h}(s|\pi,P):=\mathbb{P}\left(s_{h}=s|P,\pi\right)
, which is the probability to visit a state at timestep
h
. Clearly,
q_{h}(s,a|\pi,P)=q_{h}(s|\pi,P)\mathbb{P}\left([\pi_{h}(s)=a]\right)
.
Occupancy measures capture the visitation frequencies of state-action pairs along an episode and thus define a distribution over them.

Reward-free exploration

is the task of learning an accurate estimate of the dynamics
P
, which can later be used to compute an
\epsilon
-optimal policy for any given reward function.
In the reward-free exploration phase, the rewards are not observed by the learners, and the focus is to learn an accurate approximation of the dynamics.

Formally, let
\widehat{P}
denote the estimated dynamics learned by a reward-free algorithm when interacting with an unknown environment
\mathcal{M}
.
For any reward function
r
, let

\widehat{\pi}_{r}:=\argmax_{\pi}V^{\pi}_{\widehat{P},r}
.
The goal of the reward-free learning algorithm is to produce an estimate
\widehat{P}
such that, with high probability,

V^{\star}_{P,r}-V^{\widehat{\pi}_{r}}_{P,r}\leq\epsilon.

Cooperative multi-agent RL.

We consider a cooperative multi-agent reinforcement learning (MARL, see
(
24
)
) setting in which multiple agents interact with a shared environment and share information.
We assume
fresh randomness
across agents, i.e., during each learning phase, all random variables
are i.i.d sampled for each agent.
In particular, even when multiple agents take identical actions in identical states at the same timestep, they observe independently sampled next state.

A learning algorithm in this setting operates over
\rho
learning phases, each phase decomposed into
m
episodes of interactions, one for each agent.
Formally, in each phase
i\in[\rho]
, the algorithm deploys all
m
agents to interact with the environment in parallel.
Each agent executes a single episode according to its assigned policy, and there is no communication or interaction between agents during the phase.
At the end of each phase, the algorithm aggregates the trajectories collected by all agents and updates the policies used in subsequent phases.

Note we distinguish the agent complexity from sample complexity.
Sample complexity is the total number of environment interactions required by the algorithm, while agent complexity is the required number of agents in each learning phase. They are closely related: multiplying the agent complexity by the number of learning phases yields the sample complexity, but the reverse is subtler, since a sequential algorithm may not exploit parallelism across agents.

reward-free exploration

Algorithm and Main Result

Our goal is to accelerate reward-free exploration by leveraging multiple agents to
reduce the number of learning phases, while keeping the total number of agents
polynomial in
S
,
A
,
H
, and
\epsilon^{-2}

Section

5

Accordingly, we design an algorithm that operates in exactly
H
learning phases
and requires only a polynomial number of agents.

We note that an agent complexity at scale
O(1/\epsilon^{3})
can be achieved
using a simple construction. We sketch the idea here. In phase
i
, we explore
timestep
i
dynamics,
P_{i}
, by sending
S/\epsilon^{3}
agents to each state–action pair
(s,a)
. If
at least
1/\epsilon^{2}
agents reach
(s,a)
, we obtain sufficiently many samples
to accurately estimate their transitions. Otherwise, it means the probability to visits them lower than
\epsilon/S
, thus they contribute at most
\epsilon
to the overall estimation error. This yields an

\epsilon
-accurate estimation of the dynamics using
O(1/\epsilon^{3})
agents.
The main technical challenge is to achieve the same guarantee using only

O(1/\epsilon^{2})
agents.

Our algorithm addresses this challenge by exploiting the fact that states differ
in their reachability. Highly reachable states are naturally explored by many
agents, while low reachable states are visited by only a few agents. Nevertheless,
because low-reachability states are encountered infrequently, their contribution
to the total value is negligible compared to that of highly reachable states, for any reward function.
Our approach leverages this observation by allowing the estimation error at each state to depend on its reachability probability, focusing accuracy on the states that have non-negligible visitation probability.

The key observation underlying our Algorithm,
MARFE
, is that it suffices to
control the
policy-weighted error
for any policy
\pi
, meaning,

Proposition 4.6

Assume the conditions of

3.1

\pi

using an auxiliary dynamics

\mathcal{S}^{2}_{h}\subseteq\widehat{\mathcal{S}}^{\beta}_{h}
,

\widehat{\mathcal{S}}^{\beta}_{h}:=\bigl\{s\in\mathcal{S}\;\big|\;q_{h}(s\mid\widehat{\pi}^{h,s},\widehat{P})\geq\beta\bigr\}

, there is a constant probability that

is empty; therefore, the algorithm fails to recover the full key.
Consequently, for our reward function

∎

6
Discussion and Future Work

In this work, we introduce the problem of cooperative multi-agent reward-free exploration, in which a centralized learning algorithm deploys multiple agents in parallel to learn unknown environment dynamics.
We identify a fundamental trade-off between parallel time and agent complexity that naturally arises in this setting and analyze it.

Our results present a sharp transition when the number of learning phases scales with
H
, the horizon of the learned MDP.
For
H
learning phases we show a computationally efficient algorithm that requires

\tilde{O}(S^{6}H^{6}A/\epsilon^{2})
agents.
In contrast, when the number of learning phases is reduced to
\rho<<H
, we prove that any algorithm must deploy at least

\Omega(A^{(H-1)/\rho}/\rho)
agents.
Together, these results demonstrate two distinct learning regimes: one with polynomial and one with exponential agent complexity, determined by the number of learning phases.

Several directions for future work remain.
First, reducing the polynomial dependence on
S
and
H
in our upper bound would lead to a tighter characterization of the polynomial regime.
Second, extending our results to settings with large or continuous state spaces, where effective exploration is substantially more challenging and crucial for many real-world applications, is an important direction for future work.

A.4.1
The
P^{2}
dynamics

Analogous to the
P^{1}
dynamics, we define the
P^{2}
dynamics. This transition function serves as a theoretical bridge between the true dynamics
P
and the
P^{1}
dynamics
P^{1}
. While
P^{1}
is constructed based on empirical reachability,
P^{2}
is defined using the true transition dynamics but restricted to states that remain significantly reachable under the inductive constraint.

Specifically, in
P^{2}
, transitions continue only from states that are truly
\beta
-reachable within this restricted model. Unlike
\widehat{\mathcal{S}}^{\beta}_{h}
, which depends on the collected data, the set of reachable states in this dynamics is deterministic.

Let
q_{h}(s\mid\pi,P^{2}):=q^{2}_{h}(s\mid\pi)
be the
occupancy measure
of
P^{2}
, excluding
s_{\mathrm{sink}}
.
Note, it is not
q
-square, but just a notation.

Definition A.22
.

We define the set of inductive
\beta
-significant states at timestep
h
as:

\mathcal{S}^{2}_{h}:=\{s\in\mathcal{S}\mid\max_{\pi}q_{h}(s\mid\pi,P^{2})\geq{2\beta}\}.

Note that
\mathcal{S}^{2}_{h}
is a deterministic set.

Transition function for
P^{2}
.

As before, we introduce a sink state
s_{\mathrm{sink}}
to collect the probability mass of all non-reachable states. The state space of
P^{2}
is
\mathcal{S}\cup\{s_{\mathrm{sink}}\}
, and the transition kernel
P^{2}_{h}
is defined as follows:

\begin{array}[]{c c | c}s&s^{\prime}&P^{2}_{h}(s^{\prime}\mid s,a)\\
\hline\cr\rule{0.0pt}{15.0pt}\mathcal{S}^{2}_{h}&\mathcal{S}&P_{h}(s^{\prime}\mid s,a)\\[6.0pt]
\mathcal{S}\setminus\mathcal{S}^{2}_{h}&s_{\mathrm{sink}}&1\\[6.0pt]
s_{\mathrm{sink}}&s_{\mathrm{sink}}&1\\[6.0pt]
\text{Otherwise}&&0\end{array}

By this definition, if a state
s
is not
\beta
-reachable in
P^{2}
(i.e.,
s\notin\mathcal{S}^{2}_{h}
), it acts as a termination point where all subsequent transitions lead to
s_{\mathrm{sink}}
with probability
1
, effectively pruning the dynamics.

Lemma A.23
.

If
\mathcal{S}^{2}_{i}\subseteq\widehat{\mathcal{S}}^{\beta}_{i}
for every
i<h
,
then for every policy
\pi
and state

q_{h}(s\mid\pi,P^{2})\leq q_{h}(s\mid\pi,P^{1})
.

Proof.

By induction. Immediate for
h=0
.
Assume true for
h
.
For
h+1
:
Assume
\mathcal{S}^{2}_{i}\subseteq\widehat{\mathcal{S}}^{\beta}_{i}
for every
i<h+1
.
Let
s\in\widehat{\mathcal{S}}^{\beta}_{h+1}
.
Denote
q^{2}_{h}(s\mid\pi):=q_{h}(s\mid\pi,P^{2})
and
q^{1}_{h}(s\mid\pi)=q_{h}(s\mid\pi,P^{1})
.

\displaystyle q^{1}_{h+1}(s\mid\pi)=\sum_{s^{\prime}\in\widehat{\mathcal{S}}^{\beta}_{h}}q^{1}_{h}(s^{\prime}\mid\pi)P^{1}_{h}(s\mid s^{\prime},\pi_{h}(s^{\prime}))

\displaystyle=\sum_{s^{\prime}\in\widehat{\mathcal{S}}^{\beta}_{h}}q^{1}_{h}(s^{\prime}\mid\pi)P_{h}(s\mid s^{\prime},\pi_{h}(s^{\prime}))

\displaystyle\geq\sum_{s^{\prime}\in\mathcal{S}^{2}_{h}}q^{1}_{h}(s^{\prime}\mid\pi)P_{h}(s\mid s^{\prime},\pi_{h}(s^{\prime}))\quad\text{(since $\mathcal{S}^{2}_{h}\subseteq\widehat{\mathcal{S}}^{\beta}_{h}$)}

\displaystyle\geq\sum_{s^{\prime}\in\mathcal{S}^{2}_{h}}q^{2}_{h}(s^{\prime}\mid\pi)P_{h}(s\mid s^{\prime},\pi_{h}(s^{\prime}))\quad\text{(induction hypothesis)}

\displaystyle=q^{2}_{h+1}(s\mid\pi)

B.1
The Key-Dynamic Framework

The Key-Dynamic is characterized by a minimal state space and deterministic transitions that simulate a “lock” that only one sequence of actions can open.

The
state space

\mathcal{S}
consists of only two states:

\mathcal{S}=\{s_{\mathrm{sink}},s^{\star}\}.

The
initial state
is always the “informative” state:

s_{0}=s^{\star}.

The transition functions
P_{h}
are deterministic. In state
s^{\star}
, there exists exactly one “correct” action
a^{\star}_{h}
at each timestep
h
that remains the agent in
s^{\star}
. Any other action leads to the absorbing state
s_{\mathrm{sink}}
. Once in
s_{\mathrm{sink}}
, the agent remains there regardless of the actions chosen.

The
transition function
is defined as follows:

\begin{array}[]{c c | c}s&s^{\prime}&P_{h}(s^{\prime}\mid s,a)\\
\hline\cr\rule{0.0pt}{15.0pt}s^{\star}&s^{\star}&\mathbbm{1}(a=a^{\star}_{h})\\[6.0pt]
s^{\star}&s_{\mathrm{sink}}&\mathbbm{1}(a\neq a^{\star}_{h})\\[6.0pt]
s_{\mathrm{sink}}&s^{\star}&0\\[6.0pt]
s_{\mathrm{sink}}&s_{\mathrm{sink}}&1\\[6.0pt]
\end{array}

Definition B.2
.

We call the sequence of actions that keep the agent in
s^{\star}
the
key
of the dynamics.
We also call these actions the
good actions
.

Although we explore without any reward, the interesting reward function will be the reward that tells if the algorithm knows the “key” of the Key-Dynamic.

Definition B.3
.

We denote with
r^{\mathrm{key}}
the following reward function.

r^{\mathrm{key}}_{h}(s,a)=\mathbbm{1}(h=H-1,s=s^{\star},a=a^{\star}_{H-1}).

B.1.1
Structural Implications

Below are several structural implications.

•

Action Sequences:
There are
A^{H}
possible action sequences, but only one unique sequence
(a^{\star}_{1},a^{\star}_{2},\allowbreak\dots,a^{\star}_{H})
maintains the agent in
s^{\star}
.

•

Information Gain:
If an agent makes a mistake at any step
h
, it transitions to
s_{\mathrm{sink}}
for the remainder of the episode. In this state, the agent receives no new information regarding the correct actions for steps
h+1\dots H
.

•

Visual Analogy:
The dynamics can be visualized as two parallel lines of length
H
. The agent traverses the
s^{\star}
line as long as it provides the “correct key” (actions). A single error drops the agent into the
s_{\mathrm{sink}}
line, where it remains until the end of the horizon.

•

dynamics Space:
There are
A^{H}
distinct Key-Dynamic, each corresponding to a unique sequence of optimal actions.

B.2
The Key-Dynamic is learnable in one phase with
m=A^{H}

Proposition B.4
.

When the number of agents is
m=A^{H}
, each such Key-Dynamic is learnable in one phase.
I.e.,
Assume
m=A^{H}
.
There exists an algorithm s.t. for every
\epsilon>0,\delta>0
, a Key-Dynamic
P^{\mathrm{key}}
,
and a reward function

after
1

\Pr\left(V^{\star}(s_{0};P^{\mathrm{key}},r)-V^{\widehat{\pi}}(s_{0};P^{\mathrm{key}},r)\leq\epsilon\right)\geq 1-\delta.

Furthermore, the algorithm is deterministic and it always outputs the best policy, i.e.,
\widehat{\pi}=\pi^{\star}
.

Proof.

We construct a deterministic algorithm that will output the best policy.
Let us enumerate all the possible action selections in each timestep, regardless of the states.
We have
A^{H}
such selections, since we have
A
actions for each timestep.
Let us enumerate the agents.
The algorithm sends the agent of index
i
to action selections in index
i
, regardless of the state the agent reaches.

Since we send an agent to each action selection, one agent is sent to the selection we denote with
i^{\star}
, the selection that keeps in
s^{\star}
:
(a^{\star}_{0},a^{\star}_{1},\dots,a^{\star}_{H-1})
.

Since we restrict the learning to Key-Dynamic, all agents start at
s^{\star}
, and one agent, the one in index
{i^{\star}}

s^{\star}
.
Therefore, we know the sequence of the actions that keep in
s^{\star}

Hence, we learned completely the transition function of the dynamics we explored,

The transition function we estimated is as follows,

\begin{array}[]{c c | c}s&s^{\prime}&\widehat{P}_{h}(s^{\prime}\mid s,a)\\
\hline\cr\rule{0.0pt}{15.0pt}s^{\star}&s^{\star}&\mathbbm{1}(a=a^{\star}_{h})\\[6.0pt]
s^{\star}&s_{\mathrm{sink}}&\mathbbm{1}(a\neq a^{\star}_{h})\\[6.0pt]
s_{\mathrm{sink}}&s^{\star}&0\\[6.0pt]
s_{\mathrm{sink}}&s_{\mathrm{sink}}&1\\[6.0pt]
\end{array}

and

.

Since the algorithm and the dynamics are deterministic, we get that for any reward function

, the algorithm outputs

.
Hence,

\Pr\left(V^{\star}(s_{0};P^{\mathrm{key}},r)-V^{\widehat{\pi}}(s_{0};P^{\mathrm{key}},r)=0\right)=1,

and we managed to learn the Key-Dynamic in one phase.
∎

Lemma C.2

(Markov inequality for conditional expectation)
.

Let
(\Omega,\mathcal{F},P)
be a probability space. Let
X\geq 0
be a non-negative random variable.
Let
a,b\in\mathbb{R},a>0,b\geq 0
. Let
A\in\mathcal{F}
be an event.

Assume
E(X|A)\leq b
.

Then,
\Pr(X\geq a|A)\leq b/a
.

Proof.

From the definition of conditional expectation we have,

\int_{A}XdP=\int_{A}E(X|A)dP,

and from the assumption we get,

\int_{A}E(X|A)dP\leq\int_{A}bdP=bPr(A).

Together we get

\int_{A}XdP\leq bPr(A).

(14)

Hence,

Pr(X\geq a|A)=\frac{Pr(X\geq a,A)}{Pr(A)}=\frac{\int_{A\cap\{X\geq a\}}1dP}{Pr(A)}\leq\frac{\frac{1}{a}\int_{A}XdP}{Pr(A)}\leq\frac{\frac{1}{a}bPr(A)}{Pr(A)}=\frac{b}{a},

where the second inequality is from
Equation

14
, and the first inequality is since,

\int_{\{X\geq a\}\cap A}1dP=\frac{1}{a}\int_{\{X\geq a\}\cap A}adP\leq\frac{1}{a}\int_{\{X\geq a\}\cap A}XdP\leq\frac{1}{a}\int_{A}XdP.

∎

(Bretagnolle–Huber–Carol with a

.

Let
X
be a random variable taking values in
\{1,\ldots,S\}
, where
\Pr[X=i]=p_{i}
.
Assume we sample
X
for
n
times and observe the value
i

\hat{n}_{i}
outcomes.

\hat{p}
, i.e.,
\hat{p}_{i}=\hat{n}_{i}/n

\delta\in(0,1)

\|\hat{p}-p\|_{1}\;\leq\;\sqrt{\frac{\ln(1/\delta)+2S}{2n}}.

Proof.

The Bretagnolle–Huber–Carol inequality gives, for all

Lemma C.5

(Bretagnolle–Huber–Carol with a random variable)

\lambda_{\mathcal{K}}=\sqrt{\frac{\log(\operatorname{supp}(\mathcal{K})/\delta)+2S}{2\mathcal{K}}}.

\Pr(\mathopen{{\mathchoice{\hbox{$\displaystyle\left\lVert\vbox to0.0pt{}\right.$}}{\hbox{$\textstyle\left\lVert\vbox to0.0pt{}\right.$}}{\hbox{$\scriptstyle\left\lVert\vbox to0.0pt{}\right.$}}{\hbox{$\scriptscriptstyle\left\lVert\vbox to0.0pt{}\right.$}}}}{p-\hat{p}}\mathclose{{\mathchoice{\hbox{$\displaystyle\left\rVert\vbox to0.0pt{}\right.$}}{\hbox{$\textstyle\left\rVert\vbox to0.0pt{}\right.$}}{\hbox{$\scriptstyle\left\rVert\vbox to0.0pt{}\right.$}}{\hbox{$\scriptscriptstyle\left\rVert\vbox to0.0pt{}\right.$}}}}_{1}\geq\lambda_{\mathcal{K}})\leq\delta.

Lemma C.7
