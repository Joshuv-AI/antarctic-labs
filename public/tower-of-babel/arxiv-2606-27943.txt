Abstract
. For a given Tychonoff space X X , a point p ∈ β ⁡ ( X ) ∖ X p\in\beta(X)\setminus X is called remote if p p is not in the closure of any nowhere dense subset of X X . In this paper, we characterize spaces with remote points in terms of certain topological ultrafilters, measures, and compact-like properties corresponding to the ideal consisting of nowhere dense sets. It is shown that the space of remote points is homeomorphic to a subspace of the Stone space taken over the smallest Boolean algebra containing all open and nowhere dense sets. Also, we show that the space of remote points of ℝ \mathbb{R} is ω \omega -bounded.

1.
Introduction and main results

A
filter
on a set
X
is a family of subsets of
X
that does not contain the empty set, and is closed under finite intersections and taking supersets. A filter
\mathcal{F}
on a set
X
is called an
ultrafilter
if for each
A\in X
either
A\in\mathcal{F}
or
X\setminus A\in\mathcal{F}
, or equivalently,
\mathcal{F}
is maximal with respect to the inclusion among filters on
X
.
If we consider filters on a topological space
X
, it is natural to assume that they are somehow connected with the topological structure of
X
. An instance of such connection is presented in the following definition.

Definition 1.1
.

Let
R
be a property of subsets of a space
X
. A filter
\mathcal{F}
on
X
is called

(i)

an
R
filter
if
\mathcal{F}
possesses a base consisting of sets with property
R
;

(ii)

an
R
ultrafilter
if
\mathcal{F}
is an
R
filter, and for any subset
A\subseteq X
with property
R
either
A\in\mathcal{F}
or
X\setminus A\in\mathcal{F}
;

It is straightforward to check that each
R
ultrafilter is maximal with respect to the inclusion among
R
filters. The converse implication holds true, if the property
R
is preserved under finite intersections. In this paper, we are mostly dealing with the properties of being open, closed, zero, or cozero. Recall that a subset
A
of a space
X
is called a
zero set
if
A=f^{-1}(0)
for some continuous function
f\colon X\rightarrow[0,1]
. Furthermore, the set
A
is called
cozero
if
X\setminus A
is a zero set.
If
\mathcal{F}
is simultaneously an
R_{i}
(ultra)filter for each
i\leq n
, then
\mathcal{F}
is called an
R_{0}
-
\cdots
-
R_{n}
(ultra)filter. For more on open and closed filters, see
[
2
]
and references therein.

For a Tychonoff space
X

we denote the Stone-Čech compactification of

. We shall consider the representation of

given in

is the set of all zero ultrafilters on

endowed with the topology

\mathcal{B}=\{\{u\in\beta(X):A\notin u\}:A\hbox{ is a zero subset of }X\}.

Note that in this representation, a point
x
of

is identified with a zero ultrafilter generated by all zero subsets of

that contain

. As usual, the remainder
\beta(X)\setminus X
is denoted by

. A point

is called

if

is not in the closure of any nowhere dense subset of

. We write that a space

.

Definition 1.4

Let

Let

Theorem 1.6
.

For a Tychonoff space

(a)

For a space

Theorem 1.7
.

For a normal space

the following conditions are equivalent:

(a)

has a remote point;

(b)

(c)

on

(d)

\operatorname{NF}

2.
Filters on topological spaces

Let
R
be a property of subsets of a topological space
X
. We write that a subset
A\subseteq X
has property
R^{c}
if
X\setminus A
has property
R
.

Proposition 2.1
.

Let
\mathcal{F}
be a filter on a space
X
. If
\mathcal{F}
is both, an
R
filter and
R^{c}
ultrafilter, then
\mathcal{F}
is an
R
ultrafilter.

Proof.

Assume that an
R
filter
\mathcal{F}
is an
R^{c}
ultrafilter and fix a set
A\not\in\mathcal{F}
with property
R
. Since
\mathcal{F}
is an
R^{c}
ultrafilter, the set
X\setminus A
is either an element of
\mathcal{F}
or there is
F\in\mathcal{F}
disjoint with
X\setminus A
. The latter case yields
F\subseteq A
, and so
A\in\mathcal{F}
, a contradiction. Hence the set
X\setminus A
is an element of
\mathcal{F}
disjoint with
A
. Thus
\mathcal{F}
is an
R
ultrafilter.
∎

Proposition
2.1
implies the following.

Corollary 2.2
.

Let
\mathcal{F}
be a filter on a space
X
. Then the following hold:

(1)

If
\mathcal{F}
is an open filter and a closed ultrafilter, then
\mathcal{F}
is an open ultrafilter.

(2)

If
\mathcal{F}
is a closed filter and an open ultrafilter, then
\mathcal{F}
is a closed ultrafilter.

(3)

If
\mathcal{F}
is a cozero filter and a zero ultrafilter, then
\mathcal{F}
is a cozero ultrafilter.

(4)

If
\mathcal{F}
is a zero filter and a cozero ultrafilter, then
\mathcal{F}
is a zero ultrafilter.

(5)

If
\mathcal{F}
is an open-closed filter, then
\mathcal{F}
is a closed ultrafilter if and only if
\mathcal{F}
is an open ultrafilter.

(6)

If
\mathcal{F}
is a zero-cozero filter, then
\mathcal{F}
is a cozero ultrafilter if and only if
\mathcal{F}
is a zero ultrafilter.

In addition to item (1) in Corollary
2.2
, we give an alternative assumption that forces a closed ultrafilter to be an open ultrafilter.

Proposition 2.3
.

Let
\mathcal{F}
be a closed ultrafilter on a space
X
such that
A\notin\mathcal{F}
for each nowhere dense subset
A
of
X
. Then
\mathcal{F}
is an open ultrafilter.

Proof.

Fix any
F\in\mathcal{F}
. Since
\mathcal{F}
is a closed filter, there exists a closed
F^{\prime}\in\mathcal{F}
such that
F^{\prime}\subseteq F
.
Note that the set
P:=F^{\prime}\setminus\Int(F^{\prime})
is nowhere dense, so
P\not\in\mathcal{F}
. Since the set
P
is closed and
\mathcal{F}
is a closed ultrafilter, there is
G\in\mathcal{F}
such that
G\cap P=\emptyset
. Then
G\cap F^{\prime}\subseteq\Int(F^{\prime})
, implying that
\Int(F^{\prime})\in\mathcal{F}
. Since
F
was arbitrarily chosen,
\mathcal{F}
is an open filter. Corollary
2.2
(i) implies that
\mathcal{F}
is an open ultrafilter.
∎

Recall that a space
X
is said to have
ccc property
, if each family of pairwise disjoint open sets is at most countable. A subset
A
of a space
X
is said to have ccc property, if
A
equipped with the subspace topology has ccc property.

Proposition 2.4
.

Let
\mathcal{F}
be an open ultrafilter on a Tychonoff space
X
such that
\mathcal{F}
has an element with a ccc property.
Then
\mathcal{F}
is a cozero ultrafilter.

Proof.

It suffices to show that
\mathcal{F}
has a base consisting of cozero sets. Fix an arbitrary set
F\in\mathcal{F}
with ccc property. It is straightforward to check that each open subset of
F
has ccc property. Then the family
\mathcal{B}=\{U\subseteq F:U\hbox{ is open and }U\in\mathcal{F}\}
forms a base of
\mathcal{F}
consisting of open sets with ccc property. Fix any
B\in\mathcal{B}
. Find a maximal pairwise disjoint family
\mathcal{C}
of subsets of
B
, which are cozero in
X
. By ccc property of
B
, the family
\mathcal{C}
is countable. Since
X
is Tychonoff, the maximality of
\mathcal{C}
implies that the open subset
\bigcup\mathcal{C}
is dense in
B
. Lemma 3.1 from
[
2
]
implies that
\bigcup\mathcal{C}\in\mathcal{F}
. Moreover,
\bigcup\mathcal{C}
, being a countable union of cozero sets, is a cozero set itself. Hence
\mathcal{F}
is a cozero filter, as required.
∎

Proposition 2.5
.

If
\mathcal{F}
is a closed-open ultrafilter on a normal space
X
, then
\mathcal{F}
is a zero-cozero ultrafilter.

Proof.

It suffices to show that
\mathcal{F}
is a zero-cozero filter. Fix any set
F\in\mathcal{F}
. Since
\mathcal{F}
is an open filter, without loss of generality we can assume that
F
is open. Since
\mathcal{F}
is a closed filter, there exists a closed
G\subseteq F
such that
G\in\mathcal{F}
. Since the space
X
is normal, by the Urysohn Lemma
[
24
, Theorem 1.5.11]
there exists a continuous function
f\colon X\rightarrow[0,1]
such that
f{\restriction}_{G}\equiv 1
and
f{\restriction}_{X\setminus F}\equiv 0
. Observe that
G\subseteq f^{-1}([1/2,1])\subseteq f^{-1}((0,1])\subseteq F
, implying
f^{-1}((0,1])\in\mathcal{F}
and
f^{-1}([1/2,1])\in\mathcal{F}
. Since
f^{-1}((0,1])
is a cozero set and
f^{-1}([1/2,1])
is a zero set, we get that
\mathcal{F}
is a zero-cozero filter, as required.
∎

The following question is left open.

Question 1
.

Does there exist a Tychonoff space
X
possessing a free closed-open ultrafilter that is not a zero-cozero ultrafilter?

Noteworthy, the filter on the ordinal
\omega_{1}
(endowed with the order topology) generated by complements of all initial segments is a zero-cozero ultrafilter that is neither open ultrafilter nor closed ultrafilter.

Recall that a space
X
has a
large inductive dimension
0
if two nonempty disjoint closed subsets can be separated by a clopen set. The following result gives a partial answer to Question
1
.

Proposition 2.6
.

Assume that a space
X
contains a dense open subspace of large inductive dimension
0
. If
\mathcal{F}
is a closed-open ultrafilter on
X
then
\mathcal{F}
is a zero-cozero ultrafilter.

Proof.

Fix any element
W\in\mathcal{F}
. It suffices to find a clopen set
M\in\mathcal{F}
such that
M\subseteq W
, as clopen sets are both zero and cozero. Let
D
be a dense open subspace of
X
with large inductive dimension
0
. Since
\mathcal{F}
is an open ultrafilter,
D\in\mathcal{F}
. Since
\mathcal{F}
is a closed-open filter, there exist an open set
V\in\mathcal{F}
and a closed set
F\in\mathcal{F}
such that

F\subseteq V\subseteq\cl_{X}(V)\subseteq D\cap W.

Since
D
has large inductive dimension
0
, there exists a clopen subset
M
of
D
such that
F\subseteq M\subseteq V
. Since
D
is open in
X
, we get that
M
is open in
X
too. Since
M\subseteq\cl_{X}(V)\subseteq D
, we get that
M
is closed in
X
. Hence
M
is a clopen element of
\mathcal{F}
, as required.
∎

A family
\mathcal{A}
of subsets of a space
X
is called
locally finite
if for each
x\in X
there exists an open neighborhood of
x
that intersects only finitely many members of
\mathcal{A}
.
Recall that a space
X
is called
feebly compact
if each locally finite family of nonempty open sets is finite. By
[
24
, Theorem 3.10.22]
, a Tychonoff space is feebly compact if and only if it is pseudocompact.
Taking into account Theorem
1.6
, the following proposition implies Theorem
1.2
.

Proposition 2.7
.

Let
\mathcal{F}
be a closed-open ultrafilter on a space
X
with no accumulation points. Then
X
is not feebly compact.

Proof.

By Zorn’s Lemma, there exists a maximal family
\mathcal{A}
consisting of open pairwise disjoint subsets of
X
that are not in
\mathcal{F}
. Since the filter
\mathcal{F}
has no accumulation points, the set
\bigcup\mathcal{A}
is dense in
X
. As
\mathcal{F}
is an open ultrafilter,
\bigcup\mathcal{A}\in\mathcal{F}
. Since
\mathcal{F}
is a closed-open filter there exists an open set
F\in\mathcal{F}
such that
\overline{F}\subseteq\bigcup\mathcal{A}
. We claim that the family
\mathcal{A}^{\prime}=\{F\cap A:A\in\mathcal{A}\}
is infinite and locally finite. Seeking a contradiction, assume that
\mathcal{A}^{\prime}
is finite. Then there exists a finite subfamily
\mathcal{B}
of
\mathcal{A}
such that
F\subseteq\bigcup\mathcal{B}
. Since
\mathcal{F}
is an open ultrafilter and elements of
\mathcal{B}
are pairwise disjoint, there exists
B\in\mathcal{B}\subseteq\mathcal{A}
such that
B\in\mathcal{F}
, which contradicts the choice of
\mathcal{A}
. Hence
\mathcal{A}^{\prime}
is infinite. To show that
\mathcal{A}^{\prime}
is locally finite, fix any
x\in X
. If
x\notin\bigcup\mathcal{A}
, then
X\setminus\overline{F}
is an open neighborhood of
x
disjoint with
\bigcup\mathcal{A}^{\prime}
. If
x\in\bigcup\mathcal{A}
, then there exists a unique
A\in\mathcal{A}
that contains
x
. Note that
A
is an open neighborhood of
x
intersecting at most one element of
\mathcal{A}^{\prime}
. Hence
\mathcal{A}^{\prime}
is an infinite locally finite collection of nonempty open subsets, witnessing that
X
is not feebly compact.
∎

The following result implies that in some cases feeble compactness is equivalent to non-existence of a closed-open ultrafilter without accumulation points, and as such complements Proposition
2.7
.

Proposition 2.8
.

Let
X
be a space with a dense discrete subspace. Then the following assertions are equivalent:

(a)

X
contains an infinite closed set consisting of isolated points;

(b)

X
possesses a closed-open ultrafilter with no accumulation points.

Proof.

(a)
\Rightarrow
(b) Let
D
be an infinite closed set consisting of isolated points. Then each nonprincipal ultrafilter
u
on
D
generates a closed-open ultrafilter on
X
with no accumulation points.

(b)
\Rightarrow
(a) Let
\mathcal{F}
be a closed-open ultrafilter on
X
with no accumulation points and
D
be a dense discrete subset of
X
. It follows that
D
consists of isolated points and thus is open. Hence
D\in\mathcal{F}
. Since
\mathcal{F}
is a closed filter, there exists a closed set
F\in\mathcal{F}
such that
F\subseteq D
. Then the closed set
F
consists of isolated points. Since the filter
\mathcal{F}
has no accumulation points, the set
F
is infinite.
∎

The next proposition shows that for each ultrafilter

Proposition 2.9
.

Let
\mathcal{F}
be an
R
filter on a space
X
. Then the following are equivalent:

(a)

Let
H_{1},\ldots H_{n}
be subsets of
X
with property
R
such that
\bigcup_{i\leq n}H_{i}\in\mathcal{F}
. Then
H_{i}\in\mathcal{F}
for some
i\leq n
;

(b)

There is an ultrafilter
u
on
X
such that
\mathcal{F}=R(u)
;

(c)

Let
\mathcal{F}_{1},\cdots,\mathcal{F}_{n}
be
R
filters, where
\mathcal{F}_{i}\neq\mathcal{F}
for all
i\leq n
. Then
\mathcal{F}\neq\bigcap_{i\leq n}\mathcal{F}_{i}
.

Proof.

(a)
\Rightarrow
(b)
Let

\mathcal{E}=\{E\subseteq X:E\notin\mathcal{F},E\hbox{ has property }R\hbox{ and }E\cap F\neq\emptyset\hbox{ for all }F\in\mathcal{F}\}.

Let us show that the family
\Theta=\mathcal{F}\cup\{X\setminus E:\ E\in\mathcal{E}\}
has the finite intersection property.
Seeking a contradiction, assume that there exist sets
E_{i}\in\mathcal{E}
,
i\leq n
and
F\in\mathcal{F}
satisfying

\bigcap_{i\leq n}(X\setminus E_{i})\cap F=(X\setminus\bigcup_{i\leq n}E_{i})\cap F=\emptyset.

Thus
F\subseteq\bigcup_{i\leq n}E_{i}
, and so
\bigcup_{i\leq n}E_{i}\in\mathcal{F}
. By the assumption there is
i\leq n
such that
E_{i}\in\mathcal{F}
. But this contradicts the equality
\mathcal{E}\cap\mathcal{F}=\emptyset
. Hence the family
\Theta
has the finite intersection property. Pick any ultrafilter
u
that contains
\Theta
. Since
\mathcal{F}\subseteq\Theta\subseteq u
and
\mathcal{F}
is an
R
filter, we obtain
\mathcal{F}\subseteq R(u)
. In order to show the converse inclusion, fix any element
C\in R(u)
with property
R
. Observe that
C\notin\mathcal{E}
, as otherwise,
X\setminus C\in\Theta\subseteq u
, which would yield a contradiction.
On the other hand, since
C\in u
and
\mathcal{F}\subseteq u
, we get that
C\cap F\neq\emptyset
for each
F\in\mathcal{F}
. The definition of
\mathcal{E}
implies that
C\in\mathcal{F}
. Thus
\mathcal{F}=R(u)
, as required.

(b)
\Rightarrow
(c) Seeking a contradiction, assume that there exist
R
filters
\mathcal{F}_{i}
,
i\leq n
such that all of them are distinct from
\mathcal{F}
, and
R(u)=\mathcal{F}=\bigcap_{i\leq n}\mathcal{F}_{i}
. Then for each
i\leq n
there exist a subset
A_{i}\in\mathcal{F}_{i}\setminus R(u)
with property
R
. It follows that
A_{i}\notin u
for all
i\leq n
. Observe that

\bigcup_{i\leq n}A_{i}\in\bigcap_{i\leq n}\mathcal{F}_{i}=R(u)\subseteq u.

Since
u
is an ultrafilter, there exists
i\leq n
such that
A_{i}\in u
, a contradiction.

We prove (c)
\Rightarrow
(a) by contraposition. That is we actually prove
\neg
(a)
\Rightarrow\neg
(c). Suppose that
\mathcal{F}
does not satisfy (a). Then there exist subsets
A_{i}
,
i\leq n
of
X
with property
R
such that
\bigcup_{i\leq n}A_{i}\in\mathcal{F}
and
A_{i}\notin\mathcal{F}
for all
i\leq n
. Let
M=\{i\leq n:A_{i}\cap F\neq\emptyset\hbox{ for all }F\in\mathcal{F}\}
. It is easy to check that
\bigcup_{i\in M}A_{i}\in\mathcal{F}
. For each
i\in M
let
\mathcal{F}_{i}
be the
R
filter generated by
\mathcal{F}\cup\{A_{i}\}
. The sets
A_{i}
,
i\in M
witness that the filters
\mathcal{F}_{i}
,
i\in M
are distinct from
\mathcal{F}
. Observe that the filter
\bigcap_{i\in M}\mathcal{F}_{i}
is generated by the family

\mathcal{B}=\{F\cap\bigcup_{i\in M}A_{i}:F\in\mathcal{F}\}
,
which is a base for
\mathcal{F}
. Hence
\mathcal{F}=\bigcap_{i\in M}\mathcal{F}_{i}
, as required.
∎

In the following we explore conditions guaranteeing that the filter
R(u)
is an ultrafilter in a topological sense. Recall that for a given property
R
a subset
A
of a space
X
is said to have property
R^{c}
if
X\setminus A
has property
R
.

Proposition 2.10
.

Let
u
be an ultrafilter on a space
X
. Then
R(u)
is an
R
-
R^{c}
ultrafilter if and only if
R(u)=R^{c}(u)
.

Proof.

(
\Rightarrow
) Since
R(u)
has a base consisting of elements of
u
with property
R^{c}
, we get
R(u)\subseteq R^{c}(u)
. Since
R(u)
is an
R^{c}
ultrafilter, it is easy to check that
R(u)
is maximal with respect to the inclusion among
R^{c}
filters. Hence
R(u)=R^{c}(u)
, as required.

(
\Leftarrow
) Since
R(u)=R^{c}(u)
, we get that
R(u)
is an
R
-
R^{c}
filter. Fix a subset
A\subseteq X
with property
R
such that
A\notin R(u)
. Then
A\notin u
. Since
u
is an ultrafilter, we get
X\setminus A\in u
. Then
X\setminus A\in R^{c}(u)
, as the set
X\setminus A
has property
R^{c}
. Since
R(u)=R^{c}(u)
, we get that
X\setminus A\in R(u)
. Hence
R(u)
is an
R
ultrafilter. One can symmetrically show that
R(u)
is an
R^{c}
ultrafilter.
∎

Corollary 2.11
.

Let
u
be an ultrafilter on
X
. Then the following holds:

(1)

\mathtt{Op}(u)
is a closed-open ultrafilter if and only if
\mathtt{Op}(u)=\mathtt{Cl}(u)
.

(2)

\mathtt{Z}(u)
is a zero-cozero ultrafilter if and only if
\mathtt{Z}(u)=\mathtt{Cz}(u)
.

(3)

\mathtt{Op}(u)
is a closed-open-zero-cozero ultrafilter if and only if
\mathtt{Op}(u)=\mathtt{Cl}(u)=\mathtt{Z}(u)=\mathtt{Cz}(u)
.

Proof.

Assertions (1) and (2) are immediate consequences of Proposition
2.10
.

(3) (
\Leftarrow
) Items (1) and (2) imply that
\mathtt{Op}(u)
is a closed-open ultrafilter, and
\mathtt{Z}(u)
is a zero-cozero ultrafilter. By the assumption,
\mathtt{Op}(u)=\mathtt{Z}(u)
. Hence
\mathtt{Op}(u)
is a closed-open-zero-cozero ultrafilter.

(
\Rightarrow
) Assertion (1) implies that
\mathtt{Op}(u)=\mathtt{Cl}(u)
. Since each cozero set is open and each zero set is closed, we get that
\mathtt{Cz}(u)\subseteq\mathtt{Op}(u)
and
\mathtt{Z}(u)\subseteq\mathtt{Cl}(u)
. Since
\mathtt{Op}(u)
is a cozero filter,
\mathtt{Cz}(u)=\mathtt{Op}(u)
. It remains to show that
\mathtt{Cl}(u)\subseteq\mathtt{Z}(u)
. Since
\mathtt{Op}(u)=\mathtt{Cl}(u)
it suffices to show that
\mathtt{Op}(u)\subseteq\mathtt{Z}(u)
. By the assumption,
\mathtt{Op}(u)
has a base consisting of zero sets which are elements of the ultrafilter
u
. Thus
\mathtt{Op}(u)\subseteq\mathtt{Z}(u)
, and
\mathtt{Op}(u)=\mathtt{Cl}(u)=\mathtt{Z}(u)=\mathtt{Cz}(u)
, as required.
∎

Lemma 2.12
.

Let
u
be a non-principal ultrafilter on a
T_{1}
space
X
. If
\mathtt{Op}(u)
is a closed-open filter, then
\mathtt{Op}(u)
has no accumulation points.

Proof.

Fix any
x\in X
. Since
u
is not principal, we get that
A=X\setminus\{x\}\in u
. Since the space
X
is
T_{1}
,
A\in\mathtt{Op}(u)
. As
\mathtt{Op}(u)
is a closed filter, there exists a closed set
B\in\mathtt{Op}(u)
such that
B\subseteq A
. It is clear that the open neighborhood
X\setminus B
of
x
witnesses that
x
is not an accumulation point of
\mathtt{Op}(u)
. Since the point
x
was chosen arbitrarily, the filter
\mathtt{Op}(u)
has no accumulation points.
∎

Lemma 2.13
.

Let
\mathcal{F}
be an
R
ultrafilter on
X
. Then for every ultrafilter
u
that contains
\mathcal{F}
, we have
R(u)=\mathcal{F}
.

Proof.

It is clear that
\mathcal{F}\subseteq R(u)
. It is easy to see that
\mathcal{F}
is maximal with respect to the inclusion among
R
filters. Thus
R(u)=\mathcal{F}
, as required.
∎

3.
Measures on topological spaces

In this section, we show how the topological filters investigated in the previous section are connected to certain measures. Recall that
\mathtt{wB}(X)
denotes the family

\{(U\setminus P)\cup Q\colon U\hbox{ is open in }X\hbox{ and }P,Q\hbox{ are nowhere dense in }X\}.

The following lemma is folklore. Nevertheless we include its short proof.

Lemma 3.1

(Folklore)
.

For every space
X
,
\mathtt{wB}(X)
is an algebra of subsets of
X
. Moreover,
\mathtt{wB}(X)
is the smallest algebra containing all open and nowhere dense subsets of
X
.

Proof.

It is clear that
\{\emptyset,X\}\subset\mathtt{wB}(X)
. Fix any
A,B\in\mathtt{wB}(X)
. Then there exist open sets
U_{A},U_{B}
and nowhere dense sets
P_{A},Q_{A},P_{B},Q_{B}
such that
A=(U_{A}\setminus P_{A})\cup Q_{A}
and
B=(U_{B}\setminus P_{B})\cup Q_{B}
. Then the sets

P:=(P_{A}\setminus B)\cup(P_{B}\setminus A)\quad\hbox{
and }\quad Q:=Q_{A}\cup Q_{B}

are nowhere dense, and
A\cup B=((U_{A}\cup U_{B})\setminus P)\cup Q\in\mathtt{wB}(X)
. Since

X\setminus A=\big(\Int(X\setminus U_{A})\setminus Q_{A}\big)\cup\big(((X\setminus U_{A})\setminus\Int(X\setminus U_{A}))\setminus Q_{A}\big)\cup(P_{A}\setminus Q_{A}),

and
((X\setminus U_{A})\setminus\Int(X\setminus U_{A}))\setminus Q_{A}\cup(P_{A}\setminus Q_{A})
is a nowhere dense subset of
X
, we get
X\setminus A\in\mathtt{wB}(X)
.

Consider an algebra
\mathcal{B}
containing all open and nowhere dense subsets of
X
. Then
\mathcal{B}
contains all sets of the form
(U\setminus P)\cup Q
for
U
open and
P,Q
nowhere dense. Hence
\mathtt{wB}(X)\subseteq\mathcal{B}
, implying that
\mathtt{wB}(X)
is the smallest algebra containing all open and nowhere dense subsets of
X
.
∎

Let
\mathcal{A}
be an algebra of subsets of a space
X
. A subset
B\subseteq X
is said to have
property
\mathcal{A}
if
B\in\mathcal{A}
.

Lemma 3.2
.

Let
X
be a space. Then
\mathcal{F}
is a closed-open ultrafilter on
X
if and only if
\mathcal{F}
is a
\mathtt{wB}(X)
ultrafilter such that for every nowhere dense subset
N
of
X
there exists an open set
V\supseteq N
with
V\notin\mathcal{F}
.

Proof.

(
\Rightarrow
)
As
\mathtt{wB}(X)
contains all open (and closed) sets, we get that
\mathcal{F}
is a
\mathtt{wB}(X)
filter. Fix any subset
A\in\mathtt{wB}(X)
such that
A\notin\mathcal{F}
. There exist an open set
U_{A}
and nowhere dense sets
P_{A},Q_{A}
such that
A=(U_{A}\setminus P_{A})\cup Q_{A}
. Since
\mathcal{F}
is an open ultrafilter, the open dense set
D:=X\setminus(\overline{P_{A}}\cup\overline{Q_{A}})
is in
\mathcal{F}
. It follows that
U_{A}\notin\mathcal{F}
, as otherwise the inclusion
A\supseteq D\cap U_{A}\in\mathcal{F}
yields a contradiction. As
\mathcal{F}
is an open ultrafilter,
X\setminus U_{A}\in\mathcal{F}
. Finally,
(X\setminus U_{A})\cap D
is an element of
\mathcal{F}
disjoint with
A
. Hence
\mathcal{F}
is a
\mathtt{wB}(X)
ultrafilter. Fix any nowhere dense subset
N
of
X
. Since
\mathcal{F}
is an open ultrafilter, the open dense set
X\setminus\overline{N}
belongs to
\mathcal{F}
. Since
\mathcal{F}
is a closed ultrafilter, there exists a closed set
C\in\mathcal{F}
such that
C\subseteq X\setminus\overline{N}
. Then
V=X\setminus C
is an open set that contains
N
and does not belong to
\mathcal{F}
.

(
\Leftarrow
) Since
\mathtt{wB}(X)
contains all open (and closed) sets, it suffices to show that
\mathcal{F}
is a closed-open filter. Fix any
A\in\mathtt{wB}(X)\cap\mathcal{F}
. There exist an open set
U_{A}
and nowhere dense sets
P_{A},Q_{A}
such that
A=(U_{A}\setminus P_{A})\cup Q_{A}
. By the assumption, each element of
\mathcal{F}
is dense in an open set. Since
Q_{A}\notin\mathcal{F}
,
Q_{A}\in\mathtt{wB}(X)
, and
\mathcal{F}
is a
\mathtt{wB}(X)
ultrafilter,
X\setminus Q_{A}\in\mathcal{F}
. It follows that
U_{A}\supseteq A\cap(X\setminus Q_{A})\in\mathcal{F}
. By the assumption,
\overline{P_{A}}\in\mathtt{wB}(X)\setminus\mathcal{F}
. Since
\mathcal{F}
is a
\mathtt{wB}(X)
ultrafilter, we get
X\setminus\overline{P_{A}}\in\mathcal{F}
and, consequently,
B:=U_{A}\cap(X\setminus\overline{P_{A}})\in\mathcal{F}
. As
B
is an open set contained in
A
we get that
\mathcal{F}
is an open filter. Consider the nowhere dense set
N:=\overline{B}\setminus B
. By the assumption, there exists an open set
V
such that
N\subseteq V
and
V\notin\mathcal{F}
. Since
V\in\mathtt{wB}(X)
and
\mathcal{F}
is a
\mathtt{wB}(X)
ultrafilter,
X\setminus V\in\mathcal{F}
. It is easy to check that
C=B\cap(X\setminus V)\in\mathcal{F}
is a closed subset contained in
B
. Hence
\mathcal{F}
is also a closed filter, as required.
∎

Following
[
7
]
, a measure
\mu
on a space
X
is said to be
non-atomic
if
\mu(\{x\})=0
for each
x\in X
.
For a
\{0,1\}
-measure
\mu
let
\mathcal{F}_{\mu}
be the filter whose base consists of measure one sets.

Proposition 3.3
.

Let
\mu
be a finitely additive
\{0,1\}
-measure defined on an algebra
\mathcal{A}
of subsets of a space
X
. Then the following assertions hold:

(1)

\mathcal{F}_{\mu}
is an
\mathcal{A}
ultrafilter.

(2)

If
\mu
is outer regular, then
\mathcal{F}_{\mu}
is a closed filter.

(3)

If
\mathtt{wB}(X)\subseteq\mathcal{A}
and
\mu
is outer regular, then
\mathcal{F}_{\mu}
is a closed ultrafilter.

(4)

If
\mu
is outer regular and non-atomic, then
\mathcal{F}_{\mu}
has no accumulation points.

(5)

If
\mathtt{wB}(X)\subseteq\mathcal{A}
,
\mu
is outer regular and vanishes on nowhere dense sets, then
\mathcal{F}_{\mu}
is a closed-open ultrafilter.

(6)

If
X
is
T_{1}
,
\mathtt{wB}(X)\subseteq\mathcal{A}
,
\mu
is outer regular and vanishes on nowhere dense sets, then
\mathcal{F}_{\mu}
has no accumulation points if and only if
\{x\}\notin\mathcal{F}_{\mu}
for any isolated point
x\in X
.

Proof.

(1) By the definition,
\mathcal{F}_{\mu}
is an
\mathcal{A}
filter. Fix any
A\in\mathcal{A}
such that
A\notin\mathcal{F}_{\mu}
. Then
\mu(A)=0
. Since
\mu
is finitely additive and
\mu(X)=1
, we get that
\mu(X\setminus A)=1
. Thus,
X\setminus A\in\mathcal{F}_{\mu}
witnessing that
\mathcal{F}_{\mu}
is an
\mathcal{A}
ultrafilter.

(2) Fix any
F\in\mathcal{F}_{\mu}
. By the outer regularity of
\mu
, there exists an open set
C
such that
X\setminus F\subseteq C
and
\mu(C)=0
. It follows that
X\setminus C\in\mathcal{F}_{\mu}
is a closed subset of
F
, witnessing that
\mathcal{F}_{\mu}
is a closed filter.

Assertion (3) follows from assertions (1) and (2).

(4) Fix any
x\in X
. Since
\mu(\{x\})=0
, the outer regularity of
\mu
yields an open neighborhood
U
of
x
such that
\mu(U)=0
. It follows that
X\setminus U\in\mathcal{F}_{\mu}
and, as such, the filter
\mathcal{F}_{\mu}
has no accumulation points.

(5) By assertion (3),
\mathcal{F}_{\mu}
is a closed ultrafilter. Proposition
2.3
implies that
\mathcal{F}_{\mu}
is an open ultrafilter.

(6) The implication (
\Rightarrow
) is obvious.

(
\Leftarrow
) Assertion (5) implies that
\mathcal{F}_{\mu}
is a closed-open ultrafilter. Fix any
x\in X
. If
x
is isolated, then by assumption
\{x\}\notin\mathcal{F}_{\mu}
. Since
\mathcal{F}_{\mu}
is an open ultrafilter,
X\setminus\{x\}\in\mathcal{F}_{\mu}
. Then the open set
\{x\}
witnesses that
x
is not an accumulation point of
\mathcal{F}_{\mu}
. Suppose that the point
x
is not isolated. Since
\{x\}
is a nowhere dense set, we get that
\{x\}\notin\mathcal{F}_{\mu}
. Since
\mathcal{F}_{\mu}
is a closed ultrafilter and
\{x\}
is a closed set, there exists a closed set
C\in\mathcal{F}_{\mu}
such that
x\notin C
. Then the open set
X\setminus C
witnesses that
x
is not an accumulation point of
\mathcal{F}_{\mu}
. Since the point
x
is chosen arbitrarily, the filter
\mathcal{F}_{\mu}
has no accumulation points.
∎

For any closed-open ultrafilter
\mathcal{F}
on a space
X
define the map
\mu_{\mathcal{F}}\colon\mathtt{wB}(X)\rightarrow\{0,1\}
by
\mu_{\mathcal{F}}(A)=1
if
A\in\mathcal{F}
and
\mu_{\mathcal{F}}(A)=0
, otherwise.

Proposition 3.4
.

Let
\mathcal{F}
be a closed-open ultrafilter on a given space
X
. Then
\mu_{\mathcal{F}}
is an outer regular
\{0,1\}
-measure that is defined on
\mathtt{wB}(X)
and vanishes on nowhere dense sets.

Proof.

In order to show that
\mu_{\mathcal{F}}
is a measure, fix any disjoint sets
A,B\in\mathtt{wB}(X)
. Since
\mathcal{F}
is a filter and
A\cap B=\emptyset
, either
A\notin\mathcal{F}
or
B\notin\mathcal{F}
. If
A\in\mathcal{F}
and
B\notin\mathcal{F}
or
B\in\mathcal{F}
and
A\notin\mathcal{F}
, we get
\mu_{\mathcal{F}}(A\cup B)=1=\mu_{\mathcal{F}}(A)+\mu_{\mathcal{F}}(B)
. It remains to consider the case when
A\notin\mathcal{F}
and
B\notin\mathcal{F}
. By the definition of
\mathtt{wB}(X)
, there exist open sets
U_{A},U_{B}
and nowhere dense sets
P_{A},Q_{A},P_{B},Q_{B}
such that
A=(U_{A}\setminus P_{A})\cup Q_{A}
and
B=(U_{B}\setminus P_{B})\cup Q_{B}
. Since
\mathcal{F}
is an open ultrafilter, the open dense set
X\setminus\overline{P_{A}}
belongs to
\mathcal{F}
. We claim that
U_{A}\notin\mathcal{F}
. Indeed, assuming the contrary, we get
A\supseteq(X\setminus P_{A})\cap U_{A}\in\mathcal{F}
, which contradicts the choice of
A
. Thus
U_{A}\notin\mathcal{F}
. Similarly, it can be shown that
U_{B}\notin\mathcal{F}
. Since
\mathcal{F}
is an open ultrafilter,
\{X\setminus U_{A},X\setminus\overline{Q_{A}},X\setminus U_{B},X\setminus\overline{Q_{B}}\}\subseteq\mathcal{F}
. It follows that

X\setminus(A\cup B)\supseteq(X\setminus U_{A})\cap(X\setminus\overline{Q_{A}})\cap(X\setminus U_{B})\cap(X\setminus\overline{Q_{B}})\in\mathcal{F}.

Thus
\mu_{\mathcal{F}}(A\cup B)=0=\mu_{\mathcal{F}}(A)+\mu_{\mathcal{F}}(B)
. Hence
\mu_{\mathcal{F}}
is a
\{0,1\}
-measure defined on
\mathtt{wB}(X)
.

Since each element of
\mathcal{F}
has nonempty interior,
\mu_{\mathcal{F}}
vanishes on nowhere dense sets. It remains to show the outer regularity of
\mu_{\mathcal{F}}
. Fix any
A\in\mathtt{wB}(X)
such that
\mu_{\mathcal{F}}(A)=0
. Then
X\setminus A\in\mathcal{F}
. Since
\mathcal{F}
is a closed filter, there exists a closed set
C\in\mathcal{F}
such that
C\subseteq X\setminus A
. Then
\mu_{\mathcal{F}}(X\setminus C)=0=\mu_{\mathcal{F}}(A)
, witnessing that the measure
\mu_{\mathcal{F}}
is outer regular.
∎

The following corollary of Propositions
3.3
and
3.4
establishes a one-to-one correspondence between closed-open ultrafilters on a space
X
with no accumulation points and outer regular
\{0,1\}
-measures which are defined on
\mathtt{wB}(X)
and vanish on nowhere dense and finite sets.

Corollary 3.5
.

For a space
X
the following assertions hold:

(i)

If
\mu
is an outer regular
\{0,1\}
-measure that is defined on
\mathtt{wB}(X)
and vanishes on nowhere dense and finite sets, then
\mathcal{F}_{\mu}
is a closed-open ultrafilter without accumulation points.

(ii)

If
\mathcal{F}
is a closed-open ultrafilter on
X
with no accumulation points, then
\mu_{\mathcal{F}}
is an outer regular
\{0,1\}
-measure that is defined on
\mathtt{wB}(X)
and vanishes on nowhere dense and finite sets.

4.
Remote points

For a point
y
of a space
X
by
\mathcal{N}(y)
we denote the open filter on
X
generated by the set of all open neighborhoods of
y
. The following was proven in
[
14
, Theorem 14.2]
.

Theorem 4.1

(van Douwen)
.

Let
X
be a Tychonoff space and
p\in X^{*}
. Then the following conditions are equivalent.

(a)

p
is a remote point.

(b)

The trace of
\mathcal{N}(p)
on
X
is an open ultrafilter.

(c)

The trace of
\mathcal{N}(p)
on
X
is a closed ultrafilter.

The following theorem reveals a correspondence between zero-cozero-closed-open ultrafilters without accumulation points on a space
X
and remote points from
X^{*}
.

Proposition 4.2
.

Let
X
be a Tychonoff space. Then
\mathcal{F}\in X^{*}
is a remote point if and only if
\mathcal{F}
is a zero-cozero-closed-open ultrafilter on
X
with no accumulation points.

Proof.

(
\Rightarrow
): Recall that elements of
X^{*}
are zero ultrafilters. Assume that a zero ultrafilter
\mathcal{F}\in X^{\ast}
is a remote point and denote the trace of
\mathcal{N}(\mathcal{F})
on
X
by
\mathcal{H}
. Since
\beta(X)
is Hausdorff, we get that
\mathcal{F}
has no accumulation points in
X
. By Theorem
4.1
, the filter
\mathcal{H}
is a closed-open ultrafilter. Fix any
U\in\mathcal{N}(\mathcal{F})
.
Let us first show that
\mathcal{H}
is a cozero filter. Since all cozero sets of
\beta(X)
form a base of open sets in
\beta(X)
, there exists a cozero (in
\beta(X)
) set
W\in\mathcal{N}(\mathcal{F})
with
W\subseteq U
. Then
W\cap X
is a cozero set in
X
which belongs to
\mathcal{H}
and
W\cap X\subseteq U\cap X
. Hence
\mathcal{H}
is a cozero filter.
Let us show that
\mathcal{H}
is a zero filter. Since
\beta(X)
is Tychonoff, there exists a continuous function
f:\beta(X)\rightarrow[0,1]
such that
f(\beta(X)\setminus U)=0
and
f(\mathcal{F})=1
. Then
f^{-1}([1/2,1])\subseteq U
is a zero set that is contained in
\mathcal{N}(\mathcal{F})
. Then
f^{-1}([1/2,1])\cap X\in\mathcal{H}
is a zero set in
X
that is contained in
U\cap X
. Hence
\mathcal{H}
is a zero filter. Since
\mathcal{H}
is a closed-open ultrafilter and a zero-cozero filter, we get that
\mathcal{H}
is a closed-open-zero-cozero ultrafilter. To derive a contradiction, assume that
\mathcal{F}\neq\mathcal{H}
. Then there exist disjoint zero subsets
A,B
of
X
such that
A\in\mathcal{H}
and
B\in\mathcal{F}
. The set

T=\{y\in\beta(X):X\setminus A\in y\}
is an open neighborhood of
\mathcal{F}
in
\beta(X)
. By the definition of
\mathcal{H}
,
T\cap X\in\mathcal{H}
, and thus
\emptyset=T\cap X\cap A\in\mathcal{H}
. The obtained contradiction implies
\mathcal{F}=\mathcal{H}
.

(
\Leftarrow
): Let
\mathcal{F}
be a zero-cozero-closed-open ultrafilter on a space
X
with no accumulation points. Then
\mathcal{F}
belongs to
X^{*}
. It is clear that the filter
\mathcal{N}(\mathcal{F})
traces on
X
an open filter, which we denote by
\mathcal{H}
. We are going to show that
\mathcal{H}=\mathcal{F}
. Since
\mathcal{F}
is an open ultrafilter, it suffices to check that
\mathcal{F}\subseteq\mathcal{H}
. Fix any
F\in\mathcal{F}
. Since
\mathcal{F}
is a cozero ultrafilter, there exists a cozero set
F^{\prime}\in\mathcal{F}
such that
F^{\prime}\subseteq F
.
Note that
X\setminus F^{\prime}
is a zero set and
X\setminus F^{\prime}\notin\mathcal{F}
. Then the set
W=\{u\in\beta(X)\colon X\setminus F^{\prime}\notin u\}
is an open neighborhood of
\mathcal{F}
in
\beta(X)
. Observe that
W\cap X\in\mathcal{H}
and
W\cap X=F^{\prime}\subseteq F
. Hence
\mathcal{F}\subseteq\mathcal{H}
, as required.
∎

Corollary 4.3
.

Let
X
be a Tychonoff space and
p\in X^{*}
. The following are equivalent.

(a)

p
is a remote point;

(b)

p
is a zero-cozero-closed-open ultrafilter with no accumulation points;

(c)

p
is a zero-cozero-open ultrafilter with no accumulation points;

(d)

p
is a zero-cozero-closed ultrafilter with no accumulation points.

Proof.

The equivalence of items (a) and (b) is established in Theorem
4.2
. The equivalences (b)
\Leftrightarrow
(c) and (b)
\Leftrightarrow
(d) follow from items (1) and (2) of Corollary
2.2
.
∎

Proposition 4.4
.

Let
X
be a normal space. Then
\mathcal{F}\in X^{*}
is a remote point if and only if
\mathcal{F}
is a closed-open ultrafilter on
X
with no accumulation points.

Recall that for a given space
X
by
\operatorname{NF}
we denote the ideal on
X
consisting of all nowhere dense subsets of
X
together with all finite subsets of
X
.

Proposition 4.5
.

A Tychonoff space
X
has a remote point if and only if
X
is not weakly
\operatorname{NF}
-compact.

Proof.

(
\Rightarrow
) By Theorem
4.2
there exists a closed-open-zero-cozero ultrafilter
\mathcal{F}
on
X
with no accumulation points. Since
\mathcal{F}
has no accumulation points and
X
is Tychonoff, for each finite subset
A
of
X
there exist a zero set
Z_{A}
and a cozero set
V_{A}
such that
A\subseteq Z_{A}\subseteq V_{A}
and
V_{A}\notin\mathcal{F}
. Fix any infinite nowhere dense subset
B
of
X
. Since
\mathcal{F}
is an open ultrafilter, the open dense set
X\setminus\overline{B}
belongs to
\mathcal{F}
. Since
\mathcal{F}
is a zero-cozero filter, there exist a zero set
C\in\mathcal{F}
and a cozero set
D\in\mathcal{F}
such that
C\subseteq D\subseteq X\setminus\overline{B}
. Put
Z_{B}=X\setminus D
and
V_{B}=X\setminus C
. Then
Z_{B}
is a zero set,
V_{B}
is a cozero set,
B\subseteq Z_{B}\subseteq V_{B}
and
V_{B}\notin\mathcal{F}
. Thus for each
A\in\operatorname{NF}
there exist a zero set
Z_{A}
and a cozero set
V_{A}
such that
A\subseteq Z_{A}\subseteq V_{A}
and
V_{A}\notin\mathcal{F}
. Let
\phi:\operatorname{NF}\rightarrow cz(X)
be defined by
\phi(A)=V_{A}
. Then for each finite subfamily
\mathcal{A}
of
\operatorname{NF}
the set
X\setminus\bigcup_{A\in\mathcal{A}}\phi(A)
belongs to
\mathcal{F}
and thus is nonempty. The function
\phi
witnesses that
X
is not weakly
\operatorname{NF}
-compact.

(
\Leftarrow
) Since
X
is not weakly
\operatorname{NF}
-compact, there exists a function
\phi:\operatorname{NF}\rightarrow cz(X)
such that for each
A\in\operatorname{NF}
there exists a zero set
Z_{A}
satisfying
A\subseteq Z_{A}\subseteq\phi(A)
, and for each finite subfamily
\mathcal{A}\subseteq\operatorname{NF}
the set
X\setminus\bigcup_{A\in\mathcal{A}}\phi(A)
is nonempty. Consider the zero filter
\mathcal{F}
generated by the family

\{X\setminus\bigcup_{A\in\mathcal{A}}\phi(A)\colon\mathcal{A}\hbox{ is a finite subset of }\operatorname{NF}\}.

By Zorn’s lemma,
\mathcal{F}
can be enlarged to a zero ultrafilter
\mathcal{F}^{\prime}
. In order to show that
\mathcal{F}^{\prime}
is a remote point, fix any nowhere dense subset
A\subseteq X
. Since
X\setminus\phi(A)\in\mathcal{F}\subseteq\mathcal{F}^{\prime}
and
Z_{A}\subseteq\phi(A)
, we get that
Z_{A}\notin\mathcal{F}^{\prime}
. Then
\{u\in\beta(X):Z_{A}\notin u\}
is an open neighborhood of
\mathcal{F}^{\prime}
in
\beta(X)
which is disjoint with
A
. Since the nowhere dense set
A
was chosen arbitrarily,
\mathcal{F}^{\prime}
is a remote point.
∎

Proposition 4.6
.

A normal space
X
is weakly
\operatorname{NF}
-compact if and only if
X
is
\operatorname{NF}
-compact.

Proof.

The implication (
\Leftarrow
) is obvious. To prove the reverse implication, assume that a normal space
X
is weakly
\operatorname{NF}
-compact. Consider any function
\phi:\operatorname{NF}\rightarrow o(X)
such that
A\subseteq\phi(A)
for all
A\in\operatorname{NF}
. By the Tietze-Urysohn Theorem
[
24
, Theorem 2.1.8]
, for each closed
A\in\operatorname{NF}
there exists a continuous function
f:X\rightarrow[0,1]
such that
A\subseteq f^{-1}(0)
and
X\setminus\phi(A)\subseteq f^{-1}(1)
. Put
Z_{A}=f^{-1}(0)
and
V_{A}=f^{-1}([0,1/2))
. It is clear that
Z_{A}
is a zero set,
V_{A}
is a cozero set and
A\subseteq Z_{A}\subseteq V_{A}\subseteq\phi(A)
. Define a function
\psi:\operatorname{NF}\rightarrow cz(X)
by
\psi(A)=V_{\overline{A}}
for all
A\in\operatorname{NF}
. Since
X
is weakly
\operatorname{NF}
-compact, there exists a finite family
\mathcal{A}\subseteq\operatorname{NF}
such that
\bigcup_{A\in\mathcal{A}}\psi(A)=X
. Let
\mathcal{B}:=\{\overline{A}:A\in\mathcal{A}\}
. Taking into account that
\psi(A)=\psi(\overline{A})\subseteq\phi(\overline{A})
for each
A\in\operatorname{NF}
, we have that
\bigcup_{B\in\mathcal{B}}\phi(B)=X
. Hence
X
is
\operatorname{NF}
-compact.
∎

) By Proposition
4.7
,

has a remote point. By Proposition

possesses a closed-open ultrafilter
\mathcal{F}
with no accumulation points in

3.5

-measure that is defined on

We are going to prove Theorem

We need to show that for a Tychonoff space
X
,
\rho(X)
is homeomorphic to a subspace of
S(\mathtt{wB}(X))
.
Moreover, if

\sigma

\rho(X)
is

-bounded.

Proof of Theorem
1.8

By Proposition
4.2
, each remote point
p\in X^{*}
is in fact a closed-open-zero-cozero ultrafilter with no accumulation points. It is easy to check that each closed-open ultrafilter on a space
X
is an ultrafilter on the Boolean algebra
\mathtt{wB}(X)
. So, each remote point
p\in X^{*}
can be identified with the unique element
\phi(p)\in S(\mathtt{wB}(X))
. Let us check that the defined above map
\phi\colon\rho(X)\rightarrow S(\mathtt{wB}(X))
is a topological embedding. It is clear that
\phi
is injective. Fix a remote point
p\in X^{*}
and an open neighborhood
W
of
\phi(p)
. Without loss of generality we can assume that
W=\{u\in S(\mathtt{wB}(X)):A\in u\}
, for some
A\in\mathtt{wB}(X)
. Since
\phi(p)\in W
, we get
A\in\phi(p)
, which implies that
A\in p
. Since
p
is a cozero filter, there exists a cozero set
B\in p
such that
B\subseteq A
. Then
U:=\{y\in\rho(X):X\setminus B\notin y\}
is an open neighborhood of
p
such that
\phi(U)\subseteq W
. Hence
\phi
is continuous. It remains to show that the map
\phi
is open onto its image. Fix a zero subset
Z
of
X
and a basic open set
V=\{y\in\rho(X):Z\notin y\}
in
\rho(X)
. It is a routine to check that

\phi(V)=\{u\in S(\mathtt{wB}(X)):X\setminus Z\in u\}\cap\phi(\rho(X)).

Hence
\phi
is open onto its image, as required.

Assume that the space
X
is locally compact and
\sigma
-compact. Then there exists a family
\{V_{n}:n\in\omega\}
of open subsets of
X
such that
\bigcup_{n\in\omega}V_{n}=X
,
\cl_{X}(V_{n})
is compact and
\overline{V_{n}}\subseteq V_{n+1}
for each
n\in\omega
.
If
\rho(X)=\emptyset
, then there is nothing to prove. Assume that
\rho(X)\neq\emptyset
. Note that
\sigma
-compactness of
X
implies that
X
is normal. So, elements of
\rho(X)
are closed-open ultrafilters on
X
with no accumulation points, and the topology on
\beta(X)
is generated by the sets
\{z\in\beta(X):O\in z\}
, where
O
is an open subset of
X
. Fix a countable subset
C=\{u_{n}:n\in\omega\}\subseteq\rho(X)
. We are going to show that
\cl_{\rho(X)}(C)=\cl_{\beta(X)}C
, which in turn would imply that
\rho(X)
is
\omega
-bounded.
It is clear that
\cl_{\rho(X)}(C)\subseteq\cl_{\beta(X)}C
. To show the converse inclusion, fix any
y\in\cl_{\beta(X)}(C)
and any nowhere dense subset
A
of
X
. It suffices to show that
y\notin\cl_{\beta(X)}(A)
. Without loss of generality we can assume that
A
is closed in
X
, as otherwise we can substitute
A
with
\cl_{X}(A)
. Since
C\subseteq\rho(X)
, for each
i\in\omega
there exists an open set
U_{i}\in u_{i}
such that
\cl_{X}(U_{i})\cap A=\emptyset
. Let
W_{i}:=U_{i}\setminus\cl_{X}(V_{i})
. Since
\cl_{X}(V_{i})
is compact,
W_{i}\in u_{i}
for all
i\in\omega
. For each
x\in X
there exists
i(x)\in\omega
such that
V_{i(x)}
is an open neighborhood of
x
. Thus the family
W:=\{W_{i}:i\in\omega\}
is locally finite in
X
. It follows that

\cl_{X}(\bigcup W)=\bigcup_{n\in\omega}\cl_{X}(W_{n})\subseteq\bigcup_{n\in\omega}\cl_{X}(U_{n})\subseteq X\setminus A.

We claim that
\cl_{X}(\bigcup W)\in y
. Otherwise, since
y
is a closed ultrafilter,
X\setminus\cl_{X}(\bigcup W)\in y
. But then
\{z\in\beta(X):X\setminus\cl_{X}(\bigcup W)\in z\}
is an open neighborhood of
y
disjoint with
C
, which contradicts the assumption. Since
\cl_{X}(\bigcup W)\subseteq X\setminus A
, the set
\{z\in\beta(X):X\setminus A\in z\}
is an open neighborhood of
y
disjoint with
A
. Hence
y\notin\cl_{\beta(X)}(A)
, as required. ∎
