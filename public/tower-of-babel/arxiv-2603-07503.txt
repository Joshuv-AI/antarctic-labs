The Integration of Stepanov Remotely Almost Periodic Functions
David Cheban

Abstract
. The aim of this paper is to study the problem of the integration of Stepanov remotely almost periodic functions. We prove that every compact primitive of a Stepanov remotely almost periodic function with a minimal ω \omega -limit set is remotely almost periodic. This fact proves the conjecture previously formulated by the author.

(X,\mathbb{T},\pi)
. Note that

\widetilde{X}:=H^{+}(x_{0})
is a nonempty, compact and positively
invariant subset of
(X,\mathbb{T},\pi)
. Since
\varphi=h(x_{0})

is positively
S^{p}
Lagrange stable then

h(H^{+}(x_{0}))=H^{+}(\varphi)
and, consequently, the
nonautonomous dynamical system
\langle(X,\mathbb{T},\pi),(Y,\mathbb{T},\sigma),h\rangle
induces on

\widetilde{X}=H^{+}(x_{0})
(respectively, on
\omega_{x_{0}}
) a
semi-group (respectively, a two-sided) nonautonomous dynamical
system
\langle(\widetilde{X},\mathbb{R}_{+},\pi),(\widetilde{Y},\mathbb{R}_{+},\sigma),h\rangle

(respectively,
\langle(\omega_{x_{0}},

\mathbb{R},

\pi),

(\omega_{\varphi},

\mathbb{R},

\sigma),

h\rangle
), where

\widetilde{Y}:=H^{+}(\varphi)
.

Now we will show that there exist at least one continuous mapping

\nu:\omega_{\varphi}\to\mathfrak{B}
such that

\nu(\sigma(t,\psi))=\phi(t,\nu(\psi),\psi)

for all
(t,\psi)\in\mathbb{R}\times\omega_{\varphi}
. To this
end we fix a point
\widetilde{x}\in\omega_{x_{0}}.

Since the point
x_{0}
is positively Lagrange stable in the
skew-product dynamical system
(X,\mathbb{T},\pi)
then

\omega_{x_{0}}
is a nonempty, compact and invariant set. For the
point
\widetilde{x}\in\omega_{x_{0}}
there exists a sequence

such that

\pi(t_{n},x_{0})=(\phi(t_{n},x_{0},\varphi),\sigma(t_{n},\varphi))\to(\widetilde{u},\widetilde{\psi})=\widetilde{x}
as
n\to\infty
.

Note that

(28)

F^{t_{n}}(t)=F^{t_{n}}(0)+\int_{0}^{t}\varphi^{t_{n}}(s)ds

for all
t\in\mathbb{T}
and, consequently, passing to the limit
in (
28
) as
n\to\infty
we obtain

\widetilde{F}(t)=\widetilde{F}(0)+\int_{0}^{t}\widetilde{\psi}(s)ds.

Taking into account that
\widetilde{F}(\mathbb{R})\subseteq Q=\overline{\varphi(\mathbb{R}_{+})}
we conclude that the function

\widetilde{F}
is a compact primitive of the function

\widetilde{\psi}\in\omega_{\psi}
. On the other hand since the
function
\varphi
is
S^{p}
remotely almost periodic then by
Theorem
2.50
the function
\widetilde{\psi}
is
S^{p}

almost periodic and by Corollary
3.11
there exist a
continuous mapping
\nu:\omega_{\varphi}\to\mathfrak{B}
such
that

\nu(\widetilde{\psi})=\widetilde{u}\ \ \mbox{and}\ \ \nu(\sigma(t,\psi))=\phi(t,\nu(\psi),\psi)

for all
(t,\psi)\in\mathbb{R}\times\omega_{\varphi}
.

Now we will show that the
\omega
-limit set
\omega_{x_{0}}
of

x_{0}
(or equivalently, the
\omega
-limit set

\omega_{(F,\varphi)}
of
(F,\varphi)
) is an equi-almost
periodic set. To prove this fact we fix an arbitrary positive
number
\varepsilon
.

By uniform continuity of the map
\gamma:\omega_{\varphi}\to\omega_{x_{0}}
(respectively, the map
\nu:\omega_{\varphi}\to I:=pr_{1}(\omega_{x_{0}})
because
\gamma=(\nu,Id_{Y})
) for

\varepsilon/2
there exists a positive number

\delta=\delta(\varepsilon/2)

(
0<\delta(\varepsilon)<\varepsilon
) such that

\rho_{S^{p}}(\theta_{1},\theta_{2})<\delta
implies

(29)

\rho_{X}(\gamma(\theta_{1}),\gamma(\theta_{2}))<\varepsilon/2\ \ (\mbox{respectively},\ \rho_{\mathfrak{B}}(\nu(\theta_{1}),\nu(\theta_{2}))<\varepsilon/2),

where
\rho_{\mathfrak{B}}(u,v):=|u-v|
for all
u,v\in\mathfrak{B}
,
\rho_{X}(x_{1},x_{2})=\rho_{\mathfrak{B}}(v_{1},v_{2})+\rho_{S^{p}}(\theta_{1},\theta_{2})
and

x_{i}=(v_{i},\theta_{i})
(i=1,2).

Since the function
\varphi
is positively Lagrange stable and
remotely almost periodic then by Theorem
2.50
the set

\omega_{\varphi}
is
S^{p}
equi-almost periodic. This means
that the set

(30)

\mathcal{F}(\varepsilon/2,\omega_{\varphi}):=\{\tau\in\mathbb{R}|\ \sup\limits_{t\in\mathbb{T},\ \theta\in\omega_{\varphi}}\rho_{S^{p}}(\sigma(t+\tau,\theta),\sigma(t,\theta))<\delta(\varepsilon/2)\}

is relatively dense in
\mathbb{R}
.

If
\tau\in\mathcal{F}(\varepsilon/2,\omega_{\varphi})
, then from
(
29
) and (
30
) we have

\rho_{X}(\phi(t+\tau,\gamma(\theta),\theta),\phi(t,\gamma(\theta),\theta))=\rho_{X}(\gamma(\sigma(t+\tau,\theta)),\gamma(\sigma(t,\theta))<\varepsilon/2

(respectively,

\rho_{\mathfrak{B}}(\phi(t+\tau,\nu(\theta),\theta),\phi(t,\nu(\theta),\theta))=\rho_{\mathfrak{B}}(\nu(\sigma(t+\tau,\theta)),\nu(\sigma(t,\theta))<\varepsilon/2)

for all
t\in\mathbb{R}
and
\theta\in\omega_{\varphi}
, i.e.,

\tau\in\mathcal{F}(\varepsilon,\omega_{\varphi})
.

Let now
(\Phi,\psi)\in\omega_{(F,\varphi)}
be an arbitrary
point then as we established above
\Phi^{\prime}(t)=\psi(t)
for all

t\in\mathbb{R}
. On the other hand

\phi(t,\nu(\psi),\psi)^{\prime}=\psi(t)
and, consequently,

(31)

\Phi(t)=\nu(\sigma(t,\psi))+\Phi(0)-\nu(\psi)

for all
t\in\mathbb{R}
. From (
31
) we obtain

(32)

\rho_{\mathfrak{B}}(\Phi(t+\tau),\Phi(t))=\rho_{\mathfrak{B}}(\nu(\sigma(t+\tau,\psi),\gamma(\sigma(t,\psi)))<\varepsilon/2.

According to (
30
) and (
32
) we obtain

\rho_{X}((\Phi(t+\tau),\sigma(t+\tau,\psi)),\Phi(t),\sigma(t,\psi))=

\rho_{\mathfrak{B}}(\Phi(t+\tau),\Phi(t))+\rho_{S^{p}}(\sigma(t+\tau,\psi),\sigma(t,\psi))<\varepsilon/2+\varepsilon/2=\varepsilon

for all
t\in\mathbb{T}
and
(\Phi,\psi)\in\omega_{(F,\varphi)}
.

This means that the set
\omega_{(F,\varphi)}
is equi-almost
periodic. To finish the proof we note that if the set

\omega_{\varphi}
consists of
\tau
-periodic (respectively,
stationary) points, then the set

is so.
Theorem is proved.
∎

Corollary 3.13
.

Let
\varphi\in C(\mathbb{R},\mathfrak{B})
be a positively Lagrange stable function. Assume that the
following conditions are fulfilled:

(i)

\varphi
is a positively remotely almost periodic
(respectively, positively remotely
\tau
-periodic or positively
remotely stationary) function and its
\omega
-limit set

\omega_{\varphi}
is minimal;

(ii)

the primitive

F(t):=\int_{0}^{t}\varphi(s)ds
of the function
\varphi
is
precompact.

Then the primitive
\Phi
of
\varphi
is positively remotely
almost periodic (respectively, positively remotely
\tau
-periodic
or positively remotely stationary) function.

Proof.

This statement directly follows from Theorem
3.12

because every remotely almost periodic (respectively, remotely

\tau
-periodic or remotely stationary) function
\varphi\in C(\mathbb{R},\mathfrak{B})
is
S^{p}
remotely almost periodic
(respectively, remotely
\tau
-periodic or remotely stationary).
∎

Remark 3.15
.

Note that under the conditions of

3.13
the compact primitive

F(t)=\int_{0}^{t}\varphi(s)ds
of the function
\varphi\in C(\mathbb{T},\mathfrak{B})
is remotely stationary (respectively,

\tau

-limit set
\omega_{F}
of

Example 4.1
.

We note (see, for example,
[
10
]
) that the
function
\psi(t)=\sin(t+\ln(1+|t|))
(
t\in\mathbb{R}
)
possesses the following properties:

(i)

\psi
is remotely
2\pi
-periodic;

(ii)

the set

\omega_{\psi}
is minimal;

(iii)

\psi
is not asymptotically
almost periodic.

Consider the function
\varphi\in C(\mathbb{R}_{+},\mathbb{R})

defined by the equality
\varphi(t):=\cos(t+\ln(1+t))
for every

t\in\mathbb{R}_{+}
. The function
\varphi
possesses the
following properties:

(i)

|\cos(t+2\pi+\ln(1+t+2\pi))-\cos(t+\ln(1+t))|=

2|\sin(t+\frac{\ln(1+t+2\pi)(1+t)}{2})\sin(\frac{\ln(1+\frac{2\pi}{1+t})}{2})|\leq

|\ln(1+\frac{2\pi}{1+t})|\to 0

as
t\to+\infty
and, consequently, the function
\varphi
is
remotely
2\pi
-periodic;

(ii)

\varphi
is bounded on the

\mathbb{R}_{+}
;

(iii)

\varphi^{\prime}(t)=-(1+\frac{1}{1+t})\sin(t+\ln(1+t))

for all
t\in\mathbb{R}_{+}

derivative
\varphi^{\prime}
is bounded on
\mathbb{R}_{+}
and,
consequently, the function
\varphi
is uniformly continuous on

\mathbb{R}_{+}
;

(iv)

the function
\varphi
is positively
Lagrange stable and, consequently, its
\omega
-limit set

\omega_{\varphi}
is nonempty, compact and invariant (in the
shift dynamical system
(C(\mathbb{R}_{+},\mathbb{R}),\mathbb{R}_{+},\sigma)
);

(v)

\omega_{\varphi}=\{\cos^{h}:\ h\in[0,2\pi)\}.

To prove this equality we note that the function

\widetilde{\varphi}\in\omega_{\varphi}
if and only if there exists
a sequence
\{h_{k}\}\subset\mathbb{R}_{+}
such that
h_{k}\to+\infty
and
\varphi^{h_{k}}\to\widetilde{\varphi}
(in the space

C(\mathbb{R}_{+},\mathbb{R})
) as

It easy to see that

\widetilde{\varphi}(t)=\lim\limits_{k\to\infty}\cos(r+h_{k}+\ln(1+t+h_{k}))=

(33)

\lim\limits_{k\to\infty}\cos(t+h_{k}+\ln(2\pi h_{k})+\ln(1+\frac{1+t}{h_{k}})

for every
k\in\mathbb{N}
.

Note that

(34)

h_{k}+\ln(2\pi m_{k})=2\pi m_{k}+\tau_{k}

for all
k\in\mathbb{N}
, where
m_{k}\in\mathbb{N}
. Without loos of the
generality we can suppose that the sequences
\{\tau_{k}\}
is
convergent and its limit
\widetilde{\tau}\in[0,2\pi)
, i.e.,

(35)

\widetilde{\tau}=\lim\limits_{k\to\infty}\tau_{k}.

Passing to the limit in the equality (

) and taking into

for every fixed

(for some

obtain that the set
\omega_{\varphi}
is minimal.

(vi)

the
function
\varphi
is not asymptotically
2\pi
-periodic.

If we assume that it is not true, then there exists a

2\pi
-periodic function
\widetilde{\varphi}\in\omega_{\varphi}

(and, consequently, there exists a number

with property
\widetilde{\varphi}=\cos^{\alpha}

\lim\limits_{t\to+\infty}|\varphi(t)-\widetilde{\varphi}(t)|=0.

Note that

\psi^{2}(t)+\varphi^{2}(t)=\sin^{2}(t+\ln(1+t))+\cos^{2}(t+\ln(1+t))=1

and, consequently,

(37)

.\psi^{2}(t)=1-\varphi^{2}(t)

for all
t\in\mathbb{R}_{+}
. From (
37
), taking into
account (
36

\psi
is
asymptotically
2\pi
-periodic. The last statement contradicts to

\psi

(vii)

\psi^{\prime}(t)=(1+\frac{1}{1+t})\varphi(t):=\mu(t)

for all

, i.e., the function

is a

-periodic function

(as the product of two remotely

Example 4.2
