 Abstract

 This report walks through the process of deriving the wave equation for a vertical wave being
 propagated through a spatially varying plasma in a vertical magnetic field. Additionally, this
 report shows how to derive the index of refraction of the plasma corresponding to three different
 modes of the vertical magnetic field. Finally, this paper briefly explores the next steps planned
 to successfully simulate and test the equations in a pre-existing phase screen scintillation code.

1 Overview
This report outlines the process for deriving the wave equation for a radio wave propagating
through a spatially varying plasma in a vertical magnetic field. We used the macroscopic Maxwell’s
equations with the Lorentz force law to generalize the electric permittivity tensor. We then as-
sumed that spatial gradients of the tensor are small compared with the wavenumber. To obtain
scalar parabolic wave equations for each of the 3 distinct modes, we solved an eigenvalue prob-
lem for the index of refraction and the modes. We found the ordinary mode and both polarizations
of the extraordinary modes along with the corresponding indices of refraction. Finally, we provide
a plan for incorporating these new modes into a previously existing multiple phase screen model
(see [1], [2]) for radio wave propagation.

4 A Plan for Moving Forward
Now that the theory has been fleshed out, the plan for the future of this project revolves around
alterations to an already existing phase screen scintillation code. The bulk of the initial improve-
ments will be made inside the Fresnel propagator function ’prop’ in lines 735-766. Additional
adjustments will certainly need to be made to fully implement the improvements throughout the
scintillation code.

 Figure 1: Scintillation code’s existing Fresnel propagator function ’prop’.

 First, the equation identified by the blue box in Figure 1 needs to be adjusted. Line 752 can
be left as is, but the latter half of line 753 should now be adjusted to model the term exp(i ∗ k0 ∗
∆n(x, z)∗dz). After the subtraction sign, the line should read ’light_delay * I * k0 * n[j,k] * dz’, where
’j’ is the variable of the for-loop identified by the red box and represents the horizontal dimension.
’k’ is the variable of a for-loop that will be added later and represents the vertical dimension.
 Second, a larger for-loop will be added. This for-loop will encase the red box identified in Figure

 8

 9

1 and will use ’k’ as its counter. This is to act as an integral in the vertical dimension. In code, an
integral is calculated by summation.
 The third alteration is when changes will be made to several other sections of the code. A new
’.dat’ file for the two-dimensional refractive index profile will be made and code will be created to
read this file. This file will include the data n[x,z] in terms of an indexed [j,k] function similar to that
of the input waveform.
 Part four goes even further in that it will break down function n[x,z] into two functions: B0 [x,z]
and Ne [x,z]. Both of these functions will need a new ’.dat’ file and code to read them. This change
allows the user to enter information relating specifically to the background magnetic field and the
plasma density spatial profiles.
