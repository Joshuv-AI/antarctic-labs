 EXECUTIVE SUMMARY

GeoWISE is the first-of-its-kind web-based software tool, empowering users to streamline preliminary
design and economic analysis for deploying Geothermal Heat Pump (GHP) systems in virtually any
building. Harnessing cutting-edge technologies, GeoWISE integrates advanced tools such as AutoBEM for
automatic building energy simulation model creation, EnergyPlus and OpenStudio for precise HVAC
equipment sizing and energy simulation, and GHEDesigner for automated borehole field design within
available land area. With access to more than 120 million existing buildings from the
comprehensive Model America Database, you can select a building for analysis or create a new custom
building. GeoWISE conducts high-level techno-economic analyses for implementing GHP systems in
individual buildings, neighborhoods, or even districts featuring mixed-use spaces, vintage structures, as
well as new or existing constructions.

This manual serves as a comprehensive guide for users to effectively utilize the ORNL developed GeoWISE
tool. It contains information on accessing the tool, inputting data, and interpreting the results. The first
chapter provides guidance on accessing the tool, its layout, and the workflow of the tool in brief. The second
chapter introduces the input parameters for the tool, and the third chapter discusses the outputs and
interpretation of the outputs. This document is for assisting engineers, consultants, building professionals,
and building owners with limited information on GHP systems in evaluating the technical feasibility and
economic viability of GHP applications tailored to their specific buildings.

 2. PROJECT SET UP

GeoWISE is the first-of-its-kind web-based software tool, empowering users to streamline preliminary
design and economic analysis for deploying Geothermal Heat Pump (GHP) systems in virtually any
building. Harnessing cutting-edge technologies, GeoWISE integrates advanced tools such as AutoBEM for
automatic building energy simulation model creation, EnergyPlus and OpenStudio for precise HVAC
equipment sizing and energy simulation, and GHEDesigner for automated borehole field design within
available land area. With access to more than 120 million existing buildings from the
comprehensive Model America Database, you can select a building for analysis or create a new custom
building. GeoWISE conducts high-level techno-economic analyses for implementing GHP systems in
individual buildings, neighborhoods, or even districts featuring mixed-use spaces, vintage structures, as
well as new or existing constructions.

The first step in setting up a project is to input the building information. Two options exist for selecting a
building type in the web interface. The first option is to select from available DOE prototype building types
(Option: Pre-configured building), and the second is to select an existing building on the satellite (or street)
view of a US map (Option: Real time simulation) If users require a quick assessment of the feasibility of
their geothermal system, they can select the Pre-Configured Building Designs option. This option
provides instant results based on pre-calculated simulations for various building types across multiple
locations in the United States. Additional information on Pre-Configured Building Designs is provided in
Section 2.1. Alternatively, if users require a more representative feasibility assessment based on the
characteristics of their actual building, they can select the Real-Time Simulation option. This option
performs a whole-building energy analysis using the specific building parameters provided by the user,
delivering a customized evaluation of geothermal system feasibility. Additional information on the Real-
Time Simulation option is provided in Section 2.2.

Figure 3 shows the overall workflow and key components of GeoWISE. The workflow begins when a user
selects either a pre-defined building design or a real-time simulation through the web interface. If a pre-
defined building design is selected, the system retrieves and displays results directly from the database.
Otherwise, the AutoBEM tool generates a building energy model based on the user's specific building
inputs, and the HVAC system is automatically replaced with a ground-source heat pump (GHP) system.
An initial simulation is then performed using OpenStudio to calculate the thermal loads required for the
ground heat exchanger (GHE). These loads are passed to GHEDesigner, which automatically sizes the
GHE. The resulting GHE specifications are incorporated into a final OpenStudio simulation to evaluate
overall system performance. Finally, the simulation results are stored in the database and presented to the
user through detailed reports and performance summaries.

2.1 Pre-Configured Building

This option is supported with a database of pre-simulated results so that the results can be displayed
instantaneously after a user selects a prototype building [1]. Users can specify specific climate zone and
building type by selecting from the Climate Zone drop down menu and Building Type drop down menu
based on their building location and type. The Pre-Configured Building option currently does not include
low-rise residential, which can be specified and simulated in Real time simulation. Fifteen different climate
zones can be selected and sixteen different building types (including mid-rise and high-rise apartments) can
be selected based on Department of Energy (DOE) prototype building models
(https://www.energycodes.gov/prototype-building-models). Figures 4 and 5 show the user inputs needed
for selecting prototype building models and design parameters. The fields are set with default inputs, but
users can change them based on their preferences. The current version of GeoWISE allows user to select
ground thermal conductivity between low value (1.3 W/m-K) and high value (3 W/m-K). Table 1 lists the
prototype buildings along with their corresponding floor areas and existing HVAC system types. Based on
user selection of building type and climate zone, basic information of the building, including total floor area
and HVAC system configuration, will be displayed in the interface. By clicking on the “Simulate” button
at the bottom right corner of the web page, pre-simulated results will be displayed on another web page.

2.2 Real Time Simulation

This option allows users to select from 126 million existing buildings in the United States that have been
identified in ORNL’s Model America database (version 1.0) [2]. Users can enter the address of a building.
The GeoWISE built-in map will locate. the building and zoom in to show the satellite view of the building.
Using the latitude and longitude of the selected building, GeoWISE searches the Model America database
to find the basic information of the building, including the climate zone where the building is located,
building type (principal function), footprint of the building, vintage, total height, floor to floor height,
number of floors, total floor area, and window-to-wall ratio. The footprint of a building is drawn based on
available Google Earth image of the building. The other information about the building is estimated from
the street view of the building or other available data sources. Thus, this data may not be accurate all the
time.

Users can modify the number of floors and floor-to-floor height to change the total height of the building.
Users can also modify the window-to-wall ratio of the building and the thermal conductivity of the ground
formation at the building site if they have more accurate information than what is shown on the webpage.
Users can edit the polygon that reprsents the footprint of the selected building directly on the map. When
editing the polygon, users can add, delete, and move polygon points to match the footprint of the selected
building. If the building selected through the address search is incorrect, user can use the 'Pick Building'
button option (as shown in Figure 6) to manually select the correct one by navigating on the map. This
option is available only for the existing buildings.

If the intended building is not included in the Model America database or has not been yet constructed, the
user can draw footprint of the building based on the satellite view, or building design, and provide the
building information manually by selecting “New Building” in the “Choose New or Existing building”
option. In other words, if the user selects “New Building” for the “Choose New or Existing building” option,
the tool assumes the user would like to draw the footprint manually. The buttons to draw the footprint of
the “New Building” can be seen in Figure 7.

Users can describe multiple buildings to evaluate the potential of a district GHP system, as shown in Figure
6. GeoWISE currently can simulate a simplified district GHP system, which has a two-pipe water loop
(supply and return) and a central GHE that serves multiple buildings in the district GHP system. The heat
loss and thermal mass of the two-pipe water loop is not accounted for. GeoWISE can determine the required
borehole length, total number and layout of boreholes of the central GHE and predict energy use of the
district GHP system.

The available data input fields in the GeoWISE tool are described below. The options with “*” are
mandatory input, rest are optional.

  Choose New or Existing building*: New building option allows users to draw their building
 footprint, and existing building allows users to search their existing building through Model
 America database.
  Street Address, City, Zip Code, State: Enter location details. Users can use the “Search Address”
 button to find the building in the built-in map. These inputs are not mandatory for “New Building”,

 in which case users can find location of a new building by navigating the built-in map in satellite
 or street view.
 Climate Zone*: Auto-populated based on location.
 Building Type*: Select the type of building (e.g., Residential, Office, School, etc.).
 Vintage*: Choose the edition of ASHRAE standard 90.1, which the building was designed in
 compliance with.
 Total Building Height: Auto-calculated value based on user inputs of Number of Floors and Floor-
 to-Floor Height.
 Floor-to-Floor Height*: Enter the average value of distance between floors in the building.
 Number of Floors*: Enter the number of above-grade floors in the building.
 Total Building Floor Area: Auto-calculated value based on the area of building footprint (shown
 on the map) and user input of Number of Floors.
 Window-to-Wall Ratio*: Specify the fraction of window area relative to the gross wall area. The
 tool accepts values between 0.05 to 1.
 Baseline Infiltration Level*: Specify a specific infiltration level. This option is available only for
 single family residential buildings.
 Baseline Wall Insulation*: Specify a wall insulation R-value. Default wall insulation level of
 DOE’s prototype building model for the selected climate zone and vintage-specific building type.
 Baseline Roof Insulation*: Specify a roof insulation R-value. Default roof insulation level of
 DOE’s prototype building model for the selected climate zone and vintage-specific building type.
 Baseline Glazing*: Specify specific glazing type. Default glazing type of DOE’s prototype
 building model for the selected climate zone and vintage-specific building type.

2.2.1 Borehole field properties and available area for drilling boreholes

These are optional parameters that users can define if they have the relevant information, as shown in Figure
8. Each parameter has a default value, which users can modify. GeoWISE will show acceptable range for
each borehole field design parameters if users delete the default values. In the current version of GeoWISE,
only one land area can be defined, regardless of the number of buildings selected for the simulation.
Therefore, if a user has multiple land areas available for drilling boreholes, it is recommended to specify a
land area that is equivalent to the combined multiple available land areas. If omitted, GeoWISE will assume
there is sufficient land for drilling all the boreholes needed.

2.2.2 Building envelope improvements

GeoWISE allows users to evaluate the benefits of combining building envelope improvements with GHP
deployment, as shown in Figure 9. The current version supports improvements in wall insulation, roof
insulation, glazing, and outdoor air infiltration. For wall insulation and roof insulation, the tool offers
options of increasing insulation by 10%, 30%, or 50% from the baseline. For glazing system, the options
are double pane clear windows, double pane low-e windows, and triple pane low-e windows. It is important
to note that glazing improvements may not always represent an actual improvement, since baseline
buildings of recent vintages may already include higher-performance glazing systems. However, for
consistency, these options are provided, and users are advised to choose glazing options carefully. The
outdoor air infiltration improvement is only applicable to single-family houses. The infiltration can be
reduced by 10%, 30%, or 50% from the baseline.

 Figure 9. Building envelope improvement options

Users may select infiltration rates of 0.8 ACH, 0.5 ACH or 0.35 ACH for residential buildings. If a user
selects 0.8 ACH, all available retrofit options for infiltration improvements will be displayed. If the user
maintains the default outdoor air infiltration rate of 0.5 ACH, only 10% or 30% improvement options will
be available. However, if the tight construction option of 0.35 ACH is selected, no infiltration improvement
options will be shown.

 3. OUTPUT ANALYSIS

3.1 Interpreting Output Results

Results of pre-configured buildings are displayed instantly after users selects a pre-configured building.
The real-time simulations typically take about 2–3 minutes to complete and display the results. The results
compare the GHP system with a conventional baseline HVAC system in terms of energy use, cost, and
carbon emissions. Figure 9 shows the full portion of the webpage displaying the results, including the
annual benefits to the user and the economics of the GHP system compared with the baseline HVAC system.
Default values of utility rates are displayed in the webpage and used to calculate the operation cost savings
from GHP system. The default values are national averages obtained from the DOE’s Energy Information
Administration [3]. Users can modify the natural gas price, electricity price, and water price on the webpage,
GeoWISE will automatically recalculate the costs using the modified prices. Users can also modify the
GHE price (with a default value of $14 per linear feet of borehole length) to see how it will affect the
economic metrics (Simple Payback Period and Annual Return of Investment) of the GHP system in real
time. The tool also enables users to input cost data for air sealing, insulation, and glazing replacement, see
Figure 10.

The results are classified into different categories as shown in Figure 9. These are:
  GHP system size: It includes total borehole length and the total capacity of the GHP system. It
 also displays the length of borehole per ton of GHP capacity for the designed system
  Economics: It displays the cost premium of the GHP system. The cost premium of the GHP system
 is approximated as the cost of the GHE. Based on this cost, a simple payback period is calculated
 by dividing with annual utility cost savings.
  Benefits: This section presents annual savings in electricity, natural gas, site energy, and source
 energy, as well as a reduction in annual carbon emissions, annual peak electricity demand, and
 annual water usage, from the GHP system compared with the baseline HVAC system.
  Consumptions: This section reports the energy use, water use, carbon emissions, energy cost, and
 peak electricity demand for the baseline HVAC system and GHP system on an annual basis. A
 stacked bar chart is also displayed on the right side of this table to compare various energy end uses
 on annual basis between the baseline HVAC and the GHP system.
  Annual end use electricity and natural gas use: This horizontal bar chart presents the comparison
 between the two systems in terms of electricity and natural gas usage in each end use.

The displayed results can be downloaded or printed by clicking “Print Results” button available at the top
right corner of the webpage.

3.2 Simulation History Page

The Simulation History page (shown in Figure 11) allows each user to view the status and results of his/her
simulations, as well as download the necessary input and output files for debugging. The user can access
simulation history page using the top menu button option, as shown in Figure 2. Simulation history page
is only available for real time simulation. To view the results, users can click the 'View' button under the
RESULTS column. Results of successful simulations can be reviewed by the user at any time.

If a simulation fails, GeoWISE will provide users with a brief error message, as illustrated in Figure 11. All
required files for debugging can be downloaded from the DEBUG FILES column. The downloaded files
include OpenStudio input files (baseline building, retrofitted baseline, building with GHP deployed)
generated by the GeoWISE, hourly thermal loads of GHE, borefield layout in csv file and image file, and
GHE design parameters. Figure 13 shows a sample borefield layout generated based on available land area,
thermal loads of GHE, and borehole field design shown in Figure 8.

If the user wants to analyze different energy-efficiency measures or adjust the borehole field from the
previous simulation, they can use the “Load/Edit” option (shown in Figure 11) to modify the existing inputs
and rerun the simulation.

 Figure 11. Simulation history page of each user

To run the OpenStudio files generated by GeoWISE, users must use OpenStudio version 3.2.0 or 3.2.1 (or
OpenStudio Application version 1.2.0 or 1.2.1). In the event of a failed simulation, users can use the
downloaded files to debug the issue or to report it to us. To report issues or errors, please contact the site
administrator, using the feedback option as shown in Figure 2.

 4. LIMITATIONS

Despite its advanced capabilities, GeoWISE has several limitations that should be acknowledged. One
important limitation is the simplified representation of thermal energy networks. The current version does
not explicitly model hydronic loop dynamics, including thermal losses to the surrounding environment and
the thermal storage effects within distribution piping. These factors can significantly influence system
performance, particularly in district-scale geothermal applications where piping networks cover large areas
and operate under varying load conditions. Consequently, system efficiency and thermal energy exchange
among buildings may be somewhat idealized.

Another limitation concerns the characterization of baseline HVAC systems, particularly for residential
buildings. At present, baseline systems are generated using generalized assumptions based on building type
and construction vintage. While this approach enables rapid model development, it may not fully capture

 14

the diversity of HVAC configurations found in real-world buildings, potentially affecting the accuracy of
comparative techno-economic analyses between conventional and geothermal systems.

In addition, GeoWISE does not currently model the integration of ground-source heat pump (GSHP)
systems for domestic hot water (DHW) production. Because DHW can account for a substantial portion of
building energy consumption, especially in residential and multifamily buildings, the absence of this
capability may result in an incomplete assessment of overall energy savings and system performance.

Additionally, the current version of GeoWISE does not allow users to define below-grade floors
(basements). A further limitation stems from the use of the AutoBEM tool for automated building model
generation. AutoBEM represents each floor as a single thermal zone, which does not capture core-perimeter
zoning or other multizone complexities commonly present in real buildings. As a result, the generated
building energy models may not fully represent spatial variations in thermal loads and indoor environmental
conditions.

Future developments of GeoWISE will address these limitations by incorporating more detailed thermal
network modeling, improving baseline HVAC system characterization, expanding GSHP applications to
include domestic hot water production, and enhancing building energy model fidelity. These
improvements will strengthen the accuracy and robustness of techno-economic analyses for both
individual buildings and district-scale geothermal systems.
