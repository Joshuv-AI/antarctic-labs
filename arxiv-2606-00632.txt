Handling Control System Optimality
Hao Li

Abstract
Control science is a core representative of the third industrial revolution and is so important to modern civilization. Control systems are the main subject of control science and may involve many aspects of consideration, such as hardware consideration, software consideration, operation consideration, maintenance consideration, economy consideration, society consideration. However, besides all such aspects of consideration, one aspect that is most essential to the control system is methodology consideration in mathematical sense, knowledge on which is what we refer to as control theory . Besides its importance from the mathematical perspective, control theory is even more charming as it is deeply rooted in practical applications. Charms of control theory consist in both know-why and know-how and it is the fusion of control theory and practical applications that highlights such charms. Control theory for practical applications, especially when somewhat with so-called “advanced” flavour, involves several fundamental aspects. This article introduces the Handling Control System Optimality aspect of Advanced Control Theory for Practical Applications [ 19 , 29 ] .



1
Optimal control

Handling of control system uncertainty intends to
guarantee the bottom-line performance
of a control system, whereas handling of control system optimality intends to
achieve the best or at least better performance
of the control system. This chapter presents a number of representative methods for handling control system optimality.

1.1
Minimizing control cost

As clarified in Section 5.2 in Chapter 5, a full-state feedback control law for the single or double inverted pendulum control system, which works if the initial deviation of the cart position is close to zero, may no longer work if the initial deviation of the cart position is not close to zero. The reason why the full-state feedback control law may incur a control failure is that it only focuses on converging the final state to the expected state as soon as possible,
without considering intermediate state evolution during the control process
, or more specifically,
without considering quality of intermediate state evolution during the control process
. Consequently, it may generate drastic control input and cause the state to evolve into state space where the essential modelling assumption is violated.

How to take
intermediate state evolution during the control process
into account? One methodology is to regulate intermediate state evolution indirectly by incorporating the spirit of
sliding mode control
, as already demonstrated in in Section 5.2 in Chapter 5.

1.2
Linear quadratic regulator

It is normally difficult to solve (
3
) analytically and even numerically. On the other hand, if linear state-space modelling described by

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\mathbf{A}\mathbf{x}+\mathbf{B}\mathbf{u}

(4)

can be fairly adopted for the control system and if the control cost functional
c(\mathbf{x}_{:},\mathbf{u}_{:})
adopts a quadratic form as

\displaystyle c(\mathbf{x}_{:},\mathbf{u}_{:})=\int_{0}^{\infty}(\mathbf{x}^{\mathrm{T}}\mathbf{Q}\mathbf{x}+\mathbf{u}^{\mathrm{T}}\mathbf{R}\mathbf{u})\mathrm{d}t

(5)

with normally
positive definite
cost matrices
\mathbf{Q}
and
\mathbf{R}
, then the optimal control law of
\mathbf{u}_{:}
can be obtained analytically.

The instantiation of the optimal control strategy described by (
3

4

5

linear quadratic regulator

1

\mathbf{u}_{:}=\arg\min_{\mathbf{u}_{:}}\int_{0}^{\infty}(\mathbf{x}^{\mathrm{T}}\mathbf{Q}\mathbf{x}+\mathbf{u}^{\mathrm{T}}\mathbf{R}\mathbf{u})\mathrm{d}t.

(6)

To solve (
6

calculus of variations

1.3

For the moment, we consider a simplified version of the linear quadratic regulator. More specifically, instead of considering generic control input
\mathbf{u}_{:}
, we focus on the family of control input functions that are generated according to the full-state feedback control strategy. Then (
6

\mathbf{K}=\arg\min_{\mathbf{K}}\int_{0}^{\infty}(\mathbf{x}^{\mathrm{T}}\mathbf{Q}\mathbf{x}+\mathbf{u}^{\mathrm{T}}\mathbf{R}\mathbf{u})\mathrm{d}t|_{\mathbf{u}=-\mathbf{K}^{\mathrm{T}}\mathbf{x}},

(7)

which aims at obtaining the
optimal gain matrix

\mathbf{K}
of full-state feedback control. By default, we only consider the stabilizing gain matrix set specified in

\displaystyle\mathbf{K}_{\Omega}=\{\mathbf{K}\mbox{ }|\mbox{ }\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}}\mbox{ is stable.}\},

(8)

namely the set of gain matrices
\mathbf{K}
that can stabilize the control system. Suppose the control system’s target process is controllable and hence the stabilizing gain matrix set
\mathbf{K}_{\Omega}
is non-empty.

In the simplified version of the linear quadratic regulator, both the state function
\mathbf{x}_{:}
and the control input function
\mathbf{u}_{:}
can be expressed in terms of the gain matrix
\mathbf{K}

\displaystyle\mathbf{u}=-\mathbf{K}^{\mathrm{T}}\mathbf{x}

4

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\mathbf{A}\mathbf{x}+\mathbf{B}\mathbf{u}=(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})\mathbf{x},

from which we can derive

\displaystyle\mathbf{x}

\displaystyle=\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})t}\mathbf{x}_{0},

\displaystyle\mathbf{u}

\displaystyle=-\mathbf{K}^{\mathrm{T}}\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})t}\mathbf{x}_{0}.

We abuse the control cost functional notation to simply denote

\displaystyle c(\mathbf{K})\equiv c(\mathbf{x}_{:},\mathbf{u}_{:}),

which is computed as

\displaystyle c(\mathbf{K})=\int_{0}^{\infty}(\mathbf{x}^{\mathrm{T}}\mathbf{Q}\mathbf{x}+\mathbf{u}^{\mathrm{T}}\mathbf{R}\mathbf{u})\mathrm{d}t=\mathbf{x}_{0}^{\mathrm{T}}\mathbf{P}(\mathbf{K})\mathbf{x}_{0},

\displaystyle\mathbf{P}(\mathbf{K})\equiv\int_{0}^{\infty}\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})^{\mathrm{T}}t}(\mathbf{Q}+\mathbf{K}\mathbf{R}\mathbf{K}^{\mathrm{T}})\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})t}\mathrm{d}t.

The positive definite matrix
\mathbf{P}(\mathbf{K})
determines the control cost of full-state feedback control associated with the gain matrix
\mathbf{K}

\displaystyle\mathbf{K}\in\mathbf{K}_{\Omega},

namely if and only if

\displaystyle\mathbf{A}_{c}\equiv\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}}

is stable — Note that the integrand

\displaystyle\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})^{\mathrm{T}}t}(\mathbf{Q}+\mathbf{K}\mathbf{R}\mathbf{K}^{\mathrm{T}})\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})t}>0

\displaystyle\lim_{t\to\infty}\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})^{\mathrm{T}}t}(\mathbf{Q}+\mathbf{K}\mathbf{R}\mathbf{K}^{\mathrm{T}})\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})t}

\displaystyle=0

and hence

is stable, we can choose a matrix norm and know that the norm of

\displaystyle\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})t}

is bounded within certain exponentially-decaying limit. Since the integral of an exponentially-decaying function definitely exists,
\mathbf{P}(\mathbf{K})

As

\displaystyle\mathbf{P}(\mathbf{K})

\displaystyle\equiv\int_{0}^{\infty}\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})^{\mathrm{T}}t}(\mathbf{Q}+\mathbf{K}\mathbf{R}\mathbf{K}^{\mathrm{T}})\mathrm{e}^{(\mathbf{A}-\mathbf{B}\mathbf{K}^{\mathrm{T}})t}\mathrm{d}t

Each non-zero element of

\displaystyle\mathbf{K}^{\mathrm{T}}\mathbf{z}=\mathbf{K}^{\mathrm{T}}\mathrm{e}^{\mathbf{M}t}\mathbf{z}_{0}

must be a linear combination of linearly independent function terms, in the form of

\displaystyle\sum_{i}c_{i}\mathrm{e}^{\lambda_{i}t}t^{k_{i}}

where all
\lambda_{i}
belong to the set of eigenvalues of
\mathbf{M}
. Since all eigenvalues of
\mathbf{M}
are with positive real part, we definitely have

\displaystyle\lim_{t\to\infty}\sum_{i}c_{i}\mathrm{e}^{\lambda_{i}t}t^{k_{i}}\not=\mathbf{0},

which contradicts the condition that

\displaystyle\lim_{t\to\infty}\mathbf{K}^{\mathrm{T}}\mathrm{e}^{\mathbf{M}t}\mathbf{z}_{0}=\mathbf{0}.

To avoid such contradiction, we must have

\displaystyle\mathbf{K}^{\mathrm{T}}\mathbf{z}=\mathbf{K}^{\mathrm{T}}\mathrm{e}^{\mathbf{M}t}\mathbf{z}_{0}\equiv\mathbf{0}

and hence have

\mathbf{u}=-\mathbf{K}^{\mathrm{T}}(\mathbf{x}-\mathbf{z})=-\mathbf{K}^{\mathrm{T}}\mathbf{x}.

(23)

The derived result given in (
23
) conveys an important and interesting fact: For the linear quadratic regulator, the optimal control input function
\mathbf{u}_{:}
and the optimal state function
\mathbf{x}_{:}
caused by the optimal
\mathbf{u}_{:}
mutually satisfy a relationship the same to that of optimal full-state feedback control. In other words, for the linear quadratic regulator, the optimal control method is right the optimal full-state feedback control method.

2.1
System model simplification for optimal control

As presented in Section
1
, given a control system that adopts generic state-space modelling described by (
1
)

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=f(\mathbf{x},\mathbf{u}).

We can treat the state function
\mathbf{x}_{:}
as a functional in terms of the control input function
\mathbf{u}_{:}
. Once certain control cost functional
c(\mathbf{x}_{:},\mathbf{u}_{:})
is defined, the methodology of
optimal control
is formalized in (
3
)

\displaystyle\mathbf{u}_{:}=\arg\min_{\mathbf{u}_{:}}c(\mathbf{x}_{:},\mathbf{u}_{:})\equiv\arg\min_{\mathbf{u}_{:}}c(\mathbf{u}_{:}),

where the control cost functional
c(\mathbf{x}_{:},\mathbf{u}_{:})
can be treated as a functional implicitly in terms of
\mathbf{u}_{:}
, and we may abuse the control cost functional notation to simply denote

\displaystyle c(\mathbf{u}_{:})\equiv c(\mathbf{x}_{:},\mathbf{u}_{:}).

If the control system can fairly adopt linear state-space modelling described by (
4
) and if the control cost functional
c(\mathbf{x}_{:},\mathbf{u}_{:})
adopts the quadratic form described in (
5
), then the methodology of optimal control is instantiated as the
linear quadratic regulator
described by (
6
)

\displaystyle\mathbf{u}_{:}=\arg\min_{\mathbf{u}_{:}}\int_{0}^{\infty}(\mathbf{x}^{\mathrm{T}}\mathbf{Q}\mathbf{x}+\mathbf{u}^{\mathrm{T}}\mathbf{R}\mathbf{u})\mathrm{d}t,

which can be solved analytically and its solution is right the optimal full-state feedback control method.

What if linear state space modelling cannot be adopted for the control system? In this case, it is normally difficult to solve (
3
) analytically and even numerically. Despite such difficulty, can we still take advantage of the spirit of optimal control in regulating intermediate state evolution via minimization of certain control cost?

Fortunately, the answer is
yes
, yet we need to follow the spirit of optimal control in adapted way. More specifically, we may simplify the original system model described by (
1
) to a new formalism as

\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\bar{f}(\mathbf{x},\mathbf{u})

(26)

such that (
26
) can somehow approximate dynamics of the control system’s state on one hand and that

\displaystyle\mathbf{u}_{:}=\arg\min_{\mathbf{u}_{:}}c(\mathbf{x}_{:},\mathbf{u}_{:})|_{\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\bar{f}(\mathbf{x},\mathbf{u})}

(27)

can be effectively solved in analytical or numerical way on the other hand.

There are usually two directions for simplification of (
1
) into (
26
). First, we may simplify the system model directly by approximating partial state dynamics. Second, we may simplify the system model indirectly by confining the control input function to tractable patterns. Practical applications will be presented later for demonstration.

As only a simplified version of the original system model described by (
1
), the new system model described by (
26
) may not predict state evolution so accurately in the long run, yet (
26
) tends to fairly predict general tendency of state evolution. Consequently, the control input function
\mathbf{u}_{:}
obtained by solving (
27
) may not be really optimal in the long run, yet the obtained
\mathbf{u}_{:}
in short time tends to enable the state to evolve optimally, at least in the sense of general tendency of state evolution. In other words, the obtained
\mathbf{u}_{:}
in short time tends to be reasonable, whereas the obtained
\mathbf{u}_{:}
in the long run may not.

2.2
Dynamical optimal control

How to harmonize inconsistency between the performance of the obtained control input function
\mathbf{u}_{:}
in short time and that in the long run? For this concern, an idea is: At the first control period

\displaystyle t=0,

based on current state feedback, solve the following optimization problem

\displaystyle\mathbf{u}_{0:\infty}=\arg\min_{\mathbf{u}_{0:\infty}}c(\mathbf{x}_{0:\infty},\mathbf{u}_{0:\infty})|_{\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\bar{f}(\mathbf{x},\mathbf{u})}

to obtain the optimal control input function
\mathbf{u}_{0:\infty}
. Adopt the first control input
\mathbf{u}_{0}
from the obtained
\mathbf{u}_{0:\infty}
but discard all remaining part of the obtained
\mathbf{u}_{0:\infty}
. Apply only the first control input
\mathbf{u}_{0}
to the control system at the first control period. At next control period

\displaystyle t=\Delta t,

based on state feedback at the moment then, solve the following optimization problem

\displaystyle\mathbf{u}_{\Delta t:\infty}=\arg\min_{\mathbf{u}_{\Delta t:\infty}}c(\mathbf{x}_{\Delta t:\infty},\mathbf{u}_{\Delta t:\infty})|_{\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\bar{f}(\mathbf{x},\mathbf{u})}

to obtain the optimal control input function
\mathbf{u}_{\Delta t:\infty}
. Also adopt the first control input
\mathbf{u}_{\Delta t}
but discard all remaining part of the obtained
\mathbf{u}_{\Delta t:\infty}
. Also apply only the first control input
\mathbf{u}_{\Delta t}
to the control system. Further at next control period

\displaystyle t=2\Delta t,

solve the following optimization problem

\displaystyle\mathbf{u}_{2\Delta t:\infty}=\arg\min_{\mathbf{u}_{2\Delta t:\infty}}c(\mathbf{x}_{2\Delta t:\infty},\mathbf{u}_{2\Delta t:\infty})|_{\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\bar{f}(\mathbf{x},\mathbf{u})}

to obtain the optimal control input function
\mathbf{u}_{2\Delta t:\infty}
. Also adopt the first control input
\mathbf{u}_{2\Delta t}
only and apply it to the control system. Continue above process in similar way at control periods

\displaystyle t=3\Delta t,\quad 4\Delta t,\quad 5\Delta t,\quad\cdots

and so on.

In one word,
this idea consists in performing optimal control iteratively in dynamical way
: At each control period
t
, based on current state feedback, solve the following functional optimization problem

\displaystyle\mathbf{u}_{t:\infty}=\arg\min_{\mathbf{u}_{t:\infty}}c(\mathbf{x}_{t:\infty},\mathbf{u}_{t:\infty})|_{\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\bar{f}(\mathbf{x},\mathbf{u})}

(28)

to obtain the optimal control input function
\mathbf{u}_{t:\infty}
. Adopt the current control input namely the first control input
\mathbf{u}_{t}
from the obtained
\mathbf{u}_{t:\infty}
but discard all remaining part of the obtained
\mathbf{u}_{t:\infty}
. Apply only
\mathbf{u}_{t}
to the control system at current control period
t
. To distinguish from the original methodology of optimal control, above methodology of dynamical optimal control is called the
model predictive control
or simply
predictive control

[
28
,
15
]
.

Model predictive control

Initialization:

Approximate the system model (
1
) by a fairly simplified version (
26
).

Iteration:

Retrieve state feedback at current control period
t
.

Solve (
28
) to obtain the optimal control input function
\mathbf{u}_{t:\infty}

Adopt the first control input
\mathbf{u}_{t}
but discard all remaining part of

Apply only

Application: intelligent vehicle model predictive control

Consider intelligent vehicle parking control which aims at controlling the intelligent vehicle to move from certain initial pose to the destination pose in a parking slot. Low-speed dynamics of the intelligent vehicle state
\mathbf{x}
can be modelled by the state differential equation

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}\equiv\frac{\mathrm{d}}{\mathrm{d}t}\begin{bmatrix}x\\
y\\
\phi\\
\beta\\
v\end{bmatrix}=\begin{bmatrix}v\cos\phi\\
v\sin\phi\\
\frac{v}{L}\tan\beta\\
\max\{\min\{\frac{1}{\tau_{\beta}}(\beta_{I}-\beta),s_{M}\},-s_{M}\}\\
\max\{\min\{\frac{1}{\tau_{v}}(v_{I}-v),a_{M}\},-a_{M}\}\end{bmatrix}\equiv f(\mathbf{x},\mathbf{u}),

(29)

where the state

\displaystyle\mathbf{x}\equiv\begin{bmatrix}x&y&\phi&\beta&v\end{bmatrix}^{\mathrm{T}}

consists of the vehicle longitudinal position, the vehicle lateral position, the vehicle orientation or heading angle (namely yaw angle), the vehicle steering angle, and the vehicle velocity. Besides,
L
denotes the vehicle wheel-base,
\tau_{\beta}
denotes the time-constant of the steer controller,
s_{M}
denotes the maximum steering velocity,
\tau_{v}
denotes the time-constant of the velocity controller, and
a_{M}
denotes the maximum vehicle acceleration (or deceleration). The control input

\displaystyle\mathbf{u}\equiv\begin{bmatrix}\beta_{I}&v_{I}\end{bmatrix}^{\mathrm{T}}

is the multiple-input of vehicle steering angle command
\beta_{I}
and vehicle velocity command
v_{I}
.

We decouple intelligent vehicle longitudinal control and intelligent vehicle lateral control. For longitudinal control, we may empirically follow the constrained proportional control method as

\displaystyle v_{I}=\max\{\min\{-P\Delta x,v_{M}\},-v_{M}\},

where
\Delta x
denotes the distance of the intelligent vehicle in front of or behind the expected parking slot pose,
v_{M}
denotes the maximum vehicle velocity allowed during parking.

The more difficult part of intelligent vehicle parking control is lateral control and we focus on this part. The system model described by (
29
) is nonlinear and complicated. It is difficult to apply optimal control with (
29
) as

\displaystyle\mathbf{u}_{:}=\arg\min_{\mathbf{u}_{:}}c(\mathbf{x}_{:},\mathbf{u}_{:})|_{\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=f(\mathbf{x},\mathbf{u})}.

Instead, we resort to the methodology of model predictive control. For this purpose, we simplify (
29
) in two directions: First, we simplify (
29
) directly by neglecting both lateral and longitudinal transient dynamics and obtain

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\begin{bmatrix}x\\
y\\
\phi\\
\beta\\
v\end{bmatrix}=\begin{bmatrix}v_{I}\cos\phi\\
v_{I}\sin\phi\\
\frac{1}{L}v_{I}\tan\beta_{I}\\
\beta_{I}\\
v_{I}\end{bmatrix}.

(30)

Given constant
\beta_{I}
and
v_{I}
, based on (
30
), we can conveniently derive the state evolution between any two time instants
t
and
t^{\prime}
as

\displaystyle\left\{\begin{array}[]{l l}\phi_{t^{\prime}}-\phi_{t}&=\frac{v_{I}}{L}\tan\beta_{I}(t^{\prime}-t)\equiv\omega_{I}(t^{\prime}-t)\\
x_{t^{\prime}}-x_{t}&=\int_{t}^{t^{\prime}}v_{I}\cos\phi\mathrm{d}t=\frac{v_{I}}{\omega_{I}}(\sin\phi_{t^{\prime}}-\sin\phi_{t})\\
y_{t^{\prime}}-y_{t}&=\int_{t}^{t^{\prime}}v_{I}\sin\phi\mathrm{d}t=\frac{v_{I}}{\omega_{I}}(\cos\phi_{t}-\cos\phi_{t^{\prime}})\end{array}\right.

It is worth noting that when

\displaystyle\omega_{I}\approx 0,

the last two equations in (
2.2
) are replaced by

\displaystyle\left\{\begin{array}[]{l l}x_{t^{\prime}}-x_{t}&=v_{I}(t^{\prime}-t)\cos\frac{\phi_{t^{\prime}}+\phi_{t}}{2}\\
y_{t^{\prime}}-y_{t}&=v_{I}(t^{\prime}-t)\sin\frac{\phi_{t^{\prime}}+\phi_{t}}{2}\end{array}\right.

Second, we simplify (
29
) indirectly by confining the control input function to a special action pattern. More specifically, we set a predictive time span as

\displaystyle T_{P}=\frac{\sqrt{(x-x_{\mathrm{E}})^{2}+(y-y_{\mathrm{E}})^{2}}}{v_{I}},

which heuristically represents the time roughly needed for the intelligent vehicle to move from its current pose to the expected parking slot pose. Besides, to avoid a too long predictive time span
T_{P}
that causes predictive ability of the simplified system model to deteriorate significantly, we set an upper limit for the predictive time span
T_{P}
as

\displaystyle T_{P}=\min\{\frac{\sqrt{(x-x_{\mathrm{E}})^{2}+(y-y_{\mathrm{E}})^{2}}}{v_{I}},T_{M}\}.

(36)

Divide the predictive time horizon

\displaystyle[0,T_{P}]\equiv\{t_{P}\mbox{ }|\mbox{ }0\leq t_{P}\leq T_{P}\}

into two even halves

\displaystyle[0,T_{P}/2]

\displaystyle\equiv\{t_{P}\mbox{ }|\mbox{ }0\leq t_{P}\leq T_{P}/2\},

\displaystyle[T_{P}/2,T_{P}]

\displaystyle\equiv\{t_{P}\mbox{ }|\mbox{ }T_{P}/2\leq t_{P}\leq T_{P}\}.

In the first predictive time horizon half, set

\displaystyle\beta_{I}=\beta_{I1}\in[-\beta_{M},\beta_{M}]

where
\beta_{M}
denotes the maximum steering angle. Then in the second predictive time horizon half, set

\displaystyle\beta_{I}=\beta_{I2}\in\{-\beta_{I1},0,\beta_{I1}\}.

In other words, choices of the steering angle command
\beta_{I2}
for the second predictive time horizon half depend on the choice of the steering angle command
\beta_{I1}
for the first predictive time horizon half. Such pattern of the steering angle command pair

\displaystyle\{\beta_{I1},\beta_{I2}\}

is called the
double-action pattern
.

Figure 1:
Typical steering modes: (a) steering/back-steering mode; (b) steering/straight mode; (c) pure-steering mode.

The double-action pattern has three modes namely the steering/back-steering mode

\displaystyle\{\beta_{I1},-\beta_{I1}\},

the steering/straight mode

\displaystyle\{\beta_{I1},0\},

and the pure-steering mode

\displaystyle\{\beta_{I1},\beta_{I1}\}

that correspond to three typical daily-life steering modes respectively, as illustrated in Figure
1
. The steering/straight mode is reduced to the pure-straight mode if

\displaystyle\beta_{I1}=0.

After above simplification, the control input function
\mathbf{u}_{t:t+T_{P}}
can be represented by the double-action pattern. We can use (
2.2
) to conveniently predict the state at any time of the predictive time horizon, yet we only examine the predicted state at the end of the predictive time horizon and compare it with the expected parking slot pose. We have

\displaystyle v_{t+T_{P}}

\displaystyle=v_{I},

\displaystyle\beta_{t+T_{P}}

\displaystyle=\beta_{I2},

\displaystyle\phi_{t+T_{P}/2}

\displaystyle=\phi_{t}+\omega_{I1}\frac{T_{P}}{2},

\displaystyle\phi_{t+T_{P}}

\displaystyle=\phi_{t}+\omega_{I1}\frac{T_{P}}{2}+\omega_{I2}\frac{T_{P}}{2},

\displaystyle x_{t+T_{P}}

\displaystyle=x_{t}+\frac{v_{I}}{\omega_{I1}}(\sin\phi_{t+T_{P}/2}-\sin\phi_{t})+\frac{v_{I}}{\omega_{I2}}(\sin\phi_{t+T_{P}}-\sin\phi_{t+T_{P}/2}),

\displaystyle y_{t+T_{P}}

\displaystyle=y_{t}+\frac{v_{I}}{\omega_{I1}}(\cos\phi_{t}-\cos\phi_{t+T_{P}/2})+\frac{v_{I}}{\omega_{I2}}(\cos\phi_{t+T_{P}/2}-\cos\phi_{t+T_{P}}),

compactly denoted as

\displaystyle\mathbf{x}_{t+T_{P}}=\bar{f}(\mathbf{x}_{t},\mathbf{u}_{t:t+T_{P}})\equiv\bar{f}(\mathbf{x}_{t},\{\beta_{I1},\beta_{I2}\}).

(37)

When

\displaystyle\omega_{I1}\approx 0

or

\displaystyle\omega_{I2}\approx 0,

the terms associated with
\omega_{I1}
or
\omega_{I2}
in the last two equations above are replaced by corresponding terms as those in (
2.2
).

Define the control cost functional
c(\mathbf{x}_{t:t+T_{P}},\mathbf{u}_{t:t+T_{P}})
namely the control cost functional on the predictive time horizon as

\displaystyle c(\mathbf{x}_{t:t+T_{P}},\mathbf{u}_{t:t+T_{P}})\equiv c(\mathbf{x}_{t+T_{P}},\{\beta_{I1},\beta_{I2}\})=(\mathbf{x}_{t+T_{P}}-\mathbf{x}_{\mathrm{E}})^{\mathrm{T}}\mathbf{Q}(\mathbf{x}_{t+T_{P}}-\mathbf{x}_{\mathrm{E}})+R\beta_{I1}^{2}.

(38)

Then instantiate the methodology of model predictive control for intelligent vehicle lateral control as follows. At each control period
t
, based on current intelligent vehicle state feedback, solve the following optimization problem

\displaystyle\mathbf{u}_{t:t+T_{P}}=\arg\min_{\mathbf{u}_{t:t+T_{P}}}c(\mathbf{x}_{t:t+T_{P}},\mathbf{u}_{t:t+T_{P}})|_{\mathbf{x}_{t+T_{P}}=\bar{f}(\mathbf{x}_{t},\mathbf{u}_{t:t+T_{P}})}

namely

\displaystyle\{\beta_{I1},\beta_{I2}\}=\arg\min_{\{\beta_{I1},\beta_{I2}\}}c(\mathbf{x}_{t+T_{P}},\{\beta_{I1},\beta_{I2}\})|_{\mathbf{x}_{t+T_{P}}=\bar{f}(\mathbf{x}_{t},\{\beta_{I1},\beta_{I2}\})}

(39)

to obtain the optimal control input function
\mathbf{u}_{t:t+T_{P}}
namely the optimal double-action pattern. Adopt the first control input
\beta_{I1}
but discard
\beta_{I2}
. Apply only
\beta_{I1}
to the intelligent vehicle lateral control system at current control period
t

function stt = DynamicsIVforMPC(ConfigMPC, sttIn, sIn, vIn)

if (nargin
<
4) vIn = 2; end

2.3
Use a linear system model as the simplified system model

To perform model predictive control in many practical applications, a natural choice of the simplified system model for a control system is its linear system model. More specifically, given a control system that adopts generic state-space modelling described by (
1
)

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=f(\mathbf{x},\mathbf{u}).

Suppose a linear state differential equation described in (
4
)

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\mathbf{A}\mathbf{x}+\mathbf{B}\mathbf{u}

is adopted as the simplified system model (
26
) for sake of effectively applying model predictive control. Then the functional optimization problem (
27
) namely the simplified version of the original functional optimization problem (
3
) actually becomes

\mathbf{u}_{:}=\arg\min_{\mathbf{u}_{:}}c(\mathbf{x}_{:},\mathbf{u}_{:})|_{\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\mathbf{A}\mathbf{x}+\mathbf{B}\mathbf{u}}.

(40)

As only a simplified version of the original system model described by (
1
), the linear system model described by (
4
) may not predict state evolution so accurately in the long run, yet it tends to fairly predict general tendency of state evolution. Consequently, the control input function
\mathbf{u}_{:}
obtained by solving (
40
) may not be really optimal in the long run, but tends to be reasonable in short time. To avoid a too long predictive time span that causes predictive ability of the linear system model to deteriorate significantly, we may set an upper limit for the predictive time span, denoted as
T_{P}
. Then we have model predictive control based on linear system modelling or for short
linear model predictive control
.

Linear model predictive control

Initialization:

1
) by a linear system model (
4
).

Iteration:

Retrieve state feedback at current control period
t
.

Solve (

) to obtain the optimal control input function
\mathbf{u}_{t:t+T_{P}}
.

Adopt the first control input
\mathbf{u}_{t}
but discard all remaining part of
\mathbf{u}_{t:t+T_{P}}
.

Apply only
\mathbf{u}_{t}
to the control system at
t
. Then
t\to t+\Delta t
.

It is worth clarifying differences between the linear quadratic regulator and the linear model predictive control, both of which resort to linear system modelling. The ways in which they treat linear system modelling are different: The former treats the linear system model as an indeed valid model that can describe dynamics of the control system’s state, whereas the latter treats the linear system model only as an expedient model that enables realization of model predictive control. The ways in which they treat the obtained control input function are also different: The former treats the obtained control input function as the indeed optimal control solution for the entire time span, whereas the latter does not treat it so but only takes its first one.

Closed-form solution

A closed-form solution can be derived for linear model predictive control. Recall the discrete-time system model

\displaystyle\mathbf{x}_{t}=\mathrm{e}^{\mathbf{A}\Delta t}\mathbf{x}_{t-1}+[\int_{0}^{\Delta t}\mathrm{e}^{\mathbf{A}(\Delta t-\tau)}\mathbf{B}\mathrm{d}\tau]\mathbf{u}_{t}\equiv\mathbf{A}^{*}\mathbf{x}_{t-1}+\mathbf{B}^{*}\mathbf{u}_{t},

(41)

derivation of which follows the natural assumption that the control input during current control period

\displaystyle[t-1,t]\equiv[t-\Delta t,t]

is constantly
\mathbf{u}_{t}
. In (
41
),
\Delta t
denotes the control period and

\displaystyle\mathbf{A}^{*}

\displaystyle\equiv\mathrm{e}^{\mathbf{A}\Delta t}=\sum_{k=0}^{\infty}\frac{\mathbf{A}^{k}\Delta t^{k}}{k!}=\mathbf{I}+\mathbf{A}\Delta t+\frac{\mathbf{A}^{2}\Delta t^{2}}{2}+\cdots,

\displaystyle\mathbf{B}^{*}

\displaystyle\equiv\int_{0}^{\Delta t}\mathrm{e}^{\mathbf{A}(\Delta t-\tau)}\mathbf{B}\mathrm{d}\tau=[\sum_{k=0}^{\infty}\frac{\mathbf{A}^{k}\Delta t^{k+1}}{(k+1)!}]\mathbf{B}=(\mathbf{I}+\frac{\mathbf{A}\Delta t}{2}+\frac{\mathbf{A}^{2}\Delta t^{2}}{6}+\cdots)\mathbf{B}\Delta t.

In the context of model predictive control, we needs to predict future states from current state, so apply (
41
) iteratively forwards (i.e. towards the future) as

\displaystyle\mathbf{x}_{t+1}

\displaystyle=\mathbf{A}^{*}\mathbf{x}_{t}+\mathbf{B}^{*}\mathbf{u}_{t},

\displaystyle\mathbf{x}_{t+2}

\displaystyle=\mathbf{A}^{*}\mathbf{x}_{t+1}+\mathbf{B}^{*}\mathbf{u}_{t+1}=\mathbf{A}^{*}(\mathbf{A}^{*}\mathbf{x}_{t}+\mathbf{B}^{*}\mathbf{u}_{t})+\mathbf{B}^{*}\mathbf{u}_{t+1}=\mathbf{A}^{*2}\mathbf{x}_{t}+\sum_{i=0}^{1}\mathbf{A}^{*1-i}\mathbf{B}^{*}\mathbf{u}_{t+i},

\displaystyle\mathbf{x}_{t+3}

\displaystyle=\mathbf{A}^{*}\mathbf{x}_{t+2}+\mathbf{B}^{*}\mathbf{u}_{t+2}=\mathbf{A}^{*3}\mathbf{x}_{t}+\sum_{i=0}^{2}\mathbf{A}^{*2-i}\mathbf{B}^{*}\mathbf{u}_{t+i},

\displaystyle\cdots

\displaystyle\quad\cdots

or generically as

\mathbf{x}_{t+k}=\mathbf{A}^{*k}\mathbf{x}_{t}+\sum_{i=0}^{k-1}\mathbf{A}^{*k-1-i}\mathbf{B}^{*}\mathbf{u}_{t+i}

(42)

where
k\in\{1,2,3,\cdots\}
. It is worth noting that control input subscripts in the formalism (
42
), compared with those in the formalism (
41
), are shifted by one control period towards the past. However, such “paraphrasing” of control input scripts has no influence on the discrete-time system model itself, only if one bears in mind that
\mathbf{u}_{t}
in the discrete-time system model formalism (
42
) namely the formalism used in the context of control effect analysis is actually
\mathbf{u}_{t+1}
in the discrete-time system model formalism (
41
) namely the formalism used in the context of state estimation.

Suppose the predictive time span length is generically denoted as
n
or in other words the predictive time span consists of
n
control periods. Predict the
n
future states

\displaystyle\mathbf{x}_{t+1},\quad\mathbf{x}_{t+2},\quad\mathbf{x}_{t+3},\quad\cdots\quad,\quad\mathbf{x}_{t+n-1},\quad\mathbf{x}_{t+n}

via (
42
) and concatenate them into one large vector as

\begin{bmatrix}\mathbf{x}_{t+1}\\
\mathbf{x}_{t+2}\\
\mathbf{x}_{t+3}\\
\vdots\\
\mathbf{x}_{t+n}\end{bmatrix}=\begin{bmatrix}\mathbf{A}^{*}\\
\mathbf{A}^{*2}\\
\mathbf{A}^{*3}\\
\vdots\\
\mathbf{A}^{*n}\end{bmatrix}\mathbf{x}_{t}+\begin{bmatrix}\mathbf{B}^{*}&&&&\\
\mathbf{A}^{*}\mathbf{B}^{*}&\mathbf{B}^{*}&&&\\
\mathbf{A}^{*2}\mathbf{B}^{*}&\mathbf{A}^{*}\mathbf{B}^{*}&\mathbf{B}^{*}&&\\
\vdots&\vdots&\vdots&\ddots&\\
\mathbf{A}^{*n-1}\mathbf{B}^{*}&\mathbf{A}^{*n-2}\mathbf{B}^{*}&\mathbf{A}^{*n-3}\mathbf{B}^{*}&\cdots&\mathbf{B}^{*}\end{bmatrix}\begin{bmatrix}\mathbf{u}_{t}\\
\mathbf{u}_{t+1}\\
\mathbf{u}_{t+2}\\
\vdots\\
\mathbf{u}_{t+n-1}\end{bmatrix}.

(43)

Denote relevant vectors and matrices in (
43
) as

\mathbf{X}_{n}\equiv\begin{bmatrix}\mathbf{x}_{t+1}\\
\vdots\\
\mathbf{x}_{t+n}\end{bmatrix},\quad\mathbf{U}_{n}\equiv\begin{bmatrix}\mathbf{u}_{t}\\
\vdots\\
\mathbf{u}_{t+n-1}\end{bmatrix},\quad\mathbf{A}_{n}\equiv\begin{bmatrix}\mathbf{A}^{*}\\
\vdots\\
\mathbf{A}^{*n}\end{bmatrix},\quad\mathbf{B}_{n}\equiv\begin{bmatrix}\mathbf{B}^{*}&&\\
\vdots&\ddots&\\
\mathbf{A}^{*n-1}\mathbf{B}^{*}&\cdots&\mathbf{B}^{*}\end{bmatrix}

(44)

and formalize (
43
) compactly as

\mathbf{X}_{n}=\mathbf{A}_{n}\mathbf{x}_{t}+\mathbf{B}_{n}\mathbf{U}_{n}.

(45)

The block matrix
\mathbf{A}_{n}
and the lower triangular block matrix
\mathbf{B}_{n}
are fixed and can be pre-computed once the predictive time span length
n
is given.

Suppose the control cost functional
c(\mathbf{x}_{t+1:t+n},\mathbf{u}_{t:t+n-1})
adopts a quadratic form as

c(\mathbf{x}_{t+1:t+n},\mathbf{u}_{t:t+n-1})=\sum_{k=1}^{n}(\mathbf{x}_{t+k}^{\mathrm{T}}\mathbf{Q}_{k}\mathbf{x}_{t+k}+\mathbf{u}_{t+k-1}^{\mathrm{T}}\mathbf{R}_{k}\mathbf{u}_{t+k-1})\equiv\mathbf{X}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{X}_{n}+\mathbf{U}_{n}^{\mathrm{T}}\mathbf{R}\mathbf{U}_{n},

(46)

where

\displaystyle\mathbf{Q}\equiv\begin{bmatrix}\mathbf{Q}_{1}&&\\
&\ddots&\\
&&\mathbf{Q}_{n}\end{bmatrix},\quad\mathbf{R}\equiv\begin{bmatrix}\mathbf{R}_{1}&&\\
&\ddots&\\
&&\mathbf{R}_{n}\end{bmatrix}

are two positive definite diagonal block matrices. Substitute (
45
) and (
46
) into (
40
) and obtain the concrete functional optimization problem

\mathbf{U}_{n}=\arg\min_{\mathbf{U}_{n}}\mathbf{X}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{X}_{n}+\mathbf{U}_{n}^{\mathrm{T}}\mathbf{R}\mathbf{U}_{n}|_{\mathbf{X}_{n}=\mathbf{A}_{n}\mathbf{x}_{t}+\mathbf{B}_{n}\mathbf{U}_{n}}

(47)

namely

\displaystyle\mathbf{U}_{n}

\displaystyle=\arg\min_{\mathbf{U}_{n}}(\mathbf{A}_{n}\mathbf{x}_{t}+\mathbf{B}_{n}\mathbf{U}_{n})^{\mathrm{T}}\mathbf{Q}(\mathbf{A}_{n}\mathbf{x}_{t}+\mathbf{B}_{n}\mathbf{U}_{n})+\mathbf{U}_{n}^{\mathrm{T}}\mathbf{R}\mathbf{U}_{n}

\displaystyle=\mathbf{U}_{n}^{\mathrm{T}}(\mathbf{B}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{B}_{n}+\mathbf{R})\mathbf{U}_{n}+2\mathbf{x}_{t}^{\mathrm{T}}\mathbf{A}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{B}_{n}\mathbf{U}_{n}+\mathbf{x}_{t}^{\mathrm{T}}\mathbf{A}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{A}_{n}\mathbf{x}_{t}

which has the closed-form solution

\mathbf{U}_{n}=-(\mathbf{B}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{B}_{n}+\mathbf{R})^{-1}\mathbf{B}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{A}_{n}\mathbf{x}_{t}.

(48)

For model predictive control, take only the first one of the control input sequence
\mathbf{U}_{n}
as

\mathbf{u}_{t}=\mathbf{E}_{1}^{\mathrm{T}}\mathbf{U}_{n}=-\mathbf{E}_{1}^{\mathrm{T}}(\mathbf{B}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{B}_{n}+\mathbf{R})^{-1}\mathbf{B}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{A}_{n}\mathbf{x}_{t}

(49)

namely

\displaystyle\mathbf{u}=-\mathbf{K}_{mpc}^{\mathrm{T}}\mathbf{x},

where

\displaystyle\mathbf{E}_{1}

\displaystyle=\begin{bmatrix}\mathbf{I}&\mathbf{0}&\cdots&\mathbf{0}\end{bmatrix}^{\mathrm{T}},

\displaystyle\mathbf{K}_{mpc}

\displaystyle=\mathbf{A}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{B}_{n}(\mathbf{B}_{n}^{\mathrm{T}}\mathbf{Q}\mathbf{B}_{n}+\mathbf{R})^{-1}\mathbf{E}_{1}

and the time index subscript
t
is omitted. Here,
\mathbf{E}_{1}
can be regarded as the block matrix version of
\mathbf{e}_{1}
.

DesignGMLinearMPC.m

% A : State transition matrix

% B : Control input matrix

% DT : Control period

% n : Predictive time span length

% Q,R: Control cost weights

function [Kmpc, Astar, Bstar, An, Bn] = DesignGMLinearMPC(A,B,DT,n,Q,R)

sttn = size(A,2); sttm = size(B,2); I = eye(sttn);

Astar = I + A*DT + Aˆ2*DTˆ2/2;

Bstar = (I + A*DT/2 + Aˆ2*DTˆ2/6)*B*DT;

An = zeros(n*sttn,sttn); Bn = zeros(n*sttn,n*sttm);

An(1:sttn,:) = Astar; Bn(1:sttn,1:sttm) = Bstar;

for i=2:n

iS = (i-1)*sttn+1:i*sttn; An(iS,:) = An(iS-sttn,:)*Astar;

Bn(iS,1:sttm) = Astar*Bn(iS-sttn,1:sttm);

Bn(iS,sttm+1:i*sttm) = Bn(iS-sttn,1:(i-1)*sttm);

end

Kmpc = An’*Q*Bn*inv(Bn’*Q*Bn+R); Kmpc = Kmpc(:,1);

end

We should hold a dialectic attitude towards models or model formalisms: We not only need to bear in mind what they can describe, but also need to bear in mind what they cannot describe and make sure that what they cannot describe will not influence achievement of our concerned objectives or at least of our main concerned objectives in practical applications. However, what if stochastic factors do have considerable influence on the control system and we do need to handle them explicitly? 3.1
Stochastic optimal control

As concrete realization of stochastic optimal control tends to have a flavour of numeric computation, a discrete-time version of state-space modelling for the control system would be more appropriate than a continuous-time counterpart version, in terms of facilitating control system analysis and control law design. Recall the generic discrete-time system model described in

\displaystyle\mathbf{x}_{t}=g(\mathbf{x}_{t-1},\mathbf{u}_{t}).

(55)

Similar to what is explained in Section
2.3
, (
55
) gives the discrete-time system model formalism used rather in the context of state estimation. We can “paraphrase” the discrete-time system model (
55
) from the control perspective by shifting control period indices as

\mathbf{x}_{t+1}=g(\mathbf{x}_{t},\mathbf{u}_{t}).

(56)

We can further incorporate explicit modelling of stochastic factors into (
56
) as

\mathbf{x}_{t+1}=g(\mathbf{x}_{t},\mathbf{u}_{t},\mathbf{w}_{t}),

(57)

where
\mathbf{w}
denotes the input of stochastic factors that cause stochastic behaviour of control system dynamics.

Unique-modal stochastic behaviour versus multiple-modal stochastic behaviour

Stochastic behaviour of control system dynamics includes two kinds: unique-modal stochastic behaviour and multiple-modal stochastic behaviour. The former refers to the kind of state evolution that is about a unique state trajectory with certain random uncertainty, whereas the latter refers to the kind of state evolution that can be potentially about multiple state trajectories with certain random uncertainty.

Daily-life analogy may facilitate understanding of the difference between the two kinds of stochastic behaviour. Unique-modal stochastic behaviour is like we drive on a single-lane road. Although usually there is somewhat random deviation of the vehicle from the lane center, the vehicle is always about the center of the unique lane. In contrast, multiple-modal stochastic behaviour is like we drive on a multiple-lane road. There is still random deviation of the vehicle from the center of the lane on which the vehicle drives, and this is one aspect of stochastic behaviour of the vehicle driving on the multiple-lane road. Besides, we may potentially switch among all the multiple lanes from time to time, and this is another aspect of stochastic behaviour of the vehicle driving on the multiple-lane road.

Be stochastic behaviour actually unique-modal or multiple-modal, the stochastic factors that cause it are compactly denoted as
\mathbf{w}
in the generic discrete-time system model (
57
).

Policy, stationary policy, and optimal policy

As implied by (
64

\displaystyle\mathbf{u}_{0}^{*}(\mathbf{x}),\quad\mathbf{u}_{1}^{*}(\mathbf{x}),\quad\mathbf{u}_{2}^{*}(\mathbf{x}),\quad\mathbf{u}_{3}^{*}(\mathbf{x}),\quad\cdots

at the very beginning (i.e.
\mathbf{x}_{0}

3.2
Bellman equation and dynamic programming mapping

Consider the optimal total cost expectation function
c^{*}(\mathbf{x})
defined in (
62
)

\displaystyle c^{*}(\mathbf{x})=\min_{\mathbf{u}_{:}}c_{\mathbf{u}_{:}}(\mathbf{x}).

For expression conciseness, save the time subscript for variables at the initial time

\displaystyle t=0,

namely

\displaystyle\mathbf{x}_{0}=\mathbf{x},\quad\mathbf{u}_{0}=\mathbf{u},\quad\mathbf{w}_{0}=\mathbf{w}.

Substitute (
59
) into (
62
) and obtain

\displaystyle c^{*}(\mathbf{x})

\displaystyle=\min_{\mathbf{u}_{:}}\mathop{E}\{\sum_{t=0}^{\infty}\alpha^{t}s(\mathbf{x}_{t},\mathbf{u}_{t},\mathbf{w}_{t})\}=\min_{\mathbf{u}_{:}}\mathop{E}\{s(\mathbf{x},\mathbf{u},\mathbf{w})+\alpha\sum_{t=1}^{\infty}\alpha^{t-1}s(\mathbf{x}_{t},\mathbf{u}_{t},\mathbf{w}_{t})\}

\displaystyle=\min_{\mathbf{u}\equiv\mu(\mathbf{x})}\mathop{E}\{s(\mathbf{x},\mathbf{u},\mathbf{w})+\alpha\min_{\mathbf{u}_{1:\infty}}\mathop{E}\{\sum_{t=0}^{\infty}\alpha^{t}s(\mathbf{x}_{t+1},\mathbf{u}_{t+1},\mathbf{w}_{t+1})\}\}

\displaystyle=\min_{\mathbf{u}\equiv\mu(\mathbf{x})}\mathop{E}\{s(\mathbf{x},\mathbf{u},\mathbf{w})+\alpha c^{*}(\mathbf{x}_{1})\}

\displaystyle=\min_{\mathbf{u}\equiv\mu(\mathbf{x})}\mathop{E}\{s(\mathbf{x},\mathbf{u},\mathbf{w})+\alpha c^{*}(g(\mathbf{x},\mathbf{u},\mathbf{w}))\},

which implies that
c^{*}(\mathbf{x})
is the solution of the functional equation

c(\mathbf{x})=\min_{\mathbf{u}\equiv\mu(\mathbf{x})}\mathop{E}\{s(\mathbf{x},\mathbf{u},\mathbf{w})+\alpha c(g(\mathbf{x},\mathbf{u},\mathbf{w}))\}.

(74)

This functional equation (
74
) is called the
Bellman equation

[
3
]
.

Define a functional mapping, namely the
dynamic programming mapping

[
4
]

\displaystyle T\quad:\quad c(\mathbf{x})\to(Tc)(\mathbf{x})

as

(Tc)(\mathbf{x})\equiv\min_{\mathbf{u}\equiv\mu(\mathbf{x})}\mathop{E}\{s(\mathbf{x},\mathbf{u},\mathbf{w})+\alpha c(g(\mathbf{x},\mathbf{u},\mathbf{w}))\}.

(75)

Similarly, given a stationary policy
\mu
, define the functional mapping

\displaystyle T_{\mu}\quad:\quad c(\mathbf{x})\to(T_{\mu}c)(\mathbf{x})

as

(T_{\mu}c)(\mathbf{x})\equiv\mathop{E}\{s(\mathbf{x},\mu(\mathbf{x}),\mathbf{w})+\alpha c(g(\mathbf{x},\mu(\mathbf{x}),\mathbf{w}))\}.

(76)

Let
T^{k}
denote the composition of the dynamic programming mapping
T
with itself
k
times, i.e.

\displaystyle(T^{0}c)(\mathbf{x})

\displaystyle\equiv c(\mathbf{x}),

(77a)

\displaystyle(T^{k}c)(\mathbf{x})

\displaystyle\equiv(T(T^{k-1}c))(\mathbf{x}),\quad k\in\{1,2,\cdots\}.

(77b)

Let
T_{\mu}^{k}
similarly denote the composition of the mapping
T_{\mu}
with itself
k
times.

Dynamic programming algorithm

Based on above functional mapping notations, the
dynamic programming algorithm
can be put forward as follows.

Dynamic programming

Initialization:

Set
(T^{0}c)(\mathbf{x})
to the zero function, i.e.
(T^{0}c)(\mathbf{x})=0
.

Iteration:

Apply the dynamic programming mapping (
75
) to

.

Then
k\to k+1
.

Given a discount factor
\alpha
and a bounded cost per stage function

, the dynamic programming algorithm tends to converge to
c^{*}(\mathbf{x})
namely the solution of the Bellman equation

c(\mathbf{x})=(Tc)(\mathbf{x}).

(78)

The formalism (
78
), which takes advantage of the dynamic programming mapping notation
T
defined in (
75
), is the compact version of the Bellman equation (
74
). Once

converges, the optimal policy
\mu
is the one that achieves

\displaystyle\mathop{E}\{s(\mathbf{x},\mu(\mathbf{x}),\mathbf{w})+\alpha c(g(\mathbf{x},\mu(\mathbf{x}),\mathbf{w}))\}

\displaystyle=c(\mathbf{x})

\displaystyle=\min_{\mu}\mathop{E}\{s(\mathbf{x},\mu(\mathbf{x}),\mathbf{w})+\alpha c(g(\mathbf{x},\mu(\mathbf{x}),\mathbf{w}))\}.

3.3
Markov decision process (MDP)

For tractability of performing stochastic optimal control in practical applications, we may discretize the state space
\mathbf{X}
to a finite state space namely a state space of finite states only. We may also discretize the control input space
\mathbf{U}
to a finite control input space.

Suppose the state space
\mathbf{X}
consists of
n
states as

\mathbf{X}\equiv\{\mathbf{x}^{[1]},\quad\mathbf{x}^{[2]},\quad\cdots\quad,\quad\mathbf{x}^{[n]}\}.

(79)

Formalize the
transition probabilities
among the states as

p_{ij}(\mathbf{u})=p(\mathbf{x}^{[j]}\mbox{ }|\mathbf{x}^{[i]},\mathbf{u})\equiv p(\mathbf{x}_{t+1}=\mathbf{x}^{[j]}\mbox{ }|\mathbf{x}_{t}=\mathbf{x}^{[i]},\mathbf{u}),

(80)

where

\displaystyle t\in\{0,1,2,\cdots\},\quad i,j\in\{1,\cdots,n\},\quad\mathbf{u}\in\mathbf{U}.

For a stationary policy
\mu
, once the state space is finite as specified in (
79
), the control input space is naturally finite as

\mathbf{U}\equiv\{\mu(\mathbf{x}^{[1]}),\quad\mu(\mathbf{x}^{[2]}),\quad\cdots\quad,\quad\mu(\mathbf{x}^{[n]})\}.

(81)

If both the state space
\mathbf{X}
and the control input space

3.2
is reduced to the

Markov decision process dynamic programming mapping

The dynamic programming mapping
T

\displaystyle(Tc)(\mathbf{x})\equiv\min_{\mathbf{u}}\mathop{E}\{s(\mathbf{x},\mathbf{u},\mathbf{w})+\alpha c(g(\mathbf{x},\mathbf{u},\mathbf{w}))\}

(Tc)(\mathbf{x}^{[i]})\equiv\min_{\mathbf{u}}\sum_{j=1}^{n}p_{ij}(\mathbf{u})(s(\mathbf{x}^{[i]},\mathbf{u},\mathbf{x}^{[j]})+\alpha c(\mathbf{x}^{[j]}))

where the expression

denotes the cost per stage function. The stationary policy mapping
T_{\mu}

(T_{\mu}c)(\mathbf{x}^{[i]})\equiv\sum_{j=1}^{n}p_{ij}(\mu(\mathbf{x}^{[i]}))(s(\mathbf{x}^{[i]},\mu(\mathbf{x}^{[i]}),\mathbf{x}^{[j]})+\alpha c(\mathbf{x}^{[j]})).

(83)

We may further assume that the cost per stage does not depend on
\mathbf{x}^{[j]}
but only on
\mathbf{x}^{[i]}
and
\mathbf{u}
— This is fair in practice, because cost due to
\mathbf{x}^{[j]}
will after all be counted in the cost per stage at next control period. It is unnecessary to double count cost due to any state — The assumption that the cost per stage depends only on
\mathbf{x}^{[i]}
and
\mathbf{u}
, i.e.

s(\mathbf{x}^{[i]},\mathbf{u},\mathbf{x}^{[1]})=s(\mathbf{x}^{[i]},\mathbf{u},\mathbf{x}^{[2]})=\cdots=s(\mathbf{x}^{[i]},\mathbf{u},\mathbf{x}^{[n]})=s(\mathbf{x}^{[i]},\mathbf{u})

(84)

will be followed by default throughout the remaining part of Section

. Then the Markov decision process dynamic programming mapping described by (
82
) becomes

(Tc)(\mathbf{x}^{[i]})\equiv\min_{\mathbf{u}}[s(\mathbf{x}^{[i]},\mathbf{u})+\alpha\sum_{j=1}^{n}p_{ij}(\mathbf{u})c(\mathbf{x}^{[j]})]

(85)

and the Markov decision process stationary policy mapping described by (

) becomes

(T_{\mu}c)(\mathbf{x}^{[i]})\equiv s(\mathbf{x}^{[i]},\mu(\mathbf{x}^{[i]}))+\alpha\sum_{j=1}^{n}p_{ij}(\mu(\mathbf{x}^{[i]}))c(\mathbf{x}^{[j]}).

(86)

Represent the functions

,

, and

(Tc)(\mathbf{x}^{[n]})\end{bmatrix},\quad T_{\mu}c\equiv\begin{bmatrix}(T_{\mu}c)(\mathbf{x}^{[1]})\\
(T_{\mu}c)(\mathbf{x}^{[2]})\\
\vdots\\
(T_{\mu}c)(\mathbf{x}^{[n]})\end{bmatrix}.

(87)

For a stationary policy
\mu

\mathbf{P}_{\mu}\equiv\begin{bmatrix}p_{11}(\mu(\mathbf{x}^{[1]}))&p_{12}(\mu(\mathbf{x}^{[1]}))&\cdots&p_{1n}(\mu(\mathbf{x}^{[1]}))\\

(89)

Then we can formalize (

T_{\mu}c=s_{\mu}+\alpha\mathbf{P}_{\mu}c.

Then from (

The reason why the matrix

\displaystyle\lambda(\mathbf{I}-\alpha\mathbf{P}_{\mu})\geq 1-\alpha\rho(\mathbf{P}_{\mu})\geq 1-\alpha\||\mathbf{P}_{\mu}\||_{\infty}=1-\alpha>0.

The concatenated inequalities in above derivation are supported by (

) presented in Section

in Appendix

as the maximum row sum matrix norm
\||\cdot\||_{\infty}
defined in (

Value iteration and Q-learning

To apply the Markov decision process version of stochastic optimal control, we may resort to the method of
value iteration
. More specifically, start with an arbitrary
n
-dimensional vector
c
and iteratively compute

c\quad\implies\quad Tc\quad\implies\quad T^{2}c\quad\implies\quad\cdots\quad\implies\quad c^{*}\equiv\lim_{k\to\infty}T^{k}c

More specifically, denote

\displaystyle c_{k}\equiv T^{k}c,\quad k\in\{0,1,2,\cdots\}

and follow (
82

c_{k+1}(\mathbf{x}^{[i]})=\min_{\mathbf{u}}\sum_{j=1}^{n}p_{ij}(\mathbf{u})(s(\mathbf{x}^{[i]},\mathbf{u},\mathbf{x}^{[j]})+\alpha c_{k}(\mathbf{x}^{[j]})).

(94)

Then we have the
value iteration algorithm
.

Value iteration

Initialization:

Set certain initial cost function
c_{0}
.

Iteration:

Apply the dynamic programming mapping
T
to the cost function
c_{k}

\displaystyle c_{k+1}=Tc_{k}.

Obtain the corresponding policy
\mu_{k+1}
according to (
94

\displaystyle c_{k+1}

\displaystyle=T_{\mu_{k+1}}c_{k}=Tc_{k}

\displaystyle\iff\mu_{k+1}(\mathbf{x}^{[i]})

\displaystyle=\arg\min_{\mathbf{u}}\sum_{j=1}^{n}p_{ij}(\mathbf{u})(s(\mathbf{x}^{[i]},\mathbf{u},\mathbf{x}^{[j]})+\alpha c_{k}(\mathbf{x}^{[j]})).

Then
k\to k+1
.

Define

(96)

Substitute (

(97)

(100)

Policy iteration and rollout

To apply the Markov decision process version of stochastic optimal control, we may also resort to the method of
policy iteration
. The idea of policy iteration is to generate a sequence of stationary policies with monotonically improving cost. The policy iteration method may be implemented with the state related costs or with the Q-factors.

For a stationary policy
\mu

91

\displaystyle(\mathbf{I}-\alpha\mathbf{P}_{\mu})c_{\mu}=s_{\mu}

in terms of

\displaystyle c_{\mu}=(\mathbf{I}-\alpha\mathbf{P}_{\mu})^{-1}s_{\mu}.

This is to compute the converged cost function corresponding to
\mu

\displaystyle c_{\mu}=T_{\mu}c_{\mu}

which conveys that
c_{\mu}
is the “stationary point” or “fixed point” of the stationary policy mapping
T_{\mu}

Based on the stationary policy
\mu
, compute an improved policy
\bar{\mu}

(101)

\displaystyle\iff\bar{\mu}(\mathbf{x}^{[i]})=\arg\min_{\mathbf{u}}\sum_{j=1}^{n}p_{ij}(\mathbf{u})(s(\mathbf{x}^{[i]},\mathbf{u},\mathbf{x}^{[j]})+\alpha c_{\mu}(\mathbf{x}^{[j]})).

3.4
Probability-weighted Markov decision process

For practical applications that are themselves of discrete logic nature, for example, the game of
Go
(i.e. “Yi” or “Wei Qi” in its original Chinese name), the Markov decision process version of stochastic optimal control can be applied directly. In contrast, for practical applications that involve continuous state space and control input space, we cannot apply the Markov decision process version of stochastic optimal control directly. To take advantage of the Markov decision process methodology, we first need to discretize the state space
\mathbf{X}
to a finite state space and discretize the control input space
\mathbf{U}
to a finite control input space as well. Then we need to approximate the continuous state space by the finite number of states and approximate the continuous control input space by the finite number of control input choices. A natural idea for such approximation is to approximate a generic state by the closest one in the finite state space and approximate a generic control input value by the closest one in the finite control input space.

However, this simple way of state space and control input space approximation tends to face a dilemma: On one hand, if the cardinalities of the finite state space and the finite control input space are large enough to guarantee desirable approximation effect, then the computational burden incurred by the huge amount of states and control input choices tends to be forbidding. On the other hand, if the cardinalities of the finite state space and the finite control input space are moderate for computational tractability, then coarse approximation due to the insufficient amount of states and control input choices tends to cause a completely useless instantiation of the Markov decision process methodology — The latter aspect of the dilemma will be further clarified with the application example of low-speed vehicle lateral control to be presented below soon.

To handle the dilemma between forbidding computation and coarse approximation, the
probability-weighted Markov decision process
method or
randomized Markov decision process
method is proposed. More specifically, given a continuous state space
\mathbf{X}
discretized into a finite state space
\mathbf{X}_{D}
of
n
states as formalized in (
79
)

\displaystyle\mathbf{X}_{D}\equiv\{\mathbf{x}^{[1]},\quad\mathbf{x}^{[2]},\quad\cdots\quad,\quad\mathbf{x}^{[n]}\}.

For a generic continuous state
\mathbf{x}\in\mathbf{X}
, instead of approximating it by the closest one in the finite state space
\mathbf{X}_{D}
, we may treat it as a
probabilistic superposition
of multiple states and even all the states in
\mathbf{X}_{D}
, namely

\mathbf{x}=\sum_{i=1}^{n}p(\mathbf{x}|\mathbf{x}^{[i]})\mathbf{x}^{[i]}.

(109)

Suppose the optimal policy
\mu
is obtained and hence the continuous control input space
\mathbf{U}
is naturally discretized into the finite control input space as formalized in (
81
)

\displaystyle\mathbf{U}_{D}\equiv\{\mu(\mathbf{x}^{[1]}),\quad\mu(\mathbf{x}^{[2]}),\quad\cdots\quad,\quad\mu(\mathbf{x}^{[n]})\},

then for the generic continuous state
\mathbf{x}
, its corresponding control input
\mathbf{u}
can be treated as a probabilistic superposition of the control input choices in
\mathbf{U}_{D}
, namely

\mathbf{u}=\mu(\mathbf{x})\equiv\sum_{i=1}^{n}p(\mathbf{x}|\mathbf{x}^{[i]})\mu(\mathbf{x}^{[i]}).

(110)

For the probability weights
p(\mathbf{x}|\mathbf{x}^{[i]})
involved in (
109
) and (
110
), a heuristic yet not bad way is to set it according to the Gaussian distribution as

p(\mathbf{x}|\mathbf{x}^{[i]})\propto\frac{1}{\sqrt{(2\pi)^{n}|\mathbf{\Sigma}|}}\mathrm{e}^{-\frac{1}{2}(\mathbf{x}-\mathbf{x}^{[i]})^{\mathrm{T}}\mathbf{\Sigma}^{-1}(\mathbf{x}-\mathbf{x}^{[i]})}

(111)

or simply as

\displaystyle p(\mathbf{x}|\mathbf{x}^{[i]})\propto\mathrm{e}^{-(\mathbf{x}-\mathbf{x}^{[i]})^{\mathrm{T}}\mathbf{\Sigma}^{-1}(\mathbf{x}-\mathbf{x}^{[i]})},

which implies that

p(\mathbf{x}|\mathbf{x}^{[i]})=\frac{\mathrm{e}^{-(\mathbf{x}-\mathbf{x}^{[i]})^{\mathrm{T}}\mathbf{\Sigma}^{-1}(\mathbf{x}-\mathbf{x}^{[i]})}}{\sum_{j=1}^{n}\mathrm{e}^{-(\mathbf{x}-\mathbf{x}^{[j]})^{\mathrm{T}}\mathbf{\Sigma}^{-1}(\mathbf{x}-\mathbf{x}^{[j]})}}.

(112)

The motivation to “approximate” dynamic programming, be the “approximate” spirit embodied as
approximation in value space
(or for short
value approximation
) or embodied as
approximation in policy space
(or for short
policy approximation
), normally consists in two aspects:
computation reduction
and
representation reduction
.

Computation reduction

Dynamic programming involves iteration by nature. Then the ideal case of computation reduction for dynamic programming is to perform only one step or round of iteration. Take the value iteration algorithm as example, its underlying working mechanism is that given an arbitrary initial cost function
c_{0}
, then by a large enough number of value improvement steps the cost function will converge to the optimal one
c^{*}
as

\displaystyle\lim_{k\to\infty}T^{k}c_{0}\to c^{*}

and to the corresponding optimal policy
\mu^{*}
as

\displaystyle T_{\mu^{*}}c^{*}

\displaystyle=Tc^{*}=c^{*}

\displaystyle\iff\mu^{*}(\mathbf{x}^{[i]})

\displaystyle=\arg\min_{\mathbf{u}}\sum_{j=1}^{n}p_{ij}(\mathbf{u})(s(\mathbf{x}^{[i]},\mathbf{u},\mathbf{x}^{[j]})+\alpha c^{*}(\mathbf{x}^{[j]})).

However, if we can ideally set the initial cost function

c_{0}=c^{*},

(119)

then we can obtain the optimal policy
\mu^{*}
just by one step or round of value improvement as

\mu^{*}(\mathbf{x}^{[i]})=\arg\min_{\mathbf{u}}\sum_{j=1}^{n}p_{ij}(\mathbf{u})(s(\mathbf{x}^{[i]},\mathbf{u},\mathbf{x}^{[j]})+\alpha c_{0}(\mathbf{x}^{[j]})),

(120)

which achieves the ideal case of computation reduction.

It is true that the initial condition described in (
119
) is ideal and can hardly be satisfied, yet an initial cost function
c_{0}
close enough to the optimal
c^{*}
, i.e.

c_{0}\approx c^{*},

(121)

would already enable the one step of value improvement described by (
120
) to achieve desirable control effect in practical applications — Even when the initial cost function
c_{0}
is not so close enough to the optimal
c^{*}
but is fairly close enough to
c^{*}
or even just fair enough (such as the one obtained via
Monte Carlo
simulation, be it close enough to
c^{*}
or not), it would still enable one step or few steps of (
120
) iteration to perform well.

Representation reduction

When the number of states is very large (and probably when the number of control input choices is large as well), how to represent the optimal cost function
c(\mathbf{x})
, how to represent the optimal Q-factors
Q(\mathbf{x},\mathbf{u})
, and how to represent the optimal policy
\mu(\mathbf{x})
, even when the optimal
c(\mathbf{x})
,
Q(\mathbf{x},\mathbf{u})
, and
\mu(\mathbf{x})
are assumed to be obtained, are not trivial issues but are themselves problems worth cares.

Compared with direct representation in look-up table fashion,
parametric representation
tends to be favoured. For example, artificial neural networks especially deep neural networks
[
8
]

[
12
]
can be used. To facilitate understanding of how parametric representation brings representation reduction, we may resort to an analogue with image classification. Consider the AlexNet
[
16
]
, the debut of which marks renaissance of deep learning. It consists of five convolutional layers and three full connection (or dense) layers, and has a total number of
60
million parameters

18
18

18

The first convolutional layer consists of two tensors of size
55\times 55\times 48
(i.e. 48 feature maps of size
55\times 55
) accommodated by two GPUs respectively, with a convolution kernel of size
11\times 11\times 3
; so the layer has
(11\times 11\times 3+55\times 55)\times 48\times 2=325248
parameters. The second convolutional layer consists of two tensors of size
27\times 27\times 128
on the two GPUs respectively, with a convolution kernel of size
5\times 5\times 48
(input from the previous layer only on one GPU); so the layer has
(5\times 5\times 48+27\times 27)*128*2=493824
parameters. The third convolutional layer consists of two tensors of size
13\times 13\times 192
, with a convolution kernel of size
3\times 3\times 256
(input from the previous layer on both GPUs); so the layer has
(3\times 3\times(128+128)+13\times 13)\times 192\times 2=949632
parameters. The fourth convolutional layer consists of two tensors of size
13\times 13\times 192
, with a convolution kernel of size
3\times 3\times 192
(input from the previous layer only on one GPU); so the layer has
(3\times 3\times 192+13\times 13)\times 192\times 2=728448
parameters. The fifth convolutional layer consists of two tensors of size
13\times 13\times 128
, with a convolution kernel of size
3\times 3\times 192
(input from the previous layer only on one GPU); so the layer has
(3\times 3\times 192+13\times 13)\times 128\times 2=485632
parameters. After max pooling, the fifth convolutional layer has two output tensors of size
6\times 6\times 128
. The first full connection layer has two arrays of 2048 neurons distributed on the two GPUs respectively; so the layer has
6\times 6\times(128+128)\times(2048+2048)+(2048+2048)=37752832
parameters. The second full connection layer has two arrays of 2048 neurons; so the layer has
4096\times 4096+4096=16781312
parameters. The third full connection layer has
1000
neurons; so the layer has
4096\times 1000+1000=4097000
parameters. Therefore, the AlexNet has a total number of
325248+493824+949632+728448+485632+37752832+16781312+4097000=61613928
parameters
\approx 60
million parameters.
.

The number of parameters of the AlexNet is indeed huge, yet is negligible compared with the total number of targeted image pixel states, which is

\displaystyle 256^{224\times 224\times 3}\approx 3.5\times 10^{362507}\gg 6\times 10^{7}.

Even suppose targeted images are binarized, the total number of targeted image pixel states is still

\displaystyle 2^{224\times 224\times 3}\approx 2.8\times 10^{45313}\gg 6\times 10^{7}.

In other words, the parametric representation of the AlexNet apparently brings representation reduction compared with the total number of targeted image pixel states.

Similarly, state-of-the-art visual “end-to-end” methods for autonomous driving
[
6
]
tend to involve large-scale neural network models that have a huge amount of parameters on one hand but can still bring much representation reduction on the other hand.

Application: low-speed vehicle lateral reinforcement learning control (via value approximation)

Consider the application example of low-speed vehicle lateral control as presented in Section
3.4
, for which the nonlinear state-space modelling described by (
113
)

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}\equiv\frac{\mathrm{d}}{\mathrm{d}t}\begin{bmatrix}y\\
\phi\\
\beta\end{bmatrix}=\begin{bmatrix}v\sin\phi\\
\frac{v}{L}\tan\beta\\
\max\{\min\{\frac{1}{\tau_{\beta}}(\beta_{I}-\beta),s_{M}\},-s_{M}\}\end{bmatrix}\equiv f(\mathbf{x},\beta_{I})

is adopted. Further suppose the vehicle steering operations are smooth enough such that vehicle steering dynamics can be neglected and adopt the vehicle lateral dynamics model described by (
114

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}\equiv\frac{\mathrm{d}}{\mathrm{d}t}\begin{bmatrix}y\\
\phi\end{bmatrix}=\begin{bmatrix}v\sin\phi\\
\frac{v}{L}\tan\beta\end{bmatrix}\equiv f(\mathbf{x},\beta),

where the vehicle lateral state

\displaystyle\mathbf{x}\equiv\begin{bmatrix}y&\phi\end{bmatrix}^{\mathrm{T}}

and

\displaystyle\beta\equiv\beta_{I}

serves directly as control input.

Set the cost per stage function as

s(\mathbf{x},\beta)=\begin{bmatrix}y&\phi\end{bmatrix}\begin{bmatrix}1&\\
&4\end{bmatrix}\begin{bmatrix}y\\
\phi\end{bmatrix}+0.1\beta^{2}\equiv\mathbf{x}^{\mathrm{T}}\mathbf{Q}\mathbf{x}+\beta^{\mathrm{T}}\mathbf{R}\beta.

(122)

For immediate cost per stage prediction at current control period, adopt the linearized version of (
114
), namely (
115
)

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{x}=\begin{bmatrix}0&v\\
0&0\end{bmatrix}\mathbf{x}+\begin{bmatrix}0\\
\frac{v}{L}\end{bmatrix}\beta\equiv\mathbf{A}\mathbf{x}+\mathbf{B}\beta,

the discrete-time counterpart of which can be approximated as

\begin{bmatrix}y_{t+1}\\
\phi_{t+1}\end{bmatrix}=(\mathbf{I}+\begin{bmatrix}0&v\\
0&0\end{bmatrix}\Delta T_{RL})\begin{bmatrix}y_{t}\\
\phi_{t}\end{bmatrix}+\begin{bmatrix}0\\
\frac{v}{L}\end{bmatrix}\Delta T_{RL}\beta_{t}\equiv\mathbf{A}^{*}\mathbf{x}_{t}+\mathbf{B}^{*}\beta_{t}

(123)

with
\Delta T_{RL}
denoting the reinforcement learning
Monte Carlo
simulation period.

For cost per stage prediction at following simulation periods, adopt (
2.2
)

\displaystyle\left\{\begin{array}[]{l l}\phi_{t^{\prime}}-\phi_{t}&=\frac{v}{L}\tan\beta(t^{\prime}-t)\equiv\omega(t^{\prime}-t)\\
x_{t^{\prime}}-x_{t}&=\int_{t}^{t^{\prime}}v\cos\phi\mathrm{d}t=\frac{v}{\omega}(\sin\phi_{t^{\prime}}-\sin\phi_{t})\\
y_{t^{\prime}}-y_{t}&=\int_{t}^{t^{\prime}}v\sin\phi\mathrm{d}t=\frac{v}{\omega}(\cos\phi_{t}-\cos\phi_{t^{\prime}})\end{array}\right.

the last two equations of which are replaced by (
2.2

\displaystyle\left\{\begin{array}[]{l l}x_{t^{\prime}}-x_{t}&=v(t^{\prime}-t)\cos\frac{\phi_{t^{\prime}}+\phi_{t}}{2}\\
y_{t^{\prime}}-y_{t}&=v(t^{\prime}-t)\sin\frac{\phi_{t^{\prime}}+\phi_{t}}{2}\end{array}\right.

when

\displaystyle\omega\approx 0.

Adopt a quadratic state cost model as

c(\mathbf{x})=\begin{bmatrix}y&\phi\end{bmatrix}\begin{bmatrix}m_{1}&m_{2}\\
m_{2}&m_{3}\end{bmatrix}\begin{bmatrix}y\\
\phi\end{bmatrix}\equiv\mathbf{x}^{\mathrm{T}}\mathbf{M}_{c}\mathbf{x}.

(124)

To learn the state cost model, perform
Monte Carlo
simulation for
N_{sim}
randomly selected state samples

\displaystyle\begin{bmatrix}y_{1}\\
\phi_{1}\end{bmatrix},\quad\begin{bmatrix}y_{2}\\
\phi_{2}\end{bmatrix},\quad\cdots\quad,\quad\begin{bmatrix}y_{N_{sim}}\\
\phi_{N_{sim}}\end{bmatrix}.

Given a generic state sample

\displaystyle\mathbf{x}^{[i]}=\begin{bmatrix}y_{i}&\phi_{i}\end{bmatrix}^{\mathrm{T}},

evaluate its associated cost via
Monte Carlo
implementation of (
71
) as

\displaystyle c(\mathbf{x}^{[i]})=\mathop{E}\{\sum_{t=0}^{N_{RL}}\alpha^{t}s(\mathbf{x}_{t},\beta_{t},\mathbf{w}_{t})\}

with

\displaystyle\mathbf{x}_{0}=\mathbf{x}^{[i]}

and
N_{RL}
denoting the reinforcement learning
Monte Carlo
simulation length.

Then we can establish a linear equation group in terms of
\mathbf{M}_{c}
elements according to

\displaystyle\mbox{vec}(\mathbf{x}^{\mathrm{T}}\mathbf{M}_{c}\mathbf{x})=(\mathbf{x}^{\mathrm{T}}\otimes\mathbf{x}^{\mathrm{T}})\mbox{vec}(\mathbf{M}_{c})=\begin{bmatrix}y^{2}&2y\phi&\phi^{2}\end{bmatrix}\begin{bmatrix}m_{1}\\
m_{2}\\
m_{3}\end{bmatrix}

as

\begin{bmatrix}y_{1}^{2}&2y_{1}\phi_{1}&\phi_{1}^{2}\\
y_{2}^{2}&2y_{2}\phi_{2}&\phi_{2}^{2}\\
\vdots&\vdots&\vdots\\
y_{N_{sim}}^{2}&2y_{N_{sim}}\phi_{N_{sim}}&\phi_{N_{sim}}^{2}\end{bmatrix}\begin{bmatrix}m_{1}\\
m_{2}\\
m_{3}\end{bmatrix}=\begin{bmatrix}c(\mathbf{x}^{[1]})\\
c(\mathbf{x}^{[2]})\\
\vdots\\
c(\mathbf{x}^{[N_{sim}]})\end{bmatrix}.

(125)

The state cost matrix
\mathbf{M}_{c}
can be obtained by solving (
125
).

Once the quadratic state cost model described by (
124
) is learned, obtain the optimal policy
\mu
according to (
94

\displaystyle c

\displaystyle=T_{\mu}c=Tc\iff

\displaystyle\mu(\mathbf{x}_{t})

\displaystyle=\arg\min_{\beta_{t}}[s(\mathbf{x}_{t},\beta_{t})+\alpha c(\mathbf{x}_{t+1})]

\displaystyle=\arg\min_{\beta_{t}}[\mathbf{x}_{t}^{\mathrm{T}}\mathbf{Q}\mathbf{x}_{t}+\beta_{t}^{\mathrm{T}}\mathbf{R}\beta_{t}+\alpha(\mathbf{A}^{*}\mathbf{x}_{t}+\mathbf{B}^{*}\beta_{t})^{\mathrm{T}}\mathbf{M}_{c}(\mathbf{A}^{*}\mathbf{x}_{t}+\mathbf{B}^{*}\beta_{t})]

\displaystyle=\arg\min_{\beta_{t}}[\beta_{t}^{\mathrm{T}}(\mathbf{R}+\alpha\mathbf{B}^{*\mathrm{T}}\mathbf{M}_{c}\mathbf{B}^{*})\beta_{t}+2\alpha\mathbf{x}_{t}^{\mathrm{T}}\mathbf{A}^{*\mathrm{T}}\mathbf{M}_{c}\mathbf{B}^{*}\beta_{t}],

which gives

(126)

where

\displaystyle\mathbf{K}_{opt}=\alpha\mathbf{A}^{*\mathrm{T}}\mathbf{M}_{c}\mathbf{B}^{*}(\mathbf{R}+\alpha\mathbf{B}^{*\mathrm{T}}\mathbf{M}_{c}\mathbf{B}^{*})^{-1}.

A.1
Vector norms

A.1.1
Vector norm conditions

Given a generic vector space
\mathbf{V}
, a
norm

\|\cdot\|
defined on it is a scalar function that satisfies the following three conditions.

•

Positive definiteness
: Given a generic vector
\mathbf{v}\in\mathbf{V}
, we have

\displaystyle\|\mathbf{v}\|>0,

\displaystyle\qquad\forall\mathbf{v}\not=\mathbf{0},

(129a)

\displaystyle\|\mathbf{v}\|=0,

\displaystyle\qquad\mathbf{v}=\mathbf{0}.

(129b)

•

Homogeneity
or
linear scalability
: Given a generic vector
\mathbf{v}\in\mathbf{V}
and a generic scalar value
a
, we have

\|a\mathbf{v}\|=|a|\cdot\|\mathbf{v}\|.

(130)

•

Triangular inequality
: Given two generic vectors
\mathbf{v}_{1},\mathbf{v}_{2}\in\mathbf{V}
, we have

\|\mathbf{v}_{1}+\mathbf{v}_{2}\|\leq\|\mathbf{v}_{1}\|+\|\mathbf{v}_{2}\|.

(131)

In fact, the second equation of (
129
) can be saved because it can be derived from (
130
) as

\displaystyle\|\mathbf{0}\|=\|0\cdot\mathbf{v}\|=0\cdot\|\mathbf{v}\|=0.

Thanks to the
positive definiteness
condition and the
triangular inequality
condition, a norm
\|\cdot\|
defined on the vector space
\mathbf{V}
gives directly a
distance
defined on
\mathbf{V}
as well. Such distance is called the
norm distance
. Given two generic vectors
\mathbf{v}_{1},\mathbf{v}_{2}\in\mathbf{V}
, the norm distance between them is right the norm of their vector difference, namely

\mbox{dist}(\mathbf{v}_{1},\mathbf{v}_{2})\equiv\|\mathbf{v}_{1}-\mathbf{v}_{2}\|.

(132)

A
pre-norm
defined on the generic vector space
\mathbf{V}
is a
continuous
scalar function that satisfies the
positive definiteness
condition and the
homogeneity
condition only. A pre-norm that satisfies the
triangular inequality
condition is a norm. Let
\|\cdot\|^{P}
be a pre-norm defined on
\mathbf{V}
, then its
dual norm
is the scalar function

\|\mathbf{v}\|^{D}\equiv\max_{\|\mathbf{x}\|^{P}=1}\mbox{Re}(\mathbf{v}^{*}\mathbf{x})=\max_{\|\mathbf{x}\|^{P}=1}|\mathbf{v}^{*}\mathbf{x}|=\max_{\mathbf{x}\not=\mathbf{0}}\frac{|\mathbf{v}^{*}\mathbf{x}|}{\|\mathbf{x}\|^{P}}

(133)

defined on
\mathbf{V}
as well.

Given two generic vectors

\displaystyle\mathbf{v}_{1}\equiv\begin{bmatrix}v_{11}\\
v_{12}\\
\vdots\\
v_{1n}\end{bmatrix}\in\mathbf{V},\qquad\mathbf{v}_{2}\equiv\begin{bmatrix}v_{21}\\
v_{22}\\
\vdots\\
v_{2n}\end{bmatrix}\in\mathbf{V},

denote their element-wise absolute value vectors respectively as

\displaystyle|\mathbf{v}_{1}|\equiv\begin{bmatrix}|v_{11}|\\
|v_{12}|\\
\vdots\\
|v_{1n}|\end{bmatrix},\qquad|\mathbf{v}_{2}|\equiv\begin{bmatrix}|v_{21}|\\
|v_{22}|\\
\vdots\\
|v_{2n}|\end{bmatrix}.

we say that

|\mathbf{v}_{1}|\leq|\mathbf{v}_{2}|

(134)

if

\displaystyle|v_{11}|\leq|v_{21}|,\quad|v_{12}|\leq|v_{22}|,\quad\cdots\quad,\quad|v_{1n}|\leq|v_{2n}|.

A norm
\|\cdot\|
defined on the vector space
\mathbf{V}
is
monotone
if

\forall\mathbf{v}_{1},\mathbf{v}_{2}\in\mathbf{V},\quad|\mathbf{v}_{1}|\leq|\mathbf{v}_{2}|\implies\|\mathbf{v}_{1}\|\leq\|\mathbf{v}_{2}\|

(135)

and is
absolute
if

\forall\mathbf{v}\in\mathbf{V},\quad\|\mathbf{v}\|=\|\mbox{ }|\mathbf{v}|\mbox{ }\|.

(136)

It is worth noting that in (
136
), empty space is intentionally added between the double vertical lines
\|
and the single vertical line
|
to highlight the consecutive procedures of first computing the element-wise absolute value vector of
\mathbf{v}

\displaystyle\sum_{i=1}^{n}|v_{1i}+v_{2i}|^{p}\leq[(\sum_{i=1}^{n}|v_{1i}|^{p})^{\frac{1}{p}}+(\sum_{i=1}^{n}|v_{2i}|^{p})^{\frac{1}{p}}](\sum_{i=1}^{n}|v_{1i}+v_{2i}|^{p})^{1-\frac{1}{p}}\quad(\frac{1}{q}\equiv 1-\frac{1}{p})

\displaystyle\sum_{i=1}^{n}|v_{i}||v_{1i}+v_{2i}|^{p-1}\leq(\sum_{i=1}^{n}|v_{i}|^{p})^{\frac{1}{p}}(\sum_{i=1}^{n}(|v_{1i}+v_{2i}|^{p-1})^{q})^{\frac{1}{q}}

where (

A.2.3
Induced matrix norms

Matrix norms can be induced by vector norms. Given a vector norm
\|\cdot\|
, the matrix norm
\||\cdot\||

\||\mathbf{A}\||\equiv\max_{\|\mathbf{v}\|=1}\|\mathbf{A}\mathbf{v}\|=\max_{\|\mathbf{v}\|\not=0}\frac{\|\mathbf{A}\mathbf{v}\|}{\|\mathbf{v}\|}.

(153)

The induced matrix norm
\||\cdot\||
defined in (

\displaystyle\||\cdot\||\mbox{ is a matrix norm},

(154a)

\displaystyle\|\mathbf{A}\mathbf{v}\|\leq\||\mathbf{A}\||\cdot\|\mathbf{v}\|,

(154b)

\displaystyle\||\mathbf{I}\||=1,

(154c)

\displaystyle\||\mathbf{A}\||=\max_{\|\mathbf{v}\|=\|\mathbf{x}\|^{D}=1}|\mathbf{x}^{*}\mathbf{A}\mathbf{v}|.

(154d)

The first property of (

\mathbf{v}

\displaystyle\mathbf{A}\mathbf{v}\not=\mathbf{0}\implies\|\mathbf{A}\mathbf{v}\|>0\implies\||\mathbf{A}\||>0.

Besides, we have

\displaystyle\mathbf{A}=0\implies\forall\mathbf{v},\mbox{ }\|\mathbf{A}\mathbf{v}\|=\|\mathbf{0}\|=0\implies\||\mathbf{A}\||=0.

So the

\displaystyle\forall\mathbf{v},\mbox{ }\|(a\mathbf{A})\mathbf{v}\|=\|a(\mathbf{A}\mathbf{v})\|=|a|\cdot\|\mathbf{A}\mathbf{v}\|\implies\||a\mathbf{A}\||=|a|\cdot\||\mathbf{A}\||.

For any
\mathbf{v}\in\{\mathbf{v}\mbox{ }|\mbox{ }\|\mathbf{v}\|=1\}
, we have

\displaystyle\|(\mathbf{A}_{1}+\mathbf{A}_{2})\mathbf{v}\|

\displaystyle=\|\mathbf{A}_{1}\mathbf{v}+\mathbf{A}_{2}\mathbf{v}\|\leq\|\mathbf{A}_{1}\mathbf{v}\|+\|\mathbf{A}_{2}\mathbf{v}\|

\displaystyle\leq\max_{\|\mathbf{v}\|=1}\|\mathbf{A}_{1}\mathbf{v}\|+\max_{\|\mathbf{v}\|=1}\|\mathbf{A}_{2}\mathbf{v}\|=\||\mathbf{A}_{1}\||+\||\mathbf{A}_{2}\||.

\displaystyle\||\mathbf{A}_{1}+\mathbf{A}_{2}\||=\max_{\|\mathbf{v}\|=1}\|(\mathbf{A}_{1}+\mathbf{A}_{2})\mathbf{v}\|\leq\||\mathbf{A}_{1}\||+\||\mathbf{A}_{2}\||

\displaystyle\||\mathbf{A}_{1}\mathbf{A}_{2}\||

\displaystyle=\max_{\|\mathbf{v}\|=1}\|\mathbf{A}_{1}\mathbf{A}_{2}\mathbf{v}\|=\max_{\|\mathbf{v}\|=1}[\frac{\|\mathbf{A}_{1}(\mathbf{A}_{2}\mathbf{v})\|}{\|\mathbf{A}_{2}\mathbf{v}\|}\|\mathbf{A}_{2}\mathbf{v}\|]

\displaystyle\leq\max_{\|\mathbf{v}\|=1}[(\max_{\|\mathbf{x}\|\not=0}\frac{\|\mathbf{A}_{1}\mathbf{x}\|}{\|\mathbf{x}\|})\|\mathbf{A}_{2}\mathbf{v}\|]=\max_{\|\mathbf{v}\|=1}\||\mathbf{A}_{1}\||\cdot\|\mathbf{A}_{2}\mathbf{v}\|

\displaystyle=\||\mathbf{A}_{1}\||\cdot\max_{\|\mathbf{v}\|=1}\|\mathbf{A}_{2}\mathbf{v}\|=\||\mathbf{A}_{1}\||\cdot\||\mathbf{A}_{2}\||

B.1.2
Problem statement with constraint

A typical problem statement with constraint for calculus of variations is as follows: Given a pair of functions

\displaystyle y\equiv y(x),\quad z\equiv z(x)

in terms of
x
, which are subject to the constraint

g(x,y,z)=0,

(166)

and an objective functional

c(y,z)=\int_{x_{1}}^{x_{2}}f(x,y,z,\dot{y},\dot{z})\mathrm{d}x

(167)

in terms of the pair of functions
y(x)
and
z(x)
, then find the solution of the functions
y(x)
and
z(x)
that optimize the objective functional

\{y(x),z(x)\}=\arg\min_{\{y(x),z(x)\}}c(y,z).

(168)

By default,
y
,
\dot{y}
,
z
,
\dot{z}
,
f
in (
167
) and
g
in (
166
) are assumed any-order continuous. It is worth noting that the constraint (
166
) implies the mutually-deterministic relationship between
y(x)
and
z(x)
, namely when one of them is given, then the other can be implicitly determined. Denote

\displaystyle f_{y}\equiv\frac{\partial}{\partial y}f(x,y,z,\dot{y},\dot{z}),\quad f_{\dot{y}}\equiv\frac{\partial}{\partial\dot{y}}f(x,y,z,\dot{y},\dot{z}),

\displaystyle f_{z}\equiv\frac{\partial}{\partial z}f(x,y,z,\dot{y},\dot{z}),\quad f_{\dot{z}}\equiv\frac{\partial}{\partial\dot{z}}f(x,y,z,\dot{y},\dot{z}),

\displaystyle g_{x}\equiv\frac{\partial}{\partial x}g(x,y,z),\quad g_{y}\equiv\frac{\partial}{\partial y}g(x,y,z),\quad g_{z}\equiv\frac{\partial}{\partial z}g(x,y,z).

The constraint (
166
) implies the following constraint among differentials

g_{x}\mathrm{d}x+g_{y}\mathrm{d}y+g_{z}\mathrm{d}z=0\iff g_{x}+g_{y}\dot{y}+g_{z}\dot{z}=0.

(169)

Consider an infinitesimal variation
\Delta y(x)
and an infinitesimal variation
\Delta z(x)
on the optimal pair of functions
y(x)
and
z(x)
. The infinitesimal variations
\Delta y(x)
and
\Delta z(x)
satisfy the boundary conditions

\Delta y(x_{1})=0,\quad\Delta y(x_{2})=0,\quad\Delta z(x_{1})=0,\quad\Delta z(x_{2})=0.

(170)

Besides, the constraint (
166
) implies that
\Delta y(x)
and
\Delta z(x)
also satisfy the variation constraint

g_{y}\Delta y+g_{z}\Delta z=0.

(171)

We have

\displaystyle c(y+\Delta y,z+\Delta z)-c(y,z)

\displaystyle=

\displaystyle\int_{x_{1}}^{x_{2}}[f(x,y+\Delta y,z+\Delta z,\dot{y}+\Delta\dot{y},\dot{z}+\Delta\dot{z})-f(x,y,z,\dot{y},\dot{z})]\mathrm{d}x

\displaystyle=

\displaystyle\int_{x_{1}}^{x_{2}}(f_{y}\Delta y+f_{\dot{y}}\Delta\dot{y}+f_{z}\Delta z+f_{\dot{z}}\Delta\dot{z})\mathrm{d}x.

Recall how (
164
) is derived and further obtain

\displaystyle c(y+\Delta y,z+\Delta z)-c(y,z)=\int_{x_{1}}^{x_{2}}[\Delta y(f_{y}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{y}})+\Delta z(f_{z}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{z}})]\mathrm{d}x

namely

c(y+\Delta y,z+\Delta z)=c(y,z)+\int_{x_{1}}^{x_{2}}[\Delta y(f_{y}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{y}})+\Delta z(f_{z}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{z}})]\mathrm{d}x.

(172)

Substitute (
171
) into (
172
) and obtain

c(y+\Delta y,z+\Delta z)=c(y,z)+\int_{x_{1}}^{x_{2}}\frac{\Delta y}{g_{z}}[g_{z}(f_{y}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{y}})-g_{y}(f_{z}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{z}})]\mathrm{d}x.

(173)

Since the infinitesimal variation
\Delta y(x)
can be arbitrary and is independent of

\displaystyle g_{z}(f_{y}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{y}})-g_{y}(f_{z}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{z}})

in (
173
), according to which the optimal pair of functions
y(x)
and
z(x)
necessitate the following condition

g_{z}(f_{y}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{y}})-g_{y}(f_{z}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{z}})=0.

(174)

The differential constraint (
169
) and the Euler-Lagrange equation variant (
174
) are used together to solve the optimal pair of functions
y(x)
and
z(x)
.

23

\displaystyle(x_{1},y_{1}),\quad(x_{2},y_{2})

\displaystyle y(x_{1})=y_{1},\quad y(x_{2})=y_{2}

with

\displaystyle x_{1}<x_{2},

y(x)=\arg\min_{y(x)}\int_{x_{1}}^{x_{2}}\sqrt{1+\dot{y}^{2}}\mathrm{d}x.

(175)

For (
175

f
is

\displaystyle f(x,y,\dot{y})=\sqrt{1+\dot{y}^{2}},

the objective functional
c(y)
is

\displaystyle c(y)=\int_{x_{1}}^{x_{2}}\sqrt{1+\dot{y}^{2}}\mathrm{d}x,

\min c(y)

(176)

which tells that the optimal function

B.2.2
Brachistochrone problem

The brachistochrone problem is to determine the fastest descending curve. More specifically, given two points

\displaystyle(0,0),\quad(x_{2},y_{2})

or equivalently

\displaystyle y(0)=0,\quad y(x_{2})=y_{2}

with

\displaystyle x_{2}>0,\quad y_{2}\leq 0,

solve the following functional optimization problem

y(x)=\arg\min_{y(x)}\int_{0}^{x_{2}}\sqrt{\frac{1+\dot{y}^{2}}{2g(-y)}}\mathrm{d}x\iff y(x)=\arg\min_{y(x)}\int_{0}^{x_{2}}\sqrt{\frac{1+\dot{y}^{2}}{-y}}\mathrm{d}x.

(177)

For (
177
), the functional
f
is

\displaystyle f(x,y,\dot{y})=\sqrt{\frac{1+\dot{y}^{2}}{-y}}

and the objective functional
c(y)
is

\displaystyle c(y)=\int_{0}^{x_{2}}\sqrt{\frac{1+\dot{y}^{2}}{-y}}\mathrm{d}x.

To apply the
Euler-Lagrange equation
, compute

\displaystyle f_{y}

\displaystyle=\frac{\partial}{\partial y}\sqrt{\frac{1+\dot{y}^{2}}{-y}}=-\frac{1}{2y}\sqrt{\frac{1+\dot{y}^{2}}{-y}},

\displaystyle f_{\dot{y}}

\displaystyle=\frac{\partial}{\partial\dot{y}}\sqrt{\frac{1+\dot{y}^{2}}{-y}}=\frac{\dot{y}}{\sqrt{-(1+\dot{y}^{2})y}},

and

\displaystyle\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{y}}=\frac{1}{\sqrt{-(1+\dot{y}^{2})y}}(\frac{\ddot{y}}{1+\dot{y}^{2}}-\frac{\dot{y}^{2}}{2y}).

Then we have

\displaystyle f_{y}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{y}}=0

\displaystyle\iff-\frac{1}{2y}\sqrt{\frac{1+\dot{y}^{2}}{-y}}=\frac{1}{\sqrt{-(1+\dot{y}^{2})y}}(\frac{\ddot{y}}{1+\dot{y}^{2}}-\frac{\dot{y}^{2}}{2y})

\displaystyle\iff 1+\dot{y}^{2}+2\ddot{y}y=0.

Perform the differential transform

\displaystyle\ddot{y}=\frac{\mathrm{d}\dot{y}}{\mathrm{d}x}=\frac{\mathrm{d}y}{\mathrm{d}x}\frac{\mathrm{d}\dot{y}}{\mathrm{d}y}=\dot{y}\frac{\mathrm{d}\dot{y}}{\mathrm{d}y}

and obtain

\displaystyle f_{y}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{y}}=0

\displaystyle\iff 1+\dot{y}^{2}+2(\dot{y}\frac{\mathrm{d}\dot{y}}{\mathrm{d}y})y=0\iff\frac{\mathrm{d}(-y)}{(-y)}+\frac{2\dot{y}\mathrm{d}\dot{y}}{1+\dot{y}^{2}}=0

\displaystyle\iff\mathrm{d}[\ln(-y)+\ln(1+\dot{y}^{2})]=0

\displaystyle\iff-y(1+\dot{y}^{2})=a>0\quad(\mbox{a positive constant})

which further implies that

\displaystyle\dot{y}

\displaystyle=-\sqrt{\frac{a+y}{-y}}\quad\mbox{ or }

(178a)

\displaystyle\dot{y}

\displaystyle=+\sqrt{\frac{a+y}{-y}}.

(178b)

The first and second equations of (
178
) correspond to the descending part and the ascending part of the fastest descending curve respectively, as illustrated in Figure
4
. It is worth noting that the ascending part does not necessarily exist, whereas the descending part always exists.

Figure 4:
Brachistochrone curve

For the descending part which is associated with the first equation of (
178
), perform the variable transform

\displaystyle-y=a\sin u^{2}\quad(0\leq u\leq\pi/2)

or equivalently

\displaystyle u=\arcsin\sqrt{\frac{-y}{a}}

and obtain

\displaystyle\frac{\mathrm{d}}{\mathrm{d}x}(-y)=\sqrt{\frac{a-(-y)}{(-y)}}

\displaystyle\iff 2a\sin u\cos u\frac{\mathrm{d}u}{\mathrm{d}x}=\frac{\cos u}{\sin u}\iff 2a(\sin u)^{2}\mathrm{d}u=\mathrm{d}x

\displaystyle\iff a(1-\cos 2u)\mathrm{d}u=\mathrm{d}x,

integration of which under the boundary condition

\displaystyle x(0)=u(0)=0

gives

x=au-a\sin u\cos u=a\arcsin\sqrt{\frac{-y}{a}}-\sqrt{-y(a+y)}.

(179)

Similar, for the ascending part which is associated with the second equation of (
178
), we have

x=a\pi-a\arcsin\sqrt{\frac{-y}{a}}+\sqrt{-y(a+y)}.

(180)

When the descended height
-y
achieves its summit

\displaystyle(-y)_{\max}=a,

the horizontally moved distance is

\displaystyle x_{m}=\frac{1}{2}a\pi.

The vertical line

\displaystyle x=x_{m}

is right the line that separates the descending part and the ascending part (if existing) of the fastest descending curve on the left and right sides respectively.

On one hand, if

\displaystyle\frac{x_{2}}{(-y_{2})}\leq\frac{x_{m}}{(-y)_{\max}}=\frac{\pi}{2},

then the fastest descending curve has no ascending part and the parameter
a
is determined according to (
179
) with the boundary condition

\displaystyle y(x_{2})=y_{2},

i.e.

x_{2}=a\arcsin\sqrt{\frac{-y_{2}}{a}}-\sqrt{-y_{2}(a+y_{2})}.

(181)

On the other hand, if

\displaystyle\frac{x_{2}}{(-y_{2})}>\frac{x_{m}}{(-y)_{\max}}=\frac{\pi}{2},

then the fastest descending curve has the ascending part and the parameter
a
is determined according to (
180
) with the boundary condition

\displaystyle y(x_{2})=y_{2},

i.e.

x_{2}=a\pi-a\arcsin\sqrt{\frac{-y_{2}}{a}}+\sqrt{-y_{2}(a+y_{2})}.

(182)

B.2.3
Largest enclosed area problem

The largest enclosed area problem is to determine the largest area enclosed by a curve with fixed circumference. To handle the problem, it is unnecessary to consider the entire curve. A more convenient way is to consider a generic line segment that intersects the curve and analyse the largest area that can be enclosed by the curve segment and the line segment, as illustrated in Figure
5
.

Figure 5:
Largest enclosed area given a fixed circumference

Following above way of handling the largest enclosed area problem, suppose the line segment that intersects the curve is the line segment between two points

\displaystyle(0,0),\quad(x_{2},0)

and the fixed length of the curve segment is
L
. Then the largest enclosed area problem can be formalized as the following functional optimization problem

y(x)=\arg\max_{y(x)}\int_{0}^{x_{2}}y\mathrm{d}x

(183)

subject to the constraint

\int_{0}^{x_{2}}\sqrt{1+\dot{y}^{2}}\mathrm{d}x=L.

(184)

Consider an infinitesimal variation
\Delta y(x)
on the optimal function
y(x)
. The infinitesimal variation
\Delta y(x)
satisfies the boundary conditions (
163
)

\displaystyle\Delta y(x_{1})=0,\quad\Delta y(x_{2})=0.

Substitute the infinitesimal variation
\Delta y(x)
into the constraint (
184
) and obtain

\displaystyle\int_{0}^{x_{2}}\sqrt{1+(\dot{y}+\Delta\dot{y})^{2}}\mathrm{d}x=L\iff\int_{0}^{x_{2}}(\sqrt{1+\dot{y}^{2}}+\frac{\dot{y}}{\sqrt{1+\dot{y}^{2}}}\Delta\dot{y})\mathrm{d}x=L

\displaystyle\iff L+\int_{0}^{x_{2}}\frac{\dot{y}}{\sqrt{1+\dot{y}^{2}}}\Delta\dot{y}\mathrm{d}x=L\iff\int_{0}^{x_{2}}\frac{\dot{y}}{\sqrt{1+\dot{y}^{2}}}\mathrm{d}\Delta y=0

\displaystyle\iff\frac{\dot{y}}{\sqrt{1+\dot{y}^{2}}}\Delta y|_{0}^{x_{2}}-\int_{0}^{x_{2}}\Delta y\mathrm{d}\frac{\dot{y}}{\sqrt{1+\dot{y}^{2}}}=0\iff 0-\int_{0}^{x_{2}}\frac{\Delta y\ddot{y}}{(1+\dot{y}^{2})^{\frac{3}{2}}}\mathrm{d}x=0

which gives

\int_{0}^{x_{2}}\Delta y\frac{\ddot{y}}{(1+\dot{y}^{2})^{\frac{3}{2}}}\mathrm{d}x=0.

(185)

The integrand part

\rho(x)\equiv\frac{\ddot{y}}{(1+\dot{y}^{2})^{\frac{3}{2}}}

(186)

in (
185
) is right the curvature function of the curve segment. Note that
\Delta y(x)
is independent of the curvature function
\rho(x)
, so if the curvature function
\rho(x)
is not constant, there must exist
\Delta y
such that

\displaystyle\int_{0}^{x_{2}}\Delta y\mathrm{d}x\not=0

and hence either

\displaystyle\int_{0}^{x_{2}}\Delta y\mathrm{d}x>0

or

\displaystyle\int_{0}^{x_{2}}(-\Delta y)\mathrm{d}x>0.

Consequently, either

\displaystyle\int_{0}^{x_{2}}(y+\Delta y)\mathrm{d}x>\int_{0}^{x_{2}}y\mathrm{d}x

or

\displaystyle\int_{0}^{x_{2}}(y-\Delta y)\mathrm{d}x>\int_{0}^{x_{2}}y\mathrm{d}x,

which violates optimality of the optimal function
y(x)
. So by proof of contradiction, the curvature function
\rho(x)
specified in (
186
) must be constant for the optimal function
y(x)
.

Since choice of the intersection line segment is arbitrary, above conclusion tells that the optimal curve associated with the largest enclosed area must have a constant curvature everywhere. In other words, the optimal curve must be a circle.

B.2.4
Geodesic problem

The geodesic problem is to determine the shortest path between two points on a sphere. For analysis by calculus of variations, the geodesic problem can be formalized as a problem without constraint

25
25

25

For the purpose, the spherical (polar) coordinates system can be adopted.

as presented in Section
B.1.1
, and can also be formalized as a problem with constraint as presented in Section
B.1.2
. Although the former is easier to handle than the latter, the author intentionally chooses the latter to demonstrate how to solve a problem with constraint.

The geodesic problem is formalized as a problem with constraint as follows: Given a sphere with radius
r
, i.e.

g(x,y,z)\equiv x^{2}+y^{2}+z^{2}-r^{2}=0,

(187)

a fixed starting point
(x_{1},y_{1},z_{1})
with

x_{1}=0,\quad y(x_{1})=y_{1}=0,\quad z(x_{1})=z_{1}=r,

(188)

and a generic destination point
(x_{2},y_{2},z_{2})
with

x_{2}=a\in(0,r],\quad y(x_{2})=y_{2}=0,\quad z(x_{2})=z_{2}=\sqrt{r^{2}-a^{2}}.

(189)

Some explanations hover over the starting and destination points specified in (
188
) and (
189
). Given a generic starting point and a generic destination point on the sphere, we can always rotate the sphere such that the starting point is located at the “north pole” namely as specified in (
188
). Once the starting point is fixed at the “north pole”, we can further rotate the sphere such that the destination point has “zero longitude” namely as specified in (
189
). Setting the destination point on the “northern hemisphere” namely setting

\displaystyle z_{2}\geq 0

has no influence on demonstrating how to solve the geodesic problem via calculus of variations. After such demonstration, similar analysis can be naturally applied when the destination point is on the “southern hemisphere”.

The geodesic problem is to solve the following functional optimization problem

\{y(x),z(x)\}=\arg\min_{\{y(x),z(x)\}}\int_{0}^{a}\sqrt{1+\dot{y}^{2}+\dot{z}^{2}}\mathrm{d}x.

(190)

subject to the constraint (
187
). For (
190
), the functional
f
is

\displaystyle f(x,y,z,\dot{y},\dot{z})=\sqrt{1+\dot{y}^{2}+\dot{z}^{2}}

and the objective functional
c(y,z)
is

\displaystyle c(y,z)=\int_{0}^{a}\sqrt{1+\dot{y}^{2}+\dot{z}^{2}}\mathrm{d}x.

Compute

\displaystyle g_{x}=2x,\quad g_{y}=2y,\quad g_{z}=2z

and apply the differential constraint (
169
) as

g_{x}+g_{y}\dot{y}+g_{z}\dot{z}=0\implies x+y\dot{y}+z\dot{z}=0.

(191)

Compute

\displaystyle\frac{\mathrm{d}}{\mathrm{d}x}f=\frac{\dot{y}\ddot{y}+\dot{z}\ddot{z}}{\sqrt{1+\dot{y}^{2}+\dot{z}^{2}}}=\frac{\dot{y}\ddot{y}+\dot{z}\ddot{z}}{f},

\displaystyle f_{y}=0,\quad f_{\dot{y}}=\frac{\dot{y}}{\sqrt{1+\dot{y}^{2}+\dot{z}^{2}}}=\frac{\dot{y}}{f},\quad\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{y}}=\frac{\ddot{y}f-\dot{y}\frac{\mathrm{d}}{\mathrm{d}x}f}{f^{2}}=\frac{(1+\dot{z}^{2})\ddot{y}-\dot{y}\dot{z}\ddot{z}}{f^{3}},

\displaystyle f_{z}=0,\quad f_{\dot{z}}=\frac{\dot{z}}{\sqrt{1+\dot{y}^{2}+\dot{z}^{2}}}=\frac{\dot{z}}{f},\quad\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{z}}=\frac{\ddot{z}f-\dot{z}\frac{\mathrm{d}}{\mathrm{d}x}f}{f^{2}}=\frac{(1+\dot{y}^{2})\ddot{z}-\dot{y}\dot{z}\ddot{y}}{f^{3}}

and apply the Euler-Lagrange equation variant (
174
) as

\displaystyle g_{z}(f_{y}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{y}})-g_{y}(f_{z}-\frac{\mathrm{d}}{\mathrm{d}x}f_{\dot{z}})=0

\displaystyle\implies

\displaystyle z(0-\frac{(1+\dot{z}^{2})\ddot{y}-\dot{y}\dot{z}\ddot{z}}{f^{3}})-y(0-\frac{(1+\dot{y}^{2})\ddot{z}-\dot{y}\dot{z}\ddot{y}}{f^{3}})=0

\displaystyle\iff

\displaystyle(z+z\dot{z}^{2}+y\dot{y}\dot{z})\ddot{y}=(y+y\dot{y}^{2}+z\dot{z}\dot{y})\ddot{z}.

Substitute (
191
) into above equation, perform the variable transforms

\displaystyle y\equiv x\bar{y},\quad z\equiv x\bar{z},

and obtain

\displaystyle[z+z\dot{z}^{2}+(-x-z\dot{z})\dot{z}]\ddot{y}=[y+y\dot{y}^{2}+(-x-y\dot{y})\dot{y}]\ddot{z}\iff(z-x\dot{z})\ddot{y}=(y-x\dot{y})\ddot{z}

\displaystyle\iff[x\bar{z}-x\frac{\mathrm{d}}{\mathrm{d}x}(x\bar{z})]\frac{\mathrm{d}^{2}}{\mathrm{d}x^{2}}(x\bar{y})=[x\bar{y}-x\frac{\mathrm{d}}{\mathrm{d}x}(x\bar{y})]\frac{\mathrm{d}^{2}}{\mathrm{d}x^{2}}(x\bar{z})\iff\dot{\bar{z}}\ddot{\bar{y}}=\dot{\bar{y}}\ddot{\bar{z}}

\displaystyle\iff\frac{\mathrm{d}}{\mathrm{d}x}(\frac{\dot{\bar{y}}}{\dot{\bar{z}}})=0\quad\mbox{or}\quad\frac{\mathrm{d}}{\mathrm{d}x}(\frac{\dot{\bar{z}}}{\dot{\bar{y}}})=0\iff c_{y}\dot{\bar{y}}+c_{z}\dot{\bar{z}}=0\iff c_{x}+c_{y}\bar{y}+c_{z}\bar{z}=0

namely

c_{x}x+c_{y}y+c_{z}z=0,

(192)

where

\displaystyle c_{x},\quad c_{y},\quad c_{z}

are certain constant coefficients. By associating (
192
) with (
188
) and (
189
), we have

c_{x}=c_{z}=0,\quad y=0.

(193)

Geometric interpretation of the solution (
193
) is that the shortest spherical path between the starting point and the destination point is the great circle arc connecting the two points.
