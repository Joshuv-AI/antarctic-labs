 ABSTRACT
Nuclear data covariance libraries have been created for use with the sensitivity and uncertainty modules in
SCALE 7.0. The data have been assembled from a variety of sources, including high-fidelity covariance
evaluations from ENDF/B-VIII.1 as well as approximate uncertainties obtained from a collaborative
project performed by Brookhaven National Laboratory, Los Alamos National Laboratory, and Oak
Ridge National Laboratory. This document describes the assumptions in generating the data, the library
contents, and the processing procedure for the SCALE 56-group and 252-group covariance libraries. The
ENDF/B-VIII.1 covariance library is the default library provided with SCALE 7.0. The SCALE 44-group
covariance library distributed with the SCALE 6.x series has been deprecated.
 1. INTRODUCTION
During almost all modern evaluations, some sort of minimization or regression algorithm is used to
determine the best fit of theoretical nuclear data (ND) to observed ND. In the resolved resonance region,
this typically means performing a Bayesian or frequentist generalized least squares (GLS) fit of resonance
parameters which are used to compare theoretical to experimental observations of neutron reactions (or
lack thereof). For evaluations of higher energy regions, for example fast region cross sections or average
number of neutrons per fission, 𝜈, several methods including Total Monte Carlo (TMC), Kalman filter
technique, or GLS can be used. In almost every case, nuclear reaction theory is compared to observed
data which are uncertain. Even though every experimental dataset does not have reported data uncertainty,
every measurement has uncertainty. Since all ND in the ENDF/B evaluated ND libraries are adjusted
to fit experimental data (or are dependent on uncertain models), all ND in ENDF/B inherently contain
uncertainty as well. In our effort to compile the most comprehensive and complete ND covariance datasets
available, we supplement ENDF/B evaluated covariance data with “low-fidelity” or “LoFi” covariances
(Little et al. 2008) and JENDL covariances (Shibata et al. 2011).
The covariance libraries generated here provide covariance data for SCALE sensitivity and uncertainty
sequences. The general principles for covariance library construction are as follows: Evaluated covariance
information is preferred when it is present, approximate low-fidelity covariance data are used to provide
uncertainty estimates for materials whose evaluated covariance coverage is missing or incomplete, and
nonphysical covariances are corrected. All the recipes, source data, and covariance libraries are planned
to be released publicly on the SCALE data GitLab hosted on Oak Ridge National Laboratory (ORNL)
servers.
While covariance libraries can be grouped into any arbitrary group structure, the default distribution with
SCALE 7.0 is planned to have ENDF/B-VIII.1 covariance libraries in the 56- and 252-group structures.
The ENDF/B-VII.1 covariance libraries will be available to SCALE users as well (on request), just not part
of the default distribution. As we are maintaining only the latest revisions of the major library versions
(VII.1, VIII.1), ENDF/B-VIII.0 has been deprecated and removed from SCALE data and will not be
maintained or distributed.1 For both ENDF/B-VIII.1 and ENDF/B-VII.1 covariance libraries, we fill many
of the gaps in the evaluated covariance where the ENDF/B evaluations failed to report any. These gaps will
be filled with data from the LoFi covariances (Little et al. 2008) and covariances on the fission neutron
spectrum, 𝜒, from JENDL-4.0u2 (Shibata et al. 2011). ORNL modifies the LoFi data. Most of these
modifications are well described in the SCALE 6.3 manual (Lefebvre and Wieselquist 2025) online here;
in this report, we add to that description.
 1. AMPX maintains the capability of processing the ENDF/B-VIII.0 covariance data, but the SCALE team will only be
providing these on a case-by-case basis for isolated projects.
 2. Shortly after the JENDL-4.0 library release evaluators made updates with the name “JENDL-4.0u”. We verified that the
JENDL-4.0u files match our internal SCALE files. Details can be found here.

2.1 EVALUATED COVARIANCE DATA
Evaluated covariance data from the ENDF/B release associated with the library are almost3 always given
priority over other sources of covariance data. In other words, if ENDF/B-VII.1 or ENDF/B-VIII.1 have
covariance data for any ND type, they will be used in the corresponding library. In the ENDF/B-VIII.1
release, 266 neutron evaluations provide covariance data, and for our scale.252groupcov8.1 library,
we add on top of that 202 nuclides with LoFi covariance files. Our scale.252groupcov7.1 covariance
library contains 181 neutron evaluations from ENDF/B-VII.1 and 227 LoFi covariance files. For thermal
scattering law (TSL) data, we repeat the covariance data for the scattering atom (e.g., 1 H in CH2 uses
the 1 H covariance). New ENDF/B-VIII.1 covariance data relative to ENDF/B-VII.1 are listed in Table 1;
ENDF/B-VII.1 covariance evaluations absent from ENDF/B-VIII.1 are listed in Table 2; and an example

2.2 THE SCALE LOFI COVARIANCE DATASET
The SCALE LoFi covariance dataset is almost entirely based on the low-fidelity data reported by Little
et al. (2008), but almost all the files have small changes. Though there was not an official release of
low-fidelity files based on Little et al., here we reference the “official” National Nuclear Data Center
(NNDC) low-fidelity dataset as the set of files found on the NNDC website here. In comparing the NNDC
dataset to the LoFi ENDF-6 format files that ORNL maintains, we found that:
 • The NNDC dataset contains 387 distinct files
 • The ORNL dataset contains 225 files (excluding prelim. VII.2 files)
 3. For ENDF/B-VII.1, we have five nuclides for which the evaluated data were replaced with other datasets: 1 H, 103 Rh, 151 Sm,
235 U, 239 Pu. 103 Rh and 151 Sm contain single-value changes to thermal capture uncertainty, and 1 H, 235 U, 239 Pu use preliminary
ENDF/B-VII.2 data.

2.3 COVARIANCE DATA FOR FISSION SPECTRA
Additional fission spectrum covariance data are supplied from JENDL-4.0u. The JENDL covariance files
are processed separately and then merged only for MT=1018. The ordinary cross section and 𝜈 covariance
reactions remain from the ENDF/B or low-fidelity side of the library. The final retained reaction set is
given with definitions in Table 3.

2.4 MULTIGROUP COVARIANCE PROCESSING
Nuclear data processing “recipes” are planned to be released for all covariance library generation on
the SCALE data GitLab. The goal of the recipes is to simplify library building as much as possible,
so much that from the viewpoint of a user, it is only a simple set of instructions. The recipes use the
AMPX processing code (Lefebvre and Wieselquist 2025) to process the selected covariance evaluations
into multigroup covariance libraries in SCALE’s COVERX binary format. The open-source graphical
user interface (GUI) exsite found here uses static metadata in the recipes to automatically generate
input files for the various modules of AMPX. PUFF-IV (Wiarda and Dunn 2006) performs the bulk of
covariance processing operations for ENDF/B, LoFi, and JENDL files. Custom AMPX input files then
restore selected cross-material correlations, merge the JENDL fission spectrum covariances into the
affected actinides, and combine the individual COVERX files into an all-material covariance library. A
final COGNAC pass keeps only the reaction set listed above, applies covariance corrections (e.g., limits the
relative uncertainty to 100%), removes unneeded data, and writes the delivered SCALE covariance library
