Simulations in slide-away regime filtered from dataset to
improve MSE
 ● Worst MSE cases for ML fits occurs in
 slide-away regime which occurs at low
 density and high DC electric field
 ○ The regime is not of experimental
 interest and is not correctly modeled EDC
 by the codes used
 ● Following Dreicer [1], a critical electric field
 can be found by balancing collisional drag drag
 of LH tail electrons with the DC electric field
                                                                  V~c/n||
 to arrive at a rejection criteria
           ○ Ecrit = 7.9x1024 ne0 Zeff n||2 [V/cm]
 ○ Reject simulations with EDC/Ecrit > 0.9
 which eliminates about 18% of cases.
[1] Dreicer, H. (1959). "Electron and Ion Runaway in a Fully
Ionized Gas. I". Physical Review. 115 (2): 238–249.                         19

Overall Workflow for AI Models
Exploratory data analysis: normalization,
removing bad values (eg, slide-away regime)
Try out a preliminary model implementation
using a subset of data, experiment with different
parameters to find promising values
Optimize the model: k-fold cross validation, grid
search/randomized search
Use best model parameters for doing full model
training
Evaluate performance of model

 Themes
● Stress tests of models: bugs, validity, corner and edge cases, convergence
 ○ LW Fokker-Planck code not designed to handle RF generated
 runaways - these impact surrogate accuracy
 ○ ICRF cases with unphysical behavior - surrogate tends to get these
 correct but points to needed corrections in code
 ○ Convergence - different cases require different resolution. Surrogate
 accuracy affected by poorly converged cases
● Surrogate models can be accurate and very fast
 ○ appropriate for integrated modeling and real time control.
 ○ narrower parameter ranges
 ○ different models for different discrete cases
 ○ Appropriateness limited by underlying model validation
● Generative AI - labor saving tool
  ○ Can preproduce model generation surprisingly fast
  ○ dependent on having curated training already performed
  ○ Even there can assist in generating initial raw data

 Gaussian Process Regression (GPR)
● Nonparametric Bayesian approach
 ○ Prior + calculation of posterior using training data
 ○ Calculates the probability distribution over all admissible functions that fit the data
● Main advantages:
 ○ Flexibility with the amount of data, ability to provide uncertainty measurements on the
 predictions, extendable to arbitrary dimensions
● Confidence intervals at all points in parameter space
 ○ Allows for refinement of model in regions of higher uncertainty
