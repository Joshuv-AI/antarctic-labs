 ABSTRACT
The official ENDF/B nuclear data evaluation releases in the past two decades have incrementally incorporated
more detailed information, new nuclide evaluations, and very often have improved the accuracy of
radiation transport codes when modeling shielding, fission reactors, criticality benchmarks, and fusion
systems. However, like any large collaborative data compilation, these releases have all included small
errors. This report documents the small corrections to ENDF/B releases ENDF/B-VII.1, ENDF/B-VIII.0,
and ENDF/B-VIII.1 that have been applied during nuclear data processing to produce data libraries for the
SCALE code system.

 1. CORRECTIONS APPLIED TO ENDF/B LIBRARIES
The SCALE code system (Wieselquist and Lefebvre 2024) includes several radiation transport sequences
that rely on accurate nuclear data (ND) for accurate modeling of applications. The foundational ND for
SCALE include several evaluated datasets released by the Cross Section Evaluation Working Group
(CSEWG) through the National Nuclear Data Center (NNDC). These include ENDF/B-VII.0 (Chadwick
et al., 2006) (only data specific to use in ORIGEN), ENDF/B-VII.1 (Chadwick et al. 2011), ENDF/B-VIII.0
(Brown et al. 2018), and ENDF/B-VIII.1 (Nobre et al. 2026), which is the latest release. The latest releases
of SCALE will only include processed data from ENDF/B-VII.1 or later. The planned release of SCALE
7.0 is expected to have only ENDF/B-VIII.1 by default and others by request.
Like almost any collaborative compilation of large datasets, each release of the ENDF/B evaluated ND
library has small errors. These errors can be difficult to catch. In fact, many of the errors documented
in this report would not present themselves when a user processed the ENDF files with the processing
code NJOY (Macfarlane et al. 2017; Haeck et al. 2024) because NJOY corrects the problem “under the
hood.” The SCALE ND library, however, uses the AMPX processing code to produce continuous-energy
(CE), multigroup (MG), and covariance libraries. The AMPX code is often more strict than NJOY in its
interpretation of the ENDF-6 format (Members of the CSWEG 2018). This results in better adherence to
evaluator intentions but also can result in errors if an evaluator only checks their file by processing with
NJOY and does not perfectly conform to ENDF-6 formats.
The files that were corrected are listed in Table 1. Many of the corrections required were due to a
misinterpretation of the ENDF-6 format variable SB, which is the characteristic bound cross section, 𝜎𝑏 ,
as used in the calculation of the incoherent inelastic scattering cross section defined in Eq. (1).

                           𝑑2𝜎                       𝜎𝑏 −2𝐸𝑊 ′ (𝑇 ) (1− 𝜇)
                                  (𝐸 → 𝐸 ′ , 𝜇, 𝑇) =    𝑒                  𝛿 (𝐸 − 𝐸 ′ )                     (1)
 𝑑𝐸 ′ 𝑑Ω 4𝜋

Here, 𝜇 is the cosine of the scattering angle, 𝑊 ′ is the Debye–Waller integral divided by the atomic mass
(eV−1 ), 𝑇 is the moderator temperature (K), 𝐸 is the incident neutron energy (eV), and 𝐸 ′ is the secondary
neutron energy (eV). The evaluators seemed to have interpreted SB as the cross section multiplied by the
number of atoms in the molecule (e.g., two hydrogens for H in CH2 ), while the manual defines it as the
bound cross section per atom.

The issues surrounding the two SiO2 files are of a similar nature to those found in the H-CH2 and
H-C5 O2 H8 files. The SiO2 files are mixed-moderator files, meaning they contain information about both Si
and O in them (as opposed to what has become the standard practice within the nuclear data community:
splitting the file into atomistic components). Because of this, the total Bragg data for SiO2 is correct,
but the way it is handled in the ENDF-formatted file again requires accessing information outside of
the MF=7/MT=2 block, so when the file is ‘split’ into their isotopic components of 28,29,30 Si-SiO2 and
16,17,18 O-SiO (as required for use in SCALE), the cross sections are three times larger than they should
 2
be (since there are three atoms in SiO2 ).
Another type of correction necessary was to change the last digit of the moderator temperature given in the
tsl-Be-metal.endf file, which listed a temperature of 800.0001 K instead of 800.0 K. The evaluator’s
reasoning for this very small delta above 800 K is unknown. This is not a problem with the format or
evaluation, but it causes havoc in SCALE libraries because AMPX sometimes rounds this temperature
for users and sometimes lists it precisely in binary representation. To avoid problems, we simply assume
800.0001 ≈ 800.0.
The final corrections necessary were to change MT=107 to MT=105 for cross material covariance data
describing cross correlations between 238 U(𝑛, 𝑓 ) and 6 Li(𝑛, 𝑡) as well as 235 U(𝑛, 𝑓 ) and 6 Li(𝑛, 𝑡) in the
ENDF/B-VIII.0 library. The 6 Li target forms a compound nucleus and decays by emitting a triton and
an alpha particle, i.e. 6 Li(n,t)𝛼. The 235 U and 238 U evaluators incorrectly assumed that the 6 Li evaluator
would assign MT=107 for an exit channel of residual + 𝛼 instead of the correct assignment of MT=105 for
an exit channel of residual + 𝑡.
We plan to make the updated ENDF/B libraries available on the ORNL GitLab server under the SCALE
data group. For now, each version of ENDF/B is maintained in a separate repo and each repo contains
a Git "tag" of ornl and nndc which persistently identifies the Git version that corresponds to ORNL
modified or as-released NNDC versions, respectively.

 2. RESULTS AND IMPACT
To indicate the impact of these changes, we give the example of hydrogen in polyethylene (H in CH2 ).
Polyethylene is commonly used in criticality safety benchmarks to moderate neutrons, and those systems
are very sensitive to the scattering cross section of hydrogen bound in CH2 molecules. The differences in
elastic cross section (ENDF/B reaction number MT=2) between the as-released tsl-HinCH2.endf file
and the corrected file are shown in Figure 1.

 Figure 1. Elastic cross section from AMPX. It is drastically different before and after the bound cross
 section correction.

Although polyethylene appears in several International Criticality Safety Benchmark Evaluation Project
(ICSBEP) benchmarks (OECD Nuclear Energy Agency 2021), we selected PMM-003-005 to illustrate the
potential impact of this issue on criticality calculations. Assuming the authors of the H-in-CH2 evaluation
interpreted the ENDF-6 format correctly, the bound scattering cross section (SB) would be approximately
163 b, yielding a calculated 𝑘 eff = 0.99619 ± 0.00010. Using the corrected SCALE value of SB ≈ 81.8 b
instead produces 𝑘 eff = 0.98951 ± 0.00010, a decrease of 668 pcm. Because the benchmark’s experimental
value is 𝑘 eff ≈ 0.99670 ± 0.00122, the larger bound scattering cross section appears to provide better
agreement with this particular benchmark. However, such agreement alone should not be interpreted as
validation of every single element of the underlying ND. The bound scattering cross section of hydrogen
is a well-established quantity that has been measured and evaluated extensively, with a value near 81.8 b
consistently reported throughout the literature (Sears 1992).
