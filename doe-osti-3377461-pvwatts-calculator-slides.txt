 What is the PVWatts Calculator?

• NREL's PVWatts® Calculator estimates the
 energy production of grid-connected
 photovoltaic (PV) energy systems.
• Homeowners, small building owners,
 installers, and manufacturers can easily
 develop estimates of the performance of
 potential PV installations, including the cost
 of electricity produced by the system.
• PVWatts is used in combination with other
  tools at NREL, including the System
  Advisor Model (SAM).

 What Kind of Questions can PVWatts Answer?

• What is the possible performance and
  annual value of my grid-connected roof-
  or ground-mounted solar project?
• How does potential hourly alternating
  current energy output differ for the same
  system in one location versus another?
• How does expected system output
  change with different array tilt or
  orientations? Photo: Gregory Cooper, NREL, 96662

Getting Started With
PVWatts Calculator

 Accessing PVWatts Calculator

• PVWatts Calculator is ready to use for new users on a web-
  based platform to get preliminary estimates.
• For software developers, it is available as a web API on the
  NREL Developer Network, or as part of the SAM Simulation
  Core Software Development Kit, which includes the PySAM
  Python package.
• Users can find the PVWatts Calculator on the NREL Website.
Source: NREL, PR-5600-90876, 2024

 Add a Location

• To get started with PVWatts®, type the street address, zip code, or latitude and longitude
  of the system's location, and click GO.
• PVWatts® uses this information to automatically identify solar resource data available at
  or near the system's location.
• For example, for a system on the NREL campus, you could type any of the following:
 ◦ 15013 Denver W Parkway, Golden CO
 ◦ 80401
      ◦ 39.7N, 105.2W
• Tool data comes from NREL National Solar Radiation Database (NSRDB), hourly typical
  meteorological year data and other international sources to estimate solar resource.
Source: NREL, 2025

 Add System Information
• The calculator estimates the monthly and annual electricity production of a PV system
  using an hour-by-hour simulation over a period of one year.
• To represent the system's physical characteristics, PVWatts® requires values for six
  inputs:
 o Direct current system size
 o Module type
 o Array type
 o System losses
 o Array tilt angle
 o Array azimuth angle

 Source: NREL, 2025
