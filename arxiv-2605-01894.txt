Poisson approximation by coupling Keywords: Poisson approximation, binomial, coupling


Abstract
It is well known that a binomial ( n , p ) (n,p) can be approximated by a Poisson distribution with parameter n ​ p np . The typical approach in undergraduate probability texts is to show a convergence result for the distribution of the binomial as n n goes to infinity and n ​ p np converges to some λ \lambda . In this note we use instead the coupling technique to show a much more general result. Moreover, we only use elementary results from probability.

Introduction

It is well known that a binomial random variable
B
with parameters
(n,p)
can be approximated by a Poisson random variable
L
with parameter
\lambda=np
. To show this result, undergraduate texts typically compute the limit of
P(B=k)
as
n\to\infty
and
np\to\lambda
and show that this limit is
P(L=k)
for any fixed integer
k
, see for instance
[
1
]
or
[
3
]
. This shows the convergence in distribution of a binomial to a Poisson distribution. But this is not really an approximation result as it does not provide a bound on the error made by the approximation. By using the coupling technique one gets a much more general result and in particular a bound on the error valid for all
n
and
p
. More precisely, we prove the following theorem.

Theorem 1
.

Let
B
be a binomial random variable with parameters
(n,p)
and
L
be a Poisson random variable with parameter
np
. Let
D
be a set of positive integers. Then, for all
n\geq 1
and
p\in(0,1)
,

\left|P(L\in D)-P(B\in D)\right|\leq np^{2}.

Since
D
is an arbitrary set of integers and the bound
np^{2}
is uniform in
D
the maximum error by approximating the distribution of a binomial
(n,p)
by a Poisson
np
is smaller than
np^{2}
.

Coupling is a very powerful and beautiful technique discovered by Wolfang Doeblin in the 1930’s, see Appendix 4 in
[
2
]
. However, for some reason coupling is mostly covered in graduate texts and research monographs, see for instance
[
4
]
. The coupling we discuss in this note is not new, see for instance page 5 in
[
2
]
. There, however, it is a minor point in an advanced text. In this note we will streamline the proof and provide all the details at an elementary level.

2
Coupling a Poisson and a Bernoulli random variables

Let
U
be uniform on
(0,1)
. Let
p\in(0,1)
. For
k\geq 0
, let

r_{k}=e^{-p}\frac{p^{k}}{k!}\mbox{ and }s_{k}=r_{0}+r_{1}+\dots+r_{k}.

Define the random variables
B
and
L
by,

B=\begin{cases}0\mbox{ if }U<1-p\\
1\mbox{ if }U>1-p\end{cases}\mbox{ and }L=\begin{cases}0\mbox{ if }U<r_{0}\\
k\geq 1\mbox{ if }s_{k-1}<U<s_{k}.\end{cases}

Hence,
B
is a Bernoulli with parameter
p
and
L
is a Poisson random variable with parameter
p
.
This construction yields the following coupling,

(L,B)=\begin{cases}(0,0)\mbox{ if }U<1-p\\
(0,1)\mbox{ if }1-p<U<r_{0}\\
(k,1)\mbox{ for }k\geq 1\mbox{ if }s_{k-1}<U<s_{k}.\end{cases}

Therefore,

\displaystyle E|L-B|=

\displaystyle r_{0}-(1-p)+\sum_{k\geq 1}(k-1)r_{k}

\displaystyle=

\displaystyle r_{0}-(1-p)+E(L)-P(L\geq 1)

\displaystyle=

\displaystyle 2(r_{0}-(1-p))

\displaystyle=

\displaystyle 2(e^{-p}-(1-p)).

Note that

2(e^{-p}-(1-p))\leq p^{2}.

Therefore,

E|L-B|\leq p^{2}.

[formula]

3
Coupling a Poisson and a Binomial random variables

Consider a sequence
(U_{i})_{1\leq i\leq n}
of independent uniform random variables on
(0,1)
. For every
i
in
\{1,\dots,n\}
we use the construction in the previous section with
U_{i}
(instead of
U
) to get the pair
(L_{i},B_{i})
where
L_{i}
is a Poisson and
B_{i}
is a Bernoulli, both with parameter
p
. Note that the random variables
(B_{i})
are mutually independent and so are the random variables
(L_{i})
.

Let
B=\sum_{i=1}^{n}B_{i}
, then
B
is a binomial random variable with parameters
(n,p)
.
Let
L=\sum_{i=1}^{n}L_{i}
then
L
is a Poisson random variable with parameter
np
.

\displaystyle E\left|L-B\right|=

\displaystyle E\left|\sum_{i=1}^{n}(L_{i}-B_{i})\right|

\displaystyle\leq

\displaystyle E\left(\sum_{i=1}^{n}|L_{i}-B_{i}|\right)

\displaystyle\leq

\displaystyle np^{2},

where the last inequality comes from (1).

4
The Poisson approximation to a binomial

An elementary computation shows that for any random variables
B
and
L
,

|P(L\in D)-P(B\in D)|\leq P(L\not=B),

where
D
is a set of positive integers, see for instance Section 3, Chapter 21 in
[
5
]
. Thus,

\displaystyle|P(L\in D)-P(B\in D)|

\displaystyle\leq P(L\not=B)

\displaystyle=P(|L-B|\geq 1)

\displaystyle\leq E|L-B|

\displaystyle\leq np^{2}.
