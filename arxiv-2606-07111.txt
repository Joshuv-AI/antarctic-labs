Failure of the Quench Action Formalism for Mott Insulator Initial States
Garry Goldstein

Abstract
The quench action formalism relies on the assumption that the overlap between a generic initial state | Ψ 0 ⟩ \left|\Psi_{0}\right\rangle and an eigenstate of an integrable model - defined through the rapidities | k 1 , … k N ⟩ \left|k_{1},...k_{N}\right\rangle - can be written as: ⟨ k 1 , … k N ∣ Ψ 0 ⟩ = exp ( − S Ψ 0 ( ρ ( k ) ) ) , \left\langle k_{1},...k_{N}\mid\Psi_{0}\right\rangle=\exp\left(-S_{\Psi_{0}}\left(\rho\left(k\right)\right)\right), (1) where ρ ⁡ ( k ) \rho\left(k\right) is the quasiparticle density of the state | k 1 , … k N ⟩ \left|k_{1},...k_{N}\right\rangle and S Ψ 0 S_{\Psi_{0}} is some smooth function of ρ ⁡ ( k ) \rho\left(k\right) that depends on Ψ 0 \Psi_{0} . In particular the quench action formalism assumes the overlap depends smoothly on the quasiparticle density ρ ⁡ ( k ) \rho\left(k\right) . In this work, by explicit counter example, we show that this is not the case. We consider the quench between a Mott insulator and a Lieb Liniger gas. We show that the overlap between the ground state of the Mott insulator and arbitrary eigenstates of the Lieb Liniger gas has a highly singular behavior and no expression like Eq. ( 1 ) applies. We do so within the Tonks Girardeau limit of the Lieb Liniger gas and to leading order in the 1 / c 1/c expansion for the overlap (with c c being the coupling constant of the Lieb Liniger gas). In Appendix A we show similar results for overlaps in the XXZ model with crystal states.



I
Introduction

The question of how and whether an isolated quantum system relaxes
to which equilibrium state is of great interest to modern physicist.
On the forefront of this area of research are studies of Bethe integrable
systems
(
Bethe 1931
;
Zvyagin 2005
;
Korepin 1993
;
Samaj 2013
;
Franchini 2017
)

in 1D. In Bethe integrable systems the exact eigenstates are known
due to the existence of an infinite number of commuting conserved
quantities
Q_{i}

(
Samaj 2013
;
Zvyagin 2005
;
Franchini 2017
)
.
In particular the eigenstates can be characterized in terms of rapidities

\left|k_{1},...k_{N}\right\rangle
. Furthermore there has been
tremendous experimental effort to understand the dynamics and thermodynamics
of these integrable systems
(
Weiss 2004
;
Amergon 2008
;
Dahr 2025
;
Ganahal 2012
;
Gring 2012
;
Haller 2009
;
Kinoshita 2006
;
Langen 2015
;
Paredez 2004
;
Rosenberg 2024
;
Trotsky 2012
;
Meinert 2015
)
.
One of the key questions asked is the fate of a quenched system. A
quench is when a system is initially prepared in an eigenstate
\left|\Psi_{0}\right\rangle

of a Hamiltonian
H_{0}
and then instantaneously - on the time scale
of the experiment - a new Hamiltonian
H_{f}
is turned on and the
system evolves as:

\left|\Psi\left(t\right)\right\rangle=\exp\left(-iH_{f}t\right)\left|\Psi_{0}\right\rangle.

(2)

Here
t
is the time of evolution. One of the key questions involved
is what happens if
H_{f}
is an integrable Hamiltonian. By now it
is strongly theoretically believed that the final state of the system
is given by a Generalized Gibbs Ensemble (GGE)
(
Rigol 2008
;
Goldstein 2014(2
;
Ilievski 2015
;
Pozsgay 2014
)
,
with the GGE being observed experimentally in Ref.
(
Langen 2015
)
.
One of the key theoretical underpinnings of the GGE formalism and
the way in which an integrable system equilibrates to the GGE is the
quench action formalism
(
Caux 2013
;
Caux 2016
;
Brockmann 2014
;
Brockmann 2014(2
;
Brockmann 2014(3
;
Ilievski 2015
;
Luca 2015
;
Mastyan 2015
;
Nardis 2014
;
Wouters 2014
;
Wouters 2015
)
.
In the quench action formalism it is assumed that the overlap between
the initial state and an eigenstate of the integrable final Hamiltonian
is given by:

\left\langle k_{1},...k_{N}\mid\Psi_{0}\right\rangle=\exp\left(-S_{\Psi_{0}}\left(\rho\left(k\right)\right)\right)

(3)

Where
\rho\left(k\right)
is a the quasiparticle density of the
state
\left|k_{1},...k_{N}\right\rangle
and
S_{\Psi_{0}}
is
some smooth function of
\rho\left(k\right)
which is dependent on

\left|\Psi_{0}\right\rangle
. The final state at long times
\left|\Psi\left(t\rightarrow\infty\right)\right\rangle

is then shown to be essentially an eigenstates of
H_{f}
and the
quasiparticle density of the final eigenstate of
H_{f}
is determined
by maximizing the Yang-Yang action for the system given by:

Z=\int\mathcal{D}\left(\rho\left(k\right)\right)\exp\left(-2Re\left[S_{\Psi_{0}}\left(\rho\left(k\right)\right)\right]+S_{YY}\left(\rho\left(k\right)\right)\right)

(4)

with respect to
\rho\left(k\right)
, subject to the Bethe ansatz
equations for
\rho\left(k\right)
. Here
S_{YY}\left(\rho\left(k\right)\right)

is the Yang-Yang entropy of the system
(
Yang 1969
;
Zvyagin 2005
;
Samaj 2013
;
Korepin 1993
;
Franchini 2017
)
.
More precisely the long term behavior of the integrable system is
controlled by the density
\rho^{*}\left(k\right)
s.t.

\frac{\delta}{\delta\rho\left(k\right)}\left[-2Re\left[S_{\Psi_{0}}\left(\rho^{*}\left(k\right)\right)\right]+S_{YY}\left(\rho^{*}\left(k\right)\right)\right]=0

(5)

Furthermore equilibration can be understood by studying small fluctuations
about the saddle point
\rho^{*}\left(k\right)

Caux 2013
;
Caux 2016
.
Models with multiple species of quasiparticles (such as bound states)
can be studied by replacing
\rho\left(k\right)\rightarrow\rho_{n}\left(k\right)

in Eqs. (
3
), (
4
) and (
5
),
where
n
labels the different quasiparticle species.

The main result of this work is that this approach is incorrect, the
quench action formalism is wrong. The most pertinent mistake of the
quench action formalism is that the quench action formalism assumes
that if we take an initial state
\left|\Psi_{0}\right\rangle
then
the overlap with the state
\left|k_{1},k_{2},...k_{N}\right\rangle

(with
N/L
fixed, where
L
is the length of the system) depends
smoothly on the density of states
\rho\left(k\right)
. Thats is
if we take two eigenstates of
H_{f}
,
\left|\Phi_{1}\right\rangle

and
\left|\Phi_{2}\right\rangle
, with the same
\rho\left(k\right)
,
the overlap does not depend on which states we are considering:

\left\langle\Phi_{1}\mid\Psi_{0}\right\rangle=\left\langle\Phi_{2}\mid\Psi_{0}\right\rangle+O\left(\frac{1}{N}\right)

(6)

We will show this through a counter example to be explicitly false
and that overlaps have significantly more structure then in given
in Eq. (
3
) above. We first would like to note
that there is already a counter example to Eq. (
6
)
in the literature
(
Brockmann 2014
;
Brockmann 2014(2
;
Brockmann 2014(3
;
Caux 2016
;
Nardis 2014
;
Wouters 2014
;
Wouters 2015
)
.
For this counter example we can take an integrable quench
(
Pozsgay 2020
;
Piroli 2017
)

- where for the conserved charges (for say the Lieb Liniger gas) we
have that:

Q_{2p+1}\left|k_{1},k_{2},...k_{N}\right\rangle=\sum_{i}k_{i}^{2p+1}\left|k_{1},k_{2},...k_{N}\right\rangle

(7)

and the initial state
\left|\Psi_{0}\right\rangle
satisfies:

Q_{2p+1}\left|\Psi_{0}\right\rangle=0,\>\forall p

(8)

Then:

\displaystyle\left\langle k_{1},k_{2},...k_{N}\mid\Psi_{0}\right\rangle=0,

\displaystyle unless:k_{1}=-k_{2},\>k_{3}=-k_{4},\>k_{5}=-k_{6},...

(9)

(there is paring of the rapidities). For such states there is an ad
hoc correction to the quench action - where the Yang-Yang entropy
is divided by two:

S_{YY}\left(\rho\left(k\right)\right)\rightarrow\frac{1}{2}S_{YY}\left(\rho\left(k\right)\right)

(10)

in Eqs. (
4
) and (
5
). In
this work we show that the problem is much worse that there are overlaps
with significantly more structure then just pairing where there is
no obvious modification to the Yang-Yang entropy that will work. We
will do so by an explicit example of the quench of the Mott insulator
into the Tonks Girardeau gas
(
Giradeau 1960
;
Tonks 1936
)
and
to leading order in
1/c
for overlaps of the Lieb Liniger gas
(
Lieb 1963
;
Lieb 1963
)

(here
c
is the coupling constant of the Lieb Liniger gas). In Appendix

A
we will study similar states (crystal states)
for the XXZ model, in the limit a large anisotropy
\left|\Delta\right|\gg 1
,
and find they also have a very rich overlap structure where Eq. (
6
)
does not apply.

II
Explicit Example: Quench between a Mott Insulator and the Tonks
limit of the Lieb Liniger gas

The Lieb Liniger Hamiltonian is given by:

H=\int_{0}^{L}dx\left[\partial_{x}b^{\dagger}\left(x\right)\partial_{x}b\left(x\right)+cb^{\dagger}\left(x\right)b^{\dagger}\left(x\right)b\left(x\right)b\left(x\right)\right]

(11)

Here
b^{\dagger}\left(x\right)
,
b\left(x\right)
are bosonic
creation and annihilation operators at the point
x
. We will assume
periodic boundary conditions. We consider the initial state
(
Goldstein 2014
)
:

\left|\Psi_{0}\right\rangle=\prod_{j=0}^{N-1}\int_{-\infty}^{\infty}dx\varphi\left(x-jl\right)b^{\dagger}\left(x\right)\left|0\right\rangle

(12)

with
Nl=L
. Where we will assume that the width
W
of
\varphi\left(x\right)

is much small the
l
,
W\ll l
so that

\int_{-\infty}^{\infty}dx\varphi^{*}\left(x-jl\right)\varphi\left(x-kl\right)\cong\delta_{jk}

(13)

Where if we further assume that:

\varphi\left(x\right)=\frac{\exp\left(-x^{2}/\sigma\right)}{\left(\pi\sigma/2\right)^{1/4}}

(14)

with
\sqrt{\sigma}\ll l
we get the Mott insulator initial state
quench
(
Goldstein 2014
)
. We will show that the state in Eq.
(
12
) has much richer structure of overlaps
with the eigenstates of the Lieb Liniger gas then is given by Eq.
(
6
) above. We will not use the assumption given in
Eq. (
14
) above. Then the un-normalized eigenstates
of the Lieb Liniger gas are given by:

\displaystyle\left|k_{1},..k_{N}\right\rangle

\displaystyle=\int_{0<x_{1}<...x_{N}<L}\psi\left(k_{1},...k_{N};x_{1},...x_{N}\right)\prod_{j}b^{\dagger}\left(x_{j}\right)\left|0\right\rangle

(15)

with:

\displaystyle\psi\left(k_{1},...k_{N};x_{1},...x_{N}\right)

\displaystyle=\sum_{P\in\pi_{N}}\left(-1\right)^{P}\exp\left[\sum_{j}ik_{Pj}x_{j}\right]

\displaystyle\times\prod_{m<n}\left(k_{Pm}-k_{Pn}+ic\right)

(16)

Where
\pi_{N}
is the permutation group on
N
elements. To find
the overlap between the wavefunction in Eq. (
12
)
and (
15
) we first need to integrate:

\int\varphi\left(x-jl\right)\exp\left(-ik_{Pj}\left(x\right)\right)=\exp\left(-ik_{Pj}jl\right)\tilde{\varphi}\left(k_{Pj}\right)

(17)

where
\tilde{\varphi}\left(k\right)=\int dxe^{-ikx}\varphi\left(x\right)

is the Fourier transform of
\varphi\left(x\right)
. Now doing the
Wick contractions we have that:

\displaystyle\left\langle k_{1},....k_{N}\mid\Psi_{0}\right\rangle

\displaystyle=\prod_{j}\tilde{\varphi}\left(k_{j}\right)\sum_{P\in\pi_{N}}\left(-1\right)^{P}\exp\left[-i\sum_{j}jlk_{Pj}\right]

\displaystyle\times\prod_{m<n}\left(k_{Pm}-k_{Pn}-ic\right)

(18)

Lets take
c\rightarrow\infty
and study:

\displaystyle\frac{1}{\left(-ic\right)^{N\left(N-1\right)/2}}\left\langle k_{1},....k_{N}\mid\Psi_{0}\right\rangle

\displaystyle=\prod_{j}\tilde{\varphi}\left(k_{j}\right)\sum_{P\in\pi_{N}}\left(-1\right)^{P}\exp\left(-i\sum_{j}jlk_{Pj}\right)

\displaystyle=\prod_{j}\tilde{\varphi}\left(k_{j}\right)\det\left(\exp\left(-ilk_{i}\right)^{j}\right)

\displaystyle=\prod_{j}\tilde{\varphi}\left(k_{j}\right)\prod_{j>i}\left(\exp\left(-ik_{j}l\right)-\exp\left(-ik_{i}l\right)\right)

(19)

(we recognize the Vandermonde determinant). Now we study:

\displaystyle\frac{1}{c^{N(N-1)}}\left|\left\langle k_{1},....k_{N}\mid\Psi_{0}\right\rangle\right|^{2}

\displaystyle=\prod_{j}\left|\tilde{\varphi}\left(-k_{j}\right)\right|^{2}\prod_{j>i}4\sin^{2}\left[\frac{k_{j}-k_{i}}{2}l\right]

(20)

Now we have that
lN=L
and
k_{j}=\frac{2\pi I_{j}}{L}
(with
I_{j}\in\mathbb{Z}

we will assume
N
is odd) so we have that:

\displaystyle\frac{1}{c^{N\left(N-1\right)}}\left|\left\langle k_{1},....k_{N}\mid\Psi_{0}\right\rangle\right|^{2}

\displaystyle=\prod_{j}\left|\tilde{\varphi}\left(k_{j}\right)\right|^{2}\prod_{j>i}4\sin^{2}\left[\pi\frac{I_{j}-I_{i}}{N}\right]

(21)

We notice that this function is not a smooth function of
\rho\left(k\right)
.
Indeed we must have that every
I=0,1,2,....N-1
(mod
N)
is occupied
exactly once or the product in Eq. (
21
) is zero.
As such:

\displaystyle\frac{1}{c^{N\left(N-1\right)}}\left|\left\langle k_{1},....k_{N}\mid\Psi_{0}\right\rangle\right|^{2}

\displaystyle=\prod_{j}\left|\tilde{\varphi}\left(k_{j}\right)\right|^{2}\prod_{N\geq j>i\geq 1}4\sin^{2}\left[\pi\frac{j-i}{N}\right]

(22)

for
\left\{k_{1},....k_{N}\right\}=\left\{p\frac{2\pi}{L}+m_{p}\frac{2\pi N}{L}\right\},\>with\>p=0,1,2,...N-1,\>m_{p}\in\mathbb{Z}
.
In other words the overlap has structure where only:

\displaystyle\left\{k_{1},....k_{N}\right\}=\left\{p\frac{2\pi}{L}+m_{p}\frac{2\pi N}{L}\right\},

\displaystyle\>with\>p=0,1,2,...N-1,\>m_{p}\in\mathbb{Z}

(23)

have non-zero overlap. This is a much richer structure then in Eq.
(
6
). As such the quench action fails as Eq. (
6
)
fails.

III
Mott Insulator Quench: Leading Order in
1/c
expansion

We will again consider the Mott insulator quench but now to leading
order in
1/c
expansion for the overlap. We will consider the initial
state given in Eq. (
12
) without the assumption
given in Eq. (
14
). Then the overlap of the initial
state with an eigenstate of the form in Eq. (
15
)
is given by Eq. (
18
). Now lets write:

k_{Pm}-k_{Pn}-ic\cong-ic\exp\left(i\left(k_{Pm}-k_{Pn}\right)/c\right)+O\left(\frac{1}{W^{2}c^{2}}\right)

(24)

This means that:

\displaystyle\prod_{m<n}\left(k_{Pm}-k_{Pn}-ic\right)

\displaystyle\cong\left(-ic\right)^{N\left(N-1\right)/2}\prod_{m}\exp\left(i\left[N-2m\right]k_{Pm}/c\right)

(25)

So that:

\displaystyle\frac{1}{\left(-ic\right)^{N\left(N-1\right)/2}}\left\langle k_{1},....k_{N}\mid\Psi_{0}\right\rangle

\displaystyle=\exp\left(i\frac{N}{c}\sum_{i}k_{i}\right)\prod_{j}\tilde{\varphi}\left(k_{j}\right)\times

\displaystyle\times\sum_{P\in\pi_{N}}\left(-1\right)^{P}\exp\left(-i\sum_{j}j\left[l+\frac{2}{c}\right]k_{Pj}\right)

\displaystyle=\exp\left(i\frac{N}{c}\sum_{i}k_{i}\right)\prod_{j}\tilde{\varphi}\left(k_{j}\right)\det\left(\exp\left(-i\left[l+\frac{2}{c}\right]k_{i}\right)^{j}\right)

\displaystyle=\exp\left(i\frac{N}{c}\sum_{i}k_{i}\right)\prod_{j}\tilde{\varphi}\left(k_{j}\right)\times

\displaystyle\times\prod_{j>i}\left(\exp\left(-ik_{j}\left[l+\frac{2}{c}\right]\right)-\exp\left(-ik_{i}\left[l+\frac{2}{c}\right]\right)\right)

(26)

(we recognize the Vandermonde determinant). Now we study:

\displaystyle\frac{1}{c^{N(N-1)}}\left|\left\langle k_{1},....k_{N}\mid\Psi_{0}\right\rangle\right|^{2}

\displaystyle=\prod_{j}\left|\tilde{\varphi}\left(k_{j}\right)\right|^{2}\prod_{j>i}4\sin^{2}\left[\frac{k_{j}-k_{i}}{2}\left[l+\frac{2}{c}\right]\right]

(27)

Now we have that the Bethe equations are given by:

\displaystyle k_{j}L=2\pi I_{j}+\left(N-1\right)\pi-2\sum_{m}\arctan\left(\frac{k_{j}-k_{m}}{c}\right)

\displaystyle\Rightarrow k_{j}\left(L+\frac{2N}{c}\right)\cong 2\pi I_{j}+\left(N-1\right)\pi+2\sum_{m}\frac{k_{m}}{c}

\displaystyle\Rightarrow\left[k_{j}-k_{i}\right]\left(L+\frac{2N}{c}\right)=2\pi\left(I_{j}-I_{i}\right)

(28)

Here
I_{i}
are the occupied quantum numbers (with
I_{j}\in\mathbb{Z}
).
This means that:

\displaystyle\frac{1}{c^{N(N-1)}}\left|\left\langle k_{1},....k_{N}\mid\Psi_{0}\right\rangle\right|^{2}

\displaystyle=\prod_{j}\left|\tilde{\varphi}\left(k_{j}\right)\right|^{2}\prod_{j>i}4\sin^{2}\left[\frac{\pi\left(I_{j}-I_{i}\right)}{N\left(l+\frac{2}{c}\right)}\left[l+\frac{2}{c}\right]\right]

\displaystyle=\prod_{j}\left|\tilde{\varphi}\left(k_{j}\right)\right|^{2}\prod_{j>i}4\sin^{2}\left[\frac{\pi\left(j-i\right)}{N}\right]+O\left(\frac{1}{W^{2}c^{2}}\right)

(29)

where again we must have that every
I=0,1,2,....N-1
(mod
N)

is occupied exactly once or the overlap is zero. So the overlap is
finite if:

k_{j}=k_{1}+\frac{2\pi\left(j-1\right)}{L+\frac{2N}{c}}+n_{j}\frac{2\pi N}{L+\frac{2N}{c}},\>n_{j}\in\mathbb{Z}

(30)

and zero otherwise. Again this is a much richer structure then in
Eq. (
6
). As such the quench action fails as Eq. (
6
)
fails.

IV
Conclusions

In this work we have presented a counterexample to the quench action
formalism. We have presented an initial state - the bosonic Mott insulator
ground state in 1D - whose overlap with the Lieb Liniger eigenstates
has a highly singular form - where Eq. (
1
) does
not apply in any form. In Appendix
A
we study
some initial states (crystal states) for quenches of the XXZ model,
in the limit of large anisotropy
\left|\Delta\right|\gg 1
, and find
similar results where Eq. (
6
) fails. We would like
to note that this is a very exciting development - whereby overlaps
have significantly more structure then expectation values of local
operators - which are known to be smooth functions of
\rho\left(k\right)

(
Korepin 1993
)
. The quench action, which previously was thought
to describe all quenches into integrable models, apparently greatly
simplified the situation - making all quenches appear somewhat bland;
quenches were always controlled by a version of the Yang-Yang equations
and small fluctuations about the saddle point of the Yang-Yang action.
Now we see that the situation, in reality, is much more rich and exciting
with many singular possibilities leading to potentially new formalisms
and new theoretical approaches as to how or if the system equilibrates
to a GGE. To support our claims further, in the future, it would be
of interest to look into nearly integrable quenches, ones with initial
states of the form:
\left|\Psi_{0}\right\rangle=

\left(\frac{1}{\sqrt{L\left(1+\left|\alpha\right|^{2}\right)}}\int_{0}^{L}dx\left(1+\alpha\exp\left(ikx\right)\right)b^{\dagger}\left(x\right)\right)^{N}\left|0\right\rangle

(31)

with
\left|\alpha\right|\ll 1
and obtain conditions similar to Eq.
(
9
) but with deviations of the order of
\alpha

leading to more complex corrections to the Yang-Yang entropy then
in Eq. (
10
) thereby presenting another counter-example
to the quench action formalism.

Appendix A
XXZ Model for
\left|\Delta\right|\gg 1
: Crystal State Quenches

In this appendix we will consider crystal state quenches in to the
XXZ model. We consider the XXZ model with
\left|\Delta\right|\gg 1

with periodic boundary conditions on a ring of length
L
. The Hamiltonian
of the XXZ model is given by:

H_{XXZ}=J\sum_{j=1}^{L}\left(\sigma_{j}^{x}\sigma_{j+1}^{x}+\sigma_{j}^{y}\sigma_{j+1}^{y}+\Delta\sigma_{j}^{z}\sigma_{j+1}^{z}\right)

(32)

(with
\vec{\sigma}_{L+1}\equiv\vec{\sigma}_{1}
). Here
\sigma_{i}^{x/y/z}

are the Pauli matrices at site
i
and
J
is a irrelevant coupling
constant. Now consider the initial state (crystal state):

\left|\Psi_{0}\right\rangle=\prod_{j=1}^{N}\sigma_{jl}^{-}\left|\uparrow......\uparrow\right\rangle

(33)

Where
l=\frac{L}{N}\in\mathbb{N}
. Then we have that the un-normalized
eigenstates of the XXZ Hamiltonian are given by
(
Korepin 1993
)
:

\left|\lambda_{1},....\lambda_{N}\right\rangle=

\sum_{m_{1}<m_{2}<....m_{N}}\chi\left(\lambda_{1},....\lambda_{N};m_{1},....m_{N}\right)\sigma_{m_{1}}^{-}....\sigma_{m_{N}}^{-}\left|\uparrow......\uparrow\right\rangle

(34)

where:

\displaystyle\chi\left(\lambda_{1},....\lambda_{N};m_{1},....m_{N}\right)

\displaystyle=\sum_{P\in\pi_{N}}\left(-1\right)^{P}A_{P}\exp\left(i\sum_{a=1}^{N}\lambda_{Pa}m_{a}\right)

(35)

We will assume
\lambda_{a}\in\mathbb{R}
that is neglect states
with string solutions. This will already be enough to show the failure
of Eq. (
3
) for those states.

Where:

\displaystyle A_{P}

\displaystyle=\left(-1\right)^{N-1}\prod_{j<m}\left(\exp\left(i\left[\lambda_{Pm}+\lambda_{Pj}\right]\right)+1-2\Delta\exp\left(i\lambda_{Pj}\right)\right)

\displaystyle=\left(-1\right)^{N-1}\left(-2\Delta\right)^{\left(N-1\right)N/2}\prod_{k}\exp\left(i\left(N-k\right)\lambda_{Pk}\right)\prod_{j<m}\left(1-\frac{\exp\left(i\lambda_{Pm}\right)}{2\Delta}-\frac{\exp\left(-i\lambda_{Pj}\right)}{2\Delta}\right)

\displaystyle\cong\left(-1\right)^{N-1}\left(-2\Delta\right)^{\left(N-1\right)N/2}\prod_{k}\exp\left(i\left(N-k\right)\lambda_{Pk}\right)\prod_{j<m}\left(\exp\left[-\frac{\exp\left(i\lambda_{Pm}\right)}{2\Delta}\right]\exp\left[-\frac{\exp\left(-i\lambda_{Pj}\right)}{2\Delta}\right]\right)

\displaystyle=\left(-1\right)^{N-1}\left(-2\Delta\right)^{\left(N-1\right)N/2}\prod_{k}\exp\left(i\left(N-k\right)\lambda_{Pk}\right)\prod_{j<m}\exp\left(-\frac{\cos\left(\lambda_{Pj}\right)+\cos\left(\lambda_{Pm}\right)}{2\Delta}\right)\prod_{j<l}\exp\left(-i\frac{\sin\left(\lambda_{Pj}\right)-\sin\left(\lambda_{Pm}\right)}{2\Delta}\right)

\displaystyle=\left(-1\right)^{N-1}\left(-2\Delta\right)^{\left(N-1\right)N/2}\prod_{k}\exp\left(iN\lambda_{k}\right)\prod_{j}\exp\left(-\left(N-1\right)\frac{\cos\left(\lambda_{Pj}\right)}{2\Delta}\right)\prod_{j}\exp\left(-i\left(N-2j\right)\frac{\sin\left(\lambda_{Pj}\right)}{2\Delta}-i\left(j\lambda_{Pj}\right)\right)

(36)

Then we have that:

\displaystyle\frac{1}{\left(2\Delta\right)^{N\left(N-1\right)}}\left|\left\langle\lambda_{1},....\lambda_{N}\mid\Psi_{0}\right\rangle\right|^{2}
