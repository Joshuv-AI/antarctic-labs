1. Introduction
 Computed radiography (CR) imaging plates and film are used in HEAF firing tanks
and in the NDE group. The imaging plates allow for the creation of high-resolution digital
images with flash X-ray (FXR). A typical treatment of flash X-ray radiographs is flat-field
correction, where the image from an experiment is normalized by a “flat-field” or “bright-
field” image. This flat-field image is taken in an identical configuration to the experimental
image, but without the object or experiment in the field of view (FOV). This treatment
reduces spatial effects from the FXR spot size and detector misalignment, as each pixel
value in the corrected image represents a ratio of collected radiation with the object in FOV
to the collected radiation without the object in FOV.

 One challenge in the creation of a corrected image is the misalignment of the CR
plate or film pack between capturing the flat-field image and the experimental image.
Fiducial structures can remedy this issue. Small (3.18mm) stainless steel ball bearings
serve as good fiducial structures due to their small size and high radiographic contrast.
Spheres are view-agnostic geometry, always presenting a circular cross section no matter
the orientation.

 This process was developed for images from the flash X-ray testbed. The flash
testbed was used to compare the X-ray transmission at different thicknesses of aluminum
and copper step wedges. Each step wedge section is a rectangular shape, so evaluation is
made much simpler if the rectangles are not rotated with respect to the image. This
alignment process aligns the object and flat-field images together and leaves the
rectangles of each step aligned with the image.

2. Fiducial-Based Image Alignment
2.1 Software
 This image correction script runs in MATLAB and was written in version R2022b. The
program relies on functions from the Image Processing Toolbox, downloadable from
MathWorks or directly within the MATLAB application.

 The script will be included in the appendix of this report. Indexing and variable
names are in reference to a broader workflow and should be adjusted to fit the user’s
application.

2.2 Process overview
 This image alignment process relies on two circular fiducials included in the FOV in
both the experimental image and in the flat-field image. Figure 1 (a) shows an image of a
stepped wedge and line pair gauge taken on film and scanned directly into a digital format.
At the bottom face of the steps wedge, two fiducial spheres can be seen on the left and
right of the wedge. Figure 1 (b) shows the flat-field image to highlight that the fiducial
structures are still in the FOV.

 In between taking image (a) and image (b), the step wedge and line pair gauge were
removed from the alignment stand. The stand maintains alignment between the objects
and the fiducials. The stand is also fixed in place relative to the center of the X-ray tube. The
film pack is removed, processed, and replaced with a fresh film between shots. The film
pack is replaced at the same location, but small rotations of the film pack were not
controlled for.

2.3 Getting started
 The first step to running this script is to upload the raw images to MATLAB. The
“imread” function works well to import a TIF file directly. Variable labels “im0” and “bk0”
refer to the experimental image file and the background/flat-field image file, respectively.
The script shown in the appendix references a MATLAB structure called “B0” with the set of
TIF images saved directly in MATLAB, and index “i” refers to image number within the set.
For the data set used in this example, the background shot was captured directly after each
experimental image, resulting in indexing of “i” for “im0” and “i+1” for “bk0”.

 There are two additional inputs to the alignment script: The first is “bit-depth”, where
the digital bit depth of the scanned image can be input. This value is only used for scanned
film images, which are uploaded as “attenuation” images, where bright areas represent
more attenuation of the incident radiation. Scanned CR images are in an inverted format,
with bright regions representing more transmission of the incident beam. The second input
is the “gain” required to view the raw images. Depending on the imaging set up, the raw
scanned image may appear too dark to see without scaling. By adding a gain value, for
example 10, the image is artificially brightened when displayed for user input.

 The second section of the script, used to create a cropped and flat-field corrected
image, requires another set of inputs discussed in section 2.5.

2.4 Running the script
 After uploading and indexing the images and adjusting the remaining inputs, the
script is ready to run. A figure window will pop up showing the raw experimental image
scaled with the gain value. Figure 2 is an example of this first figure window. Along with the
figure window, the “drawcircle” tool is activated.

Figure 2: First figure window to pop up when running the script. This image is displayed with
 a gain value of 10.

 The user must highlight the two spherical fiducial structures. Selecting the “zoom
in” feature on the top right of the figure window allows the user to zoom in more on the
fiducial structures, shown in figure 3. Deselecting the “zoom in” feature reactivates the
“drawcircle” tool. Draw the first circle on the top-most fiducial structure. The second circle
goes on the lower fiducial.

 Figure 3: Figure window from figure 2 after zooming into the fiducial structures.

 The circle is drawn by diameter – left click on the edge of the fiducial and hold to
stretch the circle across the fiducial. The circle has an edge thickness, so it is
recommended to keep the circle slightly smaller than the fiducial. It was easier for the user
to center the drawn circle by keeping a constant distance between the drawn circle edge
and the fiducial edge. This is demonstrated in figure 4, where both circles have already
been drawn. After the second circle is drawn, the script continues automatically.

 5

 Figure 4: Both circles have been drawn onto the figure window. Note the constant-width
between the fiducial structure and the drawn circle. Centering based on this width proved
 to be easier for the user than selecting the center of the fiducial structure.

 The circles and image are then sent to the function “CR_align.m”. Behind the
scenes, the function finds the center of the image file to set a center of rotation. Then,
vectors are created from the centers of each drawn circle to the center of the image. A
small angle, 0.01˚, is used to create a 2D rotation tensor. This rotation is applied to the
vectors once, creating new circle centers. The horizontal location – in this case, pixel
number – of the two new centers are checked for vertical alignment. The rotation and
checking process is repeated until the centers are vertically aligned.

 This final rotation angle is then applied to the image using the “imrotate” function.
The rotation process necessarily requires resampling of the pixel values. Here, bilinear

interpolation is used. An additional input to “imrotate” is selecting “crop” vs “loose”. Here,
“crop” is used to leave the newly rotated image the same size as the input image. In
general, either option suffices. The regions evaluated in this experiment were very close to
the center of the image, so slight cropping at the edges was not a concern. Figure 5 shows
the second figure window which pops up in the script, showing the applied correction to
the first image.

Figure 5: Figure window showing the applied correction to the first image. The image is dark

 After this second figure window is displayed, a third figure window pops open. This
third figure window shows the flat-field image. If the fiducials appear on the opposite side
of the image compared to the experimental image (i.e. right-hand side instead of left-hand
side, or on the bottom face rather than the left side) the image should be rotated 180˚ or
90˚. This can be done either in windows file explorer or in MATLAB prior to this script.
Repeat the circle fitting process as outlined above.

2.5 Flat-field correction
 Flat-field correction occurs within the same script but is highlighted separately here.
The script grabs a rectangle of user-defined size, and bases placement of the rectangle on
the top-most fiducial. This rectangle is created for the flat-field correction operation, which
requires arrays of the same size.

 The user must input three values, “L”, “W” and “O”. These three variables
correspond to length, width, and offset. Length and width are used to set the size of the
final image. Here, the center of the image is where the object of interest sits, so we choose
a region which includes the object of interest and sufficient empty space adjacent to the
object for contrast calculations. A square region of 3600 pixels by 3600 pixels is used for
this example. The offset is used to account for the placement of the fiducials. The
rectangle, now with dimensions L by W, is created with one corner on the top-most fiducial.
An offset of 300 pixels is used to offset the rectangle corner, so 300 pixels to the left of the
fiducial is included in the new rectangle. Both experimental and flat-field images are
cropped to this new rectangle using the “imcrop” function, shown in figure 6.

3. Conclusion
The script discussed in this report can be found in appendix A. The example shown in this
report was a film image, but this process also works for CR images in the same manner. The

colored rectangles are in a set position relative to the image fiducials, highlighting the

 CR_alignment.m

Iterative image rotation function

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% function to rotate images until they are vertical
% FW cic
% started 1-15-2024
function [rotated_image, fiducial_centers] = CR_align(circle1,circle2,image)

%%%%%%%%%%%%%% now, lets establish the "tilt" in the image %%%%%%%%%%%%%%%
% want the centers of the fiducials to be on the same y position (same col)
% circle.center = (x,y)

% find center of image A0
[M,N] = size(image);
if mod(M,2) == 0 % even
 centerM = M/2 +.5; % center is technically between the two middle lines
else
 centerM = (M+1)/2; % center line
end
if mod(N,2) == 0 % even
 centerN = N/2 +.5; % center is technically between the two middle lines
else
 centerN = (N+1)/2; % center line
end

% vectors from center of fiducials to center of image
OGvec1 = [circle1.Center(1)-centerN; circle1.Center(2)-centerM];
OGvec2 = [circle2.Center(1)-centerN; circle2.Center(2)-centerM];

% use rotation tensor to rotate both vectors until the x value is equal
% use an iterative approach
vec1 = OGvec1;
vec2 = OGvec2;
Dx = vec1(1)-vec2(1);
if Dx<0
     th = -.01; % deg
else
     th = .01; % deg
end
R = [cosd(th) sind(th); -sind(th) cosd(th)];
count = 0;
while abs(vec1(1)-vec2(1)) >= 1
     vec1 = R*vec1;
     vec2 = R*vec2;
     Dx = vec1(1)-vec2(1);
 count = count+1;
end
figure
imshow(image)
hold on
plot(centerN + OGvec1(1),centerM + OGvec1(2), 'og') % old
plot(centerN + OGvec2(1),centerM + OGvec2(2), 'oc') % old
plot(centerN + vec1(1),centerM + vec1(2), '+g') % new

 1

plot(centerN + vec2(1),centerM + vec2(2), '+c') % new
plot(centerN,centerM, '*r') % image center
title("applied correction")
hold off
rotated_image = imrotate(image, count*th, "bilinear", "crop");
% new fiducial centers
fiducial_centers = [centerN + vec1(1),centerM + vec1(2); centerN + vec2(1),
 centerM + vec2(2)];
end
