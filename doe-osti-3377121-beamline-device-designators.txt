Executive Summary
LAMP is to replace the front-end of LANSCE. Therefore, the device designators for LAMP needs approval
from LANSCE. This document defines the agreed upon device designator names to be used in LAMP and
in the prototype beamline LAMP in ADEF Tunnel (LAT).

1 Introduction
LAMP is designing a new front-end for the LANSCE accelerator. The device designators for the accelerator
need to be consistent with LANSCE at the time of installation. LAMP-SE-RPT-001 [1] is the official LAMP
Acronym list and LANSCE AOM 2.04 Attachment A [2] is the official Acronym and Abbreviation list for
LANSCE Accelerator Operations. This document defines the agreed upon beamline device designators for
LAMP and LAT in-order to interface with LANSCE at the time of installation.

2 LANSCE’s Device Designators
From the LANSCE wiki [3] the designator for each device is defined as shown in Figure 1.

Figure 1: Device Designator nomenclature used at LANSCE

The ten-digit string is based off the old LANSCE Remote Instrumentation and Control Equipment (RICE)
[4] system. Since LANSCE now runs the Experimental Physics and Industrial Control System (EPICS)
[4] system, 40 characters are the maximum number allowed. It is outside of LAMP scope to change this
format for the LANSCE accelerator. That means that each “beamline” in LAMP will be composed of a
two-letter or one letter one number designator.

3 LAMP Device Designator Interface Requirements
The requirements for LAMP are given below:
 1. LAMP designators shall fit within the 10-character designator currently used by LANSCE EPICS
 system as given in Figure 1.
 2. LAMP shall not use any designators that remain after the LANSCE front-end is removed
 a. For example: The modules in the CCL will still be numbered 05 through 48.
 3. LAMP could reuse the designators that no longer remain after the LANSCE front-end is removed
 a. For example: The LAMP H+ line may still be called TA.
 4. If the number of LAMP DTL tanks exceeds 4 their designation will be D1-N with N being the
 number of tanks.
 5. Each LAMP RFQ will have its own Beamline ID given by Q# with # being the number of the RFQ.
 a. This is because the device designators for the HPRF system, e.g. the 02JL is the Module 2
 201 RF Amplifier Low Voltage Device, assumes each HPRF device is connected to a single
 Beamline ID.
 6. The Medium Beam Energy Transport line that transports the beam from the RFQ to the DTL will
 have a different Beamline ID from Low Energy Beam Transport line that is before the RFQ.
 7. LAT will use LAMP Beamline IDs.
