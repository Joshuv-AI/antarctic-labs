 ABSTRACT
This technical memorandum documents an update to the building use-type classification workflow, used in
LandScan Mosaic, that replaces a fixed, semantically defined class schema with a learnability-first schema
discovery procedure. Historically, the target label schema was specified a priori (e.g., predicting a chosen
set of use-type codes), and model training and evaluation were performed within that fixed label space. In
the updated workflow, the pipeline first evaluates which non-residential distinctions are learnable under
spatial generalization and then collapses ambiguous classes into data-driven groupings before finalizing the
schema used for production training.
A demonstration is presented for Argentina using a two-million-row read from a collapsed building
table and morphology features. Schema discovery is performed on a 100,000-row sample using spatial
cross-validation (admin2 GroupKFold), followed by A/B evaluation of the original fixed schema versus
the discovered schema under spatial CV, random stratified CV, and group holdout (train-groups to
holdout-groups). Results show substantial improvements in balanced accuracy and macro-F1 under the
discovered schema, with minimal change in overall accuracy (dominated by the residential class). The
principal production tradeoff is increased country-to-country schema inconsistency, offset by improved
model performance and improved learnability-aligned label definitions.

 1. INTRODUCTION
Historically, LandScan Mosaic building use-type models relied on a fixed schema chosen based on
semantic intent: the team selected which classes to predict, then trained and evaluated models within that
predetermined label space. While operationally simple, this approach can force the model to distinguish
classes that are not consistently separable given available features and label noise, particularly under
spatial generalization.
This update introduces schema discovery: a learnability-first step that determines which distinctions
are learnable before setting the final prediction schema. In practice, the workflow evaluates performance
on the non-residential subset under spatial CV and selects a collapsed label mapping that improves
learnability-aligned metrics (e.g., macro-F1 and balanced accuracy). The final schema is then used for
full-data training and export of production artifacts.

 3. METHODS
3.1 EVALUATION MODES
Three evaluation modes are used:
 • Spatial CV: GroupKFold by admin2 to assess spatial generalization.
 • Random Stratified CV: a non-spatial reference.
 • Group Holdout: hold out a subset of admin2 groups entirely (train-groups → holdout-groups).

3.2 SCHEMA DISCOVERY PROCEDURE
Schema discovery is performed on the non-residential subset:
 1. Compute spatial out-of-fold predictions for non-residential classes.
 2. Enumerate candidate semantic collapse mappings (e.g., CIVIC vs COMMERCE groupings).
 3. Score candidates using an equal-weight combination of normalized negative log-likelihood (NLL)
 and macro-F1:
 score = 0.5 · NLLnorm − 0.5 · F1norm
 where lower is better.
 4. Select the best collapse mapping and apply it to the all-codes schema, while keeping residential
 separate.

3.3 DISCOVERED SCHEMA
Semantic groups used are the same eight categories employed by the LandScan mosaic project: 0100
(residential), 0200 (institutional), 0300 (retail), 0400 (commercial), 0500 (transportation),
0600 (military), 0700 (recreation), 0800 (agriculture). The discovered non-residential
schema is:
   • NONRES_CIVIC(0200+0500+0600)
   • NONRES_COMMERCE(0300+0400+0700)
 • 0800
The resulting all-codes schema becomes:

 {0100, NONRES_CIVIC, NONRES_COMMERCE, 0800}.

 5. FINAL EVALUATION USING ALL LABELED DATA FOR COUNTRY
To characterize expected performance under a full-scale operational training run, we trained the use-type
model using all available Argentina training data under the collapsed, learnability-driven schema and
evaluated using a standard random 80/20 holdout split. This experiment is intended to quantify the
impact of increased training volume (relative to the 2M-row demonstration) on both overall accuracy and
minority-class behavior, and to provide an approximate upper-bound on within-country performance when
train and test samples share similar geographic and feature distributions. Because this evaluation does
not enforce spatial separation of administrative units, the resulting metrics are expected to be optimistic
relative to spatial cross-validation and admin2 group holdout tests; those spatial evaluations remain the
primary indicators of geographic transfer performance.

 6. ENGINEERING AND PRODUCTION IMPLICATIONS
6.1 BENEFITS
Schema discovery materially improves learnability-aligned performance metrics (macro-F1 and balanced
accuracy) under spatial CV and group holdout, indicating more reliable non-residential differentiation in
settings that resemble real transfer.

6.2 TRADEOFFS
The primary tradeoff is inconsistent schema country-by-country and more coarse semantic use-type
classes. While Argentina’s discovered schema merges 0400 into a broader commerce grouping, other
countries may produce different collapse mappings depending on label quality, class support, and feature
separability. This impacts:
 • global harmonization and downstream analytics,
 • QA dashboards and reporting,
 • cross-country comparability unless a canonical mapping is maintained.

 8

 7. CONCLUSIONS
The Argentina demonstration shows that a learnability-first schema discovery workflow can improve
non-residential separability under spatial generalization while preserving overall accuracy. The approach
introduces a production tradeoff: schema inconsistency across countries. This provides a scalable path to
higher-confidence use-type outputs in building use type attribution.
