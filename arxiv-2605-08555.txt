Entropy of pebble and space complexity
J. Andres Montoya

Abstract
Let ℒ \mathcal{L} denote the class Logspace and 𝒩 ​ ℒ \mathcal{NL} the class NLogspace. We use log ⁡ 𝒞 ​ ℱ ​ ℒ \log\mathcal{CFL} to denote the closure under logspace reductions of the set of context-free languages. We prove that 𝒩 ​ ℒ ≠ log ⁡ 𝒞 ​ ℱ ​ ℒ \mathcal{NL}\neq\log\mathcal{CFL} . This result implies ℒ ≠ P \mathcal{L}\neq\mathrm{P} and the stronger separation 𝒩 ​ ℒ ≠ P \mathcal{NL}\neq\mathrm{P} .



Keywords:

Computational complexity, Logspace, Context-free languages,
Entropy, Pebble automata.

The connection with entropy is based on the following naive idea: languages
that force automata accepting them to store high-entropy random variables
are languages that require large work tapes. Let us briefly discuss this

Let

\mathcal{L}
,
\mathcal{NL}
, and the pebble hierarchy

Let
k\geq 0
. Deterministic
k
-pebble automata are deterministic two-way
finite state automata provided with
k
labeled pebbles, which the finite
control can use as markers on the input tape. The study of this restricted
type of Turing machine goes back to Kreider and Ritchie
[
3
]
.

Definition 4
.

Let
k\geq 0,
a deterministic
k
-pebble automaton is
a tuple

\mathcal{M}=\left(Q,q_{0},\Sigma,A,\delta\right),

where:

1.

Q
is a finite set of states.

2.

q_{0}\in Q
is the initial state.

3.

A\subseteq Q
is the set of accepting states.

4.

\Sigma
is the input alphabet.

5.

The transition function

\delta:Q\times\Sigma\times\left(\mathcal{P}\left(\left\{1,...,k\right\}\right)\right)^{2}\rightarrow Q\times\left(\mathcal{P}\left(\left\{1,...,k\right\}\right)\right)^{2}\times\left\{-1,0,1\right\}

is deterministic.

Let
\mathcal{M}
be a
k
-pebble automaton. Automaton
\mathcal{M}
is a
two-way deterministic finite state automaton provided with
k
labeled
pebbles. This automaton has the following capabilities:

•

It can place its pebbles on the tape.

•

It can sense the pebbles that lie on the current cell.

•

It can pick specific pebbles from the set of pebbles that lie on the
current cell.

Let
\left(q,a,B,C\right)
be a tuple such that
B
and
C
are disjoint
subsets of
\left\{1,...,k\right\}.
Suppose that
\mathcal{M}
is
processing the input
w.
Suppose that:

•

q
is the current inner state.

•

a
is the character being scanned.

•

B
is the set of pebbles that are placed on the current cell.

•

C
is the set of available pebbles.

Suppose
\delta\left(q,a,B,C\right)=\left(p,D,K,\varepsilon\right).

Then:

•

B\cup C=D\cup K,

•

\mathcal{M}
change its inner state from
q
to
p,

•

\mathcal{M}
places the pebbles belonging to
D
(and only these
pebbles) on the current cell, and

•

\mathcal{M}
moves its head in the direction indicated by
\varepsilon\in\left\{-1,0,1\right\}
.

Let
\mathcal{M}
be a deterministic pebble automaton and let
w
be an
input of
\mathcal{M}
. We say that
\mathcal{M}
accepts
w
if this input
leads the automaton to an accepting state.

Definition 5
.

We use
\mathcal{REG}_{m}
to denote the class of languages accepted by
deterministic
m
-pebble automata.

The
deterministic pebble hierarchy
is the chain of inclusions:

\mathcal{REG}_{0}\subseteq\mathcal{REG}_{1}\subseteq\mathcal{REG}_{2}\subseteq\cdots

We have the following result:

Theorem 6
.

The equality

\mathcal{L}=\bigcup_{0\leq m}\mathcal{REG}_{m}

holds.

Proof.

Let
\mathcal{M}
be an
m
-pebble automaton. Observe that a single pebble
of
\mathcal{M}
can be simulated using a binary work tape of logarithmic
size. Hence, it is straightforward to construct a deterministic Turing
machine
\mathcal{N}
equipped with
m+1
work tapes of logarithmic size
that simulates
\mathcal{M}
. Therefore,

\bigcup_{0\leq m}\mathcal{REG}_{m}\subseteq\mathcal{L}.

We now prove the converse inclusion. Let
L\in\mathcal{L}
. Then there
exist an integer
m\geq 0
and a deterministic Turing machine

\mathcal{M}
such that:

•

\mathcal{M}
accepts
L.

•

\mathcal{M}
is provided with a read-only input tape and
m
binary
tapes of size
\left\lfloor\log\left(n\right)\right\rfloor-2
.

Let us prove that each one of those binary tapes can be simulated using
three pebbles. Let
w\in\Sigma^{n}
be the input of
\mathcal{M}
. Let us
focus on the
i
-th tape and let us consider the configuration reached by
this tape at instant
t.
We represent this configuration as a pair
\left(1n_{L},n_{R}1\right)\in\left(\left\{0,1\right\}^{\ast}\right)^{2}.

This pair tells us that
n_{L}n_{R}
is the work tape content, and it also
tells us that the head assigned to this tape is located on cell
\left|n_{L}\right|.
Let
\left(n_{R}1\right)^{R}
be the reverse of
n_{R}1.
Note that
1n_{L}
and
\left(n_{R}1\right)^{R}
are binary
strings whose lengths are bounded above by
\left\lfloor\log\left(n\right)\right\rfloor-1.
These binary strings encode two positive
integers
m_{L}
and
m_{R}
that belong to the interval
\left\{0,...,n-1\right\}
. We use this to represent the configuration
\left(1n_{L},n_{R}1\right)
using two pebbles that we call
1
and
2
. We assign
to pebble
1
the position
m_{L}
and to pebble
2
the position
m_{R}
.
We use these pebbles to simulate the changes occurring on tape
i.
Let us
suppose, for instance, that the transition function of
\mathcal{M}
forces
the head (of tape
i
) to move one cell to the left, after replacing with
0

the character
1
that was written on the current cell (which is cell
\left|n_{L}\right|
). Let
\left(1n_{L}^{\ast},n_{R}^{\ast}1\right)
be the configuration reached at time
t+1
. Let
m_{L}^{\ast}

and
m_{R}^{\ast}
be the corresponding integers. Notice that

m_{L}^{\ast}=\frac{m_{L}-1}{2}\text{ and }m_{R}^{\ast}=2m_{R}.

This means that we have to move pebbles
1
and
2,
from the positions
m_{L}
and
m_{R}
to the positions
\frac{m_{L}-1}{2}
and
2m_{R}.
This
can be done with the help of a third pebble. This means that we can simulate
this transition using three pebbles. Notice that we can simulate any other
transition of the
i
-th tape using the same three pebbles. This means that
we can replace tape
i
with three pebbles. This also means that we can
replace all the
m
work tapes of
\mathcal{M}
with
3m
pebbles. If we do
the latter, we obtain a deterministic
3m
-pebble automaton that accepts
L.

We get that
L\in\mathcal{REG}_{3m}
. We conclude that
\mathcal{L}
is
included in

\bigcup_{0\leq m}\mathcal{REG}_{m}.

The theorem is
proved.
∎

We want to construct a sequence
\left\{\text{RA}_{k}\right\}_{k\geq 0}\subseteq\mathcal{CFL}
and a language RA
{}_{\infty}\in\mathcal{CFL}

such that:

1.

\left\{\text{RA}_{k}\right\}_{k\geq 0}

∞

Definition 9
.

Let
\Sigma
and
\Omega
be two finite alphabets. Let
f
be a function
from
\Sigma
to
\Omega^{\ast}
. Let
\widehat{f}:\Sigma^{\ast}

\rightarrow

\Omega^{\ast}
be the function that is defined by the

\widehat{f}\left(w\right)=\left\{\begin{array}[]{c}\varepsilon\text{, if }w=\varepsilon\\
f\left(w\left[1\right]\right)\cdots f\left(w\left[\left|w\right|\right]\right)\text{, if }\left|w\right|>0\end{array}\right.

We say that
\widehat{f}
is a word morphism from
\Sigma^{\ast}
to
\Omega^{\ast}
, and any word morphism between these two free monoids is
defined this way from a function
f:\Sigma

\rightarrow

\Omega^{\ast}
.

Definition 10
.

Let
L\subset\Sigma^{\ast}
and
T\subset\Gamma^{\ast}
be two
languages. We say that
L
is an inverse image of
T
if and only if there
exists a word morphism
\widehat{f}:\Sigma^{\ast}\rightarrow

\Omega^{\ast}
such that
L=\widehat{f}^{-1}\left(T\right)
.

The class
\mathcal{CFL}
contains languages that are complete for
\mathcal{CFL}
under inverse images of
word morphisms
; see
[
1
]
.
This means that there exists
L_{G_{0}}\in\mathcal{CFL}
such that, for all

T\in\mathcal{CFL}
, the language
T
is an inverse image of
L_{G_{0}}

under a word morphism. We use
L_{G_{0}}
to denote
Greibach hardest
context-free language
; see
[
1
]
.

We have:

Theorem 11
.

Let
k\geq 0,
the set
\mathcal{NREG}_{k}
is closed under inverse images
of word morphism.

Proof.

Suppose
L\subset\Sigma^{\ast}
is an inverse image of
T\subset\Gamma^{\ast}
and suppose
T\in\mathcal{NREG}_{k}
. We prove that
L\in\mathcal{NREG}_{k}
.

Let
\mathcal{M}
be a nondeterministic
k
-pebble automaton accepting
T\subset\Gamma^{\ast}.
Let
f:\Sigma\rightarrow\Gamma^{\ast}
be a
function such that
L=\widehat{f}^{-1}\left(T\right).
We construct a
nondeterministic
k
-pebble automaton
\mathcal{S}
that receives as input
w\in\Sigma^{n}
and simulates the computation of
\mathcal{M}
, on input
\widehat{f}\left(w\right).

Let

N_{0}=\max\left\{\left|f\left(a\right)\right|:\text{ }a\in\Sigma\right\}

Let
Q
be the set of states of
\mathcal{M}.
The set of states of
\mathcal{S}
is equal to

Q\times\left\{0,\ldots,N_{0}\right\}^{k+1}.

We use this set of states to simulate
\mathcal{M}
. Recall that

\widehat{f}\left(w\right)=f\left(w\left[1\right]\right)\cdots f\left(w\left[n\right]\right)

Thus, suppose:

•

\mathcal{M}
is in state
q
,

•

the input head is placed on the
r
-th character of the
i
-th factor
(i.e., factor
f\left(w\left[i\right]\right)
),

•

the set of available pebbles is
B\subseteq\left\{1,\ldots,k\right\},
and

•

given
j\notin B,
the pebble
j
is placed on the
r_{j}
character
of the
l_{j}
factor.

Then:

•

\mathcal{S}
is in state
\left(q,r,s_{1},\ldots,s_{k}\right)
,
with:

s_{i}=\left\{\begin{array}[]{c}r_{i}\text{, }i\notin B\\
0\text{, }i\in B\end{array}\right.,

•

the input head is placed on the
i
-th cell,

•

the set of available pebbles is
B
, and

•

for all
j\notin B
, the pebble
j
is placed on the
l_{j}
-th cell.

The set of accepting states is the set:

\left\{\left(q,r,s_{1},\ldots,s_{k}\right):q\in A\right\}.

The transition function is defined accordingly.

It is easy to check that the above construction works. We conclude that
\mathcal{NREG}_{m}
is closed under inverse images of word morphism. The

High sequences of context-free languages

We showed that
\mathcal{NL}\neq\log\mathcal{CFL}
is equivalent to the
existence of

in
\mathcal{CFL}
. We try an inductive

Definition 14
.

Let
\Sigma,\Gamma
be two finite alphabets and let
\#\notin\Sigma\cup\Gamma
. A bi-string over
\left(\Sigma,\Gamma,\#\right)
is a string

w_{1}\#r_{1}\#\cdots\#w_{n}\#r_{n}

such that
w_{1},\ldots,w_{n}\in\Sigma^{\ast}
; and
r_{1},\ldots,r_{n}\in\Gamma^{\ast}
. We use
s\left(w,r\right)
as a shorthand for
the bi-string

w_{1}\#r_{1}\#\cdots\#w_{n}\#r_{n}.

We say that
w_{1},\ldots,w_{n}
are the
local factors
of
s\left(w,r\right)
and we say that
r_{1},\ldots,r_{n}
are the local co-factors
of this bi-string.

Definition 15
.

Let
T\subset\Sigma^{\ast}
and let
w\in\Sigma^{\ast}
. Define:

\varepsilon^{T}\left(w\right)=\left\{\begin{array}[]{c}1\text{, if }w\in T\\
0\text{, otherwise}\end{array}\right.

We say that
\varepsilon^{T}\left(w\right)
is the characteristic bit
(with respect to
T
) of the string
w
.

Definition 16
.

Let
r=r_{1}\cdots r_{n}
. Let
I=\left\{i_{1},\ldots,i_{k}\right\}
be a
subset of
\left\{1,\ldots,n\right\}
. Suppose
i_{1}<\cdots<i_{k}
. We
use
\bigodot_{i\in I}r_{i}
to denote the substring

r_{i_{1}}\cdots r_{i_{k}}
.

Definition 17
.

Let
L\subseteq\Sigma^{\ast}
,
T\subseteq\Gamma^{\ast}
, and

\#\notin\Sigma\cup\Gamma
. We define the language

T\otimes_{\pi}L
as the set of all bi-strings

w_{1}\#r_{1}\#\cdots\#w_{n}\#r_{n}

that satisfy the condition

\bigodot_{i\in T(w)}r_{i}\in L,

where:

T\left(w\right)=\left\{i\leq n:\varepsilon^{T}\left(w_{i}\right)=1\right\}.

We say that
T\otimes_{\pi}L
is the masked concatenation of
L
over
T
.

Theorem 18
.

Let
L,T\in\mathcal{CFL}
. The language
T\otimes_{\pi}L
belongs to
\mathcal{CFL}
.

Proof.

Let
\mathcal{A}
and
\mathcal{B}
be pushdown automata accepting
L
and
T.
Let
\Theta
and
\Delta
be the work alphabets of these automata. We
suppose that those alphabets are disjoint. We construct a pushdown automaton

\mathcal{N}
accepting
T\otimes L
. The work alphabet of
\mathcal{N}
is
\Theta\cup\Delta.

Let

s\left(w,r\right)=w_{1}\#r_{1}\#\cdots\#v_{n}\#r_{n}

be an input of
\mathcal{N}
. The automaton works on that input as follows:

Let
i\leq n
. Suppose that
\mathcal{N}
is starting to process the factor

Automaton

8
Rectangles, digraph accessibility, and the language RA

Corollary
45
reduces the problem of proving the
separation
\mathcal{NL}\neq\log\mathcal{CFL}
to that of constructing a
context-free language that is crossing-hard. We construct a context-free
language, denoted RA, and show that it is crossing-hard. This language is closely
related to the digraph accessibility problem.

Definition 46
.

Let
G
be a digraph. We say that

is a rectangle of depth
k

1.

V\left(G\right)=\left\{1,\ldots,n\right\}\times\left\{1,\ldots,k+1\right\}.

2.

If
\left(\left(i,j\right),\left(r,t\right)\right)\in E\left(G\right)
the equality

holds.

Rectangles are
layered digraphs
with edges directed strictly
between successive layers (levels). It is worth recalling that the
restriction of digraph accessibility to the class of layered digraphs is
\mathcal{NL}
-complete; see
[
2
]
. One can verify that the
restriction of this latter problem to the class of rectangles is also
\mathcal{NL}
-complete.

Definition 47
.

Let
G
be a rectangle of depth
k
. We say that
G
is crossable if there
exists a path from the first level of
G
(i.e., the set
\left\{1,...,n\right\}\times\left\{1\right\}
) to the level
k+1
.

Definition 48
.

Let
G
be a rectangle of depth
k
. We encode
G
as follows:

•

Let
s<k+1
and let

l\left(s\right)=\left\{\left(\left(i_{1},s\right),\left(j_{1},s+1\right)\right),...,\left(\left(i_{m_{s}},s\right),\left(j_{m_{s}},s+1\right)\right)\right\}

We define:

r_{s,l\left(s\right)}=1^{i_{1}}01^{j_{1}}0\cdots 01^{i_{m_{s}}}01^{j_{m_{s}}}.

•

We set
w_{G,l}=r_{1,l\left(1\right)}\$\cdots\$r_{k,l\left(k\right)}\$
.

Let
G
be rectangle of depth
k.
Suppose
w_{G,l}=r_{1,l\left(1\right)}\$\cdots\$r_{k,l\left(k\right)}\$
. Notice that

is the concatenation
of
k

1
, the rectangles encoded by the strings
r_{1,l\left(1\right)}\$,\ldots,r_{k-1,l\left(k-1\right)}\$

.

Remark 49
.

Let
n
be a large integer. Let
G
be a rectangle of depth
1
and width
\left\lfloor n^{\frac{1}{4}}\right\rfloor

is no longer than

Then there exists a code-word

such that
\left|w_{G,l}\right|\leq n

\left\lfloor n^{\frac{1}{4}}\right\rfloor
.

Definition 50
.

We use RA to denote the following context-free language

\left\{w_{G,l}\in\left\{0,1,\$\right\}^{\ast}:G\text{ is crossable}\right\}.

We have:

Theorem 51
.

RA is a context-free language.

Proof.

Let
w_{1}\$\cdot\cdots\$w_{k}\$
be an instance of RA. This instance
belongs to RA if and only if there exists factors
1^{i_{1}}01^{j_{1}},\ldots,1^{i_{k}}01^{j_{k}}
such that:

1.

1^{i_{1}}01^{j_{1}}
is a factor of
w_{1},
…
,

1^{i_{k-1}}01^{j_{k-1}}
is a factor of
w_{k-1}
, and
1^{i_{k}}01^{j_{k}}

is a factor of
w_{k}
.

2.

j_{1}=i_{2},\ldots,j_{k-2}=i_{k-1}
, and

It is easy to build a nondeterministic pushdown automaton that guesses those

∎

We set RA
{}_{\infty}=L_{G_{0}}
, we have:

1.

RA

\left\{\text{RA}_{k}\right\}_{k\geq 0}
.

2.

If RA is crossing-hard the sequence
\left\{\text{RA}_{k}\right\}_{k\geq 0}

8.1
Decorated versions of RA

From now, we study the crossing complexity of RA. We aim to show that RA is
crossing-hard. Let us observe that this problem is a question about the

of 2NFAs.

Definition 52
.

Let

The next proposition is straightforward.

Proposition 53
.

Suppose

\left[\frac{m}{2}+1\right]_{m}=11\left(10\right)^{\frac{m}{2}-1}

\left[\frac{m}{2}+2\right]_{m}=1111\left(10\right)^{\frac{m}{2}-2}.

.

We define:

•

.

For all

, the following inequality holds:

\mathcal{M}

∎

We show, in Section

9
On the crossing complexity of pattern matching

We are interested in the crossing complexity of digraph accessibility (the crossing complexity of the language RA). This leads us to study the crossing complexity of pattern
matching:

1.

We show that a promise problem related to pattern matching is crossing

2.

Let

.

Theorem 60

For all

to

be its set of crossing states. Let

) to right (

such

•

and

•

f_{w,\mathcal{M}_{n}}=

f_{u,\mathcal{M}_{n}}
.

Let
j\notin S\left(w\right)\cap S\left(u\right)
and let
\mathbf{\gamma}=\left\langle j\right\rangle_{\left\lfloor\log\left(n\right)\right\rfloor}
. Set
w^{\ast}=\mathbf{\gamma}\#1^{n_{1}}\#\cdots\#1^{n_{k}}
and
u^{\ast}=\mathbf{\gamma}\#1^{s_{1}}\#\cdots\#1^{s_{t}}.

Let us consider these two inputs. We have:

1.

w^{\ast}\in PM_{n}^{+}\Leftrightarrow u^{\ast}\notin PM_{n}^{+}

2.

The automaton accepts both inputs or rejects both.

This is a contradiction. We conclude that there exists an injective function
from
\mathcal{P}\left(\left\{1,...,2^{\left\lfloor\log\left(n\right)\right\rfloor}\right\}\right)
into
\left(2^{Q_{c}}\right)^{Q_{c}}
.
This entails the inequality

\left\|\mathcal{M}_{n}\right\|_{c}\geq\left(\frac{n}{2}\right)^{\frac{1}{2}}.

The theorem follows.
∎

In the next section, we show that a 2NFA separating
POS_{n}^{\ast}\left(\text{RA}\right)
from
NEG_{n}^{\ast}\left(\text{RA}\right)
requires
as many states as a 2NFA solving the problem
PM_{n^{\frac{1}{4}}}
. This
implies that RA is crossing-hard.

10
The language RA is crossing-hard

In this section, the last section of this work, we prove that RA is

\mathcal{NL}\neq\log\mathcal{CFL}
.

Definition 61

Proposition 62
.

Let

.

Let

Let
n\geq 1
and let
\mathcal{M}_{n}

\mathbf{\varepsilon}\neq 0^{\ast}
. Let

on

\displaystyle\left\{1,\ldots,\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor\right\}.

•

Suppose
\mathcal{M}_{n}
is in state
q
scanning the
i
-th position
of
X\#11\left(10\right)^{\ast}\$
. Then,
\mathcal{N}_{n}
is in state
\left(q,i,\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor\right)

\left|\mathbf{\varepsilon}\#\right|+1.

•

Suppose
\mathcal{M}_{n}
is in state
q

i
-th position

\mathcal{N}_{n}

\left(q,\left|X\#11\left(10\right)^{\ast}\$\right|+1,\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor\right)

•

\mathcal{M}_{n}
is in state
q
scanning the
i
-th position

. Then,
\mathcal{N}_{n}

is in state

\left(q,\left|X\#11\left(10\right)^{\ast}\$\right|+1+i,\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor\right)

•

Let
\delta=0,1
. Suppose
\mathcal{M}_{n}
is in state

10.2
From pattern matching to rectangle traversing

Let
n\geq 2.
We show that there exist two strings
X_{n},Y_{n}\in\left\{0,1,\#,\$\right\}^{\ast}
such that:

1.

X_{n}
avoids the pattern
\#11\left(10\right)^{\ast}\$
and
Y_{n}
avoids the pattern
\#1111\left(10\right)^{\ast}\$
.

2.

If
\mathcal{M}
is a 2NFA that separates
POS_{n}^{\ast}\left(\text{RA}\right)
from
NEG_{n}^{\ast}\left(\text{RA}\right)
, then this same
automaton solves the
promise problem

LOC_{n}\left(X_{n},Y_{n}\right)
.

We construct
X_{n}
and
Y_{n}
in such a way that every positive instance
of
LOC_{n}\left(X_{n},Y_{n}\right)
, say

Z=\mathbf{\varepsilon}^{\left(2\right)}111X_{n}\#11\left(10\right)^{\ast}\$\mathbf{1}^{n_{1}}\mathbf{0\cdots 01}^{n_{m}}\#1111\left(10\right)^{\ast}\$Y_{n},

is an element of
POS_{n}^{\ast}\left(\text{RA}\right)
and every
negative instance is an element of
NEG_{n}^{\ast}\left(\text{RA}\right)

1.

If we view
Z
as an instance of
LOC_{n}\left(X_{n},Y_{n}\right),

the problem we are considering is the problem of deciding whether we can
find the pattern
\mathbf{\varepsilon}
within the set
\left\{n_{1},\ldots,n_{m}\right\}.
Here,
\mathbf{\varepsilon}
acts as a
pattern.

2.

If we view
Z
as an element of
POS_{n}^{\ast}\left(\text{RA}\right)\cup NEG_{n}^{\ast}\left(\text{RA}\right)
, the problem we are
considering is the problem of deciding whether the rectangle encoded by
Z

can be crossed from left to right. Here,
\mathbf{\varepsilon}
acts as
part of a mask.

Then, we have to build a gadget that converts masks into patterns. Given
n\geq 32,
we construct a gadget
B_{n}
that fulfills this function.

Definition 67
.

Let
n\geq 32.
The construction of
B_{n}
proceeds as
follows:

1.

Given
1\leq i\leq\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor
, we choose a word
r_{2i-1}\in\left\{0,1\right\}^{\leq n}

encoding the rectangle
G_{i,1}
that is defined by:

•

V\left(G_{i,1}\right)=\left\{1,\ldots,2^{\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}\right\}\times\left\{1,2\right\}
.

•

E\left(G_{i,1}\right)=\left\{\left(\left(s,1\right),\left(s,2\right)\right):\text{the }i\text{-th bit of }\left\langle s\right\rangle_{\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}\text{ is equal to }1\right\}
.

2.

Given
1\leq i\leq\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor
, we choose a word
r_{2i}\in\left\{0,1\right\}^{\leq n}

that encodes the even version of
G_{i,1}
, namely the rectangle
G_{i,0\text{ }}
defined by the following dual condition:

E\left(G_{i,0}\right)=\left\{\left(\left(s,1\right),\left(s,2\right)\right):\text{the }i\text{-th bit of }\left\langle s\right\rangle_{\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}\text{ is equal
to }0\right\}.

3.

We set:

B_{n}=r_{1}\$\cdots\$r_{2\cdot\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}\$.

Definition 68
.

Let
\mathbf{\varepsilon}\in\left\{0,1\right\}^{\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}
. We use
i_{\mathbf{\varepsilon}}
to
denote the integer in
\left\{1,...,2^{\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}\right\}

\left\langle i_{\mathbf{\varepsilon}}\right\rangle_{\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}=\mathbf{\varepsilon}

Lemma 69
.

Let
\mathbf{\varepsilon}\in\left\{0,1\right\}^{\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}
and let
B_{n}\left(\mathbf{\varepsilon}\right)
be the rectangle encoded by the
string

\bigodot_{i\leq 2\lfloor\tfrac{\log(n)}{4}\rfloor:\,\boldsymbol{\varepsilon}^{\oplus}[i]=1}r_{i}\$.

The only node in the last level of
B_{n}\left(\mathbf{\varepsilon}\right)
that can be reached from the first level is the node
\left(i_{\mathbf{\varepsilon}},\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor+1\right).

Proof.

Let
\mathbf{\varepsilon}\in\left\{0,1\right\}^{\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}
. Notice that:

1.

The rectangle
B_{n}\left(\mathbf{\varepsilon}\right)
is the rectangle of depth

\lfloor\log(n)/4\rfloor

encoded by the string

\bigodot_{i\leq\lfloor\log(n)/4\rfloor}G_{i,\boldsymbol{\varepsilon}[i]}\$.

2.

Suppose that there exists a path from the first layer of
B_{n}\left(\mathbf{\varepsilon}\right)
to the node
\left(s,\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor+1\right).
This path is equal to

\left(s,1\right),\left(s,2\right),\ldots,\left(s,\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor+1\right).

3.

For all
i\leq\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor
and all
s\in\left\{1,\ldots,2^{\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}\right\}
, the edge
\left(\left(s,i\right),\left(s,i+1\right)\right)
occurs in
B_{n}\left(\mathbf{\varepsilon}\right)
if and only if

\mathbf{\varepsilon}\left[i\right]=\left\langle s\right\rangle_{\left\lfloor\frac{\log\left(n\right)}{4}\right\rfloor}\left[i\right].

The lemma follows from these three facts.

Main theorem

We have:

Theorem 70
.

For all
