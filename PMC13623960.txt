Fundamental kinematic indicators predict surgical expertise and clinical outcomes in robot-assisted surgery

Hideto Ueki, Takuto Hara, Tomoko Yamaguchi, Naoto Wakita, Yasuyoshi Okamura, Kotaro Suzuki, Yukari Bando, Kiyoyuki Chinzei, Munenori Uemura, Tomoaki Terakawa, Akihisa Yao, Koji Chiba, Jun Teishima, Hideaki Miyake

Abstract

The global proliferation of robotic surgical platforms necessitates a framework for objective skill assessment using fundamental kinematic features that are theoretically extractable from any robotic system with 3D position tracking. Here, we demonstrated that fundamental three-dimensional movement patterns alone can accurately distinguish surgical expertise and show associations with clinical outcomes. A Random Forest classifier discriminated expertise with high case-wise accuracy (area under the curve 0.892 ± 0.075), and feature-importance analysis identified left-hand peak density as the principal discriminator. A small set of these fundamental indicators generalized to unseen surgeons in leave-one-surgeon-out validation, localizing the expertise-associated signal to a few interpretable kinematic measures. Kinematic patterns were correlated with clinical outcomes, and exploratory analysis revealed associations between movement features and blood loss. Individual learning curve analysis revealed heterogeneous adaptation patterns among experts transitioning to the new platform and identified distinct phenotypes with implications for personalized training. These findings show that fundamental kinematic analysis using only three-dimensional positional data can provide interpretable indicators of surgical performance that may extend across robotic systems providing coordinate data.

Introduction

The integration of artificial intelligence with robotic surgery offers unprecedented opportunities for objective performance assessment through the automated capture of high-fidelity movement data. Comprehensive platform-specific metrics from established systems, such as the da Vinci, have exhibited strong correlations with clinical outcomes–; however, this approach faces fundamental limitations as diverse robotic platforms have emerged globally–. Each system’s proprietary data architecture presents barriers to standardized evaluation; yet, all systems must capture basic end-effector positions for control purposes.

According to motor learning theory, surgical expertise is expressed through fundamental movement patterns that are independent of the specific interface used. Evidence from laparoscopic surgery shows that simple metrics, such as path length, movement smoothness, and completion time, are strongly correlated with experience and outcomes. This raises a critical question: Can positional data alone offer sufficient information for accurate skill assessment while enabling cross-platform generalizability?

The Hinotori Surgical Robot System, Japan’s first nationally developed platform, offers an ideal test bed for this hypothesis–. Its system architecture allows for the extraction of three-dimensional coordinate data, facilitating the investigation of movement-based assessment methods. In this study, using the Hinotori surgical robot system as an initial platform, we investigated whether kinematic signatures captured solely through position data could discriminate expertise levels and predict clinical outcomes, thereby exploring the potential for a generalizable framework applicable across robotic platforms that provide access to coordinate data.

Results

Cohort characteristics and surgical expertise distribution

The analysis involved 98 robot-assisted radical prostatectomy procedures with complete kinematic data capture during vesicourethral anastomosis. Sixteen surgeons performed the cases (range: 1–18, median: 6, interquartile range (IQR) 2–14), with certified proctors conducting 68 procedures (69.4%) and non-proctors 30 procedures (30.6%). Patient demographics did not differ significantly between the groups (Table ), supporting that outcome variations are attributable to surgical technique rather than case-selection bias.

Movement quality as an indicator of surgical expertise

The left peak density emerged as the most powerful discriminator of expertise (Fig. ).

Proctor surgeons demonstrated significantly higher movement consistency, with a left peak density of 0.087 ± 0.005 compared with 0.079 ± 0.005 in non-proctors (d = 1.618, p < 0.001), representing a 10.1% higher frequency of velocity peaks (Table , Supplementary Data ). Movement smoothness metrics also exhibited strong discrimination: dimensionless jerk for left hand [(4.3 ± 2.3) × 105 vs (7.8 ± 3.3) × 105 (d = 1.314, p < 0.001)] and right hand [(4.2 ± 2.2) × 105 vs (7.3 ± 3.0) × 105 (d = 1.249, p < 0.001)], indicating 44% smoother movements in proctor surgeons. Temporal efficiency demonstrated a comparable effect size, with anastomosis times of 45.5 ± 16.1 min for proctors versus 67.8 ± 18.8 min for non-proctors (d = 1.313, p < 0.001), reflecting a 32.9% reduction. Fifteen of the 25 features (60%) achieved statistical significance after false discovery rate correction (Table , Supplementary Data ). Notably, speed variability metrics showed strong bilateral discrimination, with a right speed coefficient of variation (d = 1.041) and left speed coefficient of variation (d = 0.873), both p < 0.001 (Fig. ). Left- and right-hand features exhibited differential effect sizes across feature categories: left-hand features showed stronger discrimination for movement-pattern metrics (peak density and movement sharpness) and path length, whereas right-hand features showed stronger discrimination for speed-related metrics and dwell time (Fig. , Table ).

Machine learning validates objective expertise classification

The Random Forest classifier demonstrated exceptional performance across multiple validation strategies (Fig. ). Twenty independent train-test splits yielded a mean area under the curve (AUC) of 0.892 ± 0.075, with five-fold cross-validation demonstrating a mean AUC of 0.882 (Fig. ). Precision-Recall analysis confirmed robust performance despite class imbalance (68 proctor vs 30 non-proctor), with an average precision of 0.940 (Supplementary Fig. ).

Because expertise is a surgeon-level attribute, we additionally evaluated generalization to unseen surgeons using leave-one-surgeon-out and surgeon-grouped cross-validation (Supplementary Data ). A small set of fundamental indicators generalized to unseen surgeons. Models restricted to the three highest-ranked features by importance (left peak density, right speed coefficient of variation, and anastomosis time) reached leave-one-surgeon-out AUC 0.788 (Random Forest) and 0.844 (logistic regression), with surgeon-grouped AUC 0.877 and 0.883, respectively, and left peak density alone, modeled as a single feature, discriminated at AUC 0.869. Because a single feature cannot encode multivariable surgeon-specific patterns, this provides the most leakage-resistant evidence that the expertise-associated signal generalizes across surgeons. By contrast, the full 25-feature Random Forest generalized less well to unseen surgeons (leave-one-surgeon-out AUC 0.571 versus a case-wise estimate of 0.888), indicating that its high case-wise performance partly reflected surgeon-specific patterns. The expertise-associated signal is therefore concentrated in a small set of fundamental indicators rather than in the full multivariable model. Feature importance analysis revealed movement pattern consistency (left peak density, 11.9%) as a highly predictive characteristic, followed by movement variability (right speed coefficient of variation, 11.1%) and anastomosis time (9.0%). The highest-ranked single feature was a left-hand metric (left peak density), consistent with the non-dominant hand's critical role in maintaining tissue tension and needle control during vesicourethral anastomosis (Fig. ). These features reflect fundamental movement characteristics that, in theory, can be extracted from any robotic system capable of providing 3D coordinate data.

Kinematic patterns and clinical outcomes

Partial correlation analysis, controlling for anastomosis time, was conducted on time-independent features to identify associations with clinical outcomes beyond task duration (Table , Supplementary Data ). Left movement sharpness correlated with estimated blood loss (r = 0.202, p = 0.046), as did left workspace volume (r = 0.204, p = 0.044). In an exploratory analysis of a small number of patients with anastomotic leaks (n = 5), movement-related features exhibited larger effect sizes compared with those in patients without leaks (Table ). Proctor surgeons achieved shorter console times (227.6 ± 78.4 vs 281.4 ± 76.9 min, p = 0.008) with comparable blood loss rates (150.6 ± 187.3 vs 203.0 ± 305.1 mL, p = 0.975) (Table ). At 3 months, the continence recovery rate was 46.2% for proctors compared with 23.3% for non-proctors (p = 0.058), with differences diminishing by 6 months (58.5% vs. 53.3%, p = 0.805) (Supplementary Fig. ).

Heterogeneous learning trajectories define expert adaptation

The two certified proctors exhibited distinct adaptation patterns on the Hinotori platform (Fig. ). Surgeon A (n = 18) showed progressive changes, with a 25.7% reduction in anastomosis time, an 18.5% increase in speed correlation, and a 50.8% decrease in left workspace volume. Surgeon B (n = 14) maintained consistent performance metrics from the first case. The greatest differences between the two surgeons were observed in bimanual coordination metrics. Surgeon A improved bilateral dwell time by 8.7%, while Surgeon B showed a 4.8% increase. For speed correlation, Surgeon A demonstrated an 18.5% improvement, whereas Surgeon B exhibited a 7.4% decrease.

Sensitivity analyses

Sensitivity analysis assessing model robustness to individual surgeon effects confirmed stable classification performance across different surgeon inclusion/exclusion scenarios, with AUC values ranging from 0.86 to 0.91 (Supplementary Fig. ). Performance was maintained even when excluding the highest-volume non-proctor surgeon who contributed 16 of the 30 non-proctor cases (AUC = 0.86), indicating that the case-wise result is not attributable to any single dominant surgeon. This inclusion/exclusion analysis (Supplementary Fig. ) is distinct from the surgeon-held-out validation reported above and does not by itself assess generalization to unseen surgeons. Excluding the jerk-based features changed case-wise performance only minimally (delta AUC approximately 0.01), consistent with their strong correlation with task duration and path length, which left little information independent of the retained features. Power analysis demonstrated 95.1% power to detect effect sizes with d > 0.8. The mean observed effect size among significant features was 0.94 (Supplementary Fig. , Supplementary Data ).

Discussion

In this study, it was established that fundamental movement patterns derived from three-dimensional coordinates provide sufficient information for accurate surgical skill assessment, achieving performance comparable to that of comprehensive platform-specific approaches while offering potential applicability across platforms with position-tracking capability. Our findings highlight three key insights: (1) movement pattern consistency (peak density) and smoothness serve as robust kinematic indicators of surgical expertise; (2) machine learning based on just 25 kinematic features can accurately classify expertise levels; and (3) expert surgeons display heterogeneous adaptation patterns when transitioning between platforms.

The concentration of discriminative power in movement patterns, particularly peak density (d = 1.618), is consistent with established motor-learning principles,–. Peak density was defined operationally as the frequency of local peaks in the hand-speed profile. We do not interpret higher peak density as skillful rhythmicity in isolation, because repetitive velocity peaks could also arise from mechanical or strategically inefficient motion. During vesicourethral anastomosis these peaks plausibly correspond to recurring submovements such as needle driving, suture handling, and hand repositioning, although coordinate-only data do not segment these gestures directly. Peak density partially overlapped with efficiency (correlation with task time, Spearman rho = −0.53) but was not reducible to task time alone. After adjustment for task time, it retained discrimination across unseen surgeons (residualized leave-one-surgeon-out AUC 0.771, partial correlation with expertise r = 0.45, p < 0.001), and combining it with task time improved unseen-surgeon discrimination from 0.869 to 0.885. We therefore interpret repeated movement structure together with efficiency rather than rhythmicity alone. We speculate that the observed pattern of reduced pausing (lower dwell time) combined with consistent speed (lower CV) in expert surgeons may reflect what has been described as ‘flow state’ in expertise research, though this interpretation remains conjecture requiring dedicated psychological assessment in future studies. Our finding that left peak density exhibited the strongest effect size likely reflects the non-dominant hand’s critical role in maintaining tissue tension and needle control during anastomosis.

Our approach, which relies solely on fundamental kinematic features, offers advantages over existing comprehensive assessment methods. Hung et al. achieved comparable discrimination between expert groups using over 40 automated performance metrics from the da Vinci system, including camera movements, clutch usage, and energy application patterns. Conversely, while the full 25-feature model matched comprehensive approaches in case-wise discrimination (AUC 0.892), it did not generalize to unseen surgeons; the generalizable signal was concentrated in a few fundamental indicators. This parsimony is essential as robotic systems proliferate globally and movement patterns, such as peak density and smoothness, reflect

fundamental neuromuscular control patterns that may transcend specific interfaces, whereas system-specific events can vary across platforms and software versions,,,. However, the availability of raw coordinate data varies across platforms, and further validation is needed to confirm the cross-platform applicability of our approach. Our coordinate-derived indicators should be interpreted as complementary to, rather than replacements for, expert video-based assessment tools such as GEARS. GEARS evaluates multidimensional robotic skill through expert review, including depth perception, bimanual dexterity, efficiency, force sensitivity, autonomy, and robotic control. In prior dVLogger work during robot-assisted radical prostatectomy, expertise was defined using case-volume thresholds, and blinded GEARS scoring was used for concurrent validation. During the vesicourethral anastomosis, that work found domain-specific concordance between automated kinematic metrics and GEARS, with time- and velocity-related metrics showing moderate associations with the GEARS efficiency domain,. These findings indicate that automated kinematic indicators and GEARS capture overlapping but non-identical constructs. Accordingly, we do not claim GEARS-level convergent validity for the present retrospective coordinate-only dataset. Future prospective studies should include blinded multi-rater GEARS assessment with inter-rater reliability analysis to define how coordinate-derived indicators map onto expert-rated technical domains.

The strong correlation between anastomosis time and total console time (r = 0.704, p < 0.001) warrants special consideration. Vesicourethral anastomosis represents only one phase of robot-assisted radical prostatectomy; however, we interpret it as an indicator of performance within this specific suturing-dominant phase rather than a proxy for overall procedural proficiency. This relationship likely reflects that surgeons who struggle with the technically demanding anastomosis phase may also encounter difficulties in other complex stages, such as nerve sparing or apical dissection–. The anastomosis phase offers distinct advantages for standardized assessment, as it requires consistent bimanual coordination, follows a predictable sequence, and directly influences functional outcomes. These characteristics make it a standardized, suturing-dominant phase suitable for objective, phase-specific skill evaluation–, enabling targeted assessment without the need to analyze entire procedures.

The association between movement quality metrics and clinical outcomes enables performance monitoring in practical settings. Institutions could adopt kinematic thresholds as preliminary benchmarks for future validation: maintaining a left peak density above 0.082, dimensionless jerk below 5.5 × 105, and speed coefficient of variation below 1.10 aligns with proctor-level performance (Supplementary Data ). These thresholds should be considered hypothesis-generating and require prospective validation before clinical application. The correlations between kinematic features and blood loss, while statistically significant (path length: r = 0.33, p < 0.001; jerk: r = 0.26, p < 0.01), are modest in magnitude, explaining approximately 7–11% of variance. This suggests that movement patterns during urethrovesical anastomosis have a detectable but limited association with overall blood loss. This modest effect size is clinically plausible, as the anastomosis phase represents only a portion of the total procedure, and blood loss is influenced by multiple factors including prostate vascularity and patient anatomy,. Shorter console times without increased complications indicate that efficiency does not compromise safety, a critical finding for training programs,. While our exploratory analysis of anastomotic leak cases (n = 5) revealed large effect sizes for movement features, the small sample size limits definitive conclusions. Our identification of distinct learning phenotypes among expert surgeons transitioning to the Hinotori platform represents a novel contribution of this study. The contrast between the progressive adapter pattern (Surgeon A: 25.7% improvement in anastomosis time, 50.8% reduction in workspace volume) and the immediate transfer pattern (Surgeon B: consistent performance from case one) challenges the assumption of uniform skill transfer among experts. The differential improvement in bimanual coordination ( + 18.5%) compared with the unilateral skills suggests platform-specific optimization requirements, even for experienced surgeons. This heterogeneity has important implications for platform adoption strategies. Institutions should consider implementing baseline kinematic assessments to identify surgeons who may require additional support during transitions.

Our approach, based on fundamental kinematic features, has the potential to democratize access to objective performance evaluation. As robotic systems proliferate globally, from China’s Micro Hand S– to Europe’s Versius and Hugo, platforms, the need for platform-agnostic assessment methods has become critical. By focusing on fundamental movements rather than on proprietary metrics, institutions with access to basic position-tracking data can potentially implement meaningful skill evaluations. This accessibility is especially important for emerging markets, where access to advanced analytics for specific platforms may be limited, yet the need for objective surgical assessment remains critical. An additional methodological analysis in this study was the explicit evaluation of generalization to unseen surgeons. Many prior automated performance metric studies used case-level validation designs appropriate to their original aims. Because kinematic patterns can encode surgeon-specific tendencies, we additionally applied surgeon-held-out validation, which provides a more stringent test of whether the expertise-associated signal transfers beyond the surgeons used for model development. To our knowledge, few coordinate-derived robotic skill studies have explicitly reported surgeon-held-out validation. This analysis showed that the high-dimensional classifier did not generalize on its own, whereas a small set of fundamental, interpretable indicators retained discrimination across unseen surgeons.

This study has certain limitations that warrant consideration. First, the analysis was confined to vesicourethral anastomosis, a single suturing-dominant phase performed at one institution on one robotic platform. It therefore does not capture tissue dissection, energy-device handling, or intraoperative judgment, and characterizes phase-specific performance rather than overall surgical proficiency. Validation across additional surgical phases, institutions, and robotic platforms is needed before claims of platform independence can be substantiated. Second, the correlation between dimensionless jerk and duration, although addressed through partial correlation analysis, warrants investigation using alternative smoothness metrics. The 1 Hz sampling frequency is well below that required for reliable third-order derivatives (30–60 Hz). Consequently, our jerk-based features are a coarse surrogate for movement smoothness and should be regarded as exploratory, and our principal conclusions accordingly rest on peak density, task time, and speed variability rather than on jerk-based measures. Third, the small number of anastomotic leak cases (n = 5) limits the reliability of the complication findings, although the observed effect sizes motivate investigation in larger cohorts. Fourth, expertise was defined by proctor certification rather than by expert video-based rating, and prospective convergent validation against established global rating scales such as GEARS remains a priority for future work. Finally, the parsimonious models were derived from 16 right-handed surgeons, and these results, together with long-term oncological outcomes, require prospective external validation in larger and mixed-handedness cohorts before any credentialing or training use. Future studies should focus on developing real-time intraoperative feedback, validating these findings across multiple platforms and surgical specialties, as well as conducting randomized trials of kinematic-based training interventions. Additionally, establishing international benchmarks for kinematic performance could help standardize surgical training globally. Validation on publicly available surgical skill datasets would enable direct comparison with other assessment methods.

In conclusion, kinematic analysis based solely on fundamental three-dimensional position data distinguished proctor-level performance, and a small set of interpretable indicators generalized to unseen surgeons. Because these indicators derive from position coordinates alone, they offer a potential route to platform-independent skill assessment that does not rely on proprietary metrics. Proctor-level performance was associated with greater operative efficiency, whereas associations with specific perioperative outcomes were exploratory and require confirmation. Prospective, multi-surgeon validation is needed before clinical deployment.

Methods

Study design and participants

In this retrospective observational study, we analyzed consecutive robot-assisted radical prostatectomies performed using the Hinotori Surgical Robot System (Medicaroid Corporation, Kobe, Japan) between December 2020 and November 2023 at Kobe University Hospital (Fig. ). The study protocol was approved by the Kobe University Hospital Institutional Review Board (approval number: B230172) in accordance with the Declaration of Helsinki. The requirement for written informed consent was waived by the Kobe University Hospital Institutional Review Board because this study was a retrospective analysis of routinely collected clinical and operative data, and all data were anonymized prior to analysis. Of 132 consecutive procedures, 98 (74.2%) had complete kinematic logs during vesicourethral anastomosis. The remaining 34 cases were excluded owing to technical logging failures, primarily network connectivity issues, during early adoption.

Surgeon stratification

Surgeons were classified as ‘Proctor’ (expert) or ‘Non-Proctor’ based on formal Proctor certification for robot-assisted urologic surgery in Japan. Proctor certification requires: (1) Board certification as a Japanese Urological Association certified specialist, (2) Membership in the Japanese Society of Endourology and Robotics, (3) ≥ 40 cases as primary surgeon (radical prostatectomy and/or radical cystectomy combined), (4) At least one publication or conference presentation on robot-assisted surgery, and (5) Completion of the official Proctor education seminar. This certification-based definition represents a rigorous, multi-dimensional credentialing standard that incorporates case volume, academic engagement, and formal training assessment. Certified proctors performed 68 procedures (69.4%) and non-proctors 30 procedures (30.6%). All surgeons were right-handed. Detailed profiles are provided in Supplementary Data .

Kinematic data acquisition and processing

The Hinotori system records three-dimensional position data at 1 Hz using the Medicaroid Intelligent Network System. We extracted the bilateral hand controller coordinates (x, y, and z in millimeters) during vesicourethral anastomosis, defined as the interval from the first needle grasp to final knot completion. Missing data ( < 0.1%) were addressed using bidirectional filling. The raw operation log files contain time-stamped three-dimensional Cartesian coordinates (X, Y, Z in millimeters) for each hand controller. Preprocessing included forward-fill followed by backward-fill for missing values, a minimum trajectory length requirement of 100 samples (100 s), and truncation of left and right trajectories to equal length.

Feature engineering framework

We developed a comprehensive feature extraction pipeline that generated 25 kinematic parameters across five categories, all derived solely from 3D position coordinates, making them theoretically extractable from any robotic system with position tracking capability (Table ): Movement Smoothness: Dimensionless jerk, and jerk mean.

Speed Characteristics: Mean velocity, coefficient of variation, and percentile distributions (25th).

Movement Patterns: Dwell-time percentage (velocity <2 mm/s) and peak density in the velocity profile.

Workspace Utilization: Three-dimensional bounding box volume and range of motion.

Path Efficiency: Ratio of Euclidean distance to actual path length.

Bimanual Coordination: Interhand speed correlation, mean distance, motion synchrony, and bilateral dwell synchrony.

Complete mathematical definitions are provided in Supplementary Data . Velocity was computed as the first-order difference of consecutive position coordinates divided by the sampling interval (Δt = 1 s). Speed was defined as the Euclidean norm of the velocity vector. Dimensionless jerk was calculated as DJ = √((1/2)·mean(jerk2) × T5/L2), where jerk is the third-order difference of position, mean(jerk2) is the mean squared jerk magnitude across samples, T is the duration in seconds, and L is the total path length in millimeters. Mean jerk was the average of jerk magnitudes. Peak density was defined as the number of peaks in the speed profile per unit time (peaks/s), identified using scipy.signal.find_peaks with height, distance, and prominence thresholds derived from each trajectory’s speed distribution. Dwell time was the proportion of samples with speed below 2.0 mm/s. Workspace volume was calculated as the three-dimensional bounding box volume (range_X × range_Y × range_Z). Path efficiency was the ratio of the Euclidean distance between the start and end positions to the total path length. Bimanual coordination metrics included: interhand speed correlation (Pearson correlation between left and right hand speeds over the entire time series without windowing), motion synchrony (the mean of Pearson correlations between left- and right-hand speed profiles computed over consecutive, non-overlapping windows of 50 samples, corresponding to 50-s windows at the sampling rate), mean bimanual distance (average Euclidean distance between hands), and bilateral dwell synchrony (proportion of time both hands had speed below the 10th percentile of their respective speed distributions).

Statistical analysis and reproducibility

All statistical analyses were conducted using Python 3.8, employing scipy.stats and scikit-learn libraries. Regarding between-group comparisons, we used two-tailed Mann–Whitney U tests with Benjamini–Hochberg false discovery rate correction (α = 0.05). Effect sizes were calculated using Cohen’s d, based on pooled standard deviations. Data are presented as mean ± standard deviation unless otherwise specified. For correlation analyses, Spearman’s rank correlation was used, as non-normal distributions were confirmed using Shapiro–Wilk tests. All p-values are reported exactly. Stratified sampling was used to maintain class balance in all machine learning models. Error bars in the figures represent the standard error of the mean. Partial correlations were controlled for anastomosis time to identify efficiency-independent features.

To assess model robustness to individual surgeon effects, we performed sensitivity analysis evaluating classification performance under different surgeon inclusion/exclusion conditions. For each scenario (all data, without highest-volume non-proctor surgeon contributing 16/30 non-proctor cases, etc.), we conducted 10 iterations of stratified 80/20 train-test splits and computed mean AUC. To assess generalization to unseen surgeons, we additionally performed leave-one-surgeon-out and surgeon-grouped (five-fold) cross-validation, holding out all cases from a given surgeon as the test set. Because most surgeons contributed cases of a single expertise class, we report pooled out-of-fold AUC, with feature standardization fit within each training fold. We further evaluated parsimonious models restricted to the three highest-importance features (Fig. ) using both Random Forest and logistic regression. To evaluate the impact of the 1 Hz sampling limitation on jerk-based features, we compared classification performance with and without jerk-based features using the same classification pipeline (20 stratified train-test splits, Random Forest with class_weight = ‘balanced’).

Machine learning implementation

Random Forest classification was implemented using scikit-learn, with hyperparameter optimization performed via five-fold grid search. Parameters included: n_estimators=100, max_depth=None, min_samples_split=5, min_samples_leaf=2, class_weight = ‘balanced’. Random Forest was selected for the main analysis because it: (1) provides feature importance rankings for interpretability, (2) shows robust performance across cross-validation and test sets, and (3) handles potential non-linear relationships without explicit specification. Performance was evaluated using the area under the receiver operating characteristic curve across 20 iterations with different random seeds. Feature importance was determined based on the mean decrease in Gini impurity. Alternative classifiers (SVM, Neural Network, Logistic Regression, Gradient Boosting) were systematically compared (Supplementary Data ). Feature preprocessing included z-score normalization using StandardScaler. Cross-validation used stratified 5-fold splits (shuffle=True, random_state=42).

Clinical outcome extraction

Perioperative outcomes (including console time, blood loss, anastomotic leak, and continence recovery [pad-free at 3/6 months]) were extracted from medical records. Association analyses were conducted using appropriate statistical tests, with clinical thresholds defined in Supplementary Data .

Software environment

All analyses were performed using Python 3.8 with the following packages: numpy ( ≥ 1.24) for numerical computation, pandas ( ≥ 2.0) for data manipulation, scipy ( ≥ 1.10) for signal processing and statistical tests, scikit-learn ( ≥ 1.2) for machine learning, and matplotlib ( ≥ 3.7) for visualization.

Code availability

The custom Python code for kinematic feature extraction, expertise classification, and surgeon-aware validation, which reproduces the central findings of this study, will be made available in a public repository with a permanent DOI upon publication. The released code does not include patient-identifiable raw surgical logs. The code was developed using Python 3.8 with the following key dependencies: numpy (≥1.24), pandas (≥2.0), scipy (≥1.10), scikit-learn (≥1.2), and matplotlib (≥3.7). The code includes: (1) feature extraction functions for all 25 kinematic metrics with the mathematical definitions described in the Methods, (2) machine learning pipeline with hyperparameter configurations (Random Forest: n_estimators=100, max_depth=None, class_weight = ‘balanced’, random_state=42), and (3) visualization scripts for generating all figures. No custom software or specialized hardware is required beyond standard Python scientific computing packages.
